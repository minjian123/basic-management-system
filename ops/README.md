# ops — 产品运维脚本

> 根目录 `ops/` 承载**产品交付形态**的运维脚本（随产品交付、在部署机运行）：种子数据、备份恢复、租户库迁移等。

## 职责边界

- 根 `ops/` 只放**产品运维脚本**；**不放**开发工具链（见 `scripts/`），**不放**部署产物（见 `deploy/`）。
- **后端开发期运维脚本在 `backend/ops/`**（随后端工程走：模块 / 插件 / 契约检查、租户库初始化与批量迁移、测试库流程、各类 `seed_*.py`、`dev_run.py`），根 `ops/` 与 `backend/ops/` 不重复。
- `scripts/` 只放开发期工具链（dev / deps / base-check / check-docs / preflight / governance / wol 等），不放产品运维脚本。

## 目录状态

当前本目录仅保留本说明文件；根级产品运维脚本随后续交付阶段补充（开发期能力已在 `backend/ops/`）。

## 规划脚本（按阶段补充）

| 能力 | 现状 | 归口 |
| --- | --- | --- |
| 租户库初始化 / 批量迁移 | 已实现于 `backend/ops/init_tenant.py` / `migrate_tenants.py`（开发期形态）；交付形态封装随部署阶段补充 | 部署发布阶段 |
| 备份 / 恢复 | 备份脚本现运行于开发服务器 `~/deploy/backup/`（版本管理源 `scripts/tools/backup/`） | 运维阶段 |
| 种子数据 | 与结构迁移分离，现为 `backend/ops/seed_*.py`（幂等） | 随各业务域 |
