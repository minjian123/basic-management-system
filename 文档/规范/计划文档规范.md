# 计划文档规范

> 计划文档格式契约 · 排期唯一落点

## 1. 目的与适用范围 <a id="purpose"></a>

本规范定义**计划文档**（排期计划）的固定格式，是项目排期管理的**统一契约**：计划表即排期唯一落点，与需求/任务文档三处一致。

- 适用于 `文档/项目/{阶段}/计划/` 下全部计划文档（阶段0 准备期、阶段一 项目骨架已按本规范编写）。
- 本规范只约束**文档怎么写**（可核对、可评审的排期表格式）；管理口径（排期窗口格式、状态与工时）以《[项目管理规范](项目管理规范.md)》为准，两者配套。
- **强制契约**：计划文档必须符合本规范规定格式；字段缺失、窗口格式不符即为不合格文档。
- 与《[文档生成规范](文档生成规范.md)》、《[需求文档规范](需求文档规范.md)》、《[任务文档规范](任务文档规范.md)》同时适用。

## 2. 文件组织 <a id="files"></a>

```text
计划/
└── 01_计划_{阶段}.md        # 一个阶段一份排期计划（01 起编号，顺延）
    └── 例：01_计划_准备期.md
```

- 计划文档按阶段组织，一个阶段一份；编号 `01` 起顺延。
- 计划文档**不创建独立对象**，它把排期「落到任务」——映射到对应阶段任务的状态/工时/完成日期（见第 5 节）。

## 3. 固定章节 <a id="sections"></a>

| 章节 | 标题（固定） | 锚点 | 内容 |
| --- | --- | --- | --- |
| 计划说明 | `## 1. 计划说明` | `purpose` | 排期对象、口径、里程碑锚点、负责人 |
| 已完成任务 | `## 2. 已完成任务（{区间}）` | `done` | 已完成任务汇总表（下表，区间为实际完成区间） |
| **剩余排期** | `## 3. 剩余任务排期（自 {日期}）` | `todo` | 剩余任务排期表（下表，核心核对对象） |
| 甘特图 | `## 4. 排期甘特图` | `gantt` | mermaid gantt（人读） |
| 里程碑对照 | `## 5. {阶段}验收门禁` 或里程碑对照 | `accept` | 验收点/里程碑对照 |
| 风险对策 | `## 6. 风险与对策` | `risk` | 风险表 |
| 变更记录 | `## 7. 变更记录` | `changes` | 日期/变更 |

> 章节序号可按内容增删，但**已完成任务表**与**剩余排期表**两张表必须存在且列头固定。

## 4. 已完成任务表 <a id="done"></a>

列固定为（顺序不可变）：

```markdown
| 编号 | 任务 | 工时（重估） | 完成日期 | 任务文件 |
| --- | --- | --- | --- | --- |
| 01-1 | mjbk Ubuntu 基础 | 4h | 2026-08-15 | [01-1](../任务/01_环境与工具链_01-1_mjbk_Ubuntu基础.md) |
```

- **编号**：任务主键（`{域两位}-{序号一位}`），与任务文档编号一致。
- **工时（重估）**：`{数字}h`；未完成部分/不适用填 `—`。
- **完成日期**：`YYYY-MM-DD`。
- **任务文件**：相对链接，指向任务文档。

## 5. 剩余任务排期表 <a id="todo"></a>

列固定为（顺序不可变）：

```markdown
| 编号 | 任务 | 工时 | 依赖 | 排期窗口 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 01-5 | 备份体系 | 4h | 01-1/01-3/02-1/03-2 | 2026-08-24 ~ 2026-08-25 | 三库 dump + GitLab |
| 03-5 | 平台备份联动 | 1h | 01-5 | 2026-08-26 | Kiwi 数据纳入 01-5 备份脚本 |
| 02-6 | Renovate 与 GitHub 归档 | 3h | mjbk 外网恢复 | 搁置（暂排 M1 之后） | 不入甘特图，外网恢复后排期 |
```

| 列（固定） | 值格式 | 说明 |
| --- | --- | --- |
| 编号 | `{域两位}-{序号一位}` | 与任务文档编号一致（主键） |
| 任务 | 任务名 | 与任务文档标题一致（校验用） |
| 工时 | `{数字}h` | 与任务文档工时一致 |
| 依赖 | `{编号}/{编号}` 或文字 | 甘特依赖（人读） |
| **排期窗口** | 见 5.1 | 排期唯一口径 |
| 备注 | 自由文本 | 搁置原因等 |

### 5.1 排期窗口格式 <a id="window"></a>

「排期窗口」取值固定为下列三种之一：

| 窗口写法 | 示例 | 含义 |
| --- | --- | --- |
| 区间 | `2026-08-24 ~ 2026-08-25` | 开始与截止 |
| 单日 | `2026-08-26` | 开始截止同日 |
| 搁置 | `搁置（…）` 或 `搁置` | 不排日期；备注记搁置原因 |

- 区间分隔符固定为 ` ~ `（空格 + 波浪号 + 空格），两端 `YYYY-MM-DD`。
- 单日必须 `YYYY-MM-DD`。
- 搁置行不得填日期。
- 其它任意写法（缺日期、`TBD`、自然语言日期）视为**格式违规**。

## 6. 与任务/需求文档一致性 <a id="mapping"></a>

| 计划文档字段 | 对应字段 | 说明 |
| --- | --- | --- |
| 剩余排期表·排期窗口 | 计划解释 | 按 5.1 解析 |
| 剩余排期表·工时 | 任务信息表·工时 | 与任务文档工时分歧时以计划表为准（重估口径） |
| 已完成表·完成日期 | 任务信息表·完成日期 | 与任务文档完成日期一致 |
| 已完成表·状态 | 任务/需求文档状态 | 已完成任务须三处一致 |

**核对顺序**：需求总清单（状态/日期）→ 任务信息表（状态/日期/工时）→ 计划表（工时/完成日期/排期窗口），三处不一致时以最新回写为准并修正其它两处。

## 7. 检查清单 <a id="checklist"></a>

- □ 已完成任务表五列、剩余排期表六列表头与顺序正确
- □ 编号与任务文档编号一致（主键对齐）
- □ 排期窗口只取 5.1 三种格式；搁置行无日期
- □ 工时 `{数字}h` 可被提取；与任务文档分歧处已注明重估口径
- □ 甘特图为 mermaid（人读）
