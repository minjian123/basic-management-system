3.2 配置体系

按设计第 4 节落地，实现于 backend/app/core/config.py（140 行）：

  • 加载顺序（后者覆盖前者）：config.toml 公共段 → config.toml 环境段（[env.dev] / [env.test] / [env.prod]，由 BMS_ENV 指定）→ 环境变量 BMS_* → init 参数
  • 实现方式：pydantic-settings 自定义数据源——_TomlSource（tomllib 解析 + 环境段深合并）与 _EnvVarSource（BMS_<节>_<键> 映射），经 settings_customise_sources 组合
  • 配置模型：Settings 聚合 AppSettings / LogSettings / DatabaseSettings / RedisSettings / SnowflakeSettings，统一入口 get_settings()，禁止散落 os.getenv
  • config.toml：全量中文注释（含 MySQL/PostgreSQL 连接串示例与部署说明），密钥类不入文件
  • .env.example：仅变量名与占位值，不填真实密钥
  • 关键行为：BMS_ENV 特例映射 app.env；环境段支持小节覆盖与扁平键覆盖（如 [env.prod] 下 debug = false）
