1. 环境准备

本指南以 Windows + PowerShell 为准（开发主力环境）；macOS/Linux 命令差异在括号内注明。版本为实测基线（2026-08-05）：

2. 后端

2.1 安装依赖

cd backend
uv sync
  • uv sync 按 pyproject.toml + uv.lock 创建 .venv 并安装全部依赖（含 dev 组：ruff / pyright / pytest 等）
  • Python 解释器版本由 .python-version（3.14）自动管理，无需手动安装；首次运行 uv 会自行下载
  • 命令统一带 uv run 前缀，无需手动激活虚拟环境

2.2 验证配置加载

当前骨架已完成配置模块（实施记录 3.2 节），可先验证配置加载是否正常：

# 查看默认配置（dev 环境）
uv run python -c "from app.core.config import get_settings; s = get_settings(); print(s.app, s.database, s.redis, s.snowflake)"

# 验证 BMS_ENV 切换环境段（[env.prod] debug=false 覆盖公共段）
$env:BMS_ENV = "prod"
uv run python -c "from app.core.config import get_settings; s = get_settings(); print(s.app.env, s.app.debug)"

# 验证环境变量覆盖（BMS_<节>_<键>）
$env:BMS_LOG_LEVEL = "DEBUG"
uv run python -c "from app.core.config import get_settings; s = get_settings(); print(s.log.level)"

# 还原
Remove-Item Env:BMS_ENV, Env:BMS_LOG_LEVEL

5. 常见问题

现象处理
uv sync 下载解释器很慢uv 自动下载 Python 3.14 到本地缓存，仅首次发生；或先手动安装 Python 3.14 后 uv sync 直接复用
PowerShell 提示「无法加载，因为在此系统上禁止运行脚本」执行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 后重试
Windows 下 SQLite 相对路径不一致config.toml 中 sqlite+aiosqlite:///./data/xxx.db 相对 backend 目录解析；确保在 backend 目录下执行命令
环境变量残留导致配置异常检查 $env:BMS_*；PowerShell 用 Get-ChildItem Env:BMS_* 查看，Remove-Item Env:BMS_* 清理
