## 2. 准备期目标与范围 <a id="goal"></a>

**M0 目标**（《总体项目规划》7.1 M0 行）：环境 / 仓库 / CI 就绪，可进入阶段一骨架开发。周期口径 2 周（兼职，T+0 启动）。

**范围内**（共 15 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 一 环境与工具链 | mjbk Ubuntu 基础、Docker 与 ufw、三库 + Redis + MinIO 常驻、运维工具链、备份体系、mjpc 开发机 |
| 二 仓库与 CI | GitLab CE + runner、仓库迁移与分支模型、MR/main 流水线、缺陷自动上报、Renovate 与 GitHub 归档 |
| 三 测试与项目管理平台 | Kiwi TCMS、平台分工、备份联动 |

**范围外**：

- 阶段一及以后交付物（monorepo 骨架代码、三库驱动兼容性验证等，见《总体项目规划》第 10 节风险表）
- 预留业务模块（销售 `sale_`、仓储 `wh_`，预留不排期，见《总体项目规划》第 8 节）
- 对外集成、第三方系统对接

> 边界说明：仓库迁移与分支模型属准备期（已完成）；`backend/frontend/frontend-mobile` 工程骨架属阶段一。`.gitlab-ci.yml` 流水线**框架**（02-3/02-4 六类 job）已于 2026-08-23 落地、main 空载通过；端到端执行（E2E/三库集成/镜像/契约/Allure）随阶段一代码落地自动激活，Trivy 镜像扫描因外网依赖暂缓（《开发部署规划》第 10 节口径）。

## 4. M0 验收门禁 <a id="accept"></a>

门禁定义（《总体项目规划》7.1 M0 行）：**环境 / 仓库 / CI 就绪，可进入骨架开发**。逐项核对：

| 验收点 | 核对方式 | 对应需求 | 结论 |
| --- | --- | --- | --- |
| 环境可达 | mjpc SSH 免密到 mjbk；三库 / Redis / MinIO 可连通 | 01-1 ~ 01-3、01-6 | 达标 |
| 工具链可用 | WOL 唤醒/关机实测；bg 往返；graphify query | 01-4 | 达标 |
| 平台可用 | Kiwi TCMS 可用 | 03-1、03-4 | 达标 |
| 仓库就绪 | bms 仓库在 GitLab；main 保护分支 + MR 流转 | 02-1、02-2 | 达标 |
| CI 就绪 | MR 门禁 + main 流水线框架已落地；main 空载通过（2026-08-23 复核最近 5 次 success）；端到端执行（E2E/三库/镜像/契约/Allure）随阶段一代码落地自动激活；Trivy 镜像扫描因外网依赖暂缓 | 02-3、02-4 | 达标（框架就绪、空载通过） |
| 备份就绪 | 三库 / GitLab / Kiwi 定时备份 + 恢复演练 + 云容灾 | 01-5、03-5 | 达标 |

**结论**：M0 门禁全部达成，准备期完成，可进入阶段一骨架开发。其中 CI（02-3/02-4）为「框架就绪、空载通过」——六类 job 已全部定义，阶段一代码落地后自动激活端到端执行；Trivy 镜像扫描因镜像需外网拉取（mjbk 外网不可达）暂缓，不阻塞其余 job。02-5 缺陷上报脚本已就绪；02-6 Renovate 已于 2026-08-23 实际启用（修正指向 `bms/bms`、禁用 gitlabci、pep621 管理 `mcp`），GitHub push mirror 正常。
