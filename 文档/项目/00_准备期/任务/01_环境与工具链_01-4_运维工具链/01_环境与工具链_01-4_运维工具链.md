## 2. 任务内容 <a id="content"></a>

1. WOL 远程唤醒/关机：`deploy/tools/wol/`（`wake_mjbk.py` 发魔术包并等待 SSH 就绪；`shutdown_mjbk.py` 为破坏性操作，执行前必须确认）；凭据从 `deploy/.env` 读取，不硬编码
2. bg 后台执行器：`deploy/tools/bg/`（bg-run/bg-status/bg-stop），长命令后台化 + 秒级轮询状态，替代同步阻塞
3. graphify 知识图谱：`graphify update/query/path/explain`；更新后跑 `deploy/tools/graphify/localize-graph.py` 收尾汉化
4. 禅道 API 工具包：`deploy/tools/zentao/`（CLI + ZentaoClient），凭据读 `deploy/.env` 的 `ZENTAO_API_*`；API 踩坑已固化（Token 认证头、任务创建走 batchCreate、子任务父级走 URL 参数等）

## 3. 完成标准 <a id="accept"></a>

唤醒/关机实测可用；bg_run/bg_status 往返通过；`graphify query` 返回子图；`zentao.py tasks list/search` 实测可用。
