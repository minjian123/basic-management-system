## 2. 任务内容 <a id="content"></a>

1. 统一响应模型（`app/schemas/common.py`）：ApiResponse（code/message/data，code=0 成功）、PageResponse（list/total/page/size）；分页参数 page（1 起）/size（默认 20 上限 200）公共 Schema
2. 异常体系（`app/core/exceptions.py`）：BizError(code, detail) 基类；全局异常处理器注册于 create_app——BizError → HTTP 200 + `{code, message, data: null}`；RequestValidationError → 422 + 10001；未捕获 → 500 + 10002（不暴露堆栈）；HTTPException 透传语义
3. 基础错误码登记「错误码总表」：10001 参数校验失败、10002 系统内部错误、10003 资源不存在、10004 操作不允许；发布后不可更改含义、段内递增不复用
4. 文案口径：后端不拼装文案，前端按 `error.{code}` i18n 映射

## 3. 完成标准 <a id="accept"></a>

`raise BizError(10003)` 经接口返回 HTTP 200 + `{"code": 10003, "data": null}`；非法请求体返回 422 + 10001；未捕获异常返回 500 + 10002 且响应体无堆栈；四错误码已登记。
