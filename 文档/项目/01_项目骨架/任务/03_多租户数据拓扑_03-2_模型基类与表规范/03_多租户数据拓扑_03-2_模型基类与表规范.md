## 2. 任务内容 <a id="content"></a>

1. `app/models/base.py` BaseModel：主键 id 雪花 ID（yitter/IdGenerator，BIGINT，生成器封装于 `app/core/id.py`）；审计 created_at/created_by/updated_at/updated_by（ORM 事件自动填充，禁止手动赋值）；软删除 deleted_at；乐观锁 version（更新比对，冲突明确错误码）
2. 四库类型映射表（写入模型定义注释）：id BIGINT（达梦自增列口径）；时间 DATETIME/TIMESTAMP；version INT；布尔 INTEGER/TINYINT(1)/SMALLINT；时间 UTC 存储；金额 NUMERIC(20,4)；禁用方言专用类型
3. 软删除机制：查询默认过滤 deleted_at IS NULL（repository 基类统一注入）；唯一约束建 (唯一字段, deleted_at) 复合唯一索引（达梦按 Oracle 兼容口径实测验证）；删除写时间戳释放唯一键、恢复清 NULL；PostgreSQL 部分唯一索引可选
4. 索引规范：排序/外键/数据权限过滤字段必建索引；idx_/uq_ 前缀；每表 ≤ 5 个
5. 表级规范：表名单数 snake_case；前缀平台域 sys_/wf_/rpt_/ai_ 与业务 {简称}_；表与字段 COMMENT 中文必填

## 3. 完成标准 <a id="accept"></a>

基于 BaseModel 的示例模型（sys_tenant 复用验证）四库均能建表；审计字段插入/更新自动填充实测通过；同值两行未删插入被 (唯一字段, deleted_at) 索引拒绝、软删除后再插入同值成功（达梦实测）；乐观锁版本冲突返回明确错误码。
