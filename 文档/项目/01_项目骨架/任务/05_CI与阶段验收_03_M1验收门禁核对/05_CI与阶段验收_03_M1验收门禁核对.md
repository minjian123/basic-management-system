## 2. 任务内容 <a id="content"></a>

1. 五项门禁逐项核对，每项留可复现核对命令与证据（截图/日志片段/流水线链接）：本地起服务（uvicorn + 双端 dev，启动日志 + 页面截图）；CI 通过（main 最近一次含代码推送全绿，流水线链接）；健康检查正常（curl /healthz 200、/readyz 200、停 Redis 后 503，命令输出）；三库拓扑可路由（三库集成 job + 01_06 达梦验证矩阵）；模块注册校验生效（冲突种子启动/CI 拒绝记录 + GET /api/v1/modules 返回 9 条）
2. 核对结论回写本阶段需求总览「M1 验收门禁」表（达标/不达标 + 证据索引）；24 条需求状态同步更新（已完成/完成日期）
3. 未达标项：记录阻塞原因与补救排期，触发里程碑评审（滚动调整工期基线，回写《总体项目规划》里程碑日期）
4. 文档收口：M1 阶段需求/任务/计划文档全部更新为终态（已完成 + 完成日期），评审结论留档

## 3. 完成标准 <a id="accept"></a>

门禁表五项结论全部落文档且均有证据索引；24 条需求状态与完成日期回写完毕；M1 阶段文档全部终态收口；评审结论落档。
