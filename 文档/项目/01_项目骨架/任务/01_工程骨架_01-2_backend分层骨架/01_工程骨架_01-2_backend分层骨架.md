## 2. 任务内容 <a id="content"></a>

1. `backend/app` 分层目录：`core`（配置、安全、异常处理）、`api`（路由层，按模块）、`models`、`schemas`、`services`、`repositories`（多数据源/分片路由）、`db`（异步引擎、AsyncSession、读写分离路由）、`tasks`、`ws`、`i18n`
2. `alembic/`、`tests/`、`config.toml`、`pyproject.toml` 就位（alembic.ini 随 03-3 细化）
3. 分层职责落地：api 层只做参数校验与路由分发；services 层承载业务逻辑；repositories 层承载数据访问与数据源路由；禁止在 api 层直接操作模型

## 3. 完成标准 <a id="accept"></a>

目录齐全、分层职责注释与骨架代码一致；`uv run uvicorn` 可启动空应用（/docs 可访问）；pytest 空用例可运行。
