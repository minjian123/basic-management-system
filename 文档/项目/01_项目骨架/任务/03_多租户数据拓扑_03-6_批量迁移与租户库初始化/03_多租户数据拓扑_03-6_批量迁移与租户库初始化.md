## 2. 任务内容 <a id="content"></a>

1. Alembic 结构（`backend/alembic/`）：env.py 按数据源读 URL、区分平台库/租户库迁移上下文；versions/ 三套方言脚本（不写方言 SQL、达梦注意 schema 前缀）；SQLite 开发库自动建表
2. 批量迁移脚本 `ops/migrate_tenants.py`：参数 `--target all|tenant_code|platform`、`--db mysql|postgres|dameng`、`--dry-run`；遍历 sys_tenant 逐库迁移；失败不中断后续库、输出成功/失败/跳过汇总、失败库重跑幂等
3. 新租户初始化 `ops/init_tenant.py`：建库 → 三套迁移 → 幂等种子；种子机制（backend/alembic/seeds/ 或 ops/seeds/，幂等可重复，与结构迁移分离）；阶段一种子仅空租户基线
4. 迁移验证矩阵：三库各跑「迁移 → 建表检查 → 回滚/再迁移」；CI 三库流程与 05-2 衔接

## 3. 完成标准 <a id="accept"></a>

迁移脚本三库各执行通过（sys_tenant + sys_module 表就位）；migrate_tenants.py --dry-run 输出正确库清单、实际执行后 demo 租户库 schema 与平台库一致；init_tenant.py 新租户（t1）建库→迁移→种子一次跑通且重跑幂等无报错。
