## 2. 任务内容 <a id="content"></a>

1. structlog 配置（`app/core/logging.py`）：processors 链（时间戳/级别/logger 名/上下文合并/堆栈单行化/JSON 渲染）；输出 stdout；级别默认 dev=DEBUG、prod=INFO；禁止 print
2. 上下文字段中间件注入：request_id、trace_id（读 `X-Trace-Id` 头，缺失生成 UUID4）、tenant（03-4 接入后启用）、user_id/user（阶段二启用）、client_ip、duration_ms
3. 请求日志中间件：每请求 1-2 条（进入 + 结束带 status/duration_ms）；4xx WARNING、5xx ERROR；未捕获异常 ERROR + 堆栈单行，生产响应不回显堆栈
4. 脱敏清单：密码、token、验证码、私钥、PII、连接串密码、ORM bind params、第三方密钥；慢查询依赖三库慢查询日志

## 3. 完成标准 <a id="accept"></a>

请求日志为单行 JSON 且含 request_id/trace_id/client_ip/duration_ms；`X-Trace-Id: abc` 请求日志 trace_id 为 `abc`；未捕获异常 ERROR 行堆栈单行、响应无堆栈；密码/token 全量日志不出现明文。
