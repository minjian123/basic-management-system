## 2. 任务内容 <a id="content"></a>

1. structlog 结构化 JSON 日志，每行一条；字段名 snake_case，`event` 为动作描述；禁止 print
2. 级别 DEBUG / INFO / WARNING / ERROR / CRITICAL 按《日志规范》第 2 节口径；DEBUG 默认关闭（dev 可开）
3. 上下文字段（trace_id / tenant / user_id / user / duration_ms / client_ip / request_id）由中间件注入，业务代码只记业务字段
4. 脱敏：密码、令牌、验证码、PII、连接串密码一律不出现明文（《日志规范》第 5 节）；异常堆栈单行合并

## 3. 完成标准 <a id="accept"></a>

请求日志按 JSON 格式输出且含上下文字段；敏感字段不回显；堆栈单行可被逐行解析。
