## 2. 任务内容 <a id="content"></a>

1. SQLAlchemy 2.0+ 异步 ORM：`app/db` 异步 engine 管理、AsyncSession 工厂；异步会话不可跨请求共享
2. 四库方言：SQLite（本地 dev）、MySQL、PostgreSQL、达梦 DM8（`dm+dmPython`），URL 从 config.toml 读取
3. 基础异常与错误码骨架（`app/core/exceptions`，统一异常处理与响应格式，供后续模块复用）
4. 读写分离路由占位（`app/db`，阶段九前主从同源即可）

## 3. 完成标准 <a id="accept"></a>

SQLite 本地 Alembic 迁移 + CRUD 冒烟通过；MySQL / PostgreSQL / 达梦三方言 engine 连通冒烟通过（完整迁移验证见 03-3）。
