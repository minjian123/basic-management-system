## 2. 任务内容 <a id="content"></a>

1. Alembic 配置：`alembic/` + `alembic.ini`，URL 从 config.toml 读取
2. 批量迁移脚本：遍历全部租户库执行迁移；新租户开通自动建库 + 迁移 + 种子（基础工具；租户开通业务功能在阶段三）
3. 三库方言验证：MySQL / PostgreSQL / 达梦 DM8 迁移脚本分环境验证（方言差异，达梦按 Oracle 兼容口径）

## 3. 完成标准 <a id="accept"></a>

迁移脚本在 MySQL / PostgreSQL / 达梦三库执行通过；新租户库批量创建 + 迁移 + 种子至少一次实测跑通。
