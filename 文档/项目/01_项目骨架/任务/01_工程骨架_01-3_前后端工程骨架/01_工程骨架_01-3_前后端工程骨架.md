## 2. 任务内容 <a id="content"></a>

1. `frontend`：Vue 3 + Vite + Element Plus；`src/api`（Axios 封装与接口定义）、`router`（动态路由生成）、`stores`（Pinia）、`views`（按模块）、`layouts`、`components`、`i18n`（中英文文案）、`utils`；`package.json`、`.nvmrc`
2. `frontend-mobile`：Vue 3 + Vant（移动端 H5：审批、通知、数据查询）
3. Node 版本 `.nvmrc` 固定（≥ 20.19），volta/fnm 管理（自动读 `.nvmrc`）

## 3. 完成标准 <a id="accept"></a>
