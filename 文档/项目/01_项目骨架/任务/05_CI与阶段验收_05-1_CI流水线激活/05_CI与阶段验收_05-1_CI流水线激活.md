## 2. 任务内容 <a id="content"></a>

1. 激活口径（单人开发期直推 main 不走 MR）：`.gitlab-ci.yml` 既有 job 以 exists 守卫——backend/ 存在跑 Python 系、frontend/ 存在跑前端系；纯文档推送继续免 CI
2. main 冒烟层（含代码改动直推自动执行）：gate-smoke + ruff check + pyright + pytest（SQLite）+ ESLint + Vitest + 双构建；任一步失败 pipeline 红
3. 重验证层（仅 main）：Playwright E2E（SQLite 起 backend + 前端产物，骨架期覆盖三工程可达/健康检查探针/模块查询接口）、三库集成（05-2）、镜像构建推 Registry（bms-backend/bms-frontend）、Trivy 扫描（CVSS ≥ 9 阻断；外网不可达暂缓不阻塞）、swagger.json 契约快照、Allure 归档导入 Kiwi TCMS
4. 覆盖率门禁：pytest-cov 接入（核心 ≥ 80% / 整体 ≥ 70% 为后续阶段达标线）；骨架期阈值按 70% 起步并注明随阶段递增口径
5. 02-4 收口衔接：重验证层真实数据跑通后回写准备期文档（执行详情在 05-2）

## 3. 完成标准 <a id="accept"></a>

含代码改动的 main 推送自动跑冒烟层且全绿；重验证层六类 job 全绿（Trivy 暂缓项按暂缓口径标注）；覆盖率报告产出且低于阈值时 pipeline 红；纯文档推送不触发 CI。
