## 2. 任务内容 <a id="content"></a>

1. `/healthz`：GET，进程存活即 200，响应 `{"status": "ok"}`，不触碰 DB/Redis
2. `/readyz`：GET，依赖检查——全部就绪 200 / 任一不可达 503；响应体 `{status, checks: {database: {ok, latency_ms}, redis: {ok, error}}}`；检查项 database（平台库 SELECT 1）、redis（PING）、minio（阶段一未接入则省略该键）；每项超时 2 秒；error 仅写异常类别不暴露连接串/堆栈
3. 鉴权豁免：两探针不在 Bearer 校验范围（与登录/刷新同列豁免清单）
4. 路由注册：`app/api/health.py` 独立 APIRouter 统一 include；不计限流（阶段二排除清单预留）

## 3. 完成标准 <a id="accept"></a>

本地起服务后两探针均 200 且响应体结构正确；停 Redis 后 /readyz 503 且 checks.redis.ok=false、/healthz 保持 200；停平台库后 /readyz 503 且 checks.database.ok=false；响应体无密码/连接串信息。
