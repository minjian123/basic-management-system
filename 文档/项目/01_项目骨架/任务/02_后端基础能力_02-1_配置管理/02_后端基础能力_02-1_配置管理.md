## 2. 任务内容 <a id="content"></a>

1. `config.toml` 单配置文件 + 环境变量覆盖（12-factor）；敏感项（DB URL、密钥）只走环境变量，不落仓库
2. 三套环境 dev / test / prod 由 `BMS_ENV` 区分，按环境分层配置
3. 数据源声明（多库，含主从连接占位）在 config.toml（口径见《项目规划说明》第 10 节）
4. 配置读取封装（`app/core/config.py`，Pydantic 校验），启动时加载并校验必填项

## 3. 完成标准 <a id="accept"></a>

三环境可切换加载；环境变量覆盖生效（如 DB URL 以环境变量注入优先于文件）；缺失必填项启动即报错并指出字段。
