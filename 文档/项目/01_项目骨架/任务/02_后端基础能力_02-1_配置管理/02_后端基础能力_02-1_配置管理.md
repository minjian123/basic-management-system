## 2. 任务内容 <a id="content"></a>

1. `config.toml` 分区与键清单：`[app]`（name/env/debug）、`[server]`（host/port/workers）、`[log]`（level/format）、`[database]`（platform/tenants/archive，每库 primary/replicas + pool_size/max_overflow/pool_recycle/pool_pre_ping）、`[redis]`、`[minio]`（占位）、`[security]`（占位）、`[cors]`；键逐项中文注释
2. 环境分层：`BMS_ENV` 指定 dev/test/prod；基础节 + `[env.dev]`/`[env.test]`/`[env.prod]` 覆盖节；`BMS_` 前缀环境变量映射覆盖配置键（`BMS_DB_URL` → database.platform.url）；密钥类配置只走环境变量
3. `app/core/config.py` pydantic-settings 建模（Settings 类），lifespan 内加载校验（必填缺失/类型错误启动失败并报字段名），结果存 `app.state.settings`
4. 敏感值保护：任何位置不回显配置密码（与 02-2 脱敏联动）

## 3. 完成标准 <a id="accept"></a>

`BMS_ENV=dev|test|prod` 三环境可切换加载；`BMS_DB_URL` 环境变量注入后覆盖生效；删除必填键后启动报错并指出字段名；三环境差异处（日志级别、CORS）加载结果正确。
