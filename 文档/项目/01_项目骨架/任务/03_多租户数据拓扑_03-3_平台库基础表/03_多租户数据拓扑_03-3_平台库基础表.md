## 2. 任务内容 <a id="content"></a>

1. `sys_tenant` 表（平台库）：code VARCHAR(32)（(code, deleted_at) 复合唯一，建库后缀来源）、name VARCHAR(64)、domain VARCHAR(128) 可空（子域名解析来源）、db_key VARCHAR(32)（数据源配置键）、status SMALLINT 默认 1、expire_at DATETIME 可空（阶段三起用）+ 基类字段；索引 uq_code_deleted_at、idx_domain
2. `sys_module` 表占位引用（表结构与种子在 04-1，与 sys_tenant 同迁移流水线）
3. 种子：demo 租户记录（code=demo、name=演示租户、db_key=tenants、status=1），走 Alembic 数据迁移或幂等种子脚本
4. 范围约束：阶段一只建 sys_tenant 与 sys_module；其余平台表随阶段二/三交付

## 3. 完成标准 <a id="accept"></a>

sys_tenant 三库迁移通过；demo 种子落库可查询；(code, deleted_at) 复合唯一索引生效（重复 code 插入被拒）；其余平台表未建。
