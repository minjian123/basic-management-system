## 2. 任务内容 <a id="content"></a>

1. `/healthz` 存活探针：进程存活即 200
2. `/readyz` 就绪探针：检查依赖连通性（DB / Redis；MinIO 按依赖接入情况），依赖不可达返回不健康（503），供编排系统滚动发布
3. 探针响应体含各依赖状态明细
4. 鉴权豁免：健康检查不在 Bearer 校验范围（《项目规划说明》第 8 节口径）

## 3. 完成标准 <a id="accept"></a>

本地起服务 `/healthz`、`/readyz` 均 200；停 Redis / DB 后 `/readyz` 变不健康、`/healthz` 保持 200。
