## 1. 域说明 <a id="intro"></a>

本域对应禅道 M1 迭代父任务「02 后端基础能力」（待建），覆盖四块：

- **配置管理**：config.toml + 环境变量覆盖，BMS_ENV 三环境

**目标**：backend 具备可配置、可观测、可探活、可连库的基础能力，支撑 03 域数据拓扑与后续全部模块。

## 2. 需求 02-1：配置管理 <a id="r02-1"></a>

优先级：2（高）　|　禅道 story：—　|　禅道任务：—　|　状态：未开始　|　完成日期：—

**内容**（《项目规划说明》3.1/17、《总体项目规划》第 12 节）：

3. 数据源声明（多库，含主从连接占位）在 config.toml（为 03 域数据源路由预留，口径见《项目规划说明》第 10 节）

**完成标准**：三环境可切换加载；环境变量覆盖生效（如 DB URL 以环境变量注入优先于文件）；缺失必填项启动即报错并指出字段。

**参考文档**：《项目规划说明》3.1/17、《总体项目规划》第 12 节

## 3. 需求 02-2：日志体系 <a id="r02-2"></a>

优先级：2（高）　|　禅道 story：—　|　禅道任务：—　|　状态：未开始　|　完成日期：—

**内容**（《日志规范》）：

1. structlog 结构化 JSON 日志，每行一条；字段名 snake_case，`event` 为动作描述；禁止 print
2. 级别 DEBUG / INFO / WARNING / ERROR / CRITICAL 按《日志规范》第 2 节口径；DEBUG 默认关闭（dev 可开）
3. 上下文字段（trace_id / tenant / user_id / user / duration_ms / client_ip / request_id）由中间件注入，业务代码只记业务字段
4. 脱敏：密码、令牌、验证码、PII、连接串密码一律不出现明文（《日志规范》第 5 节）；异常堆栈单行合并

**完成标准**：请求日志按 JSON 格式输出且含上下文字段；敏感字段不回显；堆栈单行可被逐行解析。

**参考文档**：《日志规范》、《项目规划说明》19.3

## 4. 需求 02-3：健康检查 <a id="r02-3"></a>

优先级：2（高）　|　禅道 story：—　|　禅道任务：—　|　状态：未开始　|　完成日期：—

**内容**（《项目规划说明》2.4/3.4/8/19.3）：

1. `/healthz` 存活探针：进程存活即 200
2. `/readyz` 就绪探针：检查依赖连通性（DB / Redis；MinIO 按依赖接入情况），依赖不可达返回不健康（503），供编排系统滚动发布
3. 探针响应体含各依赖状态明细
4. 鉴权豁免：健康检查不在 Bearer 校验范围（《项目规划说明》第 8 节口径）

**完成标准**：本地起服务 `/healthz`、`/readyz` 均 200；停 Redis / DB 后 `/readyz` 变不健康、`/healthz` 保持 200。

**参考文档**：《项目规划说明》2.4/3.4/8/19.3

## 5. 需求 02-4：SQLAlchemy 接入 <a id="r02-4"></a>

优先级：2（高）　|　禅道 story：—　|　禅道任务：—　|　状态：未开始　|　完成日期：—

**内容**（《项目规划说明》3.1/第 10 节）：

1. SQLAlchemy 2.0+ 异步 ORM：`app/db` 异步 engine 管理、AsyncSession 工厂；异步会话不可跨请求共享
2. 四库方言：SQLite（本地 dev）、MySQL、PostgreSQL、达梦 DM8（`dm+dmPython`），URL 从 config.toml 读取
3. 基础异常与错误码骨架（`app/core/exceptions`，统一异常处理与响应格式，供后续模块复用）
4. 读写分离路由占位（`app/db`，阶段九前主从同源即可）

**完成标准**：SQLite 本地 Alembic 迁移 + CRUD 冒烟通过；MySQL / PostgreSQL / 达梦三方言 engine 连通冒烟通过（完整迁移验证见 03-3）。
