## 1. 域说明 <a id="intro"></a>

本域对应禅道 M1 迭代父任务「01 工程骨架」（待建），覆盖四块：

- **monorepo 仓库骨架**：backend / frontend / frontend-mobile 三工程 + deploy / scripts
- **backend 分层骨架**：core / api / models / schemas / services / repositories / db 分层职责落地
- **前端双工程骨架**：Vue 3 + Vite（Element Plus / Vant），router / stores / api / i18n 目录
- **依赖锁定与兼容验证**：uv 锁定、Python 3.14 与核心依赖（含 dmPython）逐依赖验证

**依据**：《[项目规划说明](../../规划/项目规划说明.md)》第 4 节（项目目录结构）、3.1（技术选型）、17 节（环境与配置）、《总体项目规划》第 6 节 WBS。
**目标**：三工程骨架可本地启动，依赖版本锁定，Python 版本口径确定（3.14 保持或整体回退 3.13）。

## 5. 需求 01-4：依赖锁定与 Python 3.14 兼容验证 <a id="r01-4"></a>

优先级：2（高）　|　禅道 story：—　|　禅道任务：—　|　状态：未开始　|　完成日期：—

**内容**（《项目规划说明》2.1/3.1、《总体项目规划》第 10 节风险表）：

1. backend 用 uv 管理依赖：`pyproject.toml` + `uv.lock` 提交仓库；`.python-version` 锁定版本

4. 验证结论落文档；若回退，同步更新《项目规划说明》2.1 与《开发部署规划》第 10 节口径

**完成标准**：`uv sync` 通过；核心依赖 import 冒烟通过（含 dmPython 连接测试）；兼容结论（3.14 保持 / 回退 3.13）落文档并回写《项目规划说明》。
