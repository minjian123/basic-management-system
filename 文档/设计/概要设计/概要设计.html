1. 概述

本文档是 BMS 基础管理系统的概要设计，在《架构设计》（文档/设计/架构设计/架构设计.html）基础上， 描述功能模块划分、模块间关系、核心业务流程与接口/数据/前端概要，作为详细设计（数据库表结构、 接口参数、页面交互）的实施依据。

本文档为设计阶段文档，与《项目规划说明》《命名规范》配套；文中接口路径、表名、权限码命名均遵循《命名规范》。

2.2 模块归属与权限码

  • 每个模块以「业务权限码」标识（sys_business），如 user、wf、purchase、rpt；动作权限码归属业务（sys_action），如 user:create、wf:approve、file:upload
  • 默认归属：平台超管（sys/tenant/menu/business/action）、系统管理员（用户/岗位/部门/字典/配置/文件/会话/邮件/任务/归档/i18n/SSO/回收站/备份）、安全管理员（角色/开放接口/IdP/数据脱敏）、审计管理员（log）、普通角色（工作流/公告/采购/通知/报表/监控/导入导出/AI 对话）
  • 租户开通种子：三类内置管理员角色（系统/安全/审计，权限互斥）预授对应权限码

4. 核心业务流程

4.1 账号密码登录

用户 → 登录页（连续失败 3 次后显示图形验证码）
  → POST /api/v1/auth/login（slowapi 限流：5 次失败锁 15 分钟）
  → PBKDF2 校验密码 → 检查账号状态（停用/锁定）
  → 签发双 token（access 30 分钟内存态 + refresh 14 天 httpOnly cookie）
  → 写 sys_login_log（成功/失败，异步经 RocketMQ）→ 写 sys_session → 返回用户与权限概要

登出：refresh token 加入 Redis 黑名单即时失效；refresh 轮换滚动续期；重置密码后强制失效该账号全部会话。

4.2 SSO 登录

用户 → 登录页选择 IdP 入口（sys_identity_provider，OIDC/CAS/企微/钉钉）
  → 外部 IdP 认证 → 回跳携带身份凭证
  → 经 sys_user_identity 全局映射定位租户与用户
  → 未绑定则 JIT 自动建号（并落 sso.user.jit_created 事件）
  → 签发 BMS 双 token，进入系统
本地账号密码登录并存（超管应急通道，防 IdP 故障锁死）

4.3 请求鉴权与权限校验

请求 → nginx 解析租户子域名 → backend 中间件
  → Bearer access token 校验 → Redis 会话有效标记校验（踢出即时生效）
  → 解析主体链（用户→角色取并集）→ 汇总权限码集合
  → 路由级 require_permission(业务:动作) 校验（动作级数据范围读校验）
  → 响应序列化（字段权限：不可见字段过滤、脱敏字段掩码）
写入类请求在保存前再做一次数据范围校验

4.4 租户开通

平台超管 → 租户管理创建租户（录入 code/名称/域名）
  → 自动建库 bms_tenant_{code} → 双套 Alembic 迁移
  → 种子：三类内置管理员角色 + 初始系统管理员账号 + 默认 IdP 占位
         + 归档策略 + 平台统一菜单/表单/按钮/字段挂接与权限码
  → 落 tenant.created 事件 → 租户侧可登录使用
停用/启用/配额调整同理走平台超管运营视图

4.5 采购审批工作流

申请人 → 提交采购申请（幂等键去重）
  → 启动流程实例（采购三级审批模板：部门经理 → 财务 → 分管领导）
  → 审批人收到待办（Socket.IO 实时 + 站内信）→ 同意/驳回/评论（会签/或签按流程定义）
  → 全部通过 → 生成采购订单（biz_purchase_order）→ 落 purchase.order.created 事件
  → Webhook 订阅方收到推送；审批记录与流程轨迹全量落库

4.6 审计日志与归档

业务写操作 → ORM 事件捕获字段级变更（sys_data_audit_log）
  → 审计事件经 RocketMQ 按租户分区有序消费 → 逐条哈希串联（prev_hash + record_hash）
  → 按月分片落库（sys_operation_log_yyyyMM 等）
  → 90 天归档策略触发：链完整性校验 → 迁归档库（可在线查询）→ 转对象存储冷化
  → 归档文件随哈希链导出，供事后校验；合规销毁记录销毁日志

4.7 文件分片上传

≤20MB：整包上传（类型白名单 + SHA256 校验）→ MinIO 私有桶 → 记录 sys_file 元数据
  >20MB：初始化 upload_id（sys_file 状态=上传中）→ 逐分片上传
  （分片临时对象 .part 标识，逐片 SHA256 校验，支持断点续传）
  → 全部完成后合并为最终对象并清理分片 → 状态=完成 → 落 file.uploaded 事件
  → 下载走预签名 URL（限时有效）；中断遗留孤儿分片由 Celery 定时回收

4.8 通知与 Webhook 推送

业务事件 → RocketMQ 事件总线（事件命名 {域}.{对象}.{动作}）
  → event-worker 消费：
      · 通知类（审批待办等）→ 站内信落库 + Socket.IO 实时推送（Redis 适配器广播）
      · 邮件/短信 → 模板渲染（Jinja2，按收件人 locale）→ aiosmtplib/短信渠道发送 → 发送记录
      · Webhook 订阅 → 匹配事件名 → HMAC 签名推送 → 指数退避重试 → 失败记录

4.9 全文检索同步（阶段十三）

主数据/审计日志/文件内容变更 → RocketMQ 事件 → event-worker 消费
  → 解析文件文本（PDF/Word/Excel/TXT，扫描件走 OCR）→ 写入 ES 索引
  → 查询：ES 命中返回业务 ID + 高亮 → 回查数据库取最新数据（避免双写一致性问题）
  → 索引重建：重放事件流；ES 故障降级数据库模糊查询兜底
  → 检索强制租户隔离（索引含 tenant_id 字段 + 数据权限过滤）

4.10 AI 交互（阶段十四）

用户提问（智能问数/审批辅助/文档问答）→ LLM 适配层（外部 API/私有化可切）
  → 全量落 ai_chat_log 审计（提示词/响应/模型/成本）
  → RAG 检索（Milvus 向量库，按租户隔离）遵守动作级数据权限范围
  → 结果仅辅助展示；自动执行写操作/自动审批默认关闭（开关开启需白名单 + 二次确认 + 可撤销）

5. 接口概要设计

5.1 公共约定

  • 前缀：内部 /api/v1，开放 /api/open；统一响应 {code, message, data}，code=0 成功
  • 错误码 5 位分段：1xxxx 通用 / 2xxxx 认证 / 3xxxx 用户与组织 / 4xxxx 系统配置 / 5xxxx 文件 / 6xxxx 工作流 / 7xxxx 通知邮件任务 / 8xxxx 开放接口租户 SSO / 9xxxx 报表审计归档监控；文案前端按 i18n 映射
  • 分页参数 page/size，响应 {list, total, page, size}；大数据量列表游标分页（cursor/limit）
  • 鉴权：除登录/刷新/健康检查外一律 Bearer access token；权限校验 require_permission 依赖
  • 写接口支持幂等键（请求头 Idempotency-Key，Redis SETNX 前置 + 唯一约束兜底）
  • RESTful 资源式：GET /users、POST /users、PUT /users/{id}、DELETE /users/{id}；动作类 /auth/login、/users/{id}/reset-password

5.2 接口分组

分组典型接口
认证POST /api/v1/auth/login、/auth/refresh、/auth/logout、/auth/captcha、/auth/forgot-password
用户与组织/users（含锁定/解锁/重置密码/绑定角色）、/posts、/departments、/roles（含授权/数据范围）
系统配置/menus（含表单/按钮/字段）、/business、/actions、/dicts、/configs、/i18n/messages

业务/purchase/applies、/purchase/orders、/purchase/suppliers
通知与任务/notifications（批量已读）、/notices（已读回执）、/mails、/sms、/tasks（调度管理/触发）
平台/tenants（开通/停用/配额）、/idps、/sessions（踢出）、/webhooks、/open/clients

5.3 开放接口

  • OAuth2 Client Credentials：client_id/secret 换取 access token（自签 JWT 短 TTL），支持 scope 最小化分配，写接口需显式授予
  • 独立前缀 /api/open，按 client 维度独立限流，全量调用审计（sys_open_log 按月分片 + 哈希链）
  • 契约：OpenAPI（swagger.json）CI 导出快照存档分发；生产关闭在线文档端点
  • BMS 兼作 IdP：对外提供 OIDC Provider（授权码流程），第三方系统以 BMS 用户体系实现单点登录

6.2 关键数据要点

  • 多语言附表：{主表}_i18n（菜单/业务/动作/字段/字典/邮件模板），联合主键（主表 ID + locale），查询按当前 locale 关联、缺省回退主表默认文案
  • 软删除统一 deleted_at；唯一约束 (唯一字段, deleted_at) 复合唯一索引；回收站复用软删除字段，无独立表
  • 审计类表按月分片（物理表名 yyyyMM 后缀），分片表由 Celery 预创建；跨月哈希链首尾衔接
  • 全部业务表统一：雪花 ID 主键、审计字段、乐观锁 version、时间 UTC；关联表联合主键不设 id
