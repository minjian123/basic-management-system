1. 概述

国际化子系统统一管理前后端文案与业务数据文案的多语言能力：语言清单动态扩展、语言包页面 在线维护、i18n 附表、RTL 布局与用户时区。对应《项目规划说明》的「后端国际化」「国际化管理」 「国际化（前端）」「多语言数据规范」章节。

2. 固定文案语言包

  • 前后端固定文案（错误消息、按钮、提示）统一存 sys_i18n_message（msg_key + locale 联合主键），页面在线维护、运行时下发（Redis 缓存），新增语言免发版
  • 后端 Babel 仅开发期提取消息 key 入库（gettext 机制，Accept-Language 驱动）
  • 前端 vue-i18n：语言包运行时从后端拉取（GET /api/v1/i18n/messages，Redis 缓存 + localStorage 二次缓存）；前端不硬编码文案；错误码文案按 error.{code} 映射
  • i18n key 命名：模块.页面.字段（user.form.username、common.confirm）

3. 业务数据文案（i18n 附表）

  • 需多语言的展示文案不入主表，由 {主表}_i18n 附表存储（主表 ID + locale + 翻译字段，联合主键）
  • 覆盖：sys_menu_i18n（name）、sys_business_i18n、sys_action_i18n、sys_field_i18n、sys_dict_type_i18n、sys_dict_item_i18n、sys_mail_template_i18n（subject、content）
  • 查询规则：按当前 locale 关联，缺省回退主表默认文案

4. 语言与 RTL

  • sys_i18n_locale（code、name、rtl、status）：语言清单动态扩展；rtl 标记驱动前端布局切换
  • 种子：中文/英文语言（zh-CN / en-US）与前后端文案
  • 语言偏好 localStorage 持久化；用户级语言偏好 sys_user.locale

5. 用户时区

  • sys_user.timezone 用户时区偏好；时间统一 UTC 存储，按用户时区展示
  • 数字/日期格式经 Intl API 本地化
  • 个人中心可修改语言与时区偏好

6. 运行时渲染

  • 菜单树按当前 locale 关联 i18n 附表返回翻译文案（动态菜单接口）
  • 运行时生成的通知内容不走附表：由 gettext 按收件人语言翻译（如审批提醒邮件、告警短信）
  • 邮件模板多语言内容走 sys_mail_template_i18n

7. 与其他子系统的协调

  • 通知公告：模板与通知内容按收件人 locale 渲染
  • 权限计算引擎：菜单/权限码名称多语言（i18n 附表）
  • 前端架构：语言包运行时拉取 + RTL 布局 + 时区格式化
  • 数据架构：i18n 附表与主表数据规范（联合主键、回退规则）
  • 认证与会话：登录返回用户语言/时区偏好
