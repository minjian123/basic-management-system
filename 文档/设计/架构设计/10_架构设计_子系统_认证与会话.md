## 2. 双 token 模型 <a id="token"></a>

| 项 | 设计 |
| --- | --- |
| access token | 30 分钟；载荷 sub、tenant_id、jti（会话 id）、type=access；仅存前端内存（刷新页面后静默续期） |
| refresh token | 14 天滚动轮换；httpOnly + Secure + SameSite cookie（防 XSS 窃取）；CSRF 双重提交校验（SameSite=Lax + 自定义请求头校验） |
| 签发 | PyJWT；JWT secret 支持轮换（新旧并行验证期） |
| 刷新轮换 | refresh 使用一次即轮换：签发新 refresh + 旧 jti 入黑名单（bms:global:token:blacklist:{jti}，短 TTL）；并发重放由旧 token 已失效拦截 |
| 登出 | refresh 入黑名单即时失效；会话记录置 revoked |

## 3. 会话管理 <a id="session"></a>

- 持久层 sys_session（refresh_token_hash、设备、IP、login_at、expires_at、revoked_at）+ 运行时 Redis 标记 `bms:{tenant}:sess:{session_id}`（TTL 与 refresh 有效期对齐）
- 每请求校验链：验签（access）→ 类型校验 → Redis 会话标记存在性（不存在=已踢出/登出）→ 设备/IP 一致性（可选强度）；每请求一次 Redis 读（毫秒级）
- 强制踢出：删 Redis 会话标记 + 吊销 refresh + revoked_at 落库 + Socket.IO 广播 session.revoked 关闭该会话全部实时连接；HTTP 侧下一请求即拦截（即时生效）
- 多端会话：允许并发登录，活跃会话数上限（默认 5，sys_config 可配），超限自动作废最旧会话
- 会话管理页面：在线会话查看（session:kick 踢出）

## 4. SSO 集成 <a id="sso"></a>

- authlib：OIDC 为主 + CAS 兼容——作为客户端接入各租户外部 IdP（Keycloak/AD/Authing 等）；同时提供 OIDC Provider 能力（BMS 兼作 IdP，其他系统以 BMS 用户体系为统一认证源）
- 企业微信/钉钉免登复用同一外部身份框架；移动端内嵌 H5 走各自 OAuth 免登
- SSO 首次登录 JIT 自动建号（sys_user_identity 全局映射定位租户与用户；唯一约束防并发重复建号）；本地账号密码登录并存（超管应急通道，防 IdP 故障锁死）
- 登录页展示租户配置的 IdP 入口（sys_identity_provider）

## 5. 密码与账号策略 <a id="password"></a>

- PBKDF2 哈希（标准库，不引入额外密码库）；登录失败限流（slowapi，Redis 后端，如 5 次锁 15 分钟）
- 图形验证码：Pillow 生成，Redis 存储（bms:global:captcha:{uuid}，TTL 5 分钟），连续失败 3 次后强制要求
- 密码策略（sys_config 可配）：复杂度校验、90 天有效期强制改密（pwd_changed_at 驱动）、近 5 次历史密码不可重复（pwd_history）、180 天未登录自动锁定（定时任务扫描 last_login_at）
- 找回密码：邮箱与企业微信/钉钉双通道；token 存 Redis（TTL 15 分钟、单次有效）；叠加限流防滥用（每账号 1 次/5 分钟、每 IP 5 次/小时）；重置成功后强制失效该账号全部会话
- 账号锁定/解锁：sys_account_lock（lock_type: fail_limit/inactive/manual），锁定列表/手动解锁/解锁记录审计（user:unlock）
- 数据脱敏：敏感字段注册标记，序列化层默认掩码（138****5678）与导出脱敏；持 data:plain 权限码方可查看明文

## 6. 开放接口鉴权 <a id="open-auth"></a>

- OAuth2 Client Credentials：client_id/secret 换取 access token（自签 JWT 短 TTL），支持 scope（接口权限范围）、独立撤销
- 按 client 维度独立限流（slowapi）；IP 白名单（sys_client.ip_whitelist）
- 调用审计：sys_open_log 按月分片 + 哈希链（open:call 权限码）
