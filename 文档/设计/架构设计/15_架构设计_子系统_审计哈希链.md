## 1. 概述 <a id="overview"></a>

审计哈希链子系统保证审计记录不可篡改：操作日志、登录日志、开放接口日志与字段级变更审计
逐条哈希串联，配合 RocketMQ 分区有序消费保证链序。对应[《项目规划说明》](../../规划/项目规划说明.md)的「审计合规」
「操作日志」「登录日志」章节，覆盖操作日志、登录日志、数据变更审计模块。

## 2. 审计捕获 <a id="capture"></a>

- 字段级变更审计：关键表（sys_user、sys_role、sys_role_assign、sys_role_permission、sys_role_field、sys_post、sys_dept、sys_notice、sys_help_article、sys_tenant_quota、sup_supplier、wf_process、pur_purchase_*、pay_payment_*、pay_receipt、pay_refund 等）经 ORM 事件自动记录旧值/新值至 sys_data_audit_log（table_name、record_id、field、old_value、new_value、operator_id）
- 操作日志：action 记录权限码（业务:动作，与权限体系对齐）；敏感字段（密码、token、密钥）脱敏后记录，不落原始值
- 登录日志：成功/失败记录（username、ip、user_agent、status、fail_reason）

## 3. 哈希链构造 <a id="chain"></a>

- `record_hash = SHA256(prev_hash + 规范化记录内容)`；prev_hash 取当前分片表末条 record_hash
- 跨月衔接：新分片表首条 prev_hash = 上月末条 record_hash（分片表内成链、跨月表首尾衔接）
- 链头：各分片表首条记录的 prev_hash 为上一月链尾哈希（首月链头为约定初始值）

## 4. 写入顺序保证 <a id="order"></a>

- 审计事件经 RocketMQ 分区有序消费（分区键 = 租户）→ 同租户串行追加，杜绝并发写乱序破坏 prev_hash 衔接
- 跨月切换由事件消费逻辑保证（新月份分片表已由任务预创建）

## 5. 校验与巡检 <a id="verify"></a>

- 链校验工具：逐条重算 record_hash 与 prev_hash 比对，定位被篡改记录
- 定期巡检（内置任务）+ 归档前强制校验（链完整方可归档）
- 校验结果与异常告警接入系统监控

## 6. 留存与销毁 <a id="retention"></a>

- 合规留存：审计数据 90 天热表 + 归档冷存储（两段式归档，见核心交互时序-归档流转）
- 哈希链随归档一并导出（含链头尾哈希），供事后独立校验
- 合规销毁（含审计数据销毁）记录销毁日志备查
- 归档数据查询：只读（bms_archive 库），审计管理员权限

## 7. 与其他子系统的协调 <a id="coordination"></a>

- **[事件总线](12_架构设计_子系统_事件总线.md)**：审计事件生产与分区有序消费（链序保证）
- **[数据访问与分片](09_架构设计_子系统_数据访问与分片.md)**：审计日志按月分片落库（分片键=时间）
- **[任务调度](13_架构设计_子系统_任务调度.md)**：归档、链校验巡检为内置任务
- **[权限计算引擎](11_架构设计_子系统_权限计算引擎.md)**：三权分立中审计管理员只读全部日志与审计数据（log 业务）
- **[全文检索](21_架构设计_子系统_全文检索.md)**：审计日志经事件同步至 ES 按月索引（阶段十四）
