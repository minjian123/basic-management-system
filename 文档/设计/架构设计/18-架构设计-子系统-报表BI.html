1. 概述

报表 BI 子系统提供数据集管理（SQL 建模）、拖拽报表设计器（ECharts）与可视化大屏。 对应《项目规划说明》的「报表中心」章节，覆盖数据集管理、报表设计器、报表查看、大屏设计器与播放模块。

2. 数据集管理

  • rpt_dataset：code、name、source_key（只读从库数据源）、sql_text、fields、status——SQL 建模，页面配置
  • 执行模型：只读从库强制执行（隔离生产读写）；字段清单（fields）声明，禁止返回未声明字段
  • 权限码 rpt:design（设计）、rpt:view（查看）

3. 报表设计器

  • rpt_report：code、name、dataset_id、chart_config、layout、status——拖拽设计（ECharts 图表类型全覆盖）
  • 报表查看：按数据集参数查询渲染；移动端可查看（数据查询）
  • 报表移动端查看纳入移动端 H5（数据查询页）

4. 可视化大屏

  • rpt_screen：code、name、canvas_config、status——自由画布设计器 + 轮播播放
  • 大屏播放页独立路由（无需登录态可配置分享；默认需权限）

5. SQL 安全执行

  • 数据集白名单：仅可执行平台审核过的数据集 SQL；页面禁止任意 SQL 输入
  • 只读从库执行：强制 read-only 连接（禁用写语句）；SQL 注入防护：参数化 + 语句类别白名单（仅 SELECT）
  • 超时与限流：数据集执行超时限制、接口限流（slowapi）
  • 租户隔离：数据集属租户库，执行绑定当前租户数据源
  • AI 问数（阶段十四）：NL2SQL 仅在数据集白名单 + 只读从库 + 安全校验范围内生成与执行

6. 与其他子系统的协调

  • 数据访问与分片：报表查询走只读从库（读写分离路由）
  • 权限计算引擎：报表/大屏按权限码与数据范围过滤
  • 前端架构：ECharts 渲染；大屏设计器（拖拽画布）
  • AI 服务（阶段十四）：智能报表助手（NL2SQL 问数，结果图表化）
