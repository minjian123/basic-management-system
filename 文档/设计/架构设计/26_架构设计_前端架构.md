## 1. 概述 <a id="overview"></a>

前端架构定义 PC 管理端与移动端 H5 双工程的总体设计：工程结构、技术要点、动态菜单机制、页面清单与性能要求。对应[《项目规划说明》](../../规划/项目规划说明.md)的「前端」「前端页面清单与菜单机制」「移动端」章节。

## 2. 双工程结构 <a id="engines"></a>

- PC 管理端 `frontend/`（Vue 3 + Vite + TypeScript + Element Plus）与移动端 `frontend-mobile/`（Vue 3 + Vant）为两个彻底独立的工程：各自 package.json / lock 文件与 ESLint/Prettier/TS 配置，不共享基础配置与公共类型
- 包管理 npm（Node 官方自带，不生成额外配置文件）；CI 用 `npm ci` 锁定安装
- 工程目录：src/api（Axios 封装）、src/router（动态路由生成）、src/stores（Pinia）、src/views（按模块）、src/layouts、src/components、src/i18n、src/utils
- 前后端契约：openapi-typescript 由 OpenAPI schema 自动生成 TS 类型（与后端 Pydantic schema 一致）

## 3. 技术要点 <a id="tech"></a>

| 项 | 选型与要点 |
| --- | --- |
| 路由 / 状态 | Vue Router 4（路由守卫配合业务权限菜单级控制）、Pinia（TS 支持好） |
| HTTP | Axios：请求拦截器注入 access token、处理 401 刷新；响应拦截器统一错误提示 |
| 流程建模 | bpmn-js 拖拽绘制 BPMN，导出 XML 交 SpiffWorkflow 执行 |
| 图表 | ECharts（报表与大屏渲染） |
| 网格拖拽 | gridstack.js（首页工作台卡片与报表设计器统一布局：网格拖拽/尺寸调整/响应式，layout_config 序列化其结构） |
| 大屏画布 | vue-flow（@vue-flow/core，大屏自由画布：绝对定位拖拽、连线与缩放，与 gridstack 分工不混用） |
| 表单设计器 | vuedraggable（SortableJS 封装，表单设计器字段排序/分组/跨区拖拽；三库分工：列表排序 / 网格布局 / 自由画布） |
| 实时推送 | socket.io-client（待办/通知实时到达；断线自动重连 + 未读补偿） |
| 样式 | SCSS（Element Plus 主题定制）；避免重型 CSS 方案 |
| 规范 / 测试 | ESLint + Prettier；Vitest 单元 + Playwright E2E |

## 4. 动态菜单与权限渲染 <a id="menu"></a>

- 菜单树由后端按用户业务权限动态返回（sys_menu + sys_form 挂接业务权限过滤，按当前 locale 关联 i18n 附表返回翻译文案）
- 表单元数据（按钮/字段定义与当前用户可见/可编辑状态）随菜单接口一并下发；前端根据菜单树动态注册路由与生成侧边栏
- 前端不硬编码路由表：新增菜单/表单/按钮/字段无需发版
- 按钮按动作权限显隐（默认无按钮权限）：权限指令 `v-perm="'业务:动作'"`；字段权限控制表单字段可见/可编辑
- 双重控制：前端显隐 + 后端 require_permission 强制校验

- 工作台管理：工作台卡片管理、工作台模板管理（dashboard 业务）
- 表单定制：表单布局管理（选表单 → 布局编辑/字段属性/租户自建字段，formdesign 业务，见[31-表单定制](31_架构设计_子系统_表单定制.md)）
- 组织与权限：用户管理、账号锁定、岗位管理、角色管理、菜单管理（含表单/按钮/字段维护与字段权限配置）、业务权限管理、动作权限管理、部门管理、字典管理、系统参数
- 治理：操作日志、登录日志、数据变更审计、会话管理、归档策略、归档执行记录、备份管理、回收站、归档数据查询、任务调度
- 通用：文件管理、公告管理、通知中心、帮助中心（前台展示）、帮助管理（分类/文章维护、AI 生成草稿与审核）、邮件模板、邮件日志、短信记录、语言管理、语言包维护
- 业务：流程建模（bpmn-js）、流程实例、我的待办/已办、采购申请、采购订单、供应商档案、收款管理、付款管理、退款管理、收付款流水、支付渠道配置、数据集管理、报表设计器、报表查看、大屏设计器、大屏播放
- 平台：租户管理（含配额与模块开通/开关）、IdP 配置、开放接口管理、Webhook 管理、系统监控（Grafana 跳转 + 依赖状态 + 缓存管理）
- 扩展：全局搜索（阶段十四）、AI 助手（智能问数/审批辅助/文档问答）、模型配置（阶段十五）、个人中心（改密/语言/时区/喜好偏好：主题模式、列表页个性化、通知偏好、工作台自定义）

## 6. 移动端页面清单 <a id="pages-mobile"></a>

- 登录（账号密码 / SSO / 企业微信钉钉免登）
- 首页工作台（TabBar 首 Tab：待办/通知/公告/快捷入口简化卡片，布局配置与 PC 同源跨端同步）
- 我的待办/已办、审批操作（同意/驳回/评论，附件在线预览）、通知列表（批量已读/全部已读）、公告查看、帮助中心、我发起的、数据查询（报表查看）、个人中心（改密/语言/喜好偏好/退出登录）
- 企业微信/钉钉工作台内嵌免登；手机浏览器可直接访问

## 7. 前端性能 <a id="perf"></a>

- Element Plus 按需引入；路由懒加载
- 静态资源 gzip/brotli 压缩 + 缓存头
- **性能预算**（阶段十一验收口径）：Core Web Vitals 目标 LCP ≤ 2.5s / INP ≤ 200ms / CLS < 0.1（管理端桌面基线）；路由分片后单页 JS 包 gzip ≤ 300KB；Lighthouse 抽测随 E2E 执行，超标页面列入优化清单跟踪
- 语言包运行时拉取（Redis 缓存 + localStorage 二次缓存）
- 深色/浅色主题：SCSS 主题变量切换（CSS 变量驱动），主题偏好存 sys_user_preference（跨端同步）+ localStorage 临时态
- 列表页个性化：列显隐/顺序/宽度、每页条数与密度按页面维度存偏好（sys_user_preference），列表渲染前应用
- 无障碍：WCAG / 信息无障碍专项适配不纳入 MVP（Element Plus 基础可访问性兜底），合同要求时以 WCAG 2.1 AA 为基线专项立项（见[目标与约束](02_架构设计_目标与约束.md)明确不采用清单）
