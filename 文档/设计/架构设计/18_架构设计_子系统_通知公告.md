（个人维度）区别于公告（面向全员）。

## 2. 站内信与待办通知 <a id="notification"></a>

- sys_notification：user_id、title、content、type、biz_type、biz_id、is_read（个人维度）
- 生成路径：业务事件 → 通知组消费 → 站内信落库 + 触发实时推送（notification.new）
- 渠道偏好过滤：发送前按用户通知偏好（sys_user_preference）过滤渠道（站内信/邮件/短信开关）与免打扰时段，被过滤渠道不发送
- 待办提醒：审批待办生成 → 站内信 + Socket.IO（approval.todo）+ 待办角标
- 批量已读/全部已读（PC + 移动端）

## 3. 公告与已读回执 <a id="notice"></a>

- sys_notice：title、content、type、priority、is_top、publish_at、expire_at、status——发布/编辑/置顶/过期自动下线（定时任务扫描）
- sys_notice_read（notice_id + user_id 联合主键）：已读回执统计（全员维度）
- 发布/更新/下线落 notice.published 事件（Webhook 可订阅）

## 4. 邮件通知 <a id="mail"></a>

- sys_mail_template（code、name、subject、content、status）：Jinja2 模板入库、页面在线编辑、保存前语法校验与沙箱渲染测试；多语言主题/内容存 sys_mail_template_i18n
- 发送：aiosmtplib（异步 SMTP）+ Jinja2 渲染，按收件人 locale 渲染内容；发送记录 sys_mail_log
- 场景：审批提醒、告警通知、找回密码重置链接（短时效 token）
- 权限码 mail:send；模板平台默认、租户可覆盖

## 5. 短信通知 <a id="sms"></a>

- sys_sms_template（code、name、content、channel: aliyun/tencent、status）：页面在线编辑（验证码/告警/通知）
- 渠道：阿里云 / 腾讯云；发送记录 sys_sms_log（phone、channel、template_code、status、error_msg）
- 场景：验证码、告警通知；渠道故障时告警降级企业微信/钉钉
