1. 概述

首页工作台子系统定义登录后默认首页的架构机制：卡片注册双轨制（内置功能卡 + 数据集图表卡）、 三级模板（平台默认 → 角色 → 个人）与布局解析、卡片数据聚合与前端渲染。对应《项目规划说明》 「首页工作台」模块与「用户喜好」「初始化数据」章节，落地规范见《概要设计-首页工作台》与 《布局设计-首页工作台》。

2. 职责与边界

  • 本子系统负责：卡片注册表（sys_dashboard_card）与模板表（sys_dashboard_template）的管理接口、布局解析接口（三级回退）、统计聚合卡接口、卡片/布局缓存。
  • 明确不负责：待办/通知/公告等卡片数据的产生与持久化——数据来自工作流、通知中心、公告管理等各自模块的既有接口；个人布局的持久化复用用户喜好模块（sys_user_preference），不新建存储。
  • 边界约束：本子系统不发出业务事件（无 Webhook 订阅价值）；不参与数据分片与归档（配置类小表）；卡片数据接口一律转发到来源模块，不绕行来源模块的权限校验。

3. 卡片注册机制（双轨制）

卡片统一注册于 sys_dashboard_card（租户库，与 sys_config 同模式：平台内置卡随租户开通复制、平台升级批量同步），按 card_type 分两类：

类型来源渲染方式数据来源
builtin（内置功能卡）平台种子（待办/已办、通知、公告、快捷入口、帮助入口、数据统计），租户仅可停用前端渲染器组件（render_key → 组件注册表映射）各来源模块既有接口
dataset（数据集图表卡）租户自建（选 rpt_dataset + chart_type）通用图表渲染器（ECharts）报表中心数据集执行接口（只读从库 + 安全校验）
  • 卡片元数据随布局接口下发（name 按 locale 关联 sys_dashboard_card_i18n 回退默认文案、default_width/default_height、render_key/dataset_id/chart_type、数据接口地址），前端不做卡片清单硬编码。
  • 新增内置卡 = 平台种子 + 前端新增渲染器组件（一次开发全租户可用），不涉及菜单/权限变更；停用卡片后，引用它的模板与个人布局在解析时自动跳过。

  • 回退语义：个人布局 > 角色模板（用户角色集中优先级最高的一个角色的模板；多角色均有模板时按角色排序取首个）> 平台默认模板；均为空时返回内置卡片的最小默认布局。
  • 解析幂等性：解析结果只依赖 用户角色 → 模板/偏好 的当前状态，不依赖会话与时间；模板删除/停用、卡片停用后，任何用户刷新即得新结果，无需主动推送。
  • 重置：一键重置 = 删除个人偏好（DELETE /layout），回退语义自动生效；角色模板重置由管理员编辑模板内容实现。

5. 前端渲染架构

  • 网格容器：gridstack.js 承载布局（12 列网格、拖拽/缩放/响应式断点），layout_config 与 gridstack 结构一一对应；报表设计器复用同一网格组件（双端共用技术，见前端架构）。
  • 卡片渲染器注册表：内置卡按 render_key 注册组件（如 TodoCard、NoticeCard、QuickLinksCard、StatsCard），前端懒加载渲染；图表卡用通用 ChartCard（dataset_id + chart_type → 数据集接口 → ECharts 配置）。
  • 数据拉取：布局接口下发各卡数据接口地址，前端并行拉取（Promise.allSettled），单卡失败降级不阻塞整页；卡片数据接口失败不重试风暴（单卡手动重试）。
  • 编辑态：编辑模式 = gridstack 交互层（拖拽/缩放/显隐/添加面板），保存时前端将 gridstack 序列化结果提交 PUT /layout，后端做引用与尺寸合法性校验。
  • 移动端：frontend-mobile 独立渲染同一布局数据（单列简化卡片，见布局设计 15），布局接口与存储完全同源。

7. 与其他子系统的协作

  • 权限计算引擎（10）：dashboard 业务码控制卡片/模板管理；布局解析按用户角色集（主体链计算结果）定位角色模板；卡片数据沿用来源模块权限
  • 报表 BI（18）：数据集图表卡挂接 rpt_dataset，复用数据集执行接口与安全校验（只读从库）
  • 工作流（16） / 通知公告（17）：待办/通知/公告卡与顶栏角标的数据来源（既有接口 + Socket.IO 实时推送）
  • 实时推送（13）：待办/通知角标增量刷新（socket.io-client 订阅既有事件，不新增推送通道）
  • 前端架构（25）：工作台为登录后默认页与主框架固定 Tab；gridstack/vue-flow 选型与报表/大屏共用（见规划说明技术栈）
  • 国际化（19）：卡片名走 i18n 附表、布局接口按 locale 下发；工作台固定文案走 sys_i18n_message
  • 认证与会话（09）：登录成功跳转工作台；未登录访问重定向登录页

8. 性能、安全与测试

  • 性能：布局接口为轻查询（偏好表 + 模板表 + 缓存），命中缓存 < 50ms；卡片数据并行拉取不叠加延迟；统计卡短缓存 + 用户维度限流
  • 安全：布局/卡片/模板接口走统一鉴权与 require_permission（manage 动作两级校验）；布局保存校验卡片引用合法性与尺寸区间（防越界注入）；数据集卡执行沿用报表中心 SQL 安全校验（只读 + 黑名单）；跨租户隔离由租户路由保证，卡片/模板数据均在租户库
  • 测试：布局三级回退矩阵用例（个人/角色/平台/空布局 × 模板停用/卡片停用）、布局校验边界（非法引用/越界尺寸）、缓存失效策略、数据集卡降级、统计卡限流；E2E 覆盖定制保存 → 刷新保持 → 重置回退（纳入测试与质量）
