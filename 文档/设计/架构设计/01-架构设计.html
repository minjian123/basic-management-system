1. 文档目的

本文档是 BMS（基础管理系统）架构设计的总纲：说明项目背景、设计依据与文档组织方式， 并作为入口引用全部架构设计节点文件。架构设计完整覆盖《项目规划说明》 的每一个决策点，阐述各组件、模块、数据、接口在架构中如何协调运作。

2. 项目概述

BMS 为多租户 SaaS 形态的基础管理系统，主要用作后端管理：支持分布式、集群部署；多租户 SaaS 架构（租户独立库）；支持 SSO 单点登录；内置报表 BI 与移动端 H5；集成全文检索与 AI 能力。

  • 后端：Python 3.14+ / FastAPI / SQLAlchemy 2.0 异步 / Alembic / Redis / RocketMQ / Celery / MinIO / ES / Milvus（阶段十四）
  • 前端：Vue 3 + Vite + TypeScript（PC 端 Element Plus + 移动端 Vant 双工程，npm 各自独立）
  • 部署：Docker Compose + nginx；监控 Prometheus/Loki/Grafana/Alertmanager + Jaeger（OpenTelemetry）
  • 研发辅助：知识图谱（graphify）辅助代码理解与架构分析
