## 2. 租户解析链 <a id="resolve"></a>

| 来源 | 场景 | 优先级 |
| --- | --- | --- |
| 子域名 `{tenant}.bms.example.com` | 生产环境（泛域名 DNS + 泛 TLS 证书） | 1 |
| `X-Tenant-ID` 请求头 | 一人多租户切换（切换后重发 token） | 2 |
| access token 内 tenant_id | 开发环境兜底 | 3 |

解析结果构造 TenantContext（tenant_code、db_key、引擎引用），经 FastAPI 依赖注入传入 services/repositories；禁止全局单例持有租户引擎。子域名查 `sys_tenant.domain`（平台库），命中缓存（短 TTL）。

## 3. 引擎注册表与生命周期 <a id="engine"></a>

| 机制 | 设计 |
| --- | --- |
| EngineRegistry | 注册表 `{db_key → AsyncEngine}`；平台引擎常驻（bms_platform）；租户引擎懒加载（首次访问创建，连接参数来自 config.toml 数据源声明） |
| 闲置回收 | LRU + 最后使用时间：超时未访问的租户引擎 dispose 回收；停用租户强制回收；控制活跃租户引擎数上限 |
| 连接预算 | 总连接 = worker 数 × (pool_size + max_overflow) ≤ 数据库 max_connections 的 70%（预留其他客户端）；多租户按活跃租户数规划，避免全量租户连接常驻 |
| 并发保护 | 引擎创建加锁（进程内锁 + Redis 锁），防多实例同时为同一租户建引擎；创建失败快速失败并告警 |

## 4. 租户开通/停用 <a id="provision"></a>

- 开通流程（平台超管 `tenant:manage`）：校验 code 唯一 → 建库 `bms_tenant_{code}` → 三套 Alembic 迁移（按目标库方言，MySQL/PostgreSQL/达梦 DM8）→ 批量种子（三类内置管理员角色 + 初始系统管理员账号（首次登录强制改密）+ 默认 IdP 占位 + 归档策略 + 平台统一菜单/表单/按钮/字段挂接与权限码）→ **模块开通勾选**（可选已注册启用模块写入 sys_tenant_module，租户模块开关运营期启停，见[模块注册节点](07_架构设计_子系统_模块注册.md) 3.4）→ 注册 sys_tenant → 预热引擎（可选）→ 落 tenant.created 事件
- 停用：租户引擎全部回收、会话标记失效（按租户前缀批量清理 Redis）、登录拦截；启用：恢复正常 + 落 tenant.activated 事件
- 租户库批量迁移：Alembic 遍历 sys_tenant 逐库执行（运维脚本 scripts/）

## 5. 配额管理 <a id="quota"></a>

- 配额维度（sys_tenant_quota.quota_key）：user_count / storage_bytes / open_calls
- 超限拦截：创建用户/上传文件/开放接口调用前校验配额，超限拒绝并告警；used_value 计数落库
- 配额变更由平台超管运营视图配置（tenant:quota）

## 6. 隔离边界 <a id="isolation"></a>

- 第一层：引擎物理隔离（一租户一独立库，库级隔离）
- 第二层：查询强制 tenant 过滤（repository 统一注入 tenant_id 条件）
- 第三层：跨库引用走 code 逻辑外键（不建物理外键）；业务/动作权限码跨库引用同理
- 验证：跨租户访问拒绝测试纳入 CI（安全专项用例集）
