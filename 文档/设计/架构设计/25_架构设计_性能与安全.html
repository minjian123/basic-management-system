1. 概述

本节点是性能与安全的横切设计：性能目标与连接规划、分页查询、限流降级、超时资源， 以及完整安全架构。对应《项目规划说明》的「性能与高并发设计」「认证与安全」「基础防护」章节， 横切全部子系统。

2. 性能架构

2.1 性能目标

  • ≥ 500 并发用户，P99 响应 ≤ 1s（登录、列表查询、审批提交主链路）
  • 验收前压测验证：locust 脚本（登录、列表查询、审批提交场景）
  • 压测纳入 CI 验收门槛（阶段十）

2.2 部署规模与连接规划

  • uvicorn 多 worker 部署（如 4 worker）；每个 worker 独立连接池
  • 连接预算：总连接数 = worker × (pool_size + max_overflow) ≤ 数据库 max_connections 的 70%，预留其他客户端
  • 多租户场景按活跃租户数规划连接（engine 懒加载 + 闲置回收），避免全量租户连接常驻
  • 写事务尽量短，避免长事务占用连接

2.3 分页与查询

  • 常规列表 limit/offset（限深 100 页）；大数据量列表（如操作日志）游标分页兜底（last_id + 排序键索引）
  • 排序字段、外键、数据权限过滤字段必须建索引；禁止 SELECT *；批量写入用 bulk；N+1 走查
  • 慢查询日志开启，定期走查（报表数据集慢查询纳入）

2.4 限流与降级

  • 接口级限流：slowapi（limits 库，Redis 后端，IP / 用户 / client 维度），登录限流优先；Redis 故障降级 memory 后端（本地计数）
  • 降级矩阵：
    • Redis 故障：缓存失效直连 DB + 日志告警，限流降级 memory 后端
    • 主库故障：只读模式（从库响应查询，写接口返回明确错误）
    • RocketMQ 故障：审计/日志降级同步直写（标记降级时段，恢复后补发）
    • ES 故障：检索降级数据库模糊查询
    • 依赖接口故障：接口熔断（短超时、重试幂等）

2.5 超时与资源

  • DB 连接/执行超时、Redis 操作短超时快速失败（如 500ms）
  • 操作日志/登录日志：经 RocketMQ 异步写入降低主库写压力
  • 分布式锁 Redis SETNX 带过期（防死锁）

3. 安全架构

3.1 认证与存储安全

  • 双 token：access（30 分钟，仅存前端内存）+ refresh（14 天滚动轮换，httpOnly + Secure + SameSite cookie）；CSRF 双重提交校验（SameSite=Lax + 自定义请求头）
  • 密码：PBKDF2 哈希（标准库）；登录失败限流（5 次锁 15 分钟）+ 连续失败 3 次强制图形验证码
  • 密码策略（sys_config 可配）：复杂度校验、90 天有效期强制改密、近 5 次历史不可重复、180 天未登录自动锁定
  • 找回密码：邮箱 + 企业微信/钉钉双通道，token 存 Redis（TTL 15 分钟、单次有效）+ 限流防滥用；重置后强制失效全部会话

3.2 数据安全

  • 数据脱敏：敏感字段注册标记，序列化层默认掩码（138****5678）与导出脱敏；持 data:plain 权限码方可查看明文
  • 字段权限：visible/editable 读时过滤、写时校验（与脱敏互补）
  • 审计日志哈希链防篡改；日志敏感字段脱敏（密码/token/密钥不落原始值）

3.3 上传安全

  • 文件类型白名单 + 大小上限（默认 20MB，超限分片，单文件上限可配置如 2GB）
  • 分片 SHA256 校验 + 整文件校验；存储于 MinIO 私有桶
  • 下载用预签名 URL（限时有效），后端不代理文件流

3.4 基础防护

  • ORM 参数化防 SQL 注入（数据集 SQL 另有白名单 + 只读约束）
  • Element Plus 默认转义防 XSS
  • 接口级限流（slowapi，Redis 后端）防爆破
  • 安全响应头：nginx 统一配置 CSP、HSTS（dev 关闭）、X-Frame-Options（SAMEORIGIN）、X-Content-Type-Options、Referrer-Policy、Permissions-Policy
  • 生产关闭 Swagger/ReDoc；契约走 CI 导出快照

3.5 密钥管理

  • JWT secret 支持轮换（新旧并行验证期）
  • DB/Redis/MinIO 凭据、短信/AI key 走 Secret 管理（K8s Secret / Docker secrets），不落库不入镜像
  • 密钥类配置只走环境变量，不入 config.toml

3.6 AI 安全（阶段十五）

  • AI 交互全量落审计（ai_chat_log），提示词与响应不出租户边界
  • RAG 检索上下文遵守动作级数据权限范围；prompt 注入防护（角色隔离、指令约束、输出校验）
  • AI 结果默认仅辅助展示；自动写操作/自动审批开关默认关闭（白名单 + 二次确认 + 审计 + 可撤销）
  • AI 接口独立限流与预算控制
