## 1. 概述 <a id="overview"></a>

全文检索子系统（阶段十四）基于 ElasticSearch 8.x：覆盖主数据全局搜索、审计日志检索、
文件内容检索三类场景。对应[《项目规划说明》](../../规划/项目规划说明.md)的「全文检索」「检索」章节。

## 2. 索引规划 <a id="index"></a>

| 索引 | 内容 | 说明 |
| --- | --- | --- |
| `bms-main` | 主数据：用户/部门/角色/字典/采购单据/文件元数据/帮助文章 | 按用途分索引；均含 tenant_id 字段，查询强制租户隔离与数据权限过滤 |
| `bms-log-{类型}-{yyyyMM}` | 审计日志（操作/登录/开放接口/数据变更） | 按月索引，与分片表对齐 |
| `bms-file` | 文件内容（PDF/Word/Excel/TXT 解析文本） | 扫描件 OCR 由阶段十五 AI 支持 |

## 3. 同步管线 <a id="pipeline"></a>

- 变更事件 → RocketMQ → event-worker（ES 同步组）消费 → 文件类转文本解析任务（Celery：PDF/Word/Excel/TXT 文本提取）→ 写入索引
- 文本解析失败重试/标记；解析任务与 OCR（阶段十五）衔接
- 数据同步经事件驱动异步消费，避免双写一致性问题

## 4. 查询路径 <a id="query"></a>

- ES 只承担检索匹配：返回业务 ID + 高亮；详情回查数据库取最新数据（避免双写一致性难题）
- 权限过滤：索引 tenant_id 字段强制租户隔离 + 动作级数据权限范围过滤
- 全局搜索页面（管理端 + 移动端）

## 5. 索引重建 <a id="rebuild"></a>

- 索引重建任务（sys_task 入库）：重放事件流（事件已落库可追溯）+ 全量快照兜底
- 可对单索引/按月索引独立重建；重建期间新旧索引切换（别名方式）

## 6. 降级策略 <a id="degrade"></a>

- ES 故障：检索降级数据库模糊查询兜底（检索页面降级提示）
- 恢复后重放事件重建索引；ES 生产多节点集群（多副本、故障自动分片迁移），MVP 单节点

## 7. 与其他子系统的协调 <a id="coordination"></a>

- **[事件总线](12_架构设计_子系统_事件总线.md)**：同步管线经事件驱动；重建经事件重放
- **[审计哈希链](15_架构设计_子系统_审计哈希链.md)**：审计日志按月索引与分片表归档对齐（归档后索引同步裁剪）
- **[文件管理](16_架构设计_子系统_文件管理.md)**：文件内容解析依赖文件元数据与 MinIO 对象
- **AI 服务（阶段十五）**：OCR 与文件自动分类衔接文本解析；语义搜索与文件问答走 Milvus（独立向量检索）
- **[可观测性](23_架构设计_子系统_可观测性.md)**：索引健康、同步积压纳入监控
