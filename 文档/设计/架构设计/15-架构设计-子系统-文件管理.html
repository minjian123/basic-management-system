1. 概述

文件管理子系统承载文件上传/下载/预览、分片上传与断点续传、Excel 导入导出。 存储基于 MinIO（S3 兼容对象存储，多实例共享；本地开发可用文件系统模拟）。 对应《项目规划说明》的「文件管理」「文件上传」「Excel 处理」「导入导出」章节。

2. 分片状态机

状态迁移说明
上传中（uploading）初始化上传 → 上传中记录 upload_id、total_parts；sys_file 跟踪每片 sha256/状态
完成（completed）全部片校验通过合并后 → 完成合并为最终对象并清理 .part；落 file.uploaded 事件
失败（failed）校验失败/合并失败 → 失败清理临时对象；允许重新初始化上传
孤儿（orphan）超时未完成 → 回收Celery 扫描超时 .part 与超期 uploading 记录，物理清理
  • 大小规则：≤20MB 整包上传；超限分片上传 + 断点续传（单文件上限可配置如 2GB）
  • 分片临时对象 key 加 .part 标识；合并用 MinIO 组合对象
  • 断点续传：前端按 part_no 状态列表仅重传缺失片

3. 安全控制

  • 类型白名单 + 大小上限（默认 20MB，超限分片）
  • 分片 SHA256 校验 + 整文件校验；文件元数据记录 sha256（sys_file）
  • 存储于 MinIO 私有桶（bms-files），按租户 bucket 前缀隔离
  • 下载用预签名 URL（限时有效），后端不代理文件流；类型与大小检查在下载前复核
  • 配额联动：上传前校验租户存储配额（storage_bytes，见多租户路由子系统）

4. 在线预览与下载

  • 图片/PDF 经预签名 URL 直开（PC + 移动端；移动端审批附件预览）
  • 权限码：file:upload、file:download、file:manage
  • 对象存储故障时上传/下载接口报错并告警（见部署与运维节点故障应对）

5. Excel 导入导出

  • openpyxl 读写：用户等批量导入（import:execute）、列表导出（export）
  • 导入：模板下载 → 上传解析 → 校验预览 → 批量入库（幂等键防重复提交；唯一约束兜底）
  • 导出：列表查询结果导出（含脱敏字段掩码）；大数据量分页拉取

6. 与其他子系统的协调

  • 任务调度：孤儿分片回收任务（清理中断遗留）
  • 事件总线：file.uploaded 事件（Webhook 可订阅）；全文检索文件内容索引（阶段十三）经事件驱动
  • 审计哈希链：上传/下载关键操作落操作日志；文件表变更落字段级审计
  • 多租户路由：存储配额（storage_bytes）超限拦截
  • 备份与归档：MinIO 对象数据定期增量备份 + 生命周期策略；归档文件亦存 MinIO
