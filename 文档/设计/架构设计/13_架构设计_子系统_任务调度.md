# 架构设计 · 子系统 · 任务调度

> BMS · 定时任务入库、调度器与执行

## 1. 概述 <a id="overview"></a>

任务调度子系统基于 Celery（Redis broker）+ 自研数据库调度器：任务定义入库（sys_task）、
页面动态增删改与启停、手动触发、执行历史。对应[《项目规划说明》](../../规划/项目规划说明.md)的「定时任务」章节，覆盖任务调度模块。

## 2. 任务模型 <a id="model"></a>

- `sys_task`：name、handler（Celery 任务名）、cron、args、status、last_run_at、remark
- `sys_task_log`：task_id、status、cost_time、error_msg、started_at、finished_at
- 页面管理权限码 task:manage；手动触发 task:trigger

## 3. 调度器设计 <a id="scheduler"></a>

- celery-beat 单副本运行 + 自研数据库调度器：周期扫描待运行任务，按 cron 计算 next_run，到期投递到 worker 队列（Redis broker），更新 last_run_at
- 单副本保障：Redis 分布式锁（`bms:global:lock:beat`）防双调度重复执行（异常重启时锁可抢占）
- 变更热加载：任务 CRUD/启停 → Redis pub/sub 通知 beat 重载任务列表（无需重启）
- Celery 官方不支持 RocketMQ broker，任务队列与事件总线解耦（Redis 管任务，RocketMQ 管事件）

## 4. 执行与重试 <a id="execution"></a>

- worker 多副本横向扩展执行；失败自动重试（有限次）+ ack 确认
- worker 为同步进程：任务内执行异步业务须用 asyncio.run 或独立引擎，禁止跨事件循环复用连接/会话
- 任务执行完成落 task.completed 事件（Webhook 可订阅）

## 5. 内置任务清单 <a id="builtin"></a>

| 任务 | 周期 | 职责 |
| --- | --- | --- |
| 孤儿分片清理 | 定时 | 回收上传中断遗留的 .part 对象与超期上传中记录（配合文件管理子系统） |
| 日志归档 | 定时 | 四类审计日志按归档策略迁移（热表 → 归档库 → 对象存储） |
| 分片表预创建 | 定时 | 提前创建下月分片表（sys_operation_log_yyyyMM 等） |
| 每日全量备份 | 每日 | 数据库备份（sys_backup_task 驱动） |
| 未登录账号锁定扫描 | 每日 | 180 天未登录账号自动锁定（配合认证与会话子系统） |
| 软删除残留物理清理 | 定时 | 过期回收站数据物理清理（配合归档清理衔接） |
| 帮助文章质量评估扫描（阶段十五） | 定时 | 扫描已发布帮助文章，评估陈旧度/完整性/准确性，生成改进建议 |

## 6. 与其他子系统的协调 <a id="coordination"></a>

- **[文件管理](16_架构设计_子系统_文件管理.md)**：孤儿分片回收由本子系统执行
- **[审计哈希链](15_架构设计_子系统_审计哈希链.md)**：日志归档任务执行前做链完整性校验
- **[部署与运维](28_架构设计_部署与运维.md)**：备份任务（sys_backup_task）与恢复演练登记由本子系统调度
- **[事件总线](12_架构设计_子系统_事件总线.md)**：任务完成落事件；与 RocketMQ 事件总线互不干扰（独立 broker）
