实时推送Socket.IO + Redis 适配器自动重连、跨实例广播；替代原生 WebSocket

风险影响应对
Python 3.14 生态兼容核心依赖（FastAPI/SQLAlchemy/psycopg/Celery/SpiffWorkflow）未适配阶段一逐依赖验证，任一不兼容整体回退 3.13（已定口径）
RocketMQ 运维复杂度nameserver + broker 部署与调优成本Compose 标准化部署；MVP 单机起步，生产集群化；故障降级同步直写
双库方言维护MySQL/PostgreSQL 两套迁移与方言差异ORM 层禁用方言特性；CI 双库集成测试；SQLite 自动建表
多租户引擎连接膨胀租户库增多后连接数失控懒加载 + 闲置回收 + 池上限 + 活跃租户数上限；连接预算公式约束
ES 资源占用单节点内存需求高MVP 单节点按需分配；索引按月拆分可裁剪；故障降级兜底
审计链性能瓶颈串行消费限制写入吞吐单租户日志量级有限；跨租户分区并行；必要时按表拆分消费组（链内保持有序）
AI 依赖（阶段十四）外部 API 不可用/成本/合规适配层可切私有化端点；独立限流与预算；全量审计；默认仅辅助
SpiffWorkflow 兼容性Python 3.14 / 异步栈集成风险线程池运行隔离；版本回退预案；测试覆盖完整流转

4. 演进路线

  • Kubernetes 化部署（当前 Docker Compose，数据量或规模增长后迁移）
  • 阶段十三 全文检索：ES 接入、文件内容解析、全局搜索页面
