1. 概述

1.1 适用范围

本文档定义 BMS 移动端 H5（frontend-mobile 工程，Vue 3 + Vant）的布局设计。 移动端面向审批、通知、公告、数据查询、个人中心等高频移动场景，与 PC 管理端共享后端 API 与会话体系。

1.2 与 PC 端的关系

维度PC 管理端（frontend）移动端（frontend-mobile）
导航模式左侧树状导航 + 多 Tab 页底部 TabBar + 页面栈（单页展开）
页面容器FormFrame（列表/详情多 Tab）单页表单（列表 → 详情页跳转）
权限体系动态菜单 + v-perm + 字段权限同一权限体系，按需渲染入口与按钮
工程frontend（独立工程）frontend-mobile（独立工程，npm 各自管理）
移动端不采用 PC 端的主框架/Tab 布局（见《主框架布局设计》《表单框架布局设计》），两者相互独立、互不影响。

2. 总体布局

2.1 布局结构

安全区（iPhone 刘海 / 状态栏适配）
NavBar（导航头）：返回 / 标题 / 右侧操作
页面内容区（滚动）列表 / 表单 / 详情 / 公告 / 数据查询
TabBar（底部主导航，仅 Tab 根页面显示）工作台 │ 待办 │ 通知 │ 我的
安全区（iPhone 底部 Home 条适配）
  • 页面分两类：Tab 根页面（工作台/待办/通知/我的，带底部 TabBar）与子页面（审批详情、通知列表详情、公告详情、数据查询详情等，无 TabBar，NavBar 显示返回）
  • 安全区适配：顶部状态栏与底部 Home 条用 env(safe-area-inset-*) 撑开，避免刘海与手势条遮挡

2.2 导航模式

  • Tab 切换：底部 TabBar 在四个根页面间切换（路由切换，非页面栈 push）
  • 页面栈：子页面用路由 push（如 待办列表 → 审批操作页），NavBar 返回 pop；支持浏览器返回手势
  • 返回拦截：子页面存在未保存修改（dirty）时，返回前弹确认（与 PC 端脏数据保护一致）
  • 每个子页面与 URL 一一对应，支持分享/收藏直达（无 TabBar 环境显示 NavBar 返回）

  • 角标数据来源：Socket.IO 实时事件（approval.todo / notification.new）增量更新 + 进入页面拉取兜底
  • 仅登录后显示；登录页/审批页等子页面隐藏 TabBar

4. 页面导航（NavBar）

  • 子页面顶部 NavBar：左侧返回（页面栈 pop）、中间标题、右侧操作（如审批"提交"、通知"全部已读"）
  • 标题取路由 meta.title（多语言，见第 10 节）；固定吸顶，内容滚动
  • 返回行为：无未保存修改直接 pop；有 dirty 弹确认；从外部（分享直达/免登进入）无栈可退时隐藏返回或回工作台

5. 核心页面布局

5.1 登录页

  • 账号密码登录（含图形验证码，连续失败 3 次后强制）+ SSO 入口（企业微信/钉钉免登按钮、OIDC 跳转）
  • 登录成功后进入工作台（首页）；本地登录与免登并存

5.2 工作台

  • 欢迎横幅（用户名 + 日期）、快捷入口卡片（待办/通知/公告/数据查询，无权限的入口不渲染）
  • 待办/未读角标展示（与 TabBar 角标数据同源）

5.3 我的待办/已办

  • 分段切换：待办 / 已办；列表项：业务类型、标题、发起人、时间、状态标签（待审批/已通过/已驳回）
  • 下拉刷新 + 上拉加载（分页 page/size）；点击待办项进入审批操作页
  • 我发起的入口（工作台快捷入口）

  • 驳回需填写意见；提交防重复（幂等键）；提交后返回列表并刷新
  • 已办视图：无操作栏，仅展示详情与审批轨迹

5.5 通知列表

  • 站内信列表（类型图标 + 标题 + 时间，未读高亮）；左滑删除（Vant SwipeCell）
  • 批量已读/全部已读（NavBar 右侧操作）；未读数角标联动

5.6 公告查看

  • 公告列表（置顶标识、过期不展示）→ 公告详情（正文、发布时间、已读回执自动上报）
  • 打开详情即上报已读（sys_notice_read）

5.7 数据查询

  • 报表查看（复用后端 rpt 数据源与权限）；列表 → 详情/图表渲染（ECharts 移动端适配）
  • 查询条件表单 + 结果列表分页加载

5.8 个人中心

  • 用户信息卡片（头像/昵称/部门）；菜单列表：修改密码、语言偏好、时区偏好、退出登录
  • 修改密码：原密码 + 新密码（含策略校验提示）；退出登录走登出流程（refresh 黑名单即时失效）

6. 移动端表单

  • Vant Form 组件：单元格式表单布局（字段 label 左侧、内容右侧），编辑态字段可编辑
  • 字段权限联动：表单元数据接口下发的字段权限——visible=false 不渲染、editable=false 编辑态也禁用（与 PC 端一致）
  • 脱敏展示：敏感字段默认掩码（138****5678），持 data:plain 权限查看明文
  • i18n：字段标签/标题取当前 locale 翻译；错误提示走错误码 i18n 映射
  • 文件类字段：通用上传组件（分片上传/断点续传、预签名预览下载）
  • 乐观锁：保存携带 version，冲突提示重新加载（与 PC 端一致）

7. 附件预览

  • 图片/PDF 经预签名 URL 直开（限时有效）；移动端审批附件、申请附件均支持
  • 大图缩放/双指手势（Vant ImagePreview）；PDF 内嵌浏览器打开或 App 内 webview 渲染
  • 文件类型白名单与大小限制与后端文件接口一致

8. 内嵌适配（企业微信/钉钉）

  • 企微/钉钉工作台内嵌 H5：经各自 OAuth 免登（复用外部身份框架，JIT 建号），免登录直接进入工作台
  • WebView 环境：禁用手势刷新（避免页面刷新丢会话）、适配 WebView 顶部高度（避免双导航条）
  • 手机浏览器直接访问：走账号密码 / SSO 登录
  • 安全区与横屏：企微/钉钉内嵌均按竖屏适配，横屏不承诺支持

10. 技术要点

  • Vant 4 组件库：Tabbar / NavBar / Form / Field / List / PullRefresh / SwipeCell / ImagePreview 等
  • 路由：Vue Router（Tab 根页 + 页面栈子页），路由守卫校验权限（无权限跳 403/提示）
  • 权限：入口/按钮按权限码显隐（v-perm="'业务:动作'"），与后端 require_permission 双重控制
  • 实时角标：socket.io-client 接收 approval.todo / notification.new / session.revoked，增量更新 badge
  • 会话：access token 内存态 + refresh cookie；401 静默刷新；session.revoked 强制登出
  • i18n：语言包运行时拉取（localStorage 缓存），RTL 布局切换，时区按用户偏好（Intl）
  • 状态管理：Pinia（用户会话、角标计数、全局配置）
