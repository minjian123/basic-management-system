1. 目的与适用范围

规范 BMS 管理端在多种屏幕宽度下的适配策略（1920 / 1366 / 1024 / 768 及以下）， 保证表格、表单、导航在窄屏不失效。移动端（H5）为独立工程，见《移动端布局细化》。

2. 断点体系

断点宽度策略
≥ 1536px（2K）大屏内容最大 1600px 居中，表格列完整展示
1024-1535px常规默认布局，筛选一行收起
768-1023px窄屏侧边栏折叠为图标模式（64px），或抽屉化
< 768px平板/小窗侧边栏抽屉化（遮罩），表格横向滚动，操作列「更多」
PC 基线：Chrome / Edge / Firefox / Safari 最新版（《项目规划说明》「测试策略」兼容性）。

3. 主框架适配

  • 侧边栏：≥ 1024px 可用折叠（220 ↔ 64px）；< 1024px 默认收起；< 768px 改为抽屉（el-drawer 内嵌菜单，遮罩点击关闭）。
  • 顶栏：窄屏隐藏面包屑（保留折叠按钮与右侧功能区）；标签页横向滚动（scrollbar）。
  • 内容区边距：宽屏 24px，窄屏 16px；页面最小宽度 360px（不破版）。

4. 表格适配

  • 表格默认 min-width 保证可读性，超出容器横向滚动（滚动条统一样式）。
  • 关键列（名称/状态/操作）fixed 固定；< 768px 时仅操作列固定。
  • 列显隐策略：按断点隐藏次要列（如创建时间、备注），不隐藏关键操作；也可依赖「自定义列」用户偏好。
  • 筛选区：< 1024px 默认折叠，仅保留关键字 + 查询/重置。

5. 表单与弹窗适配

  • 抽屉宽度：< 768px 时占满宽度（100%）；对话框同理（margin 16px）。
  • 表单栅格：宽屏两列，< 1024px 单列。
  • 底部操作栏始终固定，不随内容滚动；按钮窄屏允许图标化。

6. 检查清单

  • □ 1024/1366/1920 三档截图核验无破版
  • □ 侧边栏折叠/抽屉化行为正确，状态可记忆
  • □ 表格横向滚动与固定列正常，无内容截断
  • □ 弹窗/抽屉窄屏占满可用宽度
  • □ 无固定 px 魔法值（走断点与令牌）
