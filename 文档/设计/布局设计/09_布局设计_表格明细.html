1. 目的与适用范围

规范 BMS 管理端表格明细（主从模块的子表数据）的统一展示与编辑布局。 表格明细组件嵌入《列表页》与《表单页》中使用， 用于主从模块（如采购申请 + 表格明细行、审批单 + 流转表格明细）的数据记录表格明细展示。

主从模块：主表一条记录对应表格明细多行（1:N）。表格明细复用统一组件（表格明细列表），列表页与表单页通过 props 注入数据源与编辑态。

2. 表格明细列表结构

表格明细结构
表格：多选列 + 数据列 + 主表数据 id 列（隐藏，用于关联；无操作列，双击行打开表单）行内编辑（仅编辑态可用）· 空状态 / 加载遮罩 / 骨架屏（表格区跟随表格明细，见 2.3 节）
新增行 / 删除行 / 上移行 / 下移行 + 自动列宽 / 自定义列 / 刷新 / 全屏（表格工具栏，图标按钮，仅编辑态，靠左）总数 + 页码 + 每页条数（分页区，靠右，见 2.4 节）

2.1 多表格明细（Tab 页）

  • 主表存在多个表格明细（表格明细A/表格明细B）时，每个表格明细一个 Tab 页，各自展示其列表。
  • 表格明细 Tab 与主表字段区同处「详细信息」信息栏（见《表单页布局》2.1）。

2.2 单表格明细

  • 仅一个表格明细时直接展示表格明细列表，不套 Tab 壳。
  • 无表格明细结构的主从模块（如用户）不显示表格明细区，表单页自行实现简单表单。

2.3 表格布局约定

表格明细嵌套于列表页表格（展开行）与表单页信息栏中展示，表格区跟随表格明细，其列布局、空状态与加载态约定如下；列宽自适应、超出横向滚动。

项约定
多选列有批量操作时保留，宽度 48px；行点击不默认勾选
数据列关键信息靠左（名称/编码），数字右对齐，状态用 tag 语义色（见令牌）
操作列列表页无操作列（数据行仅展示，双击行打开表单 Tab，见《表单框架布局》）；查看/编辑等操作由双击或表单 Tab 承载
空状态el-table 空数据插槽：图标 + 「暂无数据」+ 可选引导按钮
加载loading 遮罩 + 首次加载骨架屏（v-loading）

2.4 分页区约定

列表页分页区跟随表格明细，与表格工具栏同处表格下方一行，分页约定如下：

  • 位置：表格下方，靠右显示；左侧为表格工具栏（新增行/删除行/上移行/下移行及通用工具按钮）；布局「总数, 选择页码, 跳页, 每页条数, 页码」。
  • 参数与后端约定一致：page/size（《API接口规范》第 5 节），默认 20 条/页。
  • 大数据量（日志/审计）场景可切换游标分页（cursor/limit）。

3. 嵌入位置

3.1 列表页中的表格明细

  • 列表页（主表列表）中，表格明细以展开行（el-table expand）或行内子表形式展示：点击展开图标查看该主表记录关联的表格明细行。
  • 展开行表格明细遵循第 2.3 节表格布局约定。
  • 展开行表格明细为只读列表（数量有限制，如最多展示最近 N 条），完整表格明细在表单页查看/编辑。
  • 展开行表格明细不分页，列宽自适应、超出横向滚动；不承载新增/删除操作。

3.2 表单页中的表格明细

  • 表单页（记录 Tab）中，表格明细位于「详细信息」信息栏的主表字段区下方（或表格明细 Tab 页区），完整展示与编辑。
  • 只读态：表格明细行仅展示（字段禁用），随主表整体只读。
  • 编辑态：表格明细工具栏与行内编辑可用（见第 4、5 节）。
  • 分页/滚动：表单页明细区 ≤ 10 行时直接展示、超出 10 行启用分页（page/size 约定同列表页，默认 10 条/页）；明细工具栏与分页区同处表格下方一行（见 2.4 节）。

4. 表格明细工具栏

  • 图标表示：工具栏按钮均使用图标表示（不显示文字标签），悬停 tooltip 提示功能名称（走 i18n）。
  • 提供：新增行、删除行、上移行、下移行（作用于当前表格明细列表，仅编辑态可用），位于分页区左侧（见 2.4 节）。
  • 通用工具按钮（同位于分页区左侧，按需展示）：自动列宽（一键自适应列宽）、自定义列（列显示/隐藏与拖动排序，存用户偏好，同《列表页布局》「自定义列」抽屉约定）、刷新（重新加载当前明细数据）、全屏（表格全屏查看）。
  • 删除行需二次确认（ElMessageBox.confirm）。
  • 批量操作（如表格明细行勾选批量删除）按需提供，受权限码控制。
  • 编辑态自动空行：编辑态下表格末尾自动追加一行空明细作为新增行，供用户直接录入新数据记录；非编辑态（只读）不显示该空行。

5. 行内编辑

  • 表格明细行行内编辑：字段直接 v-model 绑定（仅编辑态），未保存修改随整体保存一并提交。
  • 文件类字段同表单页规则（通用上传组件、预签名 URL，见《表单页布局》第 7 节）。
  • 字段校验与主表一致（必填/格式，错误提示走 i18n）。

6. 与主表关联

  • 表格明细与主表通过表格明细中的「主表数据 id」列关联（对应当前主表 ID）。
  • 新增主表时，表格明细的「主表数据 id」在保存事务内用新主表 ID 回填。
  • 关联遵循逻辑外键约定（不建物理外键，见《数据库开发规范》）。

7. 保存与事务

  • 整体保存：工具栏「保存」一次性提交主表 + 全部表格明细（单事务），保证主表与表格明细一致性。
  • 空行过滤：保存时过滤编辑态自动追加的空行（未录入任何数据的行不参与提交）。
  • 乐观锁：保存携带主表 version，冲突时提示「记录已被修改」并重新加载。
  • 保存成功后自动刷新列表页（含展开行表格明细）与表单页（详见《表单框架布局》第 2 节交互协议）。

8. 检查清单

  • □ 表格明细组件嵌入列表页（展开行只读）与表单页（信息栏完整编辑）
  • □ 多表格明细 Tab 化、单表格明细直接展示
  • □ 表格明细工具栏/行内编辑仅编辑态可用，删除二次确认
  • □ 通用工具按钮（自动列宽/自定义列/刷新/全屏）按需展示，自定义列存用户偏好
  • □ 编辑态末尾自动空行仅编辑态存在，保存时过滤空行
  • □ 「主表数据 id」关联正确，新增主表事务内回填
  • □ 整体保存单事务 + 乐观锁，保存后刷新主表列表
  • □ 字段校验与文件字段规则同表单页
