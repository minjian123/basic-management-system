1. 目的与适用范围

定义 BMS 前端（PC 管理端 Element Plus + 移动端 H5 Vant）的设计令牌（Design Tokens）： 色彩、字体、间距、栅格、圆角、阴影、图标等基础规范，作为全部布局与组件样式的单一事实来源。 与《前端开发规范》配套。

2. 色彩令牌

令牌用途默认值
--color-primary主色（品牌、主按钮、选中态）#0969da（可租户覆盖）
--color-success成功/已通过#2da44e
--color-warning警告/待审批#d4a72c

  • 主色允许租户覆盖（品牌化，见《主题与租户品牌化》）。
  • 禁止在组件内硬编码色值，一律引用令牌。

4. 间距与栅格

令牌值典型用途
--space-xs4px图标与文字、行内元素

--space-md12px表单项间距、列表单元

  • 栅格：PC 12/24 列（Element Plus el-row/el-col），内容最大宽度 1600px 居中；间距遵循 4px 基准（4/8/12/16/24/32）。
  • 页面内容区边距：PC 24px（--space-xl），移动端 16px。
  • 禁止散落魔法间距值（如 13px、21px），一律取令牌。

6. 图标与图片

  • 图标统一 @element-plus/icons-vue（PC）与 Vant 图标（移动端）；业务图标自绘放 src/assets/icons/，kebab-case 命名（《命名规范》第 9 节）。
  • 图标尺寸随字号：14px 内联图标、16px 菜单图标、20px 按钮图标；不拉伸变形。
  • 图片资源（logo 等）放 src/assets/images/，SVG 优先。

7. 令牌落地（CSS 变量）

/* src/styles/tokens.css */
:root {
  --color-primary: #0969da;
  --color-success: #2da44e;
  /* ... 全部令牌 */
}
/* 映射到 Element Plus 变量 */
:root {
  --el-color-primary: var(--color-primary);
  --el-border-radius-base: var(--radius-md);
}
  • 令牌定义唯一来源：src/styles/tokens.css；暗色模式与租户主题通过 [data-theme] / [data-tenant] 覆盖（见《主题与租户品牌化》）。
  • 新令牌必须在此文件登记后使用；组件样式不复制令牌值。

8. 检查清单

  • □ 无硬编码色值/字号/间距（全部走令牌）
  • □ 状态色语义全局统一（通过/待审/驳回）
  • □ 间距符合 4px 基准阶梯，栅格 24 列
  • □ 图标/图片资源命名与目录规范
  • □ 新令牌已登记 tokens.css 并映射组件库
