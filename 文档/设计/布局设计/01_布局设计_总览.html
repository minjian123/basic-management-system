本文档是布局设计体系的总览：汇总全部布局设计文档（02-14）、说明编号与依赖关系、 概括总体设计原则，并对接《架构设计 · 前端架构》（第 25 节点）。

3. 总体设计原则

  • 模板化：页面不逐个手写布局，基于统一框架组件（主框架、FormFrame、列表页模板）按菜单动态生成。
  • 权限驱动渲染：菜单树、按钮、字段按权限码动态下发与显隐（对应《架构设计 · 前端架构》第 4 节），布局不承载硬编码路由。
  • Token 化设计：颜色、字体、间距等一律走设计令牌（02），主题切换（08）与租户品牌化仅覆盖令牌，不侵入组件。
  • 双端独立：PC 与移动端各自布局体系，共用后端 API 与会话，不共用组件与样式。
  • 状态保持：PC 端 Tab 切换 keep-alive 缓存组件状态；移动端列表触底加载/下拉刷新，均以用户操作连续性优先。

4. PC 管理端布局

4.1 主框架

  • 左右结构：左侧导航栏（品牌区 + 导航搜索框 + 树状菜单）+ 右侧内容栏（Tab 页）。详见《布局设计-主框架》。
  • 右侧内容栏：上为 Tab 栏（固定工作台首页 Tab + 业务 Tab，与 URL 一一对应，路由联动），下为表单框架（具体界面内容）。
  • 导航细节（侧边菜单、顶栏、标签页、面包屑取舍）见《布局设计-导航》：面包屑不采用，Tab 栏承担定位与导航职责。

4.2 页面形态

  • 列表页：工具栏 + 筛选区 + 表格区 + 分页区四段式（嵌于 FormFrame 列表 Tab），见《布局设计-列表页》。
  • 表单页：FormDetailPanel 单条记录查看/编辑（只读/编辑分态、主表与明细、字段权限与校验），见《布局设计-表单页》。
  • 明细：主从模块明细（嵌入列表页展开行与表单页信息栏，行内编辑与事务），见《布局设计-明细》。
  • 表单框架：FormFrame 承载列表页与表单页；两者职责分离、各自独立；工具栏（新增/修改/删除/刷新/关闭）见《布局设计-表单框架》。
  • 弹窗：抽屉/对话框的选用与尺寸、底部操作栏，见《布局设计-弹窗》。
