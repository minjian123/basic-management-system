1. 定位与原则

本目录存放可复用原型组件（纯 JS 生成 HTML，无 fetch 依赖，file:// 双击可用）。 组件由各业务模块的页面嵌入引用：组件只在本目录维护一份，修改一处、全部引用页面同步生效， 避免同一 UI 结构在多个页面复制粘贴后出现改一处漏一处的问题。

  • 适用范围：跨模块复用、且结构统一的界面片段（系统信息、分页、空状态等）。
  • 边界：业务内容各异的界面（弹窗表单、明细行等）不组件化，保留在各页面内；共享资源/ 仍负责全局样式与全局脚本（原型样式.css / 原型脚本.js）。
  • 组件命名：kebab-case 文件（系统信息.js、分页.js、空状态.js）；对外函数挂 window（mountSysInfo、renderPager、renderEmpty）。

2.1 系统信息.js 系统信息

表单详情页「系统信息」区块：字段与《布局设计-表单页》2.1 一致——ID / 创建时间 / 创建用户 / 修改时间 / 修改用户（纯文本只读，不套输入框）。支持 extra 扩展字段（如采购表单的版本号）。

mountSysInfo(document.getElementById('sys-info-user'), {
  id: '1902876345762181120',
  createdAt: '2026-07-01 10:00:00 (UTC)',
  createdBy: 'admin',
  updatedAt: '2026-08-12 09:30:00 (UTC)',
  updatedBy: 'admin',
  extra: [['版本号', 'version 2（乐观锁校验）']]
});

2.2 分页.js 分页

列表分页区：总数 / 页码按钮 / 上一页下一页 / 每页条数（默认 20）/ 跳页，结构与《布局设计-表格明细》2.4 一致；挂载元素自动附加 p-pager 类，分页在表格右下角右对齐（与《布局设计-列表页》分页位置一致）。

renderPager(document.getElementById('pager-user'), {
  total: 128, page: 1, size: 20,
  onPage: function (n) { /* 切换页码 */ },
  onSize: function (s) { /* 切换每页条数，回第 1 页 */ }
});

2.3 空状态.js 空状态

空状态插画（inline SVG）+ 文案 + 可选引导按钮；文案场景：list「暂无数据」、search「未找到相关内容」、todo「暂无待办，享受这一刻」、msg「暂无消息」、error「加载失败」。

renderEmpty(document.getElementById('empty-user'), {
  type: 'list', action: '去创建', onAction: function () { /* 打开新增 */ }
});

3. 引用方式

页面在底部脚本区引用组件文件（相对路径按页面层级：业务模块页 = ../02_公共原型/组件名.js），并在元素存在后调用：

<!-- 页面 HTML：占位容器 -->
<div id="sys-info-user"></div>

<script src="../共享资源/原型脚本.js"></script>
<script src="../02_公共原型/系统信息.js"></script>
<script>
  mountSysInfo(document.getElementById('sys-info-user'), { /* 数据 */ });
</script>

4. 新增组件规则

  1. 满足「跨模块复用 + 结构统一」才组件化；业务内容各异的界面不做。
  2. 文件放本目录，命名 kebab-case；对外函数挂 window，函数名与文件对应（xx.js → mountXx / renderXx）。
  3. 组件头部注释：用途、依据的布局文档章节、用法示例；修改组件后所有引用页面自动生效。
  4. 新增组件后：更新本说明组件清单表与《原型设计总览》模块地图。
