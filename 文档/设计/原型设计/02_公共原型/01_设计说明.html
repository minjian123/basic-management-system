2.6 公共组件-系统信息（iframe）

04_系统信息组件.html —— 系统信息统一组件，依《布局设计-表单页》2.1.1：el-form label-position="top" 三列只读栅格（ID / 版本号 / 创建用户 / 创建时间 / 修改用户 / 修改时间 / 表单标识，disabled 输入框与主表字段形态一致仅不可编辑、表单标识为禁用下拉框、时间无时区后缀）。

  • 嵌入方式：各表单页系统信息 Tab 内放 <iframe class="sys-frame" src="../02_公共原型/04_系统信息组件.html">（样式 .sys-frame 在 原型样式.css）；改组件一处，全站表单生效。
  • 数据协议：父页在 iframe @load 时 postMessage({type:'sys-info', data:{id,version,createdAt,createdBy,updatedAt,updatedBy,formKey,formLabel}}) 传入当前记录数据（表单标识传英文标识 formKey + 中文名 formLabel）。
  • 高度自适应：组件渲染完成后回传 {type:'sys-info-height', height}，父页据此调整 iframe 高度。
  • 已接入页面：表单框架骨架（03_通用骨架/04）、用户表单页（08_用户管理/03）、部门管理页/岗位表单页/部门表单页（11_部门与岗位/02/04/05）、采购申请表单页（12_采购/03）。

4. 新增组件规则

  • 组件优先用 Element Plus / Vant 真实组件；页面级私有样式内联 <style>，公共样式进 共享资源/原型样式.css。
  • 新页面从模板复制改造（02_EP模板_列表页 / 03_EP模板_表单页），保证全体系风格一致。
  • 交互反馈统一 ElMessage / ElMessageBox（PC）、vant.showToast / showConfirmDialog（移动端）。
  • vendor 组件升级：整体替换 共享资源/vendor/ 下文件（保持与 BMS 前端版本对齐），避免版本混用。
