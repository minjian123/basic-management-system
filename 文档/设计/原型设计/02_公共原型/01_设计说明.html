3. 引用方式

<!-- PC 管理端页面 -->
<link rel="stylesheet" href="../共享资源/vendor/element-plus.css">
<link rel="stylesheet" href="../共享资源/原型样式.css">   <!-- 仅框架样式（proto-bar/proto-frame） -->
<script src="../共享资源/vendor/vue.global.prod.js"></script>
<script src="../共享资源/vendor/element-plus.min.js"></script>
<script>
  var app = Vue.createApp({
    template: document.getElementById('app').outerHTML,  // 或模板字符串
    setup: function () { /* 数据与交互 */ }
  });
  app.use(ElementPlus, { locale: ElementPlusLocaleZhCn });
  app.mount('#app');
</script>

<!-- 移动端页面 -->
<link rel="stylesheet" href="../共享资源/vendor/vant.css">

<script>
  var app = Vue.createApp({ /* ... */ });
  app.use(vant);
  app.mount('#app');
</script>

4. 新增组件规则

  • 组件优先用 Element Plus / Vant 真实组件；页面级私有样式内联 <style>，公共样式进 共享资源/原型样式.css。
  • 新页面从模板复制改造（02_EP模板_列表页 / 03_EP模板_表单页），保证全体系风格一致。
  • 交互反馈统一 ElMessage / ElMessageBox（PC）、vant.showToast / showConfirmDialog（移动端）。
  • vendor 组件升级：整体替换 共享资源/vendor/ 下文件（保持与 BMS 前端版本对齐），避免版本混用。
