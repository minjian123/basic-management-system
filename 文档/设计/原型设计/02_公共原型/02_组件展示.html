1. 系统信息（系统信息.js）

表单详情页「系统信息」区块：ID / 创建时间 / 创建用户 / 修改时间 / 修改用户（纯文本只读），支持 extra 扩展字段（如版本号）。
用法：mountSysInfo(el, { id, createdAt, createdBy, updatedAt, updatedBy, extra })

2. 分页（分页.js）

列表分页区：总数 / 页码 / 跳页 / 每页条数（默认 20 条/页），页码可点击切换。
用法：renderPager(el, { total, page, size, onPage, onSize })

当前：第 1 页 · 每页 20 条

3. 空状态（空状态.js）

空状态插画（SVG）+ 文案 + 可选引导按钮；场景：list / search / todo / msg / error。
用法：renderEmpty(el, { type, text, action, onAction })，点击下方按钮切换场景。

4. 表格明细工具栏（明细工具栏.js）

主从模块明细底部栏：图标按钮组靠左（新增/删除/上移/下移 + 自动列宽/自定义列/刷新/全屏）+ 分页靠右同一行（《布局设计-表格明细》第 4 节 / 2.4 节，行操作仅编辑态、删除二次确认）。
用法：renderDetailBar(el, { readonly, onAdd, onDelete, onMoveUp, onMoveDown, tools, onTool, page })，返回对象可 setReadonly() 切换编辑态。

5. 列表页工具栏（列表页工具栏.js）

列表页三段式（《布局设计-列表页》）：工具栏（主按钮 + 按钮组 + 右侧提示）+ 筛选区（关键字 + 附加控件 + 查询/重置）+ 分页（右对齐）。
用法：renderListToolbar({ top, bottom, primary, buttons, extra, filter, page })，top 挂表格上方、bottom 挂表格下方（分页）。

6. 明细表格（明细表格.js，一体组件）

主从明细完整组件：明细表格（行内编辑）+ 左下角明细工具栏（图标按钮）+ 右下角分页，一个挂载点生成（《布局设计-表格明细》）。
用法：renderDetailTable(el, { columns, data, readonly, rowTools, tools, page, onChange })；返回 setReadonly() / getRows()。
