# 项目规划说明

基础管理系统，主要用作后端管理，简称BMS。

## 项目概述

基础管理系统，支持分布式、集群部署。

后端基于 FastAPI + SQLAlchemy，前端基于 Vue 3 + Vite，通过知识图谱（graphify）辅助代码理解与架构分析。

## 技术栈

| 层面 | 技术选型 |
|------|---------|
| 语言 | Python 3.14+ |
| Web 框架 | FastAPI |
| 数据库抽象 | SQLAlchemy 2.0+（ORM / Core，读写分离 / 分库分表） |
| 数据库迁移 | Alembic（alembic/ + alembic.ini，URL 来自 config.toml） |
| 数据库 | SQLite（默认）/ MySQL / PostgreSQL |
| 缓存 | Redis（redis-py，RESP2 兼容旧版服务器）/ 内存缓存 MemoryCache |
| MySQL 驱动 | PyMySQL |
| PostgreSQL 驱动 | psycopg2-binary |
| 认证 | JWT（PyJWT）+ PBKDF2 密码哈希（标准库） |
| 后端国际化 | Babel + gettext（Accept-Language 驱动错误消息翻译） |
| 前端国际化 | vue-i18n（中英文切换，localStorage 持久化） |
| 配置格式 | TOML |
| ID 生成 | yitter/IdGenerator（雪花算法） |
| 测试框架 | pytest + httpx / Selenium + webdriver-manager |
| 前端框架 | Vue 3 + Vite |
| 前端路由 | Vue Router 4 |
| HTTP 客户端 | Axios |
| 知识图谱 | graphify |

## 基本规划

分为前后端。

### 后端

后端采用python。

提供数据库功能，对数据的增删改查。

使用FastAPI

#### 数据库

数据库功能支持多数据源，

缓存功能，采用redis。

JWT验证功能。

### 前端

前端Web界面采用Vue。
