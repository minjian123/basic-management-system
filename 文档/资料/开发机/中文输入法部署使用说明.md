## 1. 目的与适用范围 <a id="purpose"></a>

记录开发机 **mjpc**（Ubuntu 26.04.1 LTS，GNOME，Wayland）上英文系统默认输入法（IBus + libpinyin）使用体验不佳，改为 **Fcitx5 + 中文拼音（全拼）** 的完整方案、部署步骤、配置项与排障方法，作为日后重装或迁移的参照。

方案经过确认（2026-08-29）：输入法框架选 Fcitx5 + 中文拼音，输入方式用全拼。

## 2. 背景：为何更换 <a id="background"></a>

mjpc 系统环境与原输入法现状：

| 项 | 现状 |
| --- | --- |
| 系统 | Ubuntu 26.04.1 LTS（resolute），GNOME 桌面，Wayland 会话（`XDG_SESSION_TYPE=wayland`） |
| 原输入法 | IBus 1.5.34 + ibus-libpinyin 1.16.5（Ubuntu 自带） |
| 问题 | 智能拼音的候选词、联想与词库体验一般，中文输入不顺手 |
| 目标 | 更换为候选词/联想/云词库更好的 **Fcitx5 + 中文拼音**，保留全拼习惯 |

在 Wayland + GNOME 下，Fcitx5 是国内用户常用且成熟的方案；GNOME 默认只管理 IBus，需额外配置环境变量与自启动才能让 Fcitx5 接管中文输入。

## 3. 技术方案 <a id="scheme"></a>

| 层 | 组件 | 版本 | 作用 |
| --- | --- | --- | --- |
| 输入法框架 | fcitx5 | 5.1.19 | 输入法容器，管理引擎与候选窗 |
| 中文引擎 | fcitx5-chinese-addons | 5.1.12-1 | 提供拼音（pinyin）、双拼（shuangpin）等 |
| 图形配置 | fcitx5-configtool（fcitx5-config-qt） | — | 打开 fcitx5 图形配置界面 |
| 前端 | gtk3 / gtk4 / qt5 / qt6 frontend | — | 让各类型应用的输入框接入 fcitx5 |

部署后本机核实：`/usr/bin/fcitx5`、`/usr/bin/fcitx5-configtool` 均存在；拼音引擎 `/usr/lib/x86_64-linux-gnu/fcitx5/libpinyin.so` 存在。

## 4. 部署步骤 <a id="deploy"></a>

以下全部在开发机本地执行，安装类命令需 sudo。下载走 Ubuntu 官方国内镜像（清华 TUNA），已由系统源配置覆盖。

### 4.1 安装 Fcitx5 与中文引擎 <a id="install"></a>

```bash
sudo apt-get update

sudo apt-get install -y --no-install-recommends \
  fcitx5 fcitx5-chinese-addons \
  fcitx5-config-qt \
  fcitx5-frontend-gtk3 fcitx5-frontend-gtk4 \
  fcitx5-frontend-qt5 fcitx5-frontend-qt6 \
  fcitx5-modules
```

### 4.2 切换默认输入法框架 <a id="switch-framework"></a>

Ubuntu 用 im-config（输入法配置工具）管理默认框架。将默认框架切到 fcitx5：

```bash
im-config -n fcitx5
```

执行后用户级配置 `~/.xinputrc` 写入 `run_im fcitx5`，登录时据此启动 fcitx5。可用的框架用 `im-config -l` 查看（本机为 `ibus fcitx5 xim`）。

### 4.3 配置 Wayland 环境变量 <a id="env"></a>

**关键**：Ubuntu 的 im-config 在 Wayland 下其环境变量注入脚本 `/etc/profile.d/im-config_wayland.sh` 被整体禁用（脚本内为 `if false`），GNOME 会话由 `systemd --user` 接管，只读取 `~/.config/environment.d/`。因此必须显式写环境变量文件，否则 GTK/Qt 应用仍会走 IBus 或完全不出输入法。

创建 `~/.config/environment.d/10-fcitx5-env.conf`：

```text
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
SDL_IM_MODULE=fcitx
```

重启登录后可用 `systemctl --user show-environment | grep IM_MODULE` 核对是否已注入（见 7.1）。

### 4.4 配置自启动 <a id="autostart"></a>

GNOME 登录时启动 fcitx5 守护进程。创建 `~/.config/autostart/fcitx5.desktop`：

```text
[Desktop Entry]
Type=Application
Name=Fcitx5
GenericName=Fcitx 5 Input Method
Comment=Input Method
Exec=/usr/bin/fcitx5 -d
Terminal=false
X-GNOME-Autostart-enabled=true
X-GNOME-Autostart-Delay=2
```

`X-GNOME-Autostart-Delay=2` 让 fcitx5 在桌面组件起来后再启动，避免抢在桌面前出错。

### 4.5 设置默认拼音引擎 <a id="default-engine"></a>

让默认输入法组使用拼音而非仅英文键盘。创建 `~/.config/fcitx5/profile`：

```text
[Groups/0]
Name=默认
Default Layout=us
DefaultIM=pinyin

[Groups/0/Items/0]
Name=keyboard-us
Layout=

[Groups/0/Items/1]
Name=pinyin
Layout=

[GroupOrder]
0=默认
```

第一组包含英文键盘（keyboard-us）与拼音（pinyin），默认语言设为拼音，之后在候选窗内按切换键即可中英互切。

### 4.6 生效 <a id="reload"></a>

配置只在登录会话启动时加载，已运行的进程不会即时切换。保存工作后**注销当前会话或重启系统**，重新登录后 fcitx5 自动启动，中文输入即对浏览器、编辑器、终端等生效。

## 5. 配置文件清单 <a id="config-files"></a>

| 路径 | 作用 |
| --- | --- |
| `~/.xinputrc` | im-config 写入：`run_im fcitx5`，登录启动 fcitx5 |
| `~/.config/environment.d/10-fcitx5-env.conf` | Wayland 下注入 GTK/QT/X 输入法环境变量（第 4.3 节） |
| `~/.config/autostart/fcitx5.desktop` | GNOME 登录自启动 fcitx5（第 4.4 节） |
| `~/.config/fcitx5/profile` | 输入法分组与默认引擎：默认拼音（第 4.5 节） |
| `~/.config/fcitx5/config` | 全局配置（快捷键、候选窗等，首次运行由系统生成，可不手改） |

## 6. 使用说明 <a id="usage"></a>

- **中英文切换**：默认快捷键 **Ctrl+Space**（触发激活/停用）。
- **图形配置**：运行 `fcitx5-configtool` 打开配置界面，可修改候选窗、快捷键、切换组等；也可拖拽调整候选词/双拼方案。
- **候选词翻页**：默认 `-` / `=`（或方向键），可在配置界面自定义。
- **输入法组切换**：默认 `Ctrl+Shift` 在组内多个引擎（如键盘 ↔ 拼音）间切换。
- 若系统中同时存在 GNOME 输入源（Super+Space，走 IBus），建议统一使用 Ctrl+Space 在 fcitx5 内切换，避免两套快捷键混淆（见 7.2）。

## 7. 常见问题与故障排查 <a id="troubleshoot"></a>

### 7.1 登录后不出中文输入法 <a id="no-input"></a>

按顺序排查：环境变量是否注入 → fcitx5 是否在跑 → 引擎是否加载。

```bash
# 1) 环境变量是否已注入（应在输出里见到 GTK_IM_MODULE=fcitx 等）
systemctl --user show-environment | grep -iE "IM_MODULE|XMODIFIERS"

# 2) fcitx5 进程
pgrep -a fcitx5

# 3) 拼音引擎
ls /usr/lib/x86_64-linux-gnu/fcitx5/ | grep pinyin
```

- 若 1) 为空：确认 `~/.config/environment.d/10-fcitx5-env.conf` 存在且内容正确，注销重登。
- 若 2) 无进程：确认 `~/.config/autostart/fcitx5.desktop` 存在，或手动 `fcitx5 -d` 试启动。
- 若 3) 无 `libpinyin.so`：补装 `fcitx5-chinese-addons`。
- 若某应用打开前 gsettings 输入源仍是 IBus：注销该应用所属会话再重登生效。

### 7.2 GNOME 输入源与 fcitx5 并存 <a id="gnome-imes"></a>

GNOME 自带"输入源"功能（快捷键 Super+Space）走 IBus，与 fcitx5 的 Ctrl+Space 是两套体系。若同时开启会互相抢键。建议：日常在 fcitx5 内用 Ctrl+Space 处理，GNOME 输入源保持默认即可；gnome-shell 自带的搜索框等界面文本输入仍走 IBus，属 GNOME 层行为，不影响应用内中文输入。

### 7.3 想用双拼 <a id="shuangpin"></a>

`fcitx5-chinese-addons` 已含双拼（shuangpin）引擎。在 `fcitx5-configtool` 的输入法组中新增"双拼"，并在其配置里选方案（小鹤/自然码等）。全拼与双拼可并存，使用组内切换键切换。
