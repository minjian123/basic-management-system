## 1. 目的与适用范围 <a id="purpose"></a>

本文档是开发机 **mjpc** 的**总览**：它与开发服务器 mjbk 的职责划分、系统与硬件、已装开发设施（工具链 / AI / 项目）与日常运维入口。每项设施的详细部署与排障单独成文（见[第 6 节](#docs)），本文档只做汇总与导航。它对应《[开发服务器部署使用说明总览](../开发服务器/开发服务器部署使用说明总览.md)》的「机器侧」文档——那份汇总 mjbk 上的**服务部署**，本文汇总 mjpc 上的**开发环境**。

**取值说明**：`<mjpc-IP>` / `<开发服务器-IP>` / `<Git某账户>` 等占位符与真实凭据的具体值见《[本地资源](../../用户文档/本地资源.md)》与 mjbk 本机 `deploy/.env`，不在仓库文档中记录。开发机是单人开发环境，账号与密码以本机密码管理器为准。

部署依据《[开发部署规划](../../规划/开发部署规划.md)》；系统安装与基础配置见《[Ubuntu安装部署使用说明](../工具/Ubuntu安装部署使用说明.md)》。

> **口径说明**：开发服务器文档的环境概览中曾将 mjpc 记为 Windows 11，实际 mjpc 为 **Ubuntu 26.04.1 LTS**（本机核实 2026-08-29）。以本机为准。

## 2. 环境概览 <a id="env"></a>

### 2.1 机器与角色 <a id="env-role"></a>

| 机器 | IP | 系统 | 角色 |
| --- | --- | --- | --- |
| mjpc | `<mjpc-IP>` | Ubuntu 26.04.1 LTS（GNOME，Wayland） | 开发机（本地编码、AI 助手、文档；本地模型推理） |
| mjbk | `<开发服务器-IP>` | Ubuntu 24.04.4 LTS（桌面版） | 开发服务器（GitLab、三库、CI 等，常开） |

- **开发机 mjpc**：日常开发与文档的主要环境，运行 BMS 项目、opencode 桌面、deepseek-harness 等；本地跑大模型推理（llama-server）。
- **开发服务器 mjbk**：完成持续服务（GitLab CE + runner、MySQL/PostgreSQL/达梦 DM8、MinIO 等），详见《[开发服务器部署使用说明总览](../开发服务器/开发服务器部署使用说明总览.md)》。
- 二者由 BMS 仓库的 `deploy/.env` 与脚本（如 wol、ssh）关联，详见[第 5 节](#collab)。

## 4. 项目与数据 <a id="projects"></a>

开发机源码在 `~/develop/` 下：

| 项目 | 目录 | 说明 |

| BMS（基础管理系统） | `~/develop/bms/` | 当前主项目（后端管理用途），含 `文档/`、`deploy/`、`scripts/`、`AGENTS.md` |

> BMS 的 Git 远程为内网 GitLab（地址 `http://<开发服务器-IP>:8080/bms/bms.git`，含认证凭据），凭据不在文档中记录；开发机为单人直推 main 模式（见《[Git协作规范](../../规范/Git协作规范.md)》）。

## 5. 部署与运维联动 <a id="collab"></a>

开发机与开发服务器 mjbk 的联动入口：

- **凭据**：真实值只写 mjbk 本机 `deploy/.env`（键位见 `deploy/.env.example`），开发机侧通过 SSH 免密登录 mjbk 操作，不复制凭据到文档。
- **服务器电源控制**：远程唤醒 `python scripts/tools/wol/wake_mjbk.py`；远程关机 `python scripts/tools/wol/shutdown_mjbk.py`（破坏性，需人工确认）。详见《[开发服务器电源控制使用说明](../工具/开发服务器电源控制使用说明.md)》。
- **后台任务**：长命令用 `scripts/tools/bg/`（bg-run/bg-status/bg-stop）与 `.opencode/plugins/bg.js` 后台化，避免同步阻塞。详见《[通用后台执行器部署使用说明](../工具/通用后台执行器部署使用说明.md)》。
- **远程操作**：SSH/WinRM 到 mjbk 的方式与模板见《开发服务器部署使用说明总览》相关章节。
