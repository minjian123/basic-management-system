1. 简介与选型理由

uv 是 Astral 出品的 Python 包管理与虚拟环境一体化工具（Rust 实现），兼具 pip / pip-tools / virtualenv / pyenv 的能力。BMS 规划选型 uv 的理由：速度远超 pip、pyproject.toml 集中声明依赖与工具配置、uv.lock 锁定全量依赖保证可复现构建、解释器版本自动管理。

本机实测版本：uv 0.11.7（2026-08-05）。

2. 安装

Windows（PowerShell，推荐 winget 或官方脚本其一即可）：

winget install astral-sh.uv
# 或官方安装脚本：
irm https://astral.sh/uv/install.ps1 | iex

macOS / Linux：

brew install uv
# 或 curl -LsSf https://astral.sh/uv/install.sh | sh

安装后验证：

uv --version

3. 常用命令

3.1 依赖同步

uv sync

按 pyproject.toml + uv.lock 创建 .venv 并安装全部依赖（含 dev 组）。BMS 后端所有命令统一带 uv run 前缀，无需手动激活虚拟环境。

3.2 依赖增删

uv add fastapi            # 添加运行依赖
uv add --dev pytest        # 添加开发依赖
uv remove structlog        # 移除依赖
uv lock                    # 仅更新锁文件（如手动改过 pyproject.toml）

3.3 运行命令

uv run python -c "print('hi')"        # 在虚拟环境中执行
uv run uvicorn app.main:app --reload  # 运行项目命令
uv run ruff check .                    # 运行工具（ruff/pyright/pytest 等同理）

3.4 Python 版本管理

uv python install 3.14    # 安装指定解释器（按需，首次 uv sync 也会自动下载）
uv python list             # 查看已安装解释器

解释器版本由项目根 .python-version 固定（BMS 为 3.14），uv 自动选择对应版本，无需手动管理 PATH。

4. 与 BMS 的集成

位置说明
backend/pyproject.toml项目元数据（name bms-backend）、运行依赖、[dependency-groups] dev 开发依赖组、ruff/pyright/pytest 工具配置集中于此
backend/uv.lock全量依赖锁定（含传递依赖与哈希），CI 中 uv sync 据此可复现安装
backend/.python-version固定 3.14；若阶段依赖验证失败需按规划回退 3.13，改此文件与 pyproject 的 requires-python 并同步 CI
.github/workflows/ci.yml（阶段一任务 10）CI 后端 job 用 setup-uv → uv sync → uv run ruff / uv run pytest

5. 常见问题

现象处理
首次 uv sync 下载解释器较慢仅首次发生；或先 uv python install 3.14 手动预装
依赖变更后锁文件与 pyproject 不一致执行 uv lock 更新锁文件，再 uv sync
国内网络下载 PyPI 包慢设置镜像源：$env:UV_DEFAULT_INDEX = "https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple"（PowerShell）或写入环境变量
Windows 缓存目录占用磁盘大默认缓存 %LOCALAPPDATA%\uv\cache，可 uv cache dir 查看、uv cache clean 清理
