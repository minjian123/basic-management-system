## 1. 目的与适用范围 <a id="purpose"></a>

为 mjbk 每日本地备份（《开发服务器部署使用说明》第 8 节、脚本 `deploy/tools/backup/backup_daily.sh`）
增加**异地容灾层**：加密后单向上传百度网盘，与本地备份保留策略解耦（网盘侧删除不影响本地）。

- 上传内容：当日 MySQL 全量 / PostgreSQL 单库 / 达梦 dexp / GitLab 数据与 config（gpg AES256 加密件）
- 落位：网盘 `/apps/bms-backup/`（应用隔离目录，网页端从「我的应用数据」进入查看）
- 凭据与解密口令：《[本地资源](../../用户文档/本地资源.md)》百度网盘条目

## 2. 方案选型记录 <a id="decision"></a>

| 尝试 | 结果 |
| --- | --- |
| BaiduPCS-Go 账号密码登录 | ❌ 风控拒绝（错误 50052） |
| BaiduPCS-Go 纯 BDUSS 登录 | ❌ quota 可用但文件操作全 -6 风控 |
| BaiduPCS-Go v3.9.9（老协议） | ❌ 31030 pcs token not exist（老接口已下线） |
| 官方客户端同步空间 | ❌ 双向镜像，删除回传风险，否决 |
| **BaiduPCS-Go v4.0.2 + 官方客户端完整 Cookie** | ✅ ls/upload 可用，采用 |

## 3. 工具安装 <a id="install"></a>

1. **官方 Linux 客户端**（8.7.0，用于建立可信登录态）：`pan.baidu.com/download` 下载 deb，
   `sudo apt install -y ./baidunetdisk_8.7.0_amd64.deb`，装于 `/opt/baidunetdisk/`；远程桌面打开登录账号。
2. **BaiduPCS-Go v4.0.2**：GitHub 加速用 ghfast.top 前缀拼接
   （`git ls-remote --tags https://ghfast.top/https://github.com/qjfoidnh/BaiduPCS-Go.git` 取版本），
   下载 `BaiduPCS-Go-v4.0.2-linux-amd64.zip` 解压安装至 `/usr/local/bin/`。
   注意 mirror.ghproxy.com 已失效勿用。
3. **sqlite3**：`sudo apt install -y sqlite3`（读取客户端 cookie 库用）。

## 4. 登录与凭据 <a id="auth"></a>

核心机制：**官方客户端登录后的 cookie 库是明文 SQLite**（`~/.config/baidunetdisk/Cookies`），
提取 BDUSS/STOKEN/BAIDUID/PTOKEN 组装 `-cookies` 登录即可解除第三方风控：

```bash
DB=~/.config/baidunetdisk/Cookies
gc() { sqlite3 "$DB" "SELECT value FROM cookies WHERE name='$1' AND host_key='${2:-.baidu.com}' LIMIT 1"; }
CK="BDUSS=$(gc BDUSS .pan.baidu.com); STOKEN=$(gc STOKEN .pan.baidu.com); BAIDUID=$(gc BAIDUID .baidu.com); PTOKEN=$(gc PTOKEN .passport.baidu.com)"
BaiduPCS-Go login -cookies="$CK"
```

- 官方客户端需保持登录态（cookie 过期后在客户端重新登录一次即可，脚本每次运行实时提取）。
- 纯 BDUSS / 账号密码登录均被风控，勿再尝试（详见《[本地资源](../../用户文档/本地资源.md)》条目）。

## 5. 脚本接入 <a id="integration"></a>

`backup_daily.sh` 云同步步骤（主组件完成后执行，失败不阻断主备份）：

1. 当日产物清单：`find ... -newermt <今日>` 按 mtime 收集（含 GitLab 数据包）
2. 加密：`printf '%s' '<口令>' | gpg --batch --passphrase-fd 0 --symmetric --cipher-algo AES256 -o <产物>.gpg`
   → `/mnt/data/backup/cloud/<日期>/`
3. 上传：`BaiduPCS-Go upload *.gpg /apps/bms-backup/`（平铺，文件名自带日期时间戳；
   若网页端建了当月文件夹如 `2026-08` 则自动按月归档——mkdir 老 API 失效无法自动建目录）
4. 核验：云端 `ls` 逐一比对文件名（upload 对不存在目录会静默返回成功，必须核验防假阳性）

## 6. 测速与容量 <a id="speed"></a>

- 上传实测：10MB / 1.6s ≈ **6 MB/s**（SVIP 不限速带宽内）
- 容量：每日约 100MB（GitLab 数据包为主），年增约 36GB，18T 空间无压力
- 下载：v4.0.2 命令行有缺陷（静默 0B），恢复取件走网页端 / 官方客户端（SVIP 不限速）

## 7. 解密与恢复 <a id="restore"></a>

```bash
# 取回 .gpg 后解密还原
printf '%s' '<口令>' | gpg --batch --passphrase-fd 0 --decrypt <文件>.sql.gz.gpg > <文件>.sql.gz
```

口令见《[本地资源](../../用户文档/本地资源.md)》`BACKUP_CRYPT_PASSPHRASE` 条目（mjbk 全损时凭该文档解密云端）。
解密后按各组件标准流程恢复（MySQL 临时库导入抽查 / GitLab restore / 达梦 dimp），见 `deploy/tools/backup/README.md`。

## 8. 已知限制与维护 <a id="limits"></a>

| 项 | 说明 |
| --- | --- |
| mkdir/rm/download 失效 | 走老 PCS 接口（31030 或静默失败）；目录在网页端手动建、清理在网页端做（建议保留 30 天） |
| Cookie 过期 | 表现为云同步日志连续 `-6 请重新登录`——远程桌面打开官方客户端重新登录一次即可续期 |
| 口令轮换 | 改 mjbk `~/deploy/.env` 的 `BACKUP_CRYPT_PASSPHRASE` + 同步更新《本地资源》，旧 .gpg 用旧口令解密 |
| **客户端不常驻** | 平时完全不运行（实测常驻占约 1.9GB 内存，已禁 autostart 的 `netdisk_service.desktop` 并结束进程）；备份链路只读其 Cookies 库静态文件；唯一需要开客户端的时刻是 Cookie 过期续登 |

> 注意：pkill 客户端后可能残留 apport 崩溃收集进程数秒，无碍；Cookies 库（28KB SQLite）与进程无关。
