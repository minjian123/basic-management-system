1. 目的与适用范围

本文档指导将开发服务器 mjbk（192.168.0.107）从 Windows 11 全盘换装为 Ubuntu 22.04 LTS Server（有线网络接入），以便在其上稳定运行开发服务 （Docker + MySQL/PostgreSQL/Redis/MinIO/RocketMQ/ElasticSearch + GitLab CE）。

注意：全盘安装会清空 mjbk 现有 Windows 系统与全部数据，操作前确认无需要保留的内容。

3. 制作启动盘（Rufus）

  1. 插入 U 盘（内容会被清空）。
  2. 打开 Rufus：
    • 设备：选择 U 盘
    • 引导类型选择：点「选择」→ 选中 D:\bms-install\ubuntu-22.04.5-bms-autoinstall.iso
    • 分区类型：GPT；目标系统：UEFI（非 CSM）（默认即可，mjbk 为 UEFI 机型）
    • 点「开始」→ 弹出提示选「以 ISO 镜像模式写入」（推荐）→ 等待完成

4. 安装 Ubuntu Server

4.1 开机启动

  1. mjbk 关机，插入启动 U 盘。
  2. 开机，反复按 F12 进入启动菜单（若无效，开机按 Del/F2 进 BIOS，在 Boot 菜单把 U 盘调到第一位）。
  3. 选择 U 盘启动项（含 "UEFI" 字样的 USB 设备），回车。
  4. 出现 GRUB 菜单后，直接回车选择 Try or Install Ubuntu Server。
  5. 之后安装全程自动进行（约 10-15 分钟），无需任何键盘操作；完成后自动重启。

5. 安装后验证

  1. 确认 mjbk 网线已插好，系统开机完成（出现 mjbk login: 提示）。
  2. mjpc 上验证网络与 SSH： 
    ping 192.168.0.107
ssh minjian@192.168.0.107
  3. SSH 登录成功后确认基本环境： 
    cat /etc/os-release | head -2
ip addr | grep "inet 192.168"
sudo apt-get update -qq && echo APT-OK

6. 服务部署衔接

系统就绪后，由自动化脚本完成后续部署（仓库 deploy/setup/install-all.sh），内容包括：

  • apt 清华源、基础工具、Docker Engine（清华 docker-ce 源 + 国内镜像加速 + vfs 存储）
  • MySQL（原生服务）、PostgreSQL、Redis、MinIO、RocketMQ、ElasticSearch（Docker Compose）
  • GitLab CE（清华 deb 直装，8080 端口，已降配）+ gitlab-runner
  • 防火墙（ufw）放行、时区 Asia/Shanghai、主机名 mjbk
部署脚本与 Compose 文件从代码仓库获取（deploy/ 目录），部署详情见《开发服务器部署使用说明》。

7. 常见问题

问题处理
开机不出现启动菜单确认 BIOS 的 Secure Boot 开启与否均可启动；U 盘需为 UEFI 启动（Rufus GPT）；尝试 Del/F2 进 BIOS 手动改启动顺序
有线网卡未识别（Network 界面无 eth0）等待几秒刷新；确认网线已插且路由器灯亮；若确实无驱动，记录网卡型号反馈处理（多数 Intel/Realtek 有线网卡内核原生支持）
镜像源访问慢第 5 步必须改为清华源，否则安装可能很慢
安装后 ping 不通检查网线、路由器；确认静态 IP/网关/DNS 填写正确；ip addr 查看网卡状态
SSH 连接被拒确认第 9 步勾选了 OpenSSH；未勾选可在控制台执行 sudo apt install openssh-server
