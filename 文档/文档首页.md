## 1. 用途说明 <a id="purpose"></a>

本文档是 `文档/` 目录的**全量索引**，汇总 BMS 项目全部规划、规范、资料与设计文档，按目录分类提供跳转入口。文件格式约定：正文载体不限（`.md` / `.html`），线框图/可交互原型用 `.html` 资产（见《[文档生成规范](规范/文档生成规范.md)》）。

## 2. 目录结构总览 <a id="structure"></a>

```text
文档/
├── 规划/       # 项目级规划文档
├── 项目/       # 按阶段的项目基线
│   └── 00_准备期/  # 阶段0（准备期 / M0 启动就绪）
│       ├── 需求/   # 阶段需求基线
│       ├── 任务/   # 阶段任务基线
│       └── 计划/   # 阶段计划基线
├── 规范/       # 开发与文档规范
├── 设计/       # 系统设计文档
│   ├── 架构设计/  # 总体架构与子系统设计
│   ├── 概要设计/  # 功能模块详细设计
│   └── 布局设计/  # 界面布局方案
├── 资料/       # 参考资料、工具与部署使用说明
│   ├── 开发服务器/ # 各服务部署说明
│   └── 知识档案/  # 技术栈知识档案（72 项技术介绍）
└── 用户文档/   # 本地资源（机器凭据等）
```

| 文件夹 | 用途 | 典型文档 |
| --- | --- | --- |
| `规划/` | 项目顶层规划：总体项目规划、技术选型、功能范围、开发计划、环境部署方案 | 《总体项目规划》《项目规划说明》《开发部署规划》 |
| `项目/` | 按阶段的项目基线：需求 / 任务 / 计划 | 《准备期需求总览》《准备期计划》及各需求域 / 任务 / 计划文档 |
| `规范/` | 约束性规范：文档怎么写、标识符怎么命名、前后端代码规范 | 《文档生成规范》《命名规范》《英文简称规范》 |
| `资料/` | 参考资料与实操说明：系统安装、工具使用、服务部署 | 《Ubuntu安装部署使用说明》《graphify部署使用说明》 |
| `用户文档/` | 本地资源（机器凭据等，已 gitignore） | 《本地资源》 |
| `资料/开发服务器/` | mjbk 开发服务器各服务的部署、验证、排障记录（每服务一份） | 《开发服务器部署使用说明》及各服务说明 |
| `资料/知识档案/` | 技术栈知识档案：项目技术栈 72 项技术的通俗介绍、选型对比、参考链接（后端核心 34 + 前端 20 + 工程化 9 + 部署运维 8 + AI 工具 1） | 《技术栈知识档案总览》及各技术介绍 |
| `设计/架构设计/` | 系统架构：总体架构、数据架构、子系统拆分与设计、部署运维 | 《架构设计》01-31 |
| `设计/概要设计/` | 功能模块详细设计：用户、工作流、报表、收付款等 37 个模块 + 模块注册基础能力 | 《概要设计》01-38 |
| `设计/布局设计/` | 界面布局方案：主框架、表单框架、移动端 | 《主框架布局设计》等 |

> 浏览建议：先读「规划」了解项目，再看「设计」理解系统，开发时遵循「规范」，部署运维查「资料」。
