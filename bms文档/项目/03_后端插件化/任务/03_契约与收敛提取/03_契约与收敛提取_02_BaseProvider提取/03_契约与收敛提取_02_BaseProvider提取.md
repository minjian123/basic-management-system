## 2. 任务内容 <a id="content"></a>

1. 提取 `BaseProvider(BaseCapability)`：统一「注册项」公共契约（抽象 `key` + 元信息），4 类提供者（`BaseFieldType` / `BaseQueryProvider` / `BaseDashboardCardProvider` / `BaseHealthCheck`）改继承
2. 与 `BasePluggable` 边界保持清晰：提供者走**组合轨**（域注册表 / `register_plugin` 显式登记），不因本提取混入继承自动登记
3. 键口径统一：各域 `key` 与健康 `name` 的收敛口径随详细设计逐项确认（不破坏既有 API）
4. 登记回写：架构 04、基类清单

## 3. 完成标准 <a id="accept"></a>
