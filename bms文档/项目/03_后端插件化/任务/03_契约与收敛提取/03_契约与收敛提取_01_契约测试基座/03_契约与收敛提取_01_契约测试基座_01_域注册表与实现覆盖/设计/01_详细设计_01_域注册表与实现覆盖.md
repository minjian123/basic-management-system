## 1. 概述 <a id="overview"></a>

- **目标**：4 个域注册表（字段类型 / 查询提供者 / 仪表盘卡片 / 健康检查）实现变体与**注册项**纳入统一契约套件：聚合模板语义、`Null` 无副作用、注册项枚举自动纳入（含额外测试注册项验证链路）。
- **范围**：`tests/contracts/test_domain_registry_contracts.py` + `tests/contracts/conftest.py`（测试注册表 / 注册项替身）。
- **不含**：3 域注册表唯一性断言（其 `Null` 实现当前 `register` 为 no-op；随 **03-3** 收敛后按声明式清单开启）；真实依赖探针（健康 `local` 的 redis/database 聚合不执行真实探活，用测试检查项构造验证模板）。
- **依据**：[需求 03-1](../../../../../需求/03_需求_契约与收敛提取.md#r03-1)、《[03-1 详细设计](../../设计/01_详细设计_01_契约测试基座.md)》、《架构设计 · 扩展点与插件化》「阶段三交付与验收（M3 口径）」节。

## 2. 现状与差距 <a id="gap"></a>

| 域 | 注册表变体 | 注册项 |
| --- | --- | --- |
| 字段类型 | `BaseFieldTypeRegistry`（抽象）/ `NullFieldTypeRegistry` | 空集（`Null` 恒过 / 固定列类型） |
| 查询提供者 | `BaseQueryProviderRegistry` / `NullQueryProviderRegistry` | 空集（空结果） |
| 仪表盘卡片 | `BaseDashboardCardRegistry` / `NullDashboardCardRegistry` | 空集（空卡片集） |
| 健康检查 | `BaseHealthCheckRegistry` / `HealthCheckRegistry`（`local`）/ `NullHealthCheckRegistry` | `redis` / `database`（`local` 装配工厂注入） |

## 3. 套件设计 <a id="design"></a>

### 3.1 域注册表契约清单（声明式，供 03-3 翻转）

```python
@dataclass(frozen=True)
class RegistryContract(BaseObject):
    suite_name: str                 # 域名（fieldtype / query / dashboard / health）
    registry_factory: Callable[[], Any]   # 变体实例工厂
    uniqueness: bool                # 唯一性断言开关（当前仅 health=True；03-3 收敛后翻转）
    empty_aggregate: ...            # 空集聚合语义断言（按域）
```

- 唯一性：`health=True`（02-2 已收敛，重名 `ConflictError`）；其余 3 域当前为 `Null` no-op → 断言「**Null 无副作用**」（`register` 后 `keys()` 仍空）；03-3 收敛后把开关改 `True` 并补重名断言（数据翻转，不改套件结构）。

### 3.2 聚合模板语义（按域断言）

| 域 | 断言 |
| --- | --- |
| 字段类型 | `validate(unknown)` / `column_type(unknown)` → `NotFoundError`；`Null`：恒过（空违规元组）/ 固定 `NULL_COLUMN_TYPE` |
| 查询提供者 | `query(unknown)` → `NotFoundError`；`Null`：空行 / `total=0` |
| 仪表盘卡片 | `metadata(unknown)` / `fetch(unknown)` → `NotFoundError`；`Null`：空卡片集 |
| 健康检查 | 空集 `aggregate().ok is True`；含测试检查项（通过 / 失败 / 超时）聚合语义（复用既有模板口径）；`Null`：`register` no-op、`aggregate().ok is True`（不探依赖） |

### 3.3 注册项自动纳入（额外测试注册项）

- `conftest.py` 提供各域**测试注册表替身**（继承对应基类的内存实现，测试专用，不入 `app/`）：登记 1 个测试注册项后，套件按 `values()` / `keys()` 枚举——**新增注册项自动出现在参数化用例**（数量互证）。
- 健康域用真实 `HealthCheckRegistry` 实例 + 测试检查项，不触碰装配工厂实例（不执行真实探活）。
