## 3. 任务内容 <a id="content"></a>

1. 统一契约套件（pytest）：以参数化 fixture 遍历注册表**全部注册实现**，统一校验——注册唯一性（重名拒）/ 未命中语义（按域约定）/ `Null` 无副作用 / 聚合模板 / 生命周期（`setup` 幂等、`aclose` 可重入）
2. **自动纳入**机制：新增实现仅需登记注册表即被套件遍历（防漏测）；用例与被测域解耦（不改套件加实现）
3. 覆盖插件注册表（01-1 语义：构建 / 解析 / 快照 / 实例缓存 / 契约版本）与域注册表（4 域）及全部注册实现（含 `Null`）
4. 执行口径：入常规 `pytest` 链路（本地 / CI 冒烟与全量分层一致）；用例入 Kiwi
5. 嵌套子任务「域注册表与实现覆盖」（03-1-1）：4 域注册表与全部实现遍历 + 聚合模板 / Null 语义（见子任务文档）

## 4. 完成标准 <a id="accept"></a>

契约套件可运行并遍历全部已注册实现；新增实现自动纳入（以对象存储双实现验证——随 04-1 接入）；`Null` 实现纳入；全量 `pytest` / `ruff` / `pyright` 全绿；作为 M3「契约测试全覆盖」证据入阶段测试报告（04-2）。
