## 1. 概述 <a id="overview"></a>

- **目标**：落地统一契约套件——以**装配快照自动枚举**为机制，统一校验插件注册表语义与**全部注册实现**（类实现实例化断言生命周期；工厂实现只读）；域注册表与注册项覆盖归嵌套 03-1-1；套件入常规 `pytest` 链路，作为 M3「契约测试全覆盖」证据。
- **范围**：`tests/contracts/`（新增目录：`conftest.py` + `support.py` + `test_plugin_contracts.py`）；域侧用例归 [03-1-1](../03_契约与收敛提取_01_契约测试基座_01_域注册表与实现覆盖/03_契约与收敛提取_01_契约测试基座_01_域注册表与实现覆盖.md)。
- **不含**：对象存储双实现（04-1）——其登记后**自动**被快照枚举纳入，套件无需改动；注册表构建 / 解析语义的既有单测（01-1 / 01-1-1 / 02-2，Kiwi 529 / 530 / 565）保留，本套件只做必要抽查避免重复建设。
- **依据**：[需求 03-1](../../../../需求/03_需求_契约与收敛提取.md#r03-1)、《架构设计 · 扩展点与插件化》「阶段三交付与验收（M3 口径）」节交付物 #7、《[测试规范](../../../../../../规范/测试规范.md)》「自动化测试分层」节、《[01-1 详细设计](../../../01_插件化基座/01_插件化基座_01_中间层与注册表/设计/01_详细设计_01_中间层与注册表.md)》。

## 4. 套件设计 <a id="design"></a>

### 4.1 快照与自动纳入（核心机制）

```python
@pytest.fixture(scope="session")
def plugin_snapshot() -> Mapping[str, Mapping[str, PluginImpl]]:
    """全量装配快照：应用工厂 → 平台实现登记 → 注册表构建（离线，不进入 lifespan）。"""
```

- 参数化用例在收集期由快照生成（`plugin_key` / `plugin_name` / 实现条目三元组，构建函数落在 `support.py` 供模块导入期调用；`conftest.py` 会话级 fixture 兜底单文件运行场景）——**新增实现仅需登记注册表即被遍历**；快照条目数与被测参数数由一条结构性用例互证。
- 工厂实现不实例化（保持依赖隔离：不拖入未选中实现）；类实现可实例化（当前 35 个均为 `Null` 类，无副作用）。

### 4.2 注册表语义抽查（不与既有单测重复）

| 断言 | 说明 |
| --- | --- |
| 快照完整性 | 快照键与装配清单一致；`plugin_name` 非空；`contract_version` 为 `X.Y.Z`；`null` **类实现**继承 `BaseNullObject`（`masking:null` 为工厂条目，不实例化故不适用） |
| 唯一性（临时注册表实例） | 同 `(plugin_key, plugin_name)` 两实现构建 → `PluginError`（注册表语义护栏） |
| 未命中与缺省 | 未注册 provider → `PluginError`；空 provider → 解析到 `null` |
| 实例缓存 | 同一 provider 两次解析同实例 |

### 4.3 全部类实现遍历（参数化，35 项）

| 断言组 | 内容 |
| --- | --- |
| 可实例化 | `inspect.signature` 无必填参数且实际零参构造成功 |
| 生命周期 | `await setup()` 连续两次无异常（幂等）；`await aclose()` 连续两次无异常（可重入） |
| 元信息 | `describe()` 非空且含 `plugin_key:plugin_name@contract_version`；`contract_version` 格式合法 |
| Null 语义 | `plugin_name == "null"` → `isinstance(impl, BaseNullObject)` |

### 4.4 工厂实现只读断言（2 项）

- 条目存在且名称规范；**不实例化、不解析**（避免导入未选中实现依赖）；
- 工厂条目在 `PLUGIN_WIRINGS` 中有对应端口（登记完整性）。

## 6. 实施步骤 <a id="steps"></a>

1. `tests/contracts/support.py`（快照构建函数 + 域侧替身）+ `conftest.py`（会话级快照 fixture；`create_app` + `register_platform_plugins` + `build_plugin_registry`）。
2. `test_plugin_contracts.py`（Kiwi 567）。
3. 验证：`pytest tests/contracts -q`、全量 `pytest` / `ruff` / `pyright` 全绿。
4. 回写：任务 / 需求 / 计划状态与记录；M3 门禁证据索引（04-2）。

## 7. 验收映射 <a id="accept-map"></a>

| 完成标准 | 验证方式 |
| --- | --- |
| 契约套件可运行并遍历全部已注册实现 | 快照参数化用例（35 类 + 2 工厂条目） |

| `Null` 实现纳入 | 参数化覆盖 35 个 `null` 类 |
| `pytest` / `ruff` / `pyright` 全绿 | 验证命令输出 |

## 8. 边界与开放项 <a id="boundary"></a>

- 域注册表与聚合模板覆盖 → 03-1-1；3 域注册表唯一性断言待 03-3 收敛后按声明式清单开启。
- 生命周期的**真实依赖行为**（如 MinIO 客户端初始化）属实现自身测试与阶段八实测，本套件只做契约级幂等 / 可重入。
