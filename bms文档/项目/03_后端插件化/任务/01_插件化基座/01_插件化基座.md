## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段三插件化基座 3 条需求——[01-1 插件化中间层与注册表](../../需求/01_需求_插件化基座.md#r01-1)、[01-2 配置驱动装配与启动 / CI 校验](../../需求/01_需求_插件化基座.md#r01-2)、[01-3 插件清单接口](../../需求/01_需求_插件化基座.md#r01-3)，细拆为 5 个子任务：中间层与注册表（01）、解析器与契约版本（02）、配置分区与启动装配（03）、启动校验与 CI 离线校验（04）、插件清单接口（05）。
- **依据**：[《架构设计 · 扩展点与插件化》](../../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)「基类承载与双轨」「注册表与三阶段发现」「配置驱动装配」「阶段三交付与验收（M3 口径）」节；[《后端基类清单》](../../../../后端基类清单.md)「中间层基类」节；[《后端开发规范》](../../../../规范/后端开发规范.md)「后端基座体系（强制）」节。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：16h（01 4h + 02 4h + 03 3h + 04 2h + 05 3h）。
- **关键依赖**：02 → 01（注册表）；03 → 01、02（注册表 + 解析器）；04 → 02、03（契约版本 + 装配路径）；05 → 01、03（注册表快照 + 当前 provider）。域内串行为主；域二 ~ 四任务依赖本域机制就位后启动。
- **风险**：`__init_subclass__` 自动登记对可实例化子类的判定边界（抽象端口误登记 / 实现漏登记）；延迟导入与已装配单例路径保持唯一（防绕过注册表直连实现）；契约版本主版本兼容口径与域二各能力域基类 `contract_version` 起步值需保持一致。
