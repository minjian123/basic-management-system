## 4. resolve 契约 <a id="resolve"></a>

```python
class PluginRegistry(BaseObject):
    def resolve(
        self,
        plugin_key: str,
        provider: str | None = None,
        *,
        expected_version: str | None = None,
    ) -> object: ...


def resolve_plugin(
    plugin_key: str,
    provider: str | None = None,
    *,
    expected_version: str | None = None,
) -> object: ...
```

语义：

| 步骤 | 规则 |
| --- | --- |
| provider 归一 | `provider or NULL_PLUGIN_NAME`（`None` / 空串回退缺省实现 `null`，占位可跑） |
| 实现查找 | 只读快照按 `(plugin_key, 实现名)` 命中；未命中 → `PluginError`（消息含键、实现名与已注册实现列表） |
| 实例化与缓存 | 缓存未命中时调用注册项（实现类或零参工厂）；结果按 `(plugin_key, 实现名)` 缓存，**同 provider 复用唯一实例**（请求期只取引用） |
| 契约版本 | 传 `expected_version` 时校验主版本一致（见第 5 节）；未传不比对（专项校验归装配 / CI） |
| 生命周期 | 只实例化与缓存，**不调用** `setup()` / `aclose()`（归装配 02/03；`aclose` 经 `ResourceManager` 回收） |
| 缓存重建 | `build()` 清空实例缓存（快照变更防陈旧；重建后实例重建） |

- 返回类型为 `object`（组合路径的结构化实现不继承 `BasePluggable`）；消费方（提供者 `get_xxx`）按其能力端口 `cast`。
- 生产路径由装配期（02）统一预热解析：请求期调用为缓存命中，不在请求内实例化 / 导入。

## 5. 契约版本兼容校验 <a id="version"></a>

| 项 | 规则 |
| --- | --- |
| 版本形态 | `X.Y.Z`（与 `BasePluggable.contract_version` 口径一致） |
| 兼容判定 | 主版本（`X`）一致即兼容；minor / patch 差异放行 |
| 实现侧取值 | 实例属性 `contract_version`；组合路径结构化实现缺失该属性且传了 `expected_version` → `PluginError`（无法证明兼容） |
| 期望版本格式非法 | 非 `X.Y.Z` → `PluginError` |
| 不匹配处置 | `get_logger("bms").error("插件契约版本不兼容", plugin_key=…, plugin_name=…, expected=…, actual=…)` 告警 + 抛 `PluginError`（40002）；**不缓存**失败实例 |
| 调用落点 | 装配（02）/ CI（01-2-1）取端口 `BaseXxx.contract_version` 作为 `expected_version`；域二 02-2 提供者改造时接入 |

## 6. 测试设计（Kiwi 先行） <a id="tests"></a>

用例先登记 Kiwi（本任务登记 **Kiwi 530**，平台自增顺延）：

| Kiwi | 用例 | 断言要点 |
| --- | --- | --- |
| 530 | 同 provider 唯一实例 | 连续 `resolve` 返回同一对象；不同 `plugin_key` / 实现名各自独立 |
| 530 | 缺省回退 `null` | `provider=None` 与 `provider=""` 均解析到 `null` 登记实现 |
| 530 | 未注册抛错 | 未注册 `(键, 实现名)` → `PluginError`（含键名与已注册实现名） |
| 530 | 组合路径工厂 | 零参工厂仅调用一次，结果缓存复用 |
| 530 | 版本兼容放行 | 期望与实现主版本一致（minor / patch 不同）通过 |
| 530 | 主版本不匹配 | 不匹配 `PluginError` + stdout 告警日志（含键 / 实现名 / 版本） |
| 530 | 缺失版本属性 | 结构化实现无 `contract_version` 且传期望版本 → `PluginError`；未传则跳过 |
| 530 | 期望版本格式非法 | 非 `X.Y.Z` → `PluginError` |
| 530 | 构建清缓存 | `build()` 重建后解析得到新实例（非旧缓存） |
| 530 | 模块入口 | `resolve_plugin` 薄封装（隔离默认注册表）按同一语义工作 |

- 测试隔离：沿用 01-1 夹具——`monkeypatch` 替换进程级默认注册表，用例类不污染真实默认实例。
- 覆盖率：`app/core/plugin.py` 保持 100%（《AI开发规范》验证步）。
