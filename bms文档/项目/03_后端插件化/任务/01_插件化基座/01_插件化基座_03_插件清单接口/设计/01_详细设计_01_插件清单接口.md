## 1. 概述 <a id="overview"></a>

- **目标**：提供平台超管只读插件清单——`GET /api/v1/plugins`（按能力分组）与 `GET /api/v1/plugins/{plugin_key}`（单能力明细）；字段与《架构设计 · 扩展点与插件化》「插件清单接口」节一致；**不含 `options` 密钥**；未登记能力 404。
- **范围**：`app/api/plugins.py`（新增）、`app/schemas/plugin.py`（新增响应模型）、`app/api/router.py`（挂载）、`app/core/assembly.py`（`app.state.plugin_providers` 摘要）、`tests/api/test_plugins.py`。
- **不含**：启停 / 热切换写接口（演进项）；`platform:manage` 鉴权（随认证 / RBAC 阶段，当前与既有平台接口一致暂不鉴权）。
- **依据**：[需求 01-3](../../../../需求/01_需求_插件化基座.md#r01-3)、《架构设计 · 扩展点与插件化》「注册表与三阶段发现」节（插件清单接口）、《[01_02 详细设计 · 配置分区与启动装配](../../01_插件化基座_02_配置分区与启动装配/设计/01_详细设计_01_配置分区与启动装配.md)》、《[后端开发规范](../../../../../../规范/后端开发规范.md)》（API 接口规范）、《架构设计 · 接口与集成》错误码口径。

## 4. 接口契约 <a id="api"></a>

### 4.1 `GET /api/v1/plugins`

统一 `ApiResponse`，`data` 为按能力分组的数组（组内 `plugin_key` 排序、实现按 `plugin_name` 排序）：

```json
[
  {
    "plugin_key": "health_check_registry",
    "provider": "local",
    "implementations": [
      {"plugin_name": "local", "contract_version": "0.1.0", "status": "active"},
      {"plugin_name": "null", "contract_version": "0.1.0", "status": "registered"}
    ]
  }
]
```

| 字段 | 口径 |
| --- | --- |
| `provider` | 当前配置选中的实现名（空配置 → `null`）；取 `app.state.plugin_providers`（装配摘要，与启动日志同源） |
| `contract_version` | 类实现读类属性 `contract_version`（缺失时回落端口版本）；**工厂 / 结构化实现报端口契约版本**（装配已验主版本一致） |
| `status` | 当前选中 → `active`；其余已注册 → `registered` |
| 密钥 | 不返回 `options`（装配摘要只含 provider 名，天然不含密钥） |

### 4.2 `GET /api/v1/plugins/{plugin_key}`

返回单个能力分组（字段同上）；**未登记能力**（不在装配清单）→ `NotFoundError`（10002 / 404，统一响应体）。

### 4.3 只读与鉴权

- 仅 `GET`；无启停 / 切换写接口（`POST` / `PUT` / `DELETE` → 405 Method Not Allowed）。
- 当前与既有平台接口一致**暂不鉴权**；`platform:manage` 随认证 / RBAC 阶段接入（架构 10 §4 口径）。

## 5. 实现要点 <a id="impl"></a>

- `assemble_plugins` 在日志前后落 `app.state.plugin_providers = providers`（`dict[plugin_key, provider]`）。
- 接口组装：`plugin_registry_snapshot()`（实现与类版本）+ `PLUGIN_WIRINGS`（端口版本 / 登记能力集合）+ `app.state.plugin_providers`（当前选中）；不实例化实现、不读 `options`。
- 响应模型落 `app/schemas/plugin.py`（`BaseSchema` 体系）；路由落 `app/api/plugins.py`（`APIRouter(prefix="/plugins")`）并挂 `api_router`。

## 9. 边界与开放项 <a id="boundary"></a>

- 鉴权（`platform:manage`）随认证 / RBAC 阶段；启停 / 热切换属演进路线，不提供写接口。
- 平台内建存储实现（`local` / `minio`）落地后清单自动呈现（04-1），本接口无需改动。
