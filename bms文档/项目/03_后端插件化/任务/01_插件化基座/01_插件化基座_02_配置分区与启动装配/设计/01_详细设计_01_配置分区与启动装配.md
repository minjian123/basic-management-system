## 1. 概述 <a id="overview"></a>

- **目标**：`config.toml` 能力分区 `provider` / `options` 配置化；新增装配清单与装配函数（`app/core/assembly.py`），应用 lifespan 严格装配（读取 provider → 解析实例化缓存 → 落 `app.state` → `setup()` → 启动日志 → `aclose` 经 `ResourceManager`）；替代 `main.py` 直连 `NullXxx()` 装配段；注册规则补充「构造需参数类不自动登记」，masking 以显式工厂登记。
- **范围**：`app/core/config.py`（`PluginSelection` + 35 个选择字段）、`app/core/assembly.py`（新增）、`app/core/plugin.py`（登记排除规则）、`app/main.py`（lifespan 装配、删直连段）、`config.toml`（分区示例）、测试 lifespan 化。
- **不含**（归嵌套 01-2-1 / 后续任务）：启动校验与 CI 离线校验、依赖隔离用例（01-2-1）；35 个 `get_xxx` 提供者改造（02-2）；平台内建实现（04-1）；`app/plugins/` 集中区不启用。
- **依据**：[需求 01-2](../../../../需求/01_需求_插件化基座.md#r01-2)、《架构设计 · 扩展点与插件化》「配置驱动装配」节、《[01-1 详细设计 · 中间层与注册表](../../01_插件化基座_01_中间层与注册表/设计/01_详细设计_01_中间层与注册表.md)》、《后端开发规范》「后端基座体系（强制）」节。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |
| --- | --- |
| `main.py` 直连装配 33 个能力占位实例（`app.state.<attr> = NullXxx()`） | 未走注册表解析、配置不可切换 |

## 4. 配置分区口径 <a id="settings"></a>

```python
class PluginSelection(BaseSettings):
    """能力实现选择（provider + 非敏感 options；密钥只走 Secret / 环境变量）。"""

    provider: str = ""
    options: dict[str, object] = Field(default_factory=dict[str, object])
```

- `provider` 缺省 `""` → 解析到 `null`（占位可跑）；`options` 仅非敏感项（`BMS_<分区>__OPTIONS__<键>` 亦可覆盖）。
- `Settings` 为**全部已登记能力**（35 项：33 个 `app.state` 属性 + `data_scope` / `sharding`）声明选择字段；字段名即 `config.toml` 分区名（`object_storage` 别名 `storage`；分区名为契约，变更走破坏性流程）。
- `config.toml` 仅按需列**被替换域**（本轮 `[storage] provider = ""` 示例 + 注释），未列域取默认空 → `null`。

## 5. 装配清单与装配函数 <a id="assembly"></a>

`app/core/assembly.py`：

```python
@dataclass(frozen=True)
class PluginWiring(BaseObject):
    plugin_key: str
    port: type[BasePluggable]        # 端口类（契约版本基准 / 状态归属）
    settings_section: str            # config.toml 分区名
    state_attr: str | None           # app.state 属性名（None=仅预热）

PLUGIN_WIRINGS: tuple[PluginWiring, ...]  # 35 项（含 storage 别名 object_storage）
```

| 规则 | 说明 |
| --- | --- |
| `register_platform_plugins(settings, app, resources)` | 平台内建实现登记（显式工厂；延迟导入/依赖注入落点）：先导入 33 个同域 `null.py`（**导入即经继承自动登记**；`main.py` 不再导入缺省实现），再登记 `masking:null`（工厂内 `checker = resolve_plugin("permission", …)` 注入）与 `health_check_registry:local`（02-2 起；工厂读取运行期对象：超时配置 / `redis`、`database` 检查项 / 资源登记）；真实实现（04-1 `local` / `minio`）后续在此追加（工厂内 import 实现模块） |
| 幂等 | 以默认注册表对象身份记账，同一进程重复生命周期只登记一次（注册表构建后只读） |
| `assemble_plugins(app, settings, resources)` | 遍历清单：取 `provider`（空 → `null`）→ `resolve_plugin(..., expected_version=port.contract_version)`（存在性 / 版本校验）→ `await setup()`（失败包装 `PluginError` 拒启、CRITICAL 日志）→ 实例登记 `ResourceManager`（逆序 `aclose`）→ 有 `state_attr` 则落 `app.state` |
| 启动日志 | 单条结构化 INFO `插件装配完成`，字段 `providers={plugin_key: 实现名}`（**不含 options**） |
| 顺序 | 清单顺序保证依赖先行（`permission` 在 `masking` 前）；同 provider 复用唯一实例（解析缓存） |

`main.py` lifespan 顺序：`validate_startup` → 模块注册校验 → `register_platform_plugins` → `build_plugin_registry` → `assemble_plugins` → `startup_complete=True` → `finally: resources.aclose()`；删除 33 项直连段（`health_check_registry` / engine / module_registry / demo_service 等非插件项保留）。

## 6. 登记规则补充 <a id="rule"></a>

`core/plugin.py` 构建期候选剔除新增一条：**构造需参数（非零参可实例化）的类不自动登记**（与「抽象剔除 / 无名跳过」并列）——插件实例化口径为零参，需注入依赖的实现经显式工厂登记（`register_plugin` / 装配清单）。影响：`NullMasker` 不再自动登记，由 `register_platform_plugins` 显式工厂登记；其余类零参可实例化不受影响。回写 01-1 / 02-1 详细设计口径注记。

## 7. 测试改造与用例 <a id="tests"></a>

- **既有用例 lifespan 化**（Kiwi 无新增，回归口径）：33 个文件中 40 处 `create_app()` 模式统一改为 `async with lifespan(app):` 包裹后续断言 / 请求（codemod + 人工复核；`conftest`、已用 lifespan 的用例跳过）。
- **新增 `tests/crosscut/test_plugin_assembly.py`（Kiwi 533）**：

| Kiwi | 用例 | 断言要点 |
| --- | --- | --- |
| 533 | 默认装配 | lifespan 后 33 个 `app.state.<attr>` 为对应 `NullXxx`；`health_check_registry` 等非插件项不受影响 |
| 533 | 配置切换 | 隔离注册表 + 自定义 `Settings`（`storage.provider` 指向测试工厂）：装配取测试实现、消费方（既有 provider / 路由）零改动 |
| 533 | 依赖注入工厂 | `masking:null` 工厂拿到 `permission` 解析实例（`checker` 注入生效） |
| 533 | 缓存复用 | 装配后 `resolve_plugin` 返回同一实例；请求期不重新实例化 |
| 533 | setup / aclose | 覆写 `setup` / `aclose` 的测试实现被调用；lifespan 退出后 `aclose` 触发（`ResourceManager` 逆序） |
| 533 | 启动日志 | `插件装配完成` 含各能力 provider；`options` 值不出现在输出 |

- 覆盖率：`app/core/plugin.py` / `app/core/assembly.py` 100%。
