## 1. 概述 <a id="overview"></a>

- **目标**：核销 M3 收口后的四项遗留（过渡物清理 / MinIO 真实连通 / 4 端口 Null 与接线 / health Null 口径对齐），完善插件化收尾质量；不改需求状态，M3 结论维持（插件清单口径由 36 扩至 40 属能力补齐）。
- **范围**：`app/core/registry.py` 删除、`[minio].bucket` 移除、4 个能力域 Null 实现与全量接线、MinIO 集成用例、health Null 登记口径、登记回写。
- **不含**：四能力的真实实现（缓存接 Region 真实实现（**2026-09-21 口径回写**：redis-py（asyncio）自写，02-4-27 落地）/ 审计落库 / 任务调度入库 / 消息中间件分别随审计 / 阶段六 / 阶段八）；事件域消费轨 Null（同 `plugin_key` 重名约束，随后续）。
- **依据**：[阶段测试报告](../../../../01_测试报告_后端插件化.md)§4、[计划台账](../../../../计划/01_计划_后端插件化.md#deferred)第 6 项、《架构设计 · 扩展点与插件化》「配置驱动装配」节、《安全开发规范》「密钥与脱敏」节。

## 4. 设计 <a id="design"></a>

### 4.1 过渡物清理

| 项 | 动作 |
| --- | --- |
| `app/core/registry.py` | 删除；`tests/crosscut/test_plugin_providers.py` / `test_plugin_registration.py` 导入改 `app.core.provider`；文档注记（架构 04 / 基类清单「过渡导出」→ 已清理） |
| `[minio].bucket` | `MinioSettings` 去除 `bucket` 字段、`config.toml` 去键；桶名唯一口径 `[storage].options.bucket`（缺省 `bms-files`）；环境变量 `BMS_MINIO__BUCKET` 失效（原已不读取） |

### 4.2 4 端口 Null 实现（组合轨：自动登记，零显式注册）

| 能力（`plugin_key`） | 端口 | Null 实现（语义） |
| --- | --- | --- |
| `cache` | `CacheRegion` | `NullCacheRegion`：`domain="null"`；`get → None`；`set` 空操作；`delete → False`；`get_global_version → 0` |
| `audit` | `AuditCapturer` | `NullAuditCapturer`：`is_audited → False`；`capture` 返回占位审计事件（`EventEnvelope(event_type="audit.null")`，不改写库） |
| `task` | `BaseTask` | `NullTask`：`name="null_task"`；`run` 空操作返回 `None` |
| `event` | `EventPublisher` | `NullEventPublisher`：`event_type="event.null"`；`publish` / `publish_transactional` 空操作（消费轨随后续） |

- 装配接线（`assembly.py`）：`PluginWiring("cache", CacheRegion, "cache", "cache")`、`("audit", AuditCapturer, "audit", "audit")`、`("task", BaseTask, "task", "task")`、`("event", EventPublisher, "event", "event_publisher")`。
- 配置分区：`Settings` 增 `cache` / `audit` / `task` / `event`（`PluginSelection`，缺省 `provider=""` → 解析到 `null`）；`config.toml` 增对应节（同既有注释口径）。
- 提供者薄封装：`get_cache_region` / `get_audit_capturer` / `get_task` / `get_event_publisher`（`resolve_plugin` + `app.state.settings`），经 `app/api/deps.py` 导出。
- 口径变化：插件清单 **36 → 40 键**；契约快照类实现 35 → 39（自动遍历，套件结构不改）；`ops/check_plugins` 校验 40 项；相关计数断言（`test_plugins` 等）同步。

### 4.3 health Null 登记口径对齐

- `NullHealthCheckRegistry` 删除 `register` 覆写（继承真实登记：登记可枚举、重名 `ConflictError`）；`keys` / `get` 继承；`aggregate` 覆写不变（空集恒通过、不探依赖）。
- 影响用例：`test_null_health_semantics` 断言「注册后可枚举 + 聚合仍为空集就绪」（03-3 同法）。

### 4.4 MinIO 真实连通验证（env 门控）

- 新增 `tests/integration/test_minio_integration.py`：`pytestmark = pytest.mark.integration`；未配置 `BMS_MINIO__ENDPOINT` / `BMS_MINIO__ACCESS_KEY` / `BMS_MINIO__SECRET_KEY` 时 `pytest.skip`（与 Redis / 真库集成用例同口径）。
- 用例：以唯一前缀建对象 → `put` / `get` 回读一致 / `exists` / `presign`（URL 可解析）→ `delete`（幂等）；收尾清理。
- 本地实测：以开发服务器 `bms-minio` 凭据（本地资源文档）导出环境变量运行一次；CI 无凭据自动跳过（不阻塞流水线）。

## 8. 边界与开放项 <a id="boundary"></a>

- 事件域消费轨（`EventConsumer`）Null 随后续（同键约束下只登记发布轨）。
- 4 能力真实实现分别随通用能力（缓存）/ 审计 / 阶段六（任务）/ 阶段八（事件）；本任务只补缺省实现与接线。
- MinIO 集成用例默认跳过，激活方式与环境变量口径随《测试规范》集成用例章。
