## 2. 任务内容 <a id="content"></a>

1. **过渡物清理**：删除 `app/core/registry.py` 过渡导出（导入改 `app/core/provider.py`）；移除 `[minio].bucket` 废弃键位（桶名统一 `[storage].options.bucket`）
2. **MinIO 真实连通验证**：新增 env 门控集成用例（`BMS_MINIO__*`）；本地以开发服务器 `bms-minio` 实测 `put` / `get` / `exists` / `presign` / `delete`，CI 无凭据自动跳过（与 Redis / 真库集成用例同口径）
3. **4 端口 Null 实现与装配接线**：`CacheRegion` / `AuditCapturer` / `BaseTask` / `EventPublisher` 补 `NullXxx` 并全量接线（`PluginWiring` + 配置分区 + `app.state` + `get_xxx` 提供者）；插件清单 36 → 40，契约套件自动纳入（事件域仅发布轨，消费轨随阶段八）
4. **health Null 登记口径对齐**：`NullHealthCheckRegistry.register` 改真实登记（与其余 3 域一致）；空集聚合「不探依赖」语义不变
5. 登记回写：计划台账第 6 项核销（第 7 项仍随对应阶段）；架构 04 / 基类清单 / 相关任务记录注记

## 3. 完成标准 <a id="accept"></a>

四项遗留处理完成：过渡物零残留；MinIO 连通实测通过且 CI 跳过可控；4 能力接线后清单 40 项、契约套件与既有用例全绿；health Null 口径与 3 域一致；全量 `pytest` / `ruff` / `pyright` / `check_plugins` 通过；台账与记录同步。
