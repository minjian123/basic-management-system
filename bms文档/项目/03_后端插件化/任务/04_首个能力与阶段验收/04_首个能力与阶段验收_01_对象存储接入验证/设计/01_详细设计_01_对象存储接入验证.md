## 1. 概述 <a id="overview"></a>

- **目标**：对象存储首个纵向能力落地——`local`（本地文件系统，真实读写）落 `app/storage/local.py` 并经装配工厂登记；`config.toml [storage] provider` 缺省改 `local`；切换 `local` / `minio` 消费方零改动；双实现纳入契约套件（03-1）与插件清单（01-3）。
- **范围**：`local` 实现、工厂登记、缺省切换与影响面适配、测试（真实读写 / 切换零改动 / 纳管）；`minio` 实现等归 [04-1-1](../04_首个能力与阶段验收_01_对象存储接入验证_01_minio实现与双实现纳管/04_首个能力与阶段验收_01_对象存储接入验证_01_minio实现与双实现纳管.md)。
- **不含**：MinIO 真实连通 E2E（随阶段八文件管理）；上传下载 / 分片状态机与安全控制（类型白名单 / 大小上限 / 配额联动，归文件管理阶段）。
- **依据**：[需求 04-1](../../../../需求/04_需求_首个能力与阶段验收.md#r04-1)、《架构设计 · 扩展点与插件化》「阶段三交付与验收（M3 口径）」节、《架构设计 · 文件管理》对象存储口径、《[01-2 详细设计](../../../01_插件化基座/01_插件化基座_02_配置分区与启动装配/设计/01_详细设计_01_配置分区与启动装配.md)》。

## 4. 设计 <a id="design"></a>

### 4.1 LocalObjectStorage（`app/storage/local.py`）

```python
class LocalObjectStorage(BaseObjectStorage):
    """本地文件系统对象存储：真实读写（零外部依赖），根目录经 options.root 配置。"""
    def __init__(self, *, root: str | Path = "var/storage") -> None: ...
```

| 方法 | 语义 |
| --- | --- |
| `put` | 键安全校验（拒绝绝对路径 / `..` / 空）→ 目录按需创建 → 临时文件 + `os.replace` **原子写** → `StoredObject(size / content_type / etag=sha256 前 16 位)` |
| `get` | 读取字节；未命中 → `NotFoundError`（与仓储 / 域口径一致） |
| `delete` | 幂等（未命中不抛） |
| `exists` | 文件存在判定 |
| `presign` | 返回 `file://` 绝对路径 URL（本地实现无远端直连；消费方仍走统一契约） |

- 阻塞 IO 统一 `asyncio.to_thread`（不阻塞事件循环）；`__init__` 不建目录（写入时按需创建，避免测试 / 只读场景副作用）。
- 根目录：`options.root` 缺省 `var/storage`（相对运行目录；仓库根 `var/` 已 gitignore），可经 `BMS_STORAGE__OPTIONS__ROOT` 覆盖。

### 4.2 工厂登记与缺省切换

- `register_platform_plugins` 增 `register_plugin("object_storage", "local", _local_storage_factory(settings))`（工厂内延迟导入 `app.storage.local`）；`minio` 工厂随 04-1-1。
- `config.toml [storage] provider = "local"`（缺省真实落盘）；`options` 保持非敏感（`root`）。
- **影响面适配**：`test_plugin_assembly` 默认装配断言改 `LocalObjectStorage`；`test_plugins` 缺省清单断言改 `provider=local`（实现清单：`local` active + `minio` / `null` registered）；显式 `provider=""` 的既有用例不受影响。

### 4.3 纳管路径（零套件改动）

| 通道 | 机制 |
| --- | --- |
| 契约套件（03-1） | 装配快照自动多出 `object_storage:local` / `minio` 条目——参数化遍历自动纳入（class 参数或 factory 只读分支） |
| 插件清单（01-3） | 注册表驱动，`/api/v1/plugins` 自动呈现双实现与状态（不含 `options` 密钥） |
| 消费方 | `get_object_storage` 继续薄封装 `resolve_plugin`，切换 provider 零改动 |

## 8. 边界与开放项 <a id="boundary"></a>

- 真实连通（MinIO 服务）E2E 随阶段八；本任务只证「实现就位 + 配置切换 + 纳管」。
- `local` 预签名返回 `file://`（后端不代理文件流的口径在文件管理阶段细化）。
- 上传下载状态机 / 安全控制（白名单 / 大小 / 配额）归文件管理阶段。
