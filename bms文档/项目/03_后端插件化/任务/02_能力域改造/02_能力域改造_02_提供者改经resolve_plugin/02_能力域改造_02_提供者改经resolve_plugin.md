## 2. 任务内容 <a id="content"></a>

1. 35 个 `get_xxx(request)` 改为薄封装：`return cast("BaseXxx", resolve_plugin(plugin_key, settings.<domain>.provider))`；请求期只取缓存实例（**不得**在请求内实例化 / 导入实现）
2. `settings` 各能力分区补齐（与域一 01_02 配置驱动装配配套）；未配置能力维持解析到 `null`
3. 调用面保持稳定：业务模块与既有测试不改调用签名；仅提供者内部解析路径变化
4. 解析路径唯一性核查：不再存在绕过注册表直连具体实现的路径（含既有 `config` 开关分支）

## 3. 完成标准 <a id="accept"></a>

切换 provider 后消费方零改动（测试或示例可证）；35 个提供者全部经 `resolve_plugin`；无绕过注册表的直连实现；全量 `pytest` / `ruff` / `pyright` 全绿。
