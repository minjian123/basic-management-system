## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    A[登记规则自身声明优先] --> B[BaseEventWorker 迁 events/base.py]
    B --> C[40 类换挂 BasePluggable + 三属性]
    C --> D[Kiwi 531 注册语义用例 + 验证]
    D --> E[基类清单 / 架构 04 回写]
```

结果小结：40 个直接 `BaseCapability` 子类全部换挂 `BasePluggable` 并显式声明 `plugin_key` / `plugin_name` / `contract_version`；`BaseEventWorker` 自 `core/capability.py` 迁至 `events/base.py`（解循环导入，事件发布 / 消费继承不变）；登记名规则改「自身声明优先」；36 个端口的 `NullXxx` 登记为 `null`，4 个无缺省实现端口（`audit` / `cache` / `task` / `event`）不登记；应用行为不变，全量 `pytest` / `ruff` / `pyright` 全绿。

## 3. 实施过程 <a id="process"></a>

1. **登记规则**：`core/plugin.py` `_registration_name` 改「类自身声明优先」——端口声明的 `plugin_name="null"` 作为契约文档值不被具体子类继承生效，`HealthCheckRegistry` 等无名具体子类维持不登记。
2. **事件基座迁移**：`BaseEventWorker(BasePluggable)` 落 `app/events/base.py`（三属性 + 抽象 `event_type`）；`core/capability.py` 删除该类；`tests/core/test_capability.py` 导入来源调整。
3. **40 类换挂**：AST codemod 精准定位 39 个文件中的目标类（`BaseCapability` → `BasePluggable`，`key` 赋值后插入三属性）；`BaseEventWorker` 手工处理；`uv run ruff check --fix` 自动清理未用导入并排序（74 项）、`ruff format` 归一。
4. **测试**：Kiwi 先登记（**531**，平台自增顺延），新增 `backend/tests/crosscut/test_plugin_registration.py`（7 条用例）：40 端口清单一致 / Null 缺省登记 / 抽象与无名不登记 / 继承申明不生效 / 事件基座落点与抽象 / 应用可启动。
5. **验证**：命令与结果见[测试记录](../测试/01_测试_01_能力域基类改继承.md)；`app/core/plugin.py` 覆盖率 100%。
6. **登记回写**：《后端基类清单》（分层表 / `BaseEventWorker` 代码位置 / 继承链 / 候选状态）、《架构设计 · 后端基础类体系》（中间层表 / 演进注记 / 候选表状态）。

关键命令：

```bash
uv run pytest tests/crosscut/test_plugin_registration.py -q
uv run pytest --cov=app --cov-branch --cov-report=term-missing -q
uv run ruff check .
uv run ruff format --check .
uv run pyright
```

## 4. 问题与处置 <a id="issues"></a>

| 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- |
| `BaseEventWorker`（`core/capability.py`）换挂会循环导入 | `plugin.py` 依赖 `capability.py`，反向导入成环 | 经确认迁至 `app/events/base.py`（单向依赖）；基类清单 / 架构 04 代码位置同步 |
| 端口声明 `plugin_name="null"` 会被具体子类继承而误登记 | 原规则按继承值判定 | 登记规则改「自身声明优先」并同步 01-1 详细设计 §5.1 口径注记；新增用例覆盖「继承申明不生效」 |
| 设计预期「每个端口均有 `NullXxx`」与实际不符 | 实测 `audit` / `cache` / `task` / `event` 四个端口无缺省实现 | **回写设计**（§4 注记 / §7 测试口径）后调整用例期望；四端口登记随对应阶段补实现 |
| codemod 后 74 项 lint（未用导入 / 排序） | 换挂后 `BaseCapability` 导入失效 | `ruff check --fix` + `ruff format` 收敛（零残留） |

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：4 个端口（`audit` / `cache` / `task` / `event`）暂无 `NullXxx` 缺省实现，不登记 `null`（设计已回写）。
