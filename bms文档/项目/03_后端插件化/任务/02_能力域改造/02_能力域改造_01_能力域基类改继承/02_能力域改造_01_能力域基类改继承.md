## 2. 任务内容 <a id="content"></a>

1. 40 个能力域基类 `BaseXxx(BaseCapability, ABC)` 改为继承 `BasePluggable`（**业务方法签名不变**，仅替换继承与补字段；以基类清单与实测清单为准，无遗漏、无多余）
2. 各基类补类属性：`plugin_key`（与能力 `key` 一致）、`plugin_name`（平台内建默认实现名；缺省实现由 `Null` 规则登记 `null`）、`contract_version`（自 `0.1.0` 起）
3. 继承链核对：`BasePluggable → BaseCapability → BaseAsyncResource → BaseObject`；抽象端口不因「可实例化判定」误登记（与域一 01-1 构建规则配套）
4. Null 缺省实现自动登记为 `null`；实工具类（如 `HealthCheckRegistry` 等无名非 Null）维持不登记
5. 登记回写：架构 04「基类候选」、基类清单「能力域基类清单」与「继承链」、相关设计文档同步

## 3. 完成标准 <a id="accept"></a>

40 个基类继承链一致且业务方法未变；抽象端口不误登记、`Null` 缺省实现登记为 `null`；应用可正常启动（装配接线前行为不变）；全量 `pytest` / `ruff` / `pyright` 全绿；架构 04 与基类清单登记同步。
