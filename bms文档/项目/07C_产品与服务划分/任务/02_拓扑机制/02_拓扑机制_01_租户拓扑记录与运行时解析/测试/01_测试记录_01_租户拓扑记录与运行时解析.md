## 2. 用例与断言 <a id="cases"></a>

| # | 用例 | 断言 | 结果 |
| --- | --- | --- | --- |
| 1 | 默认拓扑整批写入 | 启动后默认拓扑行集 = 已登记域集、版本 1、单元 = 该域承载服务键 | 通过 |
| 2 | 租户拓扑覆盖默认 | 租户有自己的版本时按租户解析，且不逐域合并默认 | 通过 |
| 3 | 租户无记录 | 解析与导出均回退默认拓扑 | 通过 |
| 4 | 默认拓扑缺域 | 写入默认拓扑缺域即拒并列出缺失域（10001） | 通过 |
| 5 | 域未登记 | 拒绝整批写入并列出未登记域（10001） | 通过 |
| 6 | 同域重复 | 拒绝并指出重复域（10003） | 通过 |
| 7 | 空单元 | 空拓扑被拒（10001，每单元至少承载一域） | 通过 |
| 8 | 单元命名非法 | `Core_1` 等命名被拒（10001） | 通过 |
| 9 | 版本回退 | 同版本重写被拒（10003） | 通过 |
| 10 | 整批替换后解析 | 只看到新版本；旧行软删除（库内计数 1 行） | 通过 |
| 11 | 域 `status=disabled` | 解析抛 `CatalogError`，`data.reason=not_enabled` | 通过 |
| 12 | 缓存与版本 | 同租户新版本登记后解析立即返回新结果 | 通过 |
| 13 | 库派生 | `db_keys` 为 `platform_{unit}`，基址按单元派生 | 通过 |
| 14 | 协议替换 | 登记后 `resolve_topology()` 为 `TenantTopologyResolver`；未登记仍为 07B 过渡实现 | 通过 |
| 15 | 模板展开 | 三档展开符合预期（只展开已登记域；独立型 `dom-*` 下划线转连字符） | 通过 |
| 16 | 只读端点 | 分页（含按租户 / 域 / 单元筛选与不带筛选全量）+ 按租户导出 + 导出回退 | 通过 |

**补齐与释放**（同属 Kiwi 2366）：默认拓扑缺已登记域时按「域 → 承载服务键」补行并写下一版本（类级替身校验补齐行集合，不改会话级默认拓扑）；应用关闭后解析器与快照复位（随即由注册通道 / 启动钩子重新登记）。

**补充反例**（同属 Kiwi 2366）：`rows` 与 `template` 都给 / 都不给 / 未知模板 / 状态非法 / 导出默认拓扑缺失（10002）/ 装配失败包装为 `CatalogError` / 装配期 `CatalogError` 原样上抛 / 域登记为空拒自举 / 既有版本但读不到行不伪造快照 / 快照超容量淘汰最早 / 上下文非法回落默认 / 过渡实现域未登记承载服务。

与[实施记录 §6](../实施/01_实施记录_01_租户拓扑记录与运行时解析.md#leftover)一致（跨进程分发归 `02_02`、租户库键由调用方派生、`grouped` 待 `biz` 域登记、迁移归 `04_02`、编排归 `04_01`、ops 仅平台镜像、单元可见性归 `04_03`）。
