## 2. 任务内容 <a id="content"></a>

1. **拓扑记录**：每租户一份「域 → 部署单元 → 库」映射，作为平台侧运营数据（可审计、可查全貌）。
2. **生效方式**：发布时生效（改拓扑 = 一次发布动作），不允许运行期随意漂移。
3. **解析入口**：提供运行期拓扑解析（给定域 → 当前租户的部署单元与库），供能力寻址、部署编排、运维排查共用。
4. **模板**：允许以模板预置常见组合（小 / 中 / 大 / 特定行业），单租户可在此基础上调整。
5. **校验**：拓扑引用的域与部署单元必须已登记；同一域在租户内只能映射到一个部署单元（禁止长期双活）。

## 3. 完成标准 <a id="accept"></a>

拓扑记录可登记、查询、变更（变更留审计）；运行期解析对「域 → 部署单元 → 库」给出唯一结果；引用未登记域 / 部署单元时拒绝；同域双映射被拒；模板可用且不改变语义。
