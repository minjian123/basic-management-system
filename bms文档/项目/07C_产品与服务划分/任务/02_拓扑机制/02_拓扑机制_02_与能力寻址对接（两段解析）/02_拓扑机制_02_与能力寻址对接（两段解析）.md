## 2. 任务内容 <a id="content"></a>

1. **第一段**：能力 → 域（能力绑域，稳定；见跨产品协同节点）。
2. **第二段**：域 → 部署单元与库（按当前租户拓扑解析）。
3. **寻址结果**：消费方拿到的是「当前租户下该能力的实际访问位置」，不感知服务标识。
4. **失败语义**：第一段缺失即拒启（沿用协同节点口径）；第二段缺失（拓扑未配置）在启动期拒启、运行期报明确错误，不得回落默认服务。

## 3. 完成标准 <a id="accept"></a>

消费方按两段解析取址，代码中无服务标识与路径字面量；同一能力在两种拓扑下均可正确取址（夹具验证：合并部署与拆分部署各一组）；拓扑缺失时启动拒启、运行期明确报错。
