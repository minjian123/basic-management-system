## 4. 存量失败与修复（原与本任务无关） <a id="preexisting"></a>

`services/identity/tests/oidc/test_clients.py::test_create_scope_outside_registry_rejected`：用例期望 `mdm:read` 属已登记 scope，但 `bms_core/oauth/scopes.py::OPEN_SCOPES` 是**导入期**常量（仅含 `biz` / `cw` 静态产品）；`mdm` 产品档案由 `config.dev.toml` 的 `product_manifests` 在**应用装配期**注册，晚于常量构建。

- **复现**：在 HEAD 干净工作树（临时 git worktree）执行同一用例 → 同样失败；
- **结论**：存量缺陷（产品清单化改造后未同步 OAuth scope 校验口径），与本次分包无因果；
- **修复（经确认随本任务）**：`known_scopes(None)` / `open_scopes(None)` 改取运行期合并视图 `product_catalog_view()`（`OPEN_SCOPES` 保留为静态基线）；
- **回归用例**：`libs/bms_core/tests/oauth/test_scopes.py::test_runtime_registered_product_scopes_are_validated`（注册探针产品 → scope 可校验 → 复位后消失）；
- **结果**：该用例与全量 pytest 转绿（**3419 passed / 57 skipped**）。
