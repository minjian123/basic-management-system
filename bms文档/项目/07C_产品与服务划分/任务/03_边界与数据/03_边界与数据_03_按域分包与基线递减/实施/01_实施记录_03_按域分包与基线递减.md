### 2.3 域公共出口与装配面 <a id="public"></a>

- **`public.py`（16 个）**：`auth` / `user` / `role` / `menu_form` / `permission_meta` 导出实际被跨域使用的模型、仓储、服务与工厂；其余 11 域为空占位（`__all__` 显式为空，形态一致）。`public_api` 字段登记为 `bms_<服务>.domains.<域>.public`。
- **`wiring.py`（platform）**：`build_menu_service` / `build_permission_service` 两个构造入口，把「菜单表单 ← 权限元数据读取器」「权限元数据 ← 按钮 / 表单 / 角色探测」的跨域依赖在装配面注入。依赖方向固定为「装配 → 域」，域实现之间只经 `public`。
- **共享横切助手（平台侧）**：`services/i18n_text.py`（多语言入参 / 出参口径）、`services/metadata_cache.py`（菜单 + 权限双版本失效与进程内索引清理）、`api/locale.py`（请求语言解析与作用域依赖）——三者均不含表结构与业务规则，登记 `shared_paths`。

### 2.5 模型按域与清单收紧 <a id="modules"></a>

| 项 | 实现 |
| --- | --- |
| `BASE_MODEL_MODULES`（新增） | `("bms_core.models.outbox",)`——基础设施模型（每库一份） |
| `domain_model_modules(domain)` | 有布局：从布局 paths 派生「声明了 `__tablename__` 的模块」（进程内缓存）；无布局：`COMMON_MODEL_MODULES + service_model_modules(承载服务)` 安全回退（容器内未携带 `deploy/` 时建表集不变） |
| `import_models(domain)` | `BASE + 逐域模型`（不再全量拼公共清单） |
| `import_service_models(service)` | `BASE + 该服务承载域模型并集`（无布局回退全量 + 服务自声明模型） |
| `all_model_modules()`（新增） | 全量模型模块（`check_tables` 声明集与导入面同源） |
| 服务模型清单 | `bms_ai` / `bms_notification` / `bms_txn` 的 `models::MODEL_MODULES` 改指域内模块（无布局回退仍可取到本服务模型）；`bms_core.models.platform::MODEL_MODULES` 更新为 8 个逐域模块 |

**建表集不变**：新增 `test_unit_metadata_equals_registry_derivation`（逐单元逐数据源严格相等）与 `test_domain_model_modules_cover_domain_tables`（逐域模型表集 ⊇ 登记表集，多出的只允许 `planned` 表）兜住。

### 2.6 布局与护栏 <a id="guard"></a>

| 项 | 实现 |
| --- | --- |

| `_subpackage` | 跳过 `domains/<域>` 段取层名——域内 `api → services → repositories` 方向继续生效 |
