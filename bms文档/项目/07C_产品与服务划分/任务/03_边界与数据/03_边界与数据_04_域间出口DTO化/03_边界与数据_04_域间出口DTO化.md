## 2. 任务内容 <a id="content"></a>

1. **口径成文**：定义「域公共出口可导出什么」——只导出基座不可变对象（`BaseValueObject` 派生的 DTO）与领域服务接口；禁止导出 `MODEL_MODULES` 内的 ORM 类、仓储类、可变服务对象。
2. **契约对齐**：出口 DTO 与能力契约的响应模型字段一致；消费方按字段取值，不遍历模型关系、不依赖懒加载（懒加载跨域即隐式读表）。
3. **机器护栏**：静态断言 `public.py` 的导出面不含 ORM 模型 / 仓储（`__all__` + AST 双重判定），例外白名单（附理由与归口）与递减基线，条目只减不增；并入 `check_service_boundaries` 的域级断言。
4. **试点迁移**：先迁**低消费试点域**（消费方最少的域，验证口径与护栏），再迁**高消费域**（组织 `/` 角色相关出口，覆盖用户 / 角色编排与权限解析三类真实消费点）；每步行为等价（现有用例零改动回归）。
5. **迁移台账**：登记「已迁 / 待迁」业务域清单，剩余域的迁移在计划表「偏差与遗留」列跟踪，不一次性铺开。

## 3. 完成标准 <a id="accept"></a>

- 出口护栏可机器判定：正例（导出 DTO）通过、反例（导出 ORM / 仓储）失败，两条用例齐备且并入域级断言；
- 试点域 + 一个高消费域的 `public.py` 完成 DTO 化，护栏对这两个域零命中；
- 出口对象为冻结对象（改动即抛 `FrozenInstanceError` 类错误），用例断言；
- 出口 DTO 字段与能力契约响应模型一致（对账用例，字段集合逐一比对）；
- 两域消费方无 ORM 依赖（跨域编排只持 DTO 与领域服务接口）；现有回归用例零改动通过；
- 已迁 / 待迁清单登记，剩余域在计划偏差列有归口。
