## 2. 任务内容 <a id="content"></a>

1. **库名派生**：库名由部署单元标识派生，不由业务域派生。
2. **表归属按业务域**：表前缀体现业务域；拓扑变更不改变表名。
3. **变更序列按业务域**：每个业务域一条独立链（业务域内线性、业务域间独立），部署单元运行时执行所含业务域的各链；任一拓扑下库结构 = 所含业务域各链的并集，**拆 / 合不切迁移历史**。
4. **校验**：表归属登记 ↔ 模型 ↔ 变更序列三处一致，由既有校验脚本承接（不新增并行入口）。

## 3. 完成标准 <a id="accept"></a>

同一套业务域在「合并」与「拆分」两种拓扑下均可完成建表与迁移，结果一致；表名不随拓扑变化；变更序列按业务域的口径有文档与用例（含拆 / 合两种拓扑下链集一致）；三处一致性校验通过。
