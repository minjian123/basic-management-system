## 2. 后端基座目标与范围 <a id="goal"></a>

**M2 目标**（《总体项目规划》「里程碑」节 M2 行）：`BizError` 与统一响应生效、`BaseModel` 落库、三库拓扑可路由、租户隔离与批量迁移正确、模块注册校验生效、跨阶段基座登记齐备。周期口径 4 周（兼职）。

**范围内**（共 16 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 一 基座与异常体系 | 异常体系 `BizError` + 统一响应 `ApiResponse`；core 基座补齐（配置 / 安全基座）与已交付基座登记 |
| 二 数据访问底座 | 引擎 / 会话工厂 / 四库方言 / 基类异步切换 / 读写分离占位 |
| 三 多租户数据拓扑 | 三库拓扑与建库、模型基类 `BaseModel` 与表规范、平台库基础表、租户解析中间件、引擎注册表与池管理、批量迁移与租户库初始化 |
| 四 模块注册表 | sys_module 表与种子、注册唯一性校验、模块查询接口 |
| 五 CI 与阶段验收 | 三库集成测试与流水线收口、M2 验收门禁核对、测试报告与 README |
| 六 跨阶段基座 | 缓存 Region 分域 / 数据范围注入 / 分片路由 / 事件发布消费 / 任务基座 / 审计捕获基座（登记 + 按阶段回补） |

**范围外**：

- 认证与会话安全基座的具体实现（阶段四 认证与安全）；RBAC 数据范围**规则**（阶段五）；缓存三防与性能加固（阶段十二）；真实分片规则落地（阶段十一）；事件总线与任务调度**业务实现**（阶段六 / 八）。
- 前端组件库（阶段三）与前端页面（阶段十三）。
- 业务模块（biz / cw）由产品仓库承载。

> 边界说明：阶段一已交付的基座为**同步实现**，本阶段「02 数据访问底座」在基类统一切换异步（调用面改动集中一次）；达梦同步驱动例外口径按《后端开发规范》「异步与并发」节执行。

## 4. M2 验收门禁 <a id="accept"></a>

门禁定义（《总体项目规划》「里程碑」节 M2 行）：**`BizError` 与统一响应生效、`BaseModel` 落库、三库拓扑可路由、租户隔离与批量迁移正确、模块注册校验生效、跨阶段基座登记齐备**。逐项核对：

| 验收点 | 核对方式 | 对应需求 | 结论 |
| --- | --- | --- | --- |
| 异常体系生效 | `BizError` 抛错经全局处理器转统一响应 `{code, message, data}`；`NotFoundError` 过渡实现被替换 | 01-1 | 待阶段完成核对 |
| BaseModel 落库 | 雪花 ID / 软删除 / 审计字段 / 乐观锁 / 四库类型映射生效；三库迁移可执行 | 03-2 | 待阶段完成核对 |
| 三库拓扑可路由 | MySQL/PostgreSQL/达梦 DM8 驱动连通与迁移通过；租户请求路由到对应租户库 | 02-1、03-1、03-5、03-6 | 待阶段完成核对 |
| 租户隔离与批量迁移正确 | 跨租户访问被拒；租户库批量迁移演练通过 | 03-4、03-6 | 待阶段完成核对 |
| 模块注册校验生效 | 表前缀/错误码段/事件域冲突种子被启动与 CI 拒绝；GET /api/v1/modules 返回注册清单 | 04-1、04-2、04-3 | 待阶段完成核对 |
| 跨阶段基座登记齐备 | 缓存/数据范围/分片/事件/任务/审计基座的登记与回补窗口写入计划 | 06-1 | 待阶段完成核对 |

**结论**：承接原阶段一 M1 缺失的两项（三库拓扑、模块注册校验）；阶段二 16 条需求在本阶段内闭环（跨阶段基座为登记 + 按对应阶段回补）。
