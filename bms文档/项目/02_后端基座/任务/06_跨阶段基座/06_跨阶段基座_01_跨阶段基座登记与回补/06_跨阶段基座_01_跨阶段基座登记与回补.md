## 2. 任务内容 <a id="content"></a>

1. **缓存 Region 分域基座**：dogpile.cache Region 分域管理 + 全局版本号惰性比对；key 规范 `bms:{租户|global}:{域}:{业务键}`、全 key 带 TTL；三防（穿透空值 / 击穿互斥锁 / 雪崩随机偏移）在基座统一（回补阶段六）。
2. **数据范围注入基座**：`BaseRepository` 的数据访问范围注入钩子（写读双向校验），规则由 RBAC 提供（回补阶段五）。
3. **分片路由基座**：`ShardingRouter` 抽象（分片键 → 物理库/表解析），MVP 按月分表（回补阶段十一）。
4. **事件发布 / 消费基座**：统一事件发布接口（RocketMQ 事务消息）与消费基类（分区有序消费），业务模块不直接调用通知/审计（回补阶段八）。
5. **Celery 任务基座**：任务定义入库（sys_task）+ 自研 beat 调度基类 + 执行记录（sys_task_log）（回补阶段六）。
6. **ORM 审计捕获基座**：ORM 事件自动捕获关键表字段级变更，审计事件走分区有序消费（哈希链）（回补阶段六）。
7. 登记：六类基座的职责、契约与回补阶段写入《[架构设计 · 后端基础类体系](../../../../../设计/架构设计/33_架构设计_后端基础类体系.md)》与阶段二计划表；对应阶段实施时在**该阶段计划**登记窗口（同一任务文档，不重复建任务）。

## 3. 完成标准 <a id="accept"></a>

六类跨阶段基座的职责与契约在架构节点登记；回补阶段与窗口写入阶段二计划表；本阶段可独立实现的封装骨架（接口与契约层）就位；对应阶段启动时按登记实施并回写状态；无遗漏、无重复实现。
