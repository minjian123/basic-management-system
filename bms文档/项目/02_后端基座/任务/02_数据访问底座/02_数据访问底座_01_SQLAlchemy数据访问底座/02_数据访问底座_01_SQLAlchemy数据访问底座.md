## 2. 任务内容 <a id="content"></a>

1. 异步引擎工厂：按数据源创建/缓存 `AsyncEngine`（连接池参数、超时、`pool_pre_ping`）；多数据源经多 engine 管理，总连接数 ≤ 数据库 `max_connections` 的 70%。
2. AsyncSession 工厂：`async_sessionmaker` + 请求级会话（依赖注入），事务边界显式（`with session.begin()`）；禁止异步会话跨请求共享、避免 N+1、大事务显式声明边界。
3. 四库方言适配：MySQL（aiomysql）、PostgreSQL（psycopg 3）、达梦 DM8（dmPython 同步驱动，经 `asyncio.to_thread` 封装例外口径）、SQLite（aiosqlite）；Alembic URL 从 config.toml 读取。
4. **基类异步切换**：`BaseRepository[T]` 数据库实现覆写原子方法为异步、`exists`/`count` 派生方法沿用；`BaseService[T]` 异步化；分页与软删除过滤等通用能力**回填基类**（只加基类，模块类不改）；阶段一同步内存基线保留为测试替身。
5. 读写分离占位：读写路由接口（按上下文标记选引擎），本阶段主从同源；写操作与事务强制走主库。
6. 测试：先登记 Kiwi 用例；单元用 SQLite，集成连三库（随 05-1）；`ruff`、`pyright` 全绿。
