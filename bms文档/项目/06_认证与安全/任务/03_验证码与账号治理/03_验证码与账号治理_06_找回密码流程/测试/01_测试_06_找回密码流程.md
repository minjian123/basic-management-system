**范围**：org 标识解析（账号 / 手机 / 邮箱三形态、邮箱大小写不敏感、通道优先级、可送达判定）；发起找回成功链路（验证码 → org 解析 → token 落 `pwdreset` 命名空间 → 通知占位发送 → 恒 `{sent:true}`）；防枚举；限流（账号 / IP 维度，20006）；重置（单次 `GETDEL` 消费、过期 / 无效 / 脏载荷 20005、策略闸门 30005 / 30006）；重置后全部会话失效（`revoked_at` 落库 + 标记删除 + 广播）与原 access 下一请求 401；fail-closed（存储 / 通知 / org 不可用 10007）。不含：真实通知渠道（阶段八）、前端页面（阶段十五）、`email` / `phone` 维护入口（阶段七）。
