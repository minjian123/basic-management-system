- **覆盖范围**：阶段六需求域 03 的 7 条需求——[03-1 图形验证码真实实现](../../需求/03_需求_验证码与账号治理.md#r03-1)、[03-2 滑块挑战真实实现](../../需求/03_需求_验证码与账号治理.md#r03-2)、[03-3 短信验证码真实实现](../../需求/03_需求_验证码与账号治理.md#r03-3)、[03-4 场景策略与失败计数](../../需求/03_需求_验证码与账号治理.md#r03-4)、[03-5 密码策略真实实现](../../需求/03_需求_验证码与账号治理.md#r03-5)、[03-6 找回密码流程](../../需求/03_需求_验证码与账号治理.md#r03-6)、[03-7 账号锁定与解锁管理](../../需求/03_需求_验证码与账号治理.md#r03-7)，按「1 需求 = 1 子任务」拆 7 个子任务（`03_01` ~ `03_07`）。
- **端范围**：**后端为主**（identity 服务 + org 服务锁定字段 + 通知 / 限流 / 脱敏基座消费）；前端验证码字段联调归 `03_04`（含滑块 `payload` 新形态渲染调整）。
- **承接口径**：`BaseCaptcha` 三形态契约与场景五项 / 策略契约 / 一次性凭证 / 占位路由（阶段二 `02-3-14` 已交付）、`BasePasswordPolicy` 占位（`02-3-07`）、`BaseNotifier` 与限流基座（阶段二已交付占位）；本域**只做真实实现与接线**，不新建契约、不另起编号空间。
- **已定口径**（2026-09-26 拍板）：滑块服务端合成出图、不下发缺口坐标；Redis 不可用验证码 fail-closed；登录日志本期不落表（失败计数 Redis + `sys_account_lock`）；锁定后端全做、页面归阶段七；找回密码 token 流程 + 通道占位；180 天扫描落服务方法 + 手动触发（Celery 归阶段八）。
- **依据**：《[架构设计 · 认证与会话](../../../../设计/架构设计/14_架构设计_子系统_认证与会话.md)》§5、《[概要设计 · 用户管理](../../../../设计/概要设计/03_概要设计_用户管理.md)》、《[后端基类清单](../../../../后端基类清单.md)》「验证码渠道」「密码策略」条目、需求 `02-31` / `02-42` 实现期要点。
- **执行序**：`03_01 图形码` → `03_02 滑块` → `03_03 短信` → `03_04 场景策略与失败计数联调` → `03_05 密码策略` → `03_07 账号锁定` → `03_06 找回密码`（见[计划](../../计划/01_计划_认证与安全.md)）。
