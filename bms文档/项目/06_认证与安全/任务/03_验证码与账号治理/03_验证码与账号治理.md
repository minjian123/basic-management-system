- **工时合计**：90h（01 8h + 02 10h + 03 8h + 04 16h + 05 10h + 06 10h + 07 12h + 08 16h）。
- **关键依赖**：`03_08` 依赖阶段二 `02-4-27`（字典基座范式）；`03_04` 依赖 `03_01` / `03_02` / `03_03` 与 `03_08`（按租户策略读取）及域一 `01_03`（失败计数接线）；`03_05` 依赖 `01_03`（改密 / 登录路径）、`01_01`（PBKDF2）与 `03_08`（密码策略键）；`03_06` 依赖 `03_04` / `03_05` / `01_04`（重置失效会话）；`03_07` 依赖 `01_03`（登录失败联动）与 org 内部接口。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_认证与安全.md)（本节不写排期）。
- **风险**：Pillow 出图在事件循环的阻塞（须线程池）；滑块轨迹判定阈值过严 / 过松（须真机调试取样）；`sys_config` 读取高频（须缓存与失效口径）；跨服务读 `sys_config` 的降级语义（platform 不可达时回落平台默认）；失败计数与锁定阈值口径须与限流基座一致（避免双重惩罚）。
