## 2. 任务内容 <a id="content"></a>

1. **场景策略**：五场景（登录 / 找回密码 / 绑定手机 / 解绑手机 / 注册）策略从 `sys_config` 按租户读取、缺省回落平台默认表；读取带缓存与失效（策略变更即时生效）。
2. **失败计数与强制**：登录失败计数落 Redis（窗口 TTL），连续失败达阈值（默认 3）后登录强制要求验证码；成功登录清零；与账号锁定（`03_07`）阈值联动、避免双重惩罚。
3. **策略端点**：`/captcha/scenes/{scene}/policy` 按当前租户返回策略；渠道不可用（如短信未配）的降级顺序成文（图形码兜底）。
4. **前端联调**：阶段四 `06_04` 验证码字段对接真实四端点（替换占位数据源）、滑块新 `payload` 形态落地、核对页与错误码 `201xx` 文案更新。
5. **用例**：策略按租户 / 缺省回落 / 变更即时生效；连续失败强制；失败窗口与清零；前端图形 / 滑块 / 短信各一次端到端。

## 3. 完成标准 <a id="accept"></a>

策略按租户读取、缺省回落、变更即时生效；连续失败 3 次后登录强制验证码（窗口与清零用例覆盖）；前端四端点真实联通、滑块新 `payload` 渲染正确；错误码文案与前端契约一致；`pytest` / Vitest / `vue-tsc` 相关门禁全绿。
