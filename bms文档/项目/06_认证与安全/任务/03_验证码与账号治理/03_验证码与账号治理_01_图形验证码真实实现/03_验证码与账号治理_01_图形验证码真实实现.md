## 2. 任务内容 <a id="content"></a>

1. **真实出题**：Pillow 生成图形码（干扰线 / 噪点 / 字符变形等基础抗识别处理），经线程池执行避免阻塞事件循环；图片 base64 返回（沿用四端点冻结形态，不扩字段）。
2. **一次性校验**：挑战存 Redis `bms:global:captcha:{uuid}`（TTL 5 分钟）；`verify` 大小写不敏感比对，成功后立即删除（单次有效），失败计数。
3. **接口兼容**：`/api/v1/captcha/challenges` / `verify` 响应字段与错误码子段 `20101` ~ `20103` 保持契约；图像形态若后续改直连取图按「只增字段」扩展（本期不做）。
4. **降级口径**：Redis 不可用时出题 / 校验 fail-closed（明确报错，不放行）。
5. **实现登记**：`BaseCaptcha` 真实实现部分交付状态在《[后端基类清单](../../../../../后端基类清单.md)》更新。

## 3. 完成标准 <a id="accept"></a>

出图非空且可人工识别；正确码校验通过且挑战单次失效（二次使用被拒）；错误码 `20101` 子段生效并计数；Redis 不可用 fail-closed 用例通过；Pillow 出图与 Redis 存取集成用例（真 Redis）全绿。
