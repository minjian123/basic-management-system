## 2. 任务内容 <a id="content"></a>

1. **下发与校验**：生成短验证码存 Redis（TTL 300s），经 `BaseNotifier` 发送（本期占位不真发，接口契约不变）；校验一次性、失败计数。
2. **脱敏回显**：响应目标手机号一律脱敏（改经域 04 脱敏基座）；不回显验证码本身。
3. **冷却与频次**：重发冷却 60s、按账号 / IP 维度限次（经限流基座 Redis 计数）；冷却期内重复请求明确提示且不重置倒计时。
4. **降级口径**：Redis 不可用 fail-closed；通知渠道不可用时明确报错（不静默放行）。
5. **对接口径**：短信模板与真实渠道实现归阶段八（通知公告），本期接口与错误子段 `20103` 定稿并与前端短信件契约对齐。

## 3. 完成标准 <a id="accept"></a>

短信出题落 Redis、校验一次性；目标脱敏、冷却与限次生效（含「限流命中不重置倒计时」用例）；通知基座占位下流程跑通且契约与阶段八对齐；错误子段 `20103` 生效；`pytest`、`pyright`、`ruff` 通过。
