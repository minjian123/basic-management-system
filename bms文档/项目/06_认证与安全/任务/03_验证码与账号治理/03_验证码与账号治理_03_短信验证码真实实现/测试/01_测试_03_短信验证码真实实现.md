## 2. 测试范围与用例 <a id="scope"></a>

**范围**：`bms_core/captcha/default.py` 短信真实实现（生成 / 通知下发 / 一次性校验与失败计数 / 冷却不重置 / 账号·IP 限次 / 脱敏回显 / Redis 与渠道不可用 fail-closed / 选项 / 提供者装配）与真 Redis 集成。不含：脱敏回接 `BaseMasker`（04_02）、前端短信件联调与策略按租户读取（03_04）、短信模板 / 真实渠道（阶段八）；图形 / 滑块既有用例（Kiwi 2204 / 2205）沿用、仅适配「短信未启用」一条。

| # | 自动化文件 | 用例（Kiwi 2206 覆盖清单） | 断言要点 |
| --- | --- | --- | --- |
| 1 | `tests/captcha/test_captcha_sms.py` | 生成与数据契约 | `kind=sms` / `image=b""` / `payload==""` / `expires_in=300` / `cooldown=60` / `target=138****5678`；响应不含验证码；Redis 记录 `kind=sms` / `scene` / `fails=0` / `code` 为 6 位数字 |
| 2 | 同上 | 通知下发（占位） | 通知器收到 `channel=sms` / `recipient=原手机号` / `content` 含验证码与「5 分钟」/ 标题空 / `biz_type=captcha` |
| 3 | 同上 | 校验一次性 | 正确码 True；二次 False / `require_credential` 抛 20102（404） |
| 4 | 同上 | 失败计数与可重试 | 错误码 → 20101；`fails=1`、TTL > 0；随后正确码仍通过 |
| 5 | 同上 | 冷却不重置 | 冷却期内二次发送 → 20103（429）；`data.reset_after` 不回退 |
| 6 | 同上 | 账号频次 | `account_limit=2` 下第三次（换场景绕过冷却）→ 20103 |
| 7 | 同上 | IP 频次 / IP 缺失 | 注入 `current_client_ip`，`ip_limit=2` 下第三次 → 20103；IP 缺失跳过该维 |
| 8 | 同上 | Redis 不可用 fail-closed | 写入抛错 → 10007 / 503 |
| 9 | 同上 | 渠道不可用不放行 | `delivered=False` / 发送抛异常 → 10007 / 503，且已写入挑战被删除 |
| 10 | 同上 | 发送失败清理降级 | `delete` 抛错仅日志、仍抛 10007 / 503 |
| 11 | 同上 | `generate(kind=sms)` 拒绝 | → `ParamError`（10001）；枚举外取值同判参数错误 |
| 12 | 同上 | 选项解析与校验 | 缺省 / 覆盖生效；非整数 / 越界 `PluginError` |
| 13 | 同上 | 提供者装配 | 工厂注入通知器 / 限流器 / 短信选项；默认配置解析 `DefaultCaptcha`；provider 空回落 `NullCaptcha` |
| 14 | `tests/integration/test_captcha_integration.py` | 真 Redis / 真限流往返（integration 标记） | 发送 → 正确码通过 → 单次失效被拒；二次发送冷却命中 20103（并清理限流键） |
