## 2. 任务内容 <a id="content"></a>

1. **复杂度校验**：长度 / 大小写 / 数字 / 符号 / 不得含用户名，规则从 `sys_config` 读取，返回缺失项清单（`PASSWORD_VIOLATIONS`）；前端强度提示只展示等级与缺失项、不回显密码。
2. **有效期与历史**：`pwd_changed_at` 驱动 90 天强制改密判定（置 `pwd_reset_required`）；`pwd_history` 近 5 次历史 PBKDF2 比对不可重复。
3. **180 天不活跃**：按 `last_login_at` 扫描的服务方法 + 手动触发入口（Celery 定时任务归阶段八），命中写 `sys_account_lock`（`inactive` 型）。
4. **接线**：改密 / 重置路径（`03_06` 与 org 内部接口）强制过策略；登录成功后按判定置 `pwd_reset_required`。
5. **口径回写**：《[后端基类清单](../../../../../后端基类清单.md)》「密码策略」条目状态更新；`sys_config` 键位与《[概要设计 · 系统参数](../../../../../设计/概要设计/10_概要设计_系统参数.md)》一致。
6. **用例**：四规则正反用例、`sys_config` 变更即时生效、历史追加与比对。

## 3. 完成标准 <a id="accept"></a>

复杂度 / 90 天 / 近 5 次历史 / 180 天扫描四规则正反用例全绿；改密与重置路径强制过策略；`sys_config` 变更即时生效；`pwd_history` 追加与比对正确；`pytest`、`pyright`、`ruff` 通过。
