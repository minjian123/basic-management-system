## 2. 任务内容 <a id="content"></a>

1. **锁定记录**：复用 `03_05` 已落库的 `sys_account_lock`（`lock_type`：`fail_limit` / `inactive` / `manual`；原因 / 时间 / 操作人 / 解锁时间），补 `fail_limit` / `manual` 两型与解锁字段写入口径，与用户状态字段一致（org 服务库）。
2. **自动锁定**：登录失败达阈值触发 `fail_limit`（与限流窗口口径协同）；180 天未登录扫描触发 `inactive`（服务方法 + 手动触发，`03_05` 交付）。
3. **手动解锁**：解锁接口（`user:unlock` 权限码占位，RBAC 前平台超管口径）+ 锁定列表 / 详情接口；解锁恢复账号状态并留痕（结构化日志 + 操作日志占位）。
4. **登录联动**：被锁账号登录被拒（`20004` / `20005` 语义）；锁定期满自动解锁或保持直到手动解锁的口径成文并与概要一致。
5. **页面归口**：锁定列表 / 解锁页面随阶段七用户管理（本期只交接口与 E2E 证据，登记归口）。
6. **用例**：三型锁定产生与落库、手动解锁恢复登录、被锁登录被拒、并发与幂等分支。

## 3. 完成标准 <a id="accept"></a>

三型锁定均可产生且落库；手动解锁恢复登录且留痕；被锁账号登录被拒且返回码符合契约；并发 / 幂等用例通过；`sys_account_lock` 表文件 ↔ 登记 ↔ 迁移零漂移；页面归口在计划台账登记。
