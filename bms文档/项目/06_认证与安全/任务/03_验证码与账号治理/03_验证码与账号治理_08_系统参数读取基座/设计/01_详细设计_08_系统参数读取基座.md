## 1. 设计目标与范围 <a id="goal"></a>

把「系统参数（`sys_config`）按租户读取」落为**可复用的跨阶段基座**：新建 `sys_config`（platform 服务租户库）+ `config` 能力域（`BaseConfigSource` / `ConfigCacheRegion` + `sql` / `http` / `null` 实现 + 内部失效服务）+ platform 内部读取端点（服务 JWT 鉴权）；平台默认参数经幂等种子写入各租户库，消费方按 key 读取、缺省回落代码默认表。**本轮只交读取链路 + 失效服务方法**，管理面（CRUD / 页面 / 审计）归阶段八。

- **本任务范围**：`sys_config` 表 / 模型 / 迁移 / 归属登记；`config` 能力域契约与 `sql` / `http` / `memory` / `redis` / `null` 实现；platform 内部读端点与路由登记；验证码场景策略键的平台默认种子与 `ops` 接入；配置装配（`[config_source]` / `[config_cache_region]`）；测试、契约快照与登记回写。
- **不在本任务**：密码策略 / 会话 / 上传等其它消费方（各自任务）；`sys_config` 管理面（CRUD 接口、页面、`config:manage`、字段级审计、平台库默认向租户库的自动下发流程）→ 阶段八「系统参数」模块；验证码策略读取与失败计数强制 → `03_04`。
- **接口兼容**：不改既有四端点契约、不改既有能力域签名；**纯新增**能力域 `config_source` / `config_cache_region` 与 platform 内部端点（新增插件键，须同步平台契约快照与 `_EXPECTED_PLUGIN_KEYS`）。
- **安全影响（SDL）**：`sys_config` 可能承载安全敏感参数——专项验收点：内部端点仅接受白名单服务 JWT（拒用户票据 / 网关票据 / 无票据）、不落配置值明文日志、跨服务读失败**降级为「无覆盖」**（回落平台默认，不静默放宽）、缓存键带租户前缀隔离。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 能力域与插件键 <a id="domain"></a>

| 能力域（插件键） | 插件基类 | 实现（`plugin_name`） | Null 实现 | 契约版本 |
| --- | --- | --- | --- | --- |
| `config_source` | `BaseConfigSource` | `SqlConfigSource`（`sql`）/ `HttpConfigSource`（`http`） | `NullConfigSource` | `0.1.0` |
| `config_cache_region` | `ConfigCacheRegion` | `MemoryConfigCacheRegion`（`memory`）/ `RedisConfigCacheRegion`（`redis`） | `NullConfigCacheRegion` | `0.1.0` |

- 继承链沿用基座体系：`BaseObject` → `BaseCapability` → `BasePluggable`（+ `BaseAsyncResource`）→ `BaseConfigSource` / `ConfigCacheRegion`（能力域）；Null 走 `BaseNullObject` 缺省轨。
- **新增两个插件键**：`_EXPECTED_PLUGIN_KEYS` 与 `PluginWiring`（`app.state` 落点 `config_source` / `config_cache_region`）同步登记；`test_plugin_registration` 键集断言更新。

### 3.2 数据契约与读接口 <a id="api"></a>

```python
# bms_core/config/base.py
CONFIG_CACHE_DOMAIN = "config"
CONFIG_SOURCE_UNAVAILABLE = 4_0201   # 预留：配置源不可用（本任务降级不抛，登记备用）
"""配置域常量：缓存域 `config`；错误码预留 `402xx` 段（与概要 10 §7 一致）。"""

class BaseConfigSource(BasePluggable, ABC):
    key: str = plugin_key = "config_source"
    plugin_name: str = NULL_PLUGIN_NAME
    contract_version: str = "0.1.0"

    @abstractmethod
    async def get_many(self, keys: Sequence[str]) -> Mapping[str, str]:
        """批量取参数值（按 key；缺失键不出现在结果中，由调用方回落默认）。"""

    async def get(self, key: str, default: str = "") -> str:
        """取单参数（默认实现委托 `get_many`）。"""
        values = await self.get_many((key,))
        return values.get(key, default)


class ConfigCacheRegion(CacheRegion, ABC):
    key: str = plugin_key = "config_cache_region"
    plugin_name: str = NULL_PLUGIN_NAME
    contract_version: str = "0.1.0"

    @property
    def domain(self) -> str: return CONFIG_CACHE_DOMAIN

    def config_key(self, tenant: str | None, config_key: str) -> str: ...
    def version_key(self, tenant: str | None) -> str: ...
    def is_version_current(self, version: int, *, tenant: str | None) -> bool: ...
    async def aget_value(self, tenant, config_key) -> str | None: ...
    async def aset_value(self, tenant, config_key, value, ttl=None) -> None: ...
    async def adrop_value(self, tenant, config_key) -> None: ...
    async def aversion(self, tenant) -> int: ...
    async def aincrease_version(self, tenant) -> int: ...
```

- **租户口径**：与字典一致，**方法不显式传租户**（`get_many` 不传 tenant），实现侧从请求上下文 `get_current_tenant()` 取租户拼 key / 选库；调用方不可绕过。
- **缺省语义**：`get_many` 只返回「存在的键值」；键缺失（未覆盖且未种子 / 源不可达降级）由调用方回落代码默认表。

### 3.4 取数实现口径 <a id="impl"></a>

**`SqlConfigSource`（platform 侧，数据权威）**：

1. 经 `EngineRegistry` + 当前租户上下文取租户库会话（同 `SqlDictSource`）。
2. 逐 key 读缓存域（L1 内置 / Redis 共享）：命中直接返回；未命中批量回源（单条 `WHERE config_key IN (...)` 且 `deleted_at IS NULL`）→ 回填缓存（短 TTL + 随机偏移）。
3. 只返回命中键；DB 不可用 / 查询异常 → 返回空结果 + 日志告警（**降级为「无覆盖」**，由消费方回落默认，不抛业务错）。

**`HttpConfigSource`（非 platform 服务，跨服务读出口）**：

- 经 `BaseServiceClient` 调 platform 内部端点（服务 JWT，`service="platform"`，`X-Tenant-Id` 透传租户）；解析 `{values: {key: value}}`。
- 不可达 / 超时 / 熔断 / 非 2xx / 响应体非法 → 返回空结果 + 日志告警（降级不抛，与 `NullConfigSource` 同语义）。

**缓存失效（`ConfigService`，本轮无管理 API）**：

```python
class ConfigService(BaseObject):
    async def set(self, engines, cache, *, config_key, value, remark=None) -> None: ...
        # upsert 租户库 sys_config 行 → 删缓存 key（含 L1）→ 递增租户版本键
    async def drop(self, engines, cache, *, config_key) -> None: ...
        # 软删除行（恢复平台默认）→ 删缓存 key → 递增版本键
```

- 先写库后删缓存；版本键供多实例 L1 惰性失效。**仅服务方法，无路由**（管理面归阶段八）。

### 3.5 platform 内部读端点 {#endpoint}

| 方法 | 路径 | 鉴权 | 请求 | 响应 data |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/platform/internal/configs/resolve` | `require_service("identity", "org")` | `{keys: string[]}` | `{values: {config_key: value}}` |

- 路由基类 `BaseRouter(key="config_internal", prefix="/platform/internal/configs")`；仅接受白名单服务 JWT（用户票据 / 网关 `sub=gateway` / 无票据一律 401 `20001`）。
- 响应**只回存在键**；未知 key 静默省略（不报错、不泄露 key 是否存在之外的语义）。
- 计入 platform 公开契约（`deploy/contracts/platform.json` 重生成，零漂移）。

### 3.7 配置契约 <a id="config"></a>

`config.toml` 新增两节（结构同其它能力选择）：

```toml
[config_source]
# 系统参数读取实现选择（sql = platform 侧直连租户库读、http = 跨服务读 platform 内部端点、空串 = null 占位）
provider = "http"
options = {}

[config_cache_region]
# 系统参数缓存域实现选择（memory / redis；空串 = null 占位）
provider = ""
options = {}
```

- `Settings` 增 `config_source: PluginSelection` / `config_cache_region: PluginSelection`（`config.toml` 基线不配置，默认空 → null 占位）。
- **provider 口径（与 dict 同构，2026-09-27 实施回写）**：`config.dev.toml` 置 `[config_source].provider = "sql"`（各服务读**本服务租户库**副本，dev 各库自动建表 + 种子）、`[config_cache_region].provider = "memory"`；生产环境非 `platform` 服务经部署环境变量覆盖为 `http`（`BMS_CONFIG_SOURCE__PROVIDER=http`，读 platform 内部端点），`platform` 服务为 `sql`。各服务单测默认空回落 Null（保持离线）。
- `deploy/.env.example` 不新增键（嵌套规则自动可用）。

### 3.8 失败分支与错误语义 <a id="failures"></a>

| 场景 | 行为 |
| --- | --- |
| 键存在 | 返回库值（缓存命中直接返回） |
| 键不存在（未覆盖 / 未种子） | 结果中省略该键；调用方回落代码默认 |
| DB 不可用 / 查询异常（sql） | 返回空结果 + 日志告警（降级为「无覆盖」，不抛） |
| platform 端点不可达 / 非 2xx / 熔断（http） | 返回空结果 + 日志告警（降级为「无覆盖」，不抛） |
| 内部端点：无 / 用户 / 网关票据 | `AuthError`（20001 / 401） |
| 内部端点：白名单服务 JWT | 放行；租户由 `X-Tenant-Id` / 服务 JWT 解析 |
| Redis 不可用（缓存） | 直连 DB（读写不中断，沿用 `RedisCacheRegion` 内部兜底） |
| `[config_*]` 选项非法 | 工厂 `PluginError`（装配拒启） |

## 4. 兼容性与消费方影响 <a id="compat"></a>

- **纯新增**：新增能力域与插件键、新增表与端点；既有 `dict` / `captcha` / `rate_limiter` 等零改动。
- **platform 契约快照**：新增内部端点后重生成 `deploy/contracts/platform.json`（纯新增，契约版本不变）。
- **迁移链**：`platform:tenant` 新增 `0004_sys_config`（`down_revision=0003_sys_outbox_event_version`）；`test_alembic_chains` 表集随归属登记自动纳入。
- **消费方**：`03_04`（identity 经 `http` 读策略键）、`03_05`（identity / org）；调用经 `BaseConfigSource`，后续换成配置服务真实实现时仅改 provider，不动判定逻辑。
- **single table 通用性**：`config_key` 为平台统一命名空间，后续密码 / 会话 / 文件 / AI 键直接扩展，无需改表。

## 7. 边界与开放项 <a id="boundary"></a>

- **管理面**（CRUD / 页面 / `config:manage` / 字段级审计 / 平台库默认向租户库自动下发流程）→ **阶段八「系统参数」模块**；本轮只交读取链路 + 内部 `set` / `drop` 服务方法。
- **平台默认来源**：本轮以「种子写入租户库 + 消费方代码默认表兜底」实现；概要所说的「平台库存默认 → 租户开通种子下发」完整流程归阶段八。
- **写入路径契约**：`ConfigService` 仅服务方法、无路由；阶段八接入管理 API 时复用其失效协议。
- **配置变更广播事件**（跨服务缓存失效）：本轮靠短 TTL + 版本键；事件广播归后续。
- **敏感值加密**：`value` 本轮明文入库（键为策略类非密值）；密钥类参数（如 AI `api_key`）不入本表（另走 `secret:` 机制，域 04_03）。
