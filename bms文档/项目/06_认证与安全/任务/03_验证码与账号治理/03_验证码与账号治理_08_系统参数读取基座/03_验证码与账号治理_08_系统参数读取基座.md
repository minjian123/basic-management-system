## 2. 任务内容 <a id="content"></a>

1. **表与模型**：新建 `sys_config`（`config_key` 唯一、`value`、`remark`，公共字段继承 `BaseModel`），随 `platform:tenant` 链迁移落地；表文件先设计后落库，表归属登记纳入链表集。
2. **读取能力域**：新增 `BaseConfigSource`（按 key / 批量取数，缺省空结果）+ `ConfigCacheRegion`（缓存域 `config`、key `bms:{tenant}:config:{config_key}`、版本键 `bms:{tenant}:config:version`）；`sql` 实现供 platform 侧、`http` 实现供其他服务经服务间契约读取；缺省回落由消费方代码默认表兜底。
3. **跨服务读出口**：platform 暴露内部读端点（服务 JWT 鉴权，服务间经 `/api/v1`）；identity 经 `http` 读本租户参数。
4. **缓存与失效**：读取带短 TTL + 随机偏移缓存；提供内部写 / 失效服务方法（先写库后删缓存 + 递增版本键），供「策略变更即时生效」验证与后续管理面复用。
5. **平台默认种子**：幂等种子写入验证码五场景键 `captcha.scene.{scene}.{required|fail_threshold|ttl|cooldown}` 与渠道开关 `captcha.channel.{image|slider|sms}`；`ops/seed_config.py` 并接入 `ops/init_tenant.py`。
6. **登记回写**：《[后端基类清单](../../../../../后端基类清单.md)》登记基座条目；《[概要设计 · 系统参数](../../../../../设计/概要设计/10_概要设计_系统参数.md)》§6.3 键命名定稿回写；《数据库设计总览》表文件登记状态回写。

## 3. 完成标准 <a id="accept"></a>

`sys_config` 表文件 ↔ 总览登记 ↔ 迁移零漂移；platform 内部读端点可被 identity 经服务 JWT 读到本租户值、缺省回落平台默认；缓存读写与失效即时生效用例通过；种子幂等；`pytest` / `ruff` / `pyright` / 基座校验 / 契约快照零漂移全绿。
