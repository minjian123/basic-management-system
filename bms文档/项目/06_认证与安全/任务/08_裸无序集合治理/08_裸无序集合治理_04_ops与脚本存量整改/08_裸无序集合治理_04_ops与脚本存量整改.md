## 2. 任务内容 <a id="content"></a>

1. **存量整改（批次 3 · `ops` 与 `scripts/tools`）**：`backend/ops` 与 `scripts/tools` 合计命中 **327 处**（`scripts/tools` 224 处、`backend/ops` 103 处；2026-09-30 实测，含测试目录与函数体局部变量）**全落插入序形态**（`ConcurrentStableList` / `ConcurrentStableSet` / `ConcurrentStableDict`，类字段 / 参数 / 返回 / 局部变量位置全覆盖）——**口径与落点以 [08_02 详细设计](../08_裸无序集合治理_02_bms_core存量整改/设计/01_详细设计_02_bms_core存量整改.md) 为准**；`ConcurrentSorted*` 与 `SortedList` / `SortedDict` / `SortedSet` 为体系内部基础实现、不作为整改落点（不得直接声明 / 继承）；**批内先类字段、后签名、再局部变量**。
2. **`scripts/tools` 长期口径专项**（报告 §6 遗留 2）：评估 `scripts/tools`（构建期内部工具、结构不外流、不在 CI `ruff` / `pyright` 覆盖范围）是否纳入长期强制口径——「内部工具豁免」与「统一整改」两案取证比对，结论回写《[后端开发规范](../../../../../规范/后端开发规范.md)》「集合与排序」与《[后端基类清单](../../../../../后端基类清单.md)》「集合体系」；若判定豁免，须**同步护栏扫描范围**（`check-bare-collections.py` 的扫描域与基线快照一并调整，并补自测用例）。
3. **基线递减至归零**：`python3 scripts/tools/base-check/check-bare-collections.py . --update-baseline` 重写 `deploy/boundaries/bare_collections_baseline.json`（本批段 327 → **0**），**不得手工增删基线条目**；复跑检查「新增 0 / 残留 0」。
4. **登记回写**：《[后端基类清单](../../../../../后端基类清单.md)》「集合体系」节「裸无序集合护栏与基线」小段登记批次归零状态与 `scripts/tools` 口径结论；盘点报告 §4 批次表状态随实施更新。
5. **测试**：先登记 Kiwi TCMS 用例取号、后写自动化——断言 `ops` 与 `scripts/tools` 命中归零、基线**条目归零**、护栏复跑「新增 0 / 残留 0」（若豁免 `scripts/tools` 则断言扫描范围与基线同步正确）；护栏 `--self-test` 全绿；受影响定向回归与门禁全绿。

## 3. 完成标准 <a id="accept"></a>

`backend/ops` 与 `scripts/tools` 327 处整改完毕（或按长期口径结论将 `scripts/tools` 移出扫描范围并同步护栏与基线）且**形态一致 + 逐处登记**；基线快照**条目归零**、`check-bare-collections.py` 复跑「新增 0 / 残留 0」；`scripts/tools` 长期口径结论回写规范与清单；《后端基类清单》「集合体系」与代码一致；定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
