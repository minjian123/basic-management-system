## 2. 任务内容 <a id="content"></a>

1. **存量整改（批次 1 · `bms_core`）**：`backend/libs/bms_core/src` 命中 **305 处**（类字段 111 / 签名参数 32 / 签名返回 162，2026-09-29 实测）逐处整改——以「换基座形态 / 只读抽象」为主（`dict[str, X]` → `Mapping[str, X]`、`list[X]` → `Sequence[X]`），对外返回稳定序要求（分页 / 游标 / 导出）**一律落 `ConcurrentSorted*`（并发有序集合）或 `Sequence`**——**`SortedList` / `SortedDict` / `SortedSet` 为基座内部基础实现，不作为整改落点**（业务与契约不得直接声明 / 继承，2026-09-29 定档）；**批内先类字段、后签名参数与返回**（契约影响面优先）；仅改声明与 import，不改行为。
2. **行为等价把握**：`dict` → `Mapping`、`list` → `Sequence` 后调用方若需可变操作，改「按需拷贝 / 保留具体类型并只收窄契约边界」；每处实际处置方式记入实施记录，不顺手改逻辑。
3. **基线递减**：`python3 scripts/tools/base-check/check-bare-collections.py . --update-baseline` 重写 `deploy/boundaries/bare_collections_baseline.json`（548 → 243 处，聚合条目数同步递减），**不得手工删除基线条目**（基线即台账）。
4. **登记回写**：《[后端基类清单](../../../../../后端基类清单.md)》「集合体系」节「裸无序集合护栏与基线」小段登记批次进度与余量；《[存量盘点报告](../08_裸无序集合治理_01_护栏与基线盘点/实施/02_存量盘点报告_01_护栏与基线盘点.md)》§4 批次表状态随实施更新。
5. **测试**：先登记 Kiwi TCMS 用例取号、后写自动化——断言 `bms_core` 命中归零、基线递减至 243、护栏复跑「新增 0 / 残留 0」；受影响定向回归（`bms_core` 相关用例）与门禁全绿。

## 3. 完成标准 <a id="accept"></a>

`bms_core` 305 处全部改为**并发有序集合类或只读抽象**（稳定序落 `ConcurrentSorted*`；`SortedList` / `SortedDict` / `SortedSet` 不作为整改落点、不得新增直接声明 / 继承）且**行为零变更**；基线快照递减至 243 处且 `check-bare-collections.py` 复跑「新增 0 / 残留 0」；《后端基类清单》「集合体系」与代码一致；受影响定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
