## 2. 任务内容 <a id="content"></a>

1. **护栏脚本**：新增 `scripts/tools/base-check/check-bare-collections.py`——以 AST 解析后端 Python（`bms_core` / `services` / `ops` / `scripts/tools`，排除测试），检出**类字段注解**与**函数签名注解**（参数 / 返回）中的裸无序集合（`dict` / `list` / `set` / `frozenset` 及 typing 别名 `Dict` / `List` / `Set` / `FrozenSet` / `DefaultDict`）；支持文本清单、`--json` 机器可读输出、`--report` 报告模式（仅统计、不改退出码）与 `--update-baseline` 更新基线。
2. **基线快照**：现存违规以「文件路径 + 规范化行内容指纹」入基线快照（`deploy/boundaries/bare_collections_baseline.json`）；**新增违规即失败**；修复后更新快照、条目**可审计递减**（防回潜）。
3. **挂接**：纳入 `scripts/tools/preflight/check-preflight.py --fast`（基座与边界段）与 CI 静态 / 基座校验域，与 `check-base.py` / `check-backend-base.py` 同机制、可单独运行。
4. **存量盘点报告**：按「区域（`bms_core` / `services` / `ops` / `scripts/tools`）× 位置（类字段 / 签名参数 / 签名返回）× 容器形态」统计，给出分批整改建议（独立报告，落本目录 `实施/`）。
5. **规范口径补强**：《[后端开发规范](../../../../../规范/后端开发规范.md)》「集合与排序」明确「对外数据契约、值对象与模块类的集合字段与签名**一律使用继承基座的集合类或只读抽象**（`Sequence` / `Mapping` / `Iterable`），禁止裸无序集合」，并指向护栏脚本与基线快照。
6. **用例**：护栏检出（命中 / 不命中形态、只读 / 有序抽象不报）、基线豁免与新增拦截、报告模式与退出码语义。

## 3. 完成标准 <a id="accept"></a>

新增违规被拦截（自测用例证明）；基线快照与现状一致（生成后复校零漂移）；存量盘点报告落文档（含分批建议）；规范「集合与排序」口径补强完成并在《[后端基类清单](../../../../../后端基类清单.md)》「集合体系」节登记护栏与基线落点；preflight 与 CI 挂接生效；`pytest`、`pyright`、`ruff` 通过。
