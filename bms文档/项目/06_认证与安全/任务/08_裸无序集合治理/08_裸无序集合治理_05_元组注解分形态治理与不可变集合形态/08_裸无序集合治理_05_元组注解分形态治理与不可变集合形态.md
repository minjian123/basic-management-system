## 2. 任务内容 <a id="content"></a>

1. **护栏改真白名单**（`scripts/tools/base_check/check_bare_collections.py`）：`WHITELIST_FORMS` 参与判定（现为死常量——判定处只用 `BANNED_FORMS`），**未命中白名单即违规**；`tuple` 按形态区分——**同构 `tuple[X, ...]` 判违规**（落 `ConcurrentStableList`）、**固定元数 `tuple[A, B]` 豁免**；`--self-test` 矩阵补四类断言（同构 tuple 报 / 固定元数不报 / 新形态报 / 未登记形态报）。
2. **新增不可变层与三形态**（`core/collections.py` + `core/concurrent.py`）：`BaseImmutable` 承 `BaseConcurrent`（**构造期即写路径**，需分段写锁与序号锁）；`ConcurrentStableFrozenList` / `ConcurrentStableFrozenSet` / `ConcurrentStableFrozenDict` 构造期直接写、构造后恒冻结（不复用 `freeze()`）；`collection_kind = "stable_frozen"`。
3. **哈希不变量修正**：可变形态 `ConcurrentStable*` 改 `__hash__ = None`（与内置 `list` / `dict` / `set` 对齐）；不可变形态补**内容哈希**（列表按序、集合与映射用 `frozenset`，与 `eq` 语义对齐，哈希值缓存）。
4. **派生运算口径**：不可变形态的 `|` / `union` / `difference` / `symmetric_difference` 等改为「先算可变临时实例、最后一次冻结」（现实现 `copy()` 后 `update()` 会撞冻结，实测三处失败）。
5. **值对象字段归位**：**16 处** `BaseValueObject` 字段由可变集合类改落不可变形态（`_Granted.permission_codes` / `menu_ids` / `form_ids`、`QueryResult.rows`、`ImportResult.rows`、`ServiceRequest.query` / `headers` / `json_body`、`SpanContext.attributes`、`RealtimeEvent.data`、`HashChainEntry.record`、`MigrationChain.tables`、`IdentityProviderSpec.config`、`BranchOp.args`、`SearchHit.highlight`、`DataScopeGrantEntry.config`），使 frozen dataclass 的 `hash` 与 `eq` 对齐（`len({同内容两实例}) == 1`）。
6. **存量整改（524 处同构元组，分四批递减基线）**：批次 1 `libs` 源侧 **294** → 批次 2 `services` **51** + `ops` **31** → 批次 3 `scripts/tools` **83** → 批次 4 `libs` 测试 **65**；与 08-2 区域口径一致（同一文件只被一批触碰）、批内先类字段后签名后局部变量、每批 `--update-baseline` 递减。
7. **口径回写**：《后端开发规范》「集合与排序」（tuple 分形态口径、白名单判定语义、可变 / 不可变哈希分工）；《后端基类清单》「集合体系」（`BaseImmutable` 新层 + 三形态 + 哈希口径 + 派生运算）；《后端基类治理台账》「裸无序集合护栏与基线」（白名单判定与豁免口径）。

## 3. 完成标准 <a id="accept"></a>

护栏为**真白名单判定**（未命中即违规）且 `--self-test` 覆盖同构 tuple 报 / 固定元数不报 / 未登记形态报；`BaseImmutable` 与三形态落集合体系唯一链，`check_backend_base.py` 继承链对账与《后端基类清单》零漂移；不可变形态构造期写、构造后一切写操作抛 `TypeError`，**内容哈希与 `eq` 语义对齐**（同内容实例可作 dict 键、set 去重生效、嵌套形态一致）；可变形态改不可哈希且与内置容器行为一致；16 处值对象字段归位后 `len({同内容两实例}) == 1`；派生运算不撞冻结；**524 处同构元组整改完成、基线归零、复跑「新增 0 / 残留 0」**；规范与清单回写并与代码零漂移；定向 `pytest`（覆盖率 100% 行 + 分支）、`ruff`、`pyright`、基座护栏与 `preflight` 全绿。
