## 2. 任务内容 <a id="content"></a>

1. **集合体系唯一链收口**：集合体系收敛为**唯一继承链**——基础集合基类 `BaseCollection` 为**集合体系唯根**（集合通用语义 + 稳定序约定 + `collection_kind`），其下按形态分支：`BaseSorted`（非并发有序 · 无锁高效；`Sorted*` 落点）；`BaseSorted` → `BaseConcurrent`（基础并发：锁策略守卫 + 原子复合操作 + 快照遍历；`ConcurrentSorted*` / `ConcurrentStable*`）与 `BaseAsyncSorted`（跨副本：并发由 Lua + 版本号承载、无同步锁层）；`BaseCollection` → `BaseCacheSnapshot`（通用缓存层）。**所有集合类一律（间接）继承 `BaseCollection`、无任何例外**；旧名 `BaseSorted`（旧语义根）/ `BaseSyncSorted` / `BaseConcurrentSorted` 退场。
2. **跨副本形态回链**：`RedisSortedSet` / `RedisSortedDict`（`bms_core/core/redis_collections.py`）挂 `BaseAsyncSorted`（承 `BaseSorted`；**无同步读入口**——同步读公共段显式置为不支持）；`RedisSnapshot` 经**通用缓存层 `BaseCacheSnapshot`** 入链（由框架对象体系改挂，不再有链外例外）。
3. **登记与口径回写**：《[后端基类清单](../../../../../后端基类清单.md)》**§1 层级图与表**（唯一链）、**§4 集合体系表**与「扩展与演进」、**§10 体系根清单**（`BaseCollection`）与继承链登记。
4. **护栏**：`check-backend-base.py` 的继承链对账与「体系根白名单」覆盖新根（`BaseCollection`）；`check-bare-collections.py` 白名单与「不属约束对象」口径同步；如集合体系新增语义约束，补对应检查与 `--self-test` 用例。
5. **规范与架构回写**：《[后端开发规范](../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[架构设计 · 后端基础类体系](../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》的集合体系分层口径同步（多处一致）。
6. **测试**：先登记 Kiwi TCMS 用例取号、后写自动化——`issubclass` 断言所有集合类（含 `Sorted*` / `Concurrent*` / `Redis*` / `RedisSnapshot`）均（间接）继承 `BaseCollection`、跨副本形态无同步读入口、清单 §1/§4/§10 与代码零漂移；受影响定向回归（集合类 + Redis 集合用例）与门禁全绿。

## 3. 完成标准 <a id="accept"></a>

集合体系为**一条继承链**（所有集合类均继承 `BaseCollection`；`RedisSortedSet` / `RedisSortedDict` 挂 `BaseAsyncSorted`；`RedisSnapshot` 挂 `BaseCacheSnapshot`）；《[后端基类清单](../../../../../后端基类清单.md)》§1 / §4 / §10 与代码**零漂移**；`check-backend-base.py` 继承链对账与体系语义检查通过（含 `--self-test`）；**同步侧行为零变更**（既有集合用例全绿）；定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
