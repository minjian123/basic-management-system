## 2. 任务内容 <a id="content"></a>

1. **公共段对同步 / 异步中立**：把集合体系公共段调整为「有序语义 + 稳定序 / 序列化契约」，同步抽象（`to_list` / `__iter__`）与异步抽象（异步读写 + 快照）各自下沉为**角色链上的层**；**具体落法（体系根只留语义 + 同步方法下沉 / 拆同步-异步两条角色链 / 新增集合体系根）在详细设计逐项确认后再实施**，不在任务层定死。
2. **跨副本形态回链**：`RedisSortedSet` / `RedisSortedDict`（`bms_core/core/redis_collections.py`）改挂集合体系（异步角色链上的层）；`RedisSnapshot` 为**通用缓存快照、非有序集合**，保持框架对象体系，并在《[后端基类清单](../../../../../后端基类清单.md)》注明其归属与理由。
3. **登记与口径回写**：《[后端基类清单](../../../../../后端基类清单.md)》**§1 表**第三层父类登记修正（现记 `BaseObject`，实际已是 `BaseFrameworkObject` → 改为改挂后的父类）、**§4 表**与「扩展与演进」**示例一**（三层为一条链）、**§10** 链登记与体系根白名单（如新增层 / 体系根）。
4. **护栏**：`check-backend-base.py` 的继承链对账与「体系根白名单」须覆盖新层；如集合体系新增语义约束（例如异步角色链成员不得为 dataclass），补对应检查与 `--self-test` 用例。
5. **规范与架构回写**：《[后端开发规范](../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[架构设计 · 后端基础类体系](../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》的集合体系分层口径同步（四处一致）。
6. **测试**：先登记 Kiwi TCMS 用例取号、后写自动化——`issubclass` 断言 `RedisSortedSet` / `RedisSortedDict` 落在集合体系链上、`RedisSnapshot` 仍在框架对象侧、清单 §1/§4/§10 与代码零漂移；受影响定向回归（集合类 + Redis 集合用例）与门禁全绿。

## 3. 完成标准 <a id="accept"></a>

集合体系三层为**一条继承链**（`RedisSortedSet` / `RedisSortedDict` 在链上，`RedisSnapshot` 按非有序集合在框架对象侧且有清单注明）；《[后端基类清单](../../../../../后端基类清单.md)》§1 / §4 / §10 与代码**零漂移**；`check-backend-base.py` 继承链对账与体系语义检查通过（含 `--self-test`）；**行为零变更**（既有 Redis 集合用例全绿）；定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
