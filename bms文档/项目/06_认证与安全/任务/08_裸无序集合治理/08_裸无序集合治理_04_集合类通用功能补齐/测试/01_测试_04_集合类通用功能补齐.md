| 用例组 | 覆盖点 | 对应设计 |
| --- | --- | --- |
| 输出可读性 | `render_payload` 字面量渲染 / 超限截断 / 非容器兜底；三类形态 `str`≡`repr`；映射不再是键值对列表；跨副本描述式 `repr` 恒不抛错 | §3.1 |
| 冻结只读快照 | `freeze()` 内容独立；三类形态一切写操作抛 `TypeError`；升序形态同样受保护；跨副本与缓存快照不支持 `freeze` | §3.1 |
| 列表写糖等价 | `append` ≡ `add` / `extend` ≡ `update` / `+=` ≡ `update`；`+` 返回同类新实例且原实例不变、策略保真；`copy` 保策略 | §3.2 |
| 列表按索引写删 | `pop()` / `pop(i)` / `pop(-1)` / 越界 / 空表；`l[i] = v` 保留原位置；`del l[i]`；负索引；切片赋值与切片删除抛 `TypeError` | §3.2 |
| 列表排序与拼接 | `sorted(key, reverse)` 返回同类新实例、原实例不变；`merge` 为顺序拼接 | §3.2 |
| 字典通用功能 | `d[k] = v` / `del d[k]` / 越界 `KeyError`；`update` 三形态（映射 / 键值对 / kwargs）可叠加；`pop` 哨兵区分缺失与 `None` 值；`popitem` LIFO；`setdefault`（含既有值为 `None`）；`fromkeys`；`clear` / `copy`；`\|` / `\|=`；`sorted_items` / `sorted_keys` 返回内置 `list` | §3.3 |
| 集合通用功能 | `remove` 缺失抛 `KeyError`；`pop` 首个插入元素、空集 `KeyError`、跨多段与「首个元素不在 0 号段」；四个命名运算保插入序；四个 `*_update` | §3.4 |
| 形态一致性 | 两形态同一套方法名同时存在；`insert` / `sort` / `reverse` 不存在 | §3.2 / §5 |
| 并发安全 | 多线程写糖混写（`append` / `extend` / `__iadd__`）：元素不丢不重、每线程子序列保插入序；字典 / 集合写糖多线程不崩、结果正确 | §5 |
| 四种锁策略 | `SHARDED` / `RW` / `RLCK` / `SNAPSHOT` 全覆盖（含升序形态 `SHARDED`） | §5 |
| 边界分支 | `_delete_seq` / `_replace_seq` 的并发窗口防御（替身 `_view`）；非分段策略下空表 `pop` / `popitem`；`put_if_absent` 两条路径；`__deepcopy__` 独立副本 | §3 / §5 |
