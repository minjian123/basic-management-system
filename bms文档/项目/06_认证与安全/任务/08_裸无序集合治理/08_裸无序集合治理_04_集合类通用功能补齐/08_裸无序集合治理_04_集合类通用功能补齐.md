## 2. 任务内容 <a id="content"></a>

1. **输出可读性**：集合体系公共段（`core/collections.py`）统一 `__str__` / `__repr__` 为「类名 + 内置字面量」，超长截断（默认 10 项 + 「共 N 项」提示）；`BaseAsyncSorted` 改**描述式 `repr`**（含键名、不读远端），**永不抛错**。
2. **列表通用功能**（`ConcurrentStableList`，同步落 `ConcurrentSortedList`）：`append` / `extend` / `__iadd__` / `__add__` / `pop(index=-1)` / `__setitem__`（索引，非切片）/ `__delitem__`（索引，非切片）/ `sorted(key=, reverse=)`；**不提供 `insert`、原地 `sort`、原地 `reverse`**。
3. **字典通用功能**（`ConcurrentStableDict`，同步落 `ConcurrentSortedDict`）：`__setitem__` / `__delitem__` / `clear` / `pop(key[, default])` / `popitem` / `setdefault` / `fromkeys` / `update(映射 | 键值对 | kwargs)` / `__or__` / `__ior__` / `sorted_items` / `sorted_keys`；修掉 `update(映射)` 抛 `ValueError` 的缺陷。
4. **集合通用功能**（`ConcurrentStableSet`，同步落 `ConcurrentSortedSet`）：`remove`（缺失抛 `KeyError`）/ `pop` / `copy` / `union` / `intersection` / `difference` / `symmetric_difference` 及四个 `*_update`。
5. **性能口径**：每个新增方法标注复杂度；「禁用 / 慎用场景」表落《后端基类清单》「集合体系」节；**不得为对齐写法引入新锁、全表重编号或额外快照拷贝**。
6. **口径回写**：规范「集合与排序」、清单「集合体系」、治理台账、`08_02` 详细设计 §3.3 的旧表述统一改为「写糖一律等价于对应原子方法、不新增写路径」。

## 3. 完成标准 <a id="accept"></a>

`ConcurrentStable*` 与 `ConcurrentSorted*` 覆盖任务内容 2~4 的通用方法面，内置容器日常写法可直接使用；`repr` / `str` 可读且**任何形态打印都不抛错**；写糖与对应原子方法**行为等价**（用例逐对断言）；并发用例证明写糖不破坏插入序与线程安全；每个新增方法标注复杂度、「禁用 / 慎用场景」表成文；定向 `pytest`（覆盖率 100% 行 + 分支）、`ruff`、`pyright`、基座护栏与 `preflight` 全绿。
