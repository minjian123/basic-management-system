## 2. 任务内容 <a id="content"></a>

1. **CAS 适配实现**：按 `BaseIdentityProvider` 契约实现 CAS 客户端（授权跳转 / `serviceValidate` 票据校验 / 用户属性解析），复用同一 SSO 登录链路与 JIT 建号，不另建链路。
2. **属性映射与失败语义**：账号 / 姓名 / 邮箱映射；票据无效 / 服务未注册 / IdP 不可达的明确错误语义。
3. **mock CAS 联调**：以本地 mock CAS 服务（测试夹具）完成端到端联调；真实 CAS IdP 联调归凭据就绪时（与域 02_04 同口径）。
4. **插件登记**：协议实现登记进身份源插件族（`plugin_name` 与 `IDP_PROTOCOLS` 对齐），配置经 `sys_identity_provider`（域 02_06）读取。
5. **用例**：成功票据 / 无效票据 / 服务未注册 / IdP 不可达分支；OIDC 主链回归不受影响。

## 3. 完成标准 <a id="accept"></a>

mock CAS 服务下端到端 SSO 登录（含 JIT 建号）通过；失败分支错误语义明确且有用例；OIDC 主链回归全绿；`pytest`、`pyright`、`ruff` 通过。
