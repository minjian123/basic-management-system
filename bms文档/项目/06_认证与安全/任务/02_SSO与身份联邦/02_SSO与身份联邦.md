## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段六需求域 02 的 6 条需求——[02-1 SSO 登录链路](../../需求/02_需求_SSO与身份联邦.md#r02-1)、[02-2 JIT 建号与身份映射](../../需求/02_需求_SSO与身份联邦.md#r02-2)、[02-3 CAS 兼容适配](../../需求/02_需求_SSO与身份联邦.md#r02-3)、[02-4 企业微信 / 钉钉免登适配](../../需求/02_需求_SSO与身份联邦.md#r02-4)、[02-5 BMS 兼作 IdP](../../需求/02_需求_SSO与身份联邦.md#r02-5)、[02-6 外部 IdP 配置管理](../../需求/02_需求_SSO与身份联邦.md#r02-6)，按「1 需求 = 1 子任务」拆 6 个子任务（`02_01` ~ `02_06`）。
- **端范围**：**后端为主**（identity 服务 + org 服务最小模型 + 部署侧 Keycloak / mock CAS 测试件）；扫码登录前端归域 05。
- **承接口径**：阶段二已交付 OIDC 客户端（Discovery / 授权 URL / 换码 / userinfo / JWKS 验签）、`BaseIdentityProvider` 契约与 `IDP_PROTOCOLS` 常量、`sys_user_identity` 与外部身份映射设计口径；本域在其上**闭环登录链路、扩展协议、落地联邦治理**，OIDC 之外协议一律复用同一链路与 JIT，不另起框架。
- **本期联调口径**（2026-09-26 拍板）：OIDC（Keycloak）真联调；CAS 本地 mock 联调；企微 / 钉钉适配 + 单测，真实凭据联调与移动端内嵌 H5 免登留阶段十七；BMS 兼作 IdP 交内核 + `sys_client` 最小接口（管理页面归阶段十）。
- **依据**：《[架构设计 · 认证与会话](../../../../设计/架构设计/14_架构设计_子系统_认证与会话.md)》§4、《[架构设计 · 接口与集成](../../../../设计/架构设计/09_架构设计_接口与集成.md)》、《[概要设计 · 身份认证SSO](../../../../设计/概要设计/26_概要设计_身份认证SSO.md)》。
- **执行序**：`02_01 SSO 登录链路` → `02_02 JIT 建号与身份映射` → `02_05 BMS 兼作 IdP` → `02_06 IdP 配置管理` → `02_03 CAS` → `02_04 企微 / 钉钉`（见[计划](../../计划/01_计划_认证与安全.md)）。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：90h（01 16h + 02 12h + 03 12h + 04 14h + 05 24h + 06 12h）。
- **关键依赖**：`02_01` 依赖域一 `01_03`（会话签发）与阶段二 `07_01`；`02_02` 依赖 `02_01` 与 `01_03`（org 内部接口）；`02_05` 依赖 `01_02`（用户令牌密钥体系）；`02_06` 依赖 `02_01`；`02_03` / `02_04` 依赖 `02_01`。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_认证与安全.md)（本节不写排期）。
- **风险**：协议适配不得绕开统一 `BaseIdentityProvider` 框架（否则 JIT 与会话链路分裂）；企微 / 钉钉真实凭据不可得导致联调延后（按拍板口径以单测 + 遗留登记）；BMS 兼作 IdP 与开放接口（阶段十）存在边界重叠（本期只交内核 + `sys_client` 最小接口，页面 / 审计归阶段十）。
