## 2. 任务内容 <a id="content"></a>

1. **两适配实现**：企业微信 / 钉钉各按 `BaseIdentityProvider` 契约实现（授权跳转 / 换取用户身份 / 用户信息解析），复用 SSO 登录链路与 JIT 建号。
2. **PC 扫码形态**：支持两平台扫码登录（`snsapi_login`）；前端轮询与换取会话由域 05_04 对接，接口契约先行冻结。
3. **配置与校验**：企业应用凭据（`corp_id` / `agent_id` / `app_secret` 等）经 `sys_identity_provider` 配置与连通性测试（域 02_06）；凭据缺失时入口不可用并明确提示。
4. **联调口径**：交付适配与单元测试；**企业真实凭据联调与移动端内嵌 H5 免登留阶段十七**（凭据就绪可提前真跑）。
5. **用例**：授权成功 / 凭据缺失 / 用户未授权 / 状态失效分支；适配登记进身份源插件族。

## 3. 完成标准 <a id="accept"></a>

两类免登适配可用且登记进插件族；配置齐备时完成一次 PC 扫码登录 E2E，未齐备以测试夹具 / 单测覆盖并登记遗留；失败分支错误语义明确；`pytest`、`pyright`、`ruff` 通过。
