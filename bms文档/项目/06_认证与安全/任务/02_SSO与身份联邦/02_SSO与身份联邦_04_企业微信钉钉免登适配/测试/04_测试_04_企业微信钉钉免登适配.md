## 5. 端到端证据 <a id="e2e"></a>

- **企业微信端点 E2E（ASGI + Mock 企微）**：`test_wecom.py::test_wecom_authorize_url_and_302_and_end_to_end` —— `authorize-url` 返回授权 URL（含 `appid=corp-1` / `agentid=agent-1` / `state`）与有效期；`authorize` 302 至 `login.work.weixin.qq.com`；回调 `?state=&code=` 经 `gettoken` + `getuserinfo` 取 `userid` → JIT 自动建号 → 平台库写入 `sys_user_identity`（`idp_key=demo:wecom`、`external_id=wecom-alice`）→ `identity.user.jit_created` 入发件箱。
- **钉钉端点 E2E（ASGI + Mock 钉钉）**：`test_dingtalk.py::test_dingtalk_authorize_url_and_end_to_end` —— `providers` 含 `type=dingtalk`；`authorize-url` 返回含 `client_id=client-1` 的授权 URL；回调经 `userAccessToken` + `contact/users/me` 取 `unionId` → JIT 建号 → 映射写入（`external_id=dingtalk-union`）→ 事件入队。
- **失败分支**：`test_wecom_failure_branches`（20057 / 20059 / 20058 / 20054）、`test_wecom_config_missing_returns_20057`、`test_dingtalk_failure_branches`（20061 / 20062 / 20062 / 20054）。
- **令牌缓存**：`test_wecom.py::test_exchange_token_member_and_non_member_with_token_cache` 断言二次换取复用应用令牌（`gettoken` 只调一次）。

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：
  1. 企微 / 钉钉为增量适配，不改 `BaseIdentityProvider` 契约（企微经 `token.identity`、钉钉经 `userinfo` 回填）——设计已定，实现一致。
  2. 授权 URL 端点以独立路径 `authorize-url` 落地（用户拍板），响应契约 `SsoAuthorizeInfo` 与设计 §3.5 一致。
- **遗留**：
  1. 企微 / 钉钉真实企业凭据联调与移动端内嵌 H5 免登（**归口：阶段十七**，凭据就绪可提前）。
  2. 企微 / 钉钉行配置管理面校验与连通性测试（**归口：02_06**）。
  3. 登录页入口与扫码前端轮询 / 换取会话（**归口：域五 `05_01` / `05_04`**）。
  4. 前端 i18n 补 `error.20057`~`error.20062` 文案（**归口：域五 / 域六**）。
  5. 企微敏感信息 / 钉钉旧版兼容 / 企微令牌跨实例缓存（**归口：后续任务，计划 §7 第 16 项**）。
  6. 登录失败日志 / `sys_login_log`（**归口：阶段八**）。
