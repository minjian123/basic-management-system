## 5. 端到端证据 <a id="e2e"></a>

- **JIT 端点 E2E（ASGI + Mock IdP）**：`test_jit.py::test_jit_endpoint_end_to_end` —— 首登经完整回调（授权 → 换码 → ID Token 验签 / nonce）自动建号（org 替身分配主键）→ 平台库写入 `sys_user_identity`（`idp_key=demo:keycloak`、`external_id=sub-1`）→ `identity.user.jit_created` 入发件箱（一次）；二次登录命中映射复用（映射仍一行、事件仍一条）。
- **事件同事务与契约**：`test_provision_creates_user_mapping_and_event` —— 真实 SQLite 平台库 + `SqlOutboxStore(contract_mode="enforce")`：映射行与 `sys_outbox` 行同事务提交，`event_version=1.0.0`、`payload={user_id, idp_key}`；`resolve_event_contract("identity.user.jit_created")` 非空。
- **并发 / 重复**：`test_provision_reuses_existing_mapping`（锁内二次查复用）、`test_provision_mapping_integrity_conflict`（唯一冲突回读复用 / 回读未命中 20055）、`test_provision_lock_conflict_and_org_unavailable`（锁未取到 20055）。
- **白名单与建号规则**：`test_provision_disabled_and_whitelist`（开关关闭 / 租户白名单 / 域名白名单 / 缺邮箱）、`test_provision_username_suffix_and_exhaustion`（`_2.._5` 与用尽 20054）。
- **绑定查看**：`test_bind.py`（命中 / 空 / 401）。

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：
  1. 详细设计 §5 用例 6（helper 分支）落点为 `test_jit.py::test_helpers_username_and_config`（原拟 `test_units.py`）；已回写设计 §9。
  2. 全量套件以 `-p no:logging` 运行时报 `services/file/tests/storage/test_storage.py::test_minio_secret_not_leaked` 缺少 `caplog` 夹具（该参数停用 logging 插件所致）；去该参数单跑即通过，属运行参数副作用、非代码失败。
- **遗留**：
  1. Redis 降级下极端孤儿用户（**归口：运维对账 / 清理**）。
  2. `sso:bind` 真实权限与本人 / 超管判定（**归口：阶段七**）。
  3. `identity.user.jit_created` 内建消费方 / Webhook（**归口：阶段八 / 十**）。
  4. JIT 操作日志与 `sys_login_log`（**归口：阶段八**）。
  5. `02_06` 行配置新增键管理面校验（**归口：02_06**）。
