> **背景（2026-10-04 立项）**：阶段七 `03_01` 排查「启动全套看不到登录界面」时实测确认三处**阻断登录可用性**的缺口——① refresh cookie `Path=/api/v1/auth`（**服务内**路径）与浏览器地址 `/api/identity/v1/auth/*`（网关**外部**路径）不匹配 ⇒ cookie 从不回传、硬刷新必回登录页（[计划 §7 第 50 项](../../../计划/01_计划_认证与安全.md#followup)）；② `ModuleBoundary` 包在 `router-view` 外层且错误态全局单例 ⇒ 模块产物服务未起时**免登录的 `/login` 也被错误页顶掉**；③ `ops/` 从未建过用户、JIT 建号落占位口令 ⇒ **没有任何可用账号**（[计划 §7 第 34 项](../../../计划/01_计划_认证与安全.md#followup) 亦因此改归口）。本任务把这三处打通，并一并修 [计划 §7 第 29 项](../../../计划/01_计划_认证与安全.md#followup)（守卫关闭时会话就绪无人触发 → 停骨架屏）。

## 2. 任务内容 <a id="content"></a>

1. **refresh cookie 路径对齐浏览器可见路径**：`REFRESH_COOKIE_PATH` 由 `/api/v1/auth` 改为 **`"/"`**——浏览器按 `Path` 前缀匹配回传，`/` 与外部路径形态（网关 shape / 部署形态）解耦、dev 与生产同形；`HttpOnly` / `Secure` / `SameSite=Lax` 口径**不变**。范围含 SSO 回调（`api/sso.py` 复用同一下发函数）。
2. **登出双 Path 清理（迁移兼容）**：`clear_refresh_cookie` 按新路径（`/`）与历史路径（`/api/v1/auth`）**各下发一次删除**；既有接口签名与调用点不变。
3. **首个可用账号种子 `ops/seed_user.py`**：在目标租户的 **org 租户库**建 / 重置账号——口令经 `Pbkdf2PasswordHasher`（`[password_hasher]` 插件口径）生成自描述串，置 `status=enabled` / `pwd_changed_at` / `pwd_reset_required=False`；`--reset-password` 重置既有账号口令并清零 `failed_count` / `locked_until`；`--dry-run` 只打印计划（连接串脱敏）；幂等（重复执行新增为 0）；标准输出打印「新增 / 重置 / 跳过」行数与**一次性明文口令**（不落库、不落日志）。
4. **模块错误态作用域收敛**：模块加载失败（`module/host.ts` 记录，含 `modules.json` 清单失败）只阻断**归属该失败模块**的路由；`/login`、`/403`、`/404`、`/500`（`DEFAULT_PUBLIC_PATHS`）与平台自身路由**不受影响**；**当前路由自身渲染失败**（`onErrorCaptured`）仍渲染错误页并支持重试。
5. **守卫未装配时的会话就绪兜底**：`installAuthGuard` 在守卫关闭（`VITE_AUTH_GUARD=off`）时**仍触发一次会话就绪**（`ensureSession`），避免 `session.ready` 恒假导致应用停在骨架屏。
6. **真机浏览器端到端回归**：远端开发环境（网关 `192.168.0.107:8088`、租户 `demo`）用 `ops/seed_user.py` 建号后，真实浏览器跑「登录 → 硬刷新（静默续期、不跳登录页）→ `remember_me=true` / 缺省两分支 → 登出（两 Path cookie 清空）」并留证。
7. **文档口径回写**：`01_03` / `02_01` / `02_03` 与 `05_01` / `05_05` 设计 / 任务文档中的 `Path=/api/v1/auth` 表述校正为 `/`；部署说明（若含 cookie 口径）同步；HTTP 契约不变（**契约版本不升**、oasdiff 基线不动）。
8. **用例与门禁**：后端覆盖「登录 / 刷新 / SSO 回调下发 `Path=/`」「登出双 Path 清理」；前端覆盖「模块加载失败不顶免登录页 / 平台路由」「守卫关闭触发会话就绪、不卡骨架屏」；`ops/seed_user.py` 幂等用例；定向 `pytest` / `vitest` / `vue-tsc` / `eslint` / `ruff` / `pyright` / 基座校验全绿。

## 3. 完成标准 <a id="accept"></a>

真实浏览器「登录 → 硬刷新 → **不跳登录页**（静默续期 200）」；`remember_me` 两分支的 `Max-Age`（14 天 / 会话级）与续期行为符合 [05-5](../../../需求/05_需求_登录前端.md#r05-5) 口径；登出后浏览器**两个 Path 的 cookie 均被清除**；模块产物服务（5002）未起时 `/login` 仍渲染登录表单；`VITE_AUTH_GUARD=off` 时不卡骨架屏；远端开发环境用 `ops/seed_user.py` 建出的账号可正常登录；后端 `pytest` / `ruff` / `pyright`、前端 `vitest` / `vue-tsc` / `eslint`、契约与基座门禁全绿；[计划 §7 第 50 / 34 / 29 项](../../../计划/01_计划_认证与安全.md#followup) 三处遗留一并闭环。
