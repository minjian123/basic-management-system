## 2. 关键实现口径 <a id="impl"></a>

1. **cookie 作用域**：`REFRESH_COOKIE_PATH = "/"`——浏览器按 `Path` 前缀匹配回传，服务内 `/api/v1/auth` 与前端外部地址 `/api/identity/v1/auth/*` 不匹配 ⇒ 恒不回传；改 `/` 后与网关 shape / 部署形态解耦、dev 与生产同形（`HttpOnly` / `Secure` / `SameSite=Lax` 不变）；SSO 回调复用同一下发函数自动覆盖。
2. **登出双 Path 清理**：`REFRESH_COOKIE_LEGACY_PATHS = ("/api/v1/auth",)`，`clear_refresh_cookie` 对「当前路径 + 历史路径」各 `delete_cookie` 一次（浏览器按 `Path` 隔离 cookie，只删当前路径清不掉历史残留）。
3. **模块错误态作用域**（`blocksModuleFailure`）：失败态只阻断「归属该失败模块」的路由；`DEFAULT_PUBLIC_PATHS`（`/login` / `/403` / `/404` / `/500`）与平台自身路由**永不受影响**；`modules.json` 清单失败不阻断宿主页面；**当前路由自身渲染失败**仍渲染错误页并支持重试（`renderFailed` 本地标记，`retry()` 复位）。
4. **守卫关闭兜底**：`installAuthGuard` 关闭分支仍 `void deps.ensureSession()`（不注册钩子、不阻塞、失败静默），使 `session.ready` 落定、应用不停在骨架屏。
5. **建号脚本**：库定位与 `ops/init_tenant.py` 同源（注册库对照表 → `tenant_org_{db_basis}` → `url_template`）；写 `sys_user`（`Pbkdf2PasswordHasher` 自描述哈希 + `status=enabled` / `pwd_changed_at` / `pwd_reset_required=False`）；`--reset-password` 重置哈希并清 `failed_count` / `locked_until`（**不改账号状态**）；口令明文不落库、不落日志、仅一次性打印。
