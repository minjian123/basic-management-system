## 1. 设计目标与范围 <a id="goal"></a>

在 01_03 已交付的会话载体（`sys_session` 表 / 模型 / 迁移、Redis 会话标记 `bms:{租户}:sess:{会话 id}`、`BaseSessionStore` 黑名单方法、登录 / 刷新 / 登出链路）之上，落**会话管理接口与强制踢出治理**：

1. **在线会话列表 / 详情**——按用户 / 设备 / IP / 登录时间区间筛选 + 分页；列表只展示「未撤销且未过期」会话，详情返回任意记录（含已撤销，展示 `revoked_at`）；
2. **强制踢出**——删 Redis 标记 + 吊销 refresh（黑名单）+ `revoked_at` 落库 + `session.revoked` 广播占位；HTTP 侧下一请求即拦截（即时生效）；
3. **多端会话上限**——并发登录允许，活跃上限默认 5（`[session].max_active` 可配），登录成功后超限自动作废最旧会话；
4. **统一撤销原语**——抽取「撤销会话」（黑名单 + 落库 + 删标记 + 广播占位）单一出口，登出与踢出共用，保证三路径清理一致；
5. **错误码与审计**——新增会话错误码 `20011` / `20012` / `20013`（`20014` / `20015` / `20016` 登记不判定）；踢出动作结构化日志留痕、操作日志归阶段八；`session:query` / `session:kick` 权限码占位（RBAC 前平台超管口径）。

**不在本期**：`require_auth` 真实登录态与每请求会话标记校验、租户解析接线（`01_05`）；会话管理页面（阶段十五）；操作日志落库（阶段八）；`session.revoked` 真实 Socket.IO 推送（阶段八）；按用户批量撤销接口（归 `03_06` 复用统一撤销原语循环调用）；三型账号锁定与解锁（域三 `03_07`）。

**安全影响（SDL）**：涉及会话治理与强制失效。专项验收点：踢出后下一请求即 401 且不静默续期、refresh 不可用；跨租户不可见（租户库天然隔离）；结构化日志不落 refresh 原始值；权限码占位统一（RBAC 就绪自动收口）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 会话管理端点 <a id="endpoints"></a>

落 **identity 服务**新增 `sessions` 模块路由，内部路径 `/api/v1/sessions`（经网关暴露为 `/api/identity/v1/sessions`）；模块级依赖 `Depends(require_auth)`，各端点再挂 `Depends(require_permission("session:query" | "session:kick"))`（permission 基座当前 Null 恒定通过 = RBAC 前平台超管口径）。

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/sessions` | `session:query` | 在线会话列表（仅未撤销未过期；分页 + 筛选） |
| GET | `/api/v1/sessions/{session_id}` | `session:query` | 会话详情（任意记录，含已撤销） |
| POST | `/api/v1/sessions/{session_id}/kick` | `session:kick` | 强制踢出（即时生效） |

**列表查询参数**：`page` / `size` / `order_by` / `order`（经 `page_query` 统一绑定）+ `user_id`（精确）+ `device`（模糊）+ `ip`（模糊）+ `login_from` / `login_to`（登录时间闭区间，UTC）。

**列表响应**：`{code, message, data: {list, total, page, size}}`，`SessionItem` 字段：

```json
{ "session_id": "1800...", "user_id": 1001, "device": "Mozilla/5.0 ...", "ip": "10.0.0.1",
  "login_at": "2026-09-29T02:00:00", "expires_at": "2026-10-13T02:00:00", "revoked_at": null }
```

**详情响应**：同 `SessionItem`（已撤销会话 `revoked_at` 非空）；`session_id` 不存在 → `SessionNotFoundError`（20011 / 404）。

**踢出响应**：`{ "session_id": "1800...", "revoked_at": "2026-09-29T02:10:00", "reason": "kick" }`。

### 3.2 撤销原语与三路径一致性 <a id="revoke"></a>

新增 `bms_identity/services/session.py::SessionService`（`BaseObject`），承载：

- **`revoke(session_id, *, tenant, reason, broadcast) -> SessionRevokeResult`**（统一撤销原语，**不抛**）：
  1. 取记录；不存在 → `found=False`（不写）；
  2. 已 `revoked_at` → `already_revoked=True`（不重复写）；
  3. 新建撤销：工作单元内 `revoked_at=now` 落库 → refresh `jti` 入黑名单（TTL = refresh 剩余生命周期）→ 删 Redis 会话标记 →（`broadcast=True`）`BaseRealtimePublisher.emit(RealtimeEvent(event="session.revoked", session_id=..., data={...}))`。
- **`enforce_max_active(user_id, *, tenant, max_active) -> list[str]`**：取该用户未撤销未过期会话（按 `login_at` 升序），需要腾位 `len - max_active + 1` 个（仅当 `len >= max_active`）→ 逐个经统一原语撤销（`reason="max_active"`，`broadcast=True`）→ 返回被作废会话 id。
- **`list_sessions(...)` / `detail(session_id)` / `kick(session_id, *, tenant, actor)`**：管理接口编排；`kick` 语义见 3.4。

| 路径 | 触发方 | 原语调用（reason / broadcast） | 结果 |
| --- | --- | --- | --- |
| 登出 | `LoginService.logout`（改） | `revoke(..., reason="logout", broadcast=False)`，尽力而为吞异常 | 黑名单 + `revoked_at` + 删标记（与 01_03 行为等价） |
| 踢出 | `SessionService.kick` | `revoke(..., reason="kick", broadcast=True)` | 同上 + 广播占位 + 结构化日志 |
| 超限 | `SessionService.enforce_max_active`（登录调用） | `revoke(..., reason="max_active", broadcast=True)` | 同上（最旧会话） |
| 过期 | 自然过期（不主动清理） | —（Redis TTL 自然到期；列表按 `expires_at` 判定非活跃） | 详情可见、列表不展示 |

- **原语复用**：登出与踢出共用 `revoke`，三路径清理字段与顺序一致；`LoginService.logout` 保持「尽力而为 + 幂等」外语义（原语异常时告警不回滚）。
- **顺序**：先落库（`revoked_at`）再黑名单 / 删标记，符合《概要 14》「Redis 异常时优先保证落库，标记 TTL 到期自然失效」降级口径。

### 3.3 多端上限 <a id="limit"></a>

- **配置**：`[session].max_active`（`SessionSettings`，默认 5；环境变量 `BMS_SESSION__MAX_ACTIVE`）；租户级 `sys_config` 覆盖归后续阶段（沿用 `[login]` 同口径）。
- **判定时机**：登录凭据校验通过、签发双 token 之后、写入新会话记录之前，调 `enforce_max_active(user_id, tenant, max_active)`。
- **作废口径**：`len(active) >= max_active` 时作废最旧 `len - max_active + 1` 个（保证新建后恰为上限）；`Active` = `revoked_at IS NULL AND expires_at > now`；排序按 `login_at ASC`（同值兜底 `id ASC`）。
- **被作废会话**：refresh 入黑名单 + Redis 标记删除 → 被踢端下一请求 401、refresh 不可用（不等自然过期）。

### 3.4 踢出语义与错误分支 <a id="kick"></a>

| 场景 | 行为 |
| --- | --- |
| 会话不存在 | `SessionNotFoundError`（20011 / 404） |
| 会话已撤销（重复踢出） | `SessionRevokedError`（20013 / 200 业务失败），**幂等**，不重复写 |
| 会话已过期（`revoked_at` 为空但 `expires_at <= now`） | 尽力清理（黑名单 + 删标记）后 `SessionExpiredError`（20012 / 200 业务失败） |
| 会话有效 | 统一撤销原语 → 成功，返回 `revoked_at` |
| 跨租户会话 | 租户库天然隔离，按 `session_id` 查询即不存在 → 20011（`20016` 码位登记，不单独判定） |
| 踢出自身当前会话 | 平台超管口径允许；前端跳登录页归阶段十五（`20014` 码位登记，不判定） |
| Redis 删除 / 黑名单失败 | 落库为主，尽力而为 + 告警；广播不回滚踢出 |

- **操作者**：从请求上下文 `current_user_id` 尽力取（01_05 接真实登录态前多为 None，记 `system`）；结构化日志记 `action=session.kick` / 目标会话 / 操作者 / 结果 / 租户，**不落 refresh 原始值**。
- **广播载荷**：`RealtimeEvent(event="session.revoked", session_id=..., data={"session_id", "user_id", "reason", "revoked_at"})`；`NullRealtimePublisher` 空操作，阶段八接真实 Socket.IO 零改动。

### 3.5 错误码口径 <a id="errors"></a>

| 码位 | 含义 | 类型 / HTTP | 本期 |
| --- | --- | --- | --- |
| `20011` | 会话不存在 | `SessionNotFoundError` / 404 | 实现 |
| `20012` | 会话已失效（已过期 / 已登出） | `SessionExpiredError` / 200 业务 | 实现 |
| `20013` | 会话已撤销（重复踢出） | `SessionRevokedError` / 200 业务 | 实现 |
| `20014` | 拒绝操作当前会话 | — | 登记不判定（RBAC 阶段） |
| `20015` | 活跃会话数达上限 | — | 登记（登录链路提示，本期不返） |
| `20016` | 无权操作该会话 | — | 登记不判定（租户库隔离兜底） |

- 新增 `SessionError(AuthError)` 子段基类，子类构造预置码位与 HTTP；`ErrorCode` 常量一并登记。
- 回写《架构设计 · 接口与集成》「平台已发布码位」与《概要 14》§7（已由 01_03 后移至 `20011~20016`，本期落地前三项）。

### 3.7 失败分支与降级 <a id="failures"></a>

| 场景 | 行为 |
| --- | --- |
| 列表 / 详情无租户上下文 | 依赖 `get_tenant`；缺失时租户中间件已拦（与既有端点同口径） |
| 列表筛选无命中 | 200，`list=[]`、`total=0` |
| 详情 / 踢出会话不存在 | 20011 / 404 |
| 踢出已撤销 / 已过期 | 20013 / 20012（200 业务失败，前端提示） |
| 踢出时 Redis 不可用 | 落库优先，标记 TTL 自然失效 + 告警；接口按成功返回 |
| 多端上限作废时 Redis 失败 | 同上；新会话正常建立（作废尽力而为） |
| 达梦 / 三库方言 | 仅查询与 `revoked_at` 更新，走 ORM 参数化，零方言差异；无新表无迁移 |

## 4. 兼容性与消费方影响 <a id="compat"></a>

- **新增**：`SessionSettings` / `[session]` 配置、`SessionError` 及三子类、`SessionService` / `SessionRevokeResult`、`/api/v1/sessions` 三端点、identity 契约快照与前端类型。
- **重构（语义不变）**：`LoginService.logout` 改为复用统一撤销原语（黑名单 + 落库 + 删标记，尽力而为 + 幂等）；`LoginService` 构造新增 `realtime_publisher` 与 `session_settings` 入参（内部编排，非公开契约）。
- **扩展**：`SessionRepository` 增查询方法（只读，不影响既有 `get_by_session_id` / `create_session` / `update_refresh_hash` / `revoke`）。
- **默认值变更（需回归）**：无（`[session]` 为新增段）。
- **不改**：`sys_session` 表结构与迁移、登录 / 刷新 / 登出端点契约与 cookie 口径、`introspect` 与网关生成件、既有 Kiwi 用例号。
- **消费方**：`01_05` 消费会话标记存在性校验（本任务保证标记写入 / 删除口径稳定）；`03_06` 复用统一撤销原语做「重置密码失效全部会话」；阶段十五消费本三端点。

## 7. 边界与开放项 <a id="boundary"></a>

- **归 01_05**：`require_auth` 真实登录态与每请求会话标记校验、租户解析接线；本任务路由已挂 `require_auth` 依赖，01_05 真实化后自动生效。
- **归 03_06**：重置密码后失效该用户全部会话——复用 `SessionService.revoke` 循环；本期不提供批量接口。
- **归阶段七 RBAC**：`session:query` / `session:kick` 权限码真实判定、`20014` / `20016` 越权判定；本期 permission 基座 Null（恒定通过）即平台超管口径。
- **归阶段八**：操作日志落库（踢出动作）、`session.revoked` 真实 Socket.IO 广播（本期 `BaseRealtimePublisher` 占位）。
- **归阶段十五**：会话管理页面（列表 / 详情 / 踢出二次确认 / 踢自己跳登录）。
- **开放项（登录响应上限提示）**：`20015` 登录链路提示本期不返（登录成功即已作废最旧，前端列表可见），随域三 / 前端联调评估。
- **开放项（真机冒烟）**：沿用 01_03 口径——本期以 ASGI 端到端 + 单元 / 服务层用例覆盖，真机容器冒烟归 01_05 / 部署窗口（重建 identity / org 镜像 + 服务 JWT 密钥 + `sys_user` 种子）。
- **开放项（`sys_config` 覆盖）**：租户级 `max_active` 覆盖当前取 `[session]` 平台默认；`sys_config` 真实接入归后续阶段，届时仅改配置读取源、不动判定逻辑。
