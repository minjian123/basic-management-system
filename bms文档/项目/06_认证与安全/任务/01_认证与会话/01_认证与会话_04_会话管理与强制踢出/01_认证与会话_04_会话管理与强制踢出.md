## 2. 任务内容 <a id="content"></a>

1. **会话记录落库**：`sys_session` 表文件先设计后落库（`refresh_token_hash` / 设备 / IP / `login_at` / `expires_at` / `revoked_at`），迁移与表归属登记齐备（租户库）。
2. **Redis 会话标记**：`bms:{tenant}:sess:{session_id}`（TTL 与 refresh 对齐）；每请求校验链（验签 → 类型 → 会话标记 →（可选）设备 / IP 一致性）接入统一校验路径，每请求一次 Redis 读。
3. **强制踢出**：删 Redis 标记 + 吊销 refresh（黑名单）+ `revoked_at` 落库，HTTP 下一请求即拦截（即时生效）；踢出动作审计留痕（结构化日志 + 操作日志占位）；`session.revoked` 广播经 `BaseRealtimePublisher` 占位接口（阶段八接真实 Socket.IO）。
4. **多端会话**：并发登录允许，活跃会话上限默认 5（`sys_config` 可配），超限自动作废最旧会话。
5. **会话接口**：在线会话列表 / 详情 / 强制踢出（`session:query` / `session:kick` 权限码占位，RBAC 就绪前平台超管口径）；会话管理页面归阶段十五（本期只交接口与证据）。
6. **清理一致性**：登出 / 过期 / 踢出三路径的会话记录与 Redis 标记清理一致；`revoked` 状态可查询。

## 3. 完成标准 <a id="accept"></a>

踢出后目标会话下一请求即 401、refresh 不可用（不等 access 自然过期）；多端上限生效（第 6 次登录作废最旧会话）；三路径清理一致；`sys_session` 表文件 ↔ 登记 ↔ 迁移零漂移；用例覆盖踢出即时性 / 上限 / 幂等分支并登记 Kiwi。
