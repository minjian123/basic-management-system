## 4. 端到端证据（ASGI） <a id="e2e"></a>

- **登录 → 刷新 → 登出**：`test_login_success_creates_session`（登录成功、cookie 下发、`sys_session` + Redis 标记写入）→ `test_refresh_rotates_and_rejects_replay`（同会话 id 轮换、旧票据重放 401）→ `test_logout_revokes_and_is_idempotent`（黑名单 + 标记删除 + 刷新失效 + 幂等 200）。
- **错误分支**：错密 / 不存在 → `20002`；锁定 → `20003`；停用 → `20004`；验证码 → `20101`；限流 → `10005`；org 不可达 → 服务不可用（fail-closed）。
- **内部接口鉴权**：`test_internal_endpoint_requires_identity_service` —— `sub=identity` 服务票据放行；`sub=gateway` / 无票据 / 无效票据一律 `401`。
- **真机冒烟**：本机 mjbk 容器为 01_03 之前镜像，真机端到端冒烟需重建 identity / org 镜像并注入服务 JWT 密钥与 `sys_user` 种子，登记为遗留（归口 01_04 / 01_05 或部署窗口，见实施记录 §6）。
