## 1. 设计目标与范围 <a id="goal"></a>

把 `bms_core` 安全原语从**结构占位**落为**插件化真实实现**，并把 `[security]` 配置一次定稿：

1. **口令哈希（PBKDF2-HMAC-SHA256）**——自描述哈希串、常量时间比对、参数升级重哈希判定；
2. **令牌编解码（JWT）**——复用 `oauth/keys.py` 密钥工具（`TokenKey` / `build_jwks` / `to_key_set`），RS256 / ES256 白名单、多密钥并行轮换（`kid` 选择）；
3. **会话安全**——雪花会话 id（与 `sys_session.id` 同值）、HMAC 会话指纹、Refresh 黑名单键；
4. **插件化装配**——三个能力域（`password_hasher` / `token_codec` / `session_security`）各一插件键，工厂装配进统一插件注册表，`get_*` 提供者供依赖注入；Null 实现 **fail-closed**；
5. **配置定稿**——`[security]`（secret_key / access 30 分钟 / refresh 14 天 / keys / active_kid）与三个插件选择段；`config.{dev,test,prod}.toml`、`deploy/.env.example` 同步。

**不在本期**：令牌签发 / 刷新 / 登出流程（`01_02` / `01_03`）、会话记录与踢出（`01_04`）、登录态依赖（`01_05`）、生产密钥分发与 K8s Secret（运维阶段）；本任务只交原语与装配，不产生业务端点。

**安全影响（SDL）**：涉及口令存储、令牌签名与会话标识三类高风险原语——专项验收点：口令不可逆且常量时间比对、签名算法仅非对称白名单、密钥不入库 / 不入镜像 / 不落日志、Null 实现 fail-closed（配置缺失不误放行）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 能力域与插件键 <a id="domains"></a>

| 能力域（插件键） | 插件基类 | 真实实现（`plugin_name`） | Null 实现 | 契约版本 |
| --- | --- | --- | --- | --- |
| `password_hasher` | `BasePasswordHasher` | `Pbkdf2PasswordHasher`（`pbkdf2`） | `NullPasswordHasher` | `0.1.0` |
| `token_codec` | `BaseTokenCodec` | `JwtTokenCodec`（`jwt`） | `NullTokenCodec` | `0.1.0` |
| `session_security` | `BaseSessionSecurity` | `DefaultSessionSecurity`（`default`） | `NullSessionSecurity` | `0.1.0` |

继承链（固定前三段 + 域中间层）：`BaseObject` → `BaseCapability` → `BasePluggable` → **`BaseSecurity`（域中间层，`key` / 插件的公共密钥与算法约定）** → `BasePasswordHasher` / `BaseTokenCodec` / `BaseSessionSecurity`（插件基类，各带 `plugin_key`）→ 真实 / Null 实现。

### 3.2 插件基类签名 <a id="bases"></a>

```python
class BaseSecurity(BasePluggable, ABC):
    """安全域中间层：统一密钥只走环境变量、算法白名单、脱敏约定。"""

class BasePasswordHasher(BaseSecurity, ABC):
    key: str = "password_hasher"
    plugin_key: str = "password_hasher"

    @abstractmethod
    def hash(self, password: str) -> str: ...
    @abstractmethod
    def verify(self, password: str, hashed: str) -> bool: ...
    @abstractmethod
    def needs_rehash(self, hashed: str) -> bool: ...

class BaseTokenCodec(BaseSecurity, ABC):
    key: str = "token_codec"
    plugin_key: str = "token_codec"

    @abstractmethod
    def encode(self, claims: dict[str, object], *, expires_in: int | None = None) -> str: ...
    @abstractmethod
    def decode(self, token: str) -> dict[str, object]: ...

class BaseSessionSecurity(BaseSecurity, ABC):
    key: str = "session_security"
    plugin_key: str = "session_security"

    @abstractmethod
    def new_session_id(self) -> str: ...
    @abstractmethod
    def fingerprint(self, *, ip: str | None, user_agent: str | None) -> str: ...
    @abstractmethod
    def blacklist_key(self, session_id: str) -> str: ...
```

提供者（依赖注入，应用级单例）：`get_password_hasher(request)` / `get_token_codec(request)` / `get_session_security(request)` → `resolve_plugin("<键>", settings.<段>.provider, expected_version=<基类>.contract_version)`；公共依赖经 `app/api/deps.py` 统一导出（沿用既有口径）。

### 3.3 真实实现口径 <a id="impl"></a>

**PBKDF2（`security/pbkdf2.py`）**：

- 常量：`PBKDF2_HASH = "sha256"`、`PBKDF2_ITERATIONS = 600_000`、`PBKDF2_SALT_BYTES = 16`、`PBKDF2_KEY_BYTES = 32`、`PBKDF2_PREFIX = "pbkdf2_sha256"`。
- 哈希串（自描述，`$` 分隔；salt / hash 用 base64 标准字母表，不含 `$`）：`pbkdf2_sha256$600000$<salt_b64>$<hash_b64>`。
- `hash`：`secrets.token_bytes(16)` 盐 → `hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, iterations, dklen=32)`。
- `verify`：解析串 → 重算 → `hmac.compare_digest`（常量时间）；串格式非法 / 字段缺失恒 `False`（不抛错，防探测）。
- `needs_rehash`：迭代次数 / 算法 / 盐长与当前口径不一致、或串非法 → `True`；由登录路径（`01_03`）决定重算。
- 迭代次数可配：`[password_hasher].options.iterations`（非敏感，缺省 600000；工厂读入并校验 `>= 100000`）。

**JWT（`security/jwt.py`）**：

- 构造：`JwtTokenCodec(keys: Sequence[TokenKey], active_kid: str)`；密钥复用 `oauth/keys.py` 的 `TokenKey`（算法白名单 RS256 / ES256、公私钥 PEM 校验）与 `to_key_set`（本地验签 KeySet，joserfc 按 `kid` 命中）。
- `encode`：`iat` 恒补当前秒；`expires_in` 非空时补 `exp = iat + expires_in`；用 `active_kid` 对应私钥签名（`joserfc.jwt.encode(payload, key, algorithms=[alg], header={"kid": kid})`）；`aud` / `iss` / `typ` 等由调用方 claims 传入（本任务不绑业务值）。
- `decode`：`joserfc.jwt.decode(token, key_set, algorithms=ALLOWED_ALGORITHMS)`——签名、`exp` 校验；`kid` 未命中 / 签名不符 / 过期 → `AuthError`（20001，认证错误段）；算法非白名单 → `AuthError`（不泄露内部细节）。
- 轮换：多把公钥并行（旧 `kid` 仍可验签）；签发只用 `active_kid`。

**会话安全（`security/session.py`）**：

- `DefaultSessionSecurity(secret_key: str)`：
  - `new_session_id` → `id_generator.next_id()`（`core/id.py` 雪花；与 `sys_session.id`、`jti` 同值，单套 id）；
  - `fingerprint` → `HMAC-SHA256(secret_key, f"{ip or ''}\n{ua or ''}")` hex 小写（不落 ip / ua 原始值；`secret_key` 为空仅 dev 允许，prod 由启动校验拒绝）；
  - `blacklist_key` → `bms:global:token:blacklist:{session_id}`（global 域、全小写冒号分隔，符合《[命名规范](../../../../../../规范/命名规范.md)》key 口径；租户解析前即可校验）。

**Null（`security/null.py`，fail-closed）**：

| 实现 | 语义 |
| --- | --- |
| `NullPasswordHasher` | `hash` 抛 `ConfigError`（40001）；`verify` 恒 `False`；`needs_rehash` 恒 `True` |
| `NullTokenCodec` | `encode` 抛 `ConfigError`；`decode` 抛 `AuthError`（20001） |
| `NullSessionSecurity` | 三方法均抛 `ConfigError`（未配置真实实现即拒绝） |

### 3.4 配置契约 <a id="config"></a>

| 配置键（`config.toml`） | 环境变量 | 定稿值 / 口径 |
| --- | --- | --- |
| `[security].secret_key` | `BMS_SECURITY__SECRET_KEY` | 通用密钥（会话指纹 HMAC + 生产启动校验）；默认空（dev），prod 必填 |
| `[security].access_token_expire_minutes` | `BMS_SECURITY__ACCESS_TOKEN_EXPIRE_MINUTES` | **30** |
| `[security].refresh_token_expire_days` | `BMS_SECURITY__REFRESH_TOKEN_EXPIRE_DAYS` | **14**（新增） |
| `[security].active_kid` | `BMS_SECURITY__ACTIVE_KID` | 当前签名密钥 `kid`（新增） |
| `[security].keys` | `BMS_SECURITY__KEYS` | `kid → {algorithm, public_key, private_key}` 映射（新增；私钥只走环境变量 / Secret；结构复用 `TokenKeySettings`） |
| `[security].algorithm` | — | **移除**（算法随 `keys.<kid>.algorithm` 自带，消除双来源） |
| `[password_hasher].provider` / `options` | `BMS_PASSWORD_HASHER__…` | 默认 `pbkdf2`；`options.iterations` 缺省 600000 |
| `[token_codec].provider` / `options` | `BMS_TOKEN_CODEC__…` | 默认 `jwt` |
| `[session_security].provider` / `options` | `BMS_SESSION_SECURITY__…` | 默认 `default` |

装配登记（`core/assembly.py`）：`register_plugin("password_hasher", "pbkdf2", Pbkdf2PasswordHasherFactory(settings))`、`register_plugin("token_codec", "jwt", JwtTokenCodecFactory(settings))`、`register_plugin("session_security", "default", DefaultSessionSecurityFactory(settings))`；Null 实现经 `__init_subclass__` 自动登记（零参）。

### 3.5 失败分支与错误语义 <a id="failures"></a>

| 场景 | 行为 |
| --- | --- |
| 哈希串非法 / 盐或摘要损坏 | `verify` → `False`；`needs_rehash` → `True` |
| 迭代次数低于下限（配置） | 工厂 `ConfigError`（40001，拒绝启动装配） |
| `[security].keys` 为空 / `active_kid` 缺失或无私钥 | 工厂 `ConfigError`（40001，显式失败不静默） |
| 令牌算法非 RS256 / ES256 | `TokenKey` 校验 `ConfigError`；验签阶段 `AuthError` |
| 令牌 `kid` 未命中 / 签名不符 / 过期 | `AuthError`（20001；不区分具体原因对外） |
| 提供者未配置（provider 空） | `resolve_plugin` 回落 Null → fail-closed |

## 4. 兼容性与消费方影响 <a id="compat"></a>

- **退役类**：`core/security.py` 的 `PasswordHasher` / `TokenCodec` / `SessionSecurity` 占位类删除，迁为 `security/` 包契约（`Base*` 命名）；消费方仅 `tests/core/test_security.py`（改造）与文档（回写），**零业务消费方**。

- `app/api/deps.py` 增三个提供者导出（供后续任务消费）。
