## 4. 端到端证据（ASGI） <a id="e2e"></a>

- **登录态强制**：`test_protected_route_requires_valid_login` —— 默认测试登录令牌访问 `/api/v1/sessions` 返回 200；无效令牌返回 401 + `20001`。
- **踢出即时性**：`test_kicked_session_rejected_on_next_request` —— 登录建会话 → 踢出（`POST /sessions/{id}/kick`）→ 以该会话 id 签发的 access 下一请求返回 401 + `20012`（不等 access 自然过期）。
- **依赖全分支**：`test_require_auth.py` 覆盖网关身份 / 本地令牌 / 缺令牌 / 无效令牌 / 会话标记未命中 / 缺会话标识 / device_check / 跨租户 / token 租户兜底。
- **身份头传递**：`test_introspect.py` 校验通过回填 `X-Session-Id`；`test_gateway_catalog.py` 生成件剥头与注入含 `X-Session-Id`。
- **真机冒烟**：网关生成件与后端同步发布的真机端到端（`X-Session-Id` 注入 → 每请求标记校验 → 踢出即时 401）归部署窗口，登记为遗留（见实施记录 §6）。

## 5. 偏差与遗留 <a id="deviations"></a>

- **偏差**：测试迁移采用共享夹具自动注入真实签名令牌（`tests_support.auth` + 各服务 `conftest`），并在 bms_core 套件固定进程内首个装配的令牌密钥（见实施记录 §4-1）；用例与详细设计验收映射逐条对应。
- **遗留**：见[实施记录 §6](../实施/01_实施_05_登录态依赖与租户解析接线.md#deviations)（真机端到端冒烟、RBAC 权限判定与 `AuthContext` 消费、操作日志与真实 Socket.IO 广播、`sys_config` 租户级会话覆盖、外部 IdP 主体映射，均登记归口）。
