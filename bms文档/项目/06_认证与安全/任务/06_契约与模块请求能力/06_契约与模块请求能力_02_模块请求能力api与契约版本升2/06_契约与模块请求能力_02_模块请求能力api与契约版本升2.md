## 2. 任务内容 <a id="content"></a>

1. **`api` 能力注入**：`ModuleHostContext` 新增请求能力 `api`（按服务键 + 路径调用，宿主统一注入 token、错误解包与 401 处理）；**token 不注入模块**。
2. **模块禁自建 HTTP**：模块内禁止自建 axios / 裸 `fetch`（隔离扫描护栏扩展该规则）；demo / sample 模块改造为经 `api` 消费。
3. **契约版本升 2**：模块契约版本自增（`MODULE_CONTRACT_VERSION`），版本不匹配模块拒绝加载 / 明确提示；《[架构设计 · 前端模块契约](../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》同步新增请求能力语义。
4. **双模块回归**：demo 与 sample 经 `api` 完成一次登录态真实请求与 401 分支；契约用例工厂覆盖新能力；发布清单与契约版本校验（阶段五 `03_02` 机制）同步。
5. **基类清单回写**：《[前端基类清单](../../../../../前端基类清单.md)》模块上下文与宿主请求层条目更新。
6. **用例**：`api` 请求鉴权透明、401 自动刷新、模块自建 HTTP 被拦（fixture）、版本不匹配拒绝。

## 3. 完成标准 <a id="accept"></a>

模块可经 `api` 完成真实接口请求（鉴权由宿主处理）、401 自动刷新对模块透明；模块自建 HTTP 被护栏拦截；契约版本升 2 后旧模块加载被明确拒绝 / 提示，demo / sample 回归通过；`vue-tsc`、ESLint、Vitest 与契约用例全绿。
