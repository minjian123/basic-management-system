## 4. 实测（真实网关 + 发布存储 + 宿主 dev）

| # | 实测项 | 方式与结论 |
| --- | --- | --- |
| 1 | 真实网关连通与模块所用端点的鉴权语义 | `curl` 实测开发服务器网关：`/healthz` → 200；`/api/identity/v1/auth/me`（模块调用的同一路径）→ **401** —— 确认模块端点经网关的真实鉴权分支存在 |
| 2 | 契约版本升 2 后的模块加载（真实浏览器） | 发布存储 5002 托管归档 + 宿主 dev（`VITE_API_PROXY` 指向开发服务器网关）+ Chrome：宿主菜单出现「演示模块 / 示例模块」、模块页面正常渲染、**无模块加载失败兜底页** → 0.2.0 产物（`contractVersion: 2`）被加载器接受 |
| 3 | 未登录访问受保护模块页的守卫行为 | Chrome 打开 `/demo` → 重定向至 `/login?redirect=/demo`（既有守卫默认开启口径，验证宿主应用在真实链路下正常运行） |
| 4 | 模块降级呈现（真实浏览器） | 样例模块独立预览（5003）打开列表页：`[data-test="sample-host-user"]` 文案为「未接入宿主请求能力（独立预览 / 未接线），已降级。」且列表占位数据正常渲染（10 行）→ **未注入请求能力时不崩、按降级口径呈现** |
| 5 | 401 静默刷新对模块透明 | 宿主集成用例（`apps/desktop/tests/module-api.spec.ts`）在 axios 边界打桩：首次 401 → 宿主单例刷新 → 原请求重放 → **模块侧拿到业务数据**；刷新失败 → 模块收到会话失效并降级 |

**边界（已登记计划 §7 第 34 项）**：模块经 `api` 的**真实后端登录态成功路径**未做浏览器端到端实测——本地资源未记录 BMS 应用账号，未登录直达模块页会被守卫重定向；该路径由第 5 项用例（整链 + 401 透明，仅网络边界打桩）与第 1 项 curl（真实 401）共同覆盖，真实登录态补测归 07_01 阶段验收。
