## 2. 任务内容 <a id="content"></a>

1. **默认开启**：`VITE_AUTH_GUARD` 默认 `on`（移除骨架期「默认关闭」口径）；白名单（登录页 / 错误页 / 公开页）与后端公开路径口径一致。
2. **回跳**：未登录访问受保护路由 → 跳登录并携带 `redirect`；登录成功后回跳原目标（无目标回默认首页）。
3. **与动态路由协同**：登录后按用户上下文装载动态路由（阶段七动态菜单就绪前的占位口径成文）；无权限路由跳 403。
4. **首屏体验**：已登录刷新时静默续期期间不闪登录页（骨架屏 / 等待态）；守卫判定分支纳入既有观测口径。
5. **用例**：拦截与回跳、白名单放行、刷新不闪登录页。

## 3. 完成标准 <a id="accept"></a>

未登录直达受保护路由被拦截并回跳；登录后回跳正确；白名单路由不受拦；刷新不闪登录页；Vitest 与宿主核对页验证通过。
