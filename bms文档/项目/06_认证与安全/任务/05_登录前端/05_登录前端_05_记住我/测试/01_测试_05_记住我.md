## 2. 测试范围与用例 <a id="scope"></a>

范围：本任务新增 / 变更的**受影响因素**——bms_core 配置与令牌签发（按选项 TTL）、identity 登录契约 / 会话表 / 迁移 / 仓储 / 签发 / 刷新 / Cookie / 端点、前端单布尔复选件与登录页勾选接入；以及受影响面的定向回归（identity 认证用例 / bms_core oauth；ui-ep / desktop 用例）。

| # | 用例文件 | 类型 | 断言要点 |
| --- | --- | --- | --- |
| 1 | `backend/libs/bms_core/tests/core/test_config.py` | 单元 | `[security].session_refresh_expire_hours` 缺省 24 |
| 2 | `backend/services/identity/tests/oauth/test_user_token.py` | 单元 | `remember_me=true` / 缺省 → refresh `exp - iat = 14 天`；`false` + `session_refresh_ttl` → 会话级 TTL；未配置会话级 TTL 时回落 14 天 |
| 3 | `backend/services/identity/tests/auth/test_login.py` | 接口 | 缺省：`Set-Cookie` 无 `Max-Age`（会话 Cookie）、`remember_me=False`、`expires_at ≈ now + 24 小时`、Redis 标记 TTL 一致；`remember_me=true`：`Max-Age=1209600`、`remember_me=True`、`expires_at ≈ now + 14 天` |
| 4 | `backend/services/identity/tests/auth/test_refresh.py` | 接口 | 轮换保持选项：记住我仍持久 Cookie + `expires_at` 滚动 14 天；会话级仍会话 Cookie + 滚动 24 小时；会话 id 稳定；历史 `NULL` 行轮换按 14 天 |
| 5 | `frontend/packages/ui-ep/tests/input-boolean-checkbox.spec.ts` | 单元（挂载） | 受控取值与变更事件（归一布尔）；缺省未设置按未勾选渲染；禁用透传；根类名与 `indeterminate` 透传 |
| 6 | `frontend/apps/desktop/tests/login-utils.spec.ts` | 单元 | `buildLoginRequest` 恒含 `remember_me`（缺省 false）、租户缺省归一 `null`、勾选 true 与验证码分支 |
| 7 | `frontend/apps/desktop/tests/login-view.spec.ts` | 单元（挂载） | 勾选项缺省不勾选；勾选后提交载荷 `remember_me=true`、缺省 `false`；表单件复用计数含 `BooleanCheckbox`；密码安全口径（无强度提示） |
| 8 | `frontend/apps/desktop/tests/login-check.spec.ts` | 单元（挂载） | 核对页三组 17 项自检全部通过（含「记住我勾选项」与「表单件复用」） |
| 9 | 契约门禁 | 门禁 | `api-types:gen:check` 零漂移；`contract_snapshot check` 一致；生成类型含 `remember_me` |
| 10 | 三包既有全部用例 | 回归 | identity 275 / bms_core oauth+config+ops 194 / ui-ep 920 / desktop 217 全绿 |

**用例文本（Kiwi 2234）**：覆盖登录契约增可选 `remember_me`（会话级 / 14 天两分支）、Cookie 持久与会话语义、`sys_session.expires_at` 与 Redis TTL 对齐与轮换滚动、Cookie 安全口径不变、前端单布尔复选件与登录页勾选显式提交；自动化文件与 Kiwi 标注方式见用例文本原文。

## 5. 覆盖率 <a id="coverage"></a>

后端 `bms_core` / identity 各模块由包内既有覆盖率口径承接（新增分支：`_effective_refresh_ttl` 两分支、登录 / 刷新两选项分支均由 §2 用例逐分支覆盖）；前端新增 / 变更模块（`BooleanCheckbox.vue` / `utils/login.ts::buildLoginRequest` / `LoginView.vue` 勾选分支）由 ui-ep 与 desktop 用例直接覆盖，宿主三包无全局覆盖率门槛（与既有前端任务同口径）。

## 6. 偏差与遗留 <a id="deviations"></a>

- **未覆盖项**：真实浏览器端到端核验（勾选后刷新页面续期）本轮以接口层 `Set-Cookie` / `expires_at` / Redis TTL 断言 + 组件用例覆盖；真机冒烟归阶段部署窗口。
- **后续接收项**：SSO / 扫码跟随选项（另立任务）、会话列表展示 `remember_me`（阶段十五）、超时无操作退出（后续安全强化）、多标签页同步（阶段十五）、宿主国际化（国际化阶段）。
