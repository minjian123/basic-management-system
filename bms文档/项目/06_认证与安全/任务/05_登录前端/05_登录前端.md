## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段六需求域 05 的 5 条需求——[05-1 登录页真实实现](../../需求/05_需求_登录前端.md#r05-1)、[05-2 token 与 401 静默刷新接线](../../需求/05_需求_登录前端.md#r05-2)、[05-3 路由守卫默认开启与回跳](../../需求/05_需求_登录前端.md#r05-3)、[05-4 扫码登录前端](../../需求/05_需求_登录前端.md#r05-4)、[05-5 记住我（登录保留时长选项）](../../需求/05_需求_登录前端.md#r05-5)，按「1 需求 = 1 子任务」拆 5 个子任务（`05_01` ~ `05_05`）。
- **端范围**：**仅 PC**（`frontend/apps/desktop` + `frontend/packages/*`）；移动端工程尚未建立（阶段十七）。
- **承接口径**：阶段二 `04-1-1` 已交付服务段寻址（`service-endpoint.ts`）、能力源分流（`endpoints.ts`）、请求层（`request` / `token` / `http` 401 钩子）、路由守卫骨架（`resolveAuthRedirect` + 白名单，默认关闭）、登录占位页；阶段四交付验证码件族与二维码件。本域只做**真实业务接线与登录页交付**。
- **公共前置**：域一 `01_03`（登录 / 刷新 / 登出端点）、域二 `02_01` / `02_04`（SSO 与扫码）、域三 `03_04`（验证码四端点真实联通）、域六 `06_01`（契约类型生成，先行）。
- **依据**：《[架构设计 · 前端架构](../../../../设计/架构设计/08_架构设计_前端架构.md)》、《[前端基类清单](../../../../前端基类清单.md)》「宿主横切底座」节、《[安全开发规范](../../../../规范/安全开发规范.md)》「前端密码口径」。
- **执行序**：`05_02 token 与 401 接线` → `05_03 路由守卫` → `05_01 登录页` → `05_04 扫码登录`（见[计划](../../计划/01_计划_认证与安全.md)）。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：`05_02` 依赖域一 `01_03`；`05_03` 依赖 `05_02`；`05_01` 依赖 `05_02` / `05_03`、域三 `03_04`、域六 `06_01`；`05_04` 依赖域二 `02_04` 与 `05_02`；`05_05` 依赖域一 `01_03` 与 `05_01`（后端登录契约扩展 + 登录页勾选项接入）。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_认证与安全.md)。
- **风险**：401 静默刷新与并发重试处理不当会刷新风暴或丢请求（须单例刷新 + 重放用例）；守卫默认开启会影响既有演示页可达性（白名单须与后端公开路径口径一致）；验证码件契约微调（滑块 payload）若不同步会造成渲染失败。
