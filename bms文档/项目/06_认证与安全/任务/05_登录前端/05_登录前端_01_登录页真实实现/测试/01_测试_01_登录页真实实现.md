| # | 问题 | 处置 |

| 1 | 阶段二骨架用例（Kiwi 2191）断言登录占位页文案失败 | 断言改为「登录页可达 + 真实表单要素」，并注明登录页行为由 Kiwi 2232 覆盖（占位页随 05_01 退役） |
| 2 | SSO 授权地址用例偶发带 `?tenant=acme` | `api/tenant.ts` 模块态跨用例残留 → 用例 `beforeEach` 显式 `setTenantCode(null)` 复位 |
| 3 | 首次直接 `mount(LoginView)` 报「no active Pinia」 | 测试与核对页入口统一安装 pinia + router 插件 |
| 4 | 件族文件被默认 Prettier 配置全量重排（噪声） | 按项目风格显式参数重排，diff 收敛为语义改动（详见实施记录 §4 第 4 项） |
| 5 | 短信渠道在登录场景无手机号来源 | 按拍板跳过 `sms`，取首个可渲染渠道；用例锁定该分支 |

| 8 | `bulk-theme-tenant-check` 自检抛 `Maximum recursive updates exceeded in <BrandProvider>`（**先存缺陷**，原版文件复现） | 归口组件库 `components/interaction/BrandProvider.vue`（深监听回调就地改写被监听对象）；本任务登记遗留，不改库内部实现 |

## 6. 偏差与遗留 <a id="deviations"></a>

- **未覆盖项**：SSO 端到端回跳（真实 IdP 授权 → 回调 `302` → 首页静默续期）依赖后端 `[sso].success_redirect` / `failure_redirect` 配置与外部 IdP，本轮以「地址构造 + 入口渲染 + 失败回显」用例覆盖；真实 SSO 联调证据归 `02_01` 真机冒烟与后续联调窗口。
- **未覆盖项**：滑块在登录页的真实拖动提交（件层 `defer` 契约已由件族用例锁定；登录页侧以图形码凭证路径覆盖「凭证随请求提交」等价链路）。
- **后续接收项**：找回 / 重置页面与「忘记密码」入口、改密页面与强制改密流转（阶段十五）；租户品牌资源（品牌化阶段）；扫码登录入口（`05_04`）；记住我（`05-5`）；宿主国际化文案（国际化阶段）。
- **后续接收项（本轮新发现）**：组件库 `BrandProvider` 深监听递归缺陷（`bulk-theme-tenant-check` 核对页自检不可运行）→ 归组件库修复；与登录页无关，登记于此以免遗漏。
