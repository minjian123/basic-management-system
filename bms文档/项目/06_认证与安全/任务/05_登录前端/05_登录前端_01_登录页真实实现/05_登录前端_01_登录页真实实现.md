## 2. 任务内容 <a id="content"></a>

1. **登录表单**：账号 / 密码 / 租户标识（或域名识别）；提交经服务段寻址调用 `/auth/login`；成功后装载用户上下文并进入回跳流程（`05_03`）。
2. **验证码接入**：按场景策略渲染图形 / 滑块 / 短信件（复用阶段四 `06_04` 件族），连续失败达阈值后强制；验证码失败自动刷新与错误提示。
3. **SSO 与扫码入口**：按 `/auth/sso/providers` 渲染 IdP 入口（`02_06` 数据）与扫码登录入口（`05_04`）；入口不可用时隐藏或提示。
4. **错误与状态**：错误码文案映射（账号锁定 / 密码错误 / 验证码失败 / 限流命中 / IdP 故障）；登录中态防重复提交；「记住我」不落 access（仅影响 refresh 选项，口径成文）。
5. **安全口径**：密码框不回填、明文切换仅内存态、不写控制台 / `localStorage` / `sessionStorage`、`autocomplete="new-password"`；强度提示只展示等级与缺失项。
6. **用例与核对**：Vitest 组件用例 + 核对页；`vue-tsc`、ESLint 门禁。

## 3. 完成标准 <a id="accept"></a>

本地账号登录（含三类验证码强制分支）与 SSO 跳转入口均可用；错误码文案与后端契约一致；密码安全口径经用例 / 核对页验证；`vue-tsc`、ESLint、Vitest 全通过。
