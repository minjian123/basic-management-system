## 2. 任务内容 <a id="content"></a>

1. **token 注入**：access 仅存内存（Pinia），请求拦截器统一注入 `Authorization`；刷新页面后首屏静默续期（先 refresh 再放行受保护请求）。
2. **401 静默刷新**：单例刷新（并发 401 共享同一次 `/auth/refresh`），成功后重放原请求；刷新失败清会话并跳登录（带 `redirect`）；**不产生刷新循环**。
3. **登出**：调用 `/auth/logout` 清 refresh cookie 与会话、清内存 token 与用户上下文、跳登录；多标签页口径成文（本期以单标签为准并登记）。
4. **失效提示**：会话被踢出 / 过期时统一提示并跳登录（结合域一踢出即时拦截）。
5. **契约对齐**：refresh 经 `api/identity` 寻址、携带 httpOnly cookie（`withCredentials` 口径），字段与后端契约一致。
6. **用例**：过期自动刷新重放、并发 401 单次刷新、刷新失败跳登录无循环、登出清理。

## 3. 完成标准 <a id="accept"></a>

受保护请求在 access 过期后自动刷新并重放（用户无感）；并发 401 仅一次刷新；刷新失败跳登录且无循环；登出后不再携带旧 token；Vitest 用例全绿。
