## 2. 实施过程 <a id="process"></a>

1. **设计与立项上下文**：`06_03`（响应契约）与 `01_06`（`/auth/me`）先行交付，本任务按其生成类型与端点消费；详细设计定稿提交 `5c8d4b4b`。
2. **Kiwi 登记**：经容器内 Django shell 登记 1 条策展用例，回读用例号 **2230**；脚本临时文件用后即删。
3. **依赖声明与别名**：`apps/desktop/package.json` 增 `@bms/api-types` / `@bms/core` / `@bms/ui-ep`（`workspace:*`，均为宿主实际引用项；**`@bms/vue` 宿主未引用故不声明**）；`tsconfig.app.json` / `vite.config.ts` / `vitest.config.ts` 增 `@bms/api-types` 别名。锁文件经 `还原依赖` → `pnpm install`（更新 `pnpm-lock.yaml`，+195/−29）→ `pnpm install --frozen-lockfile`（校验通过）→ `外置依赖` 复位。
4. **租户编码承载**：新增 `api/tenant.ts`（内存 + `localStorage['bms.tenant']`，惰性恢复、存储不可用时降级为纯内存），供 refresh / logout 注入 `X-Tenant-ID`。
5. **认证端点封装**：新增 `api/identity.ts`（`login` / `refreshAccessToken` / `logout` / `fetchCurrentUser`）——服务段寻址 + **生成类型消费**（`identity.components['schemas'][…]`）；refresh / logout 用核心 `request` 显式发起，不附幂等键。
6. **请求层刷新链**：`api/http.ts` 扩展 —— `HttpHooks` 增 `onRefresh`；模块级单例 `refreshPromise`；401 分支判定「不重试端点 + 是否已重放 + 是否注入处理器」→ 刷新成功则**重放原请求**（配置原样，含 `Idempotency-Key`）→ 否则宿主 `onUnauthorized` + 抛 `SessionExpiredError`；请求拦截器对认证端点置 `withCredentials` 并注入 `X-Tenant-ID`。
7. **会话 store**：`stores/session.ts` 状态增 `user` / `tenant`；`signIn` 改对象载荷；新增 `applyToken` / `bootstrapSession`（首屏静默续期）/ `signOut`（尽力而为登出）/ `clearSession`（同步清内存态）。
8. **宿主装配**：新增 `utils/feedback.ts`（`ElMessage` + 显式样式导入）；`main.ts` 装配 `onRefresh`（刷新 → 写内存令牌 → 复位失效标记）与 `onUnauthorized`（提示 + `clearSession` + 跳登录带 `redirect`，并发只处理一次）。
9. **登记回写**：《前端基类清单》「宿主横切底座」节扩展（认证端点封装 / 租户编码承载 / 会话 store / 宿主提示 / 401 单例刷新与重放 / 凭据口径）；阶段计划表回写。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 | 归口 |
| --- | --- | --- | --- |
| 1 | 401 失效路径若调 `signOut()`（含服务端登出）会与刷新链互递归（登出请求 401 → 再次触发失效处理 → 再登出） | 失效路径改用 **`clearSession()`**（同步、不调服务端）；`signOut()`（含服务端登出）留给用户主动登出（登录页 / 后续布局） | 设计 §3.6 / §8.1 第 13 项同源回写（实施记录登记） |
| 2 | 宿主未引入国际化库（`module/i18n.ts` 已说明归国际化阶段）→「文案走 i18n」无法落地 | 失效提示用**宿主文案常量**（`SESSION_EXPIRED_MESSAGE`）；错误码 → 文案映射归 `05_01` / 国际化阶段 | 设计 §3.6 与 §8.1 第 13 项已登记 |
| 3 | 设计 §3.7 原列「补齐 `@bms/core` / `@bms/vue` / `@bms/ui-ep`」，实测宿主**未引用 `@bms/vue`** | 只声明实际引用项（`@bms/api-types` / `@bms/core` / `@bms/ui-ep`），避免声明未用依赖 | 计划表 05_02 偏差列已登记 |
| 4 | `vue-tsc` 报 `this.request<T>(request, true)` 参数数不符（对象字面量按 `RequestAdapter` 收窄） | 抽出内部 `execute<T>(request, retried)` 函数，返回对象以方法简写调用之 | 本任务内闭环 |
| 5 | 锁文件变更需先还原依赖（安装器遇外置符号链接会误判跳过） | 按《pnpm部署使用说明》口径执行「还原 → 安装 → 冻结校验 → 外置」四步 | 本任务内闭环 |
