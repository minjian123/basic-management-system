## 2. 用例与断言 <a id="cases"></a>

新增用例先登记 Kiwi TCMS 再编码（编号 2220，分类「平台骨架」/ 优先级 P2 / 状态 CONFIRMED / 标签「自动化」）；自动化落点 `libs/bms_core/tests/core/test_tenant_id_naming.py`，代码以 `@pytest.mark.kiwi_id(2220)` 标注。

| # | 用例（Kiwi 2220） | 断言要点 | 结果 |
| --- | --- | --- | --- |
| 1 | 载体字段按值命名 | `TenantContext` / `TenantSnapshot` 有 `code` + `tenant_id`（快照另含 `db_basis`）且**无** `tenant_code`；`AuthContext` / `EdgeIdentity` / `IdpFlowState` 同时含 `tenant_id` + `tenant_code`；`ServiceTokenSpec` / `UserTokenSpec` / `VerifiedToken` / `EventEnvelope` / `OutboxRecord` / `DeadLetterRecord` 只含 `tenant_id`（无 `tenant` / `tenant_code`）；`DbKey.tenant_code` 白名单存在 | 通过 |
| 2 | 事件负载键 | `TENANT_ID_PAYLOAD_KEY == "tenant_id"`；`platform_events` 无 `TENANT_CODE_PAYLOAD_KEY`（属性与 `__all__` 均无） | 通过 |
| 3 | 发件箱 / 死信列类型 | `SysOutbox` / `SysEventDeadLetter` 的 `tenant_id` 列为 `BigInteger`、列名为 `tenant_id` | 通过 |
| 4 | 键空间与助手 | `build_cache_key(tenant=<id>, …)` 形如 `bms:{id}:…`、无主键落 `bms:global:…`；`current_tenant_id_of` 取雪花 id、`current_code_of` 仅取编码（无上下文为 None） | 通过 |
| 5 | 形态判定互斥 | `is_tenant_id("1001")` 真 / `is_tenant_code("1001")` 假；`is_tenant_code("demo")` 真 / `is_tenant_id("demo")` 假 | 通过 |
| 6 | 源码扫描 | `bms_core/src` 与 `services/*/src` 全部 `*.py` 中不出现已退场常量 `TENANT_CODE_PAYLOAD_KEY` | 通过 |

> 覆盖边界：租户事件负载字段 / 版本 / 信封保留键由既有用例（Kiwi 2218）承接；令牌声明值形态由既有用例（Kiwi 2217）承接；服务侧模型（`SysUserIdentity` / `SysTenantDatabase`）列类型由 10_04 全链零漂移门禁与 `check-base` 表文件登记一致性承接——本用例**不重复**断言（设计与实施记录 §4-2 已说明）。

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：
  - 断言的实现收敛（设计 §5.2 已回写，见实施记录 §4-2）：不重复既有用例（2217 / 2218）、不跨包断言服务侧模型列类型；
  - 任务文档 §2.2 兼容窗口表述回写（实施记录 §4-1）；
  - 收口发现存量格式化漂移 1 处（`services/identity/tests/sso/test_jit.py`）并修正。
- **遗留**：
  - `ops/backfill_tenant_id_columns.py` 单测覆盖率 62%（达梦同步分支 / CLI 编排未覆盖）→ 真库路径由 10_04 三库 drill 承接；如需单模块门槛另立测试资产任务（已登记[计划 §3.1 遗留 33](../../../../计划/01_计划_认证与安全.md)）；
  - `sys_user_identity.tenant_id` 库内注释陈旧 → 归并[计划 §3.1 遗留 32](../../../../计划/01_计划_认证与安全.md)（达梦注释变更支持）；
  - 产品仓库跨服务事件消费方前置契约标注 → 消费方实现时补（计划 §3.1 遗留 31）；
  - 未覆盖项：Redis 真实实现的键形态（测试环境关闭，随 CI / 安全专项）；三库集成随 CI main 重验证层。
