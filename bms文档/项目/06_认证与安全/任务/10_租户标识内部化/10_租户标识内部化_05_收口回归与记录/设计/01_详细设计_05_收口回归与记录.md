## 5. 命名一致性复查与自动护栏 <a id="naming"></a>

### 5.1 载体清单（按值判定基线） <a id="naming-table"></a>

| 载体 | 字段 / 键 | 承载值 | 判定 |
| --- | --- | --- | --- |
| 请求上下文 | `TenantContext.code` / `.tenant_id` | 租户自身编码 / 雪花 id | 按值命名（`tenant_id` 必填非空；**不得**有 `tenant_code` 字段） |
| 租户快照 | `TenantSnapshot.code` / `.tenant_id` / `.db_basis` | 编码 / 雪花 id / 库名基 | 按值命名 |
| 登录态契约 | `AuthContext.tenant_id` / `.tenant_code` | 雪花 id / 展示编码 | 按值命名 |
| 边缘身份 | `EdgeIdentity.tenant_code` / `.tenant_id` | 网关注入头编码 / 服务 JWT 雪花 id | 按值命名 |
| 用户令牌 | `UserTokenSpec.tenant_id` | 雪花 id 十进制字符串 | 按值命名（claim 名 `tenant_id`） |
| 服务 JWT | `ServiceTokenSpec.tenant_id` | 雪花 id 十进制字符串 | 按值命名（claim 原 `tenant` 已退场） |
| 事件信封 / 发件箱 / 死信 | `EventEnvelope.tenant_id` / `OutboxRecord.tenant_id` / `DeadLetterRecord.tenant_id` | 雪花 id 十进制字符串 | 按值命名 |
| 事件负载 | 平台事件负载键 `tenant_id`（`TENANT_ID_PAYLOAD_KEY`） | 雪花 id 十进制字符串 | 按值命名（`TENANT_CODE_PAYLOAD_KEY` 退场） |
| IdP 流程状态 | `IdpFlowState.tenant_code` / `.tenant_id` | 校验用编码 / 内部键雪花 id | 按值命名 |
| 请求态 / 上下文变量 | `state["tenant_id"]` / `current_tenant_id` | 雪花 id 字符串 | 按值命名（`current_tenant` 保留为 code 展示） |
| 键空间 | 会话 / 缓存 / 限流 / 幂等 / 锁 / IdP state 键 | 租户位 = 雪花 id | 按值命名 |
| DB 列 | `sys_outbox` / `sys_event_dead_letter` / `sys_user_identity` / `sys_tenant_database` 的 `tenant_id` | BIGINT 雪花 id | 按值命名 |
| 库键对象 | `DbKey.tenant_code` | **库名基 `db_basis`**（运维命名空间） | **白名单**：字段名保持，语义为创建时冻结的租户编码（10_01 §3.1） |

**允许保留 `tenant_code` 的场景（白名单，非误用）**：外部边界（`X-Tenant-ID` 头、子域名、登录体、SSO 回调 `tenant=`）、展示 / 日志、白名单比对（JIT 允许租户清单）、库键对象字段名、租户编码形态校验函数（`is_tenant_code`）。

### 5.2 自动护栏用例设计 <a id="naming-guard"></a>

**落点**：`libs/bms_core/tests/core/test_tenant_id_naming.py`（Kiwi 新编号，见测试记录）。

**断言组**（结构性断言为主，不依赖注释文本，避免脆弱）：

| # | 断言组 | 内容 | 失败含义 |
| --- | --- | --- | --- |
| 1 | 载体字段 | 反射 dataclass 字段：`TenantContext` / `TenantSnapshot` 有 `code` + `tenant_id`（+ `db_basis`）且**无** `tenant_code`；`AuthContext` / `EdgeIdentity` / `IdpFlowState` 有 `tenant_id` + `tenant_code`；`ServiceTokenSpec` / `UserTokenSpec` / `EventEnvelope` / `OutboxRecord` / `DeadLetterRecord` 有 `tenant_id` 且无 `tenant` / `tenant_code`；`DbKey` 有 `tenant_code`（白名单） | 载体字段命名回退 |
| 2 | 令牌 claim | `user_jwt` 构造的声明含 `tenant_id` 且值为雪花 id 字符串；服务 JWT claim 名为 `tenant_id` | 令牌租户位回退 code / 旧 claim 名 |
| 3 | 事件契约 | `TENANT_ID_PAYLOAD_KEY == "tenant_id"`；`platform_events` 无 `TENANT_CODE_PAYLOAD_KEY`；三条租户事件负载含 `tenant_id` 不含 `tenant_code`；版本 `2.0.0`；`RESERVED_PAYLOAD_KEYS` 不含 `tenant_id` | 事件负载键被误留 `tenant_code` / 保留键冲突 |
| 4 | ORM 列 | `SysOutbox` / `SysEventDeadLetter` / `SysUserIdentity` 的 `tenant_id` 为 `BigInteger`；`SysTenantDatabase.tenant_id` 为 `BigInteger`、`db_basis` 为 `String` | DB 列类型回退 `VARCHAR` |
| 5 | 键空间 | `build_cache_key(tenant=<id>, …)` 形态为 `bms:{id}:…`；`current_tenant_id_of` 存在并取 id（`current_code_of` 保留为展示） | 键租户位回退 code |
| 6 | 形态判定 | `is_tenant_id("1001")` 真、`is_tenant_code("1001")` 假（纯数字不判为编码）；`is_tenant_code("demo")` 真 | 边界形态判定错位 |
| 7 | 源码扫描 | `bms_core/src` 与 `services/*/src` 中不再出现已退场标识 `TENANT_CODE_PAYLOAD_KEY` | 已退场常量复活 |

**失败分支**：任一组断言失败即用例失败，由受影响定向回归与 CI 拦截（对应「内部标识统一 / 命名按值」两条完成标准）。

### 5.3 命名误用处置 <a id="naming-fix"></a>

- **误用修正（本任务内一并修正，2026-09-29 拍板）**：字段名为 `tenant_id`（值为雪花 id）但注释 / docstring 仍写「租户编码」的残留——`bms_core/oauth/user_token.py::UserTokenSpec.tenant_id`、`bms_core/oauth/user_jwt.py::_build_claims(tenant_id=…)`、`services/identity/tests/auth/helpers.py::FakeTokenVerifier.mint(tenant_id=…)`（默认值由编码 `"demo"` 改雪花 id 串）；
- **登记为遗留（不修）**：已应用的历史迁移 `alembic/versions/identity/platform/0001_sys_user_identity.py` 中 `tenant_id` 列的 DDL 注释仍为「租户编码（值传递）」——迁移不可回改、且达梦不支持注释变更（10_04 已定「只改类型」），该库内注释陈旧问题**归口 [计划 §3.1 遗留 32](../../../../计划/01_计划_认证与安全.md)**（达梦注释变更支持）；
- **判定纪律**：白名单场景（§5.1）不算误用；判据以「字段实际承载的值」为准，不以出现位置为准。
