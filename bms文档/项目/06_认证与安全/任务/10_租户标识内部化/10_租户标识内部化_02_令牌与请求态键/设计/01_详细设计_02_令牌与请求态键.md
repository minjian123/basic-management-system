## 3. 接口与字段边界 <a id="contract"></a>

| 对象 | 口径 |
| --- | --- |
| `TenantLookup.by_id(tenant_id: str)` | 新增；本地源按 `SysTenant.id` 查、远程契约 `?tenant_id=`；缓存 kind `id` |
| `TenantSnapshot.db_basis` | 新增（库名基 = 对照表 `db_basis`；10_02 期未落表时**回落当前 code**） |
| `to_tenant_context` | `db_key = build_tenant_db_key(snapshot.db_basis or snapshot.code)` |
| `TenantContext` | `code` + `tenant_id`（解析链产出后**必非空**，缺失即拒绝）+ `db_key`（由 `db_basis` 派生） |
| 请求态 | `state["tenant"]` = `TenantContext`；`state["tenant_id"]` = 令牌位雪花 id 字符串（认证后写入） |
| 上下文变量 | `current_tenant` = code（展示 / 日志）；**新增** `current_tenant_id` = 雪花 id 字符串（内部键来源） |
| `AuthContext` | `tenant` → **`tenant_id`（id 字符串）+ `tenant_code`（code）** |
| 用户 / OIDC access token | claim `tenant_id` = 雪花 id **十进制字符串**；读取只认 `tenant_id` |
| 服务 JWT | claim `tenant` → **`tenant_id`** = 雪花 id 字符串；`ServiceTokenSpec.tenant` → `tenant_id` |
| `EdgeIdentity` | 新增 `tenant_id: str | None`（服务 JWT claim 填）；`tenant_code` 保留（网关注入头 code） |
| `ServiceRequest.tenant` | 值为雪花 id（跨服务租户位）；以 `current_tenant_id` 构造 |
| 会话键 | `bms:{tenant_id}:sess:{会话 id}`（`build_session_key(tenant=id)`） |
| IdP state 键 | `bms:{tenant_id}:{命名空间}:{state}` |
| `sys_user_identity.idp_key` | `{tenant_id}:{provider_key}`（雪花 id 字符串前缀） |
| 网关注入头 `X-Tenant-Id` | 保持 code；introspect 由令牌 `tenant_id`（id）**经租户源解析出 code** 后注入 |

**边界解析算法（`_wire_tenant`，认证后）**：

- 本地令牌路径（`context.tenant_id` 有值）：以 id 经租户源 `by_id` 解析为 `TenantContext`；若中间件已按显式来源（子域名 / 头）解析出上下文且其 `tenant_id` 与令牌一致则复用；**显式来源**与令牌 id 不一致 → 跨租户拒绝。
- 网关路径（`context.tenant_code` 有值）：中间件已按 code 解析出上下文，以之回填 `tenant_id` / `tenant_code`。

**失败分支**：令牌位形态非法（非纯数字）/ 未知 id → `TenantNotFoundError`（404 / 80001）；租户停用 → `TenantSuspendedError`（403 / 80002）；显式来源与令牌 id 不一致 → `AuthError`（跨租户）；`tenant_id` 缺失 → 拒绝。

## 4. 测试设计与验收映射 <a id="test"></a>

用例**先登记 Kiwi TCMS 再编码**；断言要点：

| # | 用例 | 断言要点 | 对应完成标准 |
| --- | --- | --- | --- |
| 1 | 用户令牌 claim | access / refresh 的 `tenant_id` 为雪花 id 字符串，`sub`/`jti` 不变 | 令牌 claim 统一 |
| 2 | 服务 JWT claim | 服务 JWT 携带 `tenant_id`（原 `tenant` 退场），验签租户位为 id | 服务 JWT 统一 |
| 3 | OIDC access token | claim `tenant_id` 为 id | OIDC 统一 |
| 4 | 边界一次解析 | 子域名 / 头（code）与令牌（id）解析出同一 `tenant_id`；未知 id 拒绝 | 边界解析与失败分支 |
| 5 | 请求态 / 上下文 | `state["tenant"].tenant_id`、`current_tenant_id`、`AuthContext.tenant_id` 均为 id | 请求态统一 |
| 6 | 会话键 | `bms:{id}:sess:{id}` 形态 | 键统一 |
| 7 | SSO / IdP state / `idp_key` | 流程状态键含 id、`idp_key` 前缀为 id | SSO 统一 |
| 8 | 门禁 | 受影响定向 `pytest`、`ruff`、`pyright`、基座校验、`preflight --fast` 全绿 | 门禁全绿 |

- 网关 introspect `id → code` 解析依赖租户源缓存（TTL 60s）；真实压测随 10_05。
