## 5. 覆盖率 <a id="coverage"></a>

- 本任务**无生产代码改动**，只新增 1 个收口断言用例文件（`test_m6_closure.py`）；覆盖率口径**引用 04_04 收口快照**（决策项 6），不现场重跑全量后端：
  - 全量后端行覆盖率 **96.28%**（阈值 70%），分支 3524 / 部分 210；
  - 认证（identity 服务）**99.3%**（47 文件）、认证（`bms_core` 横切）**99.5%**（56 文件），阈值 80%；
  - 新增 / 变更模块（逐任务）语句覆盖率 100%，分支未覆盖为防御性边界与可选参数展开（逐任务记录已说明）；
  - 前端核心三包与宿主无全局门槛（包门禁为 typecheck + lint + test）。
- 快照归档：CI `backend-test` artifact `backend/coverage.json`（`when: always`，保留 30 天），供本任务与阶段报告引用。

## 6. 偏差与遗留 <a id="deviations"></a>

- 同[实施记录 §6](../实施/01_实施_01_阶段验收门禁核对与测试报告.md#deviations)（设计偏差 2 处；补充确认 1 项：《文档首页》阶段六索引刷新；范围外口径：不现场重跑全量）。
- 用例反向有效性：`test_gate_table_has_conclusions_and_evidence` 在门禁表仅有「核对方式与证据来源（基线）」、无结论时会**必然失败**；`test_plan_closure_state` 的「剩余 0 / 进度含达成节点 / 工作量行可校验 / §7 台账存在」四项断言在收口前同样必红——断言对收口动作有效。
- 外部证据（流水线号、失败岗位、缺陷单状态、Kiwi 编号归属）由 GitLab API 与 Kiwi 平台承载，可经项目 2 的 API 与 `export_cases.py` 复核（编号见[阶段测试报告 附录 A](../../../../01_测试报告_认证与安全.md#appendix)）。
