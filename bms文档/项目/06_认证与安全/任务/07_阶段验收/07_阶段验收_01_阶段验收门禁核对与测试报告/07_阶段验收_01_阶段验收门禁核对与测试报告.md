## 2. 任务内容 <a id="content"></a>

1. **M6 门禁逐条核对**：按阶段六完成标准（本地 + SSO 登录链路 E2E、JIT 建号落库、前端登录与按服务寻址联通、策略强制生效）与《[总体项目规划](../../../../../规划/总体项目规划.md)》阶段六行逐条给出结论与证据索引（Kiwi 用例 / 门禁输出 / 报告章节）。
2. **阶段测试报告**：归档 `01_测试报告_认证与安全.md`（用例执行、缺陷、覆盖率（认证模块 ≥80% 与整体口径）、安全专项、风险与遗留）。
3. **状态一致性**：任务 / 计划两处状态与完成日期一致；父任务工时 = 自有 + 直属子任务合计。
4. **遗留归口**：确需延后的项逐条给归口（企业真实凭据联调 → 阶段十七、Socket.IO 广播 → 阶段八、登录日志 → 阶段八、`data:plain` 真实权限 → 阶段七、会话管理页面 → 阶段十五 等），登记计划「后续阶段待办」台账。
5. **收口提交**：门禁结论表 + 测试报告归档 + 状态回写。

## 3. 完成标准 <a id="accept"></a>

M6 门禁逐条有结论与证据且无未达标项（或未达标项已归口并获确认）；阶段测试报告归档；三类文档状态一致；遗留台账逐条有归口、无「无归口」条目。
