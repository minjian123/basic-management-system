## 2. 任务内容 <a id="content"></a>

1. **数据契约归位（批次 2 前段，3 处 → 0）**：`FieldChange`（`audit/base.py`）/ `EventEnvelope`（`events/base.py`）/ `ShardBinding`（`sharding/base.py`）改挂 `BaseDataContract`（可变数据契约体系根）；逐类确认「可变 + 契约」语义成立（若实为不可变 → 归 `BaseValueObject`）。
2. **框架对象归位（批次 2 后段 + 批次 3，47 处 → 0）**：`bms_core` **30** 个 + `identity` **12** 个 + `org` **3** 个 + `tenant` **2** 个直继承 `BaseObject` 的类**逐类判定落点**并改挂：
   - `BaseFrameworkObject`（框架对象体系根：非数据对象 + `object_kind` 统一标识 + 可选 `aclose` 钩子位）；或
   - 其下**能力域基类**（如服务类 → `BaseService`、中间件 / 注册表 / 缓存 / 资源锁等按语义归入既有能力域基类；确无归属者**新增**能力域基类或角色层）。
   - 典型待判定组：中间件 4（`EdgeGuardMiddleware` / `ReadOnlyMiddleware` / `RequestLoggingMiddleware` / `TenantMiddleware` / `TraceIdMiddleware`）、注册表 5（`EventContractRegistry` / `IdentityProviderRegistry` / `ModuleRegistry` / `PluginRegistry` / `TableOwnershipRegistry` / `RouterRegistry`）、服务类（`ConfigService` / `DictQueryService` / `DictService` / identity 与 org 侧各服务）、Redis 包装（`RedisSnapshot` / `RedisSortedDict` / `RedisSortedSet`）、资源与事务（`ResourceManager` / `LockGuard` / `SyncSession` / `_SyncTransaction`）、私有辅助（`_EmptyExporterStream` / `_KeyRule` 等）。
3. **护栏收口**：基线快照 **50 → 0**（需求 09-1 验收目标「除体系根外零直继承」）；用 `scripts/tools/base-check/check-backend-base.py . --update-baseline` 递减，**不得手工删除基线条目**。
4. **清单回写**：《[后端基类清单](../../../../../后端基类清单.md)》§10 历史链逐处改写（`→ BaseObject` → 对应体系根 / 能力域基类），并同步 §1「体系根白名单」、继承链小节与「存量链路口径」处数。
5. **测试**：新增 Kiwi 用例（**先登记取号、后写自动化**）——断言 50 处均已改挂体系根 / 能力域基类、均不再直继承 `BaseObject`、基线递减至 0；受影响定向回归与门禁全绿。
6. **盘点报告回写**：09_01《存量归位盘点报告》§3 批次表批次 2 / 批次 3 状态与余量随实施更新（基线即台账）。

## 3. 完成标准 <a id="accept"></a>

数据契约 3 处 + 框架对象 47 处全部改挂对应体系根 / 能力域基类且行为零变更（除按框架对象语义补 `object_kind` / `aclose` 钩子位）；`check-backend-base` 直继承合法性检查**基线 0 条**、继承链对账与数据类体系语义检查通过；《后端基类清单》§10 与代码一致；受影响定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
