## 1. 实施范围与口径 <a id="scope"></a>

- **范围**：基线快照剩余 **50 处**直继承 `BaseObject` 的类全部归位（数据契约 3 + 框架对象 47），基线递减至 **0**。
- **口径**：除按框架对象语义补 `object_kind`（及必要的 `aclose`）外**不改任何行为**；落点判定规则与逐类判定表见《[详细设计](../设计/01_详细设计_05_框架对象与数据契约存量归位.md)》§2 / §4。
- **护栏与台账**：每批次用 `check-backend-base.py . --update-baseline` 递减基线（**不得手工删除条目**）；《后端基类清单》§10 与 09_01《存量归位盘点报告》§3 随批次回写。

## 4. 批次 ②b（`ValueHolder` 迁出 + `BizError` 错误体系根归位） <a id="batch2b"></a>

| 项 | 内容 |
| --- | --- |
| `ValueHolder` 迁出（1 处） | 原定义在 `core/base.py`（**根系所在模块**）——根系模块**不能**导入 `core.objects`（`core/objects/roots.py` 反向依赖 `core/base.BaseObject`，形成循环导入）→ 新建 **`core/holder.py`** 承载 `ValueHolder[ValueT]` 并挂 `BaseFrameworkObject`（`object_kind = "value_holder"`）；导入方 `core/concurrent.py` / `core/redis_collections.py` 由 `core.base` 改从 `core.holder` 导入（行为零变更：`__init__` 与 `value` 属性不变） |
| `BizError` 归位（1 处） | `class BizError(BaseObject, Exception)` → `(BaseFrameworkObject, Exception)`（错误体系根＝框架对象：非数据对象），补 `object_kind = "biz_error"`；**错误段位链不变**（`GeneralError` / `AuthError` / `UserOrgError` / `ConfigError` / `FileError` / `OpenTenantError` 及子段基仍以 `BizError` 为基），`raise` / `except` 语义与 `Exception` 多父类保持 |
| **循环导入（本批真正的难点）** | `core/exceptions.py` 需要 `BaseFrameworkObject`，而 `core/objects/options.py` 顶层依赖 `core.exceptions.PluginError` → 顶层互相导入必然 `ImportError`。**修法**：把 `options.py` 的 `PluginError` 改为**使用处延迟导入**（4 个取值助手方法内）+ 注释说明成因；ruff 规则集（`E/F/W/I/B/UP/SIM/RUF`）不含 `PLC0415`，故函数内导入合法且无需 `noqa` |
| 清单回写 | 错误体系链 **12 处**（11 处 `` `BizError` → `BaseObject` `` + 1 处整段反引号形态）统一改写为 `BaseFrameworkObject`（09_05 归入框架对象体系）；`ValueHolder` 原未登记链，无链改写 |
| 基线 | `--update-baseline` → **19 → 17**（仅余服务侧 17） |
| 用例 | 台账 +2 行、`BASELINE_REMAINING` → **17**；台账断言收紧为「归位目标在首位 + **仅**容许 `Exception` 附加父类」（多父类特例显式受限）；新增 `test_biz_error_keeps_exception_semantics`（仍为 `Exception` 子类、`object_kind`、可 `raise/except`）与 `test_value_holder_moved_to_own_module`（迁移后行为不变、不再直继承根系） |

**验证**：全量 `uv run pytest -q` = **1824 passed / 40 skipped**；`ruff check` / `ruff format --check` / `pyright`（0 errors）全绿；护栏 6 项（继承链对账通过）+ 裸集合 554 无新增 + `check-base` / `check-links` 通过。

**遗留（批次 ③）**：服务侧 17 处（identity 12 / org 3 / tenant 2）→ 基线 **17 → 0**。
