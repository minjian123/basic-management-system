## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段六补充需求域 09 的 1 条需求——[09-1 禁止上帝基类与体系根治理](../../需求/09_需求_类体系根治理.md#r09-1)，按「1 需求 = 2 子任务」拆（后端体系根治理 + 前端框架层对称）。
- **端范围**：**后端为主**（`bms_core` 体系基类 / 继承链四段 / 继承链护栏 / 基线 / 盘点）+ **前端对称**（组件链加框架对象层与《前端基类清单》回写）。
- **承接口径**：根系与既有基类体系（集合体系 / 模块基类 / 中间层基类）已交付；本域只做**分层收口、归位与护栏**，不重写既有基类语义。
- **已定口径**（2026-09-28 拍板）：严禁上帝基类（除体系根禁止直继承）；体系根＝现有 11 个 + 新增 3 个（`BaseValueObject` / `BaseDataContract` / `BaseFrameworkObject`）；继承链固定四段（`BaseObject → BaseFrameworkObject → 能力域基类 → 插件基类`）；存量 160 处入基线递减、**目标零直继承**；首轮只交付基类 + 护栏 + 基线 + 盘点 + 口径回写，存量归位分批另立任务。
- **依据**：《[架构设计 · 后端基础类体系](../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》、《[后端开发规范](../../../../规范/后端开发规范.md)》、《[后端基类清单](../../../../后端基类清单.md)》、《[前端基类清单](../../../../前端基类清单.md)》。
- **执行序**：`09_01 后端类体系根治理` → `09_02 前端框架层对称`；其成果作为后续**存量归位分批任务**的口径来源。
