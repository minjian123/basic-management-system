## 2. 任务内容 <a id="content"></a>

1. **命名规则**：确立并写入《[后端开发规范](../../../../../规范/后端开发规范.md)》——泛指编码用 `code`（实体自身编码）、专指编码用 `<业务>_code`（引用某业务编码，如 `tenant_code`）。
2. **租户视图对象用 `code`**：`TenantContext.tenant_code` → `code`；`TenantSnapshot.code` / `TenantSummary.code` / `SysTenant.code` 保持。
3. **引用一律 `tenant_code`（口径三全域）**：现名 `tenant_id`（存编码）/ `tenant` / 引用型 `code` 全改——覆盖值对象与数据契约、参数 / 局部变量 / 辅助函数名、JWT claim、事件信封与发件箱键、缓存 / 会话载荷键、请求态键、API 协议与 query 参数、DB 列（含 Alembic 迁移）。
4. **契约键隔离**：字段（属性）与契约键（事件负载键 / 缓存载荷键 / DB 列 / JWT claim / API 协议）逐处显式映射；事件负载键 `_TENANT_PAYLOAD["tenant_code"]` 保持并作事件侧单一来源常量。
5. **映射退场与护栏**：租户链层公共段纳入 `code`，`CODE_FIELD` 退场；测试批量更新；新增命名护栏用例（视图对象自身编码为 `code`、引用型一律 `tenant_code`、层公共段、契约键一致、迁移链零漂移）。
6. **兼容口径**：**硬切不兼容**（同一次发版同步切换，不设新旧并存窗口）。

## 3. 完成标准 <a id="accept"></a>

命名规则写入《后端开发规范》；`TenantContext.code` 落地；全域「引用租户编码」字段统一为 `tenant_code`（含 JWT claim / 事件信封 / API 协议 / DB 列与迁移），无引用型 `tenant_id` / `tenant` / `code` 残留（`grep` 白名单 + `pyright` 严格模式 + 用例共同保证）；`CODE_FIELD` 退场；事件负载键与缓存载荷键隔离有断言；《后端基类清单》§10 与代码一致；受影响定向 `pytest`、`ruff`、`pyright`、基座校验（迁移链）、契约快照与 `preflight --fast` 全绿。
