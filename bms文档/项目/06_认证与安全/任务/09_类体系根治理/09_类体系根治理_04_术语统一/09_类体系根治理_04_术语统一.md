## 2. 任务内容 <a id="content"></a>

0. **命名规则（按值命名）**：实体（基础数据）自身编码 → `code`；租户主键（雪花 id，全系统唯一且不可变） → `tenant_id`；租户业务编码（人为编码，**可变 / 软删后可复用**） → `tenant_code`；真 ID → `<实体>_id`。写入《[后端开发规范](../../../../../规范/后端开发规范.md)》命名节。**只做命名与视图对象自身编码，不动内部链路租户标识**。
1. **字段名统一（Python 属性面）**：`TenantContext.tenant_code` → `code`（租户视图对象**自身**编码）；`UserInfoResult.sub` → `subject`（09_03 批次 ⑤ 已交付）。
2. **契约面隔离**：`tenant_code` 同为平台事件负载键（`bms_core/events/platform_events.py` 的 `_TENANT_PAYLOAD`）——**只改属性名**，负载键保持 `tenant_code`，以事件侧常量 `TENANT_CODE_PAYLOAD_KEY` 单一来源承接（对象字段 `code` ↔ 负载键 `tenant_code` 显式映射）。
3. **明确不动项**：数据库列名与 alembic 迁移不动（存储面）；`UserInfoResponse.sub` 协议 schema 键不动（协议面）；**内部链路租户标识（JWT claim / 事件信封 / 发件箱 / 请求态键 / API 协议 / DB 列）不改**——租户编码可变 / 可复用，不作内部稳定键；「内部标识改以雪花 `tenant_id` 为准」的架构改造另立[需求域 10](../../../需求/10_需求_租户标识内部化.md)。
4. **测试与护栏**：受影响测试批量更新；新增断言「事件负载键仍为 `tenant_code`」「迁移链零变更」；`grep` 复查 `tenant_code` **属性引用**零残留（负载键字符串与列名除外）。
5. **文档与映射退场**：术语口径写入《[后端开发规范](../../../../../规范/后端开发规范.md)》与《[后端基类清单](../../../../../后端基类清单.md)》§10；字段名统一后 09_03 落地的 `CODE_FIELD` 映射退场。

## 3. 完成标准 <a id="accept"></a>

命名规则写入《后端开发规范》；`TenantContext.code` / `UserInfoResult.subject` 落地且租户链层公共段纳入 `code`、`CODE_FIELD` 退场；事件负载契约键（`tenant_code`）与 DB 列名零变更（有显式映射与断言）；《后端基类清单》§10 与代码一致；受影响定向 `pytest`、`ruff`、`pyright`、基座校验与 `preflight --fast` 全绿。
