## 2. 任务内容 <a id="content"></a>

1. **三个体系基类**（`bms_core/core/objects.py` 新增）：`BaseValueObject`（`@dataclass(frozen=True)` 不可变值对象基类）、`BaseDataContract`（`@dataclass` 可变数据契约基类）、`BaseFrameworkObject`（框架对象：非数据对象约定——不参与值语义与序列化输出 + `object_kind` 统一标识 + 可选 `aclose` 生命周期钩子位）。
2. **继承链四段落地（基座侧）**：`BaseFrameworkObject` 接管既有框架类基类（`BaseCapability` / `BaseAsyncResource` / `BasePlaceholder` / `BaseLogger` / `BaseRouter` 等）；`BaseSchema`（Pydantic 混入）／`BaseModel`（ORM 混入）归数据契约体系；同步《后端基类清单》继承链与《架构设计 · 后端基础类体系》「固定四段」。
3. **强制口径回写**：`BaseObject` 仅为根系、除体系根禁止直继承、体系根必须承载公共语义——写入《后端开发规范》「后端基座体系（强制）」节与架构 04。
4. **继承链护栏**（扩展 `check-backend-base`）：直继承 `BaseObject` 仅允许体系根（白名单来自《后端基类清单》登记），其余即失败；存量以基线快照 `deploy/boundaries/direct_base_object_baseline.json` 豁免并递减；支持自测矩阵。
5. **存量盘点**：160 个直继承类按「区域 × 体系 × 位置」分类成文（含归位建议与分批），报告落本目录 `实施/`。
6. **未登记补齐**：8 个未登记直继承类（`RateLimitDecision` / `_KeyRule` / `_SyncTransaction` / `_EmptyExporterStream` 与 `ops/` 4 个）补登《后端基类清单》，并标注拟归位体系。
7. **用例**：体系基类继承与语义、护栏对体系根放行／对新增直继承失败、基线豁免与递减、`ops/` 纳入清单范围。

## 3. 完成标准 <a id="accept"></a>

三个体系基类就位并登记；`check-backend-base` 对「新增直继承」失败、对「体系根」放行（自测用例证明）；基线快照生成且零漂移；160 处归位清单与分批建议成文；《后端开发规范》/《架构设计 · 后端基础类体系》/《后端基类清单》口径一致（四段）；8 个未登记类补齐；`pytest`、`pyright`、`ruff`、基座校验通过。
