## 2. 任务内容 <a id="content"></a>

1. **前端框架对象层**：新增与后端同构的框架对象层基类（组件链由「组件根 → 能力基类 → 组件基类 → 具体件」改为四段：「组件根 → **框架对象层** → 能力基类 → 组件基类」），承载既有框架类组件基类的公共语义（非渲染对象约定 + 统一标识 + 生命周期钩子位）。
2. **既有链对齐**：既有框架类组件基类（宿主横切底座 / 路由 / 请求 / 状态等）改继承框架对象层；具体件链不受影响。
3. **口径同步**：《[前端基类清单](../../../../../前端基类清单.md)》回写四条链（组件根 / 框架对象层 / 能力基类 / 组件基类）；《[架构设计 · 后端基础类体系](../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「前后端对称」由「固定前三段」改为「**固定四段**」。
4. **用例**：框架对象层基类继承断言与契约用例（沿用前端既有契约套件口径），并回归已交付组件链（阶段四 / 五已收口件）。

## 3. 完成标准 <a id="accept"></a>

前端框架对象层基类就位并登记《前端基类清单》；组件链四段口径在《前端基类清单》与架构 04 一致；前端契约用例（含框架对象层断言）与既有组件链回归全绿；`npm run check`（lint / 类型 / 用例）通过。
