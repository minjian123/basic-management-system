## 1. 设计目标与口径依据 <a id="goal"></a>

**把「不可变数据类」按公共段分成各自独立的继承链**：解决 `BaseValueObject` 被当收容所（110 个子类平铺挂根、体系语义无从表达）的问题；每条链自身体系根之下**按语义细分**，链长不限、不设固定层数。

口径依据（原文）：

- 《[架构设计 · 前端组件体系](../../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》：固定段之后「**每条继承链按功能与抽象需要自行延伸、长短不一**——两条链**出现公共段即提取**能力基类；**不设固定层数、不做封闭枚举**」。
- 《[AI开发规范](../../../../../../规范/AI开发规范.md)》架构铁律：**能力即继承链上的层**；公共字段与方法只在链上对应基类维护；**加层优先于在既有层堆逻辑**，每层只解决一类横切职责。
- 《[架构设计 · 后端基础类体系](../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》：体系根必须承载本体系公共语义（**禁止空壳层**）。

**本设计的方法（三步）**：

1. **取公共段**：对每个类抽取「字段 / 方法 / 不变式」；
2. **聚链**：当两个及以上类共享**同一公共段**（同一批字段、同一对方法、同一不变式）时，把该段提为**层**，这些类挂到该层之下；
3. **逐级细分**：层内若仍可分出更细的公共段，**继续拉长链**（多层）；无公共段可提者**不成链**，直接挂 `BaseValueObject`（单类链，需在清单写明理由）。

**不采用**「按用途给所有类套一个统一接口」的做法：用途不是横切职责，强行统一会产生「恒真 / 恒抛未实现」的假契约。

### 2.1 不成链的类（单类链，直挂 `BaseValueObject`） <a id="singletons"></a>

判定理由统一为「**无同族公共段**（字段 / 方法 / 不变式均无第二个类共享）」——**40 个类**（本表为落点权威，与 §2 层成员互补不重叠）：

`ArchiveResult`、`CaptchaScenePolicy`、`ChainVerifyResult`、`ChatMessage`、`CursorPayload`、`DbKey`、`HashChainEntry`、`IdentityProviderSpec`、`IdpFlowState`、`IdpProbeResult`、`InitResult`、`JitResult`、`MaskSpec`、`MigrationChain`、`MigrationTask`、`NotificationMessage`、`OidcCode`、`PluginWiring`、`PresignedUrl`、`ProvisionTask`、`QueryResult`、`RateLimitRule`、`RealtimeEvent`、`RowError`、`SagaDefinition`、`SagaStep`、`SagaStepOutcome`、`SearchHit`、`SeedAttr`、`SeedConfig`、`ServiceCallPolicy`、`ServiceIdentity`、`ServiceRequest`、`SessionRevokeResult`、`SpanContext`、`SsoLoginResult`、`StoredObject`、`UserInfoResult`、`WorkflowTask`、`_KeyRule`

## 4. 层公共语义与准入判据 <a id="contract"></a>

| 项 | 口径 |
| --- | --- |
| 层的成立判据 | 层内成员**全部**共享该层声明的公共段（字段 / 方法 / 不变式）；不得存在「为满足契约而设的恒真 / 恒抛未实现」成员 |
| 层接口 | 公共段以**字段约定**（同名同义）、**成对方法**（如 `to_snapshot` / `from_snapshot`）或**钩子位**表达；新增子类须满足本层公共段 |
| 链长 | 二级层（`BaseRefreshableTokenContract` / `BaseOidcTokenSpecContract`）只承载其细分公共段；后续如出现更细公共段**继续加层**，不设固定层数 |
| 值对象体系根 | 语义正式定为「**不可变数据类体系根**」（值对象 + 只读结果 / 快照 / 规格 / 投影的共同落点）：Python 实测约束——`@dataclass(frozen=True)` 子类**不能**继承非 frozen 的 `BaseDataContract`（`TypeError`），故不可变数据类只有此根可挂 |
| **层落点（09_03 批次 ②定）** | `core/objects/` 包**一链一模块**：体系根在 `core/objects/roots.py`（对外统一从 `bms_core.core.objects` 导入，路径不变）；链层模块从 `bms_core.core.objects.roots` 导入体系根（**避免包内循环导入**）；成员类照旧挂本链层 |
| 落地状态 | 选项链（`BaseOptionsContract`，4 成员）**已落地**（批次 ②）；其余 28 层按批次 ③~⑥ 落地 |

## 5. 影响与迁移 <a id="impact"></a>

| 项 | 说明 |
| --- | --- |
| 迁移（行为变更） | `ChatStreamHandle` → `BaseFrameworkObject`（普通类 + 显式 `__init__` + `object_kind`，接 `aclose`）；消费点仅 `chat/null.py` 构造与 `services/ai` 测试 `isinstance`，无相等 / 哈希 / 序列化依赖 |
| 字段名统一（需评估消费方） | `EdgeTrustDecision.trusted` → 判定族 `allowed`；`TenantContext.tenant_code` → 租户族 `code`；`UserInfoResult.sub` → `subject`——**逐项评估消费方后执行**，无法统一者以「层内抽象属性映射」表达 |
| 新增方法（附加，不改既有行为） | 层接口按 §2 表补：`BaseOpsReportContract.describe()`（1 个成员待补）、`BaseTallyContract.total`（派生）、`BaseSecretMaterialContract` 遮蔽输出、`BaseSnapshotRoundTripContract` 成员命名统一 |
| 零风险部分 | 父类改挂 + 层拆分本身不改行为（frozen dataclass 语义不变） |
| 清单 / 台账 | 《后端基类清单》§10 新增 24 条链登记；盘点报告 §3 批次表按链分批 |

## 6. 护栏（判据强制化） <a id="guard"></a>

`scripts/tools/base-check/check-backend-base.py` 增第 6 项检查（含 `--self-test` 用例）：

| 检查 | 语义 |
| --- | --- |
| 值对象体系子类须为 frozen dataclass | `BaseValueObject` 体系（含各角色层）下的类必须声明 `@dataclass(frozen=True)`（实测现状 0 违规） |
| 框架对象体系子类不得为 dataclass | `BaseFrameworkObject` 体系下的类不得声明 `@dataclass`（实测现状 0 违规；`ChatStreamHandle` 迁移后仍为 0） |

## 8. 边界与开放项 <a id="boundary"></a>

- **字段名统一**（`trusted` / `tenant_code` / `sub`）涉及消费方改动，逐项评估后执行，不统一者用层内抽象属性表达。
- **弱公共段层**（`BaseDeliveryResultContract` 仅 `delivered`、`BaseFieldRuleContract` 仅 `field`）为 2 成员层；如实施时发现抽象成本高于收益，回写本设计降为单类链。
- **不改 08 裸集合批次 1**（7 处类字段）——仍归 08 域。
- **`BaseValueObject` 无字段 / 方法**：本次不再往体系根堆语义，公共语义一律落角色层。
