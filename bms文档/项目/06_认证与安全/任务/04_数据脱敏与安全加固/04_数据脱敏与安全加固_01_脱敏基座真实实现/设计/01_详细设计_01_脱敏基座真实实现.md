## 1. 设计目标与范围 <a id="goal"></a>

把 `BaseMasker` 从**结构占位**（`NullMasker` 原样返回，敏感字段在接口 / 日志 / 导出中全部明文）落为**规则化真实实现**：内置 6 类掩码规则 + 自定义策略注册 + 受权限约束的明文揭示，规则表与掩码字符可配置化；`data:plain` 判定**本期 fail-closed**（占位权限检查器一律按「无权限码」处理），真实权限校验随阶段七 RBAC 接入而不改脱敏侧。登记回写《[后端基类清单](../../../../../../后端基类清单.md)》「数据脱敏」条目（含规则清单）。

- **本任务范围**：`DefaultMasker` 真实实现（规则分派 / 自定义策略 / `reveal`）、`MASK_STRATEGIES` 策略清单扩展（+`address`）、`BaseMasker.register_strategy`（契约层策略注册）、装配工厂与 `[masking]` 配置节、单测与登记。
- **不在本任务**：`BaseSchema.masked_fields` 序列化接线（含嵌套 / 列表）、日志与导出接入、`mask_phone` 回接基座——均归 [04-2 脱敏接入与明文权限口径](../../04_数据脱敏与安全加固.md)（任务 02）；加密字段加解密与密钥管理归 [04-3](../../04_数据脱敏与安全加固.md)（任务 03）；`data:plain` 真实权限校验归阶段七 RBAC。
- **接口兼容**：`BaseMasker` 现有成员（`register` / `masked_fields` / `rules` / `check_plain` / `mask` / `reveal`）签名与语义不变（只**新增** `register_strategy` / `strategies`）；插件键 `masking`、`app.state.masker` 落点、`get_masker` 提供者均不变；**不新增插件键、不新增能力域**（`_EXPECTED_PLUGIN_KEYS` 不变）。
- **安全影响（SDL）**：涉及「敏感数据出接口必须脱敏」第一道闸——专项验收点：各内置策略掩码结果符合规范示例；**无 `data:plain` 权限码时一律掩码（占位检查器下不得放行明文）**；未注册字段不被误掩 / 已注册字段不泄露原值；掩码为纯函数（无 IO、无正则扫描），不落日志、不缓存原值。

### 1.1 现状与缺口 <a id="gap"></a>

```text
backend/libs/bms_core/src/bms_core/
├── masking/
│   ├── __init__.py        # 包口径（“真实掩码规则随性能与安全阶段回补”）
│   ├── base.py            # MASK_STRATEGIES(6 项) / MaskRule / BaseMasker(register/mask/reveal/check_plain) / get_masker
│   └── null.py            # NullMasker（mask/reveal 原样返回）
├── permission/
│   ├── base.py            # BasePermissionChecker.check/require + PLAIN 判定入口
│   └── null.py            # NullPermissionChecker（check 恒定 True）
├── schemas/base.py        # BaseSchema.masked_fields + _apply_masking（无掩码器直通）
├── core/
│   ├── config.py          # Settings.masking: PluginSelection（provider 空串 → null）
│   ├── assembly.py        # PLUGIN_WIRINGS("masking") + DefaultMaskerFactory（实际构造 NullMasker）
│   └── context.py         # current_masker 上下文变量
└── config.toml            # 无 [masking] 节（默认解析到 null）
```

缺口：① 无内置掩码规则（`NullMasker.mask` 原样返回，`MASK_STRATEGIES` 仅登记不生效）与对应策略实现落点；② 无自定义策略注册通道，业务特字段无法定制口径；③ `reveal` 无真实语义；④ 「无权限码一律掩码」无落地——占位检查器 `check_plain()` 恒真，真实实现若直接信任会**放行全部明文**；⑤ 无 `[masking]` 配置节与真实实现插件名，配置无法选择实现、测试无法隔离。**消费方**：序列化层（04-2 接线，零改动）、`mask_phone`（04-2 回接）、日志 / 导出（04-2 / 后续阶段）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 能力域与插件键 <a id="domain"></a>

| 能力域（插件键） | 插件基类 | 真实实现（`plugin_name`） | Null 实现 | 契约版本 |
| --- | --- | --- | --- | --- |
| `masking` | `BaseMasker` | `DefaultMasker`（`default`） | `NullMasker` | `0.1.0` |

继承链（固定前三段 + 域中间层）：`BaseObject` → `BaseCapability` → `BasePluggable` → `BaseMasker`（能力域，`key = plugin_key = "masking"`）→ `DefaultMasker`；`NullMasker` 走 `BaseNullObject` 缺省轨。**不新增插件键、不新增能力域、`_EXPECTED_PLUGIN_KEYS` 不变**。

### 3.2 实现类与方法面 <a id="bases"></a>

```python
class DefaultMasker(BaseMasker):
    plugin_name: str = "default"

    def __init__(self, *, checker: BasePermissionChecker, mask_char: str = "*",
                 rules: Mapping[str, str] | None = None) -> None: ...
    # checker 无默认值 → 非零参可实例化 → 不进插件注册表自动收集，交装配工厂显式登记

class MaskerOptions(BaseObject):
    mask_char: str = "*"                       # 掩码字符（单字符）
    rules: dict[str, str] = {}                 # 字段名 → 策略名

    @classmethod
    def from_options(cls, options: Mapping[str, object]) -> "MaskerOptions": ...   # 校验 + 缺省回落
```

| 方法 | 语义（本任务） |
| --- | --- |
| `mask(field, value)` | 未注册字段 / `None` → 原样返回；持 `data:plain` → 原值；否则按字段策略返回掩码字符串（非字符串先 `str()`） |
| `reveal(field, value)` | 与 `mask` 对称（本期无加密字段）：持 `data:plain` → 原值；否则掩码值 |
| `check_plain()` | **覆写**：注入检查器为占位实现（`BasePlaceholder`）→ `False`（视为「无权限码」）；否则经检查器判定 `data:plain` |
| `register(field, strategy="custom")` | 沿用基类实现（同字段后注册覆盖）；**不校验策略取值**（沿用既有语义，未知策略运行时兜底全掩码） |
| `register_strategy(name, strategy)` | 基类新增：登记自定义掩码函数（`Callable[[str, str], str]`——`值, 掩码字符 → 掩码串`）；与内置 7 策略同名 / 名称格式非法 → `PluginError`（40002）；同名自定义策略后注册覆盖 |
| `strategies()` | 基类新增：自定义策略名快照（按名称排序，输出稳定） |

### 3.3 掩码规则口径 <a id="rules"></a>

**内置策略规格**（`BUILTIN_MASK_SPECS`：保留前段 `head` / 保留后段 `tail` / 固定掩码字符数 `stars`）：

| 策略 | 保留规则 | 星数 | 示例 | 长度不足退化 |
| --- | --- | --- | --- | --- |
| `phone` | 前 3 + 后 4 | 4 | `13812345678` → `138****5678` | `1234567` → `123****`；`""` → `****` |
| `id_card` | 前 6 + 后 4 | 8 | `110101199001011234` → `110101********1234` | `1101011` → `110101********` |
| `bank_card` | 前 4 + 后 4 | 8 | `6222021234567890` → `6222********7890` | `622202` → `6222********` |
| `name` | 前 1 | 1 | `张三` → `张*` | `张` → `*`；`""` → `*` |
| `address` | 前 6 | 3 | `北京市朝阳区某某路1号` → `北京市朝阳区***` | `北京市朝阳` → `北京市朝***` |
| `custom` | 不保留 | 3 | `EMP-0001` → `***` | `""` → `***` |

- **星数固定**（不随被掩码字符数变化）：不泄露真实长度，且长短字段视觉统一。
- **通用退化规则**（保留首尾类，纯函数 `mask_edges`）：设 `mask = mask_char * stars`；
  若 `len(text) >= head + tail + 1` → `text[:head] + mask + text[-tail:]`（`tail` 为 0 时无尾段）；
  否则 → `text[:min(head, max(len(text) - 1, 0))] + mask`（**保底不原样回显**、不抛错）。
- **邮箱特例**（纯函数 `mask_email`）：按首个 `@` 切分 → `local[0] + mask*3 + "@" + domain`（`zhangsan@example.com` → `z***@example.com`）；`local` 为空 → `mask*3 + "@" + domain`；**无 `@`** → 退化「首 1 字符保留 + `mask*3`」（`abc` → `a***`、`""` → `***`）。
- **策略解析顺序**：已注册自定义函数 → 内置策略（`email` 特例 → 规格表）→ **兜底 `custom` 全掩码**（未知策略名不抛错，序列化期安全）。
- **掩码字符**：`mask_char` 缺省 `*`，经 `[masking].options.mask_char` 可配（须为**单字符**，否则 `PluginError`）。

### 3.4 配置契约 <a id="config"></a>

`config.toml` 新增 `[masking]` 节：

```toml
[masking]
# 数据脱敏实现选择（插件化配置；default = 内置规则掩码 + 自定义策略、空串解析到 null 占位原样返回）
provider = "default"
# 非敏感选项（rules = 字段名 → 策略映射，启动期注册；mask_char = 掩码字符，缺省 *）
options = {}
```

- `Settings.masking` 仍为 `PluginSelection`（`provider` + `options`），**不新增配置类**；`MaskerOptions.from_options` 在工厂构造期解析并校验。
- 选项非法（`mask_char` 非单字符 / `rules` 非映射 / 键值非字符串）→ `PluginError`（40002，装配拒启，不静默降级）。
- `deploy/.env.example` 无需新增键（`BMS_MASKING__PROVIDER` / `BMS_MASKING__OPTIONS__RULES` / `BMS_MASKING__OPTIONS__MASK_CHAR` 由通用嵌套规则自动可用，不入样例；口径同 03_01）。

### 3.5 失败分支与错误语义 <a id="failures"></a>

| 场景 | 行为 |
| --- | --- |
| 未注册字段 / `value is None` | 原样返回（未注册即非敏感；不把 `None` 变成掩码串） |
| 已注册 + 无 `data:plain` | 返回掩码字符串（非字符串值先 `str()`，出参恒为 `str`） |
| 已注册 + 有 `data:plain` | 原样返回原值（不 `str()` 转换） |
| 占位权限检查器（`NullPermissionChecker`） | `check_plain()` → `False`（**fail-closed**，本期不放行明文） |
| 字段注册了未知策略名 | 兜底 `custom` 全掩码（不抛错——序列化期抛错会 500） |
| `register_strategy` 与内置策略同名 / 名称格式非法 | `PluginError`（40002，装配期 fail-fast） |
| `[masking].options` 非法 | `PluginError`（40002，装配拒启） |
| 空串值（已注册字段） | 按策略掩码为掩码串（`phone` → `****`，与既有 `mask_phone("")` 口径一致） |

## 4. 兼容性与消费方影响 <a id="compat"></a>

- **新增而非替换**：`NullMasker` 保留（provider 空 / 测试回落），`BaseMasker` 既有成员零改动（仅新增 `register_strategy` / `strategies`）。
- **`MASK_STRATEGIES` 扩展**：6 → 7 项（新增 `address`），属实现侧清单元数据；既有 Kiwi 39 用例仅同步该常量断言（其余断言不动）。
- **默认 provider 切换**：`config.toml` 由「无 `[masking]` 节 → null」改为 `provider = "default"`；`libs/bms_core` 与 9 个服务单测在 `conftest.py` 的 `isolate_settings` 增 `BMS_MASKING__PROVIDER=""` 回落 `NullMasker`（与 `captcha` / `rate_limiter` / `session_store` 同口径）——既有用例离线、行为不变。
- **序列化侧零影响**：`BaseSchema.masked_fields` 默认空集，且本任务**不接线**；即使 `current_masker` 被注入为 `DefaultMasker`，无字段声明即直通——既有响应逐字节不变。
- **既有契约用例**（`libs/bms_core/tests/masking/test_masking.py`，Kiwi 39）**保留**：`NullMasker` 占位语义、`check_plain` 经注入检查器判定（`NullPermissionChecker` → `True`）等断言不变（fail-closed 覆写只在 `DefaultMasker`，不动基类）。
- **后续扩展点**：04-2 接线序列化 / 日志 / 导出并回接 `mask_phone`（口径一致，签名不变）；阶段七把 `NullPermissionChecker` 换为 RBAC 真实实现后，`DefaultMasker.check_plain()` 的占位判定自动失效、按 `data:plain` 放行，**脱敏侧零改动**；加密字段加解密在 `reveal` 内扩展（04-3）。
- **平台契约套件**：新增实现类有必填构造参数 → 不自动登记（`test_plugin_registration` 键集不变）；工厂在 `assembly.py` 显式登记。

## 7. 边界与开放项 <a id="boundary"></a>

- **序列化 / 日志 / 导出接线**与 `mask_phone` 回接 → 04-2（本任务只保证基座能力就位且口径与 `mask_phone` 一致）。
- **`data:plain` 真实权限判定**（RBAC 权限码）→ 阶段七；本任务 fail-closed，阶段七接真实检查器后自动放行。
- **加密字段的真实解密**（`reveal` 解密路径与密钥来源）→ 04-3（密钥只走环境变量，不入库 / 不入镜像 / 不写日志）。
- **值探测自动识别**（按值正则猜类型）：本期**不做**（显式注册驱动）；如后续确需，另行立项并在设计里补误掩边界。
- **地址策略粒度**：`address` 保留前 6 字符（行政区划前缀）；若后续需按省 / 市分级保留，另行扩展规格表。
- **Kiwi 用例编号** → 测试实施时登记回填。
- **`MASK_STRATEGIES` 顺序**：`address` 插入 `name` 之后、`custom` 之前（`custom` 恒居末位）。
