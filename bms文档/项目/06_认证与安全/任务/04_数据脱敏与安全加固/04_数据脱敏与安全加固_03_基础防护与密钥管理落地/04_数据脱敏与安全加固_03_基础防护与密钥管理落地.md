## 2. 任务内容 <a id="content"></a>

1. **安全响应头**：核验 nginx 统一配置（CSP / HSTS（dev 关）/ `X-Frame-Options` / `X-Content-Type-Options` / `Referrer-Policy` / `Permissions-Policy`），缺口补齐。
2. **文档端点**：生产环境关闭 Swagger / ReDoc，契约走 CI 导出快照（`deploy/contracts/`）口径核验。
3. **密钥管理**：JWT / 服务令牌密钥只走环境变量与 Secret（不入库 / 不入镜像 / 不落日志）；与 `[security]` 配置定稿（`01_01`）配合核验轮换流程；`deploy/.env.example` 键位同步。
4. **CI 安全扫描**：依赖漏洞扫描既有 job 口径核验（高危阻断）；镜像扫描（Trivy）与 SBOM 的 CI 挂点确认存在（完整落地归部署阶段）。
5. **证据留痕**：核验命令与结果登记实施记录（可复查）。

## 3. 完成标准 <a id="accept"></a>

响应头按环境差异正确（dev 关 HSTS）；生产文档端点关闭；密钥来源检查通过（无硬编码 / 无入库）；`.env.example` 键位与实现一致；核验证据归档。
