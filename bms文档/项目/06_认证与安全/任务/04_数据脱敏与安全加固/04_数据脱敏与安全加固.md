## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段六需求域 04 的 4 条需求——[04-1 脱敏基座真实实现](../../需求/04_需求_数据脱敏与安全加固.md#r04-1)、[04-2 脱敏接入与明文权限口径](../../需求/04_需求_数据脱敏与安全加固.md#r04-2)、[04-3 基础防护与密钥管理落地](../../需求/04_需求_数据脱敏与安全加固.md#r04-3)、[04-4 安全专项用例与覆盖率门槛](../../需求/04_需求_数据脱敏与安全加固.md#r04-4)，按「1 需求 = 1 子任务」拆 4 个子任务（`04_01` ~ `04_04`）。
- **端范围**：**后端为主**（bms_core 脱敏基座 + 序列化 / 日志 / 导出接线 + 部署件核验）；安全专项用例覆盖前后端既有能力（前端项按既有护栏口径引用）。
- **承接口径**：`BaseMasker` 与 `BasePermissionChecker` 占位、`BaseSchema.masked_fields` 字段约定（阶段二 `02-3-05`）、nginx 安全响应头与限流基座（阶段一 / 二交付）、CI 依赖扫描既有 job；本域只做**真实实现、接线与核验**。
- **已定口径**（2026-09-26 拍板）：脱敏本期落规则 + 序列化 / 日志 / 导出接入；RBAC 就绪前 `data:plain` 按「无权限码一律掩码」执行（判定接口预留，阶段七接真实权限）。
- **依据**：《[架构设计 · 性能与安全](../../../../设计/架构设计/31_架构设计_性能与安全.md)》§3、《[安全开发规范](../../../../规范/安全开发规范.md)》、《[测试规范](../../../../规范/测试规范.md)》「安全专项」节、《[后端基类清单](../../../../后端基类清单.md)》。
- **执行序**：`04_01 脱敏基座` → `04_02 脱敏接入` → `04_03 基础防护与密钥管理` → `04_04 安全专项与覆盖率`（收口段，见[计划](../../计划/01_计划_认证与安全.md)）。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：34h（01 12h + 02 8h + 03 6h + 04 8h）。
- **关键依赖**：`04_01` 依赖阶段二 `02-3-05`（脱敏基座占位）；`04_02` 依赖 `04_01` 与域三 `03_03`（短信手机号回显消费方）；`04_03` 依赖域一 `01_01`（密钥与配置定稿）；`04_04` 依赖域一 / 二 / 三全部交付（专项覆盖面）。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_认证与安全.md)（本节不写排期）。
- **风险**：`data:plain` 过渡口径若被误当默认放行会造成泄露（须「无权限码一律掩码」并加用例）；脱敏接入若逐接口手工调用会漏（须序列化层统一）；安全响应头在 dev 与 prod 有环境差异（须按环境核验）。
