## 2. 任务内容 <a id="content"></a>

1. **序列化自动掩码**：`BaseSchema.masked_fields` 标记字段在序列化层默认掩码，支持嵌套模型与列表；标记与数据库字段 / 业务标记单一来源。
2. **日志脱敏**：结构化日志过滤器对敏感键（密码 / token / 密钥 / 手机号等）掩码；`ai_chat_log` 落库前消费同口径（占位接线）。
3. **导出脱敏**：导入导出框架导出路径走脱敏（与阶段四前端导入导出件后端契约对齐）；导出大文件记录审计占位。
4. **明文口径**：`data:plain` 判定经 `BasePermissionChecker` 预留点；RBAC 就绪前一律掩码；阶段七接入后按权限码放行（消费方登记）。
5. **既有场景回接**：短信手机号回显（`03_03`）、SSO / 会话接口中的用户标识按本域规则输出。
6. **用例**：带标记字段响应掩码（含嵌套 / 列表）、日志与导出无敏感明文、无权限码时 `data:plain` 不生效。

## 3. 完成标准 <a id="accept"></a>

带标记字段的响应全部掩码（含嵌套 / 列表用例）；日志与导出无敏感明文；无权限码时 `data:plain` 静默不生效；阶段七依赖登记在计划台账；`pytest`、`pyright`、`ruff` 通过。
