## 1. 文档说明 <a id="purpose"></a>

- **阶段二已交付基础（本阶段在其上接线，不重复建设）**：网关 forward-auth 认证接线与身份头契约（`/api/v1/auth/introspect`）、OIDC 客户端（Discovery + 授权码 + JWKS 验签）、服务 JWT 自签与统一校验（双类 JWT 按 `aud` 分流）、边缘信任（`ServiceJwtEdgeTrust` / `EdgeGuardMiddleware` / 请求净化）、验证码与密码策略基座占位契约（含三形态渠道扩展）、脱敏基座与权限校验占位、会话存储占位、出站 / 幂等等横切基座；前端服务段寻址（`servicePrefix` / `apiUrl`）、能力源按服务分流、9 份契约前端类型生成（`@bms/api-types`）、请求层 token 注入与 401 钩子、路由守卫骨架（默认关闭）。
- **已定口径（2026-09-26 拍板，见 [README 「启动时需求提出清单」](../README.md#intake)）**：
  1. 用户 JWT（`aud=api`）由 **BMS 自签**——本地与 SSO 登录统一经 identity 服务签发双 token，网关校验源切至 identity JWKS，Keycloak 降为外部 IdP 之一；回写架构 14 / 36 与阶段二网关配置；
  2. 认证所需 `sys_user` 最小模型落 **org 服务**（用户主数据归属），identity 经服务间契约调用凭据校验 / 锁定写入内部接口，阶段七无缝续建；
  3. **BMS 兼作 IdP** 本期交付 OIDC Provider 内核 + `sys_client` 表与最小注册接口，管理页面归阶段十；
  4. SSO **四协议实现**：OIDC（Keycloak）真联调、CAS（本地 mock 服务）联调、企业微信 / 钉钉适配 + 单测，企业真实凭据联调与移动端内嵌 H5 免登留阶段十七；
  5. 会话强制踢出按 **HTTP + Redis 即时拦截**（广播经 `BaseRealtimePublisher` 占位，阶段八接 Socket.IO）；
  6. 密码哈希取 **PBKDF2 标准库**，回写《安全开发规范》；
  7. Redis 故障降级：**验证码 fail-closed 拒绝**，登录限流降级 memory；
  8. **登录日志本期不落表**（失败计数 Redis + `sys_account_lock`），日志分片与哈希链归阶段八；
  9. 账号锁定 / 解锁**后端全做**（三型锁定 + 手动解锁 + 审计），管理页面归阶段七；
  10. 找回密码本期做 token 流程（通道占位），180 天未登录扫描落服务方法 + 手动触发，Celery 定时归阶段八；
  11. 数据脱敏本期落规则 + 序列化 / 日志 / 导出接入；RBAC 就绪前 `data:plain` 按「无权限码一律掩码」执行；
  12. 模块请求能力 `api`（契约版本升 2）本期交付（`ModuleHostContext.api` 注入 + demo / sample 双模块回归）；
  13. 滑块验证码**服务端合成出图、不下发缺口坐标**，前端只提交轨迹（前端 `06_04` 契约同步微调）；
  14. 排期沿用《总体项目规划》阶段六 4 周基线（累计 30 周），任务级工时随详细设计重估；
  15. 认证配置口径本期定稿（`[security]`：access 30 分钟、RS256/ES256、密钥轮换；补《概要设计 · 系统参数》「前端配置」节）。
- **范围外**（按规划归口，详见各域文档）：开放接口 OAuth2 / `/api/open` / `sys_open_log` 调用审计 → 阶段十；用户管理完整 CRUD、个人资料、组织归属与权限码细粒度校验 → 阶段七；登录 / 操作日志落库与哈希链、通知中心 Socket.IO 后端 → 阶段八；会话管理页、个人中心、登录相关页面收口 → 阶段十五；移动端 H5 与企微 / 钉钉内嵌免登 E2E → 阶段十七；认证端点独立鉴权、mTLS、票据 / 网关令牌缓存优化 → K8s / 性能阶段；MFA / 两步验证不采用（既定口径）。

## 2. 阶段六目标与范围 <a id="goal"></a>

**阶段目标**（《总体项目规划》「阶段内容与完成标准」节）：**本地 + SSO 登录链路 E2E 通过、JIT 建号落库正确、前端登录与按服务寻址联通、策略强制生效**（M6 认证安全可用）。

**范围内**（共 29 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 01 认证与会话 | 安全原语（PBKDF2 / 令牌编解码 / 会话黑名单）真实实现；用户双 token 自签与网关校验源切换；本地登录 / 刷新 / 登出链路；会话记录与 Redis 标记、多端上限、强制踢出；`require_auth` 真实化与租户解析接线 |
| 02 SSO 与身份联邦 | OIDC 授权码完整链路（state / nonce / PKCE）；JIT 建号与 `sys_user_identity` 全局映射；CAS 兼容适配；企业微信 / 钉钉免登适配；BMS 兼作 IdP 与 `sys_client` 最小注册；租户级 IdP 配置管理 |
| 03 验证码与账号治理 | 图形 / 滑块 / 短信三形态真实实现；场景策略与失败计数（连续失败强制）；密码策略（复杂度 / 90 天 / 近 5 次历史 / 180 天不活跃）；找回密码；账号锁定与解锁管理 |
| 04 数据脱敏与安全加固 | 脱敏规则与序列化 / 日志 / 导出接入（`data:plain` 口径）；安全响应头、生产关闭 Swagger、密钥管理复核；安全专项用例与认证模块覆盖率门槛 |
| 05 登录前端 | 登录页真实实现（含验证码与 SSO 入口）；token 与 401 静默刷新接线；路由守卫默认开启与回跳；扫码登录轮询与换取会话 |
| 06 契约与模块请求能力 | 认证端点契约快照与 `@bms/api-types` 重新生成零漂移；模块请求能力 `api` 注入与契约版本升 2 |
| 07 阶段验收 | M6 验收门禁核对、阶段测试报告、状态收口与遗留归口 |

**范围外**：见第 1 节「范围外」。
