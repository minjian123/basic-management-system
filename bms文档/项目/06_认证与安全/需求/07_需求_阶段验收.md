## 1. 域说明 <a id="intro"></a>

本域是阶段六收口：对照《[总体项目规划](../../../规划/总体项目规划.md)》阶段六行的**完成标准与 M6 里程碑**逐条核对验收门禁，归档阶段测试报告（需求 / 任务 / 计划 / 任务文档状态一致），并把跨阶段遗留逐条归口，作为 M6 放行与阶段七启动的依据。

- **本域范围**：M6 验收门禁逐条结论与证据索引；阶段测试报告归档；三类文档状态一致性与遗留归口。
- **依据**：《[总体项目规划](../../../规划/总体项目规划.md)》（阶段内容与完成标准、里程碑、MVP 验收标准）、《[测试规范](../../../规范/测试规范.md)》、《[项目管理规范](../../../规范/项目管理规范.md)》与《[计划文档规范](../../../规范/计划文档规范.md)》。
- **用例口径**：本域核对复用各域 Kiwi 用例编号与门禁输出，不新造证据。

## 2. 需求 07-1：M6 验收门禁核对与阶段测试报告 <a id="r07-1"></a>

优先级：2（高）

**背景与动机**：阶段完成必须「以完成标准为准、逐条有结论有证据」，否则 M6 只是口头达成：本阶段涉及认证安全（安全专项 / 覆盖率 / 三库 / 覆盖率门禁）与跨端联调，证据链最长，更需要一次集中核对与归档，避免带着未闭环项进入阶段七。

**内容**（《[总体项目规划](../../../规划/总体项目规划.md)》「阶段内容与完成标准」「验收与收尾」节、《[测试规范](../../../规范/测试规范.md)》）：

1. **M6 门禁逐条核对**：按阶段六完成标准（登录链路本地 + SSO E2E、JIT 建号、前端登录与按服务寻址联通、策略强制生效）与《总体项目规划》阶段六行逐条给出结论与证据索引（Kiwi 用例 / 门禁输出 / 报告章节）。
2. **阶段测试报告**：归档 `01_测试报告_认证与安全.md`——用例执行、缺陷、覆盖率（认证模块 ≥80% 与整体口径）、安全专项、风险与遗留。
3. **状态一致性**：任务 / 计划两处状态与完成日期一致（需求文档不承载进度）；父任务工时 = 自有 + 直属子任务合计。
4. **遗留归口**：本阶段交付中确需延后的项逐条给归口（如企业真实凭据联调 → 阶段十七、Socket.IO 广播 → 阶段八、登录日志 → 阶段八、`data:plain` 真实权限 → 阶段七、会话管理页面 → 阶段十五），登记计划「后续阶段待办」台账。
5. **收口提交**：阶段文档状态回写与收口提交（含计划门禁结论表与测试报告归档）。

**完成标准**：M6 门禁逐条有结论与证据且无未达标项（或未达标项已明确归口并获确认）；阶段测试报告归档；三类文档状态一致；遗留台账逐条有归口无「无归口」条目。
