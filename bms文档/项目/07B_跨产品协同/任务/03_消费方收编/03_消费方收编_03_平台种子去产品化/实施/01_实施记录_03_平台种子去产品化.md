## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    A["Kiwi 先登记<br/>2364"] --> B["平台种子去产品化<br/>业务码 −1 / 权限码 −4 / 注释归一"]
    B --> C["探针改声明驱动<br/>删硬编码表 + 值列派生 + 登记时机下移"]
    C --> D["声明对齐<br/>platform.toml 9 段 / mdm.toml 真实表名"]
    D --> E["用例改造与新增<br/>2254 改造 + 新用例 6 条"]
    E --> F["基线递减<br/>95 → 76（消耗 19）"]
    F --> G["门禁与回写<br/>预检 + 文档四处"]
```

结果小结：平台种子不再写产品业务码与权限码（`mdm` 业务码 1 条、权限码 4 条移除），动作码字典 31 个动词不变；种子统计探针由平台侧硬编码改为**按种子声明派生**（值列自动派生、登记时机下移到记录装载之后），平台源码不再持有产品种子的统计口径；平台 / 产品两侧 `[seeds.tables]` 统一为「真实表名 → 自然键」；产品字面量基线 **95 → 76**（本任务消耗 **19 条**）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `register_seed_probes` 原在端点在记录装载**之前**调用，产品种子不可见（时序隐患） | 登记下移到编排服务 `_load_records()` 之后；端点删除调用 |
| 2 | 平台 9 个种子的 `[seeds.tables]` 原写逻辑名，与 `SeedRecord.tables` 契约（真实表名）不一致，且授权种子自然键仅 `role_id`、系统参数种子无声明 | 统一改真实表名；授权种子改三列组合键（与改造前硬编码口径一致）；补 `seed-config` |
| 3 | 值列原只存在于硬编码表，声明侧无来源 | 按表结构自动派生，并排除审计 / 时间戳 / 版本列（避免「跳过」行误判为更新） |
| 4 | 新增用例签名用 `dict` / `Mapping` 触发裸集合护栏 | 改 `**tables: str` 关键字参数（用例内部再装 `ConcurrentStableFrozenDict`） |
| 5 | 技能点：`--only` 只选不自动补依赖，选中 `seed-menu` 会因 `after` 缺 `seed-module` 前置报错 | 用例改用无依赖种子（`seed-module` + 注入记录）构造场景；不修改编排语义 |
| 6 | Kiwi 用例文本原先设想一条用例覆盖 18 条设计用例 | 沿用既有口径（一条 / 任务，2254 改造 + 2364 新增） |
