## 2. 任务内容 <a id="content"></a>

1. 平台种子清单移除产品业务码与产品权限码条目。
2. 产品权限码改由产品种子声明、平台统一调度（机制由 `02_03` 提供）。
3. 已部署库补种口径更新：平台种子 + 各产品种子按声明执行；运维文档同步。
4. 平台侧既有种子用例改按「平台 + 产品」两段断言。

## 3. 完成标准 <a id="accept"></a>

平台种子清单无产品标识（护栏通过）；执行「平台种子 + 产品种子」后产品权限码正确入库；重复执行幂等；冲突时报错并输出差异；平台侧种子用例全绿；运维口径同步。
