## 2. 任务内容 <a id="content"></a>

1. **产品键来源**：前端产品键清单改为从平台目录快照获取（运行期），移除手写常量清单。
2. **命名空间取址**：产品端点按能力的前端面取址，由寻址契约统一组装；移除页面端点里的产品命名空间常量。
3. **寻址工具**：产品寻址工具不再内置产品键与domain 段，改为查询目录视图。
4. **失败语义**：目录快照不可用时给出明确降级（禁用相关产品能力并提示），不静默拼出错误地址。
5. **零改动验证**：以夹具模拟新增产品，前端无需改代码即可取址。

## 3. 完成标准 <a id="accept"></a>

前端源码不再出现产品标识与产品命名空间字面量（护栏通过）；产品键与端点均由目录快照驱动；快照不可用时有明确降级与提示；新增产品夹具用例通过；受影响包的类型检查与用例全绿。
