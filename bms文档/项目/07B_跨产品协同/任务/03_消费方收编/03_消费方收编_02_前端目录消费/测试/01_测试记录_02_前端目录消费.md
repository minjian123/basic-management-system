## 3. 执行记录与结果 <a id="run"></a>

| 命令 | 结果 |
| --- | --- |
| `pnpm run core:test` | 113 文件 / **1383 passed** |
| `pnpm run ui_ep:test` | 72 文件 / **1107 passed** |
| `npx vitest run`（apps/desktop） | 101 文件 / **885 passed** |
| `uv run pytest -q`（预检定向档退化全量，487 文件） | **4011 passed / 60 skipped**（143.96s） |
| `python scripts/tools/preflight/check_preflight.py`（`run_once` 包装） | **全部通过**（328.5s） |
| `python scripts/tools/base_check/check_product_literals.py` | 通过：命中 95 处全在基线（新增 0） |

手工核对：

1. 组织数据源自检页（开发态 `/dev/org`）第 13 项：注入虚构产品目录 → 端点解析为 `/api/demo/v1/demo`；复位后解析为 `null`（显式降级）。
2. 目录不可用时字段组件显示降级占位文案，不再发起请求（用例 20 断言 `fetch` 零调用）。
3. 基线文件复核：前端 15 个文件 54 条全部消失，基线仅剩后端 95 条。
