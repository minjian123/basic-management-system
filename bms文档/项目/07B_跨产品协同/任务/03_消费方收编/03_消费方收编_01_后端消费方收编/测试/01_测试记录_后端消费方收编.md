## 3. 关键断言口径 <a id="asserts"></a>

| 主题 | 断言 |
| --- | --- |
| 入站判定顺序 | 网关代发票据拒（403）→ 白名单服务放行（不查分配）→ 其余按能力分配判定（无分配 403） |
| 取用失败降级 | 消费方声明了 `degrade`：取用失败即降级并计 `capability_degrade_total`（`stage=resolve`）；未声明才上抛 |
| 注册期宽松度 | 消费方 / 被消费能力未注册 → 警示但落库；跨产品撞键、写能力降级、缺理由仍是硬错误 |
| 分支换算 | 同一保存请求各段必须同分支同承载服务（否则 fail-closed），库键优先取声明、否则按服务键派生；分支三要素以值对象 `OrgBranch` 返回 |
| 写通道等价性 | 收编后服务键 / 路径模板 / 分支动作名 / 分支标识须与收编前常量逐字一致（用例内显式锁定，防止声明漂移被静默接受） |
| 恒开通语义 | 平台侧视图 = 平台常量 + 已装载且 `tenant_base=true` 的模块键；租户侧 = 目录行标记 **或** 常量（旧对端不返回字段时平台模块仍恒开通）；未装载产品清单的环境不含产品模块 |
