## 3. 关键断言口径 <a id="asserts"></a>

| 主题 | 断言 |
| --- | --- |
| 幂等 | 同内容重复注册 → 全 `unchanged`、`created` 全 0；库中行数不变 |
| 演进 | 同键换内容 → `updated` 计数 1、回读路径与指纹同步变化 |
| 退役 | 本次未声明 → 置 `retired`（不删行）；回读 `is_retired()` 为真；再声明即恢复 |
| 作用域 | 别的产品名下的行不因本次全量而退役、不参与撞键判定 |
| 撞键 | 同键已属他产品 → 抛 `CatalogError` 且**不写库** |
| 降级 | 库不可用 → 平台自注册降级放行并置 `declaration_register_degraded`；产品拉取失败 → 拒启 |
| 投影 | 退役项不出现在视图；常量承载行不重复；同声明方多条使用声明同组累加 |
