## 2. 测试范围与用例 <a id="scope"></a>

**范围**：授权记录落库与两层来源、三类派生（出站 scope / 入站校验 / 监控维度）、授权视图分发与缓存、拒绝语义、审计留痕（占位契约）、管理面与内部视图端点、启动装配（同步 / 预热 / 降级 / 拒启）。
**不在范围**：端点接线与调用方字面量清理（`03_01`）、产品侧远端来源注册（`03_01` / 产品仓）、真实审计落库（29-审计合规）、面板（08 阶段）。

## 4. 问题与处置 <a id="issues"></a>

| # | 现象 | 处置 |
| --- | --- | --- |
| 1 | 管理面用例 403 | 权限码判定由权限引擎专项用例覆盖；本套用例显式设 `[permission].provider=null` 后专测端点语义（路由权限码挂载保持真实） |
| 2 | 会话级平台库跨用例累积授权行 | 新增 `_clean_grants` 夹具：每例启动后将授权表清空，保证用例起点一致 |
| 3 | 会话 autobegin 导致写事务冲突 | 见实施记录问题 1（`_write_scope()` 统一写事务） |
| 4 | 未建表环境的健康 / 插件用例失败 | 见实施记录问题 3（库不可读降级放行） |
