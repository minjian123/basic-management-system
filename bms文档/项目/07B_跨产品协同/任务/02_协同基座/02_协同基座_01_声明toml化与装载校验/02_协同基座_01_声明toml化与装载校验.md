## 2. 任务内容 <a id="content"></a>

1. **格式切换**：产品自持清单改为 toml，注册要素字段语义保持不变；读取方（平台运行时装载、离线网关生成、运维脚本、护栏脚本、产品仓自检）同批改为读 toml。
2. **能力段**：能力作为产品自持声明的**第五类登记记录**（与既有四类同源、同装载入口、同一合并视图族、同唯一性纪律），清单新增能力声明段——能力名、访问面类别与位置、业务语义要素、前端命名空间、契约版本。
3. **种子段**：清单新增种子声明段——模块路径、入口、依赖顺序、说明。
4. **装载校验**：能力名全局唯一；提供方与清单归属一致；访问面能在对端公开契约中定位；声明版本与提供方契约版本兼容；种子入口可解析。任一不满足即拒启，错误信息定位到能力名。
5. **跨仓切换**：平台仓与产品仓在同一批次切换（不做双格式过渡），切换后两仓的装载校验、模块清单对账与预检全绿。
6. **登记回写**：《跨产品协同登记清单》补「清单结构」与状态。

## 3. 完成标准 <a id="accept"></a>

清单为 toml 且含注册要素 / 能力 / 种子三段；对「缺能力 / 能力重名 / 提供方不符 / 访问面不在契约 / 版本不兼容 / 种子入口不可解析」分别有用例且均拒绝启动；合法声明装载用例通过；能力记录与既有四类同源同通道（**不新增第二套注册表**）；两仓切换后各自校验与预检全绿；登记清单同步更新。
