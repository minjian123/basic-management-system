## 2. 用例清单 <a id="cases"></a>

### 2.1 bms 解析与记录（`libs/bms_core/tests/registry/`）

| # | 用例 | 断言 |
| --- | --- | --- |
| 1 | 完整六段装载 | 六类记录字段逐一正确；`status` / `after` 等缺省值生效 |
| 2 | 最简清单（仅 `product_key`） | 各段为空列表、各视图等于平台侧内容，不报错 |
| 3 | 结构反例（段非数组 / 元素非对象 / 必填缺失或空串） | 各自抛 `CatalogError` |
| 4 | 归属反例 5 例（产品档案 / 服务行 / 路由 / 数据源 / 能力） | 与清单 `product_key` 不符即拒 |
| 5 | 非数组字符串字段（`allowlist` / `strategies`） | 按空处理并回落缺省 `select` |
| 6 | 文件反例（不可读 / TOML 非法 / 交付 `.json`） | 均转 `CatalogError`，`.json` 提示改用 toml |
| 7 | 装载即注册 | 六类视图各增一条 |
| 8 | 相对路径基准 | 按后端工程根解析；不存在路径跳过 |
| 9 | 类型收紧 4 例（`build_batch` 非整数 / 布尔 / `cascade` 非布尔 / 数组含非整数） | 各自抛结构非法 |
| 10 | 种子字段反例（`status` 非法 / 必填缺失） | 抛 `CatalogError` |
| 11 | 装配期失败 | 聚合错误抛 `CatalogError`；警示经日志门面输出 |

### 2.2 bms 六类校验与边界（`inspect_product_manifests`）

| # | 用例 | 断言 |
| --- | --- | --- |
| 12 | 完整清单 + 契约 + 域布局 + 可导入种子 | 校验通过、无警示 |
| 13 | 能力重名（跨清单同名异值） | 抛错且信息含能力名 |
| 14 | 能力同名同值（幂等） | 不报错，两份清单均装载 |
| 15 | 提供方业务域未登记 | 抛错且信息含域标识 |
| 16 | 域布局两处都缺 | 只做形态校验并输出警示（不拒启） |
| 17 | 域布局非法三态（根为数组 / JSON 破损 / 读取异常） | 警示并降级；读取异常转清单错误 |
| 18 | 域布局条目缺 `domain_key` | 该条忽略（不计数），不误判 |
| 19 | 访问面模板归一化（契约 `{other_id}` vs 清单 `{dept_id}`） | 视为同一路径，通过 |
| 20 | 访问面拼错 | 抛错且信息含路径 |
| 21 | 契约版本不兼容（能力 1.0.0 / 服务 0.2.0） | 抛错且信息含两侧版本 |
| 22 | `kind` 与要素不匹配 6 例 | `txn-branch` 缺 `branch_id` / 缺 `branch_op`、`dataset` 缺 `data_source_key`、`codes` 缺 `permission_codes` / 带 `path`、有访问面类缺 `path` 各自抛错 |
| 23 | 能力字段反例 5 例 | `kind` 非法 / `status` 非法 / 契约版本非 semver / `deprecated` 缺 `replacement` / `branch_id` 超 16 字符 |
| 24 | `codes` 类正例 | 无访问面、只有码集，校验通过 |
| 25 | 种子入口不可解析 3 例 | 子模块缺失 / 入口缺失 / 入口不可调用，均定位 `module:entry` |
| 26 | 提供方包不可导入 | 跳过入口校验并输出警示（不静默） |
| 27 | 契约文件缺失 | 缺省拒启；设置跳过变量后通过并警示 |
| 28 | 契约定位回退 | 清单不在本仓时按后端工程根 `deploy/contracts` 兜底 |
| 29 | 契约 JSON 破损 / `paths` 非对象 | 逐项报错不静默 |
| 30 | 默认消费方未登记 2 例（未知标识 / 前端应用名 `desktop`） | 均拒 |
| 31 | 分支标识跨业务域混用 | 拒；同域多能力共用同一 `branch_id` 合法 |
| 32 | 前端命名空间不可推导（无路由 / 多路由且未显式声明） | 拒 |
| 33 | 无能力段清单 | 跳过契约定位与域基准校验，无警示 |
| 34 | 解析失败短路 | 只报解析错误，不再做语义校验 |
| 35 | 契约读取异常（`OSError`） | 转 `CatalogError` 且信息含路径 |
