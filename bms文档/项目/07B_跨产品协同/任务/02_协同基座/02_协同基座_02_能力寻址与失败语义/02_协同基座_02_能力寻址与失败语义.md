## 2. 任务内容 <a id="content"></a>

1. **能力视图**：装载后形成运行期只读能力视图，按能力名提供访问面（提供方服务标识、访问面位置、业务语义要素、前端面、版本）。
2. **寻址入口**：消费方以能力名取用；取用失败（能力未声明）抛出可定位的错误，不返回空值。
3. **装载期失败**：缺失 / 未登记 / 访问面不在契约 / 版本不兼容 → 拒启（与 `02_01` 同源校验）。
4. **运行期失败三档**：写与强一致路径 fail-closed（整体失败 + 明确错误码，无半写）；读与弱一致路径按**逐能力声明**的有界降级（空集或旧副本），记录日志并计入指标；未声明降级的能力失败即上抛。
5. **目录下发**：**扩展既有 `/api/v1/modules/snapshot`（不新开端点）**，能力与产品键一并下发，供服务启动对账、跨服务查询与前端取址共用同一份。

## 3. 完成标准 <a id="accept"></a>

消费方改按能力名取用（以 `03_01` 收编为最终验证）；缺能力时启动即失败且错误信息含能力名；写路径失败用例断言 fail-closed 且无半写；读路径降级仅发生在被声明的能力上，并有日志与指标断言；未声明降级的能力失败即上抛；既有快照端点扩展后契约与用例齐备（**无新增目录出口**）。
