## 2. 用例清单 <a id="cases"></a>

### 2.1 取用入口与两段解析（`libs/bms_core/tests/collaboration/test_capability_resolution.py`）

| # | 用例 | 断言 |
| --- | --- | --- |
| 1 | 能力存在 → 取用 | 字段与清单一致；`mode=remote`、`unit_key=org`、`service_key=mdm`、`base_url=http://mdm:8000`、`db_keys` 空、`access_url` 拼接正确 |
| 2 | 能力未声明 → 取用 | `ParamError`（10001），信息含能力名与「请检查产品清单」；不返回空值 |
| 3 | 能力名为空 → 取用 | 立即报错（不落到「查不到」分支） |
| 4 | `status=disabled` → 取用 | `ParamError` 且注明状态 |
| 5 | `status=deprecated` → 取用 | 正常返回（弃用期迁移窗口） |
| 6 | `codes` 类取用 | `path is None`；`access_url()` 抛「能力无访问面」 |
| 7 | `txn-branch` 取用 | `is_write_path=True`，`branch_op` / `branch_id` 带回 |
| 8 | 业务域无承载服务 | `CatalogError`，信息含业务域名 |
| 9 | 第二段实现替换 | 替换后 `mode=local` 生效；复位回 `remote` |
| 10 | 域 → 服务键登记 | 视图为只读副本、按域取值、同域异服务即拒 |
| 11 | 自定义基址模板 | 默认实现按模板派生基址（部署形态差异不改协议） |

### 2.2 三档失败语义与降级（`test_capability_usage.py`）

| # | 用例 | 断言 |
| --- | --- | --- |
| 12 | 声明登记 | 幂等、视图只读副本、按名查找、复位清空 |
| 13 | 登记冲突 / 空消费方 | 同消费方异值即拒；空标识即拒 |
| 14 | 合规声明校验 | 读能力 + 有理由 `empty` 通过；显式 `none` 通过 |
| 15 | 校验反例合集 | 模式非法 / 无理由 / `stale` / 重复 / 未登记 / 已禁用 / 写能力降级七类信息齐备 |
| 16 | 校验失败拒启 | `CatalogError`，信息定位消费方与能力名 |
| 17 | 取用成功调用 | 原样返回调用结果，不产生降级指标 |
| 18 | 声明 `empty` 且调用失败 | 返回兜底值 + 一条 `capability_degrade` WARNING（含 6 个结构化字段）+ `bms_capability_degrade_total` 计数（含 mode 标签） |
| 19 | 未声明降级失败 | 原样上抛，无降级指标 |
| 20 | 显式 `degrade=none` 失败 | 同上抛 |
| 21 | 能力取用失败 | 计 `bms_capability_resolve_error_total` 后上抛（契约断链不降级） |
| 22 | 无指标器 | 降级仍生效（指标缺省跳过，日志照常） |
