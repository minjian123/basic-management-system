## 2. 任务内容 <a id="content"></a>

1. **第七类记录**：清单新增错误码段（`code` / `domain` / `http_status` / `message_key` / `severity` / `description`），与能力、种子同源同通道装载。
2. **合并视图**：平台 `ErrorCode` 枚举保持代码常量，装载后与产品声明合成 `code → 定义` 视图；中间件只走这一条渲染路径。
3. **统一渲染**：错误响应按视图取 `http_status` 与 `message_key`；文案缺失回退 `description` 并记警告（不静默给空文案）。
4. **三类校验**：段位归属（码前两位 = 声明段、不落平台码区）、全局唯一（跨产品与平台码）、契约反向（契约声明的错误码必须已登记，双向一致）。
5. **手册导出**：按视图导出错误码表，供开放平台文档与前端映射；导出与视图逐项一致。
6. **边界**：错误码与能力里的业务码 / 权限码（`kind = "codes"`）不共用段与命名空间。

## 3. 完成标准 <a id="accept"></a>

产品可登记错误码并被装载；合并视图含平台码与产品码且无重复；错误响应按视图渲染状态与文案键，缺失时回退并告警；段位越界、跨产品撞码、契约与登记不一致三类反例均被拒；手册导出与视图逐项一致；定向覆盖率达标（行 + 分支）。
