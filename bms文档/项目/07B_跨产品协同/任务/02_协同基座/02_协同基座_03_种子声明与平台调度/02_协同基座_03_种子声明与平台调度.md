## 2. 任务内容 <a id="content"></a>

1. **种子入口声明**：产品在自持清单声明种子入口（模块路径 + 入口 + 依赖顺序），平台装载时校验可解析（不可解析即拒启）。
2. **统一调度**：并入**既有平台种子编排入口**（`seed_platform`）——既有种子族视为「平台自身种子」，产品种子按声明追加后按依赖顺序执行，统一幂等（重复执行结果一致）、冲突（已存在异值即报错并输出差异，不覆盖）、失败隔离（单个产品失败不影响已成功产品，整体退出码非零）。
3. **逐项结果**：每次执行输出逐项结果（跳过 / 新建 / 冲突 / 失败原因），供运维与验收核对。
4. **平台种子去产品化**：与 `03_03` 配合——本节只提供调度能力与用例，实际移除产品条目由 `03_03` 完成。

## 3. 完成标准 <a id="accept"></a>

种子入口不可解析时拒启；调度按依赖顺序执行且重复执行幂等；构造冲突时非零退出并输出差异；单产品失败不影响其他产品且整体非零；逐项结果可核对；用例覆盖上述正反路径。
