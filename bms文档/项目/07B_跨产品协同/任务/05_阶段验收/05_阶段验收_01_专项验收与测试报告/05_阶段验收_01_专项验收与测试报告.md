## 2. 任务内容 <a id="content"></a>

1. **门禁逐条核对**：平台源码 / 平台种子 / 前端常量零产品字面量；能力声明缺失或与契约不符时拒启；写路径 fail-closed、读路径降级仅限显式声明；产品种子由平台统一调度且幂等、冲突报错；前端在产品新增时零改动；CI 能取产品仓清单并校验；与既有注册机制统一（无第二套注册表 / 目录出口 / 播种入口 / 校验入口）。
2. **阶段测试报告归档**：汇总用例执行、缺陷、覆盖率、风险与遗留、复盘与经验教训。
3. **三类文档一致性核对**：需求 ↔ 任务 ↔ 计划编号与挂接一致、进度只在计划表；跑一致性核对与预检。
4. **收口回写**：计划进度与遗留台账、《跨产品协同登记清单》状态（「设计已定（待收编）」→「已收编」）、索引与导航。
5. **遗留归口**：逐条给归口，无「无归口」条目。

## 3. 完成标准 <a id="accept"></a>

门禁逐条有结论与证据索引、无未达标项（限定项注明归口）；阶段测试报告归档且结构齐备；需求 / 任务 / 计划一致、编号无缺失、一致性核对无硬规则不合规；登记清单状态全部回写；遗留项全部归口。
