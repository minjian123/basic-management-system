## 2. 任务内容 <a id="content"></a>

1. **架构节点**：新增《架构设计 · 跨产品协同》，含三类协同方向、能力目录语义、协同契约要素类别与归属、契约版本与兼容、消费方寻址与三档失败语义、依赖方向与六条红线、与相邻节点分工、演进与开放项。
2. **规划节**：《平台可扩展性规划》「产品间协同与能力契约」节（新增）新增「产品间协同与能力契约」节；《项目规划说明》「平台扩展接入流程」把「协同能力登记」写入接入步骤并补说明块。
3. **登记清单**：新增《跨产品协同登记清单》，登记 11 项跨产品能力、消费方、产品间直连（空）、自持声明要素类别、种子登记与「现状 → 目标」收编映射。
4. **导航与追溯**：架构总览节点地图收录新节点；相邻节点（服务间通信）补前后导航；专项 README 与仓根 README 增索引。

## 3. 完成标准 <a id="accept"></a>

四份文档落地且互相引用可跳转；架构节点只写语义（无实现侧命名、代码落点、配置项与代码片段、脚本命令、字段级结构）；登记清单覆盖 11 项能力且每项有提供方与消费方；规划节与接入流程步骤可追溯到架构节点；链接自洽、基座完整性、docs-scope 三项校验全通过。
