## 5. 问题与处置

| 问题 | 处置 |
| --- | --- |
| bms 仓缺 `msgpack`，搬迁后 `import bms_core.msgclient` 报 ModuleNotFoundError | `libs/bms_core/pyproject.toml` 加 `msgpack>=1.1` / `h2>=4.1`，`uv lock` + `uv sync` |
| bms 仓 pyright 报 msgpack 缺 stub（msg 仓全局配了 `reportMissingTypeStubs=false`） | `codec.py` import 行局部 `# pyright: ignore[reportMissingTypeStubs]`，不改全局配置 |
| `values.py` 按行号抽取时截断 `RpcHandler` docstring | 改按标记切分（`@dataclass...class RpcCall` → `class RpcHandler(Protocol):`） |
| 协议向量用例找不到 `data/frames/*.json` | 复制 16 个向量到 `tests/msgclient/data/frames/` |
| `rpc_stream_frame` 替身签名与服务端不一致 | 改为从服务端 `api/rpc/responses.py` 抽取真实实现 |
| ruff `--fix` 把 `config.py` 的 re-export import 当 F401 删除 | 改为显式赋值转发（`_rpc_constants.X`） |
| `errors.py` 的 `BizError` 注解丢 import | 补回 `from bms_core.core.exceptions import BizError` |
