## 1. 域说明 <a id="intro"></a>

本域对应[《组件设计》](../../../设计/组件设计/01_组件设计_总览.md)「展示类」（`07_展示类/`，14 节点），是只读呈现类组件，派生展示域基类 `BaseDisplay`（组合展示形态片段 + 受控值片段），只读不编辑。

- **归属说明**：该类的「异常与空状态」按执行顺序前移至需求域 03（编号 `03-2`），因结构布局与通用容器都依赖它；本域只承接其余 13 节点。
- **占位口径**：本域多数组件依赖后端能力（列表接口与偏好表、通知与实时推送、文件与审计、报表数据集、检索索引），未就绪期间先交付**占位版**（骨架 + 空态 / 降级语义 + 占位契约测试，对齐后端 Null 占位模式）——由 `07-1` 统一承接。
- **回补锚点**：文件预览 / 审计差异 ← 阶段八（通用能力）；通知与消息 ← 阶段八（数据）+ 阶段十（实时推送）；数据呈现 ← 阶段八后 ~ 阶段十五；图表卡 ← 阶段十六（报表 BI）；全局搜索 ← 阶段十八（全文检索）。

**依据**：《组件设计》展示类各节点、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「八类组件与边界」「取数与缓存协作」「阶段落地（地基波 + 回补）」节。
**用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
**目标**：列表页与工作台可直接由展示类组件组装；依赖后端的展示件先以占位版纳管，回补后与后端契约一致。

## 2. 需求 07-1：占位版交付（依赖后端的展示件） <a id="r07-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：通用表格、通知、预览、图表与搜索都依赖后端能力，对应阶段尚未就绪；先冻结组件契约与占位语义，可让页面开发不必等后端，也避免后端就绪后大改组件结构。

**内容**（《组件设计》展示类「通用表格 / 通知与消息 / 文件预览 / 审计差异查看 / 图表卡 / 全局搜索」）：

1. 骨架与契约：`ProTable`、`NotificationList`、`FilePreview`、`AuditDiffViewer`、`ChartCard`、`GlobalSearch` 等组件的 Props / 事件 / 插槽契约与容器装配先行落地。
2. 占位语义：后端未就绪时不发请求，呈现空态 / 骨架 / 降级提示（复用 `03-2` 的空状态件）。
3. 占位契约测试：覆盖占位态渲染与降级分支（不写死数据）。
4. 回补衔接：`07-3` ~ `07-7` 落地真实实现时，改数据通路不改对外契约。

**完成标准**：占位版组件可被页面引用且不产生无效请求；占位契约测试通过并纳入前端门禁；回补条（`07-3` ~ `07-7`）确认只需替换数据通路；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[01_组件设计_通用表格](../../../设计/组件设计/07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)、[06_组件设计_通知与消息](../../../设计/组件设计/07_展示类/06_组件设计_通知与消息/06_组件设计_通知与消息.md)、[08_组件设计_文件预览](../../../设计/组件设计/07_展示类/08_组件设计_文件预览/08_组件设计_文件预览.md)、[04_组件设计_图表卡](../../../设计/组件设计/07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)、[07_组件设计_全局搜索](../../../设计/组件设计/07_展示类/07_组件设计_全局搜索/07_组件设计_全局搜索.md)（均含可交互原型）

## 3. 需求 07-2：轻量展示件 <a id="r07-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：快捷入口、头像与用户信息、二维码、水印是跨页面高频的只读展示元素，体量小但复用面极广；用户与组织展示、二维码生成、水印覆盖若各页各写，会出现头像与部门路径口径不一、导出物无水印等安全与体验问题。

**内容**（《组件设计》展示类「快捷入口 / 头像与用户信息 / 二维码 / 水印」）：

1. `QuickEntry`：工作台快捷入口（图标 + 文案 + 跳转，权限过滤）。
2. `UserAvatar` / `UserPill`：头像与用户信息胶囊；用户 / 组织展示统一经用户展示片段 `useUserDisplay`（姓名 / 头像 / 状态 / 部门路径，与组织选择回显、审批流、通知共用）。
3. `QrCode`：二维码（内容与容错级别、下载）。
4. `Watermark`：水印（用户 / 租户信息，覆盖页面内容与导出物），统一经水印片段 `useWatermark`。

**完成标准**：四项展示件可用；用户展示口径与其它域一致；水印可覆盖指定容器；Vitest 覆盖渲染与降级分支（用户数据未就绪时占位）。**回补窗口**：无后端强依赖，占位版之后即可推进；用户数据通路随阶段七 ~ 八完善。

**参考文档**：《组件设计》[11_组件设计_快捷入口](../../../设计/组件设计/07_展示类/11_组件设计_快捷入口/11_组件设计_快捷入口.md)、[12_组件设计_头像与用户信息](../../../设计/组件设计/07_展示类/12_组件设计_头像与用户信息/12_组件设计_头像与用户信息.md)、[13_组件设计_二维码](../../../设计/组件设计/07_展示类/13_组件设计_二维码/13_组件设计_二维码.md)、[14_组件设计_水印](../../../设计/组件设计/07_展示类/14_组件设计_水印/14_组件设计_水印.md)（均含可交互原型）

## 4. 需求 07-3：文件预览与审计差异查看 <a id="r07-3"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：附件查看与操作审计是管理端的基础诉求；预签名 URL 会失效、审计差异需字段级渲染与脱敏，若不统一实现，各处会出现预览失败不重取、差异展示与实际变更不符的问题。

**内容**（《组件设计》展示类「文件预览 / 审计差异查看」）：

1. `FilePreview` / `ImageViewer` / `PdfViewer` / `useFilePreview`：图片 / PDF / 音视频 / 文本分发、缩放旋转翻页、预签名 URL 失效重取与降级下载；预签名经预签名片段 `usePresignedUrl`。
2. `AuditDiffViewer` / `DiffTable` / `FieldDiff` / `ChainVerifyPanel` / `useAuditDiff`：字段级旧值 → 新值差异、脱敏、链字段与校验结果、篡改定位。

**完成标准**：预览各类型可正常渲染、URL 失效自动重取、降级下载可用；审计差异渲染与脱敏正确、篡改可定位；Vitest 覆盖关键渲染分支。**回补窗口**：阶段八（通用能力 · 文件 / 审计）就绪后。

**参考文档**：《组件设计》[08_组件设计_文件预览](../../../设计/组件设计/07_展示类/08_组件设计_文件预览/08_组件设计_文件预览.md)、[09_组件设计_审计差异查看](../../../设计/组件设计/07_展示类/09_组件设计_审计差异查看/09_组件设计_审计差异查看.md)（均含可交互原型）

## 5. 需求 07-4：通知与消息 <a id="r07-4"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：顶栏铃铛、消息列表与详情是平台与用户的主要触达通道；实时推送与断线补偿若不统一，会出现漏消息、重复消息与角标不准，直接影响待办与审批的时效性。

**内容**（《组件设计》展示类「通知与消息」）：

1. `NotificationBell` / `NotificationList` / `MessageItem` / `NotificationDetail` / `useNotification`：顶栏铃铛与角标、列表与详情、单条 / 批量 / 全部已读。
2. 实时通道采用 Socket.IO（随阶段十集成消息落地），含断线重连与补偿拉取；未就绪期间以轮询占位。
3. 消息类型与已读状态展示复用用户展示片段 `useUserDisplay`（`07-2`，已就位）与语义色令牌，不依赖后续条目。

**完成标准**：铃铛与列表详情可用、已读操作生效、实时与断线补偿正确、角标与实际未读一致；Vitest 覆盖补偿与角标分支。**回补窗口**：阶段八（通知数据）+ 阶段十（实时推送）。

**参考文档**：《组件设计》[06_组件设计_通知与消息](../../../设计/组件设计/07_展示类/06_组件设计_通知与消息/06_组件设计_通知与消息.md)（含可交互原型）

## 6. 需求 07-5：数据呈现 <a id="r07-5"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：管理端以列表为主；通用表格（列配置、分页、多列排序、树形、行内编辑、列个性化持久化）与查询筛选区（条件模型、折叠、高级查询、方案保存）若不统一，每个列表页都要重复实现且交互不一致。

**内容**（《组件设计》展示类「通用表格 / 查询筛选区 / 状态标签与描述列表 / 指标卡」）：

1. 通用表格 `ProTable`：声明式列配置与渲染优先级、分页与多列排序、树形与行内编辑、列个性化持久化；显隐 / 顺序 / 宽度统一经列配置片段 `useColumnConfig`。
2. 查询筛选区 `QueryFilter` / `QueryField`：条件模型、折叠与窄屏口径、高级查询入口与条件摘要、查询方案（应用 / 另存 / 设默认）与条件持久化，统一经查询方案片段 `useQueryScheme`。
3. 状态标签与描述列表 `StatusTag` / `DescList` / `DescItem`：语义色三层取色、标签形态、描述列表响应式列数。
4. 指标卡 `StatCard` / `useStat`：数值与单位、环比同比与状态色、口径说明、迷你趋势图、数字滚动、加载 / 空态与跳转。

**完成标准**：列表页可由 `ProTable + QueryFilter` 直接组装；列个性化与查询方案持久化生效；分页与排序与后端契约一致；Vitest 覆盖列配置与条件模型。**回补窗口**：阶段八（列表接口与偏好表）之后，随阶段十五（前端全页面）逐步收口。

**参考文档**：《组件设计》[01_组件设计_通用表格](../../../设计/组件设计/07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)、[02_组件设计_查询筛选区](../../../设计/组件设计/07_展示类/02_组件设计_查询筛选区/02_组件设计_查询筛选区.md)、[03_组件设计_状态标签与描述列表](../../../设计/组件设计/07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)、[10_组件设计_指标卡](../../../设计/组件设计/07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md)（均含可交互原型）

## 7. 需求 07-6：图表卡 <a id="r07-6"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：图表涉及 ECharts 分包与主题令牌，工作台与本页多处复用；若各页各画图表，会出现主题色不统一、深色模式失效与首屏体积膨胀。

**内容**（《组件设计》展示类「图表卡」、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「分包与加载策略」节）：

1. `EChart` / `ChartCard` / `useChart` / `chartTheme`：常用图表类型与地图、令牌色板与深色主题、工作台卡片形态、加载 / 空 / 错误 / 降级四态、自适应。
2. **按需分包**：ECharts 与地图独立分包，首屏不加载；图表域基类 `BaseChart` 随本需求演练新增（`02-4` 规则）。

**完成标准**：图表卡可挂数据集渲染、主题与深色模式正确、四态完备、独立分包生效（首屏体积预算内）；Vitest 覆盖主题与四态分支。**回补窗口**：阶段十六（报表 BI）就绪后。

**参考文档**：《组件设计》[04_组件设计_图表卡](../../../设计/组件设计/07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)（含可交互原型）、《[架构设计 · 子系统 · 报表 BI](../../../设计/架构设计/23_架构设计_子系统_报表BI.md)》

## 8. 需求 07-7：全局搜索 <a id="r07-7"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：顶栏全局搜索是跨模块入口，依赖检索能力与多域结果聚合；权限与租户过滤、结果高亮与降级提示若不统一，会泄露越权数据或检索不可用时整块不可用。

**内容**（《组件设计》展示类「全局搜索」）：

1. `GlobalSearch` / `SearchPanel` / `SearchResults` / `SearchResultItem` / `useGlobalSearch`：顶栏入口与命令面板、多域分组结果与高亮、审计日志页签、键盘导航。
2. 权限与租户过滤在检索侧与前端双重生效；ES 不可用时给出降级提示与替代入口，不阻塞页面。

**完成标准**：命中与高亮正确、权限与租户过滤生效、降级兜底可用、命令面板键盘流顺畅；Vitest 覆盖降级与过滤分支。**回补窗口**：阶段十八（全文检索）就绪后。
