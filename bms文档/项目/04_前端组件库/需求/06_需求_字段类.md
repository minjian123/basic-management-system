## 1. 域说明 <a id="intro"></a>

本域对应[《组件设计》](../../../设计/组件设计/01_组件设计_总览.md)「字段类」（`06_字段类/`，12 节点），是带数据源、特殊交互或特殊格式的字段控件，在需求域 05 的八件基础控件之上扩展。

- **占位口径**：本域多数字段依赖后端模块能力，随对应阶段回补；未就绪期间先交付**占位版**（骨架 + 空态 / 禁用态 / 降级语义 + 占位契约测试，对齐后端 Null 占位模式）——由 `06-1` 统一承接，真实实现由 `06-4` ~ `06-7` 按回补窗口落地。
- **回补锚点**：验证码 ← 阶段六（认证与安全）；部门 / 用户 / 岗位 ← 阶段七（RBAC 基础模块）；字典 ← 阶段八（通用能力 · 字典）；文件 ← 阶段八（通用能力 · 文件）。
- **无强依赖部分**：基础与数据源字段（`06-2`）、富文本与高级交互字段（`06-3`）不依赖后端强能力，可在占位版之后直接推进。

**依据**：《组件设计》字段类各节点、《[前端开发规范](../../../规范/前端开发规范.md)》「前端基类体系（开放式，强制）」节、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「取数与缓存协作」「阶段落地（地基波 + 回补）」节。
**用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
**目标**：基础字段与高级交互字段可用；依赖后端的字段先以占位版纳管，回补后与后端契约一致并按 locale / 时区正确展示。

## 2. 需求 06-1：占位版交付（依赖后端的字段） <a id="r06-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：字典、组织、文件、验证码等字段依赖后端能力，对应阶段尚未就绪；若等到后端就绪才动手，字段组件会与页面开发挤在同一窗口。先交付「骨架 + 占位语义 + 占位契约测试」，可把契约与组合关系提前冻结，后端就绪后只补数据通路。

**内容**（《组件设计》字段类「字典字段 / 组织选择字段 / 文件上传字段 / 验证码」）：

1. 骨架与契约：`DictSelect`、`UserSelectField` / `OrgSelectField`、`FileUploadField`、`Captcha` 等组件的 Props / 事件 / 插槽契约与字段壳装配先行落地。
2. 占位语义：后端未就绪时不发请求，呈现空态 / 禁用态 / 降级提示，并与异常与空状态（`03-2`）的反馈口径一致。
3. 占位契约测试：覆盖占位态渲染、禁用态、降级分支与契约形状（不写死数据）。
4. 回补衔接：`06-4` ~ `06-7` 落地真实实现时，改数据通路不改对外契约。

**完成标准**：占位版组件可被页面引用且不产生后端请求；占位契约测试通过并纳入前端门禁；回补条（`06-4` ~ `06-7`）确认只需替换数据通路；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[01_组件设计_字典字段](../../../设计/组件设计/06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)、[05_组件设计_组织选择字段](../../../设计/组件设计/06_字段类/05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)、[06_组件设计_文件上传字段](../../../设计/组件设计/06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)、[10_组件设计_验证码](../../../设计/组件设计/06_字段类/10_组件设计_验证码/10_组件设计_验证码.md)（均含可交互原型）

## 3. 需求 06-2：基础与数据源字段 <a id="r06-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：日期 / 金额 / 枚举 / 树 / 级联是业务表单最高频字段；若各写各的时区格式化、精度校验、选项加载与缓存，会出现展示口径不一与重复请求。

**内容**（《组件设计》字段类「日期时间字段 / 数值与金额字段 / 开关与枚举字段 / 树选择字段 / 级联选择」）：

1. 日期时间字段 `DateField` / `DateRangeField` / `TimeField`：时区、格式化与只读回显契约。
2. 数值与金额字段 `NumberField` / `AmountField` / `PercentField`：精度、范围校验与金额格式化（格式化复用 `02-6`）。
3. 开关与枚举字段 `SwitchField` / `InlineSwitch` / `EnumField` / `EnumCheckboxField`：三态开关、列表内联切换、自定义选项集枚举。
4. 树选择字段 `TreeSelectField` / `MenuTreeSelect`：树数据、懒加载与只读路径回显（树数据经树数据能力 `tree-data`（`BaseTreeData`，投影按需）与树域基类 `BaseTree`）。
5. 级联选择 `CascaderField` / `useCascader`：多级联动、懒加载、任意级可选、多选、搜索、路径回显。

**完成标准**：五类字段可用并按 locale / 时区正确展示；校验规则生效；Vitest 覆盖格式化与校验契约；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[02_组件设计_日期时间字段](../../../设计/组件设计/06_字段类/02_组件设计_日期时间字段/02_组件设计_日期时间字段.md)、[03_组件设计_数值与金额字段](../../../设计/组件设计/06_字段类/03_组件设计_数值与金额字段/03_组件设计_数值与金额字段.md)、[08_组件设计_开关与枚举字段](../../../设计/组件设计/06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)、[04_组件设计_树选择字段](../../../设计/组件设计/06_字段类/04_组件设计_树选择字段/04_组件设计_树选择字段.md)、[12_组件设计_级联选择](../../../设计/组件设计/06_字段类/12_组件设计_级联选择/12_组件设计_级联选择.md)（均含可交互原型）

## 4. 需求 06-3：富文本与高级交互字段 <a id="r06-3"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：富文本涉及双向 XSS 清洗与编辑器内核加载，穿梭框与标签输入交互密度高；三者不依赖后端数据结构，但都要求统一实现，否则每处各写一套清洗与交互逻辑，安全与体验都不可控。

**内容**（《组件设计》字段类「富文本字段 / 穿梭框 / 标签输入」）：

1. 富文本字段 `RichTextField` / `MarkdownField` / `RichTextViewer` / `sanitizeHtml`：双模式、白名单双向清洗（前端 DOMPurify + 后端白名单）、只读渲染；编辑器内核经编辑器内核能力 `editor-kernel`（`BaseEditorKernel`，投影按需；与代码编辑器共用，独立分包）；图片上传经上传引擎能力 `upload-engine`（`BaseUploadEngine`，投影按需），文件后端未就绪时降级为占位。
2. 穿梭框 `TransferField` / `useTransfer`：双列表穿梭、搜索、分组、分页 / 异步、上限。
3. 标签输入 `TagInput` / `useTagInput`：建议与自由新建、去重、数量 / 长度上限、颜色映射、粘贴批量。

**完成标准**：三类字段可用；富文本 XSS 双向清洗验证通过；编辑器内核与上传引擎按能力契约接入；Vitest 覆盖清洗与交互分支；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[07_组件设计_富文本字段](../../../设计/组件设计/06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)、[09_组件设计_穿梭框](../../../设计/组件设计/06_字段类/09_组件设计_穿梭框/09_组件设计_穿梭框.md)、[11_组件设计_标签输入](../../../设计/组件设计/06_字段类/11_组件设计_标签输入/11_组件设计_标签输入.md)（均含可交互原型）、《[架构设计 · 性能与安全](../../../设计/架构设计/31_架构设计_性能与安全.md)》安全相关节

## 5. 需求 06-4：验证码字段 <a id="r06-4"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：验证码是登录、注册与敏感操作的安全前置，图形（失败阈值强制、刷新、一次性失效）、滑块、短信（脱敏、倒计时、限流）三类形态与后端认证流程强耦合，必须与认证阶段同步实现。

**内容**（《组件设计》字段类「验证码」）：

1. `Captcha` / `useCaptcha`：图形验证码（失败阈值后强制、刷新、一次性失效）。
2. 滑块验证：轨迹与二次校验。
3. 短信验证码：手机号脱敏、倒计时、发送限流、错误提示。

**完成标准**：三类验证码可用、失败阈值与限流行为生效；与后端认证接口契约一致；Vitest 覆盖阈值与倒计时分支。**回补窗口**：阶段六（认证与安全）就绪后。

**参考文档**：《组件设计》[10_组件设计_验证码](../../../设计/组件设计/06_字段类/10_组件设计_验证码/10_组件设计_验证码.md)（含可交互原型）

## 6. 需求 06-5：组织选择字段 <a id="r06-5"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：用户 / 岗位 / 部门 / 组织选择字段依赖平台组织模型（部门树、用户列表、岗位），是权限与业务流程（审批人、数据归属）的高频字段，需与后端组织接口契约一致并支持远程搜索、多选与只读回显。

**内容**（《组件设计》字段类「树选择字段 / 组织选择字段」）：

1. `UserSelectField` / `PostSelectField` / `OrgSelectField`：远程搜索、多选、只读回显、已删除 / 停用对象占位。
2. `DeptTreeSelect`：部门树选择（与权限数据范围口径一致）。
3. 数据来源统一走组织相关 store 并复用缓存；批量按 id 回显走批量接口，避免 N+1；用户展示统一经用户展示能力 `user-display`（`BaseUserDisplay`，投影按需）。

**完成标准**：三类组织选择字段可用、远程搜索与多选正确、只读回显稳定；Vitest 覆盖回显与搜索分支。**回补窗口**：阶段七（RBAC 基础模块）就绪后。

**参考文档**：《组件设计》[05_组件设计_组织选择字段](../../../设计/组件设计/06_字段类/05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)、[04_组件设计_树选择字段](../../../设计/组件设计/06_字段类/04_组件设计_树选择字段/04_组件设计_树选择字段.md)（均含可交互原型）、《[架构设计 · 子系统 · 权限计算引擎](../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md)》

## 7. 需求 06-6：字典字段 <a id="r06-6"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：字典是下拉、级联与只读回显的通用数据源，若不统一走缓存与版本比对，同一页面会重复请求同一字典，且字典变更后标签展示不一致。

**内容**（《组件设计》字段类「字典字段」）：

1. `DictSelect` / `DictCascader`：字典下拉与字典级联，支持多选、搜索、禁用项。
2. `getDictLabel`：列表与详情中的字典标签回显。
3. `useDictStore`：字典数据经 store 复用缓存与版本比对，避免同屏重复请求；批量子项加载走批量接口。
4. 选项源统一经选项源能力 `option-source`（`BaseOptionSource`，投影按需），与静态选项控件（`05-1`）共用加载与缓存口径。

**完成标准**：字典字段与标签回显可用、缓存命中不重复请求、字典变更后展示同步；Vitest 覆盖缓存与版本比对分支。**回补窗口**：阶段八（通用能力 · 字典）就绪后。

**参考文档**：《组件设计》[01_组件设计_字典字段](../../../设计/组件设计/06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)（含可交互原型）、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「取数与缓存协作」节

## 8. 需求 06-7：文件上传字段 <a id="r06-7"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：文件上传（分片、秒传、断点续传、预签名回显）涉及存储与安全契约，是附件、图片、导入、富文本等场景的公共能力，必须统一经上传引擎能力实现，避免各处各写一套上传逻辑。

**内容**（《组件设计》字段类「文件上传字段」）：

1. `FileUploadField` / `ImageUploadField` / `FileListField` / `useFileUpload`：分片、秒传、断点续传、数量与大小限制、只读回显。
2. 上传细节统一经上传引擎能力 `upload-engine`（`BaseUploadEngine`，投影按需；与富文本、头像、导入共用）；预签名 URL 获取与失效重取经预签名能力 `presigned-url`（`BasePresignedUrl`，投影按需）。
3. 后端未就绪时按降级语义呈现（禁用上传、占位列表），不产生无效请求。

**完成标准**：上传与回显可用、分片与断点续传与后端契约一致、失败重试与降级生效；Vitest 覆盖分片与预签名失效分支。**回补窗口**：阶段八（通用能力 · 文件）就绪后。

**参考文档**：《组件设计》[06_组件设计_文件上传字段](../../../设计/组件设计/06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（含可交互原型）、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「取数与缓存协作」节
