## 1. 域说明 <a id="intro"></a>

本域对应[《组件设计》](../../../设计/组件设计/01_组件设计_总览.md)「基础控件类」（`05_基础控件类/`，8 节点），是无数据源、无特殊格式的基础输入控件，均派生输入域基类 `BaseInput`（组合输入形态能力 `input-control` + 字段编排能力 `field`）。

- **八件**：文本框 `TextField`、文本域 `TextareaField`、密码框 `PasswordField`、数字框 `NumberInput`、下拉框 `SelectInput`（静态选项）、单选 `RadioField`、复选 `CheckboxField`、开关 `SwitchInput`。
- **与字段类的关系**：字典 / 枚举 / 金额 / 上传等带数据源或格式语义的字段（需求域 06）在本域八件之上扩展，本域只做「无数据源、无特殊格式」的基础形态。

**依据**：《组件设计》基础控件类各节点、《[前端开发规范](../../../规范/前端开发规范.md)》「前端基类体系（开放式，强制）」节、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「前端基类体系（开放式，对齐后端基类体系）」「八类组件与边界」节。
**用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
**目标**：八件基础控件可用并作为字段类的组合底座；受控绑定、三态、校验触发等行为在输入域基类定义一次。

## 2. 需求 05-1：八基础控件 <a id="r05-1"></a>

优先级：2（高）　|　状态：已完成　|　完成日期：2026-09-17

**背景与动机**：所有带数据源或格式语义的字段（字典、金额、上传等）都建立在基础输入之上；基础控件若不在本阶段统一（受控绑定、三态、`disabled` 合并、校验触发、只读回显、大小与密度），字段类与后续全部表单会重复实现并逐渐发散。

**内容**（《组件设计》基础控件类「文本框 / 文本域 / 密码框 / 数字框 / 下拉框 / 单选 / 复选 / 开关」）：

1. `TextField`：单行文本（前后缀、清空、字数限制）。
2. `TextareaField`：多行文本（行数 / 自适应、字数统计、换行保留）。
3. `PasswordField`：密码输入（明文切换、强度提示、不回填）。
4. `NumberInput`：纯数字（精度 / 范围 / 步进 / 千分位；金额语义在 `06-2` 的金额字段）。
5. `SelectInput`：静态选项下拉（单选 / 多选、搜索、分组；字典 / 枚举在 `06-2`、`06-6`）。
6. `RadioField`：单选（radio / button / segmented）。
7. `CheckboxField`：复选（checkbox / tag、全选、数量上下限）。
8. `SwitchInput`：布尔开关（三态、加载态、危险切换确认；字段语义在 `06-2` 的开关字段）。
9. 统一派生输入域基类 `BaseInput` 并组合值·字段链能力：受控 `modelValue` / `update:modelValue`、三态、`disabled` 合并、`change` 上报、校验触发在基类定义一次；只读态以 `disabled` 或纯文本回显，不做两套组件；校验与格式化复用 `02-6`。

**完成标准**：八件控件可用、字段壳可装配（label / 必填 / 错误 / 栅格）；受控与三态行为一致；Vitest 覆盖八件的关键契约；`vue-tsc`、ESLint、Vitest 全通过。
