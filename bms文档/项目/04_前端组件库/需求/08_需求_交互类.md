## 1. 域说明 <a id="intro"></a>

本域对应[《组件设计》](../../../设计/组件设计/01_组件设计_总览.md)「交互类」（`08_交互类/`，19 节点），承载操作流的容器、设计器与专用面板，组合容器 + 展示 + 字段类能力。

- **归属说明**：该类的「侧边菜单」按执行顺序前移至需求域 03（编号 `03-4`，主框架侧栏组成部分）；本域只承接其余 18 节点。
- **占位口径**：本域多数组件依赖后端能力（表单定制、工作流、国际化、报表、AI），未就绪期间先交付**占位版**（骨架 + 空态 / 禁用态 / 降级语义 + 占位契约测试，对齐后端 Null 占位模式）——由 `08-1` 统一承接。
- **回补锚点**：权限配置 ← 阶段七（RBAC）；导入导出 / 表单设计器与渲染器 / 国际化文案编辑器 ← 阶段八（通用能力）；审批流与流程建模 ← 阶段九（工作流引擎）；报表 / 大屏设计器 ← 阶段十六（报表 BI）；AI 助手 ← 阶段十九（AI 能力）。
- **无强依赖部分**：图标选择器与代码表达式编辑器（`08-2`）、面板与工具（`08-3`）可在占位版之后直接推进。

**依据**：《组件设计》交互类各节点、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「渲染器与扩展点注册机制」「阶段落地（地基波 + 回补）」节、《[架构设计 · 子系统 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》。
**用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
**目标**：操作流与设计器可用且独立分包（首屏不加载）；依赖后端的交互件先以占位版纳管，回补后与后端契约一致。

## 2. 需求 08-1：占位版交付（依赖后端的交互件） <a id="r08-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：设计器、审批流、报表与 AI 助手是平台最重的交互件，后端能力分散在阶段七 ~ 十九；若等到各自阶段再动手，组件库会长期缺件。先冻结契约与占位语义、并把分包边界立好，后续每阶段只补数据通路与真实渲染。

**内容**（《组件设计》交互类「导入导出 / 表单设计器 / 表单渲染器 / 权限配置 / 审批流展示 / 流程建模器 / 报表设计器 / 大屏设计器与播放 / AI 助手 / 国际化文案编辑器」）：

1. 骨架与契约：`ImportDialog`、`FormDesigner`、`PermissionConfig`、`ProcessDesigner`、`ReportDesigner`、`AiAssistant` 等组件的 Props / 事件 / 插槽契约与容器装配先行落地。
2. 占位语义：后端未就绪时不发请求，呈现空态 / 禁用态 / 降级提示（复用 `03-2` 的空状态件）。
3. 分包边界：重交互件（bpmn-js、gridstack、vue-flow、CodeMirror、ECharts）与 AI 面板在占位阶段即确定独立分包与懒加载入口，首屏不加载。
4. 回补衔接：`08-4` ~ `08-10` 落地真实实现时，改数据通路与渲染，不改对外契约与分包入口。

**完成标准**：占位版组件可被页面引用且不产生无效请求；分包入口就位（首屏体积在预算内）；占位契约测试通过并纳入前端门禁；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[01_组件设计_导入导出](../../../设计/组件设计/08_交互类/01_组件设计_导入导出/01_组件设计_导入导出.md)、[05_组件设计_表单设计器](../../../设计/组件设计/08_交互类/05_组件设计_表单设计器/05_组件设计_表单设计器.md)、[07_组件设计_权限配置](../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_组件设计_权限配置.md)、[06_组件设计_流程建模器](../../../设计/组件设计/08_交互类/06_组件设计_流程建模器/06_组件设计_流程建模器.md)、[08_组件设计_报表设计器](../../../设计/组件设计/08_交互类/08_组件设计_报表设计器/08_组件设计_报表设计器.md)、[10_组件设计_AI助手](../../../设计/组件设计/08_交互类/10_组件设计_AI助手/10_组件设计_AI助手.md)（均含可交互原型）

## 3. 需求 08-2：图标选择器与代码表达式编辑器 <a id="r08-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：图标选择是菜单、快捷入口与表单配置的通用输入；代码表达式、SQL、Cron 编辑器是流程条件、查询与调度配置的输入工具。两者都不依赖后端能力，但都要求统一实现（图标注册表、CodeMirror 6 内核与分包），否则各处各写会带来内核重复加载与体积膨胀。

**内容**（《组件设计》交互类「图标选择器 / 代码表达式编辑器」）：

1. `IconPicker` / `IconDisplay` / `IconLibrary` / `iconRegistry`：图标库浏览、搜索、预览与选择；图标经图标注册表登记，未注册不可用。
2. `CodeEditor` / `SqlEditor` / `ExpressionEditor` / `CronEditor` / `CodeViewer` / `useCodeEditor`：CodeMirror 6 内核封装（语法高亮、自动补全、只读查看）；内核加载与释放经编辑器内核片段 `useEditorKernel`（与富文本共用），**独立分包**。

**完成标准**：图标选择与预览可用、注册表唯一性校验生效；四类代码编辑器与只读查看可用、内核复用不重复加载、分包生效；Vitest 覆盖注册表与内核复用分支；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》[03_组件设计_图标选择器](../../../设计/组件设计/08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)、[04_组件设计_代码表达式编辑器](../../../设计/组件设计/08_交互类/04_组件设计_代码表达式编辑器/04_组件设计_代码表达式编辑器.md)（均含可交互原型）

## 4. 需求 08-3：面板与工具 <a id="r08-3"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：向导、偏好设置、批量操作栏、主题品牌、租户切换与打印导出是平台的配置与运营交互面，散落在多个页面但形态固定；不统一会出现操作栏样式各异、主题与租户切换生效范围不一致、打印样式不可控。

**内容**（《组件设计》交互类「向导与步骤 / 偏好设置面板 / 批量操作栏 / 主题与品牌化 / 租户切换 / 打印与导出 PDF」）：

1. `Wizard` / `WizardStep`：分步向导（步骤校验、前后跳转、完成态）。
2. `PreferencePanel`：用户偏好设置（持久化经偏好持久化片段 `usePreference`）。
3. `BatchActionBar` / `useSelection`：批量操作栏与选中状态（自身可用；与列表组件的接入随需求域 07 的收口进行，不阻塞本项）。
4. `ThemeSwitcher` / `ThemeProvider` / `useTheme`：主题与品牌化切换，消费设计令牌片段 `useDesignToken`。
5. `TenantSwitcher` / `useTenant`：租户切换与上下文刷新。
6. `PrintTemplate` / `PrintPreview` / `usePrint`：打印模板与导出 PDF（样式与分页可控）。
7. 拖拽交互统一经拖拽基座片段 `useDragDrop`；语言与格式上下文统一经语言上下文片段 `useLocale`。

**完成标准**：六项可用并与布局壳正确协作；主题与租户切换即时生效且不残留旧上下文；打印预览与导出结果一致；Vitest 覆盖切换与持久化分支。**回补窗口**：无后端强依赖，占位版之后即可推进；租户上下文与偏好落库随阶段七 ~ 八完善。

**参考文档**：《组件设计》[14_组件设计_向导与步骤](../../../设计/组件设计/08_交互类/14_组件设计_向导与步骤/14_组件设计_向导与步骤.md)、[15_组件设计_偏好设置面板](../../../设计/组件设计/08_交互类/15_组件设计_偏好设置面板/15_组件设计_偏好设置面板.md)、[16_组件设计_批量操作栏](../../../设计/组件设计/08_交互类/16_组件设计_批量操作栏/16_组件设计_批量操作栏.md)、[17_组件设计_主题与品牌化](../../../设计/组件设计/08_交互类/17_组件设计_主题与品牌化/17_组件设计_主题与品牌化.md)、[18_组件设计_租户切换](../../../设计/组件设计/08_交互类/18_组件设计_租户切换/18_组件设计_租户切换.md)、[19_组件设计_打印与导出PDF](../../../设计/组件设计/08_交互类/19_组件设计_打印与导出PDF/19_组件设计_打印与导出PDF.md)（均含可交互原型）

## 5. 需求 08-4：权限配置 <a id="r08-4"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：菜单 / 表单 / 动作权限与数据范围是平台权限体系的操作界面；权限树隐含推导、字段权限矩阵与主体绑定的交互复杂，且必须与后端权限模型逐字段对齐，否则配权结果与运行时判定不一致。

**内容**（《组件设计》交互类「权限配置」）：

1. `PermissionConfig` / `PermTree` / `FieldPermMatrix` / `DataScopeConfig` / `SubjectBinding` / `usePermissionConfig`：菜单 / 表单 / 动作权限树与隐含推导、字段权限矩阵、动作数据范围、主体（角色 / 用户 / 岗位）绑定。
2. 全量覆盖提交与幂等：重复提交结果一致；配置变更后前端权限上下文（`useAccess`，`02-3`）刷新。
3. 与后端权限计算引擎契约一致，避免前端展示与运行时判定偏差。

**完成标准**：权限树 / 矩阵 / 数据范围 / 主体绑定可用、隐含推导正确、提交幂等、上下文即时刷新；Vitest 覆盖推导与幂等分支。**回补窗口**：阶段七（RBAC 基础模块）就绪后。

**参考文档**：《组件设计》[07_组件设计_权限配置](../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_组件设计_权限配置.md)（含可交互原型）、《[架构设计 · 子系统 · 权限计算引擎](../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md)》

## 6. 需求 08-5：导入导出 <a id="r08-5"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：批量数据进出是管理端高频操作，涉及模板下载、文件校验、幂等提交、错误行报告与大数据量异步导出；若各页各写，会出现重复导入、进度不可见、错误无法定位。

**内容**（《组件设计》交互类「导入导出」）：

1. `ImportDialog` / `ExportButton` / `useImport` / `useExport`：模板下载、文件校验与上传进度、幂等键、错误行报告与明细下载。
2. 导出支持当前筛选条件导出与字段脱敏；大数据量走异步导出，任务提交 / 轮询进度 / 取消 / 结果下载统一经异步任务片段 `useAsyncTask`。
3. 上传细节经上传引擎片段 `useUploadEngine`（与文件上传字段 `06-7` 共用）。

**完成标准**：导入幂等与错误报告正确、导出筛选与脱敏生效、异步任务进度与取消可用；Vitest 覆盖幂等与错误行解析分支。**回补窗口**：阶段八（通用能力 · 异步任务）就绪后。

**参考文档**：《组件设计》[01_组件设计_导入导出](../../../设计/组件设计/08_交互类/01_组件设计_导入导出/01_组件设计_导入导出.md)（含可交互原型）、《[架构设计 · 子系统 · 任务调度](../../../设计/架构设计/17_架构设计_子系统_任务调度.md)》

## 7. 需求 08-6：表单设计器与表单渲染器 <a id="r08-6"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：表单定制是平台可扩展性的核心能力：业务方拖拽配置表单、运行时按元数据渲染。设计器与渲染器必须成对实现、共享同一份元数据契约，否则「设计的」与「渲染的」不一致。

**内容**（《组件设计》交互类「表单设计器 / 表单渲染器」、《布局设计》表单定制节点）：

1. `FormDesigner` / `FieldPanel` / `DesignerCanvas` / `FieldPropertyPanel` / `ExtFieldDialog` / `useFormDesigner`：三区拖拽（拖拽基座片段 `useDragDrop`）、分区列数与跨列、字段属性配置、租户自建字段、查询区与明细区配置、三级层级与保存发布。
2. `FormRenderer` / `FormField` / `useFormRender`：布局元数据驱动渲染、字段类型分发、三态与字段权限叠加、校验与提交、明细区；元数据加载与缓存经表单元数据片段 `useFormMeta`。
3. 字段类型分发复用字段类与基础控件（`06-*`、`05-1`）；渲染器注册经注册表基座（`10-2`），未注册类型不生效。

**完成标准**：设计器拖拽、属性配置与保存发布可用；渲染器按元数据正确分发并支持三态与权限叠加；设计与渲染元数据契约一致；Vitest 覆盖拖拽落点与渲染分发分支。**回补窗口**：阶段八（通用能力 · 表单定制）就绪后。

**参考文档**：《组件设计》[05_组件设计_表单设计器](../../../设计/组件设计/08_交互类/05_组件设计_表单设计器/05_组件设计_表单设计器.md)、[12_组件设计_表单渲染器](../../../设计/组件设计/08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)（均含可交互原型）、《布局设计》[14_布局设计_表单定制](../../../设计/布局设计/14_布局设计_表单定制.html)、《[架构设计 · 子系统 · 表单定制](../../../设计/架构设计/30_架构设计_子系统_表单定制.md)》

## 8. 需求 08-7：国际化文案编辑器 <a id="r08-7"></a>

**完成标准**：四件可用、网格编辑与批量保存正确、缺失筛选准确、导入导出可用、保存后文案即时生效；Vitest 覆盖筛选与缓存失效分支。**回补窗口**：阶段八（通用能力 · 国际化）就绪后。

## 9. 需求 08-8：审批流展示与流程建模器 <a id="r08-8"></a>
