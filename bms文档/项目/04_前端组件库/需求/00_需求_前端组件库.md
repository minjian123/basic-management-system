- **组件契约前置**：《[组件设计](../../../设计/组件设计/01_组件设计_总览.md)》总览 + 全部节点（各含设计文档与可交互原型）**已全部交付**，是本次组件实施的契约依据；实施须与原型交互和视觉一致（原型即验收基准）。
- **本次为全新构建**：前端代码已清空，按现行基类口径从零实现，不涉及旧口径迁移。
- **范围外**：移动端宿主与组件（`frontend/apps/mobile` + `frontend/packages/ui-vant`，另算）；前端页面开发（后续）；运行时模块加载（Module Federation）与模块治理（阶段五及后续）；各依赖条的真实后端接口实现（随对应阶段实现）。

## 2. 前端组件库目标与范围 <a id="goal"></a>

**阶段目标**（《总体项目规划》「阶段内容与完成标准」节）：**前端基类体系（固定前三级 + 组件侧继承链）与基础组件（布局（含侧边菜单）/ 容器 / 基础控件 / 基础类 / 异常与空状态）全部可用、组件单测通过、与可交互原型一致；微前端骨架起步（宿主薄壳与模块契约）**。周期口径 7 周（兼职口径，含缓冲与 M4 收口）；组件地基不完成则前端页面开发无法推进。

**范围内**（共 40 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 02 基础组件类 | 基类体系（固定前三段 / 组件根 / 能力基类族 / 组件基类族 / 体系机制）与基础类横切底座（请求封装 / 权限指令 / 格式化工具 / 设计令牌） |
| 03 布局组件类 | 弹窗抽屉表单、异常与空状态、结构布局（含多标签导航）、侧边菜单、框架与容器 |
| 04 容器组件类 | 通用容器八件（滚动 / 懒加载 / 全屏 / 自适应高度 / 虚拟列表 / 加载遮罩 / 分区 / 宽高比） |
| 05 基础控件类 | 八种基础输入控件（文本 / 文本域 / 密码 / 数字 / 下拉 / 单选 / 复选 / 开关） |
| 06 字段类 | 占位版交付、基础与数据源字段、富文本与高级交互字段、验证码、组织选择、字典、文件上传 |
| 07 展示类 | 占位版交付、轻量展示件、文件预览与审计差异、通知与消息、数据呈现、图表卡、全局搜索 |
| 08 交互类 | 占位版交付、图标与代码编辑器、面板与工具、权限配置、导入导出、表单设计器与渲染器、国际化文案编辑器、审批流与流程建模、报表与大屏设计器、AI 助手 |
| 10 微前端骨架 | 宿主外壳与模块加载器、模块契约与注册表基座 |

**范围外**：

- 移动端宿主与组件（`frontend/apps/mobile` / `frontend/packages/ui-vant`，Vant 生态；同契约另一实现，不在本次范围）。
- 前端页面（后续）与产品仓库前端模块。
- 运行时模块加载（Module Federation）、模块清单与版本字段、隔离增强 / 版本协商 / 灰度回滚 / 按模块观测等治理项——随后续与后续阶段（清单见[阶段五需求提出清单](../../05_前端插件化/README.md)）。
- 各依赖条的真实后端接口——随对应阶段实现（阶段窗口见计划文档）。

> 边界说明：组件实现均须沿《[前端基类清单](../../../前端基类清单.md)》的继承链派生、横切功能经链上基类取得，公共字段与方法只在链上对应基类维护（见《[前端开发规范](../../../规范/前端开发规范.md)》「前端基类体系（强制）」节）；《组件设计》各节点为契约依据，实现偏离契约须先改设计节点。
