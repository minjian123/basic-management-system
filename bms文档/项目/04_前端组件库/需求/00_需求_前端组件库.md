**编号与归属口径**：

- 需求编号为 `{域两位}-{序号}`，**编号顺序即执行顺序**：任一条只依赖编号比它小的条目（除非个别依赖关系，无前向依赖）。
- 需求域编号沿用《组件设计》类别号，故 **域 01 空缺**（对应《组件设计》01 总览）；**域 09 空缺**（该类三节点——请求封装 / 权限指令 / 格式化工具——是全组件库横切底座，按执行顺序并入需求域 02 的 `02-6`）。
- 三件组件按执行顺序前移需求域（契约与原型归属不变）：**弹窗抽屉表单**（组件设计容器类 01）→ `03-1`；**异常与空状态**（组件设计展示类 05）→ `03-2`；**侧边菜单**（组件设计交互类 13）→ `03-4`。

**波次与占位口径**：

- **地基波（阶段四内闭环，18 条）**：基类体系与基础类横切底座、八基础控件、弹窗抽屉表单、异常与空状态、通用容器、结构布局、侧边菜单、框架与容器、微前端骨架，以及三域依赖条的**占位版交付**（`06-1` / `07-1` / `08-1`）。
- **依赖回补波（21 条）**：字段类 / 展示类 / 交互类中依赖后端能力的条目，未就绪期间按**占位语义**落地（不发请求、空态 / 禁用态 / 降级提示 + 占位契约测试，对齐后端 Null 占位模式），**真实实现随对应阶段回补**（回补窗口逐条写在各需求「完成标准」内）。
- **共同前置**：契约 / 数据根（`BaseEntity` / `BasePageQuery` / `BaseApi` / `createCrudStore` / `stableStringify`）已在阶段一落地，本阶段复用不重复建设。

**依据**：《[总体项目规划](../../../规划/总体项目规划.md)》「工作分解结构（WBS）」节（WBS 阶段四）、「阶段内容与完成标准」节（阶段四）、「里程碑」节（M4）、「阶段工期估算基线」节；《[项目规划说明](../../../规划/项目规划说明.md)》「前端页面清单与菜单机制」节、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》、《[架构设计 · 前端架构](../../../设计/架构设计/08_架构设计_前端架构.md)》、《[前端基类清单](../../../前端基类清单.md)》、《[前端开发规范](../../../规范/前端开发规范.md)》、《[需求文档规范](../../../规范/需求文档规范.md)》。

**组件契约前置**：《[组件设计](../../../设计/组件设计/01_组件设计_总览.md)》总览 + 118 个节点（各含设计文档与可交互原型）**已全部交付**，是本次组件实施的契约依据；实施须与原型交互和视觉一致（原型即验收基准）。

**范围外**：移动端宿主与组件（`frontend/apps/mobile` + `frontend/packages/ui-vant`，专项 `02_07` S4 已收口，另算）；前端页面开发（阶段十五）；运行时模块加载与模块治理（阶段五及后续）；各依赖条的真实实现（随对应后端阶段）。

## 2. 前端组件库目标与范围 <a id="goal"></a>

**M4 目标**（《总体项目规划》「里程碑」节 M4 行）：**前端基类体系（开放式）与地基波组件（布局（含侧边菜单）/ 容器 / 基础控件 / 基础类 / 异常与空状态）全部可用、组件单测通过、与可交互原型一致；微前端骨架起步（宿主薄壳与模块契约）**。周期口径 7 周（兼职口径，含缓冲与 M4 收口）；组件地基不完成则前端页面开发无法推进。

**范围内**（共 39 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 02 基础组件类 | 开放式基类体系（根系 / 组件根 / 能力机制与预置 31 能力 / 域基类 / 扩展登记）与基础类横切底座（请求封装 / 权限指令 / 格式化工具） |
| 03 布局组件类 | 弹窗抽屉表单、异常与空状态、结构布局（含标签栏本体）、侧边菜单、框架与容器 |
| 04 容器组件类 | 通用容器八件（滚动 / 懒加载 / 全屏 / 自适应高度 / 虚拟列表 / 加载遮罩 / 分区 / 宽高比） |
| 05 基础控件类 | 八种基础输入控件（文本 / 文本域 / 密码 / 数字 / 下拉 / 单选 / 复选 / 开关） |
| 06 字段类 | 占位版交付、基础与数据源字段、富文本与高级交互字段、验证码、组织选择、字典、文件上传 |
| 07 展示类 | 占位版交付、轻量展示件、文件预览与审计差异、通知与消息、数据呈现、图表卡、全局搜索 |
| 08 交互类 | 占位版交付、图标与代码编辑器、面板与工具、权限配置、导入导出、表单设计器与渲染器、国际化文案编辑器、审批流与流程建模、报表与大屏设计器、AI 助手 |
| 10 微前端骨架 | 宿主外壳与模块加载器、模块契约与注册表基座 |

**范围外**：

- 移动端宿主与组件（`frontend/apps/mobile` / `frontend/packages/ui-vant`，Vant 生态；同接口多实现，不复用 PC 组件实现）。
- 前端页面（阶段十五）与产品仓库前端模块。
- 运行时模块加载（Module Federation）、模块清单与版本字段、隔离增强 / 版本协商 / 灰度回滚 / 按模块观测等治理项——随阶段五与后续阶段（清单见[阶段五需求提出清单](../../05_前端插件化/README.md)）。
- 各依赖条的真实实现——随对应后端阶段回补，回补窗口写在各需求「完成标准」内。

> 边界说明：组件实现均须派生对应层基类并组合能力，公共字段与方法只在基类或能力维护（见《[前端开发规范](../../../规范/前端开发规范.md)》「前端基类体系（开放式，强制）」节）；《组件设计》各节点为契约依据，实现偏离契约须先改设计节点。

## 4. M4 验收门禁 <a id="accept"></a>

门禁定义（《总体项目规划》「里程碑」节 M4 行）：**前端基类体系（开放式）与地基波组件全部可用、组件单测通过、与可交互原型一致；微前端骨架起步（宿主薄壳与模块契约）**。逐项核对：

| 验收点 | 核对方式 | 对应需求 | 结论 | 证据索引 |
