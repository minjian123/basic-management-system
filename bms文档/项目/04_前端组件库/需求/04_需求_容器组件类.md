## 1. 域说明 <a id="intro"></a>

本域对应[《组件设计》](../../../设计/组件设计/01_组件设计_总览.md)「容器组件类」（`04_容器组件类/`，9 节点），沉淀承载内容的容器，均组合容器片段 `useContainer` / 表单容器片段 `useFormContainer`。

- **本域范围**：滚动、懒加载、全屏、自适应高度、虚拟列表、加载遮罩、分区、宽高比八件通用容器。
- **归属说明**：该类的「弹窗抽屉表单」按执行顺序前移至需求域 03（编号 `03-1`，结构布局的确认能力依赖它）；本域只承接其余八件。
- **公共前置**：四态（加载 / 空 / 错误 / 内容）与占位防抖动复用需求域 03 的异常与空状态（`03-2`）。

**依据**：《[项目规划说明](../../../规划/项目规划说明.md)》「前端页面清单与菜单机制」节、《组件设计》容器组件类通用容器各节点、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「八类组件与边界」「分包与加载策略」节。
**用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
**目标**：滚动、懒加载、虚拟列表等容器可直接复用，避免各页各写；长列表与懒加载场景性能达标。

## 2. 需求 04-1：通用容器（滚动 / 懒加载 / 全屏 / 自适应 / 虚拟列表 / 遮罩 / 分区 / 宽高比） <a id="r04-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：滚动区、懒加载、全屏、高度自适应、大列表虚拟滚动、加载四态、分区与宽高比占位是页面常见的容器级需求；各页各写会出现滚动条样式不一、加载闪烁、长列表卡顿、图片抖动等一致性与性能问题。

**内容**（《组件设计》容器组件类「滚动容器 / 懒加载容器 / 全屏容器 / 自适应高度容器 / 虚拟列表容器 / 加载遮罩容器 / 分区容器 / 宽高比容器」、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》「分包与加载策略」节）：

1. `ScrollContainer`：统一滚动区（自定义滚动条、位置保持、触底加载）。
2. `LazyContainer`：进入视口才渲染（占位防抖动，配合路由级分包与组件懒加载）。
3. `FullscreenContainer`：全屏展示（Esc 退出、失败降级）。
4. `AutoHeight`：高度占满父剩余空间（减头部 / 工具栏）。
5. `VirtualList`：大数据只渲染可视区 + 缓冲。
6. `LoadingContainer`：加载 / 空 / 错误 / 内容四态（延迟显示防闪烁；四态复用 `03-2` 的 `useFeedback` 与空状态件）。
7. `SectionContainer`：轻量分区（标题 / 工具区 / 内容 / 折叠，无卡片外观）。
8. `AspectRatio`：固定宽高比容器（占位防抖动）。

**完成标准**：八项容器可用且可组合；虚拟列表在大数据集下滚动流畅；懒加载容器与分包策略协作正确；Vitest 覆盖关键行为（触底、四态、可视区计算）；`vue-tsc`、ESLint、Vitest 全通过。
