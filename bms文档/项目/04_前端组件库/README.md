## 1. 波次与口径 <a id="waves"></a>

- **地基波（本期实施）**：机制基类（根系 / 组件根）+ 能力片段（预置 11，开放新增）+ 域基类、布局组件类、容器组件类、基础控件类、基础类、微前端骨架——13 条需求，合计 **152h**。
- **依赖波（占位先行）**：字段 / 展示 / 交互类 8 条——**占位版**（空态 / 禁用态 / 降级语义 + 占位契约测试，对齐后端 Null 占位模式）本期交付，合计 **40h**；**真实实现**（合计 74h）随对应后端阶段（阶段六 / 七 / 八 / 九 / 十六 / 十八 / 十九）就绪后回补。
- **占位口径**：片段 / 域基类 / 组件对依赖后端能力的行为先以占位语义落地（不请求、空结果 / 降级 / 禁用态）并纳入契约测试；真实能力随对应阶段回补。
- **用例口径**：全部用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。
- **验收基准**：组件交互与视觉与《[组件设计 · 总览](../../设计/组件设计/01_组件设计_总览.md)》各节点可交互原型一致（原型即验收基准）。
