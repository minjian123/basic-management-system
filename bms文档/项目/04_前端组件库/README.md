## 阶段口径 <a id="scope"></a>

- **范围**：40 条需求，映射《[组件设计](../../设计/组件设计/01_组件设计_总览.md)》八类组件与微前端骨架；**组件语义与契约边界以《组件设计》各节点为准（原型即验收基准）**。
- **范围外**：移动端宿主与组件（`apps/mobile` / `ui-vant`，随阶段十七）；前端页面（随阶段十五）；运行时模块加载（Module Federation）与模块治理（随阶段五及后续）；各依赖条的真实后端接口实现（随对应阶段）。
- **基类口径（强制）**：前端基类体系与后端同构——固定前三段（总基类 → 能力域基类 → 插件基类）+ 组件侧（组件根 → 能力基类 → 组件基类 → 具体件）；**继承链唯一权威为《[前端基类清单](../../前端基类清单.md)》**，机器护栏 `guard-base-registry` 双向对账清单与代码。
- **落地顺序口径（2026-09-20 拍板）**：依赖后端业务能力的件按**占位契约做通路注入式开发**（未注入即占位、零请求）；已冻结对外契约不改，契约缺口前端可自行冻结新契约并同步登记后端需求；**后端真实落地**待「骨架」（阶段一 ~ 三 + 本阶段地基波 + 阶段五）完成、架构冻结后启动。
- **口径修订（2026-09-21）**：字典字段（`06_06`）为重要组件，其**后端真实取数与缓存**提前落地并登记于后端基座（任务 `02-4-27`，需求 `02-56`），不等阶段八窗口，已端到端打通。
