## 1. 波次与口径 <a id="waves"></a>

- **地基波（18 条需求）**：开放基类体系与基础类横切底座、八基础控件、弹窗抽屉表单、异常与空状态、通用容器、结构布局、侧边菜单、框架与容器、微前端骨架，以及三域依赖条的**占位版交付**（`06-1` / `07-1` / `08-1`）——在阶段四窗口内闭环。
- **依赖回补波（21 条需求）**：字段 / 展示 / 交互类中依赖后端能力的条目——先交付**占位版**（不发请求 + 空态 / 禁用态 / 降级语义 + 占位契约测试，对齐后端 Null 占位模式），**真实实现随对应阶段回补**（回补窗口逐条写在需求「完成标准」内）。
- **占位口径**：片段 / 域基类 / 组件对依赖后端能力的行为先以占位语义落地并纳入契约测试；真实能力随对应阶段回补。
- **用例口径**：全部用例入 Kiwi TCMS（**先登记用例、后写自动化代码**），自动化用例标注 `kiwi_id`。
- **验收基准**：组件交互与视觉与《[组件设计 · 总览](../../设计/组件设计/01_组件设计_总览.md)》各节点可交互原型一致（原型即验收基准）。
- **编号与归属口径**：需求域编号沿用《组件设计》类别号，故域 01（总览）与域 09（基础类三件已并入 `02-6`）无独立文档；三件按执行顺序前移需求域——弹窗抽屉表单 → `03-1`、异常与空状态 → `03-2`、侧边菜单 → `03-4`；**编号顺序 = 执行顺序，无前向依赖**。
- **范围外**：移动端组件（`frontend-mobile/` Vant 生态）；前端页面（阶段十五）；运行时片段加载与片段治理（阶段五及后续，清单见[阶段五需求提出清单](../05_前端插件化/README.md)）。
