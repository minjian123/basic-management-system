## 3. 违规与修复（位置 / 修复 / 回写） <a id="fix"></a>

### 3.1 继承链（A）

| 位置 | 违规 | 修复 |
| --- | --- | --- |
| `useDisplayPlaceholder` / `useFieldPlaceholder` / `useInteractionPlaceholder` | 同一「就绪 / 降级 / 零请求」语义三份链外重复 | 新增核心能力基类 `BasePlaceholderState`；`BaseValue` / `BaseDataState` / `BaseNotice` 继承之；各编排能力基类改父为 `BasePlaceholderState` 并删除重复成员；三组合式改薄投影（具体类直接 `extends BaseDisplay / BaseInput / BaseDataState`） |
| `useBaseTable` / `MetricCard` / `FormRenderer` / `FormDesigner` | 投影内并列第二个基类实例（组合） | 改用主基类链上继承的占位语义（`useBaseTable` 用 `Table`；两件用 `renderer` / `designer`） |
| `composables/useHighlight.ts` | `class HighlightRuntime extends BaseObject` 链外 runtime | 恢复为链上投影（具体件 `extends BaseEditorKernel`），删除 `utils/highlight.ts` |
| `ContentTabs.vue` / `PrintPreview.vue` | 件内定义链上类 | 改为 `useContentTabs` / `useBaseWatermark` 投影 |

### 3.2 单一落点（B）

| 位置 | 违规 | 修复 |
| --- | --- | --- |
| `IconRenderer.vue` | 直引 DOMPurify | `utils/sanitizeHtml.sanitizeSvg`（新增） |
| `RichTextEditor.vue` | 直引 `@tiptap/*` | `composables/useRichTextEditor`（内部投影，不导出以保首屏分包） |
| `IconPicker.vue` / `ScrollContainer.vue` | 直用 localStorage / sessionStorage | `useBasePersistedState` |
| `FilePreview.vue` / `QrCode.vue` | 直建 `<a download>` | `utils/downloadFile.triggerDownload` |
| 全屏 / 可见性 / 观察器 / 视口 / 媒体查询 / 指针拖拽 / 令牌读取（约 15 件） | 浏览器 API 散落 | 新增 `utils/{fullscreen,visibility,observe,media,keyboard,cssVar}.ts` 并收敛 |

### 3.3 可替换实现（C）

| 位置 | 违规 | 修复 |
| --- | --- | --- |
| `ChartEngineAdapter` / `NotificationRealtimeAdapter` / `AiStreamAdapter` | 裸接口注入，未走插件轨 | 新增 `BaseChartEngine` / `BaseRealtimeChannel` / `BaseAiStream`（继承 `BasePluggable`）+ 注册项（继承 `BaseProvider`）+ 注册表（继承 `BaseProviderRegistry`）；内建 ECharts / SSE 继承插件基类；图表引擎经 `chartEngineRegistry` 解析 |

### 3.4 令牌消费（D）

| 位置 | 违规 | 修复 |
| --- | --- | --- |
| 45 文件 240 处 | `var(--bms-*, #hex)` 颜色兜底 | 移除兜底、统一消费令牌 |
| 9 个缺失令牌 | `--bms-color-{fill,primary-light,primary-border,warning-bg,white,focus-ring}`、`--bms-shadow-{sm,md}` 未定义 | 补入 `tokens.scss`（亮 / 暗） |
| `ThemeSwitch` / `WatermarkOverlay` / `ScreenPropertyPanel` / 6 处白字 | 原始色值 | 归位域层（`THEME_ACCENT_PRESETS` / `DEFAULT_CANVAS_BACKGROUND`）或令牌 |

## 4. 分级处置 <a id="grade"></a>

| 项 | 处置 |

## 5. 护栏补强（每类违规沉淀） <a id="guard"></a>

| 违规类 | 护栏 | 落点 |
| --- | --- | --- |
| 继承链 | 组件须实质挂链；组件不得内联链上类；ui-ep 不得链外类（`extends BaseObject`） | `ui-ep/tests/guard-component-inheritance.spec.ts`（强化 + fixture） |
| 单一落点 | 组件不得直引第三方库 / 直用持久化、下载、观察器、媒体查询、令牌读取、全屏 API | `ui-ep/tests/guard-single-source.spec.ts`（新增 + fixture） |
| 令牌消费 | 组件样式不得硬编码色值（令牌源 / 动态值豁免） | `ui-ep/tests/guard-tokens.spec.ts`、`apps/desktop/tests/guard-tokens.spec.ts`（新增 + fixture） |
| 可替换实现 | 插件基类 + 注册表由契约与用例覆盖（注册 / 解析 / 拒重） | 核心用例 + 基类清单登记（护栏候选） |
