## 2. 任务内容 <a id="content"></a>

1. `RadioField.vue`（`frontend/packages/ui-ep/src/components/input/`；移动端 `frontend/packages/ui-vant/src/components/input/` 同契约实现）：静态单选——`widget`（`radio` / `button` / `segmented`）、`options`（`OptionItem`）、`optionType`（button 形态语义色）；空 → `null`、无效值回退空；只读态保留选中高亮但不响应；选项多时换行 / 滚动。
2. `CheckboxField.vue`（同落点双端实现）：静态复选——`widget`（`checkbox` / `tag`）、`options`、`min` / `max`（数量上下限校验并提示）、`selectAll`（全选 / 反选，忽略禁用项）；归一（去重、**按选项顺序输出**、空 → `[]`）；只读态展示已选标签 / 勾选。
3. `SwitchInput.vue`（同落点双端实现）：布尔开关——`activeText` / `inactiveText`、`loading`（切换中禁重复）、`dangerConfirm`（危险切换二次确认）、`threeState`（`null` 显示「未设置」，与 `false` 区分）；值域只暴露布尔 / `null`，后端 `SMALLINT` 1/0 由边界归一（受控值能力 `value`）。
4. **边界**：自定义选项集枚举归字段类「开关与枚举字段」（`06-2`，其 `EnumField` / `EnumCheckboxField` / `SwitchField` 继承本三件）；列表内联切换的失败回滚由字段层负责；本任务只做选项原语与开关原语。
5. **契约套件与用例**：`@bms/core/testing` 组件契约套件双端同一套断言；用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）——本条 1 条、双端同号（预计 758）。
6. 实现以《组件设计》节点「06 单选」「07 复选」「08 开关」及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. 设计节点 §6.2「需登记的上游变更」随实施逐个确认并回写（《前端开发规范》继承链；《概要设计 · 表单定制》`radio` / `checkbox` / `switch` 形态与属性、选项集统一 `OptionItem`；《架构设计 · 数据架构》多值存储去重保序、布尔 `SMALLINT` 1/0 与三态口径）。
8. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

单选（三形态）、复选（两形态 / 全选 / 数量上下限 / 去重保序）与开关（三态 / 加载态 / 危险确认 / 1-0 归一）双端可用且走同一输入域口径；三件的受控与三态行为与文本 / 数字 / 下拉件一致；契约套件双端断言全绿；Vitest 覆盖形态切换、全选与禁用、数量边界、去重保序、`null` 与 `false` 区分；`prettier --check`、ESLint、`vue-tsc`、Vitest、构建与体积预算全通过；《[前端基类清单](../../../../../前端基类清单.md)》与《组件设计》相关登记回写同步。
