## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | `vue-tsc` 报 `TS2322`：`Type 'null' is not assignable to type '((props) => {}) \| undefined'`（`BaseInput.vue` 默认值块） | Vue 宏对 `unknown` 类型 prop 的推断退化（被当作函数形态 prop），叠加函数类型 prop（`normalize`）后 `withDefaults` 重载解析失败 | 壳 `modelValue` 改显式联合类型 `string \| number \| boolean \| null`；移除壳的函数类型 `normalize` prop（换行归一改落 `TextareaField` 件内）；回写设计 §8 第 8 条 |
| 2 | 用例全红：受控值不更新、`change` 不上报、计数恒为 `0/5`、禁用门禁失效 | 件内 `handleUpdate` 只更新本地 `current` 并 emit，**从未写入域上下文** | 写入链路改为「控件 `@update:model-value="slot.setValue"` → 域统一写入口 → 域变化再由壳外发 `update:modelValue`」；回写设计 §8 第 6 条（关键口径） |
| 3 | 只读件仍渲染输入元素（期望纯文本回显） | 壳未把 `readonly` 传进域上下文（`fieldOptions.value.readonly`），`mode()` 判不出 `text` | 壳传 `value: { readonly: props.readonly }`；回写设计 §1 只读态条 |
| 4 | 契约用例报「当前实现未提供 setValue 适配」 | 结构接口加了 `setValue?`，但 `@bms/vue/testing` 的实现漏改 | 补 `createContractKit` 的 `setValue` 实现（`wrapper.find(selector).setValue` + 等一帧） |
| 5 | 断言细节：EP 计数文案为 `3 / 5`（含空格）；Vant 不把 `maxlength` 落到 input 属性 | 内核实现差异 | 契约断言去空格比较；Vant 端内 spec 去掉 `maxlength` 属性断言（计数与归一断言保留） |

## 6. 偏差与遗留 <a id="deviations"></a>

**偏差（均已回写详细设计 §8）**：

- `useInput` 增 `commit()`（归一 + 写回 + 失焦一步）。
- 写入链路口径：控件写域、域变化外发（禁止件内直接 emit）。
- 脱敏规则细化为「保留首尾各 1 位 + 中间 `*`，≤ 2 位全掩码」。
- 换行归一落 `TextareaField` 件内（域工厂 `normalize` 选项保留供字段类）。
- i18n 仅落 `input.required` / `input.emptyText` / `input.password.*`；字数计数沿用内核文案（未新增 `input.wordLimit`）。
- 字段壳 ↔ 控件不引入 `provide` / `inject`，改用默认插槽作用域参数（已回写《前端基类清单》「上下文机制」条）。
- 只读 `disabled` 模式：壳只切文本态 / 控件态，`disabled` 由件层按 `slot.disabled` 施加。

**遗留（含归口）**：

| # | 遗留 | 归口 |
| --- | --- | --- |
| 1 | 清空按钮（`clearable`）交互未进契约：EP 需聚焦且有值才显示清除图标，jsdom 下不稳定 | `05_04` 收口核对（浏览器层人工核对） |
| 2 | 移动端密码键盘类型（`inputmode`）与真机触控尺寸核对 | `05_04` 收口核对 |
| 3 | 字段类继承与格式化接入（日期 / 金额展示、枚举文本） | `06_2` / `06_6`（字段类任务） |
| 4 | 字段权限元数据来源（`field-perm` 的 `visible` / `editable` 随后端下发） | 认证 / RBAC 阶段（当前默认全放开，占位语义） |
| 5 | 移动端 `span` 栅格仅 CSS 宽度机制（无 `GridCol` 对齐验证） | `05_04` 视觉核对 |
