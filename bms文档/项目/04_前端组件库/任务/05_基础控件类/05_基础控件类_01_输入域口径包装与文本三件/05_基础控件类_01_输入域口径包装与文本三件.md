## 2. 任务内容 <a id="content"></a>

1. **输入域口径包装重建（需求 05-1 第 9 条；旧 `BaseInput` 域包装已随旧层删除）**：按「核心能力 + 投影 + 插件包装」新体系交付输入域口径包装——core 侧输入域契约（组合 `field` + `input-control` 的域语义；如需新增契约 / 登记项，按「候选 → 设计节点 → 评审 → 清单登记」流程先行登记）+ `@bms/vue` 输入域投影 + `ui-ep` / `ui-vant` 输入域包装件；受控 `modelValue` / `update:modelValue`、三态、`disabled` 合并、`change` 上报、`focus` / `blur` / composition、校验触发在包装层定义一次，八件统一派生；只读态以 `disabled` 或纯文本回显、不做两套组件。
2. **字段壳装配**：label / 必填 / 错误 / 栅格（消费字段壳能力 `field-shell`、字段权限能力 `field-perm`）；校验与格式化复用 `02-6` 已交付能力层（`02_07` 后归 `@bms/core` 能力层注册表分发）。
3. `TextField.vue`（`frontend/packages/ui-ep/src/components/input/`；移动端 `frontend/packages/ui-vant/src/components/input/` 同契约实现）：单行文本——`maxlength` / `minlength` / `showWordLimit` / `pattern` / `trim` / `mask`（脱敏展示）、前后缀与清空、长度截断与计数、正则校验绑定。
4. `TextareaField.vue`：多行文本——`rows` / `autosize`（`minRows` / `maxRows`）、`maxlength` / `showWordLimit`、换行保留（提交统一 `\n`）、`trim` 归一。
5. `PasswordField.vue` 与密码强度工具（组件内工具，按新体系评估落点，不占能力 key）：`showToggle` 明文切换（仅前端内存态）、`strength` 强度提示、`minLength`、`noAutofill`；**不回填**（编辑态留空表示不修改）、密码不 `trim`、值不写日志 / 不落本地存储。
6. **契约套件与用例**：`@bms/core/testing` 组件契约套件双端同一套断言；用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）——本条 1 条、双端同号（预计 756）。
7. 实现以《组件设计》节点「01 文本框」「02 文本域」「03 密码框」及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
8. 设计节点 §6.2「需登记的上游变更」随实施逐个确认并回写（《前端开发规范》继承链、《概要设计 · 表单定制》组件类型与属性、《布局设计 · 表单页》只读回显、《安全开发规范》密码口径）。
9. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

输入域口径包装可用并被八件统一派生（受控与三态一致、`disabled` 合并、`change` 上报、校验触发一次定义）；文本三件（长度 / 计数 / 正则 / `autosize` / 换行 / 脱敏 / 密码安全口径）双端可用且字段壳可装配（label / 必填 / 错误 / 栅格）；契约套件双端断言全绿；Vitest 覆盖文本三件关键契约与密码不回填 / 明文仅内存行为；`prettier --check`、ESLint、`vue-tsc`、Vitest、构建与体积预算全通过；《[前端基类清单](../../../../../前端基类清单.md)》输入域节与《[前端开发规范](../../../../../规范/前端开发规范.md)》继承链回写同步。
