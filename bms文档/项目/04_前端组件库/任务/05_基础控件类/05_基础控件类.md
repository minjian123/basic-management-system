## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：《组件设计》基础控件类八节点——文本框（`TextField`）、文本域（`TextareaField`）、密码框（`PasswordField`）、数字框（`NumberInput`）、下拉框（`SelectInput`）、单选（`RadioField`）、复选（`CheckboxField`）、开关（`SwitchInput`）。对应需求 [05-1](../../需求/05_需求_基础控件类.md#r05-1)。
- **归属说明**：八件即本域全部（无前移 / 后移）；带数据源与格式语义的字段（字典 / 枚举 / 金额 / 上传等）在八件之上扩展，归需求域 06（字段类）。
- **公共前置**：输入域能力 `field`（`value` + `field-shell` + `field-perm`）与 `input-control`（输入形态）已类化交付（`frontend/packages/core/src/capabilities/{field,input-control,field-shell,field-perm,value}.ts`，登记 `capabilities/manifest.ts`）；`@bms/vue` 投影 `useField` / `useValue` / `useComponentBase`；契约套件 `@bms/core/testing`；框架无关核心重构 `02_07` 已于 2026-09-17 全链收口（旧基座层与旧 `base-control` 组件目录已删除），本域按「核心能力 + 投影 + 插件包装」新体系交付。
- **域包装口径（2026-09-17 建任务确认）**：需求 05-1 第 9 条「统一派生输入域基类」按新体系重建为**输入域口径包装**——core 侧输入域契约（组合 `field` + `input-control` 的域语义，必要时登记新增项）+ `@bms/vue` 输入域投影 + `ui-ep` / `ui-vant` 输入域包装件，八件统一派生；受控绑定、三态、`disabled` 合并、`change` 上报、校验触发与字段壳装配在包装层定义一次。
- **双端口径**：八件双端同批同契约交付（`frontend/packages/ui-ep/src/components/input/` 与 `frontend/packages/ui-vant/src/components/input/`，契约套件同一套断言，Kiwi 双端同号）。
- **依据**：[前端组件库需求总览](../../需求/00_需求_前端组件库.md)、[基础控件类需求](../../需求/05_需求_基础控件类.md)、《[组件设计 · 总览](../../../../设计/组件设计/01_组件设计_总览.md)》、《[前端开发规范](../../../../规范/前端开发规范.md)》、《[前端基类清单](../../../../前端基类清单.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：24h（子任务 01 9h〔输入域口径包装 3h + 文本三件 6h〕、02 5h、03 6h、04 4h）；周期口径见[计划](../../计划/01_计划_前端组件库.md)（名义窗口 2026-09-17 ~ 09-19，沿用「名义窗口 + 当日闭环」写法）。
- **关键依赖**：`01 → 02 → 03 → 04` 串行；01 的输入域口径包装为八件共同前置；02 / 03 分别交付数字·下拉族与选择族，互不依赖但按编号顺序排期；04 收口依赖前三项全部交付；全部任务消费输入域能力 `field` + `input-control`（域 02 `02_03` 类化交付）与设计令牌（`03_06` 已交付）。
- **确认口径（2026-09-17 建任务）**：子任务按族拆 4 项；双端同批同契约；输入域口径包装集中交付（core 契约 + 投影 + 双插件包装件）；工时 24h、名义窗口 2026-09-17 ~ 09-19；用例一子任务一条、双端同号（预计 Kiwi 756 ~ 759）；设计节点 §6.2「需登记的上游变更」随实施逐个确认并回写；`05_04` 交付《测试/02_收口核对_基础控件类.md》。
- **上游登记（随实施逐个确认并由上游文档同步）**：① 基础控件继承链 →《前端开发规范》「前端基类体系（开放式，强制）」节（`文本 / 文本域 / 密码 / 数字 / 下拉 / 单选 / 复选 / 开关` 八类的提供方与输入域口径）；② 组件类型与字段属性、选项集统一 `OptionItem` →《概要设计 · 表单定制》；③ 字段与校验、只读回显、短文本 / 长文本回显 →《布局设计 · 表单页》；④ 密码不回填 / 明文仅内存 / 不落日志与存储 / 禁自动填充 →《安全开发规范》；⑤ 数值精度与空值、多值存储（去重保序）、布尔 `SMALLINT` 1/0 与三态 →《架构设计 · 数据架构》。
- **后续消费方**：字段类（`06-1` ~ `06-7`）在本域八件之上扩展（字典 / 枚举 / 金额 / 日期 / 树选择 / 上传等），继承点与输入域口径以本域交付为准；`06_06` 字典字段经选项源能力 `option-source` 接入动态选项，不改八件原语。
- **登记项**：八件各设计节点的「需登记的上游变更」（见上）随实施逐个确认并由上游文档同步（对齐记录）；《前端基类清单》「域基类（按需）」输入域节状态与本域交付同步回写。
