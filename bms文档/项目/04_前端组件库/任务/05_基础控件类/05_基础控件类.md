## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段四需求域 05 的 1 条需求——[05-1 八基础控件](../../需求/05_需求_基础控件类.md#r05-1)，按「1 需求 = 1 子任务」拆 1 个子任务并含 2 个嵌套子任务（文本类 4 件 / 选择类 4 件）。
- **端范围**：**仅 PC**（`frontend/packages/ui-ep`，Element Plus）；移动端 `ui-vant` 本阶段范围外。
- **域边界**：本域只做「**无数据源、无特殊格式**」的基础输入形态；字典 / 枚举 / 金额 / 上传等带数据源或格式语义的字段由需求域 06 在本域之上扩展。
- **公共前置**：输入能力链（`BaseValue` → `BaseField` → `BaseInput`）与字段壳族、校验 / 格式化复用 `02_04` / `02_06`；新增投影 `useBaseInput` / `useBaseField`。
- **依据**：《组件设计》基础控件类各节点、《[前端开发规范](../../../../规范/前端开发规范.md)》「前端基类体系（强制）」节、《[前端基类清单](../../../../前端基类清单.md)》。
- **执行序**：`05_01 基础控件`（嵌套 01 文本类 → 02 选择类）；嵌套子任务并入其直属父任务统计。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：24h（嵌套 01 文本类控件 12h + 02 选择类控件 12h）。
- **关键依赖**：`05_01` 依赖 `02_04`（输入组件基类 `BaseInput` / 字段能力基类 `BaseField` / 值能力基类 `BaseValue`）、`02_06`（校验与格式化）、`03_02`（异常与空状态，下拉空态复用）。
- **风险**：八件若各自实现受控 / 三态 / `disabled` 合并会发散（须在投影层定义一次）；数字框精度 / 千分位与金额字段边界需清晰；EP 表单校验收敛（`el-form-item` 错误位）与字段壳族的边界。
