## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 原因 | 处置 |
| --- | --- | --- | --- |
| 1 | 移动端精度用例失败（`1.2` → `1`） | `van-field type="digit"` 截断小数 | 改 `inputmode="decimal"`（重建实施记录 §4.1） |
| 2 | `clamp=false` 越界校验恒通过 | EP 内核依 `max` 自行钳制 | `clamp=false` 不下传 `min` / `max` |
| 3 | 件层 `validate(false)` 被壳结果覆盖 | emit 顺序（壳在后） | 件监听壳 `validate` 后合并上报 |
| 4 | 只读文本显示无效值 / 未格式化 | 壳按域值直出 | 壳增 `displayText` 覆盖（下拉框传归一文本、数字框传格式化文本） |
| 5 | `vue/no-deprecated-filter` 报错 | 模板内 TS 联合类型断言的 `\|` | 改取值归一函数 |
| 6 | 多选只读文本未保序 | `labelOfOption` 多值按传入顺序 | 先剔除无效值再按选项顺序保序 |
| 7 | Vant 暴露方法未守上限 | 守卫只在面板层 | `selectOption` 统一加守卫 |
| 8 | EP `labelOfOption is not a function` | 模板用到未 import | 补 import |
