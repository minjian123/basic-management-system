## 2. 任务内容 <a id="content"></a>

1. `NumberInput.vue`（`frontend/packages/ui-ep/src/components/input/`；移动端 `frontend/packages/ui-vant/src/components/input/` 同契约实现）：纯数值输入——`precision`（0 = 整数）/ `min` / `max` / `step` / `thousands`（千分位仅显示层，存储为数值）；归一（空串 → `null`、精度四舍五入、越界钳制或校验可配、`null` 与 `0` 区分）；非数值即时拦截；移动端 `inputmode=decimal`。
2. `SelectInput.vue`（同落点双端实现）：**静态选项**下拉——`options`（`OptionItem`：`value` / `label` / `disabled` / `group`）/ `multiple` / `filterable`（本地过滤）/ `clearable`（默认 true）/ `collapseTags` / `maxCount`；分组按 `group` 分节；归一（空 → `null`（单选）/ `[]`（多选）、剔除无效值）；只读回显经展示域口径（`value` + `display-control`）。
3. **边界**：金额 / 币种 / 百分比语义归字段类「数值与金额字段」（`06-2`，可继承本件再加语义）；字典来源下拉归 `06-6`、枚举选项集归 `06-2`，均经选项源能力 `option-source` 接入（本任务只做静态 `options` 原语，不做取数 / 缓存 / 远程搜索）。
4. **契约套件与用例**：`@bms/core/testing` 组件契约套件双端同一套断言；用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）——本条 1 条、双端同号（预计 757）。
5. 实现以《组件设计》节点「04 数字框」「05 下拉框」及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. 设计节点 §6.2「需登记的上游变更」随实施逐个确认并回写（《前端开发规范》继承链；《概要设计 · 表单定制》`number` 属性与静态 `select` / 选项集统一 `OptionItem`；《架构设计 · 数据架构》数值精度与空值语义）。
7. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

数字框（精度 / 范围 / 步进 / 千分位 / `null` 与 `0` 三态）与静态下拉框（单选 / 多选 / 搜索 / 清空 / 分组 / 多选上限 / 无效值剔除）双端可用且走同一输入域口径（继承任务 01 的包装，不重复实现受控与三态）；`OptionItem` 与字典 / 枚举同构、可被字段类继承；契约套件双端断言全绿；Vitest 覆盖精度舍入、越界、空值归一与多选上限行为；`prettier --check`、ESLint、`vue-tsc`、Vitest、构建与体积预算全通过；《[前端基类清单](../../../../../前端基类清单.md)》与《组件设计》相关登记回写同步。
