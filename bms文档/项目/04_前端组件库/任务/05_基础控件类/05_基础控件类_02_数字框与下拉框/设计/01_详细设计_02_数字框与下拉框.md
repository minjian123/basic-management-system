## 3. 接口设计 <a id="api"></a>

### 3.1 core：`contracts/option.ts` <a id="api-option"></a>

```ts
export type OptionValue = string | number

export interface OptionItem {
  /** 选项值（字符串 / 数字，与字典、枚举同构） */
  value: OptionValue
  /** 选项文本（已由使用方按 locale 处理后传入） */
  label: string
  /** 禁用（仍展示，不可选） */
  disabled?: boolean
  /** 分组名（同组连续排列；缺省不分组） */
  group?: string
}

/** 选项分组视图（渲染用；顺序保持 options 中出现顺序） */
export interface OptionGroup {
  group: string
  items: readonly OptionItem[]
}
```

- `capabilities/option-source.ts`：`import type { OptionItem } from '../contracts/option'` 并 `export type { OptionItem }`（既有 `from '@bms/core'` / `from '.../option-source'` 导入不受影响）；`OptionSourceLoader` 返回值类型不变。

### 3.2 core：`domain/number.ts` <a id="api-number"></a>

```ts
export interface NumberParseOptions {
  precision?: number
  min?: number
  max?: number
  /** 越界钳制（默认 true） */
  clamp?: boolean
}
export interface NumberParseResult {
  /** 归一后的数值（空 / 非法 → null） */
  value: number | null
  /** 是否越界（clamp=false 时供 validate 用） */
  outOfRange: boolean
  /** 是否非法输入（如 `1.2.3`，已丢弃） */
  invalid: boolean
}

/** 解析输入文本 → 数值（允许中间态返回 null 且 invalid=false） */
export function parseNumberInput(text: string, options?: NumberParseOptions): NumberParseResult
/** 精度归一（四舍五入到 precision 位；precision 0 = 整数） */
export function applyPrecision(value: number, precision?: number): number
/** 钳制到 [min, max]（缺省边界不限制） */
export function clampNumber(value: number, min?: number, max?: number): number
/** 是否在范围内 */
export function inNumberRange(value: number, min?: number, max?: number): boolean
/** 千分位格式化（仅显示；`thousands=false` 时原样） */
export function formatNumber(value: number | null, options?: { precision?: number; thousands?: boolean }): string
/** 千分位输入解析（容错空格与逗号） */
export function parseFormattedNumber(text: string): string
```

判定口径：空串 / 仅符号（`-`）/ 仅小数点 → `null` 且 `invalid=false`（中间态）；含非法字符（除首位 `-`、数字、单个 `.`、千分位逗号）→ `invalid=true` 并取可解析前缀；`precision` 缺省不截断（`NumberInput` 默认传 `0`）。

### 3.3 core：`domain/option.ts` <a id="api-option-domain"></a>

```ts
/** 剔除不在选项集内的值（单选 → null；多选 → 过滤后的数组） */
export function normalizeOptionValue(
  value: OptionValue | readonly OptionValue[] | null,
  options: readonly OptionItem[],
  multiple: boolean,
): OptionValue | OptionValue[] | null
/** 多选值去重并按选项顺序保序 */

/** 取选项文本（未命中回退 `String(value)`；多值按「、」拼接） */
export function labelOfOption(value: OptionValue | readonly OptionValue[] | null, options: readonly OptionItem[]): string
/** 分组视图（保持出现顺序） */
export function groupOptions(options: readonly OptionItem[]): OptionGroup[]
/** 是否已达多选上限 */
export function reachMaxCount(value: readonly OptionValue[], maxCount?: number): boolean
/** 指定选项是否可选中（禁用项与「达上限时未选中项」都不可选） */
export function isOptionSelectable(item: OptionItem, value: readonly OptionValue[], maxCount?: number): boolean
```

## 4. 行为、边界与失败分支 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 数字：受控与中间态 | 对外只发 `number \| null`；`-` / `1.` / 空 等中间态仅在件内字符串态保存，失焦经 `parseNumberInput` 归一（空 → `null`） |
| 数字：精度 | `precision` 默认 `0`（整数）；失焦 / 步进后 `applyPrecision` 四舍五入（浮点陷阱用例按 `precision: 1` + `1.25 → 1.3` 设计） |
| 数字：越界 | `clamp=true`：失焦 / 步进后钳制并回写；`clamp=false`：保留输入 + `validate(false)` + 错误文案 `input.outOfRange` |
| 数字：`null` 与 `0` | 严格区分：`0` 是已填（只读态显示 `0`），`null` 是空（显示壳的空值占位）；`false` / `0` 不被空值判定吞掉（`input` 域工厂既有口径） |
| 数字：千分位 | 编辑聚焦去分隔符（`parseFormattedNumber`）、失焦 / 只读态格式化；`v-model` 始终为数值（不污染） |
| 数字：步进 | PC 由 `el-input-number` 箭头提供；移动端 `stepControls` 打开后渲染加减按钮（按 `step` / `min` / `max` / `precision` 计算） |
| 数字：非法输入 | 输入非法字符 → `invalid=true` → 不写入域（值保持上一个合法态）、开发态告警一次；不抛错 |
| 选择：归一 | 单选空 / 无效值 → `null`；多选空 → `[]`；多选去重并按 **选项顺序** 保序（与勾选顺序无关） |
| 选择：多选上限 | 达 `maxCount` → 其余未选项不可选（`isOptionSelectable`）+ 提示文案 `input.maxCount`；超出值不写入域 |
| 选择：禁用选项 | `disabled` 项展示但不可选（PC `disabled` / 移动端灰显不可点） |
| 选择：分组 | `group` 相同的选项连续渲染并带分组标题（PC `el-option-group`；移动端列表分组标题），顺序保持 |
| 选择：过滤 | `filterable` 本地按 `label` 包含匹配（大小写不敏感）；无命中显示空态文案 |
| 选择：只读 | 壳的只读文本态显示已选 `label`（多值「、」拼接，空值显示占位） |
| 移动端弹层 | `van-field`（只读触发，显示已选 label）+ `van-popup`（底部）：搜索（`filterable`）、分组标题、单选 / 多选（多选带确认按钮）、达上限项灰显 |
| 失败分支 | `options` 为空 → 下拉显示空态（不报错）；`modelValue` 传数组但 `multiple=false` → 取首个并告警；`maxCount ≤ 0` → 视为不限制；`precision < 0` → 视为 `0` |

## 7. 边界与开放项 <a id="open"></a>

- **不含**：金额 / 百分比语义（归 `06_2`）；字典 / 远程搜索 / 缓存（归 `06_6`，经 `option-source` 接入）；级联 / 树选择（归 `06_2`）；虚拟滚动下拉（大数据量场景，随展示域评估）。
- **占位语义**：`options` 为空时下拉显示空态（不请求、不报错），与后端 Null 占位模式一致。
- **性能**：静态选项过滤为线性扫描（建议 ≤ 50 项，超出建议改用字典 / 远程搜索字段）；千分位格式化仅在失焦 / 只读态执行。
- **开放项**：① 移动端是否引入 `van-picker` 替代自研列表（当前自研列表支持分组与多选确认，picker 不支持分组）——随 `05_04` 真机核对评估；② 数字框大数（超 `Number.MAX_SAFE_INTEGER`）建议改用字符串字段（设计节点已提示），当前不实现；③ `step` 长按连续步进（PC 内核自带）在移动端是否复刻——`05_04` 评估。
