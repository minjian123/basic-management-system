## 3. 实施过程 <a id="process"></a>

1. **上下文**：读设计节点「04 数字框」「05 下拉框」、`05_01` 已交付的输入域口径与契约范式、`capabilities/option-source.ts` 现状。
2. **决策确认**：8 项待拍板事项逐项确认（内核 / 越界 / 千分位 / 选项模型 / 多选上限 / 移动端步进 / 契约落点 / 值类型）；其中「选项模型」按用户选择落**核心契约类型**（非插件自定义）。
3. **详细设计**：落 `设计/01_详细设计_02_数字框与下拉框.md`，定稿提交。
4. **Kiwi 登记**：先登记后编码，回读编号 **757**（双端同号）。
5. **core**：新建 `contracts/option.ts`（`OptionItem` / `OptionValue` / `OptionGroup`），`option-source.ts` 改引用 + re-export（既有导入路径不变）；新建 `domain/number.ts`（`parseNumberInput` / `applyPrecision` / `clampNumber` / `inNumberRange` / `formatNumber` / `parseFormattedNumber`）与 `domain/option.ts`（归一 / 保序 / 文本 / 分组 / 上限 / 可选性 / 过滤）。
6. **壳扩展**：两插件 `BaseInput.vue` 增 `displayText`（只读文本覆盖）与 `setValue` / `clear` / `commit` 对外方法。
7. **契约套件**：`@bms/core/testing/input.ts` 增「数字框」「下拉框」两组断言（值写入 / 空值 / 精度 / 钳制与校验 / `0` 与 `null`；只读文本 / 多选顺序 / 无效值剔除 / 上限拒绝）。
8. **双插件件**：`NumberInput.vue`（EP `el-input-number`；Vant `inputmode=decimal` + 可选步进按钮）、`SelectInput.vue`（EP `el-select` / `el-option-group`；Vant 底部 `van-popup` 自研列表：搜索 / 分组 / 多选确认 / 上限灰显）；两件均暴露 `selectOption`。
9. **i18n**：双端 `input` 分组补 `maxCount` / `outOfRange` / `selectPlaceholder` / `searchPlaceholder`（zh-CN / en-US）。
10. **用例**：core 纯函数 10 条；双端 `number-select.spec.ts`（Kiwi 757）+ 契约套件自动覆盖。
11. **门禁**：四包 `npm run check` 全绿；双宿主 `prettier` / `lint` / `vue-tsc` / `test:cov` / `build` + `budget` 全绿。
12. **登记回写**：详细设计 §8 实施对齐记录（6 条）、前端基类清单（契约 / 领域层、具体组件）、前端开发规范 §3.5、概要设计 36（字段属性 + 选项模型）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | 移动端数字框输入 `1.2` 解析为 `1`（精度用例失败） | `van-field type="digit"` 会截断小数输入 | 改 `type="text"` + `inputmode="decimal"`（保留数字键盘、小数可控）；回写设计 §8 第 7 条 |
| 2 | `clamp=false` 时越界校验恒为通过（未能保留原值） | `el-input-number` 收到 `max` 会自行钳制输入，件层拿不到越界原值 | `clamp=false` 时不再下传 `min` / `max`（越界判定统一由件层 `inNumberRange` 负责）；回写设计 §8 第 6 条 |
| 3 | 件层 `validate(false)` 被覆盖为 `true` | 壳在 `commit` 后 emit `validate`（必填结果）在件结果**之后**发出 | 件改为监听壳 `validate` 事件再合并上报（`handleShellValidate`）；回写设计 §8 第 8 条 |
| 4 | 下拉框只读文本仍显示无效值（`ghost`） | 壳只读文本用域值直出，无法剔除无效值 / 显示千分位 | 壳新增 `displayText` prop（只读文本覆盖，非 `undefined` 优先），下拉框传归一后文本、数字框传格式化文本；回写设计 §8 第 5 条 |
| 5 | `vue/no-deprecated-filter` 报错（`SelectInput` 模板） | 模板表达式内的 TS 联合类型断言 `slot.value as A \| B` 中的 `\|` 被 Vue 解析器判为旧式过滤器语法 | 改用取值归一函数（`coerceNumber` / `coerceOptionValue`），模板内不做类型断言；回写设计 §8 第 9 条 |
| 6 | 多选值只读文本顺序与选项顺序不一致 | `labelOfOption` 多值分支按传入顺序拼接 | 该分支改为「先剔除无效值 + 按选项顺序保序」；回写设计 §8（对齐第 3 条） |
| 7 | Vant 端 `selectOption` 在达上限时仍写入 | 面板层有守卫，暴露方法未加 | `selectOption` 统一加 `reachMaxCount` 守卫（与 `isSelectable` 一致） |
| 8 | EP 侧 `labelOfOption is not a function` | 模板用到但 script 未 import | 补 import（属实施疏漏，非设计问题） |

## 6. 偏差与遗留 <a id="deviations"></a>

**偏差（均已回写详细设计 §8）**：壳增 `displayText` 覆盖；`clamp=false` 不下传 `min`/`max`；移动端改 `inputmode=decimal`；件规则在壳 `validate` 之后合并；模板内不做 TS 联合断言；`labelOfOption` 多值保序；`SelectInput` 暴露 `selectOption`。

**遗留（含归口）**：

| # | 遗留 | 归口 |
| --- | --- | --- |
| 1 | 下拉框弹层交互（EP 下拉定位 / Vant 面板滚动与键盘避让）真机核对 | `05_04` 收口核对 |
| 2 | 数字框大数（超 `Number.MAX_SAFE_INTEGER`）与科学计数法输入 | 设计已提示改用字符串字段；如需支持随字段类评估 |
| 3 | 移动端步进长按连续步进 | `05_04` 评估（当前点击单步） |
| 4 | 字典 / 远程选项与缓存（`option-source` 消费） | `06_6` 字典字段 |
| 5 | 金额 / 百分比语义与 `Intl` 格式化 | `06_2` 数值与金额字段 |
| 6 | 虚拟滚动下拉（超 50 项场景） | 展示域评估 |
