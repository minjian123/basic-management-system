## 2. 任务内容 <a id="content"></a>

1. **跨件一致性收口**：核对八件的受控 `modelValue` / `update:modelValue`、三态（未设置 / 空 / 已填）、`disabled` 合并、`change` 上报、`focus` / `blur` / composition、校验触发、字段壳装配（label / 必填 / 错误 / 栅格）、只读回显（`disabled` 或纯文本）、大小与密度——均经输入域口径包装定义一次，无逐件重复实现；`ui-ep` / `ui-vant` 同一套契约断言复核（契约套件全绿）。
2. **原型逐节点对照（原型即验收基准）**：8 个《组件设计》节点与 8 份可交互原型逐项对照（交互与视觉），双端含移动视口抽查；核对结论落《测试/02_收口核对_基础控件类.md》，作为 M4「原型一致」验收点证据（同域 04 [收口核对记录](../../04_容器组件类/测试/02_收口核对_容器组件类.md)体例）。
3. **门禁复核（双端各自执行）**：`npx prettier --check`（仅本域文件）、`npm run lint`（含包级 ESLint）、`npx vue-tsc -b`、`npm run test:cov`（阈值 70%）、`npm run build` + `npm run budget`；覆盖率与体积预算实测值回写测试记录。
4. **索引与登记回写**：《[前端基类清单](../../../../../前端基类清单.md)》输入域节（域包装已重建）与《[前端开发规范](../../../../../规范/前端开发规范.md)》继承链终稿回写；《组件设计》八节点 §6.2 上游登记项逐项确认结果核对（无漏项）。
5. **用例与域收口**：本条 1 条 Kiwi 用例（先登记后编码，自动化标注 `kiwi_id`，双端同号，预计 759）；域收口说明回写父任务与[计划](../../../计划/01_计划_前端组件库.md)（工时、状态、偏差与遗留）。
6. **遗留归口登记**：字段类继承点（`06-2` 基础与数据源字段、`06-6` 字典字段）、金额与百分比语义、真机触摸项抽查（移动端键盘 / 触控尺寸）等，写入实施记录「偏差与遗留」并回写计划 §3.1 归口表。

## 3. 完成标准 <a id="accept"></a>

八件跨件一致性核对完成（受控 / 三态 / `disabled` / 校验触发 / 字段壳装配口径一致，无逐件重复实现）；8 节点原型逐项对照记录成文；双端门禁（`prettier` / ESLint / `vue-tsc` / Vitest / 构建与预算）全绿且实测值留痕；输入域节与继承链回写同步；遗留逐项归口到字段类任务或后续批次；域 05 父任务与计划收口回写完成。
