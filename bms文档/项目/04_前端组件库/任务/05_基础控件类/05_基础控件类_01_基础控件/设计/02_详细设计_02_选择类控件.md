## 1. 设计目标与范围 <a id="goal"></a>

选择类四件：下拉框（静态选项）、单选、复选、开关。均薄封装 Element Plus 并派生 `BaseInput`（经 `useBaseInput` 投影），与文本类共享受控 / 三态 / 禁用合并 / `change` / 校验触发口径。

不在本期：字典 / 枚举数据源（`06-2` / `06-6`）、开关字段语义（`06-2`）、字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 选项类型 <a id="option"></a>

```ts
interface InputOption<T = string | number> { label: string; value: T; disabled?: boolean }
interface InputOptionGroup<T> { label: string; options: InputOption<T>[] }
```

### 3.2 四件组件契约 <a id="components"></a>

| 件 | Props（除通用外） | 说明 |
| --- | --- | --- |
| `SelectInput` | `options`（含分组）/ `multiple` / `searchable` / `clearable` / `collapseTags` | 静态选项；搜索为本地过滤；空态复用 `03_02` `EmptyState` |
| `RadioInput` | `options` / `form: 'radio' \| 'button' \| 'segmented'` | 单值 |
| `CheckboxInput` | `options` / `form: 'checkbox' \| 'tag'` / `selectAll` / `min` / `max` | 多值；全选与数量上下限 |
| `SwitchInput` | `loading` / `confirm`（危险切换确认）/ `activeText` / `inactiveText` | 布尔；三态（`undefined` 表示未设置） |

- 通用：`modelValue` / `disabled` / `readonly` / `size` / `density`；事件 `update:modelValue` / `change` / `clear`。
- 多值件（下拉多选 / 复选）值类型 `T[]`；`min` / `max` 越界时拒绝变更并回传 `invalid` 事件（不改值）。
- 危险切换确认复用 `03_01` `useConfirm`；取消则值不变（受控回滚）。
- 空态：下拉无匹配项渲染 `EmptyState(type="result")`（插槽可覆盖）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 复选低于 `min` / 高于 `max` | 拒绝变更 + `invalid` 事件，值保持不变 |
| 全选时部分项禁用 | 全选仅作用于可选中的项 |
| 下拉搜索无匹配 | 渲染 `EmptyState(type="result")` |
| 开关危险切换被取消 | 值不变（不触发 `update:modelValue`） |
| `multiple` 与 `modelValue` 非数组 | 归一为空数组并告警 |
| 单选 / 开关收到数组值 | 取首值 / 归一为布尔，开发态告警 |
