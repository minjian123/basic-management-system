## 1. 设计目标与范围 <a id="goal"></a>

文本类四件：文本框、文本域、密码框、数字框。均薄封装 Element Plus 并派生输入组件基类 `BaseInput`（经 `BaseField` → `BaseValue` 链），新增投影 `useBaseInput` / `useBaseField`——**受控绑定、三态、`disabled` 合并、`change` 上报、校验触发在投影层定义一次**。

不在本期：字段壳（label / 必填 / 错误 / 栅格，随 `02_04` 组装）、金额语义（`06-2`）、选择类四件（嵌套 02）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `useBaseInput` <a id="use-base-input"></a>

```ts
useBaseInput<T>(options?: {
  value?: T
  disabled?: boolean
  loading?: boolean
  placeholder?: string
  clearable?: boolean
}): {
  input: BaseInput<T>
  value: Ref<T | undefined>
  isEmpty: Ref<boolean>       // 三态：空
  disabled: Ref<boolean>      // 合并：base.disabled ∨ 传入 disabled
  loading: Ref<boolean>
  focused: Ref<boolean>
  sizeToken: Ref<string>
  density: Ref<string>
  setValue(v: T | undefined): void
  clear(): void
  focus(): void
  blur(): void
  onValueChange(listener): () => void   // 值变更订阅（组件桥接 `update:modelValue` / `change`）
}
```

- 值链：`BaseValue.setValue` 同值不触发；`clear()` 仅 `clearable` 生效。
- `disabled` 合并：基类 `disabled` 与传入项取或（表单级 / 件级合并语义）。

### 3.2 `useBaseField` <a id="use-base-field"></a>

```ts
useBaseField<T>(options?: { fieldName?: string; trigger?: FieldTrigger }): {
  field: BaseField<T>
  value: Ref<T | undefined>
  fieldName: Ref<string>
  trigger: Ref<FieldTrigger>   // 'change' | 'blur' | 'submit'
  setTrigger(trigger): void
}
```

### 3.3 四件组件契约 <a id="components"></a>

| 件 | Props（除通用外） | 说明 |
| --- | --- | --- |
| `TextInput` | `maxlength` / `showWordLimit` / `prefix` `suffix` 插槽 | 单行文本、清空 |
| `TextareaInput` | `rows`（缺省 3）/ `autosize` / `maxlength` / `showWordLimit` | 多行、换行保留 |
| `PasswordInput` | `showToggle`（明文切换）/ `strength`（强度提示） / `maxlength` | **不回填**（`autocomplete="new-password"`，不读写任何持久化） |
| `NumberInput` | `min` / `max` / `step` / `precision` / `thousandSeparator` | 数值范围与精度；金额归 `06-2` |

- 通用（四件一致）：`modelValue` / `disabled` / `readonly` / `placeholder` / `size` / `density`；事件 `update:modelValue` / `change` / `blur` / `focus` / `clear`。
- 受控：外部 `modelValue` 变化 → 投影 `setValue`；投影值变更 → `update:modelValue` + `change`（同值不重复）。
- `readonly`：只读回显不换组件（`:readonly` 传 EP），`disabled` 优先。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 同值重复输入 | 不触发 `update:modelValue` / `change`（值链同值短路） |
| `clear()` 但 `clearable` 为假 | 无操作 |
| 数字框输入非法 / 越界 | 夹取到 `[min, max]`，精度按 `precision` 归一 |
| `precision` 与 `step` 冲突 | 以 `precision` 为准，开发态告警 |
| 密码框浏览器回填 | `autocomplete="new-password"`；不写任何持久化 |
| 文本域 `autosize` 与 `rows` 同传 | `autosize` 优先 |
| `disabled` 与外层表单级禁用并存 | 取或合并 |
