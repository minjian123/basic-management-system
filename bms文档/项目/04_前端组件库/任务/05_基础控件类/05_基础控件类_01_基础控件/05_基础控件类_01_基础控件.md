## 3. 任务内容 <a id="content"></a>

1. 八件基础控件由两个嵌套子任务承载：文本类（文本框 / 文本域 / 密码框 / 数字框）、选择类（下拉框 / 单选 / 复选 / 开关）。
2. 八件统一派生输入组件基类 `BaseInput`（经 `BaseField` → `BaseValue` 链），并新增投影 `useBaseInput` / `useBaseField`：受控 `modelValue` / `update:modelValue`、三态、`disabled` 合并、`change` 上报、校验触发**在投影层定义一次**。
3. 只读态以 `disabled` 或纯文本回显（不做两套组件）；字段壳（label / 必填 / 错误 / 栅格）由字段壳族组装（`02_04`）；校验与格式化复用 `02_06`。
4. 视觉与交互对齐 Element Plus 与《组件设计》各节点，消费设计令牌（`data-size` / `data-density` 属性协议）。

## 4. 完成标准 <a id="accept"></a>

八件控件可用、字段壳可装配（label / 必填 / 错误 / 栅格）；受控与三态行为一致；Vitest 覆盖八件的关键契约；`vue-tsc`、ESLint、Vitest 全通过。
