## 2. 任务内容 <a id="content"></a>

1. **下拉框**：静态选项（单选 / 多选、搜索、分组）；空态复用 `03_02`；**字典 / 枚举**在 `06-2` / `06-6`，本件只做静态选项。
2. **单选**：`radio` / `button` / `segmented` 三种形态。
3. **复选**：`checkbox` / `tag` 两种形态、全选、数量上下限。
4. **开关**：布尔开关（三态、加载态、危险切换确认）；**字段语义**在 `06-2` 的开关字段。
5. 四件统一派生 `BaseInput`（经 `useBaseInput` 投影）：受控值、三态、`disabled` 合并、`change` 上报与校验触发一致；只读态以 `disabled` 或纯文本回显。
6. Vitest 覆盖四件关键契约（受控 / 多值边界 / 全选与上下限 / 危险确认）。

## 3. 完成标准 <a id="accept"></a>

四件选择类控件可用且行为一致；下拉搜索 / 分组与空态正确；复选全选与上下限生效；危险切换经二次确认（复用 `03_01`）；Vitest 覆盖关键契约；`vue-tsc`、ESLint、Vitest 全通过。
