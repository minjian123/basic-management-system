## 2. 任务内容 <a id="content"></a>

1. **文本框**：单行文本（前后缀、清空、字数限制）；派生 `BaseInput`（经 `useBaseInput` 投影）。
2. **文本域**：多行文本（行数 / 自适应、字数统计、换行保留）。
3. **密码框**：密码输入（明文切换、强度提示、**不回填**）。
4. **数字框**：纯数字（精度 / 范围 / 步进 / 千分位）；**金额语义**在 `06-2` 的金额字段，本件只做数值形态。
5. 四件统一受控 `modelValue` / `update:modelValue`、三态、`disabled` 合并、`change` 上报与校验触发（投影层统一定义）；只读态以 `disabled` 或纯文本回显。
6. Vitest 覆盖四件关键契约（受控 / 三态 / 边界与降级）。

## 3. 完成标准 <a id="accept"></a>

四件文本类控件可用且行为一致；密码框不回填、数字框精度与范围生效；受控与三态一致；Vitest 覆盖关键契约；`vue-tsc`、ESLint、Vitest 全通过。
