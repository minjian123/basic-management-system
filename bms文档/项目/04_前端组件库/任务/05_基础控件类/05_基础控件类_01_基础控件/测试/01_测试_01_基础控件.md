## 2. 测试范围与用例 <a id="scope"></a>

| 用例组 | 类型 | 自动化文件 | 覆盖点 |
| --- | --- | --- | --- |
| 输入投影 | 单元 | `ui-ep/tests/input-text.spec.ts` | 受控值 / 三态 / 禁用合并 / 同值短路；不可清空时 `clear` 无操作 |
| 字段投影 | 单元 | 同上 | 字段标识 / 校验触发切换 |
| 文本框 | 单元 | 同上 | 值回传与同值不重复；清空与 `clear`；禁用合并 |
| 文本域 | 单元 | 同上 | `rows` / `autosize` 透传 |
| 密码框 | 单元 | 同上 | 明文切换 / 不回填属性 / 强度档随值变化 |
| 数字框 | 单元 | 同上 | 值回传；千分位格式化；范围与精度透传 |
| 下拉框 | 单元 | `ui-ep/tests/input-select.spec.ts` | 单选 / 多选归一 / 分组渲染 / 空态插槽 / 清空 |
| 单选 | 单元 | 同上 | 三形态渲染与值回传 |
| 复选 | 单元 | 同上 | 多选回传 / 全选（跳过禁用项）/ 上下限越界 `invalid` 且不改值 / tag 形态 |
| 开关 | 单元 | 同上 | 直接切换；危险确认取消不改值、确认才改 |
