## 2. 任务内容 <a id="content"></a>

1. `ErrorPage`（403 / 404 / 500 错误页：插画 + 标题 + 说明 + 主操作，**不展示技术堆栈**）。
2. `EmptyState`（空状态场景矩阵：列表无数据 / 搜索无结果 / 待办为空 / 消息为空 / 自定义；引导按钮受权限控制；`size` 支持表格内 / 卡片内）。
3. `SkeletonBlock`（骨架屏：list / table / form / card 形态、行数、动画开关，首屏与内容同结构）。
4. `LoadingMask`（内容遮罩 loading：局部覆盖、`delay` 防闪烁、`text`、`fullscreen`）。
5. `useFeedback`（组合式：`loading → ready / empty / error` 状态机 + `retry`、空值判定、错误文案映射入口）。
6. 令牌与 i18n：遮罩 / 骨架 / 空态令牌统一消费；文案走 vue-i18n，插画资源 `src/assets/images/empty-*.svg` 按需引用（不内联大段 SVG）。
7. 边界：与 03/02 `LoadingContainer` 分工为「组件本体 / 容器编排」；接口拦截与错误码文案归 08/01 请求封装，本任务只提供呈现与重试入口。
8. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
9. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
10. 详细设计随任务启动时补建（按前序任务完成情况调整口径）。
