## 2. 任务内容 <a id="content"></a>

1. 通知与消息 `NotificationBell` / `NotificationList` / `MessageItem` / `NotificationDetail` / `useNotification`：顶栏铃铛与角标、列表/详情、单条/批量/全部已读、Socket.IO 实时与断线补偿。
2. 文件预览 `FilePreview` / `ImageViewer` / `PdfViewer` / `useFilePreview`：图片 / PDF / 音视频 / 文本分发、缩放旋转翻页、预签名 URL 失效重取与降级下载。
3. 审计差异查看 `AuditDiffViewer` / `DiffTable` / `FieldDiff` / `ChainVerifyPanel` / `useAuditDiff`：字段级旧值→新值差异、脱敏、链字段与校验结果、篡改定位。
4. 快捷入口 `QuickEntry`、头像与用户信息 `UserAvatar` / `UserPill`、二维码 `QrCode`、水印 `Watermark`；用户/组织展示统一经 `useUserDisplay` 片段；预签名 URL 统一经 `usePresignedUrl` 片段（与下载、导出共用）；水印统一经 `useWatermark` 片段（覆盖内容与导出）。
5. 空态 / 骨架 / 遮罩等**不重复实现**，统一复用 06/03（异常与空状态）；接口错误码文案与重试入口归 08/01 请求封装。
6. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
7. **占位先行**：本期先交付**占位版**（空态 / 禁用态 / 降级语义，对齐后端 Null 占位模式）+ **占位契约测试**，并登记《[前端基类清单](../../../../../前端基类清单.md)》与《组件设计》；**真实实现**随 阶段八起 ~ 十八 回补（回补时补设计、实施与记录）。
8. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
9. 详细设计随任务启动时补建（占位版先行；真实实现回补时另行设计）。
