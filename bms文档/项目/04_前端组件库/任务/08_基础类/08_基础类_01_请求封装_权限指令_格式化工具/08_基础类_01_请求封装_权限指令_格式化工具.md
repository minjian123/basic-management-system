## 2. 任务内容 <a id="content"></a>

1. `http.ts` 接入层与 `useRequest` / `useListPage`（复用阶段一实现并补契约）、`v-perm` / `hasPerm` / `canAccess` / `usePermissionStore`、`formatDateTime` / `formatAmount` / `validators`；复用阶段一 `stableStringify`。
2. 范围口径（2026-09-15 重排确认）：`useTabs` / `useFormPage` 等**能力片段归 01/03**，权限集合的使用统一经 `useAccess` 片段（本任务提供指令与请求层落地，不重复实现片段）；本任务提前到 01/05 之后、各组件任务之前实施（弹窗抽屉表单、八基础控件的请求与格式化均以其为前提）。
2. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
3. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
4. 详细设计随任务启动时补建（按前序任务完成情况调整口径）。
