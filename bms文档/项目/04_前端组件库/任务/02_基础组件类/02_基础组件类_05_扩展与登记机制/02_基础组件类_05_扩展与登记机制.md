## 2. 任务内容 <a id="content"></a>

1. 扩展流程落地：候选 → 设计节点（《组件设计》，契约与原型）→ 评审确认 →《[前端基类清单](../../../../../前端基类清单.md)》登记 → 同步《[架构设计 · 前端组件体系](../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》与《[前端开发规范](../../../../../规范/前端开发规范.md)》。
2. 组合轨默认口径：组件以组合能力为主，派生域基类仅作语义归类（可选）；机制变更（根系 / 组件根 / 能力机制）须评估全链影响。**（2026-09-17 二次返工修正：本条为历史任务留痕，其「组合轨默认」口径已废——主体内建走继承轨（能力入继承链），平台之外定制走组合轨；以《前端开发规范》§1「架构铁律」与 §3.4 为准。）**
3. 兼容性口径：新增能力 / 基类为兼容变更；调整既有能力契约（行为 / 参数 / 事件）须评估使用方并升主版本标注。
4. 同接口多实现基线：`frontend/apps/desktop/` 与 `frontend/apps/mobile/` 同步扩展，不得只在单端加基类能力。
5. 目录与命名校验：机制层 `frontend/packages/core/src/mechanisms/`、能力层 `frontend/packages/core/src/capabilities/<key>.ts`；核心类 `BaseXxx`、投影 `useXxx`（仅 `frontend/packages/vue/src/bindings/`）符合《[命名规范](../../../../../规范/命名规范.md)》。
6. 护栏落地（本任务侧）：继承护栏、依赖边界测试、清单对账脚本；「不注册不可用」随微前端骨架任务（`10_02`）落地。
7. 演练一次新增（文档级 + 单测目录约定），验证流程可行。

8. **前置契约（已交付）**：01 ~ 04 中 01 已交付（根系基类，2026-09-16，核心 `frontend/packages/core/src/base/` 三件）；本任务的继承护栏、依赖边界测试与清单对账脚本（旧护栏，随旧层删除，历史经 git 追溯）以 `frontend/packages/core/src/` 已落地文件为扫描基线；现行护栏为 `frontend/packages/core/tests/guard-core-framework-agnostic.spec.ts` + `frontend/packages/core/tests/contracts/*.spec.ts`；[02 组件根基类](../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现；[03 能力机制与预置能力](../02_基础组件类_03_能力机制与预置能力/02_基础组件类_03_能力机制与预置能力.md)（2026-09-16 交付）提供能力机制（`BaseCapability` + `manifest.ts` 登记）、注册表基座（`BaseRegistry` / `RegistryItemLike`）与预置 31 能力（形态 7 / 值·字段链 4 / 选项源 1 / 复用 19；`key` 与 `depends` 见《前端基类清单》『能力』节），本任务直接复用，不重复实现；[04 域基类](../02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)（2026-09-16 交付）提供输入 / 展示 / 树 / 编辑器域能力（`BaseField` + `BaseInputControl` / `BaseValue` + `BaseDisplayControl` / `BaseTreeData` / `BaseEditorKernel`；`BaseChart` 规则已登记、实现随 `07_06`）与字段壳能力（字段上下文语义），本任务的护栏随其覆盖域能力层，不重复实现
