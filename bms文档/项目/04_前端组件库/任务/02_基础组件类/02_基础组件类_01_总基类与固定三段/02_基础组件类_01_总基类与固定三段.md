## 2. 任务内容 <a id="content"></a>

1. 核心落点：`frontend/packages/core/src/base/BaseObject.ts`、`mechanisms/capability.ts`、`mechanisms/pluggable.ts`（纯 TS，复用 `02_07` 工程脚手架）
2. 总基类 `BaseObject`（对齐后端「根系」已验证口径）：**只放所有基类共有的横切方法、不放 UI / 业务字段**；命名空间 / 版本、日志、错误上报、配置读取、生命周期（`dispose`）；**普通类（非抽象）**，可被混合继承；子类自带实现优先；**公共方法唯一落点**；定义「一切基类从其派生（零例外）」
3. 能力域基类 `BaseCapability`（对齐后端「极简能力域基类」）：**只承载能力声明机制**——能力键（kebab-case）、`depends` 依赖登记、单向校验（依赖已登记 / 无环 / 键名合法）、开发态告警、`describe`；**不塞入 UI / 业务语义**，具体机制走 `02_05` 注册表与能力依赖登记表
4. 插件基类 `BasePluggable`（对齐后端「插件中间层」）：能力键 / 实现名 / 契约版本 / 注册与解析 / 生命周期（`setup` / 释放）/ `describe`；只承载装配语义、不含具体实现；注册与解析统一走 `02_05` 注册表、释放经统一资源登记
5. 错误基座的入链说明：`extends BaseObject + Error`（多重继承），为体系**唯一有理由的多重继承**；本体由 `02_05` 实现
6. 单测（对齐后端「逐基类一文件」口径）：`BaseObject`（序列化 / 相等 / 生命周期）、`BaseCapability`（能力声明与依赖校验）、`BasePluggable`（装配语义）；另设继承护栏用例（零例外派生）

## 3. 完成标准 <a id="accept"></a>

固定三段就位且与后端同名同序；口径对齐后端已验证做法（极简根系 / 能力域基类仅声明 / 插件装配语义）；一切基类由其派生（含错误基座唯一多重继承）；能力声明 / 依赖登记 / 开发态校验可用；核心用例覆盖三段契约；核心框架无关护栏通过；`vue-tsc`、ESLint、Vitest 全通过。
