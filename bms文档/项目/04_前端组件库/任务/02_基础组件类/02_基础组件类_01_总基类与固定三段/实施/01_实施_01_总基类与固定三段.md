## 3. 实施过程 <a id="process"></a>

1. **总基类**：`frontend/packages/core/src/base/BaseObject.ts` 落 `BaseObject`（命名空间 / 版本、`log` / `reportError` / `getConfig` / `dispose` + `onDispose` 钩子）与模块级 sink（`configureBase` / `resetBaseSinks`，缺省 console / 空配置）。
2. **能力域基类**：`src/mechanisms/capability.ts` 落抽象类 `BaseCapability extends BaseObject`（`key` 抽象、`depends`、`describe`）。
3. **插件基类**：`src/mechanisms/pluggable.ts` 落抽象类 `BasePluggable extends BaseCapability`（`pluginKey` / `pluginName` 抽象、`contractVersion` 默认 `0.1.0`、`get key()=pluginKey`、`setup()`、`describe()`）。
4. **入口导出**：`src/index.ts` 追加三段与 sink 导出。
5. **用例**：`tests/{base-object,capability,pluggable}.spec.ts`（5 + 2 + 4 用例）。
6. **验证**：`pnpm run core:check`（typecheck + lint + test）全绿。
