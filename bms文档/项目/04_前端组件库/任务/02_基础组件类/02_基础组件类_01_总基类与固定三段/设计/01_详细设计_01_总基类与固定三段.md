## 1. 设计目标与范围 <a id="goal"></a>

落地与后端同名同序的**固定前三段**（总基类 → 能力域基类 → 插件基类），为后续基类提供唯一公共方法落点与能力 / 装配语义：

- `BaseObject`：命名空间 / 版本、日志、错误上报、配置读取、生命周期（`dispose`）；普通类、零例外之根。
- `BaseCapability`：能力键声明、依赖登记、`describe`；抽象类。
- `BasePluggable`：能力键 / 实现名 / 契约版本 / 生命周期 / `describe`；抽象类。

不在本期：能力依赖校验与登记表（`02_03`）、注册与解析（`02_05`）、资源 / 占位 / 错误基座（`02_05`）、组件根（`02_02`）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `BaseObject`（普通类，可混合继承） <a id="base-object"></a>

```ts
export type LogLevel = 'debug' | 'info' | 'warn' | 'error'

export interface BaseLoggerSink { (level: LogLevel, message: string, meta?: Record<string, unknown>): void }
export interface BaseReporterSink { (error: unknown, meta?: Record<string, unknown>): void }
export interface BaseConfigSource { get(key: string): unknown }
export interface BaseSinks { logger?: BaseLoggerSink; reporter?: BaseReporterSink; config?: BaseConfigSource }

/** 注入基础 sink（宿主装配期调用；未注入用默认 console / 空配置）。 */
export function configureBase(sinks: BaseSinks): void
/** 重置 sink（测试用）。 */
export function resetBaseSinks(): void

export class BaseObject {
  constructor(namespace?: string, version?: string)
  readonly namespace: string
  readonly version: string
  get isDisposed(): boolean
  log(level: LogLevel, message: string, meta?: Record<string, unknown>): void
  reportError(error: unknown, meta?: Record<string, unknown>): void
  getConfig<T>(key: string, fallback?: T): T
  dispose(): void
  protected onDispose(): void   // 子类释放钩子（幂等内只调一次）
}
```

- 公共方法唯一落点；子类自带实现优先；`dispose` 幂等、置 `isDisposed` 后调一次 `onDispose`。
- sink 缺省：`logger` → `console`（按级别）、`reporter` → `console.error`、`config` → 空源（`getConfig` 返回 `fallback`）。

### 3.2 `BaseCapability`（抽象类） <a id="capability"></a>

```ts
export abstract class BaseCapability extends BaseObject {
  abstract readonly key: string        // 能力键（kebab-case）
  readonly depends: readonly string[] = []   // 依赖的能力键（登记 / 校验由 02_03 / 02_05 承接）
  describe(): string                   // 缺省 `${key}（能力域基类）`
}
```

- 只承载能力声明机制（键 / 依赖 / 元信息），不含 UI 与业务语义；依赖校验与登记表归 `02_03`。

### 3.3 `BasePluggable`（抽象类） <a id="pluggable"></a>

```ts
export const DEFAULT_CONTRACT_VERSION = '0.1.0'

export abstract class BasePluggable extends BaseCapability {
  abstract readonly pluginKey: string      // 与能力键一致
  abstract readonly pluginName: string     // 实现名（内部实现名 / "null" 占位）
  readonly contractVersion: string = DEFAULT_CONTRACT_VERSION
  get key(): string                        // = pluginKey（满足 BaseCapability 抽象键）
  setup(): void                            // 装配钩子，缺省空实现
  dispose(): void                          // 释放（沿用 BaseObject 幂等）
  describe(): string                       // `${pluginKey}:${pluginName}@${contractVersion}`
}
```

- 只承载装配语义；注册与解析调用统一注册表（`02_05`），不在此实现。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未注入 sink | 用默认 console / 空配置，不抛错 |
| `getConfig` 命中非期望类型 | 返回原值，由消费方按泛型约定处理（本期不做类型校验） |
| `dispose` 重复调用 | 幂等；`onDispose` 只执行一次 |
| 子类未提供 `key` / `pluginKey` | 类型检查期报错（抽象成员） |
| 子类构造未传 namespace | 用缺省值 |

## 8. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
