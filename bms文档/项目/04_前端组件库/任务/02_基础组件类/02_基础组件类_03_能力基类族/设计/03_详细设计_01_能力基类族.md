## 1. 设计目标与范围 <a id="goal"></a>

落地 **27 个能力基类**（横切功能基类，挂组件根或已有能力基类）与**能力依赖登记表 + 单向校验**。对齐后端已验证做法：能力基类只承载横切功能的语义与可订阅状态（纯 TS、框架无关），公共字段 / 方法只在链上对应基类维护；**契约骨架 + 可验证状态**（网络 / 数据通路按占位，不请求）。

**分三批**（每批自测提交）：

| 批 | 覆盖 | 数量 |
| --- | --- | --- |
| 一 | 值·字段链与形态类：`BaseValue` / `BaseField` / `BaseSized` / `BaseDataState` / `BaseOverlay` / `BaseNotice` / `BaseLabeled` / `BaseValidatable` | 8 |
| 二 | 交互与上下文类：`BasePersistedState` / `BaseMounted` / `BaseDesignToken` / `BaseClickable` / `BaseDragDrop` / `BaseTabs` / `BaseLocale` / `BaseAccess` / `BaseModuleContext` | 9 |
| 三 | 数据源与内核类：`BaseAsyncTask` / `BaseUploadEngine` / `BaseEditorKernel` / `BaseOptionSource` / `BasePresignedUrl` / `BaseWatermark` / `BaseUserDisplay` / `BaseDynamicRoutes` / `BaseFormMeta` / `BaseFormPage` | 10 |

不在本期：组件基类（`02_04`）、具体组件、真实数据通路（随组件域）、注册表具体实现（域 10）。

## 3. 公共机制 <a id="mechanism"></a>

`capabilities/manifest.ts`：

```ts
export const CAPABILITY_MANIFEST: Readonly<Record<string, readonly string[]>>  // key → depends
export interface CapabilityProblem { key: string; kind: 'unregistered' | 'cycle' | 'bad-key'; detail: string }
export function validateCapabilityGraph(manifest?: Readonly<Record<string, readonly string[]>>): CapabilityProblem[]
export function assertCapabilityGraph(manifest?): void   // 有违规：开发态告警（reportError），strict 抛 BaseError(10001)
```

- 校验三类：**依赖已登记**、**无环**、**键名合法**（kebab-case）。
- 开发态默认告警（经 `BaseObject.reportError`），`strict` 选项抛 `BaseError(ErrorCodes.CAPABILITY_VIOLATION)`。

## 4. 各能力基类契约概要 <a id="classes"></a>

> 统一形态：`extends 父基类`，`identifier` 与 `depends`；状态为**纯 TS 内存状态 + 可订阅快照**（`getSnapshot()` / `subscribe(listener)`，监听返回取消函数）；网络 / 数据通路按占位（不请求）。

| 能力基类 | 关键契约（骨架） |
| --- | --- |
| `BaseValue` | `value` 归一 / `setValue` / 三态（空 / 有值 / 只读）/ `onChange` / 格式化钩子 |
| `BaseField` | 字段标识 / 字段上下文 / 校验触发时机（`trigger`） |
| `BaseSized` | 尺寸 / 密度档位解析（复用组件根档位，派生为尺寸语义） |
| `BaseDataState` | `loading → ready / empty / error` 状态机 + 竞态序号 + 订阅 |
| `BaseOverlay` | `open` / `close` / 层级 `zIndex` / 挂载点 / 焦点陷阱标记 / 关闭原因 |
| `BaseNotice` | 提示类型 / 时长 / 关闭语义 / 队列 |
| `BaseLabeled` | `label` 文案 / 位置 / 宽度 / 必填标记 / 帮助与错误位 |
| `BaseValidatable` | 规则汇总 / `validate()` / 错误定位 / 结果回传 |
| `BasePersistedState` | 本地即时状态 + 远端偏好同步接口（占位）/ 版本比对 |
| `BaseMounted` | 挂载 / 卸载生命周期 + 释放登记（复用 `dispose`） |
| `BaseDesignToken` | 令牌消费（间距 / 色板 / 密度 / 断点）/ 主题订阅（占位数据源） |
| `BaseClickable` | `loading` / `disabled` / 防抖 / 危险确认 / 键盘触发 / 埋点钩子 |
| `BaseDragDrop` | 拖拽 / 排序 / 跨区事件骨架 |
| `BaseTabs` | 打开 / 关闭 / 固定 / 缓存键清单 |
| `BaseLocale` | locale / 时区 / 格式上下文（切换与缓存） |
| `BaseAccess` | 权限码集合 + `has` / `hasAny` / `hasAll` |
| `BaseModuleContext` | 宿主注入 router / store / i18n / 用户 / 租户（只读约束） |
| `BaseAsyncTask` | 提交 / 轮询进度（退避）/ 取消 / 结果下载（占位执行器） |
| `BaseUploadEngine` | 分片 / 秒传 / 断点续传 / 进度 / 取消（占位上传器） |
| `BaseEditorKernel` | 懒加载 / 创建销毁 / 内容协议（占位加载器） |
| `BaseOptionSource` | 加载 / 缓存与版本比对 / 搜索 / 回显（占位加载器） |
| `BasePresignedUrl` | 获取 / 失效重取 / 降级下载（占位获取器） |
| `BaseWatermark` | 用户 / 租户信息注入（覆盖内容与导出） |
| `BaseUserDisplay` | 姓名 / 头像 / 状态 / 部门路径 |
| `BaseDynamicRoutes` | 菜单树 → 路由构建 / 注册 / 卸载 |
| `BaseFormMeta` | 元数据加载 / 缓存 / 版本比对（占位加载器） |
| `BaseFormPage` | 三态（新增 / 编辑 / 详情）/ 提交 / 脏数据 / 返回 |

## 5. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 依赖未登记 / 成环 / 键名非法 | `validateCapabilityGraph` 报告；开发态告警，`strict` 抛 `BaseError(10001)` |
| 数据源未注入（占位） | 返回占位态（空 / 禁用 / 降级），不请求、不抛错；占位契约纳入门禁 |
| `setValue` 值未变 | 不触发 `onChange`（值比较） |
| 状态机非法迁移 | 终止并告警，不破坏当前状态 |
| 订阅重复取消 | 幂等 |
| 释放后调用状态变更 | 忽略 / 告警（不抛） |

## 8. 边界与开放项 <a id="open"></a>

- 真实数据通路（选项源 / 上传 / 预签名 / 元数据 / 动态路由菜单源等）随组件域与后端能力阶段回补，本任务只落契约骨架与占位。
- 清单对账护栏（`manifest` ↔ 清单 ↔ 组件清单双向）随本任务收口（候选）。
- 组件基类（`02_04`）继承相应能力基类；具体组件落渲染插件。
