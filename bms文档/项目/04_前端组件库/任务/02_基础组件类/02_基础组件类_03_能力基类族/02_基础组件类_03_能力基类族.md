## 2. 任务内容 <a id="content"></a>

1. 能力基类族（开放集合，挂组件根或已有能力基类）落 `frontend/packages/core/src/capabilities/` 与 `base/`：值语义 `BaseValue`、字段语义 `BaseField`、尺寸档位 `BaseSized`、数据状态 `BaseDataState`、浮层 `BaseOverlay`、提示通知 `BaseNotice`、标签语义 `BaseLabeled`、校验 `BaseValidatable`、偏好持久化 `BasePersistedState`、可挂载 `BaseMounted`、设计令牌 `BaseDesignToken`、可点击 `BaseClickable`、拖拽 `BaseDragDrop`、页签 `BaseTabs`、语言上下文 `BaseLocale`、权限上下文 `BaseAccess`、模块上下文 `BaseModuleContext`、异步任务 `BaseAsyncTask`、上传引擎 `BaseUploadEngine`、编辑器内核 `BaseEditorKernel`、选项源 `BaseOptionSource`、预签名 `BasePresignedUrl`、水印 `BaseWatermark`、用户 / 组织展示 `BaseUserDisplay`、动态路由 `BaseDynamicRoutes`、表单元数据 `BaseFormMeta`、表单页组合 `BaseFormPage`
2. 提取规则落地（同后端「公共段提取」口径）：两条链公共段 → 提取能力基类（如 `BaseSized` 承载容器 / 布局 / 媒体尺寸档位）；`BaseOverlay` 挂 `BaseSized`、`BaseValidatable` 挂 `BaseLabeled`、`BaseField` 挂 `BaseValue` 等
3. 口径对齐后端已验证做法：能力基类**只承载横切功能的语义与可订阅状态**（框架无关、纯 TS），不掺 UI 视觉与业务；能力正交、可组合、可新增，不设层数 / 数量上限、不做封闭枚举
4. 新增规则（对齐后端「一域一目录 + 登记 + 契约测试」）：新增横切功能 = 新增能力基类（定父基类 + 登记）+ 契约用例；登记源 `capabilities/manifest.ts`
5. 占位先行：选项源 / 上传 / 异步任务 / 预签名 / 用户展示 / 表单元数据 / 偏好远端 / 权限码 / 动态路由菜单源按占位语义运行（不请求），占位契约纳入门禁（占位基座由 `02_05` 承载，对齐后端占位三件）
6. 单测：横切契约（受控值 / 三态 / 权限判定 / 校验触发 / 数据状态 / 释放联动等）；「同契约多实现」断言由 `02_07` 契约用例工厂承载

## 3. 完成标准 <a id="accept"></a>

能力基类族就位并被相应组件基类继承；口径对齐后端已验证做法（能力基类只承载横切语义、正交可组合、一域一目录 + 登记 + 契约测试）；新增能力基类流程可验证（不改固定三段与组件根）；核心用例覆盖横切契约；占位契约纳入门禁；《前端基类清单》§5.2 登记同步；`vue-tsc`、ESLint、Vitest 全通过。
