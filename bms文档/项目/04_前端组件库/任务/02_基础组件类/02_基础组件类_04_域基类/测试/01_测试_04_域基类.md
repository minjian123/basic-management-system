## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 用例内「同组件 provide → inject」断言失败 | Vue 的 `inject` 只解析父链 provides；用例改「父提供 / 子消费」结构（机制用法不变） |
| 2 | 函数格式化器不生效（`toValue` 将裸函数当 getter 调用） | 域层明确「裸函数 = 格式化函数」；响应式切换传 `ref` / `computed`（详细设计 §4.3 同步） |
| 3 | `sanitizeHtml` 解包 `<script>` 残留文本 | 危险标签（`script` / `style` / `iframe` / `object` / `embed` / `link` / `meta`）整块剔除 |
| 4 | `eslint` 对 `.vue` 脚本 DOM 类型误报 `no-undef` | 双端 `eslint.config.js` 对 `**/*.vue` 关闭（`vue-tsc` 保障类型） |
| 5 | 测试文件多 `defineComponent` 触发 `vue/one-component-per-file` | 双端 `eslint.config.js` 对 `tests/**` 关闭 |
| 6 | 首轮 5 条断言失败（合并 / 校验 / 注入 / 格式化 / 净化） | 逐项定位并修复（见[实施记录](../实施/01_实施_04_域基类.md) §4）；修复后 34 条全绿 |
