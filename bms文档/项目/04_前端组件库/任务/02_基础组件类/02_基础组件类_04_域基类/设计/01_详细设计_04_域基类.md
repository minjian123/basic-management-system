## 1. 概述 <a id="overview"></a>

- **目标**：落地**域基类**（双端 `frontend/` + `frontend-mobile/` 同款）——输入域 `BaseInput` / 展示域 `BaseDisplay` / 树域 `BaseTree` / 编辑器域 `BaseEditor`，每域「组合式（`useXxxBase`）+ 组件包装（`BaseXxx.vue`）」双轨；并补交付**字段上下文机制** `useFieldContext`（字段壳 ↔ 控件通道）。`BaseChart`（图表域）本次只落**新增域规则与登记口径**，实现随 `07_06` 演练新增。
- **范围**：需求 [02-4](../../../../需求/02_需求_基础组件类.md#r02-4)、任务 [02-4](../02_基础组件类_04_域基类.md)。
- **依据**：《组件设计》[01 输入域基类](../../../../../../设计/组件设计/02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)、[02 展示域基类](../../../../../../设计/组件设计/02_基础组件类/03_域基类/02_组件设计_展示域基类/02_组件设计_展示域基类.md)、[03 树域基类](../../../../../../设计/组件设计/02_基础组件类/03_域基类/03_组件设计_树域基类/03_组件设计_树域基类.md)、[04 图表域基类](../../../../../../设计/组件设计/02_基础组件类/03_域基类/04_组件设计_图表域基类/04_组件设计_图表域基类.md)、[05 编辑器域基类](../../../../../../设计/组件设计/02_基础组件类/03_域基类/05_组件设计_编辑器域基类/05_组件设计_编辑器域基类.md)（均含可交互原型）；《[前端开发规范](../../../../../../规范/前端开发规范.md)》§3（继承与组合分工 / 扩展规则 / 双端同款）；《[前端基类清单](../../../../../../前端基类清单.md)》§2 / §5 / §6 / §7；《[命名规范](../../../../../../规范/命名规范.md)》§9；《[架构设计 · 前端组件体系](../../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》。

## 4. 契约设计 <a id="contract"></a>

### 4.1 字段上下文机制（`field-shell/useFieldContext.ts`，非片段） <a id="field-context"></a>

```ts
export interface FieldContextControl {
  readonly fieldKey: string
  focus?: () => void
}

export interface FieldContextValue {
  readonly fieldKey: string
  readonly label: string
  readonly required: boolean
  readonly readonly: boolean
  readonly disabled: boolean
  readonly visible: boolean
  readonly errorText: string
  registerControl?: (control: FieldContextControl) => void
  unregisterControl?: (fieldKey: string) => void
  emitValueChange?: (value: unknown) => void
  emitValidate?: (passed: boolean, message?: string) => void
}

export const FIELD_CONTEXT_KEY: InjectionKey<FieldContextValue>
export function provideFieldContext(value: FieldContextValue): void
export function useFieldContext(): FieldContextValue | undefined
```

| 行为 | 口径 |
| --- | --- |
| 注入 | `inject` 缺省返回 `undefined`（控件脱离字段壳可独立工作，不报错） |
| 提供 | `provideFieldContext` 幂等（同组件重复提供以最后一次为准，开发态可告警） |
| 登记 | **上下文机制**（非片段）：不声明 `key`、不占《前端基类清单》§5 片段表；落档清单 §5 注记 + 组件设计输入域节点实现口径 |
| 依赖方向 | 只依赖 Vue `provide` / `inject`；`BaseInput` 消费，字段壳 / 字段类消费方未来提供 |

### 4.2 输入域（`input/`） <a id="input"></a>

```ts
export interface UseInputBaseOptions<T = unknown> {
  modelValue?: MaybeRefOrGetter<T>
  emptyValue?: T
  disabled?: MaybeRefOrGetter<boolean>
  readonly?: MaybeRefOrGetter<boolean>
  loading?: MaybeRefOrGetter<boolean>
  placeholder?: MaybeRefOrGetter<string>
  clearable?: MaybeRefOrGetter<boolean>
  fieldKey?: string
  required?: MaybeRefOrGetter<boolean>
  formatter?: (value: T) => string
  threeState?: MaybeRefOrGetter<boolean>
  validator?: () => string | undefined
  onChange?: (value: T | undefined) => void
  onValidateFail?: (message: string) => void
}

export interface UseInputBaseReturn<T = unknown> {
  readonly value: T | undefined
  readonly display: string
  readonly isUnset: boolean
  readonly isCleared: boolean
  readonly disabled: boolean          // 合并后
  readonly readonly: boolean          // 合并后
  readonly placeholder: string
  readonly canClear: boolean
  readonly isFocused: boolean
  readonly isComposing: boolean
  readonly context: FieldContextValue | undefined
  setValue: (value: unknown) => void
  clear: () => void
  validate: () => boolean
  resetValidation: () => void
  onFocus: () => void
  onBlur: () => void
  onCompositionStart: () => void
  onCompositionEnd: (value?: unknown) => void
}
```

| 行为 | 口径 |
| --- | --- |
| 组合 | `useField`（值归一 / 三态 / 校验 / 壳 / 权限）+ `useInputControl`（输入形态：composition / 清空 / 焦点） |
| 受控 | 只认 `modelValue`；输入经 `field.setValue`（归一 + 判等）→ 无变化不回调 `onChange` |
| `disabled` 合并 | `props.disabled \|\| loading \|\| context.readonly \|\| context.disabled \|\| field.perm.disabled`（字段权限 / 只读统一汇合） |
| `readonly` 合并 | `props.readonly \|\| context.readonly`；只读态禁改、保聚焦与复制 |
| 三态 | `isUnset` / `isCleared` 透出（`emptyValue` 缺省 `undefined`；必填校验区分未设置与显式空） |
| 校验 | `required`（显式 options 优先，缺省取 `context.required`）与 `validator`；不可见 / 只读直通通过；失败经 `onValidateFail` |
| 上下文注册 | 组件包装在 `onMounted` 调 `context.registerControl({ fieldKey, focus })`、`onUnmounted` 注销（`focus` 供壳错误定位） |
| 依赖方向 | 只依赖已交付片段 + `useFieldContext` + Vue；不依赖 UI 库 |

`BaseInput.vue`（框架无关）：

| 面 | 内容 |
| --- | --- |
| props | 组件根通用（`ns` / `size` / `density` / `loading` / `disabled` / `visible` / `dataTest`）+ 域属性 `modelValue` / `readonly` / `placeholder` / `clearable` / `emptyValue` / `fieldKey` |
| emits | `update:modelValue`（受控）/ `change`（归一后）/ `focus` / `blur` / `validate` |
| 插槽 | `default`（作用域 `{ base, value, disabled, readonly }`，子类填充真实控件）/ `prefix` / `suffix` / `prepend` / `append` / `empty` |
| 兜底渲染 | 无 `default` 插槽时渲染**原生 `<input>`**（最小可用兜底；节点「default 留空」的实现口径，子类插槽覆盖） |
| 透传 | 根属性经组件根令牌协议（`data-size` / `data-density` / 状态类 / aria）；未声明 attrs 透传原生 `<input>`（保留键不回传） |
| expose | `base`（组件根）/ `mechanisms` / 输入域组合式返回值（`value` / `validate` 等） |

### 4.3 展示域（`display/`） <a id="display"></a>

```ts
export interface UseDisplayBaseOptions {
  value?: MaybeRefOrGetter<unknown>
  formatter?: string | ((value: unknown) => string)
  emptyText?: MaybeRefOrGetter<string>
  density?: MaybeRefOrGetter<string>
  copyable?: MaybeRefOrGetter<boolean>
  ellipsis?: MaybeRefOrGetter<boolean | number>
  tooltip?: MaybeRefOrGetter<boolean | 'overflow'>
  onClickValue?: (value: unknown) => void
  onCopy?: (value: unknown) => void
}

export interface UseDisplayBaseReturn {
  readonly displayText: string     // 省略后文本（空值 → emptyText）
  readonly fullText: string        // 完整格式化文本
  readonly tooltipText: string     // 省略 / tooltip 开启时的完整文本
  readonly isEmpty: boolean
  readonly isEllipsis: boolean
  readonly isClickable: boolean
  readonly canCopy: boolean
  onClick: () => boolean
  copy: () => Promise<boolean>
}
```

| 行为 | 口径 |
| --- | --- |
| 组合 | `useValue`（值归一与格式化调度）+ `useDisplayControl`（空值占位 / 省略 / 密度 / 点击） |
| 格式化 | `formatter` 为函数直接用；为**名称**时查注册表（`02_06` 格式化工具接入前**未注册即回退 `String(value)`**，占位口径）；空值 `—`（i18n `common.empty` 优先） |
| 空值判定 | `null` / `undefined` / `''` 为空；**`0` / `false` 非空**（不误判） |
| 省略 / tooltip | `ellipsis` = `true`（32 字符）/ 数字；悬停展示完整值（`title` 兜底，重 Tooltip 由子类接入） |
| 复制 | `navigator.clipboard` 可用时写剪贴板并触发 `onCopy` / 组件 `copy` 事件；不可用返回 `false`（不抛错）；**脱敏字段由壳传 `copyable=false`**（不复制明文） |
| 只读 | 不接收 `modelValue`、不参与校验（与输入域严格区分） |

`BaseDisplay.vue`：props `value` / `formatter` / `emptyText` / `density`（组件根既有）/ `copyable` / `ellipsis` / `tooltip`；emits `copy` / `click-value`；插槽 `default`（作用域 `{ value, text }`）/ `empty`；兜底渲染 `<span>` + `title` + 复制按钮。

```ts
  readonly loading: boolean
  readonly isPlaceholder: boolean
  readonly selectedKey: string | undefined
  readonly checkedKeys: string[]
  readonly expandedKeys: string[]
  readonly keyword: string

  toggleExpand: (key: string) => void

  loadChildren: (node: TreeNode) => Promise<TreeNode[]>
  filterNodes: (keyword: string) => TreeNode[]

```

| 行为 | 口径 |
| --- | --- |
| 组合 | `useTreeData`（归一 / 懒加载 / 选中 / 勾选 / 释放）；`load` 拆为根 / 子加载器，缺省即占位（不请求，静态数据或空） |
| 选择模型 | `selectable=false` 时 `select` 空操作；勾选级联 / `checkStrictly` 透传片段 |
| 过滤 | **保留命中节点及其祖先路径**（剪枝复制，不破坏原树）；`keyword` 空即全量；远程过滤由消费方按域接入（不在本层） |
| 全展开 | `defaultExpandAll`：静态数据同步收集；懒加载在根加载后展开已加载分支 |
| 手风琴 | `accordion=true`：`toggleExpand` 同层只保留一个展开项 |
| 空态 / 加载态 | `loading` 透出；空数据由消费方接展示类「异常与空状态」，本层给 `empty` 插槽 |
| 依赖方向 | 只依赖片段 + Vue；不依赖 UI 库（`el-tree` / Vant 由子类接入） |

`BaseTree.vue`：props `data` / `load` / `nodeKey` / `labelKey` / `childrenKey` / `checkable` / `checkStrictly` / `selectable` / `accordion` / `filterable` / `defaultExpandAll`（+ 组件根通用）；emits `select` / `check` / `node-click` / `node-expand` / `node-collapse` / `loaded`；插槽 `default`（作用域 `{ node }`）/ `empty` / `actions`（作用域 `{ node }`）；兜底渲染**递归原生列表**（`ul` / `li`，缩进 + 展开标记 + 勾选框）。

### 4.5 编辑器域（`editor/`） <a id="editor"></a>

```ts
export interface UseEditorBaseOptions {
  modelValue?: MaybeRefOrGetter<string>
  kind?: MaybeRefOrGetter<'rich' | 'markdown' | 'code'>
  language?: MaybeRefOrGetter<string>
  readonly?: MaybeRefOrGetter<boolean>
  placeholder?: MaybeRefOrGetter<string>
  debounce?: number                  // `change` 去抖（缺省 300ms）
  loader?: EditorKernelLoader        // 缺省即占位：不加载内核
  onChange?: (content: string) => void
}

export interface UseEditorBaseReturn {
  readonly content: string
  readonly kind: string
  readonly isLoaded: boolean
  readonly isPlaceholder: boolean
  readonly readonly: boolean
  mount: (el: HTMLElement) => Promise<void>
  unmount: () => void
  setContent: (content: string) => void
  getContent: () => string
  focus: () => void
  onInput: (content: string) => void  // 降级 textarea / 内核输入统一入口（去抖上报）
  sanitize: (html: string) => string  // rich 协议白名单净化
}
export function sanitizeHtml(html: string): string
```

| 行为 | 口径 |
| --- | --- |
| 组合 | `useEditorKernel`（懒加载 / 创建销毁 / 内容协议）；内核缺省占位（不动态 import、不报错） |
| 降级 | kernel 占位或未就绪时 `BaseEditor.vue` 渲染 **textarea**（读写受控、去抖上报） |
| 内容协议 | `rich`＝HTML（**白名单净化**：script / iframe / `on*` / `javascript:` 一律剔除，服务端二次净化仍为最终防线）；`markdown`＝文本；`code`＝纯文本 |
| 变更上报 | 输入即时 `update:modelValue`；`change` **去抖**（缺省 300ms，经作用域释放清理定时器） |
| 挂卸 | `mount(el)` 创建实例（登记 `useEditorKernel` 的销毁路径）；`unmount()` 销毁；组件卸载自动调用 |
| 只读 | `readonly=true` 透传内核与降级 textarea（禁编辑、保复制与滚动） |
| 上传 | `upload` 配置透传（富文本图片 / 附件**占位**：不请求，随上传引擎 / 富文本字段任务接入） |
| 依赖方向 | 只依赖片段 + Vue；内核（CodeMirror / 富文本）由 loader 注入、独立分包 |

`BaseEditor.vue`：props `modelValue` / `kind` / `language` / `readonly` / `height`（缺省 `240`）/ `placeholder` / `upload`（+ 组件根通用）；emits `update:modelValue` / `change` / `kernel-ready`；插槽 `toolbar` / `default`（内核容器内容）；expose `focus` / `blur` / `getContent` / `setContent`。

### 4.6 `BaseChart` 新增域规则与登记口径（本次不实现） <a id="chart-rules"></a>

1. **新增域流程（强制）**：候选 → 组件设计节点（契约 + 可交互原型）→ 评审确认 →《前端基类清单》§6 登记 → 《前端开发规范》§3 与《架构设计》同步；未登记不得散落实现。
2. **域基类约束**：只做**语义归类与最终细化**，不设域枚举上限；不得依赖具体组件；组合式 `use + 域 + Base`、组件 `Base + 域`；组合式 + 组件包装双轨（本设计口径）。
3. **`BaseChart` 落地口径**：契约以[图表域基类节点](../../../../../../设计/组件设计/02_基础组件类/03_域基类/04_组件设计_图表域基类/04_组件设计_图表域基类.md)为准（实例生命周期 / `ResizeObserver` 尺寸自适应 / 主题令牌 / 空态占位 / `toDataURL` 导出）；**实现与用例随 `07_06`（展示类图表卡）演练新增**，ECharts 独立分包（知识档案《ECharts 技术介绍》已备）；清单 §6 保留行并注明实现去向。
4. **新增域演练验证**：`BaseChart` 规则经「登记即用」链路验证（清单 ↔ 节点 ↔ 消费方回引），归 `07_06`；本任务在需求 02-4 注块登记去向。
