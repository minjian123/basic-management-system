## 2. 任务内容 <a id="content"></a>

1. `BaseInput`（输入域）：组合输入形态片段 + 字段编排片段，统一受控绑定、`modelValue` / `update:modelValue` / `change` / `focus` / `blur`、`disabled` / `readonly` / `size` / `placeholder` / `clearable`、插槽与透传；供基础控件类与字段类使用。
2. `BaseDisplay`（展示域）：组合展示形态片段 + 受控值片段，统一只读回显、值格式化调度、空值占位、密度；供展示类与字段只读回显使用。
3. `BaseTree`（树域）：组合树数据片段 `useTreeData`，树选择 / 组织树 / 权限树共用（本阶段落地）。
4. `BaseEditor`（编辑器域）：组合编辑器内核片段 `useEditorKernel`（富文本 / Markdown / 代码编辑器共用）。
5. `BaseChart`（图表域）：本任务只定新增规则与登记口径，**实现随展示类图表卡任务（`07_06`）演练新增**。
6. 新增域规则：域基类只做语义归类与最终细化，不设域枚举上限；新增走「候选 → 设计节点 → 评审 → 清单登记」；域基类不得依赖具体组件。
7. 实现以《组件设计》`02_基础组件类/03_域基类/` 5 个节点及可交互原型为契约依据；用例入 Kiwi TCMS（先登记后编码）；详细设计随任务启动在 `设计/` 下补建。

8. **前置契约（已交付）**：[01 根系基类](../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）已提供日志 / 错误上报 / 配置 / i18n / 生命周期钩子与可选组件包装；域基类经组件根与片段组合取得横切能力，不重复实现；[02 组件根基类](../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（组合式 `usePlaceholderBase` / `useAsyncResourceBase` / `useSubscriptionBase`；经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现

## 3. 完成标准 <a id="accept"></a>

`BaseInput` / `BaseDisplay` / `BaseTree` / `BaseEditor` 就位并被基础控件类、字段类、展示类复用；`BaseChart` 新增规则成文且可在 `07_06` 落地；Vitest 覆盖域契约（受控绑定 / 只读回显 / 树数据 / 编辑器内核加载释放）；`vue-tsc`、ESLint、Vitest 全通过；《前端基类清单》「域基类（按需）」节状态回写同步。
