## 2. 任务内容 <a id="content"></a>

**变更目标**（设计见《[架构设计 · 前端组件体系](../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》「片段基类化」节）：原「能力片段 = 组合式（`useXxx`）」核心状态机无类形态、约束力弱；按「**基类核心统一强制、业务实现与界面表现自由**」原则，31 个片段**基类化**，对齐后端「能力基类 + 插件注册表 + 配置选择 + 提供者」形态：

1. **片段基类**：每片段新增 `BaseXxx extends BaseCapability`（状态机 / 契约 / 生命周期在类里；类内允许 Vue 响应式；「框架无关」仅指不依赖 UI 库）；命名 `Base` 前缀（与域基类区分）。
2. **注册与提供者**：能力域注册表（复用 `BaseRegistry` / `BaseRegistryItem`）+ `getXxx()` 提供者；多实现能力实现名登记、可替换；**不注册不可用**（护栏 + 运行时）。
3. **门面**：`useXxx()` 降为薄门面（实例化基类 + 组件根 `mechanisms` 挂接 + 响应式投影）；**组件调用面不变**。
4. **强制护栏（增补）**：片段类必须继承机制基类（AST 扫描）；清单对账扩展为「片段基类 ↔ 门面 ↔ 注册」三向一致；护栏规则**先于对应批次**落地。

**五批迁移**（双端同款；每批含契约 / 用例 / 清单 / 护栏 / 文档同步）：

| 批 | 内容 | 片段（数量） | 备注 |
| --- | --- | --- | --- |
| 1 | 试点与机制接线 | `value`（1） | 注册表 / 提供者 / 门面 / 护栏**模板成形**（含链路自证：未注册不可用 fixture 可拦） |
| 2 | 值·字段链 | `field-shell` / `field-perm` / `field` / `input-control` / `display-control`（5） | 链上依赖（`field` → value / field-shell / field-perm）改经基类 + 提供者 |
| 3 | 形态类 | `interactive` / `container` / `form-container` / `media` / `layout`（5） | 与域 03 / 04 已交付组件的消费面回归 |
| 4 | 复用类 | `tabs` / `persisted-state` / `option-source` / `upload-engine` / `async-task` / `editor-kernel` / `tree-data` / `user-display` / `dynamic-routes` / `form-meta` / `presigned-url` / `drag-drop` / `design-token` / `form-page` / `locale` / `access` / `column-config` / `query-scheme` / `watermark` / `fragment-context`（20） | 多实现能力（上传引擎 / 编辑器内核 / 选项源）登记与提供者收口 |
| 5 | 域基类与组件接入收口 | —（收口） | 域基类组合面（`useInputBase` 等）改走片段基类 / 门面；42 组件回归；**基类与片段合规审计重跑** |

**影响面**：组件设计 31 节点 + 片段机制 / 注册表节点；《[前端开发规范](../../../../../规范/前端开发规范.md)》§3；《[前端基类清单](../../../../../前端基类清单.md)》（角色 / 继承链 / 片段节）；`guard-*.spec.ts`（继承 / 依赖 / 清单 / 演练）；契约套件（`tests/base-*.spec.ts`）；Kiwi 用例（`705 ~ 708` 等修订 / 新增）；审计报告（重跑并更新结论）。

5. 用例入 Kiwi TCMS（先登记后编码）；详细设计随**批 1** 启动在 `设计/` 下补建（模板定稿后其余批次按模板执行，必要时按批补设计增量）。
