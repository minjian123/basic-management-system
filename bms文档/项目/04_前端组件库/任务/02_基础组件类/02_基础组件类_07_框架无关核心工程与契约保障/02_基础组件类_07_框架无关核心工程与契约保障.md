## 2. 任务内容 <a id="content"></a>

1. **工程分包（单仓多包 workspace）**：`frontend/packages/{core,vue,ui-ep,ui-vant}` + `frontend/apps/{desktop,mobile}` 骨架与包依赖（本期先建 `core` 与最小可跑骨架，渲染插件与宿主随后续需求域补）；核心纯 TS（固定三段 + 注册表与工厂 + 组件侧 + 资源占位错误 + 契约与领域逻辑）
2. **依赖方向与核心护栏**（对齐后端「CI 静态护栏」做法）：宿主 → 插件 → 核心；核心不得依赖渲染框架 / UI 库 / 插件 / 宿主（`guard-core-framework-agnostic`，核心包运行时依赖面为空）；插件之间不互相依赖；继承关系与层依赖由静态护栏校验
3. **契约用例工厂**（`frontend/packages/core/testing/`，`@bms/core/testing`）：同一契约对全部实现跑同一套断言（确认 / 权限 / 容器件 / 权限按钮 / 反馈件 / 输入控件等）；新增契约先落核心与契约用例
4. **扩展与登记机制**：候选 → 组件设计节点 → 评审确认 →《前端基类清单》登记 → 代码登记（`capabilities/manifest.ts`）+ 契约用例 → 同步架构与规范；兼容性口径（新增为兼容变更、调整既有契约升主版本）
5. **护栏**（对齐后端 CI 静态护栏项）：核心框架无关、能力登记与依赖校验（开发态告警）、契约测试套件、清单对账护栏（实现侧登记 ↔《前端基类清单》↔ 插件导出 ↔ 组件清单双向校验）、注册表「不注册不可用」
6. **错误码段位**：前端内建码对齐平台段位并保留自有子段（落点随 `02_05` 错误基座）
7. 单测 / 护栏用例（对齐后端「逐基类 + contracts + crosscut」测试分层）：护栏规则自测、契约用例工厂最小套件、包级 lint / typecheck / test 命令汇入根命令与 CI

## 3. 完成标准 <a id="accept"></a>

单仓多包 workspace 就位、依赖方向与核心护栏可查；契约用例工厂可对实现跑同一套断言；扩展流程成文并被至少一次新增演练验证；清单对账护栏可查（漏登记 / 僵尸条目）；错误码段位成文并被错误基座与请求层遵循；`vue-tsc`、ESLint、Vitest 全通过。
