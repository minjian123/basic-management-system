## 5. 关键约束与惯例（勿忘） <a id="rules"></a>

- **执行纪律**：待拍板事项一律 question 逐项确认（推荐项在前）；提交分笔（代码 / 文档）；**推送需用户明确指令**；全程中文；动手前先读《AI开发规范》与相关设计。
- **架构口径**：「同接口多实现 + 契约测试同一套断言」（契约用例工厂 `@bms/core/testing`）；能力避让组件根通用名（`busy` / `inactive` / `pending` / `metaVersion` / `permVisible` 等）；「不注册不可用」（`BaseError 10002`）；`packages/core` 禁依赖 Vue / UI 库 / 插件 / 宿主（护栏）；`useXxx` 只存在 `packages/vue/bindings`。
- **路径（S4c 后）**：宿主 `apps/desktop` / `apps/mobile`；插件 `packages/{core,vue,ui-ep,ui-vant}`；镜像内路径 `/opt/ci/frontend`、`/opt/ci/frontend-mobile`、`/opt/ci/workspace` 与 job 名保持；依赖桥模式见 `.gitlab-ci.yml`。
- **预算**：desktop 109.3 / 120 KB（合计 240 KB）；mobile 127.6 / 140 KB（2026-09-17 经确认放宽，理由入实施记录 19）；`ui-vant` 的 Vant 对话框走按需加载。
- **服务器**：睡眠时先 `python3 scripts/tools/wol/wake_mjbk.py` 唤醒（凭据在 `deploy/.env`）。
- **提交前全套**：`apps/desktop` 与 `apps/mobile`（lint / test / build / budget）+ bms 根 `npm run check` + `check-links.py` + `check-base.py`；CI 推送后 `gl_watch_pipeline` 跟盯。
