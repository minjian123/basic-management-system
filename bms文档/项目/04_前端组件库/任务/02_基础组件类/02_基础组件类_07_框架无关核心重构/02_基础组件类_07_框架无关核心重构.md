## 2. 任务内容 <a id="content"></a>

**根因与目标**（设计见《[架构设计 · 前端组件体系](../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》「框架无关核心与插件架构」节）：原基类体系把框架（Vue / Element Plus / Vant）混进基类层，衍生「双端同款 `diff -r`」「EP 依赖不可移植」「移动端缺件」等一连串技术冲突。**目标**：前端基类体系重做为**纯 TS/JS 框架无关核心**，Vue 与 UI 库降为**可替换渲染插件**，移动端成为同一核心的另一插件实现（与后端「纯 Python 基类 + 插件注册表 + 提供者」同构）。

**目标结构（单仓多包 workspace）**：

| 包 | 内容 | 依赖约束 |
| --- | --- | --- |
| `packages/core` | 根系 / 组件根（抽象）/ 机制基类 / **能力类基类（原 31 片段全部类化，纯 TS）** / 注册表 + 提供者（不注册不可用）/ 领域逻辑（值、校验、格式化、权限判定、请求契约）/ 契约与契约测试 | **不得依赖 Vue / UI 库 / 插件 / 宿主**（护栏） |
| `packages/vue` | Vue 绑定插件：组合式投影（`useXxx` 仅存在于此）+ 指令 + 令牌样式 | 依赖 core，不依赖 UI 库与宿主 |
| `packages/ui-ep` | PC 实现插件（Element Plus）：42 组件等 UI 实现（**原 `frontend/` 组件迁移，作为参考实现复用**） | 依赖 core + vue |
| `packages/ui-vant` | 移动端实现插件（Vant）：同接口实现 | 依赖 core + vue |
| `apps/desktop`、`apps/mobile` | 宿主装配（原 `frontend/` / `frontend-mobile/` 工程降级：路由 / 菜单运行时 / 页面） | 依赖插件与 core |

**实施阶段（6 段，双端口径废止、改为「同接口多实现 + 契约测试同一套断言」）**：

| 阶段 | 内容 | 工时（草案） |
| --- | --- | --- |
| S0 | 核心骨架与工程化：workspace 建立（pnpm/npm workspace + tsconfig + 构建 + CI 分包门禁）、`core` 骨架（base / mechanisms / registry / providers）、**「核心框架无关」护栏**（import 方向扫描）、契约测试模板 | 16h |
| S1 | 机制与能力试点：机制基类纯 TS 化；能力类化模板（可订阅状态接口 + 注册 + 提供者 `getXxx()`）；试点 `value` / 字段链（`field-shell` / `field-perm` / `field`）；`packages/vue` 投影试点（`useValue` / `useField` 仅作绑定） | 24h |
| S2 | 能力类化续批：形态类（`interactive` / `container` / `form-container` / `media` / `layout`）与复用类（`tabs` / `persisted-state` / `option-source` / `upload-engine` / `async-task` / `editor-kernel` / `tree-data` / `user-display` / `dynamic-routes` / `form-meta` / `presigned-url` / `drag-drop` / `design-token` / `form-page` / `locale` / `access` / `column-config` / `query-scheme` / `watermark` / `fragment-context`）全部类化 + 注册收口 + 契约用例 | 36h |
| S3 | `ui-ep` 插件重建：42 组件迁入（保留实现、重写绑定与令牌消费）、宿主接入准备、全量回归（替换旧 `frontend/` 内同名实现） | 40h |
| S4 | `ui-vant` 插件：同契约实现（原 `frontend-mobile/` 可复用部分迁移）+ 移动端宿主接入 | 24h |
| S5 | 宿主切流与收口：`apps/desktop` / `apps/mobile` 装配切到新架构、旧工程归档（`frontend/` / `frontend-mobile/` 标记 deprecated 或删除）、**审计重跑**（基类与片段合规 + 后端对账口径不变）、文档全面回写（前端规范 §3 / 基类清单 / 组件设计 31 节点 / 计划 / README / 首页 / Kiwi 用例处置） | 24h |

**旧交付处置**：域 02/03/04 代码**降级为「ui-ep 插件层参考实现」**（不废弃，`packages/ui-ep` 迁移复用；绑定层按新口径重写）；已建护栏 / 契约 / Kiwi 用例随新架构改造并保留。

5. 用例入 Kiwi TCMS（先登记后编码）；详细设计随 S0 启动在 `设计/` 下补建（S0 定骨架，各阶段按批补设计增量，模板定稿后其余批次按模板执行）。

## 3. 完成标准 <a id="accept"></a>

`packages/core` 纯 TS 且零框架依赖（护栏拦截）；31 能力全部类化并注册（不注册不可用）；`packages/vue` / `ui-ep` / `ui-vant` 三层插件就位且可替换（契约测试同一套断言全绿）；宿主切流完成；「双端同款」旧口径全面废止并回写（规范 / 清单 / 组件设计 / 计划 / 任务记录）；旧码归档或删除；**审计重跑通过**；`vue-tsc`（各包）/ ESLint / Vitest / 分包构建与体积门禁全通过。
