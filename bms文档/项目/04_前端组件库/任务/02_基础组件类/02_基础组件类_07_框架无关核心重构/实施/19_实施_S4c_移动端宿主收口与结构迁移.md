## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 预算超限：切流后 127.6 KB（≈ 框架 30 KB + Vant 对话框 JS/CSS 懒 chunk 45 KB），预算 83 KB | 经 question 确认放宽至 140 KB（理由入记录）；同时把 `ui-vant` 的 Vant 对话框与样式改**按需加载**（首屏不载，懒 chunk 仍计入总量口径） |
| 2 | 移动端 vitest 无法加载 Vant 的 `.css`（外部化后 Node 报 `Unknown file extension`） | `frontend/apps/mobile/vitest.config.ts` 增 `server.deps.inline: ['vant']`（与 `frontend/apps/desktop` 的 element-plus 同口径） |
| 3 | `useAccess` 投影初版经 watch 异步刷写 + 判定不建立 Vue 依赖 → store 判定滞后一拍、`PermButton` 不重算 | 投影改 `flush: 'sync'` 刷写 + 判定前读一次响应式集合建立追踪（保留核心实例为判定唯一实现） |
| 4 | 核心 `BaseError` 无 `data` 字段、构造为位置参数（与旧宿主 `BaseError` 对象式不同） | `ApiError` 适配核心构造 + 保留 `details`；`userMessage` 以 `declare` 收窄为 `string`（`request.ts` 提示调用不变） |
| 5 | 移动端 tsconfig 仅含 `src/`（旧工程不检查 tests），迁包后 `wrapper.vm.resetMeasurement` 报错 | 按包口径显式结构类型断言（与 `ui-ep` 测试同风格） |
| 6 | 旧 `BaseFrontend` 的全局 sink（`setFrontendSinks` / `resetFrontendBaseConfig`）在核心不存在 | 宿主新增 `adapters/host-base.ts`（`setHostSinks` / `resetHostSinks` + `hostBaseOptions`），测试与生产出口统一；错误记录补 `name` 字段保断言口径 |
| 7 | 旧 spec 28 个随旧层删除（含 Kiwi 编号用例） | 按台账 §2.1 口径登记下线；容器件用例迁 `ui-vant/tests/`（Kiwi 742 ~ 750 等原号保持） |
