## 2. 交付物 <a id="deliverables"></a>

```text
bms/（仓库根）
├── package.json                  # workspace 根（workspaces: packages/*；core:typecheck / core:test / core:check）
├── .npmrc                        # npmmirror 源（同 frontend/.npmrc）
├── tsconfig.base.json            # 共享 TS 配置（strict / ES2022 / Bundler / verbatimModuleSyntax）
└── packages/core/                # @bms/core：框架无关核心（纯 TS，运行时零依赖）
    ├── package.json / tsconfig.json / vitest.config.ts
    ├── src/
    │   ├── base/BaseFrontend.ts        # 根系（ns / version / 日志 / 错误上报 / 配置读取 / 生命周期）
    │   ├── base/BaseComponent.ts       # 组件根（档位属性 / 状态类 / 根属性协议——纯数据，不触 DOM）
    │   ├── mechanisms/error.ts         # BaseError + 前端内建码（10001 / 10002 / 10003 / 19001）
    │   ├── mechanisms/capability.ts    # 能力基类（key 校验 / 依赖登记 / 循环检测；strict 抛 10001）
    │   ├── mechanisms/registry.ts      # 注册表基座（唯一性拒重 / 未命中 undefined / 保序 / 只读快照）
    │   ├── mechanisms/placeholder.ts   # 占位基类（三类原因 × 三类降级；不请求约定）
    │   ├── mechanisms/resource.ts      # 异步资源基类（登记 / 逆序释放 / 幂等 / 释放后拒绝登记）
    │   ├── mechanisms/subscription.ts  # 订阅基类（topic 点分小写校验；占位总线先行）
    │   ├── providers/index.ts          # 提供者（getProvider 未命中 undefined / requireProvider 不注册不可用抛 10002）
    │   ├── contracts/index.ts          # 核心契约（CapabilityDescriptor / RenderBinding）
    │   └── index.ts
    └── tests/
        ├── guard-core-framework-agnostic.spec.ts   # 护栏：核心不得依赖 Vue / UI 库 / 插件 / 宿主（含 fixture 自证）
        └── contracts/{registry,capability}-contract.spec.ts  # 契约测试模板（实现清单参数化）
```

## 3. 验证结果 <a id="verify"></a>

| 命令 | 结果 |
| --- | --- |
| `npm run core:typecheck`（根 → `@bms/core`） | 通过（`tsc --noEmit`，strict） |
| `npm run core:test`（根 → `@bms/core`） | **3 文件 / 14 用例全绿**（护栏 3 + 能力契约 3 + 注册表契约 8） |
| `npm run core:check` | 通过（typecheck + test 串联） |

- 护栏自证：fixture 含 `import { ref } from 'vue'` / `element-plus` / 宿主相对路径 → 三例全拦；包依赖面断言 `dependencies` / `peerDependencies` 为空。
- 契约模板：注册表契约以 `BaseRegistry` / `ProviderRegistry` 两实现参数化（`describe.each`），新增实现登记即纳入覆盖。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | vitest 5 启动报 `Cannot find package 'vite'`（vite 为 peer） | 根 devDependencies 显式加 `vite@^8.2.2`（与 `frontend/` 对齐）后通过 |
| 2 | 环境事实：CI 前端 job 依赖**镜像预置** `/opt/ci/frontend/node_modules`（非 `npm ci`） | 本阶段**不接 CI**（避免空跑/误红）；CI 接入（触发器 `packages/**` + job + 镜像依赖预置）登记为 S1 前置项（见 §5） |

## 5. 偏差与遗留 <a id="deviations"></a>

| # | 项 | 归口 / 去向 |
| --- | --- | --- |
| 1 | S0 工时口径：原估 16h 含「CI 分包门禁」；实测 ≈2h（骨架 + 护栏 + 契约模板，CI 未接） | 偏差按实测回写计划；S1 起始补 CI 接入（触发器 + job + 镜像预置依赖） |

| 3 | 核心骨架范围：DOM / 渲染无关已保证；`mechanisms` 挂接点（组件根 `mechanisms`）当前为最小骨架 | S1 随机制接线补全（防重复：与既有 `guard-*` 体系对照改造） |
| 4 | 旧体系（`frontend/` / `frontend-mobile/`）仍为现状；新核心未接任何消费方 | S1 试点（`value` / 字段链）时接入首个消费方验证链路 |
