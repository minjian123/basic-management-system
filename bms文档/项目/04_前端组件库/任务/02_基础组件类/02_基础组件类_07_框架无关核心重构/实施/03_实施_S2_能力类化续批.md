## 2. 交付物 <a id="deliverables"></a>

| 组 | 能力（类） | 数量 |
| --- | --- | --- |
| 值 · 字段链（S1） | `BaseValue` / `BaseFieldShell` / `BaseFieldPerm` / `BaseField` | 4 |
| **形态（S2）** | `BaseInteractive`（忙碌 / 禁用 / 防抖）、`BaseInputControl`（composition / 焦点）、`BaseDisplayControl`（空值占位 / 省略）、`BaseContainer`（折叠状态机）、`BaseFormContainer`（label 位置 / 栅格 / 错误汇总）、`BaseMedia`（加载状态机 + 重试，依赖 `presigned-url`）、`BaseLayout`（断点 / 栅格，依赖 `design-token`） | 7 |
| **复用（S2）** | `BaseTabs`（开关 / 固定 / 上限淘汰 / `cachedNames`）、`BasePersistedState`（可注入存储 + 内存适配器）、`BaseOptionSource`（占位 / loader）、`BaseUploadEngine`（占位 / 取消）、`BaseAsyncTask`（占位 / submit+poll）、`BaseEditorKernel`（懒加载 / 销毁）、`BaseTreeData`（展开 / 选中 / 勾选）、`BaseUserDisplay`、`BaseDynamicRoutes`（adapter 注入）、`BaseFormMeta`（版本缓存）、`BasePresignedUrl`（缓存 / 失效）、`BaseDragDrop`（`reorder`）、`BaseDesignToken`（reader 注入）、`BaseFormPage`（三态 / 脏数据 / 离开守卫）、`BaseLocale`、`BaseAccess`（has / hasAny / hasAll）、`BaseColumnConfig`、`BaseQueryScheme`（保存 / 应用）、`BaseWatermark`、`BaseModuleContext`（宿主句柄注入） | 20 |

- **清单与注册**：`capabilities/manifest.ts` 扩至 **31 项**（key / depends 与《前端基类清单》能力节逐项对齐）；`capabilities/index.ts` 注册 31 项（导入即登记，**不注册不可用**）。
- **契约（新增 16 用例）**：`s2-capability-matrix.spec.ts`（规模 31 / 登记一致 / 全量可创建 / 依赖无幽灵）+ `s2-behaviors.spec.ts`（27 类行为分组抽查 12 组）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 能力属性与组件根通用名冲突（TS2416）：`interactive` 的 `loading` / `disabled`、`option-source` 的 `loading`、`form-meta` 的 `version` / `loading` | **能力避让组件根通用名**（既定口径）：改域语义名——`busy` / `inactive`、`pending`、`metaVersion`；组件根协议（`loading` / `disabled` / `version`）保持唯一来源 |

## 5. 偏差与遗留 <a id="deviations"></a>

| # | 项 | 归口 / 去向 |
| --- | --- | --- |
| 1 | 能力实现为**骨架级**（分片 / 秒传 / 轮询退避 / 编辑器内核细节 / 树懒加载等） | 随 S3（`ui-ep` 重建）接入真实消费方时按需补深；契约先行保证行为面稳定 |
| 2 | `@bms/vue` 投影仅 `useValue` / `useField`（试点链接） | 其余能力投影随 S3 组件接入按需补（模式：实例化核心 + `shallowRef` 投影 + scope 释放） |
| 3 | 旧体系（`frontend/apps/desktop/`）能力（Vue 组合式）与新核心并存 | S3 起 `ui-ep` 迁移接入；S5 旧工程归档 / 删除 |
| 4 | 能力注册目前「导入即注册」（`@bms/core` 出口副作用） | 可评估改为显式 `registerAll()`（S5 收口时统一，避免副作用导入争议） |
