### 2.2 机制节点契约对齐（7 个节点） <a id="contracts"></a>

| 节点 | 原设计面（改前） | 现行实现（改后） |
| --- | --- | --- |
| 03 能力机制 | `assertDeps()` / `register()` / `fragment:*` 事件 | 构造期校验（key 口径 / 依赖已登记 / 无循环；`strict` 抛 `CAPABILITY_VIOLATION`）+ `describe()` / `isDisposed` |
| 04 占位基类 | `label` / `degrade` / `mark()` / `assertImplemented()` / `silentInProd` | `reason` / `fallback` / `note` / `describe()`（打标与断言标注为原设计面） |
| 05 异步资源基类 | `track()` / `releaseAll()` / `onRelease()` / `kind` / `autoRelease` / `onError` | `registerResource()` / `dispose()`（逆序 + 幂等，失败经 `reportError` 不阻断）/ `isDisposed` |
| 06 注册表基类 | `unregister` / `has` / `list()` / `size` / 注册事件 | `register(item, {strict, onWarn})` / `get` / `keys` / `values` / `snapshot` / `count` |
| 07 错误基类 | `data` / `fromResponse()` / `toUserMessage()` / `report()` / 段位判定 | `code` / `message` / `userMessage` / `cause` + 标准 `Error` 派生；解析 / 映射 / 上报归宿主请求层（`ApiError` / `errorMessage`） |
| 08 订阅基类 | `unsubscribe` / `once` / `publish` / `has` / `source` 枚举 | `bus`（`SubscriptionBus` 注入，占位总线先行）/ `subscribe`（点分小写校验 + 登记取消）/ `dispose()` |
| 20 动态路由能力 | `mode` / `fallback404` | `key` / `adapter` + `buildRoutes(menuTree, {pathPrefix, allowedPaths})` / `register` / `unregister` / `hasRoute` / `reset` / `routes` / `describe()` |

- 统一口径：各节点 §2 / §3 / §4 / §7 / §9 同步改写；未落码项统一标注「原设计面（未落码）」，不做删除（保留演化方向），与《[前端开发规范](../../../../../../规范/前端开发规范.md)》§3.2「机制基类契约要点」及《[前端基类清单](../../../../../../前端基类清单.md)》机制行逐项一致。
- 原型配套：05 / 07 / 08 / 20 四个原型 html 的可见说明文案同步（`registerResource` / `dispose` / 宿主解析 / 占位总线 / `mode` 注）；**JS 逻辑与函数名零改动**（演示代码自洽）。
