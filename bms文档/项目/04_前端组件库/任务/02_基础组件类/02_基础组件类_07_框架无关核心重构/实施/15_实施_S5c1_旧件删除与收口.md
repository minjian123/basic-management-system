## 1. 实施信息 <a id="meta"></a>

| 项 | 值 |
| --- | --- |
| 阶段 | S5c-1 旧件删除与引用收口（`frontend/apps/desktop` 旧组件目录与旧 spec 删除；旧能力层保留） |
| 实施日期 | 2026-09-17 |
| 实测工时 | ≈2h |
| 结论 | S5c-1 完成：旧组件目录（7 目录 / 34 件）与 23 个旧 spec 删除，宿主残留引用全量切 `@bms/ui-ep`；测试 234 用例全绿、构建与分包预算通过 |

## 2. 交付物 <a id="deliverables"></a>

| 块 | 内容 |
| --- | --- |
| 删除 | `frontend/apps/desktop/src/components/` 下 `common` / `container` / `feedback` / `layout` / `menu` / `modal` / `tabs`（34 件）与 23 个旧件 spec（layout-* / container-* / feedback-* / menu-side-menu / tabs-* / modal-containers）；`components/README.md` 改写为「仅能力层」说明；历史经 git 追溯 |
| 引用收口 | `stores/menu`、`config/placeholder-menu`（`MenuItem` 类型 → `@bms/ui-ep`）；`dev/ContainersCheck`、`views/PlaceholderView`、`router/menuRoutes`、`tests/permission.spec`（`PermButton` + 注入判定器）切 `@bms/ui-ep` |
| 保留 | 旧能力层（31 个预置能力，stores / directives / 未来域组件消费；后随 S6 删除，历史经 git 追溯）；基础设施 spec（护栏 / 能力 / 格式化 / 权限判定 / 菜单数据层 / 请求）与宿主用例（739 切流断言）不变 |
| 分包优化 | `vite.config.ts` 增 `manualChunks`（`element-plus` → `vendor-element-plus`；`/packages/` → `bms-base`）——旧件删除致 chunk 划分变化（127 KB 超限），分包后最大单文件 **109.3** KB |

## 4. 问题与处置 <a id="issues"></a>

| 问题 | 处置 |
| --- | --- |
| 删除后 chunk 划分变化，单文件超预算（127 > 120 KB） | 手动分包（`manualChunks`：EP 与基座源码独立 chunk），预算保持 120 不放松 |
| `PermButton` 旧测试依赖 store 响应式 | 测试经 `configurePermissionChecker` 注入权限 store 语义（组件侧保持注入点口径） |
| `stores/menu` / `placeholder-menu` 仍引旧件类型 | 统一切 `@bms/ui-ep`（`MenuItem` / `sortVisible` 等函数已随迁） |
| Kiwi 平台侧用例状态 | 台账登记 `DISABLED` 口径；平台操作（置 DISABLED）待执行（遗留，登记于台账 §2.1） |
