## 3. 口径与规则（本次统一） <a id="rules"></a>

- **术语**：**能力（类）** + 按需投影；`useXxx` 仅指 `frontend/packages/vue/src/bindings/` 的投影；双端一致性为「**同一契约多实现**」（+ 契约测试同一套断言）。
- **落点写法**：仓库根视角全路径（`frontend/packages/{core,vue,ui-ep,ui-vant}`、`frontend/apps/{desktop,mobile}`）；镜像内路径 `/opt/ci/*` 保持。
- **历史留痕**：项目 04 文档已按现行口径全量对齐（2026-09-17，实施记录 28；历史经 git 追溯）。
- **微前端「片段」**：产品前端模块（Module Federation）仍称「片段」，与能力（类）区分，不替换。
