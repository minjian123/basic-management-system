## 2. 交付物 <a id="deliverables"></a>

| 块 | 内容 |
| --- | --- |
| 接入（alias + paths） | `frontend/apps/desktop/vite.config.ts` 与 `tsconfig.app.json`：`@bms/core` / `@bms/vue` / `@bms/ui-ep` → `frontend/packages/*/src/index.ts`（源码直出，与包 `exports` 设定一致；零安装与 CI 依赖改动） |
| 宿主适配层（新，`frontend/apps/desktop/src/adapters/`） | `ui-bootstrap.ts`：注入点接线（`configurePermissionChecker` ← 权限 store（any/all 语义）、`configureMenuSource` ← 菜单 store、`configureViewResolver` ← 路由视图工具）；`use-app-tabs.ts`：`@bms/vue` `useTabs`（核心 `BaseTabs`）模块级单例 → 标签栏（含 `closeOthers` / `closeRight` / `closeAll` 组合与 `resetAppTabs` 测试隔离） |
| 切流（4 处） | `BasicLayout`（`ui-ep` `AppLayout` / `SideMenu` / `TabsNav` 受控 + `useAppTabs` 桥接；keep-alive `:include` ← `cachedNames`）；`HomeView`（`PageContainer` + `Card`）；`routes.ts` 错误页（`ui-ep` `ErrorPage` 静态导入）；`main.ts`（`bootstrapUiBridge()` 装配） |
| 组件侧配套 | `ui-ep` `TabsNav` 受控 `tabs` props 放宽为 `readonly TabNavItem[]`（只读输入语义） |
| 宿主用例更新 | `tests/home.spec.ts`（Kiwi 19）与 `tests/layout-app-shell.spec.ts`（Kiwi 739）按切流后结构更新（语义与用例号不变）；`AppLayout` 引用切至 `@bms/ui-ep` |
| 预算 | `budget.json`：合计 200 → **240** KB、单文件 100 → **120** KB（新体系源码合入主包；`note` 说明，S5b 按路由级分割复评） |

## 4. 问题与处置 <a id="issues"></a>

| 问题 | 处置 |
| --- | --- |
| `readonly TabEntry[]` 与 `TabsNav` 的 `tabs: TabNavItem[]` 不兼容 | 组件 props 放宽为 `readonly TabNavItem[]`（受控输入应为只读；内部逻辑不变） |
| 错误页懒加载与 `ui-ep` 静态导入并存（`INEFFECTIVE_DYNAMIC_IMPORT`） | 错误页改静态导入（`ui-ep` 已随主包；消除告警与无效分包） |
| 切流后主包体积超预算（214.7 > 200 KB） | 预算调至 240 / 120（`budget.json` 注明原因；后续按路由级分割复评） |
| 标签状态单例跨测试残留 | 适配层导出 `resetAppTabs()`（宿主 spec `beforeEach` 调用） |
| CI `desktop-check` / `desktop-build` 失败（本地通过）：CI 仅有 `frontend/apps/desktop/node_modules`，`frontend/packages/**` 源码向上解析依赖（element-plus 等）失败 | job 内补根 `node_modules` 桥 + `@bms/*` symlink（与 `core-check` 同模式，`cf8f16ae`）；pipeline **242** 全绿 |
| `defect-capture`（241 失败时触发）因数据库 `bms_test_mysql` 不存在而失败 | **遗留**：捕获脚本库名 / 前置与 `backend-test` 环境不一致，待专项排查（不影响正常流水线） |
