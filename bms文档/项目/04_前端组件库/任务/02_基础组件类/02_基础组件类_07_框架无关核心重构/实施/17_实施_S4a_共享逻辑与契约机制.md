## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `sessionStorage` 适配器依赖 DOM 类型，而 core `lib` 仅 `ES2022`（无 DOM） | 以最小结构面（`ScrollStorage`）探测 `globalThis.sessionStorage`，行为不变；core 保持无 DOM 类型面（禁止靠 DOM lib 兜底） |
| 2 | `viewResolver` 契约带 Vue `Component` 类型，直迁 core 会破「核心不得依赖 Vue」护栏 | 泛型化 `ViewResolver<TView = unknown>`；`ui-ep` 侧专化为 `ViewResolver<Component>`，对外类型名与用法不变 |
| 3 | 契约工厂的「恢复默认」断言若调用真实默认实现（ElMessageBox / Vant Dialog）会引入 UI 依赖与悬挂 Promise | 契约套件只断言覆盖语义（透传 / rejection / 多次覆盖 / 恢复后可再配置）；共享工厂的「未覆盖走默认、恢复回默认」由 core 自测（探针默认）覆盖；默认 UI 行为由各插件自测 |
| 4 | 旧 `useVirtualRange` 的路径判定按「`heights` 选项在场」而非取值（在场但为 `null` 走动态路径） | 投影层映射 `heights: options.heights ? (toValue(...) ?? []) : null`，保持旧判定与数值结果一致 |
| 5 | `permission` 契约断言中「空数组放行不经过判定器」的调用次数口径 | 契约用例显式覆盖：`check([])` 放行且判定器调用次数不增（与旧 `checkPerm` 逐条等价） |
