## 1. 设计目标与范围 <a id="goal"></a>

落地 **16 个组件基类**（各组件族的身份骨架与统一契约，继承相应能力基类）。形态：**契约骨架 + 可验证状态**（纯 TS、框架无关）；具体组件只写自身差异、继承对应族基类。

**字段链组合口径（确认）**：值链（`BaseValue → BaseField → BaseInput`）与壳链（`BaseLabeled → BaseFieldShell → BaseFieldPerm`）**当前不互相依赖，两条链各自独立**；具体字段件在渲染插件层组合「值控 + 壳 / 权限」，后续任务实现（本任务不合并、不改父基类）。

不在本期：具体组件（域 03+）、`BaseChart`（只留规则，随需求域 07 图表卡演练新增）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

| 组件基类 | 父基类 | identifier | 关键契约（骨架） |
| --- | --- | --- | --- |
| `BaseInput` | `BaseField` | `input` | 受控绑定（继承值链）/ `placeholder` / `clearable` + `clear()` / composition 标记 / 焦点 `focus` / `blur` |
| `BaseDisplay` | `BaseValue` | `display` | 只读呈现 / `emptyText` 空值占位 / `ellipsis` / `displayText` |
| `BaseTable` | `BaseDataState` | `table` | 行数据 / 排序 / 选中 / 分页 |
| `BaseList` | `BaseDataState` | `list` | 列表数据 / 滚动加载 `append` / 空态错误态 / `refresh` |
| `BaseTreeData` | `BaseDataState` | `tree-data` | 加载 / 展开与勾选 / 过滤 / 缓存 |
| `BaseModalShell` | `BaseOverlay` | `modal-shell` | 模态语义 / 关闭拦截 `beforeClose` / 底部操作区 |
| `BaseFormContainer` | `BaseValidatable` | `form-container` | label 位置与宽度 / 规则汇总 / 字段错误定位 / 只读态 |
| `BaseContainer` | `BaseSized` | `container` | 折叠 / 分栏 / 区域令牌 |
| `BaseLayout` | `BaseSized` | `layout` | 栅格列数 / 间距 / 显隐 |
| `BaseMediaContent` | `BaseSized` | `media-content` | 加载状态机 / 宽高比 / 过期重取 / 回退 |
| `BaseFeedback` | `BaseNotice` | `feedback` | `loading → ready / empty / error` 反馈状态机与降级重试 |
| `BaseNotification` | `BaseNotice` | `notification` | 站内信 / 公告展示与已读 |
| `BaseColumnConfig` | `BasePersistedState` | `column-config` | 列显隐 / 顺序 / 宽度 / 冻结 / 持久化 |
| `BaseQueryScheme` | `BasePersistedState` | `query-scheme` | 条件模型 / 方案保存·应用 |
| `BaseFieldShell` | `BaseLabeled` | `field-shell` | label / 必填 / 帮助 / 错误 / 栅格跨度 / 只读回显 |
| `BaseFieldPerm` | `BaseFieldShell` | `field-perm` | `permVisible` / `editable` / `permRequired` 三态 + 脱敏 |

- 组件基类经继承链取得能力键（`key = pluginKey = identifier`）；不进入能力依赖登记表（`manifest` 仅登记能力基类）。
- 网络 / 数据通路按占位（不请求）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 表格 / 列表数据未就绪 | 用 `BaseDataState` 状态机（`loading` / `empty` / `error`），不请求 |
| 关闭拦截返回否 | `requestClose` 返回 `false` 且不关闭 |
| 字段权限不可见 | `rendered` 为假（不渲染）；不可编辑 → `effectiveDisabled` |
| 媒体加载失败 | 状态置 `error`，提供回退（占位） |
| 释放后调用 | 幂等 / 忽略（沿用基类） |
