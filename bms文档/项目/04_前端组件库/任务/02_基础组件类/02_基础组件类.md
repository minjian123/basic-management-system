## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段四需求域 02 的 7 条需求——[02-1 总基类与固定三段](../../需求/02_需求_基础组件类.md#r02-1)、[02-2 组件根](../../需求/02_需求_基础组件类.md#r02-2)、[02-3 能力基类族](../../需求/02_需求_基础组件类.md#r02-3)、[02-4 组件基类族](../../需求/02_需求_基础组件类.md#r02-4)、[02-5 体系机制](../../需求/02_需求_基础组件类.md#r02-5)、[02-6 基础类横切底座](../../需求/02_需求_基础组件类.md#r02-6)、[02-7 框架无关核心工程与契约保障](../../需求/02_需求_基础组件类.md#r02-7)，按「1 需求 = 1 子任务」拆 7 个子任务（`02-6` 含 4 个嵌套子任务：请求封装 / 权限指令 / 格式化工具 / 设计令牌）。
- **依据**：[《架构设计 · 前端组件体系》](../../../../设计/架构设计/05_架构设计_前端组件体系.md)「前端基类体系（开放式，对齐后端基类体系）」「框架无关核心与插件架构」「执行护栏（机器强制）」节；[《前端基类清单》](../../../../前端基类清单.md)；[《前端开发规范》](../../../../规范/前端开发规范.md)「架构铁律」「前端基类体系（强制）」节；[《组件设计 · 总览》](../../../../设计/组件设计/01_组件设计_总览.md)。
- **口径**：本域为全组件库的根——**公共字段 / 方法只在链上对应基类维护**；固定前三段（总基类 → 能力域基类 → 插件基类）+ 组件侧（组件根 → 能力基类 → 组件基类 → 具体件）；**继承链唯一权威为《前端基类清单》**。**本次为全新构建**（前端代码已清空），不涉及旧口径迁移。其余需求域（03 ~ 10）任务随各自启动补建。
- **对齐后端已验证做法**：本域按后端跑通的基类体系落地——极简根系（只放公共方法 / 不放业务字段）、能力域基类只做能力声明、占位三件（`NullObject` / `Stub`）、异步资源统一登记与逆序释放、插件中间层（双轨登记 + 实例缓存 + 契约版本）、提供者走组合轨、错误码段位、逐基类 + contracts + crosscut 测试分层；参考只引文档（《[后端基类清单](../../../../后端基类清单.md)》《[架构设计 · 后端基础类体系](../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》《[后端开发规范](../../../../规范/后端开发规范.md)》）。
- **执行序**：`02_07 工程脚手架` → `02_01 固定三段` → `02_05 体系机制` → `02_02 组件根` → `02_03 能力基类族` → `02_04 组件基类族` → `02_06 基础类横切底座`；`02_07` 的护栏与契约用例工厂随 `02_03` / `02_04` 就位收口。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：146h（01 8h + 02 8h + 03 40h + 04 22h + 05 20h + 06 24h + 07 24h；其中 `02-6` 含嵌套子任务 01 请求封装 8h、02 权限指令 6h、03 格式化工具 6h、04 设计令牌 4h）。
- **关键依赖**：`02_07`（工程与护栏，首务）→ `02_01`（固定三段）→ `02_05`（体系机制）→ `02_02`（组件根）→ `02_03`（能力基类族）→ `02_04`（组件基类族）→ `02_06`（基础类横切底座）；`02_07` 的契约用例工厂与清单对账护栏随 `02_03` / `02_04` 收口补全。
- **风险**：能力基类族 / 组件基类族体量大（合计 62h），易滑期；契约用例工厂与护栏滞后会影响「同接口多实现」保障；基类身份与继承关系须与《前端基类清单》保持一致（登记即对账）；设计令牌与渲染实现主题映射需联调。
