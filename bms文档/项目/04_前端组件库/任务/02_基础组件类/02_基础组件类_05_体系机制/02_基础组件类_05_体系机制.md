## 2. 任务内容 <a id="content"></a>

1. 注册表与工厂（继承插件基类，落 `mechanisms/`；对齐后端已验证口径）：统一提供者注册表基座 `BaseProviderRegistry`——`register` / `get`（**未命中返回 `undefined`**）/ `keys` / `values`（**保序**）、同键唯一性拒重（严格域抛错 / 一般域告警保留首个）、只读快照；注册项公共契约 `BaseProvider`（抽象 `key` + 自描述 `describe`，**走组合轨、不继承插件基类**）；能力注册表 `CapabilityRegistry`；工厂基类 `BaseFactory`（创建入口标识 / 参数校验 / 产出物释放登记）。各扩展点注册表一律基于统一基座扩展，**不得另起映射登记实现**
2. 异步资源与订阅（挂总基类）：`BaseAsyncResource`（释放协议 / 幂等 / **释放后拒绝登记**）与**统一资源登记表**（登记 / **逆序释放** / 单资源失败不阻断）；`BaseSubscription`（主题点分小写、来源解耦、取消函数登记为异步资源、卸载自动取消）
3. 占位三件（挂总基类，对齐后端占位三件）：`BasePlaceholder`（三类原因 `pending` / `null` / `stub` × 三类降级；`placeholder` 标记 + `describe`）→ `BaseNullObject`（空实现、无副作用）、`BaseStub`（未实现统一抛错）；**占位不请求、不写缓存、无副作用**
4. 错误基座 `BaseError extends BaseObject, Error`（**唯一有理由的多重继承**）：`code` / `userMessage`、提示映射（i18n `error.{code}`）、上报委托总基类；**错误码段位**对齐平台（参数 / 未登记 / 冲突 / 限流 / 权限），前端保留自有子段，不自造段位、不复用平台已发布码
5. 契约基类（挂总基类）：模块 API `BaseApi`（路径前缀 / 请求方法 / 自动幂等键）；数据对象 `BaseDataObject`（不可变语义 / 字段声明 / 归一 / 稳定序列化）→ 实体 `BaseEntity`（标识 / 版本 / 软删除回显）、分页查询 `BasePageQuery`（页码 / 页长 / 排序 / 筛选）
6. 单测（对齐后端「逐基类一文件 + contracts + crosscut」口径）：注册唯一性 / 未命中 / 保序 / 释放逆序与幂等 / 占位无副作用 / 错误映射 / 契约序列化；另设**组合轨边界护栏**用例（提供者不误入继承自动登记）

## 3. 完成标准 <a id="accept"></a>

注册表与工厂基座、资源 / 占位 / 错误基座、契约基类就位并被各域复用；口径对齐后端已验证做法（组合轨提供者、注册表基座行为一致、占位三件、资源统一登记逆序释放、错误段位）；各扩展点注册表基于同一基座且行为一致；占位语义成为依赖波组件的统一降级口径；核心用例覆盖注册 / 释放 / 占位 / 错误映射契约；`vue-tsc`、ESLint、Vitest 全通过。
