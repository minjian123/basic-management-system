## 1. 设计目标与范围 <a id="goal"></a>

落地体系公共机制：注册表与工厂、资源 / 占位 / 错误基座、契约基类。对齐后端已验证口径（提供者组合轨不出现在继承自动登记、资源统一登记与逆序释放、占位不请求无副作用、错误段位、错误基座唯一多重继承）。

不在本期：各扩展点具体注册表最小实现（域 10）、组件根（`02_02`）、能力基类 / 组件基类（`02_03` / `02_04`）、请求执行层（`02_06`）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 错误基座（mixin 多重继承） <a id="error"></a>

TS 不支持 `extends A, B`，用 **mixin** 把 `BaseObject` 能力注入 `Error` 子类：

```ts
export function withBaseObject<TBase extends new (...args: any[]) => object>(Base: TBase, namespace?: string)

export class BaseError extends withBaseObject(Error, 'bms:error') {
  constructor(code: number, message: string, options?: { userMessage?: string; cause?: unknown })
  readonly code: number
  readonly userMessage?: string
}
```

- 保留 `instanceof Error` 与堆栈；具备 `namespace` / `log` / `reportError` / `getConfig` / `dispose` / `isDisposed`。
- `code` 取 `ErrorCodes`（前端内建码，`02_07` 已落）。

### 3.2 注册表与工厂 <a id="registry"></a>

```ts
export abstract class BaseProviderRegistry<T> extends BasePluggable {
  register(provider: T): void          // 同键拒重 → BaseError(REGISTRY_CONFLICT)
  get(key: string): T | undefined      // 未命中返回 undefined
  keys(): string[]                     // 保序
  values(): T[]                        // 保序
  snapshot(): ReadonlyMap<string, T>   // 只读快照
  protected abstract providerKey(provider: T): string
}

export class CapabilityRegistry extends BaseProviderRegistry<BaseCapability>  // 缺省实现

export abstract class BaseProvider extends BaseCapability   // 组合轨：不继承插件基类
export abstract class BaseFactory<TOptions, TProduct> extends BasePluggable {
  protected validate(options: TOptions): void   // 缺省空
  abstract create(options: TOptions): TProduct
}
```

### 3.3 资源与订阅 <a id="resource"></a>

```ts
export interface Disposable { dispose(): void }
export abstract class BaseAsyncResource extends BaseObject {
  protected registerDisposable(resource: Disposable): void   // 释放后登记 → BaseError(10001)
  // onDispose 逆序释放已登记资源（幂等、单个失败不阻断）
}
export abstract class BaseSubscription extends BaseAsyncResource {
  protected registerUnsubscribe(fn: () => void): void
}
```

### 3.4 占位三件 <a id="placeholder"></a>

```ts
export type PlaceholderReason = 'pending' | 'null' | 'stub'
export abstract class BasePlaceholder extends BaseObject { readonly placeholder = true; abstract readonly reason }
export abstract class BaseNullObject extends BasePlaceholder  // reason = 'null'，无副作用
export abstract class BaseStub extends BasePlaceholder        // reason = 'stub'，notImplemented() 抛 BaseError(19001)
```

### 3.5 契约基类 <a id="contracts"></a>

```ts
export type HttpMethod = 'GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE'
export abstract class BaseApi extends BaseObject {
  abstract readonly pathPrefix: string
  protected path(sub: string): string
  createIdempotencyKey(): string        // 写方法自动幂等键（宿主可覆写）
}

export abstract class BaseDataObject extends BaseObject { toStableJSON(): string }
export abstract class BaseEntity extends BaseDataObject { abstract readonly id: string; recordVersion?; deletedAt?; isDeleted }
export class BasePageQuery extends BaseDataObject { page = 1; size = 20; orderBy?; order?; offset }
export function stableStringify(value: unknown): string   // 键排序的稳定序列化
```

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 注册表同键重复登记 | 抛 `BaseError(REGISTRY_CONFLICT=10003)` |
| `get` 未命中 | 返回 `undefined`（不替各域兜底） |
| 释放后登记资源 | 抛 `BaseError(CAPABILITY_VIOLATION=10001)` |
| `BaseStub` 调用未实现 | 抛 `BaseError(NOT_IMPLEMENTED=19001)` |
| 资源释放中单个失败 | 继续释放其余，不阻断（错误经 `reportError`） |
| `stableStringify` 遇不可序列化值 | 降级为 `String(value)` |

## 7. 边界与开放项 <a id="open"></a>

- 各扩展点注册表最小实现（路由·菜单 / 组件 / 字段渲染器 / 图标 / 工作台卡片）随域 10。
- `BaseApi` 请求执行、401、错误提示等由宿主请求层（`02_06`）承接；本任务只落契约。
- 占位的三类降级（`empty` / `disabled` / `hidden`）渲染语义随组件域；本期只落标记与原因。
