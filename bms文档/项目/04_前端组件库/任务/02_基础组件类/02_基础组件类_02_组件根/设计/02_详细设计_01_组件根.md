## 1. 设计目标与范围 <a id="goal"></a>

落地组件根 `BaseComponent`（继承插件基类）：所有 UI 组件的公共协议——标识与命名空间类名、尺寸 / 密度、`loading` / `disabled` / 显隐、**令牌属性协议**、attrs 透传（保留键过滤）、运行期字段设置、生命周期通知、机制装配点。约束：**纯数据输出**（不触 DOM、不依赖渲染框架）、组件只消费令牌语义变量。

不在本期：具体组件与渲染插件（域 03+）、能力基类 / 组件基类（`02_03` / `02_04`）、设计令牌文件（`02_06`）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
export type SizeToken = 'small' | 'default' | 'large'
export type DensityToken = 'compact' | 'default' | 'loose'
export type LifecycleEvent = 'mount' | 'update' | 'unmount'
export interface ComponentProps { size?: SizeToken; density?: DensityToken; loading?: boolean; disabled?: boolean; visible?: boolean }
export interface LifecyclePayload extends Required<ComponentProps> { identifier: string; nsClass: string }
export type LifecycleListener = (event: LifecycleEvent, payload: LifecyclePayload) => void

export abstract class BaseComponent extends BasePluggable {
  abstract readonly identifier: string            // 组件标识（kebab-case）
  get pluginKey(): string                          // = identifier
  readonly pluginName: string = 'core'             // 缺省实现名（可覆写）
  size: SizeToken = 'default'
  density: DensityToken = 'default'
  loading = false
  disabled = false
  visible = true
  get nsClass(): string                            // `${namespace}-${identifier}`
  rootAttrs(): Record<string, string>              // data-size / data-density / aria-* / 状态
  stateClasses(): string[]                         // is-loading / is-disabled / is-hidden
  passthroughAttrs(attrs: Record<string, unknown>): Record<string, unknown>
  setProps(props: ComponentProps): void            // 已知字段合并 + 广播 update
  onLifecycle(listener: LifecycleListener): () => void
  notifyLifecycle(event: LifecycleEvent, detail?: Record<string, unknown>): void
  readonly mechanisms: Map<string, unknown>        // 机制装配点
  protected mountMechanism(name: string, mechanism: unknown): void
  protected onDispose(): void                      // 广播 unmount + 清监听与装配点
}
```

- **保留键过滤**：`passthroughAttrs` 过滤 `size` / `density` / `loading` / `disabled` / `visible` 与下划线前缀键；其余（`class` / `style` / `data-*` / `aria-*` 等）照常透传。
- **令牌属性协议**：档位只写根元素属性（`data-size` / `data-density`），状态加状态类；`loading` / `disabled` 同步 `aria-busy` / `aria-disabled`。
- **生命周期**：多监听、返回取消函数；`dispose` 时广播 `unmount` 并清空。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 解决 |
| --- | --- |
| 未设置档位 | 缺省 `default` |
| 监听中移除 / 重复移除 | 取消函数幂等 |
| `notifyLifecycle` 中监听抛错 | 逐个调用，异常经 `reportError` 上报，不阻断其余 |
| `dispose` 后调用 `setProps` | 仍可设置（数据对象），但不保证通知（`isDisposed` 时不再广播） |
| 透传含组件保留键 | 被过滤，不外传 |

## 7. 边界与开放项 <a id="open"></a>

- 组件与渲染框架的绑定（attrs 落到真实根元素、投影）由渲染插件与绑定包承接，核心只产出数据。
- `mount` / `update` 的触发时机由投影 / 组件调用；核心提供 `notifyLifecycle`。
- 设计令牌文件与属性选择器映射随 `02_06`。
