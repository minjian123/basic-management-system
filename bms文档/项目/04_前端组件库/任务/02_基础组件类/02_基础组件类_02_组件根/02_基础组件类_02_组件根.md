## 2. 任务内容 <a id="content"></a>

1. 组件根 `BaseComponent`（继承插件基类，落 `frontend/packages/core/src/base/BaseComponent.ts`）：所有 UI 组件公共协议——标识 `identifier` 与命名空间类名 `nsClass`
2. 尺寸 / 密度、`loading` / `disabled` / 显隐
3. 令牌属性协议 `rootAttrs`：`data-size` / `data-density` / `aria-*` + 状态类（档位只写根元素属性、状态只加状态类）
4. attrs 透传 `passthroughAttrs`（保留键过滤）、运行期字段 `setProps`、生命周期通知 `notifyLifecycle`、机制装配点 `mechanisms`
5. 对齐后端根系已验证口径：**只放所有 UI 组件共有的协议**、子类自带实现优先、纯数据输出（不触 DOM、不依赖渲染框架、不掺 UI 视觉与业务语义）
6. 约束：组件只消费令牌语义变量，不硬编码色值与尺寸；与令牌属性选择器联动（核心产出在本任务，联调随 `02_06`）
7. 单测（对齐后端「逐基类一文件」口径）：组件根契约（属性协议 / 透传保留键 / `loading` / `disabled` 合并 / 生命周期通知）

## 3. 完成标准 <a id="accept"></a>

组件根就位并被能力基类 / 组件基类继承；口径对齐后端根系已验证做法（只放公共协议、子类优先、纯数据输出）；令牌属性协议与 attrs 透传生效；核心用例覆盖组件根契约；`vue-tsc`、ESLint、Vitest 全通过。
