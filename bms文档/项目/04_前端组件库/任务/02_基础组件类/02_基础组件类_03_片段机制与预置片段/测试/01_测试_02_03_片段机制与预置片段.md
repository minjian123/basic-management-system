## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 片段机制校验时机（构造即校验导致 `strict` 在构造抛错、用例 3 处失败） | 改为挂载 / 显式 / 登记三处校验；未挂接告警仅在 `register()` 触发 |
| 2 | 媒体过期重取语义（首次 `onError` 后停在 `loading`） | 明确「首次 error → expired + 重取一次；再次 error → error + 回退」，用例断言两步 |
| 3 | 上传引擎占位返回入参副本（调用方读不到 `placeholder`） | 占位分支返回队列最新项 |
| 4 | 选项源搜索未生效（用例期望过滤但返回全部） | `search` 语义受 `searchable` 控制，用例补 `searchable: true`（文档口径一致） |
| 5 | 受控值 `isEqual(' x ', 'x')` 期望与归一语义不符 | 归一**不**做 trim（避免误改密码类输入）；用例改断言「空串 ≡ `undefined`」与同值相等 |
| 6 | 语言上下文相对时间期望值（i18n stub 前缀）与数字/日期边界 | 按注入 i18n 口径断言 `t:common.justNow`；补时间 / 相对 / 非法日期 / 数字粒度断言 |
| 7 | 纯再导出的 barrel `index.ts` 记 0%，拉低聚合覆盖率 | 双端 `vitest.config.ts` 增 `coverage.exclude`（仅片段层 barrel），覆盖率口径见 §5 |
| 8 | 脚本化补断言静默未生效（变量写错） | 改用独立脚本 + 逐项 `assert count == 1` 校验，并二次 `grep` 复核落盘 |
