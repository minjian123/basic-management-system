## 3. 任务内容 <a id="content"></a>

1. 片段机制与注册表基类（嵌套子任务 01）：`BaseCapability` + `useCapabilityBase`（片段标识 / 依赖声明 / 单向依赖校验 / 开发态告警）；注册表基类 `BaseRegistry` + `BaseRegistryItem`（`key` + `describe`、唯一性 / 未命中 / 查询），供微前端骨架（域 10）与各注册表复用。
2. 预置 31 个能力片段（嵌套子任务 02）：形态 7 / 值·字段链 4 / 选项源 1 / 复用类 19。
3. 组合约束：片段正交可组合（如展示域 = 展示形态 + 受控值）；片段依赖单向并登记；新增能力 = 新增片段，不改根系 / 组件根。
4. 实现以《组件设计》「03 片段机制」「06 注册表基类」与 `02_基础组件类/02_能力片段/` 31 节点及可交互原型为契约依据（原型即验收基准）。
5. **占位先行**：片段对依赖后端能力的行为先以占位语义落地（不请求、空结果 / 降级 / 禁用态）并纳入占位契约测试，真实能力随对应阶段回补。
6. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

## 4. 完成标准 <a id="accept"></a>

片段机制与 31 个预置片段就位；组件可组合多个片段且行为符合各片段设计节点；新增片段流程可验证（不触碰根系 / 组件根）；注册表基类被域 10 复用；Vitest 覆盖片段契约（受控值 / 三态 / 权限脱敏 / 校验触发 / 注册表唯一性与未命中）与占位契约；`vue-tsc`、ESLint、Vitest 全通过；《前端基类清单》「能力片段」节状态回写同步。
