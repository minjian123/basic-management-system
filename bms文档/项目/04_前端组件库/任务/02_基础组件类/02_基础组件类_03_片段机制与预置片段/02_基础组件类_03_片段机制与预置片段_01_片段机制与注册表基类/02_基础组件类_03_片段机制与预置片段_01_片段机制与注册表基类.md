## 2. 任务内容 <a id="content"></a>

1. 片段机制 `BaseCapability` + `useCapabilityBase`：片段标识、依赖声明、**单向依赖校验**、开发态告警；片段必须先声明后使用，未登记片段不可用。
2. 注册表基类 `BaseRegistry` + `BaseRegistryItem`：注册项 `key` + `describe`；唯一性校验、未命中语义、查询与快照；供微前端骨架（域 10 的 `10_02`）与路由·菜单 / 组件 / 字段渲染器 / 图标 / 工作台卡片注册表复用。
3. 组合约束：片段正交可组合；片段依赖方向校验（禁止反向依赖与循环依赖）。
4. 实现以《组件设计》「03 片段机制」「06 注册表基类」节点及可交互原型为契约依据。
5. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

6. **前置契约（已交付）**：[01 根系基类](../../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）的 `BaseFrontend` / `useFrontendBase` 为片段机制的派生基座（日志与错误上报出口复用根系，不重复实现）；[02 组件根基类](../../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（组合式 `usePlaceholderBase` / `useAsyncResourceBase` / `useSubscriptionBase`；经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现

## 3. 完成标准 <a id="accept"></a>

片段机制就位（标识 / 依赖声明 / 单向校验 / 开发态告警），注册表基类唯一性与未命中语义正确；违规片段（未登记 / 反向依赖）在开发态可被拦截；Vitest 覆盖机制与注册表分支；`vue-tsc`、ESLint、Vitest 全通过。
