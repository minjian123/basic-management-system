## 2. 任务内容 <a id="content"></a>

1. 形态 7：`useInteractive`（交互）、`useInputControl`（输入形态）、`useDisplayControl`（展示形态）、`useContainer`（容器）、`useFormContainer`（表单容器）、`useMedia`（媒体）、`useLayout`（布局）。
2. 值·字段链 4：`useValue`（受控值 / 格式化 / 三态）、`useField`（字段编排：壳 + 权限 + 校验）、`useFieldShell`（字段壳）、`useFieldPermission`（字段权限）。
3. 选项源 1：`useOptionSource`（选项加载与缓存，静态选项与远端选项共用口径）。
4. 复用类 19：`useUploadEngine`、`useAsyncTask`、`useTabs`、`usePreference`、`useEditorKernel`、`useTreeData`、`useUserDisplay`、`useDynamicRoutes`、`useFormMeta`、`usePresignedUrl`、`useDragDrop`、`useDesignToken`、`useFormPage`、`useLocale`、`useAccess`、`useColumnConfig`、`useQueryScheme`、`useWatermark`、`useFragmentContext`。
5. **占位先行**：依赖后端能力的行为（字典 / 组织 / 文件 / 权限码 / 服务端校验）先落占位语义 + 占位契约测试，真实能力随对应阶段回补；`useRequest` / `useListPage` 等请求组合式归子任务 06（基础类横切底座），本任务不重复建设。
6. 实现以《组件设计》`02_基础组件类/02_能力片段/` 下 31 个节点及可交互原型为契约依据（原型即验收基准）；用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

31 个预置片段就位（片段机制登记齐备、无未登记片段）；受控值 / 三态 / 权限脱敏 / 校验触发等契约行为符合各设计节点；占位契约测试通过并纳入前端门禁；`vue-tsc`、ESLint、Vitest 全通过；《前端基类清单》「能力片段」节状态回写同步。
