## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `BaseAsyncResource.size` 与组件根尺寸档位 `size` 冲突（`vue-tsc` 报错） | 资源计数改名 `count`；用例与组合式返回值同步（详见实施记录 §4 第 1 项） |
| 2 | 组合式 `setProps` 与 `rootAttrs()` 取值不同源 | 组合式改为读前同步 props（props 优先）；用例 ⑤ 覆盖三档优先级 |
| 3 | Node 运行时定时器句柄（`Timeout` 对象）不被识别 | 归一化补 `ref` / `unref` 分支；用例 ⑮ 覆盖该类句柄 |
| 4 | 组件根释放未联动取消订阅 / 释放资源 | `MechanismLike` 增 `releaseFromComponent()`；用例 ⑧（包装卸载）与 ㉛（订阅）覆盖 |
| 5 | 资源释放函数经 `releaseAll()` 后仍可二次执行 | 幂等标记移入 `ResourceEntry`；用例 ⑮ / ⑰ 覆盖 |
| 6 | `placeholder.ts` 函数覆盖率 68.75% | 扩组合式断言（全量 getter / 方法与 `detach` 路径），升至 96.87% |
| 7 | 用例输出污染：机制未挂接告警与订阅事件名告警走默认 sink | 各用例文件 `beforeEach` 注入收集 sink（`setFrontendSinks`）并断言记录，控制台无噪声 |
