## 2. 任务内容 <a id="content"></a>

1. 组件根 `useComponentBase` + `BaseComponent.vue`：attrs 透传、尺寸与密度、主题令牌、i18n 与命名空间、生命周期埋点、可访问性与 `expose`、`loading` / `disabled` / `visible`。
2. 机制基类（对齐后端基类体系）：
   - 占位 `BasePlaceholder` + `usePlaceholderBase`（占位标记、`describe`、空态 / 禁用态 / 降级语义）
   - 异步资源 `useAsyncResourceBase`（登记 / 逆序释放 / 幂等 / 释放钩子；取消入口 `addAbort`）——「加载 / 成功 / 失败 / 空四态与重试」归异步任务片段（子任务 03）与请求层（子任务 06）
   - 错误 `BaseError`（错误分类、错误边界与上报）
   - 订阅 `useSubscriptionBase`（事件订阅与销毁，与后端事件域对齐）
   - 落地 `src/base/{placeholder,resource,error,subscription}.ts`
3. 占位语义成为依赖波组件（字段 / 展示 / 交互类）的统一降级口径：后端未就绪时不发请求。
4. 实现以《组件设计》「02 组件根基类」「04 占位基类」「05 异步资源基类」「07 错误基类」「08 订阅基类」节点及可交互原型为契约依据。
5. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

6. **前置契约（已交付）**：组件根与机制基类经 [01 根系基类](../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）的 `BaseFrontend` / `useFrontendBase` 派生或组合——日志、错误上报、配置读取、i18n 与生命周期钩子一律复用根系，不重复实现；契约/数据根（`BaseApi` / `createCrudStore` / `request()`）已接根系，可直接取用

## 3. 完成标准 <a id="accept"></a>

组件根与四类机制基类就位并被后续组件 / 片段组合使用；占位语义在依赖波任务中可复用；Vitest 覆盖组件根契约与机制基类分支（含占位态与四态流转）；`vue-tsc`、ESLint、Vitest 全通过；《前端基类清单》状态回写同步。
