## 3. 任务内容 <a id="content"></a>

1. 请求封装（嵌套子任务 01）：`frontend/apps/*/src/api/http.ts` Axios 实例 + `useRequest` + `useListPage`。
2. 权限指令（嵌套子任务 02）：`v-perm` / `hasPerm` / `canAccess`；权限码集合与路由·菜单过滤经权限上下文能力 `useAccess`（子任务 03 产出）。
3. 格式化工具（嵌套子任务 03）：`formatDateTime` / `formatAmount` / `validators`；`stableStringify` 阶段一已交付，复用不重复建设。
4. 复用与衔接：`useRequest` / `useListPage` 复用阶段一既有实现并补契约与单测；请求与响应类型与 openapi-typescript 生成类型保持一致。
5. 实现以《组件设计》「01 请求封装」「02 权限指令」「03 格式化工具」节点及可交互原型为契约依据（原型即验收基准）。
6. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

7. **前置契约（已交付）**：[01 根系基类](../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）提供统一日志与错误上报出口；`BaseApi` 已继承根系、`http.request()` 业务错误与 401 已接上报，本任务在其上补**完整**请求能力（统一错误提示 / token 注入 / 401 静默刷新）与权限指令，不重复建设；[02 组件根基类](../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现；[03 能力机制与预置能力](../02_基础组件类_03_能力机制与预置能力/02_基础组件类_03_能力机制与预置能力.md)（2026-09-16 交付）提供能力机制（`BaseCapability` + `manifest.ts` 登记）、注册表基座（`BaseRegistry` / `RegistryItemLike`）与预置 31 能力（形态 7 / 值·字段链 4 / 选项源 1 / 复用 19；`key` 与 `depends` 见《前端基类清单》『能力』节），本任务直接复用，不重复实现；[04 域基类](../02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)（2026-09-16 交付）提供输入 / 展示 / 树 / 编辑器域能力（`BaseField` + `BaseInputControl` / `BaseValue` + `BaseDisplayControl` / `BaseTreeData` / `BaseEditorKernel`）与字段壳能力（字段上下文语义）——格式化工具（本任务 03 `02_06_03`）接入后收敛展示域名义格式化器分发，本任务不重复实现
