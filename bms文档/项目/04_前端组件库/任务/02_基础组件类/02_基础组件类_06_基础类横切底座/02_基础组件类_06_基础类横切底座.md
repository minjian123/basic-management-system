## 3. 任务内容 <a id="content"></a>

1. 基础类横切底座由四个嵌套子任务承载：请求封装（01）、权限指令（02）、格式化工具（03）、设计令牌（04）；对应《组件设计》基础类 3 节点（请求封装 / 权限指令 / 格式化工具）+ 设计令牌
2. 共性口径：**两宿主同契约**（核心 + 宿主横切底座）；请求层、权限判定与格式化在核心与宿主各就各位，UI 提示 / 路由跳转 / 语言与时区基准经宿主注入；组件只消费设计令牌语义变量（不硬编码色值与尺寸）
3. 与基类体系衔接（对齐后端「能力实现收口于基座、禁止平行实现」）：请求基类继承核心总基类模块 API、业务错误继承核心错误基座；权限码集合与判定**唯一来源**为核心权限能力基类；格式化按用户时区 / locale、`Intl` 为唯一落点、校验规则工厂空值跳过；设计令牌为基础令牌**唯一来源**、组件不得硬编码

## 4. 完成标准 <a id="accept"></a>

见四个嵌套子任务各自「完成标准」；父任务以四子任务全部达标为完成。
