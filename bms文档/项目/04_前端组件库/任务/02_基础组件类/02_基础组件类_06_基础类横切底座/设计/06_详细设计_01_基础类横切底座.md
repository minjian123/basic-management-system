## 1. 设计目标与范围 <a id="goal"></a>

落地基础类横切底座。**当前工作区只有 `core` 包**（`frontend/apps/*`、`vue` 绑定未建），故按「**核心可落部分先落、宿主随后续宿主包回补**」两分：

| 嵌套子任务 | 核心本期交付（`frontend/packages/core`） | 宿主后续回补 |
| --- | --- | --- |
| 01 请求封装 | 请求适配契约 `contracts/request.ts`（`ApiResponse` / `PageResponse` / `RequestAdapter` / `request()` 占位） | Axios 实例、拦截器、401 刷新、提示注入、`useRequest` / `useListPage` |
| 02 权限指令 | 权限判定纯函数 `domain/permission.ts`（`any` / `all` / `not`） | `v-perm` 指令、`hasPerm` / `canAccess`、注入点 |
| 03 格式化工具 | 格式化纯函数 + 校验器 `domain/{format,validators}.ts` | 宿主基准注入（时区 / locale / 约定默认） |
| 04 设计令牌 | 令牌类型（已在 `capabilities/design-token.ts`）+ 令牌解析 `domain/token.ts` | `tokens.scss`（令牌值 + 属性选择器 + 主题映射） |

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 格式化 <a id="format"></a>

```ts
export interface FormatContext { locale?: string; timezone?: string }
formatDateTime(value, ctx?): string
formatDate(value, ctx?): string
formatAmount(value: number, ctx? & { currency?: string; precision?: number }): string
formatNumber(value: number, ctx?): string
formatPercent(value: number, ctx?): string
formatFileSize(bytes: number): string
formatDuration(ms: number): string
formatRelativeTime(value, ctx? & { base?: Date }): string
mask(value: string, options?: { head?: number; tail?: number }): string
```

- 一律走 `Intl`；空值 / 非法值占位 `—`；缺省 locale `zh-CN`、时区 `Asia/Shanghai`。

### 3.2 校验器 <a id="validators"></a>

```ts
type Validator<T> = (value: T | undefined) => string | undefined
required(message?): Validator<unknown>
lengthRange(min, max, message?): Validator<string>
email(message?)/phone(message?)/url(message?)/amount(message?): Validator<string | number>
numberRange(min, max, message?): Validator<number>
codePattern(pattern, message): Validator<string>
```

- 空值跳过（必填独立）；命中返回错误文案。

### 3.3 权限判定 <a id="permission"></a>

```ts
type PermissionMode = 'any' | 'all' | 'not'
evaluatePermission(codes: Iterable<string>, required: readonly string[], mode?): boolean
```

### 3.4 令牌解析 <a id="token"></a>

```ts
resolveToken(tokens: Partial<DesignTokens>, path: string): string | number | undefined   // 'spacing.sm'
```

### 3.5 请求适配契约 <a id="request"></a>

```ts
interface ApiResponse<T> { code: number; message: string; data: T }
interface PageResponse<T> { list: T[]; total: number; page: number; size: number }
interface RequestConfig { method: HttpMethod; url: string; params?; data?; headers?; idempotencyKey? }
interface RequestAdapter { request<T>(config: RequestConfig): Promise<T> }
configureRequestAdapter(adapter): void
request<T>(config): Promise<T>   // 未注入适配器 → 抛 BaseError(19001)（占位不请求）
```

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 格式化传入空值 / 非法值 | 返回占位 `—`，不抛 |
| 未注入请求适配器 | `request()` 抛 `BaseError(NOT_IMPLEMENTED=19001)`（占位不请求） |
| 权限要求为空 | `any` → false；`all` → true；`not` → 无可否定项 → true |
| 令牌路径缺失 | 返回 `undefined` |
