## 2. 任务内容 <a id="content"></a>

1. 宿主令牌文件为基础令牌**唯一来源**（落点见《[前端基类清单](../../../../../../前端基类清单.md)》）：基础令牌五组（色 / 字 / 间距 / 圆角 / 阴影）+ 尺寸 / 密度档位 + 语义变量
2. 令牌属性选择器：`data-size` / `data-density` / 状态类 → 语义变量映射（与组件根属性协议联动）
3. 组件库主题映射（色阶运行时派生）；深色 / 浅色主题以 CSS 变量驱动切换
4. 约束：组件只消费令牌语义变量，**不得硬编码色值与尺寸**（豁免项见《[前端开发规范](../../../../../../规范/前端开发规范.md)》）；新增令牌先登记后使用
5. 口径对齐后端已验证做法：令牌为**基础令牌唯一来源**、组件只消费语义变量、不各组件各写（同后端「能力实现收口于基座、禁止平行实现」）
6. 检查：令牌覆盖与属性选择器映射、硬编码色值护栏可查

## 3. 完成标准 <a id="accept"></a>

设计令牌可被组件与模块复用、属性协议映射生效；硬编码色值被护栏拦截；主题切换生效；`vue-tsc`、ESLint、Vitest 全通过。
