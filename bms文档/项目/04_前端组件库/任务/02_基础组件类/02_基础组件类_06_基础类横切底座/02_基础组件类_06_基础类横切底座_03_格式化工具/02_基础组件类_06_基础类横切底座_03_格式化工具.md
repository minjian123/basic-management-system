## 2. 任务内容 <a id="content"></a>

1. 格式化纯函数（宿主 `src/utils/`）：日期时间（用户时区 + `Intl`）、数值 / 金额（只格式化不运算）/ 百分比 / 文件大小 / 时长 / 相对时间 / 脱敏；空值与非法值占位（默认基准经宿主注入）
2. 用户时区读取与切换（宿主持久化）
3. 通用校验器：必填独立、空值跳过；长度范围 / 邮箱 / 手机 / URL / 金额 / 数值范围 / 编码格式
4. 格式化入口与 `Intl` 实例缓存；名义格式化器注册表沿用核心能力（展示域回补波接入）
5. 口径对齐后端已验证做法：格式化与校验为**统一唯一落点**、空值 / 非法值语义一致、不各页各写（同后端「统一序列化 / 公共方法唯一落点」）
6. 单测：时区 / 金额 / 空值与非法值占位 / 校验器边界

## 3. 完成标准 <a id="accept"></a>

格式化工具在时区 / 金额口径上与后端一致、空值占位统一；校验器可用且必填独立；`vue-tsc`、ESLint、Vitest 全通过。
