## 2. 任务内容 <a id="content"></a>

1. `formatDateTime`：按用户时区与 locale 格式化日期时间（列表 / 详情 / 导出统一口径）。
2. `formatAmount`：金额与千分位格式化（精度、负数、货币符号；与后端展示口径一致）。
3. `validators`：通用校验规则集（必填 / 长度 / 范围 / 正则 / 自定义），供表单与字段类复用。
4. `stableStringify` 阶段一已交付，本任务**复用不重复建设**；`useTabs` 等其它工具随其归口任务落地。
5. 实现以《组件设计》「03 格式化工具」节点及可交互原型为契约依据；用例入 Kiwi TCMS（先登记后编码）；详细设计随任务启动在 `设计/` 下补建。

6. **前置契约（已交付）**：[01 根系基类](../../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）提供 i18n 取词与配置读取出口；`src/utils/serialize.ts` 的 `stableStringify` 与 `src/utils/validators.ts` 由阶段一交付，本任务复用并按需补强，不重复建设；[02 组件根基类](../../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（组合式 `usePlaceholderBase` / `useAsyncResourceBase` / `useSubscriptionBase`；经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现；[03 片段机制与预置片段](../../02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（2026-09-16 交付）提供片段机制（`BaseCapability` + `useCapabilityBase`）、注册表基座（`BaseRegistry` / `BaseRegistryItem` / `useRegistryBase`）与预置 31 片段（形态 7 / 值·字段链 4 / 选项源 1 / 复用 19；`key` 与 `depends` 见《前端基类清单》§5），本任务直接复用，不重复实现

## 3. 完成标准 <a id="accept"></a>

三类工具可用并在时区 / locale / 金额口径上与后端一致（含边界值：空值、负数、超大数、非法输入）；Vitest 覆盖格式化与校验分支；`vue-tsc`、ESLint、Vitest 全通过。
