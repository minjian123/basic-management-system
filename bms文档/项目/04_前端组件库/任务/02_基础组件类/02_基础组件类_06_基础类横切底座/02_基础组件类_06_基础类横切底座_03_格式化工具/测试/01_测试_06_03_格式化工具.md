## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | pattern token 与 `formatToParts` 键不一致导致输出原样 token | `timeParts` 归一为 token 键 |
| 2 | 「昨天」分支误判 | `dateKeyOf` 取 `yyyy/MM/dd` |
| 3 | `en-US` 基准下时长仍中文单位 | 标签按 `formatDefaults.locale` 取语言包 |
| 4 | `email` / `phone` / `url` 规则单测失败 | `regexRule`（`pattern` + `validator` 双消费面） |
| 5 | `useDisplayBase` 名称分发 TS 报错 | 导入重命名消除遮蔽 |
| 6 | `setTimezone` 持久化断言时序 | watch `flush: 'sync'` |
| 7 | Kiwi 710 既有断言/正文与新行为不一致 | 用例更新 + 平台 710 正文修订（台账留痕） |
