## 1. 概述 <a id="overview"></a>

- **目标**：交付**通用格式化纯函数**（`src/utils/format.ts`：日期时间 / 数值 / 金额 / 百分比 / 文件大小 / 时长 / 相对时间 / 脱敏）、**用户时区组合式**（`src/utils/useTimezone.ts`）、**校验器补强**（`src/utils/validators.ts`），并把**名义格式化器注册表**落 **片段层**（`src/components/base/formatters.ts`），收敛 `useDisplayBase` 的名称分发回退；`stableStringify` 复用不重复建设。
- **范围**：需求 [02-6](../../../../需求/02_需求_基础组件类.md#r02-6)、任务 [02-6-3](../02_基础组件类_06_基础类横切底座_03_格式化工具/02_基础组件类_06_基础类横切底座_03_格式化工具.md)。**域 02 收尾任务**。
- **依据**：《组件设计》[03_格式化工具](../../../../../../设计/组件设计/09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（含可交互原型）、《[前端开发规范](../../../../../../规范/前端开发规范.md)》§10（国际化）、`useLocale` 片段（locale / timezone 现状）、布局设计「表单页」系统信息时间格式 `yyyy-MM-dd HH:mm`。
- **边界**：不含 `useTabs` 增强（阶段一已有基础实现，UI/路由联动归布局任务）；不含字段组件（日期 / 金额字段归字段类任务）；不含真实用户偏好接口（`sys_user.timezone` 未接入，按 localStorage / 浏览器时区占位）；金额只格式化不参与运算（后端以字符串 / 定点传输）。

## 4. 契约设计 <a id="contract"></a>

### 4.1 格式化纯函数（`utils/format.ts`） <a id="format"></a>

```ts
export interface FormatDefaults { locale: string; timezone: string }
export function configureFormatDefaults(patch: Partial<FormatDefaults>): void   // 注入（入口 / useTimezone）
export function getFormatDefaults(): FormatDefaults                             // 缺省：i18n locale + 浏览器时区（非浏览器 UTC）

export interface FormatOptions { locale?: string; timezone?: string; placeholder?: string }
export function formatDateTime(value: unknown, opts?: FormatOptions & { pattern?: string; seconds?: boolean }): string
export function formatDate(value: unknown, opts?: FormatOptions & { pattern?: string }): string
export function formatDateRange(value: [unknown, unknown] | null, opts?: FormatOptions): string
export function formatRelativeTime(value: unknown, opts?: FormatOptions & { now?: Date }): string
export function formatNumber(value: unknown, opts?: FormatOptions & { precision?: number; grouping?: boolean }): string
export function formatAmount(value: unknown, opts?: FormatOptions & { precision?: number; currency?: string; symbol?: boolean }): string
export function formatPercent(value: unknown, opts?: FormatOptions & { precision?: number; ratio?: boolean }): string
export function formatFileSize(bytes: unknown, opts?: FormatOptions & { precision?: number }): string
export function formatDuration(seconds: unknown, opts?: FormatOptions): string
export function maskValue(value: unknown, type?: 'phone' | 'email' | 'idcard' | 'generic'): string
```

| 行为 | 口径 |
| --- | --- |
| 引擎 | 一律 `Intl`（`DateTimeFormat` / `NumberFormat` / `RelativeTimeFormat`）；按 `{locale, timezone, pattern/options}` 缓存实例复用 |
| 空值 / 非法 | 返回 `placeholder`（缺省 `—`），不出现 `Invalid Date` / `NaN` |
| 默认时间格式 | `yyyy-MM-dd HH:mm`（含秒 `yyyy-MM-dd HH:mm:ss`；token 由 `formatToParts` 组装） |
| 相对时间 | < 60s → `common.justNow`；< 60min → n 分钟前；< 24h → n 小时前；昨天 → `common.yesterday HH:mm`；更早 → 默认日期格式 |
| 金额 | 仅格式化不运算：接受 `string \| number`（字符串经校验后 `Number` 转换，超范围回落占位）；精度缺省 2；`currency`（ISO）走 `Intl` 货币样式，否则 `symbol !== false` 时加 `¥` 前缀 |
| 百分比 | `ratio: true` 视为比值（`Intl` percent 样式）；否则按已乘 100 数值 + `%` 后缀 |
| 脱敏 | `phone` → `138****5678`；`email` → `z***@x.com`；`idcard` → 保留首尾各 1~2 位；`generic` → 保留首尾；短文本全掩 |
| `localStorage` | 不使用（纯函数）；时区持久化由 `useTimezone` 负责 |

### 4.2 用户时区（`utils/useTimezone.ts`） <a id="timezone"></a>

```ts
export const TIMEZONE_STORAGE_KEY = 'bms_timezone'
export interface UseTimezoneReturn {
  readonly timezone: string
  setTimezone(next: string): void
  readonly isPlaceholder: boolean   // 未接入用户偏好接口（当前恒 true → 占位）
}
export function useTimezone(options?: { timezone?: MaybeRefOrGetter<string>; persist?: boolean }): UseTimezoneReturn
```

- 取值优先级：显式入参 > localStorage（`persist !== false`）> 浏览器时区（非浏览器 UTC）。
- 变更时同步 `configureFormatDefaults({ timezone })`（格式化纯函数随之取新基准；页面经响应式引用自动更新）。
- **占位**：`sys_user.timezone` 接口未接入——登录装配后经入参 / `setTimezone` 注入即接（登记遗留）。

### 4.3 名义格式化器注册表（`components/base/formatters.ts`，片段层） <a id="registry"></a>

```ts
export type ValueFormatter = (value: unknown, options?: { locale?: string; timezone?: string }) => string
export function registerFormatter(name: string, formatter: ValueFormatter): void
export function resolveFormatter(name: string): ValueFormatter | undefined
export function resetFormatters(): void     // 测试
```

- **内置**（模块加载即注册）：`amount` / `number` / `percent` / `date` / `datetime` / `boolean`（`common.yes` / `common.no`）。
- **扩展**：业务 / 消费方经 `registerFormatter` 注册（如枚举文本由选项源协作后续接入）；重复注册覆盖并开发态告警（沿用根系日志）。
- **落点理由**：注册表服务于**片段 / 域基类**的展示分发（`useDisplayBase`），与片段层同层；纯函数本体仍归 `utils/format.ts`。
- `useDisplayBase` 接入：`formatter` 为名称时先查注册表 → 命中即调度；未注册回退 `String(value)`（原有占位口径不变）。

### 4.4 校验器补强（`utils/validators.ts`） <a id="validators"></a>

- 保留既有 predicates（`isPhone` / `isEmail` / `isIdCard` / `isUrl` / `passwordStrength`）与 `required` / `pattern`。
- 补节点规则（返回 `FieldRule`；`FieldRule` 增可选 `validator`，兼容 Element Plus / Vant）：

| 规则 | 说明 |
| --- | --- |
| `lengthRange(min, max, msg?)` | 长度区间（空值跳过，必填由 `required` 负责） |
| `email(msg?)` / `phone(msg?)` / `url(msg?)` | 基于既有 predicates 的规则工厂 |
| `amount({ min?, max?, precision? }, msg?)` | 金额精度（小数位 ≤ precision）与区间 |
| `numberRange(min, max, msg?)` | 数值区间（含边界；非数值报错） |
| `codePattern(regex, msg?)` | 编码规则（点分小写 / 岗位编码等） |

### 4.5 i18n 与入口 <a id="i18n"></a>

- 语言包补最小集（中英）：`common.justNow` / `common.yesterday` / `common.yes` / `common.no` / `common.hour` / `common.minute` / `common.second`。
- 入口（`main.ts`）可调用 `configureFormatDefaults` 注入初始 locale / 时区（缺省自动）；用户切换经 `useTimezone` 同步。
