## 2. 任务内容 <a id="content"></a>

1. 统一请求实例（宿主 `src/api/`，两宿主同契约）：token 注入（仅存内存）、401 静默刷新、统一响应 `{code, message, data}` 解析与错误提示
2. 模块 API 继承契约层模块 API 基类 `BaseApi`（`02_05`），禁止绕过基类裸用请求库；写接口自动生成幂等键
3. 业务错误码在请求层判定并抛业务错误（继承核心错误基座 `BaseError`），文案走 i18n `error.{code}`
4. 提示 / 登录与 403 跳转 / 刷新处理器经宿主入口注入；未注入刷新处理器时 401 按会话失效占位（清会话 + 跳登录、不发起请求）
5. 请求组合式（loading / 错误 / 重试 / 取消）与分页列表组合式（分页 / 筛选 / 刷新 / 重置）
6. 口径对齐后端已验证做法：模块 API 一律继承基类、不裸用请求库、统一响应为唯一出口、写接口幂等键（同后端「请求响应契约 / 统一响应 / 分页契约」口径）
7. 单测：请求拦截与 401 分支、幂等键、统一响应解析、分页列表组合式状态机

## 3. 完成标准 <a id="accept"></a>

请求实例与组合式可用并被列表页类需求复用；401 未注入处理器时占位正确；统一响应解析与错误映射生效；`vue-tsc`、ESLint、Vitest 全通过。
