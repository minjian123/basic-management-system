## 2. 任务内容 <a id="content"></a>

1. `src/api/http.ts`：Axios 实例——token 注入、401 静默刷新、统一响应 `{code, message, data}` 解析与错误提示、请求取消。
2. `useRequest`：loading / 错误 / 重试 / 取消（**复用阶段一既有实现**，本任务补契约、边界与单测）。
3. `useListPage`：分页 / 筛选 / 排序 / 导出的列表页组合式（复用阶段一实现并补齐与后端契约的对接）。
4. 类型衔接：`ApiResponse<T>` / `PageResponse<T>` 与 openapi-typescript 生成的类型保持一致；错误码文案按 i18n key 映射。
5. 实现以《组件设计》「01 请求封装」节点及可交互原型为契约依据；用例入 Kiwi TCMS（先登记后编码）；详细设计随任务启动在 `设计/` 下补建。

6. **前置契约（已交付）**：[01 根系基类](../../02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)（2026-09-16 交付）已提供 `reportError` 出口；`src/api/http.ts` 已接根系上报（业务错误 + 401 分支）且 `BaseApi extends BaseFrontend`——本任务在其上补 token 注入、401 静默刷新与统一提示的**完整能力**；[02 组件根基类](../../02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）与四机制基类 `BasePlaceholder` / `BaseAsyncResource` / `BaseError` / `BaseSubscription`（组合式 `usePlaceholderBase` / `useAsyncResourceBase` / `useSubscriptionBase`；经组件根 `mechanisms` 装配点挂接）亦已交付，本任务直接复用其令牌属性协议、占位降级语义与资源释放联动，不重复实现；[03 片段机制与预置片段](../../02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（2026-09-16 交付）提供片段机制（`BaseCapability` + `useCapabilityBase`）、注册表基座（`BaseRegistry` / `BaseRegistryItem` / `useRegistryBase`）与预置 31 片段（形态 7 / 值·字段链 4 / 选项源 1 / 复用 19；`key` 与 `depends` 见《前端基类清单》§5），本任务直接复用，不重复实现
