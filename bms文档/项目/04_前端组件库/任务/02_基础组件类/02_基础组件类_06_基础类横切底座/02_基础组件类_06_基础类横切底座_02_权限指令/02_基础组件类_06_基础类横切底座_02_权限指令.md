## 2. 任务内容 <a id="content"></a>

1. 权限指令 `v-perm`（宿主 `src/directives/`）：默认任一满足、支持全部满足 / 取反；无权限移除 DOM（锚点注释，权限恢复原位回插）、权限版本监听重评
2. 脚本判定与 `canAccess`（宿主 `src/utils/`）：脚本场景经宿主权限工具 → 插件注入点判定
3. 权限码集合与判定**唯一来源为核心权限上下文能力基类 `BaseAccess`**（`02_03`）；应用态 store 只做集合 / 菜单 / 版本 / 加载编排，不另建判定
4. 字段权限不在本项（属字段权限能力 / 组件基类）；路由守卫注册与 403 页随后续任务
5. 口径对齐后端已验证做法：判定**唯一来源为核心能力**、应用态只做集合 / 编排、不另建判定（同后端「能力实现收口于基座、禁止平行实现」）
6. 单测：指令三种模式与 DOM 移除 / 回插、脚本判定、注入点未配置时的占位行为

## 3. 完成标准 <a id="accept"></a>

`v-perm` 与脚本判定经注入点显隐生效、权限恢复可回插；判定唯一来源为核心权限能力；`vue-tsc`、ESLint、Vitest 全通过。
