## 2. 任务内容 <a id="content"></a>

1. `v-perm="'业务:动作'"` 指令：按权限码控制按钮 / 动作渲染（无权限不渲染，非仅置灰）。
2. `hasPerm` / `canAccess`：脚本式权限判断（表格列、工具栏等非指令场景）。
3. 权限码集合与路由·菜单过滤统一经权限上下文片段 `useAccess`（子任务 03 产出），不在本任务另建权限存储；**字段权限不在本项**（属字段权限片段）。
4. 实现以《组件设计》「02 权限指令」节点及可交互原型为契约依据；用例入 Kiwi TCMS（先登记后编码）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

`v-perm` 与 `hasPerm` / `canAccess` 显隐生效、权限码来源唯一（`useAccess`）；无权限码 / 空权限集时行为明确（不渲染）；Vitest 覆盖指令与判定分支；`vue-tsc`、ESLint、Vitest 全通过。
