## 1. 概述 <a id="overview"></a>

- **目标**：落地**动作（按钮）权限**契约（双端同款核心 + 双端指令）——`v-perm` 指令（`业务:动作` 显隐、无权限移除 DOM、`[]` anyOf / `.all` / `.not`）、`hasPerm` / `canAccess` 脚本判断、`usePermissionStore`（应用态汇聚，**权限码集合与判定唯一来自 `useAccess` 片段**）、可选 `PermButton` 组件；权限变更经版本号触发指令重评。
- **范围**：需求 [02-6](../../../../../需求/02_需求_基础组件类.md#r02-6)、任务 [02-6-2](../../02_基础组件类_06_基础类横切底座_02_权限指令/02_基础组件类_06_基础类横切底座_02_权限指令.md)；**不含**字段权限（属字段权限片段）、路由守卫注册（脚本判断先行，守卫随登录页 / 菜单任务）。
- **依据**：《组件设计》[02_权限指令](../../../../../../../设计/组件设计/09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（含可交互原型）、《[前端开发规范](../../../../../../../规范/前端开发规范.md)》§7、`useAccess` 片段（`src/components/base/access/useAccess.ts`）。
- **边界**：菜单接口未就绪——权限集合按占位空集运行（无 loader 不请求）；`usePermissionStore` 只做应用态汇聚与加载编排，判定实现复用 `useAccess`；移动端同样交付核心与指令（与 PC 同款），菜单 / 守卫随后续任务。

## 4. 契约设计 <a id="contract"></a>

### 4.1 `usePermissionStore`（`stores/permission.ts`） <a id="store"></a>

```ts
export interface PermissionBridge {
  codes: string[]
  version?: string | number
  menus?: AccessFilterableNode[]
}
export type PermissionLoader = () => Promise<PermissionBridge>

export const usePermissionStore = defineStore('permission', () => {
  // 状态：codes / version / menus / loaded / loading / loader（可注入）
  // 能力（唯一来自 useAccess 片段）：has / hasAny / hasAll / filterRoutes
  // 编排：configureLoader(loader) / load() / reset() / setCodes(codes, version?)
  // 派生：permissions（Set）/ permVersion（版本，供指令重评）/ isPlaceholder
})
```

| 行为 | 口径 |
| --- | --- |
| 唯一来源 | 权限码集合 / 判定 / 过滤**全部经 `useAccess` 片段**（store 把它作为唯一能力载体，`codes` / `version` 以响应式入参传入）；store 只做应用态汇聚与加载编排 |
| 占位 | 未注入 loader 时 `isPlaceholder = true`，`load()` 不请求、保持空集（无权限降级） |
| 加载 | `load()`：loader 返回 `{codes, version?, menus?}` → 写集合 / 版本 / 菜单树，`loaded = true`；失败经根系上报后原样抛 |
| 重置 | `reset()`：清集合 / 菜单 / 版本归 0（登出 / 会话失效调用） |
| 版本 | `permVersion` 随集合更新递增（指令重评依据）；`setCodes` 供登录装配与测试 |

### 4.2 `v-perm` 指令（`directives/perm.ts`） <a id="vperm"></a>

| 项 | 口径 |
| --- | --- |
| 写法 | `v-perm="'user:create'"`；`v-perm="['a', 'b']"`（默认 anyOf）；`v-perm.all="['a','b']"`；`v-perm.not="'x'"` |
| 语义 | 有权限保留元素；无权限**移除 DOM**（非 `display:none`）；`.not` 取反 |
| 可恢复 | 移除时插入注释锚点；权限恢复（版本变化后重评）按锚点原位回插 |
| 重评 | `mounted` / `updated` 求值；`mounted` 建 `effectScope` 监听 `store.permVersion`（`flush: 'post'`），`unmounted` 停止并清理锚点 |
| 空值 | 未传码 / 空数组视为不限制（保留元素） |
| 注册 | `main.ts`：`app.directive('perm', vPerm)`（双端） |

### 4.3 `hasPerm` / `canAccess`（`utils/perm.ts`） <a id="hasperm"></a>

```ts
export function hasPerm(code: string | string[], mode: 'any' | 'all' = 'any'): boolean
export function canAccess(target: string | string[] | { permission?: string | string[]; public?: boolean } | null | undefined): boolean
```

- `hasPerm`：读 store（判定经 `useAccess`）；`mode` 缺省 anyOf。
- `canAccess`：字符串 / 数组等价 `hasPerm`；对象取 `permission`（`public` 或缺省视为公开）；`null` / `undefined` 视为允许（公开路由 / 无权限要求节点）。
- **不含路由守卫注册**（`router.beforeEach` + 登录态 + `meta.perm` 跳 403）——随登录页 / 菜单任务（遗留）。

### 4.4 `PermButton.vue`（`components/common/`） <a id="permbutton"></a>

```vue
<PermButton perm="user:create" fallback="disable" tip="仅管理员可操作" @click="...">新增</PermButton>
```

- props：`perm`（string / string[]）、`mode`（`any` / `all`）、`fallback`（`hide` 默认 / `disable`）、`disabled`（外部禁用）、`tip`（禁用提示，缺省 `common.noPermission`）。
- `fallback='hide'`：无权限不渲染；`'disable'`：渲染禁用按钮 + `title` 提示；点击在禁用态被拦截（不 emit `click`）。
- **框架无关**（原生 `<button>` + 插槽 + attrs 透传），双端同款；具体皮肤由消费方 / 后续组件任务包装（登记遗留）。

### 4.5 i18n 与入口 <a id="i18n"></a>

- `common.noPermission`（无权限）/ `common.forbidden`（403）中英文案。
- 入口注册指令（双端 `main.ts`）；菜单接口接入时经 `configureLoader` 注入（登录装配随认证阶段）。

## 5. 双端同款 <a id="dup"></a>

- 核心（`stores/permission.ts` / `utils/perm.ts`）与指令（`directives/perm.ts`）、`PermButton.vue`、用例**双端逐字一致**；`main.ts` 指令注册双端同款。
- 校验：`diff` 为空；双端门禁（prettier / eslint / `vue-tsc` / Vitest + 覆盖率 / build + budget）。

## 10. 边界与开放项 <a id="boundary"></a>

- **不含**字段权限（`useFieldPerm` / `v-plain`，属字段权限片段）。
- **不含**路由守卫注册与 403 页面（脚本 `canAccess` 先行；守卫随登录页 / 菜单任务）。
- **不含**菜单接口真实接入（占位空集；经 `configureLoader` 注入即可接）。
- **不含**按钮视觉皮肤（`PermButton` 为框架无关最小版；Element Plus 按钮包装随组件任务）。
- **移动端**指令同款交付（节点 §9 原「移动端不用 PC 指令」按本轮拍板调整——同款实现，消费时按需使用）。
