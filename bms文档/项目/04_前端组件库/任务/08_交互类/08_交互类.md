## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段四需求域 08 的 10 条需求——[08-1 占位版交付](../../需求/08_需求_交互类.md#r08-1)、[08-2 图标选择器与代码表达式编辑器](../../需求/08_需求_交互类.md#r08-2)、[08-3 面板与工具](../../需求/08_需求_交互类.md#r08-3)、[08-4 权限配置](../../需求/08_需求_交互类.md#r08-4)、[08-5 导入导出](../../需求/08_需求_交互类.md#r08-5)、[08-6 表单设计器与表单渲染器](../../需求/08_需求_交互类.md#r08-6)、[08-7 国际化文案编辑器](../../需求/08_需求_交互类.md#r08-7)、[08-8 审批流展示与流程建模器](../../需求/08_需求_交互类.md#r08-8)、[08-9 报表设计器与大屏设计器与播放](../../需求/08_需求_交互类.md#r08-9)、[08-10 AI 助手](../../需求/08_需求_交互类.md#r08-10)，按「1 需求 = 1 子任务」拆 10 个子任务（`08_01` / `08_03` / `08_04` / `08_05` / `08_06` / `08_07` / `08_08` / `08_09` 含嵌套子任务）。
- **端范围**：**仅 PC**（`frontend/packages/ui-ep`，Element Plus）；移动端 `ui-vant` 不在本次范围。
- **占位口径**：依赖后端的交互件（导入导出 / 表单设计器 / 表单渲染器 / 权限配置 / 审批流展示 / 流程建模器 / 报表设计器 / 大屏设计器与播放 / AI 助手 / 国际化文案编辑器）由 `08_01` 先交付**占位版**（骨架 + 空态 / 禁用态 / 降级语义 + 分包入口 + 占位契约测试），**契约先行冻结**；`08_04` ~ `08_10` 落地真实实现时**只换数据通路、不改对外契约**（变更走版本升级）。
- **公共前置**：统一提供者注册表基座 `BaseProviderRegistry` / 注册项契约 `BaseProvider`（`02_05`）；能力基类 `BaseEditorKernel` / `BaseDragDrop` / `BaseOptionSource` / `BasePersistedState` / `BaseDesignToken` / `BaseLocale` / `BaseAccess` / `BaseTreeData` / `BaseAsyncTask` / `BaseUploadEngine` / `BaseFormMeta` / `BaseSelection` / `BaseBulkAction` / `BaseTheme` / `BaseTenant` / `BaseFormDesigner` 与组件基类 `BaseChart`（`07_06`）、空状态件（`03_02`）均已就位，本节不重复维护。
- **依据**：[交互类需求](../../需求/08_需求_交互类.md)、《[组件设计 · 总览](../../../../设计/组件设计/01_组件设计_总览.md)》与交互类 18 节点、《[前端基类清单](../../../../前端基类清单.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》「渲染器与扩展点注册机制」节、《[前端开发规范](../../../../规范/前端开发规范.md)》「前端基类体系（强制）」节。
- **执行序**：`08_01 占位版交付` → `08_02 图标选择器与代码表达式编辑器` → `08_03 面板与工具` → `08_04` ~ `08_10`（依赖就绪后推进，见[计划](../../计划/01_计划_前端组件库.md)）。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：252h（01 20h + 02 20h + 03 36h + 04 20h + 05 20h + 06 36h + 07 16h + 08 28h + 09 32h + 10 24h）。
- **关键依赖**：`08_01` 依赖 `02_05`（注册表基座 / 注册项契约）、`03_02`（空态）、`08_02`（编辑器内核 / 图标注册表）；`08_02` 依赖 `02_03`（编辑器内核能力基类）、`02_05`；`08_03` 依赖 `02_03`（持久化 / 令牌 / 拖拽 / 语言能力基类）；`08_04` ~ `08_10` 均依赖 `08_01`（对外契约冻结），真实数据通路分别依赖对应后端能力。
