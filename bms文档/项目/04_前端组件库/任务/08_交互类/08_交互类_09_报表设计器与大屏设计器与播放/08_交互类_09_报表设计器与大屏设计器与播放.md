## 3. 任务内容 <a id="content"></a>

1. 数据集选择、图表配置、网格与自由画布布局、多页轮播播放均需重交互与 ECharts 生态，独立分包并与报表 / 数据集后端契约对齐。
2. 图表渲染复用图表卡 `07_06` 与图表组件基类 `BaseChart`，不重复实现取色与渲染。
3. 两者均**独立分包**，首屏不加载。
4. 以 `08_01` 冻结的对外契约替换数据通路，不改对外形状与分包入口。

## 4. 完成标准 <a id="accept"></a>

设计器可配置并保存发布、数据预览正确、播放器多页轮播与自适应正常、分包生效；Vitest 覆盖配置序列化与播放切换分支；`vue-tsc`、ESLint、Vitest 全通过。
