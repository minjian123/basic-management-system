## 3. 任务内容 <a id="content"></a>

1. **导入**：模板下载、文件校验与上传进度、幂等键、错误行报告与明细下载；上传细节经上传引擎能力基类 `BaseUploadEngine`（与文件上传字段 `06_07` 共用）。
2. **导出**：支持当前筛选条件导出与字段脱敏；大数据量走异步导出，任务提交 / 轮询进度 / 取消 / 结果下载统一经异步任务能力基类 `BaseAsyncTask`。
3. **编排入链**：新增能力基类 `BaseImportFlow`（导入流，组合上传引擎）、`BaseExportFlow`（导出流，组合异步任务）与 `BaseFileDownload`（下载触发，组合预签名），横切语义落继承链、不在件内重复实现。
4. **数据通路注入式**：模板下载 / 执行导入 / 错误明细 / 列表导出 / 异步任务的处理函数由宿主注入，未注入即占位（不发请求、按钮禁用 + 提示）；真实接口联调归口阶段八（通用能力 · 文件存储 / 导入导出）。
5. 以 `08_01` 冻结的对外契约替换数据通路，不改组件对外形状（新增可选 Props / 事件均为向后兼容扩展）。

## 4. 完成标准 <a id="accept"></a>

导入幂等与错误报告正确、导出筛选与脱敏生效、异步任务进度与取消可用；Vitest 覆盖幂等与错误行解析分支；`vue-tsc`、ESLint、Vitest 全通过。
