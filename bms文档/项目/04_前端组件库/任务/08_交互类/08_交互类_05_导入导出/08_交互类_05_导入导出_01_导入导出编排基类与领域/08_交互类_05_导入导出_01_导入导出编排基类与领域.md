## 2. 任务内容 <a id="content"></a>

1. **领域纯函数**：`domain/import.ts`（文件类型与大小校验、空文件判定、内容派生幂等键、错误行归一与分页、错误码 → i18n 键、汇总计数）与 `domain/export.ts`（取数参数构造与排序归一、导出范围与选中校验、脱敏与明文判定、异步阈值判定、文件名生成、无数据判定）。
2. **能力基类三条**：新增 `BaseFileDownload`（下载触发：取址 / 失效重取 / 降级重试，组合预签名能力）、`BaseImportFlow`（导入编排：模板下载、文件校验、幂等键、上传与解析阶段、错误行报告、错误明细下载、重试与重置、占位语义）、`BaseExportFlow`（导出编排：取数参数、导出范围、脱敏与明文、同步下载与超阈值异步导出（经异步任务）、进度与取消、失败重试、占位语义）。
3. **既有基类向后兼容扩展**：`BaseUploadEngine` 支持可量化进度回传与取消中断；`BaseAsyncTask` 支持 poller 两段（提交 → 轮询 → 结果），未注入 poller 时既有 executor 路径逐字不变。
4. **能力依赖登记与契约套件**：登记三条能力依赖（`file-download` / `import-flow` / `export-flow`）；落两套跨端复用契约套件（导入流 / 导出流）与核心用例。

## 3. 完成标准 <a id="accept"></a>

文件校验、内容派生幂等键（同内容同键、内容变更换键）、错误行归一与分页、取数参数构造与脱敏判定、异步阈值判定正确；未注入数据通路时不发请求（占位语义保持）；上传进度与取消、异步任务轮询两段可用且既有 executor 路径不回归；Vitest 覆盖幂等与错误行解析分支；`vue-tsc`、ESLint、Vitest 全通过。
