## 2. 过程 <a id="process"></a>

```mermaid
flowchart LR
    A["Kiwi 用例登记（769）"] --> B["共享工具：fnv1aHex（serialize）+ formatCompactTimestamp（format）"]
    B --> C["领域纯函数：domain/import（校验 / 幂等键 / 错误行 / 文件名）+ domain/export（取数参数 / 决策 / 阈值 / 文件名）"]
    C --> D["既有基类扩展：BaseUploadEngine（进度回传 / 取消中断）+ BaseAsyncTask（poller 两段）"]
    D --> E["新增能力基类：BaseFileDownload → BaseImportFlow / BaseExportFlow"]
    E --> F["登记与导出：manifest 三键 + 核心导出面 + 《前端基类清单》编号顺延与三行新增"]
    F --> G["契约套件两套：describeImportFlowContract / describeExportFlowContract"]
    G --> H["用例 5 文件 60 条 + 既有批三补 5 条"]
    H --> I["门禁验证（typecheck / lint / 362 用例 / 护栏）"]
```

1. **Kiwi 先行**：按《测试规范》先用 Django shell 批量登记（平台骨架 / P2 / CONFIRMED / 标签「自动化」），取得 **769 / 770** 两个编号后写自动化代码，用例文件首行标注 `// kiwi_id: 769`。
2. **共享工具提取**：`fnv1aHex` 由 `domain/permission-config.ts` 的私有实现**原样上提**至 `domain/serialize.ts`（`permission-config` 改为引用，同内容同键、输出逐字不变）；`formatCompactTimestamp`（本地时区 `yyyyMMddHHmmss`）落 `domain/format.ts` 与既有格式化纯函数同族。
3. **领域纯函数**：`domain/import.ts` 落文件校验（类型 → 大小 → 空文件顺序短路）、内容派生幂等键（`imp:{biz}:{FNV-1a}`）、结果归一（后端省略字段补零 / 空数组）、汇总态、文件级错误判定、错误码 → i18n 键、错误行分页与展示上限截断、模板与错误明细文件名；`domain/export.ts` 落取数参数归一（剔空、键名不改写）、选中集合字符串化去重排序、同步 / 异步阈值判定、明文权限判定、导出决策（未就绪 / 禁用 / 无权 / 未选中 / 无数据）、文件名与错误文案。
4. **既有基类向后兼容扩展**：`BaseUploadEngine` 的 `Uploader` 增可选进度回传参数、`cancel()` 增 `abort` 中断钩子并置取消态（失败保留进度、取消不视为失败）；`BaseAsyncTask` 新增可选 `submitter` + `poller`（**同时注入**才走两段轮询，否则 `executor` 单段路径逐字不变）、`cancel()` 增 `abort` 钩子与轮询退出判定。
5. **新增能力基类三条**：`BaseFileDownload`（取址顺序：直连 URL → 宿主取址 → 预签名回退；占位不动作；阶段与重试）、`BaseImportFlow`（组合上传引擎承载进度与取消；幂等键内容派生、提交阶段 `uploading → parsing → done`、错误行报告、模板与错误明细下载三通路）、`BaseExportFlow`（组合异步任务与下载触发；决策分支、同步下载与超阈值两段轮询、进度与取消、失败重试）。
6. **登记与导出**：`capabilities/manifest.ts` 新增 `file-download` / `import-flow` / `export-flow` 三键；`core/src/index.ts` 追加基类、领域函数与类型导出；《前端基类清单》§2 继承链总览、§2.1 全量表（新增 44 / 45 / 46，原 44 ~ 69 顺延至 47 ~ 72）、§5.2 能力基类表同步，既有两项基类职责文本补「进度回传 / 取消中断」与「两段轮询」。
7. **契约套件两套**：`describeImportFlowContract` 覆盖占位零请求、文件校验、幂等键派生、阶段与结果、分页截断、失败与重试、进行中防重、取消、下载三通路共 10 组断言；`describeExportFlowContract` 覆盖占位零请求、决策分支、载荷归一与明文收窄、同步下载触发、超阈值两段轮询、轮询缺失回落、失败重试、防重、取消共 10 组断言。
8. **用例**：新增 5 个用例文件（60 条）并在 `capabilities-batch3.spec.ts` 补 5 条既有基类扩展断言（进度夹取与失败保留、取消中断、单段路径回归、poller 两段成功与取消与失败）。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 异步导出契约断言失败：`progress` 停在 `{ value: 1, total: 2 }`（轮询进度只写在任务对象上，未同步到导出流） | `BaseExportFlow` 的 `poller` 适配器补「outcome.progress → `this.progress` 并广播」（回写详细设计 §3.8「异步通路」行） |
| 2 | 取消后仍结算：执行 / 导出在途返回时未判中断，`cancel()` 后仍置 `done` 并展示结果 | `submit()` 与 `export()` 的成功与失败路径均补 `signal.aborted` 判定，取消时阶段复位 `idle`、进度复位、不写结果（回写详细设计 §3.7 / §3.8 的取消口径） |
| 3 | JSDoc 护栏（`guard-jsdoc`）按**行**判定成员，跨行方法签名被误判为缺注释成员 | `BaseAsyncTask.runPolled` 收敛为单行签名（引入模块内类型别名 `AnyTaskPoller`）；`BaseImportFlow.runDownload` 改为单参对象签名（新增 `ImportDownloadInput`） |
| 4 | 核心 `lib: ["ES2022"]` **无 DOM**：`AbortSignal` / `Blob` 不可用 | 中断信号用最小结构 `ImportAbortSignal`（`{ readonly aborted: boolean }`，与浏览器 `AbortSignal` 结构兼容）；下载载荷用 `DownloadSource.blob: unknown`（由件层解释），核心不引 DOM 类型 |
| 5 | 文件名时间戳原设计落 `domain/export.ts`，被 `domain/import.ts` 引用会造成跨域依赖 | 改落 `domain/format.ts`（与既有格式化纯函数同族），**先回写详细设计**（交付物 9 / §3.1 / §3.2 / 决策 9）再实施 |
| 6 | 「文件级错误」判定口径：行级校验失败按设计随结果对象返回，不抛错，故错误码段（5xxxx）无法区分行级与文件级 | `isFileLevelError` 保持错误码段判定并在 JSDoc 写明语义（抛出即文件 / 网络级）；整体拒绝在基类按「失败路径 + 不展示错误行表」落实 |
| 7 | `permission-config` 的 FNV-1a 为私有实现，导入幂等键需要同一算法 | 原样上提 `domain/serialize.ts` 的 `fnv1aHex`，`permission-config` 改引用；既有授权幂等键字符串逐字不变（`domain-permission-config.spec.ts` 未改动即通过） |
