## 2. 任务内容 <a id="content"></a>

1. **投影**：`useBaseFileDownload` / `useBaseImportFlow` / `useBaseExportFlow`（薄适配，判定逻辑全部在核心）。
2. **四件迁移与真实实现**：四件（`ImportDialog` / `ImportDialogBody` / `ExportButton` / `ExportProgress`）迁入 `ui-ep/src/components/import-export/`——导入三步真实编排（模板下载、文件校验、上传解析、结果与幂等键）、导出按当前筛选 / 选中行取数与超阈值异步导出反馈、脱敏提示与动作权限显隐；**对外 Props / 事件 / 插槽保持 `08_01` 冻结形状**（仅新增可选 Props / 事件，事件上抛保留）。
3. **错误报告件**：新增 `ImportErrorReport.vue`（汇总计数 + 错误行明细表分页 + 「下载错误明细」），供导入对话框与后续国际化导入导出（`08_07`）复用。
4. **宿主核对页**：`apps/desktop/import-export-check.html` + `src/dev/{importExportCheck.ts,ImportExportCheck.vue}`（导入三步含错误行报告与分页、导出同步 / 异步分支、失败重试、权限过滤），自检项上屏（`vite build` 不含）。

## 3. 完成标准 <a id="accept"></a>

导入三步与错误行报告（分页 / 明细下载）可用、幂等键随文件与重试口径正确；导出筛选同口径、脱敏默认与明文声明生效、超阈值转后台异步反馈与取消可用；核对页自检全绿；Vitest 覆盖幂等与错误行解析分支；`vue-tsc`、ESLint、Vitest 全通过。
