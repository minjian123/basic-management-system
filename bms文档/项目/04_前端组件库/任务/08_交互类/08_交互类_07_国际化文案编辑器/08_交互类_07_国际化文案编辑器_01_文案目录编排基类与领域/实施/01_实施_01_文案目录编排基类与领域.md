## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先行**：经容器内 Django shell 登记用例，取得编号 **773**（平台既有编号已用至 772）；用例文件首行标注 `// kiwi_id: 773`。
2. **领域纯函数**（`core/src/domain/i18n.ts`）：
   - 常量与边界：权限码 `i18n:manage`、默认语言 `zh-CN`、值长 4000（Unicode 码点口径，2026-09-19 随 `08_08` 上调）、网格页长 50、筛选页长 200、虚拟滚动阈值 200、错误码 44001 ~ 44005 与文案表；
   - 装载输入（`I18nLocaleInput` / `I18nMessageInput`）与运行态（`I18nLocaleItem` / `I18nMessageItem`）分离，`normalize*` 补齐确定值；
   - 校验：`validateLocaleAdd` / `validateLocaleUpdate` / `validateLocaleToggle` / `validateLocaleRemove` / `validateMessageKey` / `validateMessageValue`；
   - 缺失：`deriveMissingLocales`（前端派生 ∪ 后端标记，按清单顺序）；
   - 筛选：`filterMessages`（前缀 / 关键词 / 缺失 / 仅已修改 / 语言聚焦）与 `resolveFilterParams`（剔空下发）；
   - 变更与幂等：`diffMessages` / `isDirty` / `deriveMessageKey`（`i18n:{fnv1aHex(stableStringify(变更集))}`，复用 `08_05` 已提取的 `stableStringify` + `fnv1aHex`）；
   - 分页与虚拟阈值：`paginateMessages` / `shouldVirtualize`；文案与文件名：`resolveMessageErrorText` / `messageExportFileName`。
3. **能力基类**（`core/src/capabilities/message-catalog.ts`）：
   - 键 `message-catalog`、依赖 `['locale', 'access', 'notice']`、组合 `BaseLocale` 承载聚焦语言；
   - 取数 `load()` / `reload()`（清单 + 当前页文案，成功置基线）；编辑 `editCell` / `addKey` / `removeKey`；
   - 语言清单 `addLocale` / `updateLocale` / `toggleLocale` / `removeLocale`（本地生效 + 校验 + 异步提交，失败回滚）；
   - 保存 `save()`（占位 / 无权 / 无变更 / key 校验失败均不请求；成功置基线后**依次失效缓存与重载语言包**）；`retry()` 复用同幂等键；
   - 缓存 `invalidateCache()`（失败写提示、返回 `false`、不改失败态）与 `reloadMessages()`（成功 `messagesRevision += 1`）；
   - 脏数据 `dirty` / `changeSet` / `resetDirty()`；导出参数 `exportParams`；
   - 向后兼容新增 `applySnapshot()`：宿主下发面（件层 props）同步进内核并置基线，使「渲染用 props、编排用内核」两处一致。
4. **登记与导出**：`capabilities/manifest.ts` 增 `'message-catalog': ['locale', 'access', 'notice']`；`core/src/index.ts` 增基类 8 项类型导出 + 领域 59 项导出。
5. **契约套件**：`core/testing/message-catalog.ts` 的 `describeMessageCatalogContract`（占位零请求 / 就绪取数 / 缺失并集 / 编辑与幂等键 / 值长与命名拒绝 / 清单四类规则 / 保存链路 / 无变更与未注入 / 失败重试同键 / 失效失败不阻断与版本号 / 列集与开关 / 筛选仅本地），并在 `testing/index.ts` 再导出。
6. **核心用例**：`core/tests/domain-i18n.spec.ts`（领域 22 条）与 `core/tests/message-catalog.spec.ts`（能力基类 19 条 + 契约套件 13 条）。
7. **护栏适配**：`guard-jsdoc.spec.ts` 要求常量逐项 JSDoc（已补）；`guard-manifest.spec.ts` 要求能力基类在《前端基类清单》登记为「已交付」（已在清单 §2.1 / §2 / §5.2 / §9 登记）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 缺失派生含**停用语言**（`ar-SA` 空值也算缺失），与设计意图「缺失只对需补齐的启用语言」不符 | `normalizeMessage` 的缺失判定改按**启用语言**（`localeColumns(locales)`）派生，`values` 仍保留全部语言键以承载存量值；`editCell` 同步改按启用语言重算；详细设计 §3.2 缺失条目已回写 |
| 2 | `editCell` 调 `deriveMissingLocales(row.values, this.locales)` 会丢掉既有后端标记 | 改按启用语言整集重算（派生与标记并集语义在领域函数内保证），避免编辑后标记漂移 |
| 3 | 契约套件中「列集」用例先 `toggleLocale` 再 `load`，`load` 会用夹具清单覆盖本地变更 | 用例改为**先断言就绪列集再切停用**（不重取），断言意图不变 |
| 4 | 契约套件「编辑与脏态」在设置筛选后读 `observable()`，行数与可见行语义混用 | 契约面补断言「行数不随筛选变化、可见行随筛选变化」，语义边界更清晰 |
| 5 | `guard-jsdoc.spec.ts` 报常量块缺 JSDoc | 占位与提示文案常量**逐项补 JSDoc**（护栏要求逐条注释） |
| 6 | 件层需要「宿主下发数据即已保存」语义，否则 `dirty` 初值为真 | 能力基类**向后兼容新增** `applySnapshot()`（件层 watch 下发面调用，置基线）；契约面不涉及该入口，对外形状不变 |
| 7 | 领域 `missing` 排序依赖语言清单顺序，但编辑路径原按自身序拼装 | 统一走 `deriveMissingLocales`（内部按清单顺序输出），去掉件/基类内的排序逻辑 |

## 6. 偏差与遗留 <a id="deviation"></a>

- **工时偏差**：名义 8h；因领域 59 项导出、能力基类 10 个公开方法、契约套件 13 条与 54 条用例实际上浮，明细见第 4 节。
- **真实接口联调**：语言清单增改启停 / 文案维护取数 / 批量保存 / 缓存失效 / 语言包重载处理函数由宿主注入，未注入即占位（不发请求）；真实联调随**阶段八**（通用能力 · 国际化）。
- **上游回写已完成**：三处（《概要设计 · 国际化管理》《架构设计 · 国际化》《架构设计 · 前端架构》）随本任务一并回写。
- **缺失口径的开放项**：当前为「前端派生 ∪ 后端标记」；若阶段八后端给出更权威判定（如按默认语言回退策略细分），以后端为准并回写详细设计 §7。
- **移动端**：本期仅 PC；`BaseMessageCatalog` 与 `describeMessageCatalogContract` 端中立，移动端实现随移动端任务。
