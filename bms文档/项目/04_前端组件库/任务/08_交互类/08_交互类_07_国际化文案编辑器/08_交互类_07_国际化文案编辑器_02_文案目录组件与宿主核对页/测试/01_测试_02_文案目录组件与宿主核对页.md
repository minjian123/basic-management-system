## 4. 问题与偏差 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 既有冻结用例对文案网格单元格调 `setValue` 报「cannot be called on TD」（输入框 `data-test` 一度被挪到 `<td>`） | 冻结标记 `cell-{key}-{code}` 迁回输入框，`<td>` 用 `cell-wrap-*` 承载状态属性；既有用例未改动即通过 |
| 2 | 契约套件在 `it()` 内调用被拒（「Calling the suite function inside test function is not allowed」） | 套件调用提到**文件顶层**（`ui-ep` 侧与 `core` 侧一致） |
| 3 | 语言清单件弹窗断言取不到元素（Element Plus `ElDialog` 未渲染内容） | 用例对 EP 件下桩（`ElDialog` / `ElButton` / `SwitchInput`），与既有 `modal.spec.ts` 口径一致 |
| 4 | 核对页首轮 9/12（缺失筛选、重试提示、占位零请求三项） | 分别处置见实施记录 §4 第 6~8 项；复跑 12/12 |
| 5 | `useBaseMessageCatalog` 未同步宿主下发面，导致 `dirty` 初值恒真 | 容器 watch 下发面调 `applySnapshot()`（下发即已保存基线）；详见实施记录 §4 第 6 项 |
