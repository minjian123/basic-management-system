## 2. 任务内容 <a id="content"></a>

1. **投影**：新增 `useBaseMessageCatalog`（核心实例 ↔ Vue 响应式薄适配，件层唯一状态源）。
2. **组件**：新建专题族 `ui-ep/src/components/i18n/`（四件）——编辑器容器（迁移 + 真实实现，页签装配 / 工具栏 / 缓存失效 / 脏数据拦截 / 导入导出接线）、语言清单件（新增，code/name/rtl/status 增改启停 + 弹窗表单 + 默认语言保护）、筛选器件（新增，模块前缀 / 关键词 / 缺失 / 仅已修改 / 语言聚焦）、文案网格件（迁移，`msg_key` × 多语言可编辑单元格 + 缺失高亮 + 分页与虚拟滚动双路径，独立分包懒加载）。
3. **导入导出复用**：语言包导入经 `08_05` 的导入编排与错误报告件；导出经导出编排与件层下载触发工具。
4. **宿主核对页**：`apps/desktop/i18n-editor-check.html` + `src/dev/*`（十二项自检上屏，`vite build` 不含）。
5. 以 `08_01` 冻结的对外契约替换数据通路，不改组件对外形状。

## 3. 完成标准 <a name="accept"></a>

四件可用、网格编辑与批量保存正确、缺失筛选准确、导入导出可用、保存后缓存失效并重载即时生效；Vitest 覆盖筛选与缓存失效分支；`vue-tsc`、ESLint、Vitest 全通过。
