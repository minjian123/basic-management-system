## 3. 任务内容 <a id="content"></a>

1. **国际化文案编辑器**：语言清单维护、`msg_key` × 多语言列内可编辑网格、缺失与冲突筛选、批量保存与缓存失效、导入导出。
2. 保存后前端语言包缓存失效并按语言上下文能力基类 `BaseLocale` 重新加载，文案即时生效。
3. **编排入链**：新增能力基类 `BaseMessageCatalog`（文案目录编排，依赖语言上下文 / 权限 / 提示），横切语义落继承链、不在件内重复实现。
4. **数据通路注入式**：语言清单取数与增改启停、文案维护取数、批量保存、缓存失效与语言包重载的处理函数由宿主注入，未注入即占位（不发请求、按钮禁用 + 提示）；真实接口联调归口阶段八（通用能力 · 国际化）。
5. 以 `08_01` 冻结的对外契约替换数据通路，不改组件对外形状（新增可选 Props / 事件均为向后兼容扩展）。

## 4. 完成标准 <a id="accept"></a>

四件可用、网格编辑与批量保存正确、缺失筛选准确、导入导出可用、保存后文案即时生效；Vitest 覆盖筛选与缓存失效分支；`vue-tsc`、ESLint、Vitest 全通过。
