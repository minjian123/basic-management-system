## 1. 设计目标与范围 <a id="goal"></a>

交付两节真实能力：**图标选择/渲染/清单**（icon key 统一口径、注册表登记与唯一性校验、多来源解析与降级、独立分包）与**代码/表达式编辑器**（SQL / 表达式 / cron 编辑 + 只读高亮，编辑内核 `BaseEditorKernel` 复用、独立分包懒加载）。

- **图标注册表**：扩展核心 `IconRegistry` 承载 icon key（放宽键校验、补展示元信息与检索），平台/业务/自定义统一登记；**未注册不可用**（未知 key 降级问号 + 去重告警）。
- **编辑器内核**：引入 **CodeMirror 6**（按需动态 import，SQL / JSON / JavaScript 语言包）与 **highlight.js**（只读高亮），内核经 `BaseEditorKernel` 共享、模块级缓存**不重复加载**。
- 依赖 02_03（`BaseEditorKernel`）、02_05（注册表基座 / 注册项契约）、02_06（校验与格式化）。

不在本期：自定义图标 CRUD 与 `sys_icon` 后端联动、SQL 测试执行真实后端、表达式后端校验接口、清单页与路由页面组装（随对应后端 / 页面任务）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 核心图标注册表扩展 <a id="icon-registry"></a>

```ts
// 注册项（新增可选元信息，构造签名向后兼容）
class IconProvider extends BaseProvider {
  readonly key: string          // icon key：el:User / biz:purchase-order / custom:1024 / van:todo-o
  readonly source: unknown      // 组件 / SVG 文本 / 懒加载器
  readonly name?: string        // 展示名
  readonly category?: string    // 分类（如 direction / edit / media / business / custom）
  readonly tags?: string[]      // 搜索标签
  constructor(key: string, source: unknown, options?: { name?; category?; tags? })
}

// 注册表：键校验改为 icon key 口径；补检索（基座 register/get/keys/values/snapshot 不变）
class IconRegistry extends BaseProviderRegistry<IconProvider> {
  register(provider): void      // assertIconKey
  byPrefix(prefix): IconProvider[]   // el: / biz: / custom: / van:
  search(keyword): IconProvider[]    // 归一匹配 key / name / tags
  resolve(key): unknown | undefined  // get(key)?.source
}
```

- `assertIconKey`：`^[a-z][a-z0-9-]*:[A-Za-z0-9][A-Za-z0-9._-]*$`——兼容现有模块键（`demo:sparkles`）与 icon key（`el:User` / `custom:1024`）；无前缀/非法即拒（唯一性拒重由基座保证）。

### 3.2 ui-ep 图标注册表与登记 <a id="icon-catalog"></a>

```ts
// 活动注册表（默认本地实例，宿主可注入覆盖——注入点）
setIconRegistry(registry: IconRegistry): void
getIconRegistry(): IconRegistry
useIconRegistry(override?: IconRegistry): IconRegistry

// 官方图标登记（首次打开选择器 / 清单时懒加载 @element-plus/icons-vue，幂等注册）
ensureOfficialIcons(registry): Promise<void>
```

- 官方图标键 `el:{PascalCase}`（如 `el:User`），分类按内置映射（缺省 `common`）；重复登记由基座抛 `BaseError`（**唯一性校验生效**）。
- 未知 key 解析失败 → 兜底问号 + 开发环境**去重告警一次**。

### 3.3 图标三件契约（冻结） <a id="icon-components"></a>

#### 3.3.1 `IconRenderer` 只读渲染件 <a id="icon-renderer"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `name`（icon key）/ `size`（缺省 `16`）/ `color`（缺省 `currentColor`）/ `spin` / `fallback`（缺省 `QuestionFilled`）/ `registry` |
| 事件 | `resolved`（`key`）/ `missing`（`key`） |
| 行为 | `el:` → 官方图标组件；`biz:` → 注册表来源；`custom:` → 组件或 SVG 文本（`DOMPurify` 清洗后内联）；未知/无前缀 → 兜底 + 告警；`name` 为空不渲染 |

#### 3.3.2 `IconPicker` 图标选择件 <a id="icon-picker"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `modelValue` / `size`（`small` / `default` / `large`）/ `placeholder` / `clearable`（缺省 `true`）/ `disabled` / `category` / `includeCustom`（缺省 `true`）/ `recentLimit`（缺省 `12`）/ `registry` |
| 事件 | `update:modelValue` / `change` / `clear` / `open` / `close` |
| 对外能力 | `open()` / `close()` / `clear()`（`defineExpose`） |

- 触发框（图标 + key）+ 弹层（搜索防抖 200ms、分类 Tab、图标网格、最近使用）；选中即回填并关闭；最近使用按用户本地存储（键 `bms_icon_recent`）。

#### 3.3.3 `IconLibrary` 清单管理件 <a id="icon-library"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `registry` / `customIcons`（`CustomIcon[]`）/ `references`（`Record<string, number>`）/ `canManage` / `loading` |
| 事件 | `copy`（`key`）/ `add` / `edit`（`CustomIcon`）/ `toggle`（`CustomIcon`）/ `remove`（`CustomIcon`）/ `refresh` |

```ts
export interface CustomIcon {
  id: string
  code: string
  name: string
  category?: string
  status: 'enabled' | 'disabled'
}
```

- 来源分组（平台 / 业务 / 自定义）、搜索、网格（预览 + 名称 + 来源标签）、复制 key、引用计数；自定义增删改启停按 `canManage` 显隐（占位只读，真实 CRUD 随后端）。

### 3.4 编辑器内核与投影 <a id="kernel"></a>

```ts
// useCodeKernel：经 BaseEditorKernel 承载；模块级缓存，多次使用不重复加载
useCodeKernel(): {
  kernel: BaseEditorKernel
  loaded: Ref<boolean>
  load(): Promise<void>          // 复用模块级 import 缓存
  destroy(): void
  createEditor(options): EditorHandle   // 语言包按 language 选择（sql / json / javascript / expression / text）
}

// useHighlight：highlight.js 模块级缓存 + 语言注册
useHighlight(): {
  load(): Promise<HighlightApi>  // 复用模块级 import 缓存
  highlight(code, language): Ref<string>  // 返回高亮 HTML
}
```

- **不重复加载**：`loadCodeModules()` / `loadHighlight()` 在模块级缓存 `Promise` 与加载计数；多编辑器实例共享同一份内核模块。
- 主题：编辑器主题由设计令牌变量生成（背景 / 文字 / 关键字 / 字符串 / 注释），随深浅切换重建。

### 3.5 编辑器四件契约（冻结） <a id="code-components"></a>

#### 3.5.1 `CodeEditor` 通用编辑器件 <a id="code-editor"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `modelValue` / `language`（`sql` / `expression` / `cron` / `json` / `javascript` / `text`，缺省 `text`）/ `readOnly` / `height`（缺省 `160px`）/ `lineNumbers`（缺省 `true`）/ `placeholder` / `indent`（缺省 `2`）/ `theme`（`auto` / `light` / `dark`）/ `diagnostics`（`EditorDiagnostic[]`） |
| 事件 | `update:modelValue` / `change` / `validate`（`EditorDiagnostic[]`）/ `ready` |
| 对外能力 | `focus()` / `getValue()` / `setValue(value)` / `insert(text)` / `getSelection()`（`defineExpose`） |

```ts
export interface EditorDiagnostic {
  line: number
  column?: number
  severity: 'error' | 'warning' | 'info'
  message: string
}
```

- 编辑宿主 `CodeMirrorHost` 经 `defineAsyncComponent` 独立分包懒加载；空内容占位；只读态可选中 / 复制。

#### 3.5.2 `SqlEditor` SQL 编辑器件 <a id="sql-editor"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `modelValue` / `readOnly` / `height` / `canTest`（缺省按权限）/ `fields`（`{ name; type }[]`）/ `diagnostic` |
| 事件 | `update:modelValue` / `validate`（`SqlValidateResult`）/ `test` / `format` / `insert-field`（`name`） |

```ts
export interface SqlValidateResult {
  valid: boolean
  diagnostics: EditorDiagnostic[]
}
```

- 工具栏：格式化 / 校验 / 测试执行（按 `canTest` 显隐）；前端轻校验「仅 SELECT」+ 场景校验经事件透传（后端随 08 后端）；字段清单侧栏可插入列名。

#### 3.5.3 `ExpressionEditor` 表达式编辑器件 <a id="expression-editor"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `modelValue` / `readOnly` / `height` / `fields`（`ExpressionToken[]`）/ `variables`（`ExpressionToken[]`）/ `templates`（`ExpressionTemplate[]`） |
| 事件 | `update:modelValue` / `validate`（`ExpressionValidateResult`）/ `insert`（`{ token }`） |

```ts
export interface ExpressionToken { key: string; label: string; insert: string }
export interface ExpressionTemplate { key: string; label: string; expression: string }
export interface ExpressionValidateResult { valid: boolean; diagnostics: EditorDiagnostic[] }
```

- 字段 / 预置变量面板点击插入光标处；运算符 / 常用模板一键插入；校验经事件透传（同源接口随后端）。

#### 3.5.4 `CronEditor` cron 编辑器件 <a id="cron-editor"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `modelValue`（5 段 cron）/ `readOnly` / `showNext` |
| 事件 | `update:modelValue` / `change` / `validate`（`CronValidateResult`） |

```ts
export interface CronValidateResult { valid: boolean; message?: string }
```

- 5 段（分 / 时 / 日 / 月 / 周）输入 + 常用值 + 模板 + 人类可读描述（i18n）；`utils/cron.ts` 提供 `parseCron` / `describeCron` / `validateCron` / `CRON_TEMPLATES`（纯函数，Vitest 覆盖）。

#### 3.5.5 `CodeViewer` 只读高亮件 <a id="code-viewer"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `content` / `language`（`sql` / `json` / `javascript` / `text` / `log`）/ `lineNumbers`（缺省 `true`）/ `maxHeight`（缺省 `320px`）/ `wrap` / `collapsible`（缺省 `true`）/ `collapseLines`（缺省 `15`）/ `copyable`（缺省 `true`） |
| 事件 | `copy` |

- 经 `useHighlight` 复用 highlight.js 模块（模块级缓存），长文折叠 + 最大高度滚动 + 复制。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未知 / 无前缀 icon key | 兜底问号 + 开发环境去重告警 |
| 已停用 / 删除的自定义图标 | 渲染降级问号，不阻断 |
| 图标 key 非法 / 重复登记 | `register` 抛 `BaseError`（唯一性校验） |
| 图标全量库加载失败 | 选择器降级为仅注册表已登记项 + 提示 |
| CodeMirror / highlight.js 加载失败 | 降级为纯文本域 / 纯文本展示 + 告警（能力缺失不阻断） |
| 只读态 | 禁止编辑、可选中复制 |
| 空内容 | 占位文案；cron 空值描述为空 |
| 非法 cron / 非 SELECT SQL | 内联诊断 + 事件透传；以后端校验为准 |
| 主题切换 | 重建编辑器、保留内容 |
| 实例释放 | `onScopeDispose` / `destroy()` 释放内核，模块缓存不释放 |
