## 2. 任务内容 <a id="content"></a>

1. **图标选择器**：图标库浏览、搜索、预览与选择；图标经图标注册表登记（统一提供者注册表基座 `BaseProviderRegistry` + 注册项契约 `BaseProvider`），未注册不可用，注册表唯一性校验生效。
2. **代码表达式编辑器**：CodeMirror 6 内核封装（语法高亮、自动补全、只读查看），覆盖代码表达式 / SQL / Cron 等形态。
3. 内核加载与释放经编辑器内核能力基类 `BaseEditorKernel`（与富文本字段 `06_03` 共用），**独立分包**、不重复加载。
4. 只读查看复用编辑器内核只读模式；能力缺失时降级为纯文本并告警。

## 3. 完成标准 <a id="accept"></a>

图标选择与预览可用、注册表唯一性校验生效；四类代码编辑器与只读查看可用、内核复用不重复加载、分包生效；Vitest 覆盖注册表与内核复用分支；`vue-tsc`、ESLint、Vitest 全通过。
