## 2. 测试范围与用例 <a id="scope"></a>

| 用例组 | 类型 | 自动化文件 | 覆盖点 |
| --- | --- | --- | --- |
| 图标注册表 | 单元（core） | `core/tests/registries.spec.ts` | icon key 校验（大小写 / 数字段）、唯一性拒重、来源前缀、检索、解析 |
| 图标注册表（ui-ep） | 单元 | `ui-ep/tests/interaction-icon-code.spec.ts` | 官方图标幂等登记与模块级缓存 |
| 图标渲染 | 单元 | 同上 | `biz:` 组件来源解析、未知 key 降级兜底 + `missing`、空名不渲染 |
| 图标选择 | 单元 | 同上 | 打开 / 搜索 / 分类 / 选中回填 / 清除 |
| 图标清单 | 单元 | 同上 | 来源分组、复制 key、引用计数、自定义增删改启停按 `canManage` 显隐 |
| 编辑内核 | 单元 | 同上 | CodeMirror 模块级缓存**只加载一次**、销毁复位、`CodeEditor` 受控 / 对外能力 / 纯文本降级、默认宿主异步分包 |
| SQL 编辑器 | 单元 | 同上 | 仅 SELECT 轻校验、测试执行权限、格式化、字段插入 |
| 表达式编辑器 | 单元 | 同上 | 令牌 / 模板插入、括号配对轻校验 |
| cron 编辑器 | 单元 | 同上 | 段编辑、人类可读描述、模板、非法校验；纯函数解析 / 描述 / 校验 |
| 只读高亮 | 单元 | 同上 | highlight.js 高亮、复制、长文折叠 |
