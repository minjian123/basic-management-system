## 3. 任务内容 <a id="content"></a>

1. 审批操作必须**幂等**；流程 XML 必须可导入导出与校验发布，均建立在工作流引擎契约之上。
2. 审批流展示面向业务用户、流程建模器面向流程管理员，二者共享工作流契约。
3. 以 `08_01` 冻结的对外契约替换数据通路，不改对外形状与分包入口。

## 4. 完成标准 <a id="accept"></a>

审批进度与操作可用且幂等；建模器可画、可导入导出 XML、校验并发布；分包生效；Vitest 覆盖幂等与 XML 往返分支；`vue-tsc`、ESLint、Vitest 全通过。
