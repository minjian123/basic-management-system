## 2. 任务内容 <a id="content"></a>

1. **画布**：bpmn-js Modeler 画布、元素调板、用户任务属性（审批人 / 会签条件）、条件分支。
2. **往返与发布**：XML 导入导出、校验与版本发布；XML 往返一致（导入后导出语义等价）。
3. **分包**：bpmn-js **独立分包**、懒加载，首屏不加载。
4. 以 `08_01` 冻结的对外契约替换数据通路，不改分包入口。

## 3. 完成标准 <a id="accept"></a>

建模器可画、可导入导出 XML、校验并发布；分包生效（首屏不加载）；Vitest 覆盖 XML 往返分支；`vue-tsc`、ESLint、Vitest 全通过。
