## 1. 设计目标与范围 <a id="goal"></a>

依赖后端的三节点交互件（**报表设计器 / 大屏设计器与播放 / AI 助手**）先交付**占位版**：**契约先行冻结**（Props / 事件 / 插槽），占位态不发请求、操作禁用、降级提示；`08_09`（报表设计器与大屏设计器与播放）/ `08_10`（AI 助手）真实实现**只换数据通路、不改对外契约**（变更走版本升级）。

- **复用 08_01_01 / 08_01_02 共享设施**：`describePlaceholderInteractionContract`、`useInteractionPlaceholder`、`useBaseDataState`、`useBaseDragDrop`、`useBaseAsyncTask`。
- **件数口径调整**：「大屏设计器与播放」按确认拆为 `ScreenDesigner` + `ScreenPlayer` 两件，`08_01` 对外件数由 **11 件调整为 12 件**（同步回写父任务 / 域 / 计划）。

不在本期：真实数据通路（数据集取数与预览 / 报表与大屏定义读写发布 / AI 对话与流式通道）、gridstack / vue-flow / ECharts / Markdown 渲染内核、页面与独立播放路由集成。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 新增能力投影（挂链） <a id="projections"></a>

```ts
// useBaseOptionSource：选项 / 数据集加载 / 版本比对 / 搜索回显（加载器由宿主注入，占位不请求）
useBaseOptionSource<T>(options?: { loader?: () => Promise<OptionItem<T>[]> }): {
  optionSource: BaseOptionSource<T>
  options: Ref<OptionItem<T>[]>
  dataVersion: Ref<number>
  load(): Promise<void>
  getLabel(value: T): string | undefined
  search(keyword: string): OptionItem<T>[]
}

// useBaseSubscription：点分主题订阅（占位总线 / 本地 / 实时来源解耦，释放自动取消）
useBaseSubscription(): {
  subscription: BaseSubscription
  topics: Ref<string[]>
  subscribe(topic: string, handler: (payload: unknown) => void): () => void
  emit(topic: string, payload: unknown): void
}
```

- 组件挂链：`ReportDesigner` → `useBaseOptionSource`（数据集选择）；`ScreenDesigner` / `ScreenPlayer` → `useBaseDragDrop` / `useBaseAsyncTask`（复用 08_01_02）；`AiAssistant` → `useBaseSubscription`（流式通道）。四件同时经 `useInteractionPlaceholder` 承载占位语义。
- `useBaseOptionSource` / `useBaseSubscription` 为新增投影，回写《[前端基类清单](../../../../../../../前端基类清单.md)》§9。

### 3.2 四件契约（冻结） <a id="components"></a>

#### 3.2.1 `ReportDesigner` 报表设计器 <a id="report"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `reportCode` / `datasets`（`ReportDataset[]`）/ `datasetId` / `charts`（`ReportChartItem[]`）/ `selectedId` / `dirty` / `readOnly` / `degradeText` |
| 事件 | `change`（`ReportChartItem[]`）/ `select`（`id \| null`）/ `add-chart`（`{ datasetId, chartType }`）/ `remove-chart`（`id`）/ `save` / `publish` / `save-as` / `preview` / `retry` |
| 插槽 | `degrade` / `empty` / `live` / `toolbar` / `dataset-panel` / `config-panel` |

```ts
export interface ReportDataset {
  id: string
  code: string
  name: string
  status: 'enabled' | 'disabled'
  fields?: { name: string; type: string }[]
}
export interface ReportChartItem {
  id: string
  datasetId: string
  chartType: string
  title?: string
  config?: Record<string, unknown>
  layout: { x: number; y: number; w: number; h: number }
}
```

- 三区（数据集选择 / 12 列网格画布 / 图表配置）+ 工具栏骨架；数据集经 `BaseOptionSource` 取数（占位零请求）、停用不可选；占位态禁用编辑与保存；画布经独立分包懒加载。

#### 3.2.2 `ScreenDesigner` 大屏设计器 <a id="screen-designer"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `screenCode` / `pages`（`ScreenPage[]`）/ `activePageId` / `components`（`ScreenComponent[]`）/ `selectedId` / `dirty` / `readOnly` / `degradeText` |
| 事件 | `change`（`ScreenComponent[]`）/ `select`（`id \| null`）/ `add-component`（`ScreenComponentType`）/ `remove-component`（`id`）/ `page-change`（`pageId`）/ `save` / `publish` / `preview-play` / `retry` |
| 插槽 | `degrade` / `empty` / `live` / `toolbar` / `component-panel` / `property-panel` |

```ts
export interface ScreenPage {
  id: string
  name: string
}
export type ScreenComponentType = 'chart' | 'table' | 'metric' | 'text' | 'image' | 'time' | 'decor'
export interface ScreenComponent {
  id: string
  type: ScreenComponentType
  x: number
  y: number
  w: number
  h: number
  z: number
  datasetId?: string
  chartType?: string
  text?: string
}
```

- 三区（组件面板 / 自由画布 / 属性面板）+ 工具栏（含多页与标尺网格）骨架；自由画布经 `BaseDragDrop`（绝对定位拖拽 / 缩放，占位禁用）；画布经独立分包懒加载。

#### 3.2.3 `ScreenPlayer` 大屏播放 <a id="screen-player"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `screenCode` / `pages`（`ScreenPage[]`）/ `activePageId` / `components`（`ScreenComponent[]`）/ `interval`（轮播间隔 ms）/ `autoplay` / `fullscreen` / `degradeText` |
| 事件 | `update:activePageId` / `next` / `prev` / `toggle`（`playing`）/ `refresh` / `retry` |
| 插槽 | `degrade` / `empty` / `live` |

- 多页轮播（定时 / 手动、暂停）、自适应缩放、隐藏工具栏、数据定时刷新经 `BaseAsyncTask` 占位；按当前页只渲染当前页组件；独立分包懒加载。

#### 3.2.4 `AiAssistant` AI 助手 <a id="ai"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `mode`（`ask` / `report` / `approval` / `doc_qa`）/ `sessions`（`AiSession[]`）/ `activeSessionId` / `messages`（`AiMessage[]`）/ `datasets`（`ReportDataset[]`）/ `files`（`{ id, name }[]`）/ `autoExecute` / `autoApprove` / `degradeText` |
| 事件 | `update:mode` / `send`（`{ mode, content, datasetId?, fileIds?, sessionId? }`）/ `stop` / `regenerate`（`messageId`）/ `select-session`（`sessionId`）/ `new-session` / `remove-session`（`sessionId`）/ `attach`（`fileIds`）/ `confirm-action`（`actionId`）/ `revoke-action`（`actionId`）/ `retry` |
| 插槽 | `degrade` / `empty` / `live` / `sessions` / `input` |

```ts
export type AiMode = 'ask' | 'report' | 'approval' | 'doc_qa'
export type AiRole = 'user' | 'assistant'
export type AiMessageStatus = 'streaming' | 'done' | 'error' | 'stopped'
export interface AiCitation {
  type: 'file' | 'article' | 'record'
  title: string
  id: string
}
export interface AiMessage {
  id: string
  role: AiRole
  status: AiMessageStatus
  content: string
  result?: { kind: 'chart' | 'table'; chartType?: string; datasetId?: string; rows?: unknown[] }
  citations?: AiCitation[]
  risks?: string[]
  auditId?: string
}
export interface AiSession {
  id: string
  title: string
  mode: AiMode
  updatedAt: string
}
```

- 四模式（问答 / 问数 / 审批辅助 / 文档问答）+ 会话列表 + 消息流（含图表 / 表格结果、引用、风险、审计标识）+ 输入区骨架；流式通道经 `BaseSubscription`（占位无订阅、不发请求）；自动执行 / 自动审批二次确认与撤销入口（占位只读）；对话面板经独立分包懒加载。

### 3.3 分包入口（首屏不加载） <a id="chunk"></a>

| 入口 | 宿主 | 说明 |
| --- | --- | --- |
| `ReportCanvas` | `ReportDesigner` | 12 列网格画布与图表渲染（gridstack / ECharts） |
| `ScreenCanvas` | `ScreenDesigner` | 自由画布（vue-flow / 拖拽内核） |

### 3.4 契约套件 <a id="suite"></a>

复用 `describePlaceholderInteractionContract`（`08_01_01` 冻结）：未就绪 → 降级 + 禁用 + `requestCount === 0`（含 `load()`）；就绪 → 不再降级 / 禁用。四件真实实现继续跑同一套件。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未就绪时用户交互 | 只读 + 禁用，不发请求 |
| 未就绪时调用 `markLoaded()` | 不计数（防占位期误计） |
| 自定义降级内容 | `degrade` 插槽替换，默认降级文案可配 |
| 空数据（就绪态） | 渲染 `empty` 插槽 / 缺省空态（复用 `03_02` 口径） |
| 未传集合（`datasets` / `charts` / `pages` / `messages` 等） | 视为空集合（真实实现前不报错） |
| 数据集停用 / `readOnly` | 设计器禁用编辑；停用数据集不可选 |
| 自动执行开关未开 | 入口隐藏 / 提示（真实实现按 10208/10209 处理） |
| 异步分包件加载失败 | 降级提示（真实实现补具体文案） |
| 未注入加载器 / 订阅 | 占位不请求、无副作用（能力基类已有语义） |
