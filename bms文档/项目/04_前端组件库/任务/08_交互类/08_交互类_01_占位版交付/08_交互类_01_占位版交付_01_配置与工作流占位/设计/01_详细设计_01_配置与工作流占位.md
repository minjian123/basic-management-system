## 1. 设计目标与范围 <a id="goal"></a>

依赖后端的三件交互件（**权限配置 / 审批流展示 / 流程建模器**）先交付**占位版**：**契约先行冻结**（Props / 事件 / 插槽），占位态不发请求、操作禁用、降级提示；`08_04`（权限配置）/ `08_08`（审批流展示与流程建模器）真实实现**只换数据通路与渲染、不改对外契约**（变更走版本升级）。同步建立被 `08_01_02` / `08_01_03` 复用的**共享占位契约套件与占位组合式**（三子任务同一口径）。

不在本期：真实数据通路（权限取数与全量覆盖提交 / 审批实例取数与幂等提交 / BPMN 引擎预解析）、bpmn-js 真实渲染（占位仅立独立分包懒加载入口）、字段壳与页面组装、`08_01_02` / `08_01_03` 的件。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 共享占位基础设施 <a id="shared"></a>

```ts
// useBaseDataState：数据状态投影（loading → ready / empty / error，含竞态令牌）
useBaseDataState(): {
  dataState: BaseDataState
  state: Ref<DataStateName>          // loading / ready / empty / error
  begin(): number                    // 开始一次加载，返回竞态令牌
  settle(token: number, state: SettleState): boolean   // 以令牌结算（非最新忽略）
  setState(state: SettleState): void // 便捷：直接结算
}

// useInteractionPlaceholder：交互件占位降级语义（基于 useBaseDataState）
useInteractionPlaceholder(options?: { ready?: boolean }): {
  ready: Ref<boolean>
  degraded: Ref<boolean>       // !ready
  disabled: Ref<boolean>       // !ready（操作禁用）
  requestCount: Ref<number>    // 占位态必须保持 0
  state: Ref<DataStateName>
  dataState: BaseDataState
  setReady(value): void
  markLoaded(): void           // 仅就绪后计数
  begin(): number
  settle(token, state): boolean
}
```

- **挂链口径（决策）**：权限配置另挂 `useBaseTreeData`（权限树天然树域）；审批流展示与流程建模器经 `useInteractionPlaceholder`（内部挂新增投影 `useBaseDataState` → 核心 `BaseDataState` 子类）；`useBaseDataState` 为新增投影，回写《[前端基类清单](../../../../../../../前端基类清单.md)》§9。
- **占位语义**：`ready !== true` → `degraded=true`、`disabled=true`、不发请求；`markLoaded()` 在未就绪时不计数（防占位期误计）；`setReady(true)` → 不再降级。

### 3.2 三件组件契约（冻结） <a id="components"></a>

#### 3.2.1 `PermissionConfig` 权限配置 <a id="permission"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `roleId` / `tab`（`tree` / `field` / `scope` / `subject`，缺省 `tree`）/ `treeNodes`（`PermissionNode[]`）/ `fieldPerms`（`FieldPermRow[]`）/ `dataScopes`（`DataScopeRow[]`）/ `subjects`（`SubjectItem[]`）/ `loading` / `dirty` / `degradeText` |
| 事件 | `update:tab` / `change`（`{ kind, value }`）/ `save` / `reset` / `retry` |
| 插槽 | `degrade` / `empty` / `live` |

```ts
export type PermissionTab = 'tree' | 'field' | 'scope' | 'subject'
export interface PermissionNode {
  key: string
  label: string
  type: 'menu' | 'form' | 'business' | 'action'  // 业务为推导只读
  checked?: boolean
  children?: PermissionNode[]
}
export interface FieldPermRow {
  formKey: string
  formLabel: string
  fields: { key: string; label: string; visible: boolean; editable: boolean }[]
}
export interface DataScopeRow { actionKey: string; actionLabel: string; expression: string; builtin?: boolean }
export interface SubjectItem { id: string; type: 'user' | 'position' | 'dept'; name: string }
```

- 权限树 / 字段矩阵 / 数据范围 / 主体绑定**只渲染骨架与只读状态**；就绪态下勾选与编辑事件按契约透传，提交（`save`）由真实实现接入全量覆盖 + 幂等键。
- 占位态四类页签均禁用，不发任何取数 / 提交请求。

#### 3.2.2 `ApprovalFlow` 审批流展示 <a id="approval"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `instance`（`ApprovalInstance`）/ `records`（`ApprovalRecord[]`）/ `currentTask`（`ApprovalTask`）/ `loading` / `compact` / `canApprove` / `canWithdraw` / `showDiagram` / `bpmnXml` / `degradeText` |
| 事件 | `approve` / `reject` / `transfer` / `withdraw` / `comment`（均 `ApprovalActionPayload`）/ `node-click`（`nodeId`）/ `retry` |
| 插槽 | `degrade` / `empty` / `live` / `actions` |

```ts
export type ApprovalNodeStatus = 'done' | 'active' | 'pending' | 'rejected' | 'skipped'
export interface ApprovalNode {
  nodeId: string
  name: string
  status: ApprovalNodeStatus
  assignees?: { id: string; name: string }[]
  signed?: boolean
  time?: string
}
export type ApprovalInstanceStatus = 'running' | 'finished' | 'rejected' | 'abnormal'
export interface ApprovalInstance { id: string; status: ApprovalInstanceStatus; currentNodeId?: string; nodes: ApprovalNode[] }
export type ApprovalAction = 'approve' | 'reject' | 'withdraw' | 'transfer' | 'comment'
export interface ApprovalRecord {
  id: string
  nodeId: string
  nodeName: string
  assigneeId: string
  assigneeName: string
  action: ApprovalAction
  comment?: string
  createdAt: string
}
export interface ApprovalTask { taskId: string; nodeId: string; nodeName: string; signed?: boolean; deadline?: string }
export interface ApprovalActionPayload { action: ApprovalAction; taskId?: string; comment?: string; target?: string }
```

- 默认用**轻量节点进度**（消费结构化节点序列）；`showDiagram` 且提供 `bpmnXml` 时按需异步加载只读图（`ApprovalFlowDiagram`，与流程建模器共用后续 bpmn-js 分包）；无 XML / 加载失败降级为进度件。
- 占位态操作按钮（同意 / 驳回 / 转办 / 撤回 / 评论）**全部禁用**且不提交；`canApprove` / `canWithdraw` 控制显隐，真实实现接入幂等键与二次确认。

#### 3.2.3 `ProcessModeler` 流程建模器 <a id="modeler"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `definitionKey` / `version` / `xml` / `readOnly` / `loading` / `dirty` / `degradeText` |
| 事件 | `update:xml` / `change` / `save-draft` / `deploy` / `validate`（`ModelerValidateResult`）/ `import` / `export` / `add-element`（`ModelerElementType`）/ `select`（`ModelerElement \| null`） |
| 插槽 | `degrade` / `empty` / `live` / `toolbar` / `palette` / `properties` |

```ts
export type ModelerElementType =
  | 'startEvent' | 'endEvent' | 'userTask' | 'exclusiveGateway' | 'parallelGateway' | 'sequenceFlow'
export interface ModelerElement { id: string; type: ModelerElementType; name?: string }
export interface ModelerValidateResult { valid: boolean; errors: { elementId?: string; message: string }[] }
```

- 三区（元素调板 / 建模画布 / 节点属性面板）与工具栏**只渲染骨架**；画布经 `defineAsyncComponent(() => import('./ProcessCanvas.vue'))` **独立分包懒加载**（真实实现换 bpmn-js，进入同一分包），元素调板仅列 BPMN 子集。
- 占位态画布与调板禁用；`readOnly`（历史版本 / 无 `wf:define`）禁用编辑与调板；导入 XML 覆盖前需真实实现确认，本占位仅透传事件。

### 3.3 分包入口（首屏不加载） <a id="chunk"></a>

| 入口 | 形态 | 说明 |
| --- | --- | --- |
| `ProcessCanvas` | `defineAsyncComponent` | 建模画布；真实实现承载 bpmn-js Modeler，独立分包 |
| `ApprovalFlowDiagram` | `defineAsyncComponent` | 审批实例只读 BPMN 图；真实实现承载 bpmn-js Viewer，与建模器**共用依赖**、按需加载 |

- 两者均不在组件静态 `import` 中；测试用 `flushPromises` 等待异步件解析。

### 3.4 契约套件 <a id="suite"></a>

`describePlaceholderInteractionContract(name, create)`（`@bms/core/testing`）断言：未就绪 → 降级 + 禁用 + `requestCount === 0`（含调用 `load()` 仍为 0）；`setReady(true)` → 不再降级且不再禁用。真实实现继续跑同一套件。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未就绪时用户交互 | 只读 + 禁用，不发请求 |
| 未就绪时调用 `markLoaded()` | 不计数（防占位期误计） |
| 自定义降级内容 | `degrade` 插槽替换，默认降级文案可配 |
| 空数据（就绪态） | 渲染 `empty` 插槽 / 缺省空态（复用 `03_02` 口径） |
| 未传集合（`treeNodes` / `records` / `nodes` 等） | 视为空集合（真实实现前不报错） |
| `showDiagram` 无 `bpmnXml` | 降级为节点进度件，不加载异步图 |
| `readOnly` | 建模器禁用编辑与调板；审批流只读展示 |
| 异步分包件加载失败 | 降级提示（真实实现补「已切换为进度视图」文案） |
