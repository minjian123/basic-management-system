## 1. 设计目标与范围 <a id="goal"></a>

依赖后端的四节点交互件（**导入导出 / 表单设计器 / 表单渲染器 / 国际化文案编辑器**）先交付**占位版**：**契约先行冻结**（Props / 事件 / 插槽），占位态不发请求、操作禁用、降级提示；`08_05`（导入导出）/ `08_06`（表单设计器与渲染器）/ `08_07`（国际化文案编辑器）真实实现**只换数据通路、不改对外契约**（变更走版本升级）。

- **复用 08_01_01 共享设施**：`describePlaceholderInteractionContract`（`@bms/core/testing`）、`useInteractionPlaceholder`、`useBaseDataState`（占位语义与状态机同口径）。
- **件数口径调整**：「导入导出」按确认拆为 `ImportDialog` + `ExportButton` 两件，`08_01` 对外件数由 **10 件调整为 11 件**（同步回写父任务 / 域 / 计划）。

不在本期：真实数据通路（导入执行与错误明细 / 布局读写与 DDL / `layout-effective` 渲染 / i18n 批量保存与缓存失效）、字段控件本体与拖拽内核、页面组装、`08_01_03` 的件。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 新增能力投影（挂链，逐件对应真实能力域） <a id="projections"></a>

```ts
// useBaseUploadEngine：分片 / 进度 / 取消（上传器由宿主注入，占位不请求）
useBaseUploadEngine<TFile>(options?: { chunkSize?; maxSize? }): {
  engine: BaseUploadEngine<TFile>
  progress: Ref<number>
  upload(file: TFile): Promise<string | undefined>
  cancel(): void
}

// useBaseAsyncTask：提交 / 进度 / 取消 / 结果（执行器由宿主注入，占位不请求）
useBaseAsyncTask<TResult>(options?: { pollInterval? }): {
  task: BaseAsyncTask<TResult>
  status: Ref<TaskStatus>
  progress: Ref<TaskProgress | undefined>
  result(): TResult | undefined
  submit(): Promise<void>
  cancel(): void
  nextPollDelay(attempt: number): number
}

// useBaseDragDrop：拖拽阶段 / 跨区事件（表单设计器、报表与大屏设计器共用）
useBaseDragDrop(): {
  dragDrop: BaseDragDrop
  dragging: Ref<boolean>
  emitDrag(payload: DragPayload): void
  onDrag(listener: DragListener): () => void
}

// useBaseFormMeta：元数据加载 / 缓存 / 版本比对（加载器由宿主注入，占位不请求）
useBaseFormMeta(options?: { loader? }): {
  formMeta: BaseFormMeta
  meta: Ref<unknown>
  dataVersion: Ref<number>
  load(): Promise<void>
  needsRefresh(version: number): boolean
}

// useBaseLocale：locale / 时区 / 格式上下文
useBaseLocale(options?: { locale?; timezone? }): {
  locale: Ref<string>
  timezone: Ref<string>
  formatContext: Ref<LocaleFormatContext>
  setLocale(locale: string): void
  setTimezone(timezone: string): void
}
```

- 五投影均为**薄适配**（核心实例 ↔ Vue 响应式），不含判定逻辑；回写《[前端基类清单](../../../../../../../前端基类清单.md)》§9。
- 组件挂链：`ImportDialog` → `useBaseUploadEngine`；`ExportButton` → `useBaseAsyncTask`；`FormDesigner` → `useBaseDragDrop`；`FormRenderer` → `useBaseFormMeta`；`I18nMessageEditor` → `useBaseLocale`；五件同时经 `useInteractionPlaceholder` 承载占位语义。

### 3.2 五件契约（冻结） <a id="components"></a>

#### 3.2.1 `ImportDialog` 导入对话框 <a id="import"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `visible` / `biz` / `bizName` / `accept`（缺省 `.xlsx`）/ `maxSize`（缺省 20MB）/ `templateParams` / `successAutoClose` / `degradeText` |
| 事件 | `update:visible` / `download-template`（`templateParams`）/ `submit`（`{ file, idempotencyKey }`）/ `retry` / `download-errors` / `done` / `reset` |
| 插槽 | `degrade` / `empty` / `live` / `footer` |

```ts
export type ImportStep = 'select' | 'uploading' | 'result'
export interface ImportResult {
  total: number
  successCount: number
  failCount: number
  errors: { row: number; column?: string; message: string }[]
}
```

- 三步（选文件 → 上传解析 → 结果 / 错误行）骨架与契约；占位态文件选择、模板 / 错误明细下载与提交**全部禁用**且不发请求；幂等键在选定文件时生成、重试复用、换文件重置（真实实现接入）。

#### 3.2.2 `ExportButton` 导出触发 <a id="export"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `biz` / `bizName` / `params` / `selectedIds` / `scope`（`filtered` / `selected`，缺省 `filtered`）/ `filenamePrefix` / `asyncThreshold` / `total` / `plain` / `disabled` / `degradeText` |
| 事件 | `export`（`{ biz, scope, params, selectedIds, plain }`）/ `retry` |
| 插槽 | `degrade` / `default` / `live` |

- 按当前筛选 / 排序取数（与列表、查询区同口径）、脱敏默认、超阈值转后台异步导出（经 `BaseAsyncTask`）；占位态按钮禁用、不触发下载。

#### 3.2.3 `FormDesigner` 表单设计器 <a id="designer"></a>

| 面 | 内容 |
| --- | --- |
| 数据面 | `ready`（缺省 `false`）/ `formCode` / `level`（`platform` / `tenant` / `role`，缺省 `tenant`）/ `roleId` / `readOnly` / `fields`（`DesignerField[]`）/ `layout`（`FormLayout`）/ `dirty` / `degradeText` |
| 事件 | `change`（`FormLayout`）/ `save`（`FormLayout`）/ `publish`（`FormLayout`）/ `reset` / `select`（`DesignerSelection \| null`）/ `add-field`（`{ fieldKey, sectionKey }`）/ `remove-field`（`{ fieldKey, sectionKey }`）/ `create-field` / `retry` |
| 插槽 | `degrade` / `empty` / `live` / `toolbar` / `field-panel` / `properties` |

```ts
export type DesignerLevel = 'platform' | 'tenant' | 'role'
export interface DesignerField {
  key: string
  label: string
  type: string
  group: 'platform' | 'tenant'
  disabled?: boolean
}
export interface DesignerSection {
  key: string
  title: string
  columns: 1 | 2 | 3
  fields: { key: string; colSpan?: boolean }[]
}
export interface FormLayout {
  main: { labelPosition: 'top' | 'left'; labelWidth?: number; sections: DesignerSection[] }
  query?: { fields: string[] }
  detail?: { columns: string[] }
}
export interface DesignerSelection {
  kind: 'field' | 'section'
  key: string
}
```

- 三区（字段面板 / 布局画布 / 属性面板）+ 工具栏骨架；拖拽经 `BaseDragDrop`（占位禁用）；平台默认层级 / `readOnly` 禁用编辑；画布经独立分包懒加载。

#### 3.2.4 `FormRenderer` 表单渲染器 <a id="renderer"></a>

| 事件 | `update:modelValue` / `change` / `submit` / `validate`（`{ valid, errors }`）/ `field-change`（`{ field, value }`）/ `retry` |
| 插槽 | `degrade` / `empty` / `live` / `actions` |
| 对外能力 | `validate()` / `getData()` / `setData(value)` / `reset()` / `submit()`（`defineExpose`） |

```ts
export type FormMode = 'create' | 'edit' | 'view'
export interface FormValidateResult {
  valid: boolean
  errors: { field: string; message: string }[]

```

- 元数据取数经 `BaseFormMeta`（占位零请求）；空布局按字段 `sort` 回退、未知字段跳过、权限优先（真实实现接入）；渲染主体经独立分包懒加载。

| 面 | 内容 |

| 事件 | `change`（`{ kind: 'message' \| 'key' \| 'locale'; value }`）/ `save` / `invalidate-cache` / `add-key` / `remove-key`（`key`）/ `add-locale` / `toggle-locale`（`{ code, enabled }`）/ `export` / `import` / `retry` |

```ts

  code: string

  rtl?: boolean

  key: string
```

### 3.4 契约套件 <a id="suite"></a>

复用 `describePlaceholderInteractionContract`（`08_01_01` 冻结）：未就绪 → 降级 + 禁用 + `requestCount === 0`（含 `load()`）；就绪 → 不再降级 / 禁用。五件真实实现继续跑同一套件。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未就绪时用户交互 | 只读 + 禁用，不发请求 |
| 未就绪时调用 `markLoaded()` | 不计数（防占位期误计） |
| 自定义降级内容 | `degrade` 插槽替换，默认降级文案可配 |
| 空数据（就绪态） | 渲染 `empty` 插槽 / 缺省空态（复用 `03_02` 口径） |
| 未传集合（`fields` / `messages` / `layout` 等） | 视为空集合（真实实现前不报错） |
| 平台默认层级 / `readOnly` | 设计器禁用拖拽与属性；渲染器强制只读 |
| 异步分包件加载失败 | 降级提示（真实实现补具体文案） |
| 未注入上传器 / 执行器 / 加载器 | 占位不请求、恒定返回（能力基类已有语义） |
