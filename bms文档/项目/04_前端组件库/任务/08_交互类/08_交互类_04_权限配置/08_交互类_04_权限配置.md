## 2. 任务内容 <a id="content"></a>

1. **权限配置**：菜单 / 表单 / 动作权限树与隐含推导、字段权限矩阵、动作数据范围、主体（角色 / 用户 / 岗位）绑定；权限树派生经树组件基类 `BaseTreeData`。
2. **提交与幂等**：全量覆盖提交与幂等（重复提交结果一致）；配置变更后前端权限上下文（`BaseAccess`）刷新。
3. **与后端契约一致**：与后端权限计算引擎契约逐字段对齐，避免前端展示与运行时判定偏差。
4. 以 `08_01` 冻结的对外契约替换数据通路，不改组件对外形状。

## 3. 完成标准 <a id="accept"></a>

权限树 / 矩阵 / 数据范围 / 主体绑定可用、隐含推导正确、提交幂等、上下文即时刷新；Vitest 覆盖推导与幂等分支；`vue-tsc`、ESLint、Vitest 全通过。
