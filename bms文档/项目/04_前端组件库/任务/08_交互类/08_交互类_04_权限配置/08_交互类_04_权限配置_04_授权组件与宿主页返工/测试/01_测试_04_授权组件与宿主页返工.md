## 5. 原型对照 <a id="prototype"></a>

- **原型依据**：《组件设计 · 权限配置》[可交互原型](../../../../../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_原型设计_权限配置.html)（菜单权限与表单权限的操作 / 字段配置、数据权限（字典结构化）、角色分配（用户分配内建 + mdm 插件）、全量覆盖提交与幂等、脏数据拦截）。
- **对照方式**：开发态核对页（`apps/desktop/permission-config-check.html`）在 1440×1000 视口截图，逐项比对原型结构。

| # | 对照项 | 原型 | 实现 | 结论 |
| --- | --- | --- | --- | --- |
| 1 | 四页签结构（菜单权限 / 表单权限 / 数据权限 / 角色分配） | 四页签 | 四页签齐备（总容器件） | 一致 |
| 2 | 菜单权限树（仅菜单入口，三态勾选） | 菜单树 | 仅菜单入口树 + 三态 + 勾选 | 一致 |
| 3 | 挂接缺失标记 | 未挂接 | 未挂接标记且禁用勾选 | 一致 |
| 4 | 菜单入口右侧权限码 / 字段子页签 | 权限码 / 字段 | 两子页签装配 | 一致 |
| 5 | 表单权限（含无入口表单） | 所有表单 | 表单列表含无入口标记 | 一致 |
| 6 | 字段权限默认全开与收窄 | 默认全开 | 默认全开、收窄项与批量 | 一致 |
| 7 | 数据权限四子页签（只选不编） | 选择 / 区域 / 匹配 / 扩展 | 四子页签（扩展未注册即隐藏） | 一致 |
| 8 | 角色分配（用户分配 + 计数） | 列表 + 选择用户 | 列表 + 选择用户弹窗 + 计数 | 一致 |
| 9 | 保存入口唯一（宿主工具栏） | 无组件内保存按钮 | 组件内不设保存，宿主工具栏调用 | 一致 |
| 10 | 授权条目类型 menu/form/permission（三词分治：原 `action` → `permission`，`target_id` 指权限码） | 授权类型三取值 | 契约与投影同步改为 `permission` | 一致 |

- **截图**：见 [权限配置核对页-四页签.png](资源/01_测试_04_授权组件与宿主页返工/权限配置核对页-四页签.png)。
- **整体结论**：实现与原型结构一致；未发现偏离项（角色管理页三页签空态已替换为真实组件）。
- **2026-10-10 三词分治对齐**（业务码 / 动作码 / 权限码）：授权条目类型由 `menu` / `form` / `action` 改为 `menu` / `form` / `permission`，`target_id` 指向平台库新实体 `sys_permission`（业务码 × 动作码组合）；本组件仅涉**数据契约取值改名**，界面结构、页签与交互**无可见变更**（故本条不改原型结构，仅登记契约同步）。

## 6. 覆盖率 <a id="coverage"></a>

- 八件组件与投影由 `interaction-permission.spec.ts` + 契约套件覆盖；宿主接入由 desktop 用例覆盖；覆盖率为任务内快照，门禁阈值以《[测试规范](../../../../../../../规范/测试规范.md)》为准。

## 7. 偏差与遗留 <a id="deviations"></a>

- 数据权限字典类型清单缺后端列表端点（数据权限页签空态）；表单名称后端无字段（以 `component` 兜底）；扩展权限注册清单本期空注册（归口后端）。
- 移动端实现未做（契约套件已就位供复用）。
