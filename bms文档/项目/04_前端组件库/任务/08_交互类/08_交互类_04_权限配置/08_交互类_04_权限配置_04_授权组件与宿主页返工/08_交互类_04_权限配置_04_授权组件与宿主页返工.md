# 04 授权组件与宿主页返工（新口径）

> 前端组件库 · 08 交互类 · 04 权限配置 · 嵌套子任务 04（需求 08-4；新口径返工）

> **本任务为返工**：`08-4-2` 交付的五件组件（授权总容器 / 权限树 / 字段权限矩阵 + 单元格 / 数据范围 / 角色分配）按**旧口径**落地；本任务按《组件设计 · 权限配置》新口径返工 `ui-ep` 组件与宿主接入（总容器件四页签、菜单权限件、表单权限件、权限码 / 字段权限面板、数据权限件、动态字典件、角色分配件），并把 RBAC 角色管理页「权限配置」区三页签空态替换为真实组件。

## 2. 任务内容 <a id="content"></a>

1. **投影返工**：`useBasePermissionConfig` 适配新口径四页签与来源判定（薄适配，判定逻辑全部在核心）。
2. **八件组件（新口径）**：授权总容器件（四页签装配 + 三接口顺序提交 + 脏数据）、菜单权限件（仅菜单入口树 → 权限码 / 字段子页签）、表单权限件（所有表单 → 权限码 / 字段子页签，补充授权）、权限码面板（表单动作码，默认无、来源只读）、字段权限面板（表单字段，默认全开、收窄、来源只读）、数据权限件（字典 → 选择 / 区域 / 匹配 / 扩展四 Tab，只选不编）、动态字典件（复用字典组件基类取数）、角色分配件（用户分配列表 + 选择用户弹窗 + 移除 + 计数；用户分配迁入 ui-ep）。
3. **宿主接入**：RBAC 角色管理页「权限配置」区改为消费 ui-ep 授权总容器件，移除三页签空态；`RoleAssignTab` 改为消费 ui-ep 角色分配件；补齐元数据与授权接口封装（菜单树 / 表单 / 字段 / 动作 / 字典 / 扩展注册 + 授权三接口 + 用户分配）。
4. **宿主核对页返工**：开发态核对页（`vite build` 不含）按新口径承载四页签、来源判定、连带撤销、数据权限结构、用户分配与三类幂等提交的上屏自检。
5. **原型对照**：按《组件设计 · 权限配置》[可交互原型](../../../../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_原型设计_权限配置.html)逐页截图比对（原型即验收基准）。

## 3. 完成标准 <a id="accept"></a>

八件可用、四页签结构齐备、来源判定与连带撤销正确、字段默认全开与收窄正确、数据权限四 Tab 只选不编与匹配校验可验证、用户分配可用；宿主角色管理页三页签空态替换为真实组件且与原型一致；核对页自检全绿；Vitest 覆盖推导、来源判定与幂等分支；`vue-tsc`、ESLint、Vitest 全通过。
