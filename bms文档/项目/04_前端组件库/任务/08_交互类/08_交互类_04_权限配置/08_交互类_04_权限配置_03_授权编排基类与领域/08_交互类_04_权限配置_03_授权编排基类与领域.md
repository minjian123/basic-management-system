## 2. 任务内容 <a id="content"></a>

1. **领域纯函数（新口径）**：菜单树（仅菜单入口）三态与父级级联、菜单连带表单查看与按来源撤销、表单 / 动作 / 字段授权与**来源判定**（`source_menu_id`，`0` = 表单级直接授予）、字段默认全开与收窄、数据权限（字典 × 策略 select / region / match / extension，只选不编）结构校验（匹配通配符 `*` `?` 与中英文 / 数字 / 下划线，越界 30047）、用户分配去重（不设上限）与全量覆盖载荷、三类提交载荷稳定序列化与脏基线、按类别派生幂等键、错误码 → 页签定位。
2. **授权编排能力基类（新口径）**：`BasePermissionConfig` 承载四页签状态（菜单 / 表单 / 数据 / 角色分配）、元数据装载、来源判定与只读标注、三接口顺序全量覆盖提交（permissions / fields / data-permissions）+ 用户分配差量提交、脏基线与撤销、权限上下文刷新（独立取码注入点，未注入不发请求）。
3. **契约套件（新口径）**：重写 `describePermissionConfigContract` 断言面（四页签 / 来源判定 / 连带撤销 / 数据权限结构 / 用户分配 / 三类载荷幂等），供 PC 与后续移动端复用。

## 3. 完成标准 <a id="accept"></a>

新口径领域推导（菜单三态与连带、来源判定、字段默认全开与收窄、数据权限结构与匹配校验、用户分配去重）正确；三类载荷与幂等键正确、脏基线与撤销正确；三接口顺序提交编排与用户差量提交可验证；未注入数据通路时不发请求（占位语义保持）；Vitest 覆盖推导、来源判定与幂等分支；`vue-tsc`、ESLint、Vitest 全通过。
