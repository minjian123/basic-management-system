## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    D["详细设计定稿（6 项确认）"] --> I["i18n container.fullscreenTip（双端）"]
    I --> F["FullscreenContainer（请求 / 降级铺满 / 状态同步 / 首次提示）"]
    F --> A["AutoHeight（父剩余空间 + RO 去抖 + 值比较）"]
    A --> R["AspectRatio（比例解析 / aspect-ratio + 降级 / fit）"]
    R --> X["frontend/packages/ui-ep/src/components/container/index.ts 扩展"]
    X --> M["frontend/apps/mobile 同接口多实现（契约套件同一套断言）"]
    M --> K["Kiwi 746 / 747 / 748 登记"]
    K --> U["用例三件（双端各 13 条）"]
```

结果小结：`FullscreenContainer`（`requestFullscreen` + `fullscreenchange` 同步（`isActive` 响应式缓存）；失败 / API 不可用降级固定铺满 + `fullscreen-error`；降级态 Esc；首次提示条 3 秒；`target` self / document / Element）、`AutoHeight`（父 `clientHeight` − `offset`，视口回退；`minHeight` / `maxHeight` 裁剪；RO 观察父元素 + 去抖 + 值比较；`scroll` 内部滚动消费滚动条令牌；`recalculate` / `height` / `el`）、`AspectRatio`（比例解析（数字 / `w/h` / 非法回退 + 告警）；`aspect-ratio` + `--bms-aspect-ratio-number`；`@supports` 降级；`fit` 媒体 `object-fit`；`maxWidth` / `minHeight`；占位插槽）落地。

## 3. 实施过程 <a id="process"></a>

1. 上下文：读三节点 §3 / §4 / §6 / §8；确认边界（大屏播放 / 媒体状态机 / 滚动行为均不内置）。
2. 决策确认（用户 6 项）：降级铺满 + 降级态 Esc / 内置提示条首次 / 父优先 + 视口回退 / 暴露三件 / `@supports` 降级 / `fit` 媒体作用域（见设计 §1 与 §10）。
3. 实现：i18n `container.fullscreenTip`；`FullscreenContainer.vue`（含 `isActive` 响应式缓存）；`AutoHeight.vue`；`AspectRatio.vue`；`index.ts` 扩展。
4. 双端同步：`frontend/apps/mobile` 同接口多实现落地（契约套件同一套断言）+ i18n 双端。
5. Kiwi 登记（`register_cases.py`）：**746**（全屏）/ **747**（自适应高度）/ **748**（宽高比）；双端用例三件（各 13 条）；双端全量门禁通过。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | `isFullscreen` 读取 `document.fullscreenElement` 恒定 false（视图不更新） | `document` 状态非响应式，computed 首次求值后缓存 | 增 `isActive` ref（`fullscreenchange` / 请求成功后显式同步）；设计 §4.1 + 对齐记录 7 |
| 2 | `aspect-ratio: 2` 断言失败（jsdom / 浏览器归一化 `2 / 1`） | CSS 值归一化 | 用例断言对齐归一化输出 |
| 3 | `AutoHeight` 挂到 `attachTo` 宿主后读不到宿主高度 | `@vue/test-utils` 在宿主内再包 `data-v-app` 容器，组件实际父元素是它 | 用例对**实际父元素**定义尺寸并 `recalculate()`（helper `mountAttached`）；RO 观察断言同 |
| 4 | `ROStub.instances` 跨用例残留（取到旧实例） | 用例未重置静态数组 | `beforeEach` 重置 |
| 5 | 全屏提示函数与 `showTip` prop 重名（lint `vue/no-dupe-keys`） | 命名冲突 | 改 `showEnterTip` |
| 6 | `AspectRatio` 降级样式无法经产物核对（组件未被页面引用，未进应用 CSS） | 构建产物只含入口可达模块 | 降级样式以源码断言为证；页面接入后回归（域 04 收口核对项）；设计对齐记录 9 |
