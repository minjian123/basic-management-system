## 2. 任务内容 <a id="content"></a>

1. `FullscreenContainer.vue`（`src/components/container/`）：全屏展示——`v-model`（`modelValue`）、`target`（`self` / `document` / `Element`）、首次进入提示（`showTip`，Esc 退出）、背景色消费令牌；方法 `enter()` / `exit()` / `toggle()`；事件 `update:modelValue` / `fullscreen-change`（状态同步）/ `fullscreen-error`（请求失败）；监听 `fullscreenchange` 同步状态；全屏内自适应重算（图表 resize）；需用户手势触发、iOS 元素全屏支持有限的降级说明。
2. **降级口径（确认）**：原生 `requestFullscreen` 不可用或失败 → **CSS 固定定位铺满视口**（降级态）+ `fullscreen-error` 事件；同一套退出 / Esc 逻辑覆盖两态（大屏 / 内嵌场景可复用）。
3. `AutoHeight.vue`（`src/components/container/`）：高度占满父剩余空间——`offset`（扣除头部 / 工具栏 / 边距）、`minHeight` / `maxHeight` 裁剪、`scroll`（内容超出时内部滚动）、`resizeDebounce`（默认 100ms）；ResizeObserver / 窗口 resize 重算，挂载后与内容变化后各重算一次（防 0 高度）；避免循环触发；移动端 `100vh` / 动态 `dvh` 注意地址栏收缩。
4. `AspectRatio.vue`（`src/components/container/`）：固定宽高比容器——`ratio`（默认 `'16/9'`，支持数字与 `'w/h'` 字符串）、`fit`（`fill` / `contain` / `cover` / `none`，映射 `object-fit` 或内层铺满）、`maxWidth` / `minHeight`、占位背景（令牌）+ 圆角；优先 CSS `aspect-ratio`、旧浏览器降级 padding-top 技巧；占位保证加载前后布局稳定（防抖动）。
5. **双端同款交付**：`apps/desktop/` 与 `frontend-mobile/` 同款（`diff -r` 无差异）。
6. 实现以《组件设计》「04 全屏容器」「05 自适应高度容器」「09 宽高比容器」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`，编号按登记回读）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

三件可用且可组合（全屏进入 / 退出 / 降级与状态同步；自适应高度重算 / 裁剪 / 内部滚动；宽高比占位防抖动与填充模式）；与滚动容器（`04-1`）配合正确；Vitest 覆盖全屏降级与状态同步、高度重算（ResizeObserver mock）、宽高比解析；`vue-tsc`、ESLint、Vitest 全通过；《组件设计》节点与《[前端基类清单](../../../../../前端基类清单.md)》相关登记回写同步。
