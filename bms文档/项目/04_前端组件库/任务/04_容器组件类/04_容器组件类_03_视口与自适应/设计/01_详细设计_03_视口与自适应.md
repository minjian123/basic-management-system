## 1. 概述 <a id="overview"></a>

本设计定义三件视口相关容器的实现契约与落点：`FullscreenContainer`（全屏 / 降级 / 状态同步）、`AutoHeight`（父剩余空间高度自适应 / 去抖重算 / 内部滚动）、`AspectRatio`（固定宽高比 / 填充模式 / 占位防抖动）；均继承容器能力 `container` 区域语义，双端（`frontend/apps/desktop` 与 `frontend/apps/mobile`）同接口多实现交付。

**确认口径（2026-09-16 启动确认）**：

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 全屏降级 | 根元素固定定位铺满（`background` 令牌 + 高 z-index）+ `fullscreen-error` 事件；状态同样切换（UI 一致）；**降级态自监听 Esc 退出**，真全屏由浏览器 + `fullscreenchange` 同步 |
| 2 | 进入提示 | 内置提示条（i18n 文案，约 3 秒自动消失），组件生命周期内**首次进入**显示一次；`showTip=false` 关闭；不依赖 EP / Vant（同接口多实现） |
| 3 | 自适应高度 | 高度 = 父元素可用高 − `offset`；父高不可测（0 / 无父）回退窗口视口高（`innerHeight`）；`ResizeObserver` 观察父元素 + 无 RO 回退 window resize；**去抖 + 值比较**（同值不写，防循环） |
| 4 | 高度暴露 | `recalculate()` / `height`（getter）/ `el` |
| 5 | 宽高比降级 | 主路径 CSS `aspect-ratio`；`@supports not (aspect-ratio: 1/1)` 降级 padding-top 技巧 + 内层绝对定位 |
| 6 | `fit` 作用域 | 经 CSS 作用于容器内媒体元素（`img` / `video` / `iframe` / `canvas` → `object-fit`）；普通内容默认铺满；样式变量 `--bms-aspect-ratio-fit` 可覆盖 |

## 4. 契约设计 <a id="contract"></a>

### 4.1 `FullscreenContainer` <a id="fullscreen"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `boolean` | `false` | 是否全屏（v-model） |
| `target` | `'self' \| 'document' \| HTMLElement` | `'self'` | 全屏目标（`self` 根元素 / `document` 文档根 / 指定元素） |
| `showTip` | `boolean` | `true` | 首次进入提示（Esc 退出提示条） |
| `background` | `string` | `var(--bms-color-bg)` | 降级铺满背景（令牌消费） |

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `update:modelValue` | `boolean` | 全屏状态（含降级态） |
| `fullscreen-change` | `boolean` | 状态变化（进入 / 退出，含 Esc 退出与降级） |
| `fullscreen-error` | `string`（原因） | 请求全屏失败（已降级铺满） |

| 方法 / 状态（`defineExpose`） | 说明 |
| --- | --- |
| `enter()` / `exit()` / `toggle()` | 进入 / 退出 / 切换 |
| `isFullscreen`（getter） | 当前是否全屏（含降级态；**实现调整**：真实全屏态经 `isActive` ref 由 `fullscreenchange` 缓存同步——`document.fullscreenElement` 非响应式，直接 computed 读取不会触发视图更新） |
| `isFallback`（getter） | 是否处于降级铺满态 |

- 请求链：`requestFullscreen()`（目标元素；`document` → `documentElement`）；`fullscreenchange` 同步状态（`document.fullscreenElement === 目标`）；失败 / API 不可用（`requestFullscreen` 缺失）→ 降级铺满 + `fullscreen-error`；
- 降级态：根元素加类 `bms-fullscreen-container--fallback`（`position: fixed; inset: 0; z-index: 2000; background: var(--bms-fullscreen-bg)`——经 style 写 `background` prop）；自监听 `keydown`（Esc）退出；
- 提示条：首次进入显示（i18n `container.fullscreenTip`），3 秒后自动隐藏；不阻断交互；
- 清理：卸载移除监听；若处于全屏 / 降级态则退出（防残留）。

### 4.2 `AutoHeight` <a id="auto-height"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `offset` | `number` | `0` | 需扣除高度（头部 / 工具栏 / 边距，px） |
| `minHeight` | `number` | — | 最小高度（px） |
| `maxHeight` | `number` | — | 最大高度（px） |
| `scroll` | `boolean` | `true` | 内容超出时内部滚动（`overflow: auto` + 滚动条令牌样式） |
| `resizeDebounce` | `number` | `100` | 重算去抖（ms） |

| 方法 / 状态（`defineExpose`） | 说明 |
| --- | --- |
| `recalculate()` | 手动重算（内容变化 / 兜底） |
| `height`（getter） | 当前计算高度（px） |
| `el`（getter） | 根元素 |

- 计算：`raw = parentElement.clientHeight || window.innerHeight`；`height = clamp(raw − offset, minHeight, maxHeight)`；
- 观察：`ResizeObserver` 观察**父元素**（无 RO → `window.resize` 监听）→ 去抖重算；
- 写入：`style.height` **值比较**（同值不写）；`scroll` → 类 `bms-auto-height--scroll`（`overflow: auto` + 滚动条令牌样式）；
- 时序：挂载后 `requestAnimationFrame` 重算一次（防 0 高度）；`offset` / 限制变更 `watch` 重算。

### 4.3 `AspectRatio` <a id="aspect-ratio"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ratio` | `number \| string` | `'16/9'` | 宽高比（数字或 `'w/h'`；非法回退 16/9 + 开发态告警） |
| `fit` | `'fill' \| 'contain' \| 'cover' \| 'none'` | `'cover'` | 媒体填充（映射 `object-fit`） |
| `maxWidth` | `number \| string` | — | 最大宽度（解析同 `resolveSize`） |
| `minHeight` | `number` | — | 最小高度（px） |

| 插槽 | 说明 |
| --- | --- |
| `default` | 内容（媒体 / 任意内容） |
| `placeholder` | 占位（默认占位背景块，消费令牌） |

- 比例：根元素 style 写 `--bms-aspect-ratio: w / h` 与 `--bms-aspect-ratio-number: <w/h 数值>`；主路径 `aspect-ratio: var(--bms-aspect-ratio)`；
- 降级：`@supports not (aspect-ratio: 1 / 1)` 时根元素 `position: relative` + 内层占位 `padding-top: calc(100% / var(--bms-aspect-ratio-number))`，内容层绝对定位（`inset: 0`）；
- `fit`：根元素类 `is-fit-<fit>`；样式作用于内容层媒体元素（`img` / `video` / `iframe` / `canvas`：`width/height 100%` + `object-fit: <fit>`）；`--bms-aspect-ratio-fit` 变量可覆盖；普通内容默认铺满；
- 占位：默认占位块背景消费令牌（`--bms-color-bg-page` / 圆角），内容加载前后布局稳定。

## 5. 行为与实现约定 <a id="behavior"></a>

| 项 | 实现 |
| --- | --- |
| i18n | `container.fullscreenTip`（zh `已进入全屏，按 Esc 退出` / en `Press Esc to exit fullscreen`；双端同键） |
| 令牌 | 全屏背景（`--bms-fullscreen-bg` 缺省引用 `--bms-color-bg`，经 `background` prop 可覆盖）；宽高比占位（`--bms-color-bg-page` / 圆角）；`AutoHeight` 滚动条复用 `--bms-scrollbar-*` |
| 无障碍 | 全屏容器 `role="region"`（可选 `aria-label` 透传）；提示条 `aria-live="polite"` |
| 移动端 | iOS 元素全屏支持有限 → 优先降级铺满；`AutoHeight` 父高不可测回退 `innerHeight`（地址栏收缩经 RO / resize 重算） |
| SSR / 无 API | `FullscreenContainer` 直接走降级；各件均不访问 `window` / `document` 于模块顶层 |

## 9. 边界与开放项 <a id="boundary"></a>

| # | 项 | 处置 |
| --- | --- | --- |
| 1 | 大屏播放逻辑 | 不内置（交互类「大屏设计器与播放」）；本件提供全屏容器 |
| 2 | 滚动行为 / 虚拟滚动 | 不内置（`ScrollContainer` / `VirtualList`）；`AutoHeight` 只提供定高与内部滚动 |
| 3 | 媒体加载状态机 | 不内置（媒体能力 `media`）；`AspectRatio` 只提供比例与占位背景 |
| 4 | 请求全屏被浏览器拒绝（无用户手势 / iframe 限制） | 降级铺满 + `fullscreen-error`；文档说明 |
| 5 | 全屏中路由跳转 | 退出全屏由使用方 / 路由钩子处理（文档说明）；组件卸载主动退出 |
| 6 | 嵌套自适应（父也是 AutoHeight） | RO 链式触发 + 去抖 + 值比较（防循环） |
| 7 | `aspect-ratio` 旧浏览器 | `@supports` padding-top 降级（设计 §4.3） |
| 8 | 全屏背景令牌 | `--bms-fullscreen-bg` 未登记为正式令牌（缺省引用基础色；随品牌化评估，对齐 04_02 覆盖点口径） |
