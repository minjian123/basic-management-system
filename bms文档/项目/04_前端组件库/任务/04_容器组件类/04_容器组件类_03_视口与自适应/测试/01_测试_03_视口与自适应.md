- 组件本体双端同款：`diff -r` 无差异（`src/components/container/` 与 i18n 增量）。
- Fullscreen API / `ResizeObserver` 在 jsdom 缺失：用例以 stub（`requestFullscreen` / `fullscreenElement` / `exitFullscreen` / `ROStub`）驱动全路径。
- `AspectRatio` 降级样式（`@supports not (aspect-ratio: 1 / 1)`）：组件尚未被页面引用（未进应用产物），以**源码核对**为证（`src/components/container/AspectRatio.vue:141`）；页面接入后回归（域 04 收口核对项）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `isFullscreen` 非响应（document 状态只读快照） | 组件改 `isActive` ref 缓存（见实施记录 §4-1） |
| 2 | `aspect-ratio` 断言未归一化 | 断言对齐 `2 / 1`（见实施记录 §4-2） |
| 3 | `attachTo` 宿主高度读不到 | 对实际父元素定义尺寸（见实施记录 §4-3） |
| 4 | `ROStub.instances` 跨用例残留 | `beforeEach` 重置（见实施记录 §4-4） |
