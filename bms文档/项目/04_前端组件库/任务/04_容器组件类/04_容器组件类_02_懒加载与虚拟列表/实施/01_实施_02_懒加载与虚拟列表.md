## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    D["详细设计定稿（7 项确认）"] --> S["size.ts（尺寸解析抽取，04_01 复用）"]
    S --> R["useVirtualRange.ts（前缀和 / 二分 / 视口）"]
    R --> L["LazyContainer.vue（IO + 占位骨架 + 缓存策略 + 降级）"]
    R --> V["VirtualList.vue（可视区 / 测量补偿 / 触底 / 定位）"]
    L --> X["index.ts 扩展 + types.ts（VirtualScrollMetrics）"]
    V --> X
    X --> M["frontend-mobile 同款（diff -r 无差异）"]
    M --> K["Kiwi 744 / 745 登记"]
    K --> U["用例两件（双端各 11 条）"]
```

结果小结：`LazyContainer`（IntersectionObserver + `rootMargin` 提前量；占位默认内置轻量骨架（可插槽替换）；`once` / `unmountOnLeave`（仅 `once=false` 生效）；IO 不可用降级直接渲染）与 `VirtualList`（泛型；统一前缀和可视区；`ResizeObserver` 逐项测量 + 缓存 + 补偿 / 无 RO 回退 `offsetHeight`；触底进入一次 / 离开重置；`scrollToIndex` pending / `scrollToTop` / `scrollToBottom` / `resetMeasurement`）落地；`useVirtualRange.ts`（只读注入 + 二分）；`size.ts` 抽取（`ScrollContainer` 复用）；双端同款。

## 3. 实施过程 <a id="process"></a>

1. 上下文：读节点《懒加载容器》《虚拟列表容器》§3 / §4 / §6 / §8；确认两件与既有件边界（图片懒加载归媒体片段 / 分页列表归通用表格）。
2. 决策确认（用户 7 项）：占位与 `minHeight`（按长期扩展择优：骨架 + 覆盖点）/ `#placeholder` 插槽 / RO 逐项测量 / 建议阈值 + scroll 触底 / 泛型 + 可视区参数 / `scrollToIndex` pending / 组合式拆分（见设计 §1 与 §10）。
3. 实现：`size.ts`（`resolveSize` 抽取，`ScrollContainer` 改共享，消除重复）；`useVirtualRange.ts`（前缀和 / `indexAt` / `scrollViewport` / `offsetOf`）；`LazyContainer.vue`；`VirtualList.vue`（测量注册、触底、定位、key 校验、auto 退化）；`types.ts` 扩展 `VirtualScrollMetrics`；`index.ts` 扩展。
4. 双端同步：`frontend-mobile/` 同款复制（`diff -r` 无差异）；测试公共 stub `tests/helpers/observers.ts`（`IOStub` / `ROStub`，04_01 用例同步改用）。
5. Kiwi 登记（`register_cases.py`）：**744**（懒加载容器）/ **745**（虚拟列表容器）；双端用例两件（各 11 条）；双端全量门禁通过。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | mobile 侧 `@/components/feedback` 不存在（`SkeletonBlock` 导入失败，容器件全部用例挂） | 域 03 空态件**仅 apps/desktop 交付**（双端同款约束冲突） | 懒加载默认占位改**内置轻量骨架**（消费基础色 / 圆角令牌，无跨域依赖）；`#placeholder` 插槽可传 `SkeletonBlock`；设计已回写（对齐记录 8） |
| 2 | RO 首屏元素未被观察（测量不生效） | ref 回调先于 `onMounted`，观察器创建时元素尚未注册 | `onMounted` 创建观察器后对已注册元素**补 observe**；设计 §4.4 已同步 |
| 3 | 缓冲项测量变化未补偿 `scrollTop` | 补偿基准误用 `startIndex`（含缓冲） | 基准改「可视区真实起点」（`indexAt(scrollTop)`，不含缓冲）；设计对齐记录 9 |
| 4 | `height="auto"` 分支渲染项无 `data-testid`（用例取不到） | 模板遗漏 | 补 `data-testid="virtual-item"`（degenerate 分支） |
| 5 | jsdom 无 `ResizeObserver` / `scrollTo` | 测试环境缺口 | 用例：`ROStub` 手动驱动测量；`scrollTo` 同步赋值模拟（同 04_01） |
| 6 | `scrollPosition.ts` `no-useless-assignment` lint 报错 | 变量在 catch 中重置被判无用 | 探测逻辑抽 `probeSessionStorage()`（返回 / 抛错二分），消除可变赋值 |
