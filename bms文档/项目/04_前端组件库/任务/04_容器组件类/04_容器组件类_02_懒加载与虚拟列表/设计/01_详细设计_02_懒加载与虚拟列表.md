## 1. 概述 <a id="overview"></a>

本设计定义 `LazyContainer`（容器组件类「懒加载容器」）与 `VirtualList`（「虚拟列表容器」）的实现契约与落点：视口懒渲染（占位防抖动 / 一次性 / 可卸载 / 降级）与大列表虚拟滚动（定高 + 动态高度测量缓存 / 缓冲 / 触底 / 滚动到索引）；双端（`frontend/` 与 `frontend-mobile/`）同款交付。

**确认口径（2026-09-16 启动确认）**：

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 懒加载占位 | **实现调整**：默认**内置轻量骨架**（双端同款、无跨域依赖——`SkeletonBlock` 属域 03 仅 frontend 交付件，移动端不可用）；`#placeholder` 插槽可传 `SkeletonBlock` 等正式件；`minHeight` 可选；占位高度覆盖点 `--bms-lazy-min-height`（暂不登记为正式令牌） |
| 2 | 占位自定义 | `#placeholder` 具名插槽（默认骨架；不引入形态枚举 props） |
| 3 | 动态高度测量 | `ResizeObserver` 逐项测量 + 缓存（`Map<key, number>`）+ 前缀和重建；`resetMeasurement()` 兜底；测量变化对可视区上方项做 `scrollTop` 补偿（防跳动） |
| 4 | 大列表阈值 | ≥1000 为**使用建议**（文档写明，组件不自动降级，行为可预期） |
| 5 | 触底检测 | scroll 计算（与虚拟滚动位置同源）；进入阈值一次 / 离开重置；`threshold` 容差默认 0 |
| 6 | 类型与事件 | `VirtualList` 为泛型组件；`scroll` 参数 `{ scrollTop, scrollHeight, clientHeight, startIndex, endIndex }` |
| 7 | `scrollToIndex` | pending 语义：数据未就绪时记忆目标索引，`items` 更新后自动定位一次 |

## 4. 契约设计 <a id="contract"></a>

### 4.1 `LazyContainer` Props / 插槽 <a id="lazy-contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `minHeight` | `number \| string` | — | 未渲染占位最小高度（数字按 px）；缺省由样式覆盖点 `--bms-lazy-min-height` 控制（可全局覆盖） |
| `rootMargin` | `string` | `'100px'` | 提前触发的视口边距（IO `rootMargin`） |
| `once` | `boolean` | `true` | 只渲染一次（渲染后不卸载） |
| `unmountOnLeave` | `boolean` | `false` | 离开视口卸载（仅 `once=false` 生效；否则开发态告警并忽略） |

| 插槽 | 说明 |
| --- | --- |
| `default` | 进入视口后渲染的内容 |
| `placeholder` | 未渲染占位（默认内置轻量骨架；可传 `SkeletonBlock` 等） |

- 降级：`IntersectionObserver` 不可用（SSR / 旧环境）→ **直接渲染**（不懒加载）；
- 边界：卸载后内部状态丢失（文档说明）；首屏内容应排除懒加载（使用建议）；
- 事件：无（保持设计节点契约）。

### 4.2 `VirtualList` Props / 事件 / 方法 / 插槽 <a id="virtual-contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `items` | `T[]` | `[]` | 数据源（泛型） |
| `itemHeight` | `number` | `40` | 定高项高（px） |
| `estimatedHeight` | `number` | — | 动态模式估值（px）；**传入即启用动态高度**（测量 + 缓存），缺省取 `itemHeight` |
| `buffer` | `number` | `5` | 上 / 下缓冲项数 |
| `keyField` | `string` | `'id'` | 项唯一键字段（重复值开发态告警一次） |
| `height` | `number \| string` | `'100%'` | 容器高度（数字按 px；解析同 `04_01`） |
| `threshold` | `number` | `0` | 触底容差（px） |

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `scroll` | `VirtualScrollMetrics`（`ScrollMetrics` + `startIndex` / `endIndex`） | 滚动（可视区变化；rAF 合并） |
| `reach-bottom` | `VirtualScrollMetrics` | 进入触底阈值一次 / 离开重置 |

| 方法（`defineExpose`） | 说明 |
| --- | --- |
| `scrollToIndex(index, options?)` | 滚动到索引（pending：数据未就绪时记忆，`items` 更新后自动定位一次） |
| `scrollToTop()` / `scrollToBottom()` | 到顶 / 到底 |
| `scrollTop`（getter） | 当前滚动位置 |
| `el`（getter） | 滚动容器元素 |
| `resetMeasurement()` | 清空动态高度测量缓存（内容集体变化后调用，随后重新测量） |

| 插槽 | 作用域 | 说明 |
| --- | --- | --- |
| `default` | `{ item: T, index: number }` | 列表项内容 |
| `empty` | — | 空数据占位（不传时渲染 `EmptyState` 缺省？否——保持最小：无插槽则不渲染占位） |

### 4.3 可视区计算（`useVirtualRange.ts`） <a id="range"></a>

```ts
export interface VirtualRangeOptions {
  itemCount: MaybeRefOrGetter<number>
  itemHeight: MaybeRefOrGetter<number>
  buffer: MaybeRefOrGetter<number>
  /** 动态模式（传入即启用高度缓存与前缀和） */
  measured?: MaybeRefOrGetter<Map<string, number> | null>
}

export interface VirtualRange {
  readonly startIndex: number
  readonly endIndex: number   // 不含（slice 语义）
  readonly offsetY: number    // 可视区起始项的前缀偏移（translateY）
  readonly totalHeight: number
  offsetOf(index: number): number
  indexAt(scrollTop: number): number
  setViewport(scrollTop: number, viewportHeight: number): void
  measure(key: string, height: number): number   // 返回高度增量（供 scrollTop 补偿）
}
```

- **统一前缀和路径（实现调整）**：`offsets[]`（长度 count + 1，估值兜底）——定高为「估值 = `itemHeight`」的特例（数值等价），不单设定高公式分支；
- **`indexAt`**：定高走公式（`floor(top / itemHeight)`），动态走二分查找（`offsets[i] <= top` 最大 i）；`offsetY = offsets[startIndex]`；`totalHeight = offsets[count]`；
- **scrollTop 补偿（实现修正）**：测量变化时，若「变化项索引 < 可视区**真实起点**（`indexAt(scrollTop)`，不含缓冲）」则在 `nextTick` 后执行 `scrollTop += delta`（含缓冲项在内的上方高度变化不跳动）；
- **API 定型**：`useVirtualRange` 的 `heights` 为**只读注入**（组件维护 `Map<key, height>` 缓存与测量）；纯逻辑不触 DOM。

### 4.4 测量策略 <a id="measure"></a>

- 渲染项经模板 ref 注册：`ResizeObserver` 存在时逐项 `observe`（`borderBoxSize[0].blockSize` 优先，回退 `offsetHeight`）；**首屏元素在 `onMounted` 补观察**（ref 回调先于挂载钩子，构建观察器后需回补）；不可用（jsdom / 旧环境）时更新后以 `offsetHeight` 测量；
- 测量值写入 `Map<key, number>`（键 = `String(item[keyField])`）；
- `resetMeasurement()` 清空缓存并触发重算（随后渲染项重新测量）；
- 可视区渲染项数量：`ceil(viewportHeight / itemHeight) + buffer * 2`（定高）/ 动态按估值滚动累计（实现取保守值）；
- 渲染容器 `translateY(offsetY)`；外层撑高元素 `height = totalHeight`（占位留白）。

## 5. 行为与实现约定 <a id="behavior"></a>

| 项 | 实现 |
| --- | --- |
| 滚动 | 根元素 `overflow: auto`；`scroll` 事件经 `requestAnimationFrame` 合并 → 更新可视区 + emit `scroll`（含可视区索引） |
| 触底 | scroll 计算（`scrollHeight - scrollTop - clientHeight <= threshold`）进入一次 / 离开重置；`reach-bottom` 参数含可视区索引 |
| 滚动条 | 消费 `04_01` 落地的滚动条令牌（`--bms-scrollbar-*`）；本件自绘同款规则（不依赖跨组件类名） |
| 空数据 | `items` 为空时渲染外层空态插槽（`#empty`，缺省不渲染任何占位；使用方可经 `EmptyState` 传入） |
| keyField 重复 | 渲染前校验（开发态告警一次，不中断） |
| 首屏与阈值 | 建议 ≥1000 条启用虚拟（文档写明）；小列表用普通渲染（反性能） |
| 高度 | `height` 默认 `'100%'`（父容器需定高）；`auto` 时退化为普通列表渲染 + 警告（虚拟滚动需确定视口） |
| 泛型 | `<script setup lang="ts" generic="T extends Record<string, unknown>">`；`keyField` 取值经 `String(item[props.keyField])` |
