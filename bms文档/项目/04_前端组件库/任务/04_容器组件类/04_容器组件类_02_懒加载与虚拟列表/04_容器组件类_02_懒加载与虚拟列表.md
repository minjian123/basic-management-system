## 2. 任务内容 <a id="content"></a>

1. `LazyContainer.vue`（`src/components/container/`）：进入视口才渲染——IntersectionObserver（`rootMargin` 默认 `100px` 提前量）、未渲染占位（`minHeight` 消费令牌 + 默认骨架，防布局抖动）、`once`（默认 true，渲染后不卸载）与 `unmountOnLeave`（离开视口卸载，需 `once=false`）、无 IntersectionObserver 环境降级为直接渲染；首屏内容应排除懒加载（口径写入设计）；图片懒加载与虚拟滚动不归本件（分别归媒体片段与 `VirtualList`）。
2. `VirtualList.vue`（`src/components/container/`）：大数据只渲染可视区 + 缓冲——`items` / `itemHeight`（默认 40，定高）/ `estimatedHeight`（动态高度估值）/ `buffer`（默认 5）/ `keyField`（默认 `id`）/ `height`（默认 `100%`）；只渲染可视区 + 上/下 buffer，空白占位撑高、DOM 数量恒定；**动态高度测量缓存**（渲染后测量并缓存，滚动位置补偿）；`scrollToIndex(i)` 方法、`scroll` / `reach-bottom` 事件（配合加载更多）；作用域插槽 `{ item, index }`；**启用阈值 ≥1000 条**（小列表普通渲染，误用反性能）。
3. 边界处理：动态高度测量抖动、`keyField` 重复、`scrollToIndex` 数据未加载时机、触底重复触发。
4. **双端同款交付**：`frontend/` 与 `frontend-mobile/` 同款（`diff -r` 无差异）。
5. 实现以《组件设计》「03 懒加载容器」「06 虚拟列表容器」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`，编号按登记回读）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

懒加载容器（占位防抖 / once / 卸载 / 降级）与虚拟列表（可视区计算 / 缓冲 / 动态高度 / 滚动定位 / 触底）可用且可组合；虚拟列表在大数据集下滚动流畅（DOM 数量恒定）；Vitest 覆盖可视区计算、动态高度缓存与触底；`vue-tsc`、ESLint、Vitest 全通过；《组件设计》节点与《[前端基类清单](../../../../../前端基类清单.md)》相关登记回写同步。
