## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：《组件设计》容器组件类「通用容器」八件——滚动容器（`ScrollContainer`）、懒加载容器（`LazyContainer`）、全屏容器（`FullscreenContainer`）、自适应高度容器（`AutoHeight`）、虚拟列表容器（`VirtualList`）、加载遮罩容器（`LoadingContainer`）、分区容器（`SectionContainer`）、宽高比容器（`AspectRatio`）。对应需求 [04-1](../../需求/04_需求_容器组件类.md#r04-1)。
- **归属说明**：该类的「弹窗抽屉表单」（设计节点 01）已按执行顺序前移至需求域 03（编号 `03-1`，2026-09-16 完成）；本域只承接其余八件（设计节点 02 ~ 09）。
- **公共前置**：容器能力片段 `useContainer`（域 02 `02_03` 已交付）；四态（加载 / 空 / 错误 / 内容）与占位防抖动复用需求域 03 的异常与空状态（`03-2` 已交付：`useFeedback` / `ErrorPage` / `EmptyState` / `SkeletonBlock` / `LoadingMask`）。
- **双端口径**：八件与端无关且移动端长列表 / 懒加载同样常见，**双端同款交付**（`frontend/` 与 `frontend-mobile/`，`diff -r` 无差异；口径同域 02）。
- **依据**：[前端组件库需求总览](../../需求/00_需求_前端组件库.md)、[容器组件类需求](../../需求/04_需求_容器组件类.md)、《[组件设计 · 总览](../../../../设计/组件设计/01_组件设计_总览.md)》、《[前端开发规范](../../../../规范/前端开发规范.md)》、《[前端基类清单](../../../../前端基类清单.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：25h（子任务 01 4h、02 10h、03 6h、04 5h）；其中 02 含虚拟列表动态高度测量 +3h。
- **关键依赖**：`01 → 02 → 03 → 04` 串行；02 的懒加载 / 虚拟列表复用 01 的触底与滚动语义（01 不内置虚拟滚动）；04 的 `LoadingContainer` 复用 `03-2` 的 `useFeedback` 与空状态件（2026-09-16 已交付）；八件全部消费 `useContainer` 容器片段与设计令牌（域 02 `02_03` / `03_06` 已交付）。
- **确认口径（2026-09-16 建任务）**：VirtualList 自研（定高 + 动态高度测量缓存 + `estimatedHeight`）；`ScrollContainer.keepPosition` 存储可注入（默认内存 Map，预留 `sessionStorage` 适配器接口）；`FullscreenContainer` 不可用 / 失败时降级为 CSS 固定定位铺满；用例先登记后编码、编号按登记回读（预计 10 ~ 14 条）。
- **登记项**：各设计节点的「需登记的上游变更」（滚动容器契约 →《布局设计 · 主框架》、令牌 →《布局设计 · 设计令牌》、性能契约 →《架构设计 · 前端架构》等）随实施逐个确认并由上游文档同步（对齐记录）。
