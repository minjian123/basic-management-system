## 1. 概述 <a id="overview"></a>

本设计定义 `ScrollContainer`（容器组件类「滚动容器」节点）的实现契约与落点：统一滚动区——固定 / 自适应高度、自定义滚动条、滚动位置保持、触底 / 触顶事件；继承容器能力 `container`（投影 `useContainer`）的区域语义，双端（`frontend/apps/desktop` 与 `frontend/apps/mobile`）同接口多实现交付。

**确认口径（2026-09-16 建任务 + 启动确认）**：

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 触底 / 触顶检测 | IntersectionObserver 哨兵元素（预提前量可配）；IO 不可用自动降级为 scroll 计算；进入阈值触发一次，离开后重置（防重复触发） |
| 2 | 自定义滚动条 | CSS 样式化原生滚动条（消费滚动条令牌）；`nativeScrollbar=true` 用系统默认；移动端隐藏自绘样式（媒体查询） |
| 3 | 位置保持 | `positionKey?: string` + 可注入存储 `createScrollPositionStore`（默认内存 Map；预留 `sessionStorage` 适配器）；无 key 时用组件 uid（仅当前挂载生命周期） |
| 4 | 方法与事件 | `scrollTo` / `scrollToTop` / `scrollToBottom` / `scrollTop`（getter）/ `el`；事件 `scroll`（含尺寸参数）/ `reach-bottom` / `reach-top` |
| 5 | 插槽 | `#header` / `#footer`（固定不滚动）+ 默认插槽（滚动区） |
| 6 | 令牌与上游 | 滚动条令牌增量入双端 `tokens.scss`；三项上游登记随实施回写上游文档 |

## 4. 契约设计 <a id="contract"></a>

### 4.1 `ScrollContainer` Props <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `height` | `number \| string` | — | 高度：数字按 px；字符串原样（含 `auto` 内容撑开） |
| `maxHeight` | `number \| string` | — | 最大高度（同上解析） |
| `nativeScrollbar` | `boolean` | `false` | `true` 用系统滚动条（不加样式化类） |
| `keepPosition` | `boolean` | `false` | 保持滚动位置（切换 / 重挂载恢复） |
| `positionKey` | `string` | — | 位置键（标签键 / 路由 name 等）；缺省用组件 uid（仅当前生命周期） |
| `throttle` | `number` | `100` | 滚动事件节流（ms；`0` 不节流） |
| `threshold` | `number` | `0` | 触底 / 触顶阈值（px）：IO 预提前量（`rootMargin`）与 scroll 计算容差共用 |

### 4.2 事件 <a id="events"></a>

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `scroll` | `ScrollMetrics`（`{ scrollTop, scrollHeight, clientHeight }`） | 滚动（按 `throttle` 节流；leading + trailing） |
| `reach-bottom` | `ScrollMetrics` | 进入触底阈值触发一次；离开阈值后重置（可再次触发） |
| `reach-top` | `ScrollMetrics` | 同上（触顶） |

### 4.3 暴露方法（`defineExpose`） <a id="expose"></a>

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `scrollTo` | `(top: number, options?: ScrollToOptions) => void` | 定位（`options` 透传原生 `scrollTo`，可平滑） |
| `scrollToTop` | `(options?: ScrollToOptions) => void` | 回到顶部 |
| `scrollToBottom` | `(options?: ScrollToOptions) => void` | 到底部 |
| `scrollTop` | `readonly number`（getter） | 当前滚动位置 |
| `el` | `HTMLElement \| null` | 滚动容器元素（原始句柄） |

### 4.4 插槽 <a id="slots"></a>

| 插槽 | 说明 |
| --- | --- |
| `header` | 固定头（不参与滚动；长表单 / 详情场景） |
| `default` | 滚动区内容 |
| `footer` | 固定底（同上） |

### 4.5 位置存储（`scrollPosition.ts`） <a id="position-store"></a>

```ts
export interface ScrollStorage {
  getItem(key: string): string | null
  setItem(key: string, value: string): void
  removeItem(key: string): void
}

export interface ScrollPositionStore {
  get(key: string): number | undefined
  set(key: string, top: number): void
  remove(key: string): void
}

/** 默认内存适配器（Map；同会话内跨挂载保持） */
export function createMemoryScrollStorage(): ScrollStorage

/** sessionStorage 适配器（预留；本轮交付但不默认启用，前缀默认 `bms:scroll:`） */
export function createSessionScrollStorage(prefix?: string): ScrollStorage

/** 存储工厂：缺省经内存适配器；传入适配器即用（存储键 = `positionKey`） */
export function createScrollPositionStore(storage?: ScrollStorage): ScrollPositionStore
```

- 组件内 `keepPosition=true` 时：`onBeforeUnmount` / `positionKey` 变更前写入当前 `scrollTop`；挂载后与 `positionKey` 变更后恢复（`nextTick` + 内容高度就绪的重试一次，尽力而为）；
- 无 `positionKey` 时用组件 uid 作键（仅当前挂载生命周期内有效，语义为「同一实例内恢复」）。

## 5. 行为与实现约定 <a id="behavior"></a>

| 项 | 实现 |
| --- | --- |
| 高度 | 根元素内「固定头 + 滚动体 + 固定底」；滚动体样式：`height` / `max-height` 解析后落 style；`auto` 不设高度 |
| 滚动条 | 默认根加类 `bms-scroll-container--styled`（双端同名类名经 `useComponentBase` 的 `nsClass`）；样式消费令牌（`--bms-scrollbar-*`）；`nativeScrollbar=true` 不加类；移动端媒体查询（`max-width: 768px`）隐藏自绘样式 |
| 触底 / 触顶 | 双哨兵元素（滚动体顶部 / 底部，1px 不可见）；`IntersectionObserver`（`root` = 滚动体，`rootMargin` 用 `threshold` 扩展下方 / 上方）触发进入；离开即重置；IO 不可用（`typeof IntersectionObserver === 'undefined'`）降级 scroll 计算（`scrollHeight - scrollTop - clientHeight <= threshold` / `scrollTop <= threshold`） |
| 节流 | `scroll` 事件：leading 立即 + trailing 尾发（自实现 `setTimeout` 版，不引依赖）；`throttle=0` 直通 |
| 位置保持 | 见 §4.5；恢复在 `nextTick` 后执行（DOM 高度尚未就绪时以 `requestAnimationFrame` 重试一次） |
| 令牌 | 滚动条宽 / 缩略图 / 轨道 / 圆角 / hover 经 `--bms-scrollbar-*`（`tokens.scss` 增量；不引 EP / Vant） |
| 无障碍 | 滚动体 `tabindex="0"`（键盘滚动可达）+ `role="region"`（有 `aria-label` prop 时透传，本轮不加文案） |

## 9. 边界与开放项 <a id="boundary"></a>

| # | 项 | 处置 |
| --- | --- | --- |
| 1 | 虚拟滚动 | 不内置（归 `04_02` `VirtualList`）；本件只提供滚动区与触底事件 |
| 2 | 自适应高度 | 不内置（归 `04_03` `AutoHeight`）；二者配合：`AutoHeight` 定高 + 本件滚动 |
| 3 | 嵌套滚动穿透 | 不做全局拦截（`overscroll-behavior` 消费方按需设）；在文档头注释说明 |
| 4 | 内容异步导致位置恢复偏差 | 尽力而为（`nextTick` + 一次 rAF 重试）；登记为已知限制 |
| 5 | 触底重复触发 | 进入阈值一次 + 离开重置；「加载中」抑制由消费方控制（本件不接管业务态） |
| 6 | 平滑滚动 | `scrollTo` 透传 `behavior: 'smooth'`；降级为浏览器行为 |
| 7 | 滚动条令牌 | 本轮增量落 `--bms-scrollbar-*`；品牌化 / 暗色主题跟随主色任务再评估 |
| 8 | 移动端 | 触屏滚动 / 原生滚动条 / 上拉加载经 `reach-bottom` 一致；媒体查询隐藏自绘样式 |
