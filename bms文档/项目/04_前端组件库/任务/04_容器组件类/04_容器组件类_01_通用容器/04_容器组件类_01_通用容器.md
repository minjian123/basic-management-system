## 3. 任务内容 <a id="content"></a>

1. 八件通用容器由三个嵌套子任务承载：基础容器件（滚动 / 自适应高度 / 分区 / 宽高比）、能力容器件（全屏 / 懒加载 / 虚拟列表）、四态容器件（加载遮罩，四态复用 `03_02`）。
2. 八件均派生容器组件基类 `BaseContainer`（经尺寸能力基类 `BaseSized` 派生）；四态容器采用「内置轻量形态 + 插槽组合」口径（`empty` / `error` 插槽可传 `03_02` 的空状态 / 错误页）。
3. 能力缺失降级：全屏（`requestFullscreen`）、尺寸观测（`ResizeObserver`）、交叉观察器（`IntersectionObserver`）、宽高比（`aspect-ratio`）不可用时降级 padding-top / 直接渲染 / 不做观测，不抛错。
4. 虚拟列表为自研轻量实现（定高快路径 + 动态高度测量缓存）；不新增运行时依赖。
5. 视觉与交互对齐 Element Plus 与《布局设计》各节点，消费设计令牌。

## 4. 完成标准 <a id="accept"></a>

八项容器可用且可组合；虚拟列表在大数据集下滚动流畅；懒加载容器与分包策略协作正确；浏览器能力缺失降级生效；Vitest 覆盖关键行为（触底、四态、可视区计算）；`vue-tsc`、ESLint、Vitest 全通过。
