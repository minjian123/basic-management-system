## 1. 设计目标与范围 <a id="goal"></a>

四件基础容器：滚动容器、自适应高度容器、分区容器、宽高比容器。均派生容器组件基类 `BaseContainer`（经尺寸能力基类 `BaseSized`），经 `useBaseContainer` 投影挂链，消费设计令牌。

不在本期：虚拟列表 / 懒加载 / 全屏（嵌套 02）；四态容器（嵌套 03）；滚动容器的虚拟化（由虚拟列表容器承载）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `ScrollContainer` <a id="scroll"></a>

- **Props**：`height?`（缺省自适应父容器）、`maxHeight?`、`native?`（缺省 false，走 `el-scrollbar`）、`reachThreshold?`（触底阈值 px，缺省 24）、`keepPosition?`（缺省 true，路由 / 重建后恢复滚动位置）、`positionKey?`。
- **Events**：`scroll({ top, left })` / `reach-bottom`。
- **Slots**：默认（滚动内容）。
- 触底判定：`scrollTop + clientHeight >= scrollHeight - reachThreshold`（去抖，单次触底只触发一次直到再次离开）。

### 3.2 `AutoHeightContainer` <a id="auto-height"></a>

- **Props**：`offset?`（需扣减的头部 / 工具栏高度，数字或 CSS 长度）、`minHeight?`。
- 实现：父级 `flex` 列布局 + `min-height: 0` + `height: calc(100% - offset)`；不依赖 `ResizeObserver`（能力缺失时仍可用）。

### 3.3 `SectionContainer` <a id="section"></a>

- **Props**：`title?`、`collapsible?`（缺省 false）、`collapsed?`（`v-model`）、`bordered?`（缺省 false，无卡片外观）。
- **Events**：`update:collapsed` / `toggle`。
- **Slots**：`title` / `extra`（工具区）/ 默认（内容）/ `footer`。
- 折叠经 `BaseContainer`（`collapsible` / `collapsed` / `toggleCollapse`）。

### 3.4 `AspectRatioContainer` <a id="aspect-ratio"></a>

- **Props**：`ratio?: number`（宽 / 高，缺省 16/9）。
- 实现：优先 `aspect-ratio`；不可用时降级 padding-top 技巧（`padding-top: (1 / ratio) * 100%` + 绝对定位内容）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `el-scrollbar` 内容不足一屏 | 不滚动、不触发触底 |
| 滚动位置键缺失 | 不启用位置保持 |
| `offset` 非数字且非 CSS 长度 | 视为 0，开发态告警 |
| `ratio <= 0` 或非有限数 | 回退 16/9 |
| CSS `aspect-ratio` 不支持 | 降级 padding-top |
| 折叠态下挂载 | 直接以折叠态渲染，不播放动画 |
