## 1. 设计目标与范围 <a id="goal"></a>

三件能力容器：全屏容器、懒加载容器、虚拟列表容器。均派生容器组件基类 `BaseContainer`，能力缺失一律**降级不抛错**。虚拟列表为自研轻量实现（定高快路径 + 动态高度测量缓存），不新增运行时依赖。

不在本期：基础容器件（嵌套 01）；四态容器（嵌套 03）；表格 / 树虚拟化的复用抽象（随展示域与树域任务）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `FullscreenContainer` <a id="fullscreen"></a>

- **Props**：`modelValue?`（`v-model` 全屏态）、`target?`（缺省容器自身）。
- **Events**：`update:modelValue` / `change(active)` / `error(reason)`。
- Esc 退出（监听 `fullscreenchange` 同步状态）；`requestFullscreen` 不可用 → 降级视口铺满（`position: fixed; inset: 0`）并 `error('unsupported')`。

### 3.2 `LazyContainer` <a id="lazy"></a>

- **Props**：`rootMargin?`（缺省 `0px`）、`threshold?`（缺省 0）、`once?`（缺省 true）、`placeholderHeight?`（占位防抖动）。
- **Events**：`visible`。
- 进入视口后渲染默认插槽（`once` 为真后常驻）；`IntersectionObserver` 不可用 → 直接渲染。

### 3.3 `VirtualListContainer` <a id="virtual"></a>

- **Props**：`items: readonly unknown[]`、`itemHeight?`（给定则定高快路径）、`buffer?`（上下缓冲条数，缺省 4）、`estimatedHeight?`（动态高度模式下的估算值，缺省 44）、`height?` / `maxHeight?`。
- **Events**：`visible-change`（可视区变化回传起止索引）。
- **Slots**：默认，作用域参数 `{ item, index }`。
- 实现：外层滚动（`el-scrollbar`）+ 占位容器（总高 = 定高 × 数量 或 已测量高度累加）；可视区计算经 `useVirtualRange` 纯函数；动态高度以 `ResizeObserver` 测量并缓存（不可用时退化为估算高度）。
- 复用：与 `ScrollContainer` 同滚动语义（触底由宿主在列表外层监听）。

### 3.4 `useVirtualRange` <a id="use-virtual-range"></a>

```ts
computeVirtualRange(options: {
  scrollTop: number
  viewportHeight: number
  count: number
  itemHeight?: number
  buffer?: number
  offsets?: readonly number[]     // 动态高度模式的累计偏移
}): { start: number; end: number; offsetTop: number; totalHeight: number }
```

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `requestFullscreen` 不可用 / 被拒 | 降级视口铺满 / 保持原态并 `error` |
| Esc / 用户手势退出 | 同步 `modelValue` 与 `change` |
| `IntersectionObserver` 不可用 | 直接渲染（不做观测） |
| `items` 为空 | 渲染空占位（不报错），`visible-change` 不触发 |
| 动态高度项尚未测量 | 以 `estimatedHeight` 估算，测量后就地修正 |
| `ResizeObserver` 不可用 | 动态高度退化为估算（滚动仍可用） |
| `scrollTop` 超出总高 | 夹取到 `[0, totalHeight]` |
| 可视区跨越未测量项 | 以估算值参与计算，保证 `start` / `end` 单调 |

## 7. 边界与开放项 <a id="open"></a>

- 表格 / 树虚拟化复用 `useVirtualRange`（随展示域 / 树域任务）。
- 虚拟列表的滚动锚定（锚点补偿）随性能优化任务评估。

## 8. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | 虚拟列表实现 | 自研轻量（定高快路径 + 动态高度测量缓存），不引入第三方 |
| 2 | 虚拟列表 API | `items` + 插槽 `{ item, index }`；`itemHeight` 可缺省（自动测量） |
| 3 | 懒加载语义 | 进入视口一次后常驻（`once` 缺省 true） |
| 4 | 设计粒度 | 三份子设计之一（本文件） |
