## 2. 核对结果（逐件） <a id="result"></a>

| # | 容器 | 核对点 | 期望 | 实测（自检 / 截图） | 结论 |
| --- | --- | --- | --- | --- | --- |
| 1 | `ScrollContainer` | 固定头 / 底 + 样式化滚动条类 + 触底哨兵 | 2 哨兵；滚动条细样式（消费 `--bms-scrollbar-*`） | 哨兵 2；样式化类 true；令牌 8px；滚动条视觉细条；`scrollToBottom` 触底 1 次（去重生效） | ✅ |
| 2 | `LazyContainer` | 未进入视口占位骨架；进入后渲染 | 首屏视口外 → 骨架；视口内 → 内容 | 首屏：骨架 true / 已渲染 false；长图（进入）：骨架 false / 已渲染 true | ✅ |
| 3 | `VirtualList` | 可视区渲染（DOM 恒定）+ 撑高 + 定位 | 1000 行仅渲染 ≤30 项；撑高 40000px；`scrollToIndex(500)` 定位 | 渲染 13 项；撑高 40000px；跳转后首屏 502~508（含 buffer） | ✅ |
| 4 | `FullscreenContainer` | 降级铺满 + 提示条 + 状态同步 | 无手势 / 失败 → 固定铺满；提示「已进入全屏，按 Esc 退出」；`isFullscreen / isFallback` true | 视口铺满；提示条显示；状态 `true / true` | ✅ |
| 5 | `AutoHeight` | 父剩余高度 − offset + 内部滚动 | 桌面：父 316 − 40 = 276；内部滚动条可见 | 276（父 316 − 40）；滚动条细条；移动端 381（父 421 − 40，父高随 vw 适配） | ✅ |
| 6 | `AspectRatio` | 比例输出 + 占位 + 降级规则 | 比值 1.78（16 / 9）；占位块存在；`@supports not (aspect-ratio …)` 规则存在 | 比值 1.78；内联 `16 / 9`；占位块 true；**降级规则 CSSOM 检出 true** | ✅ |
| 7 | `LoadingContainer` | 四态 + delay + 三形态 | 首屏（delay 窗口内）无 loading；stage2 错误态 + 重试按钮；mask / skeleton / spin 三形态常显 | 首屏 loading 态 false（防闪烁）；错误态 + 重试按钮；三形态视觉齐（灰块 / 骨架条 / 旋转圈） | ✅ |
| 8 | `SectionContainer` | 轻量外观 + 折叠 + 令牌 | 无卡片边框；折叠后标题保留、内容移除；分隔线 / 档位内边距 | 折叠态 `true` 内容移除 / 标题保留；折叠开关箭头可用；分隔线与间距正常 | ✅ |
| — | 双端一致性 | 组件本体同接口多实现 | 契约套件同一套断言 | 同接口多实现 ✓；移动端滚动条按媒体查询隐藏（触屏原生）；令牌按 px→vw 适配（`8px → 2.13333vw`，设计稿 375 基准） | ✅ |

## 3. 遗留与去向 <a id="rest"></a>

| # | 项 | 说明 / 去向 |
| --- | --- | --- |
| 1 | 真实触摸设备（iOS / Android）的触屏惯性滚动、上拉加载手感、iOS 元素全屏限制 | **环境不可及**（本机无真机 / 模拟器）；已由浏览器层移动视口 + 逻辑同实现覆盖主要行为；真机抽查并入页面任务 / 移动端任务（届时一并回写） |
| 2 | `AspectRatio` 降级样式的**生产产物**回归 | 核对页为 dev 资产（不进应用产物）；降级规则已在 dev 层 CSSOM 检出；生产产物回归随页面（引用方）接入时复查（届时构建产物将包含组件 CSS） |
| 3 | 「全屏真实 API 成功路径」（非降级） | headless 无用户手势 → 走降级路径（已核）；真实浏览器的 API 成功路径经完整构建 + 人工点击复核（登记随页面任务） |
| 4 | 域 03 反馈件移动端本体 | 移动端任务（口径未变；容器件已按「内置轻量 + 插槽」零依赖交付） |
