## 2. 任务内容 <a id="content"></a>

1. `LoadingContainer.vue`（`src/components/container/`）：加载 / 空 / 错误 / 内容四态——`loading`、`mode`（`mask` 遮罩 / `skeleton` 骨架 / `spin` 转圈，默认 `mask`）、`delay`（默认 200ms，延迟显示防闪烁：快请求不显示加载态）、`empty`、`error`（`string | false`）、`minHeight`（占位）；**四态互斥优先级 `loading > error > empty > content`**，仅当前态渲染；`retry` 事件（错误态重试按钮，防重复点击、错误信息脱敏不泄露技术细节）；插槽 `default` / `loading`（自定义加载）/ `empty` / `error`；**复用 `03-2` 的 `useFeedback` 与 `ErrorPage` / `EmptyState` / `SkeletonBlock` / `LoadingMask`**（不重复实现四态件）。
2. `SectionContainer.vue`（`src/components/container/`）：轻量分区（标题 / 描述 / 工具区 / 内容 / 折叠，**无卡片外观**，与布局类「卡片」区分）——`title` / `description`、`collapsible` / `collapsed`（`v-model:collapsed`）、`divider`（标题下分隔线，默认 true）、`padding`（`none` / `small` / `default` / `large`，消费间距令牌）；折叠仅隐藏内容、标题保留，内容按需渲染；插槽 `title` / `extra`（工具区）/ `default` / `footer`；事件 `update:collapsed` / `collapse-change`；表单场景 >8 字段才分区（口径随表单渲染器落地）。
3. 边界处理：快速切换态竞态（delay 与最小显示）、`minHeight` 抖动、分区与卡片外观混淆、分区嵌套、标题过长。
4. **双端同款交付**：`frontend/` 与 `frontend-mobile/` 同款（`diff -r` 无差异）。
5. 实现以《组件设计》「07 加载遮罩容器」「08 分区容器」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`，编号按登记回读）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

四态容器（互斥优先级 / 延迟显示 / 重试 / 插槽自定义）与分区容器（折叠 / 工具区 / 令牌内边距）可用且可组合；四态件复用 `03-2` 不重复造件；Vitest 覆盖四态切换、延迟显示与折叠行为；`vue-tsc`、ESLint、Vitest 全通过；《组件设计》节点与《[前端基类清单](../../../../../前端基类清单.md)》相关登记回写同步。
