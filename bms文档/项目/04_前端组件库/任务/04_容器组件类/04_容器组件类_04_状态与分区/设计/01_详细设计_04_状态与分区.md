## 1. 概述 <a id="overview"></a>

本设计定义域 04 收官两件：`LoadingContainer`（四态加载容器——loading（mask / skeleton / spin）/ empty / error + retry / content）与 `SectionContainer`（轻量分区——标题 / 描述 / 工具区 / 内容 / 折叠）；双端（`frontend/` 与 `frontend-mobile/`）同款交付。

**确认口径（2026-09-16 启动确认 + 方案澄清）**：

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 四态依赖口径 | **内置轻量四态 + 插槽**：`mask`（半透明容器）/ `skeleton`（骨架条）/ `spin`（CSS 旋转圈）均内置（纯 CSS + 令牌，双端同款零依赖）；`empty` / `error` **以插槽为主**（frontend 页面可传入域 03 的 `EmptyState` / `ErrorPage` 获得完整视觉），缺省最小文本 + 重试按钮 |
| 2 | 方案澄清 | 原选择「移植域 03 反馈件到 mobile」经澄清**不可行于同款口径**（`EmptyState` / `ErrorPage` 含 `el-button` EP 专有依赖、svg 资源与 `@/api/error` + `useRequest` 依赖链；移动端移植后两端实现必然不同）——改选上条（同 04_02「内置轻量 + 插槽组合」先例）；域 04 工时保持 **25h**（`04_04` = 5h），反馈件移动端仍归移动端任务 |
| 3 | `spin` 形态 | 内置轻量旋转圈（CSS 动画，消费色令牌，居中显示） |
| 4 | `minHeight` / 重试 / 切换 | `minHeight` 缺省由样式覆盖点 `--bms-loading-min-height` 控制（不造正式令牌，同 04_02 口径）；`retry` 点击后按钮自锁（disabled）直到 `loading` 变化复位（防重复点击）；状态切换即时（仅 `delay` 防闪烁，不加最小显示时长） |
| 5 | 分区折叠 | 复用容器片段 `useContainer` 的折叠状态机（受控 / 非受控 + `collapse-change`）；折叠经 `v-if` 按需渲染，无高度动画（登记优化项）；`padding` 档位消费 `--bms-space-*`，分隔线消费 `--bms-color-border` |

## 4. 契约设计 <a id="contract"></a>

### 4.1 `LoadingContainer` <a id="loading"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `loading` | `boolean` | `false` | 加载中（经 `delay` 防闪烁后显示） |
| `mode` | `'mask' \| 'skeleton' \| 'spin'` | `'mask'` | 加载形态（内置实现） |
| `delay` | `number` | `200` | 延迟显示（ms；快请求不显示加载态） |
| `empty` | `boolean` | `false` | 空态 |
| `error` | `string \| false` | `false` | 错误信息（用户可读文本；缺省用 i18n `container.loadingFailed`） |
| `minHeight` | `number \| string` | — | 状态区最小高度（数字按 px）；缺省由 `--bms-loading-min-height` 控制 |

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `retry` | — | 错误态重试（点击后按钮自锁，`loading` 变化复位） |

| 插槽 | 说明 |
| --- | --- |
| `default` | 内容（content 态） |
| `loading` | 自定义加载态（优先于内置形态） |
| `empty` | 空态（推荐传入 `EmptyState`；缺省最小文本） |
| `error` | 错误态（推荐传入 `ErrorPage` 或自定义；缺省文本 + 重试按钮） |

- 四态互斥：`loading（延迟后）> error > empty > content`，仅当前态渲染；
- 状态区统一承载 `minHeight`（覆盖点样式 + `minHeight` prop 覆盖）。

### 4.2 `SectionContainer` <a id="section"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | `''` | 分区标题 |
| `description` | `string` | `''` | 描述（标题下小字） |
| `collapsible` | `boolean` | `false` | 可折叠（标题行显示折叠开关） |
| `collapsed` | `boolean` | — | 折叠态（v-model:collapsed；**不传为非受控**，传为受控） |
| `divider` | `boolean` | `true` | 标题下分隔线 |
| `padding` | `'none' \| 'small' \| 'default' \| 'large'` | `'default'` | 内边距档位（`--bms-space-*`：`0 / 2 / 4 / 6`） |

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `update:collapsed` | `boolean` | 折叠变化（受控回写） |
| `collapse-change` | `boolean` | 折叠变化（通知） |

| 插槽 | 说明 |
| --- | --- |
| `title` | 标题自定义（优先于 `title` prop） |
| `extra` | 工具区（标题行右，折叠开关左侧） |
| `default` | 内容（折叠时 `v-if` 不渲染） |
| `footer` | 页脚区（可选） |

- 折叠状态机复用 `useContainer`（受控判定：`collapsed` 静态传入与否；`onCollapseChange` 内 emit 两事件）；
- 折叠开关为内置 CSS 三角（无组件库依赖），`is-collapsed` 旋转；
- 外观轻量：无边框 / 阴影（与布局类「卡片」区分）；`padding` 映射片段档位（`small → compact`、`large → loose`）仅用于区域属性透传。

## 5. 行为与实现约定 <a id="behavior"></a>

| 项 | 实现 |
| --- | --- |
| 延迟显示 | `loading` 变 true 起 `delay` 后显示（期间转 false 则取消）；`delay=0` 即时显示；显示后转 false 即时隐藏 |
| 内置形态 | `mask`：状态区半透明底（`--bms-color-bg-page`）+ 居中 `#loading`/缺省空；`skeleton`：2 行骨架条（`--bms-color-border` 渐变闪动，与 04_02 骨架同视觉）；`spin`：CSS 旋转圈（边框动画，消费主色令牌） |
| i18n | `container.retry`（重试）/ `container.loadingFailed`（加载失败）/ `container.emptyText`（暂无数据），双端同款 |
| 重试自锁 | 点击后 `retryLocked = true`（disabled）；`watch(loading)` 复位 |
| 令牌 | 骨架 / 遮罩 / 分隔线 / 内边距 / 主色（spin），不硬编码 |
| 无障碍 | 状态区 `role="status"`（加载 / 空态）/ `role="alert"`（错误）；重试按钮原生 `button` + 文案 |
| 移动端 | 内置三形态与令牌同款；`padding` 档位可收紧（消费方按端传档） |

## 9. 边界与开放项 <a id="boundary"></a>

| # | 项 | 处置 |
| --- | --- | --- |
| 1 | 反馈件本体（空态 / 错误页 / 骨架 / 遮罩） | 不内置复制（域 03 件仅 frontend）；本件内置轻量形态 + 插槽组合（frontend 传件获完整视觉）；移动端反馈件归移动端任务 |
| 2 | 折叠高度动画 | 不做（`v-if` 按需渲染）；如需动画登记优化项 |
| 3 | 最小显示时长 | 不做（仅 `delay` 防闪烁）；快切换下加载态可能一闪而过（后续按需评估 `minShowTime`） |
| 4 | `collapsed` 受控切换 | 受控判定在挂载时静态确定（与片段一致）；动态切换需重挂载（文档说明） |
| 5 | 分区嵌套 | 支持（内边距叠加），文档说明层级建议 ≤ 2 |
| 6 | `--bms-loading-min-height` / 分区档位令牌 | 覆盖点未登记为正式令牌（同 04_02 口径，随品牌化评估） |
