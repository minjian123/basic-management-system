## 1. 设计目标与范围 <a id="goal"></a>

依赖后端的四类字段（字典 / 组织 / 文件 / 验证码）先交付**占位版**：**契约先行冻结**（Props / 事件 / 插槽 / 字段壳装配），占位态不发请求、禁用并降级提示；`06_04` ~ `06_07` 真实实现**只换数据通路、不改对外契约**。

不在本期：真实数据通路（字典 store / 组织接口 / 上传引擎 / 认证接口）、字段壳族组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `useFieldPlaceholder` <a id="placeholder"></a>

```ts
useFieldPlaceholder(options?: { ready?: boolean; disabled?: boolean }): {
  ready: Ref<boolean>
  degraded: Ref<boolean>        // !ready
  disabled: Ref<boolean>        // 件级禁用 ∨ 占位（占位必禁用）
  requestCount: Ref<number>     // 占位态必须保持 0
  setReady(value): void
  markLoaded(): void            // 仅就绪后计数
  value / setValue              // 受控值（经 useBaseInput）
}
```

### 3.2 四件组件契约（冻结） <a id="components"></a>

| 件 | 值类型 | Props（除通用） | Events | Slots |
| --- | --- | --- | --- | --- |
| `DictSelectField` | `string \| number \| (string\|number)[]` | `ready` / `options`（`06_06` 填充）/ `multiple` | `update:modelValue` / `change` | `degrade` |
| `OrgSelectField` | 同上 | `ready` / `options`（`06_05` 填充）/ `multiple`（缺省 true）/ `searchable` | 同上 | `degrade` |
| `FileUploadField` | `UploadFieldItem[]` | `ready` / `limit` / `maxSize` / `accept` | `update:modelValue` / `change` / `remove` | `degrade` / `live` |
| `CaptchaField` | `string` | `ready` / `kind`（`image` / `slider` / `sms`）/ `imageUrl` / `countdown` | `update:modelValue` / `change` / `refresh` / `send` | `degrade` |

- 通用：`modelValue` / `disabled` / `placeholder` / `degradeText`；全部标注 `data-ready` / `data-degraded`。
- **占位态**：`ready !== true` → `degraded=true`、`disabled=true`、不发请求；`degrade` 插槽可替换降级内容。
- **就绪态**：字典 / 组织渲染 `SelectInput`（选项由真实实现填充）；文件 / 验证码渲染 `live` 插槽或内置轻量形态。
- 组件名与对外契约**冻结**：`06_04` ~ `06_07` 只接入数据通路。

### 3.3 契约套件 <a id="suite"></a>

`describePlaceholderFieldContract(name, create)`（`@bms/core/testing`）断言：未就绪 → 降级 + 禁用 + `requestCount === 0`（含调用 `load()` 仍为 0）；`setReady(true)` → 不再降级且禁用解除。真实实现继续跑同一套件。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未就绪时用户交互 | 控件禁用，不产生请求 |
| 未就绪时调用 `markLoaded()` | 不计数（防占位期误计） |
| 自定义降级内容 | `degrade` 插槽替换，默认文案可配 |
| 文件列表移除（占位态） | 允许移除（本地值变更，不发请求） |
| `options` 未传 | 视为空选项（真实实现前不报错） |
| 就绪态切换 | 就近生效（受控值不丢） |
