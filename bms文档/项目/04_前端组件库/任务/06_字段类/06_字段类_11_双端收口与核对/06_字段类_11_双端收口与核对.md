## 2. 任务内容 <a id="content"></a>

1. **跨件一致性收口**：核对本域各件的受控 `modelValue` / `update:modelValue`、三态、`disabled` 合并、`change` 上报、校验触发、字段壳装配（label / 必填 / 错误 / 栅格）、只读回显（`disabled` 或纯文本）、大小与密度——均经 `06_01` 公共口径与域 05 输入域包装定义一次，无逐件重复实现；`ui-ep` / `ui-vant` 同一套契约断言复核（契约套件全绿）。
2. **原型逐节点对照（原型即验收基准）**：12 个《组件设计》字段类节点与 12 份可交互原型逐项对照（交互与视觉），双端含移动视口抽查；核对结论落《测试/02_收口核对_字段类.md》，作为 M4「原型一致」验收点证据（体例参照域 04 / 05 收口核对记录）。
3. **回补口径复核**：核对回补四件（`07` ~ `10`）确与 `06_01` 骨架对外契约一致（只换数据通路）；mock 用例覆盖与「真实接口联调」遗留清单完整（逐条归口阶段六 / 七 / 八）。
4. **门禁复核（双端各自执行）**：`npx prettier --check`（仅本域文件）、`npm run lint`（含包级 ESLint）、`npx vue-tsc -b`、`npm run test:cov`（阈值 70%）、`npm run build` + `npm run budget`（含编辑器内核分包与预算重估值）；覆盖率与体积预算实测值回写测试记录。
5. **索引与登记回写**：《[前端基类清单](../../../../../前端基类清单.md)》输入域节与《[前端开发规范](../../../../../规范/前端开发规范.md)》继承链 / 体积预算终稿回写；12 节点「需登记的上游变更」逐项确认结果核对（无漏项，未闭环项归口）。
6. **用例与域收口**：本条 1 条 Kiwi 用例（先登记后编码，自动化标注 `kiwi_id`，双端同号，770）；域收口说明回写父任务与[计划](../../../计划/01_计划_前端组件库.md)（工时、状态、偏差与遗留），需求 06-1 ~ 06-7 状态按实施结果回写。
7. **遗留归口登记**：真实接口联调（认证 / 组织 / 字典 / 文件）、真机触摸项（软键盘、触控尺寸、上传选择器）、编辑器内核替换适配等，写入实施记录「偏差与遗留」并回写计划 §3.1 归口表。

## 3. 完成标准 <a id="accept"></a>

跨件一致性核对完成（受控 / 三态 / `disabled` / 校验触发 / 字段壳装配口径一致，无逐件重复实现）；12 节点原型逐项对照记录成文；回补四件契约一致性复核通过、遗留清单完整归口；双端门禁（`prettier` / ESLint / `vue-tsc` / Vitest / 构建与预算）全绿且实测值留痕；基类清单与规范回写同步；域 06 父任务与计划收口回写完成，需求 06-1 ~ 06-7 状态按结果回写。
