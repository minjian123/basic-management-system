## 2. 任务内容 <a id="content"></a>

1. **日期族五件（按设计节点全交）**：`DateField`（日期）、`DateTimeField`（日期时间）、`TimeField`（时间）、`DateRangeField`（日期区间）与值模型工具 `useDateValue`——统一派生域 05 输入域包装，受控 / 三态 / 校验触发不重复实现。
2. **时区与格式化契约**：值模型与展示分离，经 `locale` 能力（投影按需）与 `02_06` 格式化工具（`formatDateTime`）统一；只读回显口径（空值 `null` → `—`，区间缺边界的展示）；手输非法值不提交并回退；跨时区 / DST 纳入单测。
3. **双端形态**：PC 走 `el-date-picker` 家族（`type` 区分日期 / 日期时间 / 时间 / 区间）；移动端走 `van-date-picker` / `van-calendar`，值模型与 PC 同源。
4. **字段壳装配**：label / 必填 / 错误 / 栅格与只读两态经 `06_01` 公共口径装配，双端一致。
5. **用例**：本条 1 条 Kiwi 用例（双端同号，761）。
6. **实现以《组件设计》节点**「02 日期时间字段」及可交互原型为契约依据；偏离契约先改设计节点。
7. **上游登记清单（建任务时列出，随实施逐个确认并回写）**：用户时区（`sys_user.timezone`）、字段 widget 精度、自建字段类型、查询参数日期约定（该节点「依赖接口与上游变更」表）。
8. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

四类日期时间字段可用并按 locale / 时区正确展示；范围与格式校验生效；只读回显与空值口径统一；Vitest 覆盖格式化、空值与跨时区分支；契约套件双端断言全绿；`prettier --check`（仅本任务文件）、ESLint、`vue-tsc`、Vitest、构建与体积预算全通过。
