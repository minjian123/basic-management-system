## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：《组件设计》字段类 12 节点——字典字段、日期时间字段、数值与金额字段、树选择字段、组织选择字段、文件上传字段、富文本字段、开关与枚举字段、穿梭框、验证码、标签输入、级联选择。对应需求 [06-1 ~ 06-7](../../需求/06_需求_字段类.md)，共 7 条。
- **归属说明**：本域三处边界按设计节点口径确定（2026-09-17 建任务确认）——① `06_02` 日期族按设计节点交 5 件（含需求清单未列的 `DateTimeField` / `useDateValue`）；② `DeptTreeSelect`（部门树，与权限数据范围口径一致）归 `06_08` 组织选择；③ `06_05` 树与级联只交 `TreeSelectField` / `MenuTreeSelect` / `useTreeData` + `CascaderField` / `useCascader`。字典节点的两个高级查询件（`DictAdvancedQuery` / `DictQueryBuilder`，依赖 `query-scheme`）纳入 `06_09`。
- **公共前置**：域 05 输入域口径包装已交付（`05_01`：core `domain/input.ts` + `@bms/vue` `useInput` + 双插件 `BaseInput` 壳，Kiwi 756）——字段类各件统一派生输入域包装并装配字段壳，不重复实现受控 / 三态 / `disabled` 合并 / `change` 上报 / 校验触发 / 只读两态；能力契约已在 `frontend/packages/core/src/capabilities/` 类化（`field` / `input-control` / `field-shell` / `field-perm` / `option-source` / `tree-data` / `upload-engine` / `editor-kernel` / `presigned-url` / `user-display` / `query-scheme` / `locale`），`@bms/vue` 投影按需补建；契约套件 `@bms/core/testing`；框架无关核心重构 `02_07` 已于 2026-09-17 全链收口。
- **域包装口径（2026-09-17 建任务确认）**：需求 06-1 的占位版独立为首个子任务 `06_01`，一并交付**字段类公共口径**——字段壳装配（label / 必填 / 错误 / 栅格，消费 `field-shell` + `field-perm`）、只读回显（`disabled` 或纯文本，只读文本经 `displayText` 覆盖）、占位与降级语义（后端未就绪不发请求，呈现空态 / 禁用态 / 降级提示，与域 03 异常与空状态 `03-2` 反馈口径一致）、降级契约套件；受控绑定与校验触发复用域 05 输入域包装。
- **回补口径（2026-09-17 建任务确认）**：回补四件（`06_07` 验证码 / `06_08` 组织 / `06_09` 字典 / `06_10` 文件上传）**不入搁置、本域内全量实施**——按设计契约写完数据通路（含调用后端接口的代码），后端未就绪时以 mock 跑测；`06_01` 已交件的骨架与对外契约不变（同一件两段式迭代，不重建组件）。任务与需求状态均按「已完成」回写，「真实后端接口联调」登记为遗留并归口阶段六 / 七 / 八。
- **富文本内核口径（2026-09-17 建任务确认）**：按设计节点引入 `wangEditor` + `markdown-it` + `dompurify`（可选 `katex` / `prismjs`），经编辑器内核能力 `editor-kernel` 接入、编辑器内核**独立分包**且**内核可替换**（后续插件化的切换点，与域 08 代码编辑器共用同一能力）；包体积预算重估并回写《前端开发规范》§14。
- **双端口径**：各件双端同批同契约交付（`frontend/packages/ui-ep/src/components/field/` 与 `frontend/packages/ui-vant/src/components/field/`，契约套件同一套断言，Kiwi 双端同号）；移动端形态按设计节点（`van-picker` / `van-uploader` / `van-calendar` / 底部面板等），不引入移动端富文本编辑器。
- **依据**：[前端组件库需求总览](../../需求/00_需求_前端组件库.md)、[字段类需求](../../需求/06_需求_字段类.md)、《[组件设计 · 总览](../../../../设计/组件设计/01_组件设计_总览.md)》与字段类 12 节点、《[前端开发规范](../../../../规范/前端开发规范.md)》、《[前端基类清单](../../../../前端基类清单.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：110h（子任务 01 10h、02 8h、03 8h、04 10h、05 10h、06 18h、07 8h、08 10h、09 12h、10 12h、11 4h）；周期口径见[计划](../../计划/01_计划_前端组件库.md)。
- **关键依赖**：`01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11` 串行；`01` 交付字段类公共口径与占位件骨架（域内共同前置）；`04` 交付选项源投影（`useOptionSource`，供 `05` / `06` / `08` / `09` 复用）；`05` 交付树数据投影（`useTreeData`，供 `08` 复用）；回补四件（`07` ~ `10`）与 `01` 为同一件两段式（对外契约不变）；`11` 依赖前序全部交付；全部任务消费域 05 输入域口径包装（`05_01`）与设计令牌（`03_06`）。
- **上游登记（随实施逐个确认并由上游文档同步，建任务时只列待确认清单）**：① 各字段节点「依赖接口与上游变更」表（日期时间 / 数值与金额 / 树选择 / 组织选择 / 文件上传 / 富文本 / 验证码 / 标签输入 / 级联选择）→ 字段 widget 精度与组件类型白名单、用户时区、部门 / 菜单树接口、用户 / 岗位接口、文件分片与秒传接口、内容字段与白名单；② 各节点「需登记的上游变更」小节（开关与枚举 / 穿梭框 / 验证码 / 标签输入 / 级联选择各 3 条）→《概要设计 · 表单定制》《布局设计 · 表单页》《架构设计 · 数据架构》《安全开发规范》；③ 字典节点「需同步的既有设计」8 条（字典接口扩展与批量接口、`sys_dict_item.parent_id`、版本号机制、缓存与压测、高级查询接口、`sys_dict_attr` / `query_scheme` 表、界面定制、provider 注册）→《概要设计》《架构设计》相关章。
- **后续消费方**：阶段十五页面任务（表单 / 列表 / 详情）直接消费本域字段件；域 07 展示类（`RichTextViewer` 落 `components/display/`）、域 08 交互类（编辑器内核共用）与本域共用能力与件。
- **登记项**：《前端基类清单》「域基类（按需）」输入域节状态随本域交付同步回写；《前端开发规范》继承链与包体积预算随 `06` 富文本分包回写；各节点「需登记的上游变更」按上条清单随实施逐条确认。
