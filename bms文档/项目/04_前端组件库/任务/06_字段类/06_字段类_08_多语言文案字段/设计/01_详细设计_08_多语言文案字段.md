## 1. 设计目标与范围 <a id="goal"></a>

把各实体维护表单里写死的「中文名称 + 英文名称」两栏收敛为**一个通用字段件**：

- **字段恒占一行**——文本框就地编辑**必填语言**（＝当前登录用户语言；该语言未启用或为空时回退系统默认语言）的文案 + 一个**图标按钮**（悬停提示「多语言文案 · 已填 x / y」或「多语言文案 · 缺失：…」，字段标签不标注「多语言」）；
- **点开为多语言明细弹框**（**独立可复用件**，所有多语言场景共用）——明细表（语言 / 文案两列行内编辑）+ 系统默认语言 / 必填语言标记 + 语言关键字 / 仅看缺失 / 仅看已填筛选；弹框内为**草稿**，确定回写字段、取消丢弃并二次确认；
- 语言行由**启用语言清单**驱动：加语言即多一行，界面与接口契约都不随语言增减而变化；其余语言可缺省并按默认文案回退，停用语言存量值随提交透传；
- **落库随宿主工具栏「保存」**，弹框内不直接提交。

**不在本期（登记为上游待办）**：语言清单自身的增改启停与默认语言标记维护（国际化管理模块）、启用语言只读出口 `GET /api/v1/i18n/locales/enabled`、`sys_i18n_locale.is_default` 表结构与迁移——三项随未来「国际化管理」阶段落地，本任务只做设计登记（见第 11 节）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
type I18nNames = Record<string, string>            // locale → 文案（整体提交，含停用语言存量值与默认语言）
type LocaleItem = { code: string; name: string; isDefault: boolean; rtl?: boolean }

// 字段外壳
props: modelValue / required / disabled / readonly / multiline / maxLength / placeholder
events: update:modelValue / change / invalid(message)

// 明细弹框件（独立件，可单独复用）
props: modelValue / locales / requiredLocale / defaultLocale / multiline / maxLength / visible
events: update:modelValue / update:visible / confirm / cancel

// 语言清单通路（注入面；未覆写即占位零请求）
interface I18nLocaleSource {
  loadEnabledLocales(): Promise<readonly LocaleItem[] | undefined>
  currentUserLocale(): string | undefined
}
```

- **值语义**：`modelValue` 为「locale → 文案」**完整映射**（含默认语言与停用语言存量值，均**一次整体提交**），不按语言拆分事件、不为每个语言发起请求。
- **必填语义**：必填语言由 `resolveRequiredLocale(locales, userLocale)` 解析——当前登录用户语言在启用清单内即取该语言，否则取系统默认语言；`required` 为真时其文案为空即 `invalid`，事件附带目标语言标识供宿主定位与提示。
- **缺省语义**：非必填语言为空**不触发** `invalid`；仅参与缺失派生与占位提示，回退由展示与下发侧统一处理（字段**不合成**回退值）。
- **默认文案归属**：主表默认文案列（如 `sys_menu.name`）**不由界面提交**，由服务端按「系统默认语言 → 必填语言 → 首个有值语言」**优先级兜底派生**；界面只提交映射。
- **停用语言**：不进语言行，但其存量值保留在映射内并随提交透传（避免「界面未展示即被清空」）。
- **只读态**：字段外壳按当前界面语言回显单值；无值时沿回退链（当前语言 → 系统默认语言 → 映射中首个有值语言）。
- **长度上限**：按 Unicode 码点计（与平台固定文案编辑器同口径），超限截断并提示。

## 4. 核心领域纯函数 <a id="domain"></a>

| 函数 | 语义 |
| --- | --- |
| `normalizeLocaleItems(list)` | 清单归一：code 小写归一、去重、状态归一、默认标记收敛（**恰好一条**，缺失或重复视为清单异常） |
| `resolveRequiredLocale(locales, userLocale)` | 必填语言解析：用户语言在启用清单内 → 该语言；否则 → 系统默认语言 |
| `resolveDefaultLocale(locales)` | 系统默认语言 = 清单默认标记所在语言（无标记返回空并由上层快速失败） |
| `orderLocaleRows(locales, requiredCode)` | 语言行排序：必填语言恒置顶，其余按清单序 |
| `deriveMissingLocales(names, locales, requiredCode)` | 缺失集合（启用语言中值为空者），必填语言缺失单列 |
| `resolveDisplayText(names, uiLocale, defaultCode)` | 回退链：当前语言 → 系统默认语言 → 首个有值语言 → 空 |
| `buildSubmitPayload(names, locales)` | 提交载荷：启用语言可见值 + 停用语言存量值（透传） |
| `validateI18nNames(names, requiredCode, maxLength)` | 变更集校验：必填语言非空、长度上限（码点）、值类型 |
| `deriveDefaultText(names, systemDefaultCode, requiredCode)` | **与服务端同口径**的派生预览（系统默认语言 → 必填语言 → 首个有值语言），供宿主提示与双侧一致性断言 |
| `pickFallbackHint(names, code, …)` | 明细行占位提示：该语言为空时给出回退目标文案 |

- 纯函数零依赖、无副作用，不与 Vue 响应式耦合；`deriveDefaultText` 与服务端派生规则**共用一个用例表**（同一组输入 → 期望输出），前端预览与后端落库结果据此对齐。

## 5. 语言清单通路（注入式） <a id="locales"></a>

| 项 | 设计 |
| --- | --- |
| 插件基类 | `BaseI18nLocaleSource`（父 `BasePlaceholderState`，插件键 `i18n-locale`）：`loadEnabledLocales()` / `currentUserLocale()`；**未覆写即返回 `undefined`**（占位：零请求、字段外壳仅必填语言可编辑并提示） |
| 注册项 / 注册表 | `I18nLocaleSourceProvider` / `I18nLocaleSourceRegistry`（能力键登记入《前端基类清单》） |
| HTTP 内建 | 默认键 `http`：`GET /api/v1/i18n/locales/enabled`（**登录即可**，见第 11 节待办①）+ 当前登录用户语言取自会话上下文 |
| 缓存 | 语言清单按会话缓存（内存 + 宿主缓存钩子）；语言清单变更后由宿主失效重取；`currentUserLocale()` 每次读会话值 |
| 降级 | 取数失败：置占位态、字段外壳仅必填语言可编辑、明细弹框入口置灰并提示，**不阻断其它字段录入**；**不静默回落为「仅 zh-CN」**（避免误判为单语言系统） |

## 7. 表单渲染协同 <a id="render"></a>

- 语义键成对新增：`i18n-name`（单行）/ `i18n-text`（多行），在渲染器分发表内联 dispatch 并补类型守卫与单测。
- `FieldRenderAttrs` 透传：`multiline`（形态）、`maxLength`（码点上限）——沿用「多选语义单一来源」口径，不在字段内二次判断。
- 宿主核对页（`?source=http` / 占位两态）：12 项自检（语言增减后行数变化、必填语言缺文案被拒、缺省回退提示、停用语言透传、弹框草稿确定 / 取消、筛选三态、只读回退链、清单取数失败降级）。

## 9. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 必填语言文案为空 | 前端 `invalid` 阻断并定位（提示目标语言），服务端按请求语言拒绝（402xx 段） |
| 必填语言不在启用清单（用户语言停用） | 必填语言回退系统默认语言，字段提示当前必填语言为系统默认语言 |
| 清单默认标记缺失或重复 | 快速失败并提示（**不静默取第一条语言**），对应 44006（上游待实现） |
| 启用语言新增后存量记录缺该语言 | 明细行标「缺失」，字段悬停提示列出缺失语言；不阻断提交 |
| 停用语言存量值 | 不进语言行，随提交透传不丢值 |
| 语言清单取数失败 | 占位降级：仅必填语言可编辑、弹框入口置灰 + 提示，不阻断其它字段 |
| 弹框内有改动点取消 / 按 Esc | 二次确认（放弃 / 继续编辑） |
| 文本长度超上限 | 截断并提示（码点计） |
| 只读回退链耗尽 | 显示空值占位（不渲染空白阻塞） |
| RTL 语言 | 明细行与内层输入按 `rtl` 标记切换方向 |

## 12. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | 字段形态 | **字段恒占一行**：文本框就地编辑必填语言文案 + 图标按钮（悬停提示含完整度与缺失）；**不逐语言铺开**、字段标签不标注「多语言」（用户拍板 2026-10-10） |
| 2 | 明细编辑 | **多语言明细弹框**（独立可复用件）：明细表行内编辑 + 筛选（关键字 / 仅看缺失 / 仅看已填）+ 默认与必填标记 |
| 3 | 弹框与提交 | 弹框内为草稿，确定回写字段、取消丢弃并二次确认；**落库随宿主「保存」**，弹框内不直接提交 |
| 4 | 必填口径 | **必填语言＝当前登录用户语言**（未启用或为空时回退系统默认语言）；前端阻断 + 服务端按**请求语言**强制 |
| 5 | 主表 `name` 与附表 | **W**：附表承载全部语言（含默认语言）；主表 `name` 为服务端按**优先级兜底**（系统默认语言 → 必填语言 → 首个有值语言）派生的快照，写侧只提交映射 |
| 6 | 本任务代码边界 | 只收口已落地链路（platform 菜单元数据 + seed）；`is_default` 与启用语言出口随未来 i18n 阶段（第 11 节待办） |
