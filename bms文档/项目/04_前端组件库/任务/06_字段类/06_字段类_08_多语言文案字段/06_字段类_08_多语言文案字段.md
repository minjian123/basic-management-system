## 2. 任务内容 <a id="content"></a>

1. **核心领域**：`domain/i18n-name.ts`——语言清单归一（code / name / 默认标记 / RTL / 状态）、**必填语言解析**（当前登录用户语言，未启用或为空则回退系统默认语言）、语言项排序（必填语言恒首）、缺省回退链（当前语言 → 系统默认语言 → 派生默认文案）、缺失派生、提交变更集校验（必填语言非空、停用语言存量值透传）、文案长度按 Unicode 码点校验。
2. **语言清单通路（注入式）**：语言清单数据源插件基类 + 注册表（注入面为「取启用语言清单」与「当前登录用户语言」两个适配器，未覆写即占位零请求）；HTTP 内建适配器走登录即可的启用语言只读出口；按会话缓存、语言清单变更后失效重取；取数失败降级语义（仅必填语言可编辑 + 提示）。
3. **组件基类与件族**：组件基类 `BaseI18nNameField`（父 `BaseInput`；字段外壳装配 / 必填校验 / 缺省占位 / 只读回显 / 禁用）；件族三件——`I18nNameField`（单行外壳：文本框就近编辑必填语言文案 + **图标按钮**（悬停提示「多语言文案 · 已填 x / y」或「… · 缺失：…」，按钮不带文字、字段标签不标注「多语言」））、`I18nTextField`（多行外壳，内层为文本域）与 `I18nDetailDialog`（**多语言明细弹框，独立可复用件**：明细表语言 / 文案两列行内编辑、必填语言置顶、系统默认语言与必填语言标记、语言关键字与「仅看缺失 / 仅看已填」本地筛选、确定回写 / 取消丢弃 + 脏数据二次确认）。
4. **契约与投影**：契约套件 `describeI18nNameContract` / `describeI18nDetailContract`（同契约多实现：注入适配器 / 占位实现）；投影 `useBaseI18nNameField`；契约断言覆盖「语言增减后端字段形状不变」「必填语言缺文案被拒」「停用语言存量值透传」「弹框草稿确定回写 / 取消丢弃」。明细弹框件经容器组件类「弹窗抽屉表单」口径实现，可被任何多语言场景单独复用。
5. **表单协同**：表单渲染新增语义键 `i18n-name` / `i18n-text`（成对新增），`FieldRenderAttrs` 透传文案长度上限与形态（单行 / 多行）；渲染器内联 dispatch 与单测（分发表 + 类型守卫）。
6. **消费方改造**：菜单表单页、业务码表单页、动作码表单页、自定义图标表单页的名称字段与「表单定制 · 新建自定义字段」的字段名称入口，统一改用本件（去掉写死的「中文名称 / 英文名称」两栏与逐语言铺开）；原型同口径（已随设计层整改落地）。
7. **platform 菜单元数据收口（跨域项，本次唯一后端改动）**：写侧契约只收「locale → 文案」映射（默认文案列不再作为独立入参）、写侧按**优先级兜底**（系统默认语言 → 必填语言 → 首个有值语言）派生主表 `name`、读侧返回**含各语言的完整映射**并按请求语言校验必填语言非空；种子数据补「主表默认文案 ≡ 派生结果」一致性断言。
8. **测试与验证**：Vitest 覆盖必填语言解析（含未启用回退）、语言项排序、缺失派生、回退链、停用语言透传、变更集校验、下拉标签标记、只读回显、取数失败降级；护栏对账（挂链 / 单一落点 / 能力登记）；`06_01` 冻结契约用例不改动即通过。
9. **界面交付门禁**：原型整改属界面类交付，按《测试规范》跑界面类门禁脚本并留痕（本次由设计层整改先行落地，任务内以核对页方式复核形态）。

## 3. 完成标准 <a id="accept"></a>

组件契约套件通过；字段恒定一行（文本框就近编辑必填语言 + 明细弹框按钮），新增 / 停用语言后明细行随之增减而界面与接口契约不变（无写死语言栏、不逐语言铺开）；弹框内明细表行内编辑、筛选与标记生效，确定回写字段、取消丢弃并二次确认，落库随宿主「保存」（不在弹框内直接提交）；必填语言（＝当前登录用户语言，未启用则回退系统默认语言）为空时前端阻断、服务端按请求语言拒绝；缺省语言按回退链展示、停用语言存量值不丢；主表默认文案列按优先级兜底派生且与附表无两处漂移；表单渲染协同生效；Vitest 覆盖上列分支；`vue-tsc`、ESLint、Vitest 全通过；既有 `06_01` 冻结契约用例不改动即通过；platform 菜单元数据收口的定向用例通过。
