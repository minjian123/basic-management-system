## 2. 任务内容 <a id="content"></a>

1. **核心领域**：`domain/file.ts`——归一（兼容 snake_case）/ 校验（空文件 / 类型 / 大小 / 图片尺寸与比例）/ 上限截断 / 整包与分片模式决策 / 分片计划 / 进度聚合 / 元数据归一 / 增量 SHA-256（整文件 + 每片同源）/ 错误码文案（50101 ~ 50105）。
2. **上传引擎扩展（重挂占位语义）**：`BaseUploadEngine` 父基类改 `BasePlaceholderState`，新增任务队列、秒传（哈希 + 判定）、整包 / 分片编排、并发控制、断点续传（已传分片查询仅补缺失）、指数退避重试、进度聚合、取消在途与释放；既有 `uploader` / `upload` / `progress` / `cancel` / `abort` 语义**只增不改**（`08_05` 导入流保持）。
3. **预签名能力扩展**：`BasePresignedUrl` 向后兼容新增按文件标识 keyed 缓存、用途（预览 / 下载 / 直传）、提前刷新阈值、失效重取一次、并发合并与降级策略；无 key 旧调用行为不变（`07_03` 文件预览 / `08_08` 审批图保持）。
4. **组件基类与插件轨**：组件基类 `BaseFileUpload`（父 `BaseInput`；文件列表 / 校验 / 上限 / 排序 / 只读 / 进度 / 回显 / 预览下载）；上传通路插件基类 `BaseUploadTransport` + `UploadTransportProvider` + `UploadTransportRegistry`（注入面 `UploadTransportAdapter`，未覆写即占位零请求）。
5. **契约与投影**：契约套件 `describeUploadEngineContract` / `describeFileUploadContract`（同契约多实现）；投影 `useBaseFileUpload`、`useBaseUploadEngine` 扩展。
6. **件族（四件）**：`FileUploadField`（真实实现，保留 06_01 冻结契约；拖拽 / 进度 / 重试 / 取消 / 只读回显）、`ImageUploadField`（缩略图 / 多图排序 / 尺寸与比例校验 / 压缩 / 裁剪 / 头像圆形形态）、`FileListField`（只读文件列表：名称 / 大小 / 下载 / 预览 / 失效占位）、`ImageCropDialog`（cropperjs v2 裁剪弹窗：头像圆形与通用比例）。
7. **工具与单一落点**：`utils/uploadTransport.ts`（HTTP 内建通路，默认键 `http`）、`utils/fileHash.ts` + 独立哈希 Worker（整文件 / 每片 SHA-256，能力缺失降级主线程）、`utils/imageProcess.ts` + 独立图片 Worker（尺寸探测 / 压缩）、`utils/imageCrop.ts`（cropperjs v2 懒加载 + 独立分包）。
8. **协同与通道**：表单渲染协同（成对新增语义键 `file-upload` / `image-upload`、`FieldRenderAttrs` 增 `uploadAccept` / `uploadMaxSize` / `uploadLimit` / `uploadMultiple` 透传、多选语义单一来源）；设计令牌 `--bms-file-*`；宿主核对页 12 项自检（桩通路，无需后端）；`07_03` `FilePreview` 预览复用。
9. **测试与验证**：Vitest 覆盖分片与预签名失效分支（模式决策 / 并发 / 重试 / 断点 / 取消 / 回显 / 失效）；护栏对账（挂链 / 单一落点 / 令牌 / 能力登记）；`06_01` 冻结契约用例不改动即通过。

## 3. 完成标准 <a id="accept"></a>

上传与回显可用、分片与断点续传与后端契约一致（`02-4-18` 占位契约字段对齐；真实联调归阶段八）、失败重试与降级生效；图片件含压缩与裁剪且按原格式输出；表单渲染协同生效；Vitest 覆盖分片与预签名失效分支；`vue-tsc`、ESLint、Vitest 全通过；宿主核对页 12/12（桩模式）；既有 `06_01` 冻结契约与 `field-placeholder` 冻结用例不改动即通过。
