## 2. 任务内容 <a id="content"></a>

1. **取值改条目 `id`**：`BaseDictSelect` 受控值从条目 `value` 改为条目 `id`（字符串化雪花 ID）；`BaseDictStore` 的索引、缓存键、`labelOf` / `itemOf` 同步按 id。
2. **批量回显改 id 子集**：`BaseDictStore` 缺失回填参数由 `values` 改为 `ids`；字典列批量翻译、表单回显、级联父值同口径。
3. **字段类型改名**：`core/domain/form-render.ts` 的 `FIELD_WIDGET_MAP` / `FIELD_WIDGETS` 中 `select` → `option`、`multi_select` → `option_multi`；语义键与枚举组件映射同步。
4. **废弃兼容分支**：移除「`select` / `multi_select` 且带 `dictType` 优先分发字典件」逻辑；`dict` / `dict_multi` 仅按自身字段类型分发字典件。
5. **显示与容错**：`DictLabel` / 只读回显按 id 翻译，条目缺失或停用回显原始 id 并提示；导入导出模板与前端反查按 id。
6. **测试与联调**：契约套件、组件测试、表单渲染断言全量更新；与后端 `02-14` 真实接口按 id 端到端联调；覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

字典字段取值与回显全部按条目 `id`；`values` → `ids` 契约切换完成；旧「枚举字段 + 字典标识」分支删除；`option` / `option_multi` 映射生效；前端 lint / typecheck / test 全绿且覆盖率 100%；与后端同版本发布。
