## 2. 实施过程 <a id="process"></a>

```mermaid
flowchart LR
    A["决策确认（11 项）"] --> B["详细设计（定稿提交）"]
    B --> C["core 领域 / 能力换轨"]
    C --> D["ui-ep 控件与渲染协同"]
    D --> E["契约套件与用例更新"]
    E --> F["覆盖率门禁固化与验收"]
    F --> G["文档回写与提交"]
```

1. **决策确认**：受控值字符串化 + 提交序列化豁免、`dropdown` 语义键与字段属性 `widget` 覆盖、缓存键统一字符串 id、旧语义键彻底删除、覆盖率固化 `test:cov`、同窗次第发布、Kiwi 先登记、原型对照写「不适用」。
2. **core 换轨**：`domain/dict.ts` 条目按 `id` 归一（`id` 必填、`value` 缺失回落 `id`）、查找/合并/翻译/子集键/树节点值全部改 `id`、`DictTypeQuery.values → ids` 且线参数产出 `ids=1,2`（去重、空值剔除）；`capabilities/dict-store.ts` 子集回填改 `resolveIds`、子集缓存与合并按 `id`；`capabilities/dict-select.ts` 受控值/占位/候选保留/选项源值按 `id`，新增 `missingIds`（回填未命中集合，候选到达或失效/换类型时清理）；`capabilities/dict-query.ts` 取项选中值改 `selectedIds()`。
3. **字段分发**：`FormWidget` 增 `dropdown` / `dropdown-multi` / `button` / `segmented` / `tag`，删 `select` / `multi-select`；`FIELD_WIDGET_MAP` 中 `option → radio`、`option_multi → checkbox`；新增 `resolveFieldWidgetOf(type, override)` 支持字段属性 `widget` 覆盖（未登记回落默认）；新增 `collectDictIdPaths(plan)` 收集字典字段提交路径（主表 + 明细通配）。
4. **序列化豁免**：`domain/serialize.ts` 新增 `stringifyIntegerIds(payload, paths)`——命中路径的字符串 id 写成裸数字字面量，空串转 `null`，非法值抛错（文案含字段路径），未命中路径走标准 `JSON.stringify`。
5. **ui-ep 协同**：`formWidgets` 映射与多选集合改名；`FormRendererBody` 删除「枚举类型 + 字典标识」优先分发分支（只按 `dict-select` / `dict-multi`），新增枚举形态透传（`dropdown → select`、`button` / `segmented` / `tag` 直传）；`EnumMultiField` 新增下拉多选形态；`DictSelectField` / `DictLabel` / `DictCascaderField` / `DictAdvancedQuery` 全部按 `id` 取值与回显，并补未命中提示（`dict-missing-hint` / `data-missing`）；`QueryFilter` 类型与语义键改名。
6. **配置与核对页**：`@bms/core` / `@bms/ui-ep` 补 `test:cov`（`vitest run --coverage`）与 `@vitest/coverage-v8` 依赖；宿主 dev 核对页（`DictCheck` 桩补 `id` 并使用 `data-source-key`、`FormRenderCheck` / `DataDisplayCheck` / `FormDesignCheck` 样例类型改 `option`）。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 雪花 ID 63 位必超 JS 安全整数，`Number(id)` 会改数 | 受控值全程字符串；提交经 `stringifyIntegerIds` 写裸数字字面量（后端收到精确整数，契约零变更）；用例锁定 19 位 id |
| 2 | `missingIds` 初版按 `itemOf(id) === undefined` 判断，占位项入池后误判为命中 | 改为独立 `_missing` 集合：回填未命中记入、真实条目到达删除、换类型/失效清空；补三条用例 |
| 3 | `DictSelectField` 新增未命中提示 `<p>` 插在 `v-if / v-else-if` 链中间，打断条件链致降级态仍渲染下拉 | 提示节点移到整条分支链之后；`field-placeholder` 用例恢复通过 |
| 4 | 覆盖率固化时发现全包阈值被历史缺口卡死（84.72% 行 / 80.37% 分支） | 经确认改为「本次新增/修改代码 100%」口径：包级 `test:cov` 只出报告、不设全局阈值；整文件历史缺口登记遗留（见 §6） |
| 5 | 依赖外置仓在重装中断后留下不完整 Junction（`@bms/core` / `typescript` 解析失败） | 删除各包 `node_modules` 链接（仅删链接）后 `pnpm install --frozen-lockfile` 重建；`api-types` / `core` / `ui-ep` typecheck 恢复 |
| 6 | Windows 环境两个既有断言失败（`new URL(...).pathname` 前导斜杠、路径分隔符硬编码 `/`） | `shared-dependencies.spec.ts` 改 `fileURLToPath`；`guard-slot-host-isolation.spec.ts` 与 `interaction-style.spec.ts` 用 `join()` 比较；属环境适配，非本次口径 |
| 7 | 宿主核对页 `dict-type` 属性名与组件 `dataSourceKey` 不一致（既有） | 模板改 `data-source-key`，核对页可直接跑 |
