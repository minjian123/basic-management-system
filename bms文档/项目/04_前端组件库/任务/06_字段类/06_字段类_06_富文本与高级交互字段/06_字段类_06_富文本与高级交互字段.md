## 2. 任务内容 <a id="content"></a>

1. **富文本三件与清洗**：`RichTextField`（富文本编辑）、`MarkdownField`（Markdown 源码编辑）、`RichTextViewer`（只读净化渲染，落插件 `src/components/display/`，供域 07 展示类复用）；`useRichText`（消费编辑器内核能力 `editor-kernel`）、纯函数 `sanitizeHtml`（双向白名单清洗）与 `renderMarkdown`。
2. **安全口径**：白名单双向清洗（前端 DOMPurify + 后端白名单双重），禁止 `script` / `iframe` / `on*` 等；列表摘要不渲染 HTML；图片上传经上传引擎能力 `upload-engine`，文件后端未就绪时降级为占位。
3. **编辑器内核与分包**：按设计节点引入 `wangEditor` + `markdown-it` + `dompurify`（可选 `katex` / `prismjs`）；内核**经能力契约接入且可替换**（后续插件化的切换点，与域 08 代码编辑器共用 `editor-kernel`）；编辑器内核**独立分包**，包体积预算重估并回写《前端开发规范》§14。
4. **穿梭框**：`TransferField` + `useTransfer`（消费 `option-source`）——双列表穿梭、搜索、分组、分页 / 异步、数量上限（基于 `el-transfer` 定制）。
5. **标签输入**：`TagInput` + `useTagInput`（消费 `option-source`）——建议与自由新建、去重、数量 / 长度上限、颜色映射、粘贴批量。
6. **移动端口径**：只读渲染同一净化 HTML；编辑走 Markdown / 纯文本源码输入（不引入移动端富文本编辑器）；穿梭框与标签输入不复用（底部弹出多选面板 + `van-tag` chips）。
7. **用例**：本条 1 条 Kiwi 用例（双端同号，765）。
8. **实现以《组件设计》节点**「07 富文本字段」「09 穿梭框」「11 标签输入」及可交互原型为契约依据；偏离契约先改设计节点。
9. **上游登记清单（建任务时列出，随实施逐个确认并回写）**：富文本节点「上游接口与口径」与「新增前端依赖清单」；穿梭框节点「需登记的上游变更」3 条（主体绑定 / 模块开通用途、字段形态与只读口径、组件类型白名单扩展）；标签输入节点 3 条（组件类型白名单、标签值格式与选项来源、字段形态与只读口径）；《架构设计 · 性能与安全》安全相关节。
10. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

富文本 / Markdown / 只读渲染三件可用，XSS 双向清洗验证通过（白名单命中与绕过用例）；编辑器内核经能力契约接入、独立分包生效且内核可替换；穿梭框与标签输入可用（搜索 / 分组 / 上限 / 去重 / 粘贴批量）；移动端只读一致、编辑降级为源码；Vitest 覆盖清洗与交互分支；契约套件双端断言全绿；`prettier --check`（仅本任务文件）、ESLint、`vue-tsc`、Vitest、构建与体积预算（含内核分包）全通过，预算重估值回写规范。
