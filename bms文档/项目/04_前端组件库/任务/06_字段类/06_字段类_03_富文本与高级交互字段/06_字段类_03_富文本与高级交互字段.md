## 3. 任务内容 <a id="content"></a>

1. 三类均派生输入组件基类 `BaseInput` 并叠加相应能力基类（编辑器内核 / 上传引擎 / 选项源）。
2. 富文本白名单**双向**清洗（前端 DOMPurify + 后端白名单口径）；编辑器内核经 `BaseEditorKernel` 独立分包。
3. 图片上传经上传引擎能力基类 `BaseUploadEngine`，后端未就绪时按 `06_01` 占位语义降级。
4. Vitest 覆盖清洗与交互分支。

## 4. 完成标准 <a id="accept"></a>

三类字段可用；富文本 XSS 双向清洗验证通过；编辑器内核与上传引擎按能力契约接入；Vitest 覆盖清洗与交互分支；`vue-tsc`、ESLint、Vitest 全通过。
