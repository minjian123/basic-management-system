## 1. 设计目标与范围 <a id="goal"></a>

穿梭框：双列表穿梭（移动 / 全部移动）、搜索、分组展示、异步数据加载与数量上限；只读回显与空态复用 `03_02`。薄封装 `el-transfer`，件经 `useBaseInput` 挂链。

不在本期：分页加载（宿主按需分批传入）；字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
interface TransferItem { key: string | number; label: string; disabled?: boolean; group?: string }
type TransferValue = (string | number)[]

props: modelValue / data（或 load 异步）/ titles（[左, 右]）/ searchable
       / limit（最多选中数）/ load（() => Promise<TransferItem[]>）/ readonly
       / required / disabled / placeholder（空数据文案）/ errorMessage
events: update:modelValue / change / invalid / retry
```

- 值语义：**选中键数组**（右列表）。
- 异步：`load` 提供时挂载即请求；失败 → 错误态 + `retry`（保留已选）。
- 上限：右列表长度将超过 `limit` 时拒绝该次变更并 `invalid('最多选择 N 项')`（值不变）。
- 分组：`data[].group` 非空时在列表项渲染组名前缀（`renderContent`）。
- 只读：以标签列表回显选中项（缺标签时降级为键文本）。
- 校验：`required` 空值 → `invalid('该字段为必填项')`。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 异步加载失败 | 错误态 + `retry`；不清空已选 |
| 超过 `limit` | 拒绝变更 + `invalid`，值不变 |
| 数据为空 | 左右列表空态（`placeholder` 文案） |
| 选中键不在数据中（只读） | 降级为键文本回显 |
| `modelValue` 非数组 | 归一为空数组并告警 |
| `required` 空值 | `invalid('该字段为必填项')` |
