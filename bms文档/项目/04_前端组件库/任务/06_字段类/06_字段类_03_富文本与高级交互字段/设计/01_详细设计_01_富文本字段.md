## 1. 设计目标与范围 <a id="goal"></a>

富文本字段：**富文本 / 源码双模式**、只读渲染、**白名单双向 XSS 清洗**（前端 DOMPurify，白名单与后端一致）、编辑器内核经编辑器内核能力基类 `BaseEditorKernel` 承接、图片上传经上传引擎能力基类 `BaseUploadEngine`（后端未就绪时按 `06_01` 占位降级）。

不在本期：后端白名单下发与校验实现（衔接阶段八）；完整工具栏扩展（本期基础格式集）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
props: modelValue（HTML 字符串）/ mode: 'rich' | 'source' / readOnly
       / placeholder / minHeight / maxLength / uploadImage?(file) => Promise<string>
       / disabled / errorMessage
events: update:modelValue / change / invalid / upload-error
```

- 值语义：**已清洗的 HTML 字符串**；输入（编辑）与输出（对外派发）均过 `sanitizeHtml`。
- 双模式：`rich`（TipTap + StarterKit 基础格式）与 `source`（源码 textarea）；切换保留内容（均经清洗）。
- 只读：`readOnly` 渲染清洗后的 HTML（`v-html`），不可编辑。
- 图片：`uploadImage` 未提供或失败 → 降级（提示 + 不插入），复用 `06_01` 占位语义。
- 校验：`maxLength` 按**净化后纯文本长度**计；超限 → `invalid('最多 N 字')` 且不写值；`errorMessage` 外部覆盖。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 含脚本 / 事件属性的 HTML | 白名单清洗后去除（`script` / `on*` / `javascript:`） |
| 粘贴富文本 | 粘贴内容同样过清洗（TipTap 输入 → 输出前清洗） |
| 源码模式输入非法 HTML | 切换 / 派发前清洗并回写 |
| `uploadImage` 缺失或抛错 | 降级提示（`upload-error`），不插入 |
| 超 `maxLength` | `invalid` 且不写值 |
| 空内容 | 视为空值（`required` 时校验，随字段壳） |
| 编辑器内核加载失败 | 降级为源码模式并告警 |
