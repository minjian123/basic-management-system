## 1. 设计目标与范围 <a id="goal"></a>

标签输入：建议选择与自由新建、去重、数量与单个长度上限、颜色映射、粘贴批量解析、只读回显。实现为 `el-tag` + 自研输入壳（不引入第三方），件经 `useBaseInput` 挂链。

不在本期：远端建议搜索（宿主可传静态建议）；字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
props: modelValue（string[]）/ suggestions（静态建议）/ allowCreate（缺省 true）
       / max（数量上限）/ maxLength（单个标签长度上限）
       / colorMap（Record<string,string> | (tag) => string）/ readonly / required
       / disabled / placeholder / errorMessage
events: update:modelValue / change / invalid
```

- 添加途径：输入回车、建议项点击、**粘贴批量**（按逗号 / 分号 / 换行切分）。
- 去重：已存在标签不重复添加（大小写敏感全等）。
- 上限：数量超 `max` → `invalid('最多 N 个标签')` 且不添加；单个标签超 `maxLength` → `invalid('单个标签最多 N 字')` 且不添加。
- 空标签（全空白）忽略。
- 颜色：`colorMap` 为函数或映射表；未命中用默认（`info`）。
- 只读：仅标签回显，不可增删。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 重复标签 | 忽略（不触发 `invalid`） |
| 超数量 / 超长度 | `invalid` + 不添加 |
| 空白输入 | 忽略 |
| 粘贴含分隔符文本 | 批量切分后逐项按规则添加 |
| `allowCreate=false` 且非建议项 | 忽略（仅接受建议项） |
| 建议为空 | 不显示建议下拉 |
| `required` 空值 | `invalid('该字段为必填项')` |
