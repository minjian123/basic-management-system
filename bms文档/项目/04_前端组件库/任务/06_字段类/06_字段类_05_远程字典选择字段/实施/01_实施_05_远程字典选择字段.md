## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先行**：经容器内 Django shell 登记用例，取得编号 **962**（平台既有编号至 961）；新增用例文件首行标注 `// kiwi_id: 962`。
2. **选项源能力入值链（`capabilities/option-source.ts`）**：父基类由 `BaseComponent` 改 `BaseField`（`depends` 改 `['field']`），既有字段与方法（`options` / `loader` / `load` / `dataVersion` / `getLabel` / `search`）只增不改；`08_04` / `08_10` 消费方回归通过。
3. **用户展示能力扩展（`capabilities/user-display.ts`）**：向后兼容新增 `users` 花名册与 `setUsers` / `mergeUsers` / `clearUsers` / `findUser` / `displayOf`，`UserDisplayInfo` 新增可选 `deleted`；投影 `useBaseUserDisplay` 同步补花名册响应式面。
4. **核心领域纯函数 `domain/dict-data.ts`**：常量（`DICT_DATA_TARGETS` / `DICT_DATA_STATUSES` / 300ms 防抖 / 页长 / 缓存上限 / 折叠阈值 / 错误码文案）、数据模型（`DictDataOptionItem` / `DictDataDeptNodeNode` / `DictDataTreeNode`）与纯函数（归一（兼容 snake_case、脏项剔除、`exists=false` 已删除）、查询归一与线参数构造、批量回显参数（`target` + `id_in`）、分页解析、缓存键、选择与上限、已删除 / 停用标记、标签摘要、部门路径与树节点映射、错误码判定）。
5. **插件轨 `capabilities/dict-remote-source.ts`**：`BaseDictRemoteSource`（`BasePluggable`；四方法未覆写返回 `undefined` 即不请求）、`DictRemoteSourceProvider`（`BaseProvider`）、`DictRemoteSourceRegistry`（`BaseProviderRegistry`，同键拒重）；对应后端主数据出口 `/api/v1/mdm/{users,posts,dept-tree,resolve-names}`。
6. **组件基类 `BaseDictRemoteSelect`（`capabilities/dict-remote-select.ts`，父 `BaseOptionSource`）**：三类派发（用户 / 岗位 / 部门树）、关键词与部门 / 状态过滤、候选页码与总数、关键词结果短缓存（上限淘汰）、已选对象常驻、批量按 id 回显（单请求、未命中生成已删除占位）、多选去重与上限、缓存失效、错误码与竞态防护、用户展示花名册汇入与部门路径补全。**未就绪 / 未注入数据源零请求**（`requestCount` 恒 0，保持 `06_01` 冻结口径）。
7. **能力登记与导出面**：`manifest.ts` 新增 `dict-remote-select: ['option-source', 'user-display']`、`option-source` 依赖改 `['field']`；`core/src/index.ts` 新增领域、插件基类 / 注册表与组件基类导出；`core/testing/index.ts` 新增契约套件导出。
8. **契约套件 `describeDictRemoteSelectContract`**（`core/testing/dict-remote-select.ts`）：占位零请求、未注入零请求、三类派发与查询参数、关键词结果缓存命中、批量回显与标记、多选去重与上限、分页页码透传、用户展示汇入、错误码、竞态；核心与 `ui-ep` 各传适配器跑同一套断言。
9. **核心用例**：`domain-dict-data.spec.ts`（归一 / 参数 / 解析 / 选择 / 标记 / 标签摘要 / 路径与树 / 错误码）与 `dict-remote-select.spec.ts`（契约驱动 + 身份依赖 + 部门树缓存 + 用户展示汇入）；同步 `domain-form-render.spec.ts` 的 `dept` 映射断言。
10. **投影与工具**：`useBaseDictRemoteSelect`（核心实例 ↔ Vue 响应式薄适配，内建花名册实例，`onScopeDispose` 释放）；`utils/dictRemoteSource.ts`（`createHttpDictRemoteSource` 以 `fetch` 访问 `/mdm/*`，统一响应解包与错误码，注册表默认键 `http`，`fetch` 不可用降级返回 `undefined`）；`utils/debounce.ts`（定时器统一入口，件层按 `DICT_DATA_SEARCH_DEBOUNCE` 调度远程搜索）。
11. **field 件族五件**（`ui_ep/src/components/field/`）：
    - `DictRemoteSelectField`（真实实现，保留 `06_01` 冻结契约）：向后兼容新增 `kind` / `searchable`（补齐冻结契约表已登记项）/ `source` / `userDisplay` / `limit` / `status` / `deptId` / `includeChildren` / `showIncludeChildren` / `readonly` / `required` / `errorMessage` / `emptyText` / `clearable` / `collapseAfter` / `showAvatar` / `showCode`；`kind=dept` 内聚部门树件，仅传 `options` 未注入数据源时沿用 `SelectInput` 静态通路；
    - `UserSelectField`（人员：远程搜索 / 多选上限 / 部门过滤含下级 / 头像 / 只读折叠回显）；
    - `PostSelectField`（岗位：编码展示 / 状态过滤）；
    - `DeptTreeSelectField`（部门树：一次性加载会话缓存 / 路径回显 / 编辑态复用 `TreeSelectField` / `include_children` 勾选透传）；
    - `DictCompositePicker`（复合弹窗：左部门树 × 右人员 / 岗位列表 + 搜索 + 分页 + 已选标签；确认回填、取消恢复打开时快照）。
12. **表单渲染协同（`08_06` 已交付件）**：`FIELD_WIDGET_MAP.dept` 由 `tree-select` 改 `dict-remote-select`；`MULTIPLE_WIDGETS` 纳入 `dict-remote-select` 并由 `FormRendererBody` 的 `isMultiple` 复用（删除件内重复清单）；新增 `extraProps(field)` 对字典数据件透传 `kind`（`user` / `post` / `mdm` / `dept` → `user` / `post` / `dept`）。
13. **导出面与令牌**：`ui_ep/src/index.ts` 新增四件与类型、投影、两个工具导出；`apps/desktop/src/styles/tokens.scss` 新增 `--bms-mdm-*` 组（亮 / 暗两套，只增不改）。
14. **用例**：`ui_ep/tests/field-dict-remote-select.spec.ts` 32 条（契约套件适配 + 占位契约复用 + 投影 + 五件 + 工具）；`interaction-form-renderer.spec.ts` 补部门 / 岗位字段协同用例；既有 `ui_ep/tests/field-placeholder.spec.ts`（`06_01` 冻结契约）**未改动即通过**。
15. **宿主核对页**：`apps/desktop/dict-remote-select-check.html` + `src/dev/{dictRemoteSelectCheck.ts,OrgCheck.vue}`（12 项自检），`vite build` 不包含；经 chromium CDP 轮询等待自检项渲染到位后导出 DOM 核验 **12/12**（连续 3 次稳定）。

## 5. 偏差与遗留 <a id="deviations"></a>


- **既有基类调整**（均为兼容变更，登记见《前端基类清单》）：`BaseOptionSource` 父基类 `BaseComponent` → `BaseField`（依赖登记改 `['field']`）；`BaseUserDisplay` 新增花名册（字段 / 方法只增不改）。
- **对外契约扩展**（向后兼容）：`DictRemoteSelectField` 新增可选 Props（`kind` / `searchable` / `source` / `userDisplay` / `limit` / `status` / `deptId` / `includeChildren` / `showIncludeChildren` / `readonly` / `required` / `errorMessage` / `emptyText` / `clearable` / `collapseAfter` / `showAvatar` / `showCode`）、事件（`retry` / `invalid` / `limit-exceed` / `update:deptId` / `update:includeChildren`）与插槽（`empty` / `option` / `prefix`）；既有 Props / 事件 / 插槽 / `data-test` 不变；补齐 `06_01` 契约表已登记但原实现遗漏的 `searchable`。
- **核心面新增**（只增不改）：新增组件基类 `BaseDictRemoteSelect`（父 `BaseOptionSource`）与插件基类 / 注册项 / 注册表 `BaseDictRemoteSource` / `DictRemoteSourceProvider` / `DictRemoteSourceRegistry`；`domain/dict-data.ts` 与契约套件 `describeDictRemoteSelectContract`；投影补充 `page` / `total` / `limit` / `errorCode` / `errorMessage` 响应式面与 `setPage` / `setLimitExceeded`（复合弹窗分页与超限标记所需）。
- **表单渲染协同**：`dept` 字段类型改映 `dict-remote-select`（`kind=dept`）；`MULTIPLE_WIDGETS` 纳入 `dict-remote-select` 并作为多选语义唯一来源；`FormRendererBody` 新增 `extraProps` 透传 `kind`——`08_06` 任务文档已补协同契约注块。
- **真实联调**：字典数据源经注入式 `DictRemoteSourceAdapter` 注入（未注入即占位零请求），内建 HTTP 实现以默认键 `http` 登记；真实取数 / 数据范围过滤 / 字段脱敏 / 权限码（`user:query` / `mdm:query`）归**阶段七（RBAC）窗口**；宿主「字典数据相关 store」版数据源经注册表登记接入（接口就位）。
- **数据范围口径**：后端出口实现侧强制过滤与脱敏（调用方不可绕过），前端不二次过滤；部门树件只透传 `include_children`。
- **遗留**：真实 RBAC 取数与数据范围 / 脱敏联调（归口阶段七）、移动端实现（契约套件 `describeDictRemoteSelectContract` 与投影就位供同契约多实现）、字典字段（`06_06`）是否经重挂后的 `BaseOptionSource` 派生待其设计确认。
- **对齐回写**：实施期口径调整已回写[详细设计 §10 实施对齐记录](../设计/01_详细设计_05_远程字典选择字段.md#align)（查询归一函数 / 分页与超限 setter / 补充可选 Props / 投影响应式面 / Kiwi 962 / 核对页核验方式）。
- **能力登记键清理（2026-11-14，CI 存量失败收口）**：本任务顺带在 `CAPABILITY_MANIFEST` 登记了字段控件键 `dict_tree`（依赖 `option_source` / `dict_store`），但只交付控件组合（`DictTreeField.vue` 薄包 `TreeSelectField.vue`）、未建 `BaseDictTree` 能力基类，护栏 `guard-manifest.spec.ts` 判定为「僵尸条目」（bms#1627 `core-check` 失败：能力文件 identifier 77 项 vs 登记表 78 项）。**已移除该键**——控件依赖由 `dict_select` / `dict_store` 承载，全仓无任何类声明 `capability='dict_tree'`，移除不涉能力行为；后续若真出现字典树专属能力，同时落能力文件 + 登记键即可。
- **组件挂链接入（2026-11-14，同一轮收口）**：同一护栏链后续两条断言（`guard-component-inheritance` / `interaction-style`）指出 `DictTreeField.vue` 未实质挂继承链且缺 `<style scoped>`（bms#1628 `core-check`）。按 06_06 设计口径「树只是展示形态、不另立能力基类」，改为经 `useBaseDictSelect` 投影接入字典能力（`BaseDictSelect` + `BaseDictStore`：版本比对 / 缓存 / 错误态 / 大字典判定），全量条目读缓存能力 `itemsOf`（投影 `items` 在非级联口径下按顶层过滤会丢子级），懒加载子级仍按 `parentId` 单层取数，并补非空 `<style scoped>`；用例补 `beforeEach` 清 localStorage（缓存跨用例污染）。对外 Props / 事件 / `data-*` 契约不变。
