## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先行**：经容器内 Django shell 登记用例（平台既有编号至 963），取得 **964**；三份用例文件首行标注 `// kiwi_id: 964`。
2. **核心领域 `domain/dict.ts`**：常量（阈值 2000 / 探针 2001 / 防抖 300ms / 缓存与子集上限 / 本地缓存前缀与体积上限 / 错误码文案 40101~40103 / 条件深度与页长上限）、类型（`DictItem` / `DictTypeResult` / `DictBatchResult` / `DictAttrSchema` / `DictQueryProvider` / `DictQueryScheme` / 条件组）与纯函数（归一（兼容 snake_case、脏项剔除、`items=null` 三态）、值归一与选择上限、标签翻译与过滤、树构建、缓存 / 子集 / 本地键、线参数构造（`version` / `keyword` / `parent_id`（空串 = 顶层）/ `values` / `limit`）、操作符联动与条件组校验、方案归一与优先级、错误码文案、页码页长夹取）。
3. **插件轨 `capabilities/dict-source.ts`**：`BaseDictSource`（九方法：取数 / 批量 / 属性 / 提供者 / 高级查询 / 方案 CRUD；未覆写返回 `undefined` 即不请求）+ `DictSourceProvider` + `DictSourceRegistry`；注入面 `DictSourceAdapter`。
4. **能力基类 `BaseDictStore`**（父 `BasePlaceholderState`）：全局一份缓存——批量合并（同微任务批次多类型一次 `batch`）、同类型并发去重、探针与大小字典登记、子集回填（已解析集合防重复）、本地二次缓存（注入通道 + 小字典 + 体积上限 + LRU）、失效（类型 / 全清 + 本地键删除）、`bindDictStoreSource` 统一接线。
5. **组件基类 `BaseDictSelect`**（父 `BaseOptionSource`）：缓存路径（小字典本地过滤含顶层过滤 / 大字典远程搜索）与数据源直取路径（级联父值 / 无缓存）、禁用项、多选去重与上限、批量回显（`values` 一次）、选项源语义同步（`options` / `dataVersion` / `getLabel`）。
6. **能力基类 `BaseDictQuery`**（父 `BasePlaceholderState`）：元数据并行（attrs + providers）、条件组（归一 + 白名单校验）、执行（取项 / 业务筛选）、方案 CRUD（列表 / 默认 / 应用 / 保存 / 删除）。
7. **登记与导出**：`manifest`（`dict-store` / `dict-select` / `dict-query`）；`form-render`（`FormWidget` 增 `dict-select` / `dict-multi`，`FIELD_WIDGET_MAP` 增 `dict` / `dict_multi`）；`form-layout`（`FieldRenderAttrs.dictType`）；`core/src/index.ts` 与 `core/testing/index.ts` 导出。
8. **契约套件（`@bms/core/testing/dict.ts`）**：`describeDictStoreContract` / `describeDictSelectContract` / `describeDictQueryContract` + 数据源桩（版本可控 + 大字典标记 + 调用轨迹）；核心与 `ui-ep` 各传适配器跑同一套断言（同契约多实现）。
9. **投影与工具**：`useBaseDictSelect`（内建 store + localStorage 通道 + 响应式面 + `onScopeDispose` 释放）、`useBaseDictQuery`；`utils/dictSource.ts`（HTTP 内建九方法 + 统一解包 + 默认键 `http` + 方案线格式映射）、`utils/dictStorage.ts`（localStorage 通道 + 能力探测）、`utils/dictTranslator.ts`（`createDictTranslator`）。
10. **件族五件**：
    - `DictSelectField`（真实实现，保留 `06_01` 冻结契约）：degrade / 静态选项兼容 / 只读（文本或标签折叠）/ 小字典 `el-select` / 大字典 `el-select-v2`（虚拟滚动）+ 远程搜索防抖；事件 `retry` / `invalid` / `limit-exceed`；插槽 `empty` / `option` / `prefix`；
    - `DictCascaderField`（树构建 + 编辑态复用 `CascadeField` + 只读路径回显）；
    - `DictLabel`（缓存命中直出 / 未命中回退原值 / 标签形态 + 语义色点）；
    - `ConditionGroupBuilder`（AND/OR 分组树 + 字段与操作符联动 + 增删条件 / 子组 + 值控件按操作符联动；经 `useBaseInput` 挂链）；
    - `DictAdvancedQuery`（抽屉：目标切换 / 提供者与参数 / 条件组 / 结果表与分页 / 方案管理 / 打开快照与取消恢复 / 应用回填）。
11. **表单渲染协同**：`formWidgets`（`dict-select` / `dict-multi` 映射 + `MULTIPLE_WIDGETS` 纳入 `dict-multi`）；`FormRendererBody`（`isDictReferenced` 优先分发字典件 + `extraProps` 透传 `dictType`）。
12. **令牌与核对页**：`tokens.scss` 新增 `--bms-dict-*`（亮 / 暗两套）；`dict-check.html` + `src/dev/{dictCheck.ts,DictCheck.vue}`（12 项自检 + `?source=http` 真实模式）。
13. **前后端联调**：后端（`02-4-27`，dev 配置 SQLite + 种子）起服务后，curl 验证取数 / 版本一致 / 批量 / 级联 / 属性 / 提供者 / 高级查询 / en-US / 写路径与版本递增；核对页 `?source=http` 经 vite 代理 `/api` 直连后端，自检 **12/12**。
14. **登记回写**：《前端基类清单》（§2.1 三行 + §4 插件轨 + §5.2 / §5.3 + §8 继承链 + §9 目录与契约套件）、《组件设计 · 字典字段》落地口径注块、《布局设计 · 设计令牌》2.5 字典令牌、任务 / 父任务 / 计划与状态、协同契约（`06_01` 遗留闭环 / `07_05` translator / `08_06` 渲染协同）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | 契约「大字典」用例在全量运行时失败（`isLarge` 为假） | 投影缺省启用 localStorage 通道，前序用例写入的本地缓存跨用例污染 | 投影 `storage` 语义修正（显式传入含 `undefined` 以调用方为准）；测试 `afterEach` 清 localStorage；契约适配器显式禁用持久化 |
| 2 | `Cannot write private member #typeLoader`（件内使用 store） | 缓存实例经件 props 传递被 Vue 代理，`#private` 写入失败 | 字典缓存类私有字段改下划线命名（运行时普通属性）；回写设计 §18 |
| 3 | `BaseDictStore` / `BaseDictQuery` 编译失败（`ready` 缺省为真） | 父基类 `BaseComponent` 无占位语义；`BasePlaceholderState.ready` 缺省 `true` | 父基类改 `BasePlaceholderState`；`BaseDictQuery` 显式 `ready = false`（缓存类同） |
| 4 | 护栏 `guard-jsdoc` / `guard-manifest` / `guard-component-inheritance` 失败 | 多常量共用一条 JSDoc；新基类未登记《前端基类清单》；`ConditionGroupBuilder` 未挂链 | 常量逐个补 JSDoc；清单登记三行 + 插件轨 + 目录；条件组构建件经 `useBaseInput` 挂链 |
| 5 | 表单协同用例找不到字典件 | 测试未 stub `DictSelectField`（真实件内部依赖 Element Plus 组件） | 用例 `stubs` 增加 `DictSelectField: true` 并断言透传属性 |
| 6 | 核对页 HTTP 模式「禁用项」自检失败 | 真实种子条目状态均为启用（业务值「停用」状态为启用） | 自检断言分模式：桩断言存在停用条目、真实断言状态字段可读；回写设计 §18 |
| 7 | 大字典顶层过滤 / 级联父值请求口径 | 缓存整类型含子级；带过滤请求不应写缓存 | `load()` 分级：父值非空走数据源直取（带 `parent_id`）；缓存路径本地顶层过滤；回写设计 §18 |

## 6. 偏差与遗留 <a id="deviations"></a>

- **设计偏差（已回写设计 §18）**：① 缓存 / 高级查询基类父基类 `BaseComponent` → `BasePlaceholderState`；② 缓存类私有字段 `#` → 下划线（Vue 代理兼容）；③ 投影 `isLarge` 为 `Ref`；④ 投影 `storage` 显式语义；⑤ 条件组构建件经 `useBaseInput` 挂链；⑥ 级联父值直取 + 顶层过滤口径；⑦ 补 `setLimitExceeded` 与 `findDictItem` / `mergeDictItems`；⑧ 核对页「禁用项」分模式断言。
- **对外契约扩展（向后兼容）**：`DictSelectField` 新增可选 Props（`dictType` / `searchable` / `source` / `store` / `storage` / `locale` / `parentId` / `limit` / `readonly` / `required` / `errorMessage` / `emptyText` / `clearable` / `collapseAfter` / `showColor` / `readonlyTag`）、事件（`retry` / `invalid` / `limit-exceed` / `loaded`）与插槽（`empty` / `option` / `prefix`）；既有 Props / 事件 / 插槽 / `data-test` 不变。
- **核心面新增（只增不改）**：`domain/dict.ts`、`capabilities/dict-source` / `dict-store` / `dict-select` / `dict-query`、契约套件三套；`FormWidget` 增 `dict-select` / `dict-multi`、`FieldRenderAttrs.dictType`（前端先冻结，后端表单元数据下发归表单定制窗口）。
- **遗留（归口）**：
  - 三库真库执行与真实 Redis 集成、`ops/test_db.py` 真实执行 → **阶段二 后端基座窗口**（后端 `02-4-27` 遗留，与本任务共用）。
  - 字典管理页面 / 菜单、`dict:manage` / `dict:query-scheme` 权限码、操作日志与字段级审计、回收站、导入导出 → **阶段八 通用能力·字典模块**。
  - 表单元数据接口下发 `dictType`、自建字段类型白名单（`EXT_FIELD_TYPES`）扩展 → **表单定制窗口**。
  - 字典高级查询界面定制（`layout.dictAdvanced` 三级解析）宿主装配、预加载（`preload`）宿主登录流程接线 → 后续窗口。
  - 移动端实现（契约套件与投影就位供同契约多实现）。
  - 宿主「字典相关 store」版数据源（经 `DictSourceRegistry` 登记接入，接口就位）。
