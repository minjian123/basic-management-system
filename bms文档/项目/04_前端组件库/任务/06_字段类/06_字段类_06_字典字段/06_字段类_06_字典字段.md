## 2. 任务内容 <a id="content"></a>

1. **核心能力（前两段）**：领域纯函数 `domain/dict.ts`（归一 / 版本比对三态 / 大小字典判定 / 查询与批量参数 / 缓存键 / 树构建 / 标签翻译 / 错误码与文案）；能力基类 `BaseDictStore`（字典缓存：版本比对 / 批量合并与并发去重 / 大小字典缓存 / 本地二次缓存注入通道 / 失效 / 翻译）；组件基类 `BaseDictSelect`（父 `BaseOptionSource`：字典下拉语义、搜索、禁用项、级联父值、只读回显）；能力基类 `BaseDictQuery`（高级查询编排：属性 schema / 提供者清单 / 条件组 / 执行 / 方案）。
2. **插件轨**：`BaseDictSource`（`byType` / `batch`，未覆写即占位零请求）+ `DictSourceProvider` + `DictSourceRegistry`；`ui-ep` 内建 HTTP 实现（默认键 `http`）与 `localStorage` 工具（浏览器能力单一落点）。
3. **契约与投影**：契约套件 `describeDictContract` / `describeDictQueryContract`（同契约多实现）；投影 `useBaseDictSelect` / `useBaseDictQuery`（薄适配）。
4. **件族（四件 + 条件组构建件）**：`DictSelectField`（真实实现，保留 06_01 冻结契约；探针 2001 大小字典切换、远程搜索防抖、虚拟滚动 `el-select-v2`、禁用项、级联父值、多选与只读回显）、`DictCascaderField`（树形多级字典，复用级联件）、`DictLabel`（标签回显，并提供 `createDictTranslator` 供列表 / 详情注入）、高级查询件（抽屉：条件组 + 提供者参数 + 结果预览 + 方案管理）与可复用条件组构建件。
5. **协同与通道**：表单渲染协同（`dict` / `dict_multi` 语义键与字段类型、`FieldRenderAttrs.dictType` 透传、渲染器优先分发、多选语义单一来源）；列表 / 详情标签回显接入 `DataTable` / `DescriptionList` 的 `translator`；设计令牌 `--bms-dict-*`；宿主核对页 12 项自检（含 `?source=http` 真实后端模式）。
6. **测试与验证**：Vitest 覆盖缓存命中与版本比对分支（前端 / 批量 / 失效 / 本地二次缓存）；护栏对账（挂链 / 单一落点 / 令牌 / 能力登记）；与后端 `02-4-27` 真实接口（`/api/v1/dicts/*`）端到端联调。

## 3. 完成标准 <a id="accept"></a>

字典下拉（含虚拟滚动与远程搜索）、字典级联、标签回显与高级查询可用；缓存命中不重复请求、版本比对与本地二次缓存生效、字典变更后展示同步；表单渲染协同生效；Vitest 覆盖缓存与版本比对分支；`vue-tsc`、ESLint、Vitest 全通过；宿主核对页 12/12（含真实后端模式）；与后端 `02-4-27` 联调打通并留证据；既有 `06_01` 冻结契约与 `field-placeholder` 冻结用例不改动即通过。
