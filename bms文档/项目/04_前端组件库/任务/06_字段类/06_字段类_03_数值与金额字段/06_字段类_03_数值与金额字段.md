## 2. 任务内容 <a id="content"></a>

1. **数值族五件**：`NumberField`（继承域 05 `NumberInput`）、`AmountField`（金额语义：精度 / 千分位 / 大写）、`PercentField`（百分比）与工具 `useNumberInput`、纯函数 `toChineseAmount`（金额大写）。
2. **精度与校验契约**：精度、范围（`min` / `max`）与步进校验在域层定义一次；金额格式化复用 `02-6` `formatAmount` 并在能力层注册表分发；**前端禁止浮点累加**，极大值与超安全整数拦截，粘贴内容清洗（非法不提交）。
3. **只读回显**：金额 / 百分比只读态经 `displayText` 覆盖，格式化口径与可编辑态一致。
4. **双端形态**：PC 走 `el-input-number` + 金额语义包装；移动端走 `van-field` + `inputmode="decimal"` 与自定精度处理（沿用域 05 `05_02` 口径，不使用 `type="digit"`）。
5. **字段壳装配**与只读两态经 `06_01` 公共口径装配，双端一致。
6. **用例**：本条 1 条 Kiwi 用例（双端同号，762）。
7. **实现以《组件设计》节点**「03 数值与金额字段」及可交互原型为契约依据；偏离契约先改设计节点。
8. **上游登记清单（建任务时列出，随实施逐个确认并回写）**：字段精度 / 范围、金额精度默认值（系统参数）、自建字段类型、导出格式（该节点「依赖接口与上游变更」表）。
9. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>
