## 2. 任务内容 <a id="content"></a>

1. **枚举族四件**（均继承域 05 选择件）：`SwitchField`（← `SwitchInput`，三态开关 + 危险切换确认）、`InlineSwitch`（列表内联切换，受控 + 失败回滚）、`EnumField`（← `RadioField`，自定义选项集枚举）、`EnumCheckboxField`（← `CheckboxField`，枚举多选）。
2. **枚举工具**：`useEnumOptions`（选项集解析与缓存）、`getEnumLabel` / `formatEnumText`（文本回显）、`toBoolValue` / `formatBoolText`（布尔归一与展示）；存量脏值归一（`'1'` / `'0'` / `'是'` / `'否'`）。
3. **选项源投影**：交付 `@bms/vue` 选项源投影 `useOptionSource`（消费 `option-source` 能力），供 `05` / `06` / `08` / `09` 复用——静态选项与后续动态选项（字典 / 组织）共用加载与缓存口径；本任务先落静态与自定义选项集通路。
4. **只读口径**：只读一律纯文本（不做颜色标签）；危险开关二次确认走域 05 `05_03` 的 `confirm()` 注入点。
5. **字段壳装配**与只读两态经 `06_01` 公共口径装配，双端一致。
6. **用例**：本条 1 条 Kiwi 用例（双端同号，763）。
7. **实现以《组件设计》节点**「08 开关与枚举字段」及可交互原型为契约依据；偏离契约先改设计节点。
8. **上游登记清单（建任务时列出，随实施逐个确认并回写）**：① 平台字段选项集与组件形态承载位；② 列表内联切换接口与权限；③ 危险开关二次确认（该节点「需登记的上游变更」，随实施向《概要设计 · 表单定制》《布局设计 · 表单页》《安全开发规范》同步）。
9. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>
