## 2. 任务内容 <a id="content"></a>

1. **去自由选项**：`OptionSetField` / `OptionSetMultiField` 移除字段层直传 `options` 的通路，改为消费表单元数据下发的 `optionSetKey`；选项由选项集解析器注入，控件不取数。
2. **六种形态**：保留 radio / button / segmented / checkbox / tag，新增 `dropdown`（单选）与 `dropdown-multi`（多选，语义键与后端字段类型注册表一致），下拉复用基础控件类·下拉框；选项 > 8 默认建议下拉（单选 `dropdown`、多选 `dropdown-multi`）。
3. **类型映射**：`FIELD_WIDGET_MAP` / `FIELD_WIDGETS` 中 `select` → `option`、`multi_select` → `option_multi`；表单渲染按新类型分发。
4. **与字典组件拆开**：字典字段继续走 `DictSelectField` / `DictCascaderField`（绑定条目 `id`）；选项集字段不复用字典取数 / 缓存 / 版本比对；删除「`select` / `multi_select` + `dictType` 优先分发字典件」分支。
5. **解析与回显**：选项集解析（sort 升序 → value 去重 → i18n 回退 → 颜色 / 禁用）纯函数与契约套件；缺项回退原值并告警。
6. **测试与联调**：六种形态、去重、i18n、禁用项、缺项回退、数量上下限用例；与后端选项集注册基座及表单元数据 `optionSetKey` 下发联调；后端未就绪时注入式占位、零请求。
7. **命名对齐（2026-10-21 拍板）**：把拆分节点前沿用下来的旧名统一为选项集口径——组件 `EnumField` → `OptionSetField`、`EnumMultiField` → `OptionSetMultiField`；连带类型（`EnumFieldForm` / `EnumFieldValue` 等）、`ui-ep/src/index.ts` 导出、`utils/formWidgets.ts` 引用、开发态核对页 `FieldCheck.vue`（组件标签、变量名、`data-test="enum*"`）与 `apps/desktop/tests/guard-library-components.spec.ts` 守卫断言一并改。**测试文件按件拆分**：`field-switch-enum.spec.ts` 拆为 `field-switch.spec.ts`（三态开关 / 内联切换 / 乐观值 / 版本冲突）与 `field-option-set.spec.ts`（六种形态 / 去重 / i18n / 禁用项 / 缺项回退 / 数量上下限），用例逐条迁移、不删减，两文件均纳入 100% 覆盖率采集。已交付任务的历史记录（`06_02` / `06_09` / `08_06` / `11_03`）同步按新名回写。

## 3. 完成标准 <a id="accept"></a>

`OptionSetField` / `OptionSetMultiField` 不再接受自由选项、只消费 `optionSetKey`；六种形态可用；类型映射改为 `option` / `option_multi`；字典与选项集分支完全独立；实现侧命名统一为 `OptionSetField` / `OptionSetMultiField`（类型、导出、`formWidgets`、核对页、守卫断言均无旧名）；测试拆为 `field-switch.spec.ts` 与 `field-option-set.spec.ts` 且用例无删减；前端 lint / typecheck / test 全绿且覆盖率 100%。

## 5. 协同契约（上游已交付） <a id="upstream"></a>

> 后端 `02_28`（选项集注册与校验基座）已于 2026-10-21 交付**契约与占位实现**；本任务按其契约做前端消费，**不设接口、零请求**。

- **选项集契约**：`OptionItem`（`value` / `label` / `labelKey` / `color` / `disabled` / `sort`）与 `OptionSetInfo`（`optionSetKey` / `items` / `namespace` / `version`）为唯一权威；解析顺序（`sort` 升序 → 同 `value` 去重保留首个）前后端一致。
- **注册与冲突只在后端**：装载期注册、命名空间标识、同 value 异义 / 同 label 异值 / 同标识异义即失败、禁止产品覆盖基座——前端**不重复实现**，只消费元数据下发的已解析快照。
- **下发口径（登记上游变更）**：`layout-effective` 下发字段属性 `optionSetKey` + `optionSets` 快照集（`{optionSetKey, items[]}`）；真实下发随表单定制阶段接通，此前按注入式占位（空态降级、零请求，不伪造快照）。
- **与 `08_06-1` 协同**：表单定制属性面板与自建字段对话框的「自由选项录入」须改为**只引用已注册 `optionSetKey`**（禁自由录入），归 `08_06-1` / 表单定制阶段；本轮已在渲染器侧删除枚举件逐字段下发 `options` 的通路。
