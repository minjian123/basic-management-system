## 2. 任务内容 <a id="content"></a>

1. **核心领域**：`domain/captcha.ts`——常量（有效期 300s / 冷却 60s / 阈值 3 / 图形 4-6 位 / 短信 6 位 / 五场景）、归一（挑战与策略兼容 snake_case）、脱敏、输入校验、阈值判定、倒计时步进、滑块轨迹归一与提交构造、图片数据 URL 组装、错误码文案（20101 ~ 20103）。
2. **数据源插件轨（注入式）**：插件基类 `BaseCaptchaSource` + `CaptchaSourceProvider` + `CaptchaSourceRegistry`（注入面 `CaptchaSourceAdapter`：`challenge` / `sendSms` / `verify` / `policy`，未覆写即占位零请求）；`ui-ep` 内建 HTTP 实现（默认键 `http`，直连既有留位路由 `/api/v1/captcha/*`）。
3. **组件基类 `BaseCaptcha`（父 `BaseInput`）**：三形态状态机、挑战获取与刷新（一次性失效）、短信发送与倒计时（限流不重置）、校验与错误分类、滑块轨迹提交、阈值联动（`needsChallenge`）、释放停表；公共判定只在链上维护。
4. **契约与投影**：契约套件 `describeCaptchaContract`（同契约多实现，含数据源桩）；投影 `useBaseCaptcha`（核心实例 ↔ Vue 响应式薄适配）。
5. **件族（四件）**：`CaptchaField`（分发壳，保留 `06_01` 冻结契约）、`ImageCaptcha`（图形：展示 / 点击与按钮刷新 / 输入 / 一次失效自动刷新）、`SliderCaptcha`（自绘滑块：拖动轨迹采样 + 提交后端判定 + 失败自动复位 + 键盘可操作）、`SmsCaptcha`（手机号脱敏 / 60s 倒计时 / 限流提示不重置 / 一次性自动填充语义）。
6. **表单渲染协同**：`FieldRenderAttrs` 只增 `captchaKind` / `captchaScene`（向后兼容）；`FormRendererBody` 透传（语义键 `captcha` 已于 `06_01` 存在）。
7. **令牌与核对页**：设计令牌 `--bms-captcha-*`（亮 / 暗两套）；宿主核对页 `captcha-check.html` 13 项自检（桩数据源 + `?source=http` 占位端点模式）。
8. **前端先行 + 通路注入式**（用户拍板）：保持 `06_01` 冻结的对外契约，仅接入后端认证接口契约；**真实出题（Pillow）、短信下发（经 02-20 通知渠道）、冷却与频次（经 02-25 限流基座）、场景策略（`sys_config`）与联调归阶段六「认证与安全」窗口**。
9. **测试与验证**：Vitest 覆盖失败阈值与倒计时分支（挑战 / 刷新 / 限流 / 校验 / 滑块轨迹 / 策略）；护栏对账（挂链 / 单一落点 / 令牌 / 能力登记）；`06_01` 冻结契约用例不改动即通过。

## 3. 完成标准 <a id="accept"></a>

三类验证码可用、失败阈值与限流行为生效（限流命中提示且不重置倒计时）、滑块轨迹提交后端判定、图形刷新与一次性失效正确；与后端认证接口契约一致（四端点字段对齐；真实联调归阶段六）；表单渲染协同生效；Vitest 覆盖阈值与倒计时分支；`vue-tsc`、ESLint、Vitest 全通过；宿主核对页 13/13（桩模式，含 `?source=http` 占位端点联通核对）；既有 `06_01` 冻结契约与 `field-placeholder` 冻结用例不改动即通过。
