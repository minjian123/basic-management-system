## 2. 任务内容 <a id="content"></a>

1. 用户 / 岗位 / 组织选择：远程搜索、多选、只读回显、已删除 / 停用对象占位。
2. 部门树选择（与权限数据范围口径一致）。
3. 数据来源统一走组织相关 store 并复用缓存；批量按 id 回显走批量接口（避免 N+1）；用户展示经用户展示能力基类 `BaseUserDisplay`。

> 实施口径（2026-09-21）：前端先行 + 通路注入式——数据源经注入式 `OrgSourceAdapter`（内建 HTTP 实现经 `BaseOrgSource` / `OrgSourceRegistry` 登记，默认键 `http`），未注入即占位零请求；统一走**组织主数据出口** `/api/v1/org/*`（后端 `02-4-16` 已交付，含查询与批量回显两个出口）；宿主「组织相关 store」版数据源经注册表登记接入（真实 RBAC 联调归阶段七窗口）；交付五件（`OrgSelectField` / `UserSelectField` / `PostSelectField` / `DeptTreeSelectField` / `OrgCompositePicker`）与组件基类 `BaseOrgSelect`，并完成表单渲染器 `dept` → `org-select` 协同。

## 3. 完成标准 <a id="accept"></a>

三类组织选择字段可用、远程搜索与多选正确、只读回显稳定；Vitest 覆盖回显与搜索分支。
