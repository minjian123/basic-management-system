结果小结：选项源能力重挂值链（父基类 `BaseComponent` → `BaseField`）、用户展示能力向后兼容扩展花名册；新增 1 个组件基类、1 套插件基类 / 注册项 / 注册表、1 份领域纯函数、1 套契约套件、1 套投影、2 个插件工具与五件组件、1 个宿主核对页与 4 处表单渲染协同改动；`core` 78 文件 / 987 用例、`vue` 2 文件 / 5 用例、`ui-ep` 57 文件 / 796 用例全绿。

## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先行**：经容器内 Django shell 登记用例，取得编号 **962**（平台既有编号至 961）；新增用例文件首行标注 `// kiwi_id: 962`。
2. **选项源能力入值链（`capabilities/option-source.ts`）**：父基类由 `BaseComponent` 改 `BaseField`（`depends` 改 `['field']`），既有字段与方法（`options` / `loader` / `load` / `dataVersion` / `getLabel` / `search`）只增不改；`08_04` / `08_10` 消费方回归通过。
3. **用户展示能力扩展（`capabilities/user-display.ts`）**：向后兼容新增 `users` 花名册与 `setUsers` / `mergeUsers` / `clearUsers` / `findUser` / `displayOf`，`UserDisplayInfo` 新增可选 `deleted`；投影 `useBaseUserDisplay` 同步补花名册响应式面。
4. **核心领域纯函数 `domain/org.ts`**：常量（`ORG_TARGETS` / `ORG_STATUSES` / 300ms 防抖 / 页长 / 缓存上限 / 折叠阈值 / 错误码文案）、数据模型（`OrgOptionItem` / `OrgDeptNode` / `OrgTreeNode`）与纯函数（归一（兼容 snake_case、脏项剔除、`exists=false` 已删除）、查询归一与线参数构造、批量回显参数（`target` + `id_in`）、分页解析、缓存键、选择与上限、已删除 / 停用标记、标签摘要、部门路径与树节点映射、错误码判定）。
5. **插件轨 `capabilities/org-source.ts`**：`BaseOrgSource`（`BasePluggable`；四方法未覆写返回 `undefined` 即不请求）、`OrgSourceProvider`（`BaseProvider`）、`OrgSourceRegistry`（`BaseProviderRegistry`，同键拒重）；对应后端组织主数据出口 `/api/v1/org/{users,posts,dept-tree,resolve-names}`。
6. **组件基类 `BaseOrgSelect`（`capabilities/org-select.ts`，父 `BaseOptionSource`）**：三类派发（用户 / 岗位 / 部门树）、关键词与部门 / 状态过滤、候选页码与总数、关键词结果短缓存（上限淘汰）、已选对象常驻、批量按 id 回显（单请求、未命中生成已删除占位）、多选去重与上限、缓存失效、错误码与竞态防护、用户展示花名册汇入与部门路径补全。**未就绪 / 未注入数据源零请求**（`requestCount` 恒 0，保持 `06_01` 冻结口径）。
7. **能力登记与导出面**：`manifest.ts` 新增 `org-select: ['option-source', 'user-display']`、`option-source` 依赖改 `['field']`；`core/src/index.ts` 新增领域、插件基类 / 注册表与组件基类导出；`core/testing/index.ts` 新增契约套件导出。
8. **契约套件 `describeOrgSelectContract`**（`core/testing/org-select.ts`）：占位零请求、未注入零请求、三类派发与查询参数、关键词结果缓存命中、批量回显与标记、多选去重与上限、分页页码透传、用户展示汇入、错误码、竞态；核心与 `ui-ep` 各传适配器跑同一套断言。
9. **核心用例**：`domain-org.spec.ts`（归一 / 参数 / 解析 / 选择 / 标记 / 标签摘要 / 路径与树 / 错误码）与 `org-select.spec.ts`（契约驱动 + 身份依赖 + 部门树缓存 + 用户展示汇入）；同步 `domain-form-render.spec.ts` 的 `dept` 映射断言。
10. **投影与工具**：`useBaseOrgSelect`（核心实例 ↔ Vue 响应式薄适配，内建花名册实例，`onScopeDispose` 释放）；`utils/orgSource.ts`（`createHttpOrgSource` 以 `fetch` 访问 `/org/*`，统一响应解包与错误码，注册表默认键 `http`，`fetch` 不可用降级返回 `undefined`）；`utils/debounce.ts`（定时器统一入口，件层按 `ORG_SEARCH_DEBOUNCE` 调度远程搜索）。
11. **field 件族五件**（`ui-ep/src/components/field/`）：
    - `OrgSelectField`（真实实现，保留 `06_01` 冻结契约）：向后兼容新增 `kind` / `searchable`（补齐冻结契约表已登记项）/ `source` / `userDisplay` / `limit` / `status` / `deptId` / `includeChildren` / `showIncludeChildren` / `readonly` / `required` / `errorMessage` / `emptyText` / `clearable` / `collapseAfter` / `showAvatar` / `showCode`；`kind=dept` 内聚部门树件，仅传 `options` 未注入数据源时沿用 `SelectInput` 静态通路；
    - `UserSelectField`（人员：远程搜索 / 多选上限 / 部门过滤含下级 / 头像 / 只读折叠回显）；
    - `PostSelectField`（岗位：编码展示 / 状态过滤）；
    - `DeptTreeSelectField`（部门树：一次性加载会话缓存 / 路径回显 / 编辑态复用 `TreeSelectField` / `include_children` 勾选透传）；
    - `OrgCompositePicker`（复合弹窗：左部门树 × 右人员 / 岗位列表 + 搜索 + 分页 + 已选标签；确认回填、取消恢复打开时快照）。
12. **表单渲染协同（`08_06` 已交付件）**：`FIELD_WIDGET_MAP.dept` 由 `tree-select` 改 `org-select`；`MULTIPLE_WIDGETS` 纳入 `org-select` 并由 `FormRendererBody` 的 `isMultiple` 复用（删除件内重复清单）；新增 `extraProps(field)` 对组织件透传 `kind`（`user` / `post` / `org` / `dept` → `user` / `post` / `dept`）。
13. **导出面与令牌**：`ui-ep/src/index.ts` 新增四件与类型、投影、两个工具导出；`apps/desktop/src/styles/tokens.scss` 新增 `--bms-org-*` 组（亮 / 暗两套，只增不改）。
14. **用例**：`ui-ep/tests/field-org-select.spec.ts` 32 条（契约套件适配 + 占位契约复用 + 投影 + 五件 + 工具）；`interaction-form-renderer.spec.ts` 补组织字段协同用例；既有 `ui-ep/tests/field-placeholder.spec.ts`（`06_01` 冻结契约）**未改动即通过**。
15. **宿主核对页**：`apps/desktop/org-check.html` + `src/dev/{orgCheck.ts,OrgCheck.vue}`（12 项自检），`vite build` 不包含；经 chromium CDP 轮询等待自检项渲染到位后导出 DOM 核验 **12/12**（连续 3 次稳定）。

## 5. 偏差与遗留 <a id="deviations"></a>

- **工时偏差**：名义 12h；因选项源能力重挂值链、用户展示能力扩展、新增 1 个组件基类、1 套插件轨、1 份领域纯函数、1 套契约套件、1 套投影、2 个工具、五件组件、1 个核对页与表单渲染协同，实际上浮。
- **既有基类调整**（均为兼容变更，登记见《前端基类清单》）：`BaseOptionSource` 父基类 `BaseComponent` → `BaseField`（依赖登记改 `['field']`）；`BaseUserDisplay` 新增花名册（字段 / 方法只增不改）。
- **对外契约扩展**（向后兼容）：`OrgSelectField` 新增可选 Props（`kind` / `searchable` / `source` / `userDisplay` / `limit` / `status` / `deptId` / `includeChildren` / `showIncludeChildren` / `readonly` / `required` / `errorMessage` / `emptyText` / `clearable` / `collapseAfter` / `showAvatar` / `showCode`）、事件（`retry` / `invalid` / `limit-exceed` / `update:deptId` / `update:includeChildren`）与插槽（`empty` / `option` / `prefix`）；既有 Props / 事件 / 插槽 / `data-test` 不变；补齐 `06_01` 契约表已登记但原实现遗漏的 `searchable`。
- **核心面新增**（只增不改）：新增组件基类 `BaseOrgSelect`（父 `BaseOptionSource`）与插件基类 / 注册项 / 注册表 `BaseOrgSource` / `OrgSourceProvider` / `OrgSourceRegistry`；`domain/org.ts` 与契约套件 `describeOrgSelectContract`；投影补充 `page` / `total` / `limit` / `errorCode` / `errorMessage` 响应式面与 `setPage` / `setLimitExceeded`（复合弹窗分页与超限标记所需）。
- **表单渲染协同**：`dept` 字段类型改映 `org-select`（`kind=dept`）；`MULTIPLE_WIDGETS` 纳入 `org-select` 并作为多选语义唯一来源；`FormRendererBody` 新增 `extraProps` 透传 `kind`——`08_06` 任务文档已补协同契约注块。
- **真实联调**：组织数据源经注入式 `OrgSourceAdapter` 注入（未注入即占位零请求），内建 HTTP 实现以默认键 `http` 登记；真实取数 / 数据范围过滤 / 字段脱敏 / 权限码（`user:query` / `post:query` / `dept:query`）归**阶段七（RBAC）窗口**；宿主「组织相关 store」版数据源经注册表登记接入（接口就位）。
- **数据范围口径**：后端出口实现侧强制过滤与脱敏（调用方不可绕过），前端不二次过滤；部门树件只透传 `include_children`。
- **遗留**：真实 RBAC 取数与数据范围 / 脱敏联调（归口阶段七）、移动端实现（契约套件 `describeOrgSelectContract` 与投影就位供同契约多实现）、字典字段（`06_06`）是否经重挂后的 `BaseOptionSource` 派生待其设计确认。
- **对齐回写**：实施期口径调整已回写[详细设计 §10 实施对齐记录](../设计/01_详细设计_05_组织选择字段.md#align)（查询归一函数 / 分页与超限 setter / 补充可选 Props / 投影响应式面 / Kiwi 962 / 核对页核验方式）。
