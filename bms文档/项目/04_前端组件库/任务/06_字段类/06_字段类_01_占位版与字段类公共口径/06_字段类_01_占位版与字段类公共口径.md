## 2. 任务内容 <a id="content"></a>

1. **字段类公共口径**：在域 05 输入域包装之上补齐字段类共性——字段壳装配（label / 必填 / 错误 / 栅格 / 帮助文本，消费字段壳能力 `field-shell` 与字段权限能力 `field-perm`）、只读回显（`disabled` 或纯文本，只读文本经 `displayText` 覆盖，不做两套组件）、占位与降级语义（后端未就绪不发请求，呈现空态 / 禁用态 / 降级提示，反馈口径与域 03 异常与空状态 `03-2` 一致）、校验触发与三态行为在包装层定义一次；core 侧如需新增字段类契约项，按「候选 → 设计节点 → 评审 → 清单登记」流程先行登记。
2. **占位件骨架（4 类）**：`DictSelect`（字典下拉占位）、`UserSelectField` / `OrgSelectField`（组织选择占位）、`FileUploadField`（上传占位）、`Captcha`（验证码占位）——Props / 事件 / 插槽契约与字段壳装配先行落地，双端同契约（`frontend/packages/ui-ep/src/components/field/` 与 `frontend/packages/ui-vant/src/components/field/`）。
3. **占位契约测试**：覆盖占位态渲染、禁用态、降级分支与契约形状（不写死数据）；`@bms/core/testing` 契约套件新增「字段类占位契约」断言组，双端同一套断言。
4. **回补衔接**：`06_07` ~ `06_10` 落地真实实现时只改数据通路、不改对外契约；本任务交付的占位件即四件的本体（同一件两段式，不重建组件）。
5. **用例**：本条 1 条 Kiwi 用例（先登记后编码，自动化标注 `kiwi_id`，双端同号，760）。
6. **实现以《组件设计》节点**「01 字典字段」「05 组织选择字段」「06 文件上传字段」「10 验证码」及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. **上游登记清单（建任务时列出，随实施逐个确认并回写）**：字典节点「需同步的既有设计」8 条、组织选择与文件上传节点的「依赖接口与上游变更」表、验证码节点「需登记的上游变更」3 条（详见父任务[上游登记](../06_字段类.md#effort)）。
8. 详细设计随任务启动在 `设计/` 下补建；实施记录与测试记录于任务完成后生成。

## 3. 完成标准 <a id="accept"></a>

字段类公共口径可用（字段壳装配 / 只读回显 / 占位降级语义 / 校验触发一次定义，后续字段件统一消费）；4 类占位件可被页面引用且**不产生后端请求**，呈现空态 / 禁用态 / 降级提示；占位契约测试通过并纳入前端门禁；回补四件（`06_07` ~ `06_10`）确认只需替换数据通路；`prettier --check`（仅本任务文件）、ESLint、`vue-tsc`、Vitest、构建与体积预算全通过。
