## 1. 设计目标与范围 <a id="goal"></a>

两件：**数值字段**（`number`，精度 / 范围 / 步进）与**金额字段**（**十进制字符串（元）+ `precision` 0~6**，支持厘 / 毫等自定义小数位）。核心提供**定点纯函数**（归一 / 比较 / 范围判定 / 最小单位换算），避免浮点误差。

不在本期：币种汇率换算；字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 核心定点纯函数 <a id="decimal"></a>

```ts
normalizeDecimal(value: string | number, precision: number): string   // 四舍五入到 precision 位（去尾零，整数位保留）
compareDecimal(a: string | number, b: string | number): -1 | 0 | 1
isDecimalInRange(value: string | number, options: { min?: string; max?: string; precision: number }): boolean
toMinorUnits(value: string | number, precision: number): bigint      // 字符串移位，无浮点参与
fromMinorUnits(units: bigint, precision: number): string
```

- 精度上限 6（厘 3 / 毫 4 …）；`precision` 非法（负数 / 超 6）取 0 并开发态告警。
- 全程**以字符串 / BigInt 运算**，不引入浮点。

### 3.2 组件契约 <a id="components"></a>

| 件 | 值载体 | Props（除通用） | Events |
| --- | --- | --- | --- |
| `NumberField` | `number` | `min` / `max` / `step` / `precision` / `thousandSeparator` | `update:modelValue` / `change` / `invalid` |
| `AmountField` | `string`（元） | `precision`（缺省 2，0~6）/ `currency` / `min` / `max` / `thousandSeparator` | `update:modelValue` / `change` / `invalid` |

- 通用：`modelValue` / `required` / `disabled` / `readonly` / `placeholder` / `errorMessage`。
- 校验（组件内 + `invalid`）：必填、范围（`min` / `max` 按定点比较）、精度（超出位数先归一，不可归一则非法）；`errorMessage` 外部覆盖。
- 展示：数值经 `thousandSeparator`；金额经核心 `formatAmount`（币种 / 精度）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 非数字文本 | 视为空值 / 非法 → `invalid('请输入数字')` |
| 超出 `precision` 小数位 | 归一（四舍五入）后回写；不可归一则 `invalid` |
| `precision` 非法 | 取 0 并告警 |
| 超出 `min` / `max` | `invalid('不能小于 … / 不能大于 …')` |
| 金额空值且 `required` | `invalid('该字段为必填项')` |
| 大数（超双精度） | 金额路径全程字符串 / BigInt，不失真 |
