## 1. 设计目标与范围 <a id="goal"></a>

树选择字段：单选 / 多选（含父子联动策略 `checkStrictly`）、本地树数据与懒加载、搜索过滤、只读路径回显；空 / 加载 / 错误三态经 `03_02` 口径呈现。树数据语义经树组件基类 `BaseTreeData`，件经 `useBaseInput` 挂链。

不在本期：远程搜索接口（随组织字段 `06_05`）；字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
interface TreeFieldNode { key: string; label: string; disabled?: boolean; children?: TreeFieldNode[] }

props: modelValue（单值 | 数组）/ data / multiple / checkStrictly / searchable
       / lazy / load（node => Promise<TreeFieldNode[]>）/ readonly / required
       / disabled / placeholder / emptyText / errorMessage
events: update:modelValue / change / invalid / retry
```

- 多选：`modelValue` 为数组；`checkStrictly=false` 时父子联动（EP 口径），为真时独立勾选。
- 懒加载：`lazy` + `load(node)`；加载中展示加载态；`load` 抛错 → 错误态 + `retry` 事件（重试由宿主触发）。
- 只读：`readonly` 时以**路径文本**回显（`label / label / label`），不回传新值。
- 校验：`required` 空值 → `invalid('该字段为必填项')`；值不在树中 → `invalid('选项不在树中')`（不静默改值）。
- 三态：`data` 为空 → `EmptyState(type="data")`；`load` 失败 → 错误文案 + 重试入口。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `data` 为空 | 渲染 `EmptyState(type="data")`（可插槽覆盖） |
| 懒加载抛错 | 错误态 + `retry`；不清空已选值 |
| 只读且值不在当前树 | 回显已选键（降级为键文本） |
| 单选收到数组 / 多选收到单值 | 归一（取首值 / 包成数组）并开发态告警 |
| 值不在树中 | `invalid('选项不在树中')` |
| `required` 空值 | `invalid('该字段为必填项')` |
