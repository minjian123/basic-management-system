## 1. 设计目标与范围 <a id="goal"></a>

三件：**开关字段**（三态）、**列表内联切换**（保存中 / 失败回滚）、**枚举字段**（自定义选项集，下拉为默认 + 可切单选形态）。

不在本期：字段语义的后端对接（`06-2` 边界内仅静态选项集与前端提交接口）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

| 件 | 值 | Props（除通用） | Events |
| --- | --- | --- | --- |
| `SwitchField` | `boolean \| undefined`（三态） | `required` / `confirm` / `activeText` / `inactiveText` | `update:modelValue` / `change` / `invalid` |
| `InlineSwitchCell` | `boolean \| undefined` | `save: (value) => Promise<void>` / `loading` | `update:modelValue` / `change` / `saved` / `invalid` |
| `EnumField` | `string \| number \| undefined` | `options` / `form: 'select' \| 'radio' \| 'button'` / `required` | `update:modelValue` / `change` / `invalid` |

- 通用：`modelValue` / `disabled` / `readonly` / `placeholder` / `errorMessage`。
- 开关字段：`undefined` 表示未设置；`required` 时未设置 → `invalid('该字段为必填项')`；危险切换确认复用 `03_01`。
- 内联切换：切换先置**保存中**（禁用交互）→ `await save(next)`；成功写值并发 `saved`；失败**回滚原值**并发 `invalid('保存失败，已回滚')`。
- 枚举字段：选项集自定义；`form` 切下拉 / 单选（`radio` / `button`）；`required` 空值校验。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 内联切换 `save` 抛错 | 回滚原值 + `invalid`，不写值 |
| 内联切换进行中再次点击 | 保存中禁用交互（不并发提交） |
| 开关 `required` 且未设置 | `invalid('该字段为必填项')` |
| 枚举选项为空 | 视为无可选项（禁用 + 降级提示） |
| 枚举收到不在选项集中的值 | 保留原值并开发态告警（不静默改值） |
| 外部 `errorMessage` 非空 | 优先展示外部文案 |
