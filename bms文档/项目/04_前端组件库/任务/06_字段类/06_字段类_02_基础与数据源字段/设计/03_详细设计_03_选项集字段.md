## 1. 设计目标与范围 <a id="goal"></a>

一件：**选项集字段**（自定义选项集，静态选项集；单选与多选）。

- 选项集解析（排序、去重、i18n、颜色、禁用）与只读回显由本件承载；候选项由字段层注入，控件不取数。
- 不在本期：字段语义的后端对接（`06-2` 边界内仅静态选项集与前端提交接口）；注册表选项集与 `dropdown` / `dropdown-multi` 形态由 [06_10 返工](../../06_字段类_10_选项集字段返工/06_字段类_10_选项集字段返工.md) 承接。

> 开关字段与列表内联切换已拆分为嵌套 06，见[06 详细设计 · 开关字段](06_详细设计_06_开关字段.md)。

## 3. 接口 / 契约与边界 <a id="contract"></a>

| 件 | 值 | Props（除通用） | Events |
| --- | --- | --- | --- |
| `OptionSetField` | `string \| number \| undefined` | `options` / `form: 'select' \| 'radio' \| 'button'` / `required` | `update:modelValue` / `change` / `invalid` |
| `OptionSetMultiField` | `(string \| number)[]` | `options` / `form: 'checkbox' \| 'tag'` / `required` / `min` / `max` | `update:modelValue` / `change` / `exceed` / `invalid` |

- 通用：`modelValue` / `disabled` / `readonly` / `placeholder` / `errorMessage`。
- 选项集字段：选项集自定义；`form` 切下拉 / 单选（`radio` / `button`）；`required` 空值校验。
- 多选：按选项集顺序去重输出，数量上下限越限派发 `exceed` 并回退原值。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 选项集为空 | 视为无可选项（禁用 + 降级提示） |
| 收到不在选项集中的值 | 保留原值并开发态告警（不静默改值） |
| 多选数量越限 | `exceed` + 回退原值，界面与值恒一致 |
| 外部 `errorMessage` 非空 | 优先展示外部文案 |
