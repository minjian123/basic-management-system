## 1. 设计目标与范围 <a id="goal"></a>

日期时间字段：日期 / 日期时间 / 日期区间 / 日期时间区间四形态；**对外值类型为 `Date` 对象**（区间为二元组）；组件内校验（区间顺序 / `min` / `max` / 必填）经 `invalid` 事件外发，错误位接受 `errorMessage` 外部覆盖。

不在本期：字段壳（label / 栅格）组装；时区展示口径的宿主级配置（`02_06` 格式化复用）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
type DateTimeKind = 'date' | 'datetime' | 'daterange' | 'datetimerange'
type DateTimeValue = Date | [Date, Date] | undefined

props: modelValue / kind / min / max / displayFormat / required / disabled / readonly / placeholder / errorMessage
events: update:modelValue / change / invalid(message) / focus / blur
```

- 值语义：`Date` 对象（不转字符串）；区间为 `[start, end]`。
- 校验：区间顺序（start ≤ end）、`min` / `max`、`required`；越界或非法时发 `invalid(message)`；`errorMessage` 非空时接管错误位。
- 只读态：`readonly` 透传（不换组件）；`disabled` 经投影合并。
- 展示格式：`displayFormat` 透传（缺省由 EP / 宿主格式化口径决定）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 区间起止倒置 | `invalid('开始时间不能晚于结束时间')` |
| 值早于 `min` / 晚于 `max` | 对应 `invalid` 文案 |
| 空值且 `required` | `invalid('该字段为必填项')` |
| 外部 `errorMessage` 非空 | 优先展示外部文案 |
| 非 `Date` 值传入 | 视为空值并保留原值（开发态告警） |
| 仅一端填写的区间 | 视为空值（不触发顺序校验） |
