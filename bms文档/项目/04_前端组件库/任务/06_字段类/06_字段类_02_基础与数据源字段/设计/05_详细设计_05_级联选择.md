## 1. 设计目标与范围 <a id="goal"></a>

级联选择：多级联动、任意级可选（`checkStrictly`）、多选、搜索、懒加载与**路径回显**；空态复用 `03_02`。件经 `useBaseInput` 挂链。

不在本期：远程搜索接口与业务级联数据源（如行政区划）；字段壳组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

```ts
interface CascadeOption { value: string; label: string; disabled?: boolean; children?: CascadeOption[] }
type CascadeValue = string[] | string[][] | undefined   // 单选为路径；多选为路径数组

props: modelValue / options / multiple / checkStrictly（任意级可选）/ searchable
       / lazy / load（node => Promise<CascadeOption[]>）/ readonly / required
       / disabled / placeholder / emptyText / errorMessage
events: update:modelValue / change / invalid / retry
```

- 值语义：**路径数组**（单选 `['a','a1']`；多选 `[['a','a1'],['b']]`），与后端「路径 / 编码」口径一致，便于只读回显。
- 任意级可选：`checkStrictly=true` 时任意层级均可作为末级。
- 懒加载：`lazy` + `load(node)`；失败 → 错误态 + `retry`（保留已选路径）。
- 只读：按路径回显 `label / label`（缺路径时降级为值文本）。
- 校验：`required` 空值；路径不在选项树中 → `invalid('选项不在级联中')`。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `options` 为空 | 渲染 `EmptyState(type="data")` |
| 懒加载抛错 | 错误态 + `retry`；不清空已选 |
| 路径不完整（父级未加载） | 只读按已选值降级回显；可编辑态按需补取（宿主传 `load`） |
| 单选收到路径数组的数组 / 多选收到单路径 | 归一（告警） |
| 值不在选项树中 | `invalid('选项不在级联中')` |
| `required` 空值 | `invalid('该字段为必填项')` |
