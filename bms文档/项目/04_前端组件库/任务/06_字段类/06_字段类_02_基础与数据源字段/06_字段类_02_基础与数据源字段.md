## 3. 任务内容 <a id="content"></a>

1. 五类字段在 `05_01` 八件基础控件之上扩展，均派生输入组件基类 `BaseInput` 并叠加相应能力基类（值 / 字段 / 选项源 / 树数据）。
2. 格式化与校验统一复用 `02_06`（时区 / 精度 / 金额格式化），不在字段内重复实现。
3. 树数据经树组件基类 `BaseTreeData`；不可用能力降级不抛错。
4. Vitest 覆盖格式化、校验与懒加载回显分支。

## 4. 完成标准 <a id="accept"></a>

五类字段可用并按 locale / 时区正确展示；校验规则生效；Vitest 覆盖格式化与校验契约；`vue-tsc`、ESLint、Vitest 全通过。
