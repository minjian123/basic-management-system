## 2. 任务内容 <a id="content"></a>

1. 滚动 / 懒加载 / 全屏 / 自适应高度 / 虚拟列表 / 加载遮罩 / 分区 / 宽高比八件。
2. 依赖口径（2026-09-15 重排确认）：`LoadingContainer` 的 loading / 空 / 错误四态**复用 06/03 异常与空状态**的 `SkeletonBlock` / `EmptyState` / `LoadingMask`（不重复自绘），本任务只做容器编排、四态优先级与延迟显示防闪烁；错误重试入口经 `usePlaceholder` 占位语义。
2. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
3. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
4. 详细设计随任务启动时补建（按前序任务完成情况调整口径）。
