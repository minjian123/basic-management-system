## 1. 设计目标与范围 <a id="goal"></a>

宿主薄壳 + 模块加载器接口 + 本地演示模块：模块按名加载 → 挂载（注册路由）→ 卸载；模块路由并入平台动态路由并与菜单 / 页签联动；加载失败经组件边界兜底。**本期不引入 Module Federation 依赖**，接口按后续运行时加载的远端模块预留。

不在本期：远端加载与 `shared` singleton、模块清单与版本发现 / 灰度 / 回滚（后续运行时加载）；模块契约与注册表基座（`10_02`）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 模块类型（核心） <a id="types"></a>

```ts
interface ModuleManifest { name: string; version: string; entry?: string }
interface ModuleRouteDeclaration { path: string; name?: string; component: () => Promise<unknown>; meta?: Record<string, unknown> }
interface ModuleRegistration { routes?: ModuleRouteDeclaration[]; components?: Record<string, unknown>; icons?: Record<string, unknown>; cards?: unknown[] }
interface ModuleHostContext { router?: unknown; store?: unknown; i18n?: unknown; user?: unknown; tenant?: unknown }
interface ModuleDefinition { manifest: ModuleManifest; setup(context: ModuleHostContext): ModuleRegistration | Promise<ModuleRegistration> }
interface LoadedModule { manifest: ModuleManifest; registration: ModuleRegistration }
```

- `defineModule(def)`：校验 `name`（`^[a-z][a-z0-9-]*$`）与 `version`（非空），返回冻结定义。
- **`token` 不入模块上下文**（宿主注入清单明确排除）。

### 3.2 加载器 <a id="loader"></a>

```ts
interface ModuleLoader {
  load(name: string): Promise<LoadedModule>
  mount(loaded: LoadedModule): void
  unmount(name: string): void
  isMounted(name: string): boolean
  mountedNames(): string[]
}
```

- `LocalModuleLoader implements ModuleLoader`：以本地模块定义表为源（阶段四静态 `import`）；`load` 未登记模块 → `BaseError(10002)`；`mount` 记录挂载，重复挂载拒重；`unmount` 幂等。
- **非基类实现物**（同请求层口径）：登记于《[前端基类清单](../../../../../../前端基类清单.md)》§9。

### 3.3 宿主装配与路由衔接 <a id="host"></a>

- `apps/desktop/src/module/host.ts`：构造 `LocalModuleLoader`（含演示模块定义），注入宿主上下文（`router` / Pinia / i18n / 用户 / 租户）；`mountModule(name)` → `load` → `mount` → 经 `registerModuleRoutes` 并入平台动态路由；`unmountModule(name)` 逆序卸载。
- `router/dynamic.ts` 扩展：`registerModuleRoutes(router, routes)`（跳过 `/` 与已存在路径，`meta.title` 取自声明）/ `unregisterModuleRoutes(router, paths)`。
- 菜单 / 页签联动：演示模块路由的 `meta.title` / `meta.keepAlive` 与 `03_04` 菜单、`03_03` 页签口径一致；**演示分组仅开发态**追加到侧边菜单（生产不显示）。

### 3.4 模块边界 <a id="boundary"></a>

- `ModuleBoundary.vue`：包裹模块视图（`<router-view>` 内容）；`onErrorCaptured` + 路由异步加载失败（`router.onError`）写入宿主模块错误态 → 渲染 `ErrorPage(500)`，错误信息带模块名与版本；支持重试（重挂载）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未登记模块名 | `load` 抛 `BaseError(10002)`，宿主记录并提示 |
| 重复挂载同一模块 | 拒重（保留首次），开发态告警 |
| 模块 `setup` 抛错 | `mountModule` 捕获 → 模块错误态 + 边界兜底 |
| 模块路由路径冲突 | 跳过已存在路径（不覆盖平台路由） |
| 卸载未挂载模块 | 幂等无操作 |
| 演示模块在生产构建 | 菜单不展示（仅开发态追加），路由仍可加载 |
| 模块组件异步加载失败 | `router.onError` → 边界渲染错误页 + 重试 |
