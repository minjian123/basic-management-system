## 2. 任务内容 <a id="content"></a>

1. **宿主注入上下文契约**：`router` / Pinia / i18n / 当前用户与租户上下文（**`token` 不落模块持久化**）——注入清单与只读约束成文；模块侧统一经模块上下文能力基类 `BaseModuleContext` 消费（冻结只读快照）。
2. **模块注册声明契约**：模块对外提供的路由 / 菜单 / 页面区域 / 组件 / 字段渲染器 / 图标 / 工作台卡片等注册声明的字段与校验规则（**唯一性**、**路径前缀**）。
3. **注册表基座最小实现**：落核心 `core/src/registries/`——路由·菜单、通用组件、字段渲染器、图标、工作台卡片五个注册表，基于统一提供者注册表基座 `BaseProviderRegistry` 与注册项公共契约 `BaseProvider`（`02_05`），供模块注册与平台自身注册共用；「**不注册不可用**」护栏在本需求落地。
4. **一致性基础**：设计令牌（经设计令牌能力基类 `BaseDesignToken`）与组件契约保持可被模块复用的形态；**样式作用域约束**（Scoped + 前缀；禁止改全局原型、禁止挂全局事件与全局样式）。
5. **契约文档化**：以《[架构设计 · 前端架构](../../../../../设计/架构设计/08_架构设计_前端架构.md)》「模块治理要求」表为上位依据，输出模块契约说明（注入清单 / 注册声明 / 校验规则 / 样式约束），并回写《[前端基类清单](../../../../../前端基类清单.md)》§9 落点。
6. 演示模块实际使用上述契约（注册路由 / 组件 / 图标 / 卡片），并验证未注册项不生效、样式不污染宿主。

## 3. 完成标准 <a id="accept"></a>

宿主注入上下文、模块注册声明与注册表基座（路由·菜单、组件、字段渲染器、图标、工作台卡片）契约成文并被演示模块实际使用；设计令牌与组件契约可被演示模块复用；样式作用域约束生效（演示模块不污染宿主）；未注册项不生效；Vitest 覆盖注册声明校验分支；`vue-tsc`、ESLint、Vitest 全通过。
