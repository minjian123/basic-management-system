## 1. 设计目标与范围 <a id="goal"></a>

模块契约与注册表基座：宿主注入上下文契约（只读、**`token` 不入清单**）、模块注册声明契约（唯一性 / 命名空间键 / 路由路径）、五个扩展点注册表最小实现（路由·菜单 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片）、一致性基础（设计令牌与组件契约复用、样式作用域约束）与契约文档化。

不在本期：隔离增强（Shadow DOM / 沙箱）、版本协商、模块清单 / 灰度 / 回滚、按模块观测（阶段五）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 注册项与键 <a id="providers"></a>

| 注册表 | 注册项 | 键规则 |
| --- | --- | --- |
| 路由·菜单 | `RouteMenuProvider(key, path, title, icon?)` | 键 = 路由名；`path` 须以 `/` 开头 |
| 通用组件 | `ComponentProvider(key, component)` | 命名空间键 `<ns>:<key>`（kebab） |
| 字段渲染器 | `FieldRendererProvider(key, component, fieldType?)` | 命名空间键；另可按 `fieldType` 解析 |
| 图标 | `IconProvider(key, source)` | 命名空间键 |
| 工作台卡片 | `WorkbenchCardProvider(key, component, title?)` | 命名空间键 |

- 各注册表均继承 `BaseProviderRegistry`：**同键唯一性拒重**（`REGISTRY_CONFLICT`）、保序、只读快照；注册项继承 `BaseProvider`。
- `REGISTRY_KEY_PATTERN = ^[a-z][a-z0-9-]*:[a-z][a-z0-9-]*$`；模块注册项命名空间须为**模块名**。

### 3.2 宿主注入上下文契约 <a id="context"></a>

| 注入项 | 说明 |
| --- | --- |
| `router` | 路由实例（模块不得替换） |
| `store` | Pinia 实例（模块不得注册全局 store 冲突） |
| `i18n` | 国际化实例 |
| `user` / `tenant` | 当前用户与租户（**只读**） |
| **`token`** | **不注入**（模块不得持久化凭据） |

- 契约类型 `ModuleHostContext`（`10_01`）；上下文经 `BaseModuleContext` 冻结为只读快照。

### 3.3 注册装配（模块只声明、宿主逐项注册） <a id="apply"></a>

```ts
applyModuleRegistration(moduleName: string, registration: ModuleRegistration): void
```

- `components` / `icons` / `cards` 逐项倒入对应注册表；键须以 `<moduleName>:` 前缀（不满足 → `BaseError(CAPABILITY_VIOLATION)`）。
- 路由经 `registerModuleRoutes`（`10_01`，跳过 `/` 与已存在路由名）。
- 「**不注册不可用**」：解析入口 `registries.*.get(key)` 未命中返回 `undefined`，由使用方降级。

### 3.4 一致性基础与样式约束 <a id="consistency"></a>

- 设计令牌（`BaseDesignToken`）与组件契约保持可被模块复用（演示模块直接引用 `@bms/ui-ep` 组件与 `--bms-*` 令牌变量）。
- **样式作用域**：模块与组件 `<style>` 一律 `scoped`；禁 `:global` / 全局样式导入；禁改全局原型（`Object.prototype` 等）；机器护栏 `guard-module-style.spec.ts` 拦截。

### 3.5 契约文档化 <a id="doc"></a>

- 新增架构节点《[前端模块契约](../../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》（`设计/架构设计/35_架构设计_前端模块契约.md`）（注入清单 / 注册声明 / 键与路径规则 / 样式约束 / 不注册不可用），并在《[架构设计 · 前端架构](../../../../../../设计/架构设计/08_架构设计_前端架构.md)》§9 与文档首页、基座文档清单登记。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 同键重复注册 | 注册表拒重（`REGISTRY_CONFLICT`） |
| 键无命名空间 / 命名空间非本模块 | 抛 `CAPABILITY_VIOLATION` |
| 路由路径不以 `/` 开头 | 抛 `CAPABILITY_VIOLATION` |
| 解析未注册键 | 返回 `undefined`（不替调用方兜底） |
| 模块样式未 `scoped` / 用 `:global` | 护栏用例失败（CI 拦截） |
| 模块改全局原型 | 护栏用例失败 |
