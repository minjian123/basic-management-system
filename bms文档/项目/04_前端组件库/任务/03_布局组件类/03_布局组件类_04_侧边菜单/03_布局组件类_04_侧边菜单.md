## 2. 任务内容 <a id="content"></a>

1. 侧边菜单与菜单节点：动态菜单树渲染、折叠 / 展开、搜索过滤、图标与徽标、多级展开互斥。
2. 菜单到路由的注册 / 卸载统一经动态路由能力基类 `BaseDynamicRoutes`；权限过滤经权限上下文能力基类 `BaseAccess`，权限指令复用 `02_06`。
3. 菜单树未就绪时以占位菜单树驱动（对齐占位语义）；真实菜单树接入随后续阶段。
4. 菜单树由后端按权限下发（前端不硬编码路由表）；样式与交互对齐 Element Plus 与《布局设计》导航节点。

## 3. 完成标准 <a id="accept"></a>

侧边菜单可用（折叠 / 搜索 / 徽标 / 多级）、与路由联动正确；占位菜单树可驱动完整交互；Vitest 覆盖菜单树渲染与权限过滤分支；`vue-tsc`、ESLint、Vitest 全通过。
