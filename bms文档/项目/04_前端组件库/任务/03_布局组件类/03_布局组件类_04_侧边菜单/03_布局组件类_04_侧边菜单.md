## 2. 任务内容 <a id="content"></a>

1. `SideMenu.vue` / `MenuNode.vue`（`src/components/menu/`）：动态菜单树递归渲染（`name` / `path` / `component` / `icon` / `sort` / `hidden` / `children` / `badge?`）、折叠图标态与 hover 展开、当前高亮 + 父级自动展开、子菜单展开（`uniqueOpen` 手风琴）、菜单搜索（本地过滤 + 命中路径展开 + 空态）、图标经 `IconDisplay` 渲染（图标选择器归交互类回补，缺失降级）、徽标（口径同通知与消息）、`hidden` 过滤、外链、深度建议、折叠状态持久化（`usePersistedState`）。
2. 菜单 → 路由的注册 / 卸载统一经动态路由片段 `useDynamicRoutes`（前端不硬编码路由表）；权限过滤经权限上下文片段 `useAccess`（`02_03`）；权限指令复用 `02_06`；点击叶子菜单与页面级标签联动（`03-3` 多标签导航契约）。
3. **占位先行**：后端菜单树下发（`GET /menus/my`，阶段七 ~ 八）未就绪，以占位菜单树驱动（不发请求、对齐占位语义），组件契约（选中 / 折叠 / 搜索 / 徽标 / 路由与页签联动）按目标契约实现并纳入契约测试；真实菜单树下发接入随阶段七 ~ 八（菜单管理 / RBAC）就绪后按同一契约回补，回补时补设计、实施与记录（计划 §3.1 第 25 行）。
4. 样式与交互对齐 Element Plus 菜单与《布局设计》导航节点；组合布局片段（`useLayout` / `useContainer`），令牌消费（`03-6`）。
5. 实现以《组件设计》「13 侧边菜单」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. **前置契约（已交付）**：[03 片段机制与预置片段](../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（2026-09-16 交付）的 `useAccess`（权限码集合与菜单过滤，占位空集）/ `useDynamicRoutes`（路由注册 / 卸载，占位菜单源）/ `useLayout` / `usePersistedState` 片段；[06 基础类横切底座](../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)（2026-09-16 交付）的 `v-perm` / `hasPerm` 与权限 store，本任务直接复用不重复实现。
7. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建（占位版先行，真实菜单接入回补时另行设计）。
