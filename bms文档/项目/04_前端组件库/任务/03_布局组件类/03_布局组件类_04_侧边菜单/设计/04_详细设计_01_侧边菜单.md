## 1. 设计目标与范围 <a id="goal"></a>

侧边菜单：动态菜单树渲染、折叠 / 展开、搜索过滤、图标与徽标、多级展开互斥；菜单 → 路由的构建 / 注册 / 卸载统一经动态路由能力基类 `BaseDynamicRoutes`；权限过滤经权限码判定（复用 `02_06` 的 `canAccess`）；菜单树未就绪时以**占位菜单树**驱动完整交互。

不在本期：后端按权限下发菜单与登录后菜单拉取（随认证 / RBAC 阶段）；主框架布局壳与菜单装配（`03_05`）；移动端导航（范围外）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `MenuNode` 与纯函数 <a id="menu-node"></a>

```ts
interface MenuNode {
  path: string          // 路由路径（唯一）
  title: string
  name?: string         // 路由名（缺省用 path）
  icon?: string
  badge?: string | number
  permission?: string   // 权限码（空表示公开）
  children?: MenuNode[]
}

filterMenuByPermission(menu, can: (code: string) => boolean): MenuNode[]
filterMenuByKeyword(menu, keyword: string): MenuNode[]   // 命中节点保留其祖先链
flattenMenu(menu): MenuNode[]
findMenuByPath(menu, path): MenuNode | undefined
toRouteNodes(menu): RouteNode[]                            // 供 BaseDynamicRoutes.build
PLACEHOLDER_MENU: MenuNode[]                               // 占位菜单树（覆盖多级 / 徽标 / 权限项）
```

- 关键词匹配：`title` 或 `path` 不区分大小写包含；父节点命中则保留整棵子树。
- 权限过滤：`permission` 缺省视为公开；子节点全被过滤掉且自身无权限的空父节点一并剔除。
- 占位菜单树覆盖：两级以上层级、徽标、权限项（`system:user:list` 等），供未接后端时驱动完整交互。

### 3.2 `useSideMenu` <a id="use-side-menu"></a>

```ts
useSideMenu(options?: { menu?: MenuNode[]; canAccess?: (code: string) => boolean }): {
  menu: Ref<MenuNode[]>          // 权限过滤后的菜单树
  keyword: Ref<string>
  filtered: Ref<MenuNode[]>      // 关键词过滤后的菜单树
  setKeyword(value: string): void
  routes: Ref<string[]>          // 已注册路由路径
  routePaths: string[]           // 由菜单树构建的路径清单
  register(): string[]           // 注册（去重、保序）
  unregister(path?: string): void
}
```

- 内部实例化核心 `BaseDynamicRoutes` 派生状态类；`build` / `register` / `unregister` 由核心承载。
- 权限过滤使用 `filterMenuByPermission`；`canAccess` 缺省为「全部放行」。

### 3.3 `SideMenu` / `SideMenuItem` <a id="side-menu"></a>

- **`SideMenu` Props**：`menu: MenuNode[]`、`activePath: string`、`collapsed?`、`uniqueOpened?`（缺省 true）、`collapsible?`、`showBadge?`（缺省 true）、`searchable?`（缺省 true）。
- **Events**：`select(path)` / `update:collapsed` / `search(keyword)`。
- **Slots**：`logo` / `footer`。
- 渲染：`el-menu`（`router` 关闭，采用 `select` 事件跳转由宿主决定）+ `el-sub-menu` / `el-menu-item` 递归；徽标用 `el-badge`；搜索框在菜单上方（`searchable` 时）。
- 多级展开互斥：`unique-opened`；折叠态只显示图标（`collapse` + `el-tooltip` 由 EP 承载）。

### 3.4 宿主动态路由接线 <a id="host"></a>

- `apps/desktop/src/router/dynamic.ts`：`installMenuRoutes(router)` 用占位菜单树构建路径、跳过静态已存在路由与 `/`，为其余路径注册指向 `PlaceholderView` 的占位路由（`meta.title` 取自菜单），返回注册清单。
- `PlaceholderView.vue`：复用 `EmptyState`，呈现「页面建设中」与目标路径，保证「菜单点击 → 路由跳转 → 占位页」闭环。
- `main.ts` 在挂载前调用 `installMenuRoutes(router)`。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 无权限的菜单项 | 过滤剔除；父节点因此为空则一并剔除 |
| 关键词无命中 | 返回空数组（菜单区走空态，由宿主决定） |
| 重复注册路径 | `BaseDynamicRoutes.register` 去重保序 |
| 与静态路由同路径 | 跳过，不覆盖静态路由 |
| `path === '/'` | 不注册占位路由（首页已有实现） |
| 卸载单个路径不存在 | 静默忽略 |

## 7. 边界与开放项 <a id="open"></a>

- 真实菜单树来自后端按权限下发（认证 / RBAC 阶段）；本期以占位菜单树驱动并保留 `permission` 字段语义。
- 菜单图标资源登记（图标集）随主题与图标任务；本期 `icon` 仅透传。
- 主框架内菜单装配（折叠联动、页签联动）随 `03_05`。
