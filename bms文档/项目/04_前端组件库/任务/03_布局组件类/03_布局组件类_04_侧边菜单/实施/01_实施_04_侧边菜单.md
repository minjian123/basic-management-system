结果小结：`SideMenu`（`el-menu` 渲染 / 折叠 / 搜索父链过滤 / 高亮 + 父级自动展开 / `unique-open` / 徽标可选 / 外链新窗口）与 `MenuNode`（递归渲染）落地；菜单数据层 `stores/menu.ts`（占位 loader 可注入 / 展开集持久化 `bms_menu_expanded` / 搜索过滤 / `expandByPath`）；占位菜单树 `config/placeholder-menu.ts`；路由守卫 `router/guard.ts` 接入（`public` / 无 token 登录占位 / `meta.perm` → 403）。

## 3. 实施过程 <a id="process"></a>

1. 上下文：读节点 §3 / §4、布局设计导航 / 主框架、`useAccess` / `useDynamicRoutes` / `tokenManager` / `canAccess` 契约（均已交付）。
2. 决策确认（用户）：徽标按节点支持可选；路由守卫本次接入；Pinia `stores/menu.ts`；用例 737 / 738。
3. 实现：`placeholder-menu.ts`（两级为主 + 多级 / 外链 / hidden 演示，无徽标）；`stores/menu.ts`（`configureLoader` 占位 / `load` 不发请求空清单 / `sortVisible` / `filterMenuTree`（保留父链）/ `findAncestorKeys` / 展开集持久化）；`components/menu/{types.ts, MenuNode.vue, SideMenu.vue, index.ts}`（`el-menu` + 递归 / 搜索输入 / 空态 `EmptyState` / 叶子点击 `el-menu select` 统一处理）；`router/guard.ts` + `routes.ts`（错误页 `meta.public` + 守卫注册）。
4. Kiwi 登记（`register_cases.py`）：737 / 738；用例两件（10 条）；验证全通过。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | 受控 `menus` 未过滤 `hidden` / 未排序 | 过滤排序原仅存于 store | 组件 `source` 统一经 `sortVisible`（含 store 导出）；设计对齐记录 9 |
| 2 | 设计 `collapse-change` 事件无产生方 | 折叠由宿主控制 / 持久化 | 移除该事件；设计已回写（对齐记录 7） |
| 3 | 图标降级措辞二选一 | 设计写「不渲染 / 首字符占位」 | 取「缺省不渲染」（`icon` 保留待 `IconDisplay`）；设计措辞说明（对齐记录 10） |
| 4 | 徽标用例 `mountWithPlugins` 解构误用（返回 wrapper 非 `{ wrapper }`） | 测试笔误 | 修测试（一次性） |
| 5 | 登录页未就绪时守卫跳 `/login` 会落 404 | 页面任务未交付登录页 | 守卫检测 `router.resolve('/login').matched` —— 未就绪放行占位（请求层 401 兜底）；设计已含 |
