## 1. 设计目标与范围 <a id="goal"></a>

多标签导航（含表单框架双层页签）：页签与路由双向同步、关闭语义（当前 / 其他 / 右侧 / 全部）、刷新当前、右键菜单、keep-alive 清单、会话内持久化恢复。页签状态统一经页签能力基类 `BaseTabs`；关闭确认复用 `03_01` 的 `useConfirm`。

不在本期：菜单运行时与动态路由生成（`03_04`）；移动端页签形态（范围外）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 页签项 <a id="tab-item"></a>

```ts
interface TabNavItem {
  key: string          // 路由 fullPath（唯一）
  title: string        // 标题（路由 meta.title）
  path: string         // 跳转路径
  name?: string        // 路由 name
  icon?: string
  closable?: boolean   // 缺省 true；首页等固定页签为 false
  dirty?: boolean      // 脏数据标记（关闭前确认）
}
```

### 3.2 `useTabNav` <a id="use-tab-nav"></a>

```ts
useTabNav(options?: { storageKey?: string; initial?: TabNavItem[] }): {
  tabs: Ref<TabNavItem[]>
  activeKey: Ref<string>
  cachedKeys: Ref<string[]>            // keep-alive 名单 = meta.keepAlive ∩ 已打开
  open(tab: TabNavItem): void          // 打开 / 激活（存在则激活）
  activate(key: string): void
  close(key: string): Promise<boolean> // 单关（脏数据经 confirm；固定页签拒绝）
  closeOthers(key: string): Promise<void>
  closeRight(key: string): Promise<void>
  closeAll(): Promise<void>
  refresh(key: string): void           // 移除其缓存 key 以触发重建
}
```

- 持久化：本地即时状态经 `useBasePersistedState`（`BasePersistedState`）承载，`sessionStorage[storageKey]` 仅作存储 IO 适配（存 `{ tabs, activeKey }`）；初始化恢复并过滤已不存在的路由。
- 脏数据关闭：`useConfirm()` 二次确认，取消则不关闭。
- `cachedKeys` 仅取「已声明 `meta.keepAlive === true` 且已打开」的路由。

### 3.3 `TabNavBar` <a id="tab-nav-bar"></a>

- **Props**：`tabs: TabNavItem[]`、`activeKey: string`、`maxVisible?`（超出折叠进「更多」）。
- **Events**：`select(key)` / `close(key)` / `close-others(key)` / `close-right(key)` / `close-all` / `refresh(key)`。
- 右键菜单项：刷新 / 关闭 / 关闭其他 / 关闭右侧 / 关闭全部；固定页签禁用关闭类操作。

### 3.4 `DualTabs` <a id="dual-tabs"></a>

- **Props**：`primary: TabNavItem[]` / `primaryKey`、`secondary: TabNavItem[]` / `secondaryKey`。
- 上层为业务分组，下层为组内页签；下层切换不改上层。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 关闭脏数据页签 | `useConfirm` 二次确认；取消则不关闭 |
| 关闭最后一个页签 | 保留至少一个页签；无页签回首页 |
| 关闭当前页签 | 激活右邻，否则左邻 |
| 恢复的页签已不存在于路由 | 初始化时过滤掉 |
| 固定页签（`closable: false`） | 关闭类操作拒绝并返回 `false` |
| `sessionStorage` 不可用（隐私模式） | 降级为不持久化，不抛错 |
