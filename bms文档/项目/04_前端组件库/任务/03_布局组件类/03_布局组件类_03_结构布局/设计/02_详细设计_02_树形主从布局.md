## 1. 设计目标与范围 <a id="goal"></a>

树形主从布局：左侧树（可搜索 / 过滤）+ 右侧主区，选中树节点驱动主区内容；可调分割（自研轻量）；无选中 / 空树走空态（`03_02`）。树数据经树组件基类 `BaseTreeData`；布局件经布局组件基类 `BaseLayout`。

不在本期：完整树件（域 05 字段 / 树类）；虚拟滚动随大数据量优化任务。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `TreeMasterDetail` <a id="tmd"></a>

- **Props**：`treeData: TreeNode[]`、`selectedKey?`、`treeWidth?`（缺省 280）、`minTreeWidth?`（缺省 200）、`maxTreeWidth?`（缺省 480）、`resizable?`（缺省 true）、`filterPlaceholder?`、`emptyText?`。
- **Events**：`select(node)` / `update:selectedKey` / `tree-width-change(width)`。
- **Slots**：`tree-header` / `tree`（自定义树渲染）/ 默认（主区）/ `empty`。
- 缺省树渲染用 `el-tree`（`node-key` / `highlight-current` / `filter-node-method`）；筛选框过滤本地树。

### 3.2 `SplitPane` <a id="split-pane"></a>

- **Props**：`modelValue?`（左区宽度或百分比）、`min?`（缺省 180）、`max?`、`direction?: 'horizontal' | 'vertical'`（缺省 `horizontal`）、`disabled?`。
- **Events**：`update:modelValue` / `resize-end`。
- 指针事件（`pointerdown` / `pointermove` / `pointerup`）拖拽；拖拽中禁用文本选择；键盘 `←` / `→` 微调（无障碍）；双击复位缺省宽度。

### 3.3 选中联动 <a id="link"></a>

- 选中节点 → `selectedKey` → 主区；无选中时主区渲染 `EmptyState(type="unselected")`（插槽可覆盖）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 树为空 | 主区与树区均走空态（`EmptyState(type="data")`） |
| 未选择 | 主区走 `EmptyState(type="unselected")` |
| 拖拽越界 | 约束在 `[min, max]`（含容器宽度约束） |
| 容器窄于 `min` | 以容器宽度为上限，禁用拖拽 |
| 指针离开窗口 | `pointerup` 兜底结束拖拽，解除监听 |
