## 1. 设计目标与范围 <a id="goal"></a>

基础布局件六件：栅格、间距分割线、分栏、内容页签、卡片、折叠面板。统一薄封装 Element Plus 并沿用组件根的令牌属性协议（`data-size` / `data-density`），保证与设计令牌一致、可组合（卡片 + 折叠 + 栅格 + 分栏搭出详情页分区）。

不在本期：响应式断点细化（`03_05` / `11_布局设计_响应式适配`）；主题品牌化。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `GridLayout` / `GridItem` <a id="grid"></a>

- `GridLayout`：`gutter?: number`（缺省 0）、`justify?: 'start'|'center'|'end'|'space-between'|'space-around'`、`align?: 'top'|'middle'|'bottom'`。
- `GridItem`：`span?`（缺省 24）、`offset?`、`xs?` / `sm?` / `md?` / `lg?` / `xl?`（响应式断点）。
- 栅格列数固定 24（与设计令牌一致）。

### 3.2 `SpacingDivider` <a id="divider"></a>

- **Props**：`direction?: 'horizontal' | 'vertical'`（缺省 `horizontal`）、`position?: 'left'|'center'|'right'`、`size?: 'sm'|'md'|'lg'`（上下间距令牌）、`dashed?`、`contentPosition?` 同上（文案位）。
- 缺省渲染纯分割线；默认插槽存在时展示文案。

### 3.3 `ContentTabs` <a id="content-tabs"></a>

- **Props**：`modelValue: string`、`tabs: { key: string; title: string; disabled?: boolean }[]`、`type?: 'line' | 'card' | 'border-card'`、`lazy?`（缺省 true）。
- **Events**：`update:modelValue` / `change(key)`；**Slots**：`default`（按 `key` 命名的面板）。
- 状态经 `BaseTabs`；页签切换保留各面板状态（配合 `lazy`）。

### 3.4 `LayoutCard` <a id="card"></a>

- **Props**：`title?`、`shadow?: 'always'|'hover'|'never'`（缺省 `hover`）、`padding?`（缺省 `md`）、`collapsible?`（缺省 false）、`bordered?`（缺省 true）。
- **Slots**：`header` / `default` / `footer` / `extra`；`collapsible` 时标题栏可折叠正文。

### 3.5 `CollapsePanel` / `CollapsePanelGroup` <a id="collapse"></a>

- 组：`modelValue?: string | string[]`（手风琴 / 多项）、`accordion?`。
- 项：`name: string`、`title: string`、`disabled?`；**Slots**：`default` / `title` / `extra`。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `GridItem` 未传 `span` | 缺省 24（整行） |
| 栅格 `gutter` 非数字 | 视为 0，开发态告警 |
| `ContentTabs` 无匹配面板 | 渲染空面板并告警 |
| 折叠组 `accordion` 却传数组 | 取首项，开发态告警 |
| 卡片无标题与 `extra` | 隐藏标题栏，仅正文 |
