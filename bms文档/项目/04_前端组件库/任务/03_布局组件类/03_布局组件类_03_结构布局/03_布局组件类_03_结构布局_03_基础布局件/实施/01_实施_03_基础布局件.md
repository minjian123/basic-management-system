## 3. 实施过程 <a id="process"></a>

1. 上下文：读六节点 §3 / §4、`usePersistedState` 契约、`SkeletonBlock`（`03_02`）。
2. 实现：`GridRow` / `GridCol`（EP 包装 + gutter 刻度告警）；`Space`（档位映射令牌 0 / 4 / 8 / 16）/ `Divider`（虚线 → `border-style`）；`Split`（自绘：pointer 拖拽 / `min`（px）+ `max`（比例）限位 / 折叠 / `usePersistedState` 持久化 / `matchMedia` 窄屏转单栏）；`Tabs` / `TabPane`（EP 包装 + `lazy` 经上下文下发）；`Card`（EP 包装 + 头部自绘 + 折叠 + `loading` 骨架）；`Collapse` / `CollapseItem`（EP 包装 + `lazy` 首展开渲染 + `persistKey` 持久化）；`layout/index.ts` 追加导出。
3. Kiwi 登记（`register_cases.py`）：735 / 736；用例两件（7 条）；验证全通过。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- | --- |
| 1 | 分栏拖拽测试预期 0.75 被限到 0.7 | `max` 缺省 0.7 限位（正确行为） | 测试改两段（0.625 → 限位 0.7）；设计已含限位口径 |
| 2 | `persistKey` 在受控（v-model）模式不写本地 | 设计口径（非受控生效） | 测试改非受控宿主；设计口径不变 |
| 3 | 单名单词组件名触发 `vue/multi-word-component-names` | 设计节点命名（`Card` / `Collapse` / `Divider` / `Space` / `Split` / `Tabs`） | 文件级 `eslint-disable`（契约名优先）；设计对齐记录 7 |
| 4 | `GridCol` 的 `props` 变量未使用（lint） | 仅模板使用 props | 不赋值 `defineProps`（裸调用） |
| 5 | `Collapse` 模板引用 `iconPosition` 未定义（tsc） | 需经 `props.` 访问 | 改 `props.iconPosition` |
| 6 | `iconPosition` 右侧图标视觉（EP 图标固定左侧） | EP 限制 | 输出类标记（`bms-collapse--icon-*`）；视觉增强登记遗留 |
| 7 | 根类名 `bms-` 问题 | `nsClass()` 无参 | 统一 `nsClass('<kebab>')` |
