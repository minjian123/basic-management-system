## 1. 概述 <a id="overview"></a>

- **目标**：落地六组九件基础布局件（仅 `frontend/`）——栅格 `GridRow` / `GridCol`、间距与分割线 `Space` / `Divider`、分栏 `Split`（可拖拽）、内容页签 `Tabs`、卡片 `Card`、折叠面板 `Collapse` / `CollapseItem`；全部消费基础令牌（`03_06`），组合布局片段 `useLayout`，视觉与交互对齐 Element Plus 与《布局设计》。
- **范围**：嵌套子任务 [03-3-3](../03_布局组件类_03_结构布局_03_基础布局件.md)（需求 [03-3](../../../../../需求/03_需求_布局组件类.md#r03-3)）；供结构布局其余件、`03_05` 框架与容器及页面任务复用。
- **依据**：《组件设计》[06_栅格](../../../../../../../设计/组件设计/03_布局组件类/06_组件设计_栅格/06_组件设计_栅格.md)、[07_间距与分割线](../../../../../../../设计/组件设计/03_布局组件类/07_组件设计_间距与分割线/07_组件设计_间距与分割线.md)、[08_分栏](../../../../../../../设计/组件设计/03_布局组件类/08_组件设计_分栏/08_组件设计_分栏.md)、[09_内容页签](../../../../../../../设计/组件设计/03_布局组件类/09_组件设计_内容页签/09_组件设计_内容页签.md)、[10_卡片](../../../../../../../设计/组件设计/03_布局组件类/10_组件设计_卡片/10_组件设计_卡片.md)、[11_折叠面板](../../../../../../../设计/组件设计/03_布局组件类/11_组件设计_折叠面板/11_组件设计_折叠面板.md)（均含可交互原型）。
- **前置契约（已交付）**：`useLayout`（栅格 / 断点 / 令牌）/ `useContainer`（容器形态）/ `usePersistedState`（比例 / 展开项持久化）片段；`SkeletonBlock` / `LoadingMask`（`03_02`，卡片加载态复用）；基础令牌（`03_06`）。
- **边界**：不含页面级多标签（`TabsNav`，03-3-1）与明细区（表单渲染器，回补波）；不含滚动 / 自适应高度容器（容器组件类，域 04）；移动端同款消费（本任务仅 frontend 交付）。

## 4. 契约设计 <a id="contract"></a>

### 4.1 栅格 `GridRow` / `GridCol`（节点 06） <a id="grid"></a>

| 组件 | 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| GridRow | `gutter` | number \| [number, number] | 0 | 列间距（水平 / 垂直，令牌刻度：4/8/12/16/24） |
| GridRow | `justify` | 'start' \| 'center' \| 'end' \| 'space-between' \| 'space-around' | 'start' | 主轴对齐 |
| GridRow | `align` | 'top' \| 'middle' \| 'bottom' | 'top' | 交叉轴对齐 |
| GridRow | `wrap` | boolean | true | 换行 |
| GridCol | `span` / `offset` | number | 0 | 0 ~ 24 |
| GridCol | `xs` / `sm` / `md` / `lg` / `xl` | number | — | 响应式跨度（断点与 `useLayout` 一致） |

- 实现：`el-row` / `el-col` 包装（EP 已含断点与 gutter），gutter 值经令牌刻度过一遍（非令牌值开发态告警）；嵌套由 EP 支持。

### 4.2 间距 / 分割线 `Space` / `Divider`（节点 07） <a id="space-divider"></a>

| 组件 | 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| Space | `direction` | 'horizontal' \| 'vertical' | 'horizontal' | 方向 |
| Space | `size` | 'none' \| 'small' \| 'default' \| 'large' \| number | 'default' | 间距（映射令牌 0/4/8/16） |
| Space | `wrap` / `align` | boolean \| string | false / 'center' | 换行 / 对齐 |
| Divider | `direction` | 'horizontal' \| 'vertical' | 'horizontal' | 方向 |
| Divider | `contentPosition` | 'left' \| 'center' \| 'right' | 'center' | 文案位置（默认插槽文案） |
| Divider | `dashed` | boolean | false | 虚线 |

- 实现：`el-space` / `el-divider` 包装 + 令牌映射（`size` 档位 → `--bms-space-*`）；垂直分割线行内使用。

### 4.3 分栏 `Split`（节点 08） <a id="split"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `direction` | 'horizontal' \| 'vertical' | 'horizontal' | 左右 / 上下 |
| `defaultRatio` | number | 0.5 | 初始比例（0 ~ 1） |
| `min` / `max` | number \| string | 令牌（120px / 70%） | 两侧最小 / 最大尺寸 |
| `collapsible` | boolean | false | 可折叠一侧（缺省折叠 first） |
| `storageKey` | string | '' | 比例持久化键（用户偏好） |

- 事件：`resize: [ratio]` / `resize-end: [ratio]` / `collapse-change: [collapsed]`；插槽 `first` / `second`。
- 行为：分割条 `pointerdown` 拖拽（`setPointerCapture`，移动只改 CSS 变量（轻量），`resize-end` 才持久化）；`min` / `max` 限制（拖拽到限位停住）；折叠后另一侧占满 + 折叠把手；窄屏（< md）自动转上下 / 单栏（`useLayout` 断点）。

### 4.4 内容页签 `Tabs`（节点 09） <a id="tabs"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string | '' | 激活页签（v-model） |
| `type` | 'line' \| 'card' \| 'border-card' | 'line' | 形态 |
| `closable` / `addable` | boolean | false | 可关闭 / 可新增 |
| `lazy` | boolean | true | 懒渲染（切换才挂载） |
| `stretch` | boolean | false | 等宽铺满 |

- 事件：`update:modelValue` / `tab-change: [key]` / `tab-remove: [key]` / `tab-add: []`；插槽默认（`TabPane` 子项，使用方提供 `el-tab-pane` 或本组件提供薄包装 `TabPane.vue`？）。
  实现取舍：内容页签「原语」——直接包装 `el-tabs` + `el-tab-pane`（使用方用 `el-tab-pane`？为闭合契约，本组件提供子项组件 `TabPane.vue` 薄包装（`label` / `name` / `disabled` / `lazy`）并导出；`Tabs` 负责形态与事件转发。
  嗯，简化：`Tabs.vue` + `TabPane.vue` 两件（清单里说九件——Tabs 算一件，TabPane 作为配套子组件）。交付物清单已列 9 件（GridRow/GridCol/Space/Divider/Split/Tabs/Card/Collapse/CollapseItem）——加 TabPane 就是 10 件。使用方也可以直接用 `el-tab-pane`（EP 全局可用）——但契约不闭合。
  决定：`Tabs.vue` 提供 `TabPane.vue` 薄包装（第 10 件，实施记录说明）；使用方可直接用 EP 的 `el-tab-pane`（兼容）。
- 关闭当前激活相邻（EP 负责）；溢出横向滚动（EP 负责）。

### 4.5 卡片 `Card`（节点 10） <a id="card"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` / `description` | string | '' | 标题 / 描述 |
| `collapsible` / `collapsed` | boolean | false | 可折叠 / 折叠态（v-model:collapsed） |
| `hoverable` | boolean | false | 悬浮阴影 |
| `loading` | boolean | false | 加载态（骨架：`SkeletonBlock`） |
| `bordered` | boolean | true | 边框（缺省，节点默认 true） |

- 插槽：`title` / `extra` / `default` / `footer` / `cover`；事件：`update:collapsed` / `collapse-change`。
- 实现：`el-card` 包装 + 自绘头部（title/description/extra）+ 折叠（`useContainer`）+ `SkeletonBlock` 加载态；令牌消费（圆角 / 阴影 / 内边距 / 边框）。

### 4.6 折叠面板 `Collapse` / `CollapseItem`（节点 11） <a id="collapse"></a>

| 组件 | 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| Collapse | `modelValue` | string \| string[] | '' | 展开项（v-model） |
| Collapse | `accordion` | boolean | false | 手风琴 |
| Collapse | `iconPosition` | 'left' \| 'right' | 'right' | 图标位置 |
| Collapse | `lazy` | boolean | false | 首次展开才渲染 |
| Collapse | `persistKey` | string | '' | 展开项持久化键（按需，`usePersistedState`） |
| CollapseItem | `name` / `title` / `disabled` | string / string / boolean | '' / '' / false | 项标识 / 标题 / 禁用 |

- 事件：`update:modelValue` / `change: [keys]`。
- 实现：`el-collapse` / `el-collapse-item` 包装（含 `lazy` 支持需自实现：EP 无内建 lazy？EP `el-collapse-item` 无 lazy prop——自绘内容渲染控制：`v-if="hasOpened"` 包一层）；`persistKey` 经 `usePersistedState`。

## 5. 实现口径 <a id="impl"></a>

| 项 | 口径 |
| --- | --- |
| SFC | `<script setup>` + `withDefaults`；`useComponentBase({ ns: 'bms', identifier: '<kebab>' })`；样式 scoped 消费令牌 |
| 包装策略 | 栅格 / 间距分割线 / 页签 / 卡片 / 折叠基于 EP 组件包装（保证行为一致）；Split 自绘（EP 无对应）；`Card` 头部与加载态自绘 |
| 令牌刻度 | 间距类 prop 经映射表落 `--bms-space-{n}`（非刻度值开发态告警一次）；卡片 / 页签样式全部令牌 |
| 组合片段 | `useLayout`（断点 / 令牌）；`Card` / `Collapse` 组合 `useContainer`；`Split` / `Collapse` 组合 `usePersistedState` |
| i18n | 内容页签文案由使用方（label）；卡片 / 折叠标题由使用方；仅「展开 / 收起」辅助文案用 `common.*`（如需要） |
| 域名出口 | `layout/index.ts` 追加导出九件 + 主从两件（宿主 `03_05` 建壳后继续追加） |
