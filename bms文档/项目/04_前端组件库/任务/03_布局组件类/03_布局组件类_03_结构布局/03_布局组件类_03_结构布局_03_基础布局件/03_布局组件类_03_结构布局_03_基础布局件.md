## 2. 任务内容 <a id="content"></a>

1. 栅格：24 栅格 + 响应式断点（`GridRow` / `GridCol`）。
2. 间距 / 分割线（`Space` / `Divider`）。
3. 分栏：可拖拽左右 / 上下分栏（`Split`）。
4. 内容页签（区别页面级多标签，`Tabs` / `TabPane`）。
5. 卡片（`Card`）、折叠面板（`Collapse` / `CollapseItem`，手风琴 / 多开）。
6. 六件均派生布局组件基类 `BaseLayout`（经尺寸能力基类 `BaseSized` 派生），消费设计令牌；视觉与交互对齐 Element Plus 与《布局设计》。

## 3. 完成标准 <a id="accept"></a>

六件可用且可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；分栏拖拽生效；折叠手风琴 / 多开正确；Vitest 覆盖关键交互；`vue-tsc`、ESLint、Vitest 全通过。
