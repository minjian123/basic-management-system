## 2. 任务内容 <a id="content"></a>

1. 栅格 `GridRow.vue` / `GridCol.vue`：24 栅格 `span` / `offset` / `gutter`（横向 / 纵向）/ `justify` / `align` / `wrap`、响应式断点（`xs`/`sm`/`md`/`lg`/`xl`）、支持嵌套。
2. 间距 / 分割线 `Space.vue` / `Divider.vue`：`Space` 方向 / 尺寸（`none`/`small`/`default`/`large` 或数值）/ 换行 / 对齐；`Divider` 方向 / 文案位置 / 虚线。
3. 分栏 `Split.vue`：左右 / 上下可拖拽分栏、`min` / `max` 限制、折叠（`collapsible`）、比例持久化（`storageKey`）、窄屏转上下 / 单栏；拖拽过程轻量（CSS 变量）结束才持久化。
4. 内容页签 `Tabs.vue`（区别页面级多标签 `TabsNav`）：`line` / `card` / `border-card` 形态、`closable` / `addable`、`lazy` 懒渲染、`stretch` 等宽、溢出横向滚动、关闭当前激活相邻。
5. 卡片 `Card.vue`：标题 / 描述 / 操作 / 内容 / 底栏 / 封面插槽、可折叠（`collapsible` / `collapsed`）、`hoverable`、`loading`（复用 `03-2` 骨架 / 遮罩）、令牌消费。
6. 折叠面板 `Collapse.vue` / `CollapseItem.vue`：手风琴（`accordion`）/ 多开、`iconPosition`、禁用项、默认展开、`lazy` 首次展开渲染、展开项可选持久化。
7. 全部组合布局片段 `useLayout`、消费基础令牌（`03-6`），视觉与交互对齐 Element Plus 与《布局设计》；多栅格 / 折叠 / 分栏 / 卡片可组合（详情页分区形态）。
8. 实现以《组件设计》「06 栅格」「07 间距与分割线」「08 分栏」「09 内容页签」「10 卡片」「11 折叠面板」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
9. **前置契约（已交付）**：[03 片段机制与预置片段](../../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（2026-09-16 交付）的 `useLayout` / `useContainer` / `useDesignToken` 等片段；`03-2` 的骨架 / 遮罩供卡片加载态复用。
10. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

六组共九件可用且与多标签导航、树形主从可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；令牌消费无硬编码颜色 / 间距；Vitest 覆盖关键契约与交互分支（栅格断点 / 分栏拖拽 / 页签关闭相邻 / 折叠手风琴）；`vue-tsc`、ESLint、Vitest 全通过。
