## 1. 概述 <a id="overview"></a>

- **目标**：落地多标签导航（仅 `apps/desktop/`）——页面级标签栏 `TabsNav`（主框架内容区顶部，路由联动、右键菜单、keep-alive、溢出）与表单框架双层标签 `FormFrameTabs`（列表 Tab 固定 + 详情 Tab 多开）；状态核心统一经**页签状态片段 `base/tabs/useTabs`**；删除阶段一过渡单例 `utils/useTabs.ts`。
- **范围**：嵌套子任务 [03-3-1](../03_布局组件类_03_结构布局_01_多标签导航.md)（需求 [03-3](../../../../../需求/03_需求_布局组件类.md#r03-3)）；标签栏本体供 `03_05` 表单框架壳使用；宿主（`BasicLayout` → `AppLayout`）接入归 `03_05`。
- **依据**：《组件设计》[04_组件设计_多标签导航](../../../../../../../设计/组件设计/03_布局组件类/04_组件设计_多标签导航/04_组件设计_多标签导航.md)（契约基准，含可交互原型）、《布局设计》[04_主框架](../../../../../../../设计/布局设计/04_布局设计_主框架.html) / [06_表单框架](../../../../../../../设计/布局设计/06_布局设计_表单框架.html) / [11_响应式适配](../../../../../../../设计/布局设计/11_布局设计_响应式适配.html)、《[前端开发规范](../../../../../../../规范/前端开发规范.md)》§3 / §5 / §9。
- **前置契约（已交付）**：页签状态片段 `base/tabs/useTabs`（受控 / 非受控、打开 / 关闭 / 固定 / 缓存键清单，`02_03`）；`useConfirm`（脏数据关闭确认，`03_01`）；`usePersistedState`（持久化）；基础令牌（`03_06`）。
- **边界**：不含侧边菜单（`03_04`）与宿主编排 / 内容区 keep-alive 接线（`03_05`）；不含路由生成与守卫（前端架构 / 页面任务）；移动端不使用多标签。

## 4. 契约设计 <a id="contract"></a>

### 4.1 `TabsNav`（节点 §3 / §4） <a id="tabs-nav"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `tabs` | `TabNavItem[] \| null` | null | 标签项；**传 null 即非受控**（内部经片段自管） |
| `activeKey` | string \| null | null | 激活标签（受控 / 非受控初始值） |
| `pinnedKey` | string \| null | 'dashboard'? | 固定标签（工作台，不可关，首位）；缺省 `'dashboard'`（宿主可改） |
| `maxOpen` | number | 12 | 最大打开数（非受控打开超限：关闭最久未激活的可关闭标签） |
| `closableTip` | boolean | true | 关闭前检查 `dirty`（确认） |
| `draggable` | boolean | false | 拖拽排序（可选，本任务实现基础指针拖拽） |
| `transform` | boolean | false | 显示刷新图标（emit `refresh`，重挂载由宿主实现） |

```ts
// 组件标签项（片段 TabItem 的呈现扩展：片段字段 + path / icon / dirty / badge）
export interface TabNavItem {
  key: string            // 页签标识（路由名）
  title: string
  name?: string          // keep-alive 缓存匹配名（缺省 key）
  path?: string          // 路由 path（点击导航用）
  icon?: string          // 图标（IconDisplay 预留，回补前降级不渲染）
  dirty?: boolean        // 脏数据标记（关闭确认）
  badge?: string | number
  closable?: boolean
  pinned?: boolean
}
```

- 事件：`select: [key]` / `close: [key]` / `close-others: [key]` / `close-right: [key]` / `close-all: []` / `refresh: [key]` / `update:activeKey: [key]` / `update:tabs: [items]`（受控回写）。
- 暴露（`defineExpose`，非受控使用）：`openTab(tab)` / `closeTab(key)` / `closeOthers(key)` / `closeRight(key)` / `closeAll()` / `activate(key)` / `cachedNames` / `tabs`。
- **受控 / 非受控**：props `tabs` 传入 → 受控（所有变更 emit，组件不改数据）；未传 → 内部 `useTabs()` 片段自管并同步回写 `activeKey`。
- 行为（节点 §4）：
  - 固定首签：`pinnedKey` 项不显示关闭按钮、排序最前（片段保证）；
  - 关闭激活相邻：关闭激活项 → 激活**右邻**（无则左邻；无则空）——组件实现 `nextActiveAfterClose()`（片段默认取最后一个，组件按节点口径覆盖：优先右邻）；
  - 右键菜单：刷新 / 关闭当前 / 关闭其他 / 关闭右侧 / 关闭全部（自绘浮层，`@pointerdown` 外点关闭）；
  - keep-alive：`cachedNames`（片段）供宿主 `keep-alive :include`（`03_05` 接线）；
  - 溢出：横向滚动容器 + 激活项 `scrollIntoView({ inline: 'nearest' })`；
  - dirty 关闭：`closableTip && tab.dirty` → `useConfirm`（放弃修改 / 继续编辑）→ 放行才 emit close；
  - maxOpen（非受控打开路径）：超出时自动关闭最久未激活的可关闭标签（记录 `lastActiveAt`）并 `ElMessage` 提示？——**提示经事件** `exceed: [closedKey]`（不直接弹消息，避免组件依赖 EP 消息；宿主可提示）；
  - `transform` 刷新：点击刷新图标 → emit `refresh`（宿主重挂载路由组件）。
- 导航联动：`select` 时若有 router（`instance` 捕获，同 `ErrorPage` 模式）且标签有 `path` → `router.push(path)`；否则仅 emit。

### 4.2 `FormFrameTabs`（节点 §5） <a id="form-frame-tabs"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `listTab` | `TabNavItem` | —（必填） | 列表 Tab（固定不可关） |
| `detailTabs` | `TabNavItem[]` | [] | 详情 Tab 清单（多开；`key` 含记录 id） |
| `activeKey` | string | '' | 激活项（列表 Tab key 或详情 Tab key） |

- 事件：`open-detail: [key]`（双击 / 已开激活由宿主调用打开）/ `close: [key]` / `select: [key]` / `update:activeKey`。
- 行为：列表 Tab 固定首位不可关；详情 Tab 多开（不同记录 `key` 不同；已开激活不重复）；关闭详情激活相邻（无详情回列表 Tab）；`dirty` 详情 Tab 关闭走确认（同 TabsNav 口径）。

## 5. 实现口径 <a id="impl"></a>

| 项 | 口径 |
| --- | --- |
| SFC | `<script setup>` + `withDefaults`；`useComponentBase({ ns: 'bms', identifier: 'tabs-nav' / 'form-frame-tabs' })`；样式 `<style scoped>` 消费令牌 |
| 状态 | `useTabs({ tabs: props.tabs ?? undefined, activeKey })`（受控透传）；非受控 `useTabs()` + `defineExpose` |
| 右键菜单 | 自绘浮层（`position: fixed` 定位到指针），`Escape` / 外点关闭；菜单项 disabled 规则（固定签不可关） |
| 刷新图标 | 激活项 hover 显示（`transform`）；点击 emit `refresh` |
| 溢出 | 标签容器 `overflow-x: auto`（隐藏滚动条）+ `wheel` 横向滚动 + 激活项自动滚入 |
| 脏数据确认 | `useConfirm`（`modal.unsavedTitle` / `modal.unsavedMessage` / 放弃修改 / 继续编辑）；确认文案复用 `03_01` i18n |
| i18n | 新增 `tabs.*` 键：右键菜单项（刷新 / 关闭当前 / 关闭其他 / 关闭右侧 / 关闭全部）、上限提示（超限已关闭…） |
| 令牌 | 激活态 / 悬停背景 / 下边框 / 间距（`--bms-color-primary` / `--bms-color-bg-page` / `--bms-color-border` / `--bms-space-*`） |
