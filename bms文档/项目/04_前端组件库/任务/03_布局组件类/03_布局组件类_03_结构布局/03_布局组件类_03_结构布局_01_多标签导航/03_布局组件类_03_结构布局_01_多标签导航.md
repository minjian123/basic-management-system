## 2. 任务内容 <a id="content"></a>

1. `TabsNav.vue`（`frontend/packages/ui-ep/src/components/tabs/`）：页面级标签栏——固定首 Tab（工作台）不可关、打开 / 激活不重复、关闭激活相邻、右键菜单（刷新 / 关闭当前 / 关闭其他 / 关闭右侧 / 关闭全部）、溢出横向滚动与当前标签自动滚入、图标 / 角标、`maxOpen` 上限（超限关闭最久未激活的可关闭标签并提示）、`dirty` 关闭确认、`refresh` 按缓存键移除重挂载、`draggable` 拖拽排序（可选）。
2. `FormFrameTabs.vue`：表单框架双层标签——列表 Tab 固定不可关 + 详情 Tab 多开（不同记录各自新开、已开激活不重复）、默认只读、关闭激活相邻、编辑未保存切换 / 关闭脏数据拦截、两级缓存独立。
3. `useTabs` 增强（阶段一基础实现 `src/utils/useTabs.ts`）：UI / 路由联动、缓存键与 keep-alive 清单、dirty 标记、上限 LRU；白名单由占位（`ALLOWED_PATHS`）改为按动态菜单路由扩展。
4. 关闭确认复用 `03-1` 的 `useConfirm`；标签打开 / 激活与侧边菜单（`03-4`）的路由联动契约按《组件设计》协作口径实现。
5. 实现以《组件设计》「04 多标签导航」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. **前置契约（已交付）**：[03 能力机制与预置能力](../../../02_基础组件类/02_基础组件类_03_能力机制与预置能力/02_基础组件类_03_能力机制与预置能力.md)（2026-09-16 交付）的 `useTabs` 能力（标签状态核心：增删 / 切换 / 固定 / 缓存键 / keep-alive 清单）与 `useLayout` / `usePersistedState` 能力；[06 基础类横切底座](../../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)（2026-09-16 交付）格式化工具箱；本任务在其上补 UI 与路由联动，不重复实现状态核心。
7. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

页面级多标签与双层标签交互生效（右键菜单 / 关闭相邻 / 溢出 / 上限 / 脏数据确认 / refresh）；keep-alive 缓存键正确、详情 Tab 按记录区分；关闭确认复用 `useConfirm`；Vitest 覆盖标签打开 / 关闭 / 缓存与拦截分支；`vue-tsc`、ESLint、Vitest 全通过。
