## 2. 任务内容 <a id="content"></a>

1. 页面级多标签导航：打开 / 关闭 / 右键菜单（关闭其他 / 关闭右侧 / 全部关闭 / 固定）/ 固定 / 拖拽排序。
2. 表单框架双层页签（供 `03_05` 表单框架壳使用）。
3. 页签状态统一经页签能力基类 `BaseTabs`（打开 / 关闭 / 固定 / 缓存键清单）；关闭激活相邻（右 → 左）。
4. 关闭确认复用 `03_01` 的二次确认（脏数据拦截）。
5. 视觉与交互对齐 Element Plus 与《布局设计》导航节点。

## 3. 完成标准 <a id="accept"></a>

多标签导航（含双层页签）可用、固定与右键菜单正确、页签状态与 keep-alive 缓存键清单正确；Vitest 覆盖打开 / 关闭 / 固定 / 缓存键分支；`vue-tsc`、ESLint、Vitest 全通过。
