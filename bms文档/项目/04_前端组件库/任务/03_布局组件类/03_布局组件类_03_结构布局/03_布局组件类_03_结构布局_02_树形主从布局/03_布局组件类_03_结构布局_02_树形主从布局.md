## 2. 任务内容 <a id="content"></a>

1. 树形主从布局：左树右表 / 右详情，选中节点过滤主区数据。
2. 可调分割（拖拽调整树区宽度）、树区折叠。
3. 窄屏抽屉化 + 未选择空态（空态复用 `03_02`）。
4. 树数据经树组件基类 `BaseTreeData`（加载 / 懒加载 / 选中 / 过滤 / 缓存）。
5. 视觉与交互对齐 Element Plus 与《布局设计》。

## 3. 完成标准 <a id="accept"></a>

树形主从布局可用、选中过滤与可调分割生效、窄屏抽屉化与空态正确；Vitest 覆盖选中过滤与折叠分支；`vue-tsc`、ESLint、Vitest 全通过。
