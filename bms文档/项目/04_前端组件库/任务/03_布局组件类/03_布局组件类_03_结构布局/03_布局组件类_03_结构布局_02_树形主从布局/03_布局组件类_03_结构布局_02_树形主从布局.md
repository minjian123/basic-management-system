## 2. 任务内容 <a id="content"></a>

1. `MasterDetail.vue`（`src/components/layout/`）：主从布局壳——左主右从、可调分割（`resizable`）、折叠（`collapsible`）、窄屏抽屉、空态（复用 `03-2`）、`master-select` / `collapse-change` 事件、左右插槽；比例 / 折叠持久化经 `usePersistedState`（`splitStorageKey`）。
2. `MasterTree.vue`：主树——树搜索 / 选中 / 多选（`checkable` 从区按并集过滤）/ 懒加载（`loadMode='lazy'` + `loadChildren`）/ 节点计数（`showCount`）/ 工具栏与右键菜单增删改（`managePermission` 权限控制）/ `refresh`；树数据契约 `{id/parentId/label/children/leaf?/count?}` 与 `useTreeData` 对齐（字段类树控件未就绪期间按同口径实现，字段域交付后对齐）。
3. `useMasterDetail.ts`：主从状态（选中节点、树展开集、比例、窄屏抽屉开关）。
4. 联动：选中 → 从区带 `nodeId` / `nodeIds` 重新查询（防抖 + 竞态取最新，`useRequest`）；未选中占位（`emptyText`）或显示全部；节点删除后选中回退父节点 / 清空；空树空态与「新增」入口。
5. 实现以《组件设计》「05 树形主从布局」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
6. **前置契约（已交付）**：[04 域基类](../../../02_基础组件类/02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)（`BaseTree` 与域基类双轨）、[03 片段机制与预置片段](../../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（`useTreeData` / `useLayout` / `useContainer` / `usePersistedState`）、[06 基础类横切底座](../../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)（`useRequest` 竞态 / 取消）；`03-2` 的 `EmptyState` 供空树 / 未选中态复用。
7. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。
