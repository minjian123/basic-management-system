## 1. 概述 <a id="overview"></a>

- **目标**：落地树形主从布局（仅 `frontend/`）——主从壳 `MasterDetail`（左主右从、可调分割、折叠、窄屏抽屉、空态）与主树 `MasterTree`（搜索 / 选中 / 多选 / 懒加载 / 计数 / 维护入口），状态经组合式 `useMasterDetail`；树控件基于 `el-tree` 自实现并与域基类 `BaseTree` / 片段 `useTreeData` 契约对齐（字段类树控件交付后对齐）。
- **范围**：嵌套子任务 [03-3-2](../03_布局组件类_03_结构布局_02_树形主从布局.md)（需求 [03-3](../../../../../需求/03_需求_布局组件类.md#r03-3)）；右侧从区（表格 / 详情）与筛选区由展示域（回补波）与使用方提供。
- **依据**：《组件设计》[05_组件设计_树形主从布局](../../../../../../../设计/组件设计/03_布局组件类/05_组件设计_树形主从布局/05_组件设计_树形主从布局.md)（契约基准，含可交互原型）、《布局设计》[07_列表页](../../../../../../../设计/布局设计/07_布局设计_列表页.html) / [11_响应式适配](../../../../../../../设计/布局设计/11_布局设计_响应式适配.html)、《[前端开发规范](../../../../../../../规范/前端开发规范.md)》§3 / §5 / §9。
- **前置契约（已交付）**：域基类 `BaseTree` 与片段 `useTreeData`（`02_03` / `02_04`）、`useRequest`（竞态 / 取消，`02_06`）、`usePersistedState`（分割比例 / 折叠持久化）、`EmptyState` / `SkeletonBlock`（`03_02`）、基础令牌（`03_06`）。
- **边界**：不含树控件内部实现（字段类「树选择字段」，回补波——本任务同口径自实现，交付后对齐）、不含右侧表格 / 筛选区（展示类）、不含移动端手势细节（移动端任务）。

## 4. 契约设计 <a id="contract"></a>

### 4.1 `MasterDetail`（节点 §3） <a id="master-detail"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `masterWidth` | number \| string | 260 | 主区宽度（px 或百分比；可调时为初始值） |
| `resizable` | boolean | false | 可拖动分割条调整比例 |
| `collapsible` | boolean | true | 主区可折叠 / 展开 |
| `masterTitle` | string | '' | 主区标题（如「组织」） |
| `emptyText` | string | '请选择左侧节点' | 从区未选中占位文案 |
| `splitStorageKey` | string | '' | 分割比例持久化键（`usePersistedState`） |

- 事件：`master-select: [node | null]`（主树选中，null 清除）/ `collapse-change: [collapsed]`。
- 插槽：`master`（主区，缺省渲染主树由使用方传入）/ `detail`（从区）；`detail` 区未选中且 `emptyText` 非空时显示 `EmptyState`（`type='custom'` + 文案）。
- 行为：可调分割（`resizable` 时渲染分割条，`pointerdown/move/up` 计算比例，`min` 240px / `max` 主区 60%，结束持久化）；折叠（主区收起，从区占满，提供展开把手）；窄屏（< md）：主区收进抽屉（`el-drawer` 左侧，`direction='ltr'`），手扶按钮由使用方经 `expose` 打开或使用方自绘（提供 `open-master` 事件与 `expose.openMaster()`）。

### 4.2 `MasterTree`（节点 §3.1） <a id="master-tree"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `treeData` | `TreeNode[]` | [] | 树数据（`{ id, parentId?, label, children?, leaf?, count? }`，与 `useTreeData` 对齐） |
| `loadMode` | `'all' \| 'lazy'` | 'all' | 全量 / 懒加载 |
| `loadChildren` | `(node) => Promise<TreeNode[]>` | — | 懒加载函数（`loadMode='lazy'`） |
| `checkable` | boolean | false | 多选（从区按并集过滤） |
| `showCount` | boolean | false | 节点右侧显示记录数（`count`） |
| `toolbar` | boolean | true | 是否显示增删改 / 刷新工具栏 |
| `managePermission` | string[] | [] | 树节点增删改所需权限码（无权限隐藏入口） |
| `defaultExpandAll` | boolean | false | 初始展开全部 |
| `emptyText` | string | '' | 空树文案（缺省 i18n） |

- 事件：`select: [node | null]` / `node-create: [parent | null]` / `node-edit: [node]` / `node-delete: [node]` / `refresh: [parent | null]` / `check: [nodes]`。
- 行为：搜索框（本地过滤 + 命中高亮，`filter-node-method`）；懒加载（`lazy` + `load`）；多选并集（`check` 事件）；计数（自定义节点插槽）；工具栏（增删改 / 刷新，权限过滤 `hasPerm`）；右键菜单（与工具栏同项）；空树 `EmptyState`（含「新增」入口）；选中回调。
- 树维护动作仅 **emit**（弹窗由业务实现，节点口径）——不内置表单。

### 4.3 `useMasterDetail` <a id="composable"></a>

```ts
export interface UseMasterDetailOptions {
  splitStorageKey?: string
  defaultRatio?: number          // 0.2 ~ 0.6，缺省 0.3
  collapsible?: boolean
}
export interface UseMasterDetailReturn {
  selectedKeys: Ref<string[]>          // 当前选中（多选并集）
  selectedNode: Ref<TreeNode | null>
  expandedKeys: Ref<string[]>
  ratio: Ref<number>                   // 主区占比
  collapsed: Ref<boolean>
  drawerVisible: Ref<boolean>          // 窄屏抽屉
  select(node: TreeNode | null): void
  setCheckedNodes(nodes: TreeNode[]): void
  toggleCollapse(): void
  openDrawer(): void
  closeDrawer(): void
  setRatio(next: number): void
}
```

- 持久化：`ratio` 与 `collapsed` 经 `usePersistedState`（键 `bms:layout:<key>`，无 `splitStorageKey` 不持久化）。

## 5. 实现口径 <a id="impl"></a>

| 项 | 口径 |
| --- | --- |
| SFC | `<script setup>` + `withDefaults`；`useComponentBase({ ns: 'bms', identifier: 'master-detail' / 'master-tree' })`；样式 scoped 消费令牌 |
| 树渲染 | `el-tree`（`:data` / `node-key="id"` / `props={ label: 'label', children: 'children' }` / `render-content` 自定义节点：标签 + 计数 + 操作入口）；`el-tree` 实例 ref 供搜索 / 展开 |
| 搜索 | 输入防抖 200ms → `treeRef.filter(keyword)`（`filter-node-method` 匹配 label 高亮） |
| 懒加载 | `lazy` + `:load="loadChildren"`（节点 `leaf` 判定）；加载失败 emit `load-error`（使用方提示） |
| 从区过滤 | 组件只 emit `select` / `check`（`nodeId` / `nodeIds` 由使用方携带查询）；未选中显示 `emptyText` 占位 |
| 窄屏 | 断点判定经 `useLayout`（`< md` → 抽屉模式）；抽屉内复用主树插槽 |
| 空态 / 骨架 | 空树 `EmptyState`；树数据加载中 `SkeletonBlock variant='list'`（`loading` prop 可传） |
| 令牌 | 分割条 / 背景 / 边框 / 间距消费令牌；分割条 hover 高亮 `--bms-color-primary` |
| i18n | `tree.*` 键：搜索占位 / 空树 / 新增 / 编辑 / 删除 / 刷新 / 展开收起 / 已选 N 项 |

| ② | MasterTree：搜索 / 选中 / 多选 / 计数 / 权限（Kiwi 734） | `tests/layout-master-tree.spec.ts` | 渲染树节点（label）；搜索过滤（`filter` 调用与命中）；点击节点 emit `select`；`checkable` 多选 emit `check`（并集）；`showCount` 渲染计数；工具栏无权限（hasPerm mock）隐藏增删改；`node-create` / `node-edit` / `node-delete` / `refresh` emit；空树 `EmptyState` 与 `defaultExpandAll` |
