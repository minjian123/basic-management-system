## 3. 任务内容 <a id="content"></a>

1. 结构布局八件由三个嵌套子任务承载：多标签导航（01，含表单框架双层页签）、树形主从布局（02）、基础布局件（03：栅格 / 间距分割线 / 分栏 / 内容页签 / 卡片 / 折叠面板）。
2. 八件均派生布局组件基类 `BaseLayout`（经尺寸能力基类 `BaseSized` 派生）；页签状态统一经页签能力基类 `BaseTabs`；树数据经树组件基类 `BaseTreeData`。
3. 空态复用 `03_02`；关闭确认复用 `03_01`；视觉与交互对齐 Element Plus 与《布局设计》。

## 4. 完成标准 <a id="accept"></a>

八项结构组件可用且可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；树形主从的选中过滤与可调分割生效；页签状态与 keep-alive 清单正确；Vitest 覆盖关键交互；`vue-tsc`、ESLint、Vitest 全通过。
