## 3. 任务内容 <a id="content"></a>

1. 多标签导航（嵌套 01）：页面级多标签 `TabsNav` 与表单框架双层 Tab `FormFrameTabs`（**标签栏本体**，供 `03-5` 表单框架壳使用）；页签状态统一经页签状态片段 `useTabs`（打开 / 关闭 / 固定 / 缓存键 / keep-alive 清单，与内容页签共用），阶段一基础实现随本任务增强为 UI / 路由联动与 dirty 拦截；关闭确认复用 `03-1` 的 `useConfirm`。
2. 树形主从布局（嵌套 02）：`MasterDetail` / `MasterTree` 左树右表 / 左树右详情，选中过滤、可调分割、折叠、窄屏抽屉、空态（复用 `03-2`）；树能力对齐域基类 `BaseTree` 与 `useTreeData` 片段（字段类树控件未就绪期间按同口径实现，字段域交付后对齐）。
3. 基础布局件（嵌套 03）：栅格 `GridRow` / `GridCol`、间距 / 分割线 `Space` / `Divider`、分栏 `Split`、内容页签 `Tabs`、卡片 `Card`、折叠面板 `Collapse` / `CollapseItem`；消费基础令牌（`03-6`）。
4. 八件均组合布局片段 `useLayout`，视觉与交互对齐 Element Plus 与《布局设计》。
5. 范围边界（2026-09-16 建任务确认）：**标签栏本体归本任务**（`03-5` 框架壳只做壳与插槽编排）；页签关闭复用 `03-1` 的 `useConfirm`；树形主从的空态复用 `03-2`；树控件渲染实现（渲染 / 搜索 / 懒加载）与字段类「树选择字段」保持同一口径，字段域交付后对齐。
6. 实现以《组件设计》布局组件类各节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. **前置契约（已交付）**：域 02 已完成（2026-09-16）——[03 片段机制与预置片段](../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（`useTabs` / `useLayout` / `useContainer` / `useTreeData` / `usePersistedState` 等预置片段）、[04 域基类](../../02_基础组件类/02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)（`BaseTree` 与域基类双轨）、[06 基础类横切底座](../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)（`useRequest` / 权限 / 格式化），本任务直接复用不重复实现。
8. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建（嵌套子任务各自补建）。

## 4. 完成标准 <a id="accept"></a>

八项结构组件可用且可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；树形主从的选中过滤与可调分割生效；页签状态与 keep-alive 清单正确；Vitest 覆盖关键交互；`vue-tsc`、ESLint、Vitest 全通过；《组件设计》节点与《[前端基类清单](../../../../../前端基类清单.md)》相关登记回写同步。
