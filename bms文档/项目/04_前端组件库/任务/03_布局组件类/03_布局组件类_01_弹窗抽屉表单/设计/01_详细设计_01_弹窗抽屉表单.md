## 1. 设计目标与范围 <a id="goal"></a>

落地 `ui-ep` 渲染插件包（PC / Element Plus）与弹窗表单族：对话框 / 抽屉三态、通用二次确认、弹窗表单组合式。

- **前端基类继承（强制）**：弹窗件派生模态组件基类 `BaseModalShell`（经浮层能力基类 `BaseOverlay` → 尺寸能力基类 `BaseSized` → 组件根 → 插件基类 → 能力域基类 → 总基类）；状态为纯 TS（核心类）+ Vue 投影薄适配。
- **仅 PC**（`ui-ep`）；移动端 `ui-vant` 本阶段范围外。

不在本期：真实字段表单（随字段类需求）、菜单 / 页签关闭接线（`03_03` / `03_04`）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 模态件 <a id="modal"></a>

- **形态**：Vue SFC（`<script setup lang="ts">`），基于 Element Plus `el-dialog` / `el-drawer`；核心状态经 `BaseModalShell`（`open` / `show` / `hide` / `requestClose` / `beforeClose`）。
- **`FormDialog` / `FormDrawer` 三态**：`mode: 'create' | 'edit' | 'detail'`；标题按 `mode` 与对象名组合；`detail` 态只读。
- **尺寸阶梯**：对话框 `sm`(420) / `md`(480) / `lg`(520)；抽屉 `sm`(400) / `md`(480) / `lg`(640) / `xl`(720)。
- **脏数据拦截**：关闭前调 `beforeClose`（由 `useFormModal` 注入：检查 dirty → 二次确认）。
- **Props**：`modelValue`（显隐）/ `mode` / `title` / `size` / `destroyOnClose`；**Events**：`update:modelValue` / `submit` / `closed`；**插槽**：默认（表单内容）、`footer`。
- **`ConfirmDialog`**：`modelValue` / `title` / `content` / `danger` / `confirmText` / `cancelText`；`confirm` / `cancel` / `update:modelValue`。

### 3.2 组合式 <a id="composables"></a>

```ts
useFormModal<T>(options?: { mode?: FormMode; size?: DialogSize; submit?: (values: T) => Promise<void> | void }): {
  visible: Ref<boolean>; mode: Ref<FormMode>; title: Ref<string>; dirty: Ref<boolean>;
  open(mode: FormMode, title?: string): void; close(): void; reset(): void;
  submit(values?: T): Promise<void>;
}
useConfirm(): {
  confirm(options): Promise<boolean>;
  state: { visible: Ref<boolean>; title: Ref<string>; content: Ref<string>; danger: Ref<boolean> };
}
```

- `useConfirm` 由宿主在根组件挂一个 `ConfirmDialog` 实例消费（`confirm()` 返回 Promise）；`03_03` / `03_04` 复用。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `detail` 态提交 | 忽略（只读） |
| 脏数据关闭 | `beforeClose` 拦截（需确认） |
| 提交中重复点击 | `loading` 期间忽略 |
| 未提供 `submit` | 仅 `emit('submit')` |
