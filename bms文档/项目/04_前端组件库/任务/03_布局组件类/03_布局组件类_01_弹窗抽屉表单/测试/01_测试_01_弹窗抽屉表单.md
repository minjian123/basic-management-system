  1. `vitest.config.ts` 增 `server.deps.inline: ['element-plus']`（按需样式 CSS 处理）；

  3. EP 在关闭过渡 `afterLeave` 后才 emit `update:modelValue` → 测试 `stubs: { transition: false }` + `vi.waitFor` 轮询断言；
  4. `loading` 按钮禁点（预期）→ 断言 loading 后 `setProps({ loading: false })` 再点击。
