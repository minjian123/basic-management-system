## 2. 任务内容 <a id="content"></a>

1. **`ui-ep` 工程骨架（前置）**：建 `frontend/packages/ui-ep`（`package.json` / `tsconfig` / `eslint` / `vitest` + `src/components/<族>/`），并把根 `check` / `lint` 与 CI（`Dockerfile.frontend` / `build-base.sh` / `core-check` 符号链接）挂回 `core + vue + ui-ep`。
2. **弹窗表单件**：对话框 / 抽屉，三态契约（新增 / 编辑 / 详情）、尺寸阶梯、生命周期、脏数据拦截与提交前确认；提交复用 `02_06` 请求组合式；派生模态组件基类 `BaseModalShell`。
3. **通用二次确认对话框**：供页签关闭、删除确认等场景复用。
4. **弹窗表单组合式**：打开 / 关闭 / 提交 / 重置 / `loading`。
5. 字段插槽先以占位内容验证（真实字段随字段类需求接入）；语义色 / 间距 / 遮罩对齐《布局设计》与 Element Plus。

## 3. 完成标准 <a id="accept"></a>

`ui-ep` 骨架就位、根门禁与 CI 挂回 `core + vue + ui-ep`；三态弹窗表单可用、脏数据拦截生效、尺寸阶梯与《布局设计》一致；二次确认与弹窗表单组合式可被页面与其他组件直接调用；Vitest 覆盖三态与拦截行为；`vue-tsc`、ESLint、Vitest 全通过。
