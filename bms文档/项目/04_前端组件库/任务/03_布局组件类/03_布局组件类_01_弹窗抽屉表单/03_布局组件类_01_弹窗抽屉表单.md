## 2. 任务内容 <a id="content"></a>

1. `FormDrawer.vue` / `FormDialog.vue`（`src/components/modal/`）：共用同一份 Props / 事件 / 插槽契约，差异仅形态与尺寸阶梯；三态（新增 / 编辑 / 详情）、尺寸阶梯（抽屉 `sm`/`md`/`lg`/`xl` 400 / 480 / 640 / 720+，对话框 `sm`/`md`/`lg` 420 / 480 / 520）、打开 / 提交 / 关闭生命周期、脏数据拦截与 `beforeClose` 串联、`submitPerm` 动作权限、查看态只读与可选删除入口。
2. `ConfirmDialog.vue` / `useConfirm.ts`：通用二次确认对话框（危险语义、禁遮罩 / Esc、确认回调 loading、权限码显隐），供页签关闭（`03-3`）、删除确认等场景复用。
3. `useFormModal.ts`：弹窗表单组合式封装（`visible` / `mode` / `formData` 状态、`openCreate` / `openEdit` / `openView`、校验、提交、重置、loading、脏数据基线比对、409 冲突重载）。
4. 提交复用 `02_06` 的 `useRequest`，脏数据基线复用 `stableStringify`，页脚按钮权限复用 `02_06` 权限指令；字段插槽先以占位内容验证（真实字段随字段类需求接入）。
5. 语义色、间距、遮罩行为对齐 Element Plus 与《布局设计 · 弹窗》；错误文案走 i18n `error.{code}`。
6. 实现以《组件设计》「01 弹窗抽屉表单」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. **前置契约（已交付）**：域 02 基类体系已完成（2026-09-16）——[01 根系基类](../../02_基础组件类/02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)、[02 组件根基类](../../02_基础组件类/02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)、[03 片段机制与预置片段](../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)、[04 域基类](../../02_基础组件类/02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)、[06 基础类横切底座](../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)；本任务组件派生对应基类并组合片段（`useLayout` / `useContainer` / `useFormContainer` 等），请求、脏数据、权限、格式化直接复用不重复实现。
8. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。
