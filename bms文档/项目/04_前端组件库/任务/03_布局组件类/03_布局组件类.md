## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段四需求域 03 的 5 条需求——[03-1 弹窗抽屉表单](../../需求/03_需求_布局组件类.md#r03-1)、[03-2 异常与空状态](../../需求/03_需求_布局组件类.md#r03-2)、[03-3 结构布局](../../需求/03_需求_布局组件类.md#r03-3)、[03-4 侧边菜单](../../需求/03_需求_布局组件类.md#r03-4)、[03-5 框架与容器](../../需求/03_需求_布局组件类.md#r03-5)，按「1 需求 = 1 子任务」拆 5 个子任务（`03_03 结构布局` 含 3 个嵌套子任务）。

- **`ui-ep` 前置**：渲染插件包骨架（`package.json` / `tsconfig` / `eslint` / `vitest` + 族目录）在 `03_01` 内建，并把根门禁与 CI 挂回 `core + vue + ui-ep`。
- **依据**：《[布局设计](../../../../设计/布局设计/01_布局设计_总览.html)》各节点、《组件设计》布局组件类与容器 / 展示 / 交互类前移节点、《[前端基类清单](../../../../前端基类清单.md)》、《[前端开发规范](../../../../规范/前端开发规范.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》。
- **执行序**：`03_01 弹窗抽屉表单` → `03_02 异常与空状态` → `03_03 结构布局` → `03_04 侧边菜单` → `03_05 框架与容器`；嵌套子任务并入其直属父任务统计。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：58h（01 12h + 02 8h + 03 22h + 04 6h + 05 10h；其中 `03` 含嵌套子任务 01 多标签导航 9h、02 树形主从布局 7h、03 基础布局件 6h）。
- **关键依赖**：`03_01` 依赖 `02_06`（宿主请求层与 `ui-ep` 前置）；`03_02` 依赖 `02_06`；`03_03` 依赖 `03_01`（二次确认）、`03_02`（空态）；`03_04` 依赖 `02_06`（权限指令）、`03_02`；`03_05` 依赖 `03_03`、`03_04`。
- **风险**：`ui-ep` 工程骨架与 CI 挂回有一次性成本；树形主从 / 分栏 / 虚拟滚动等交互复杂，注意滑期；组件视觉须对齐《布局设计》与可交互原型。
