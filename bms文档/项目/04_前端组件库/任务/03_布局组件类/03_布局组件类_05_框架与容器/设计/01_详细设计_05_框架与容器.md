## 1. 概述 <a id="overview"></a>

- **目标**：落地 PC 管理端三件壳（仅 `frontend/`）——主框架布局壳 `AppLayout`、表单框架壳 `FormFrame`、页面容器 `PageContainer`；并完成**宿主编排**：`BasicLayout` 升级（AppLayout + SideMenu + TabsNav + keep-alive + 路由 watch 开签 + refresh 重挂载）、**菜单 → 路由注册**（占位菜单 → `useDynamicRoutes` → `addRoute`）、顶栏插槽占位与响应式；域 03 收尾。
- **范围**：任务 [03-5](../03_布局组件类_05_框架与容器.md)（需求 [03-5](../../../../需求/03_需求_布局组件类.md#r03-5)）。
- **依据**：《组件设计》[01_主框架布局壳](../../../../../../设计/组件设计/03_布局组件类/01_组件设计_主框架布局壳/01_组件设计_主框架布局壳.md)、[02_表单框架壳](../../../../../../设计/组件设计/03_布局组件类/02_组件设计_表单框架壳/02_组件设计_表单框架壳.md)、[03_页面容器](../../../../../../设计/组件设计/03_布局组件类/03_组件设计_页面容器/03_组件设计_页面容器.md)（均含可交互原型）、《布局设计》[04_主框架](../../../../../../设计/布局设计/04_布局设计_主框架.html) / [06_表单框架](../../../../../../设计/布局设计/06_布局设计_表单框架.html) / [07_列表页](../../../../../../设计/布局设计/07_布局设计_列表页.html) / [08_表单页](../../../../../../设计/布局设计/08_布局设计_表单页.html) / [11_响应式适配](../../../../../../设计/布局设计/11_布局设计_响应式适配.html)。
- **前置契约（已交付）**：`SideMenu` + `stores/menu`（`03_04`）、`TabsNav` / `FormFrameTabs` + 片段 `useTabs`（`03_03`）、`ErrorPage` / `EmptyState`（`03_02`）、`useDynamicRoutes`（`02_03`）、`usePersistedState`、`useLayout`、基础令牌（`03_06`）。
- **边界**：不含真实菜单接口（阶段七 ~ 八）与登录页（页面任务）；顶栏元素（语言 / 通知 / 搜索 / 用户）为**插槽占位**；详情表单本体归表单渲染器（回补波）；本任务后域 03 收官。

## 4. 契约设计 <a id="contract"></a>

### 4.1 `AppLayout`（节点 01） <a id="app-layout"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `collapsed` | boolean | false | 侧栏折叠（v-model:collapsed） |
| `showTabs` | boolean | true | 是否显示多标签栏 |
| `showSidebar` | boolean | true | 是否显示侧栏（纯内容页可关） |
| `headerHeight` | number | 56 | 顶栏高度（令牌缺省 56px） |
| `sidebarWidth` | number | 220 | 侧栏展开宽度；折叠宽 64px |

- 事件：`update:collapsed` / `resize-breakpoint: [mode: 'wide' | 'narrow']`；插槽：`sidebar` / `header` / `tabs` / `default` / `footer`。
- 行为：区域编排（aside + main[header + tabs + content]）；折叠 220 / 64px；窄屏（< 768px）：侧栏收进 `el-drawer`（`sidebar` 插槽复用，内容不双渲染——`v-if` 互斥），顶栏保留；内容区独立滚动；令牌消费（背景 / 边框 / 间距 / `--bms-shadow-*`）。

### 4.2 `FormFrame` + `useFormFrame`（节点 02） <a id="form-frame"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 页面标题（菜单名） |
| `listComponent` | `Component \| string` | — | 列表组件（名字经 `resolveView` 解析） |
| `detailComponent` | `Component \| string` | — | 详情组件 |
| `openMode` | `'tab' \| 'drawer' \| 'page'` | 'tab' | 详情打开方式（本任务实现 `tab`；`drawer` / `page` 按需） |
| `cacheDetail` | boolean | true | 详情 Tab keep-alive |
| `cacheLimit` | number | 8 | 详情缓存上限（超出按最久未激活释放） |

- 事件：`open-detail: [id]` / `saved: [id]` / `deleted: [id]` / `dirty: [key, dirty]` / `title-change: [key, title]` / `fetch-list: []`。
- 暴露（`defineExpose`）：`openDetail(id, title?)` / `closeDetail(key)` / `setDetailDirty(key, dirty)` / `refreshList()` / `activeKey`。
- 行为：双层 Tab 复用 `FormFrameTabs`（列表 Tab 固定 `key = \`${title}:list\``）；双击列表行由使用方（或列表组件事件）调 `openDetail`；详情组件 emit `saved` / `deleted` → 关闭对应详情 + `refreshList()`（优先调列表组件暴露的 `fetchList`）+ 事件转发；**dirty 集成（简化口径）**：由使用方 / 详情组件经 `setDetailDirty(key, dirty)` 写入（关闭确认复用 `FormFrameTabs` 能力）；组件映射：string → `resolveView`（`import.meta.glob('../views/**/*.vue')` 文件名映射），未注册 → 渲染 `EmptyState`（「未注册的组件」）+ console.warn。

### 4.3 `PageContainer`（节点 03） <a id="page-container"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` / `description` | string | '' | 标题 / 描述（i18n） |
| `breadcrumb` | `BreadcrumbItem[]` | [] | 面包屑（管理端不采用，能力保留） |
| `back` | boolean | false | 显示返回（与标签关闭联动由使用方） |
| `sticky` | boolean | true | 头部吸顶 |
| `footer` | boolean | false | 显示底部操作栏 |

- 事件：`back` / `refresh`；插槽：`title` / `extra`（右上工具栏）/ `breadcrumb` / `default` / `footer`。
- 行为：头部（标题 / 描述 / 面包屑 + `extra`）`sticky` 吸顶；内容独立滚动；底部操作栏固定（窄屏堆叠）；令牌消费。

### 4.4 宿主编排（BasicLayout + 菜单路由 + keep-alive） <a id="host"></a>

**`routeComponent.ts`**：

```ts
export function nameComponent(name: string, source: Component | (() => Promise<unknown>)): Component
export function resolveView(name: string): Component | null   // '@/views/**/*.vue' 文件名 → 异步组件
```

- `nameComponent`：`defineComponent({ name, render })` 包装（内部 `defineAsyncComponent` 支持 loader 或直接组件），保证 `keep-alive :include` 以**路由 name** 匹配。
- `resolveView`：`import.meta.glob('../views/**/*.vue')` 文件名（去路径 / 扩展）映射；未命中返回 `null`。

**`menuRoutes.ts`**：

```ts
export interface RegisterMenuRoutesOptions {
  /** 布局父路由名（菜单路由挂其 children） */
  parentName?: string
}
export function registerMenuRoutes(router: Router, menus: MenuItem[], options?): number
```

- 适配：`MenuItem[] → MenuNode[]`（`key = path ?? name`、`title = name`、`public = false`）→ `useDynamicRoutes({ pathPrefix: '' }).buildRoutes(...)`（**统一经动态路由片段**，不硬编码路由表）；
- 注册：展开 RouteRecord（含 children）叶子 → `router.addRoute(parentName ?? 'layout', { name, path, component: nameComponent(name, resolveView(component) ?? PlaceholderView), meta: { title } })`；返回注册数；
- 未注册组件名：`console.warn`（开发态一次）+ 占位视图。

**`BasicLayout.vue`（重写）**：

- 状态：`collapsed`（`usePersistedState` 键 `sidebar-collapsed`，本地键 `bms:pref:sidebar-collapsed`）、`refreshVersions`（响应式记录，refresh 重挂载）；
- 侧栏：`<SideMenu :collapsed="collapsed" :active-path="route.path" />`（非受控 → 占位菜单 store）；
- 顶栏插槽占位：折叠按钮（`collapsed` 切换）+ 「语言 / 全局搜索 / 通知 / 用户」占位文本（回补波替换）；
- 标签栏：`<TabsNav ref="tabsRef" @refresh="onRefresh" />`（非受控；`openTab` / `cachedNames` 经 ref）；
- 开签：`watch(route, …)` → `tabsRef.openTab({ key: route.name, name: route.name, title: route.meta.title ?? route.name, path: route.path })`（去重由片段保证）；
- 内容区：`<router-view v-slot="{ Component }"><keep-alive :include="openedKeys.length ? openedKeys : undefined" :max="12"><component :is="Component" :key="contentKey" /></keep-alive></router-view>`；`contentKey = (route.name ?? route.path) + '#' + (refreshVersions[route.name] ?? 0)`（refresh 变更 → 重挂载）。
  **实现调整（2026-09-16 复盘修正）**：`openedKeys`（已开标签签）由宿主维护——首签在 setup 预置、随路由开签、经 `TabsNav` 关闭 / 批量关闭 / 超限事件重读其清单，**关闭标签即时释放缓存**；列表空时传 `undefined`（避免空数组被判定为「不匹配」而不缓存）；`:max`（= maxOpen 12）保留为上限兜底。原判定「`:include` 未命中」经复盘定位为**测试装置层级错位**（直接 mount 路由组件使内部 router-view 成为根级、keep-alive 缓存错层）**而非实现缺陷**——生产经根 router-view 挂载时 `:include` 一直可用（对齐记录 6 / 9，Kiwi 739 装置已修正）；
- `main.ts`：`app.mount('#app')` 后 `void import('./router/menuBootstrap').then(({ bootstrapMenus }) => bootstrapMenus(router))`——**动态导入**菜单引导（`menuBootstrap.ts`：占位 loader → `load()` → `registerMenuRoutes`），避免基座代码被提升为应用入口静态依赖（分包与体积口径，对齐记录 7）。
