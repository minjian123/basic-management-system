## 1. 设计目标与范围 <a id="goal"></a>

三件套：**主框架布局壳**（侧栏 + 顶栏 + 多标签栏 + 内容区，含折叠持久化与断点响应式）、**表单框架壳**（列表固定 + 详情多开双层页签）、**页面容器**（标题 / 描述 / 面包屑 / 工具栏 / 内容 / 底部 / 返回）；并把宿主 `apps/desktop` 装配为可用主框架。

不在本期：顶栏元素专用组件（通知 / 全局搜索 / 用户信息）；移动端底部导航骨架；主题品牌化与令牌具体值（宿主注入）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `MainLayout` <a id="main-layout"></a>

- **Props**：`menu: MenuNode[]`、`activePath: string`、`collapsed?`（`v-model`）、`showTabs?`（缺省 true）、`showSidebar?`（缺省 true）、`tabs?: TabNavItem[]`、`activeTabKey?`、`breakpoints?`（缺省取令牌 / 内置 768 / 992 / 1200）、`storageKey?`（折叠持久化）、`appTitle?`。
- **Events**：`update:collapsed` / `update:showTabs` / `menu-select(path)` / `tab-select(key)` / `tab-close(key)` / `tab-close-others(key)` / `tab-close-right(key)` / `tab-close-all` / `tab-refresh(key)` / `breakpoint-change(name)`。
- **Slots**：`logo` / `header-left` / `header-right`（顶栏元素占位）/ `default`（内容区）。
- 折叠：经 `useBaseContainer`（`collapsible` / `collapsed` / `toggleCollapse`），状态经 `useBasePersistedState` 持久化；断点经 `useResponsive`。
- 响应式：宽度 ≤ 折叠断点（缺省 992）自动折叠；≤ 抽屉断点（缺省 768）侧栏改 `el-drawer` 呈现，标签栏溢出横向滚动。

### 3.2 `FormLayoutShell` <a id="form-shell"></a>

- **Props**：`listTab: TabNavItem`、`detailTabs: TabNavItem[]`、`activeDetailKey?: string`、`openMode?: 'tab' | 'drawer' | 'page'`（缺省 `tab`）、`cacheDetail?: boolean`。
- **Events**：`open(record)` / `select(key)` / `close(key)` / `save(record)` / `delete(record)` / `refresh()` / `title-change(key, title)`。
- **Slots**：`list`（列表区）/ `detail`（详情区，作用域参数 `{ key }`）。
- 双层页签复用 `03_03` 的 `DualTabs`（上层固定列表 Tab，下层详情多开）；`openMode` 非 `tab` 时详情以抽屉 / 独立路由呈现（壳件透传事件，宿主决定）。
- `useFormShell(options)`：基于 `useTabNav` 管理详情页签（`openDetail(id, title)` 已开激活 / 不同记录新开、`closeDetail`、脏数据、`cacheDetail` 参与 keep-alive、`requestRefresh()` 触发列表刷新信号）。

### 3.3 `PageContainer` <a id="page-container"></a>

- **Props**：`title?`、`description?`、`breadcrumb?: { title: string; path?: string }[]`、`showBack?`、`sticky?`（缺省 true）、`showFooter?`。
- **Events**：`back` / `refresh`。
- **Slots**：`title` / `extra`（右上工具栏）/ `breadcrumb` / 默认（内容区）/ `footer`。
- 头部吸顶（`sticky` 时固定），内容区独立滚动，底部操作栏固定且窄屏堆叠。

### 3.4 能力投影 <a id="projections"></a>

| 投影 | 核心基类 | 面 |
| --- | --- | --- |
| `useBaseContainer(opts?)` | `BaseContainer` | `collapsible` / `collapsed` / `toggleCollapse` |
| `useBaseDesignToken(opts?)` | `BaseDesignToken` | `tokens` / `theme` / `setTokens` / `setTheme` / `onThemeChange` |
| `useResponsive(opts?)` | 消费 `BaseDesignToken.breakpoints` + `matchMedia` | `breakpoint` / `isNarrow` / `isMobile` |

- 断点缺省 `{ mobile: 768, narrow: 992, wide: 1200 }`，可由宿主注入覆盖。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| `matchMedia` 不可用（测试 / 老环境） | 退化为「宽屏」并告警，不抛错 |
| 折叠状态持久化冲突 | 以 `sessionStorage` 本地态为准，远端偏好接入后由 `needsRemoteRefresh` 决策 |
| 侧栏抽屉态下切换路由 | 自动关闭抽屉 |
| 详情页签重复打开同一记录 | 激活已有页签（不新开） |
| 详情缓存上限 | 由 `useTabNav` / 宿主策略控制（本期不做上限淘汰） |
| 面包屑过长 | 中间项省略（宿主可在 `breadcrumb` 插槽自定义） |
| 内容区与吸顶头部冲突 | 头部 `sticky` + 内容区滚动容器分离 |
| 插槽缺失 | 仅渲染存在区域，不渲染空容器 |

## 7. 边界与开放项 <a id="open"></a>

- 顶栏元素（通知 / 搜索 / 用户信息）与主题品牌化随交互类与主题任务；本期以插槽占位。
- 侧栏折叠的远端偏好同步随偏好持久化能力就绪。
- 详情页签缓存上限淘汰策略随性能优化任务。

## 8. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | 宿主装配 | 同步装配 `apps/desktop` 主框架 + 页面容器 + 菜单/页签/路由联动 |
| 2 | 断点实现 | `useResponsive`（`BaseDesignToken.breakpoints` + `matchMedia`） |
| 3 | 折叠 / 令牌投影 | 补 `useBaseContainer` / `useBaseDesignToken` |
| 4 | 表单框架壳 | 基于 `DualTabs` + `useTabNav` 组合，不重复造页签逻辑 |
