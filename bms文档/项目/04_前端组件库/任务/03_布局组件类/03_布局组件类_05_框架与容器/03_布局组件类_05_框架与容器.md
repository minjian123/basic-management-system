## 2. 任务内容 <a id="content"></a>

1. `AppLayout.vue`（`src/components/layout/`）：主框架布局壳——侧栏（`03-4`）+ 顶栏 + 内容区 + 标签栏（`03-3` `TabsNav`）区域编排；契约 `collapsed`（v-model）/ `showTabs` / `showSidebar` / `headerHeight` / `sidebarWidth` 与插槽 `sidebar` / `header` / `tabs` / `default` / `footer`；动态菜单渲染与路由 keep-alive 配合；响应式（窄屏折叠 / 抽屉侧栏，断点经 `useLayout` / `useMedia`）；顶栏元素（语言切换 / 待办与通知角标 / 用户信息）以插槽占位，真实元素随展示类与交互类需求接入。
2. `FormFrame.vue` / `useFormFrame.ts`：表单框架壳——列表固定 + 详情多开双层 Tab（复用 `FormFrameTabs`）、组件映射（`import.meta.glob`，未注册拦截提示）、事件约定（`open-detail` / `saved` / `deleted` / `dirty` / `title-change` / `fetchList`）、详情 keep-alive 按记录缓存与上限、保存 / 删除后列表刷新（局部优先）。
3. `PageContainer.vue`：页面容器——标题 / 描述 / 面包屑 / 工具栏 / 内容 / 底部操作栏插槽、`sticky` 吸顶、返回（与标签关闭联动）、窄屏堆叠；内容区后续配合容器域自适应高度 / 滚动容器（域 04 交付后接入，占位以现有滚动）。
4. 三件均组合布局片段、消费基础令牌（`03-6` 间距 / 断点 / 主题）；响应式按《布局设计 · 响应式适配》节点处理（侧栏折叠 / 抽屉化、标签溢出、底部操作栏堆叠）。
5. 范围边界（2026-09-16 建任务确认）：**标签栏本体归 `03-3`**（`TabsNav` / `FormFrameTabs`）、**侧栏内容归 `03-4`**，本任务只做壳与插槽编排；顶栏元素插槽占位。
6. 实现以《组件设计》「01 主框架布局壳」「02 表单框架壳」「03 页面容器」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
7. **前置契约（已交付）**：[03 片段机制与预置片段](../../02_基础组件类/02_基础组件类_03_片段机制与预置片段/02_基础组件类_03_片段机制与预置片段.md)（2026-09-16 交付）的 `useLayout` / `useMedia` / `useContainer` / `usePersistedState` 片段；[04 域基类](../../02_基础组件类/02_基础组件类_04_域基类/02_基础组件类_04_域基类.md)与[06 基础类横切底座](../../02_基础组件类/02_基础组件类_06_基础类横切底座/02_基础组件类_06_基础类横切底座.md)（2026-09-16 交付）的域基类双轨与 `useRequest`，本任务直接复用不重复实现。
8. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。
