## 2. 任务内容 <a id="content"></a>

1. **主框架布局壳**：侧栏（`03_04`）+ 顶栏 + 内容区 + 标签页，配合动态菜单渲染与路由 keep-alive；标签栏本体由 `03_03` 提供；顶栏元素（语言切换、待办与通知角标、用户信息）以插槽占位。
2. **表单框架壳**：列表固定 + 详情多开双层页签，承载列表页与表单页的页签状态。
3. **页面容器**：标题 / 描述 / 面包屑 / 工具栏 / 内容 / 底部插槽。
4. 三件均派生布局组件基类 `BaseLayout`；消费设计令牌（间距 / 断点 / 主题）；响应式按《布局设计》响应式适配节点处理（侧栏折叠 / 抽屉化）。

## 3. 完成标准 <a id="accept"></a>

以三件套可搭出列表页与表单页骨架；标签页切换与 keep-alive 生效；响应式断点行为与《布局设计》一致；Vitest 覆盖壳组件关键行为；`vue-tsc`、ESLint、Vitest 全通过。
