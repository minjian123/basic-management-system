## 2. 任务内容 <a id="content"></a>

1. `ErrorPage.vue`（`frontend/packages/ui-ep/src/components/feedback/`）：403 / 404 / 500 错误页——插画 + 标题 + 说明 + 主操作（返回首页 / 刷新重试 / 联系管理员），支持自定义标题 / 说明 / 操作；**不展示技术堆栈**。
2. `EmptyState.vue`：空状态场景矩阵（列表无数据 / 搜索无结果 / 待办为空 / 消息为空 / 自定义），引导按钮经 `actionPerm` 权限控制，`size` 支持表格内 / 卡片内（`small`）。
3. `SkeletonBlock.vue`：骨架屏（`list` / `table` / `form` / `card` 形态、`rows`、`animated`、`loading` 切换插槽内容），首屏与内容结构一致。
4. `LoadingMask.vue`：内容区遮罩 loading（局部覆盖、`delay` 防闪烁、`text`、`fullscreen`）。
5. `useFeedback.ts`：反馈组合式——`loading → ready / empty / error` 状态机、`retry`、空值判定（区分「无数据」与「筛选无结果」）、错误文案映射入口（走 `02_06` 请求层错误码 → i18n）。
6. 令牌与 i18n：遮罩 / 骨架 / 空态令牌统一消费（`03-6`）；文案走 vue-i18n；插画资源 `src/assets/images/empty-*.svg` 按需引用（不内联大段 SVG）。
7. 边界：接口拦截与错误码文案归 `02_06` 请求封装，本任务只提供呈现组件与重试入口；表格内空态触发归展示类通用表格（回补波）；图表降级态归图表卡。
8. 实现以《组件设计》「05 异常与空状态」节点及可交互原型为契约依据（原型即验收基准）；偏离契约先改设计节点。
9. **前置契约（已交付）**：域 02 基类体系已完成（2026-09-16）——[01 根系基类](../../02_基础组件类/02_基础组件类_01_根系基类/02_基础组件类_01_根系基类.md)、[02 组件根基类](../../02_基础组件类/02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（含四机制基类占位 / 异步资源 / 错误 / 订阅）、[03 能力机制与预置能力](../../02_基础组件类/02_基础组件类_03_能力机制与预置能力/02_基础组件类_03_能力机制与预置能力.md)；本任务组件派生对应基类并组合能力（`BasePlaceholder` / `useLayout` / `useContainer` 等），占位降级语义直接复用不重复实现。
10. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。
11. **嵌套子任务**：[03-2-1 移动端反馈件](03_布局组件类_02_异常与空状态_01_移动端反馈件/03_布局组件类_02_异常与空状态_01_移动端反馈件.md)（2026-09-17 追加）——移动端四件（`EmptyState` / `ErrorPage` / `SkeletonBlock` / `LoadingMask`）+ `useFeedback` 按同契约补齐（`@bms/ui-vant`；Kiwi 751 ~ 755）。
