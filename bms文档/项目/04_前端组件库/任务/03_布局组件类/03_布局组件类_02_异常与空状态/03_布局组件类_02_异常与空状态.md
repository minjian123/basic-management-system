## 2. 任务内容 <a id="content"></a>

1. **错误页**：403 / 404 / 500（返回与重试入口，不展示技术堆栈）。
2. **空状态**：空状态矩阵（无数据 / 无结果 / 无权限 / 未选择），支持自定义插画与操作区。
3. **骨架屏**：列表 / 卡片 / 详情形态。
4. **内容遮罩**：内容区遮罩 `loading`（延迟显示防闪烁）。
5. **反馈组合式**：`loading → ready / empty / error` 状态机与重试（派生反馈组件基类 `BaseFeedback`，经通知能力基类 `BaseNotice` 派生）。
6. 空状态插画按资产约定（kebab-case，不内联大段 SVG）。

## 3. 完成标准 <a id="accept"></a>

五项就位且被结构布局（`03-3`）、通用容器（`04-1`）实际引用；空状态矩阵与《布局设计》一致；Vitest 覆盖状态机与关键渲染分支；`vue-tsc`、ESLint、Vitest 全通过。
