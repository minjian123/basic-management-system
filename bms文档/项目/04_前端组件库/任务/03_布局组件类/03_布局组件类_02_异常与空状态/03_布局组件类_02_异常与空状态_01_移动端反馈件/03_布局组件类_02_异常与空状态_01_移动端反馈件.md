## 2. 任务内容 <a id="content"></a>

1. `frontend/packages/ui-vant` 补反馈件（与 `ui-ep` **同契约**，`@bms/core/testing` 契约套件同一套断言）：`EmptyState` / `ErrorPage` / `SkeletonBlock` / `LoadingMask` 四件 + 插画资产（`empty-*.svg` 复制自足）。
2. 移动端反馈状态机：`frontend/apps/mobile/src/utils/useFeedback.ts`（宿主级，与 `frontend/apps/desktop/src/utils/useFeedback.ts` 同契约——`loading → ready / empty / error`、`retry`、空判定可覆盖、错误文案不暴露堆栈；复用本端 `useRequest` 与 `api/error`）。
3. Vant 映射口径（启动确认）：`EmptyState → van-empty`（自定义插画 + 文案槽）、`SkeletonBlock → van-skeleton`（`list` 形态；`table / form / card` 自绘补齐，类名钩子与 PC 同构）、`LoadingMask → van-loading`（自绘遮罩层与 `delay` 防闪）、`ErrorPage`（自绘 + `van-button`）；类名钩子（`bms-*`）与 props / emits / slots 契约不变。
4. 宿主 i18n：`frontend/apps/mobile/src/i18n/{zh-CN,en-US}.ts` 补 `feedback.*` 键（与 PC 文案一致）。
5. 用例入 Kiwi TCMS（**先登记后编码**，自动化标注 `kiwi_id`；四件 + `useFeedback` 各一条，共 5 条，编号新取不复用停用编号）；契约套件属实现一致性护栏不单独登记。
6. 实现以《组件设计》「05 异常与空状态」节点及可交互原型为契约依据；偏离契约先改设计节点（本任务增量设计见 [详细设计](设计/01_详细设计_03_02_01_移动端反馈件.md)）。

## 3. 完成标准 <a id="accept"></a>

四件 + `useFeedback` 在移动端可用且与 `ui-ep` 跑同一契约套件全绿；类名钩子 / props / emits / slots 与 PC 契约一致；`delay` 防闪与四态优先级生效；宿主 i18n 补齐；Vitest 覆盖关键分支；`vue-tsc` / ESLint / Vitest / 构建 / 预算全通过；清单 / 计划 / 台账回写同步。
