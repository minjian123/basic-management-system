## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 契约 `ErrorPage` 点击缺省动作会触发 jsdom 导航 / `useRouter` 注入告警 | 契约挂载适配注入内存路由（两插件）；契约改为点击 `home`（404）/ `contact`（403），`retry` 只断言 `data-action` 存在（真实 reload 不可测） |
| 2 | ui-vant 的 svg 导入在 vitest 下内联为 data URL（PC 断言 `src` 含 `empty-*` 不适用） | 移动端断言 `src` 含 `data:image/svg+xml`（实现中立） |
| 3 | `confirm.ts` 的动态 `import('vant')` 与反馈件静态导入同源 → Rollup `INEFFECTIVE_DYNAMIC_IMPORT` 告警 | 反馈件改 Vant **子路径导入**（`vant/es/{button,empty,skeleton,loading}`），告警消除且 tree-shaking 更精确 |
| 4 | `EmptyState` 插画尺寸原拟读 CSS 令牌 | 改与令牌同值的常量（96 / 56），免运行时读样式（jsdom 下不可靠） |
