## 4. 契约设计 <a id="contract"></a>

四件 props / emits / slots **与 `ui-ep` 逐项一致**（以父任务详细设计 §4 为准，不复述）；类名钩子（`bms-*`）为契约的一部分：

| 组件 | 根钩子 | 关键子钩子（契约断言面） |
| --- | --- | --- |
| `EmptyState` | `.bms-empty-state`（`--small`） | `.bms-empty-state-title` / `-description` / `-action` |
| `ErrorPage` | `.bms-error-page` | `.bms-error-page-title` / `-description` / `-actions`；按钮 `data-action="<key>"` |
| `SkeletonBlock` | `.bms-skeleton-block` | `.bms-skeleton`（`--{variant}`）；`table` 行 `.bms-skeleton-row`（含 `is-head`）；`list` 行 `.bms-skeleton-line` |
| `LoadingMask` | `.bms-loading-mask`（`--fullscreen`） | 遮罩 `.bms-loading-mask-overlay`（`role="status"` / `aria-busy`）/ 文案 `.bms-loading-mask-text` |

`useFeedback`（宿主级）签名与 PC 一致：

```ts
export type FeedbackState = 'loading' | 'empty' | 'error' | 'ready'
export interface FeedbackError { code?: number; message: string }
export interface UseFeedbackOptions<T> {
  loader: () => Promise<T>
  immediate?: boolean
  isEmpty?: (data: T) => boolean
  errorText?: (error: unknown) => string
  retryText?: string
  onError?: (error: unknown) => void
}
export interface UseFeedbackReturn<T> {
  state: Ref<FeedbackState>
  data: Ref<T | null>
  error: Ref<FeedbackError | null>
  loading: ComputedRef<boolean>
  load: () => Promise<void>
  retry: () => Promise<void>
}
```

## 5. 契约套件与测试面 <a id="testing"></a>

`@bms/core/testing` 增 `describeFeedbackComponentsContract(kit)`（实现中立）：

- `EmptyState`：`type='search'` 标题取 i18n；`size='small'` 根修饰类；`actionPerm` 拦截不渲染 / 放行渲染并可点击 emit `action`；
- `ErrorPage`：`code` 决定动作集（404 → 1；403 / 500 → 2）；`[data-action]` 点击 emit 对应事件；`actions` 完全覆盖；
- `SkeletonBlock`：`variant` 修饰类；`table` 行数 = `rows + 1`（表头）；`loading=false` 渲染默认插槽；
- `LoadingMask`：`loading=true delay=0` 出现遮罩（`role="status"`）；`loading=false` 移除；`fullscreen` 根修饰类。

移动端行为用例（Kiwi 5 条，新登记）：四件各一条 + `useFeedback` 一条（状态机：loading → ready / empty / error、`retry`、空判定覆盖、错误文案不暴露堆栈、竞态由 `useRequest` 承担）。

## 8. 边界与开放项 <a id="boundary"></a>

| # | 项 | 处置 |
