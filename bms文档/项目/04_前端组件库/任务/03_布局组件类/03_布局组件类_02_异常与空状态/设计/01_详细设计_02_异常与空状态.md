## 1. 概述 <a id="overview"></a>

- **目标**：落地 PC 管理端异常与空状态反馈件（仅 `apps/desktop/`）：错误页 `ErrorPage`（403 / 404 / 500）、空状态 `EmptyState`（场景矩阵）、骨架屏 `SkeletonBlock`、内容遮罩 `LoadingMask`、反馈组合式 `useFeedback`（空 / 错 / 载态状态机与重试）；补齐 `empty-*.svg` 插画资源与 `/403` `/404` `/500` 独立路由。
- **范围**：任务 [03-2](../03_布局组件类_02_异常与空状态.md)（需求 [03-2](../../../../需求/03_需求_布局组件类.md#r03-2)）；供结构布局（`03-3`）、框架与容器（`03-5`）与后续容器域复用。
- **依据**：《组件设计》[05_组件设计_异常与空状态](../../../../../../设计/组件设计/07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（契约基准，含可交互原型）、《布局设计》[12_布局设计_异常与空状态](../../../../../../设计/布局设计/12_布局设计_异常与空状态.html)、《[安全开发规范](../../../../../../规范/安全开发规范.md)》（不展示技术堆栈）、《[前端开发规范](../../../../../../规范/前端开发规范.md)》§3 / §5 / §9、《[架构设计 · 前端架构](../../../../../../设计/架构设计/08_架构设计_前端架构.md)》（错误页路由与懒加载占位，登记项②）。
- **前置契约（已交付）**：组件根 `useComponentBase`、`useRequest`（`02_06`，竞态 / 取消 / loading）、`errorMessage` / `ApiError`（请求层错误归一与 `error.{code}` 文案）、`hasPerm`（`02_06_02`）、基础令牌与 EP 映射（`03_06`）。
- **边界**：不含接口拦截与错误码文案映射（请求层职责，本任务只提供呈现与重试入口）；不含表格内空态触发（展示类通用表格，回补波）与图表降级态（图表卡）；不含移动端（Vant 骨架 / 触底 / 下拉刷新另算）；不含登录页（页面任务）。

## 4. 契约设计 <a id="contract"></a>

### 4.1 `ErrorPage`（节点 §3） <a id="error-page"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `code` | `403 \| 404 \| 500` | `404` | 错误类型（决定缺省插画 / 文案 / 操作） |
| `title` | string \| null | null | 自定义标题（缺省按 code 取 i18n） |
| `description` | string \| null | null | 自定义说明 |
| `actions` | `ErrorAction[] \| null` | null | 自定义操作（提供即**完全覆盖**缺省操作） |

```ts
interface ErrorAction {
  key: string                       // 事件键（'home' | 'retry' | 'contact' | 自定义）
  text?: string                     // 缺省按 key 取 i18n
  type?: 'primary' | 'default'      // 缺省第一个 primary
  handler?: () => void              // 自定义处理（提供则不执行默认行为）
}
```

- 事件：`home` / `retry` / `contact`（缺省动作点击时**始终 emit**，作为通知与扩展点）。
- 缺省操作（按 code）：404 → 返回首页；403 → 返回首页 / 联系管理员；500 → 刷新重试 / 返回首页。缺省行为（未传 `handler` 时）：
  - `home`：有 router（`appContext`）→ `router.push('/')`，否则 `window.location.assign('/')`；
  - `retry`：`window.location.reload()`（测试环境以 emit 断言，不触发真实 reload）；
  - `contact`：无默认行为（仅 emit，由使用方接入）。
- 文案与插画（i18n / 内置资源）：404「页面不存在（或已被移除）」/ `empty-404.svg`；403「没有访问权限（如需申请请联系管理员）」/ `empty-403.svg`；500「服务开小差了（请稍后重试）」/ `empty-500.svg`。
- **不展示技术堆栈**（安全规范）；未登录 401 跳转由请求层处理（本组件不含）。

### 4.2 `EmptyState`（节点 §4） <a id="empty-state"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | `'list' \| 'search' \| 'todo' \| 'message' \| 'custom'` | `'list'` | 场景（决定缺省插画 / 文案） |
| `title` / `description` | string \| null | null | 自定义文案（缺省按场景取 i18n） |
| `image` | string \| null | null | 自定义插画 URL（缺省按 type 映射内置 `empty-*.svg`） |
| `action` | `EmptyAction \| null` | null | 引导按钮（`{ text?, type?, handler? }`；`text` 缺省按场景：list → 去创建、search → 清除筛选） |
| `actionPerm` | string \| null | null | 引导按钮权限码（无权限不渲染） |
| `size` | `'default' \| 'small'` | `'default'` | 尺寸（`small` 供表格内 / 卡片内） |

- 事件：`action`（点击引导按钮；有 `handler` 同时调 handler）。
- 场景缺省（节点 §4 / 布局设计）：list → 「暂无数据」；search → 「未找到相关内容」；todo → 「暂无待办，享受这一刻」；message → 「暂无消息」；custom → 无缺省文案（使用方提供，插画兜底 `empty-list.svg`）。
- 优先文案引导而非纯插画（布局设计口径）；不与表格内空态触发耦合（通用表格调用本组件）。

### 4.3 `SkeletonBlock`（节点 §5） <a id="skeleton"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'list' \| 'table' \| 'form' \| 'card'` | `'list'` | 与内容结构一致的骨架形态 |
| `rows` | number | 5 | 行数（`list` / `table` 生效） |
| `animated` | boolean | true | 动画（渐变扫过，令牌色） |
| `loading` | boolean | true | 加载态；`false` 渲染默认插槽内容 |

- 自绘骨架（不引第三方骨架），结构类 `bms-skeleton--{variant}`；`card` 形态含封面块 + 标题行 + 段落行；`form` 含 label 行 + 控件块。
- 消费令牌（背景 / 圆角 / 间距）；首屏场景使用（与内容结构一致，加载完成即替换）。

### 4.4 `LoadingMask`（节点 §6） <a id="loading-mask"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `loading` | boolean | false | 是否显示遮罩 |
| `text` | string \| null | null | 遮罩文案（缺省 i18n `feedback.loading`） |
| `delay` | number | 200 | 延时显示（ms，防闪烁；短请求不显示） |
| `fullscreen` | boolean | false | 整页遮罩（缺省仅覆盖包裹内容区） |

- 包裹式：默认插槽渲染内容，遮罩绝对定位覆盖包裹区（外层 `position: relative`）；`fullscreen` 时 `position: fixed` 全覆盖。
- `delay` 计时：`loading=true` 起延迟显示，`loading=false` 立即隐藏并清计时器；组件卸载清理（`onBeforeUnmount`）。
- 遮罩色用基础令牌派生（`color-mix(in srgb, var(--bms-color-bg) 70%, transparent)`，与「遮罩 0.4 透明度」口径一致由实现微调），不硬编码色值。
- 按钮内 loading 用 EP `el-button :loading`（本组件不重复实现，节点口径）。

### 4.5 `useFeedback`（节点 §7） <a id="feedback"></a>

```ts
export type FeedbackState = 'loading' | 'empty' | 'error' | 'ready'

export interface UseFeedbackOptions<T> {
  loader: () => Promise<T>
  /** 挂载即加载（缺省 false） */
  immediate?: boolean
  /** 空判定（缺省：数组 / null / 空对象视为空——`[]` / `null` / `{}`） */
  isEmpty?: (data: T) => boolean
  /** 错误文案（缺省取 `ApiError.userMessage` / 请求层 `error.{code}` 映射） */
  errorText?: (error: unknown) => string
  /** 重试文案（供界面） */
  retryText?: string
  /** 错误变化回调（可选，供页面提示） */
  onError?: (error: unknown) => void
}

export interface UseFeedbackReturn<T> {
  state: Ref<FeedbackState>
  data: Ref<T | null>
  error: Ref<{ code?: number; message: string } | null>
  loading: ComputedRef<boolean>
  load: () => Promise<void>
  retry: () => Promise<void>
}
```

- 内部复用 `useRequest(loader)`：`load()` → `run()`；`retry()` → `run()`（重试前清 error）；竞态 / 取消由 `useRequest` 提供。
- 状态机：`loading → ready / empty / error`；`retry` 回 `loading` 重试（节点 §7）。
- **null 数据**：`loader` 返回 `null` 视为**空数据**（走 `isEmpty` 判定），不与「请求取消」混淆（取消场景由 `useRequest` 内部重发覆盖，不单独短路）。
- 错误归一：`ApiError` → `{ code, message: userMessage }`；其他异常 → `{ message: errorText?.(err) ?? String(err) }`；**不暴露堆栈**。
- 空判定缺省 `isEmpty`：`Array.isArray(data) && data.length === 0`；`data === null/undefined`；对象 `Object.keys(data).length === 0`；其余 `false`。「有筛选无结果」与「真的无数据」由使用方传 `isEmpty` 区分。
- 组件选择（页面据 `state` 渲染 `SkeletonBlock` / `EmptyState` / `ErrorPage`——区块级用 `EmptyState` + 重试按钮）。

### 4.6 路由与 i18n <a id="router-i18n"></a>

- **路由**（`routes.ts`）：

```ts
{ path: '/403', name: 'error-403', component: ErrorPage, props: { code: 403 } },
{ path: '/404', name: 'error-404', component: ErrorPage, props: { code: 404 } },
{ path: '/500', name: 'error-500', component: ErrorPage, props: { code: 500 } },
{ path: '/:pathMatch(.*)*', name: 'not-found', redirect: '/404' },
```

- 修复 `02_06` 的 `redirectToForbidden()`（跳 `/403`）落点；错误页懒加载（`() => import(...)`？ErrorPage 为共享组件、体量小——统一用动态导入以配合「错误页懒加载路由组件」口径；设计取 `component: () => import('@/components/feedback/ErrorPage.vue')` + `props`）。
- **i18n**（zh-CN / en-US 双补 `feedback` 节）：
  - 错误页：`error404Title` / `error403Title` / `error500Title`；操作：`backHome` / `retry` / `contactAdmin`；
  - 空态：`emptyList` / `emptySearch` / `emptyTodo` / `emptyMessage`；引导：`goCreate` / `clearFilters`；
  - 其他：`loading`（遮罩文案缺省）。

### 4.7 插画资源规范 <a id="assets"></a>

- 目录 `src/assets/images/`，命名 `empty-*.svg`（kebab-case）；文件：`empty-list` / `empty-search` / `empty-todo` / `empty-message` / `empty-403` / `empty-404` / `empty-500`。
- 风格：极简线性（`viewBox="0 0 96 96"`、`stroke` 2、圆角端点、无填充文字），颜色用 `currentColor`（组件外层以令牌色淡化，主题改编自然跟随）。
- 引用方式：组件内静态 `import`（Vite 资源 URL），不内联大段 SVG（节点 §2 口径）；组件按 `type` / `code` 映射，`image` 传参可覆盖。
