## 1. 设计目标与范围 <a id="goal"></a>

落地异常与空状态反馈族（`ui-ep`）：错误页、空状态、骨架屏、内容遮罩、反馈组合式。作为结构布局（`03_03`）与通用容器（`04_01`）四态的共同前置。反馈件派生反馈组件基类 `BaseFeedback`（经通知能力基类 `BaseNotice` 派生）。

不在本期：通用容器四态容器本体（`04_01`）；插画品牌化（随主题品牌化任务）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `ErrorPage` <a id="error-page"></a>

- **Props**：`code: 403 | 404 | 500`、`title?`、`description?`、`showRetry?`（缺省 `code === 500`）。
- **Events**：`home` / `retry` / `back`；**Slots**：`action`。
- 缺省文案按 code（403 无权限 / 404 页面不存在 / 500 服务异常）；**不展示技术堆栈**。
- **实现投影**：经 `useBaseDisplay`（`BaseDisplay`），主文案以值语义承载。

### 3.2 `EmptyState` <a id="empty-state"></a>

- **Props**：`type: 'data' | 'result' | 'permission' | 'unselected'`、`title?`、`description?`、`illustration?`。
- **Slots**：`action` / `illustration`；缺省插画按 `type` 映射资产。
- **实现投影**：经 `useBaseDisplay`（`BaseDisplay`）。

### 3.3 `SkeletonBlock` <a id="skeleton"></a>

- **Props**：`variant: 'list' | 'card' | 'detail'`、`rows?`（列表 / 详情行数）。
- **实现投影**：经 `useFeedback`（`BaseFeedback`），挂载即 `loading`。

### 3.4 `LoadingMask` <a id="mask"></a>

- **Props**：`loading: boolean`、`delay?`（缺省 200ms 防闪）、`text?`；**Slots**：默认（被遮罩内容）。
- **实现投影**：经 `useFeedback`，随 `loading` 切换 `loading` / `ready`。

### 3.5 `useFeedback` <a id="use-feedback"></a>

```ts
useFeedback(): {
  state: Ref<FeedbackState>;            // 'loading' | 'ready' | 'empty' | 'error'
  begin(): void;                        // → loading
  ready(): void; empty(): void; error(): void;
  setRetry(fn: () => void): void;
  retry(): boolean;                     // 错误态触发重试
}
```

- 内部实例化核心 `BaseFeedback`（派生链 `BaseFeedback → BaseNotice → BaseComponent → …`）并投影；状态机与重试由核心承载。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 错误页展示堆栈 | 不展示（只给状态码与文案） |
| 空状态未知场景 | 回退 `data` 插画与缺省文案 |
| 遮罩 `delay` 内完成 | 不显示遮罩（防闪烁） |
| 非错误态调用 `retry` | 返回 `false`，不动作 |
