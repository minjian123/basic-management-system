# 基础令牌落地详细设计

## 1. 概述 <a id="overview"></a>

- **目标**：落地《布局设计 · 设计令牌》定义的**基础令牌**（色板 / 字体 / 间距 / 圆角 / 阴影），双端（`apps/desktop/` + `frontend-mobile/`）落地；`tokens.scss` 的最小集（size / density）改为**引用基础令牌**（不改变属性协议）；映射 Element Plus（PC）与 Vant（移动端）主题变量；补齐 `useDesignToken` 片段的「未定义令牌开发态告警」契约。
- **范围**：任务 [03-6](../03_布局组件类_06_基础令牌落地.md)（对应需求 [02-2](../../../../需求/02_需求_基础组件类.md#r02-2) 遗留收口）；双端令牌文件 + EP / Vant 映射 + 片段告警 + 用例；登记回写。
- **依据**：《[布局设计 · 设计令牌](../../../../../../设计/布局设计/02_布局设计_设计令牌.html)》（令牌权威定义）、《组件设计》[24 设计令牌片段](../../../../../../设计/组件设计/02_基础组件类/02_能力片段/24_组件设计_设计令牌片段/24_组件设计_设计令牌片段.md)（读取契约，§6.2 登记项② 令牌命名映射）、《[前端开发规范](../../../../../../规范/前端开发规范.md)》（组件只消费令牌、禁硬编码）、《[前端基类清单](../../../../../../前端基类清单.md)》（令牌文件登记）、[02-02 详细设计 §4.5](../../../02_基础组件类/02_基础组件类_02_组件根基类/设计/01_详细设计_02_组件根基类.md)（最小集与「改为引用基础令牌」承诺）。
- **边界**：不含暗色主题与租户品牌覆盖（`[data-theme]` / `[data-tenant]`，归「主题与租户品牌化」任务）；不含 EP / Vant 其余变量（背景 / 文本 / 边框 / fill 等）映射；不含布局组件样式消费（随 `03-1` ~ `03-5`）。

## 2. 现状与差距 <a id="gap"></a>

| # | 项 | 现状 | 差距 / 动作 |
| --- | --- | --- | --- |
| 1 | 基础令牌 | `tokens.scss` 只有 size / density 最小集；《设计令牌》定义的 color / font / space / radius / shadow 未落（域 02 遗留） | 双端 `tokens.scss` 补基础令牌五组（决策 1 ~ 3） |
| 2 | 令牌引用 | size 字号、density 间距为**直值**（12/14/16、4/8/16） | 改为引用基础令牌（字号 → `--bms-font-size-xs/base/lg`；间距 → `--bms-space-1/2/4`）；控件高度 / 图标 / 行高保持直值（设计无对应令牌） |

| 6 | 片段告警 | `useDesignToken` 契约含「未定义令牌开发态告警」，实现缺失（静默回退） | 补告警（`console.warn` + `import.meta.env.DEV` 守卫、按令牌名去重）（决策 5） |
| 7 | 消费方 | `03-1` ~ `03-5` 组件样式尚未落地（无硬编码存量） | 本任务只落令牌与映射；组件样式消费随各任务（回归检查纳入各自用例） |

## 4. 契约设计 <a id="contract"></a>

### 4.1 基础令牌清单与值（`--bms-*`，双端同款） <a id="tokens-list"></a>

```scss
:root {
  /* 色彩（《设计令牌》§2） */
  --bms-color-primary: #0969da;          /* 品牌 / 主按钮 / 选中态（可租户覆盖） */
  --bms-color-success: #2da44e;
  --bms-color-warning: #d4a72c;
  --bms-color-danger: #cf222e;
  --bms-color-info: #57606a;
  --bms-color-bg-page: #f7f8fa;          /* 页面底色 */
  --bms-color-bg: #ffffff;               /* 卡片 / 容器面 */
  --bms-color-border: #d0d7de;
  --bms-color-text: #1f2328;
  --bms-color-text-secondary: #57606a;

  /* 字体（《设计令牌》§3） */
  --bms-font-family: 'Microsoft YaHei', 'PingFang SC', 'Segoe UI', sans-serif;
  --bms-font-family-mono: Consolas, 'Cascadia Mono', monospace;
  --bms-font-size-xs: 12px;   --bms-font-size-sm: 13px;   --bms-font-size-base: 14px;
  --bms-font-size-lg: 16px;   --bms-font-size-xl: 20px;   --bms-font-size-xxl: 24px;
  --bms-font-weight-normal: 400; --bms-font-weight-medium: 500;
  --bms-font-weight-semibold: 600; --bms-font-weight-bold: 700;
  --bms-line-height-compact: 1.5; --bms-line-height-base: 1.75; --bms-line-height-loose: 2;

  /* 间距（《设计令牌》§4；4px 基准，n×4） */
  --bms-space-1: 4px;  --bms-space-2: 8px;  --bms-space-3: 12px;
  --bms-space-4: 16px; --bms-space-6: 24px; --bms-space-8: 32px;

  /* 圆角与阴影（《设计令牌》§5） */
  --bms-radius-sm: 4px; --bms-radius-md: 6px; --bms-radius-lg: 8px;
  --bms-shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.06);
  --bms-shadow-md: 0 4px 12px rgba(0, 0, 0, 0.1);
  --bms-shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.14);
}
```

- **间距命名**（决策 1）：`--bms-space-{n}`，n 为 4px 步数；未登记档位（如 `5`、`7`）消费时由 `useDesignToken.spacing()` 回落计算值并告警（提示登记后使用）。
- **bg / bg-page 澄清**：设计 html 表格行「`--color-bg` / `--color-bg-page`｜页面 / 卡片背景｜`#f7f8fa` / `#ffffff`」按「命名与语义一致」落为 `--bms-color-bg` = `#ffffff`（卡片 / 容器面）、`--bms-color-bg-page` = `#f7f8fa`（页面底色），回写 html 时修正表格名序（对齐记录 §11-7）。
- **阴影值**（决策 3）：设计 html 原文仅「层级递进」，本次落上表三档并回写具体值。

### 4.2 size / density 引用映射 <a id="reference"></a>

```scss
/* 仅列引用变化项；其余（control-height / icon / density-row）保持直值 */
--bms-size-font-small: var(--bms-font-size-xs);      /* 12px */
--bms-size-font-default: var(--bms-font-size-base);  /* 14px */
--bms-size-font-large: var(--bms-font-size-lg);      /* 16px */
--bms-density-gap-compact: var(--bms-space-1);       /* 4px  */
--bms-density-gap-default: var(--bms-space-2);       /* 8px  */
--bms-density-gap-loose: var(--bms-space-4);         /* 16px */
```

- 属性协议（`[data-size]` / `[data-density]` 选择器与五个语义变量）**不变**；控件高度 / 图标 / `density-row` 属组件档位、设计无对应基础令牌，保持直值。

### 4.3 Element Plus 变量映射（`apps/desktop` 段，决策 4） <a id="el-map"></a>

```scss
$ep-semantic-colors: primary, success, warning, danger, info;

:root {
  @each $name in $ep-semantic-colors {
    --el-color-#{$name}: var(--bms-color-#{$name});
    --el-color-#{$name}-light-3: color-mix(in srgb, var(--bms-color-#{$name}) 70%, #fff);
    --el-color-#{$name}-light-5: color-mix(in srgb, var(--bms-color-#{$name}) 50%, #fff);
    --el-color-#{$name}-light-7: color-mix(in srgb, var(--bms-color-#{$name}) 30%, #fff);
    --el-color-#{$name}-light-8: color-mix(in srgb, var(--bms-color-#{$name}) 20%, #fff);
    --el-color-#{$name}-light-9: color-mix(in srgb, var(--bms-color-#{$name}) 10%, #fff);
    --el-color-#{$name}-dark-2:  color-mix(in srgb, var(--bms-color-#{$name}) 80%, #000);
  }
  /* EP 透明场景（rgba(var(--el-color-*-rgb), α)）的 rgb 三元组（静态值；租户动态覆盖随品牌化任务由运行时重设） */
  --el-color-primary-rgb: 9, 105, 218;
  --el-color-success-rgb: 45, 164, 78;
  --el-color-warning-rgb: 212, 167, 44;
  --el-color-danger-rgb: 207, 34, 46;
  --el-color-info-rgb: 87, 96, 106;

  --el-border-radius-small: var(--bms-radius-sm);
  --el-border-radius-base: var(--bms-radius-md);
  --el-font-family: var(--bms-font-family);
  --el-font-size-base: var(--bms-font-size-base);
}
```

- **色阶公式**：对齐 EP SCSS 生成口径（`light-3` = 30% 白 + 70% 色 …… `light-9` = 90% 白 + 10% 色，`dark-2` = 80% 色 + 20% 黑）；用 `color-mix()` 运行时派生，**租户主色覆盖时色阶自动跟随**。
- **覆盖生效**：`tokens.scss` 在 `main.ts` 中于 EP 样式之后导入（现状顺序），同特异性 `:root` 后定义者生效。
- **视觉变化已知项**：EP 默认主色 `#409eff` → `--bms-color-primary` `#0969da`（设计目标）；圆角 small/base `2px/4px` → `4px/6px`。
- **浏览器基线**：`color-mix()`（Chrome 111+ / Firefox 113+ / Safari 16.2+，2023 baseline）；实施时构建验证，若基线不满足回调设计（记录偏差）。

### 4.4 Vant 变量映射（`frontend-mobile` 段，决策 6） <a id="vant-map"></a>

```scss
:root {
  --van-primary-color: var(--bms-color-primary);
  --van-success-color: var(--bms-color-success);
  --van-warning-color: var(--bms-color-warning);
  --van-danger-color: var(--bms-color-danger);
}
```

- 变量名已本地实测（`vant@4.10.2` `lib/index.css`：`--van-primary-color: var(--van-blue)` 等）；Vant 无 info 语义色，不映射。
- Vant 其余变量（文本 / 背景 / 边框等）与暗色主题归品牌化任务。

### 4.5 文件结构与双端同款口径 <a id="dup"></a>

| 段 | `apps/desktop/src/styles/tokens.scss` | `frontend-mobile/src/styles/tokens.scss` |
| --- | --- | --- |
| §1 基础令牌（`--bms-*` 五组） | 同款 | 同款 |
| §2 size / density 档位与属性协议 | 同款（引用已改） | 同款（引用已改） |
| §3 组件库映射 | EP 段（仅 PC） | Vant 段（仅移动端） |

- **同款口径**：§1 / §2 逐行同款；§3 按端差异（符合《组件设计 · 设计令牌片段》§7「令牌集按端定义，消费方式同款」）。
- 用例分别断言各自文件的关键令牌与映射（断言集合：基础段相同 + 各端映射段），不做跨工程文件互读比对（沿用域 02 双端各跑用例的惯例）。

### 4.6 未定义令牌告警（`useDesignToken`，决策 5） <a id="warn"></a>

| 项 | 设计 |
| --- | --- |
| 触发 | `token(name, localFallback?)` 读不到且**未显式提供**局部 fallback（且 options.fallback 为空）→ 告警；`spacing(n)` 读不到 → 告警（随后回落到计算值） |
| 出口 | `console.warn('[useDesignToken] 未定义令牌: <name>（先登记 tokens.scss 后再使用）')`；**不依赖根系**（片段只依赖组件根） |
| 守卫 | `import.meta.env.DEV`（生产静默）；按令牌名**去重**（模块级 `Set`），不刷屏 |
| 不改项 | 回退值行为不变（fallback / 计算值）；已有用例断言不破坏（显式 fallback 场景不告警） |
