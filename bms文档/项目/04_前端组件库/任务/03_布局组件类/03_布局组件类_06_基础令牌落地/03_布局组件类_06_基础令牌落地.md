## 2. 任务内容 <a id="content"></a>

1. `src/styles/tokens.scss` 补基础令牌四组（命名与数值以《布局设计 · 设计令牌》为准）：`--color-*`（语义色）、`--font-*`（字体族 / 字号 / 行高）、`--space-*`（间距 4 / 8 / 12 / 16 / 24）、`--radius-*`（圆角）；与既有 size / density 令牌及属性协议（`data-size` / `data-density`）并存。
2. 属性选择器映射改为引用基础令牌（既有组件样式不回归）；窄屏整体收紧经既有属性协议表达，不在本任务扩面。
3. 断点与栅格间距以布局片段 `useLayout` 既有实现为准（不重复建设）；主题与租户品牌化（《布局设计 · 主题与租户品牌化》）不在本任务范围（后续阶段）。
4. 布局域组件（`03-1` ~ `03-5`）样式消费基础令牌，无硬编码颜色 / 间距（回归检查）。
5. 实现依据：域 02 遗留（[需求 02-2](../../../需求/02_需求_基础组件类.md#r02-2) 实现期注块 / 计划 §3.1 第 10 行）与《布局设计 · 设计令牌》；**前置契约（已交付）**：[02 组件根基类](../../02_基础组件类/02_基础组件类_02_组件根基类/02_基础组件类_02_组件根基类.md)（2026-09-16 交付）已落 size / density 令牌与属性协议，本任务在其上补基础令牌并改引用。
6. 用例入 Kiwi TCMS（先登记后编码，自动化标注 `kiwi_id`）；详细设计随任务启动在 `设计/` 下补建。

## 3. 完成标准 <a id="accept"></a>

四组基础令牌落地并被 `tokens.scss` 属性协议与布局组件消费；布局域组件无硬编码颜色 / 间距（回归检查）；Vitest 覆盖令牌文件关键变量存在性（轻量）；`vue-tsc`、ESLint、Vitest 全通过；计划 §3.1 第 10 行标记闭环。
