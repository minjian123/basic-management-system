## 4. 覆盖率 <a id="coverage"></a>

- **口径**：见《[AI开发规范](../../../../../../规范/AI开发规范.md)》「覆盖率要求」节（行 + 分支 = 100%，本地不打折）。
- **实测**：`@bms/desktop` `test:cov` → **100%**（行 / 分支 / 函数 / 语句），全库无低于 100% 文件。
- **本任务含大量组件 TS 逻辑变更**（约 178 处契约补齐新增分支 + 4 个新件 + 映射修正 + 白名单分档），故不适用 `11_01` 的「纯样式无缺口」口径；新增分支用例统一落 **ui-ep 自身** spec 与 **core 契约套件**。
- **环境阻塞与解除（本批实施期，非本批引入）**：首次跑 `test:cov` 时 desktop **36 用例失败**（`injection "Symbol(tabsRootContextKey)" not found`），覆盖率无法产出结论；定位为**依赖外置仓跨工作区污染**（`ui-ep` 等 19 个依赖链接指向 `mdm` 工作区 store → element-plus 双实例）。经用户拍板重装修复后 **638/638 全通过、覆盖率 100%**（详见实施记录 §5-1）。**`git stash` 实测确认基线同样 36 失败**，非本批引入。
