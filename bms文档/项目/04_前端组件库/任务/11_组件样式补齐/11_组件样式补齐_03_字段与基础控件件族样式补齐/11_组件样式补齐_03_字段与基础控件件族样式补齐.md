## 2. 任务内容 <a id="content"></a>

1. **字段族十五件**（`ui_ep/src/components/field/`）：金额 / 级联 / 日期时间 / 枚举 / 行内开关单元格 / 多语言明细弹框 / 多语言文案字段 / 多语言文本字段 / 数字 / 富文本编辑器 / 富文本展示 / 开关 / 标签输入 / 穿梭框 / 树选择——按《组件设计 · 字段类》各节点原型补 `<style scoped>`（字段壳占位与只读回显、标签与标记、多语言明细布局、富文本工具条与内容区）。**实施期较任务书新增 3 件**（`TimeField` 时间件 / `PercentField` 百分比件 / 枚举多选件——三者为设计节点 §2 明确列出的组成部分而实现缺失；该件名于 `06_10` 统一为 `OptionSetMultiField`），详见[详细设计 §10](设计/01_详细设计_03_字段与基础控件件族样式补齐.md#decide)。
2. **基础控件族两件**（`ui_ep/src/components/input/`）：复选组 / 密码框——按《组件设计 · 基础控件类》原型补样式；其余七件（文本 / 文本域 / 数字 / 下拉 / 单选 / 开关 / 布尔复选）根元素即 Element Plus 件、靠组件库全局样式已正常，入护栏豁免清单、不补样式。**另新增 `TriStateSwitch` 自绘三态开关件**（EP `el-switch` 无 `indeterminate`，无法承载节点 §4 的三态）。
3. **对外契约保持**：只改模板结构与样式，**不破坏**各件 Props / 事件 / 插槽 / 暴露方法的既有形状——实施前逐件比对《组件设计》节点发现**约 178 处契约缺口**，经拍板**允许只增不改地一并补齐**（新增可选 props / 事件 / 插槽 / 暴露方法，既有消费方零影响；详见[详细设计 §10](设计/01_详细设计_03_字段与基础控件件族样式补齐.md#decide)）；`data-test` 钩子保留或按新结构等价迁移。
4. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌。**实交付 13 条字段族语义令牌**，明细见[详细设计 §11](设计/01_详细设计_03_字段与基础控件件族样式补齐.md#tokens)。**另新增 ui-ep 全局样式落点 `src/styles/components.css`**（跨件共用类 `.bms-field-error` 等，原全前端无定义）。
5. **既有用例更新**：同步更新 `ui_ep/tests/` 下字段 / 输入各族既有用例中受模板变更影响的 DOM 断言（含宿主 `apps/desktop/tests/user-view.spec.ts`）。
6. **原型对照**：以对应开发态核对页（**本批新增 `field-check.html`（字段族）/ `input-check.html`（基础控件族）**）做无头真机截图，逐项对照组件设计原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 17 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约**既有形状无破坏**（只增不改地补齐约 178 处契约缺口）；`ui-ep` 与宿主 `vue-tsc` / ESLint 通过、覆盖率达标、`check_preflight.py` 业务项全绿。

> **完成标准口径说明（沿用 `11_01` 决策 7 / `11_02` 决策，2026-10-13 用户拍板）**：上段「Vitest 全通过」与需求 §2.5 / 父任务 §3 的「**件族样式护栏落地后门禁持续红，直至全库真裸骨架件补齐**」存在冲突——本批补 17 件后全库仍有 **14 件**未补（归 `11_04`），护栏用例必红。经拍板：**保持护栏全库硬断言、不留批次豁免，接受门禁红**，本批验收以「定向用例 + 覆盖率（100%）+ 原型对照」为准；该冲突登记为**已知偏差**（见[实施记录 §8](实施/01_实施_03_字段与基础控件件族样式补齐.md#deviations) 与[测试记录 §6 / §7](测试/01_测试记录_03_字段与基础控件件族样式补齐.md#proto)）。**按用户口径，全库补齐前不推送。**

> **范围偏差说明（2026-10-14 用户逐项拍板）**：本批名义范围为「补样式 + 模板改组件库件承载」，实施前逐件比对《组件设计》节点另发现**约 178 处「节点有、实现缺」的契约缺口**与 **4 类独立件缺失**（时间件 / 百分比件 / 枚举多选件 / 三态开关件），经逐项确认**本批一并补齐并新增 4 件**；另修正 **4 处既有缺陷**（`NumberField` 精度浮点误判、`formWidgets` 的 `multi_select` 误映射、`sanitizeHtml` 5 处白名单偏差、EP 开关无三态）与 **1 处依赖环境缺陷**（外置依赖仓跨工作区污染，非本批引入），明细见[实施记录 §5](实施/01_实施_03_字段与基础控件件族样式补齐.md#issues)。
