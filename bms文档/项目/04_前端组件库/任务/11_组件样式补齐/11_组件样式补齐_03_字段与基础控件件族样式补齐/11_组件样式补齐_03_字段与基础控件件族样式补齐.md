## 2. 任务内容 <a id="content"></a>

1. **字段族十五件**（`ui-ep/src/components/field/`）：金额 / 级联 / 日期时间 / 枚举 / 行内开关单元格 / 多语言明细弹框 / 多语言文案字段 / 多语言文本字段 / 数字 / 富文本编辑器 / 富文本展示 / 开关 / 标签输入 / 穿梭框 / 树选择——按《组件设计 · 字段类》各节点原型补 `<style scoped>`（字段壳占位与只读回显、标签与标记、多语言明细布局、富文本工具条与内容区）。
2. **基础控件族两件**（`ui-ep/src/components/input/`）：复选组 / 密码框——按《组件设计 · 基础控件类》原型补样式；其余七件（文本 / 文本域 / 数字 / 下拉 / 单选 / 开关 / 布尔复选）根元素即 Element Plus 件、靠组件库全局样式已正常，入护栏豁免清单、不补样式。
3. **对外契约保持**：只改模板结构与样式，不改各件 Props / 事件 / 插槽 / 暴露方法；`data-test` 钩子保留或按新结构等价迁移。
4. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌。
5. **既有用例更新**：同步更新 `ui-ep/tests/` 下字段 / 输入各族既有用例中受模板变更影响的 DOM 断言。
6. **原型对照**：以对应开发态核对页（`field-*` / `org-check` / `dict-check` 等）做无头真机截图，逐项对照组件设计原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 17 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约无破坏；`ui-ep` 与宿主 `vue-tsc` / ESLint / Vitest 全通过、覆盖率达标、`check-preflight.py` 全绿。
