## 4. 覆盖率 <a id="coverage"></a>

- **口径**：见《[AI开发规范](../../../../../../规范/AI开发规范.md)》「覆盖率要求」节（行 + 分支 = 100%，本地不打折）。
- **实测**：`@bms/desktop` `test:cov` → **100%**（行 / 分支 / 函数 / 语句），全库无低于 100% 文件。
- **本任务含组件 TS 逻辑变更**（`ImportDialog` 新增 `on-exceed` 换文件分支、`el-dialog` 受控显隐与 `before-close` 拦截、明细行内改件、i18n 页签改件等），故**不适用**「纯样式无缺口」口径；`ui-ep` 自身 spec 与新增分支用例一一对应，**1093 用例全通过**。
- **核对页改动（6 页）落在 `apps/desktop/src/dev/`**——该目录不计入覆盖率统计（`vite build` 亦不包含），故核对页新增逻辑不引入覆盖率缺口；已实测 `test:cov` 仍为 100%。

## 7. 偏差与遗留 <a id="deviations"></a>

- **未覆盖项**：① 图表内核（ECharts）与网格内核（gridstack）主题化（归品牌化任务）；② 真实后端联调（导入执行 / 导出取数 / 数据集运行 / i18n 保存与缓存失效 / 报表保存发布，归各后端窗口）；③ `FormDesigner` 字段面板搜索与拖拽源细化、组件类型值兼容性校验（归表单定制域后续任务）；④ 界面文案 i18n（全库横切）；⑤ 移动端 `ui-vant`（本阶段范围外，六族均为管理端能力）。
