## 2. 任务内容 <a id="content"></a>

1. **导入导出族五件**（`ui_ep/src/components/import_export/`）：导出按钮 / 导出进度 / 导入对话框 / 导入对话框体 / 导入错误报告——按《组件设计 · 导入导出》原型补 `<style scoped>`（步骤条与拖拽区、进度与结果、错误明细表形态）。
2. **表单设计器族四件**（`ui_ep/src/components/form_design/`）：扩展字段对话框 / 字段属性面板 / 表单设计器 / 设计器画布——按《组件设计 · 表单设计器》原型补样式（三栏布局、画布栅格与选中态、属性分组）。
3. **表单渲染器族两件**（`ui_ep/src/components/form_render/`）：表单渲染器 / 渲染器主体——按《组件设计 · 表单渲染器》原型补样式（分组区、明细区、栅格与只读态）。
4. **图表卡**（`ui_ep/src/components/chart/ChartCard.vue`）：按《组件设计 · 图表卡》原型补样式（卡片头与工具条、画布区、四态占位）；ECharts 内核经既有独立分包装载，不主题化内核。
5. **国际化文案编辑器**（`ui_ep/src/components/i18n/I18nMessageEditor.vue`）：按《组件设计 · 国际化文案编辑器》原型补样式（语言清单、文案网格、筛选区）。
6. **报表设计器**（`ui_ep/src/components/report/ReportDesigner.vue`）：按《组件设计 · 报表设计器》原型补样式（数据集面板、画布与网格、图表配置面板）；gridstack 经既有独立分包装载。
7. **对外契约保持**：**不破坏既有形状、允许只增不改**（沿用 `11_02` / `11_03` 已确认口径，2026-10-14 拍板）——可新增可选 Props / 事件 / 插槽 / 暴露方法并一并补齐设计节点契约缺口，**不删不改既有项**；`data-test` 钩子按新结构重命名并全面改写引用处（用例 + 核对页）。
8. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌。
9. **全局共享占位类**：`.bms-interaction-placeholder` / `.bms-display-placeholder` 全前端零定义（共 20 个引用件），按「跨件共用契约面」落 ui-ep 全局样式落点 `src/styles/components.css`（与 `11_03` `.bms-field-error` 同口径）。
10. **既有用例更新**：同步更新 `ui_ep/tests/` 下导入导出 / 表单设计器 / 表单渲染器 / 图表 / i18n / 报表各族既有用例中受模板变更影响的 DOM 断言。
11. **原型对照**：以对应开发态核对页（`import-export-check` / `form-design-check` / `form-render-check` / `chart-check` / `i18n-editor-check` / `report-design-check`）做无头真机截图（**六页补亮暗切换**），逐项对照组件设计原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 14 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约无破坏；`ui-ep` 与宿主 `vue-tsc` / ESLint / Vitest **全通过**、覆盖率达标、`check_preflight.py` 全绿。

> **域 11 收口口径（2026-10-14 拍板）**：本批即域 11 第四批（剩余 14 件 = 全批），交付后 `interaction-style.spec.ts` 的**全库真裸骨架硬断言转绿**——`11_01` ~ `11_03` 登记的「护栏按设计持续红」偏差随之闭环，**解除「全库补齐前不推送」限制**；EP 薄包装 10 件豁免清单保留。
