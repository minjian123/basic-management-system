## 2. 任务内容 <a id="content"></a>

1. **导入导出族五件**（`ui-ep/src/components/import-export/`）：导出按钮 / 导出进度 / 导入对话框 / 导入对话框体 / 导入错误报告——按《组件设计 · 导入导出》原型补 `<style scoped>`（步骤条与拖拽区、进度与结果、错误明细表形态）。
2. **表单设计器族四件**（`ui-ep/src/components/form-design/`）：扩展字段对话框 / 字段属性面板 / 表单设计器 / 设计器画布——按《组件设计 · 表单设计器》原型补样式（三栏布局、画布栅格与选中态、属性分组）。
3. **表单渲染器族两件**（`ui-ep/src/components/form-render/`）：表单渲染器 / 渲染器主体——按《组件设计 · 表单渲染器》原型补样式（分组区、明细区、栅格与只读态）。
4. **图表卡**（`ui-ep/src/components/chart/ChartCard.vue`）：按《组件设计 · 图表卡》原型补样式（卡片头与工具条、画布区、四态占位）；ECharts 内核经既有独立分包装载，不主题化内核。
5. **国际化文案编辑器**（`ui-ep/src/components/i18n/I18nMessageEditor.vue`）：按《组件设计 · 国际化文案编辑器》原型补样式（语言清单、文案网格、筛选区）。
6. **报表设计器**（`ui-ep/src/components/report/ReportDesigner.vue`）：按《组件设计 · 报表设计器》原型补样式（数据集面板、画布与网格、图表配置面板）；gridstack 经既有独立分包装载。
7. **对外契约保持**：只改模板结构与样式，不改各件 Props / 事件 / 插槽 / 暴露方法；`data-test` 钩子保留或按新结构等价迁移。
8. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌。
9. **既有用例更新**：同步更新 `ui-ep/tests/` 下导入导出 / 表单设计器 / 表单渲染器 / 图表 / i18n / 报表各族既有用例中受模板变更影响的 DOM 断言。
10. **原型对照**：以对应开发态核对页（`import-export-check` / `form-design-check` / `form-render-check` / `chart-check` / `i18n-editor-check` / `report-design-check`）做无头真机截图，逐项对照组件设计原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 14 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约无破坏；`ui-ep` 与宿主 `vue-tsc` / ESLint / Vitest 全通过、覆盖率达标、`check-preflight.py` 全绿。
