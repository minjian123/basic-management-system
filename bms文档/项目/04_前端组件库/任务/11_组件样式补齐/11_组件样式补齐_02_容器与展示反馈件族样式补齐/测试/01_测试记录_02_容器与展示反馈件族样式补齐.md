## 4. 覆盖率 <a id="coverage"></a>

- **口径**：见《[AI开发规范](../../../../../../规范/AI开发规范.md)》“覆盖率要求”节（行 + 分支 = 100%，本地不打折）。
- **实测**：`@bms/desktop` `test:cov` → **100%**（行 / 分支 / 函数 / 语句），全库无低于 100% 文件。
- **本任务含组件 TS 逻辑变更**（21 处契约补齐新增分支），故不适用 `11_01` 的「纯样式无缺口」口径；新增分支用例统一落 **ui-ep 自身** spec（`container-*` / `display-*` / `feedback.spec.ts`）。
- **实测更正**：`desktop` 覆盖率报告**只统计 `apps/desktop/src`**（`coverage-summary.json` 中 ui-ep 条目为 0），本批不会拉低宿主覆盖率；宿主 spec 实测无需改动（详见实施记录 §5-3）。

**偏离项与处置**：

| 偏离 | 说明 | 处置 |
| --- | --- | --- |
| 令牌取色与原型内联色 | 原型为「Element Plus 默认外观 + 内联色值」的形态示意（如 `rgba(0,0,0,.82)` / `#e6a23c`） | **不修**——色 / 圆角 / 间距一律取设计令牌，只对齐分区结构、交互形态与表格 / 网格 / 遮罩形态（详细设计 §5 已登记该口径） |
| 快捷入口路由未注册 | 节点要求「未注册路由**不渲染**并告警（防白屏）」 | **登记差异**——实现取「**保留入口 + 拦截跳转 + 控制台告警**」：既不白屏、也不静默跳转，且用户能看见配置问题；后续接入宿主路由能力时再评估「不渲染」语义 |
| 水印承载 | 原型用 `el-watermark` | **不修**——保留自研平铺层（已有防篡改 DOM 监听自动恢复 + 时间戳分钟级刷新 + 动态重绘，`el-watermark` 无这些能力；替换会丢设计节点要求的防篡改行为）；差异已登记 |
| 文件预览 PDF 翻页 | 节点「缺省用浏览器内置阅读器」，翻页能力视浏览器 | **不修**——经 iframe `#page=N` 片段驱动（节点已允许「视浏览器能力，必要时自绘」） |
| 审计差异筛选区 | 原型含表名 / 记录 ID / 操作人 / 日期范围 | **不修**——按节点 §4 实现，且**时间范围为分片键、必填**：缺失时禁用查询并提示（对齐节点 §4「91002」） |
