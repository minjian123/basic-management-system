## 2. 任务内容 <a id="content"></a>

1. **容器族八件**（`ui_ep/src/components/container/`）：宽高比容器 / 自适应高度容器 / 全屏容器 / 懒加载容器 / 滚动容器 / 分区容器 / 四态容器 / 虚拟列表容器——按《组件设计 · 通用容器》各节点原型补 `<style scoped>`（容器占位、滚动区、分区头与折叠、四态遮罩、虚拟列表行），内部已用 `el-scrollbar` 者对齐其外壳样式。
2. **展示族七件**（`ui_ep/src/components/display/`）：审计差异 / 文件预览 / 二维码 / 快捷入口 / 用户头像 / 用户信息 / 水印——按《组件设计 · 展示类》各节点原型补样式（差异增删行语义色、预览容器、二维码画布与过期遮罩、入口卡片、头像形态与溢出、水印层）。
3. **反馈族三件**（`ui_ep/src/components/feedback/`）：空状态 / 错误页 / 加载遮罩——按《组件设计 · 异常与空状态》原型补样式（插画与文案排布、错误页分区、遮罩与加载指示）；骨架屏为 Element Plus 薄包装，入护栏豁免清单、不补样式。
4. **对外契约保持**：只改模板结构与样式，**不破坏**各件 Props / 事件 / 插槽 / 暴露方法的既有形状——实施前逐件比对《组件设计》节点发现 21 处契约缺口，经拍板**允许只增不改地一并补齐**（新增可选 props / 事件 / 插槽 / 暴露方法，既有消费方零影响；详见[详细设计 §10](设计/01_详细设计_02_容器与展示反馈件族样式补齐.md#decide)）；`data-test` 钩子保留或按新结构等价迁移。
5. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌。**实交付 7 条新增**（审计差异增删行底与字色 4 条 + 二维码状态遮罩底 + 文件预览遮罩底 + 通用内容遮罩底）+ **8 条既有漂移落地**（滚动条 5 条 / 反白字色 / 插画尺寸 / 全屏背景），明细见[详细设计 §11](设计/01_详细设计_02_容器与展示反馈件族样式补齐.md#tokens)。
6. **既有用例更新**：同步更新 `ui_ep/tests/` 下容器 / 展示 / 反馈各族既有用例中受模板变更影响的 DOM 断言。
7. **原型对照**：以对应开发态核对页（**本批新增 `container-check.html`（容器族）/ `display-feedback-check.html`（展示族 + 反馈族）**）做无头真机截图，逐项对照《组件设计》各节点自带原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 18 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约**既有形状无破坏**（只增不改地补齐 21 处契约缺口）；`ui-ep` 与宿主 `vue-tsc` / ESLint 通过、覆盖率达标、`check_preflight.py` 业务项全绿。

> **完成标准口径说明（沿用 `11_01` 决策 7 / 2026-10-13 用户拍板）**：上段「Vitest 全通过」与需求 §2.5 / 父任务 §3 的「**件族样式护栏落地后门禁持续红，直至全库真裸骨架件补齐**」存在冲突——本批补 18 件后全库仍有 **31 件**未补，护栏用例必红。经拍板：**保持护栏全库硬断言、不留批次豁免，接受门禁红**，本批验收以「定向用例 + 覆盖率（100%）+ 原型对照」为准；该冲突登记为**已知偏差**（见[实施记录 §8](实施/01_实施_02_容器与展示反馈件族样式补齐.md#deviations) 与[测试记录 §6 / §7](测试/01_测试记录_02_容器与展示反馈件族样式补齐.md#proto)）。**按用户口径，全库补齐前不推送。**

> **范围偏差说明（2026-10-14 用户逐项拍板）**：本批名义范围为「补样式 + 模板改组件库件承载」，实施前逐件比对《组件设计》节点另发现 **21 处「节点有、实现缺」的契约缺口**，经逐项确认**本批一并补齐**；另修复两处**既有缺陷**（域 11 任务文档编号口径、任务域号冲突）与一处**实施期发现的核对页缺陷**，明细见[实施记录 §5](实施/01_实施_02_容器与展示反馈件族样式补齐.md#issues)。
