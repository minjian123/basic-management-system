## 2. 任务内容 <a id="content"></a>

1. **容器族八件**（`ui-ep/src/components/container/`）：宽高比容器 / 自适应高度容器 / 全屏容器 / 懒加载容器 / 滚动容器 / 分区容器 / 四态容器 / 虚拟列表容器——按《组件设计 · 通用容器》各节点原型补 `<style scoped>`（容器占位、滚动区、分区头与折叠、四态遮罩、虚拟列表行），内部已用 `el-scrollbar` 者对齐其外壳样式。
2. **展示族七件**（`ui-ep/src/components/display/`）：审计差异 / 文件预览 / 二维码 / 快捷入口 / 用户头像 / 用户信息 / 水印——按《组件设计 · 展示类》各节点原型补样式（差异增删行语义色、预览容器、二维码画布与过期遮罩、入口卡片、头像形态与溢出、水印层）。
3. **反馈族三件**（`ui-ep/src/components/feedback/`）：空状态 / 错误页 / 加载遮罩——按《组件设计 · 异常与空状态》原型补样式（插画与文案排布、错误页分区、遮罩与加载指示）；骨架屏为 Element Plus 薄包装，入护栏豁免清单、不补样式。
4. **对外契约保持**：只改模板结构与样式，不改各件 Props / 事件 / 插槽 / 暴露方法；`data-test` 钩子保留或按新结构等价迁移。
5. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌（本批预计需审计差异增删行语义底、水印与二维码过期遮罩语义色）。
6. **既有用例更新**：同步更新 `ui-ep/tests/` 下容器 / 展示 / 反馈各族既有用例中受模板变更影响的 DOM 断言。
7. **原型对照**：以对应开发态核对页（`container-check` / `data-display-check` / `error-views` 等）做无头真机截图，逐项对照组件设计原型，结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

本批 18 件逐件补齐 `<style scoped>`，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约无破坏；`ui-ep` 与宿主 `vue-tsc` / ESLint / Vitest 全通过、覆盖率达标、`check-preflight.py` 全绿。
