## 1. 设计目标与范围 <a id="goal"></a>

`frontend/packages/ui_ep/src/components/interaction/` 下三族 **17 件**阶段四只交付了结构与交互逻辑，**无 `<style scoped>` 块、模板以裸原生交互元素承载**（`<button>` / `<input>` / `<select>`），宿主角色管理页「权限配置」区呈**裸骨架**，与《组件设计》对应节点的可交互原型差距显著。

本任务按《组件设计 · 权限配置》《组件设计 · 图标选择器》《组件设计 · 代码表达式编辑器》三节点自带原型，为 17 件**重构模板为组件库件承载 + 逐件补 `<style scoped>`**，使三族可真实呈现；并落地**全库件族样式护栏**与**令牌口径**，供 `11_02` ~ `11_04` 沿用。

**边界（不在本任务）**：

- 其余三批（容器与展示反馈 18 件 / 字段与基础控件 17 件 / 专题件族 14 件）归 `11_02` ~ `11_04`；
- **编辑内核（CodeMirror）不主题化**——只补宿主壳样式（任务 §2.3 明确）；
- 不改各件对外契约（Props / 事件 / 插槽 / 暴露方法）；
- 移动端 `ui_vant` 本阶段范围外；
- 真实后端联调（自定义图标 CRUD、SQL 测试执行、表达式校验接口）归对应后端任务。

## 4. 设计要点 <a id="design"></a>

### 4.1 样式落点与口径（强制） <a id="style-base"></a>

- 样式一律入**各件 `<style scoped>`**（纯 CSS，与 ui-ep 既有 99 件同口径），**不落全局文件**。
- 类名 **kebab-case**（BEM 简化），沿用件现有 `bms-<件名>__<元素>` 前缀；模板重构后新增元素按同规则命名。
- 色 / 间距 / 圆角 / 字号 / 阴影一律 `var(--bms-*)`；**色值零硬编码**（`guard-tokens.spec.ts` 强制，色值无豁免）；EP 内部结构经 `--el-*` 覆盖时同样只写令牌。
- 尺寸硬编码白名单（《前端开发规范》「尺寸硬编码白名单」）：① `1px` 描边 / 分隔线；② 媒体查询断点；③ 树形递归缩进；④ JS 运行时计算的内联值（弹层坐标等）；⑤ 件内置图形与骨架尺寸。**间距 / 圆角 / 字号 / 结构尺寸一律走令牌**。
- **样式深度（决策 9）**：**骨架语义件深度定制 + 薄封装件最小必要**——与阶段七 `06_01` 布局族已验收口径一致，薄封装件只经 `--el-*` 与最小必要样式对齐令牌，**不重写 Element Plus 外观**。

**骨架语义件（深度定制）**：`PermissionConfig` / `MenuPermissionPanel` / `FormPermissionPanel` / `DataScopePanel` / `RoleAssignPanel` / `PermissionTree` / `IconPicker` / `IconLibrary` / `CodeEditor` / `CodeViewer` / `CronEditor` / `ExpressionEditor` / `SqlEditor`。

**薄封装件（最小必要）**：`ActionPermissionPanel` / `FieldPermissionPanel` / `DynamicDictPicker` / `CodeMirrorHost`。

### 4.2 权限配置族（9 件） <a id="perm"></a>

原型：[07_原型设计_权限配置.html](../../../../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_原型设计_权限配置.html)；对齐《布局设计 · 列表页》《布局设计 · 表格明细》《布局设计 · 设计令牌》。

- **`PermissionConfig`（授权总容器件）**：根 `div` flex 列 + `gap`；页签改用 **`el-tabs`**（`data-test="permission-tabs"` 保留，`el-tab-pane` 逐页签，`data-test="permission-tab-<key>"` 迁移至 pane 或标签）；错误条 `__error` 用警示底令牌 + 圆角 + 内边距；降级区 `__degrade` 用空态风格（居中、次要色、内边距）；`__body` `flex: 1` + `min-height: 0` + `overflow: auto`。
- **`MenuPermissionPanel`（菜单权限件）**：左右分栏（左 `PermissionTree` 固定 `320px`，右详情 `flex: 1`）；两子页签改 **`el-tabs`**（`data-test="menu-subtab-action"` / `menu-subtab-field` 保留）；表单区 `__form` 卡片化（1px 边框 + `--bms-radius-md` + 内边距 + 标题字重）；空态 `__empty` 居中次要色。
- **`PermissionTree`（菜单树子件）**：搜索框改 **`el-input`**（`clearable` + `prefix` 图标位，`data-test="tree-search"` 保留）；节点行改自绘 flex 行（`1px` 底边、悬停底 `--bms-color-fill`、选中底 `--bms-color-primary-light` + 左 2px 主色条）；展开按钮改 **`el-button` `link`** 或自绘按钮（`data-test="tree-expand"`）；勾选改 **`el-checkbox`**（`indeterminate` 承接三态，`data-test="node-check-<id>"` 保留）；「未挂接」标记 `__detached` 用新增令牌 `--bms-perm-detached-color`（字色）+ 浅底 + `--bms-radius-sm`；缩进经 `padding-left` 内联值（白名单③）。
- **`FormPermissionPanel`（表单权限件）**：左表单列表改**自绘可点列表**（`1px` 底边、悬停 / 选中底、`__free` 标记「无入口」用 `--bms-perm-detached-color`）；搜索改 **`el-input`**（`data-test="form-search"` 保留）；右侧两子页签改 **`el-tabs`**（`data-test="form-subtab-*"` 保留）；空态居中。
- **`ActionPermissionPanel`（权限码面板，薄封装）**：勾选改 **`el-checkbox`**（`data-test="action-check-<id>"` 保留）；来源只读标记 `__readonly` 用新增令牌 `--bms-perm-readonly-bg`（底）+ 次要字色 + `--bms-radius-sm`；行 `flex` 对齐 + `gap`；空态次要色。
- **`FieldPermissionPanel`（字段权限面板）**：**引入 `el-table`**（决策 4）承载字段矩阵——四列「字段 / 可见 / 可编辑 / 来源」，可见与可编辑用 **`el-switch`**（`size="small"`），来源列显示只读标记；工具栏改 **`el-input`**（搜索）+ **`el-checkbox`**（仅显示已收窄）+ **`el-button`**（三个批量动作）；`el-table` 经 `--el-table-*` 映射对齐令牌（表头底 `--bms-table-header-bg` / 边框 `--bms-table-border` / 悬停 `--bms-table-row-hover-bg`）；`data-test` 钩子按新结构重命名（决策 5，见 §6.2）。
- **`DataScopePanel`（数据权限件）**：左右分栏（左字典列表固定 `280px`，右详情 `flex: 1`）；四子页签改 **`el-tabs`**（`data-test="policy-<key>"` 保留）；数据选择改 **`el-table`** + 多选列；数据区域改 **`el-table`**（两列动态字典件选择 + 「新增区域」`el-button`）；数据匹配改 **`el-table`**（字段 `el-select` + 通配符 `el-input` + 校验列，非法值用新增令牌 `--bms-perm-invalid-color`）；扩展权限改 **`el-table`**（扩展 `el-select` + 参数列 + 「新增扩展」）；空态居中。
- **`DynamicDictPicker`（动态字典件，薄封装）**：候选列表改 **`el-checkbox-group`**（多选）/ **`el-radio-group`**（单选）承载，逐项 `el-checkbox` / `el-radio`（`data-test="dict-item-<value>"` 保留）；容器 `flex` 换行 + `gap`；空态次要色。
- **`RoleAssignPanel`（角色分配件）**：工具栏（「选择用户」`el-button` primary + 计数次要色）；已分配列表改**自绘列表**（`1px` 底边、`__name` 主字色 / `__username` 次要色 / `__disabled` 停用标记用 `--bms-perm-detached-color` / 移除 `el-button` `link` danger）；选择用户弹窗改 **`el-dialog`**（`data-test="role-assign-dialog"` 保留，宽 `520px`、标题「选择用户」、底部取消 + 确定）——弹窗内搜索 `el-input`、候选 `el-checkbox` 列表、加载态与空态；`data-test` 钩子保留或等价迁移。

### 4.3 图标选择器族（2 件） <a id="icon"></a>

原型：[03_原型设计_图标选择器.html](../../../../../../设计/组件设计/08_交互类/03_组件设计_图标选择器/03_原型设计_图标选择器.html)；对齐《布局设计 · 设计令牌》「图标与图片」（尺寸 14/16/20px）。

- **`IconPicker`（图标选择件）**：触发框改 **`el-input`**（`readonly` + `prefix` 渲染已选图标 + `suffix` 清除 / 下拉箭头，`data-test="trigger"` / `placeholder-text` / `trigger-key` / `clear` 等价迁移）；弹层改 **`el-popover`**（`trigger="click"`、宽 `360px`、`placement="bottom-start"`、`data-test="popover"` 保留）；搜索改 **`el-input`**（`size="small"` + `clearable`）；分类改 **`el-tag`** 组（`effect` 随选中切换，`data-test="category-<key>"` 保留）；最近使用与网格改**网格布局**（`grid-template-columns: repeat(8, 1fr)` + `gap`；单元格 `1px` 边框 + `--bms-radius-md` + 悬停主色边 / 选中主色底，`data-test="grid"` / `icon-<key>` / `recent-<key>` 保留）；空态居中次要色；尺寸档位经 `data-size` 属性联动控件高度（`--bms-control-height`）。
- **`IconLibrary`（图标清单管理件）**：工具栏（搜索 `el-input` + 分组 **`el-radio-group`** / `el-button` 组 + 管理动作 `el-button`）；网格同 `IconPicker` 网格口径（`data-test="grid"` / `icon-<key>` 保留）；每项显示预览 + 名称 + key（等宽字体）+ 引用计数 + 「复制 key」`el-button`；自定义图标列表改 **`el-table`**（预览 / key / 名称 / 分类 / 状态 `el-tag` / 引用 / 操作 `el-button`，`data-test="custom-<id>"` / `edit-*` / `toggle-*` / `remove-*` 等价迁移）。

### 4.4 代码表达式编辑器族（6 件） <a id="code"></a>

原型：[04_原型设计_代码表达式编辑器.html](../../../../../../设计/组件设计/08_交互类/04_组件设计_代码表达式编辑器/04_原型设计_代码表达式编辑器.html)；**编辑内核（CodeMirror）只补宿主壳样式，不主题化内核**（任务 §2.3）。

- **`CodeEditor`（通用编辑器件）**：根 flex 列 + `gap`；宿主区 `__host` 包 `1px` 边框 + `--bms-radius-md` + `overflow: hidden`；纯文本降级 `__fallback` 用等宽字体 + 内边距 + 无边框（外层边框已给）+ 可调整大小禁用；诊断汇总 `__diagnostics` 列表按 `data-severity` 着色（`error` → `--bms-color-danger`、`warning` → `--bms-color-warning`、`info` → `--bms-color-info`）+ 次要字号 + 上边框。
- **`CodeMirrorHost`（CodeMirror 宿主壳，薄封装）**：只补壳——`__mount` 最小高度与溢出；错误条 `__error` 用警示底 + 次要色 + 内边距 + `--bms-radius-md`；**不写 `.cm-*` 主题规则**（内核主题归品牌化任务）。
- **`CodeViewer`（只读高亮件）**：容器 `1px` 边框 + `--bms-radius-md` + `overflow: hidden`；头栏 `__header`（语言标签次要色 + 「复制」/「展开·收起」`el-button` `link`）+ 底边框 + `--bms-color-fill` 底；正文区 `__body` `overflow: auto`；行号槽 `__gutter` 等宽字体 + 次要色 + 右对齐 + `user-select: none`；代码区 `__code` 等宽字体 + 内边距 + 自动换行开关经 `data-wrap`。
- **`CronEditor`（cron 编辑器件）**：段编辑改**行内 `el-input`**（`prepend` 段名：分 / 时 / 日 / 月 / 周，`data-test="cron-<key>"` 保留）+ flex 换行 + `gap`；模板改 **`el-button`** 组（`data-test="cron-template-<key>"` 保留）；表达式与描述分行（描述用次要色，`data-test="cron-expression"` / `cron-description` 保留）；非法提示 `__error` 用 `--bms-color-danger`（`data-test="cron-error"` 保留）；合法态经 `data-valid` 属性联动边框色（`--el-color-success` / `--el-color-danger`）。
- **`ExpressionEditor`（表达式编辑器件）**：工具栏 `el-button`（校验）；主体左右分栏（编辑器 `flex: 1`，令牌面板固定 `220px`）；令牌面板 `__panel` 卡片化（1px 边框 + 内边距 + 分组标题字重 + 令牌 `el-button` `size="small"` 换行排布）；`data-test="toolbar"` / `panel` / `fields` / `variables` / `templates` / `token-*` / `template-*` 保留。
- **`SqlEditor`（SQL 编辑器件）**：工具栏 `el-button` 组（格式化 / 校验 / 测试执行，`data-test="toolbar"` / `format` / `validate` / `test` 保留）；主体左右分栏（编辑器 `flex: 1`，字段清单固定 `200px`）；字段清单 `__fields` 卡片化 + `el-button` 列名（等宽 + 类型次要色，`data-test="fields"` / `field-<name>` 保留）。

### 4.5 主题与响应式（强制） <a id="theme"></a>

- **主题**：颜色全部走 `--bms-color-*` / `--bms-color-fill` / `--bms-color-bg-page` / 域语义令牌 + `--el-*` 映射 → 亮 / 暗主题经 `[data-theme='dark']` 令牌自动切换，三族**不写 dark 专用规则**。
- **响应式**：三族为**面板 / 编辑器件**，主要按容器宽度自适应——左右分栏件（`MenuPermissionPanel` / `FormPermissionPanel` / `DataScopePanel` / `ExpressionEditor` / `SqlEditor`）用 flex + `min-width: 0` 防溢出，窄容器下侧栏宽度经媒体查询（`max-width: 992px`，与 `useResponsive` 缺省同值）收紧；网格件（`IconPicker` / `IconLibrary`）用 `grid-template-columns: repeat(auto-fill, minmax(...))` 自适应列数；**不承担页面级折叠 / 抽屉职责**。
