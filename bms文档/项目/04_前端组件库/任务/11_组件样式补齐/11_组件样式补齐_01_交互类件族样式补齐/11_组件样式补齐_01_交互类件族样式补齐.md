## 2. 任务内容 <a id="content"></a>

1. **权限配置族九件**（`ui_ep/src/components/interaction/`）：授权总容器件（`PermissionConfig`）/ 菜单权限件（`MenuPermissionPanel`）/ 菜单树子件（`PermissionTree`）/ 表单权限件（`FormPermissionPanel`）/ 权限码面板（`ActionPermissionPanel`）/ 字段权限面板（`FieldPermissionPanel`）/ 数据权限件（`DataScopePanel`）/ 动态字典件（`DynamicDictPicker`）/ 角色分配件（`RoleAssignPanel`）——按《组件设计 · 权限配置》可交互原型与《原型设计 · 角色管理 03 角色表单页》改用组件库件（`el-tabs` / `el-tree` / `el-table` / `el-checkbox` / `el-switch` / `el-button` / `el-input` 等）重构模板并补 `<style scoped>`，对齐原型的左右分栏、面板卡片、页签与表格形态。
2. **图标选择器族两件**（`IconPicker` / `IconLibrary`）：按《组件设计 · 图标选择器》原型改用组件库件（触发框 / 弹层 / 搜索框 / 分类 / 网格）并补样式。
3. **代码表达式编辑器族六件**（`CodeEditor` / `CodeMirrorHost` / `CodeViewer` / `CronEditor` / `ExpressionEditor` / `SqlEditor`）：按《组件设计 · 代码表达式编辑器》原型改用组件库件（工具栏 / 页签 / 只读高亮 / cron 模板）并补样式；**编辑内核（CodeMirror）只补宿主壳样式，不主题化内核**。
4. **对外契约保持**：只改模板结构与样式，不改各件 Props / 事件 / 插槽 / 暴露方法；`data-test` 钩子保留或按新结构等价迁移。
5. **令牌消费**：样式只消费 `--bms-*` 令牌，不得硬编码色值；令牌不足处按「新增先登记后使用」补语义令牌（权限配置族预计需「未挂接」标记底与「来源只读」标记底）。
6. **既有用例更新**：同步更新 `ui_ep/tests/interaction-permission.spec.ts`、`interaction-placeholder.spec.ts`、`interaction-icon-code.spec.ts` 及宿主 `apps/desktop/tests/role-permission-config.spec.ts` 中受模板变更影响的 DOM 断言。
7. **全库样式护栏**：新增件族样式护栏用例（与 `layout-style.spec.ts` 同口径），硬断言全库真裸骨架件含非空 `<style scoped>` 且无硬编码色值；EP 薄包装以显式豁免清单列名并附理由。
8. **原型对照**：以开发态核对页（`permission-config-check.html` 等）做无头真机截图，逐项对照组件设计原型（结构 / 样式 / 交互 / 去实现命名 / 主题与响应式），结论登记测试记录。

## 3. 完成标准 <a id="accept"></a>

交互类 17 件逐件补齐 `<style scoped>` 且模板经组件库件承载，与《组件设计》对应节点原型逐项对照一致（真机截图 + 对照表登记测试记录）；对外契约无破坏；全库件族样式护栏用例就位（硬断言 + EP 薄包装豁免清单）；`ui-ep` 与宿主 `vue-tsc` / ESLint / Vitest 全通过、覆盖率达标、`check_preflight.py` 全绿。

> **完成标准口径说明（2026-10-14 用户拍板）**：上段「Vitest 全通过」与需求 11-1 §2.5 / 父任务 §3 的「**件族样式护栏落地后门禁持续红，直至全库真裸骨架件补齐**」存在冲突——本批只补 17 件，全库真裸骨架硬断言下其余 **49 件**未补，护栏用例必红。经拍板：**保持护栏全库硬断言、不留批次豁免，接受门禁红**，本批验收以「定向用例 + 覆盖率（100%）+ 原型对照」为准；该冲突登记为**已知偏差**（见[实施记录 §7](实施/01_实施_01_交互类件族样式补齐.md#deviations) 与[测试记录 §5 / §7](测试/01_测试记录_01_交互类件族样式补齐.md#proto)）。**按用户口径，全库补齐前不推送。**
