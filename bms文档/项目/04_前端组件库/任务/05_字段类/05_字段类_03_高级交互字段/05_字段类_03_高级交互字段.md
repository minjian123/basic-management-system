## 2. 任务内容 <a id="content"></a>

1. 文件上传、富文本与 Markdown、穿梭框、验证码、标签输入；上传细节统一经 `useUploadEngine` 片段（与富文本、头像、导入共用；占位先行）。
2. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
3. **占位先行**：本期先交付**占位版**（空态 / 禁用态 / 降级语义，对齐后端 Null 占位模式）+ **占位契约测试**，并登记《[前端基类清单](../../../../../前端基类清单.md)》与《组件设计》；**真实实现**随 阶段六 ~ 八 回补（回补时补设计、实施与记录）。
4. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
5. 详细设计随任务启动时补建（占位版先行；真实实现回补时另行设计）。
