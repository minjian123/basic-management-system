## 2. 任务内容 <a id="content"></a>

1. 多标签导航、树形主从、栅格、间距/分割线、分栏、内容页签、卡片、折叠面板八件；页签状态统一经 `useTabs` 片段（与表单框架双层 Tab 共用）。
2. 范围边界（2026-09-15 重排确认）：**标签栏本体（`TabsNav` / `FormFrameTabs`）归本任务**，02/01 布局壳只做插槽编排；页签关闭的脏数据确认复用 03/01 的 `useConfirm`；树形主从的树能力复用 01/04 `BaseTree`（`useTreeData` 片段），未选中 / 空树用 06/03 `EmptyState`。
2. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
3. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
4. 详细设计随任务启动时补建（按前序任务完成情况调整口径）。
