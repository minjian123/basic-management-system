## 2. 任务内容 <a id="content"></a>

1. `SideMenu` / `MenuNode`：动态菜单树渲染（多级、折叠、搜索过滤、徽标角标、选中高亮）、侧栏折叠态与窄屏抽屉联动；组合布局片段（`useLayout` / `useContainer`），令牌消费与主题适配。
2. 菜单树 → 路由的注册 / 卸载统一经 `useDynamicRoutes` 片段（前端不硬编码路由表）；菜单与动作权限过滤统一经 `useAccess` 片段（`v-perm` 复用 08/01 基础类）。
3. **占位先行**：后端菜单树下发接口未就绪时以本地占位菜单树驱动（对齐后端 Null 占位模式），组件契约（选中 / 折叠 / 搜索 / 徽标 / 路由与页签联动）按目标契约实现并纳入契约测试；真实菜单树下发接入随**阶段七~八**（菜单管理 / RBAC）就绪后按同一契约回补，回补时补设计、实施与记录，工时按实施记录回写。
4. 组件 / 基类 / 片段与实现以《组件设计》对应节点及可交互原型为契约依据（原型即验收基准）。
5. 新增实现自动纳入契约套件与（前端）注册表机制；用例入 Kiwi TCMS（自动化标注用例编号）。
6. 详细设计随任务启动时补建（占位版先行；真实菜单接入回补时另行设计）。

## 3. 完成标准 <a id="accept"></a>

组件可用且与原型一致：菜单树渲染、折叠、搜索、徽标、选中高亮与路由 / 页签联动生效；`useDynamicRoutes` 与 `useAccess` 片段接线正确；Vitest 覆盖菜单树渲染与过滤分支；`vue-tsc` / ESLint / Vitest 全通过；文档与清单登记同步。
