## 2. 任务内容 <a id="content"></a>

1. **通知与消息**：顶栏铃铛与未读角标、下拉最近通知、通知中心列表 / 详情（查看即已读）、单条 / 批量 / 全部已读、单条删除。
2. **实时通道**：采用 Socket.IO（随后续集成消息落地），含断线重连与补偿拉取；未就绪期间以轮询占位。
3. 消息类型与已读状态展示复用 `07_05` 语义色能力（`StatusTag` + `domain/status.ts`）；消息内出现的用户信息复用用户展示能力基类 `BaseUserDisplay`（`07_02`），不依赖后续条目。
4. 派生通知组件基类 `BaseNotification`（经通知能力基类 `BaseNotice` 派生）。
5. 以 `07_01` 冻结的对外契约替换数据通路，不改组件对外形状。

## 3. 完成标准 <a id="accept"></a>

铃铛与列表详情可用、已读操作生效、实时与断线补偿正确、角标与实际未读一致；Vitest 覆盖补偿与角标分支；`vue-tsc`、ESLint、Vitest 全通过。
