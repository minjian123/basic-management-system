## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段四需求域 07 的 7 条需求——[07-1 占位版交付](../../需求/07_需求_展示类.md#r07-1)、[07-2 轻量展示件](../../需求/07_需求_展示类.md#r07-2)、[07-3 文件预览与审计差异查看](../../需求/07_需求_展示类.md#r07-3)、[07-4 通知与消息](../../需求/07_需求_展示类.md#r07-4)、[07-5 数据呈现](../../需求/07_需求_展示类.md#r07-5)、[07-6 图表卡](../../需求/07_需求_展示类.md#r07-6)、[07-7 全局搜索](../../需求/07_需求_展示类.md#r07-7)，按「1 需求 = 1 子任务」拆 7 个子任务（编号顺序即执行顺序）。
- **端范围**：**仅 PC**（`frontend/packages/ui-ep`，Element Plus）；移动端 `ui-vant` 本阶段范围外。
- **占位口径**：依赖后端的展示件（通用表格 / 通知 / 文件预览 / 审计差异 / 图表卡 / 全局搜索）由 `07_01` 先交付**占位版**（骨架 + 空态 / 降级语义 + 占位契约测试，空态复用 `03_02`），**契约先行冻结**；`07_03` ~ `07_07` 落地真实实现时**只换数据通路、不改对外契约**（变更走版本升级）。
- **归属说明**：该类的「异常与空状态」按执行顺序前移至需求域 03（`03-2`），本域只承接其余 13 节点。
- **公共前置**：展示组件基类 `BaseDisplay`（父 `BaseValue`）、能力基类 `BaseDataState` / `BaseNotice` / `BasePersistedState` / `BaseUserDisplay` / `BaseWatermark` / `BasePresignedUrl` 与值格式化横切（`02_03` / `02_06`，均已交付）在域 02 就位；`07_05` 演练组件基类 `BaseTable` / `BaseColumnConfig` / `BaseQueryScheme`，`07_06` 演练新增组件基类 `BaseChart`（父 `BaseDataState`，占位规则与登记见《[前端基类清单](../../../../前端基类清单.md)》§9）。
- **依据**：[展示类需求](../../需求/07_需求_展示类.md)、《[组件设计 · 总览](../../../../设计/组件设计/01_组件设计_总览.md)》与展示类 14 节点、《[前端基类清单](../../../../前端基类清单.md)》、《[架构设计 · 前端组件体系](../../../../设计/架构设计/05_架构设计_前端组件体系.md)》「八类组件与边界」「取数与缓存协作」节、《[前端开发规范](../../../../规范/前端开发规范.md)》「前端基类体系（强制）」节。
- **执行序**：`07_01 占位版交付` → `07_02 轻量展示件` → `07_03 文件预览与审计差异查看` / `07_04 通知与消息` / `07_05 数据呈现` / `07_06 图表卡` / `07_07 全局搜索`（依赖就绪后推进，见[计划](../../计划/01_计划_前端组件库.md)）。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：112h（子任务 01 12h、02 16h、03 14h、04 14h、05 30h、06 14h、07 12h）；周期口径见[计划](../../计划/01_计划_前端组件库.md)。
- **关键依赖**：`07_01` 依赖 `02_03`（数据状态 / 通知 / 用户展示 / 预签名 / 持久化能力基类）与 `03_02`（异常与空状态，占位空态复用）、`02_06`（格式化）；`07_02` 依赖 `02_03`（`BaseDisplay` / `BaseUserDisplay` / `BaseWatermark`）与 `07_01`（同域公共占位口径）；`07_03` ~ `07_07` 均依赖 `07_01`（对外契约冻结），真实数据通路分别依赖对应阶段后端能力。
- **依赖关系**：`07_01` / `07_02` 无后端强依赖；`07_03` ← 通用能力 · 文件存储 / 审计；`07_04` ← 数据 + 实时推送；`07_05` ← 数据呈现后端能力；`07_06` ← 报表 BI；`07_07` ← 全文检索（依赖与推进见[计划](../../计划/01_计划_前端组件库.md)，本节不写排期）。
- **风险**：占位契约在真实实现时被改动会连带页面（须契约先行冻结）；通用表格列配置 / 查询方案持久化与偏好表契约强耦合；图表卡 ECharts 与地图分包预算、深色主题令牌映射；通知实时推送（Socket.IO）与断线补偿、角标一致性；文件预签名 URL 失效重取；全局搜索权限 / 租户过滤越权风险与 ES 降级兜底。
