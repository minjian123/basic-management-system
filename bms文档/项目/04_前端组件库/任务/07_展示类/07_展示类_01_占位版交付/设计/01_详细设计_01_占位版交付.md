## 1. 设计目标与范围 <a id="goal"></a>

依赖后端的六类展示件（通用表格 / 通知列表 / 文件预览 / 审计差异查看 / 图表卡 / 全局搜索）先交付**占位版**：**契约先行冻结**（Props / 事件 / 插槽），占位态不发请求、呈现空态 / 降级提示；`07_03` ~ `07_07` 真实实现**只换数据通路、不改对外契约**（变更走版本升级）。

不在本期：真实数据通路（列表取数 / 通知实时与补偿 / 预签名 URL / 审计取数 / 图表数据集 / 检索接口）、字段壳与页面组装。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `useDisplayPlaceholder` <a id="placeholder"></a>

```ts
useDisplayPlaceholder(options?: { ready?: boolean }): {
  ready: Ref<boolean>
  degraded: Ref<boolean>        // !ready
  requestCount: Ref<number>     // 占位态必须保持 0
  setReady(value): void
  markLoaded(): void            // 仅就绪后计数
  value / setValue              // 只读值语义（经 useBaseDisplay）
}
```

### 3.2 六件组件契约（冻结） <a id="components"></a>

| 件 | 数据面 | 事件 | 插槽 |
| --- | --- | --- | --- |
| `DataTable` | `columns`（`DataTableColumn[]`）/ `data`（行数组）/ `loading` / `total` / `page` / `pageSize` / `rowKey` | `update:page` / `update:pageSize` / `sort-change` / `selection-change` / `row-click` | `degrade` / `toolbar` / `empty` / `live` |
| `NoticeList` | `items`（`NoticeItem[]`）/ `loading` / `unreadCount` / `compact` | `open` / `read` / `read-all` / `remove` | `degrade` / `empty` / `live` |
| `FilePreview` | `files`（`PreviewFile[]`）/ `index` / `visible` | `update:index` / `update:visible` / `change` / `close` / `error` / `download` | `degrade` / `empty` / `live` |
| `AuditDiff` | `records`（`AuditRecord[]`）/ `loading` / `page` / `total` | `query` / `select` / `verify` / `update:page` | `degrade` / `empty` / `live` |
| `ChartCard` | `title` / `chartType` / `option` / `loading` / `height` | `refresh` / `chart-click` / `download` | `degrade` / `empty` / `actions` / `live` |
| `GlobalSearch` | `modelValue`（关键词）/ `domains` / `groups` / `loading` / `engineDegraded` | `update:modelValue` / `search` / `open` / `retry` | `degrade` / `empty` / `live` |

- 通用：`modelValue` 类值面 / `ready` / `degradeText`；全部输出 `data-ready` / `data-degraded`。
- **占位态**：`ready !== true` → `degraded=true`、不发请求；`degrade` 插槽可替换降级内容（缺省降级文案）。
- **就绪态**：渲染内置轻量结构（或 `live` 插槽），事件按契约透传；真实实现只接入数据通路。
- 组件名与对外契约**冻结**：`07_03` ~ `07_07` 复用同名件补数据通路。

### 3.3 契约套件 <a id="suite"></a>

`describePlaceholderDisplayContract(name, create)`（`@bms/core/testing`）断言：未就绪 → 降级、`requestCount === 0`（含调用 `load()` 仍为 0）；`setReady(true)` → 不再降级。真实实现继续跑同一套件。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 未就绪时用户交互 | 只读、不发请求 |
| 未就绪时调用 `markLoaded()` | 不计数（防占位期误计） |
| 自定义降级内容 | `degrade` 插槽替换，默认文案可配 |
| 空数据（就绪态） | 渲染 `empty` 插槽 / 缺省空态（复用 `03_02` 口径） |
| `charts` / `groups` 等未传 | 视为空集合（真实实现前不报错） |
| 就绪态切换 | 就近生效（本地值不丢） |
