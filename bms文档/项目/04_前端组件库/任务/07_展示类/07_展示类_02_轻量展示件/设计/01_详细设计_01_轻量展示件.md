## 1. 设计目标与范围 <a id="goal"></a>

交付四项跨页面高频、无后端强依赖的只读展示件——**快捷入口 / 头像与用户信息 / 二维码 / 水印**；均派生展示组件基类 `BaseDisplay`（经值能力基类 `BaseValue` 派生），用户展示经 `BaseUserDisplay`、水印经 `BaseWatermark`，权限过滤消费 `BaseAccess`，不重复实现横切能力。

不在本期：扫码登录轮询与换取会话（随认证阶段）、域 08 图标选择器统一 icon key 解析（本期按 `el:` 前缀内置 EP 图标 + 降级）、移动端实现。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 投影 <a id="projections"></a>

```ts
useBaseUserDisplay(initial?): { user, name, avatar, status, deptPath, setUser }
useBaseWatermark(initial?): { text, enabled, setUser, setTenant, setEnabled }
```

### 3.2 四件组件契约（冻结） <a id="components"></a>

| 件 | Props | Events | Slots |
| --- | --- | --- | --- |
| `QuickEntry` | `entries`（`QuickEntryItem[]`）/ `columns`（3 / 4 / `auto`）/ `iconSize` / `showLabel` / `filterByPerm` / `permissions` / `editable` | `open` / `navigate` / `remove` / `reorder` | `icon` / `empty` |
| `UserAvatar` | `user` / `src` / `name` / `size`（xs/sm/md/lg）/ `shape` / `status` / `badge` / `group` / `max` | `error` | `default` |
| `UserInfo` | `user` / `userId` / `size` / `showDept` / `linkTo` / `popover` / `text` / `deleted` | `open` | `popover` |
| `QrCode` | `value` / `size` / `level` / `fgColor` / `bgColor` / `logo` / `downloadable` / `copyable` / `status` / `expiresIn` | `refresh` / `download` / `copy` / `status-change` | `expired` |
| `WatermarkOverlay` | `content` / `image` / `opacity` / `rotate` / `gap` / `offset` / `zIndex` / `fullscreen` / `showTime` / `enabled` | `ready` / `change` | `default` |

- `QuickEntryItem`：`{ key, label, icon?, route?, badge?, group?, order?, perm? }`；`filterByPerm` 时按 `perm` 过滤（无 `perm` 视为公开）；按 `order` 排序、`key` 去重；`el:` 前缀 icon 懒加载 `@element-plus/icons-vue` 解析，未知前缀降级问号。
- `UserAvatar` 回退链：图片 → 首字母 → 默认图标；默认色按姓名 hash 稳定派生（`hsl()` 计算，不硬编码）；`group` 超出 `max` 显示 `+N`。
- `UserInfo`：`user` 为空显示 `—`、`deleted` 显示「已删除用户」（保留 id 占位不报错）；`popover` 悬停卡片（数据来自用户展示投影缓存）。
- `QrCode`：`import('qrcode')` 独立分包懒加载；含 logo 建议 `H` 容错；`expiresIn > 0` 倒计时置过期并遮罩 + 刷新；`pollable` 契约预留（轮询本期不启动）。
- `WatermarkOverlay`：平铺层（重复水印），`MutationObserver` 监听被移除/改样后自动恢复；时间戳分钟级刷新；层不可选中、不拦截指针。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 头像图片加载失败 | 回退首字母，不暴露破图 |
| 无可见入口（权限过滤后为空） | 渲染 `empty` 插槽 / 缺省空态 |
| 入口路由未注册 | 不渲染并告警（防白屏） |
| 二维码内容为空 | 不生成并提示 |
| 二维码生成库加载失败 | 错误提示 + 重试（不阻塞页面） |
| 水印层被移除 / 改样式 | `MutationObserver` 自动恢复 |
| 容器尺寸变化 | 快捷入口列数 / 水印间距重算 |
| 用户已删除 | 展示「已删除用户」，不报错 |
