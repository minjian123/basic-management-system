## 2. 任务内容 <a id="content"></a>

1. **快捷入口**：工作台快捷入口（图标 + 文案 + 跳转，权限过滤、分组、角标、响应式列数与空态）。
2. **头像与用户信息**：头像（回退链 / 稳定默认色 / 尺寸）与用户信息胶囊、悬浮卡片；用户 / 组织展示统一经用户展示能力基类 `BaseUserDisplay`（姓名 / 头像 / 状态 / 部门路径，与组织选择回显、审批流、通知共用），批量按 ID 回显与缓存。
3. **二维码**：内容与容错级别、尺寸 / 配色 / 居中 logo、下载与复制、过期遮罩与刷新（扫码登录状态机为可选）。
4. **水印**：文字 / 图片水印、旋转与间距、透明度、全屏与局部覆盖（含导出物），统一经水印能力基类 `BaseWatermark`；防篡改与敏感页应用。
5. 四项展示件均派生展示组件基类 `BaseDisplay`（经值能力基类 `BaseValue` 派生），空值 / 用户数据未就绪走空态占位。

## 3. 完成标准 <a id="accept"></a>

四项展示件可用；用户展示口径与其它域一致；水印可覆盖指定容器；Vitest 覆盖渲染与降级分支（用户数据未就绪时占位）；`vue-tsc`、ESLint、Vitest 全通过。
