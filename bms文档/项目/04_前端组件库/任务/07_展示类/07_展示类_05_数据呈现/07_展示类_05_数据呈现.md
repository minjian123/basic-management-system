## 2. 任务内容 <a id="content"></a>

1. **通用表格**：声明式列配置与渲染优先级、分页与多列排序、多选 / 展开、树形与行内编辑；显隐 / 顺序 / 宽度统一经列配置组件基类 `BaseColumnConfig`（经偏好持久化能力基类 `BasePersistedState` 派生），表格派生表格组件基类 `BaseTable`（经数据状态能力基类 `BaseDataState` 派生）；工具栏与空 / 加载 / 错误态。
2. **查询筛选区**：条件模型、折叠与窄屏口径、高级查询入口与条件摘要、查询方案（应用 / 另存 / 设默认）与条件持久化，统一经查询方案组件基类 `BaseQueryScheme`（父 `BasePersistedState`）。
3. **状态标签与描述列表**：语义色三层取色、标签形态、描述列表响应式列数与复杂值只读回显、空值占位；标签派生展示组件基类 `BaseDisplay`。
4. **指标卡**：数值与单位、环比同比与趋势状态色、口径说明、迷你趋势图、数字滚动、加载 / 空态与跳转。
5. 以 `07_01` 冻结的对外契约替换数据通路，分页与排序与后端契约一致。

## 3. 完成标准 <a id="accept"></a>

列表页可由「通用表格 + 查询筛选区」直接组装；列个性化与查询方案持久化生效；分页与排序与后端契约一致；Vitest 覆盖列配置与条件模型；`vue-tsc`、ESLint、Vitest 全通过。
