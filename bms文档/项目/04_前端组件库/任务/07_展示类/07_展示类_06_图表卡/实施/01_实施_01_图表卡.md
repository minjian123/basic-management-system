## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先行**：经容器内 Django shell 登记用例，取得编号 **775**（平台既有编号至 774）；三个用例文件首行标注 `// kiwi_id: 775`。
2. **依赖引入**：`ui-ep` 新增 `echarts@^6.1.0`（npmmirror 源，实测安装 6.1.0）；**不进核心**（核心保持框架与第三方无关）。
3. **核心领域**（`core/src/domain/chart.ts`）：
   - 常量：权限码 `CHART_VIEW_PERM`、占位 / 空态文案、配置版本、节流间隔、短缓存 TTL、8 个序列色令牌与 5 个辅助令牌（含兜底色）；
   - 类型面：`ChartKind`（13 类）/ `ChartKindOption` / `ChartRenderMode` / `ChartThemeMode` / `ChartView` / `ChartField` / `ChartDatasetResult` / `ChartMapping` / `ChartStyleOptions` / `ChartConfig` / `ChartTheme` / `ChartTokenReader`；
   - 纯函数：类型归一 / 映射归一（剔字段清单外脏引用、缺省回落、去重）/ 配置归一（缺省确定值、色板序号夹取）/ 令牌主题生成 / 模式解析 / 空判定（无结果 · 空行 · 全非数值；`table` 特判）/ 选项生成（13 类分支，多度量与系列分组、色板循环、覆盖深合并，**不 import echarts**）/ 合并策略与全量替换判定 / 尺寸节流 / 稳定脏比对。
4. **组件基类**（`core/src/capabilities/chart.ts`）：键 `chart`，父 `BaseDataState`，依赖 `data-state`；`ChartEngineAdapter` 注入式引擎接口（`init` / `update` / `applyTheme` / `resize` / `exportImage` / `on` / `offAll` / `dispose`）；占位零请求、就绪门控、四态结算、空数据不初始化、主题令牌重建、尺寸节流、导出、`onDispose` 销毁引擎；另增 `rawOption` / `setRawOption` 支持完整选项直给（见第 4 节第 2 项）。
5. **契约套件**（`core/testing/chart.ts`）：`describeChartContract`（10 条：占位零请求、就绪不降级、空数据不初始化、就绪注引擎后初始化与写入、类型变化全量替换、主题重建且保留色板、尺寸节流、导出与销毁、就绪未注入零请求 / 注入后取数、视图切换）+ `createChartEngineStub` 引擎桩；核心用例 `domain-chart.spec.ts`（17 条）与 `chart.spec.ts`（10 条，含契约驱动）。
6. **登记**：`CAPABILITY_MANIFEST` 新增 `chart: ['data-state']`；核心导出面新增能力基类与全部领域导出；《前端基类清单》§2.1 插入行（**编号 68**，父 `BaseDataState`、「已交付」，其后 68~77 顺延为 69~78）+ §2 继承链总览 mermaid 增「组件基类 BaseChart（图表族）」+ §5.3 组件基类表增行 + §9「PC 插件」补 `components/chart/` / `useBaseChart` / `utils/echartsKernel.ts` + §10 迁移映射「图表域」行改「已按组件基类 `BaseChart` 落地（`07_06` 已交付）」。
7. **投影**（`ui-ep/src/composables/useBaseChart.ts`）：薄适配（`markRaw(toRaw(x))` 隔离引擎；`onScopeDispose` 解除订阅并 `dispose`）；含 `setRawOption`。
8. **内核适配**（`ui-ep/src/utils/echartsKernel.ts`）：**动态 `import('echarts/core')`** 单例装载，按需 `use([...])` 注册 8 类图表 / 8 个组件 / 双渲染器 / 2 个特性；`registerTheme`（令牌主题）/ `registerMap`；`ResizeObserver` 监听容器（经核心 `shouldResize` 节流）；导出 / 事件 / 销毁；`loadChartMap` 动态 `import('../assets/maps/china')`（自原型 geoJSON 提取为 ESM，**地图数据不进首屏**）。
9. **图表族两件**（`ui-ep/src/components/chart/`）：
   - `ChartRenderer`（新增）：纯渲染、不取数；`ready` / `option`（直给优先）/ `chartType` / `data` / `config` / `themeMode` / `renderMode` / `height` / `lazy`（IntersectionObserver 视口懒渲染，能力缺失降级立即装载）/ `loading` / 四态；容器挂载后动态装载内核并 `setEngine`，卸载释放；`data-subpackage="chart-kernel"`；`scoped` 样式使画布撑满容器；
   - `ChartCard`（迁入 + 真实实现）：卡头（标题 / 视图切换 / 刷新 / 详情 / 编辑态移除 / 导出）+ 内容区（图表 / 数据表）+ 脚注（数据集标注与最后更新）+ 轮询（页面可见性约束）；**对外契约保持 `07_01` 冻结形状**，仅向后兼容新增可选 Props / 事件 / 插槽；无渲染输入时保持卡壳占位（不装载内核）；数据表视图复用 `07_01` 占位 `DataTable`（`ready=true`）；
   - 旧路径 `components/display/ChartCard.vue` 删除。
10. **导出面与令牌**：`ui-ep/src/index.ts` 改 `ChartCard` 来源并新增 `ChartRenderer`、`useBaseChart`；`apps/desktop/src/styles/tokens.scss` 新增 `--bms-chart-color-1..8` 与 5 个辅助令牌（亮 / 暗两套，只增不改）。
11. **首屏体积预算改造**：`vite.config.ts` `manualChunks` 为 `echarts` / `zrender` 命名独立 vendor 块（动态导入成异步块）；`check-bundle-budget.mjs` 改为解析 `index.html` 静态引用得出**入口块集合**、只计入口块首屏预算，异步块仅打印观察值；`budget.json` 备注更新。
12. **用例**：核心 44 条 + `ui-ep/tests/display-chart.spec.ts` 12 条（投影 + 两件 + 四态 + 分包边界）；既有 `ui-ep/tests/display-placeholder.spec.ts`（`07_01` 冻结契约）**未改动即通过**。
13. **宿主核对页**：`apps/desktop/chart-check.html` + `src/dev/{chartCheck.ts,ChartCheck.vue}`（12 项自检：就绪卡头 / 容器类型 / ECharts 画布 / 类型切换 / 分包标记 / 视图切换 / 深浅主题 / 脚注 / 刷新 / 导出 / 详情与移除 / 未就绪降级），`vite build` 不包含；chromium headless `--dump-dom` 核验 **12/12**。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 核心 `BaseChart` 需支持「完整 `option` 直给」（基础图表件与报表 / 大屏自定义配置），原设计只定义了由配置 + 数据生成 | **先回写设计再实施**：详细设计 §3.2 增 `rawOption` / `setRawOption` 字段与「完整选项直给」行为行，§3.4 投影同步；核心与投影落地后再推进 |
| 2 | 图表卡新增常用样式 Prop 原名 `style` 与 Vue 保留属性同名（会被当作内联样式落根元素） | 改名 `chartStyle` 并回写详细设计 §3.7（避开 Vue 保留属性名） |
| 3 | `BaseChart` 的 `loading` / `error` getter 与 `BaseComponent.loading` 属性冲突（TS2611） | 改名 `isLoading` / `isError` / `isEmpty`，避免覆盖组件根属性 |
| 4 | 组件基类被 `guard-manifest.spec.ts` 拦截（`BaseChart` 未在《前端基类清单》登记为已交付） | 按流程先登记清单（§2.1 插入 + 顺延编号 + 继承链 / 组件基类表 / §9 / §10），再跑核心用例 |
| 5 | `ChartCard` 若把渲染件设为 `defineAsyncComponent`，`07_01` 冻结用例的同步断言（`[data-test="chart"]` 同步存在）会失败 | 采用「**静态件 + 动态库**」：两件静态可同步渲染，重量级 ECharts 经 `echartsKernel` 动态装载；回写详细设计 §3.8 |
| 6 | 开发态核对页首轮 8/12：标题未传（空）、`data-chart-type` 取 Prop 默认 `line`、ECharts 未初始化（画布容器高度 0，无 `<canvas>`） | 核对页补 `:title` 与 `:chart-type="config.chartType"`；`ChartRenderer` 增 `scoped` 样式使画布撑满容器；`effectiveKind` 配置优先；复跑 12/12 |
| 7 | `ChartCard` 的 `state-change` 在挂载前已结算，watcher 未捕获 | 状态 watcher 加 `{ immediate: true }` 上抛当前态 |
| 8 | ECharts 引入后若全量统计 dist，会挤占首屏体积预算 | 预算口径改为**入口块首屏预算**（动态异步块不计入），直接编码「首屏不加载」 |

## 6. 偏差与遗留 <a id="deviations"></a>

- **工时偏差**：名义 14h；因新增 1 个组件基类、1 份领域纯函数（37 个导出）、1 套契约套件、1 套投影、1 个 ECharts 内核适配工具、2 件组件（新增 1 + 迁移 1）与 12 项自检核对页、体积预算脚本改造，实际上浮，明细见第 4 节。
- **对外契约扩展**（向后兼容）：`ChartCard` 新增可选 Props（`datasetId` / `datasetName` / `datasetRemark` / `data` / `mapping` / `chartStyle` / `config` / `themeMode` / `renderMode` / `view` / `showViewSwitch` / `showRefresh` / `showDetail` / `pollInterval` / `editable` / `updatedAt` / `jobs` / `tokens` / `prefersDark`）、事件（`update:view` / `detail` / `remove` / `state-change` / `loaded` / `failed`）与插槽（`header-actions` / `empty` / `error` / `footer` / `params`）；既有 Props / 事件 / 插槽 / `data-test` / 分包入口**不变**（`ChartCard` 迁移至 `components/chart/`，导出名不变，旧路径删除）。
- **完整选项直给**：`BaseChart` 增 `rawOption` / `setRawOption`（优先于配置生成），供报表 / 大屏自定义配置复用。
- **数据表视图**：本期复用 `07_01` 占位 `DataTable`（`ready=true` 渲染只读表）；真实通用表格 `07_05` 交付后自然升级（消费方任务文档登记）。
- **真实数据集取数接口**：`POST /rpt/datasets/{id}/query` 未回写概要设计；取数经 `jobs.load` 注入，未注入即占位零请求；真实联调随报表 BI 窗口。
- **地图地理数据**：本期先落懒加载机制与 `china` 一份（自原型 geoJSON 提取为 ESM、独立分包），其余地区按需扩展；加载失败降级返回 `false`。
- **移动端**：本期仅 PC；同一契约套件 `describeChartContract` 就位供后续同契约多实现。
- **工作台页面集成**：布局卡槽与编辑面板归首页工作台任务；本任务只交付组件。
- **Kiwi 用例台账**：用例 775 已在平台登记（test 仓《Kiwi 用例台账》按该台账维护节奏补记）。
