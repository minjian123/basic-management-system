## 2. 任务内容 <a id="content"></a>

1. **文件预览**：图片 / PDF / 音视频 / 文本按内容类型分发渲染，缩放 / 旋转 / 翻页 / 多文件切换；预签名 URL 获取与失效自动重取、不支持类型降级下载；预签名经预签名能力基类 `BasePresignedUrl`。
2. **审计差异查看**：变更记录列表与时间范围（分片键）筛选；字段级旧值 → 新值差异与类型感知渲染、敏感字段脱敏；哈希链字段展示与校验结果、篡改记录定位。
3. 两件均以 `07_01` 冻结的对外契约替换数据通路，不改组件对外形状。

## 3. 完成标准 <a id="accept"></a>

预览各类型可正常渲染、URL 失效自动重取、降级下载可用；审计差异渲染与脱敏正确、篡改可定位；Vitest 覆盖关键渲染分支；`vue-tsc`、ESLint、Vitest 全通过。
