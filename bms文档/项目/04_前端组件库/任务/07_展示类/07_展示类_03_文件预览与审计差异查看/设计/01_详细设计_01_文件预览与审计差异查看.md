## 1. 设计目标与范围 <a id="goal"></a>

在 `07_01` 冻结的对外契约上，把**文件预览**与**审计差异查看**两件的占位数据通路替换为真实前端逻辑：文件按内容类型分发渲染 + 预签名 URL 获取 / 失效重取 / 降级下载（经 `BasePresignedUrl`）；审计变更记录渲染 + 字段级旧值 → 新值类型感知渲染 + 脱敏展示 + 链字段与校验结果。**不改对外契约**（仅新增可选属性）。

不在本期：真实后端接口联调（预签名 / 审计取数，随后续能力就绪后接通，登记为遗留）；Office 在线预览（降级下载）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 `useBasePresignedUrl` <a id="presigned"></a>

```ts
useBasePresignedUrl(): {
  presigned: BasePresignedUrl
  url: Ref<string | undefined>
  expiresAt: Ref<number>
  setFetcher(fetcher?): void
  get(): Promise<string | undefined>   // 有效复用 / 失效重取 / 未注入降级
  refresh(): void                       // 清除缓存（失效重取）
  isExpired(now?): boolean
}
```

### 3.2 组件契约（在 `07_01` 基础上仅新增可选属性） <a id="components"></a>

| 件 | 新增可选 Props | 行为 |
| --- | --- | --- |
| `FilePreview` | `presignedFetcher?: (file) => Promise<PresignedResult>`；`PreviewFile` 增 `url?` | 类型分发：图片（缩放 / 旋转）/ PDF（内嵌）/ 音视频（原生）/ 文本（拉取截断）/ 其他降级下载；加载失败**重取一次**，仍失败错误态 + 下载 |
| `AuditDiff` | `diff?: AuditFieldDiff[]`；`prevHash?` / `recordHash?` / `chainVerified?` | 选中记录渲染字段级 `旧值 → 新值`（类型感知）、脱敏原样展示、新增 / 修改 / 删除高亮；链字段缩写 + 校验结果 |

- `AuditFieldDiff`：`{ field, label?, oldValue?, newValue?, valueType? }`；`valueType` 缺省按值推断（`text` / `number` / `amount` / `date` / `boolean` / `json` / `richtext` / `dict`）。
- 预签名获取器由宿主注入（能力 `BasePresignedUrl.fetcher`），组件不硬编码接口；未注入时降级用 `file.url`。
- 数据取数编排保持在页面 / 宿主，组件只渲染与回传（对齐通用表格「不自行发请求」口径）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 预签名 URL 失效 / 加载错误 | 重取一次；仍失败错误态 + 降级下载入口 |
| 不支持类型（office / 压缩包） | 直接降级下载 + 提示 |
| 文本文件过大 | 截断前 N KB + 下载查看全文 |
| 未注入预签名获取器且无 `url` | 提示不可预览 + 下载 |
| 审计字段值为空 | 统一占位 `—` |
| 审计敏感字段 | 后端已脱敏，前端原样展示 `***`，不再还原 |
| 链校验异常 | 展示异常状态与篡改记录定位入口（`verify` 事件） |
