## 2. 任务内容 <a id="content"></a>

1. **A 继承链**：新增能力基类 `BasePlaceholderState` 并入链（`BaseValue` / `BaseDataState` / `BaseNotice` 及编排基类继承）；三占位组合式改薄投影；`useHighlight` 回链上；件内链上类改投影。
2. **B 单一落点**：新增浏览器能力 utils（全屏 / 可见性 / 观察器 / 媒体 / 键盘指针 / 令牌读取）；DOMPurify、TipTap、本地存储、下载归位。
3. **C 可替换实现**：三域插件基类 + 提供者注册表；内建 ECharts / SSE 继承插件基类；图表引擎经注册表解析。
4. **D 令牌消费**：移除颜色兜底、补齐令牌、原始色值归位。
5. **E 护栏与审计**：强化 / 新增机器护栏（含 fixture）；出首审报告并回写登记。

## 3. 完成标准 <a id="accept"></a>

四类违规全部修复；机器护栏全绿；`pnpm run check` 与宿主 `build` / `budget` 通过；首审报告与登记回写完成。
