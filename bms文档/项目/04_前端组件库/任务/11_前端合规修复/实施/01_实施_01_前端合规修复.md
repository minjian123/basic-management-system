## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    A["首审盘点（脚本 + 人工）"] --> B["A 继承链修复"]
    B --> C["B 单一落点修复"]
    C --> D["C 可替换实现插件化"]
    D --> E["D 色值令牌化"]
    E --> F["E 机器护栏（+ fixture）"]
    F --> G["首审报告 + 登记回写"]
    G --> H["门禁与分包复跑"]
```

- **A**：新增 `BasePlaceholderState`；`BaseValue` / `BaseDataState` / `BaseNotice` 继承之；13 个编排能力基类改父并删重复成员；三占位组合式、`useBaseTable`、`MetricCard`、`FormRenderer`、`FormDesigner` 改单链；`useHighlight` 回链上；`ContentTabs` / `PrintPreview` 改投影。
- **B**：新增 6 个浏览器能力 utils；`IconRenderer`→`sanitizeSvg`、`RichTextEditor`→`useRichTextEditor`、`IconPicker`/`ScrollContainer`→`useBasePersistedState`、`FilePreview`/`QrCode`→`triggerDownload`；约 15 件收敛全屏 / 可见性 / 观察器 / 视口 / 媒体 / 指针 / 令牌读取。
- **C**：新增三域插件基类 + 注册项 + 注册表；内建 ECharts / SSE 继承插件基类；`ChartRenderer` 经 `chartEngineRegistry` 解析。
- **D**：移除 240 处颜色兜底；补 9 个令牌；强调色预设与画布默认背景归核心域。
- **E**：强化 `guard-component-inheritance`；新增 `guard-single-source`、`guard-tokens`（ui-ep）与 `guard-tokens`（desktop），均含 fixture；出首审报告并回写基类 / 资产 / 计划 / 任务。

## 4. 偏差与遗留 <a id="deviations"></a>

- **兼容性**：`BaseNotification` 父基类此前已调整为 `BaseNotificationCenter`；本轮 `BaseNotice` 再上提 `BasePlaceholderState` 为兼容变更（新增字段）。`BaseValue` / `BaseDataState` 父基类由 `BaseComponent` 改为 `BasePlaceholderState`，连带 `capabilities-batch*` / 各编排 spec 的 `depends` 断言同步（已更新，行为不变）。
- **对外契约**：删除内部导出 `useHighlight`（改由 `utils/highlight`→回链上 `useHighlight` 投影，仍导出）；`useRichTextEditor` 不导出（避免 TipTap 进首屏，已由 budget 验证）。
- **护栏 fixture**：三类护栏均配 fixture 拦截用例（审计规范 §8）。
- **Kiwi 用例**：本次合规修复以护栏 fixture 覆盖，未新增平台自动化用例（沿用既有台账），登记为遗留待补。
- **机会项**：件内定时器与 `CodeEditor` 的 `document.querySelector` 暂不抽 utils（无共享需求）；清单对账护栏仍为候选。
