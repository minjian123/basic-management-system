## 1. 域说明 <a id="intro"></a>

本域对应阶段二「字段类」（WBS 05，组件设计 06 字段类 01-12），是带数据源、特殊交互或特殊格式的字段控件，在 04 基础控件之上扩展。**本域为依赖波**：多数字段依赖后端模块能力（字典、部门/用户、文件、验证码），随对应阶段就绪后回补，任务树登记在阶段二目录、计划表标回补窗口。

- **基础与数据源字段**：日期时间、数值与金额、开关与枚举、字典、树选择、级联选择。
- **组织选择字段**：用户/岗位/组织选择、部门树选择。
- **高级交互字段**：文件上传、富文本与 Markdown、穿梭框、验证码、标签输入。

**依据**：《组件设计》06 字段类节点、《前端开发规范》「前端基础类体系」节、《架构设计 · 前端组件体系》第 6/10 节。
**回补锚点**：字典 ← 阶段五 通用能力（字典）；部门/用户/岗位 ← 阶段四 RBAC；文件 ← 阶段五 通用能力（文件）；验证码 ← 阶段三 认证。

## 2. 需求 05-1：基础与数据源字段 <a id="r05-1"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：日期/金额/枚举/字典/树/级联是业务表单最高频字段；若各写各的时区格式化、精度校验、选项加载与缓存，会出现展示口径不一与重复请求。

**内容**（《组件设计》06 字段类 02/03/08/01/04/12）：

1. 日期时间字段：`DateField` / `DateRangeField` / `TimeField`——时区、格式化与只读回显契约。
2. 数值与金额字段：`NumberField` / `AmountField` / `PercentField`——精度、范围校验与金额格式化。
3. 开关与枚举字段：`SwitchField` / `InlineSwitch` / `EnumField` / `EnumCheckboxField`——三态开关、列表内联切换、自定义选项集枚举。
4. 字典字段：`DictSelect` / `DictCascader` / `getDictLabel` / `useDictStore`——字典数据经 store 复用缓存与版本比对（依赖阶段五字典模块）。
5. 树选择字段：`TreeSelectField` / `MenuTreeSelect`——树数据、懒加载与只读路径回显。
6. 级联选择：`CascaderField` / `useCascader`——多级联动、懒加载、任意级可选、多选、搜索、路径回显。

**完成标准**：六类字段可用并按 locale/时区正确展示；字典字段复用缓存不重复请求；校验规则生效；Vitest 覆盖格式化与校验契约。回补窗口：阶段五为主（字典依赖）、级联/树选择可随基础控件后独立完成。

**参考文档**：《组件设计》06 字段类 01-04/08/12 节点（含可交互原型）

## 3. 需求 05-2：组织选择字段 <a id="r05-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：用户/岗位/部门/组织选择字段依赖平台组织模型（部门树、用户列表、岗位），是权限与业务流程（审批人、数据归属）的高频字段，需与后端组织接口契约一致并支持远程搜索、多选与只读回显。

**内容**（《组件设计》06 字段类 04/05）：

1. `UserSelectField` / `PostSelectField` / `OrgSelectField`：远程搜索、多选、只读回显、已删除/停用对象占位。
2. `DeptTreeSelect`：部门树选择（与权限数据范围口径一致）。
3. 数据来源统一走组织相关 store 并复用缓存；批量按 id 回显走批量接口，避免 N+1。

**完成标准**：三类组织选择字段可用、远程搜索与多选正确、只读回显稳定；依赖阶段四 RBAC（部门/用户/岗位）就绪后回补。回补窗口：阶段四后 ~ 阶段五。

**参考文档**：《组件设计》06 字段类 04/05 节点（含可交互原型）、[11-权限计算引擎](../../../设计/架构设计/11_架构设计_子系统_权限计算引擎.md)

## 4. 需求 05-3：高级交互字段 <a id="r05-3"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：文件上传（分片/断点续传/预签名）、富文本（双向 XSS 清洗）、穿梭框、验证码、标签输入交互复杂且涉及安全与后端能力，必须统一实现并与后端契约对齐。

**内容**（《组件设计》06 字段类 06/07/09/10/11）：

1. 文件上传字段：`FileUploadField` / `ImageUploadField` / `FileListField` / `useFileUpload`——分片、秒传、断点续传、只读回显（依赖阶段五文件管理）。
2. 富文本字段：`RichTextField` / `MarkdownField` / `RichTextViewer` / `sanitizeHtml`——双模式、白名单双向清洗、只读渲染（前端 DOMPurify + 后端白名单）。
3. 穿梭框：`TransferField` / `useTransfer`——双列表穿梭、搜索、分组、分页/异步、上限。
4. 验证码：`Captcha` / `useCaptcha`——图形（失败阈值强制/刷新/一次性失效）、滑块、短信（脱敏/倒计时/限流，依赖阶段三认证）。
5. 标签输入：`TagInput` / `useTagInput`——建议与自由新建、去重、数量/长度上限、颜色映射、粘贴批量。

**完成标准**：五类字段可用；富文本 XSS 双向清洗验证通过；上传分片/断点续传与后端契约一致。回补窗口：验证码随阶段三、上传随阶段五、其余随阶段五后。

**参考文档**：《组件设计》06 字段类 06/07/09/10/11 节点（含可交互原型）、[27-性能与安全](../../../设计/架构设计/27_架构设计_性能与安全.md)
