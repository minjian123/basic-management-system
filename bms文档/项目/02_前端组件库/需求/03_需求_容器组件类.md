## 1. 域说明 <a id="intro"></a>

本域对应阶段二「容器组件类」（WBS 03，组件设计 04 容器组件类 01-09），沉淀承载内容的容器，均继承 02 基础组件类 L2-04/L2-05。

- **弹窗抽屉表单**：`FormDialog` / `FormDrawer` / `ConfirmDialog` / `useFormModal` / `useConfirm`。
- **通用容器**：`ScrollContainer`、`LazyContainer`、`FullscreenContainer`、`AutoHeight`、`VirtualList`、`LoadingContainer`、`SectionContainer`、`AspectRatio`。

**依据**：《项目规划说明》「前端页面清单与菜单机制」节、《布局设计》弹窗/列表页节点、《组件设计》04 容器组件类节点、《架构设计 · 前端组件体系》第 4/7 节。
**目标**：弹窗/抽屉表单与滚动、懒加载、虚拟列表等容器可直接复用，避免各页各写。

## 2. 需求 03-1：弹窗抽屉表单（FormDialog / FormDrawer / ConfirmDialog） <a id="r03-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：新增/编辑/详情普遍以弹窗或抽屉承载，若每页各写弹窗表单，尺寸阶梯、三态（新增/编辑/详情）、生命周期、脏数据拦截与二次确认会各不相同，交互一致性无从保证。

**内容**（《布局设计》弹窗节点、《组件设计》04 类 01）：

1. `FormDialog` / `FormDrawer`：三态契约（新增/编辑/详情）、尺寸阶梯、生命周期、脏数据拦截与提交前确认。
2. `ConfirmDialog` / `useConfirm`：通用二次确认对话框。
3. `useFormModal`：弹窗表单的组合式封装（打开/关闭/提交/重置/loading）。
4. 语义色、间距、遮罩行为对齐 Element Plus 与《布局设计》弹窗节点。

**完成标准**：三态弹窗表单可用、脏数据拦截生效、尺寸阶梯与《布局设计》一致；`useFormModal` 可被页面直接调用；Vitest 覆盖三态与拦截行为；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《布局设计》「弹窗」节点、《组件设计》04 容器组件类 01 节点（含可交互原型）

## 3. 需求 03-2：通用容器（滚动/懒加载/全屏/自适应/虚拟列表/遮罩/分区/宽高比） <a id="r03-2"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：滚动区、懒加载、全屏、高度自适应、大列表虚拟滚动、加载/空/错误四态、分区与宽高比占位是页面常见的容器级需求；各页各写会出现滚动条样式不一、加载闪烁、长列表卡顿、图片抖动等一致性与性能问题。

**内容**（《组件设计》04 类 02-09、《架构设计 · 前端组件体系》「分包与加载策略」节分包与加载）：

1. `ScrollContainer`：统一滚动区（自定义滚动条、位置保持、触底加载）。
2. `LazyContainer`：进入视口才渲染（占位防抖动，配合路由级分包与组件懒加载）。
3. `FullscreenContainer`：全屏展示（Esc 退出、失败降级）。
4. `AutoHeight`：高度占满父剩余空间（减头部/工具栏）。
5. `VirtualList`：大数据只渲染可视区 + 缓冲。
6. `LoadingContainer`：loading/空/错误四态（延迟显示防闪烁）。
7. `SectionContainer`：轻量分区（标题/工具区/内容/折叠，无卡片外观）。
8. `AspectRatio`：固定宽高比容器（占位防抖动）。

**完成标准**：八项容器可用且可组合；虚拟列表在大数据集下滚动流畅；懒加载容器与分包策略协作正确；Vitest 覆盖关键行为（触底、四态、可视区计算）；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《组件设计》04 容器组件类 02-09 节点（含可交互原型）、《架构设计 · 前端组件体系》「分包与加载策略」节
