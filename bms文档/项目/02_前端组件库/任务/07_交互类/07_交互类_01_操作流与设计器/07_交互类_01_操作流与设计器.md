## 2. 任务内容 <a id="content"></a>

1. 导入导出 `ImportDialog` / `ExportButton` / `useImport` / `useExport`：模板下载、文件校验与上传进度、幂等键、错误行报告与明细下载、脱敏导出、异步导出。
2. 审批流展示 `FlowProgress` / `ApprovalTimeline` / `ApprovalActionPanel` / `BpmnViewer` / `useApproval`：节点进度与高亮、时间线、同意/驳回/转办/撤回与评论、二次确认与幂等提交。
3. 流程建模器 `ProcessDesigner` / `BpmnCanvas` / `ElementPalette` / `NodePropertyPanel` / `useProcessDesigner`：bpmn-js Modeler、用户任务属性、条件分支、XML 导入导出、校验与版本发布。
4. 表单设计器 `FormDesigner` / `FieldPanel` / `DesignerCanvas` / `FieldPropertyPanel` / `ExtFieldDialog` / `useFormDesigner`：三区拖拽、分区列数与跨列、字段属性、租户自建字段、查询/明细区配置、三级层级与保存发布。
5. 表单渲染器 `FormRenderer` / `FormField` / `useFormRender`：布局元数据驱动渲染、字段类型分发、三态与权限叠加、校验与提交、明细区。
6. 权限配置 `PermissionConfig` / `PermTree` / `FieldPermMatrix` / `DataScopeConfig` / `SubjectBinding` / `usePermissionConfig`。
7. 图标选择器 `IconPicker` / `IconDisplay` / `IconLibrary` / `iconRegistry`；代码表达式编辑器 `CodeEditor` / `SqlEditor` / `ExpressionEditor` / `CronEditor` / `CodeViewer` / `useCodeEditor`。

## 3. 完成标准 <a id="accept"></a>

七类组件可用；导入导出幂等与错误报告正确；流程建模 XML 可导入导出并发布；表单设计器拖拽与保存发布可用；渲染器按元数据正确分发；重组件独立分包。
