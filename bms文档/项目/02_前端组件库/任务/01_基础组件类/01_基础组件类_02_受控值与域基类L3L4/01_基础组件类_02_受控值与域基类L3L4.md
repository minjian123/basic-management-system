## 2. 任务内容 <a id="content"></a>

1. L3 受控值基类 `BaseValue` + `useValueBase`：值归一、格式化调度、三态、`change` 上报。
2. L3 字段基类 `BaseField` + `useFieldMeta`：字段上下文、字段权限、校验触发、`fieldKey`；组合 `BaseFieldShell`（label/必填/帮助/错误/栅格跨度/只读回显）与 `BaseFieldPerm`（`visible`/`editable`/`required`/脱敏，`useFieldPerm`/`v-plain`）。
3. L4 `BaseInput`（输入域）与 `DisplayBase`（展示域）。
4. 字段控件统一继承链落地：`具体控件 → BaseInput(L4) → BaseField(L3) → BaseValue(L3) → BaseInputControl(L2) → BaseComponent(L1b) → BaseFrontend(L0)`。

## 3. 完成标准 <a id="accept"></a>

L3/L4 基类可被基础控件类与字段类继承；`v-plain`/`useFieldPerm` 契约（visible/editable/required/脱敏）可用；字段壳装配生效；只读态统一以 `disabled` 或纯文本回显；Vitest 覆盖受控值与字段权限契约；`vue-tsc`、ESLint、Vitest 全通过。
