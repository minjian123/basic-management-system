## 2. 任务内容 <a id="content"></a>

1. 请求封装：`src/api/http.ts` Axios 实例（token 注入、401 静默刷新、统一响应解析与错误提示）+ `useRequest`（loading/错误/重试/取消）+ `useListPage`（分页/筛选/排序/导出）。
2. 权限指令：`v-perm="'业务:动作'"` / `hasPerm` / `canAccess`——按钮/动作权限渲染契约；字段权限不在本域。
3. 格式化工具：`formatDateTime`（用户时区）、`formatAmount`（金额/千分位）、`validators`、`stableStringify`。
4. 与契约衔接：`ApiResponse<T>`/`PageResponse<T>` 与 openapi-typescript 生成的类型一致；错误码文案按 i18n key 映射。

## 3. 完成标准 <a id="accept"></a>

`useRequest`/`useListPage` 可用并被列表页复用；`v-perm` 与 `hasPerm` 显隐生效；格式化工具在时区/金额口径上与后端一致；Vitest 覆盖请求拦截与格式化分支；`vue-tsc`、ESLint、Vitest 全通过。
