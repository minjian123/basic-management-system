## 1. 域说明 <a id="intro"></a>

本域对应阶段三「布局组件类」（WBS 02，组件设计 03 布局组件类 01-11），沉淀页面/区域布局与结构，均继承 02 基础组件类 L2-07 布局组件基类；页面形态以《[布局设计](../../../设计/布局设计/01_布局设计_总览.html)》为准。

- **框架与容器**：主框架布局壳 `AppLayout`、表单框架壳 `FormFrame`、页面容器 `PageContainer`。
- **结构布局**：多标签导航 `TabsNav`/`FormFrameTabs`、树形主从布局 `MasterDetail`/`MasterTree`、栅格 `Grid`、间距/分割线 `Space`/`Divider`、分栏 `Split`、内容页签 `Tabs`、卡片 `Card`、折叠面板 `Collapse`。

**依据**：《项目规划说明》「前端页面清单与菜单机制」节、《布局设计》各节点、《组件设计》03 布局组件类节点、《架构设计 · 前端组件体系》「八类组件与边界」节。
**目标**：页面可由「主框架布局壳 + 页面容器 + 通用组件」直接组装，结构一致、可复用。

## 2. 需求 02-1：框架与容器（AppLayout / FormFrame / PageContainer） <a id="r02-1"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：主框架与表单框架是全站页面的外壳，列表/详情的四段式（工具栏 + 筛选 + 表格 + 分页）与表单页形态若不在壳组件统一，页面各写一套布局，交互与间距会发散，且动态菜单、标签页 keep-alive、页签状态无处承载。

**内容**（《布局设计》主框架/表单框架/列表页/表单页节点、《组件设计》03 类 01-03）：

1. `AppLayout` 主框架布局壳：侧栏（`SideMenu`，见 07 域）+ 顶栏（语言切换、待办/通知角标、用户信息）+ 内容区 + 标签页，配合动态菜单渲染与路由 keep-alive。
2. `FormFrame` 表单框架壳：列表固定 + 详情多开双层 Tab（`FormFrameTabs`），承载列表页与表单页的页签状态。
3. `PageContainer` 页面容器：标题/描述/面包屑/工具栏/内容/底部插槽。
4. 均继承 L2-07 布局组件基类，消费设计令牌（间距/断点/主题）；响应式按《布局设计》响应式适配节点处理（侧栏折叠/抽屉化）。

**完成标准**：以三件套可搭出列表页与表单页骨架；标签页切换与 keep-alive 生效；响应式断点行为与《布局设计》一致；Vitest 覆盖壳组件关键行为；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《布局设计》「主框架」「表单框架」「列表页」「表单页」「响应式适配」节点、《组件设计》03 布局组件类 01-03 节点（含可交互原型）

## 3. 需求 02-2：结构布局（导航/主从/栅格/间距/分栏/页签/卡片/折叠） <a id="r02-2"></a>

优先级：2（高）　|　状态：未开始　|　完成日期：—

**背景与动机**：页面内部结构（多标签、左树右表、栅格分栏、间距分割、页签、卡片、折叠）是高频重复元素，需要统一的结构组件以避免每页各写布局；其中树形主从与多标签导航承载较复杂交互（选中过滤、可调分割、窄屏抽屉、页签关闭），统一实现可显著降低页面开发成本。

**内容**（《布局设计》各形态节点、《组件设计》03 类 04-11）：

1. 多标签导航 `TabsNav`：页面级多标签（打开/关闭/右键菜单/固定）与表单框架双层 Tab（与 02-1 `FormFrameTabs` 协作）。
2. 树形主从布局 `MasterDetail` / `MasterTree`：左树右表 / 右详情、选中过滤、可调分割、折叠、窄屏抽屉与空态。
3. 栅格 `Grid`：24 栅格 + 响应式断点。
4. 间距/分割线 `Space` / `Divider`。
5. 分栏 `Split`：可拖拽左右/上下分栏。
6. 内容页签 `Tabs`（区别页面级多标签）、卡片 `Card`、折叠面板 `Collapse`（手风琴/多开）。
7. 均继承 L2-07 布局组件基类；视觉与交互对齐 Element Plus 与《布局设计》。

**完成标准**：八项结构组件可用且可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；树形主从的选中过滤与可调分割生效；Vitest 覆盖关键交互；`vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《布局设计》各形态节点、《组件设计》03 布局组件类 04-11 节点（含可交互原型）
