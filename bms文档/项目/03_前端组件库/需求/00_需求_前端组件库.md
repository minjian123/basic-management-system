## 2. 前端组件库目标与范围 <a id="goal"></a>

**M3 目标**（《总体项目规划》「里程碑」节 M3 行）：基础类体系（L0-L4）与地基波组件（布局 / 容器 / 基础控件 / 基础类）全部可用、组件单测通过、与可交互原型一致。周期口径 7 周（兼职；组件地基不完成则前端页面开发无法推进，故置于阶段一之后、前端页面之前）。

**范围内**（共 16 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 一 基础组件类 | 总基类 / 最基础组件基类 / 七形态基类 / 受控值与字段基类 / 域基类（L0-L4） |
| 二 布局组件类 | 主框架布局壳、表单框架壳、页面容器、多标签导航、树形主从、栅格、间距分割线、分栏、内容页签、卡片、折叠面板 |
| 三 容器组件类 | 弹窗抽屉表单、滚动、懒加载、全屏、自适应高度、虚拟列表、加载遮罩、分区、宽高比 |
| 四 基础控件类 | 文本框、文本域、密码框、数字框、下拉框、单选、复选、开关 |
| 五 字段类 | 基础与数据源字段、组织选择字段、高级交互字段（依赖后端能力，回补） |
| 六 展示类 | 数据呈现、图表与搜索、反馈与查看（依赖后端能力，回补） |
| 七 交互类 | 操作流与设计器、业务设计器与面板（依赖后端能力，回补） |
| 八 基础类 | 请求封装、权限指令、格式化工具 |

**范围外**：

- 移动端组件（`frontend-mobile/`，Vant 生态，不复用 PC 组件）。
- 前端页面（阶段十三）与产品仓库前端模块。
- 依赖后端能力的字段/展示/交互类组件的**排期**（本阶段仅登记任务树并标回补窗口）。

> 边界说明：L1a 数据/契约基类（`BaseEntity`/`BasePageQuery`/`BaseApi`/`createCrudStore`/`stableStringify`）已在**阶段一** `01-4-1 前端基础类` 落地，本阶段不重复建设；组件实现均须继承对应层基类，公共字段/方法只在基类维护。

## 4. M3 验收门禁 <a id="accept"></a>

门禁定义（《总体项目规划》「里程碑」节 M3 行）：**基础类体系（L0-L4）与地基波组件全部可用、组件单测通过、与可交互原型一致**。逐项核对：

| 验收点 | 核对方式 | 对应需求 | 结论 |
| --- | --- | --- | --- |
| 基础类体系可用 | L0-L4 基类按层落地于 `src/components/base/`，继承链与依赖方向符合《前端开发规范》「前端基础类体系」节 | 01-1、01-2 | 待阶段完成核对 |
| 地基波组件可用 | 布局 / 容器 / 基础控件 / 基础类组件可用，页面可由「布局壳 + 通用组件」组装 | 02-1、02-2、03-1、03-2、04-1、08-1 | 待阶段完成核对 |
| 组件单测通过 | Vitest + @vue/test-utils 覆盖基类契约与关键交互；覆盖率并入前端门禁（整体 ≥ 70%） | 01-1 ~ 04-1、08-1 | 待阶段完成核对 |
| 原型一致 | 组件交互与视觉与《组件设计》可交互原型一致（对齐 Element Plus 行为） | 全部门禁项 | 待阶段完成核对 |

**结论**：地基波 8 条需求（01-1 ~ 04-1、08-1）在阶段三内闭环；依赖波 8 条需求（05 ~ 07 域）按对应后端能力就绪后回补，其验收随对应阶段执行（回补窗口见计划文档）。
