## 1. 域说明 <a id="intro"></a>

本域对应阶段三「展示类」（WBS 06，组件设计 07 展示类 01-14），是只读呈现类组件，继承 02 基础组件类 L4-02 展示域基类。**本域为依赖波**：通用表格依赖列表接口与权限、通知消息依赖实时推送、文件预览依赖文件管理、全局搜索依赖检索、图表卡依赖报表，随对应阶段就绪后回补。

**依据**：《组件设计》07 展示类节点、《架构设计 · 前端组件体系》第 4/6/10 节。
**回补锚点**：表格/筛选 ← 阶段六~十三；通知消息 ← 阶段六 + 实时推送；文件预览 ← 阶段六；审计差异 ← 阶段六；全局搜索 ← 阶段十六；图表卡 ← 阶段十四。

## 2. 需求 06-1：数据呈现 <a id="r06-1"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：管理端以列表为主，通用表格（列配置、分页、多列排序、树形、行内编辑、列个性化持久化）与查询筛选区（条件模型、折叠、高级查询、方案保存）若不统一，每个列表页都要重复实现且交互不一致。

**内容**（《组件设计》07 展示类 01/02/03/10）：

1. 通用表格 `ProTable`：声明式列配置与渲染优先级、分页与多列排序、树形与行内编辑、列个性化持久化（`sys_user_preference`）。
2. 查询筛选区 `QueryFilter` / `QueryField`：条件模型、折叠窄屏口径、高级查询入口与条件摘要、查询方案（应用/另存/设默认）与条件持久化（`sys_query_scheme`）。
3. 状态标签与描述列表 `StatusTag` / `DescList` / `DescItem`：语义色三层取色、标签形态、描述列表响应式列数。
4. 指标卡 `StatCard` / `useStat`：数值与单位、环比同比与状态色、口径说明、迷你趋势图、数字滚动、加载/空态与跳转。

**完成标准**：列表页可由 `ProTable + QueryFilter` 直接组装；列个性化与查询方案持久化生效；Vitest 覆盖列配置与条件模型。回补窗口：阶段六（列表接口与偏好表）后，可随阶段十三页面逐步收口。

**参考文档**：《组件设计》07 展示类 01/02/03/10 节点（含可交互原型）

## 3. 需求 06-2：图表与搜索 <a id="r06-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：图表卡涉及 ECharts 分包与主题令牌，全局搜索依赖 ES 检索与命令面板交互；二者均需与后端能力（报表数据集、检索索引）对齐，属依赖回补。

**内容**（《组件设计》07 展示类 04/07）：

1. 图表卡 `EChart` / `ChartCard` / `useChart` / `chartTheme`：图表类型与地图、令牌色板与深色主题、工作台卡片形态与空/加载/错误/降级态、自适应与**按需分包**（见《架构设计 · 前端组件体系》「分包与加载策略」节）。
2. 全局搜索 `GlobalSearch` / `SearchPanel` / `SearchResults` / `SearchResultItem` / `useGlobalSearch`：顶栏入口与命令面板、多域分组结果与高亮、审计日志页签、降级提示。

**完成标准**：图表卡可挂数据集渲染且独立分包；全局搜索命中与高亮正确、权限与租户过滤生效、ES 不可用降级兜底。回补窗口：图表卡 ← 阶段十四；全局搜索 ← 阶段十六。

**参考文档**：《组件设计》07 展示类 04/07 节点（含可交互原型）、[19-报表BI](../../../设计/架构设计/19_架构设计_子系统_报表BI.md)、[21-全文检索](../../../设计/架构设计/21_架构设计_子系统_全文检索.md)

## 4. 需求 06-3：反馈与查看 <a id="r06-3"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：异常/空状态、通知消息、文件预览、审计差异、快捷入口、头像、二维码、水印是跨页面高频的只读展示元素，统一实现可保证反馈一致性与查看体验（预签名 URL 失效重取、差异渲染、脱敏等）。

**内容**（《组件设计》07 展示类 05/06/08/09/11/12/13/14）：

1. 异常与空状态 `ErrorPage` / `EmptyState` / `SkeletonBlock` / `LoadingMask` / `useFeedback`：403/404/500 错误页、空状态矩阵、骨架屏、内容遮罩 loading。
2. 通知与消息 `NotificationBell` / `NotificationList` / `MessageItem` / `NotificationDetail` / `useNotification`：顶栏铃铛与角标、列表/详情、单条/批量/全部已读、Socket.IO 实时与断线补偿。
3. 文件预览 `FilePreview` / `ImageViewer` / `PdfViewer` / `useFilePreview`：图片/PDF/音视频/文本分发、缩放旋转翻页、预签名 URL 失效重取与降级下载。
4. 审计差异查看 `AuditDiffViewer` / `DiffTable` / `FieldDiff` / `ChainVerifyPanel` / `useAuditDiff`：字段级旧值→新值差异、脱敏、链字段与校验结果、篡改定位。
5. 快捷入口 `QuickEntry`、头像与用户信息 `UserAvatar` / `UserPill`、二维码 `QrCode`、水印 `Watermark`。

**完成标准**：八项展示元素可用；通知实时与断线补偿生效；文件预览与审计差异渲染正确；Vitest 覆盖关键渲染分支。回补窗口：随阶段六（通知/文件/审计）起，至阶段十六逐步收口。

**参考文档**：《组件设计》07 展示类 05/06/08/09/11/12/13/14 节点（含可交互原型）
