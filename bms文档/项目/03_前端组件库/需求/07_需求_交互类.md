## 1. 域说明 <a id="intro"></a>

本域对应阶段三「交互类」（WBS 07，组件设计 08 交互类 01-19），承载操作流的容器、设计器与专用面板，组合容器 + 展示 + 字段。**本域为依赖波**：导入导出/表单设计器依赖阶段六、审批流/流程建模器依赖阶段七、报表与大屏设计器依赖阶段十四、AI 助手依赖阶段十七，随对应阶段就绪后回补。

**依据**：《组件设计》08 交互类节点、《架构设计 · 前端组件体系》「渲染器注册机制」节（渲染器注册）。
**回补锚点**：导入导出/表单设计器/表单渲染器/权限配置/i18n 编辑器 ← 阶段六（表单定制/国际化）、权限配置 ← 阶段五；审批流/流程建模器 ← 阶段七；报表/大屏设计器 ← 阶段十四；AI 助手 ← 阶段十七。

## 2. 需求 07-1：操作流与设计器 <a id="r07-1"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：导入导出、审批流展示、流程建模、表单设计与渲染、权限配置、图标与代码编辑是平台核心操作流，涉及幂等提交、BPMN/拖拽/CodeMirror 等重交互与独立分包，需统一实现并对齐后端契约。

**内容**（《组件设计》08 交互类 01-07）：

1. 导入导出 `ImportDialog` / `ExportButton` / `useImport` / `useExport`：模板下载、文件校验与上传进度、幂等键、错误行报告与明细下载、当前筛选导出与脱敏、大数据量异步导出。
2. 审批流展示 `FlowProgress` / `ApprovalTimeline` / `ApprovalActionPanel` / `BpmnViewer` / `useApproval`：节点进度与当前节点高亮、审批时间线、同意/驳回/转办/撤回与评论、二次确认与幂等提交、可选只读 BPMN 图。
3. 流程建模器 `ProcessDesigner` / `BpmnCanvas` / `ElementPalette` / `NodePropertyPanel` / `useProcessDesigner`：bpmn-js Modeler 画布、元素调板、用户任务属性（审批人/会签条件）、条件分支、XML 导入导出、校验与版本发布。
4. 表单设计器 `FormDesigner` / `FieldPanel` / `DesignerCanvas` / `FieldPropertyPanel` / `ExtFieldDialog` / `useFormDesigner`：三区拖拽（vuedraggable）、分区列数与跨列、字段属性、租户自建字段、查询/明细区配置、三级层级与保存发布。
5. 表单渲染器 `FormRenderer` / `FormField` / `useFormRender`：布局元数据驱动渲染、字段类型分发、三态与权限叠加、校验与提交、明细区（渲染器注册见《架构设计 · 前端组件体系》「渲染器注册机制」节）。
6. 权限配置 `PermissionConfig` / `PermTree` / `FieldPermMatrix` / `DataScopeConfig` / `SubjectBinding` / `usePermissionConfig`：菜单/表单/动作权限树与隐含推导、字段权限矩阵、动作数据范围、主体绑定、全量覆盖提交与幂等。
7. 图标选择器 `IconPicker` / `IconDisplay` / `IconLibrary` / `iconRegistry`；代码表达式编辑器 `CodeEditor` / `SqlEditor` / `ExpressionEditor` / `CronEditor` / `CodeViewer` / `useCodeEditor`（CodeMirror 6 内核，独立分包）。

**完成标准**：七类组件可用；导入导出幂等与错误报告正确；流程建模 XML 可导入导出并发布；表单设计器拖拽与保存发布可用；渲染器按元数据正确分发。回补窗口：阶段五~七为主，随对应后端能力就绪。

**参考文档**：《组件设计》08 交互类 01-07 节点（含可交互原型）、[26-表单定制](../../../设计/架构设计/26_架构设计_子系统_表单定制.md)、[17-工作流](../../../设计/架构设计/17_架构设计_子系统_工作流.md)

## 3. 需求 07-2：业务设计器与面板 <a id="r07-2"></a>

优先级：3（中）　|　状态：未开始　|　完成日期：—

**背景与动机**：报表/大屏设计器、AI 助手、国际化文案编辑器与一系列面板（侧边菜单、向导、偏好、批量操作、主题品牌、租户切换、打印）构成平台的配置与运营交互面；其中报表/大屏依赖 ECharts + gridstack + vue-flow，打印依赖模板与 PDF 导出，AI 助手依赖 SSE 流式，均需独立分包与统一交互。

**内容**（《组件设计》08 交互类 08-19）：

1. 报表设计器 `ReportDesigner` / `DatasetSelector` / `ChartConfigPanel` / `ReportCanvas` / `useReportDesigner`：数据集选择、图表类型与配置面板、ECharts 实时渲染、gridstack 网格布局、数据预览与保存发布。
2. 大屏设计器与播放 `ScreenDesigner` / `ComponentPanel` / `ScreenCanvas` / `ScreenPropertyPanel` / `ScreenPlayer` / `useScreenDesigner`：vue-flow 自由画布、组件面板、属性面板、多页轮播播放与自适应。
3. AI 助手 `AiAssistant` / `ChatPanel` / `MessageBubble` / `PromptInput` / `ConversationList` / `useAiChat`：四模式对话、流式输出与停止、问数图表结果、审批辅助、文档问答引用、自动执行二次确认与撤销。
4. 国际化文案编辑器 `I18nEditor` / `LocaleManager` / `MessageGrid` / `MessageFilter` / `useI18nMessages`：语言清单维护、msg_key × 多语言列可编辑网格、缺失筛选、批量保存与缓存失效、导入导出。
5. 侧边菜单 `SideMenu` / `MenuNode`（动态菜单树、折叠、搜索、徽标）；向导与步骤 `Wizard` / `WizardStep`；偏好设置面板 `PreferencePanel`；批量操作栏 `BatchActionBar` / `useSelection`；主题与品牌化 `ThemeSwitcher` / `ThemeProvider` / `useTheme`；租户切换 `TenantSwitcher` / `useTenant`；打印与导出 PDF `PrintTemplate` / `PrintPreview` / `usePrint`。

**完成标准**：五类设计器/面板可用；报表与大屏独立分包、首屏不加载；AI 助手流式输出与二次确认生效；主题/租户切换即时生效。回补窗口：阶段五~七（菜单/向导/偏好/批量/主题/租户切换/打印）与阶段十四（报表/大屏）、阶段十七（AI 助手）。
