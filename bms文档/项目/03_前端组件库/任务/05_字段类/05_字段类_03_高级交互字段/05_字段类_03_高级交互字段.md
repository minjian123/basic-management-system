## 2. 任务内容 <a id="content"></a>

1. 文件上传字段 `FileUploadField` / `ImageUploadField` / `FileListField` / `useFileUpload`：分片、秒传、断点续传、只读回显。
2. 富文本字段 `RichTextField` / `MarkdownField` / `RichTextViewer` / `sanitizeHtml`：双模式、白名单双向清洗、只读渲染（前端 DOMPurify + 后端白名单）。
3. 穿梭框 `TransferField` / `useTransfer`：双列表穿梭、搜索、分组、分页/异步、上限。
4. 验证码 `Captcha` / `useCaptcha`：图形（失败阈值强制/刷新/一次性失效）、滑块、短信（脱敏/倒计时/限流）。
5. 标签输入 `TagInput` / `useTagInput`：建议与自由新建、去重、数量/长度上限、颜色映射、粘贴批量。

## 3. 完成标准 <a id="accept"></a>

五类字段可用；富文本 XSS 双向清洗验证通过；上传分片/断点续传与后端契约一致；Vitest 覆盖关键交互。
