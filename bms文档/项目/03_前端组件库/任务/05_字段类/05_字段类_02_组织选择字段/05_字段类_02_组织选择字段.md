## 2. 任务内容 <a id="content"></a>

1. `UserSelectField` / `PostSelectField` / `OrgSelectField`：远程搜索、多选、只读回显、已删除/停用对象占位。
2. `DeptTreeSelect`：部门树选择（与权限数据范围口径一致）。
3. 数据来源统一走组织相关 store 并复用缓存；批量按 id 回显走批量接口，避免 N+1。

## 3. 完成标准 <a id="accept"></a>

三类组织选择字段可用、远程搜索与多选正确、只读回显稳定；Vitest 覆盖回显与搜索分支。
