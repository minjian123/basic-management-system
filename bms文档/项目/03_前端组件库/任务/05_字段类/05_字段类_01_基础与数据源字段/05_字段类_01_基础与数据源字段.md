## 2. 任务内容 <a id="content"></a>

1. 日期时间字段 `DateField` / `DateRangeField` / `TimeField`（时区、格式化、只读回显）。
2. 数值与金额字段 `NumberField` / `AmountField` / `PercentField`（精度、范围校验、金额格式化）。
3. 开关与枚举字段 `SwitchField` / `InlineSwitch` / `EnumField` / `EnumCheckboxField`。
4. 字典字段 `DictSelect` / `DictCascader` / `getDictLabel` / `useDictStore`（字典经 store 复用缓存与版本比对）。
5. 树选择字段 `TreeSelectField` / `MenuTreeSelect`（树数据、懒加载、只读路径回显）。
6. 级联选择 `CascaderField` / `useCascader`（多级联动、懒加载、任意级可选、多选、搜索、路径回显）。

## 3. 完成标准 <a id="accept"></a>

六类字段可用并按 locale/时区正确展示；字典字段复用缓存不重复请求；校验规则生效；Vitest 覆盖格式化与校验契约。
