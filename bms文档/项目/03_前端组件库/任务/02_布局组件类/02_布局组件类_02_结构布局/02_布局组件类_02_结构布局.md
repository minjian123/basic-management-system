## 2. 任务内容 <a id="content"></a>

1. 多标签导航 `TabsNav`（页面级多标签：打开/关闭/右键/固定）与 `FormFrameTabs`（表单框架双层 Tab）。
2. 树形主从布局 `MasterDetail` / `MasterTree`：左树右表/右详情、选中过滤、可调分割、折叠、窄屏抽屉与空态。
3. 栅格 `Grid`（24 栅格 + 响应式断点）。
4. 间距/分割线 `Space` / `Divider`。
5. 分栏 `Split`（可拖拽左右/上下）。
6. 内容页签 `Tabs`、卡片 `Card`、折叠面板 `Collapse`（手风琴/多开）。
7. 均继承 L2-07 布局组件基类，视觉与交互对齐 Element Plus 与《布局设计》。

## 3. 完成标准 <a id="accept"></a>

八项结构组件可用且可组合（如「卡片 + 折叠 + 栅格 + 分栏」搭出详情页分区）；树形主从选中过滤与可调分割生效；Vitest 覆盖关键交互；`vue-tsc`、ESLint、Vitest 全通过。
