## 2. 任务内容 <a id="content"></a>

1. 报表设计器 `ReportDesigner` / `DatasetSelector` / `ChartConfigPanel` / `ReportCanvas` / `useReportDesigner`：数据集选择、图表配置、ECharts 实时渲染、gridstack 网格布局、数据预览与保存发布。
2. 大屏设计器与播放 `ScreenDesigner` / `ComponentPanel` / `ScreenCanvas` / `ScreenPropertyPanel` / `ScreenPlayer` / `useScreenDesigner`：vue-flow 自由画布、组件与属性面板、多页轮播与自适应。
3. AI 助手 `AiAssistant` / `ChatPanel` / `MessageBubble` / `PromptInput` / `ConversationList` / `useAiChat`：四模式对话、流式输出与停止、问数图表结果、审批辅助、文档问答引用、自动执行二次确认与撤销。
4. 国际化文案编辑器 `I18nEditor` / `LocaleManager` / `MessageGrid` / `MessageFilter` / `useI18nMessages`。
5. 侧边菜单 `SideMenu` / `MenuNode`、向导与步骤 `Wizard` / `WizardStep`、偏好设置面板 `PreferencePanel`、批量操作栏 `BatchActionBar` / `useSelection`、主题与品牌化 `ThemeSwitcher` / `ThemeProvider` / `useTheme`、租户切换 `TenantSwitcher` / `useTenant`、打印与导出 PDF `PrintTemplate` / `PrintPreview` / `usePrint`。

## 3. 完成标准 <a id="accept"></a>

五类设计器/面板可用；报表与大屏独立分包、首屏不加载；AI 助手流式输出与二次确认生效；主题/租户切换即时生效；Vitest 覆盖关键交互。
