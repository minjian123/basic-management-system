## 2. 任务内容 <a id="content"></a>

1. 图表卡 `EChart` / `ChartCard` / `useChart` / `chartTheme`：图表类型与地图、令牌色板与深色主题、工作台卡片形态与空/加载/错误/降级态、自适应与按需分包。
2. 全局搜索 `GlobalSearch` / `SearchPanel` / `SearchResults` / `SearchResultItem` / `useGlobalSearch`：顶栏入口与命令面板、多域分组结果与高亮、审计日志页签、降级提示。

## 3. 完成标准 <a id="accept"></a>

图表卡可挂数据集渲染且独立分包；全局搜索命中与高亮正确、权限与租户过滤生效、ES 不可用降级兜底；Vitest 覆盖降级分支。
