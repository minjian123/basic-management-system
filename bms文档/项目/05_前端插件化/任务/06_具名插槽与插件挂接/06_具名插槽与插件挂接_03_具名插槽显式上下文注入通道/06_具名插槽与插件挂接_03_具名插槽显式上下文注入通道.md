## 2. 任务内容 <a id="content"></a>

1. **显式上下文注入通道**：区域插槽件新增可选 `context`（宿主页声明的作用实体标识等），以**冻结浅拷贝**经注入通道提供给区域项；区域项组件经 `useModuleSlotContext()` / `useModuleSlotField(key)` **只读取得**——宿主页与插件之间**不新增直接依赖**（宿主不 import 插件、插件不 import 宿主页）。
2. **降级口径**：未注入 / 键缺失时取得 `undefined`，插件**自行降级**（不假定存在、不发起请求、不阻塞宿主页其余部分）；插件缺失 / 未启用 / 无权限时该项不渲染（沿用 `06_01` 口径）。
3. **与路由通道并存**：既有「作用实体标识放路由参数 + 插件经注入 `router` 只读读取」通道（`sys.user.detail.tabs` 范式）**不受影响**；插件可消费两通道之一或并存。
4. **首个非路由承载消费方**：角色记录页「角色分配」页签（`RoleAssignTab`）经 `ModuleAreaOutlet` 声明挂接位 `sys.role.detail.assign` 并注入当前角色标识（`roleId`）。
5. **契约与护栏**：通道按**向后兼容新增**承载（不递增模块契约版本、不新造注册表、区域项声明字段不变）；护栏断言「宿主页不直连插件」「宿主页经插槽件声明挂接位并注入上下文」。
6. **文档回写**：架构 35（区域声明 / 具名插槽节）、架构 10 §9、组件设计《模块区域插槽》、知识档案《微前端 · 业务模块接入指南》「上下文与数据通路」节、bms 阶段七 `01_01` 的「未就绪按降级」登记回写为「已就绪」。

## 3. 完成标准 <a id="accept"></a>

1. 宿主页可经具名插槽向区域项注入**只读**上下文（含用例）；非路由承载页（角色分配页签）可取得当前角色标识；
2. 未注入上下文时区域项取得 `undefined` 且**不报错、不请求、不阻塞**宿主页（含用例）；
3. 既有路由参数通道与 `06_01` 插槽口径**零回归**（`sys.user.detail.tabs` 相关用例全绿）；
4. 护栏含「宿主不直连插件」「新宿主页经插槽件留槽并注入上下文」断言；
5. 文档四处口径与实现一致，阶段七 `01_01` 的降级登记回写为「已就绪」；
6. `vue-tsc`、ESLint、Vitest（core / ui-ep / desktop / 模块工程）与预检全通过。
