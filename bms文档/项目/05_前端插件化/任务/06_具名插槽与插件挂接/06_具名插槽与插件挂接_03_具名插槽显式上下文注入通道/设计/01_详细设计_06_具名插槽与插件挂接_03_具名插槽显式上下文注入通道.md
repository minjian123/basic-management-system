## 1. 设计目标与范围 <a id="goal"></a>

`06_01` 落地的具名插槽，宿主上下文只支持「作用实体标识放**路由参数**」（`sys.user.detail.tabs` 范式）。但角色表单页的「角色分配」页签是**表单框架的记录页签**（非独立路由、无 `:id` 路由参数），mdm「岗位分配 / 部门分配」插件取不到当前角色标识而无法读写。本任务补一条**显式上下文注入通道**，使非路由承载的宿主页也能向区域项（插件）提供作用实体标识。

1. **通道**：区域插槽件可选 `context`（宿主页声明）→ 冻结浅拷贝 → 区域项经注入通道**只读取得**。
2. **降级**：未注入 / 键缺失即 `undefined`；插件自行降级（不假定存在、不发起请求、不阻塞宿主）。
3. **并存**：路由参数通道保留不变；不新造注册表、不递增模块契约版本、区域项声明字段不变。
4. **首个消费方**：角色分配页签（`sys.role.detail.assign`）留槽并注入 `roleId`。
5. **范围外**：多实体上下文（一个宿主页给不同区域项不同上下文）、上下文变更订阅 / 双向通道（插件反向通知宿主）、移动端宿主（随移动端阶段）。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 上下文类型（core，框架无关）

```ts
/** 具名插槽上下文（宿主页注入；只读）。未提供的键以 undefined 呈现，插件自行降级。 */
export type ModuleSlotContext = Readonly<Record<string, unknown>>
```

### 3.2 通道 API（ui-ep）

```ts
/** 注入键（宿主页与插件均不直接使用）。 */
export const MODULE_SLOT_CONTEXT_KEY: InjectionKey<Readonly<Ref<ModuleSlotContext | undefined>>>

/** 提供上下文（**区域插槽件内部使用**）：冻结浅拷贝，插件改动不生效；未声明即 undefined。 */
export function provideModuleSlotContext(context: MaybeRefOrGetter<Record<string, unknown> | undefined>): void

/** 读取上下文（**区域项组件消费**）：未注入为 undefined。 */
export function useModuleSlotContext(): ComputedRef<ModuleSlotContext | undefined>

/** 读取单字段（**区域项组件消费**）：未注入 / 键缺失为 undefined。 */
export function useModuleSlotField<T = unknown>(key: string): ComputedRef<T | undefined>
```

### 3.3 区域插槽件（`ModuleAreaOutlet`）

| 项 | 口径 |
| --- | --- |
| 新增 prop | `context?: Record<string, unknown>`（可选；缺省 `undefined`） |
| 注入行为 | `provideModuleSlotContext(() => props.context)`；**冻结浅拷贝**（`Object.freeze({ ...context })`）→ 插件侧改动不生效 |
| 未声明 | 不注入（`undefined`）：既有宿主页（用户详情页）行为**零变化** |
| 形态 | `inline` / `tabs` 两形态一致（注入与形态无关） |
| 响应式 | `roleId` 等随宿主实体切换时，区域项取得的值为最新（宿主页传入响应式计算） |

### 3.4 宿主页（角色分配页签）

```vue
<module-area-outlet
  :area="ROLE_ASSIGN_SLOT"          <!-- sys.role.detail.assign -->
  variant="tabs"
  :registries="registries"
  :revision="registriesRevision"
  :permission-codes="permissionCodes"
  :context="slotContext"            <!-- { roleId: props.roleId } -->
/>
```

- 宿主页**只声明挂接位与上下文**，不 import 任何具体插件（护栏断言）。
- 插件缺失 / 未启用 / 无权限 → 插槽项不渲染，页签内**内建内容（用户分配）不受影响**。

### 3.5 兼容与边界

| 项 | 口径 |
| --- | --- |
| 区域项声明字段 | **不变**（`ModuleRegionDeclaration` 不加字段——上下文是**运行时注入**，非注册声明面） |
| 模块契约版本 | **不变**（新增能力属向后兼容；注入项未变） |
| 注册表基座 | **不变**（不新造注册表） |
| 上下文归属 | 由**宿主页**声明（谁承载实体谁提供标识）；插件只读，不得回写宿主状态 |
| 只读强度 | 冻结**浅拷贝**（顶层键不可改；嵌套对象不做深冻结——文档明示，插件不得依赖深冻结） |

## 4. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 未注入上下文 | 区域项取得 `undefined`：插件自行降级（不请求、不渲染或空态），宿主页其余正常 |
| 键缺失（注入了对象但无该键） | 同上（`undefined`） |
| 插件试图改上下文 | 冻结对象赋值抛错（严格模式）/ 不生效；宿主状态不受影响 |
| 插件未注册 / 未启用 / 无权限 | 该项不渲染，插槽为空（`06_01` 口径） |
| 插件提供方不可达 | 沿用失败兜底（错误边界 + 按模块归因） |
| 宿主页未声明 `context` | 不注入（既有路由参数通道照旧） |

## 7. 边界与开放项 <a id="open"></a>

| # | 事项 | 归口 |
| --- | --- | --- |
| 1 | **多实体 / 多上下文**：同一宿主页给不同区域项不同上下文（如记录页签同时挂多个实体） | 微前端治理增强（需要时按「按区域项声明上下文键」扩展） |
| 2 | **上下文变更订阅**：插件感知宿主实体切换的事件化通道（现为响应式只读值） | 同上（现口径：值变化自动刷新，足够） |
| 3 | **深冻结**：嵌套对象不做深冻结（文档明示浅拷贝） | 如需强隔离再评估（结构化克隆 / 只读代理） |

## 8. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | 通道形态 | **区域插槽件 `context` prop → Vue 注入通道（provide/inject）**：宿主页显式声明、插件只读取得，不新增宿主 ↔ 插件直接依赖 |
| 2 | 承载位置 | 通道 API（键 / 提供 / 消费）并入 `useModuleArea`（插槽消费投影）——**不新增基类**（继承链唯一权威，避免为纯通道新增能力域基类）；`core` 只落**框架无关类型** |
| 3 | 只读强度 | **冻结浅拷贝**（顶层不可改）；不深冻结（文档明示） |
| 4 | 契约版本 | **不升** `MODULE_CONTRACT_VERSION`（区域项声明字段不变、上下文为运行时注入） |
| 5 | 注册表 | **不新造**（复用页面区域注册表） |
| 6 | 宿主页留槽归属 | 随本任务一并落（`RoleAssignTab`），并回写阶段七 `01_01` 的降级登记 |
