## 3. 实施过程 <a id="process"></a>

1. **先登记再编码**：写 Kiwi 用例输入 → 经 mjbk 容器 `register_cases.py` 登记 → 回读编号 **2259** → 代码与用例标注（`// kiwi_id: 2259`）。
2. **契约先行**：先落寻址契约（纯函数、零依赖），再落能力契约（作用域类型）与基类实现，最后接宿主实现与导出面。
3. **路径归一收敛**：原 `serviceUrl` 内联的归一逻辑抽为共用函数，`productUrl` 复用同一函数——保证两类命名空间的归一与错误口径一致（详设 §3.1）。
4. **护栏补判据**：在 R3（自建 HTTP）之后新增 R4（自拼前缀），判据取「引号后直跟 `/api/` 的字面量或模板串」，既拦静态自拼也拦 `` `/api/mdm/v1/${domain}` `` 这类模板串，同时不误伤 `'https://example.com/api/guide'`（引号后非 `/api/`）。
5. **契约探针同步**：模块契约工厂（`@bms/core/testing`）的探针与断言补产品域入口，使**模块工程**用例在「同一套断言」下覆盖新通道；三模块工程用例回归通过。
6. **门禁复跑**：core / desktop / 三个模块工程用例、隔离扫描、`vue-tsc`、ESLint 全绿（见 §5）。

## 4. 问题与处置 <a id="issues"></a>

| # | 现象 | 处置 |
| --- | --- | --- |
| 1 | 契约探针（`createModuleApiProbe`）缺 `product`，`tsc` 报 `TS2741`（`ModuleApi` 必填属性缺失） | 探针补 `product: () => scope`（作用域方法一律返回拒绝的 `Promise`，保持「探针不产生网络副作用」口径），并把作用域六法纳入契约工厂断言 |
| 2 | 幂等键抽象签名变更（`service: ServiceKey` → `target: string`）影响宿主实现与两处用例探针 | 同步改签名与实现（宿主前缀拼接口径不变：`<target>:<path>`），既有断言（`probe:file:/files`）保持成立 |
| 3 | R4 判据初版限定「`/api/` 后跟字母」，漏掉模板串形式 | 放宽为「引号后直跟 `/api/`」，并在护栏用例补模板串负例与「外链含 `/api/`」正例（不误判） |
