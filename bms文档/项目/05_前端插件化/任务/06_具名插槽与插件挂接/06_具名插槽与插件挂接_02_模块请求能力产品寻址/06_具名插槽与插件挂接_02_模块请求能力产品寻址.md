## 2. 任务内容 <a id="content"></a>

1. **寻址层产品寻址（单一来源）**：寻址契约新增产品键与域段的地址组装（`/api/{产品键}/v1/{域}{路径}`），与平台服务寻址（`/api/{平台服务键}/v1{路径}`）**同层并列**；路径归一（去首部斜杠、折叠重复斜杠、保留查询串）与平台通道同口径；**各模块 / 页面一律不得自拼前缀**。
2. **模块请求能力产品域通道**：模块契约新增产品域作用域（`api.product(产品键, 域)`，含 `get / post / put / patch / del / request`），语义与平台服务通道一致（前缀组装、凭据注入、统一响应解包、401 静默刷新与重放由宿主请求层处理）。
3. **幂等键口径**：产品域写方法幂等键含「产品键:域」（宿主实现点口径不变），与平台服务通道互不冲突；查询 / 删除不生成幂等键。
4. **向后兼容与边界**：平台服务键清单与通道**零变化**（`org` 不回退平台清单）；产品键未登记 / 域段非法**立即抛参数段位错误**（零请求）；模块契约版本与加载器双端校验口径不变；域段由产品自持（基座不维护产品内部域清单，避免双事实源）。
5. **护栏**：隔离护栏在既有「自建 HTTP（R3）」之外新增**「自拼服务 / 产品前缀（R4）」**判据（源码面 + 产物面同判据），并补正例（经 `api.get(...)` / `api.product(...)` 取数不误判）。
6. **文档回写**：《架构设计 · 前端模块契约》「请求能力」节、《架构设计 · 前端架构》§9 治理表、《前端基类清单》（服务寻址契约 / 模块请求能力）、知识档案《微前端业务模块接入指南》「跨仓接入」节（补产品模块取数示例）。

## 3. 完成标准 <a id="accept"></a>

1. 产品命名空间寻址与平台服务寻址同层可用，路径归一与错误口径一致（含用例）；
2. 模块经产品域通道可取数且**不自拼前缀、不接触凭据**；未登记产品键 / 非法域段明确报错；
3. 既有平台服务键清单与通道零变化，模块契约版本口径不变（向后兼容）；
4. 护栏对「自拼前缀」「裸请求」均能拦截（含负例断言）；
5. 模块契约 / 前端架构 / 前端基类清单 / 模块接入指南四处文档口径与实现一致；
6. `vue-tsc`、ESLint、Vitest（core / desktop / 模块工程）与预检全通过。
