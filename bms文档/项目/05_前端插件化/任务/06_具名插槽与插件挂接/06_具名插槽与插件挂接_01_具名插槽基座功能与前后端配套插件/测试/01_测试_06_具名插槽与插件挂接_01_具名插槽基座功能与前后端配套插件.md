## 4. 问题与处置 <a id="issues"></a>

## 6. 偏差与遗留 <a id="deviations"></a>

- **未覆盖项**：
  1. **浏览器级端到端**（真实登录态下走查具名插槽渲染 / 权限显隐 / 写操作）：`VITE_AUTH_GUARD=off` 时宿主恒骨架屏、本地无 BMS 应用账号 → 不可行；本期以自动化用例 + 「构建 → 发布 → 发布存储可达 + 产物元数据核对」为证据；归阶段七（提供账号后补齐浏览器走查）与前端 E2E 阶段。
  2. **真实用户详情数据源**：宿主页按 `:id` 取任意用户详情依赖 org → mdm 用户主数据契约，本期只取当前用户概要作骨架；归阶段七 / mdm 阶段。
  3. **mdm「用户分配岗位」插件**（消费方，不在本任务内）：本任务只提供平台侧挂接基座与成文约定；该插件由 mdm 产品仓库按约定实现。
- **后续任务接收项**：① 阶段七用户管理接管用户详情宿主页（含真实用户详情契约）并补齐浏览器走查；② 「具名插槽上下文」注入通道（非路由承载场景）另立项评估；③ 插槽级观测与治理（按插槽归因 / 清单面板）；④ `frontend/modules/*` 覆盖率门禁口径统一。
