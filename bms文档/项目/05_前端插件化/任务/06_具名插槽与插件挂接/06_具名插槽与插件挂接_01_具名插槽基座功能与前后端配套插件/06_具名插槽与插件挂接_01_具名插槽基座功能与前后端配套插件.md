## 2. 任务内容 <a id="content"></a>

1. **具名插槽机制**：在**页面区域注册表**（`01_01` 已交付）之上定义**稳定命名**的具名插槽（`{域}.{页面}.{区域}`，首个落地 `sys.user.detail.tabs`）——宿主页声明插槽键，插件经统一注册通道登记区域项（**不新造注册表**）；同一插槽支持**多插件**（多 Tab / 多动作）、可排序、按权限显隐。
2. **插槽区域渲染与消费**：宿主页经区域插槽件渲染已登记项，插槽项声明携带来源（平台 / 模块名）；随模块**挂载生效、卸载还原**（复用 `01_02` 消费接线口径 `useModuleArea`）；宿主页**不直接 import 具体插件**。
3. **降级与失败兜底**：插件**未注册 / 未启用 / 提供方不可达**时，该插槽项**不渲染**（插槽为空），宿主页其余部分正常（不报错、不阻塞）；加载失败按 `03_03` 兜底口径处置（错误边界 + 按模块归因）。
4. **前后端配套插件约定**：成文「**数据归属方提供插件**」——插件 = **前端模块**（界面，注册为该插槽区域项，只经宿主注入 `api` 能力发请求）+ **后端契约**（取数与增删改查触发接口，插件提供方公开契约）；约定插件的**注册声明字段**（插槽键 / 次序 / 权限码 / 显示条件）与**后端契约路径 / 权限码归属**；跨服务调用走服务间契约或 `/api/open`。
5. **平台内样例插件**：新建一个**平台内样例插件**（例：给 `sys.user.detail.tabs` 挂「用户扩展示例」Tab，自带一件最小后端能力——读列表 + 一次写操作），真跑通「宿主留槽 → 插件注册 → 挂载渲染 → 写操作 → 卸载还原 → 移除插件后隐藏」全链路；样例落**平台内样例模块/插件工程**（与阶段五 `05-8` 样例同口径），**不进入生产业务菜单**。
6. **契约与文档化**：以《[架构设计 · 前端模块契约](../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》与架构 10 §9 为上位依据，把具名插槽的**注册声明字段、命名规则、冲突处置与降级口径**成文；插件接入指南落知识档案（复用 `04_01` 接入指南口径，增补具名插槽与前后端配套小节）。
7. **护栏**：机器护栏断言「宿主页不得直接 import 具体插件」「插槽项未登记不渲染」「插件移除后无残留注册项 / 无残留路由」。
8. **落点（已定）**：机制落平台前端基座（页面区域注册表扩展 + 插槽命名与降级约定）；样例插件落平台内样例模块/插件工程；mdm 组织域「用户分配岗位」插件由 mdm 产品仓库提供，不在本任务内。

## 3. 完成标准 <a id="accept"></a>

具名插槽（至少 `sys.user.detail.tabs`）可挂**多插件**、可排序、按权限显隐，宿主页与插件**无直接依赖**；插件缺失 / 不可达时插槽项**隐藏、宿主页其余正常**（含用例）；插件挂载与卸载**无残留**；前后端配套约定成文（注册声明字段 / 后端契约路径与权限码归属），样例插件按约定实现并真跑通「留槽 → 注册 → 渲染 → 写操作 → 卸载还原 → 移除隐藏」全链路（**不进入生产菜单**）；护栏含「宿主不直连插件」「未登记不渲染」「卸载无残留」断言；`vue-tsc`、ESLint、Vitest、模块契约测试与体积预算全通过。
