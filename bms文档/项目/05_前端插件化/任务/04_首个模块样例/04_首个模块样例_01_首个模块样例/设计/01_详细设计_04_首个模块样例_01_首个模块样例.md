## 1. 设计目标与范围 <a id="goal"></a>

在域 01 ~ 域 03 全部前置契约**已交付**（八类扩展点注册表与统一装配 / 清单驱动加载器与渲染消费接线 / Module Federation 运行时加载 / 依赖共享与版本偏斜治理 / 样式与运行时隔离护栏 / 模块清单与发布回滚治理 / 可观测与失败兜底）之上，用一个**真实形态**的页面把「扩展点注册 → 独立构建 → 运行时加载 → 独立发布 / 回滚」整条链路跑通，并沉淀为后续业务页面的标准范式：

1. **样例模块开发**——在平台 `frontend/` 下**新建独立模块工程** `frontend/modules/sample/`（模块名 `sample`，主题「示例数据管理」）：**查询筛选 + 列表 + 详情 + 独立表单**，复用阶段四组件库（`@bms/ui-ep`）、契约套件（`@bms/core`）与设计令牌；数据走**模块内占位数据服务**（异步签名对齐未来统一响应，真实接口随后续窗口联调）。
2. **注册与接入**——模块经统一注册通道声明**八类扩展点**（路由·菜单 / 页面区域 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片 / 主题令牌 / i18n 文案包）；路径前缀 `/sample`、键前缀 `sample:`（遵循 `01_01` 口径）。
3. **独立构建与发布**——模块独立构建产出独立产物（`dist/remoteEntry.js` + `dist/module.meta.json` + 外部 sourcemap），经 `03_02` 的清单注册发布；**回滚按清单版本回退**；本次**仓内真跑端到端**（发布 `0.1.0` → 升 `0.2.0` 发布 → 回滚 `0.1.0`）。
4. **运行时加载验证**——宿主运行时加载样例模块：动态路由生效、菜单联动、挂载与卸载无残留、失败兜底生效、`shared` 依赖单实例、模块产物不进首屏。
5. **宿主菜单装配泛化**——把宿主当前硬编码的「demo 分组 + 仅 DEV 可见」改为**通用模块菜单装配**：路由 `meta` 承载菜单语义（`menu` / `group` / `devOnly`），样例**进入生产菜单**，demo 保持 DEV-only；核心装配器识别 `meta.menu === false`（详情 / 表单不进菜单）。
6. **接入指南沉淀**——输出「业务页面按模块形态接入」指南（目录结构、注册声明样例、构建与依赖声明、发布与回滚步骤、自检清单），落知识档案《微前端》专题，作为后续产品模块标准范式。

**落点（已定）**：平台内样例模块；biz 首个业务页面随产品仓库排期，不在本任务内。

**不在本期**：真实后端接口联调（占位通路）、生产 / mjbk 部署形态（产物上传与部署侧清单，归部署阶段）、`biz` 产品模块、灰度进阶、字段渲染器 / 工作台卡片 / 页面的深度消费接线（各域消费方随后续页面 / 工作台阶段）。

### 1.1 现状与缺口 <a id="gap"></a>

```text

├── apps/desktop/

├── modules/demo/                        # 模块工程（契约演示基线，DEV-only）                 ← 本期 路由 meta 补 group / devOnly
│       └── src/index.ts
├── modules/sample/                      # （本期新增）首个模块样例工程（MF remote）
├── packages/core/src/registries/
│   ├── providers.ts                     # RouteMenuProvider（键 / 路径 / 标题 / 图标）        ← 本期 +meta（可选）
│   └── assemble.ts                      # 路由·菜单装配（有 meta.title 即登记菜单项）        ← 本期 +meta.menu===false 跳过
```

缺口：① 平台**尚无一个真实形态模块**验证「注册 → 独立构建 → 运行时加载 → 独立发布 / 回滚」整链路（机制可能停留「配置正确、实际不可用」）；② 详情 / 表单页不应进菜单，但路由·菜单装配**无「不进菜单」声明能力**（有 `meta.title` 即登记）；③ 宿主菜单对模块节点**硬编码为 demo 单一分组且仅 DEV 可见**，产品模块接入后**无法进生产菜单**；④ 后续业务页面缺可照抄范式（目录 / 注册 / 构建 / 发布 / 自检）。

### 3.2 路由菜单声明约定（宿主菜单装配泛化） <a id="route-menu"></a>

路由 `meta` 承载菜单语义（**向后兼容**：不改变既有「有 `meta.title` 即登记菜单项」语义，仅新增可选判据）：

| `meta` 键 | 语义 | 缺省 | 落点 |
| --- | --- | --- | --- |
| `title` | 页面 / 页签 / 菜单标题（字符串） | 无 → **不登记菜单项**（仍注册路由） | 既有 |
| `icon` | 菜单图标名（字符串） | `undefined` | 既有 |
| `menu` | 布尔；`false` → **不进菜单**（详情 / 表单页） | `true` | **本期新增** |
| `group` | 菜单分组标题（字符串）；同模块菜单项归入该组 | 无 → 顶级菜单项 | **本期新增** |
| `groupIcon` | 分组图标名（字符串） | 取组内首项 `icon` | **本期新增** |
| `devOnly` | 布尔；`true` → **生产态不展示**（开发态可见） | `false` | **本期新增** |

- **核心装配器**（`assemble.ts`）：`buildPlan` 路由分组判据由「`meta.title === undefined` 跳过」扩为「`meta.title === undefined` **或** `meta.menu === false` 跳过」；`RouteMenuProvider` 增可选 `meta`（登记前透传 `route.meta`），供宿主读取 `group` / `groupIcon` / `devOnly`；
- **宿主菜单装配**（`host.ts` + `App.vue`）：`moduleMenuNodes()` 不变（仍为注册表快照扁平节点，含 `meta` 派生信息）；新增 `moduleMenuGroups(dev)`：按 `meta.group` 分组（无 `group` 者作顶级项）、`meta.devOnly === true` 且非 DEV 时剔除；`App.vue` 以 `[...sideMenu.menu.value, ...moduleMenuGroups(import.meta.env.DEV)]` 组装，**删除硬编码 demo 分组**；
- **分组节点**：`{ path: group 内首项 path, title: group, icon: groupIcon ?? 首项 icon, children: 组内节点 }`（沿用既有 demo 分组形态，`useSideMenu` 无需改动）；
- **示例**：
  - `sample` 列表路由 `meta: { title: '示例数据管理', icon: 'document', group: '示例模块' }` → 生产菜单出现「示例模块 › 示例数据管理」；
  - `sample` 详情 / 表单路由 `meta: { title: '…', menu: false }` → 路由可用、页签有标题、**不进菜单**；
  - `demo` 路由补 `meta: { group: '演示模块', devOnly: true }` → 保持 DEV-only 与分组外观。

### 3.4 占位数据服务（模块内自包含） <a id="service"></a>

落 `modules/sample/src/services/sample-service.ts` + `src/domain.ts`（**不扩契约、不改注入上下文**）：

```ts
/** 样例记录（示例数据管理实体）。 */
export interface SampleRecord {
  id: string
  code: string
  name: string
  category: SampleCategory
  priority: SamplePriority
  amount: number
  status: SampleStatus
  owner: string
  createdAt: string
  updatedAt: string
  remark: string
}

/** 查询入参（分页 + 筛选项，对齐未来统一分页口径）。 */
export interface SampleQuery {
  keyword?: string
  category?: SampleCategory
  status?: SampleStatus
  page: number
  size: number
}

/** 统一分页响应（对齐后端 `{ list, total, page, size }`）。 */
export interface SamplePage { list: SampleRecord[]; total: number; page: number; size: number }
```

| 接口 | 签名 | 说明 |
| --- | --- | --- |
| 列表 | `list(query: SampleQuery): Promise<SamplePage>` | 关键词（`code` / `name`）+ 分类 + 状态筛选，内存分页 |
| 详情 | `get(id: string): Promise<SampleRecord>` | 未命中抛 `BaseError(PROVIDER_NOT_REGISTERED)`（占位「不存在」语义） |
| 新建 | `create(input): Promise<SampleRecord>` | 生成 `id` / `code` / 时间戳，写入内存集 |
| 更新 | `update(id, input): Promise<SampleRecord>` | 未命中抛错 |
| 删除 | `remove(id): Promise<void>` | 未命中抛错 |

- **单一实现 + 模拟延迟**：`delay(ms)`（缺省 `200ms`，可注入 0 供测试）；数据为模块内 fixture（约 23 条，覆盖多分类 / 状态 / 优先级）；
- **内存态**：`create` / `update` / `remove` 改内存集合（会话内生效，刷新复位）；**不使用任何持久化 API**（`localStorage` / `sessionStorage` / `document.cookie` 一律禁，隔离护栏 R2）；
- **真实接口替换点**：后续联调仅替换本服务实现（或改由后端接口提供），页面与路由不变——接入指南明确此替换口径。

### 3.5 真实形态页面 <a id="pages"></a>

| 页面 | 组合（阶段四组件） | 交互 |
| --- | --- | --- |
| `SampleList.vue` | `PageContainer` + `QueryFilter`（关键词 / 分类 / 状态）+ `DataTable`（多列排序 / 分页 / 行选择）+ 工具区 | 查询 / 重置 / 刷新；双击行 → 详情；「新建」→ 表单；行内「编辑」→ 表单；「删除」→ 二次确认后置空态；空 / 加载 / 错误三态由 `DataTable` 承载 |
| `SampleDetail.vue` | `PageContainer` + `DescriptionList`（只读字段）+ `StatusTag` / `SamplePriorityTag` + `SectionContainer`（备注） | 「返回列表」/「编辑」→ 表单；加载中骨架（`SkeletonBlock` / `StatusContainer`）；不存在 → 错误态 |
| `SampleForm.vue` | `PageContainer` + `SectionContainer` + 输入件（`TextInput` / `SelectInput` / `NumberInput` / `TextareaInput` / `RadioInput` / `SwitchInput`）+ 提交 / 取消 | 新建 / 编辑分态（按 `:id` 判定）；前端必填与范围校验；提交调服务后回列表；`FormLayoutShell` / `GridLayout` 组织栅格 |

- 页面逻辑（筛选 / 分页 / 加载态）以组合式承载，复用 `DataTable` / `QueryFilter` 既有能力，**不重复造件、不硬编码色值**（尺寸硬编码沿用规范白名单）；
- 页面文案一律走模块 i18n（`sample.*` 键；`useModuleI18n` 或经注入 `context.i18n` 的 `translate`），不硬编码中文（模板文案经模块文案包）。

| CI | **不改 yml**：`module-check` / `module-build` 已遍历 `frontend/modules/*`；新增模块锁文件触发基础镜像重建（`deploy/ci/build-base.sh` 遍历模块 `npm ci`）；`check-module-manifest.mjs` 自动纳入样例（版本发现 / 源码对账 / 契约用例齐备） |

**仓内真跑端到端**（`实施/` 记录命令与输出）：

```text
① sample 置 0.1.0 → build → publish（清单 sample=0.1.0，归档 releases/sample/0.1.0）
② sample 置 0.2.0 → build → publish（清单 sample=0.2.0，归档 releases/sample/0.2.0）
③ rollback --module sample（清单 sample 回 0.1.0；0.2.0 产物保留为回滚证据）
④ sample 源码/锁回 0.1.0 → 重新 build（终态 dist = 0.1.0，与清单/源码一致）
```

- 终态：清单 / `package.json` / 产物元数据**三处一致 = 0.1.0**（清单护栏断言通过）；`releases/sample/{0.1.0,0.2.0}` 保留；`release-log` 记录 `publish 0.1.0 → publish 0.2.0 → rollback 0.1.0`；
- 运行验证：`node frontend/scripts/serve-module-releases.mjs`（5002）+ 宿主 `npm run dev`（5173），登录后经生产菜单进入「示例模块 › 示例数据管理」，验证动态路由 / 菜单联动 / 挂载卸载 / 兜底。

### 3.8 宿主装配时序与卸载 <a id="host"></a>

- 启动期：`installPlatformRegistrations()` → `installObservability()` → `installModules()`（清单逐条挂载，含 `sample`：解析远端入口 → 校验形状 / 名称 / 版本 / 契约版本 → `setup` → 路由注册 → 统一装配 → 令牌注入 / 文案并入）→ `app.use(router)` → `app.mount`；
- 卸载：`unmountModule('sample')` 逆序（路由 → 文案 → 令牌 → 注册表 → 加载器）无残留；`registriesRevision` 自增驱动区域插槽与菜单重算；
- 失败兜底：远端不可达 / 超时（10s）/ 契约版本不符 / `setup` 抛错 → 该项不挂载、菜单无该项、错误带模块名与版本、单模块重试可用（`03_03`）。

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 样例远端不可达 / 产物 404 / 语法错误 | 沿用 `02_01` / `03_03`：原样上抛 + 边界兜底（带 `sample` 与版本）+ 遥测；不影响平台页面与 demo |
| 样例加载超时（>10s） | 抛 `CAPABILITY_VIOLATION`（原因明示超时与模块名）→ 降级 UI + 错误态 |
| 样例版本 / 名称 / 契约版本与清单不符 | 加载拒绝（`CAPABILITY_VIOLATION`）；发布 / 回滚同样拒绝 |
| `meta.menu === false` 的路由 | 不登记菜单项，路由照常注册（详情 / 表单可达、页签有标题） |
| 路由未登记 `meta.title` | 不登记菜单项（既有口径不变） |
| `meta.group` 未声明 | 该菜单项作顶级项（不强行分组） |
| `meta.devOnly === true` 且生产态 | 菜单项不展示（路由仍在，直接访问可达） |
| 模块注册键越权（无 `sample:` 前缀）/ 键非法 | 装配拒绝、**零登记**、回滚本次已登记项（`01_01` 口径） |
| 样例令牌名非 `--bms-*` / 覆盖宿主核心令牌 | 护栏与契约用例拦截；样例只声明**自有令牌** `--bms-sample-accent` |
| 页面数据服务抛错（详情不存在 / 更新未命中） | 页面呈现错误态（`StatusContainer` / `DataTable` error），不白屏 |
| 占位服务模拟失败（测试注入） | 页面错误态呈现 + 可重试（`03_03` 单模块重试针对加载；页面级为组件内重试按钮） |
| 模块产物超预算 / 契约用例缺失 / 清单版本错位 | `module-build` / `check-module-manifest.mjs` 门禁阻断 |
| 隔离扫描命中（源码面 / 产物面） | 护栏失败（`module-check` / `module-build`）；修复后复跑 |
| 同版本重复发布 | 版本不可变拒绝；本地重发用 `--force`（记 `republish`，生产禁用） |
| 回滚目标产物被清理 | 拒绝（产物保留是回滚前提） |
| 生产 / mjbk 部署 | 不在本期（部署阶段） |

## 7. 边界与开放项 <a id="open"></a>

- **真实后端接口**：本任务为模块内占位服务；联调随后续窗口，替换服务实现即可（页面 / 路由 / 清单元需改动）；
- **生产 / mjbk 部署**：产物上传与部署侧清单、nginx / CDN 版本目录托管归部署阶段（仓库内清单不写内网信息）；
- **组件 / 字段渲染器 / 工作台卡片 / 图标的深度消费**：本任务完成**声明与登记**及路由·菜单 / 页面区域 / 令牌 / 文案的**消费接线**；其余消费方（工作台、通用组件解析、表单字段渲染）随对应阶段接入；
- **菜单权限过滤**：`meta.devOnly` 为本期「生产隐藏」能力；按权限码过滤模块菜单项随 RBAC / 动态菜单阶段；
- **`meta` 约定扩展**：如需 `badge` / `permission` 等菜单语义，随消费方需求再扩（保持向后兼容）；
- **回滚终态**：本任务终态为 `0.1.0`（`0.2.0` 为演练版本、产物保留为回滚证据）；不追改历史归档。
