## 2. 任务内容 <a id="content"></a>

1. **加载器运行时化**：宿主加载器由「本地演示模块（静态 import / 本地产物）」升级为「按模块清单加载」——清单驱动加载 → 注入上下文 → 执行注册声明 → 挂载 → 卸载；**加载器接口保持与阶段四一致**（同接口替换实现通路）。
2. **模块清单与版本字段**：清单字段（名称 / 入口 / 版本）与加载器版本字段口径统一；清单缺失字段 / 版本不匹配 / 加载失败的分支处置口径成文（降级或拒绝加载）。
3. **注入上下文与只读约束**：宿主注入 router / Pinia / i18n / 当前用户与租户上下文；模块经模块上下文能力基类消费（只读约束）；敏感上下文（token 等）不落模块持久化。
4. **注册声明校验**：模块声明（路由 / 菜单 / 页面区域 / 组件 / 图标 / 卡片 / 主题令牌 / i18n 文案包）经统一校验（唯一性、路径前缀、命名空间）；**注册与卸载清理成对**（卸载后无残留路由 / 菜单 / 注册项）。
5. **演示验证**：以演示模块验证「加载 → 注册 → 卸载」全链路（不进入生产菜单）。

## 3. 完成标准 <a id="accept"></a>

宿主按模块清单加载模块，动态路由生效、菜单联动、挂载与卸载无残留；模块契约（注入上下文 / 注册声明 / 样式约束）在远端形态下同接口复用（不为远端另建契约）；清单缺字段 / 版本不匹配 / 加载失败各分支均有明确处置与用例；`vue-tsc`、ESLint、Vitest 全通过。
