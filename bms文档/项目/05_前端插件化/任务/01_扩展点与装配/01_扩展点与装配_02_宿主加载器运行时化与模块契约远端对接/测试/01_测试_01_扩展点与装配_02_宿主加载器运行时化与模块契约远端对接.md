## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 清单解析用例期望「先前项被拒时后续同名项仍算重名」 | 口径澄清为「保留先通过项」，用例改为断言后续同名合法项入选，并补「两项均合法时第二项判重名」 |
| 2 | 区域插槽件异步加载用例首次失败（`Component is missing template or render function`） | Vue 仅解包 ES 模块（`import()` 产物），普通 `{ default }` 形状不视为模块；用例假加载器改为直接返回组件对象，并在用例注明该口径 |
| 3 | 「清单未装载时挂载拒绝」用例受前序用例（已装载清单）影响 | 该用例移至所在分组首位，保证模块级加载器尚未构造（各用例文件独立模块图，互不影响） |
| 4 | 覆盖审计发现装配冲突回滚 / 清单未装载 / 非 `Error` 异常三条分支未执行 | 补三条用例（宿主两条、清单获取一条），`module/` 行覆盖回到 100% |

## 6. 偏差与遗留 <a id="deviations"></a>

- **未覆盖项**：远端加载通路（Module Federation 独立产物 / 远端入口）与清单治理（发布 / 回滚）未接线，故无对应断言——分别归 `02_01` / `03_02`（均已交付：远端入口经解析器注入；清单唯一来源 / 版本发现 / 发布回滚就位）；宿主 i18n 未引入国际化库，文案**消费**（页面按语言取文案）由国际化阶段覆盖，本任务只断言「并入 / 还原」。
- **后续任务接收项**：① `02_01` 接远端入口形态时复用 `ModuleLoader` 接口与清单结构（`entry` 语义由源码标识换为远端入口），并评估 `LocalModuleLoader` 去留；② `03_02` 承接清单唯一来源 / 版本发现 / 灰度回滚（**已完成**：清单获取实现保持 fetch（清单外置、随部署替换），治理经发布工具与清单护栏落地，接口不变）；③ 国际化阶段以适配层替换 `moduleI18n` 内部实现；④ 令牌 `mode` 维度注入与主题 / 品牌化阶段对齐。
