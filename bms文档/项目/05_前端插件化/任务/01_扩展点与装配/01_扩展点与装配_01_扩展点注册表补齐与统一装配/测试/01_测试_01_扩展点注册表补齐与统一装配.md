## 2. 测试范围与用例 <a id="scope"></a>

| 用例组 | 类型 | 自动化文件 | 覆盖点 |
| --- | --- | --- | --- |
| 八类公共契约 | 单元 | `core/tests/registries.spec.ts` | **同一套断言覆盖八域**：登记 / 按键解析 / 同键拒重（`REGISTRY_CONFLICT`）/ 未命中返回 `undefined` / 遍历保序 / 只读快照 / 幂等注销；`createRegistries` 八类与顺序 |
| 新增三类专有解析 | 单元 | 同上 | 页面区域 `resolveByArea`（保序）/ `areas`（去重）/ 未知区域空数组；主题令牌 `resolve` / `byMode`（空串返全部）；i18n 文案包 `resolve` / `byLocale`（入参大小写归一）/ 键派生 `locale` |
| 键与标识校验 | 单元 | 同上 | 命名空间键（六类无命名空间键拒绝）；路由路径须 `/` 开头；区域标识须点分；语言标识须小写归一且合法 |
| 拒重档位 | 单元 | 同上 | 严格档（缺省）同键抛错；宽和档（fixture 子类）告警保留首个 |
| 统一装配 | 单元 | `core/tests/assemble.spec.ts` | 平台来源不强制前缀且来源打标 `platform`；模块来源须 `<模块名>:` 前缀（越权拒绝）；八类分组登记键；路由无 `meta.title` 不登记、坏路径抛错；两段式（校验失败零登记）；冲突回滚无残留；逆序清理与幂等；未知分组键跳过 |
| 「不注册不可用」护栏 | 单元（护栏 + fixture） | `core/tests/guard-unregistered-provider.spec.ts` | 构造注册项无注册副作用（未登记即不可解析）；登记是生效唯一通道；fixture 模块声明未经装配不生效 |
| 宿主装配与演示模块 | 集成 | `apps/desktop/tests/module-registration.spec.ts` | 装配前不可解析 → 装配后可用（组件 / 图标 / 卡片 / 路由菜单 / 区域 / 令牌 / 文案包）→ 卸载后回到不可解析；越权键拒绝；平台自身注册入口；校验失败零登记；演示模块三类新声明 |

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `createRegistries` 由五类扩为八类，既有顺序断言失败 | 用例改为断言八类完整顺序（路由·菜单 / 页面区域 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片 / 主题令牌 / i18n 文案包） |
| 2 | 宿主用例依赖已移除的 `applyModuleRegistration` / `removeRegistration` | 宿主用例改为直接使用核心 `assembleRegistrations` / `releaseRegistrations`，并补「装配前不可解析 / 卸载后清理」现场断言 |
| 3 | 八类中既有域（组件 / 图标 / 卡片）原本各自散测 | 抽出 `assertRegistryContract` 公共断言函数，八域同一套断言（登记 / 解析 / 拒重 / 未命中 / 保序 / 快照 / 幂等注销） |
