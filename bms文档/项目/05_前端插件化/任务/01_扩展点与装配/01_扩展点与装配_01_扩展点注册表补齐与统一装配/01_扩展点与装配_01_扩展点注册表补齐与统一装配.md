## 2. 任务内容 <a id="content"></a>

1. **扩展点域补齐**：在阶段四已交付的五类注册表（路由·菜单 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片）基础上，补齐**页面区域**、**主题令牌**与 **i18n 文案包**，形成八类扩展点注册表。
2. **统一基座**：八类注册表一律基于统一注册表基座与注册项契约（不得另起映射）；注册项继承注册项基类，注册表继承注册表基座。
3. **统一装配**：宿主提供统一注册入口与装配时序（平台自身注册 + 模块注册共用同一通道）；注册项携带来源（平台 / 模块名）供排查与归因。
4. **注册契约与校验**：同键唯一性拒重（严格域抛错、一般域告警保留首个）、未命中返回空（不替各域裁决兜底）、遍历保序、只读快照；模块注册项额外做路径前缀与命名空间校验（防覆盖平台项）。
5. **「不注册不可用」护栏**：未登记扩展点不参与渲染与路由；机器护栏断言「随包 / 随模块引入但未登记」的项不可用，并配 fixture 拦截用例。
6. **契约文档化**：列出八类扩展点的注册声明字段、键命名与冲突处置（引用《[架构设计 · 前端模块契约](../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》为上位依据）。

## 3. 完成标准 <a id="accept"></a>

八类注册表可用；注册 / 解析 / 拒重 / 未命中 / 保序 / 只读快照契约用例全绿（同一套断言覆盖各域）；平台与模块经同一通道注册且来源可查；未登记项不生效且护栏含 fixture 拦截用例；注册声明字段与键命名成文；`vue-tsc`、ESLint、Vitest 全通过。
