## 2. 任务内容 <a id="content"></a>

1. **模块清单**：清单字段（名称 / 入口 / 版本 / 可见性）与加载器版本字段口径统一（与 `01_02` / `02_01` 一致）；清单是模块加载与回滚的**唯一来源**。
2. **版本发现**：清单版本与模块产物版本一致性校验；校验通过才可入清单。
3. **独立发布**：模块产物发布流程（构建 → 产物归档 → 清单更新）成文并可执行。
4. **回滚**：清单版本回退到上一版本（模块产物保留）成文并可执行；灰度 / 蓝绿仅保留「按清单指向切换」的最小能力。
5. **模块契约测试**：模块与平台的契约（注入上下文 / 注册声明 / 共享依赖 / 样式约束）纳入契约测试，全部注册实现跑同一套断言；契约变更走版本升级。
6. **发布留痕**：清单变更可追溯（谁 / 何时 / 哪个版本），与既有 CI 与发布记录口径一致。

## 3. 完成标准 <a id="accept"></a>

模块清单可用且字段与加载器口径一致；独立发布与**回滚**可执行并演练通过（清单版本回退生效）；模块契约测试覆盖全部注册实现（同一套断言）；发布与回滚流程成文（含校验项与留痕要求）。
