## 3. 执行记录与结果 <a id="run"></a>

```bash
# 核心三包（typecheck / lint / test）
cd bms && npm run check

# 宿主（PC）
cd frontend/apps/desktop && npx vue-tsc -b && npm run lint && npm run test:cov && npm run build && npm run budget

# 模块工程（远端产物 + 隔离护栏）
cd frontend/modules/demo && npm run lint && npm run typecheck && npm run test && npm run build && npm run budget && npm run guard:isolation

# 源码面隔离扫描（CLI，本地与 CI 同口径）
cd bms && node frontend/scripts/check-module-isolation.mjs

# 负向路径（临时目录，不入库）
node frontend/scripts/check-module-isolation.mjs --module /tmp/opencode/bad-module          # 注入 Object.prototype 改写 → 退出 1
node frontend/scripts/check-module-isolation.mjs --module /tmp/opencode/bad-module --product # 缺产物 → 明确报错退出 1

# 文档与基座校验
python3 scripts/tools/base-check/check-base.py
python3 scripts/tools/base-check/check-links.py
python3 scripts/tools/check-docs/check-status.py --stage 05_前端插件化 --strict
```

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 产物面按入口闭包整包扫描会把 MF 运行时块（`remoteEntry.js`）的 `prototype` / 全局赋值特征误报为模块违规 | 自有块识别收窄为「暴露块 + 页面块」（实施记录 §4 问题 3），平台块与 vendor 块不扫 |
| 2 | 压缩产物中 `createPinia` / `createRouter` 绑定名可能被改写，产物面判定不稳定 | 该两项不列入产物判据，由源码面拦截（实施记录 §4 问题 4） |
| 3 | 护栏用例在 Vitest 下解析平台脚本的 `import.meta.url` 非 `file:` 协议 | 脚本按测试工程目录回退推断（实施记录 §4 问题 2），用例显式传 `frontend/` 目录 |
