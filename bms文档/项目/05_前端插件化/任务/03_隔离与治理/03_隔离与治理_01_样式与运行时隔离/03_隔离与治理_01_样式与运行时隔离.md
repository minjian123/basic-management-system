## 2. 任务内容 <a id="content"></a>

1. **样式约定**：模块样式一律 `Scoped` 或加模块命名空间前缀；模块只消费平台设计令牌（不硬编码色值与尺寸）。
2. **全局污染约束**：模块不得改全局原型、不得挂全局事件、不得写全局样式（`*` / 根元素 / 第三方库全局变量覆盖）；平台侧机器护栏覆盖模块目录。
3. **运行时约束**：模块不得直接操作宿主 store / router 实例（只经注入上下文与注册声明）；不私自持久化敏感上下文（token 等）。
4. **隔离增强评估**：就「是否需要 `Shadow DOM` / JS 沙箱」给出评估结论（含触发条件与代价），成文备查；**本期不引入**。
5. **契约并入**：隔离约定并入模块契约（《[架构设计 · 前端模块契约](../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》），作为模块接入检查项。

## 3. 完成标准 <a id="accept"></a>

模块样式前缀与令牌消费约定成文且样例模块遵循；全局污染（全局原型 / 全局事件 / 全局样式 / 硬编码色值）由机器护栏拦截并含 fixture 拦截用例；模块经注入上下文访问宿主能力的口径成文且被样例模块使用；隔离增强评估结论成文（本期不引入，写明触发条件）。
