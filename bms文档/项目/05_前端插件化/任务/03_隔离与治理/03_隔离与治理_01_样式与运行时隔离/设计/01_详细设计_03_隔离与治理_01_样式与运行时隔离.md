## 1. 设计目标与范围 <a id="goal"></a>

在 [02_01](../../../02_运行时加载/02_运行时加载_01_ModuleFederation接入与模块独立构建/02_运行时加载_01_ModuleFederation接入与模块独立构建.md)（**前置契约已交付**：模块为**独立工程**（`frontend/modules/<模块名>/`）独立构建、独立产物，宿主经清单运行期加载；模块样式经共享依赖与宿主同源、`--bms-*` 令牌由宿主注入）之上，把「模块接进来不出乱子」的**样式与运行时隔离**落为「约定成文 + 机器护栏」：

1. **隔离约定成文**——模块样式一律 `Scoped`（或加模块命名空间前缀）、只消费平台设计令牌；模块不得改全局原型 / 挂全局事件 / 写全局样式 / 直接操作宿主 store 与 router 实例 / 私自持久化敏感上下文；
2. **平台侧机器护栏**——新增平台隔离扫描（**源码面 + 产物面**双扫描）：源码面覆盖模块工程 `src/**` 与宿主内构建期合并模块目录（`apps/desktop/src/modules/**`），产物面覆盖模块远端产物（`dist/**`：全部 CSS + 模块自有 JS 块）；护栏含 **fixture 拦截用例**（构造违规样例断言被拦）；
3. **运行时口径落地**——「模块只经 `setup(context)` 只读快照访问宿主能力」成文，并由演示模块作一处**只读消费**（缺失项自行降级）；
4. **隔离增强评估成文**——就「是否需要 Shadow DOM / JS 沙箱」给出评估结论（含触发条件与代价），**本期不引入**；
5. **契约并入**——隔离约定并入《[架构设计 · 前端模块契约](../../../../../../设计/架构设计/35_架构设计_前端模块契约.md)》，作为模块接入检查项。

**不在本期**：隔离增强的实际引入（Shadow DOM / JS 沙箱）、模块清单与发布治理（`03_02`）、按模块可观测与失败兜底（`03_03`）、首个模块样例（`04_01`）。

├── apps/desktop/
│   ├── src/modules/                   # 宿主内构建期合并模块目录（当前为空） ← 本期 纳入隔离扫描

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 隔离约定（口径总表） <a id="convention"></a>

| 面 | 约定（强制） | 说明 |
| --- | --- | --- |
| 样式作用域 | 模块与组件 `<style>` 一律 `scoped`；禁 `:global`；禁全局选择器（`:root` / `html` / `body` / `*`）；禁脚本 import 全局样式文件（样式一律落 SFC `<style scoped>`） | `:deep()` 允许（仍受 scoped 属性选择器限定） |
| 样式前缀 | 模块自有类名以**模块名前缀**（kebab，BEM 简化，如 `.demo-` / `.demo__`） | **约定成文 + 样例遵循**，不做机器强制（scoped 已保证不泄漏；避免动态类名与第三方类名误报） |
| 令牌消费 | 模块样式只消费 `--bms-*` 令牌，**不得硬编码色值**（色值不设豁免）；尺寸沿用《前端开发规范》§3.1 尺寸硬编码白名单 | 模块 `themeTokens` 注册声明载荷为**令牌定义源**（允许字面值，键仍须 `--bms-*`）；`tokens.scss` 类令牌定义源文件豁免 |
| 全局污染 | 禁全局原型（含 `__proto__`）、禁全局事件（`window` / `document` / `globalThis` / `self` 的 `addEventListener`）、禁全局样式（上表）、禁全局变量赋值（`window.x =` / `globalThis.x =`）、禁根节点直控（`document.documentElement` / `document.body`） | 独立预览壳（`src/standalone.ts` 与模块 `index.html`）**豁免**：不是模块契约部分、不进远端产物，本质是「临时宿主」 |
| 运行时 | 不得自建宿主级实例（`createPinia(` / `createRouter(`）；不得私自持久化（`localStorage` / `sessionStorage` / `document.cookie` 一律禁，后续模块确需持久化走平台能力开放）；只经 `setup(context)` **只读快照**消费宿主能力，缺失项自行降级（不假定存在） | 宿主实例（store / router）只读经注入上下文；模块注册一律经八类注册声明 |

- 两形态同一口径：独立模块工程（`mode: remote`）与宿主内构建期合并模块（`mode: local`）适用同一套隔离约定与扫描面；
- 约定并入模块契约（§3.6 回写），作为模块接入检查项。

### 3.2 平台隔离扫描（源码面） <a id="scan-source"></a>

扫描实现落 `frontend/scripts/check-module-isolation.mjs`（零依赖 ESM，口径与 `02_02` 护栏脚本同风格）：

**扫描目标**：`frontend/modules/*/src/**` + `frontend/apps/desktop/src/modules/**`；扩展名 `.ts` / `.mts` / `.vue` / `.js` / `.mjs` / `.scss` / `.css`；**豁免** `standalone.ts`（独立预览壳）与 `tokens.scss`（令牌定义源）；目标目录不存在时跳过（宿主 `src/modules` 当前为空）。

| # | 规则 | 判据（去注释后） | 违规示例 |
| --- | --- | --- | --- |
| S1 | 样式必须 scoped | `.vue` 每个 `<style>` 标签须含 `scoped` | `<style>` 未 scoped |
| S2 | 禁 `:global` | 样式载体出现 `:global` | `:global(.x) { … }` |
| S3 | 禁全局选择器 | 样式载体的选择器段以 `:root` / `html` / `body` / `*` 起始 | `body { margin: 0 }` |
| S4 | 禁脚本引全局样式 | 脚本 import 样式文件（`.css` / `.scss` / `.sass` / `.less`；`?inline` 除外） | `import './x.scss'` |
| S5 | 禁硬编码色值 | 样式载体出现 hex / `rgb[a]()` / `hsl[a]()`；动态计算值 `hsl(${` / `rgb(${` 豁免 | `color: #fff` |
| G1 | 禁全局原型 | `(Object\|Array\|String\|Number\|Boolean\|Function\|Symbol).prototype` 或 `__proto__` | `Object.prototype.x = 1` |
| G2 | 禁全局事件 | `(window\|document\|globalThis\|self).addEventListener(` | `window.addEventListener(…)` |
| G3 | 禁全局变量赋值 | `(window\|globalThis\|self).<标识符> =`（属性链赋值不在此列） | `window.__bms_x = 1` |
| G4 | 禁根节点直控 | `document.documentElement` / `document.body` 出现 | `document.body.appendChild(…)` |
| R1 | 禁自建宿主实例 | `createPinia(` / `createRouter(` | `createRouter({ … })` |
| R2 | 禁持久化 API | `localStorage` / `sessionStorage` / `document.cookie` | `localStorage.setItem(…)` |

- 样式载体 = `.vue` 的 `<style>` 块内容（S 规则）+ `.scss` / `.css` 全文（S 规则）；`.vue` / `.ts` / `.js` / `.mjs` 全文（G / R 规则，`.vue` 含模板与脚本）；
- 色值判据与既有 `guard-tokens` 同源（去注释、动态计算豁免）；TS 载荷（`themeTokens` 字面值）非样式载体，天然不判——与「令牌定义源豁免」口径一致。

### 3.3 平台隔离扫描（产物面） <a id="scan-product"></a>

**扫描目标**：`frontend/modules/*/dist/**`（远端产物；独立预览产物 `dist-standalone/` 不在范围）。

**模块自有 JS 块识别**（其余块不扫，避免 MF 运行时 / 平台辅助块 / 第三方依赖块误报）：

| 块 | 识别 | 说明 |
| --- | --- | --- |
| 暴露块 | `remoteEntry.js` 的**动态引用**中排除 MF 平台虚拟块（文件名含 `_virtual_mf-`）后的块 | 暴露键 `./module` 指向的模块定义块 |
| 页面块 | 入口闭包之外的 JS 块中命中模块 `budget.json` `pageChunkHints` 的块 | 页面独立分包约定（见 `02_01` §3.5） |
| CSS | `dist/**/*.css` 全部 | 模块样式编译产物 |

| # | 规则 | 判据 |
| --- | --- | --- |
| P1 | CSS 选择器须作用域化 | 每个选择器组须含 `[data-v-`（scoped 编译产物）；`@media` / `@supports` / `@keyframes` 前奏与关键帧步进（`from` / `to` / `N%`）不判 |
| P2 | CSS 禁全局选择器 | 选择器组以 `:root` / `html` / `body` / `*` 起始（同 S3） |
| P3 | CSS 禁硬编码色值 | 同 S5 |
| P4 | 自有 JS 块禁全局污染与持久化 | G1 / G2 / G3 / G4 / R2（`createPinia` / `createRouter` 在压缩产物中绑定名可能被改写，不列入产物判据——源码面已拦） |

**CLI**（平台脚本自带，本地与 CI 同口径）：

```text
node frontend/scripts/check-module-isolation.mjs [--source] [--product] [--module <模块目录>]
```

| 项 | 口径 |
| --- | --- |
| 缺省 | 等价 `--source`：扫全部模块工程源码 + 宿主 local 模块目录（目录不存在跳过） |
| `--product` | 扫模块远端产物；`dist/` 不存在即报错退出 1（提示先构建），不静默跳过 |
| `--module <目录>` | 只扫指定模块目录（本地定点排查） |
| 输出 / 退出码 | 打印扫描文件数与命中清单；有违规退出 1，全绿打印通过行（含扫描面计数） |

**导出面**（供宿主护栏用例与 fixture 直接断言）：

```js
/** 扫描一组源码文件（纯函数，供 fixture 断言）。 */
export function scanSourceFiles(files: { path: string; source: string }[]): string[]
/** 扫描一组产物文件（纯函数；入参为 CSS 与自有 JS 块清单）。 */
export function scanProductFiles(input: { css: FileLike[]; js: FileLike[] }): string[]
/** 收集并扫描全部模块源码（模块工程 + 宿主 local 模块目录）。 */
export function scanModuleSources(frontendDir: string): string[]
/** 收集并扫描全部模块远端产物。 */
export function scanModuleProducts(frontendDir: string): string[]
```

### 3.5 样例模块遵循（demo 上下文只读消费） <a id="demo"></a>

演示模块 `setup` 增一处**只读上下文消费**，作为「模块经注入上下文访问宿主能力」的样例证据（`frontend/modules/demo/src/index.ts`）：

```ts
setup: (context) => {
  // 只经注入上下文访问宿主能力（只读快照）；缺失项自行降级（宿主当前以权限码承载 user）
  const codes = Array.isArray(context.user) ? context.user : []
  const greeting = codes.length > 0 ? `你好，已接入 ${codes.length} 项权限` : '你好，演示模块'
  return {
    // …其余声明不变
    i18nPacks: [{ key: 'demo:zh-cn', messages: { 'demo.title': '演示模块', 'demo.hello': greeting, … } }, …],
  }
}
```

- 只读消费、不直连宿主实例、不持久化；缺失项降级（上下文缺失以 `undefined` 呈现）；
- 模块定义用例补断言：空上下文 → 降级文案；带 `user` 上下文 → 计数文案；
- 其余隔离规则（样式 scoped / 令牌 / 无全局污染 / 无持久化）样例现状已遵循，不改动。

| 源码面 | 随既有 `desktop-check`（护栏用例在 `npm run test:cov` 内）——**不新增 job、不改 yml** |
| 产物面 | `module-build` 构建后追加 `npm run guard:isolation`（模块工程 `package.json` 增 `guard:isolation`：`node ../../scripts/check-module-isolation.mjs --product`） |

## 4. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| 模块源码命中任一隔离规则 | 护栏用例失败（`desktop-check` 红）；违规清单含文件与规则原因，修复后复跑 |
| 模块产物命中任一隔离规则 | `module-build` 的 `guard:isolation` 退出 1（构建红）；产物未构建即跑 `--product` 明确报错 |
| 扫描目标目录不存在（宿主 `src/modules` 空） | 跳过该目标，不报错（口径：目录不存在 = 无该形态模块） |
| 独立预览壳 / `tokens.scss` 命中样式规则 | 豁免，不判（预览壳非模块契约部分；令牌定义源允许字面值） |
| `themeTokens` 载荷出现色值字面值 | 不判（非样式载体；令牌定义源豁免） |
| 第三方依赖块（vendor）出现全局特征 | 不判（不在自有块范围；误报由扫描面界定规避） |
| 产物块识别失败（无 `remoteEntry.js` / 无 `pageChunkHints`） | 报错退出 1（产物形态与 `02_01` 契约不符，先修构建） |
| 模块后续确需持久化 | 走平台能力开放（不在本任务范围）；护栏口径变更须回写规范与契约 |
| 模块注册键越权 / 装配失败 | 不在本任务（`01_01` / `01_02` 已覆盖） |

## 7. 边界与开放项 <a id="open"></a>

- **隔离增强**：本期只出评估结论（`设计/02_隔离增强评估.md`）；引入条件与代价已写明，触发条件命中时立项；
- **持久化能力**：模块一律禁持久化 API；后续确需（如列表偏好）由平台能力开放并回写规范与契约（不在本任务）；
- **`user` 语义**：宿主当前以权限码承载 `user`（`session.codes`），样例按只读消费 + 缺失降级；宿主 `user` 语义完善时模块契约接口不变、样例按需跟进；
- **产物自有块识别**：依赖 `budget.json` 的 `pageChunkHints` 与 `remoteEntry.js` 动态引用约定；模块工程改名 / 页面块命名变化须同步 `budget.json`（既有约定，`02_01` §3.5）；
- **第三方块不扫**：MF 运行时 / 平台辅助块 / vendor 依赖块不在产物扫描面；其风险由平台护栏与源码面承担，后续如需收紧再评估；
- **接入指南**：业务页面按模块形态接入的自检清单（含隔离检查项）随 `04_01` 沉淀，本任务只在契约中给检查项。

## 8. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | 护栏落点与形态 | **平台脚本 + 宿主测试双接入**：规则实现落 `frontend/scripts/check-module-isolation.mjs`（零依赖、纯函数 + CLI），fixture 拦截用例落宿主 `guard-module-isolation.spec.ts`（随 `desktop-check`），产物扫描由 CLI 在 `module-build` 执行 |

| 7 | 独立预览壳 | **豁免**（`src/standalone.ts` 与模块 `index.html`；非模块契约部分、不进远端产物） |

| 10 | 回写范围 | **全套**：规范 §16 + 模块契约 §2 / §5 / §7 + 架构 08 §9 + 审计资产清单 + 基类清单 §9 + 知识档案 |
| 11 | CI 接线 | **复用既有 job**：源码面随 `desktop-check`，产物面随 `module-build`（不新增 job） |
