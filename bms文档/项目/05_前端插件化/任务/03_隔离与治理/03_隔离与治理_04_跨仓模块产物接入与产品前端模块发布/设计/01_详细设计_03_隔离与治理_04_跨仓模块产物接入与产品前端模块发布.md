## 1. 设计目标与范围 <a id="goal"></a>

在 [02_01](../../../02_运行时加载/02_运行时加载_01_ModuleFederation接入与模块独立构建/02_运行时加载_01_ModuleFederation接入与模块独立构建.md)（模块独立工程与远端产物形态）、[03_01](../../03_隔离与治理_01_样式与运行时隔离/03_隔离与治理_01_样式与运行时隔离.md)（隔离护栏源码面 + 产物面）、[03_02](../../03_隔离与治理_02_模块清单与发布治理/03_隔离与治理_02_模块清单与发布治理.md)（清单为唯一来源 / 发布前强校验 / 回滚 / 留痕）之上，把模块产物来源由「**仓内**模块工程」扩为「**仓内 + 仓外**（产品独立仓库）」，使产品页面「经动态路由可见、无需平台前端发版」（《[平台可扩展性规划](../../../../../../规划/平台可扩展性规划.md)》R4.3）：

1. **产物来源参数化**——发布链路按**仓外模块工程目录**取数（容器入口产物 / 产物元数据 / sourcemap / 依赖声明 / 隔离与体积所需配置）；链路**不持跨仓凭据**，拉仓与构建由调用方、CI 或人工承担。
2. **跨仓与仓内同口径**——外部模块与仓内模块共用同一套发布前强校验（版本 / 隔离 / 共享 / sourcemap）与同一套清单登记、回滚、停用、启用流程。
3. **清单护栏两形态并存**——清单可同时含仓内条目与**跨仓条目**；护栏对无本地工程的跨仓条目按「发布时已校验」口径放行并在输出中**显式标注**（不伪装为已覆盖）。
4. **共享断言泛化**——产物级共享断言由「demo 单模块」口径泛化为**按在册仓内模块逐一断言**；跨仓模块的共享断言在发布时经同一强校验执行。
5. **前端包来源口径**——产品档案的「前端包来源」取值定稿为**产品前端工程标识**（仓库名 + 前端根，如 `mdm#frontend`；不含主机、凭据与访问地址），并按既定登记口径回填已接入产品。
6. **文档与口径回写**——模块接入指南补「跨仓接入」节；修正设计文档中「不做运行时远程加载」的滞后表述。

**不在本期**：生产 / mjbk 部署形态（产物上传、部署侧清单、静态托管 / CDN 基址替换——阶段五已定归**部署阶段**）、灰度 / 蓝绿进阶、产品前端工程本体（归产品仓库，如 mdm 需求 `01-4`）、`05-11` 显式上下文注入通道（另立项）。

### 1.1 现状与缺口 <a id="gap"></a>

```text
frontend/
├── apps/desktop/public/modules.json        # 清单（当前仅仓内模块条目）
├── modules/{demo,sample,slot-sample}/      # 仓内模块工程（dist = 远端产物）  ← 发布链路的唯一产物来源
├── releases/                               # 产物归档（按 名称/版本）+ 发布记录（JSON + Markdown）
└── scripts/
    ├── release-module.mjs                  # 发布 / 回滚 / 停用 / 启用（四关强校验；moduleDir 硬编码 modules/<name>）  ← 本期 +--module-dir
    ├── check-module-manifest.mjs           # 清单护栏（版本发现 / sourcemap / 契约用例齐备）  ← 本期 +跨仓条目口径
    ├── check-shared-deps.mjs               # 共享依赖产物级断言（DIST_DIRS 硬编码 apps/desktop/dist + modules/demo/dist）  ← 本期 泛化
    ├── check-shared-whitelist.mjs          # 共享白名单 / 版本 / 体积（遍历 modules/*）
    └── check-module-isolation.mjs          # 隔离扫描（源码面 + 产物面，遍历 modules/*）
```

缺口：① 发布链路的产物来源**硬编码** `frontend/modules/<name>/dist`（`release-module.mjs` 的 `checkReleaseGuards` / 归档 / 体积计量三处），仓外产物无从接入；② 隔离与共享白名单校验按 `frontend/modules/*` 遍历，**外部工程不在遍历面**；③ 产物级共享断言硬编码 `modules/demo/dist`（阶段五 §7 第 4 项同源遗留：新增模块不受产物级共享断言覆盖）；④ 清单护栏对无本地工程的条目会判「版本发现 / 契约用例缺失」失败，**跨仓条目与仓内条目无法共存**；⑤ 产品档案「前端包来源」列已建但值恒空，产品前端来自何处无登记；⑥ 设计文档仍写「MVP 只做构建期合并、不做运行时远程加载」，与已交付的运行时模块形态矛盾。

## 3. 接口 / 契约与边界 <a id="contract"></a>

### 3.1 产物来源参数化（`--module-dir`） <a id="module-dir"></a>

`release-module.mjs` 的各子命令统一接受 `--module-dir <目录>`：

| 子命令 | 是否需要 `--module-dir` | 说明 |
| --- | --- | --- |
| `publish` | 需要（跨仓时必填；缺省 `modules/<name>`） | 产物来源 = 该目录；四关强校验 / 归档源 / 体积计量全部按此目录 |
| `rollback` / `disable` / `enable` / `status` | 不需要 | 只读清单与已归档产物（归档已落平台 `releases/`），与产物原址无关 |

解析口径：

- 相对路径按**当前工作目录**解析（外部工程常位于 `frontend/` 之外）；绝对路径直接使用；
- 目录不存在、或缺少 `package.json` → 明确报错（不静默回落到仓内目录）；
- `publish` 结果与留痕打印实际使用的产物目录（人读），**发布记录文件不写路径**（见 3.4）。

### 3.2 外部（仓外）模块工程形态约束 <a id="external-shape"></a>

外部工程须与仓内模块工程**同形态**，否则发布链路拒绝：

| 项 | 要求 | 缺失后果 |
| --- | --- | --- |
| 容器入口产物 | `dist/remoteEntry.js` | 版本关失败 |
| 产物元数据 | `dist/module.meta.json`（名称 / 版本 / 契约版本） | 版本关失败 |
| sourcemap | `dist/remoteEntry.js.map` | sourcemap 关失败 |
| 依赖声明 | `package.json`（`name` / `version` / `dependencies`） | 共享白名单关无法执行，直接拒绝 |
| 体积与页面块提示 | `budget.json`（含 `pageChunkHints`） | 产物面隔离扫描无法识别模块页面块，拒绝 |
| 源码（可选） | `src/**` | 存在则跑源码面隔离扫描；不存在则跳过并在输出中提示（**只跑产物面**） |

- **共享依赖声明**仍取平台单一来源（`frontend/shared-dependencies.json`）；外部工程的构建配置须经同一读取入口取共享声明（`loadSharedDependencies({ role: 'remote' })`），否则共享关失败。
- 外部工程的**构建与拉取不在本链路职责内**：链路不调用 git、不持凭据、不写外部目录。

### 3.3 发布前强校验与归档（跨仓同口径） <a id="guards"></a>

`checkReleaseGuards` 增入参 `moduleDir`（缺省 `frontend/modules/<name>`），四关不变：

1. **版本关**：产物元数据名称 = 清单名、版本 = `package.json` 版本、契约版本 = 平台契约版本；
2. **隔离关**：源码面（模块工程 `src/**`，外部工程可缺）+ 产物面（CSS 全量 + 模块自有 JS 块）；
3. **共享关**：白名单 / 版本要求 / 非共享项体积阈值（作用于该模块工程）；
4. **sourcemap 关**：容器入口 sourcemap 存在。

归档口径不变：`releases/<名称>/<版本>/`（平台侧统一存储，回滚依赖其不可变），源为该模块目录的 `dist/` 全量。**版本不可变**与 `--force` 口径不变。

### 3.4 清单与留痕口径 <a id="manifest"></a>

- **清单结构不变**（名称 / 入口 / 版本 / 加载形态 / 可见性），跨仓条目不新增字段——「仓内 / 仓外」是**产物来源**属性，不是清单语义；对照关系由「发布记录 + 产品档案」承载。
- **发布记录**（`releases/release-log.json`，随仓库提交）新增 `source` 字段：`local`（仓内发布）/ `external`（跨仓发布）；**不记录目录 / 主机 / 凭据**（公开仓库红线）。历史记录缺该字段视为 `local`（向后兼容，读取方按缺省处理）。
- 回滚 / 停用 / 启用流程与留痕字段不变。

### 3.5 清单护栏：跨仓条目口径 <a id="manifest-guard"></a>

`check-module-manifest.mjs` 对每个清单条目的判定分两形态：

| 形态 | 判定 | 校验项 |
| --- | --- | --- |
| 仓内条目（`frontend/modules/<name>/` 存在） | `local` | 全量（入口形态 / 版本发现 / 产物元数据 / sourcemap / 契约用例齐备 / 留痕一致） |
| 跨仓条目（本地工程不存在 **且** `mode: remote`） | `external` | 仅清单契约（字段合法、入口匹配 `<基址>/<名称>/<版本>/remoteEntry.js` 且路径版本 = 条目版本）+ 留痕一致（发布记录最近一条版本 = 清单版本） |
| `mode: local` 但本地工程不存在 | 失败 | 构建期合并形态必须有本地入口表登记 |

- 输出增统计行：`仓内 N 项 / 跨仓 M 项（跨仓条目的版本发现与产物校验在发布时执行）`，并逐条列出跨仓条目名——**口径诚实，不伪装覆盖**。
- 跨仓条目的「版本发现 / sourcemap / 契约用例齐备」由**发布时强校验**承担（发布方在拥有产物的一侧执行），口径写入接入指南（3.8）。

### 3.6 产物级共享断言泛化 <a id="shared-deps"></a>

`check-shared-deps.mjs` 由「宿主 × demo」二元对改为「宿主 × **每个在册仓内模块**」：

- 遍历 `frontend/modules/*/dist`（含 `dist` 的模块工程）；宿主侧声明只解析一次，模块侧逐模块断言（原 5 条判据不变）；
- 失败信息带模块名（如 `模块 sample：共享面与单一来源不一致…`）；
- 某模块**无产物**时跳过并在输出中列名提示（不静默、不误判为通过）；
- **跨仓模块不在平台 CI 覆盖范围**（CI 只 clone 平台仓库）：其共享断言在发布时经同一强校验执行，此边界在输出与文档中写明。

### 3.7 「前端包来源」口径与回填 <a id="package-source"></a>

- **取值形态**：`{仓库名}#{前端根相对路径}`，例 `mdm#frontend`；**只记「从哪里取」**，不含主机、凭据、访问地址与协议（这些由部署环境配置注入，遵守公开文档红线）。
- **回填时点与责任方**：产品**首次发布前端模块时**由其接入方在平台产品档案回填（本任务按既定登记口径回填已接入产品 `mdm`，与「先注册后建」一致：产品档案先表达来源，产物随后接入）。
- **落点**：平台侧产品清单常量 `PRODUCT_CATALOG` 的 `mdm` 记录（`frontend_package_source="mdm#frontend"`）+ 表文件 `sys_product.md` 补口径说明；`ops/seed_module.py` 透传不变。
- **连带**：本地开发库 / 部署库需重跑 `ops.seed_module`，使库中值与清单一致（接库对账口径不变）。

## 4. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| `--module-dir` 指向目录不存在 / 缺 `package.json` | 明确报错并终止（不回落仓内目录） |
| 外部目录缺 `dist` / `remoteEntry.js` / `module.meta.json` / sourcemap | 对应关失败，列出缺失项与修复提示 |
| 外部工程 `package.json` 版本 ≠ 产物元数据版本 | 版本关失败（版本须单一来源） |
| 外部工程构建未开 sourcemap | sourcemap 关失败 |
| 外部工程缺 `budget.json`（`pageChunkHints`） | 隔离关失败（无法识别模块页面块） |
| 外部工程无 `src/` | 源码面跳过、产物面照跑，输出提示（不视为失败） |
| 清单含跨仓条目但平台 CI 无本地工程 | 护栏按 `external` 放行并标注（版本发现 / 产物校验在发布时执行） |
| 清单 `mode: local` 但无本地入口表 | 失败（构建期合并形态必须有本地工程） |
| 某仓内模块无产物 | 共享断言跳过该模块并列名提示（不静默） |
| 发布记录 `source` 字段缺失（历史记录） | 读取方按 `local` 处理（向后兼容） |
| 回填产品档案后未重播种 | 接库对账报「库中值与清单不一致」——按运维步骤重跑 `ops.seed_module` |
