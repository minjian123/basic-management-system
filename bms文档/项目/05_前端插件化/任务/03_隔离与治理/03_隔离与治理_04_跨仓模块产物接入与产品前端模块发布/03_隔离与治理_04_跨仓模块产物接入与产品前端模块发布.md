## 2. 任务内容 <a id="content"></a>

1. **产物来源参数化**：模块发布链路支持**仓外模块工程目录**（容器入口产物 / 产物元数据 / sourcemap / 依赖声明按该目录取数）；链路不持跨仓凭据，拉仓与构建由调用方、CI 或人工承担。
2. **跨仓与仓内同口径**：外部模块与仓内模块共用同一套发布前强校验（版本 / 隔离 / 共享 / sourcemap）与同一套清单登记、回滚、停用、启用流程，不开旁路。
3. **前端包来源口径**：产品档案「前端包来源」取值口径定稿为**产品前端工程标识**（仓库名 + 前端根，不含主机与凭据），并按既定产品档案登记口径回填已接入产品。
4. **共享断言泛化**：产物级共享断言由单模块口径泛化为**按在册模块逐一断言**（仓内模块全覆盖）；跨仓模块的共享断言在发布时经同一强校验执行。
5. **文档回写**：模块接入指南补**跨仓接入**一节；修正设计文档中「只做构建期合并、不做运行时远程加载」的滞后表述。

## 3. 完成标准 <a id="accept"></a>

以仓外模块工程目录跑通「发布前强校验 → 产物归档 → 清单登记 → 宿主加载」全流程并留痕；「前端包来源」取值口径与回填时点成文且已按口径登记；共享依赖产物级断言覆盖全部在册仓内模块；相关规范与设计文档口径与实现一致；前端检查（类型 / lint / 用例 / 构建）与模块脚本用例全绿。
