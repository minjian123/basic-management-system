## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段五需求域 02 的 2 条需求——[05-3 Module Federation 接入与模块独立构建](../../需求/02_需求_运行时加载.md#r05-3)、[05-4 依赖共享与版本偏斜治理](../../需求/02_需求_运行时加载.md#r05-4)，按「1 需求 = 1 子任务」拆 2 个子任务（`02_01` / `02_02`）。
- **端范围**：**仅 PC**（`frontend/apps/desktop` + 模块工程及其构建配置）；移动端不在本次范围。
- **本域性质**：把横向模块接入从「接口预留」推进到「运行时真实加载」——宿主经 Module Federation 消费独立构建的模块产物；模块产物独立构建、独立发布；`shared` 单例与版本偏斜检查固化。
- **公共前置**：阶段四宿主外壳与加载器（`10_01`）、模块契约与注册表基座（`10_02`）；本阶段 `01_01`（扩展点注册表）与 `01_02`（加载器运行时化与清单对接）。
- **依据**：《[架构设计 · 前端架构](../../../../设计/架构设计/08_架构设计_前端架构.md)》§9「运行时组合（微前端，Module Federation）」与治理表「依赖共享与版本偏斜」、《[架构设计 · 扩展点与插件化](../../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§7.2、《[架构设计 · 前端模块契约](../../../../设计/架构设计/35_架构设计_前端模块契约.md)》、知识档案《[微前端](../../../../资料/知识档案/微前端/01_微前端_总览.md)》。
- **不做**：依赖版本协商、隔离增强、按模块 SLO 等治理后补项（见需求「范围外」）。
- **执行序**：`02_01 Module Federation 接入与模块独立构建` → `02_02 依赖共享与版本偏斜治理`（见[计划](../../计划/01_计划_前端插件化.md)）。
