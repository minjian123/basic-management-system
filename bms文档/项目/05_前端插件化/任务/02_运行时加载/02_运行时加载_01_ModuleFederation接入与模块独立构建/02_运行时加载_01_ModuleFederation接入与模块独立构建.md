## 2. 任务内容 <a id="content"></a>

1. **Module Federation 接入**：宿主作为 host 消费远端模块（`remote` 声明与入口解析），模块作为 remote 暴露自身注册声明与页面。
2. **模块独立构建**：模块拥有自己的构建命令与产物目录，**不并入主应用产物**；模块产物单独归档。
3. **清单对接**：加载器按模块清单（名称 / 入口 / 版本）解析远端并加载；字段口径与 `01_02` 一致（不重复定义两套）。
4. **动态导入分包**：模块页面与重组件一律异步加载、独立分包，**不进首屏**；模块产物纳入体积预算计量口径（单独计量）。
5. **过渡形态共存**：构建期合并（平台自身页面与未迁移模块）与运行时加载共存，由清单配置区分并成文。
6. **演示验证**：提供演示 remote，宿主运行时加载并注册其路由（不进入生产菜单）。

## 3. 完成标准 <a id="accept"></a>

演示模块独立构建产出独立产物，宿主运行时加载成功（非构建期合并）；动态路由生效、挂载与卸载正常、卸载无残留；模块产物不进首屏且体积预算门禁通过（模块产物单独计量）；MF 配置与模块清单字段成文、加载器同接口复用；`vue-tsc`、ESLint、Vitest、构建与体积预算全通过。
