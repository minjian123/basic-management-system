## 2. 任务内容 <a id="content"></a>

1. **`shared` 单例声明**：框架级依赖（框架本体 / 路由 / 状态 / UI 组件库 / 核心包）在宿主与模块构建配置中声明为 `shared` 且 `singleton`，并声明 `requiredVersion`。
2. **版本来源与偏斜检查**：共享依赖版本取自依赖清单（单一来源）；模块声明版本与宿主不一致时按既定口径处置（告警 / 拒绝加载）并留痕。
3. **构建期验证**：生产构建验证宿主与模块产物**无重复实例**。
4. **CI 断言**：脚本 / 用例断言依赖实例数为 1，纳入门禁，失败即阻断。
5. **升级契约**：框架大版本升级视为跨团队契约，升级流程与兼容窗口成文。

## 3. 完成标准 <a id="accept"></a>

共享依赖声明（`singleton` + `requiredVersion`）成文且生效；生产构建无重复实例、CI 依赖实例数断言可执行并纳入门禁；版本不一致场景有明确处置与用例；升级契约（大版本协同升级流程与兼容窗口）成文。
