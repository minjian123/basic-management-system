## 2. 任务内容 <a id="content"></a>

把平台基座包 `@bms/core` / `@bms/ui-ep` 由「源码直出 + `0.0.0`」改造为「**构建产物 + 语义版本**」并纳入 **MF 共享域**，使依赖「模块级单例」的机制在真机形态下跨模块边界成立：

1. **包产物形态与版本**：两包新增构建（ESM 产物 + 类型），`package.json` 设 `version`（起于 `0.1.0`）、`exports` / `types` 指 `dist`；宿主与模块均经包解析消费，运行期请求可被 MF 探测。
2. **共享声明单一来源**：`frontend/shared-dependencies.json` 把两包自 `notShared` 迁入 `shared`（`singleton` + `requiredVersion`）；`shared-deps.mjs` 支持从产物包读版本；宿主为提供方、模块为消费方（不打包本地副本、版本不满足即拒绝）。
3. **单例机制真机验收**：显式上下文注入（`useModuleSlotField` / `registerSubmitter`）、注册表、模块 `api` 注入、`moduleI18n` / 主题令牌四类各 1 例；**以阶段七 RBAC `02_02/_01` 的「插件草稿随宿主保存」链路为端到端验收场景**（mdm 岗位 / 部门插件应取到 `userId`）。
4. **体积与首屏实测**（复刻父任务实测方法，含 `eager` 取舍与结论登记），必要时设阈值与回退口径。
5. **门禁扩展**：构建期产物断言（无副本 / 实例数 = 1）与运行期共享域条目数断言覆盖两包；白名单 / 模块隔离护栏口径同步。
