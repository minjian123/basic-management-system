## 1. 域说明 <a id="intro"></a>

本域是阶段五的**验收样例**：用一个真实形态的页面把「扩展点注册 → 独立构建 → 运行时加载 → 独立发布 / 回滚」整条链路跑通，并沉淀为后续业务页面的接入范式。架构口径为「**新业务页面按模块形态独立构建与发布**（首个业务页面即首个模块样例），平台自身页面仍在主应用内」。

- **本域范围**：首个模块样例的开发与独立发布，以及接入指南沉淀。
- **前置**：`05-1` ~ `05-7` 具备（注册表齐全、加载器运行时化、MF 接入、依赖共享、隔离约束、清单与回滚、兜底与归因）。
- **依据**：《[架构设计 · 前端架构](../../../设计/架构设计/08_架构设计_前端架构.md)》§9「新业务页面按模块形态独立构建与发布」、《[架构设计 · 前端组件体系](../../../设计/架构设计/05_架构设计_前端组件体系.md)》§7、《[总体项目规划](../../../规划/总体项目规划.md)》阶段五完成标准、《[项目规划说明](../../../规划/项目规划说明.md)》「平台扩展接入流程」节。
- **用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随任务实施登记）。

## 2. 需求 05-8：首个模块样例（首个业务页面按模块形态独立发布） <a id="r05-8"></a>

优先级：2（高）

**背景与动机**：阶段五的完成判定不是「机制就位」而是「**真的有一个页面按模块形态独立发布并跑起来**」——机制若没有样例验证，很可能停留在配置正确、实际不可用的状态；同时后续大量业务页面需要一个可照抄的范式（目录结构 / 注册声明 / 构建配置 / 依赖声明 / 发布与回滚），本需求即产出该范式。

**内容**（架构 08 §9；架构 05 §7）：

1. **样例模块开发**：以真实形态开发首个模块样例——具备真实页面要素（查询筛选 + 列表 + 详情 / 表单，复用阶段四组件库、契约套件与设计令牌），页面数据可走占位通路（真实接口随后续窗口联调），但**页面本身走完整模块形态**（注册声明 + 独立构建 + 独立产物）。
2. **注册与接入**：模块经统一注册通道声明路由 / 菜单 / 页面区域（必要时含组件、图标、工作台卡片、主题令牌）等扩展点；路径前缀与命名空间遵循 `05-1` 口径。
3. **独立构建与发布**：模块独立构建产出独立产物，经 `05-6` 的清单注册发布；**回滚按清单版本回退**可执行。
4. **运行时加载验证**：宿主运行时加载样例模块——动态路由生效、菜单联动、挂载与卸载正常、失败兜底生效、shared 依赖单实例。
5. **接入指南沉淀**：输出「业务页面按模块形态接入」指南（目录结构、注册声明样例、构建与依赖声明、发布与回滚步骤、自检清单），作为后续产品模块的标准范式。
6. **样例落点（已定）**：**平台内样例模块**——在平台 `frontend/` 下以模块形态建一个真实形态样例页（示例模块升级为真实形态）；阶段五不依赖产品仓与后端接口即可闭环，后续 biz 业务页面照此范式接入（biz 首个业务页面随产品仓库排期，不在本阶段验收内）。

**完成标准**：
1. 样例模块**独立构建产出独立产物**，经清单发布并可**回滚**；
2. 宿主**运行时加载**样例模块：动态路由生效、菜单联动、挂载与卸载无残留；
3. 样例复用阶段四组件库与设计令牌（不重复造件、不硬编码色值）；
4. shared 依赖单实例、模块产物不进首屏、失败兜底生效；
5. 接入指南成文，可直接作为后续业务页面范式；
6. `vue-tsc`、ESLint、Vitest、构建与体积预算、模块契约测试全通过。
