- **阶段四已交付基础（本阶段在其上运行时化，不重复建设）**：宿主外壳薄壳与模块加载器接口（本地演示模块）、模块契约（宿主注入上下文 / 模块注册声明 / 样式约束）、统一注册表基座与注册项契约、**五类注册表最小实现**（路由·菜单 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片）、模块边界兜底件（见阶段四需求 `10-1` / `10-2`）。
- **范围外（随后续阶段或演进路线）**：模块治理增强项（依赖版本协商、灰度 / 蓝绿进阶、隔离增强 `Shadow DOM` / JS 沙箱、按模块 SLO 与告警阈值）；移动端宿主与模块（`frontend/apps/mobile` / `ui-vant`，随阶段十七）；平台自身页面迁移为模块（保留构建期合并过渡形态）。

## 2. 阶段五目标与范围 <a id="goal"></a>

**阶段目标**（《总体项目规划》「阶段内容与完成标准」节）：**八类扩展点注册表与模块清单可用；宿主运行时加载模块（动态路由生效、产物独立构建、`shared` 依赖单实例）；新业务页面按模块形态独立发布（首个页面为样例）**。

**范围内**（共 14 条需求，含 2026-10-03 回补 `05-10`、2026-10-06 回补 `05-11`、2026-10-08 回补 `05-12` / `05-13`、2026-10-09 回补 `05-14`，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 01 扩展点与装配 | 八类扩展点注册表补齐（含页面区域、主题令牌）与统一装配；宿主加载器由「本地演示模块」升级为「按模块清单加载」，模块契约同接口接远端 |
| 02 运行时加载 | Module Federation 接入（宿主 remote 消费 / 模块 remote 暴露）与构建配置、模块独立构建产物与动态导入分包；`shared` 依赖单例声明与版本偏斜治理 |
| 03 隔离与治理 | 样式与运行时隔离（Scoped / 令牌 / 前缀 / 不污染全局）与隔离增强评估；模块清单与发布治理（版本发现 / 回滚 / 契约测试 / 产物发布）；可观测与失败兜底（超时 / 按模块归因 / sourcemap）；跨仓模块产物接入与产品前端模块发布（R4.3，产品按独立仓库发布） |
| 04 首个模块样例 | 首个业务页面按模块形态开发并独立构建发布，经宿主运行时加载（验收样例） |
| 05 阶段验收 | 验收门禁核对、阶段测试报告与证据索引、状态收口与遗留归口 |
| 06 具名插槽与插件挂接（回补） | 具名插槽基座与前后端配套插件、插件缺失降级、平台内样例插件（2026-10-03 追加）；模块请求能力产品寻址（2026-10-08 追加） |

**范围外**：见第 1 节「范围外」。

>
> **回补说明（2026-10-06）**：`05-11` 为阶段七角色管理（`07-3`）「角色分配」页签驱动追加的**基座补充需求**——现行上下文仅支持「路由参数」，非路由页面（表单框架记录 Tab）的插件无通道取实体 id；落地「显式上下文注入通道」。**2026-10-08 建任务 `06_03` 并交付**（含角色分配页签留槽与角色标识注入；阶段七 `01_01` 的降级登记同步回写）。
>
> **回补说明（2026-10-08）**：`05-12` 为 **mdm 产品接入**驱动追加的**基座补充需求**——产品前端模块按独立仓库构建发布（《平台可扩展性规划》R4.3），现行发布 / 校验链路只认仓内模块工程，且产品档案「前端包来源」为空；mdm 组织域页面与插件（mdm 需求 `01-4`）被此阻塞；任务与计划随启动补建。
>
> **回补说明（2026-10-08）**：`05-13` 为 **mdm 产品接入**驱动追加的**基座补充需求**——产品服务只经产品命名空间 `/api/{产品键}/v1/{域}/...` 对外，而寻址契约只组装平台服务前缀、模块又被禁止自拼前缀与自建 HTTP，产品前端模块因此取不到数；落地「模块请求能力产品寻址」（与 `05-12` 同批阻塞解除，mdm 需求 `01-4` 为消费方）；任务与计划随启动补建。
