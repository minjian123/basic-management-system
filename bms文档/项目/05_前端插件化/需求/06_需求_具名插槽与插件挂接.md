## 1. 域说明 <a id="intro"></a>

本域为阶段五（前端插件化）**回补需求域**（2026-10-03 追加）：在阶段五已交付的**页面区域扩展点与注册表**（`05-1` 八类注册表之一）与**区域插槽件 / `useModuleArea` 投影**（`01_02` 消费接线）之上，把「页面区域」**细化为可运营的具名插槽机制**——宿主页面留**具名插槽**、插件以**前端模块 + 后端契约成套**挂接、数据与写操作归插件提供方；落地平台内**样例插件**验证端到端。

- **对应 WBS 域**：阶段五「扩展点 + 注册表」（架构 08 §9）与「具名插槽与前后端配套插件化」（架构 10 §9）。
- **覆盖范围**：具名插槽注册与命名约定、插槽区域渲染与降级、插件前后端配套契约约定、平台内样例插件；不含具体业务插件（mdm 组织域「用户分配岗位」插件归 mdm 产品仓库）。
- **不重复建设**：插槽注册表**复用**阶段五已交付的页面区域注册表（基于统一注册表基座）；本域只补**具名插槽语义 + 降级 + 前后端配套约定 + 样例**，不改注册表基座与既有八类注册表。
- **依据**：《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§8.2 / §9「具名插槽与前后端配套插件化」、《[架构设计 · 前端架构](../../../设计/架构设计/08_架构设计_前端架构.md)》§9、《[架构设计 · 前端模块契约](../../../设计/架构设计/35_架构设计_前端模块契约.md)》、《[前端基类清单](../../../前端基类清单.md)》、《[前端开发规范](../../../规范/前端开发规范.md)》、《[需求文档规范](../../../规范/需求文档规范.md)》。
- **用例口径**：本域用例入 Kiwi TCMS，自动化用例标注用例编号（随实施登记）。

## 2. 需求 05-10：具名插槽基座功能与前后端配套插件（含样例） <a id="r05-10"></a>

优先级：2（高）

**背景与动机**：阶段五交付的「页面区域」只到「布局 / 插槽区域挂接」的笼统能力，未定义**稳定的具名插槽命名**、**多插件同槽**、**插件缺失时的降级**，也未明确**前后端配套**（谁拥有数据谁提供插件）。当主数据迁出为独立产品（mdm 组织域承载部门/岗位/用户-岗位关联）后，bms 用户管理页需要把「用户分配岗位」这类**数据不归 bms 的功能**挂接进来：若宿主页硬编码依赖该插件或该插件后端，则 bms 单独运行（无 mdm）会因缺实体而报错；若每个宿主页各写一套挂接，机制无法复用。故须把「具名插槽 + 前后端配套插件」落为**平台基座能力**，使插件**随插随用、缺失即降级隐藏**，并可推广到字典主数据、业务表单等一切「数据归某服务、界面挂另一页」的场景。

**内容**（《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§9「具名插槽与前后端配套插件化」、《[前端开发规范](../../../规范/前端开发规范.md)》「具名插槽与插件挂接」条）：

1. **具名插槽机制**：宿主页面以**稳定命名**的插槽声明挂接点（命名 `{域}.{页面}.{区域}`，首个落地 `sys.user.detail.tabs`）；插槽经**页面区域注册表**（阶段五已交付）登记与解析，**不新造注册表**；同一插槽支持**多插件**（多 Tab / 多动作）、可排序、按权限显隐。
2. **插槽区域渲染件与消费**：宿主页经区域插槽件渲染已登记项；插槽项声明携带来源（平台 / 模块名），随模块**挂载生效、卸载还原**（复用阶段五消费接线口径）；宿主页**不得硬编码依赖具体插件**。
3. **降级与失败兜底**：插件**未注册 / 未启用 / 提供方不可达**时，该插槽项**不渲染**（插槽为空），**不报错、不阻塞宿主页其余部分**；加载失败按阶段五失败兜底口径处置（错误边界兜底 + 按模块归因）。
4. **前后端配套插件约定**：明确「**数据归属方提供插件**」——插件 = **前端模块**（界面，注册为该插槽区域项，只经宿主注入 `api` 能力发请求）+ **后端契约**（取数与增删改查触发接口，插件提供方公开契约）；约定插件的**注册声明字段**（插槽键 / 次序 / 权限码 / 显示条件）与**后端契约路径 / 权限码归属**；跨服务调用走服务间契约或 `/api/open`。
5. **平台内样例插件**：新建一个**平台内样例插件**（例：给 `sys.user.detail.tabs` 挂一个「用户扩展示例」Tab，自带一件最小后端能力——读列表 + 一次写操作），真跑通「宿主留槽 → 插件注册 → 挂载渲染 → 写操作 → 卸载还原 → 移除插件后隐藏」全链路；样例落**平台内样例模块**（与阶段五 `05-8` 样例同口径），**不进入生产业务菜单**。
6. **契约与文档化**：以《[架构设计 · 前端模块契约](../../../设计/架构设计/35_架构设计_前端模块契约.md)》与架构 10 §9 为上位依据，成文具名插槽注册声明字段、命名规则、冲突处置与降级口径；插件接入指南落知识档案（复用阶段五接入指南口径）。
7. **护栏**：机器护栏断言「宿主页不得直接 import 具体插件」「插槽项未登记不渲染」「插件移除后无残留注册项 / 无残留路由」；`vue-tsc`、ESLint、Vitest 全通过。

**完成标准**：
1. 具名插槽（至少 `sys.user.detail.tabs`）可挂多插件、可排序、按权限显隐；宿主页与插件无直接依赖；
2. 插件缺失 / 不可达时插槽项隐藏、宿主页其余正常（含用例）；插件挂载与卸载无残留；
3. 前后端配套约定成文（注册声明字段 / 后端契约路径与权限码归属），样例插件按约定实现；
4. 平台内样例插件真跑通「留槽 → 注册 → 渲染 → 写操作 → 卸载还原 → 移除隐藏」全链路（不进入生产菜单）；
5. 护栏含「宿主不直连插件」「未登记不渲染」「卸载无残留」断言；
6. `vue-tsc`、ESLint、Vitest 全通过。

**参考文档**：《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§8.2 / §9、《[架构设计 · 前端架构](../../../设计/架构设计/08_架构设计_前端架构.md)》§9、《[架构设计 · 前端模块契约](../../../设计/架构设计/35_架构设计_前端模块契约.md)》、《[前端基类清单](../../../前端基类清单.md)》、《[前端开发规范](../../../规范/前端开发规范.md)》「具名插槽与插件挂接」条；参考实现：mdm《概要设计 · 岗位管理》「用户分配岗位插件」（mdm 组织域提供，消费方）

## 3. 需求 05-11：具名插槽显式上下文注入通道（补充 · 2026-10-06） <a id="r05-11"></a>

优先级：2（高）

**背景与动机**：现行具名插槽的宿主上下文仅支持「作用实体标识放**路由参数**、插件经注入 `router` 只读读取」（`sys.user.detail.tabs` 范式）。但角色表单页的「角色分配」页签是**表单框架的记录 Tab**（非独立路由、无 `:id` 路由参数），mdm「岗位分配 / 部门分配」插件无法经路由参数取到当前角色 id，遂无法读写。为支持「非路由承载页面」的插件上下文，须补一条**显式上下文注入通道**。

**内容**（承 `05-10` 机制，不新造注册表）：

1. **显式上下文注入**：宿主页在放置具名插槽时，可声明**上下文对象**（如角色 id / 业务实体标识）；区域项组件经注入通道以**只读**方式取得，**不新增宿主与插件的直接依赖**。
2. **降级**：上下文字段以 `undefined` 呈现时，插件**自行降级**（不假定存在、不发起请求）；缺上下文不阻塞宿主页其余部分。
3. **与路由通道并存**：既有「路由参数」通道保留；插件可消费两通道之一或并存。
4. **契约与护栏**：通道按**向后兼容新增**或契约版本升级承载（按实现影响面定），沿统一注册与契约测试；护栏断言「未注入上下文不渲染 / 不请求」「宿主不直连插件」。

**完成标准**：宿主页可经具名插槽向区域项注入非路由上下文；插件只读取得并在缺失时降级；既有 `sys.user.detail.tabs`（路由参数）不受影响；用例与护栏齐备；`vue-tsc` / ESLint / Vitest 全通过。

**参考文档**：《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§9、《[架构设计 · 前端模块契约](../../../设计/架构设计/35_架构设计_前端模块契约.md)》「模块声明与注册」节、《[组件设计 · 模块区域插槽](../../../设计/组件设计/03_布局组件类/12_组件设计_模块区域插槽/12_组件设计_模块区域插槽.md)》、[阶段五任务 06_01](../任务/06_具名插槽与插件挂接/06_具名插槽与插件挂接_01_具名插槽基座功能与前后端配套插件/06_具名插槽与插件挂接_01_具名插槽基座功能与前后端配套插件.md)（已交付实现）；消费方：阶段七角色管理（`07-3`）「角色分配」页签的 mdm 岗位/部门分配插件。
