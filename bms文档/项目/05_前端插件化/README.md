## 启动时需求提出清单 <a id="intake"></a>

阶段启动建需求基线时，以下事项须逐条转为需求（出处见括注；「阶段五先行 / 治理后补」的节奏见知识档案《[微前端 · 06 项目评估](../../资料/知识档案/微前端/06_微前端_项目评估.md)》与[架构设计 · 前端架构](../../设计/架构设计/08_架构设计_前端架构.md)「模块治理要求」表）：

| # | 需求事项 | 出处 |
| --- | --- | --- |
| 1 | 前端骨架与契约：宿主薄壳（布局 / 路由 / 模块加载器）、模块契约（宿主注入上下文 / 模块注册声明）、设计令牌与组件契约可被模块复用（阶段四并行） | 架构 08 §9；《项目规划说明》阶段四 / 五 |
| 2 | 运行时加载：Module Federation 接入、模块清单（名称 / 入口 / 版本）与加载器、`shared` 依赖 singleton 基础配置、构建期合并过渡形态 | 架构 08 §9、10 §6 |
| 3 | 样式与运行时隔离：Scoped / 令牌约定与全局污染约束先行；Shadow DOM / JS 沙箱评估后补 | 架构 08 §9 |
| 4 | 依赖共享与版本偏斜治理：`shared` 声明与 `requiredVersion`、双端 CI 依赖实例数断言、升级契约 | 架构 08 §9、32 §8 |
| 5 | 模块清单与发布治理：版本发现、灰度 / 蓝绿、回滚（清单版本回退）、模块契约测试、模块产物发布与回滚流程 | 架构 08 §9、33 §9、32 §8 |
| 6 | 可观测与失败兜底：加载失败兜底与超时、按模块归因（错误 / 性能 / 体积）、Web Vitals 按模块、sourcemap 映射 | 架构 08 §9、27 指标与告警 |
| 7 | 首个模块样例：首个业务页面按模块形态开发（样例），验收宿主加载 / 动态路由 / 独立发布 | 《项目规划说明》阶段五；架构 05 §7 |
