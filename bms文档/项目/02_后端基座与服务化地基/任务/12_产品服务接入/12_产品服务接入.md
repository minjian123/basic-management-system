## 1. 域说明 <a id="intro"></a>

本域对应阶段二「产品服务接入」：平台支持**产品服务注册与接入**（R4.1 / R4.2）——产品以独立服务形态部署（每服务独立库），经 OIDC + `/api/open` + 事件与平台集成；共享基座库支持**产品服务装配**；产品表归属、服务包模型解析与产品权限码种子随产品实际落表补充。本域**解除 mdm 产品实施的阻塞**（mdm 需求 `01-1` 依赖本域，`01-2` 依赖 12_04）。依据《[平台可扩展性规划](../../../../规划/平台可扩展性规划.md)》R4.1 / R4.2 节与《[微服务演进规划](../../../../规划/微服务演进规划.md)》「服务化地基要求与门禁」节；对应需求域十二（12-1 ~ 12-4）。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：`12_02` 依赖 `12_01`（先注册后接入）；`12_03` 支撑产品服务装配，`12_01` / `12_02` 与 `12_03` 协同（见各子任务「任务信息」表「依赖」行）。
- **解锁对象**：本域为 **mdm 产品实施**（mdm 需求 `01-1`）的前置（跨仓）。
- **风险**：产品接入面扩大（`/api/open` / 事件 / 网关 / 独立库）牵动安全与隔离；以接入验收（注册唯一性 / 契约测试 / 权限审计复用 / 数据隔离）与运行期配额管控收敛（详见[计划文档](../../计划/01_计划_后端基座与服务化地基.md)「风险与对策」节）。
