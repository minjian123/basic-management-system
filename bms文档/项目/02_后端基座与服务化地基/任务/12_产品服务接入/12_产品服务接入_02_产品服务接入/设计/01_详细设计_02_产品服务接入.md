## 1. 设计目标与范围 <a id="goal"></a>

承接需求 12-2：落**产品服务接入机制与接入骨架**——平台侧提供服务目录与契约 / 版本登记、认证（OIDC）、开放接口（`/api/open`）、事件接入、网关路由与独立库对接，并给出接入验收判据。真实产品（mdm）联调随产品接入推进。

1. **服务目录与契约 / 版本登记**：产品服务经 `sys_module` 登记（服务标识 / 契约版本），公开契约纳入契约快照与门禁。
2. **认证接入**：产品服务经平台 OIDC 校验（用户 JWT `aud=api` / 服务 JWT `aud=service`，平台 JWKS）；服务间经服务身份（`require_service`）。
3. **开放接口**：`/api/open`（OAuth2 Client Credentials）+ `sys_client` 注册要素（client 凭据 / scope / IP 白名单 / 调用日志）。
4. **事件接入**：产品注册事件域，经平台事件总线发布 / 订阅；事件契约登记与校验。
5. **网关路由**：产品服务经平台网关暴露（**产品命名空间**），独立库（每服务独立库 × 每租户）。
6. **接入骨架**：`sys_client` 注册要素 / 最小 scope 集合 / 必供项（健康检查 / 审计 / 事件订阅）/ 平台版本兼容承诺清单 + 接入验收判据。

**不在本期**：真实产品（mdm）完整联调（随产品接入）；产品注册表（归 12_01）；共享基座装配支持（归 12_03）。

## 3. 接入机制设计 <a id="mechanism"></a>

| 面 | 设计 | 依据 |
| --- | --- | --- |
| 服务目录登记 | 产品服务登记服务标识（`service_key`）、模块标识、注册要素、契约版本；纳入 `SERVICE_CATALOG` 对账 | 架构 11「服务目录与契约登记」节 |
| 契约 / 版本 | 产品公开契约（OpenAPI）纳入契约快照与 oasdiff 门禁；`contract_version` 主版本兼容校验（产品自报 ↔ 平台登记） | 架构 09 / 37；《微服务演进规划》S1 |
| 认证 | 平台 OIDC（Keycloak）统一签发；产品服务经平台 JWKS 校验**用户 JWT（`aud=api`）**与**服务 JWT（`aud=service`）**；服务间入站经 `require_service` 白名单 | 架构 14；《微服务演进规划》S4 |
| 开放接口 | `/api/open`（OAuth2 Client Credentials）；`sys_client` 登记 client 凭据、**最小 scope 集合**、IP 白名单、调用日志 | 架构 09「独立服务接入骨架」节；《项目规划说明》「开放接口管理」 |
| 事件 | 产品注册事件域（`known_event_domains`），经平台事件总线发布 / 订阅；事件契约登记 + 快照零漂移 | 架构 16；《后端开发规范》事件契约条 |
| 网关 | 产品服务经网关暴露，**产品命名空间**（如 `/api/mdm/v1/...`）；路由按产品 / 域前缀转发到对应产品服务 | 架构 36；《微服务演进规划》 |
| 独立库 | 产品服务每服务独立库（× 每租户）；不共享库、不跨库 JOIN | 《微服务演进规划》S2 |

## 4. 接入骨架（必供项与验收判据） <a id="skeleton"></a>

| 项 | 内容 |
| --- | --- |
| `sys_client` 注册要素 | client 标识 / 凭据、最小 scope 集合、IP 白名单（第三方 / 外部系统经 `/api/open`） |
| 必供项 | 健康检查（`/healthz` / `/readyz`）、审计接入、事件订阅声明 |
| 版本兼容承诺 | 平台能力接口与注册要素按契约管理；破坏性变更提前公告 + 过渡期（见《平台可扩展性规划》5.5） |
| **接入验收（五项）** | ① 注册唯一性（前缀 / 错误码段 / 事件域）② 契约测试通过 ③ 权限与审计复用 ④ 前端模块可加载（R4.3 / 前端阶段）⑤ 数据隔离（租户 / 数据范围） |

## 5. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 产品服务未登记 / 契约主版本不兼容 | 启动校验拒绝 / CI 不通过 |
| 产品服务不可达 | 消费方按契约超时 / 熔断降级（不拖垮平台） |
| scope / IP 不在允许范围 | 开放接口拒绝（403 / 401） |
| 事件未注册域 / 未登记契约 | 发布拒绝（`10010`） |
| 路由 / 独立库缺失 | 网关校验失败 / 建库迁移失败即拒 |
