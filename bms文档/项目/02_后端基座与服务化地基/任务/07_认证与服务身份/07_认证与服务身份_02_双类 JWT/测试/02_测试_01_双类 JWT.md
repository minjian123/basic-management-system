**mjbk 真实冒烟**（Keycloak 26.7.4，realm `bms`，issuer `http://<mjbk-IP>:8090/realms/bms`）：

| 场景 | 操作 | 观察结果 |

| 用户令牌受众 | `client_credentials` 取令牌 → 解码载荷 | `aud: ["api","account"]`（补挂前仅 `account`）；`iss` 与基址一致 |

| `aud` 隔离 | 同一用户令牌以 `audience="service"` 校验 | 被拒（`AuthError` 20001） |
| 服务 JWT 自签验签 | 本地签发 → `token_verifier`（`audience="service"`） | 通过；`service=platform` / `tenant=demo` / `scopes=(user:read,)` |
| JWKS 端点 | identity 服务（`BMS_SERVICE_TOKEN__KEYS` 注入）→ `curl /.well-known/jwks.json` | `200`；返回公钥 `kid=k1` / `alg=RS256` / `use=sig`，无私有参数 |
| 清理 | 无（Keycloak 为常驻身份源，保留运行；本地 identity 冒烟进程已停） | 部署件与仓库声明式文件一致 |

## 4. 问题与处置 <a id="issues"></a>

| 问题 | 原因 / 处置 |
| --- | --- |
| 首次冒烟 realm 令牌 `aud` 仅 `account` | `--import-realm` 对既有 realm 跳过；经 Admin REST API 补挂 `aud-api` mapper 后即含 `api`；重导入口径回写《Keycloak 部署使用说明》 |
| 测试密钥 PEM 类型与注入 | joserfc `as_pem()` 缺省公钥、`monkeypatch.setenv` 要求 `str`；统一 `as_pem(private=True).decode()` |
| 环境变量注入键位 | list-of-model 键位解析异常；改 `kid → 密钥映射`，键位与 JSON 两种注入均验证通过 |

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：`[service_token].keys` 落地为 `kid → 密钥映射`（支持按键位环境变量私钥注入）；出站换券开关 `attach_service_token` 缺省关（dev 关、prod 开）——均已登记实施记录 §7。
- **遗留（归口）**：网关 `openid-connect` 接线与服务 JWT 入站校验 → **07_03**；完整登录链路 / 用户 JWT 租户 claims 映射 / JIT 建号 → **阶段六**；OAuth2 token 端点与 `oauth_server` 真实实现 → **阶段十**；出站令牌缓存与 Vault/KMS、生产 TLS → **性能 / 运维 / 部署阶段**。
- 用例编号以平台回读（**2180**）为准，代码 `@pytest.mark.kiwi_id(2180)` 标注一致（`test_service_token.py` / `test_token_verifier.py` / `test_wellknown_jwks.py` / `test_servicecall.py`）。
