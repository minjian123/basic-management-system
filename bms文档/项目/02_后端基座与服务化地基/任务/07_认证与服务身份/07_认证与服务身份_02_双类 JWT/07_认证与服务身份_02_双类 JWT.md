## 2. 任务内容 <a id="content"></a>

1. 用户 JWT（aud=api）与服务 JWT（aud=service，短时 + scope + 服务标识）
2. RS256 / ES256 签名与 JWKS 分发、校验 exp / iss / aud
3. aud 隔离（用户 token 调内部服务被拒）、外部 token 不透传

## 3. 完成标准 <a id="accept"></a>

双类 JWT 可签发与校验；aud 区分生效；密钥轮换可并行验证；pytest / ruff / pyright 全绿。
