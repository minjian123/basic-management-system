## 4. mjbk 真实冒烟记录 <a id="smoke"></a>

**环境**：mjbk Docker（APISIX `apache/apisix:3.18.0-debian`、Keycloak 26.7.4 realm `bms`）；identity 认证服务经开发机承载并在 mjbk `~/deploy/.env` 设 `GATEWAY_AUTH_HOST=<dev-ip>`（临时 ufw 放行 mjbk→开发机 8000，冒烟后删除；`~/deploy/.env` 已还原 `identity`）。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 认证服务 JWKS | `GET /.well-known/jwks.json` | 200，公钥 `kid=k1 / alg=RS256` |
| 用户令牌校验（内部） | Keycloak `client_credentials` 令牌（`aud=["api","account"]`）→ `GET /api/v1/auth/introspect` | 200；`X-User-Subject`=真实 `sub`、`X-User-Scopes=profile,email`、`Authorization`=网关服务 JWT（`iss=bms` / `sub=gateway` / `aud=service`） |
| 受保护路径无凭证（经网关） | `GET /api/platform/v1/ping`（无 token） | **401** |
| 公开路径无凭证（经网关） | `GET /api/identity/v1/auth/login` | **200** |
| 受保护路径带令牌 + 伪造头（经网关） | 带 `Authorization` 与 `X-User-Subject: forged` / `X-User-Id: 999` / `X-Gateway-Identity: forged` 到 whoami 上游 | 上游 `Authorization`=网关服务 JWT（用户 token 被覆盖、不透传）、`X-User-Subject`=真实 sub、`X-User-Scopes=profile,email`、`X-Gateway-Identity=bms-edge`；伪造 `X-User-Id` / 伪造主体被剥除 |
| 网关服务 JWT 验签 | identity 公钥验签上游收到的 `Authorization` | 通过（`iss=bms` / `sub=gateway` / `aud=service` / `typ=service`） |
| 限流维度 | 请求后查共享 Redis 限流键 | 键含 `X-User-Subject`（用户维度生效）；响应带 `X-RateLimit-Limit/Remaining/Reset` |
| 清理 | 删除临时 whoami 容器、还原 `GATEWAY_AUTH_HOST=identity`、删除 ufw 规则、清空限流键、停止本地 identity 服务 | 无残留 |

> 后端「只信服务 JWT / 旁路拒绝」由 `ServiceJwtEdgeTrust` 单元用例覆盖（真实令牌同源）；端到端后端信任证据待服务容器化后随编排验证。

## 5. 缺陷与偏差 <a id="defects"></a>

| # | 类型 | 说明 | 处置 |
| --- | --- | --- | --- |
| 1 | 设计偏差 | 网关认证由 `openid-connect` 改 `forward-auth`（APISIX 无 `$jwt_claim_*`） | 已逐项确认并回写设计（决策 #1）与 04_02 开放项 |
| 2 | 设计偏差 | 限流用户维度取 `X-User-Subject`（`X-User-Id` 待阶段六） | 已回写设计（决策 #11） |
| 3 | 冒烟环境 | 服务未容器化，identity 经开发机承载 + 临时放行 | 已记录；服务容器化后随编排复验（归口部署 / 运维） |
| 4 | 开放项 | 认证端点独立鉴权、票据 / 服务 JWT 缓存优化 | 归口 K8s / 运维与性能阶段 |

## 6. 遗留与归口 <a id="leftover"></a>

- **阶段六**：完整登录链路、用户 JWT 租户等 claims 映射、`X-User-Id` 内部数字 id 填充、JIT 建号。
- **阶段七**：RBAC 权限码细粒度校验（`require_permission`）。
- **K8s / 运维阶段**：认证端点独立鉴权 / mTLS、`forward-auth` 平移 ext_authz、Linkerd 自动 mTLS。
- **性能阶段**：票据校验与服务 JWT 缓存优化。
- **阶段十**：OAuth2 token 端点与 `oauth_server` 真实实现。
