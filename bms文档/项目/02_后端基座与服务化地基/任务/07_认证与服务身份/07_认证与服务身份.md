## 1. 域说明 <a id="intro"></a>

本域对应阶段二「认证与服务身份」：由网关统一认证，认证地基服务提供用户认证与令牌；新增双类 JWT（用户 / 服务）与服务身份校验。完整认证业务随阶段六 / 七。依据《架构设计 · 认证与会话》《架构设计 · API 网关与边缘》；对应需求域七（07-1 ~ 07-3）。
