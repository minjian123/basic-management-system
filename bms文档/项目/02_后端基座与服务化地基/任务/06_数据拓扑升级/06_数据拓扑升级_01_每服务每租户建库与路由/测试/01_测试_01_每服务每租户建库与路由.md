## 2. 测试范围与层次 <a id="scope"></a>

1. **库键内核**（`bms_core/db/keys.py`）：键形态常量、派生与反解（相对 / 全限定 / 首段命中已知服务标识的歧义消解）、库名派生与形态校验、归属校验（越界 10008 / 未登记服务 / 运维豁免）。
2. **引擎与注册表服务化**（`db/engine.py` / `db/registry.py`）：平台与租户目标同构模板解析、空模板回落、模板需服务标识而缺失的快速失败、双入口越界拒绝、平台类键不参与租户 LRU / 闲置回收。
3. **拓扑与路由**（`db/session.py` / `db/bootstrap.py` / `tests/db/test_tenant_routing.py`）：请求级会话按租户相对键路由到本服务租户库、平台库只读会话、开发自动建表逐 `dev_tenants` 服务化落库、跨租户物理隔离。
4. **按服务 × 租户建库**（`ops/provision_tenant.py`）：服务集筛选（enabled / 显式 / 未登记拒绝）、平台与租户库矩阵、幂等、干跑、租户来源（`--code` / `--all-tenants`）、缺维度失败。
5. **启动接库校验与降级**（`bms_core/catalog/loader.py`、`application.py`、`health/*`）：目录权威本地直读、非权威经契约、契约不可达降级放行 + `catalog_degraded`、`catalog` 非必需健康项不产生 503。
6. **`sys_tenant.db_key` 废弃**（表文件 / 模型 / 迁移 / 种子 / 批量迁移）：列可空、种子不写、批量迁移只取编码、迁移可升（SQLite 批处理）。

## 5. 问题与偏差 <a id="issues"></a>

| 项 | 说明 | 处置 |
| --- | --- | --- |
| 测试环境模板隔离 | dev 默认启用服务化模板，会覆盖用例显式指定的临时库 URL | 各测试包 `isolate_settings` 夹具固定置空模板环境变量；模板行为由专门用例显式开启覆盖 |
| 03_02 用例适配 | 「运行服务未登记：workflow」用例原依赖直读平台库；改经契约后非权威服务会降级 | 该用例注入桩快照保留原断言语义；新增「契约不可达降级放行」用例补齐新行为 |
| `catalog/base.py` 覆盖率 | 60%（06_03 已交付客户端的解析分支） | 归 06_03 收口或 09_03 契约门禁补用例（实施记录 §6 偏差 2） |
| 开发库文件名变化 | 模板启用后租户库由 `bms_tenant_demo.db` 变为 `bms_{service}_{tenant}.db` | 属预期影响；操作顺序写入 `config.dev.toml` 注释（实施记录 §6 偏差 3） |
