## 3. 演练记录 <a id="drill"></a>

### 3.1 SQLite 多服务多库全量演练（已执行）

前置：备份既有开发库（`bms_*.db` → `/tmp/bms_devdb_backup`，41 个文件）后按分链重建。

```bash
cd backend
uv run python -m ops.provision_tenant --code demo --code acme --migrate   # 建库 + 开通即迁移
uv run python -m ops.seed_tables                                          # 归属登记种子
uv run python -m ops.check_tables --url sqlite+aiosqlite:///./bms_platform.db
uv run python -m ops.check_budget --service platform
```

| 观测项 | 结果 |
| --- | --- |
| 编排目标 | 共 **27** 个目标（平台服务库 9、服务租户库 18）；归档库 1（`--target all` 时的独立目标） |
| 首跑 | 成功 **6**、跳过 **21**、失败 **0**（成功 = `platform:platform` 1 + `platform:tenant` 2 + `tenant:platform` 1 + `tenant:tenant` 2） |
| 重复执行（幂等） | 成功 **0**、跳过 **27**、失败 **0** |
| 无脚本链 | 其余 7 个服务（identity / org / file / notification / search / ai / report）的两条链均输出「无脚本（跳过）」 |
| 迁移后版本 | `bms_platform.db` = `0005_sys_table_ownership`（7 表）；`bms_platform_{demo,acme}.db` = `0003_sys_outbox_event_version`（11 表）；`bms_tenant.db` = `0003_sys_outbox_event_version`（5 表）；`bms_tenant_{demo,acme}.db` = `0002_sys_outbox_event_version`（4 表）；其余服务库 0 表 |
| 归属登记 | 种子新增 39 行 / 更新 0；接库对账通过（清单 39 项 + 模型表对账 + 脚本表集 + 接库） |
| 连接预算 | 按服务 × 库类别逐行输出，均在预算内（`max_connections = 0` = 不校验） |

结论：分链形态、表集派生、批量编排、开通即迁移、幂等与无脚本跳过、归属登记种子 / 对账、库数量统计与按服务预算核对**端到端可用**；开发库与真库表集口径一致（无脚本链两边都跳过）。
