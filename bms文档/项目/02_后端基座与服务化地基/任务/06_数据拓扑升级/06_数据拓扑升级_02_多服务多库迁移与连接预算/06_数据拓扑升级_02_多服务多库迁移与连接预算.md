## 2. 任务内容 <a id="content"></a>

1. Alembic 按服务 × 数据源维护迁移（链名 `{service}:{datasource}`、版本目录两级、表集由归属登记派生、段名 = 链名）
2. 批量迁移遍历「服务 × 数据源 × 租户」幂等执行；开通（新服务 / 新租户）自动执行对应迁移
3. 连接预算按服务核算、活跃租户懒加载与回收
4. 库数量增长可观测
5. **承接 06_03 全部余量**（2026-09-23 决策）：表归属登记落库与对账（`sys_table_ownership` 表文件 + 总览登记 + 迁移 + 幂等种子 + 双向对账）、分链与过渡豁免移除、`SysModule` / `SysModuleI18n` 迁出共享基座库、字典跨服务读出口（`HttpDictSource` / `HttpDictTranslator`）

## 3. 完成标准 <a id="accept"></a>

迁移链按「服务 × 数据源」可取、可分链执行且表集由归属登记派生；多服务多库批量迁移幂等且可演练（三库真库建库 → 迁移 → 校验 → 清理）；开通即迁移可一键完成；连接预算按服务生效；库数量可观测；平台层表归属登记落库并与清单双向对账一致、`bms_core` 内无平台层表直读；pytest / ruff / pyright 全绿。
