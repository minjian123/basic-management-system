## 2. 测试范围与层次 <a id="scope"></a>

1. **归属登记内核**（`bms_core/services/table_registry.py`）：单一来源校验（表名唯一 / 归属标识 / 库类别 / 状态 / 前缀归属）、表级归属查询、服务表集与 `chain_tables(service, datasource)` 派生、接库双向对账；模型声明（`sys_table_ownership` 元数据与唯一约束）。
2. **边界判定与例外**（`bms_core/boundary/*`）：判定改为表级归属（基础设施表 / 自身归属 / 未登记表名放行，他服务归属越界）、只读例外按「表名或前缀」命中、运行时守卫三模式与错误码 10008。
3. **静态护栏**（`scripts/tools/base-check/check-service-boundaries.py`）：规则 5 增「声明表名须在归属登记中」、规则 6 按表级归属判定；`--self-test` 样例集与真实仓库基线。
4. **租户注册归属迁出**（`bms_tenant/models/tenant.py`、`repositories/tenant_registry.py`、`api/tenant_registry.py`）：模型归属、仓储读写入口、只读契约状态码与错误码语义。
5. **租户源装配点**（`bms_core/db/tenant_source.py`、`db/tenant_remote.py`、`db/tenant_registry.py`、`bms_tenant/sources/tenant_source.py`）：按名解析与自动选源、本地 / 远程取数、缓存与版本键失效、停用强制回收、契约不可达降级。

## 5. 关键口径实证 <a id="evidence"></a>

| 项 | 结果 |
| --- | --- |
| 表级归属生效 | 收窄后 `sys_` 不再整体放行：`test_boundary` 与护栏自检均验证「他服务归属表被拦、基础设施表与自身归属放行、未登记表名在**声明**场景即拒」 |
| 存量越界处置 | 首轮扫描暴露 6 项存量越界（`bms_core` 声明 `sys_tenant`、迁移链表集字面量、归属登记自身引用）；经「`sys_tenant` 迁出 + 两处过渡豁免」处置后归零（实施记录 §4） |
| 租户注册读出口 | 契约语义：命中返回快照、未知 404 / 80001、停用 403 / 80002、参数缺失 10001；消费方（远程源）按状态码映射为同义业务异常 |
| 缓存即时失效 | 版本号变更后缓存陈旧 → 自动重载（远程源与本地源各有用例）；停用租户在解析阶段即被拒并回收引擎 |
| 降级口径 | 契约不可达时：`env ∈ {dev,test}` 且 `allow_demo_fallback` → 按请求值构造兜底上下文并记 WARNING（修复 dev / 测试全量 503）；生产解析失败（不允许兜底） |
| 真实仓库基线 | `check-service-boundaries.py` 通过：0 越界、0 例外（白名单为空） |

## 6. 问题与偏差 <a id="issues"></a>

- 收窄首轮 6 项存量越界均属**过渡态**（本期只迁出 `sys_tenant`），处置与移除条件见实施记录 §4 与 §6；`migration.py` 的引用扫描豁免在「迁移链按服务分链」落地后必须移除。
- 版本号递增口径按缓存基座既有能力实现（内存域 `bump_version()`、Redis 域域内版本键写回）；**原子 `INCR` 待缓存基座扩展**（字典域有专用扩展 `DictCacheRegion`，租户域按其模式扩展随缓存回补）。
- 首轮实施缺 Kiwi 标注的用例已在本次补齐（`2176` 标注于新增/新增断言处的自动化文件），既有迁移用例保留原任务编号（`1019` / `2170` / `2171` 等）不重复标注。
- 未发现缺陷；无缺陷单。
