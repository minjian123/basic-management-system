## 2. 任务内容 <a id="content"></a>

1. 平台层表（`sys_*`）逐表服务归属定案并登记（服务目录 / 数据库设计总览 / 表文件三处一致），静态硬校验由「共享前缀放行」收窄为「表级归属」
2. `sys_tenant` 与 `sys_module` / `sys_module_i18n` 的模型与落库实现迁出共享基座库 `bms_core`，按归属落到所属服务
3. 跨服务读出口：租户上下文以网关注入身份头为主 + 服务侧缓存 + 版本键失效，未命中经服务契约取数（超时与降级口径与同步调用一致）
4. 迁移链由「数据源」扩为「服务 × 数据源」，各服务库可分别取链、独立迁移

## 3. 完成标准 <a id="accept"></a>

平台层每张表有唯一服务归属且校验生效（未登记 / 跨服务引用被拒）；`bms_core` 内无平台层表直读；租户解析与停用 / 改名失效即时生效（不直读平台库）；迁移链按「服务 × 数据源」可取、可分链执行；pytest / ruff / pyright 全绿。
