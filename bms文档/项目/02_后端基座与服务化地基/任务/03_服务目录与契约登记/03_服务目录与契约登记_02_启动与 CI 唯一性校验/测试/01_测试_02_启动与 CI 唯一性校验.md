## 4. 问题与处置 <a id="issues"></a>

| 问题 | 原因 | 处置与落点 |
| --- | --- | --- |
| 既有启动冲突断言失败 | 统一异常由 `RuntimeError` 升为 `CatalogError`（40003） | 适配平台用例（见实施记录 §4） |
| 接库失败用例产生 aiosqlite 线程关闭日志错误 | 启动失败路径未释放引擎连接池 | lifespan 失败段补 `resources.aclose()`；用例复跑无告警 |
| 路由护栏断言为空 | FastAPI 新版 `app.routes` 不展平已包含路由 | 改以 OpenAPI 契约 paths 判定（更贴近对外契约） |
| 入口守卫用例 RuntimeWarning | `runpy` 重复导入同模块 | `pytest.warns` 显式断言已知告警 |

## 6. 偏差与遗留 <a id="deviations"></a>

- 只读 HTTP 接口（03_03）、oasdiff 契约门禁与 `service_version` 回写（09_需求）、真实库迁移后查重（当前冒烟层用 SQLite 临时库）不在本任务；达梦下接库路径随环境修复后实测（CI `integration-dm8` 仍临时关闭）。
- 契约版本 minor / patch 差异按主版本兼容放行（不告警）；服务包自报契约版本当前统一 `0.1.0`，独立升版流程随 09 契约门禁。
- 启动接库校验的空目录容错（告警放行）为开发 / 测试口径；CI 接库模式空库判失败，两处口径差异见详细设计 §4.1。
