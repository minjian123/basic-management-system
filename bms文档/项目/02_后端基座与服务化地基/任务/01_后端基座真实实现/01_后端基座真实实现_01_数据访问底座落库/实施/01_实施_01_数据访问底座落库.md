## 3. 实施过程 <a id="process"></a>

1. **配置扩展**：`AppSettings.service`（服务标识）、`DbPoolSettings.connect_timeout`、`DatabaseTargetSettings.max_connections` / `services` / `effective_pool`；`config.toml` 与 `.env.example` 同步键位。
2. **错误码与异常**：`ErrorCode.DATABASE_UNAVAILABLE = 10006` + `DatabaseUnavailableError`（`GeneralError`，503）。
3. **引擎工厂**：`EngineFactory` 改按 `(db_key, 读写角色)` 创建 / 缓存；只读有副本轮询、无副本回落主；池参数取服务覆盖；非 SQLite 附 `connect_args` 建连超时；新增 `create_sync`（达梦 / 连通性）；`drop` 一次释放该库主 + 副本 + 同步引擎。
4. **注册表与会话**：`EngineRegistry.get(db_key, *, read_only=False)`；`get_db`（按只读标记）、`get_read_db` / `get_write_db`（显式强制）、`get_uow`（绑定主库会话）；`routing` 绑定常量语义分离 + `SAFE_METHODS` / `is_read_method`。
5. **只读中间件**：`ReadOnlyMiddleware`（纯 ASGI，按方法设 `read_only` 上下文，结束复位），`main` 注册。
6. **主库故障降级**：`PrimaryHealth`（降级标记 + `probe` 恢复）；`get_write_db` 降级态先探测、失败抛 `DatabaseUnavailableError`；全局异常处理器将 `OperationalError` / `InterfaceError` 标记降级并转 503。
7. **连接池预算**：`pool_budget_warnings`（`workers × (pool_size + max_overflow) ≤ max_connections × 70%`），`main` 启动期 WARNING 告警不阻断。
8. **达梦方言**：新增 `dmSQLAlchemy` 依赖（`dm+dmPython` 同步方言）；异步 `create` 对其抛 `ConfigError`，连通性走 `create_sync`（异步适配器归 01-05）。
9. **用例**：新增 `tests/db/test_engine_routing.py` / `test_readonly_middleware.py` / `test_degradation.py` / `test_pool_config.py`、`tests/integration/test_db_connectivity_integration.py`；扩展 `test_data_access.py` / `test_unit_of_work.py` / `test_config.py`；统一标注 Kiwi `984`。
10. **修复预存在失败（经用户确认）**：`tests/dict` / `listing` / `query` / `fieldtype` 四条占位用例模块加 autouse 夹具固定 `null` provider，消除对 dev 覆盖（sql / local）的隐式依赖，`backend-test` 恢复全绿。
11. **登记回写**：《后端基类清单》§2 / §7 / §8 / §10；《后端开发规范》「SQL 与数据访问规范」节；计划与任务状态。

## 4. 问题与处置 <a id="issues"></a>

| 问题 / 现象 | 原因 | 处置与落点 |
| --- | --- | --- |
| `dm+dmPython` 方言 `NoSuchModuleError` | 依赖仅 `dmPython` 裸驱动，无 SQLAlchemy 方言 | 引入 `dmSQLAlchemy`（实测 Python 3.14 可加载）；`create_sync` 建同步引擎 |
| `create_async_engine("dm+dmPython://…")` 报错 | 达梦无异步方言 | 按设计：异步 `create` 抛 `ConfigError`，异步适配器归 01-05 |
| 只读标记全仓无人设置 | 阶段一未落来源 | 新增 `ReadOnlyMiddleware`（按方法）；路由经 `get_read_db` 显式覆盖 |
| 既有绑定断言期望 `default` | `READ_BINDING` 由占位改为 `replica` | 更新 `test_data_access.py` / `test_base_repository.py` 断言 |
| `pyright` 误报 `session.bind is not None` | 类型上恒真 | 改 `isinstance(session.bind, AsyncEngine)` |
| 预存在 6 条 `backend-test` 失败（非本任务引入） | `config.dev.toml` 字典 / 查询方案 provider 置真实实现，占位用例仍断言 null（02-4-27 域） | 经用户确认后修复：四条占位用例模块加 autouse 夹具固定 `null` provider；`backend-test` 恢复全绿 |

- **预存在失败已修复**：`backend-test` 在 `main` 曾红（流水线 #306，2026-09-21，6 条，02-4-27 域）；经用户确认后于本任务内以最小改动修复（占位用例固定 `null` provider），`backend-test` 恢复全绿。
- **归任务 02**：租户解析链与引擎注册表租户库键解析、LRU 实测、跨租户隔离、连接预算按活跃租户数。
- **归任务 03 / 04**：`BaseDbRepository` 真实 CRUD / 软删除 SQL / 排序 DB 侧。
- **归任务 05**：达梦异步适配器（`asyncio.to_thread` 门面）、三库真库集成实测、CI `verify/db` 档、达梦方言细节（复合唯一 NULL / DDL / schema 前缀大小写 / 类型映射）。
- **开放项**：达梦登录超时参数随 01-05 实测；副本密码若异于主库后续按需扩展。
- 本任务未改 `dict` / `listing` 等模块 `_session`（统一归任务 03）。
