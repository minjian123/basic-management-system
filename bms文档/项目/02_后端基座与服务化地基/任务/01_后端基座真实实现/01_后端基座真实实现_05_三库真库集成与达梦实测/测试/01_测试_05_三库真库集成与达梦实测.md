### 3.3 达梦方言实测结论 <a id="dm8"></a>

| 观测项 | 实测结论 | 处置 |
| --- | --- | --- |
| schema 前缀 | URL 的模式段即 dmPython `schema` 连接参数 → 连接落在该模式内；迁移脚本不写「模式名.表名」前缀；建删模式须用去模式段连接串（模式不存在时无法作为连接参数） | 已回写方言文档 |
| 标识符大小写 | 库内对象名（`ALL_TABLES` / `SYS.SYSOBJECTS`）为大写；方言反射归一为**小写**；小写书写经折叠可用 | 已回写（用例双断言） |
| 复合唯一 NULL 语义 | **差异**：复合唯一 `(唯一字段, deleted_at)` 视 NULL 相等 → 第二条同键未删行被拒（`-6602`）；单列唯一 `(name)` 多 NULL 允许 | 登记差异 + 归口信创适配阶段（不改口径；用例断言现状） |
| 布尔落库 | 落 `SMALLINT`（0/1），ORM 往返正确 | 已回写 |
| JSON 落库 | 写入正确；经 dmPython **读回为字符串**（`'{"k":"v"}'`），应用层需 `json.loads` | 登记差异 + 用例归一化断言 |
| `VARCHAR2(n CHAR)` | 长度按**字符**计（16 个中文字符可写入、17 个被拒） | 已回写 |
| 类型映射 | 四方言 DDL 编译断言（01_03 登记表）在真库落库侧复核一致（`BIGINT` / `DATETIME` / `VARCHAR2(n CHAR)` / `SMALLINT` 布尔 / `JSON`） | 结论登记 |

**差异取证（逐条插入观察，模式 `BMS_TEST_DM`）**：

| # | 场景 | 结果 |
| --- | --- | --- |
| ① | 复合唯一 `(name, d)`：`name=a, d=NULL` 首条 | OK |
| ② | 复合唯一：`name=a, d=NULL` 第二条 | **失败**（`-6602 违反唯一性约束条件`） |
| ③ / ④ | 复合唯一：`name=a, d=非空` 两条不同时间 | OK / OK |
| ⑤ | 复合唯一：`name=b, d=NULL` | OK |
| ⑥ / ⑦ | 单列唯一 `(name)`：两条 `name=NULL` | OK / OK |

## 4. 问题与处置 <a id="issues"></a>

| 问题 | 处置 |
| --- | --- |
| MySQL 冷缓存首连报 `cryptography package is required` | 补 `cryptography` 依赖（详见实施记录 §4）；本地复跑迁移与用例通过 |
| PostgreSQL `permission denied for schema public` | 建库后转属主（`ALTER DATABASE … OWNER TO`）；复跑迁移与用例通过 |
| 达梦复合唯一多 NULL 与 MySQL / PG 相反 | 经确认：登记差异 + 另立任务定案，用例按现状分支断言（不静默放宽） |
| 达梦 JSON 读回为字符串 | 经确认：登记差异 + 用例归一化断言 |
| 达梦标识符大小写断言口径偏差 | 用例改双断言（反射小写 + 库内目录大写） |
| PostgreSQL 布尔条件字面量不兼容 | 用例改参数化绑定 |
| 达梦 executemany 列集不一致 / 副本 URL 脱敏串比较 / 分片插件未注册 | 用例分别改为统一列集、URL 对象比较、显式导入 null 实现 |

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差（已闭环）**：达梦复合唯一多 NULL 差异（新增待拍板项 → 经确认登记 + 归口）；达梦 JSON 读回字符串（经确认登记 + 归一化断言）；标识符大小写断言口径修正；迁移入口收敛、`cryptography` 依赖、PostgreSQL 属主处置（实施中新增，设计决策 16 ~ 18 已回写）。
- **遗留（归口）**：① 达梦复合唯一多 NULL 兜底方案 → 信创适配阶段（计划「后续阶段待办」）；② JSON 字段达梦读回字符串的适配 → 按影响面后续；③ `ops/init_tenant.py` 达梦种子路径需同步门面适配 → 租户管理阶段 / 达梦生产化；④ 真实主从与只读副本谓词（`待验`）→ 后续；⑤ 游标排序键类型范围（`Decimal` 等）→ 01_04 遗留保持；⑥ 骨架表迁移 → 所属阶段；⑦ 分片表按月预创建 → 任务调度阶段。
