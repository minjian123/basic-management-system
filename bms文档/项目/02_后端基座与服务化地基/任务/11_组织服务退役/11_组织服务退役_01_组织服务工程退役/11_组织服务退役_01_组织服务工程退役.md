## 2. 任务内容 <a id="content"></a>

1. **服务工程**：删除 `backend/services/org/`（源码 `src/bms_org/`、`tests/`、`pyproject.toml`）。
2. **服务目录**：移除 `bms_core/services/module_registry.py` 的 `SERVICE_CATALOG` 中 `org` 条目；平台服务清单 9 → 8 个平台服务工程。
3. **网关与部署**：移除 `deploy/gateway/apisix.yaml` 的 upstream `org` 与 `route-org` 路由；移除 `backend/Dockerfile` 与 `deploy/ci/Dockerfile.backend` 的 `COPY services/org/pyproject.toml`；移除 `backend/ops/dev_run.py` 的 org loopback 别名与 `KNOWN_SERVICES` 中的 org。
4. **契约与类型**：移除 `deploy/contracts/org.json` 与 `deploy/contracts/baseline/org.json`；移除前端 api-types 中 org 契约类型（随 `scripts/generate.mjs`）。
5. **迁移链与表归属**：移除 `backend/alembic/versions/org/`（`org:tenant` 0001~0006，剩余每服务自有基建表 `sys_outbox` / `sys_event_consumed` / `sys_event_dead_letter`）与 `org:platform`；`table_registry` 无 org 专属表需转（`sys_user` / `sys_account_lock` 已迁 platform）。
6. **校验与测试**：清理 `scripts/tools/base-check/check-service-boundaries.py`、`scripts/tools/preflight/check-preflight.py`、`bms_core` 测试（`test_tenant_routing` / `test_keys` / `test_boundary_metrics` / `test_migrate_user_tables` / `test_provision_tenant`）与 `backend/ops/migrate_user_tables.py` 中对 org 服务 / `bms_org` 的引用。

## 3. 完成标准 <a id="accept"></a>

`services/org/` 工程、`SERVICE_CATALOG` org 条目、网关 / 契约快照 / api-types / Dockerfile / `dev_run` / `alembic` org 链与相关测试引用全部移除；启动与 CI 服务目录唯一性校验通过（8 服务）；`pytest` / `ruff` / `pyright` 全绿。
