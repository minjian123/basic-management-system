## 2. 任务内容 <a id="content"></a>

1. **契约迁出**：将 `bms_core/org/`（`base.py` / `null.py` 及数据契约 `OrgUser` / `OrgPost` / `OrgDept` / `OrgNameRef` 与常量 `ORG_STATUSES` / `ORG_TARGETS` / `DEFAULT_ORG_PAGE_SIZE`）迁 **mdm 组织域**，由 mdm 提供真实实现（跨仓，见 mdm 需求 `01-3`）。
2. **基座清理**：移除 `bms_core/core/assembly.py` 的 `org_data_source` / `org_name_resolver` 装配与 `bms_core.org.null` 模块登记；移除 `bms_core/api/deps.py` 对应导出（`get_org_data_source` / `get_org_name_resolver`）。
3. **前端切换**：前端组织选择字段族（`OrgSelectField` / `PostSelectField` / `DeptTreeSelectField` / `OrgCompositePicker`）与 `src/dev/OrgCheck.vue` 出口地址切 mdm 组织域公开契约；`OrgSourceAdapter` http 默认实现指向 mdm 出口（查询与批量回显分列、部门树一次性返回），同步更新相关用例。
4. **兼容期**：mdm 出口就绪前不删除 bms 出口（依赖 mdm 需求 `01-3` 交付）。

## 3. 完成标准 <a id="accept"></a>

`bms_core/org` 契约与装配 / 导出移除；前端组织选择字段经 mdm 出口取数联通（查询与批量回显分列、部门树一次性返回）；无残留 org 出口引用；`pytest` / `ruff` / `pyright` 与前端检查全绿。
