# 01 详细设计 · 组织只读出口契约迁出与前端切换

> 后端基座与服务化地基 · 11_组织服务退役 · 子任务 02（需求 11-2）· 详细设计

## 1. 设计目标与范围 <a id="goal"></a>

承接需求 11-2：把组织只读出口契约**迁出 bms 共享基座**（归 mdm 组织域），并把 bms 前端组织选择字段切换至 **mdm 出口**。

1. **契约迁出**：移除 `bms_core/org/`（组织数据源 / 名称回显两契约 + `NullOrg*`）与 `assembly.py` 装配、`api/deps.py` 导出；契约定义与实现归 mdm 组织域（mdm 需求 01-3）。
2. **前端切换**：bms 前端组织选择字段族与 `OrgSourceAdapter` 改指 **mdm 出口基址**（产品命名空间 `/api/mdm/v1/org/...`）。

**两段执行（强制，与 11_01 联动）**：

- **前段（11_01 之前）**：前端切换（改 `OrgSourceAdapter` 与调用方出口基址）——先行，避免删服务后前端出口空窗。
- **后段（11_01 之后）**：`bms_core/org` 契约与装配移除——必须在 `services/org` 删除之后（org 服务 `api/org.py` 现依赖 `bms_core/org`）。

**不在本期**：删除 `services/org` 与登记清理（归 11_01）；门禁回归与阶段收口（归 11_03）。

## 3. 契约迁出去向 <a id="contract"></a>

| 契约 | bms 侧（迁出前） | mdm 侧（迁出后） |
| --- | --- | --- |
| 组织数据源 `BaseOrgDataSource`（`users` / `posts` / `dept_tree`） | `bms_core/org/base.py` | mdm 组织域（mdm 需求 01-3） |
| 名称回显 `BaseOrgNameResolver`（`resolve_names`） | `bms_core/org/base.py` | mdm 组织域 |
| 数据契约 `OrgUser` / `OrgPost` / `OrgDept` / `OrgNameRef`、常量 | `bms_core/org/base.py` | mdm 组织域 |
| Null 兜底 `NullOrg*` | `bms_core/org/null.py` | mdm 组织域（按需） |

- **bms 侧移除后无组织契约调用点**：bms 内部唯一消费方为 org 服务（11_01 删除）；前端经 **HTTP 出口**消费（本任务切换）。故移除后 bms 后端不再引用组织契约。
- **前端消费**：仍为 HTTP（`OrgSourceAdapter` http），仅出口基址由 bms org 服务改为 mdm 出口；查询与批量回显分列、部门树一次性返回口径不变。

## 4. 前端切换口径 <a id="frontend"></a>

| 项 | 口径 |
| --- | --- |
| 出口基址 | 由 bms `org` 服务出口（`/api/org/v1`）改为 **mdm 出口**（产品命名空间 `/api/mdm/v1/org/...`） |
| 适配器 | `OrgSourceAdapter` 的 http 默认实现改指 mdm 出口；未注入仍占位零请求（降级口径不变） |
| 组件 | 组织选择字段族（用户 / 岗位 / 部门树 / 复合）取数与回显改经 mdm 出口，行为与分页口径不变 |
| 降级 | mdm 不可达时按既有降级（占位 / 空态），不报错、不阻塞页面 |

## 5. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| mdm 出口未就绪 | 本任务前段**不得先于 mdm 01_03** 执行；否则前端出口不可用 |
| 后段早于 11_01 | 禁止：`services/org` 仍依赖 `bms_core/org`，提前移除将导致 org 服务启动失败 |
| 移除后残留引用 | 全仓检索无 `bms_core.org` / `get_org_data_source` / `get_org_name_resolver` 引用；装配警告为零 |
| 前端出口 404 | 校验 mdm 出口基址与网关路由（产品命名空间）配置一致 |
