**需求 11-2 完成标准逐条达成**：① `bms_core/org` 契约与装配 / 导出 / 配置 / 测试期望**移除且零残留**；② 前端组织选择字段族出口经**寻址契约**组装切 **mdm 产品命名空间**（`/api/mdm/v1/org` + 出口四路径；查询 / 批量回显分列、部门树一次性返回；响应形态兼容）；③ 无残留 org 出口引用；④ `pytest` / `ruff` / `pyright` 与前端检查（用例 / lint / 类型 / 隔离）**全绿**，`preflight --fast` 与基座校验通过。
