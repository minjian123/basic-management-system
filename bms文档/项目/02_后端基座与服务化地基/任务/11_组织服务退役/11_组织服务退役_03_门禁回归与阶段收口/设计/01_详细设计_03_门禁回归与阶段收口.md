## 1. 设计目标与范围 <a id="goal"></a>

承接需求 11-3：在 `11_01` / `11_02` 落地后，做**门禁回归**与**文档口径核对**，并**阶段收口**（回写阶段二计划）。

1. **门禁回归**：服务目录 / 网关配置 / 契约快照 / api-types 零漂移；`preflight --fast` 全绿；契约冒烟与事件契约校验通过。
2. **文档口径核对**：核对并补齐架构设计、规范、清单、数据库设计、阶段二需求 / 计划与实现一致。
3. **阶段收口**：阶段二计划回写状态与完成日期（进度以计划表为唯一落点）。

**不在本期**：新的功能实现（`11_01` / `11_02` 已交付）。

## 5. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 任一零漂移门禁失败 | 以工具重新生成（快照 / 类型）或回改实现，直至零漂移 |
| 文档与实现口径不一致 | 以实现为准回改文档（除非实现偏离设计，则回改设计） |
| 阶段计划与任务状态不一致 | 以任务实际状态回写计划；嵌套子任务并入父任务行 |
| 运行库残留 org 登记行 / 库 | 清理后复校（运维） |
