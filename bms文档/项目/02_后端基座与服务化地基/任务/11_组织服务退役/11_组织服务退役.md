## 1. 域说明 <a id="intro"></a>

本域对应阶段二「组织服务退役」：组织主数据（部门 / 岗位 / 用户-岗位）统一归 mdm 产品，bms 侧原 `org` 服务（`backend/services/org`）一步到位退役——删除服务工程，清理服务目录 / 网关 / 契约快照 / 前端 api-types / 迁移链 / 部署脚本 / CI 与校验脚本中的 org 登记；组织只读出口两契约（组织数据源 / 名称回显）自 `bms_core/org` 迁 **mdm 组织域**实现，bms 前端组织选择字段切 mdm 出口。依据 mdm《mdm 主数据管理规划》（`mdm/mdm文档/规划/mdm主数据管理规划.md`）「组织服务归位」节与《[架构设计 · 总体架构](../../../../设计/架构设计/03_架构设计_总体架构.md)》「进程模型」节；对应需求域十一（11-1 ~ 11-3）。

**依赖与顺序**：**mdm 先实现、bms 后退役**——本域依赖 mdm 组织主数据只读出口就绪（mdm 需求 `01-3`）（跨仓）。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：本域整体依赖 **mdm 组织主数据只读出口就绪**（mdm 需求 `01-3`，跨仓；见各子任务「任务信息」表「依赖」行）。
- **风险**：退役为跨「服务目录 / 网关 / 契约快照 / api-types / 迁移链 / 前端」联合变更，漏改一处即门禁漂移；以「登记点位清单 + 预检全绿」逐项闭环（详见[计划文档](../../计划/01_计划_后端基座与服务化地基.md)「风险与对策」节）。
