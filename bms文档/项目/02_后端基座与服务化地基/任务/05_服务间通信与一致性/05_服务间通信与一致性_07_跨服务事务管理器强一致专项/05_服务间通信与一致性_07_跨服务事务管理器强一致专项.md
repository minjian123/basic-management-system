## 2. 任务内容 <a id="content"></a>

1. **TM 协调服务**：新增 `txn` 服务（服务目录登记 / 服务身份 / 契约 / 健康检查）+ **全局事务账本库**（`txn_global` / `txn_global_branch` / `txn_global_recovery`；**平台侧独立基础设施库 `bms_txn`，`datasource=PLATFORM`、仅 `txn:platform` 单链、不建 tenant 链**）+ 表归属登记与迁移链。
2. **协调与恢复**：全局事务状态机（提交决定点唯一权威）+ 分支驱动（`begin` / `prepare` / `commit` / `rollback`）+ 分支级幂等与退避重试 + **崩溃恢复器** + 悬挂分支对账。
3. **参与方能力域**：`BaseTransactionParticipant`（端口）+ `xa` 提供者（同步引擎 + XA；达梦走 `dmxa`）+ `null` 缺省 + 配置分区 `[transaction_manager]` + 装配接线；各参与服务挂 `/api/v1/txn/branches*` 参与端点（服务身份白名单）。
4. **调用方接入（接入路径，不在本任务范围）**：角色保存与用户保存的跨服务写切为全局事务——**编排端点本身尚未存在**（角色侧归 bms `02_03/_02`、用户侧归 bms `02_02/_01`、mdm 内部写端点归 mdm `01_02/_03`），由这些任务在 `provider="xa"` 下接入；保留 `null` 提供者下的既有基线路径以便回退；**同步引擎策略**与本地环境口径按评审结论定稿。
5. **达梦补齐**：`do_recover_twophase`（`DBMS_XA.XA_RECOVER`）实现——**须含两要点**：① 可回放 xid 载体（`DMXARecoveredXid(gtrid, bqual)`，`_xid_raw` 识别该形态直接使用、不再哈希）；② `TABLE(DBMS_XA.XA_RECOVER())` + `RAWTOHEX` 还原（否则恢复器列出悬挂分支也驱动不了）+ 达梦集成作业恢复。
6. **口径回写**：据评审结论回写《[后端开发规范](../../../../../规范/后端开发规范.md)》「强一致场景口径」（现行「`dmPython` 无 XA」括注已被 05_05 实测推翻）、《[架构设计 · 服务间通信与分布式一致性](../../../../../设计/架构设计/37_架构设计_子系统_服务间通信与一致性.md)》《[架构设计 · 决策与风险](../../../../../设计/架构设计/34_架构设计_决策与风险.md)》《[后端基类清单](../../../../../后端基类清单.md)》与知识档案《分布式事务》系列。

## 3. 完成标准 <a id="accept"></a>

跨服务原子写在**两个参与方均未提交前对业务完全不可见**；提交决定点之前的失败一律全量回滚、之后的失败由恢复器驱动至提交；悬挂分支可自动对账、无法自动判定者入处置台账且**处置动作依账本决定点驱动协议完成（不修改业务数据内容）**；`null` 与 `xa` 两种提供者可配置切换且业务调用面不变；真库集成用例（含崩溃注入）与契约 / 事件 / 模块门禁全绿；架构与规范口径一致。
