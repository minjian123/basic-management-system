## 2. 用例分层与范围（第 1~3 批） <a id="layers"></a>

| 层 | 范围 | 落点 |
| --- | --- | --- |
| 单元 · TM 协调器与恢复器 | 决定点全票提交 / 非全票全回滚 / 决定点后回滚被**幂等吸收** / 重复驱动不改变终态 / 驱动失败留痕与重试计数 / 恢复器按决定点驱动与**到期回滚** / 非 leader 不执行扫描 | `services/txn/tests/test_coordinator.py`（14 例） |

## 4. 覆盖路径说明 <a id="coverage"></a>

- **本轮可自动化的判定**：缺省提供者的**拒绝语义**（不静默降级）、装配接线与分区共用、配置缺省、状态词表与终态判定、达梦悬挂回收的**列举 → 驱动**闭环（以连接替身断言实际下发的 PL/SQL：`XA_RECOVER` / `RAWTOHEX` / `HEXTORAW` 原样使用）。
- **须真库才能验证的语义**（第 4 批）：`XA_PREPARE` 后**业务不可见**、跨服务两阶段的全员提交 / 回滚、悬挂分支在真实 `DBMS_XA.XA_RECOVER` 中的可见性与可回放驱动、崩溃注入（决定点前 / 后）。
- **XA 语义的唯一验证处**是真库集成用例（详设 §7）：本地（SQLite）不参与强一致链路。
