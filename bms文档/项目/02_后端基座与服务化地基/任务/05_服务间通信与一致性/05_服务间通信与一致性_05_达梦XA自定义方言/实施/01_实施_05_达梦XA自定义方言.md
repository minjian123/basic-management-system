## 3. 问题与处置 <a id="issues"></a>

| 问题 | 现象 | 处置 |
| --- | --- | --- |
| `DBMS_XA_XID(INTEGER)` 溢出 | 以 64 位整数作 `gtrid` 时 PL/SQL 报 `[CODE:-6102] 数据溢出`（达梦该构造参数为 **32 位**） | 改用 **RAW 形态** `DBMS_XA_XID(1, HEXTORAW(gtrid), HEXTORAW(bqual))`，`gtrid`/`bqual` 由 `blake2b(xid, digest_size=16)` 派生（各 8 字节） |
| 方言解析名 | `registry.register("dmxa", …)` 后 `dmxa+dmPython://` 仍报 `NoSuchModuleError` | 增加 `registry.register("dmxa.dmPython", …)`（`dmxa+dmPython` 按 `dmxa.dmPython` 解析） |
| 既有断言/用例 | `test_engine_routing::test_dm_sync_only_dialect` 断言 `dialect.name == "dm"` | 按「全部达梦连接改走」更新为 `dmxa` |
| 裸无序集合护栏 | `check-bare-collections` 报 `list[…]`（`do_recover_twophase` 返回、测试局部变量） | 覆写契约处用 `# bare-collections:allow` 注释；测试局部改 `ConcurrentStableList` |
| pyright strict | `dmSQLAlchemy.dmpython` 无 stub、测试使用私有 `_normalize_dialect_url` | 各加 `# pyright: ignore[…]`（`reportMissingTypeStubs` / `reportPrivateUsage`） |
