## 2. 任务内容 <a id="content"></a>

1. **达梦 XA 自定义方言**：纯 Python 继承 `dmSQLAlchemy` 同步方言，将 `do_begin / do_prepare / do_commit / do_rollback / do_recover_twophase` 接到服务器端 `DBMS_XA` 包（`XA_START / XA_END / XA_PREPARE / XA_COMMIT / XA_ROLLBACK / XA_RECOVER`）；经 SQLAlchemy 方言注册表登记（新方言名，如 `dmxa`），**不改编译驱动 `dmPython`**。
2. **前置与配置**：`XA_COMPATIBLE_MODE ≠ 2`；方言与连接串经配置（配置唯一来源，不硬编码）；`begin_twophase` 走同步引擎（异步 API 不暴露两阶段）。
3. **用例与护栏**：`begin_twophase` 的 `prepare→commit` / `rollback` / `prepare→rollback`；单进程跨库 2PC（MySQL × PostgreSQL × 达梦，同步引擎）。
4. **文档登记**：方言注册与落点登记《[后端基类清单](../../../../../后端基类清单.md)》数据访问基座；结论回写《[数据库设计 · 方言特性](../../../../../设计/数据库设计/方言特性/03_DM8.md)》「事务与连接」节（已于 2026-10-06 实测登记）。
