## 2. 测试范围 <a id="scope"></a>

本任务为**数据所有权边界硬校验 + 运行时守卫 + 例外登记 + 度量**，测试面分四层：

1. **归属与判定内核**（`bms_core/boundary/{directory,sql,assess}.py`）：表前缀归属、SQL 表名 / 操作提取、越界判定纯函数。
2. **例外白名单**（`bms_core/boundary/exceptions.py`）：加载 / 结构 / 语义校验、命中判定（只读放行）。
3. **运行时守卫**（`bms_core/boundary/table.py`）：三模式（off / warn / enforce）、计数快照、指标上报、降级与幂等安装。
4. **构建期硬校验与度量**（`check-service-boundaries.py --self-test` / `boundary_metrics.py`）：规则 6/7 越界拦截、白名单放行与非法拦截、度量计数与违规退码。

## 6. 问题与偏差 <a id="issues"></a>

- 静态引用扫描首版按「服务前缀」匹配，误报列名 / 插件键 / 业务码 → 收窄为「已声明表名精确匹配」并跳过 docstring / 裸字符串（实施记录 §4）；原始 SQL 与 `ForeignKey` 形态不受影响。
- 平台模型归属冲突经用户拍板：本任务按「`sys_` 归 platform」放行，模型 + 实现迁出另立独立迁移任务（计划 §7 第 9 项）。
- 未发现缺陷；无关遗留（达梦 / `init_tenant` 等）见阶段计划「后续阶段待办」。
