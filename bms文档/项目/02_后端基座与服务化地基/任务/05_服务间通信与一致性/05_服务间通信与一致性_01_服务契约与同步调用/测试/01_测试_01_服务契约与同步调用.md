## 2. 测试范围 <a id="scope"></a>

本任务为**服务公开契约 + 服务间同步调用 + 跨服务读出口**，测试面分三层：

1. **契约快照**（`bms_core/services/service_contract.py` + `ops/contract_snapshot.py`）：启用服务枚举 / 寻址判定、确定性渲染、契约版本校验、快照 export / check 零漂移、缺件 / 多余件 / 漂移拦截。
2. **同步调用韧性**（`bms_core/servicecall/`）：公开契约边界（服务登记启用 + `/api/v1` 路径）、显式超时 / 指数退避重试 / 熔断快速失败 / 限流前置、非重试状态原样返回、占位实现与依赖解析。
3. **跨服务读出口**（`bms_core/schemas/service.py`）：`ServiceDto` 继承与序列化、只读投影沿用数据查询提供者基座。

## 6. 问题与偏差 <a id="issues"></a>

- 契约快照漂移用例首版以字符串替换制造漂移，因 OpenAPI 文本不含目标串而失效 → 改追加换行，`check` 如期拦截（实施记录 §4）。
- 服务不可用错误码由 `10006` 顺延 `10007`（`10006` 已被 `DATABASE_UNAVAILABLE` 占用）——详细设计 §4.4 / §10 与清单已按 10007 落定。
- 未发现缺陷；无关遗留（达梦 / `init_tenant` 等）见阶段计划「后续阶段待办」。
