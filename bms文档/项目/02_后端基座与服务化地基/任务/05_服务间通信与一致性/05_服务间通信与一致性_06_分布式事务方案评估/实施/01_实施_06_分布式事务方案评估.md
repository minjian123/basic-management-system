## 4. 问题与处置 <a id="issues"></a>

| 问题 | 现象 | 处置 |
| --- | --- | --- |
| MySQL / PG 无默认库 | 跨库用例需可连库 | 用例按环境变量取连接串；本地跑于临时探针库（MySQL `bms_it_2pc` / PG `bms_it_2pc`），跑完清理 |
| 达梦模式段 | 连接串带未建模式会报「无效的模式名」 | 达梦 URL 不带模式段、默认落在登录用户模式；探测表用非限定名 |
| 集合声明护栏 | 测试用 `dict[...]` 注解触发 `check-bare-collections` | 按平台口径改用 `ConcurrentStableDict`（插入序集合） |
| 跨层引用护栏 | 知识档案链接 `设计/` 文档触发 `check-base` 跨层引用 | 按口径改为纯文本「平台《文档名》」引用 |
| 文档落点护栏 | 详细设计含阶段计划专属字样触发 `check-docs-scope` | 移除设计文档内相应字样（进度归阶段计划） |
| Python 3.14 元组 `except` | `ruff format` 归一为 `except A, B:` | 项目 py314 口径（与既有代码一致），保持 |
