## 2. 任务内容 <a id="content"></a>

1. **三库同步 2PC 可行性**：单进程多库 2PC 的适用范围与限制——**三库均支持 XA 且已实测可用**（MySQL 原生 `XA`；PostgreSQL `PREPARE TRANSACTION`；达梦 `DBMS_XA`）；**异步 API 不暴露 `begin_twophase` → 2PC 一律走同步引擎**（属驱动层限制，非数据库能力缺失）。实例侧部署条件见部署说明。
2. **跨服务协调（TM）评估**：面向「结构化权限保存必须原子（角色 + 用户/岗位/部门分配 + 权限项）」场景，评估三条路线——① 外部事务管理器（TM）+ 各服务 XA；② 单进程多库（SQLAlchemy 作协调者）；③ 权限数据单库（本地事务，最简）——给出结论与推荐。
3. **口径回写**：据结论回写《[架构设计 · 服务间通信与分布式一致性](../../../../../设计/架构设计/37_架构设计_子系统_服务间通信与一致性.md)》《[后端开发规范](../../../../../规范/后端开发规范.md)》的 2PC / XA 口径与决策记录；必要时更新《[架构设计 · 决策与风险](../../../../../设计/架构设计/34_架构设计_决策与风险.md)》。
4. **产出**：评估报告（现状实测、路线对比、推荐方案与代价、开放项）。
