## 2. 自动化用例 <a id="cases"></a>

用例先登记 Kiwi TCMS 取得编号 **2182**，再编码；一任务一条策展用例、多条断言共用同一 `kiwi_id`。

| 用例 / 文件 | Kiwi | 断言要点 | 结果 |
| --- | --- | --- | --- |
| `metrics/test_prometheus_metrics.py` | 2182 | `PrometheusMetrics` 继承契约 / provider；三入口记录后 `render()` 含指标名与注入的 `service` 标签；同名跨类型冲突早失败；`NullMetrics.render()` 为 None | 通过 |
| `tracing/test_otel_tracer.py` | 2182 | 独立 provider + in-memory exporter：`start_span` 返回 OTel 形态 id、上下文变量与 OTel trace id 一致、嵌套共享 trace 且记父 span；退出复位；无有效 provider 退回本地占位 id 且父子链保留 | 通过 |
| `api/test_metrics_endpoint.py` | 2182 | `provider=prometheus` 时 `/metrics` 200 / `text/plain`、请求指标 `route` 为**模板**（非原始 path）；占位实现 404；`/metrics` 自身不计入请求指标 | 通过 |
| `ops/test_observability_config.py` | 2182 | collector OTLP→Tempo；Prometheus 抓取含 apisix / otel-collector / bms-services 且保留 15d；Tempo 72h；Loki 30d + 结构化元数据；Alloy `service`/`level` 标签 + `trace_id`/`request_id` 元数据；compose 六组件 + `bms.yml` include；Grafana 三数据源 | 通过 |

## 3. 真实冒烟（mjbk） <a id="smoke"></a>

一键拉起：`docker compose -p compose -f compose/bms.yml --env-file .env up -d`（**返回码 0**）；平台服务宿主直跑（`BMS_LOG__FORMAT=json`，日志落 `~/deploy/observability/logs/bms-platform.log` 供 Alloy 采集）。

| 场景 | 命令 / 操作 | 实测结果 |
| --- | --- | --- |
| 组件就位 | `docker ps` | otel-collector / tempo / prometheus / loki / alloy / grafana 全部 Up（collector `Everything is ready`） |
| 服务指标端点 | `curl localhost:8000/metrics` | `bms_db_count{kind=...,service="platform"}` / `bms_request_total{method,route,service,status}` |
| Prometheus 抓取 | `query=up` | `bms-services` / `apisix` / `otel-collector` / `prometheus` 均 **up=1** |
| 指标服务归因 | `query=bms_request_total` | `service="platform"` / `route="/"` / `status="200"` |
| Trace 可查 | Tempo `/api/search?tags=service.name=platform` | 命中多条，`rootServiceName=platform` / `rootTraceName=GET /` |
| 日志按服务检索 | Loki `query_range {service="platform"}` | 命中流，标签 `service=platform`/`level`；`trace_id`/`request_id` 为**结构化元数据**（`/labels` 列表无 trace_id） |
| Trace↔日志一致 | 取日志 `trace_id` → `Tempo /api/traces/<id>` | **HTTP 200**，1 batch（OTel 事实源，日志与 Trace 同 id） |
| APISIX 入栈 | `query=apisix_http_requests_total` | 命中（99 次），`apisix` job up=1 |
| Grafana | `/api/datasources` / `/api/search` | 数据源 Loki/Prometheus/Tempo；面板 `BMS 可观测总览`（uid `bms-overview`） |
