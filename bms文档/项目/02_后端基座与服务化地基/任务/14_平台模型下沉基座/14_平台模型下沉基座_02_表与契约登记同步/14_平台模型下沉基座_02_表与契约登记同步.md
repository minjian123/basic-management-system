## 2. 任务内容 <a id="content"></a>

1. **表登记同步**：核对 `sys_menu` / `sys_role` / `sys_user` 等三张表的表文件「归属服务 / 模块」字段，下沉后归属标注为**基座共享**，并同步总览登记状态（表文件与总览两处一致）。
2. **自动建表发现口径**：核对 `bms_core.db.migration` 与 `ops.init_schema` 的模型包发现逻辑，确保基座 `bms_core.models` 被纳入扫描；补充断言防止迁包后漏表。
3. **契约与快照零漂移**：执行并确认 `ops.check_tables`、`ops.contract_snapshot check`、`ops.event_contracts check`、`ops.check_contracts` 全部通过；如有差异按规范重新导出归档并人工确认差异仅为包路径。
4. **迁移链核对**：确认 Alembic 建表链路在迁包后仍可完整建出三张表（历史迁移脚本已清空、机制保留，按新基线重建时走迁移路径）。

## 3. 完成标准 <a id="accept"></a>

- `check_tables` / `contract_snapshot check` / `event_contracts check` / `check_contracts` 全部通过且零漂移。
- 启动期自动建表与 `ops.init_schema` 均能建出三张表（含表前缀与约束）。
- 表登记在表文件与总览两处一致。
- 若重新导出契约归档，差异已人工确认为「仅包路径 / 生成顺序」，无实质契约变更。
