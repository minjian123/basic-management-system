## 2. 任务内容 <a id="content"></a>

1. **迁包**：把 `backend/services/platform/src/bms_platform/models/` 下的 `menu.py`、`role.py`、`user.py` 迁至 `backend/libs/bms_core/src/bms_core/models/`；模型定义、`__tablename__`、表前缀、字段、约束**一律不变**，仅改物理位置与导入路径。
2. **转发过渡**：在 `bms_platform/models/` 保留同名转发模块（re-export 自 `bms_core.models`），保证存量引用不一次性断裂；转发层在文件头标注「过渡期，禁止新增引用」。
3. **引用同步**：全仓 58 个文件 / 80 处 `bms_platform.models.{menu,role,user}` 引用改为 `bms_core.models.*`；平台服务内部引用优先改直连，非平台服务与 `ops` 全部改直连。
4. **`ops` 收口**：`ops/` 下 `seed_menu` / `seed_module` / `seed_platform` / `seed_rbac` / `seed_user` / `check_modules` 六个文件改基座路径；`check_plugins.py` 对 `bms_platform.main` 的依赖保留并显式标注为例外（其职责是实例化平台应用做校验）。
5. **依赖声明**：`bms_core` 的 `pyproject.toml` 补齐模型所需依赖；各服务 `pyproject.toml` **不新增**服务间源码依赖。

## 3. 完成标准 <a id="accept"></a>

- tenant 等服务镜像启动无 `ModuleNotFoundError: No module named 'bms_platform'`。
- `ops/` 下除 `check_plugins.py`（显式例外）外无 `bms_platform` 导入。
- 全仓 `bms_platform.models.{menu,role,user}` **直接**引用归零；经转发层的引用计入待清理清单并在文档登记。
- `uv sync --frozen` 通过；后端全量测试通过且覆盖率仍为行 + 分支 100%。
