## 3. 实施过程 <a id="process"></a>

### 3.1 engkit 建仓与九子命令

| 子命令 / 模块 | 落点 | 要点 |
| --- | --- | --- |
| `links` / `docs-scope` | `docs_links.py` / `docs_scope.py` | 链接与锚点、进度类字段落点护栏；跳过外部链接 / 行内代码 / `[docs].skip`；**目标按 URL 编码解码**（`unquote`，路径与锚点同办） |
| `selection` / `run-selected` / `coverage` | `selection.py` / `preflight.py` / `coverage.py` | 选测（目录同构 + AST 双重收敛 + 前端反向闭包）、定向执行（扩圈 ≤2 轮 + 退化兜底）、覆盖率合并与门禁 |
| `preflight` | `preflight.py` | 三档（定向 / `--fast` / `--full`）+ 预算护栏 + 步骤全配置化 + 自测按需 + 未包装拦截 |
| `run-once` | `runonce.py` | 缓存键 = 命令 + 工作目录 + 工作区指纹；命中回放完整输出与退出码 |
| `guard` | `guard.py` | 重命令 / 全量测试判定 + 提示 + `.pth` 钩子与 pytest 插件两通道共用 `classify()` |
| `coverage_plugin` | `coverage_plugin.py` | pytest 入口：**导入即启动采集**（早于被测模块导入）+ 守卫转调；未注入采集变量时静默不采 |
| `kiwi` | `kiwi.py` | SSH + `manage.py shell` 批量登记与回读，凭据取自各仓 `deploy/.env` 或环境变量 |

包内零仓名字面（`tests/test_guards.py::test_package_has_no_repo_literals` 机器断言）；配置解析缺段 / 类型错 / 未知键即报错退出码 2。
