## 2. 任务内容 <a id="content"></a>

1. **建仓与包骨架**：新仓 `engkit`（文档根 `engkit文档/`）；Python 包 `engkit` + 统一命令入口 `engkit <子命令>`（`links` / `docs-scope` / `preflight` / `run-once` / `kiwi`）；`pyproject.toml` 与依赖最小化（仅标准库 + 必要工具），各仓以 **git 源依赖锁 rev** 引用（与 `bms-core` 同构）。
2. **仓结构配置化**：包内**不含任何仓名 / 目录字面**；各仓根放一份配置（如 `engkit.toml`：文档根、源码根、工程清单、选测映射、覆盖率门槛键），包按配置探测；新增仓库只加配置。
3. **四类能力迁入**（自 `bms/scripts/tools/` 平移并按配置化改造）：
   - `engkit links`：Markdown 相对链接 + 锚点校验（吸收本次 mdm 临时脚本的判定口径：跳过行内代码 / 外部链接 / 本地凭据文档）。
   - `engkit docs-scope`：文档口径护栏——进度类字样只允许出现在阶段计划文档；保留行内 `docs-scope:allow` 例外标记与理由。
   - `engkit preflight` / `engkit run-once`：定向档（静态 + 基座/边界 + 按变更定向用例 + 变更源文件覆盖率门禁）、`--fast` / `--full` 档、预算护栏、重命令包装与缓存回放、未包装拦截。
   - `engkit kiwi`：Kiwi TCMS 用例批量登记与回读（分类 / 优先级 / 状态 / 标签 / `text` 字段），凭据从各仓 `deploy/.env` 或环境变量读取。
4. **bms 侧薄包装**：`check-links.py` / `check-docs-scope.py` / `check-preflight.py` / `run-once.py` 改为调用 `engkit` 对应子命令（入口名、参数、退出码、CI job 命令**全部保持**），`13_01` 选测器与 `13_02` 并行映射随之迁入并只留一份实现。
5. **各仓接入**：mdm 仓接入（依赖声明 + `engkit.toml` + 本地/CI 接线：`links` / `docs-scope` / `preflight`）；biz / cw 出接入说明（随各自窗口执行）。
6. **存量整改**：mdm 全仓需求 / 任务 / 实施 / 测试文档的进度类字段清理，唯一落点归阶段计划表；bms 侧口径不因迁移放宽。
7. **工作区模型同步**：`AGENTS.md`（仓库清单、依赖与引用写法）、`README.md`（从零搭建）、`scripts/tools/workspace/搭建工作区.*`、`.gitignore` / `.ignore` 与忽略模板、`*.code-workspace` 同步登记 `engkit`；`engkit` 仓自身文档根 `engkit文档/`。

## 3. 完成标准 <a id="accept"></a>

`engkit` 可按 rev 安装且 `links` / `docs-scope` / `preflight` / `run-once` / `kiwi` 均可用；**包内无仓名字面**（机器断言）；bms 侧同名入口与 CI 命令行为不回退（`--fast` / 定向档 / 缓存命中与 `--force` / 未包装拦截）；mdm 接入后链接 0 断链、口径 0 违规、一条命令跑出定向用例与覆盖率门禁；`13_01` 选测器与 `13_03` 四项护栏在迁移后全绿且**全仓只有一份实现**；工作区模型文档与搭建脚本已含 `engkit`；Kiwi 登记凭据仅存 `deploy/.env` / 环境变量。
