## 2. 任务内容 <a id="content"></a>

1. **契约迁出**：将 `bms_core/dict/`（`base.py` / `null.py` 及数据契约 `DictDataUser` / `DictDataPost` / `DictDataDeptNode` / `DictDataNameRef` 与常量 `DICT_DATA_STATUSES` / `DICT_DATA_TARGETS` / `DEFAULT_DICT_DATA_PAGE_SIZE`）迁 **mdm 主数据域**，由 mdm 提供真实实现（跨仓，见 mdm 需求 `01-3`）。
2. **基座清理**：移除 `bms_core/core/assembly.py` 的 `dict_remote_source` / `user_display` 装配与 `bms_core.org.null` 模块登记；移除 `bms_core/api/deps.py` 对应导出（`get_dict_remote_source` / `get_user_display`）。
3. **前端切换**：前端远程字典选择字段族（`DictRemoteSelectField` / `PostSelectField` / `DeptTreeSelectField` / `DictCompositePicker`）与 `src/dev/OrgCheck.vue` 出口地址切 mdm 主数据域公开契约；`DictRemoteSourceAdapter` http 默认实现指向 mdm 出口（查询与批量回显分列、部门树一次性返回），同步更新相关用例。
4. **兼容期**：mdm 出口就绪前不删除 bms 出口（依赖 mdm 需求 `01-3` 交付）。

## 3. 完成标准 <a id="accept"></a>

`bms_core/dict` 契约与装配 / 导出移除；前端远程字典选择字段经 mdm 出口取数联通（查询与批量回显分列、部门树一次性返回）；无残留 mdm 出口引用；`pytest` / `ruff` / `pyright` 与前端检查全绿。
