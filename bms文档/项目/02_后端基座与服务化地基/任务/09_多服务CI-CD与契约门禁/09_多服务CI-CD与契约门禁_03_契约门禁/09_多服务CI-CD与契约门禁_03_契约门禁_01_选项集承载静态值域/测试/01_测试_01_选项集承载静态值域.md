## 4. 已知问题 <a id="known"></a>

| 项 | 现象 | 结论 |
| --- | --- | --- |
| i18n 单条用例在超大批次下取不到种子文案 | 全闭包选测（含 `services/tenant` + `libs/bms_core` + platform 各域）时，`test_messages_dispatch.py::test_dispatch_default_and_explicit_locale` 报 `KeyError: 'common.confirm'`；单文件 / i18n 目录 / i18n + tenant 混跑均通过 | 与本任务值域改动无关（未触 i18n 种子内容与平台缓存路径）；按**存量测试隔离问题**单列，处置见 [实施记录 §4](../实施/01_实施_01_选项集承载静态值域.md#infra) |
| `shared-db-write` 锁被长期占用（约 600s） | 全闭包选测时 import_export / file / report / jobs 等套件出现 `TimeoutError: 等待测试锁超时：…shared-db-write.lock`，整轮耗时 ~11 分钟 | 跨进程等待链（取锁与写事务顺序相反）**存量问题**，单列后续测试基座任务；CI 按服务独立跑不受影响 |
| 契约基线文件行尾 | 基线在 Windows 生成，提交前需转 LF | 提交环 `engkit eol` 自愈暂存文件 |
