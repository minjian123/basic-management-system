## 3. 真机冒烟（mjbk） <a id="smoke"></a>

| 验证项 | 操作 | 实测结果 |
| --- | --- | --- |
| 工具镜像 | `docker pull tufin/oasdiff:v1.32.1` / `schemathesis/schemathesis:4.28.0` | 拉取成功（登记《镜像清单》） |
| oasdiff 兼容比对 | 基线 ↔ 当前 platform 契约（`breaking --fail-on ERR --format json`） | `[]`，exit 0 |
| oasdiff 破坏拦截 | 人为删除 `GET /api/v1/modules/snapshot` 后比对 | 输出 `api-path-removed-without-deprecation`（`level:3`、`path` 与 `operationId` 齐全），exit 1 |
| Schemathesis 命令口径 | 容器 `run --help` 实测 | `--max-examples` / `--checks` / `--include-method` / `--suppress-health-check` 有效；无 `--method`（改 `--include-method`） |
| Schemathesis 打真实服务 | `docker run --rm --network container:bms-platform -v …/contracts:/schemas:ro schemathesis… run /schemas/platform.json --url http://127.0.0.1:8000 --max-examples 5 --checks not_a_server_error --suppress-health-check all --include-method GET --include-method HEAD` | 选中 21/46 操作、540 用例全过，exit 0；仅 2 条无害警告（HEAD 无匹配、18 操作 404） |
| 源码起服务（冒烟路径） | 本机 `BMS_ENV=dev BMS_SERVER__PORT=18000 python -m bms_platform` | 1s 内 `/healthz` 200，`/readyz` 可用（冒烟起服务路径成立） |

## 5. 问题与处置 <a id="issues"></a>

| # | 问题 | 发现阶段 | 处置 |
| --- | --- | --- | --- |
| 1 | Schemathesis 无 `--method` | mjbk `--help` | 改 `--include-method`（见实施记录 §4） |
| 2 | 健康检查误报 | 冒烟命令设计 | 增 `--suppress-health-check all` |
| 3 | oasdiff `level` 数值 | mjbk 破坏拦截实测 | `count_breaking` 兼容数值 `3` |
| 4 | `--include-method HEAD` 无匹配告警 | mjbk Schemathesis | 无害警告（exit 0），保留只读语义，登记说明 |
| 5 | 工具容器与 job 容器跨网络 | 设计 / mjbk | `--network container:$HOSTNAME` 共享网络命名空间；mjbk 以 `container:bms-platform` 验证 |
