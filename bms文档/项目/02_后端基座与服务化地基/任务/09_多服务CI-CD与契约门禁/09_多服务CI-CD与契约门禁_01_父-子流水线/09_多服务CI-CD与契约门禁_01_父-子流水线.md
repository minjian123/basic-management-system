## 2. 任务内容 <a id="content"></a>

1. 父流水线按变更路径调度、trigger 拉起服务子流水线
2. 子流水线只构建 / 测试 / 发布该服务，镜像与版本独立
3. 公共模板经 include / Components 抽取、固定完整 SHA
4. resource_group 防并发发布打架

## 3. 完成标准 <a id="accept"></a>
