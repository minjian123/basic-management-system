## 2. 任务内容 <a id="content"></a>

1. 镜像按 commit SHA / 语义化版本打标签，禁 latest 作生产引用
2. 一键回滚（切换上一 tag，迁移向前修复优先）
3. 健康门禁（/readyz 与冒烟回归判定）
4. 发布留痕（检查单关键项 CI 采集）

## 3. 完成标准 <a id="accept"></a>

镜像标签不可变可追溯；回滚可一键完成；健康门禁生效；发布留痕可查；校验通过。
