## 3. 实施过程 <a id="process"></a>

1. **上下文与决策**：读需求 04-5、《架构设计 · 文件管理》「≤20MB 整包 / >20MB 分片」、《概要设计 · 系统参数》（`file.upload.max_size` = 20971520 / `file.upload.max_file_size` = 2147483648）、04_01 / 04_03 交付物与 `deploy/gateway/`（模板 / 编排 / APISIX 配置）现状。
   - **待拍板事项逐项确认**（question 工具，3 项）：① **取值口径** → 32m（20MB 整包 + multipart 开销 + 一片余量；经环境变量可调、生产可下调）；② **落点** → 双保险（边缘 nginx 先拒 + APISIX 全局同值纵深防御）；③ **实测方式** → 配置断言（机器可验）+ 真机 413 / 分片实测**随部署联调**（本机无容器运行时）。
2. **Kiwi 先登记后编码**：登记输入 `test/scripts/kiwi/cases/2026-10-08_阶段二04-1-2_网关请求体限制.json`（经 `register_cases.py` 走 Kiwi 容器 Django shell），平台回读编号 **2264**；用例以 `@pytest.mark.kiwi_id(2264)` 标注。
3. **配置落地（声明式入 Git）**：边缘模板 `client_max_body_size ${GATEWAY_MAX_BODY_SIZE};`（`location /api/`，随 `NGINX_ENVSUBST_FILTER=^GATEWAY_` 渲染）；编排 `gateway-nginx` 增 `GATEWAY_MAX_BODY_SIZE: ${GATEWAY_MAX_BODY_SIZE:-32m}`；`.env.example` 登记键位；APISIX `config.yaml` 的 `nginx_config.http` 节增 `client_max_body_size: "32m"`（同值）。
4. **校验扩展**：`ops/gateway_config.py` 增 `parse_size()` 与 `validate_body_size()`（五项断言：变量化声明 / 编排缺省 / APISIX 同值 / 环境模板同值 / ≥ 20MB），`check()` 接入并在违规时输出说明并返回 1（纳入预检与 CI）。
5. **用例**：`libs/bms_core/tests/ops/test_gateway_config.py` 增 5 例（仓库内通过 + 体积解析 / 模板硬编码拒绝 / 跨文件不一致拒绝 / 无缺省与低于整包上限拒绝 / `check` 违规退出码）；既有 2 例（roundtrip 与 `__main__` 守卫）补请求体上限夹具。

## 5. 问题与处置 <a id="issues"></a>

| 问题 | 现象 | 处置 |
| --- | --- | --- |
| 既有 roundtrip 用例的红 | `check` 新增请求体上限校验后，临时仓库根缺模板 / 编排 / APISIX 配置 / 环境模板 → 用例失败 | 测试文件增 `_seed_body_size()` 夹具（默认合法 + 可注入负例），既有 2 例补夹具 |
| 行长超限 | `ruff` 报 3 处 `E501` | 拆行（不改语义） |
| APISIX 键名版本差异 | 3.9+ 该节更名 `http_config`；本机无容器运行时无法启动校验 | 沿用该文件**既有可用** `http` 节（与访问日志配置同节、同镜像 `3.18.0-debian` 既有配置口径一致）；**若目标镜像启动校验拒绝 `http` 键名则改 `http_config`**，登记为实测口径（§7） |
| 无容器运行时 | 本机无 `docker` → 真机「超限 413 / 分片不受影响」实测不可行 | 按拍板改为**配置断言 + 随部署实测**（与 mdm 联调同批），登记遗留 |

## 6. 覆盖率与统计 <a id="coverage"></a>

- 新增校验为**纯函数**（`parse_size` / `validate_body_size`），分支（变量化 / 缺省 / 同值 / 下界）由 5 例覆盖；`check` 的违规分支由用例断言退出码与提示文本。
- 用例规模：网关配置用例 **12**（新增 5）；影响面（`ops` + `crosscut`）**202**。

## 7. 偏差与遗留 <a id="deviations"></a>

- **偏差**：① 实测方式由「真机实测通过」调整为「配置断言 + 随部署实测」（本机无容器运行时；已拍板）；② APISIX 键名沿用 `nginx_config.http`（版本差异见 §5 第 3 项，登记实测口径）。
- **遗留（归口）**：① **真机实测**（超限 413 + 分片上传不受影响）→ **部署联调**（与 mdm 联调同批；证据补入测试记录）；② **分片单片值**由文件管理阶段初始化接口下发，若单片 > 20MB 需同步上调网关上限（下界断言已兜 20MB，单片口径待该阶段定值回看）→ 文件管理阶段；③ K8s 阶段以 Ingress / Gateway API 等价配置承载（同语义）→ K8s 阶段。
