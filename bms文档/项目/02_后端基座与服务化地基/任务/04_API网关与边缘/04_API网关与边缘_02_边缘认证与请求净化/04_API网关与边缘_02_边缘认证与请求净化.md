## 2. 任务内容 <a id="content"></a>

1. 边缘校验收用户 JWT（签名 / 过期 / iss / aud）
2. 剥离伪造身份头、注入网关验证过的身份
3. 网关旁路防护（内部服务只接受带服务身份流量）
4. 后端只做授权、不重复认证

## 3. 完成标准 <a id="accept"></a>

未认证请求被拒；伪造身份头被剥离、注入身份正确；后端仅信任网关 / 服务身份流量；用例覆盖；校验通过。
