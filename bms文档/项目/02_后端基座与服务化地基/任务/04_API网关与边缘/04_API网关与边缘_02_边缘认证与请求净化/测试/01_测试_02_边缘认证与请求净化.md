## 5. 偏差与遗留 <a id="deviations"></a>

- **偏差**：`global_rules` 的 `headers.set` 被路由级 `proxy-rewrite` 丢弃（实测定位）→ 标记置入与身份注入落路由级；断言按最终实现编写并回写设计与《APISIX 部署使用说明》。
- **遗留（归口）**：真实用户 JWT / 服务 JWT 校验（含「未认证请求被网关拒绝」的端到端证据）→ **07_03**；限流 → **04_03**；生产 `require_gateway_identity` 开启随 07_03 认证接线。
- 用例编号以平台回读（**2166**）为准，代码 `@pytest.mark.kiwi_id(2166)` 标注一致。
