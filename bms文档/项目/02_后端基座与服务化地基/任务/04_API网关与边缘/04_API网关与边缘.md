## 1. 域说明 <a id="intro"></a>

本域对应阶段二「API 网关与边缘」：以 APISIX 建立边缘统一入口（路由 / 边缘认证 / 限流 / 灰度 / 边缘观测），standalone 声明式配置入 Git；服务发现走 DNS。依据《架构设计 · API 网关与边缘》；对应需求域四（04-1 ~ 04-5）。其中 04-4 / 04-5 为 2026-09-25 微服务对前端影响评估补登的补充需求，作嵌套子任务挂 04_01 下。
