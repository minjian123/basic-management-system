### 2.1 拆分边界 <a id="boundary"></a>

- **服务级登记**：平台应用仅挂本服务路由（断言 `/api/v1/demos` `/modules` `/plugins` 在、`/org` `/notifications` 不在）；`mount_service_routers` 使多服务同进程互不串扰。
- **表 / 表前缀唯一**：护栏扫描各服务 `models` 的 `__tablename__`——表名跨服务唯一；非 `sys_` 前缀跨服务唯一；`sys_` 平台域共享前缀例外。成功输出 9 服务表名前缀清单（`bms_ai: ai_`、`bms_notification: sys_`、`bms_platform: sys_* / demo`，其余无表声明）。

### 2.2 迁移不改语义 <a id="semantics"></a>

- 路由文件迁移后前缀 / tags / 依赖 / 响应契约不变（域测试断言原样通过）；`current_code_of` 迁入 `bms_core.api.deps` 后 icon / codecheck / print / tenant 行为不变。
- 骨架表模型迁移后仍不在任何迁移链表集（`ai_chat_log` / `sys_notification` 结构未变，仅归属服务）。
