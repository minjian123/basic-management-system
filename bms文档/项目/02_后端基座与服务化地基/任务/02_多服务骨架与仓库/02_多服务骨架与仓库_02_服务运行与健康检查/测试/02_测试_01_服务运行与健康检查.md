### 2.1 服务运行与探针 <a id="probes"></a>

- 探针响应统一追加服务身份：`/healthz` → `{status, service, version}`；`/readyz` → `{status, checks, service, version}`；启动未完成 / 停机中 → 503 + 空 checks（仍带身份）。
- `/readyz` 依赖就绪聚合沿用注册表（`redis` / `database`），失败 503、`error` 仅异常类名（不泄露连接串）。

### 2.2 优雅停机 <a id="shutdown"></a>

- 信号处理顺序由 `ServiceServer.handle_exit` 断言：先 `start_drain`（`draining` + 取消就绪），再父类置 `should_exit`。
- 真实进程冒烟：`python -m bms_platform` 收到 SIGTERM 后先输出 `service_shutdown_started`，再 `Shutting down` / `Application shutdown complete` / `Finished server process` 退出。
