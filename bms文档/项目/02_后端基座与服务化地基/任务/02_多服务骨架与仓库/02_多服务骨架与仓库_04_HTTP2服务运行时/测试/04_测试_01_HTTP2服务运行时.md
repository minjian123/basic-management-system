### 2.1 信号与停机 <a id="shutdown"></a>

- 控制器计数：第一次信号 → `ServiceRuntime.start_drain()`（`draining=True`、`/readyz` 503）→ `shutdown_event.set()`；第二次信号 → 记 `service_force_exit` 后 `os._exit(1)`。
- 未接入运行时（`on_drain=None`）只触发停机事件，不抛错。
- 真实进程冒烟：SIGBREAK 后输出 `service_shutdown_started`，hypercorn 关闭监听并完成 lifespan shutdown，退出码 0。

### 2.2 协议与 TLS <a id="tls"></a>

- 明文：HTTP/1.1 与 h2c prior knowledge 均可用；不支持 `Upgrade: h2c`（客户端须直接发 preface）。
- TLS：自签证书启动后，`httpx(http2=True, verify=False)` 经 ALPN 协商到 `HTTP/2`。
- 响应头由 hypercorn 生成（`server: hypercorn-h2`），不影响业务语义。

## 4. 问题与处置 <a id="issues"></a>

测试期暴露的问题（hypercorn 与 starlette 类型不同源、h2c 需 `http1=False`、既有链路用例依赖 uvicorn、冒烟子进程日志阻塞、mdm 单机启动依赖平台）与处置见[实施记录](../实施/04_实施_01_HTTP2服务运行时.md) §4；修正后定向用例与冒烟全部通过。

## 5. 覆盖率 <a id="coverage"></a>

- `bms_core.core.run`：模块级行 + 分支 **100%**（`coverage_report.py --module bms_core.core.run`，缺行 0 / 缺分支 0）。
- `bms_core.core.config` / `bms_core.core.logging` 的其它未覆盖段属既有代码，由提交环「改动行」与推送环扩圈选测判定；本轮改动行均被上述用例覆盖。
- `services/*/__main__.py` 与 `asgi.py` 为进程入口，覆盖率为 0%，与既有口径一致，由真实启动冒烟覆盖。

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：公开 API 改名 `build_config` / `serve_service` / `run_service`；优雅停机超时改为可配（默认 30s）；既有跨服务链路用例改用 hypercorn。均已回写详细设计与实施记录。
- **遗留归口**同[实施记录](../实施/04_实施_01_HTTP2服务运行时.md) §7：HTTP/1.1 性能由 msg 03-1 基准评估、证书热轮换（部署任务）、多 worker 口径（一服务一容器）、`server` 响应头指纹（另议）、mdm 跨进程上报与拓扑分发（部署环境回归）。
