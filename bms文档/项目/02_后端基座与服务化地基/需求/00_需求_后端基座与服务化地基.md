## 2. 阶段二目标与范围 <a id="goal"></a>

**阶段目标**（《总体项目规划》「阶段内容与完成标准」节 + 《微服务演进规划》）：**数据访问真实落库**（三库拓扑可路由、租户隔离与批量迁移正确、模块注册接库校验生效、`BaseModel` 落库与排序 DB 侧生效、基类异步切换完成、三库真库集成与达梦方言实测通过）+ **服务化地基就位**（网关 / 发现 / 契约 / 一致性 / 可观测 / 多服务 CI-CD、多服务本地一键拉起、每服务独立库迁移验证通过）。

**范围内**（共 33 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 01 后端基座真实实现 | 数据访问底座落库、多租户数据拓扑落库、`BaseRepository` / `BaseModel` 落库、Alembic 在线迁移与排序契约 DB 侧、三库真库集成与达梦实测、CI 三库 job |
| 02 多服务骨架与仓库 | monorepo 多服务工程与共享基座库、服务运行与健康检查、现有单体重构为分布式（保留阶段一~五产出） |
| 03 服务目录与契约登记 | `sys_module` 升格服务目录、服务清单与注册要素（表前缀 / 业务码 / 错误码段 / 事件域）登记与校验、服务目录只读接口 |
| 04 API 网关与边缘 | APISIX 接入与声明式配置入 Git、边缘认证与请求净化、限流与服务发现（DNS）、前端网关接入改造（按服务段寻址）、网关请求体大小限制 |
| 05 服务间通信与一致性 | 服务契约与同步调用规范、数据所有权与边界硬校验、事务性 Outbox 与幂等消费、事件契约版本与 Saga / 补偿 |
| 06 数据拓扑升级 | 平台层表归属与按服务拆分、每服务每租户建库与路由、多服务多库迁移编排与连接预算按服务、租户解析与库键派生健壮性 |
| 07 认证与服务身份 | OIDC IdP 接入、双类 JWT（用户 / 服务）、网关认证接线与服务身份校验 |
| 08 可观测性栈 | OTel 采集 + Tempo + Prometheus / Grafana + Loki、按服务归因与健康就绪 |
| 09 多服务 CI-CD 与契约门禁 | 父-子流水线、不可变镜像 + 一键回滚、契约门禁（oasdiff / Schemathesis） |
| 10 阶段验收 | 阶段验收门禁核对与阶段测试报告（含服务化地基门禁 S1~S7） |

**范围外**：

- 平台业务功能模块的真实实现（认证 / RBAC / 通用能力 / 工作流 / 报表 / 检索 / AI 等）——随对应阶段交付；本阶段只交付**基座与服务化地基**。
- 运行时热插拔与第三方 entry points 自动发现（后端插件化演进后两阶段，阶段三范围）。
- K8s 化部署与多主机迁移——演进路线（《微服务演进规划》 E1 / E2），本阶段维持单机多容器。
- 前端页面与微前端治理——随前端阶段与前端专题。
