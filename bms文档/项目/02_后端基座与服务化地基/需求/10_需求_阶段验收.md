## 1. 域说明 <a id="intro"></a>

本域对应阶段二「阶段验收」：核对阶段验收门禁（含服务化地基门禁 S1~S7）、产出阶段测试报告与证据索引，收口阶段状态。

**依据**：《总体项目规划》「阶段内容与完成标准」节（阶段二行）与「验收与收尾」节；《微服务演进规划》「服务化地基要求与门禁」节（S1~S7）；《测试规范》；《项目管理规范》。**目标**：阶段二门禁逐条有结论与证据；阶段测试报告归档；三类文档状态一致。

## 2. 需求 10-1：阶段验收门禁核对与阶段测试报告 <a id="r10-1"></a>

优先级：2（高）

**背景与动机**：阶段二体量大（后端基座真实实现 + 服务化地基），须以门禁逐条核对并留证据，避免「做完了但不可证」；服务化地基 S1~S7 为新增门禁，需与后端基座门禁一并核对。

**内容**（《总体项目规划》「阶段内容与完成标准」节、《微服务演进规划》「服务化地基要求与门禁」节）：

1. 门禁核对：逐条核对阶段二完成标准（数据访问真实落库 / 三库拓扑 / 租户隔离与批量迁移 / 模块注册接库校验 / `BaseModel` 落库与排序 DB 侧 / 基类异步切换 / 三库真库集成与达梦实测）与服务化地基门禁（S1 服务边界与契约 / S2 数据所有权 / S3 事件与一致性 / S4 服务身份 / S5 运行时无状态与外部化 / S6 分布式可观测 / S7 度量与门禁），逐项给出结论与证据索引。
2. 阶段测试报告：按《测试规范》产出阶段测试报告（用例执行统计 / 覆盖率 / 缺陷统计 / 风险与遗留项），归档到阶段目录。
3. 状态收口：需求 / 任务 / 计划三类文档状态一致；遗留项登记并归口。
4. 证据落点：门禁结论与证据索引落计划文档与测试报告（需求文档不承载门禁与进度）。

**完成标准**：阶段二门禁逐条有结论与证据；服务化地基 S1~S7 逐条判定（未达标不放行）；阶段测试报告归档；三类文档状态一致；遗留项登记归口；校验通过。

**参考文档**：《总体项目规划》「阶段内容与完成标准」「验收与收尾」节；《微服务演进规划》「服务化地基要求与门禁」节；《测试规范》；《项目管理规范》
