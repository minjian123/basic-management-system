## 2. 任务内容 <a id="content"></a>

1. 按[架构 41 §7.2](../../../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md#accept-criteria) 的八条判据逐条验收：同一性、越权拒绝、停用即时、未登记拒绝、审计可追溯、配额可核对、错误码一致、无复制实现。
2. 16 条需求逐条核对完成情况；每条给出结论（达标 / 限定达标 / 不达标）与证据索引。
3. 证据包括需求、设计、任务、实施 / 测试记录、基座与产品回归结果；证据不足的条目不得判达标。
4. 未达标项写明归口（后续任务、其他专项或明确不采纳），不得静默带入下一阶段。
5. 输出专项测试报告：验收点、核对方式、结论、证据、未达标项与归口。
6. **交付物**：专项测试报告（八条判据 × 结论 × 证据索引、16 条需求核对表、未达标项归口）；边界——不提前判达标、不以文档对齐代替行为验证、不静默带入下一阶段。

## 3. 完成标准 <a id="accept"></a>

八条判据逐条有结论与证据索引；16 条需求逐条核对；未达标项有归口；测试报告归档；结论明确（达标 / 限定达标 / 不达标）。
