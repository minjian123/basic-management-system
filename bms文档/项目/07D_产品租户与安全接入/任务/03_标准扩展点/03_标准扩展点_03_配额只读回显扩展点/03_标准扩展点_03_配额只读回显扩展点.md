## 2. 任务内容 <a id="content"></a>

1. 定义产品配额投影契约：维度、限额、用量、单位、周期、软硬限、更新时间、来源；字段语义统一。
2. 产品自维护配额值与执行点，值是单一事实源；平台只读装载，不写平台通用配额表、不做双写、不代替产品执行配额。
3. 产品登记数据源与取数端点；平台负责权限、脱敏与读取审计；缺省值、不可用状态、超限状态可区分。
4. 支持一个产品多个维度、多个 `module_key`；投影可按租户 / `module_key` / 资源维度聚合。
5. 消息平台现有用量端点与表单登记按契约改造，保持「产品自维护 + 平台只读」口径不变。

## 3. 完成标准 <a id="accept"></a>

投影字段完整且语义统一；平台只读可见且与产品侧一致；无双写；超限 / 不可用状态可区分；msg 改造后可用。
