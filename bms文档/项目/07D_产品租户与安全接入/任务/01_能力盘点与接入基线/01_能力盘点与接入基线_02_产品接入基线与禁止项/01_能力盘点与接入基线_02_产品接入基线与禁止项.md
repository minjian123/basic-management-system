## 2. 任务内容 <a id="content"></a>

1. 按[架构 41 §3 / §7 / §8](../../../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md#layers) 起草接入基线四段：继承项、扩展项、禁止项、验收判据。
2. 按产品接入阶段组织：登记 → 装配 → 声明 → 验收 → 护栏；写清每个阶段产品做什么、基座校验什么、失败如何处置。
3. 禁止项逐条给出判定方式：文档评审可判、护栏可判、或两者结合；不允许只写「禁止」而无判定方式。
4. 明确产品需求篇的写法：继承项只引用基线，扩展项才写产品语义；扩展项须说明「为什么只能由本品类实现」。
5. 以 msg / mdm 为样本试读基线，确认一个新产品只读基线即可完成接入设计；评审后定稿。

## 3. 完成标准 <a id="accept"></a>

基线四段齐全；每条禁止项有判定方式；产品需求篇写法有示例；与架构 41 无冲突；msg / mdm 试读通过。
