## 2. 任务内容 <a id="content"></a>

1. 定义作用域上下文：`tenant_id`、`module_key`、`resource_key`、产品自定义扩展；不可变，请求级或批次级，禁止全局单例。
2. 上下文注入三处：HTTP 依赖、数据面帧上下文、异步守卫返回值；业务模块只经上下文取作用域。
3. 定义六类错误码：租户不存在、租户停用、`module_key` 未登记、`module_key` 未启用、`resource_key` 未注册、`resource_key` 越界；产品码在登记段内，文案键由 i18n 管理。
4. 管理面与数据面同码；错误码经 03-2 的统一渲染单点，不在业务层拼装 HTTP 响应。
5. 审计上下文注入：作用域字段进入审计条目；记录级操作可带定位字段（见 03-4）。

## 3. 完成标准 <a id="accept"></a>

三类入口都能取到不可变的作用域上下文；六类错误码逐条有定义并登记；管理面与数据面同码；审计条目带作用域字段；无业务层自行拼装响应。
