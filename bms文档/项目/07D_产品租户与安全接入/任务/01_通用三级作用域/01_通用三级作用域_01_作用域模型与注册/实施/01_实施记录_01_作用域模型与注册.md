## 2. 决策确认 <a id="decisions"></a>

实施前分三批共 **12 项**逐项确认（结论已回写设计 §8），要点：

| 组 | 事项（结论） |
| --- | --- |
| 落点 | 值对象落基座共享包；注册记录落平台库新表 `sys_scope_resource_type`；登记走既有注册通道第十类声明；进数据库设计体系（表文件 → 总览 → 模型 → 建表） |
| 校验 | 装载期强校验（模块键已登记且启用 / 类型全局唯一 / 命名规则可编译）+ 请求期只读视图；装载期失败用 `CatalogError` 拒注册（不占 82 段码） |
| 字段 | 类型标识 `{module_key}.{kind}` 全局唯一；命名规则 = 正则 + `max_length`；版本 = `declaration_version` 整数自增；保留期 = `retention_days` + `removal_policy` |
| 接口 | 查询复用 `?with=resource_types`；运营期停用用「覆盖列」且不被声明重放冲掉；停用写平台审计链 |
