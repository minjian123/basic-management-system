### 3.2 关键实现口径

| 项 | 实现 |
| --- | --- |
| 解析顺序 | 租户（`BaseTenantGuard.require`）→ 模块形态 + 登记态 → 类型形态 + 前缀归属 + 注册与有效态 → 资源取值 + 归属 |
| 模块判定 | 只判 `sys_module.status`（`service_catalog_view()`，进程内），租户模块开关不进本链 |
| 类型已停用 | 与未注册同码（82011），内部日志分 `scope_resource_type_inactive` / `scope_resource_type_unknown` 两个事件 |
| 跨模块越权 | 类型标识前缀 ≠ `module_key` 即 82011（`scope_resource_type_cross_module` 事件） |
| 跨租户 | `owner_tenant_id` 传入且 ≠ 当前租户即 82012（`scope_resource_cross_tenant` 事件）；不传表示由产品授权模型保证 |
| 三路径 | `require` / `per_round` / `batch` 全部委托 `resolve`；数据面帧入口由 `03` 任务按同一入口接入 |
| 管理面 | `require_scope(module_key, resource_type, resource_from="path|query", owner=...)`；不自动读请求体（会消费请求流） |
| 失败语义 | 租户 80001 / 80002 / 10007 原样冒泡；模块与资源用 82009 ~ 82012 |
