## 5. 需求 01-4 用例（Kiwi 2449） <a id="w01-4"></a>

| 组 | 用例 | 断言 |
| --- | --- | --- |
| 事件 | 四类事件构造 | 载荷 `tenant_id` / `db_key` / `status` / `version` 齐备；信封租户位与聚合键 `tenant:{id}` 正确 |
| 事件 | 非法事件类型构造 | `ConfigError`（编程错误，构造期即拒） |
| 契约 | `tenant.deleted` 登记 | 版本 `2.1.0`；`version` 为可选 integer 字段 |
| 路由 | 四类事件各触发对应动作（参数化四例） | 只调对应动作一次，`applied` |
| 幂等 | 同版本重复投递 | 第二次 `skipped`，动作只执行一次 |
| 幂等 | 乱序旧版本 | `skipped`，不回退动作 |
| 幂等 | 新版本 | 执行并推进账本到新版本 |
| 失败 | 动作抛错 | 上抛且账本不推进；修复后同版本重投 `applied` |
| 非法 | 未知事件类型 | `EventContractError`（10010），不调动作 |
| 非法 | 载荷缺 `tenant_id` / `db_key` / `status`（参数化三例） | `EventContractError`（fail-closed） |
| 非法 | `tenant_id` 非十进制雪花 id | `EventContractError` |
| 非法 | `version` 非整数 | `EventContractError`（不按 0 猜） |
| 兼容 | 缺 `version` 的旧事件 | 按 `0` 处理，动作仍执行 |
| 空实现 | 四动作 + 账本 | 动作 no-op；账本可读写递增 |
| 装配 | `null` 缺省实现 / 未登记实现名 | 可解析为 `NullTenantResourceHandler` / `PluginError` |
| 配置 | 缺省 provider | `[tenant_resources].provider == "null"` |
| 基类 | 只实现账本的子类 | 四动作基类默认空实现，四类事件均可分发 |

**合计 23 例**（参数化展开后），文件 `libs/bms_core/tests/tenant/test_lifecycle.py`。

### 验收标准对照（需求 01-4） <a id="accept-014"></a>

| 完成标准 | 证据 |
| --- | --- |
| 四类生命周期事件可被产品消费并逐条验证动作 | 路由用例四例 + `build_tenant_lifecycle_event` 四类构造 |
| 重复投递不产生重复副作用 | 同版本 / 旧版本 `skipped` 用例；投递级 `(consumer, event_id)` 账本由既有消费者保障 |
| 停用拒绝与恢复受理即时生效 | 动作路由用例（`suspended` / `activated`）+ 基座入口拦截（租户守卫，01-2 已覆盖） |
| 删除后按声明保留期归档 / 清理且可核对 | `on_deleted` 契约与保留期字段（`retention_days` / `removal_policy`）在设计中固定；具体资源实现归产品 |
| 清理失败可重试、可观测、有死信出口 | 动作失败不记账 + 上抛用例；消费者重试与 `sys_event_dead_letter` 为既有链路 |
| 产品仓无自建租户状态表或轮询实现 | 基座只出端口与分发器；禁止清单写入设计 §4.3.8 |
