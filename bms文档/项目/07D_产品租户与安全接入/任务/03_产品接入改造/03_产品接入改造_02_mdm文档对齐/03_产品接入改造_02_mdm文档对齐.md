## 2. 任务内容 <a id="content"></a>

1. 盘点 mdm 现有租户与安全相关需求 / 设计，识别继承项与扩展项。
2. 改写 mdm 需求篇：继承项直接引用架构节点，删除对基座能力的重复定义；扩展项（如主数据资源作用域、字段级权限、组织数据范围等）保留并补边界说明。
3. 设计篇、任务篇按实际差异最小同步；本期不改 mdm 代码。
4. 验收：mdm 需求篇无基座能力重复定义；扩展项边界清晰；引用架构节点可达；基座能力缺失或不足的已回 bms 补（提需求或缺陷），不在 mdm 仓复制实现。
5. **交付物**：mdm 需求篇「继承项 / 扩展项」改写稿、扩展项边界说明、设计 / 任务最小同步清单；边界——本期不改代码、不扩产品业务范围、不改与租户安全无关的章节。

## 3. 完成标准 <a id="accept"></a>

mdm 需求篇按继承 / 扩展两类改写完成；继承项引用可达；扩展项有边界说明；设计 / 任务按需同步；无代码改动。
