## 2. 任务内容 <a id="content"></a>

架构 41 §5 已定「扩展点由基座定义契约、顺序与统一入口，产品只实现语义」。本任务把四类扩展点从语义落成可注册、可解析、可校验的契约，并明确资源级 ACL 的**约束**（不收敛为基座引擎）。接入次序固定为「作用域校验 → 错误码映射 → 配额回显 → 审计字段」，不得调换。

### 2.1 作用域校验扩展点（需求 02-1，架构 41 §5.1） <a id="w02-1"></a>

1. 契约：输入为作用域上下文 + 产品自定义参数，输出为通过或拒绝（产品码）；前三步（租户可用性、模块登记、资源注册）由基座完成，产品只注册第四步。
2. 装配：经统一插件机制注册与解析；必需扩展点未注册即拒启，可选扩展点按产品声明跳过，不得做成隐式必需。
3. 三路径复用：管理面、数据面、异步路径走同一扩展点；扩展点异常按 fail-closed 处理。
4. msg 迁移：命名空间校验迁入本扩展点，主题归属校验作为产品规则，迁移前后行为一致。

### 2.2 错误码映射扩展点（需求 02-2，架构 41 §5.2、§7.1） <a id="w02-2"></a>

1. 映射声明：产品声明「基座码 → 产品码」与文案键，只在统一错误渲染单点生效。
2. 登记与校验：产品码段在服务行登记、码级定义随自持声明装载；平台负责唯一性、撞码检测与契约反向对账。
3. 语义边界：只做语义改写——不改 HTTP 状态语义、不吞错、不把系统性失败（如租户源不可达）改写成业务成功或参数错误。
4. 禁止：业务层自拼 HTTP 响应、绕过统一渲染、使用未登记码段或文案键。

### 2.3 配额只读回显扩展点（需求 02-3，架构 41 §5.3） <a id="w02-3"></a>

1. 投影契约：维度、限额、用量、单位、周期、软硬限、更新时间、来源，字段语义统一。
2. 单一事实源：产品自维护配额值与执行点；平台只读装载，不写平台通用配额表、不双写、不代产品执行。
3. 平台侧职责：权限、脱敏、读取审计；缺省值 / 不可用 / 超限三态可区分。
4. 多维度聚合：支持一个产品多维度、多模块键，可按租户 / 模块 / 资源聚合。

### 2.4 审计字段扩展点（需求 02-4，架构 41 §5.4） <a id="w02-4"></a>

1. 字段契约：标准字段（谁、何时、对什么、做了什么、结果、来源与链路）之上允许产品补语义字段。
2. 留痕类别：产品声明必须留痕的操作类别；普通读写不逐条留痕，只做指标统计。
3. 记录级定位：涉及具体记录的操作带记录级定位字段，可从审计条目一次定位到记录。
4. 边界：扩展字段不改变哈希链构造与归档口径；产品不得自建审计表、不得绕过基座写入、不得删除审计记录。
5. 失败处置：需强审计的操作失败即失败；其余记指标与告警，不静默丢弃。

### 2.5 资源级 ACL 接入约束（需求 02-5，架构 41 §4.2-4、§8 红线六） <a id="w02-5"></a>

1. **定位**：ACL 是产品特有扩展，不是第五类标准扩展点；基座只给约束、判定顺序与上收条件，不实现通用 ACL 引擎。
2. **判定顺序**：基座 RBAC（功能级）→ 产品资源级 ACL → 作用域归属（`tenant_id` / `module_key`）；ACL 不得前置（前置会泄露资源存在性）。
3. **边界**：ACL 只在同一模块键内生效；跨租户、跨模块键一律拒绝且不因 ACL 放行；资源级授权不得扩大租户或模块边界。
4. **产品义务**：ACL 存储自持、不写平台表；变更留痕接 02-4；三路径同口径；重放 / 删除 / 位点重置等记录级操作必须有资源级校验。
5. **单点与上收**：判定收敛为单点接口（可替换），为「第二个产品提出同类需求时上收为基座通用授权能力」预留过渡。

## 4. 完成标准 <a id="accept"></a>

| 需求 | 完成标准 |
| --- | --- |
| 02-1 | 扩展点可注册、可解析、可配置；校验顺序不可绕过；三路径同结论；必需扩展点未注册即拒启；msg 迁移后跨租户 / 停用 / 未登记命名空间行为不变 |
| 02-2 | 映射可声明、可装载、可校验；撞码或未登记码段被拒；管理面与数据面同码；无业务层自拼响应 |
| 02-3 | 投影字段完整且语义统一；平台只读可见且与产品侧一致；无双写；三态可区分 |
| 02-4 | 扩展字段可写入、可查询；审计链完整、归档口径不变；普通读写不洪泛；记录级定位可用；失败处置有口径 |
| 02-5 | 判定顺序唯一且有用例证明 ACL 绕不过 RBAC 与作用域；跨租户 / 跨模块键有拒绝用例；三路径同口径；判定收敛为单点且具备上收替换条件；产品仓无自建 RBAC 引擎与复制权限码 |

- **风险与对策**：

| 风险 | 对策 |
| --- | --- |
| 扩展点契约过宽，变成第二套框架 | 只定契约与顺序、不承载业务；边界以架构 41 §3 的「扩展不复制」判定 |

| 四类扩展点接入顺序混乱 | 固定「作用域校验 → 错误码映射 → 配额回显 → 审计字段」次序，顺序变更须回写本节 |
