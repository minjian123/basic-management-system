## 2. 任务内容 <a id="content"></a>

1. 定义错误码映射扩展点：产品声明「基座码 → 产品码」映射与文案键，映射只在统一错误渲染单点生效。
2. 产品码段在服务行登记；码级定义随产品自持声明装载；平台负责唯一性、撞码检测与契约反向对账。
3. 管理面与数据面同码；映射只做语义改写，不改 HTTP 状态语义、不吞错、不把系统性失败改写成业务成功或参数错误。
4. 禁止业务层自行拼装 HTTP 响应、绕过统一渲染、使用未登记码段或未登记文案键。
5. 消息平台现有映射迁移到该扩展点；其他产品按需接入，未接入时沿用基座默认渲染。
6. **交付物**：映射声明格式、装载与撞码检测规则、统一渲染单点说明、msg 迁移对照表；边界——不改 HTTP 状态语义、不吞错、不允许业务层自拼响应。

## 3. 完成标准 <a id="accept"></a>

映射可声明、可装载、可校验；撞码或未登记码段被拒；管理面与数据面同码；msg 迁移后行为不变；无业务层自行拼装响应。
