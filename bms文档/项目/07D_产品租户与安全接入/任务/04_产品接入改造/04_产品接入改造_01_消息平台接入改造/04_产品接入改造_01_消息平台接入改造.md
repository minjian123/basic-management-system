## 2. 任务内容 <a id="content"></a>

1. **重写 msg 05**：只保留扩展项（重新编号 `05-1`、`05-2`…），继承项单独一节列出并引用 bms 07D 的需求编号；不再重复定义租户解析、认证、RBAC、审计链等基座能力。
2. **保留现有任务**：原「05-1 租户用量板块与表单登记」任务、Kiwi 用例与实施记录保留，归入新的扩展项；不废弃、不重挂历史。
3. **映射**：消息平台的 `namespace` 映射为 `module_key`，`topic` 映射为 `resource_key`；命名空间校验迁移到 03-1，主题归属校验作为产品规则。
4. **四项扩展点一次改完**：作用域校验、错误码映射、配额只读回显、审计字段扩展；改造后跨租户、停用、未登记命名空间、错误码、配额回显、`log_id` 行为与改造前一致。
5. **同步文档**：msg 设计 07、任务 05、规划 01、需求总览 00 的定位与引用同步更新；msg 仓与 bms 仓的跨仓依赖与声明登记保持一致。
6. **msg 扩展项对账**：逐条核对 msg `05-3`（配额，接 03-3）、`05-4`（topic ACL，接 03-5）、`05-5`（审计留痕，接 03-4）、`05-6`（生命周期，接 02-4，开通初始化已由 msg `05-1` 第 7 条承接）是否都有「基座契约 + msg 任务」两段；缺任何一段即视为未完成，不得只改文档不落任务。
7. **交付物**：msg 05 重写稿、五项接入说明（作用域校验 / 错误码映射 / 配额回显 / 审计字段 / ACL 约束）、msg 05-3~05-6 对账表（基座契约 ↔ msg 任务）、行为回归基线；边界——不改产品业务功能、不把产品实现回写 bms。

## 3. 完成标准 <a id="accept"></a>

msg 05 只含扩展项 + 继承清单，继承项引用可达；原 05-1 任务与记录保留并归入扩展项；四项扩展点全部接入；跨租户 / 停用 / 未登记 / 错误码 / 配额 / 审计行为回归通过；msg 设计与任务文档口径一致。
