# 产品租户与安全接入基线

> 07D · 继承项 / 扩展项 / 禁止项 / 接入流程 / 验收判据

[文档首页](../../../文档首页.md) › [07D 产品租户与安全接入](../README.md) › 产品接入基线

## 1. 目的与适用范围 <a id="purpose"></a>

本基线面向所有基于 BMS 基座的产品（mdm、biz、msg 及后续产品），回答四个问题：

1. **继承什么**——基座已经提供、产品必须使用、不得自建的租户与安全能力；
2. **扩展什么**——基座提供契约、产品实现语义的四类标准扩展点与产品特有扩展；
3. **禁止什么**——产品侧不得出现的复制实现与绕过行为；
4. **怎么验收**——产品接入完成后按什么判据核对。

**与架构节点的关系**：语义以《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》为准；本基线只把语义落成可操作的清单与流程，两者冲突时以架构 41 为准并回写本基线。本基线不写类名、代码落点、配置项与字段级结构，这些以实现侧清单与详细设计为准。

## 2. 继承项 <a id="inherit"></a>

继承项只有一份权威实现，产品按能力形态接入。能力形态分三类：**基座库契约**（进程内依赖）、**平台服务契约**（租户 / 认证 / 权限 / 审计等服务）、**平台数据源**（只读投影）。

| 能力 | 权威节点 | 产品接入形态 | 产品必须做什么 | 不得自建什么 |
| --- | --- | --- | --- | --- |
| 租户身份、解析链、状态、生命周期、通用配额、引擎路由 | [12-多租户路由](../../../设计/架构设计/12_架构设计_子系统_多租户路由.md) | 基座库契约 + 平台租户服务 | 装配租户中间件与租户源；请求与异步路径复用同一解析；停用即拒绝；消费 `tenant.*` 事件做产品资源初始化与清理，不自建状态机 | 租户表、解析链、状态缓存、开通停用流程 |
| 租户拓扑、业务域与部署单元 | [39-产品与服务划分](../../../设计/架构设计/39_架构设计_子系统_产品与服务划分.md) | 平台拓扑记录 + 运行时解析 | 按拓扑解析库与地址；不硬编码部署单元 | 拓扑记录、库名派生规则、跨单元直连 |
| 用户认证、SSO、会话、服务身份、密钥轮换 | [14-认证与会话](../../../设计/架构设计/14_架构设计_子系统_认证与会话.md) | 网关 + 平台认证服务 + 基座库契约 | 校验用户 / 服务令牌；按服务身份调用；密钥轮换走基座 | 用户令牌、服务令牌、会话、密钥管理 |
| RBAC、字段权限、数据范围、三权分立 | [15-权限计算引擎](../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md) | 基座库契约 + 权限元数据 / 数据来源接缝 | 注册权限码；接口挂权限码；数据范围经基座引擎 | RBAC 引擎、权限码体系、数据范围求值器 |
| 操作日志、登录日志、字段级审计、哈希链、归档 | [19-审计哈希链](../../../设计/架构设计/19_架构设计_子系统_审计哈希链.md) | 基座审计能力域 + 平台审计服务 | 声明留痕类别；按契约写审计；不自建审计表 | 审计表、哈希链、归档与校验 |
| 模块键、服务行、表前缀、错误码段、事件域 | [11-模块注册](../../../设计/架构设计/11_架构设计_子系统_模块注册.md) | 产品自持声明 + 平台装载校验 | 先登记后使用；声明与代码对账 | 第二套注册表、未登记标识 |
| 跨产品能力目录、分配与授权 | [38-跨产品协同](../../../设计/架构设计/38_架构设计_子系统_跨产品协同.md) | 产品自持声明 + 平台装载 + 服务身份 | 按能力名寻址；消费前有分配记录 | 对端服务标识、路径、动作名硬编码 |
| 限流、脱敏、降级、安全防护 | [31-性能与安全](../../../设计/架构设计/31_架构设计_性能与安全.md) | 基座库契约 + 网关 | 接口纳入基座限流与防护；敏感字段登记脱敏 | 第二套限流 / 脱敏 / 降级实现 |
| 扩展点装配与插件生命周期 | [10-扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md) | 基座库契约 + 配置驱动装配 | 按能力键注册实现；契约版本对齐 | 第二套装配 / 注册机制 |
| 事件总线与 `tenant.*` 事件 | [16-事件总线](../../../设计/架构设计/16_架构设计_子系统_事件总线.md) | 平台事件服务 + 基座库契约 | 注册事件域；按契约发布 / 订阅 | 第二套事件总线、自建租户事件 |

**继承原则**：

1. 同一能力只能有一个权威实现；基座已有实现，产品只能继承。
2. 继承不等于「只有远程调用一种形态」；按能力形态接入，不因「调用不方便」在本地复制一份。
3. 继承项不在产品需求篇重新定义，只引用本基线与权威节点。
4. 产品不得在本地缓存租户状态、权限结果、令牌校验结果并覆盖基座判定；基座版本戳是唯一失效依据。

## 3. 扩展项 <a id="extend"></a>

扩展项由基座定义契约、顺序与统一入口，产品只实现语义。四类标准扩展点是默认挂载点；不在此四类中的需求，先判定是继承、扩展还是新能力，不直接在产品侧开新口子。

| 扩展点 | 基座负责 | 产品负责 | 适用场景 | 不适用场景 |
| --- | --- | --- | --- | --- |
| **作用域校验** | 解析顺序、租户可用性、`module_key` 登记校验、`resource_key` 注册校验、错误渲染入口、审计上下文 | 声明 `resource_key` 类型与规则；实现资源级归属判定 | 产品有资源级隔离（主题、存储桶、作品、单据等） | 只有租户级隔离、没有资源级隔离的产品 |
| **错误码映射** | 统一错误渲染单点、产品码段登记、码表装载与撞码检测 | 声明「基座码 → 产品码」映射与文案键 | 产品需要稳定产品码、管理面与数据面同码 | 直接沿用基座码、无产品码段的产品 |
| **配额只读回显** | 投影契约、权限、脱敏、只读装载 | 维护配额值与执行点（单一事实源在产品侧）；提供只读取数 | 产品有自有配额维度（主题数、存储、吞吐、连接数等） | 只有基座通用配额、无产品维度的产品 |
| **审计字段扩展** | 审计链写入、哈希与归档、标准字段与扩展字段序列化 | 声明留痕类别；提供作用域 / 资源 / 记录级定位字段 | 产品有记录级操作（重放、删除、位点重置等） | 只需基座标准操作审计、无记录级定位需求的产品 |

**产品特有扩展**：资源级 ACL（如消息平台的主题 ACL）当前归产品自建，但必须满足：

- 不绕过租户与 `module_key` 边界；资源级授权只在同一 `module_key` 内生效；
- 权限判定顺序仍为「RBAC → 产品资源级 ACL → 租户 / 模块归属」；
- 若第二个产品提出同类需求，按《[平台可扩展性规划](../../../规划/平台可扩展性规划.md)》「边界争议的处置」上收为基座通用授权能力，原实现保留过渡期。

**扩展项写法**：产品需求篇写扩展项时必须回答三件事——① 为什么只能由本品类实现；② 边界在哪（不碰哪些基座能力）；③ 走哪个基座契约、怎么验收。回答不了三件事的，按继承项处理。

## 4. 禁止项 <a id="forbid"></a>

禁止项不能只靠文档约定，须同时有判定方式；判定方式分「评审可判」「护栏可判」「装载校验」三类。阻断级问题在评审与护栏双轨拦截；护栏规则设计见 07D 需求 05-1。

| # | 红线 | 判定方式 | 处理 |
| --- | --- | --- | --- |
| 1 | **租户权威**：产品不得自建租户表、解析链、状态缓存与生命周期 | 代码检索 + 依赖检查 + 评审 | 阻断 |
| 2 | **身份权威**：产品不得自建用户令牌、服务令牌、会话与密钥轮换；不得透传外部 access token 给内部服务 | 依赖检查 + 符号检查 | 阻断 |
| 3 | **权限权威**：产品不得自建 RBAC 引擎与权限码体系；权限码经模块注册登记 | 路径 / 符号检查 + 评审 | 阻断 |
| 4 | **审计权威**：产品不得自建审计表或哈希链、不得绕过基座审计写入、不得删除审计记录 | 路径 / 符号检查 | 阻断 |
| 5 | **数据边界**：产品不得直写平台租户 / 用户 / 权限 / 审计等平台表；跨服务读走契约或只读投影 | 依赖检查 + 表名字面量检查 | 阻断 |
| 6 | **扩展有界**：产品不得在四类扩展点之外复制基座机制；扩展点只实现语义 | 评审 + 符号检查 | 阻断 |
| 7 | **注册在先**：`module_key`、`resource_key`、错误码段、数据源、种子一律先登记后使用 | 装载校验 | 拒绝启动 / 拒绝请求 |
| 8 | **同码同语义**：管理面与数据面返回同一产品码；不得用产品码掩盖系统性失败 | 码表对账 + 测试 | 阻断 |

**护栏落地边界**：本轮只设计规则，不实现代码。规则须区分「继承层复制」「扩展点外复制」「字面量硬编码」三类；白名单须有期限与责任人，不得长期豁免。

## 5. 接入流程 <a id="flow"></a>

1. **登记**：产品在自持声明中登记产品档案、服务行、`module_key`、表前缀、错误码段、事件域、数据源、种子与 `resource_key` 类型；平台装载并校验唯一性与归属。
2. **装配**：产品应用装配基座中间件、租户源、租户可用性守卫、认证、权限、审计与四类扩展点（按需）；装配缺失或声明非法即拒启。
3. **声明**：产品需求篇按「继承项 / 扩展项」两类组织——继承项引用本基线与权威节点，扩展项写产品语义与边界。
4. **验收**：按 §7 的判据逐项验证；验收责任在产品，权威判定在基座契约。
5. **护栏**：产品仓库不得出现继承层实现；扩展层只经基座契约；护栏规则由平台统一设计，产品不得自行放宽。

**失败语义**：

| 时点 | 情形 | 处置 |
| --- | --- | --- |
| 启动 / 装配 | 继承项未装配、必需扩展点未注册、作用域声明非法、产品码段未登记 | 拒绝启动 |
| 请求入口 | 租户不存在 / 停用、`module_key` 未登记 / 未启用、`resource_key` 未注册 / 越界 | 拒绝，按产品码段返回，不泄露存在性 |
| 运行期 | 租户源不可达 | fail-closed（503），不静默放行 |
| 租户生命周期 | 停用 / 恢复 / 删除 / 归档 | 停用即时拒绝；删除后产品消费 `tenant.deleted` 按资源保留期清理，失败重试并进死信，不阻塞基座已提交的删除；产品不得自建租户状态机 |
| 审计 | 审计写入失败 | 需强审计的操作失败即失败；其余记录指标与告警，不静默丢弃 |

## 6. 产品需求篇写法 <a id="writing"></a>

产品需求篇固定两节：

```markdown
## 继承项

| 能力 | 权威节点 | 产品接入形态 | 验收判据 |
| --- | --- | --- | --- |
| 租户解析与状态 | 架构 12 | 基座库契约 + 平台租户服务 | 跨租户拒绝、停用即拒绝 |
| ... | ... | ... | ... |

## 扩展项

### 扩展 1：{名称}

- 为什么只能由本品类实现：{业务语义 / 资源模型 / 合规要求}
- 边界：{不碰哪些基座能力；资源级授权的生效范围}
- 基座契约：{作用域校验 / 错误码映射 / 配额回显 / 审计字段 / 产品特有}
- 验收判据：{可验证的现象或测试}
```

**写法要求**：

- 继承项只引用，不重新定义、不复制实现细节；同一能力在产品文档中只出现一次。
- 扩展项必须写清「为什么只能由本品类实现」；写不出来的，按继承项处理。
- 产品文档不得出现「本产品定义租户边界 / 自建认证 / 自建权限 / 自建审计」这类表述；如有，按禁止项处理。
- 示例只作写法参考，不替代各产品自己的需求文档。

**msg 的写法示例**（仅示意，具体以 msg 05 重写结果为准）：

- 继承项：租户解析与状态、服务 JWT、RBAC 权限码、审计链、通用配额、模块注册。
- 扩展项：`namespace → module_key` 映射、`topic → resource_key` 映射、主题 ACL、消息维度配额、首次发布懒初始化、记录级审计字段（`log_id`）。

## 7. 验收判据 <a id="accept"></a>

与《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》「验收判据」节一致：

1. **同一性**：同一请求在管理面、数据面、异步路径解析出同一组 `tenant_id / module_key / resource_key`。
2. **越权拒绝**：跨租户、跨 `module_key` 的访问被拒绝；同一 `module_key` 下的资源级越权按产品授权模型拒绝。
3. **停用即时**：租户停用后，生产与消费（含数据面与异步任务）按基座版本戳即时被拒绝，不依赖产品自建缓存。
4. **未登记拒绝**：未登记或未启用的 `module_key`、未注册的 `resource_key` 被拒绝，产品不得自造。
5. **审计可追溯**：管理操作可在基座审计链查到；涉及具体记录的操作可按记录级定位字段一次定位。
6. **配额可核对**：产品配额在平台侧只读可见，且与产品侧一致；平台侧无双写。
7. **错误码一致**：同一语义在管理面与数据面返回同一产品码；产品码在登记段内，无撞码。
8. **无复制实现**：产品仓库不出现继承层实现（租户解析、令牌、权限引擎、审计链等）；扩展层只经基座契约。

## 8. 变更与维护 <a id="change"></a>

- 本基线随架构 41 与 07D 需求变更；产品侧只引用，不复制。
- 基线变更须同步 01-1 继承清单、01-2 需求与 05-1 护栏规则，避免三处口径分叉。
- 产品需求篇与本基线冲突时，以本基线为准，并回写产品文档。
- 新增产品接入时，先读本基线，再写需求篇；不得跳过登记与装配直接写业务。
- 基线不承载进度；进度见[专项计划](../计划/01_计划_产品租户与安全接入.md)。
