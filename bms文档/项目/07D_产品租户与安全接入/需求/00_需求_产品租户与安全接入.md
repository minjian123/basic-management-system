## 1. 文档说明 <a id="purpose"></a>

本文档集是 **07D 产品租户与安全接入专项**的需求基线：把「产品特有的资源作用域、扩展点与禁止行为」收敛为可引用、可验收的需求，补齐通用三级作用域与四类标准扩展点。

- **上游依据**：《[平台可扩展性规划](../../../规划/平台可扩展性规划.md)》「总体模型」「代码复用能力边界」节、《[项目规划说明](../../../规划/项目规划说明.md)》「平台扩展接入流程」节。
- **架构语义**：《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》。
- **相邻专项**：07B 跨产品协同（能力目录与分配）、07C 产品与服务划分（业务域与拓扑）。

## 2. 目标与范围 <a id="goal"></a>

### 2.1 基座能力边界 <a id="boundary"></a>

基座已交付的租户、认证、权限、审计、通用配额、模块注册、能力契约、安全防护与事件能力**不设清单、不另立接入基线**：权威只在各架构节点（[12-多租户路由](../../../设计/架构设计/12_架构设计_子系统_多租户路由.md)、[14-认证与会话](../../../设计/架构设计/14_架构设计_子系统_认证与会话.md)、[15-权限计算引擎](../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md)、[19-审计哈希链](../../../设计/架构设计/19_架构设计_子系统_审计哈希链.md)、[11-模块注册](../../../设计/架构设计/11_架构设计_子系统_模块注册.md)、[38-跨产品协同](../../../设计/架构设计/38_架构设计_子系统_跨产品协同.md)、[31-性能与安全](../../../设计/架构设计/31_架构设计_性能与安全.md)、[16-事件总线](../../../设计/架构设计/16_架构设计_子系统_事件总线.md)），产品直接按节点契约接入。

- 能力可用即直接用，不在产品仓复制实现；
- 能力缺失或接口不足的，**回 bms 补**（提需求或缺陷，随对应架构节点演进），不在产品仓自行补齐后回写；
- 本专项只补三处缺口：**通用三级作用域**、**四类标准扩展点（含资源级 ACL 接入约束）**、**禁止层护栏规则与专项验收**。

### 2.2 范围内 <a id="in-scope"></a>

1. 通用三级作用域 `tenant_id / module_key / resource_key` 的模型、注册、解析、上下文、错误码与租户生命周期资源清理（域 01）；
2. 四类标准扩展点：作用域校验、错误码映射、配额只读回显、审计字段扩展；外加产品资源级 ACL 的接入约束（域 02）；
3. 产品接入改造：消息平台按四类标准扩展点接入，msg 先行（域 03）；
4. 禁止层护栏规则设计与专项验收（域 04）。

### 2.3 范围外 <a id="out-scope"></a>

- 基座已有能力的重新实现（租户解析、认证、RBAC、审计链、通用配额等），以及任何形式的继承清单 / 接入基线维护；
- 产品业务功能与业务权限模型；
- 资源级 ACL 通用化（当前归产品，如消息平台的主题 ACL；07D 只定义接入约束与上收条件，不实现通用 ACL 引擎）；
- 配额统一执行（当前只做产品自维护 + 平台只读回显）；
- 禁止层护栏的代码实现（本专项只设计规则，2026-11-07 收尾拍板明确不实现，见计划「后续阶段待办」第 1 条）；
- 各产品代码的全面改造（本期只 msg 按 03-1 接入四类扩展点）；mdm / biz 两仓本期不改动——两仓尚无「租户与安全」需求篇与产品扩展项，专项不生造需求，待其出现真实需求时另立。

## 4. 需求计数与演进 <a id="count"></a>

- 总条数：**12 条**（域 01 四条 / 域 02 五条 / 域 03 一条 / 域 04 两条）。
- 2026-11-05 立项：按「只补作用域、扩展点与护栏」的口径一次性建立；基座已有能力不重复建设。
- 2026-11-06 补两条承接需求：`01-4 租户生命周期与产品资源清理`（产品资源不能成为孤儿）、`02-5 产品资源级 ACL 接入约束`（把产品特有扩展提升为可引用、可验收的需求）。两条不新增基座通用能力，只补「产品怎么接」的口径。
- 2026-11-06 撤销原域 01（现有能力盘点 / 继承清单 / 产品接入基线与禁止项）：基座能力以架构节点为唯一权威，产品能用即用、缺失或不足回 bms 补，不再维护单独的继承清单与接入基线；原域 02~05 顺次前移为域 01~04。
- 2026-11-07 摘除 `03-2 mdm 文档对齐`、`03-3 biz 文档对齐`：盘点确认两仓没有「租户与安全」需求篇与产品扩展项，原需求举例的扩展项无对应文档与任务；按「不生造需求」口径摘除，专项 14 → 12 条，两仓本期零改动。该结论与遗留去向见[计划](../计划/01_计划_产品租户与安全接入.md)「后续阶段待办」节。
- 进度不在此记录（唯一落点为[计划](../计划/01_计划_产品租户与安全接入.md)）。
