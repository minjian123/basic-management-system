## 1. 文档说明 <a id="purpose"></a>

本文档集是 **07D 产品租户与安全接入专项**的需求基线：把「产品如何继承基座租户与安全能力、允许扩展什么、禁止复制什么」从各产品各自表述收敛为一份可引用的基线，并补齐通用三级作用域与四类标准扩展点。

- **上游依据**：《[平台可扩展性规划](../../../规划/平台可扩展性规划.md)》「总体模型」「代码复用能力边界」节、《[项目规划说明](../../../规划/项目规划说明.md)》「平台扩展接入流程」节。
- **架构语义**：《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》。
- **相邻专项**：07B 跨产品协同（能力目录与分配）、07C 产品与服务划分（业务域与拓扑）。
- **不重复建设**：基座已交付的租户、认证、权限、审计、通用配额、模块注册、能力契约等能力全部纳入继承清单，本专项只补缺口。

**盘点结论**：基座已有能力覆盖租户、认证、权限、审计、通用配额、模块注册、能力契约与安全防护；07D 的缺口只有四类——① 继承清单与接入基线；② 通用三级作用域；③ 四类标准扩展点；④ 产品接入改造与禁止层护栏。

### 2.2 范围内 <a id="in-scope"></a>

1. 现有能力盘点、继承清单、产品接入基线与禁止项（域 01）；
2. 通用三级作用域 `tenant_id / module_key / resource_key` 的模型、注册、解析、上下文与错误码（域 02）；
3. 四类标准扩展点：作用域校验、错误码映射、配额只读回显、审计字段扩展（域 03）；
4. 产品接入改造：msg 先行，mdm / biz 现有文档对齐（域 04）；
5. 禁止层护栏规则设计与专项验收（域 05）。

### 2.3 范围外 <a id="out-scope"></a>

- 基座已有能力的重新实现（租户解析、认证、RBAC、审计链、通用配额等）；
- 产品业务功能与业务权限模型；
- 资源级 ACL 通用化（当前归产品，如消息平台的主题 ACL）；
- 配额统一执行（当前只做产品自维护 + 平台只读回显）；
- 禁止层护栏的代码实现（本专项只设计规则，实现另立任务）；
- 各产品代码的全面改造（msg 按 04-1 改造；mdm / biz 本期只对齐现有文档）。
