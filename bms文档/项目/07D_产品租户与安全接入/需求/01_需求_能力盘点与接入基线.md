## 1. 域说明 <a id="intro"></a>

本域回答「基座已经有什么、产品必须继承什么、允许扩展什么、禁止复制什么」。它是 07D 其他域的前置：先盘清楚已有能力，避免把租户解析、认证、RBAC、审计链等已交付能力再立项；再形成一份所有产品可引用的接入基线，后续 msg / mdm / biz 的需求篇只写扩展项。

覆盖范围：现有能力盘点、继承清单、产品接入基线、禁止项与验收判据。依据见《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》第 3、6、7、8 节。

## 2. 需求 01-1：现有能力盘点与继承清单 <a id="r01-1"></a>

优先级：2（高）

**背景与动机**：07D 立项前，基座已经交付了租户解析、状态校验、生命周期、服务身份、RBAC、审计链、通用配额、模块注册、能力契约等能力；如果不先盘点，立项容易变成「把已有能力再写一遍」，既浪费投入，也会让产品侧误以为这些能力还要自建。消息平台的 05 文档就是典型：实际代码已复用基座，文档却按「本域定义一套」组织。

**内容**（[架构 41 §6.1](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md#inherit-list)）：

1. 盘点范围至少覆盖八类：租户（解析 / 状态 / 生命周期 / 通用配额 / 拓扑）、认证（用户 / 服务身份 / 会话 / 密钥）、权限（RBAC / 字段 / 数据范围 / 三权分立）、审计（操作 / 登录 / 字段级 / 哈希链 / 归档）、模块注册（`module_key` / 服务行 / 表前缀 / 错误码段 / 事件域）、能力契约（目录 / 分配 / 授权）、安全防护（限流 / 脱敏 / 降级）、事件（`tenant.*` 等）。
2. 每项记录：能力名称、权威架构节点、产品接入形态（基座库契约 / 平台服务契约 / 平台数据源）、现状（已交付 / 部分交付 / 缺口）、产品不得自建的理由。
3. 盘点结论按三类归档：**已交付可继承**、**部分交付需补齐**、**缺口需 07D 建设**；三类不得混写。
4. 形成《继承清单》，作为 07D 全部需求与各产品需求篇的引用源；清单变更随架构节点与产品自持声明同步，不另建第二份清单。
5. 明确「继承不等于只有远程调用一种形态」：进程内契约、平台服务契约、平台数据源三种形态并存，同一能力只有一种权威实现。

**完成标准**：八类能力逐项有权威节点、接入形态、现状与不自建理由；三类结论边界清晰，无「已有能力被列为缺口」；各产品需求篇可直接引用清单而不重复定义。

**参考文档**：《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》第 3、6 节；《[平台可扩展性规划](../../../规划/平台可扩展性规划.md)》「代码复用能力边界」节；[需求总览 §2.1 现有能力盘点](00_需求_产品租户与安全接入.md#inventory)。

## 3. 需求 01-2：产品接入基线与禁止项 <a id="r01-2"></a>

优先级：2（高）

**背景与动机**：只有盘点还不够——产品接入时真正需要的是「照着做」的基线：继承项怎么引用、扩展项怎么接、哪些事绝对不能做、验收看什么。没有这份基线，各产品仍会各自解释「多租户与安全」，文档口径继续分叉。

**内容**（[架构 41 §3 / §7 / §8](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md#layers)）：

1. 基线结构固定为四段：**继承项**（引用 01-1 的清单）、**扩展项**（四类标准扩展点 + 产品特有扩展，如资源级 ACL）、**禁止项**（八条红线）、**验收判据**（架构 41 §7.2 的八条）。
2. 基线按产品接入阶段组织：**登记 → 装配 → 声明 → 验收 → 护栏**；每个阶段写清产品要做什么、基座校验什么、失败如何处置。
3. 明确文档口径：产品需求篇**只写扩展项**；继承项只引用基线与权威节点，不重新定义、不复制实现细节；扩展项必须写明「为什么只能由本品类实现」。
4. 禁止项逐条给出判定方式：文档评审可判、护栏可判、或两者结合；不允许只写「禁止」而无判定方式。
5. 基线作为 07D 域 04 各产品改造的输入；产品侧不得自行放宽禁止项，护栏规则调整归域 05。

**完成标准**：一个新产品只读基线即可完成接入设计；继承项、扩展项、禁止项、验收判据四段齐全；每条禁止项有判定方式；与架构 41 无冲突；msg / mdm / biz 的需求篇可按此改写。

**参考文档**：《[架构设计 · 产品租户与安全接入](../../../设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》第 3、7、8 节；《[平台可扩展性规划](../../../规划/平台可扩展性规划.md)》「总体模型」「代码复用能力边界」节；《[产品租户与安全接入基线](../基线/01_产品租户与安全接入基线.md)》；[需求 01-1](#r01-1)。
