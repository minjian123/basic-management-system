## 阶段范围（2026-10-31 立项） <a id="scope"></a>

**做**：字典与系统参数、文件管理（分片 / 断点续传 / 预签名）、导入导出、事件总线（RocketMQ + 事务性发件箱）、任务调度（`sys_task` + 数据库调度器）、通知 / 公告 / 邮件短信、操作与登录日志、字段级审计与哈希链、国际化（语言包 + i18n 附表）、归档与回收站、首页工作台后端、表单定制后端（含租户自建字段动态 DDL）、帮助中心（锚点机制 + 产品包装载 + 内容展示）、锚点登记面（元数据 `help_key` + 清单格式）、异步链路容量口径；并补齐阶段四 06 字段类 / 07 展示类的占位组件。

**不做**：工作流引擎（阶段九）、开放接口与 Webhook 实现（阶段十）、报表与全文检索（十六 / 十八）、AI 生成能力（十九，本阶段只交付输入面与开关位）、备份管理（十三）、前端全页面（十五）。

## 贯穿口径（全阶段约束，单条需求不重复） <a id="rules"></a>

1. **写路径唯一**：数据由所有者域承载，平台只做出口（字典按 `data_source_key` 路由取数，无平台字典表）。
2. **软删除统一 `deleted_at`**，物理清理归定时任务；唯一字段用 `(唯一字段, deleted_at)` 复合唯一索引。
3. **审计先过链再归档**：审计类数据归档前必须通过哈希链完整性校验。
4. **多语言一律附表**：业务文案走 `{主表}_i18n`，缺省回退主表默认文案。
5. **异步只在副作用**：读与强一致写禁止异步化（平台《架构设计 · 事件总线》§3 判定）。
6. **帮助是横切机制**：声明面（`help_key`）+ 装载面（帮助包）+ 内容面；机制缺任一层即退化为人工维护。
