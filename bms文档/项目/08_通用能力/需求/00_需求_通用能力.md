## 1. 文档说明 <a id="purpose"></a>

本文档集是**阶段八「通用能力」**的需求基线：把平台侧「每个产品都要用、但谁都不该自己造」的能力一次做齐，并用统一口径约束——**能力在平台侧、数据按业务域归属、写路径只有一条、异步只在副作用**。

- **上游依据**：《[总体项目规划](../../../规划/总体项目规划.md)》「阶段内容与完成标准」阶段八、《[项目规划说明](../../../规划/项目规划说明.md)》「功能模块」节。
- **设计底稿**：《[概要设计 · 总览](../../../设计/概要设计/01_概要设计_总览.md)》与各模块概要设计（字典 09 / 参数 10 / 文件 13 / 通知 16 / 帮助 17 / 公告 18 / 导入导出 19 / 任务调度 23 / 邮件 24 / 操作日志 11 / 登录日志 12 / 审计 28 / 国际化 29 / 归档 30 / 回收站 32 / 工作台 35 / 表单定制 36）；架构 16（事件总线）、17（任务调度）、19（审计链）、28（帮助中心）。
- **前置阶段**：阶段二（数据访问 / 事务 / 事件契约 / 缓存 / 存储契约）、阶段三（后端插件化）、阶段六（认证与安全）、阶段七（RBAC：用户 / 角色 / 菜单 / 表单 / 字段 / 权限码）、07B（能力契约）、07C（域与拓扑）。

## 2. 目标与范围 <a id="goal"></a>

**范围内**：

1. 平台通用能力的**真实实现**：字典与系统参数、文件管理、导入导出、事件总线与任务调度、通知 / 公告 / 邮件短信、操作与登录日志、字段级审计与哈希链、国际化、归档与回收站、工作台后端、表单定制后端、帮助中心（机制 + 内容）。
2. **帮助中心按横切机制建设**（2026-10-31 口径）：锚点声明面 + 产品帮助包装载面 + 内容面；锚点登记面单列一条需求，因为它改的是阶段七的元数据表与产品清单格式。
3. **组件回补**：阶段四 06 字段类（字典 / 组织选择 / 文件上传）与 07 展示类（通知 / 文件预览 / 审计差异）随本阶段能力就绪补齐。
4. 异步链路的容量与延迟口径（非功能），与阶段验收。

**范围外**：工作流引擎（阶段九）、开放接口与 Webhook 实现（阶段十）、报表与全文检索（十六 / 十八）、AI 生成能力的实现（十九，本阶段只交付其**输入面与开关位**）、备份管理（十三）、前端全页面（十五）。

## 4. 需求计数与演进 <a id="count"></a>

- 总条数：**26 条 / 12 个需求域**（01 字典与参数 2 / 02 文件与导入导出 3 / 03 消息与任务 2 / 04 通知与公告 3 / 05 日志与审计 2 / 06 国际化 2 / 07 数据生命周期 2 / 08 工作台与表单定制 3 / 09 帮助中心 4 / 10 锚点登记面 1 / 11 容量与延迟 1 / 12 阶段验收 1）。
- 2026-10-31 立项。相对初稿（22 条 / 10 域）的变化：帮助中心由 2 条拆为 4 条（机制两条 + 覆盖率 + 内容展示），新增 `10-1` 锚点登记面（跨阶段改元数据表与产品清单格式）与 `11-1` 容量与延迟。
- **口径约束**（贯穿全阶段，不在单条重复）：① 写路径唯一（数据由所有者域承载，平台只做出口）；② 软删除统一 `deleted_at`，物理清理归定时任务；③ 审计类数据先过哈希链再归档；④ 多语言一律 `{主表}_i18n` 附表 + 缺省回退；⑤ 异步只在副作用（读与强一致写禁止异步化）。
- 进度不在此记录（唯一落点为阶段计划文档）。
