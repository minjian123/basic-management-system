## 2. 实施概览 <a id="overview"></a>

```mermaid
flowchart LR
    A[新建 help 业务域] --> B[五表模型 + 表归属]
    B --> C[包规格 / 校验和]
    C --> D[仓储读写]
    D --> E[计划器 + 装载 / 卸载]
    E --> F[help_content 的 db 实现]
    F --> G[CLI 薄壳 + 测试]
    G --> H[文档 / 登记回写]
```

- 域名与代码落点：`bms_platform.domains.help`（包规格 / 计划器 / 仓储 / 解析实现 / 命令行 / 公共出口），模型落 `bms_core.models.platform.help`。
- 五表进入 platform 服务租户链；`sys_help_article_i18n` 从「待落地」改为「已落库」。
- 装载 / 卸载默认 dry-run，实跑用 `--apply`；同一计划器保证计数一致。
- 装载后 `GET /api/v1/help/context` 由 `help_content` 的 `db` 实现返回文章、相关内容与分类；12_01 只补维护、状态机与缓存。
- HTTP 契约无变化，未重建契约快照 / 前端类型。

## 3. 实施过程 <a id="process"></a>

1. **表文件与数据库节点**：新建 `17_数据库设计_帮助中心.md` 与五张表文件（分类 / 文章 / 文章多语言 / 文章锚点 / 包登记），更新总览 §6.2 / §7.2 / §7.3、国际化 30 节点的附表状态。
2. **模型与归属**：新增 `bms_core/models/platform/help.py`；`MODEL_MODULES` 加 `help`；`TABLE_OWNERSHIP` 五表 `enabled`（`owner=platform`、`domain=help`、`datasource=tenant`），反馈表 `planned`；i18n 台账状态更新。
3. **新域与依赖**：`deploy/registry/platform.toml` 加 `[[domains]] help`；`domains/__init__.py` 加 `help`；`ops.check_modules --render-domain-layout` 重生成 `deploy/boundaries/domain_layout.json`（23 域 / 29 域外路径）；`pyyaml` 从 dev 组提升为 `bms_core` 运行期依赖并更新 `uv.lock`。
4. **包规格**：`package_spec.py` 实现清单 / `includes` / 校验和 / 分类 / 文章 / 来源留痕校验、`load_package` / `filter_unknown_targets` / `filter_for_tenant` / `compute_checksum` / `write_checksum`；校验和按「清单去 checksum 后规范化 JSON + 按声明顺序的被引文件（路径 + 长度 + LF 归一内容）」计算。
5. **数据访问**：`repositories/content.py` 提供分类 / 文章 / 多语言 / 锚点 / 包 / 目标占用查询与解析读面；新增基座只读助手 `bms_core/repositories/help_locale.py` 取租户默认语言（避免 help 域跨域 import 国际化模型）。
6. **装载与卸载**：`services/package.py` 实现同版本幂等、版本冲突 / 降级拒收、分类按路径 upsert、`local_override` 跳过、包内移除下线 / 再出现恢复、目标冲突跳过、卸载保留租户自建；计划器与执行器共用同一计数。
7. **解析实现**：`services/resolver.py` 的 `DatabaseHelpContentResolver`（`db`）按候选顺序直读租户库，来源优先级 `builtin > product > tenant`，语言三级回退；导入即经 `BasePluggable` 自动登记，平台服务 `configure_plugins` 在未显式配置时置 `db`。
8. **命令行**：`cli.py` 实现 `load` / `unload` / `checksum`；`ops/help_package.py` 薄壳（`RUN_IMAGE=platform` + `worker_id_lease_sync`）。
9. **错误码与文案**：新增 `40008`~`40013`（锚点不可解析 / 包非法 / 校验和不符 / 版本冲突 / 包未装载 / 分类路径不可解析）及中英文案。
10. **测试**：先登记 Kiwi 2522，再写规格 / 装载 / 解析 / 命令行 / 薄壳 / i18n 台账用例。
11. **文档回写**：概要 17 §4、架构 28 §3.3、帮助包规范 §3 / §7 / §8、后端基类清单、需求 09-2、任务 08_03、阶段计划。
