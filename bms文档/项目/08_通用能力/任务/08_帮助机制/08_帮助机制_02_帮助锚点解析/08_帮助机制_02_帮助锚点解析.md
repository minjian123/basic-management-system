## 2. 任务内容 <a id="content"></a>

1. 五级解析：字段 → 动作 → 表单 → 模块 → 全局，命中返回文章与锚点
2. 全不命中返回空 + 分类列表（前端「暂无帮助」）；按钮按命中显隐
3. `help_key` 随菜单与表单元数据接口下发；`GET /api/v1/help/context`

## 3. 完成标准 <a id="accept"></a>

五级命中与降级正确；全不命中可打开分类；无锚点不显示按钮；多篇按来源优先级取用。
