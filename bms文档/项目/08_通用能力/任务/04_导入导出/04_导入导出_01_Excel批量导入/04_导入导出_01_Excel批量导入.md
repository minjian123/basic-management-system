## 2. 任务内容 <a id="content"></a>

1. 模板下载（openpyxl，列头与说明，列集按表单布局生成）
2. 解析校验（类型 / 必填 / 长度 / 唯一 / 外键）→ 逐行落库 → 错误行报告（行号 + 原值 + 原因）
3. 幂等：`Idempotency-Key` + Redis SETNX + 唯一约束兜底；导入动作落操作日志

## 3. 完成标准 <a id="accept"></a>

非法行逐行报错且不落库；同幂等键只生效一次；万行级不超时；数据变更可在字段级审计追溯。
