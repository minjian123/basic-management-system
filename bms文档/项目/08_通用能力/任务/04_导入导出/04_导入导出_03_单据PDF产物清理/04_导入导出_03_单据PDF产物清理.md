## 2. 任务内容 <a id="content"></a>

1. 新增作业 `print.artifact.cleanup`：按 `print.artifact_ttl` 取「成功终态且完成时间早于阈值」的批量打印作业，删除其 `result` 里记录的单据 PDF 产物对象，并在 `result` 追加 `expired_at`
2. **覆盖防护**：单据打印产物 key 按「模板 + 单据」固定（重打覆盖同一 key），删除前反查同库是否有更晚的成功打印作业引用同一 key，有则跳过，避免删掉更新后的产物
3. **调度接线**：新增两条内置任务，分别提交 `platform.export.cleanup` 与 `print.artifact.cleanup`；补齐 04_02 遗留的「导出产物清理已声明但从未被调度」缺口
4. **参数归位**：新增 `print.artifact_ttl` / `print.pdf.sync_max_docs` / `print.cleanup_batch_size` 三个参数键与 `PrintLimits`，打印路由改用 `PrintLimits`；旧键 `export.pdf.sync_max_docs` 保留读取回退

## 3. 完成标准 <a id="accept"></a>

- 过期打印产物被删除，作业结果写入 `expired_at`；未过期作业与已标记作业不动
- 同一单据重打后的新产物不被旧作业的清理误删（跳过并留痕）
- 两条清理作业各由一条内置任务按 cron 提交，任务日志与作业终态各自独立
- 打印批量阈值从 `print.pdf.sync_max_docs` 读取，缺失时回退 `export.pdf.sync_max_docs`，行为不变
- 改动模块覆盖率 100%（行 + 分支），口径见《[AI开发规范](../../../../../规范/AI开发规范.md#coverage)》
