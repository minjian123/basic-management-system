## 3. 验收映射 <a id="accept"></a>

| 需求完成标准 | 用例证据 |
| --- | --- |
| 同一筛选条件下导出条数与列表总数一致 | `test_export_excel_stream_and_rows`（与 `/api/v1/users?size=1` 的 `total` 对照） |
| 无 `data:plain` 时敏感列脱敏，有该权限时明文且审计可查 | `test_export_masks_sensitive_columns`、`test_export_plain_with_data_plain`；审计到 capture 边界（落库归 06_01） |
| PDF 产物可通过限时链接下载，链接过期失效 | `test_export_list_pdf`、`test_real_export_pdf_and_template_routes`（`url` + `expires_in`）；产物过期路径为状态端点 `artifact=null` |
| 超阈值导出转异步且完成有通知 | `test_export_async_over_threshold`、`test_execute_job_stores_masked_artifact`（作业终态 + 取址）；**站内信**归 07_01 |
| 导出文件不出现在本地磁盘路径 | 产物只经对象存储 `put`；测试用 `tmp_path` 下的本地 provider，不写仓库目录 |

## 4. 覆盖率 <a id="coverage"></a>

- 开发环不采集覆盖率（口径见《[AI开发规范](../../../../../../规范/AI开发规范.md)「覆盖率要求」节》）；**推送前由预检覆盖率门禁补齐**，结论在推送后回填本节。
- 变更模块：`bms_core/transfer`（导出）、`bms_core/print`（渲染 / 模板 / 导出器）、`platform/import_export`（导出服务 / 端点 / 作业 / 仓储查询）、`report/domains/report`（作业 / 路由）。

## 6. 未覆盖与后续 <a id="gaps"></a>

- 真 MinIO / 真 Redis 集成：单测用本地对象存储与 `fakeredis`，真机验证登记部署窗口。

- 前端导出交互（按钮显隐 / 对话框 / 异步提示）：阶段十五，本段只验后端契约。
- 超大表导出性能（offset 分页末页扫描）：真库压测归 15_01 / 部署窗口。
