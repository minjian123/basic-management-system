## 2. 任务内容 <a id="content"></a>

1. 全表可配策略（时间字段 / 阈值 / 保留期 / 目标 / 批次 / 启停）
2. 两段式：热表 → 归档库（可在线只读查）→ MinIO 冷化；执行记录（批次 / 数量 / 状态 / 耗时）
3. 审计类数据归档前强制链校验，链不完整中止并告警；物理清理与合规销毁留痕

## 3. 完成标准 <a id="accept"></a>

到期自动归档且热表消失；归档库可读；链不完整中止；执行有记录；重复执行不重复归档。
