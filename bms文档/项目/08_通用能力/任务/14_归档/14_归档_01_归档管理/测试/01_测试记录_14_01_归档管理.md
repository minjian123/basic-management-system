## 4. 问题与偏差 <a id="issues"></a>

| 现象 | 处置 |
| --- | --- |
| 首次提交环缺「校验器扫描更早活跃月份」分支 | 补 `test_verifier_reads_earlier_active_month`，直接断言 `_tails_before` 与整体校验 |
| 异常类 / 归档会话依赖未覆盖 | 补错误码断言用例与 `test_archive_deps` |
| 冷化保留期为 0 的首轮边界 | 冷化条件改 `<=` 并纳入普通表用例断言 |

- 未覆盖范围：前端页面（阶段十五）、真库与压测（部署窗口）、租户库 / 产品表归档（产品接入）。
- 已知取舍：冷化「至少一次」重复执行会重写文件，以清单 `sha256` 核对，不做去重表。
