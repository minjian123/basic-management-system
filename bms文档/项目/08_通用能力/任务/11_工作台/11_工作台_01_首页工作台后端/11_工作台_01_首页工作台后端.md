## 2. 任务内容 <a id="content"></a>

1. 新建 `dashboard` 业务域与三张表（卡片注册表 / 卡片名多语言附表 / 模板表），登记表归属与域布局
2. 三级解析引擎：个人布局 → 角色模板 → 平台默认模板 → 启用内置卡最小布局回退；解析期过滤未注册与已停用卡片，不阻断整页
3. 卡片注册：内置卡（`builtin`）由平台种子登记、租户只可停用；数据集卡（`dataset`）租户自建，做结构与图表类型校验
4. 平台默认模板（唯一）与角色模板（一角色一份）维护；平台模板写操作要求平台超管
5. 个人布局保存与一键重置：落偏好基座 `dashboard.layout`，结构校验在偏好基座与工作台双处
6. 待办 / 未读角标统一出口 `GET /dashboard/badges`：待办走领域端口（工作流未落地时占位），未读经通知服务内部端点取数，单角标降级不阻断
7. 卡片清单与解析结果缓存 + 租户级版本键失效；内置卡与平台默认模板的租户库种子（幂等、只增不改）
8. 错误码 `40301~40308`、权限码 `dashboard:manage`、契约快照与前端类型重生成

## 3. 完成标准 <a id="accept"></a>

新用户首次登录得到平台默认模板布局；绑定角色模板后该角色用户看到角色布局，多角色按角色类型优先级命中；个人改动只影响本人且重置后回落到角色 / 平台 / 内置最小布局；停用某卡片后所有用户布局中该卡消失且不报错；自建数据集卡保存后刷新仍存在；待办与未读角标经统一出口返回且不可达时单角标降级；租户无法修改内置卡定义（`40308`）；布局越界 / 重叠 / 非法引用被拒（`40304` / `40301`）。
