## 2. 任务内容 <a id="content"></a>

1. 按 个人 → 角色 → 平台 三级回退解析布局，聚合卡片数据；空布局回退默认栅格
2. 个人布局（显隐 / 排序 / 拖拽 / 尺寸 / 自建图表卡）与一键重置
3. 卡片注册（内置卡租户只可停用）、平台默认模板（唯一）、角色模板
4. 待办角标经 Socket.IO 实时刷新

## 3. 完成标准 <a id="accept"></a>

新用户得平台默认；角色模板生效；个人改动仅本人且重置回落；停用卡片不报错。
