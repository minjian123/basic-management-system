## 2. 关键实现说明 <a id="impl"></a>

### 2.1 三级解析 <a id="resolve"></a>

- **层级命中**：个人布局（偏好 `dashboard.layout`，容错归一，非法项丢弃）→ 角色模板（按角色类型内置优先级 + 角色主键升序取首个**非空**模板）→ 平台默认模板 → 启用内置卡最小布局（`source=empty` + `fallback=true`）。
- **解析期过滤**：未注册 / 已停用的卡片从布局中剔除并写入 `warnings[]`（`card_unknown` / `card_disabled`），整页照常返回；卡片清单 `available_cards` 只下发启用卡。
- **响应形态**：`source` / `template_id` / `role_id` / `layout.cards[]` / `available_cards[]` / `warnings[]` 一次给全，前端不做卡片清单硬编码。

### 2.2 卡片注册与内置卡锁定 <a id="cards"></a>

- 内置卡（`builtin`）由租户库种子登记，租户**只可改 `status`**；改定义或删除 → `40308`。
- 数据集卡（`dataset`）租户自建：`code` 形态校验 + 重复 `40302`、图表类型白名单（`bar` / `line` / `pie` / `area` / `scatter` / `funnel`）、默认尺寸夹取、`chart_config` 结构校验。
- 多语言名落 `sys_dashboard_card_i18n`（复用 i18n 助手读写）；`name` 按「请求语言 → 系统默认语言 → 任一有值语言 → 请求体 name」派生，保证主表列非空。

### 2.3 模板维护 <a id="template"></a>

- 平台默认模板全库唯一（`scope=platform` + `role_id=0`，唯一键兜底）：重复创建 `40306`；写操作要求平台超管（角色类型 `platform_admin`，判定复用 `role_priority` 的口径）。
- 角色模板一角色一份：重复 `40307`；角色不存在 / 停用 `40305`；删除为软删，相关用户自动回退下一级。

### 2.4 个人布局与偏好基座 <a id="personal"></a>

- 保存为**整份覆盖**：严格校验（卡片数上限、`w` / `h` 界内、同可见集合内不重叠、码不重复、引用必须为启用卡）→ 失败 `40304` / `40301`；通过后落 `dashboard.layout` 并只失效本人布局缓存。
- 结构校验同时下沉偏好基座（`validate_dashboard_layout`），任何写入路径（通用偏好接口 / 移动端）都无法绕过。
- 一键重置删除偏好并返回 `applied`（是否确有个人布局），无个人布局时 `applied=false`。

### 2.5 角标统一出口 <a id="badge"></a>

- `GET /dashboard/badges` 聚合待办与未读：待办经领域端口（工作流未落地 → 占位 `available=false` / `reason=workflow_unavailable`）；未读经通知服务内部端点（服务身份 + 显式用户）真实取数。
- 单角标异常只降级该角标（`available=false` + 原因），不影响另一角标与整页。

### 2.6 缓存与失效 <a id="cache"></a>

- 卡片清单与解析结构走 `CacheRegion`（业务键 + 租户版本键，版本号自增即整体失效）；卡片 / 模板写操作递增版本，布局保存 / 重置只删本人布局缓存。
- 缓存不可用降级直连库，不阻断读接口。

### 2.7 种子 <a id="seed"></a>

- 6 张内置卡（todo / notice / notification / quick_links / help / stats，含 `render_key`、默认尺寸、移动端支持标记、`sort`）与平台默认模板（引用全部内置卡的初始布局）。
- **幂等且只增不改**：已存在的卡片不覆盖（租户停用后重跑仍停用）、模板不覆盖（租户改名保留）；新增卡才补行。

### 2.8 基座复用 <a id="reuse"></a>

- 角色类型优先级与「取首个非空候选」上移到 `bms_core/permission/role_priority.py`，`form_design` 改为复用（原常量再导出，既有引用零改动），避免工作台复制一份优先级表。

## 3. 偏差与遗留 <a id="deviation"></a>

| # | 项 | 处置 |
| --- | --- | --- |
| 1 | 详设写「卡片清单 / 布局缓存用 `bms:{tenant}:dashboard:*` 键」 | 实际统一走 `CacheRegion`（业务键 + 租户版本键）：与表单定制同口径，避免各域直拼 Redis 键；失效语义不变 |
