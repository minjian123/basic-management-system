## 2. 任务内容 <a id="content"></a>

1. 整包上传（≤20MB，MIME 白名单）与分片上传（初始化 → 逐片 SHA256 → 合并）
2. 断点续传按 `part_no` 只补缺失片；状态机 uploading / completed / failed / orphan
3. 预签名下载与图片 / PDF 预览（后端不代理流）；私有桶按租户前缀隔离
4. 配额联动（`storage_bytes` 超限拦截告警）与孤儿分片回收（01_02 内置任务）

## 3. 完成标准 <a id="accept"></a>

超限文件自动分片且断网续传可合并；白名单外被拒（含改扩展名）；预签名过期不可下载；配额拦截有告警。
