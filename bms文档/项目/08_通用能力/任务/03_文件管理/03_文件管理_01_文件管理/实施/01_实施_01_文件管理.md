## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 测试 SQLite 库陈旧（`sys_outbox` 无 `trace_id`）导致上传后写发件箱报 `no such column` → 503 | 删除 `/tmp/bms-pytest-sqlite` 后重建（删库重建口径）；教训：改表结构后本地测试库需一次性清理 |
| 2 | `current_tenant` 是 **ContextVar** 不是函数（`current_tenant()` 报 not callable） | 会话 key 构造改用 `current_tenant.get()` |
| 3 | 分片实现类上声明 `plugin_name` 会与工厂登记**重名**（导入即自动登记） | 实现类不声明 `plugin_name`，由工厂声明（同 `LocalObjectStorage` 口径） |
| 4 | 存储/分片 provider「必须完全一致」的强校验误伤平台插件切换用例（自定义 provider） | 收敛为只拦 `local`↔`minio` 互斥错配（§12 对齐记录 3） |
| 5 | 内部清理端点最初挂在带 `require_auth` 的 router 下 → 服务身份被用户鉴权拒 | 拆出 `router_internal`（无登录态依赖），仅 `require_service` |
| 6 | `complete` 首次实现不可重复调用（已完成后报 `50104`） | 改为幂等：`completed` 直接回既有结果（§4.4 口径） |
| 7 | 参数 bean 里派生白名单字段触发 pyright「partially unknown」 | 改 `field(init=False, default_factory=...)` + `__post_init__` 派生 |
| 8 | 裸集合护栏拦下测试辅助（`list` / `tuple` / `dict` 注解） | 统一落 `ConcurrentStable*`（含返回值包装） |
| 9 | 测试夹具导入 `file_ports` 触发 ruff F811 重定义 | 夹具迁入 `conftest.py`，用例只按参数名使用 |
| 10 | 预签名 TTL=1s 时首次直连即 403（签名时间与请求时刻贴边） | 真实用例改 5s → 立即 200、sleep 6s → 403 |
