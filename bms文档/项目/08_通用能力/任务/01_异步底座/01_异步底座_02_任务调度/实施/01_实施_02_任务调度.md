## 2. 实施过程 <a id="process"></a>

按详细设计 §9 的五批推进，每批独立提交、逐批跑开发环：

| 批次 | 落地内容 |
| --- | --- |
| 设计 | `设计/01_详细设计_02_任务调度.md`（11 节、20 条现状差距、12 条决策） |
| 表文件 | `sys_task` / `sys_task_log` 补字段与索引、状态转 `enabled` 进租户链 |
| 批 1 | `tasks/{cron,spec,handlers,builtin}.py`、模型补列、`TableStatus` 转换、`[task_scheduler]` 配置节、`70001~70006` 错误码与 6 个异常、4 个指标名 |
| 批 2 | `tasks/{store,queue,signal,scheduler}.py`、`ops/task_scheduler.py --beat/--list` |
| 批 3 | `tasks/worker.py`、`ops --worker/--once` |
| 批 4 | `domains/task/{api,schemas,repositories,services}`、路由挂载、`tenant/seed/tasks.py` + `ops/seed_tasks.py` + registry 种子段、公开契约快照 |
| 批 5 | 真机集成用例（双 beat × 真 Redis）、文档回写 |

**关键实现口径**（与设计一致）：

1. 单副本：`UPDATE sys_task SET next_run_at=… WHERE id=… AND (next_run_at IS NULL OR next_run_at<=:now)` 的 `rowcount=1` 才算抢到；Redis 锁（`bms:global:lock:beat`）只省扫描。
2. 顺序：抢占成功 → 写 `sys_task_log(running)` → `LPUSH`；入队失败只记 error，记录留待超时回收。
3. 同一 tick 顺带回收超时 `running`（`worker` 失联兜底）。
4. 执行器：应用内退避重试（只对异常）、终态与 `sys_outbox` 同事务、取消时消息回队。
5. cron 自研 5 段解析（UTC、日/周取「或」、4 年上界）。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 日志门面是 structlog 风格 `logger.warning(event, **fields)`，第一版按 `%s` 传位置参数直接 TypeError | 全部改关键字字段（`error=str(exc)` 等） |
| 2 | `BaseAsyncResource` 实际在 `core.capability`，不在 `core.roots` | 修正导入 |
| 3 | 嵌套 `async with` 让分支覆盖率出现**假缺口**（`217->218` 无法补齐） | 合并为 `async with (a, b):`（与 `ops/outbox.py` 同范式），覆盖率即 100% |
| 4 | 测试替身类未继承基类被 `check_backend_base` 拦 | 替身一律继承 `BaseFrameworkObject` |
| 5 | 测试里 handler 白名单写死包全路径不生效（pytest 模块名非 `bms_core.tests.*`） | 白名单改用 `__name__` |
| 6 | `BaseService` 的 `list` / `delete` 签名与任务域不一致（pyright 报 override 不兼容） | 服务改继承 `BaseFrameworkObject`（与 `RoleService` 同范式） |
| 7 | `uow.begin()` 前有读操作导致 `A transaction is already begun`（`update` 路径） | 读 + 写整体收进同一 `begin()` 块，提交后再发变更信号 |
| 8 | 雪花 ID 在响应体序列化为**字符串**，测试按 `> 0` 断言报 `str > int` | 断言改 `int(...)` |
| 9 | 新增 `[[seeds]]` 段使 `seed_catalog_view` 断言（9 条）失败 | 同步更新为 10 条并按声明序插入 `seed-tasks` |
| 10 | `contract_snapshot export` 顺带改写了 8 个无关服务快照（仅行尾差异） | 还原无关文件，只保留 `platform.json`，`check` 通过 |
| 11 | 集成用例两例共用同一队列键，xdist 并行时互相清键 | 改为各自独立键（`…:it-beat` / `…:it-roundtrip`） |
| 12 | `bms_isolate_settings` 会清 `BMS_*` 环境变量，集成用例读不到 `BMS_REDIS__URL` | 改为**模块导入期**读取连接串 |
