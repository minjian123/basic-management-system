## 2. 任务内容 <a id="content"></a>

1. `sys_task` 定义（name / handler / cron / args / status / last_run_at）与执行记录 `sys_task_log`
2. 自研数据库调度器：beat 单副本 + Redis 锁 `bms:global:lock:beat`，CRUD / 启停经 pub/sub 热加载
3. 手动触发与失败重试（有限次 + ack），执行完成落 `sys.task.completed` 事件
4. 内置任务：孤儿分片清理、日志归档、分片表预创建、软删除残留清理

## 3. 完成标准 <a id="accept"></a>

新任务不重启即生效；双 beat 不重复执行；停用不再产生记录；失败重试可查。
