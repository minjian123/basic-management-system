## 3. 依赖与风险 <a id="dep"></a>

依赖阶段二事件契约与 deploy 真 broker（msg 服务）；03_03 依赖 01_02（任务定义与调度）与 03_01（迁移对象）。风险：开发期也要跑 broker，本地环境成本上升，用 compose 一键起；作业中心迁移 01_02 执行器涉及既有任务 API 与执行记录，需保持查询口径不变并做回归。
