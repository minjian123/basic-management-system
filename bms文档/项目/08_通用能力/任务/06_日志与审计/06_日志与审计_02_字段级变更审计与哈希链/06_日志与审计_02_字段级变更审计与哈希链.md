## 2. 任务内容 <a id="content"></a>

1. ORM 事件捕获旧值 / 新值落 `sys_data_audit_log`（按月分表），含 `domain_key`
2. `record_hash = SHA256(prev_hash + 规范化内容)`，分区有序消费保证链序
3. 巡检任务校验链并接监控告警；三权分立（三类管理员互斥）
4. 合规留存与销毁（链随归档导出、销毁留痕）

## 3. 完成标准 <a id="accept"></a>
