## 2. 任务内容 <a id="content"></a>

1. 中间件捕获操作上下文（用户 / 模块 / 动作 / 参数 / ip / UA / 耗时 / 状态），敏感字段脱敏
2. 登录成功 / 失败记录，失败作为账号锁定判定依据
3. 经审计链组分区有序消费写入按月分片表；查询按条件筛选（`log:query`）
4. 链完整性校验（定期 + 归档前）；热表 90 天后交 14_01 归档

## 3. 完成标准 <a id="accept"></a>

密码类字段脱敏；失败次数与锁定一致；并发下链序正确、校验通过；篡改可定位。
