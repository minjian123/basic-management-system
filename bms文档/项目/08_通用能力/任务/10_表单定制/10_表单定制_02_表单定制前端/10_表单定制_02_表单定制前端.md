## 2. 任务内容 <a id="content"></a>

1. **契约适配层**：封装 `form_design` 域端点（布局 / 属性 / 自建字段 / 生效布局 / 动态校验），并把后端 DTO 转成前端模型（`attrs` 展平、`option_sets` 转 camelCase、三层布局行与属性行归并为 `FormLayoutLevels` 与层内属性表）
2. **表单设计器页**：表单选择、三级层级（平台默认 / 租户覆盖 / 角色视图）、字段面板与画布、**结构化属性面板**（必填 / 长度 / 范围 / 正则 / 选项集 / 默认值 / 只读 / 隐藏）、保存（布局 + 属性一并提交）/ 发布 / 恢复默认、自建字段新建与 DDL 重试
3. **动态渲染器页**：按 `layout-effective` 渲染三态（新增 / 编辑 / 查看）、字段权限剔除与 `editable` 标记、选项集零额外请求、校验与提交装配、明细页签
4. **列表页查询区与明细列消费**：新增查询区派生纯函数（布局查询字段 + 字段清单 + 选项集 → 查询字段声明），运行时页用既有查询筛选件渲染（≤3 不折叠、>3 进「更多筛选」）；明细列按渲染计划的明细列消费
5. **工具栏与帮助上下文复用**：列表 / 表单工具栏由 09_02 基类派生，页面内帮助入口按锚点显隐；补齐 `formdesign:manage` 权限码种子

## 3. 完成标准 <a id="accept"></a>

- 设计器可按层级读写布局与属性：保存后重新进入读到新值；恢复默认逐级回退（角色 → 租户 → 平台 → 空布局）；平台默认层级只读
- 自建字段全流程可用：新建触发建列、建列失败可见并可重试、停用不删列；枚举字段只能引用已注册选项集
- 渲染器按生效布局渲染三态：`visible=false` 字段与其布局引用一并消失；`editable=false` 保留并标记；选项集随元数据下发、零额外请求
- 查询区按布局生成且折叠口径正确（≤3 不折叠 / >3 折叠）；明细列按布局生成（含列宽）
- 类型检查零报错（desktop / ui_ep / core）；前端用例全过、desktop 工程覆盖率达标；后端权限码种子改动定向用例全过
- 原型逐页对照结论落测试记录（含截图证据）
