## 2. 关键实现说明 <a id="impl"></a>

1. **字段清单三源合并**：`GET /form-design/layouts`（三层布局 + 属性）+ `GET /forms/{code}/layout-effective`（平台字段，登录即可）+ `GET /form-design/fields`（自建字段全状态）。平台字段取生效响应（含停用标记），自建字段取清单（含待建列 / 建列失败），两者按 `sort` 升序、同序按键升序拼接（`layoutMapping.designerFields`）。
2. **属性保存随设计器「保存」**：`jobs.save` 内先 `PUT /form-design/layouts`、再 `PUT /form-design/attrs`（整份覆盖；只带非空属性的字段）。属性失败时给「布局已保存、属性失败」的部分成功提示并保留属性脏标记。属性键与后端 `dump_attrs` 同形（`required` / `placeholder` / `defaultValue` / `rules` / `optionSetKey` / `widget` / `readonly` / `hidden`），**不做二次转换**。
3. **发布 = 保存即发布**：后端无独立发布端点；`jobs.publish` 只提示「`sys.form.updated` 随保存事务发出」。
4. **恢复默认**：按当前层取布局行与属性行主键，`DELETE` 两行（缺失即跳过，幂等），随后整体重载。
5. **自建字段键派生**：后端必填 `field_key`，前端由英文名派生（驼峰转蛇形 → 小写 → 仅留 `[a-z0-9_]` → 合并下划线 → 去首尾 → 截 60）；派生不出合法键即拒收并提示补英文名。枚举类型把弹窗选项集下拉的选中项作为 `option_set_key` 提交（只引用注册表标识）。
6. **查询区派生**（`formQueryFields`）：顺序取 `layout.query.fields`（归一去重保序）；失效 / 停用 / 建列失败 / 类型不在白名单的字段跳过；`longtext` 落文本域，枚举字段候选项取 `optionSets` 快照。折叠口径复用既有查询筛选件常量（≤3 不折叠、>3 进「更多筛选」）。
7. **明细列消费**：沿用渲染计划的 `detailColumns`（布局 `detail.columns` 归一 + 列宽夹取 + 失效引用剔除），运行时页另以布局列生成预览表（含列宽）作为消费证据。
8. **工具栏与帮助**：设计器页用 `ListToolbar`（刷新 / 关闭 + 帮助），运行时页用 `FormToolbar`（编辑 / 提交 / 重置 / 重新载入 / 关闭 + 校验自测 + 帮助）；帮助入口由 `usePageHelpContext()` 派生，无锚点时自动不显示。
9. **权限码种子**：补 `("formdesign","manage","管理（含查询与维护）","Manage")`；同时修正 `_PERMISSIONS_BEFORE` 基线（08_04 补 `help:manage` 时未同步，本次一并校正为 125）。

## 3. 偏差与遗留 <a id="deviation"></a>

| # | 事项 | 处置 |
| --- | --- | --- |
| 1 | **10_01 契约漂移**：详细设计 §6.1 写了 `GET /form-design/attrs` 与 `GET /form-design/fields?status=`，实现无此二项 | 前端按**实现**对接（属性随 `GET /layouts` 返回、自建字段列表不分状态）；漂移在 10_01 记录中未登记，本记录留痕 |
| 2 | **文档称「8 个端点」**：实际 11 个（布局 3 / 属性 2 / 自建字段 4 / 渲染 2） | 前端按实际对接；数量口径以本记录为准 |
| 3 | **`LayoutSaveRequest.role_id` 契约为整型**，雪花 ID 转数值会丢精度 | 请求体按**字符串**提交（`roleIdPayload` 注释说明），后端 pydantic 宽松解析 |
| 4 | 当前用户 `visible=false` 的平台字段不进设计器面板 | 决策 3 的已知代价；真需配置不可见字段时改走 `menu:query` + `/fields` 方案（登记为后续待办） |
| 5 | 属性面板未提供多选数量上下限 `minItems` / `maxItems`、状态色映射 | 后端 `attrs` 白名单未收，归后续需求 |
| 6 | 真实业务列表页的查询区 / 明细列接入 | 归阶段十五页面迁移；本任务交付纯函数与样板页 |
| 7 | 独立发布端点 | 后端无；当前「保存即发布」 |
| 8 | 记录读 / 写接口 | 运行时页不注入 `jobs.loadRecord` / `jobs.submit`（无通用端点），真实业务页注入 |
| 9 | 两条静态路由暂无侧边栏菜单入口 | 归阶段十五菜单登记 |
