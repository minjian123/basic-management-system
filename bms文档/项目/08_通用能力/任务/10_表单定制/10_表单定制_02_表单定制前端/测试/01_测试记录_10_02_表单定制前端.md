## 6. 原型对照结论 <a id="prototype"></a>

基准：[表单设计器原型](../../../../../../设计/原型设计/07_表单定制/02_表单设计器.html)、[新建自定义字段原型](../../../../../../设计/原型设计/07_表单定制/03_新建自定义字段.html)；布局口径见《[布局设计 · 表单定制](../../../../../../设计/布局设计/14_布局设计_表单定制.html)》§3 ~ §8。

| 原型 | 对照点 | 结论 |
| --- | --- | --- |
| `设计/原型设计/07_表单定制/02_表单设计器.html` | 表单选择器 + 层级切换（平台默认 / 租户覆盖 / 角色视图）+ 角色下拉 | 一致（页面选择行实现，业务码下拉复用业务码清单） |
| 同上 | 三区结构：字段面板（平台字段 / 租户字段 / 新建自定义字段）/ 布局画布 / 属性面板 | 一致（复用 08_06 设计器三区，未改件形状） |
| 同上 | 字段加入画布、分区列数 1/2/3、跨整行、分区新建与删除 | 一致（件内既有交互，本任务只接数据通路） |
| 同上 | 属性面板：必填 / 默认值 / 提示 / 校验规则 / 组件类型 / 只读 / 隐藏 | 一致（本任务改为结构化提交：长度 / 范围 / 正则 + 选项集标识） |
| 同上 | 保存 / 发布 / 恢复默认 动作集 | 一致（动作集同原型；位置分为页面工具栏与设计器工具栏两处） |
| 同上 | 平台默认层级只读（按钮禁用 + 提示） | 一致 |
| 同上 | 查询区（姓名 · 部门 · 状态）与明细列配置入口 | 部分一致：查询区与明细列在设计器内由画布视图配置，消费面落运行时页（本任务范围外不新增设计器视图切换） |
| `设计/原型设计/07_表单定制/03_新建自定义字段.html` | 字段名称（必填）+ 多语言按钮 + 字段类型 + 物理列名只读预览 | 一致（弹窗承载；多语言以英文名输入 + 列名预览） |
| 同上 | DDL 三步（元数据入库 / 建列 / 已生效）+ 失败重试 | 一致（`ddl_status` 状态标记 + 重试按钮） |
| 同上 | 枚举类型的选项集只引用已注册标识 | 一致（新增 `optionSets` 下拉，禁止自由录入） |

**整体结论**：两条原型的主干交互（三区设计器、层级只读、动作集、自建字段与建列状态）在实现中一致；差异集中在「查询区 / 明细列」的配置面——原型将其画在设计器画布内，本任务按详细设计 §7 把消费面落在运行时页，配置仍经布局 `query` / `detail` 段承载，差异已登记 §7。

## 7. 边界与未覆盖 <a id="boundary"></a>

- 查询区 / 明细列在设计器内的视图切换未实现（原型有「查询表单区」提示行）：本任务按详细设计以布局字段承载、消费落运行时页；设计器内配置面归阶段十五页面迁移。
- 真实业务列表页（用户管理等）的查询区与明细列接入未做：交付纯函数 + 样板页。
- 记录读 / 写接口未接入：运行时页只做布局消费，提交仅上抛事件。
- 移动端（单列重排）另实现。
- 真实 DDL 建列与四库执行归部署窗口（10_01 遗留），本任务不重复验证。
