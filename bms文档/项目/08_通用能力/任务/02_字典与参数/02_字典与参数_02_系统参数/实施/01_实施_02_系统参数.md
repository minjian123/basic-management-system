## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 概要建议的参数错误码段 **402xx 已被菜单占用**（40201~40210），403xx / 404xx 又已被首页工作台 / 表单定制的概要预留 | 参数改用 **405xx**（`40501~40507`），回写概要 §7 并注明占用理由 |
| 2 | `(code, deleted_at)` 复合唯一在 `deleted_at IS NULL` 时**不生效**（NULL 互不相等，SQLite / MySQL / PG 同语义，已实测） | 唯一性改为**应用层判重**（`get_by_key` 先查）；表文件 §3 补实测结论；全平台软删表共性问题登记为开放项 |
| 3 | 两层取值实际是**租户库单行**（覆盖即覆写默认值），重置无默认值来源 | 增 `is_overridden` 标记 + 重置按 `PLATFORM_CONFIG_DEFAULTS` 回填；种子改为「未覆盖行刷新」，平台默认升级可下发 |
| 4 | 参数缓存写路径已 `DEL + INCR`，但**读路径不校验版本** → 多实例「即时生效」只在单实例成立 | 载荷改 `{v, value, missing}`，读路径每批取一次版本比对；真 Redis 双实例用例实证（A 失效 → B 下一读回源） |
| 5 | `current_user_id` 在 `models/base.py` 里是 **ContextVar**，服务层误当函数调用 → `TypeError: '_contextvars.ContextVar' object is not callable` | 改 `current_user_id.get()`（审计 `actor` 与敏感键日志两处） |
| 6 | 初版 `PUT` 一律置 `is_overridden=true`，导致「只改名称」也会失去默认项删除保护（可误删唯一承载平台默认的行） | 改为「值变了才转覆盖态」；补用例 `test_rename_keeps_platform_default_protection` |
| 7 | `MemoryConfigCacheRegion` 的 `aget_entry` 返回载荷时无法区分「确无此键（负缓存）」与「未缓存」 | 契约改为载荷级（`ConfigCacheEntry.missing`），`SqlConfigSource` 据 `missing` 跳过回源并按 `missing_ttl_seconds` 写负缓存 |
| 8 | 契约快照导出把其余 8 份服务快照写成 CRLF，产生无意义大 diff | 只提交 `platform.json`，其余 `git checkout` 还原；`contract_snapshot check` 9 服务零漂移 |
| 9 | 既有用例 `test_schema_creates_sys_config` 断言 `sys_config` 列集合 | 补 `is_overridden` 到期望集合（结构变更的必然回归） |
| 10 | 真机用例首跑 `KeyError`：临时库未播种子，被测键无行 | 夹具内 `seed_configs` 播默认种子后再跑 |
| 11 | 开发环静态拦截：`ruff` E501 / `ruff format` 未格式化；`check_bare_collections` 拦测试里的 `dict[str, Any]` 注解与 `payload: dict[...]`；`pyright` 报 `ConcurrentStableList[Literal[...]]` 不可赋给 `ConcurrentStableList[str]`、`dict.update(object)` 不匹配、`EventEnvelope.payload` 需集合类 | 分别改：拆分长行 + `ruff format`；辅助函数返回 `Any`（httpx 只吃内置 dict）、列表显式标注 `ConcurrentStableList[str]`、`payload` 改内联 `dict({...})`、审计替身 `payload` 改 `ConcurrentStableDict()` |
| 12 | 测试替身 `_RecordingAudit` 声明了 `plugin_name` → 被插件注册表**自动收集**，`/api/v1/plugins` 的 `audit` 分组多出一条 `registered` 实现。**单跑该用例文件必过、与新用例同 worker 跑才炸**（跨文件污染，xdist 下更难定位） | 去掉替身的 `plugin_name` 声明并加注释；结论：测试替身不得声明 `plugin_name` |
| 13 | `test_seed_menu` 基线「权限码 110」被我新增的 `config:manage` 打破 | 基线常量改 111 并注明来源（08-02_02），保持「只移除产品条目」的判据不变 |
| 14 | 推送预检首跑报 **91 个 setup error**（`SystemExit: 1`，`safe-delete bulk guard EPERM`）——本机 `PYTHONPATH` 指向 IDE 注入的 `sitecustomize` 安全删除 shim，xdist 并发建临时目录时抢锁失败；同一命令前一次 `--check` 却全过（锁竞争偶发） | 推送时改用 `PYTHONPATH= ...推送.py`（清掉 shim 注入）后一次通过；属环境噪声、与代码无关，登记备查 |
