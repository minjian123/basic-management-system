## 2. 任务内容 <a id="content"></a>

1. 参数分页 / 新增 / 修改 / 重置（软删除可回收），权限码 `config:manage`
2. 两层取值：平台默认 + 租户覆盖，读取缺省回退平台默认；Redis 短 TTL 缓存
3. 乐观锁 `version` 冲突提示；安全参数变更即时生效并落操作日志与字段级审计

## 3. 完成标准 <a id="accept"></a>

未覆盖取平台默认；覆盖仅本租户；重置回落；并发冲突返回版本冲突；删除进回收站可恢复。
