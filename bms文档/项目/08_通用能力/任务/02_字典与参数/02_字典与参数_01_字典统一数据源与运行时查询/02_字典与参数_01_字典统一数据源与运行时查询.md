## 2. 任务内容 <a id="content"></a>

1. 统一数据源登记（`data_source_key` / `kind` / 出口 / 字段白名单 / 状态），构建期清单、运行期只读
2. 运行时按 key + locale 经统一出口路由取数；未登记 key 返回空
3. 版本化缓存失效：删 Redis key + `INCR bms:{tenant}:dict:version`，进程内缓存按版本重载
4. 条目 `id` 为关联唯一键（业务表存 id），`value` 仅展示 / 导出；查询方案收敛到 `sys_query_scheme`

## 3. 完成标准 <a id="accept"></a>

字典六表在四类库均不存在；改数据后下一次请求即生效；业务表字典字段落 id；key 格式违规在启动 / CI 被拒。
