## 4. 问题与偏差 <a id="issues"></a>

| # | 现象 | 归因 / 处置 |
| --- | --- | --- |
| 1 | 真机集成用例首跑：实例 B 未命中 A 写入的共享快照，`load` 被调用两次 | **产品缺陷（已修）**：出口缓存载荷用 `ConcurrentStableDict`，Redis 侧 `json.dumps(default=str)` 把它变成 repr 字符串，读回 `json.loads` 失败 → 共享层只写不读。载荷改为 JSON 可往返的普通结构，并补 `test_cache_payload_is_json_roundtrippable` 回归 |
| 2 | 集成用例中 `RedisDictCacheRegion(url=...)` 读写均降级（日志 `缓存降级 … 共享客户端未就绪`） | 缓存域经**进程共享客户端**访问 Redis，不吃构造参数 `url`；用例改为 `set_shared_redis_client(RedisRedisClient(url))` + `setup()`，结束时 `clear_shared_redis_client()` |
| 3 | `[dict_cache_region]` 在 dev 设为 redis 后，identity 子进程用例启动失败（`_warmup` fail-closed） | dev 回退为基线 memory；跨实例一致性改由集成用例自建共享客户端验证（设计决策 5 已回写） |
| 4 | 角色写端点新增 `invalidator` 依赖后，公开契约快照漂移（仅 description 变化） | 重导 `deploy/contracts/platform.json`（3 处 docstring），还原其余 8 个快照的行尾差异 |
| 5 | 开发环并行跑出现 1 例 `services/tenant/.../test_registry_unknown_and_suspended` ERROR | 单跑通过（0.72s），非本段改动；并行下共享 SQLite 争用偶发，记观察项 |
| 6 | 推送门禁首跑 pyright 报 5.3 万条（`Import "pytest" could not be resolved`），非代码缺陷 | venv 外置且按平台分目录后 pyright 环境探测落到系统解释器；门禁步骤改 `{python} -m pyright --pythonpath {python}` |
| 7 | 推送门禁三跑 `services/tenant/.../test_tenant_self_service.py::test_dependency_provider_resolves` 失败（`策略取值非法：'demo_dept' → 'tenant'` / 无提供者覆盖） | 新启动校验读到了**产品清单注入项**；口径收敛为「只校验本仓 `DATA_SOURCE_CATALOG`」，产品侧由装载入口与跨仓对账保证。单跑不复现、完整选测复现（注入字典跨测试残留），收敛后 91 passed |
