## 1. 概述 <a id="overview"></a>

- **目标**：把阶段四已交付的 7 组组件从「注入式占位通路」接到阶段八真实后端出口，补齐版本联动、分片校验、预览失效重取与降级下载、通知 / 审计取数，销掉组件设计里的能力缺口；**不重写组件实现、不改组件对外契约**。
- **依据**：需求 [08-3](../../../../需求/08_需求_工作台与表单定制.md#r08-3)；《[架构设计 · 前端组件体系](../../../../../../设计/架构设计/05_架构设计_前端组件体系.md)》；阶段四 06 字段类 / 07 展示类组件设计与原型；03_01 文件管理、02_01 字典、06_02 审计、07_01 通知的详细设计与契约。
- **范围（本任务）**：
  - 宿主能力装配：字典 / 远程字典 / 上传 / 验证码 / 通知 / 审计默认源（组合式取用）。
  - 字典：展开 / 聚焦带版本重取（版本一致零传输）。
  - 上传：前端对齐 03_01 既有契约、补每片 `X-Part-Sha256`、补批量回显 `ids`（后端加参数）。
  - 预览：预签名过期时间透传、媒体失败降级下载。
  - 通知：HTTP 取数适配器 + 顶栏铃铛（替换待办占位）。
  - 审计：HTTP 取数适配器 + 组合式（组件保持纯 props）。
  - 远程字典 / 验证码：复用既有 HTTP 数据源，补契约用例。
  - 文档回写：组件设计「回补销账」注块、03_01 接口变更、计划 / 需求交付注块。
- **不含（归 09_02）**：通用工具栏基类、页面内帮助按钮、帮助长文对话框、`/help/context` 的 `anchor_found`、顶栏帮助入口、布局 05/06/07/08/10 的帮助位。详见 [09_02 详细设计](../../09_组件回补_02_页面内帮助与工具栏基类/设计/01_详细设计_09_02_页面内帮助与工具栏基类.md)。

## 2. 现状与差距（零重写） <a id="gap"></a>

**复用清单（不改实现、不改对外契约）**：

| 组件族 | 既有文件 | 本任务只做什么 |
| --- | --- | --- |
| 字典字段 | `DictSelectField` / `DictCascaderField` / `DictLabel` / `DictAdvancedQuery` / `ConditionGroupBuilder` + `BaseDictStore` / `BaseDictSelect` / `dictSource` | 加版本重取入口；补 HTTP 契约用例 |
| 远程字典 | `DictRemoteSelectField` / `UserSelectField` / `PostSelectField` / `DeptTreeSelectField` / `DictCompositePicker` + `dictRemoteSource` | 宿主默认源；补契约用例 |
| 文件上传 | `FileUploadField` / `FileListField` / `ImageUploadField` / `ImageCropDialog` + `BaseUploadEngine` / `uploadTransport` | 通路契约对齐、分片哈希、批量回显、预览过期透传 |
| 验证码 | `CaptchaField` / `ImageCaptcha` / `SliderCaptcha` / `SmsCaptcha` + `captchaSource` | 宿主默认源；补契约用例 |
| 通知公告 | `NoticeBell` / `NoticeList` / `NoticeMessageItem` / `NoticeDetail` + `BaseNotificationCenter` | 新增 HTTP 取数适配器；顶栏接线 |
| 文件预览 | `FilePreview` + `BasePresignedUrl` | 过期透传、失败降级下载 |
| 审计差异 | `AuditDiff` + `utils/auditDiff` | 新增 HTTP 取数适配器 + 组合式；组件不动 |

**真实差距**：

| # | 关注点 | 现状 | 处置 |
| --- | --- | --- | --- |
| 1 | 宿主默认源 | 组件要求显式注入，未注入即占位；宿主无集中装配 | **本段建**：宿主能力装配 + 组合式 |
| 2 | 字典版本联动 | 已加载后不再请求；版本比对只在首次加载 | **本段建**：`revalidateType` + 展开 / 聚焦调用 |
| 3 | 上传路径契约 | 前端 `uploads` / GET dedup 与 03_01 `multipart` / POST dedup 不一致 | **本段改**：前端对齐后端 |
| 4 | 分片校验头 | 引擎哈希只保留整文件 SHA-256，丢弃每片哈希 | **本段改**：保留每片哈希并透传 `X-Part-Sha256` |
| 5 | 批量回显 | 前端 `GET /files?ids=`，后端无 `ids` 参数 | **本段改**：后端列表加 `ids` 过滤 |
| 6 | 预览过期 | `FileUploadField` 取址固定 `expiresAt: 0` | **本段改**：透传 `expires_in` |
| 7 | 预览降级 | 媒体失败只重试一次，无降级下载 | **本段改**：错误态给下载按钮 |
| 8 | 通知取数 | 只有编排基类与轮询占位，无 HTTP 实现 | **本段建**：`createHttpNotificationJobs` |
| 9 | 审计取数 | 组件纯 props，无 HTTP 实现 | **本段建**：`createHttpAuditQuery` + `useAuditDiff` |
| 10 | 契约用例 | 字典 / 远程字典 / 验证码 HTTP 适配器无用例 | **本段建**：fetch 桩用例 |

## 3. 决策记录 <a id="align"></a>

| # | 事项 | 结论 | 理由 / 长期收益 |
| --- | --- | --- | --- |
| 1 | 组件是否重写 | **零重写**：只改数据通路与缺口点，不改对外 Props / 事件 / 插槽 / data-test | 阶段四契约冻结；避免重复开发与页面回归 |
| 2 | 上传契约方向 | 前端对齐 03_01 既有契约，后端不加兼容别名 | 契约事实源唯一，避免双套路径 |
| 3 | 分片校验 | 前端补每片 `X-Part-Sha256`，后端保持复算比对 | 保持 03_01 完整性安全口径 |
| 4 | 批量回显 | `GET /files` 加 `ids` 逗号分隔过滤 | 最小契约扩展、避免 N+1，与 06_07 设计一致 |
| 5 | 字典版本 | 展开 / 聚焦带本地版本重取，同上下文节流 | 与 02_01 版本三态一致；无需推送通道 |
| 6 | 远程字典 / 验证码 | 复用既有 HTTP 数据源，真实 mdm / 短信联调登记部署窗口 | 本仓不依赖外部服务即可验收 |
| 7 | 通知接线 | 新增 HTTP 适配器；顶栏「待办」替换为 `NoticeBell` | 组件可用、角标口径与 07_01 一致；待办另做 |
| 8 | 审计接线 | 新增适配器 + 组合式；`AuditDiff` 保持纯 props | 展示件不依赖取数，后续审计页复用组合式 |
| 9 | 宿主装配 | 宿主集中装配 + `useAppCapabilities` 组合式；组件契约不变 | 可替换、可测试、产品模块可覆盖 |
| 10 | 字典重取触发 | 下拉展开 + 字段聚焦，3s 节流 | 覆盖两种入口且不打爆后端 |
| 11 | 上传进度 | 分片粒度准确（每片完成更新）；整包 0/100 | fetch 无法拿字节级上传进度，分片粒度满足验收 |
| 12 | 预览降级 | 错误态给「下载文件」按钮，不自动下载 | 避免意外下载；用户可控 |
| 13 | 通知类型映射 | `approval→todo`，`system→system`，其余→`notice` | 复用既有三型语义色，不扩枚举 |
| 14 | 审计分组 | 按 `event_id` 分组为记录行，字段差异进 `diff` | 组件按记录渲染；后端按字段行返回 |
| 15 | 错误码 | 不新增；HTTP 失败透传后端码，前端内建码沿用 19xxx | 不扩码段，避免登记成本 |
| 16 | 测试 | 1 条 Kiwi；fetch 桩走契约 DTO | 一任务一条用例；mock 不造临时字段 |
| 17 | 提交 | `feat` + `docs` 两次，不推送 | 提交纪律 |

## 5. 领域设计 <a id="design"></a>

### 5.1 宿主能力装配 <a id="capabilities"></a>

`apps/desktop/src/capabilities.ts` 暴露单一能力装配：

| 能力 | 默认实现 | 端点 / 头 |
| --- | --- | --- |
| 字典 | `createHttpDictSource(dictSourceOptions())` | `platform` + `authHeaders` |
| 远程字典 | `createHttpDictRemoteSource(dictRemoteSourceOptions())` | 产品目录推导（mdm） |
| 上传 | `createHttpUploadTransport(uploadTransportOptions())` | `file` + `authHeaders` |
| 验证码 | `createHttpCaptchaSource(captchaSourceOptions())` | `identity` + `authHeaders` |
| 通知 | `createHttpNotificationJobs(notificationOptions())` | `notification` + `authHeaders` |
| 审计 | `createHttpAuditQuery(auditOptions())` | `platform` + `authHeaders` |

- 装配在 `main.ts` 启动期安装一次；端点选项复用 `api/endpoints.ts` 的服务前缀，不新增硬编码。
- `useAppCapabilities()` 只返回已安装实例；未安装即抛 `BaseError(19001)`，不静默降级。
- 组件仍以 Props 注入（`source` / `transport` / `jobs` / `fetcher`），不改成全局单例读取；宿主页面 / 核对页经组合式取默认源。

### 5.2 字典版本联动 <a id="dict"></a>

- `BaseDictStore` 新增 `revalidateType(key)` / `revalidateTypes(keys)`：**无论是否已加载**，带本地版本发起一次取数；`items=null` 复用缓存，版本变化替换条目。
- `BaseDictSelect` 新增 `revalidate()`；`DictSelectField` 在 `visible-change(true)` 与 `focus` 时调用，3 秒节流（同一字段）。
- 失败不覆盖已有缓存，错误态交给既有投影；不自动重试。
- 大字典远程搜索仍走原 `searchRemote`，不触发全量重取。

### 5.3 文件上传契约对齐 <a id="upload"></a>

| 动作 | 03_01 后端 | 前端调整 |
| --- | --- | --- |
| 秒传 | `POST /files/dedup`，体 `{name,size,sha256,mime}`，`data=null` 未命中 | `buildDedupBody`；`UploadCheckQuery` 补 `name` / `mime`；引擎传入 `task.meta` |
| 分片初始化 | `POST /files/multipart`，体 `{name,size,sha256,mime}` | `buildMultipartInit` 补 `name`；路径改 `/multipart` |
| 分片上传 | `PUT /files/multipart/{upload_id}/parts/{part_no}`，头 `X-Part-Sha256`，表单 `data` | 路径改 `/multipart`；引擎透传每片哈希；通路写头 |
| 已传分片 | `GET /files/multipart/{upload_id}`，返回 `uploaded` / `missing` | 路径改；`readUploadedParts` 兼容 `uploaded` |
| 合并 | `POST /files/multipart/{upload_id}/complete` | 路径改 |
| 取消 | `DELETE /files/multipart/{upload_id}` | 路径改 |
| 整包 | `POST /files`，表单 `file` | 保持；`sha256` 额外字段后端忽略 |
| 批量元数据 | `GET /files?ids=1,2,3` | 后端加 `ids`；前端保持 `buildResolveQuery` |
| 预签名 | `GET /files/{id}/download-url` / `preview-url`，返回 `{url, expires_in, method}` | 保持；浮层取址映射 `expiresAt` |

**分片哈希链路**：`BaseUploadEngine` 在决定模式后，对「分片模式或启用秒传」执行一次 `transport.hash`，保留 `{sha256, partHashes}` 到任务；`runPart` 传入 `sha256 = partHashes[partNo-1]`；通路写 `X-Part-Sha256`。哈希失败按上传失败处理（不静默跳过校验）。

**进度口径**：每片完成更新 `doneBytes / size`；续传按已传分片预置；整包 0 → 100。分片并发不改变总量口径。

### 5.4 文件预览 <a id="preview"></a>

- `useBaseFileUpload` 新增 `previewResultOf(id)`：经 `BasePresignedUrl.resolve(id, {purpose:'preview'})` 返回 `{url, expiresAt}`；`FileUploadField` 的 `previewFetcher` 改为返回该结果，不再写 `expiresAt: 0`。
- `FilePreview`：
  - `load()` 使用 `presigned.get()`，有效期内复用、过期重取；
  - 媒体 `error` 后重取一次；仍失败 → 错误态 + 「下载文件」按钮（`triggerDownload` 用当前 URL）；
  - `kind==='other'` 直接给「下载文件」按钮；
  - 未注入取址器 / 无 URL → 错误态给下载按钮（有 URL 时）。
- 不自动下载，避免浏览器拦截与意外；下载事件仍上抛。

### 5.5 通知与公告 <a id="notice"></a>

`createHttpNotificationJobs({endpoint, headers})`：

| Jobs 方法 | 后端 | 归一 |
| --- | --- | --- |
| `load({type,read,page,pageSize})` | `GET /notifications?page&size&type&is_read` | `{list,total}` → `{items,total}`；类型映射 |
| `loadUnread()` | `GET /notifications/unread-count` | `{count}` |
| `detail(id)` | `GET /notifications/{id}?mark_read=true` | `Notification` → `NotificationMessage` |
| `markRead(ids)` | `POST /notifications/read` `{ids}` | `{count}` → `{unreadCount}` |
| `markAllRead()` | `POST /notifications/read-all` | `{count}` → `{unreadCount}` |
| `remove(id)` | `DELETE /notifications/{id}` | `boolean` |

- 类型映射：`approval → todo`、`system → system`、`message/notice/import/alert → notice`。
- 顶栏：`AppHeaderBar` 用 `useBaseNotification({jobs, ready:true})`；挂载后 `syncUnread()` + `load()`（最近 5 条）；`NoticeBell` 接收 `items` / `unreadCount` / `connectionState`；打开详情用 `NoticeDetail`，已读 / 全部已读 / 删除调用 jobs。
- 权限：未读数接口登录即可；列表 / 详情 / 已读 / 删除需权限码。403 时铃铛保留但列表给错误提示，不把整页打崩；无 `notification:query` 时只校准未读数。
- 实时：本轮不接 Socket.IO；`BaseNotificationCenter` 的轮询占位负责未读数校准（30s，页面可见时）。

### 5.6 审计差异 <a id="audit"></a>

- `core/domain/audit.ts`：`AuditRow`（后端字段行）、`AuditRecord` / `AuditFieldDiff`（组件入参）、`groupAuditRows(rows)`（按 `event_id` 分组）、`parseAuditJson(text)`（旧值 / 新值 JSON 文本解析，失败保留原文）。
- `createHttpAuditQuery({endpoint, headers})`：`page(filter)`（`table_name` / `record_id` / `operator_id` / `occurred_from` / `occurred_to` / page / size）、`detail(id)`、`verify(months?)`。
- `useAuditDiff`：
  - `records` 由 `page` 结果分组；`total` 取后端 total（按字段行计，页面注明「条数按字段变更计」）；
  - `select(record)` 调 `detail` 取该 `event_id` 的字段行（后端详情按审计主键；列表行首条 id 即可）；
  - `diff` 映射为 `AuditFieldDiff`；`prevHash` / `recordHash` 取组内首 / 末行；
  - `verify()` 调链校验，`chainVerified` 映射；失败给错误文案。
- `AuditDiff` 不改；页面用组合式把结果传入。筛选的「操作人」按操作人 ID 字符串传 `operator_id`；时间范围必填沿用组件既有禁用逻辑。

### 5.7 远程字典与验证码 <a id="remote-captcha"></a>

- 复用 `createHttpDictRemoteSource` / `createHttpCaptchaSource`；宿主提供默认实例。
- 用例用 fetch 桩按生成契约 DTO 返回：远程字典查询 / 批量回显 / 部门过滤；验证码出题 / 短信 / 校验 / 策略。
- 真实 mdm 服务与短信渠道联调登记部署窗口，不在本任务阻塞。

## 7. 失败分支与边界 <a id="failures"></a>

| 场景 | 处置 | 结果 |
| --- | --- | --- |
| 字典重取失败 | 保留旧缓存，投影给错误态 | 不清空已选项 |
| 字典版本一致 | `items=null` 复用缓存 | 零传输 |
| 分片哈希失败 | 任务失败，可重试 | 不跳过 `X-Part-Sha256` |
| 分片接口 4xx / 5xx | 任务失败，错误码透传 | 可重试 / 取消 |
| 续传查询无 `uploaded` | 回落到会话已传 / 全量 | 不误判完成 |
| 批量 ids 超 200 / 非法 | 后端 `10001` | 前端不发起超量请求 |
| 预签名过期 | 自动重取一次 | 成功则继续预览 |
| 预览仍失败 / 类型不支持 | 错误态 + 下载按钮 | 可下载 |
| 通知 403 | 铃铛保留，列表错误提示 | 不白屏 |
| 通知详情已删除 | 后端 404 → 提示并移除该项 | 角标校准 |
| 审计无权限 | 组合式错误态 | 页面按权限隐藏入口 |
| 审计字段值非 JSON | 原文展示 | 不抛错 |
| 审计跨分片分页 | 按字段行分页，页面注明 | 不伪造记录总数 |
