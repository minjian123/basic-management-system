## 1. 概述 <a id="overview"></a>

- **目标**：在既有主框架 / 表单框架 / 页面容器 / 用户管理页上，补一套**通用工具栏基类**（列表 / 表单分别派生并可扩展），把**页面内帮助入口**做成基类内建动作，并补一个**640px 长文阅读对话框**；不新建页面框架、不新建页面原型。
- **依据**：需求 [08-4](../../../../需求/08_需求_工作台与表单定制.md#r08-4)；《[布局设计 · 导航](../../../../../../设计/布局设计/05_布局设计_导航.html)》§3、《[列表页](../../../../../../设计/布局设计/07_布局设计_列表页.html)》§4、《[表单页](../../../../../../设计/布局设计/08_布局设计_表单页.html)》§2、《[表单框架](../../../../../../设计/布局设计/06_布局设计_表单框架.html)》§4、《[弹窗](../../../../../../设计/布局设计/10_布局设计_弹窗.html)》§3；《[组件设计 · 工具栏](../../../../../../设计/组件设计/03_布局组件类/13_组件设计_工具栏/13_组件设计_工具栏.md)》《[组件设计 · 弹窗抽屉表单](../../../../../../设计/组件设计/04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)》；08_02 帮助解析契约。
- **范围（本任务）**：
  - 新增工具栏组件族：通用工具栏基类 + 列表 / 表单派生 + 具体件；动作模型 / 分组 / 权限 / 溢出 / 帮助动作。
  - 新增帮助上下文能力：`BaseHelpContext`（继承 `BaseDataState`）+ 领域纯函数 + 投影；`HelpEntry` 帮助入口 + `LongTextDialog` 长文对话框。
  - 后端 `/help/context` 补 `anchor_found`；`my_menus` 的 `help_key` 在宿主菜单 store 保留并派生模块 / 表单上下文。
  - 顶栏帮助入口（既有 `AppHeaderBar`）；用户管理列表 / 表单页工具栏迁移试点。
  - 布局 05/06/07/08/10 回写；组件设计 03/13 新增、04/01 扩展；既有主框架 / 用户管理原型补入口。
- **不含**：其余平台页面工具栏迁移（阶段十五，计划 §7 待办 27）；帮助文章 / 分类维护（12_01）；Socket.IO 实时（阶段十）；帮助内容缓存（12_01）。

## 3. 决策记录 <a id="align"></a>

| # | 事项 | 结论 | 理由 / 长期收益 |
| --- | --- | --- | --- |
| 1 | 是否新建页面框架 | **不新建**；只改既有 `PageContainer` / `FormFrame` / `AppHeaderBar` / 用户管理页 | 既有框架完整；避免重复开发 |
| 2 | 工具栏节点粒度 | 一个节点 `03/13 工具栏`，含列表 / 表单两节；`BaseToolbar` → `BaseListToolbar` / `BaseFormToolbar` | 一个节点覆盖共性、两个派生保留扩展 |
| 3 | 工具栏基类父类 | `BaseToolbar` 继承 `BaseLayout`（布局组件基类） | 工具栏属布局组件类；复用栅格 / 间距 / 显隐 |
| 4 | 帮助动作位置 | 基类内建，默认右侧组末位，**不进溢出** | 帮助始终可达，不被「更多」折叠 |
| 5 | 帮助显隐 | 页内按锚点（元数据 `help_key` 或 `anchor_found`）；顶栏常驻 | 无锚点不显示、有锚点无文章给分类 |
| 6 | 帮助上下文 | `BaseHelpContext` 继承 `BaseDataState`，负责解析 / 竞态 / 去重 / 失败重试 | 复用数据状态机；移动端可复用 |
| 7 | 长文弹层 | 继承既有弹窗能力（`useModalShell`），新增 640 长文阅读档 | 不新造弹窗形态；布局 10 有据 |
| 8 | 入口组件 | `HelpEntry`（按钮 + 弹层）供工具栏与顶栏共用 | 一套解析 / 五态，不在两处重复 |
| 9 | 页面迁移 | 只迁用户管理列表 / 表单页；其余阶段十五 | 有真实试点、范围可控 |
| 10 | 菜单 help_key | 宿主 store 保留 `help_key`（菜单 / 表单 / 字段 / 按钮），不塞进核心 `MenuNode` | 不改核心菜单契约；按路径 / 表单索引派生上下文 |
| 11 | 上下文来源 | 模块 = 当前菜单锚点第 2 段（向父级回溯）；表单 = 主表单业务码 | 与 08_02 自然键口径一致 |
| 12 | 页内按钮首次显隐 | 由元数据 `help_key` 直接判定，不在页面加载时请求 | 避免每页一次解析请求 |

| 14 | 后端 `button_visible` | 保持 `matched` 旧语义；新增 `anchor_found`；页内按钮用元数据或 `anchor_found` | 向后兼容 08_02 既有用例 |

| 17 | 测试 | 1 条 Kiwi；工具栏 / 帮助 / 长文 / 用户页迁移用例；原型逐页对照 | 一任务一条用例 |
| 18 | 提交 | `feat` + `docs` 两次，不推送 | 提交纪律 |

## 5. 领域设计 <a id="design"></a>

### 5.1 工具栏动作模型 <a id="actions"></a>

`domain/toolbar.ts` 定义：

| 类型 | 字段 / 语义 |
| --- | --- |
| 动作 | `key` / `label` / `icon` / `group`（left/right）/ `order` / `type` / `plain` / `danger` / `disabled` / `loading` / `permission` / `confirm` / `testId` / `hidden` |
| 覆盖 | 页面可按 `key` 覆盖默认动作的文案 / 顺序 / 分组 / 禁用 / 隐藏；新增动作追加 |
| 合并 | 默认集 + 页面动作 → 按 `key` 去重、按 `order` 稳定排序；`hidden` 删除 |
| 权限 | `visibleActions(actions, hasPermission)` 过滤无权限动作；不占位 |
| 溢出 | 右侧组保留 `maxRight` 个，其余进 `overflow`；左侧组不收纳；帮助动作单独在最右、永不进溢出 |
| 分态 | 列表：选中态控制批量动作；表单：只读 / 编辑控制保存 / 取消 / 修改；加载态禁用全部 |

- 默认动作集：`BaseListToolbar` 提供 `create / refresh / close / batch / delete` 等占位默认；`BaseFormToolbar` 提供 `edit / save / cancel / delete / refresh / close`。具体默认文案与权限码由页面覆盖（不在基类写死业务码）。
- `testId` 用于保留既有 `data-test`，用户管理页迁移不改测试选择器。

### 5.2 工具栏继承链与具体件 <a id="inheritance"></a>

| 层 | 名称 | 父类 | 职责 |
| --- | --- | --- | --- |
| 组件基类（布局族） | 通用工具栏基类 | 布局组件基类 | 动作 / 分组 / 权限 / 溢出 / 帮助位 / 加载态 |
| 组件基类 | 列表工具栏基类 | 通用工具栏基类 | 列表默认动作集、选中态、批量动作 |
| 组件基类 | 表单工具栏基类 | 通用工具栏基类 | 表单默认动作集、只读 / 编辑分态、保存唯一主操作 |
| 具体件 | 列表工具栏件 | — | 渲染左 / 右组 + 溢出 + 帮助入口；只回传动作 |
| 具体件 | 表单工具栏件 | — | 同上；按 `editing` 切换保存 / 修改 |

- 投影 `useBaseToolbar` 负责核心实例 ↔ 响应式；具体件不写判定逻辑。
- 帮助入口由具体件在右组末位渲染 `HelpEntry`；帮助可见性由基类 `helpVisible`（`help` 存在且 `anchorAvailable` 或 `mode==='header'`）决定。
- 页面只传 `actions` / `permChecker` / `help` / `loading` / `editing`，不继承具体件、不改基类。

### 5.3 帮助上下文能力 <a id="help-context"></a>

`domain/help.ts`：

| 类型 / 函数 | 语义 |
| --- | --- |
| 上下文入参 | `productKey` / `moduleKey` / `formKey` / `fieldKey` / `actionCode`（camelCase，组件侧） |
| 线参数 | `buildHelpQuery` → `product_key` / `module_key` / `form_key` / `field_key` / `action_code`（空串不传） |
| 结果 | `matched` / `anchorFound` / `level` / `helpKey` / `article` / `related` / `categories` |
| 归一 | `normalizeHelpResult`：缺 `anchor_found` 时回落 `matched`（兼容旧后端）；脏项剔除；正文透传 |
| 上下文键 | `helpContextKey`：`product|module|form|field|action`，用于同上下文并发合并 |
| 层级 / 来源 | `field/action/form/module/global`、`builtin/product/tenant`；只做展示映射 |

`BaseHelpContext`（继承 `BaseDataState`）：

- 字段：`ready`（缺省 false）、`fetcher`、`context`、`result`、`errorMessage`、`requestCount`。
- 方法：`setReady` / `setFetcher` / `setContext` / `resolve` / `retry` / `reset`。
- `resolve`：未就绪 / 未注入 → 零请求；同上下文在途 → 复用 Promise；`begin` / `settle` 竞态；成功按 `matched` 落 `ready`、否则 `empty`；失败 `error` + 文案。
- 派生：`anchorFound` / `matched` / `buttonVisible`（`anchorFound`）；`article` / `related` / `categories`。
- 不缓存跨上下文；上下文变化丢弃旧结果（令牌 + 上下文键双校验）。

### 5.4 帮助入口与显隐 <a id="help-entry"></a>

`HelpEntry`（展示族具体件）：

| 语义 | 说明 |
| --- | --- |
| 模式 | `toolbar`（文字按钮「帮助」）/ `header`（图标按钮，悬停提示） |
| 显隐 | `anchorAvailable` 为真或解析结果 `anchorFound` 为真；`header` 模式常驻 |
| 打开 | 打开时 `resolve`；加载 / 命中 / 有锚点无文章 / 无锚点 / 失败五态 |
| 命中 | `LongTextDialog` 640；标题 + 层级 / 来源标签 + 正文（`sanitizeHtml`）+ 相关内容 + 分类 |
| 有锚点无文章 | 「暂无帮助内容」+ 分类列表 |
| 无锚点 | 「暂无帮助」+ 打开帮助中心（占位） |
| 失败 | 错误提示 + 重试；不自动重试 |
| 事件 | `open` / `close` / `category` / `retry` / `error` |

- 页内入口上下文：模块（菜单锚点第 2 段，向父级回溯）+ 表单（主表单业务码）；字段 / 动作留空。
- 顶栏入口上下文：当前路由同上；无上下文时全空走全局级。
- 页内按钮首次显隐由菜单 / 表单元数据 `help_key` 直接判定，不在页面加载时请求；若元数据过期，解析结果 `anchorFound=false` 时按「无锚点」呈现，关闭后不再显示。
- `button_visible`（旧字段）不参与页内按钮显隐，仅作兼容；页内按钮以 `anchor_found` / 元数据为准。

### 5.5 长文阅读对话框 <a id="long-text"></a>

`LongTextDialog`（容器组件类具体件）：

| 项 | 设计 |
| --- | --- |
| 基础 | 复用 `useModalShell`（开关 / 关闭拦截 / 层级 / 滚动锁） |
| 宽度 | `640px`（布局 10 新增档）；`width` 可覆盖但不得低于 480 |
| 高度 | 最大 `80vh`；标题与底部操作固定，正文独立滚动 |
| 内容 | 默认插槽正文；无表单、无提交；页脚默认「关闭」+ 可选附加 |
| 关闭 | 允许遮罩 / Esc（阅读型），如需禁止由调用方显式关闭 |
| i18n | 标题 / 关闭 / 分类 / 错误文案走语言能力 |
| 移动端 | 近全屏（宽 100%、高 100%），正文滚动、页脚固定 |

- 帮助入口用 `LongTextDialog` 渲染文章 / 分类；不新造弹窗形态。
- 组件设计 04/01 已补「长文阅读对话框」语义与 640 档；布局 10 已补该档。

### 5.8 后端 `anchor_found` <a id="backend"></a>

- `build_help_candidates` 结果中任一候选 `help_key` 非空 → `anchor_found=true`；全局候选不算锚点。
- `resolve_help_context` 增加可选 `candidates` 参数（避免重复构建）；新增 `has_anchor(candidates)` 纯函数。
- `HelpContextResponse` 新增 `anchor_found: bool`；`button_visible` 仍为 `matched`（旧语义）。
- 服务层先构建候选 → 计算 `anchor_found` → 内容侧解析 → 响应透出。
- 测试：命中（anchor_found=true / matched=true）、有锚点无文章（true/false）、无锚点（false/false）。
- 契约快照 `platform.json` 与前端类型重生成；08_02 详细设计 §5.4 / §7 / §8 回写；概要 17 §5 补字段说明。

### 5.9 菜单 store 与上下文派生 <a id="menu-context"></a>

- `stores/menu.ts` 新增（不改核心 `MenuNode`）：
  - `helpKeyByPath: Record<string,string>`（菜单路径 → `help_key`，递归收集）；
  - `FormMeta.helpKey` / `fieldHelpKeys` / `buttonHelpKeys`（表单 / 字段 / 按钮级）。
- `usePageHelpContext()`：
  - `moduleKey`：当前路径 `helpKeyByPath[path]` 拆 `:` 取第 2 段；无则向父路径回溯；仍无为空。
  - `formKey`：`formIdByPath[path]` → `forms[id].businessCode`；无为空。
  - `anchorAvailable`：模块 `help_key` 或表单 `help_key` 非空。
  - `fieldKey` / `actionCode`：默认空，暴露 setter 供字段 / 按钮级后续接入。
  - `help` 描述符：`{ context, anchorAvailable, fetcher, ready: true }`。

## 7. 失败分支与边界 <a id="failures"></a>

| 场景 | 处置 | 结果 |
| --- | --- | --- |
| 工具栏无权限动作 | 不渲染、不占位 | 主操作仍可达 |
| 右侧动作过多 | 收进「更多」；帮助不收纳 | 帮助始终可达 |
| 窄屏 | 主操作保留、次要收纳；帮助可进「更多」或保留图标 | 不横向滚动 |
| 帮助未注入取数 | 抛 `19001`，入口不请求 | 开发态可见错误 |
| 帮助无锚点 | 页内不显示；顶栏给全局 / 暂无 | 不出现空白弹窗 |
| 有锚点无文章 | 分类列表 | 可继续浏览 |
| 帮助加载失败 | 错误 + 重试 | 不自动轮询 |
| 上下文切换 | 旧结果按竞态丢弃 | 不串页面 |
| 长文正文含脚本 | `sanitizeHtml` 清洗 | 不执行脚本 |
| 长文过长 | 正文滚动、标题 / 页脚固定 | 不撑破视口 |
| 菜单元数据缺 `help_key` | 页内不显示；顶栏仍可用 | 不误报 |
| 后端 `anchor_found` 缺失 | 前端回落 `matched` | 兼容旧契约 |
| 用户页迁移 | 保留 data-test 与业务函数 | 既有用例只改触发方式 |
