## 2. 关键实现说明 <a id="impl"></a>

### 2.1 工具栏 <a id="toolbar"></a>

- **继承链**：`BaseComponent → BaseSized → BaseLayout → BaseToolbar → BaseListToolbar / BaseFormToolbar`；具体件只渲染与回传动作键。
- **动作合并**：派生默认 + 页面覆盖（按 `key`）+ 页面新增（同键视为再覆盖）→ 按 `order` 稳定排序 → `hidden` 删除；`testId` 用于保留既有 `data-test`。
- **权限与分态**：未注入权限判定不过滤；声明权限码的动作无权限即不渲染、不占位。表单用 `showIn` 区分只读 / 编辑（修改与保存互斥，保存为编辑态唯一主操作）。
- **溢出**：左组不收纳；右组按 `maxRight` 直显，其余进「更多」；**帮助动作由基类追加在右组末位，永不进溢出**。
- **批量动作**：`batch: true` 的动作在选中数为 0 时禁用；工具栏级加载禁用全部动作。

### 2.2 帮助 <a id="help"></a>

- **能力**：`BaseHelpContext` 未就绪零请求；同上下文在途合并为一次请求；结果按 `matched` 落 `ready` / `empty`，失败落 `error` + 文案；竞态用「令牌 + 上下文键」双校验，旧上下文迟到结果丢弃；同上下文已解析结果复用，`retry` 强制重取。
- **取数**：`createHttpHelpFetcher` 走 `GET /{platform}/help/context`，线参数由 `buildHelpQuery` 生成（空值不传；字段级缺表单键不传字段键）；业务码非 0 / 200 与 HTTP 失败统一提示「帮助服务不可用」。
- **入口五态**：加载 / 命中（层级 + 来源标签 + `sanitizeHtml` 正文 + 相关内容 + 分类）/ 有锚点无文章（「暂无帮助内容」+ 分类）/ 无锚点（「暂无帮助」+ 帮助中心占位）/ 失败（错误 + 重试，不自动重试）。
- **显隐**：页内由元数据锚点或解析结果 `anchorFound` 判定（页面加载不请求）；顶栏 `mode="header"` 常驻。元数据有锚点但解析无锚点时按「无锚点」呈现，**关闭后不再显示**。
- **长文**：`LongTextDialog` 复用 `useModalShell`，宽度缺省 640（低于 480 夹取下限），正文区 `max-height: calc(80vh - 160px)` 独立滚动，标题 / 页脚固定，移动端近全屏。

### 2.3 后端 `anchor_found` <a id="backend"></a>

- `has_anchor(candidates)`：除全局级外任一候选有锚点即真；`resolve_help_context` 新增可选 `candidates` 参数，服务层一次构建候选并同时用于解析与 `anchor_found` 判定。
- `button_visible` 保持旧语义（`= matched`）；页内入口改用 `anchor_found` / 元数据，向后兼容 08_02 既有用例。
- 契约快照与前端类型重生成；08_02 详细设计补字段与用例行。

### 2.4 宿主上下文与试点 <a id="host"></a>

- 菜单 store 保留 `help_key`（菜单路径索引 + 表单 / 字段 / 按钮锚点），核心 `MenuNode` 契约不变。
- `usePageHelpContext`：模块键取菜单锚点第 2 段（当前路径未登记向父路径回溯）；表单键取当前路径主表单业务码；锚点可用为二者任一非空；字段 / 动作暴露 setter 供后续接入。
- 用户管理列表 / 表单工具栏迁移：动作的 `testId` 与业务函数保持不变，只换触发入口；记录页脏态 / 载入提示经工具栏 `#side` 插槽保留。
