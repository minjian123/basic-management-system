## 2. 任务内容 <a id="content"></a>

1. **工具栏组件族**：通用工具栏基类（动作项模型 / 左右分组 / 排序 / 权限显隐 / 禁用 / 危险 / 溢出收纳 / 加载态）；列表工具栏 / 表单工具栏两个派生，各自维护默认动作集并允许页面扩展。
2. **帮助动作内建**：工具栏基类内置帮助动作位（默认右侧组末位）；按当前页面锚点显隐，消费 08_02 的五级解析；命中弹文章、有锚点无文章弹分类、无锚点不显示；顶栏保留常驻帮助入口。
3. **长文阅读对话框**：继承既有弹窗能力，新增 640px 长文阅读布局档（标题 / 正文滚动 / 底部操作固定），用于帮助文章与说明类长文。
4. **既有页面试点**：用户管理列表页与表单页迁到新工具栏；其余平台页面登记阶段十五统一迁移，**不新建页面框架、不新建页面原型**。
5. **布局回写**：顶栏帮助入口回写导航布局；列表 / 表单工具栏帮助位回写对应布局；长文对话框回写弹窗布局。
6. **原型**：新增工具栏组件原型；只改既有 `03_主框架.html`、`08_用户管理/02_用户列表页.html`、`03_用户表单页.html` 与既有弹窗组件原型。

## 3. 完成标准 <a id="accept"></a>

列表 / 表单工具栏由基类派生且各自可扩展；帮助按钮在基类统一提供、按锚点显隐，五级解析与未命中分类正确；长文对话框符合 640px 档且正文滚动、操作固定；用户管理页列表 / 表单试点可用；无新建页面框架；其余页面迁移有归口。
