## 2. 任务内容 <a id="content"></a>

1. `{主表}_i18n` 附表（与主表同域、同生命周期），查询按 locale 关联、缺省回退
2. 覆盖字典 label / 公告 / 帮助 / 邮件模板 / 菜单表单名称，逐项登记不全表附挂
3. 用户时区偏好 `sys_user.timezone`，存储 UTC、展示按偏好；非法时区拒

## 3. 完成标准 <a id="accept"></a>

两种 locale 正确且回退正确；主表删除附表不残留；切换时区展示变、存储不变。
