## 2. 任务内容 <a id="content"></a>

1. 语言清单（code / name / rtl / status）动态扩展，默认语言唯一且不可停用
2. 语言包 `sys_i18n_message` 页面维护，`GET /api/v1/i18n/messages` 运行时下发 + Redis 缓存
3. Babel 开发期提取 key；缺 key 回退默认语言文案

## 3. 完成标准 <a id="accept"></a>

新增语言（含 RTL）免发版可切换；编辑后下次请求生效；缺 key 回退不显示 key 原文。
