## 2. 任务内容 <a id="content"></a>

1. 邮件模板（Jinja2）保存时语法校验 + 沙箱渲染；`sys_mail_template_i18n` 多语言
2. 异步 SMTP 发送并记录 `sys_mail_log`；短信模板（aliyun / tencent）与 `sys_sms_log`
3. 发送记录按状态 / 时间查询，失败原因可定位

## 3. 完成标准 <a id="accept"></a>

语法错误保存即拒；两种 locale 渲染正确；失败可定位；发送不阻塞主请求。
