## 4. 替身与真机边界 <a id="boundary"></a>

- SMTP 用 mock `aiosmtplib.send`；阿里云 / 腾讯云用 `httpx.MockTransport` 假传输；**未使用真实凭证 / 未连外网**。
- 通知服务用例使用临时 SQLite + 共享租户库回滚会话；偏好、收件人、作业提交均注入替身。
- 作业 handler 直接以 `JobContext` 调用，不启动 worker；worker 启动只做构造 / 声明冒烟。
- 真库方言、真实 SMTP / 云短信、厂商模板审核随部署窗口；未实测结论不写入表文件或规范。
