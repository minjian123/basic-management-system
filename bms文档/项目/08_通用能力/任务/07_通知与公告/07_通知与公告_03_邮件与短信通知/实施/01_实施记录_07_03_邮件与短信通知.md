## 3. 关键实现说明 <a id="impl"></a>

### 3.1 五表与平台默认模板 <a id="tables"></a>

- `sys_mail_template`：`(code, deleted_at)` 唯一；`code` 创建后不可改；`status=enabled/disabled`。
- `sys_mail_template_i18n`：`(template_id, locale, deleted_at)` 唯一；主表 `subject` / `content` 为默认语言派生快照。
- `sys_mail_log`：只存主题与元数据，**不存正文**；正文放作业负载（随作业保留期清理）。
- `sys_sms_template`：`(code, channel, deleted_at)` 唯一；`scene` / `provider_template_id` / `provider_param_keys`。
- `sys_sms_log`：正文脱敏（连续 4 位及以上数字替换为 `****`）。
- 平台默认模板在 `mail_defaults.py` / `sms_defaults.py` 代码内置；读取先租户库、无同 code 回落内置；租户 `disabled` 不回落，删除覆盖行后回落。

### 3.2 沙箱与渲染 <a id="sandbox"></a>

- `SandboxedEnvironment`、无 loader、`StrictUndefined`（发送 / 测试接口）与宽松未定义（保存冒烟）。
- 拦截 `include/extends/import/from/macro/callblock/filterblock` 与下划线属性 / 键；过滤器白名单；`set` 上限 20。
- 流式渲染累加，邮件 60000 字节 / 短信 2000 字节上限；线程 + `wait_for` 超时（缺省 3 秒）。
- 参数扁平校验：键正则、≤50 个、值只允许标量。

### 3.3 外发调度与异步 <a id="outbound"></a>

- `OutboundDispatchService` 为渠道开关 / 免打扰唯一判定点；通知组把已读偏好传入，API / 内部入口自行读取。
- 事务性消息跳过过滤；免打扰落 `skipped`（`dnd`）；渠道关闭时 API 落 `skipped`、通知组不落日志。
- 发送记录 `pending` + 作业负载（渲染结果）同事务提交；worker 成功回写 `success` / `sent_at`，失败回写 `failed` / `error_msg`。
- 作业 `notification.mail.send` / `notification.sms.send`：超时 120s、最多 3 次、退避 30s、并发 4；新增 `notification-jobs` compose 服务（worker id 105）。
- 幂等：日志 `(idempotency_key, deleted_at)` 唯一 + 先查后插；通知组用 `event_id + channel` 作幂等键。

### 3.4 真实通道与 `BaseNotifier` http <a id="channels"></a>

- SMTP：`aiosmtplib`；`ssl` / `starttls` / `plain`；认证 / 5xx / 收件人拒绝不可重试，连接 / 超时 / 4xx 可重试。
- 阿里云：RPC HMAC-SHA1 签名；`TemplateParam` JSON；限流 / 系统错误可重试。
- 腾讯云：TC3-HMAC-SHA256；`TemplateParamSet` 按 `provider_param_keys` 顺序；手机号归一 `+86`。
- `HttpNotifier`：调 `POST /api/v1/mail/internal/send`；短信必须 `template_code`；不可达 / 非 2xx → `delivered=False`。
- identity `prepare_settings` 置 `[notifier].provider=http`；验证码 `sms_captcha`、找回密码 `sms_password_reset` 模板化。

### 3.5 能力 / 作业 / 选项集 <a id="governance"></a>

- 新增 `deploy/registry/notification.toml`（通知服务作为提供方的能力声明）：`notification.send`，`default_consumers=["identity"]`，路径 `/api/v1/mail/internal/send`。
- 新增 `[[jobs]]` 两条与 `bms.sms.scene` 选项集；`notification` 服务 worker 入口 `python -m bms_notification.jobs`。
- 模板审计：`sys_mail_template` / `sys_sms_template` 进通知服务审计白名单；日志与 i18n 附表不审计。
