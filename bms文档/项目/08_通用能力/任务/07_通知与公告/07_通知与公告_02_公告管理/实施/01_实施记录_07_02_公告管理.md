## 3. 关键实现说明 <a id="impl"></a>

### 3.1 三表与状态机 <a id="tables"></a>

- `sys_notice`：雪花 ID + 审计 + `deleted_at` + `version`；`status=draft/published/offline`；`is_top` + `publish_at` + `expire_at`。
- `sys_notice_read`：雪花 ID 主键 + `(notice_id, user_id, deleted_at)` 复合唯一；重复阅读幂等，保留首次 `read_at`。
- `sys_notice_i18n`：`(notice_id, locale, deleted_at)` 复合唯一；主表 `title` / `content` 为系统默认语言派生快照。
- 禁止迁移：`offline → published`、`published → draft`、`draft → offline` → `70204`。

### 3.2 可见性与过期 <a id="visibility"></a>

- 唯一判定：`status=published AND publish_at <= now AND (expire_at IS NULL OR now < expire_at)`。
- 普通用户列表 / 详情 / 回执只允许可见公告；草稿 / 未到时间 / 已下线按 `70201` 返回（不泄露状态）。
- 管理侧（`notice:update`）可看全部未删除公告；管理列表无 `notice:update` 时强制只看发布中。
- 排序：`is_top DESC, CASE WHEN is_top THEN updated_at ELSE publish_at END DESC, id DESC`。

### 3.3 多语言与富文本 <a id="i18n"></a>

- 写入：`i18n: {locale: {title, content}}`；空白剔除、语言数 ≤50、必填语言（请求语言）须有标题；主表列按「系统默认语言 → 请求语言 → 首个有值语言」派生。
- 读取：显式 `locale` → `Accept-Language` 主语言 → `get_default_locale()`；经 `load_i18n_texts` 两级回退，最后回落主表列。
- 管理侧详情返回完整 `i18n` 映射；公开详情不返回，减少载荷。
- 正文经 `bms_core.richtext.sanitize.sanitize_html`（`nh3`）白名单清洗后入库；清洗后 UTF-8 > 60000 字节或发布时去标签为空 → `70205`。

### 3.4 事件与发件箱 <a id="event"></a>

- `sys.notice.published` 契约 `1.1.0`：必填 `notice_id` / `title` / `is_top`，可选 `action` / `type` / `priority` / `publish_at` / `expire_at`。
- 动作：新建发布 `published`、已发布编辑 `updated`、过期扫描 `offline`；草稿与删除不发事件。
- 事件与业务写同事务写 `SqlOutboxStore`；`aggregate_key=notice:{id}`。

### 3.5 已读回执与统计 <a id="read"></a>

- 只由 `POST /api/v1/notices/{id}/read` 写入；不可见 → `70202`；不存在 → `70201`。
- 先查后插 + `begin_nested()` 保存点包住插入；唯一冲突回滚保存点后重查，返回首次 `read_at`。
- 统计：`read_count` = 回执去重用户数；`audience_count` = 平台用户只读出口 `status=enabled` 的 `total`；`unread=max(audience-read,0)`。
- 平台用户查询不可达 / 非 2xx / 响应非法 → `70206`；已停用用户存量回执仍计入已读，读>应读时未读记 0。

### 3.6 过期扫描 <a id="expire"></a>

- 内置任务 `expire_notices`（`0 * * * *`）→ `POST /api/v1/notices/internal/expire`（`require_service("platform")`）。
- 单批默认 200（上限 1000）；逐行加载 + `begin_nested()` + 乐观锁；`StaleDataError` 跳过，成功行发 `offline` 事件。
- 读取侧实时校验始终兜底展示；任务失败按调度器策略重试。

### 3.7 审计 / 表归属 / 权限 / 选项集 <a id="governance"></a>

- `sys_notice` 从基座 `AUDITED_TABLES` 移出，通知服务 `prepare_settings` 调 `register_audited_tables`；`sys_notice_read` / `sys_notice_i18n` 不单独审计。
- 表归属三表：owner/domain=`notification`、tenant、enabled。
- 权限：补 `notice:create/update/delete` 动作与权限码；不加菜单 / 按钮 / 字段种子。
- 选项集：`bms.notice.type`（system/policy/maintenance/activity）、`bms.notice.priority`（low/normal/high/urgent），运行时经注册表校验，非法值 `10001`。

### 3.8 i18n 台账的服务自有附表 <a id="ledger"></a>

- 基座台账只登记 platform 表；新增 `register_i18n_attachments()` / `all_attachments()` / `reset_i18n_attachments()`。
- 通知服务 `domains/notification/i18n_attachments.py` 在导入 / 装载期登记 `sys_notice_i18n`；护栏脚本改为导入服务台账并扫描服务模型，避免基座引用他服务表名（跨服务边界门禁）。
