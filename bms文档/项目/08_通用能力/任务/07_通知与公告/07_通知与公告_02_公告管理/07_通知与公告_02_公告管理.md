## 2. 任务内容 <a id="content"></a>

1. 发布 / 编辑（标题 / 内容 / 类型 / 优先级 / 发布与过期时间），已发布修改后重新发布并推事件
2. 置顶（多公告置顶按更新时间排序）；到期自动下线（读取校验 + 定时兜底）
3. 已读回执 `(notice_id, user_id)` 联合主键防重复，统计已读 / 未读

## 3. 完成标准 <a id="accept"></a>

置顶排序正确；到期不展示；重复阅读不产生重复回执；已读 + 未读 = 应读。
