## 2. 任务内容 <a id="content"></a>

1. 站内信列表 / 详情（类型与已读筛选），详情自动已读，`biz_type` / `biz_id` 可跳转
2. 待办角标经 Socket.IO 实时增量；单条 / 批量 / 全部已读；软删除仅本人
3. 按用户偏好过滤渠道（站内信 / 邮件 / 短信、免打扰时段）
4. 由业务事件触发经通知组消费落库，不由业务代码直写

## 3. 完成标准 <a id="accept"></a>

事件触发后角标实时变化；详情即已读；批量幂等；关闭渠道不再产生记录；跨用户不可见。
