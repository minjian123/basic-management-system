## 2. 任务内容 <a id="content"></a>

1. **分类树与文章维护**：管理面分类增删改（排序 / 启停；默认拒删并返回子分类与文章计数，`cascade=true` 级联下架子树文章后软删）；
   文章在线编辑（正文统一 HTML，后端 `richtext.sanitize` 权威清洗），草稿 / 发布 / 下架 / 置顶 / 软删除；
   包来源文章编辑自动置 `local_override`，删除一律拒绝并引导下架。
2. **状态机与审计**：新建默认草稿；发布 / 下架走专用端点并校验迁移（重复发布、下架草稿、编辑退回草稿一律拒绝）；
   文章内容变更落字段级审计（`sys_help_article` 已在白名单），分类与包操作落操作日志。
3. **多语言**：标题与正文逐语言写 `sys_help_article_i18n`，写入校验语言在租户启用清单内；
   主表两列取租户默认语言快照；读取沿用「请求语言 → 租户默认语言 → 主表快照」三级回退。
4. **读者面**：分类树（启用分类 + 已发布文章数含子孙）、文章列表（仅已发布、置顶优先、分页）、
   文章详情（当前语言 + 阅读计数 + 我的反馈）、提交反馈（有帮助 / 无帮助 + 评论，同用户同文章唯一、可改投）；
   PC 与移动端复用同一组接口。分类停用只影响树与列表入口，详情仍可读。
5. **反馈与统计**：`sys_help_feedback` 建表（雪花 `id` + `(article_id, user_id, deleted_at)` 唯一）；
   文章表 `helpful_count` / `unhelpful_count` 同事务按差值增减；阅读计数同用户同文章 60 秒去重；
   统计视图统一端点（`group_by=article|category`），帮助率 = `helpful / (helpful + unhelpful)`，无反馈返回 `null`。
6. **帮助包管理面**：`GET /help/packages`、`POST /help/packages/load`（`dry_run` 默认 true，包路径限定 `[help_package].root`）、
   `POST /help/packages/{product_key}/unload`；补 `help:package` 权限种子（基线与 `help:manage` 分离授权）。
7. **内容侧缓存**：`/help/context` 解析结果按租户内容版本键缓存（60 秒短 TTL），分类 / 文章 / 包写操作递增版本即时失效；
   缓存不可用直读库并告警。
8. **AI 草稿位**：`generated_by` / `ai_model` / `reviewed_by` 可维护；`generated_by=ai` 未填审核人不得发布；
   生成能力本身归阶段十九（生产默认关闭）。
9. **初始内容**：租户库种子落三分类（快速上手 / 系统管理 / 业务操作）与三篇双语基础文章（幂等只增不改）。

## 3. 完成标准 <a id="accept"></a>

- 草稿不可见 / 发布可见 / 下架隐藏；分类停用后列表与树不再暴露、详情仍可读；置顶优先排序正确。
- 两种 locale 展示正确且缺省回退（请求语言 → 默认语言 → 主表快照）；非法 locale 写入被拒。
- 重复反馈不产生多条但可改投，计数与反馈明细一致；阅读计数递增可查且 60 秒内同用户不重复计。
- 统计视图帮助率与反馈明细一致（无反馈文章帮助率为 `null`）。
- `generated_by=ai` 且 `reviewed_by` 为空时发布被拒；补齐审核人后可发布。
- 分类默认删除被拒并给出计数；`cascade=true` 后子树文章全部 `offline`、分类软删。
- 帮助包三端点可用：`dry_run` 不写库、实跑计数与预演一致、越界路径被拒、缺 `help:package` 被拒。
- 文章发布 / 下架后 `/help/context` 即时返回新内容（缓存按版本失效）。
- 新增 / 改动模块行 + 分支覆盖率 100%；契约快照与前端类型零漂移。
