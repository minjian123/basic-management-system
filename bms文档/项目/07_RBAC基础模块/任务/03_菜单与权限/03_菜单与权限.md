## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：阶段七需求域 03 的 2 条需求——[07-5 菜单/表单/按钮/字段挂接与动态菜单接口](../../需求/03_需求_菜单与权限.md#r07-5)、[07-6 三权分立（内置三类管理员互斥、平台超管边界）](../../需求/03_需求_菜单与权限.md#r07-6)，2 个子任务（`03_01` ~ `03_02`）。
- **端范围**：PC（后端 meta 能力 + 前端动态路由 / 菜单 / 按钮 / 字段消费）。
- **本域性质**：权限元数据与职责分离域——菜单 / 表单 / 按钮 / 字段与业务 / 动作码存平台库、平台超管统一维护，动态菜单接口是前端动态路由与显隐的唯一依据；三权分立保证授权与运营职责分离。
- **依据**：《[概要设计 · 菜单管理](../../../../设计/概要设计/07_概要设计_菜单管理.md)》、《[架构设计 · 权限计算引擎](../../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md)》§2/§7/§8、《[架构设计 · 前端架构](../../../../设计/架构设计/08_架构设计_前端架构.md)》、《[概要设计 · 审计合规](../../../../设计/概要设计/28_概要设计_审计合规.md)》。
- **执行序**：`03_01 菜单与权限挂接`（先行，作为角色授予对象）→ `03_02 三权分立与平台超管边界`（依赖 `02_03`，其内置角色作为 `04_01` 开通种子，具体见[计划](../../计划/01_计划_RBAC基础模块.md)）。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：阶段一 / 阶段二平台库基座（`sys_module` 等）；平台 MVP 页面清单（用户管理 / 角色管理 / 租户管理）作为挂接收敛对象；租户开通种子（`04_01`）作为三权分立预授入口。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_RBAC基础模块.md)。
- **风险**：元数据挂接链断裂（菜单缺表单 / 表单缺业务）会导致授权对象不可用，须在授予时前置校验；业务 / 动作码一经发布稳定，停用代替删除，误删会牵动契约与错误码；三权分立若只在种子层预授、未在授权写入前置校验，仍可能被越权授予绕过。
