## 2. 实施过程 <a id="process"></a>

### 2.1 数据库设计先行（强制顺序）

新建 10 张表文件并登记总览，再改模型与迁移：

```text
bms文档/设计/数据库设计/数据表设计/
├── sys_business.md / sys_business_i18n.md     # 业务权限码 + 名称多语言
├── sys_action.md / sys_action_i18n.md         # 动作权限码 + 名称多语言
├── sys_menu.md / sys_menu_i18n.md             # 菜单树 + 名称多语言
├── sys_form.md                                # 表单（菜单 1:1 / 业务 1:1）
├── sys_button.md                              # 按钮（表单 + 动作 1:1）
└── sys_field.md / sys_field_i18n.md           # 表单字段 + 名称多语言
```

- 总览「已设计数据表登记」新增 10 行（状态 `待落库`，与表文件一致）；
- `bms_core/services/table_registry.py::TABLE_OWNERSHIP`：`sys_menu` / `sys_business` / `sys_action` 归属由预留键 `permission` 更正为 `platform`；十表由 `planned` 转 `enabled`（自动进 `platform:platform` 链）；
- **未新建模块节点文件**（`数据库设计/` 下现无任何模块节点文件，与现状一致）。

### 2.2 模型与迁移

- 新增 `bms_platform/models/menu.py`（10 个 ORM 模型，继承 `BaseModel`）并在 `models/__init__.py::MODEL_MODULES` 登记；
- 新增迁移 `alembic/versions/platform/platform/0007_menu_metadata.py`（建表 + 唯一约束 + 索引），成为 `platform:platform` 链新头；
- 同步 `libs/bms_core/tests/alembic/test_alembic_chains.py` 的链头断言（`0006_sys_outbox_tenant_bigint` → `0007_menu_metadata`）。

### 2.3 基座扩展

- `core/error_codes.py`：新增菜单域 `402xx` 段（40201 实体不存在 / 40202 挂接链断裂 / 40203 路径冲突 / 40204 平台码租户不可改 / 40205 字段键重复 / 40206 被引用禁停用 / 40207 字段权限不匹配）；
- `core/exceptions.py`：新增 `MenuError` 基类与 7 个具名子类（不存在按 404、平台码只读按 403、其余按 200）；
- `cache/base.py`：`CacheRegion` 补**异步默认实现**（`aget` / `aset` / `adelete` / `aincrease`；`RedisCacheRegion` 已覆写为真异步，`MemoryCacheRegion` 与占位实现继承默认实现）；
- 新增 `bms_core/menu/`：缓存域常量与键构造（`MENU_CACHE_DOMAIN`、`menu_tree_key`、`menu_version_key`、`menu.tree_cache_ttl` 默认 300）。

### 2.4 平台服务

- `schemas/menu.py`：状态与按钮形态用 `Literal` 收敛；集合字段 `Annotated[集合类, CONTRACT_COLLECTION]`；动态菜单为单接口嵌套契约（`MyMenuResponse` → `MyMenuNode` → `MyMenuForm` → 按钮 / 字段，递归节点经 `model_rebuild()` 解析）；
- `repositories/menu.py`：六实体仓储 + 多语言附表读写辅助（软删除旧行再插新行，规避复合唯一冲突）；
- `services/menu.py`：维护（增改删 + 挂接链与 1:1 冲突校验）、缓存（未过滤快照按 locale 维度缓存 + 版本号失效）、事件（变更与落库**同一事务**内经发件箱发布 `sys.form.updated`）；写路径为「单次 `uow.begin()` 包住探测 + 写 + 发件箱」；
- `services/my_menu.py`：按 `BasePermissionChecker` 过滤菜单（业务码）、标记按钮可见（动作权限码）、标记字段可见可编辑（占位期默认全可见可编辑）；目录节点按「存在可见子节点」保留，挂接链断裂即不可见；
- `api/menu.py`：`/api/v1/menus`、`/forms`、`/buttons`、`/fields`、`/businesses`、`/actions` 六个 `BaseRouter`；写接口挂 `require_permission("menu:create"/"update"/"delete")`、读接口挂 `menu:query` / `business:query` / `action:query`；`/menus/my` 仅需登录态；`api/router.py` 完成登记。

### 2.5 种子

新增 `ops/seed_menu.py`（幂等 upsert）：38 个业务权限码、76 个动作权限码（归属按《英文简称规范》「动作码简称」节的典型权限码落地）、11 个菜单（含 3 个目录）、10 个表单（1:1 挂接）、18 个按钮（挂动作）、22 个字段，均配中英文文案（`_i18n` 附表）。

### 2.6 契约

`ops.contract_snapshot export` 重生成 `deploy/contracts/platform.json`：新增 11 条路径（`/menus` GET+POST、`/menus/{id}` PUT+DELETE、`/menus/my` GET、`/forms`、`/buttons`、`/fields` 各 2+2、`/businesses` GET、`/actions` GET）；**仅 platform 契约变化**，其余 8 份零漂移；契约版本保持 `0.1.0`（兼容新增不升）；未更新契约基线（新增端点非破坏性）。
