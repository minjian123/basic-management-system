## 2. 任务内容 <a id="content"></a>

1. **菜单维护**：菜单树（`parent_id/name/path/component/icon/sort/hidden/status`），1:1 挂接表单；`GET/POST/PUT/DELETE /api/v1/menus`。
2. **表单维护**：表单实体（挂菜单 `menu_id`、挂业务 `business_id`、`component`），形成菜单→表单→业务链；`/api/v1/forms`。
3. **按钮维护**：按钮实体（挂表单 `form_id`、挂权限码 `permission_id`、`type`（toolbar/interface）、`sort`），形成按钮→动作链；`/api/v1/buttons`。
4. **字段维护**：字段实体（挂表单 `field_key/name/type/sort/status`）；`/api/v1/fields`。
5. **业务 / 动作码管理**：`sys_business` / `sys_action` 平台统一维护，租户侧可见、可分配、不可增删；`GET /api/v1/businesses`、`GET /api/v1/actions`；停用代替删除。
6. **挂接链完整性校验**：菜单 1:1 表单、表单 1:1 业务、按钮 1:1 动作、字段挂表单，任一缺失导致该链路不可用，角色授予时校验并提示（40002）。
7. **多语言**：菜单 / 业务 / 动作 / 字段名称各存 `_i18n` 附表（联合主键主表 ID + locale），按 locale 关联、缺省回退主表默认文案。
8. **动态菜单接口**：`GET /api/v1/menus/my` 按已授予菜单 / 表单权限过滤菜单树并下发表单元数据（按钮按动作权限、字段按字段权限标记可见可编辑），登录即可；菜单树与表单元数据 Redis 短 TTL 缓存（含随机偏移、按 locale 维度），变更即时失效。
9. **前端消费**：按动态菜单注册路由与侧边栏（不硬编码路由表）、按钮按动作权限显隐、字段按字段权限显隐与只读；`sys.form.updated` 事件发布（AI 帮助更新触发）。
10. **平台 MVP 页面挂接**：用户管理 / 角色管理 / 账号锁定 / 租户管理等平台页面菜单→表单→业务、按钮→动作链路齐全，配 i18n 文案。
11. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

新增菜单 / 表单 / 按钮 / 字段后前端动态注册路由与侧边栏免发版生效、菜单名多语言显示正确（含缺省回退）；挂接链断裂在角色授予时被拦截并提示；动态菜单接口按权限过滤正确（未授予菜单不可见、未授予按钮不渲染、字段权限读时过滤 / 写时校验）；业务 / 动作码租户侧只读；`sys.form.updated` 事件与元数据缓存失效即时生效；平台 MVP 页面挂接完整；新增模块覆盖率达标、`preflight --fast` 全绿。
