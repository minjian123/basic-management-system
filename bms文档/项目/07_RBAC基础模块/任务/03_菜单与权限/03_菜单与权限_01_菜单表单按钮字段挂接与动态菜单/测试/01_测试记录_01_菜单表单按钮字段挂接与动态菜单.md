## 4. 原型对照结论 <a id="prototype"></a>

**对照方式**：实现侧**真实渲染**（本机全套 + 前端 5173，1440×900 同视口）+ 截图识图逐项比对；**基准**为[主框架原型](../../../../../../设计/原型设计/03_通用骨架/03_主框架.html)与[通用骨架 · 设计说明](../../../../../../设计/原型设计/03_通用骨架/01_设计说明.html)，布局类以《[布局设计 · 主框架](../../../../../../设计/布局设计/04_布局设计_主框架.html)》《[布局设计 · 导航](../../../../../../设计/布局设计/05_布局设计_导航.html)》为准（原型依据登记见[详细设计 §7](../设计/01_详细设计_01_菜单表单按钮字段挂接与动态菜单.md#prototype)）。

| 核对项 | 结论 |
| --- | --- |
| 原型依据已登记 | 详细设计 §7「原型依据与对照口径」登记主框架原型与布局依据（链接见上） |
| 侧栏由动态菜单驱动 | `App.vue` 侧栏改读动态菜单 store（`PLACEHOLDER_MENU` 仅开发态降级使用），无硬编码路由表；实测 `GET /api/platform/v1/menus/my` → **200**、`menus=3`（系统管理 / 平台管理 / 系统监控）、`permissions=0`——权限码为 0 时平台菜单经 `canAccess` 过滤为空，侧栏仅呈现**模块菜单**（演示模块 / 示例模块），RBAC 装配归 `02_03` / `02_04` |
| 按钮按动作权限显隐 | `v-perm` 在宿主全局注册，权限码由动态菜单接口回填（核对页演示 `menu:create` / `menu:delete` 显隐） |
| 字段按字段权限显隐与只读 | store 暴露 `fieldPermissions(formId)`（`FormRenderer` 的 `permissions` 消费面）；MVP 页面本体不在本任务 |
| 视觉完整、无裸骨架 | 侧栏（品牌 + 搜索 + 菜单）/ 顶栏 / 页签栏 / 内容区样式齐备（同一外壳逐项实测见 [07-06-01 原型对照](../../../06_布局样式/06_布局样式_01_前端主框架布局样式/测试/01_测试记录_01_前端主框架布局样式.md#proto)） |
| 结构对齐布局设计 | 侧栏（一级图标 + 二级文字）/ 顶栏（折叠 + 右插槽）/ 多标签栏 / 内容区分区与《布局设计 · 主框架》《导航》一致 |
| 去实现命名 | 侧栏与页签可见文本无类名 / 文件路径 / 能力键 |
| 核对载体 | 开发态核对页 `apps/desktop/menu-check.html`（+ `src/dev/MenuCheck.vue` / `menuCheck.ts`），已在两处 `.vscode/launch.json` 选页清单登记；核对页**独立打开时**未注入请求适配器 ⇒ 呈现「装载失败：请求适配器未注入」（用例内以注入适配器方式覆盖装载链路） |
| 差异说明 | 本任务界面交付面为既有主框架外壳与开发态核对页；平台「菜单管理维护页 / 权限码管理页」（原型 `10_菜单管理`）不在本任务，其对照归后续维护页任务 |

## 5. 偏差与遗留 <a id="open"></a>

- 平台「菜单管理维护页 / 权限码管理页」与业务 / 动作码维护写接口不在本任务（见详细设计「边界与开放项」节）。
- 字段权限标记在占位阶段按「默认全部可见可编辑」，真实收窄随 `02_04`；按钮 / 菜单过滤经 `BasePermissionChecker` 提供者注入，`02_04` 交付后自动收口。
- 三库真库迁移演练与联调随部署窗口执行。
