## 2. 任务内容 <a id="content"></a>

1. **内置三类管理员角色**：系统管理员（系统配置）、安全管理员（角色 / 业务 / 动作 / 数据范围 / 密码策略 / IdP 配置）、审计管理员（只读日志与审计），权限互斥；置为内置角色、禁删禁改归属。
2. **互斥校验**：同一用户不得兼任三类内置管理员；授予操作会造成职责互斥或兼任时拒绝（错误码 30010 / 30048）；校验在授权写入**前置**执行。
3. **`role` 业务约束**：`role` 业务仅安全管理员内置角色持有，系统管理员 / 审计管理员不可越权授予；安全管理员管理角色时不得授予超出自身权限的授权、不得造成自身职责冲突（防自锁）。
4. **平台超管边界**：`sys_admin` 跨租户运营仅到租户级（开通 / 停用 / 域名 / 配额 / 模块开关），不进入租户业务数据、不经租户 RBAC 计算；平台级账号与租户侧账号隔离。
5. **开通种子一致性**：租户开通种子写入三类内置管理员角色（互斥预授）与初始系统管理员账号（首次登录强制改密），由初始系统管理员创建另两类；与 `04_01` 开通流程同一口径。
6. **护栏与审计**：新增机器护栏断言内置角色不可删改归属、互斥校验前置生效；互斥与越权尝试落字段级审计。
7. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

三类内置管理员互斥校验生效、同一用户不得兼任；内置角色保护（禁删禁改归属）生效；`role` 业务仅安全管理员可授予、越权授予被拒；平台超管边界验证通过（不进入租户业务数据）；租户开通种子内置角色互斥预授、初始系统管理员账号创建正确；护栏与审计留痕齐备；新增用例覆盖互斥与越权分支。
