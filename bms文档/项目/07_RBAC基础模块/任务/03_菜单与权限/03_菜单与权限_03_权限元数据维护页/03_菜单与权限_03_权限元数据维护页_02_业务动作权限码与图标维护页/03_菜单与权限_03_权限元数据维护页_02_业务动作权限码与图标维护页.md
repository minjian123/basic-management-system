## 2. 任务内容 <a id="content"></a>

1. **业务码管理页**（`/sys/businesses`）：列表（业务码 / 名称 / 权限码数 / 状态）+ 记录页（业务码、多语言名称、状态、系统信息）；新增 / 编辑 / 停用启用 / 有条件删除（无权限码、无表单引用）。
2. **动作码管理页**（`/sys/actions`）：列表（动作码 / 名称 / 状态）+ 记录页（动作码、多语言名称、状态、系统信息）；新增 / 编辑 / 停用启用 / 有条件删除（无权限码）。
3. **权限码管理页**（`/sys/permissions`，新增菜单入口）：列表（权限码 / 名称 / 业务码 / 动作码 / 状态），筛选关键字 + 业务码 + 状态；记录页（业务码 × 动作码选择、组合派生、状态、系统信息）；**手工新增组合**、**批量补生成缺失组合**、停用启用、有条件删除（无按钮挂接、无角色授权）。
4. **自定义图标管理页**（`/sys/icons`）：列表（图标预览 / icon key 复制 / 名称 / 分组 / 引用计数 / 状态）+ 记录页（名称多语言、分组、标签、SVG 上传与预览、状态）；新增 / 编辑 / 启停 / 删除（引用检查），`icon:manage`。
5. **后端补写**：`businesses` / `actions` / `permissions` 各补 POST / PUT / DELETE；权限码补「批量补生成缺失组合」端点；业务码 / 动作码停用联动其权限码（任一被引用则整批拒绝 `40206`）。
6. **权限码与错误码登记**：新增 `business:manage`、`action:manage`（授系统管理员，登记《架构设计 · 权限计算引擎》与种子）；错误码 `40209`（业务码 / 动作码重复）、`40210`（权限码组合重复）；契约快照与 `@bms/api-types` 重生成。
7. **测试与留痕**：先登记 Kiwi 用例再编码；原型对照结论、实施记录、测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

`/sys/businesses`、`/sys/actions`、`/sys/permissions`、`/sys/icons` 渲染真实页面、无占位；三本字典可新增 / 编辑 / 停用启用 / 有条件删除，被引用一律 `40206`；权限码手工新增与批量补生成可用、组合重复报 `40210`；图标可上传 SVG 并复制 icon key；新增权限码生效（租户侧写接口被拒 `40204`）；后端定向用例与前端用例全绿、变更源文件覆盖率 100%；契约快照零漂移。
