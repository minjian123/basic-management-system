## 5. 偏差与遗留 <a id="open"></a>

| # | 偏离 / 遗留 | 处置与归口 |
| --- | --- | --- |
| 1 | 权限码「补生成缺失组合」原型未覆盖（需求 07-17 决策 5） | 已在 `01_设计说明.html` 迭代记录登记，实现与原型一致 |
| 2 | 导出按钮原型可点，本期置灰占位 | 导出 / 查询方案阶段 |
| 3 | 图标预览原恒为兜底问号（`IconRenderer` 优先级缺陷） | 当批修复：字符串 SVG 优先于兜底；ui-ep 用例 + 真机截图复核 |
| 4 | 图标状态原型的筛选值写 `enabled`，后端契约为 `active` | 前端按 `active` / `disabled` 对接，界面文案仍「启用 / 停用」 |
| 5 | SVG 深度清洗（脚本 / 事件属性 / 外链）归文件管理阶段，本期仅基础拒绝 | 文件管理阶段 |
| 6 | 图标记录页首行按字典页 Code / Name / State 三列（原型为 Code / 分组 / 状态 + 名称独占行） | 布局设计优先 |
