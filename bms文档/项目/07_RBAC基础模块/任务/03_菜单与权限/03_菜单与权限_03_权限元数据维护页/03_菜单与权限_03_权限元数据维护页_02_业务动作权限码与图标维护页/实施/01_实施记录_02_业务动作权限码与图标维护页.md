## 3. 关键实现口径 <a id="impl"></a>

1. **业务码 / 动作码**：`code` 新建可填、保存后只读（编辑态禁用）；名称多语言（`MultilingualNameField`）、状态开关；列表为关键字 + 状态 + 20 条/页分页，批量删除 / 启停逐行提交并汇总结果；错误码 `40209`（重复）与 `40206`（引用）由后端返回文案直接提示。
2. **权限码**：组合创建后只读；新增用业务码 × 动作码下拉（仅启用项）派生 `code` 与名称，编辑仅状态；补生成对话框支持「全部 / 指定业务 / 指定动作 + 含停用项」，提交后回显 `{created, restored, skipped}` 计数并刷新。
3. **自定义图标**：列表列＝预览 / 图标键（复制）/ 名称 / 分组 / 引用计数 / 状态；记录页图标键新建可填（kebab-case 校验）、保存后只读；SVG 上传经 `el-upload` 读取文本（类型白名单 + 100KB 上限），预览以 `<img>` data URI 呈现（不执行脚本）；保存时再按 `TextEncoder` 复核内容体积。
4. **图标可见性**：自定义图标装载后登记到活动 `IconRegistry`（`custom:{code}` + 字符串 SVG），`IconRenderer` 按「组件源 → SVG 字符串 → 兜底图标」渲染；停用图标不出现在选择器候选。
5. **状态取值**：图标状态沿用后端 `active` / `disabled`（界面文案仍为「启用 / 停用」）；业务码 / 动作码 / 权限码为 `enabled` / `disabled`。
6. **引用保护**：删除 / 停用一律以后端 `40206` 为准，前端不预判；失败按行提示并保留列表。
7. **数据库收口**：`sys_icon` / `sys_icon_i18n` 由 `planned` 转 `enabled` 入 `platform:tenant` 链，`ops.init_tenant` 幂等补建；`sys_icon_i18n.md` 补齐并登记总览。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 真机进入自定义图标页，`GET /api/v1/icons` 返回 503，后端日志 `no such table: sys_icon`（本地 demo 租户库缺表） | 表归属登记 `planned` → `enabled`；`ops.init_tenant --code demo --service platform` 补建 2 表；表文件 / 总览状态同步「已落库」 |
| 2 | 图标列表预览恒为兜底问号：`IconRenderer.activeComponent` 先取兜底组件，字符串 SVG 源不渲染 | 调整渲染优先级并补 ui-ep 用例；真机复核图标预览与记录页 SVG 预览正常 |
| 3 | 记录页「名称」在编辑态仍禁用：`MultilingualNameField` 的 `disabled` 只在 setup 取值（记录页先只读后切编辑） | 记录页不再传 `disabled`，由 `DictRecordLayout` 的响应式 `el-form :disabled` 控制 |
| 4 | 多语言名称回写死循环（受控件 `setNames` 每次 emit） | 改为 `:model-value` + `@change`，内容相同不回写（`applyNames`），避免对象标识变化触发同步回环 |
| 5 | `FormItem.menu_ids` 雪花 ID 精度丢失（随 `_01` 真机暴露） | 后端响应改字符串化、契约与前端类型重生成；业务 / 动作 / 权限码记录页 ID 关系均为字符串契约，不受影响 |
