## 3. 任务内容 <a id="content"></a>

1. **补 `03_01` 遗留**：把 `/sys/menus`、`/sys/businesses`、`/sys/actions` 三个占位入口替换为真实维护页，并新增 `/sys/forms`、`/sys/permissions`、`/sys/icons` 三个入口。
2. **菜单 / 表单（子任务 01）**：菜单树形列表（拖拽调序）+ 菜单记录页（详细信息 / 挂接配置 / 系统信息，表单多对多、按钮与字段内联维护）；表单独立列表页（含未挂接表单）+ 表单记录页。
3. **三本字典与图标（子任务 02）**：业务码 / 动作码完整 CRUD（多语言名称、停用启用、有条件删除）、权限码手工新增与批量补生成、自定义图标列表与记录页。
4. **后端补写**：`/api/v1/businesses`、`/api/v1/actions` 增加 POST / PUT / DELETE；`/api/v1/permissions` 增加 POST / PUT / DELETE 与「补生成缺失组合」端点；菜单 / 表单删除补角色授权引用检查。
5. **权限码与错误码**：新增 `business:manage`、`action:manage` 并授系统管理员；错误码顺延 `40209`（业务码 / 动作码重复）、`40210`（权限码组合重复）。
6. **原型与文档**：新增「表单管理 / 表单记录页」原型两页，菜单维护页补树拖拽，菜单记录页去掉字段权限入口；回写概要 07 与《架构设计 · 权限计算引擎》权限码清单、错误码登记。
7. **测试与留痕**：先登记 Kiwi 用例再编码；实施记录与测试记录随任务留痕，原型对照结论落测试记录。

## 4. 完成标准 <a id="accept"></a>

六个入口（菜单 / 表单 / 业务码 / 动作码 / 权限码 / 图标）均渲染真实页面、无「页面建设中」；菜单拖拽调序持久化并在刷新后按新顺序下发；菜单 / 表单 / 按钮 / 字段 / 三本字典码 / 图标的增改停用即时作用于动态菜单接口；停用与删除保护按 `07-17` 口径生效（被引用拒绝 `40206`，租户侧只读 `40204`）；后端定向用例与前端用例全绿、变更源文件覆盖率 100%、`preflight` 全绿；原型对照结论登记到测试记录。
