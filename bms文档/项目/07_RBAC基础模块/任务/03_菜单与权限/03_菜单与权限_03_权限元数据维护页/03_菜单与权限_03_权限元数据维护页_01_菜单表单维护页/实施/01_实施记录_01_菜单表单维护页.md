## 3. 关键实现口径 <a id="impl"></a>

1. **拖拽是唯一排序方式**：`reorderMenus` 以 `before / after / inner` 三种落位计算，`inner` 仅允许目录；拖入自身子树、拖入菜单（非目录）与节点不存在均返回 `undefined` 并提示。落位后按同级 10 / 20 / 30… 重排，只提交**父级或顺序变化**的节点（`moves`）；保存失败重新拉取全树回滚。
2. **展开策略**：节点数 ≤ 50 默认全展开、超过只展开第一层；用户展开态写 `localStorage['bms_menu_expanded']`；搜索命中路径时**临时**展开（不写偏好）；程序化展开以 `applying` 门控，避免回写污染偏好。
3. **单一保存**：菜单记录页本体、表单挂接（多对多）、按钮与字段明细只进草稿；工具栏「保存」依次提交本体 → 受影响表单的 `menu_ids` 全量替换 → 按钮 / 字段差异（删除 → 更新 → 新增），任一步失败即停止并保留草稿。新增态创建成功后由视图把 `record:new` 换成实体页签。
4. **挂接配置**：菜单 ↔ 表单多对多，默认从 `listForms()` 的 `menu_ids` 反推已关联表单；按钮 / 字段按表单懒加载，明细行内编辑，删除 / 上移 / 下移走页内工具栏；字段权限**不提供入口**（统一在角色管理授予）。
5. **字段权限入口**：按决策 6 删除，原型同步修订；记录页挂接配置仅保留一行说明。
6. **本地校验**：路由路径必填、必填语言文案非空、按钮名称与权限码必填且同表单权限码不重复、字段标识表单内唯一（`40205`）；后端仍为唯一裁决方。
7. **语言注入**：记录页使用 `MultilingualNameField`，语言清单由 `ENABLED_LOCALES`（`zh-CN` / `en-US`，与后端 `SUPPORTED_LOCALES` 同源）注入；必填语言取动态菜单响应的 `locale`，缺省回退 `zh-CN`。
8. **表单页**：`/sys/forms` 为含未挂接表单的总列表（关联菜单数 `0` 标「无入口」），记录页业务码 1:1、组件选择器候选取 `/form-keys` + `/data-sources` 且允许手输、关联菜单多选可空。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | `FORM_PAGE_DECLARATIONS` 声明 `formKey=menu` / `form`，但 `/api/v1/form-keys` 实测不含这两项（`sys_menu` / `sys_form` 为元数据表、按《数据库开发规范》不落 `form_key`，补登记会使 `check_tables` 报「模型表缺 form_key 列」） | 不改机制：两份声明仍用于**路由装载**（`ensureFormPageRoutes` 直接读声明），`pageRoute.resolve` 对二者返回 `undefined`、不参与通用页面解析；详细设计 §11 开放项 1 已允许「以实测为准、静态路由兜底」，本记录登记为口径偏差 |
| 2 | `MultilingualNameField` 的 `disabled` 在 setup 时取值、不随 prop 变化：记录页在 `load()` 期间先 `editing=false` 再切编辑态，名称输入被永久禁用 | 记录页不再向该件传 `disabled`，改由 `DictRecordLayout` 的 `el-form :disabled` 响应式禁用；编辑态即恢复可输入（`IconRecordTab` 取证） |
| 3 | 菜单记录页「表单挂接」显示 0 条：`FormItem.menu_ids` 契约为 `int[]`，雪花 ID 在 JSON 中丢精度，与菜单树字符串 ID 不匹配（同时表单记录页标签显示原始数字） | 后端契约修正：`FormItem.menu_ids` 改 `list[str]`（`_menu_id_strings` 字符串化），重生成 `platform.json` 与 `@bms/api-types`；表单记录页标签恢复为「系统管理 / 表单管理」 |
| 4 | 自定义图标列表预览恒为兜底问号：`IconRenderer` 的 `activeComponent` 先取兜底图标，字符串 SVG 源永远不渲染 | `IconRenderer` 改为「组件源 → SVG 字符串 → 兜底图标」优先级；ui-ep 用例补「字符串 SVG 优先于兜底」断言 |
| 5 | 本地 demo 租户库缺 `sys_icon` / `sys_icon_i18n`：表归属登记为 `planned` 未入链，图标接口返回 503 `no such table` | `table_registry` 两表转 `enabled`、模型注释同步；补 `sys_icon_i18n.md` 表文件并在总览登记；`ops.init_tenant --code demo --service platform` 幂等补建（新建 2 表） |
