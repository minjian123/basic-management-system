## 1. 背景与目标 <a id="goal"></a>

需求 `07-17` 补 `03_01` 遗留的**平台侧维护页**缺口。`03_01` 已交付菜单 / 表单 / 按钮 / 字段的后端 CRUD（`/api/v1/menus`、`/forms`、`/buttons`、`/fields`）与前端**消费**（动态路由 / 侧边栏 / 按钮与字段显隐），但没有维护界面：`/sys/menus` 经 `router/dynamic.ts::installMenuRoutes` 兜底到 `PlaceholderView`，显示「页面建设中」。

本任务交付两个入口的真实页面：

- `/sys/menus`：菜单树形列表 + 菜单记录页（详细信息 / 挂接配置 / 系统信息）；
- `/sys/forms`：表单独立列表页（含未挂接任何菜单入口的表单）+ 表单记录页。

**边界（不在本任务）**：

- 业务码 / 动作码 / 权限码 / 自定义图标维护页归[子任务 02](../03_菜单与权限_03_权限元数据维护页_02_业务动作权限码与图标维护页/03_菜单与权限_03_权限元数据维护页_02_业务动作权限码与图标维护页.md)。
- 字段权限（`sys_role_field`）授予仍归角色管理（`role:grant`）；菜单记录页**不提供入口**（决策 6，原型已同步删除跳转入口）。
- 角色侧「菜单 / 表单 / 权限码」授权关系维护归 [`02_03` 角色管理](../../../02_用户与角色/02_用户与角色_03_角色管理/02_用户与角色_03_角色管理.md)，本任务只做实体定义与挂接。

- **无表结构变更**：菜单 / 表单 / 按钮 / 字段与 `sys_menu_form`、`sys_role_permission`、`sys_role_field` 均已在 `03_01` / `02_03` 落地；本任务只补种子与查询。

- **删除保护读口径**（只读探测，不写授权表）：
  - 菜单：`sys_menu_form.menu_id`（已有）、子菜单（已有）、`sys_role_permission` 中 `perm_type='menu' AND target_id=menu_id` 或 `source_menu_id=menu_id`（新增）；
  - 表单：`sys_button.form_id`、`sys_field.form_id`、`sys_role_permission` 中 `perm_type='form' AND target_id=form_id` 或 `source_menu_id=form_id`、`sys_role_field.form_id`（新增）。
- 命中一律抛 `MenuReferencedError`（`40206`）。

## 5. 接口设计 <a id="api"></a>

复用 `03_01` 已交付接口，不新增业务端点；仅后端补校验。

| 方法 | 路径 | 权限码 | 本任务用法 |
| --- | --- | --- | --- |
| GET | `/api/v1/menus` | `menu:query` | 列表树（一次返回，不分页） |
| POST / PUT / DELETE | `/api/v1/menus`、`/api/v1/menus/{id}` | `menu:create` / `menu:update` / `menu:delete` | 新增 / 编辑 / 删除；**拖拽调序走 PUT 逐节点**（见 §6.3） |
| GET | `/api/v1/forms` | `menu:query` | 表单总列表（含未挂接；`menu_id` 可空） |
| POST / PUT / DELETE | `/api/v1/forms`、`/api/v1/forms/{id}` | `menu:create` / `menu:update` / `menu:delete` | 表单新增 / 编辑 / 删除 |
| GET / POST / PUT / DELETE | `/api/v1/buttons`、`/api/v1/buttons/{id}` | `menu:query` / `menu:create` / `menu:update` / `menu:delete` | 按钮内联明细 |
| GET / POST / PUT / DELETE | `/api/v1/fields`、`/api/v1/fields/{id}` | 同上 | 字段内联明细 |
| GET | `/api/v1/businesses` | `business:query` | 表单「所属业务」下拉 |
| GET | `/api/v1/form-keys` | 登录即可 | 视图组件选择器候选（`kind=form`） |
| GET | `/api/v1/data-sources` | 登录即可 | 视图组件选择器候选（`kind=dict`） |

**请求要点**：

- 菜单新增 / 编辑：`{parent_id, path, component, icon, sort, hidden, status, i18n}`，`i18n` 必含请求语言（后端 `40208`）；
- 拖拽调序：对受影响节点逐个 `PUT /menus/{id}`，请求体为该节点**完整**现状 + 新 `parent_id` / `sort`（后端为整体替换语义，不发局部补丁）；
- 表单新增 / 编辑：`{menu_ids, business_id, component, status}`；
- 按钮：`{form_id, permission_id, name, type, sort, status}`；字段：`{form_id, field_key, type, sort, status, i18n}`。

**失败分支**：`40201` 实体不存在、`40202` 挂接链断裂（保存前本地校验 + 后端兜底）、`40203` 路径 / 组件冲突、`40205` 字段键重复、`40206` 被引用禁删、`40208` 缺必填语言；前端按错误码映射提示，不逐条硬编码文案键（沿用宿主 `api/error.ts`）。

## 6. 前端设计 <a id="frontend"></a>

### 6.1 路由与菜单认领

- `FORM_PAGE_DECLARATIONS` 增两项：`{formKey:'menu', title:'菜单管理', path:'/sys/menus', name:'SystemMenu', list: () => import('@/views/system/menu/MenuView.vue')}`、`{formKey:'form', title:'表单管理', path:'/sys/forms', name:'SystemForm', list: () => import('@/views/system/form/FormView.vue')}`。
- 通用页面路由的 `formKey` 需在 `GET /form-keys` 清单中存在；`sys_menu` / `sys_form` 两表已有 `form_key` 列（`03_01` 落表），种子随表写入。若清单未返回，`pageRoute.resolve` 跳过装载、页面仍可由静态路由兜底——实施时以实测为准（见 §11 开放项 1）。

### 6.2 列表页（`MenuView.vue` / `FormView.vue`）

- 骨架复用 `FormFrame` + `PageContainer` + `DataTable`：列表 Tab 固定不可关，双击行 / 「新增」开记录 Tab（新增即编辑态），无操作列。
- 菜单树：`DataTable` 树形模式（`row-key="id"`、`tree-props`），列＝菜单名称 / 类型（目录 · 菜单，按 `component` 是否为空判定）/ 路由路径 / 视图组件 / 排序 / 状态；筛选＝关键字（名称或路径）+ 菜单类型 + 状态（单行）；展开状态写 `localStorage['bms_menu_expanded']`，≤50 节点默认全展开、超过只展开第一层；搜索命中路径自动展开（临时展开不写偏好）。
- 表单列表：列＝业务码 / 视图组件 / 关联菜单数 / 状态；筛选＝关键字（component）+ 业务码 + 状态；分页 20 条/页（**表单不是树形元数据**，按原型 08 口径分页）。
- 批量停用 / 启用：逐行 PUT 状态，汇总成功数；批量删除：二次确认，逐行 DELETE，失败逐条提示（`40206` 提示先解除引用）。

### 6.3 树拖拽调序（`menuTree.ts`）

- 纯函数 `reorderTree(nodes, dragKey, dropKey, position)` → `[{id, parent_id, sort}]`，其中 `position ∈ before | after | inner`；禁止把节点拖入自身子树（命中即拒绝并提示）。
- 交互：行拖拽手柄（`⋮⋮`），`dragover` 计算落点并高亮；`drop` 后**本地乐观更新**树，再逐个 PUT；任一 PUT 失败 → 重新拉取树回滚并提示。
- 排序值规则：同一父级内按数组顺序重算 `sort = (index + 1) * 10`，只提交**发生变化的节点**（父级或顺序变动者）。

### 6.4 记录页（`MenuRecordTab.vue` / `FormRecordTab.vue`）

- 结构：工具栏（编辑 / 保存 / 取消 / 关闭）+ 信息栏页签。菜单三页签「详细信息 / 挂接配置 / 系统信息」，表单两页签「详细信息 / 系统信息」；系统信息用 `SysInfoPanel`（`08_01` 通用件）。
- 只读 / 编辑分态：进入默认只读，点「编辑」切换；`dirty` 汇总本体 + 挂接配置三块（表单 / 按钮 / 字段），关闭页签与切页签均拦截。
- **单一保存**：本体与挂接配置草稿随工具栏「保存」一次提交——菜单本体 PUT、表单关联通过表单 PUT（`menu_ids` 全量）、按钮 / 字段逐条 POST / PUT / DELETE（新增项先建后记 ID）；任一步失败 → 停止后续、保留草稿并提示。
- 名称用 `MultilingualNameField`（`I18nNames`），语言清单经 `useBaseLocale` / 宿主语言清单注入；默认语言必填（后端 `40208`）。
- 视图组件：选择器候选来自 `/form-keys`（form）与 `/data-sources`（dict），允许手输；图标用 `IconPicker`（`el:` / `biz:` / `custom:`）。
- 表单记录页：业务码单选（来自 `stores/menuMeta` 的业务码清单）、关联菜单多选（树形多选，允许空 = 未挂接）、组件、状态。

### 6.5 挂接链本地校验

保存前本地模拟：表单未挂业务（本轮必填，编辑态不允许清空）→ 阻断并提示 `40202`；按钮未选权限码 → 不允许提交该行；字段 `field_key` 表单内重复 → `40205`。后端仍为唯一裁决方。

## 12. 决策确认（2026-10-21，共 12 项） <a id="decide"></a>
