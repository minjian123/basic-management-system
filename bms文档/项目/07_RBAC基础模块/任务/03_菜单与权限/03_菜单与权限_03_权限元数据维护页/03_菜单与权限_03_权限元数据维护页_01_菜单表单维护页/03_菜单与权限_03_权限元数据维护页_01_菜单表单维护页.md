## 2. 任务内容 <a id="content"></a>

1. **菜单管理页（列表 Tab）**：树形表格（列＝菜单名称 / 类型 / 路由路径 / 视图组件 / 排序 / 状态），**树拖拽调序**回写 `parent_id` 与 `sort`，批量停用 / 启用，删除（子节点、表单挂接、角色授权引用检查），筛选（关键字 / 菜单类型 / 状态）与展开状态本地记忆。
2. **菜单记录页（记录 Tab）**：三页签「详细信息 / 挂接配置 / 系统信息」——详细信息含父级菜单、路由路径、视图组件（选择器 + 手输）、图标（IconPicker）、多语言名称（`MultilingualNameField`）、侧边栏显示、状态；挂接配置含表单挂接（多对多）、按钮维护、字段维护（内联明细，随宿主「保存」一次提交）；**不提供字段权限入口**。
3. **表单管理页（独立列表页 `/sys/forms`）**：含未挂接任何菜单入口的表单；列＝业务码 / 视图组件 / 关联菜单数 / 状态；筛选关键字 + 业务码 + 状态；批量停用 / 启用与删除（引用检查）。
4. **表单记录页**：详细信息（业务码、视图组件、关联菜单多选、状态）+ 系统信息；只读 / 编辑分态、工具栏单一保存、dirty 拦截。
5. **后端配套（小改）**：菜单删除补角色授权引用检查（`sys_role_permission` 的 `perm_type=menu` / `source_menu_id`）；表单删除补按钮、字段、角色表单授权与字段权限引用检查；新增表单菜单种子 `/sys/forms`。
6. **路由与页面装配**：菜单页走通用页面路由（`FORM_PAGE_DECLARATIONS` 增加 `formKey=menu` → `/sys/menus`），表单页走同一机制（`formKey=form` → `/sys/forms`）；其余静态路由。
7. **测试与留痕**：先登记 Kiwi 用例再编码；原型对照结论、实施记录、测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

`/sys/menus` 与 `/sys/forms` 渲染真实页面、无占位；菜单拖拽后 `parent_id` / `sort` 落库并在刷新后按新顺序下发；菜单记录页一次保存完成菜单本体与表单 / 按钮 / 字段挂接提交；表单页可维护无入口表单；删除保护与停用口径生效（`40206`）；前端用例全绿、变更源文件覆盖率 100%；原型逐页对照结论登记。
