## 5. 偏差与遗留 <a id="open"></a>

| # | 偏离 / 遗留 | 处置与归口 |
| --- | --- | --- |
| 1 | 原型工具栏「导出」可点，本期置灰占位（导出能力未立项） | 导出 / 查询方案阶段；按钮保留 `title` 说明 |
| 2 | 原型「关闭」关闭页面；实现为返回工作台（列表页签固定不可关，表单框架口径） | 与布局设计表单框架一致 |
| 3 | 原型表单挂接用「选择表单」弹窗；实现用多选下拉 + 已关联表格 | 功能等价、关系同源（`sys_menu_form`），减少弹窗层级 |
| 4 | 业务码 / 名称 / 状态首行顺序：原型将状态与业务码同排；实现按《布局设计 · 字典页》首行 Code / Name / State 三列 | 布局设计优先（《原型审查规范》口径） |
| 5 | `/form-keys` 不含 `menu` / `form`，两页不参与通用页面解析 | 见实施记录 §4 问题 1；路由由声明装载，页面可用 |
| 6 | 键盘调序 / 拖拽无障碍未实现 | 交互增强任务 |
