## 2. 实施过程 <a id="process"></a>

### 2.1 骨架件契约扩展 <a id="uiep"></a>

`ui-ep/src/components/layout/DictRecordLayout.vue` 在「系统信息」页签内、内置 `SysInfoPanel` **之后**增加可选具名插槽 `sys-extra`（不传即不渲染，无空容器）；props / emits / 既有插槽（`toolbar` / `first-row` / `fields` / `extra-tabs`）、落点与基类挂链（布局族 `useBaseLayout` 投影）不变。

### 2.2 角色记录页（`RoleRecordTab`） <a id="role"></a>

1. 引入骨架件 `DictRecordLayout`，删除页内自建 `el-tabs` 三页签与 `el-form` / `el-row` 首行结构、删除 `import SysInfoPanel`（`sysInfo` 类型仍取 `SysInfoData`）。
2. `section` 由联合类型收敛为 `string`（仅作受控页签键，与骨架件 `modelValue: string` 对齐，避免为窄化赋值引入运行时分支）。
3. 模板改为插槽式：`toolbar`（保存 / 撤销 / 编辑 / 关闭 / 右侧载入中 · 脏标记 · 内置角色提示，`data-test` 全保留）、`first-row`（角色码 / 角色名 / 状态，三个 `el-col :span="8"`，状态沿用 `el-select`、内置角色时禁用）、`fields`（角色类型，置于 `el-row`）、`extra-tabs`（`el-tab-pane` 权限配置 + `RolePermissionConfig`，`ref` 与 `@dirty` 原样）。
4. 删除页内 `.role-record__bar` 样式（工具栏容器与间距归骨架件）；根节点保留 `data-test="role-record"` 以承接宿主用例。

### 2.3 用户记录页（`UserRecordTab`） <a id="user"></a>

1. 同 2.2 改用骨架件（引入 `DictRecordLayout`、删除页内页签与 `SysInfoPanel` 引用、`section` 收敛为 `string`）。
2. `toolbar`（保存 / 取消 / 修改 / 删除 / 刷新 / 关闭 / 载入中 · 脏标记）、`first-row`（用户名 / 姓名 / 状态，用户名仅新增态可填）、`fields`（手机号 / 邮箱 / 新增态首登改密）、`extra-tabs`（`el-tab-pane` 用户分配：新增态空态、停用只读提示、`ModuleAreaOutlet` 挂接位 `sys.user.detail.tabs`）原样迁入插槽。
3. `sys-extra` 承载原「SSO 身份绑定」只读区块（区块标题 + 提示 + `el-table`，`data-test="user-record-identities"`）；系统信息第 7 项显示名由「用户表单」改为 **「用户管理」**（与宿主表单声明 `title` 同源）。
4. 删除页内 `.user-record__bar` 样式；`user-record__section` / `__hint` 保留供 SSO 区块使用。

### 2.4 用例与护栏调整 <a id="tests"></a>

1. `ui-ep/tests/dict-record-layout.spec.ts`：插槽装配补 `sys-extra`，新增「系统信息侧扩展位渲染在内置件之后 / 不传即不渲染」用例；首行注释 `kiwi_id` 增 2294。
2. `apps/desktop/tests/role-record-tab.spec.ts` / `tests/user-record-tab.spec.ts`：系统信息断言由页内 `role-record-sysinfo` / `user-record-sysinfo` 改指内置件 `[data-test="sys-info-panel"]`（页面不向骨架件传 `data-test`，保留件自身标识）；各新增 3 例对齐断言（骨架件承载 + 页签顺序、首行三字段等宽与顺序、系统信息侧承载 / SSO 区块落位）；首行注释 `kiwi_id` 增 2294。
3. 布局族护栏 `layout-style.spec.ts` 不涉及（本次不新增件，仍 20 件）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |

| 2 | `vue/require-default-prop` 与可选 prop 无冲突（本次未新增 props） | 无 |
