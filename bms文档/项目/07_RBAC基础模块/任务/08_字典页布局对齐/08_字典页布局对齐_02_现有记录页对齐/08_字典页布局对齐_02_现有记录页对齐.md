## 2. 任务内容 <a id="content"></a>

1. **角色记录页**（`frontend/apps/desktop/src/views/system/RoleRecordTab.vue`）：详细信息首行三字段按 `Code` / `Name` / `State` 固定（角色码 / 角色名 / 状态）、三列等宽顺序固定；其余字段（角色类型等）一律排首行之后；信息栏保留「详细信息」「系统信息」两侧（业务 Tab「权限配置」不受限，照常保留）。
2. **用户记录页**（`frontend/apps/desktop/src/views/system/user/UserRecordTab.vue`）：同上口径——首行三字段（用户名 / 姓名 / 状态）、其余字段排首行之后、「详细信息 / 系统信息」两侧齐备（业务 Tab「用户分配」不受限）；SSO 身份绑定只读区块归「系统信息」侧现状不变。
3. **系统信息件**：两记录页改用 `08_01` 对齐后的通用件，删除页面内各自的系统信息写法，消除重复实现。
4. **状态控件与列宽**：首行三字段的控件形态按 17 §3 选取（`State` 可用状态开关或状态下拉），同模块内保持一致；三列等宽（`el-col :span="8"`）。
5. **原型对照（界面类强制）**：按《[原型审查规范](../../../../../规范/原型审查规范.md)》§4.9，真机截图 + 逐页对照《[布局设计 · 字典页](../../../../../设计/布局设计/17_布局设计_字典页.html)》与既有页面原型《[08_用户管理](../../../../../设计/原型设计/08_用户管理/)》《[09_角色管理](../../../../../设计/原型设计/09_角色管理/)》，结论登记测试记录（含存在性 `.png`）；发现的偏离**就地修复**或登记归口。
6. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注与实施 / 测试记录留痕。

## 3. 完成标准 <a id="accept"></a>

角色 / 用户两记录页的详细信息首行三字段顺序与列宽固定、无字段插队，信息栏含「详细信息」「系统信息」；系统信息区为对齐后的通用件（7 项、第 7 项为 `form_key`（字典对应的表单标识））；真机逐页对照结论齐备、偏离项已修复或登记归口；前端定向用例通过、覆盖率达标、`check-preflight.py --fast` 全绿（含 `check-prototype-review` 项）。
