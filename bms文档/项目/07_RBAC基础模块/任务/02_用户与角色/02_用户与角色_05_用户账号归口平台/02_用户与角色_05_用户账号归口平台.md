## 2. 任务内容 <a id="content"></a>

1. **两表迁库**：`sys_user` + `sys_account_lock` 由 org 服务租户库迁 **platform 服务租户库**（`bms_platform_{code}`）——模型 / 仓储 / 服务 / 内部端点 / 账号锁定管理端点全部随表迁；表归属登记（`TABLE_OWNERSHIP`）与链派生同步。
2. **迁移链**：`org:tenant` 链 `0001~0005` 原样保留（已部署库链不破），org 侧**补一条删表迁移**收敛为净零；platform 侧新增建表迁移；ops 侧新增**跨库幂等数据搬迁脚本**（按租户逐库，按主键 upsert）。已部署环境固定「**platform 建表 → 数据搬迁 → org 删表**」顺序；本地开发库直接重建。
3. **identity 内部契约改指**：内部凭据 / 用户契约由 org 迁 platform（`/api/v1/platform/internal/credentials/*`、`/api/v1/platform/internal/users/*`，`require_service("identity")`）；identity 侧服务间调用目标服务由 `org` 改 `platform`，客户端与 schema 命名同步为 `Platform*`。
4. **账号锁定管理面**：锁定记录列表 / 详情 / 手动锁定 / 解锁迁 platform，对外路径 `/api/v1/account-locks`；权限码 `user:query` / `user:lock` / `user:unlock` 与留痕口径不变。
5. **运维脚本**：`ops/seed_user.py` 改指 platform 租户库；新增跨库数据搬迁脚本；`ops/init_tenant.py` / `provision_tenant.py` / `migrate_tenants.py` 按服务维度核查同步。
6. **角色域协同**：`sys_user_role.user_id` 由**跨服务逻辑外键**降为**同库**引用（角色分配与用户查询同库完成）；`sys_user_role` 表文件与角色节点跨库说明同步。
7. **契约与类型**：org / platform 公开契约快照重生成、前端 `api-types` 重生成；org 移除用户 / 锁定端点属预期破坏性变更，契约基线同步更新。
8. **文档回写**：数据库设计表文件（归属库 / ORM 模型 / 迁移链 / 变更记录）、总览登记、角色节点、相关设计文档与需求 / 任务 / 计划同步。
9. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

终态「用户（账号）/ 角色 / 授权」全在 platform 服务租户库，**零跨服务引用**（角色分配与用户查询同库完成）；identity 登录 / SSO / 找回密码链路经 platform 内部端点正常；锁定管理端点可用且留痕口径不变；表归属登记与迁移链表集一致（org 历史链保留、platform 新建表、org 删表净零）；公开契约与前端类型生成一致；定向用例与基座校验全绿。
