## 2. 任务内容 <a id="content"></a>

1. **收口现存不一致**：四策略求值器当前对 `select` / `region` 额外要求「字段名」，与《数据库设计 · `sys_data_scope`》表文件口径（按数据源维度产出集合）不一致；按表文件口径修正，`config` 结构与求值语义对齐。
2. **`select` 勾选式**：按数据源维度承载少量勾选值，产出对应集合；值数量超阈值时给出引导（改用区域 / 匹配 / 扩展式），不静默退化为巨型值列表。
3. **`region` 区域式**：起止值经 SQL 区间算子表达，产出范围内集合（不枚举）。
4. **`match` 匹配式**：通配符经 SQL 匹配算子表达，产出匹配集合（不枚举）；字符与通配符允许集与既有校验口径一致。
5. **`extension` 扩展式**：二开注册求值器**直接返回权限集合**，为超大规模场景的兜底路径；未注册即不产生放行（从严）。
6. **并集与永假兜底**：四类结果并集使用；非法 / 未注册规则退化为永假条件并上报，不放大范围。
7. **文档一致性回写**：求值口径与表文件、详细设计三处一致；如涉及表文件字段语义变化，按「先改表文件 → 模型 → 建表 → 回写状态」顺序。
8. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

四策略求值语义与《数据库设计 · `sys_data_scope`》表文件口径完全一致（无「额外字段名」等差异）；`select` 超阈值给出引导而非退化；`region` / `match` 经 SQL 算子表达、不枚举；`extension` 直接返回集合；非法规则永假并上报；读注入与写校验双向生效且强制租户过滤；相关用例全绿、覆盖率达标、`preflight --fast` 全绿。
