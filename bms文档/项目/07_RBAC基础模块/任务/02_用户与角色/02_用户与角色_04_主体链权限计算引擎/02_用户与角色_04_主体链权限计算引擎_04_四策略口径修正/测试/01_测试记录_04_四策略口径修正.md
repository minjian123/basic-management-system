## 5. 问题与偏差 <a id="issues"></a>

| # | 事项 | 处置 |
| --- | --- | --- |
| 1 | `_materialize` 重建 `in` 条件时丢失数据源标识（并集合并后消费侧无法映射） | 用例先暴露 → 改为原样携带（实施记录 §3.2），复跑全绿 |
| 2 | 空 / 非序列 `config` 原为「不过滤」（等于放开全部数据） | 收口为「永假」（从严）；同步 2 处断言并在详设 §6 登记 |
| 3 | 首版集合声明被 `check_bare_collections.py` 拦下（15 处：`frozenset` / `list` / `Mapping` / `dict`） | 统一改 `ConcurrentStableSet` / `ConcurrentStableList` / `ConcurrentStableDict`，护栏复跑通过 |
| 4 | 单向类型归一导致「实体字符串列 vs 整型成员」不命中（与 SQL 侧不一致） | `_equal` / `_compare` 改双向归一，补全分支用例 |
| 5 | 前端仅转提交键会让「取数 snake → 域内 camel」失配、脏基线永久脏 | 成对实现取数回转（`fromDataScopeApiItem`），域内与 `payloadKey` 保持 camel |
| 6 | `ui-ep` 1 例与 `desktop` 2 例护栏用例在 Windows 下失败：`interaction-style.spec.ts`（相对路径 `\` vs `/`）、`guard-slot-host-isolation.spec.ts`（`endsWith('module/entries.ts')`）、`shared-dependencies.spec.ts`（外置依赖仓版本解析） | **本机环境限制，与本次改动无关**（三例均未改动、断言均为 POSIX 路径 / 依赖布局假设）；以 Linux CI 为准；为使覆盖率可度量，`test:cov` 临时排除前两例后全量 100% |
