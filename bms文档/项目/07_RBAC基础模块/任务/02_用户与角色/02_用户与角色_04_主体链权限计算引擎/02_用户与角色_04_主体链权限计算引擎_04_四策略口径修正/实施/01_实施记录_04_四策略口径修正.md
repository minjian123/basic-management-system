## 3. 实施过程与关键处置 <a id="process"></a>

### 3.1 现状实证：真实链路 `select` / `region` 一直永假

表文件口径的 `config`（`{"item_code"}` / `{"start","end"}`）进来后，求值器取不到 `field` 直接 `_deny`；平台写入口又不写 `field`、也不校验 `select` / `region`——即「配了等于没配」，且无任何报错指向根因。本次以「条件字段改由数据源维度承载」的形态收口，而非在配置里补字段。

### 3.2 执行期修正：物化把数据源标识丢掉（用例先暴露）

`scope/rbac.py::_materialize` 只重建 `in` 条件的 (field, operator, value)，**漏了 `data_source_key`**，导致层2 缓存回来的同数据源 `in` 条件在并集合并后丢失数据源标识（消费侧无法映射）。由 `test_same_source_in_conditions_merge_as_union` 断言 `data_source_key` 时暴露，改为原样携带。

### 3.3 语义收窄：空 `config` 由「不过滤」改为「永假」

旧实现下 `config` 为空（或非序列）时求值器返回空条件列表 → 注入点无过滤 → **等于放开全部数据**。新实现下 `select` 无勾选值即 `_deny`（该条不产生放行）。同步更新 `test_rbac_scope_layer2.py::test_non_sequence_config_denies_all` 与 `test_policies_rbac.py` 对应断言，并在详设 §6 登记该行为变化。

### 3.4 集合类护栏（bare-collections）强制口径

首版用 `frozenset` / `list` / `Mapping` 声明算子集合与列映射，被基座护栏 `check-bare-collections.py` 拦下（15 处新增）。统一改为 `ConcurrentStableSet` / `ConcurrentStableList` / `ConcurrentStableDict`（`scope_columns` 声明、算子集合、归一后成员列表与测试桩），复跑护栏通过。

### 3.5 类型归一：两个方向都要通

只做「字符串成员 → 实体整型」会让「实体字符串列 vs 整型成员」不命中，与 SQL 侧（`str` 列把成员 `str(...)`）不一致。`_equal` / `_compare` 改为双向归一，SQL 侧 `_coerce_member` 按列 `python_type` 覆盖 `int` / `float` / `str`；无法归一即不命中（内存）/ `false()`（SQL），并累计非法规则计数。

### 3.6 写侧映射：不传即拒（避免静默跳过）

旧 `allow_write` 对「条件字段不在待写值中」一律跳过；数据源维度条件字段为空会被静默跳过 → 越权可写。新逻辑先翻译列：数据源维度条件取 `scope_columns`，缺失且 `field` 为空 → 直接 `False`（拒），不做「跳过」；`match` 有白名单字段可回落。

### 3.7 配置期与运行期阈值同源

阈值解析下沉 `scope/limits.py`，`RbacDataScope` 与 platform `RoleGrantService` 共用 `data_scope_max_in_values(settings)`；`RoleGrantService` 增可选 `settings`（缺省 `get_settings()`，既有构造点零改动，用例可注入小阈值）。

### 3.8 前端：提交转键 + 取数回转（脏基线不漂移）

只改提交侧会让「取数（snake）→ 域内状态（camel）」失配，进而把脏基线判成永久脏。故成对实现：提交经 `collectDataScopeSubmitPayload` 转 `item_code`，取数经 `fromDataScopeApiItem` 回 `itemCode`；域内类型与 `payloadKey` 保持 camel 不变。

### 3.9 覆盖率补齐

- 后端：补 `_coerce` / `_equal` / `_compare` 全分支、`_coerce_member` / `_coerce_value` / `_python_type` 全类型、`_condition_column` 三分支、`NullDataScope.allow_write`、无租户主键时的 `_tenant_condition`、`_value_members` 非容器分支。
- 前端：补载荷转键 / 取数回转 / 空 `item_code` 回落等分支。

## 6. 偏差与遗留 <a id="open"></a>

| # | 事项 | 归口 |
| --- | --- | --- |
