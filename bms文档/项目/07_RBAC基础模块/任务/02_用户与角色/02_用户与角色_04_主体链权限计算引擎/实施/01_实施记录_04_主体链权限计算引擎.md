## 2. 改动清单（按接缝）

1. **基座校验入口**（`bms_core/permission/base.py`）：`BasePermissionChecker` 增 **`aprepare(*, request)` 请求级预加载钩子**（缺省空实现）；`require_permission` 依赖改 **async**（先预加载再同步 `require`）；新增 `prepare_permission_dependency()`（仅预加载，供 `/menus/my` 这类逐码自判端点）。**不向钩子注入依赖**——实现自取 `request.app.state` 与会话作用域。
2. **快照上下文位**（`bms_core/permission/snapshot.py`）：`current_permission_snapshot` + `get_/set_current_permission_snapshot()`；新增 **写拒绝接缝 `assert_fields_writable`**（服务层写入口显式调用）。
3. **字段权限**（`bms_core/permission/field.py`）：provider 注册表改**工厂** `(租户库会话, 元数据库会话) → provider`（会话请求级，实例不可预建）。
4. **数据范围**：`bms_core/scope/policies.py`（**策略注册表**，核心不判策略类型）；`scope/extensions.py` 补**求值器注册表**；`base_scoped_repository.py` 的 `like` 支持 SQL `LIKE` 通配（含 `%`/`_` 时通配匹配，否则保持子串语义）。
5. **平台实现**：引擎 + 校验器 + 字段 provider + 四策略 + `RbacDataScope`；`prepare_settings` 内启用 `[permission].provider = rbac` 与 `[data_scope].provider = rbac`（未显式配置时），并登记实现（**须在建注册表之前**）。
6. **动态菜单**：`MyMenuService._to_fields` 由硬编码全开改为读快照 `field_state`；`/menus/my` 挂预加载依赖。权限概要（`permissions`）经同一 checker 汇总（前端零改动）。
7. **种子**：`ops/seed_rbac.py`（`system_admin` 持除 `role:*` 外全部在册码；`security_admin` 持 `role:*`；`audit_admin` 本轮空）——**安全管理员不豁免**，其可达性完全依赖本清单。

## 3. 关键处置（踩坑与决策）

1. **插件注册表两处硬约束**：①`register_plugin(plugin_key, plugin_name, impl)` 首参是**能力域键**；②`BaseFactory` 同承 `BasePluggable`——**零参可实例化的工厂类会被自动登记**（注册表调它得到的是工厂实例而非产出物）。修法按仓内惯例：工厂**必填 `settings`**。
2. **登记时机**：插件注册表在应用构造中段构建并冻结，`configure_service` 已晚于该时点 → 登记放 **`prepare_settings`**；**按注册表实例幂等**（注册表会被测试重置，用进程级标记会在重置后丢失 `rbac`）。
3. **校验器依赖自取**：早期把 `uow` / `cache` 注入 `aprepare` 会让所有 `require_permission` 调用方与单测被迫接库（基座 3 例失败）→ 改为实现自取 `request.app.state` + `session_scope`，并以 `request.state` 标记保证同请求只预加载一次。
4. **豁免与从严口径**：无用户上下文（服务身份 / 平台层）按 `platform_admin` 豁免（避免内部通道误拒）；**未预加载则从严拒绝**（防依赖漏挂静默放权）。
5. **字段 / 数据范围的「无规则」语义**：字段默认全开、数据范围无规则不过滤（收窄语义）；「无角色 → 全无」由权限码集合为空在菜单 / 接口层体现（快照不含角色 id，无法在本层区分）。
6. **数据范围并集**：注入点条件列表按 AND 合取，故**同字段同 `in` 真合并**、其余退化合取（从严）+ 上报。

## 4. 装配与配置

```toml
[permission]
provider = "rbac"          # 未显式配置时由 platform 的 prepare_settings 置位
profile = "smb"
[permission.options]
snapshot_ttl_seconds = 300
exempt_role_types = ["system"]

[data_scope]
provider = "rbac"          # 同上
```

- 仅 **platform** 持有 `rbac` 实现（角色域与校验器所有者）；其余服务维持占位实现（配置共享，故由服务侧 `prepare_settings` 置位而非写进共享配置）。
- **运维步骤**：新环境需 `python -m ops.seed_rbac`（依赖 `ops.seed_menu` 已落动作码；平台库未登记的码跳过并上报）。生产 bootstrap 与 `seed_menu` / `seed_user` 同口径——**人工步骤**，不入 `release.py`。

## 6. 遗留 <a id="open"></a>

1. **`BaseScopedRepository._apply_data_scope` 无调用方**——数据范围为**显式 opt-in**，业务仓储需在落库时接入（随业务模块）；详设「实现 provider 即全局生效」尚未接线。
2. **字段写拒绝接入点**：接缝 `assert_fields_writable` 已交付并有用例，但**业务表单写入口尚未落地**，实际调用随业务模块。
3. **字段读过滤**：`/menus/my` 已按收窄下发标记；**列表 / 详情接口的读过滤**（按字段键剔除不可见字段）随业务查询接口落地。
4. **审计管理员授权**为空——审计域权限码随审计模块落地（`03_02` 三权互斥一并收口）。
5. **平台层豁免口径**：`tier=platform_admin` 目前按「无租户 / 无用户上下文」判定，平台超管的正式边界归 `04_01`。
6. **mdm 变更事件订阅**：当前经内部失效端点**先行**生效；事件轨（订阅 mdm 组织变更自动失效）未落。
7. **本机 dev 库**：`sys_role` 缺 `role_type` 列（迁移 `0009` 未应用到 dev sqlite）→ 执行 `ops.seed_rbac` 前需先迁移。
