## 2. 任务内容 <a id="content"></a>

1. **角色分配收敛**：用户直接角色读 `sys_user_role`；岗位/部门角色经 mdm「按用户解析角色」只读契约跨服务取回；两路并集去重，统一收敛为「用户 → 角色」。
2. **权限聚合与缓存**：角色集合 → `sys_role_permission` → 业务码 + 动作码集合；结果缓存 Redis（`bms:{tenant}:perm:{user_id}:{version}`）。
3. **版本失效**：角色 / 授权 / 角色分配 / 岗位 / 部门变更 → 权限版本 +1 并清理相应用户缓存，保证变更即时生效。
4. **两级校验点**：业务级 `require_permission(业务码)`（依赖注入，路由注册声明）与动作级 `require_permission("业务:动作")`；后端强制校验与前端显隐双重控制。
5. **字段权限**：读时序列化层过滤不可见字段（不返回不渲染）、写时拒绝不可编辑字段；与数据脱敏互补。
6. **数据范围**：规则表达式解析为 SQL 条件注入 repository 查询（读时）、写入口校验（写时），双向检查并强制叠加租户过滤，禁止跨租户。
7. **组织主数据只读出口联调**：用户 / 岗位 / 部门树作为主体链与数据范围数据源，统一经组织主数据查询出口（查询与批量回显分列、部门树一次性返回）；可见范围经数据范围注入过滤、敏感字段脱敏，**过滤与脱敏在实现侧强制接入、调用方不可绕过**；不直连 mdm 组织表。
8. **权限概要装载**：登录后首次加载权限概要，供动态菜单与前端显隐使用；token 不内嵌权限。
9. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

用户直接 + 岗位/部门（跨服务）角色并集计算正确；越权与跨租户访问被拒验证通过；授权 / 岗位 / 部门变更经版本失效即时生效；字段权限读不返回、写拒绝生效；数据范围读写双向检查生效且强制租户过滤；组织主数据只读出口联通、过滤与脱敏不可绕过；登录后权限概要装载正确；新增模块覆盖率达标、`preflight --fast` 全绿。
