## 2. 任务内容 <a id="content"></a>

1. **用户 CRUD 后端**：`GET/POST /api/v1/users`、`GET/PUT/DELETE /api/v1/users/{id}`；筛选 `username/nickname/email/phone/status/dept_id/岗位` 与分页；新建初始化密码与强制首登改密；修改昵称 / 邮箱 / 手机 / 部门 / `locale` / `timezone`；软删除 `deleted_at`（`(username, deleted_at)` 复合唯一，删除即释放用户名）；`version` 乐观锁。
2. **启用 / 停用**：`PUT /api/v1/users/{id}/status`；停用即时失效会话（复用阶段六踢出通道），列表状态列支持内联切换（不新增 toggle 接口）。
3. **重置密码**：`PUT /api/v1/users/{id}/password`；PBKDF2 重哈希、写 `pwd_changed_at/pwd_history/pwd_reset_required`、失效全部会话、可选通知。
4. **账号锁定治理**：锁定列表 / 详情（`GET /api/v1/org/locks`、`GET /api/v1/org/locks/{id}`）、手动锁定（`POST /api/v1/org/locks`，`manual` 型）、手动解锁（`PUT /api/v1/org/locks/{id}/unlock`，记录 `unlock_by/unlock_at`）；与阶段六 `sys_account_lock` 读写口径衔接。
5. **主体绑定与身份查看**：`GET /api/v1/users/{id}/roles`（只读，维护归 `02_03`）、`GET /api/v1/users/{id}/identities`（只读 `sys_user_identity`）。
6. **组织归属**：`dept_id` 为 mdm `org_dept` 逻辑外键，只读回显经组织主数据只读出口（`02_04` 联调）；岗位分配经 mdm 插件（挂 `sys.user.detail.tabs`），**本任务不提供 `/users/{id}/posts` 接口**（占位说明保留、接入后移除）。
7. **契约与安全**：权限码 `user:query/create/update/delete/reset_pwd/lock/unlock/assign_role`；错误码段 3xxxx（30001~30011）；事件 `sys.user.created/updated/deleted/password_reset`；敏感字段（密码 / token）日志脱敏；不得停用 / 删除自身、内置管理员保护、密码策略强制执行；契约快照与前端类型生成对齐。
8. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

用户 CRUD 全链路可用、软删除后用户名可复用；启停与删除即时踢出；重置密码强制改密且全部会话失效；锁定列表 / 手动锁定 / 手动解锁可用、解锁留痕可查；部门经组织只读出口回显、岗位分配经 mdm 插件（缺失隐藏、不报错）；`user.*` 事件发布；密码策略（复杂度 / 有效期 / 近 5 次历史 / 未登录自动锁定）强制生效；契约快照与前端类型生成对齐；新增模块覆盖率达标、`preflight --fast` 全绿。
