## 3. 关键实现口径 <a id="impl"></a>

1. **事务与顺序**：写操作 `async with self._uow.begin()` 包住「读 + 写」；**会话失效在事务提交之后**调用（跨服务不可回滚），失败不阻断主流程、以 `session_revoked=false` + error 日志暴露（详细设计 §4.2 / §5）。
2. **保护规则**：内置管理员按 `role_type != custom` 判定（同库 `sys_user_role` ⋈ `sys_role`）；「不得操作自身」按 `get_current_user_id()` 比对；删除前 `count_by_user > 0` 即拒（30011）。
3. **密码**：哈希走基座 `BasePasswordHasher`（PBKDF2）；复杂度 / 历史走基座 `BasePasswordPolicy`；重置写 `password_hash` / `pwd_changed_at` / `pwd_history`（保留近 `password.history_count`）/ `pwd_reset_required`；新建未传密码时**随机生成**（16 位含大小写 / 数字 / 符号，逐次过策略）并一次性回显。
4. **事件**：四个 `sys.user.*` 在写事务内经事务性发件箱发射；载荷仅 `user_id` / `username` / `status`（`password_reset` 仅 `user_id`）。
5. **幂等**：`POST /users` 支持 `Idempotency-Key`——`begin` 非首次时取首次结果回放（无缓存即按冲突拒绝），未配置 Redis 时基座占位实现恒定放行、由 `(username, deleted_at)` 唯一约束兜底。
6. **identity 侧**：新增内部端点复用阶段六 `SessionService.revoke_user_sessions`（不改其语义），白名单 `require_service("platform")`，原因 `user_disabled` / `user_deleted` / `password_reset`。
7. **种子**：`user:assign_role` 动作码 + 「用户管理」页按钮挂接；内置系统管理员补 `user:create/update/delete/reset_pwd/assign_role`（防新端点 403 自锁）；本地库需重跑 `seed_menu` + `seed_rbac`。
