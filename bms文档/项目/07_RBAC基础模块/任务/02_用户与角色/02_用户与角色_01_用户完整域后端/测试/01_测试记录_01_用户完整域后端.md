## 5. 偏差与遗留 <a id="open"></a>

| # | 事项 | 归口 |
| --- | --- | --- |
| 1 | 会话撤销失败不阻断主流程（已用例覆盖「跨服务不可达 → `session_revoked=false` 且状态已改」） | 运维重试 + 告警（可观测阶段） |
| 2 | 幂等键本机 / 未配 Redis 环境下降级（用例以内存替身验证去重语义，真实 Redis 语义随部署） | 部署（`[idempotency] provider`） |
| 3 | 联系人字段脱敏依赖掩码器装配（未装配时原值返回） | 脱敏阶段 |
| 4 | 三库（MySQL / PostgreSQL / 达梦）真库端到端与并发（唯一约束兜底 / 乐观锁） | 部署联调任务 |
| 5 | 组织字段与关系（`dept_id` 移除）随需求 [07-11](../../../../需求/02_需求_用户与角色.md#r07-11) | 本任务追加子任务 `_01` + mdm `01_02` 子任务 `_02` |
