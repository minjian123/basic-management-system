## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | mdm 管理面 `require_auth` 不认服务 JWT（旧详设遗留） | **已消解**：mdm 内部写通道与分支参与端点**均已交付**，本任务直接接入，**mdm 侧零改动** |
| 2 | 内建「用户分配」全量集合基线（角色成员可能较多） | 按 `GET /roles/{id}/users` 分页合并载入全部已分配主键（`RoleUsersPanel` `PAGE_SIZE = 200`）；体量问题见详设 §10 开放项 |
| 3 | **宿主 `session.codes` 恒空**（真机走查实测）：登录载荷不含权限码、`session.signIn` 未传 `codes`，而按权限显隐的宿主页与区域项过滤读 `session.codes` ⇒ 带 `perm` 的区域项（含用户侧「角色分配 / 岗位分配 / 部门分配」三子页签）全被过滤、页签空白 | **已按拍板修根因**（详见 §5）：菜单装载（`stores/menu.ts` `apply` / `reset` / `applyFallback`）回填 `session.codes`，`session` 增 `setCodes` 动作作为**单一来源**；`main.ts` 会话订阅改为**仅在 token 变化时**联动（避免「菜单装载 → 回填 codes → 订阅再触发」回环）；顺带修复用户侧同源同缺陷 |
| 4 | 前端全量 1 例失败 `shared-dependencies.spec.ts`（`^0.1.0` vs `workspace:*`） | **既有失败，非本任务**（`git stash` 去掉本任务改动后仍失败；归阶段五 `05_14` 基座包共享域化的 `requiredVersion` 口径，归口阶段五） |
