## 2. 任务内容 <a id="content"></a>

1. **宿主提交注册通道**：角色记录页「角色分配」页签（`RoleAssignTab.vue`）按用户侧模板改造——「用户分配」内建能力按**同一登记通道**注册为平台区域项（`order` 10），与 mdm「岗位分配 / 部门分配」插件**同槽并列**、经**单个** `ModuleAreaOutlet variant="tabs"` 渲染；页签经具名插槽上下文注入**提交器注册**（约定键 `registerSubmitter`，值即函数；上下文仍为开放键值对象、浅冻结，**基座与机制不改**），插件挂载即注册 `{ isDirty(), buildSegment(), reload() }`（**宿主收草稿**口径：`buildSegment()` 无改动返回 `null`）。

2. **保存编排**：角色记录页工具栏「保存」＝ ① **platform 编排端点**（新增 `PUT /api/v1/roles/{role_id}/assignments`，分段**全量覆盖**）——`role`（角色本体：`code` / `name` / `status` + 乐观锁 `version`）+ `user_ids`（角色↔用户分配，platform 同库 `sys_user_role`）+ `role_posts` / `role_depts`（mdm 组织分配，全量覆盖；角色侧无主要项）；② `provider = "xa"` 经 **TM 全局事务**：platform 自身分支**进程内执行**（`sys.role.assignments`）、mdm 分支经参与端点 `/api/v1/txn/branches` 执行（`org.role-posts.assign` / `org.role-depts.assign`，合并为同一分支请求的 `ops` 列表），全部分支 `PREPARED` 后由 TM 提交；`provider = null`（dev / test 的 SQLite）走**顺序提交**（platform 本地事务 → mdm 内部写通道 `/api/v1/org/internal/role-{posts,depts}/{role_id}`），**不做反向补偿、不做一致性屏障**（原子性由 TM + XA 分支保证；mdm 侧已明确补偿基线与屏障判据属**废路径**）。权限码**分段校验**（`role` 段 → `role:update`；分配段 → `role:grant`）。

3. **脏数据与取消**：插件草稿计入角色记录页「脏数据」判定（保存拦截 / 离开确认沿用既有口径）；「取消」清空全部草稿（用户分配 + 两个插件）。

4. **降级与权限**：无 `org:update` 时插件子页签不渲染、其草稿不参与提交；插件未注册 / 不可达时按降级（子页签隐藏，保存仍提交 platform 部分，mdm 部分不参与、不阻塞）。

5. **列构成约束（宿主侧）**：宿主不提供插件列表的解绑入口（插件列表零操作列由 mdm 侧保证）；本任务不新增页面。

6. **一致性回写**：概要设计 06、组件设计 07《[权限配置](../../../../../../设计/组件设计/08_交互类/07_组件设计_权限配置/07_组件设计_权限配置.md)》、`01_01` 消费约定（含 `06_03` 滞后表述与 `registerSubmitter` 契约口径）、原型 `09_角色管理/03_角色表单页.html`、需求 `07-11` 与本任务父任务 reopened 注记。

7. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

一次「保存」经 `PUT /api/v1/roles/{role_id}/assignments` 完成 platform（角色本体 + 用户分配）与 mdm（岗位 / 部门分配）两侧提交：`provider = "xa"` 下同批**原子生效**（任一步失败全不生效，**不产生「一侧已改、另一侧未改」**）、`provider = null` 下顺序提交可用且失败明确报错；分段全量覆盖语义与权限码分段校验、`Idempotency-Key` 幂等生效；插件草稿计入脏数据判定并被「取消」清空；无 `org:update` 与插件缺失时降级正确、不阻塞 platform 部分；角色本体内置保护（`30043`）与乐观锁（`10003`）沿用既有语义；契约快照 / 契约基线 / 前端 `@bms/api-types` 零漂移；前端受影响范围（基座 + 宿主）回归通过；原型与文档一致。
