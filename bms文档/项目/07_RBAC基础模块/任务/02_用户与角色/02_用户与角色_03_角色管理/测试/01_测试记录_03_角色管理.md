## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 角色服务「先读后 `uow.begin()`」在 SQLAlchemy 2.0 下抛 `InvalidRequestError` | 读 + 写收进同一事务块；详见实施记录 §4 第 1 项 |
| 2 | `sys_data_scope.config` 集合类无法落库 | 列类型改 `StableJson`；详见实施记录 §4 第 2 项 |
| 3 | 数据权限仅 `match` 策略校验字典存在性 | 补 `_dict_type_exists`（全策略）；见实施记录 §4 第 3 项 |
| 4 | 用例「先读断言 → 服务写」反复触发事务缺陷；异常分支后取 ORM 属性触发懒加载 | 用例侧 `helpers.commit()` 清事务 + 期望异常分支改用标量 ID |
| 5 | 端点用例应用未用临时租户库（读到开发库残留） | 端点用例自建应用夹具（环境注入早于应用解析）；清理早期误写开发库数据 |
| 6 | 既有断言随契约版本 0.2.0 / 链头 0008 / 表集新增需要同步 | 同步 `test_modules.py`（0.2.0）、`test_module_registry.py`（服务目录版本）、`test_alembic_chains.py` / `test_migration_ops.py`（链头）、`test_table_registry.py`（表集）；均为口径一致性更新，非缺陷 |
