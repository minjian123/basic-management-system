# 01 详细设计 · 平台用户只读出口内部契约

> RBAC 基础模块 · 02 用户与角色 · 子任务 06（需求 07-2）· 详细设计

[文档首页](../../../../../../文档首页.md) › [02 用户与角色](../../02_用户与角色.md) › 详细设计　|　[← 任务](../02_用户与角色_06_平台用户只读出口内部契约.md)

## 1. 设计目标与范围 <a id="goal"></a>

承接需求 07-2（用户完整域）的前置切片：在 platform 提供**服务间只读出口**，使 **mdm 组织域只读出口**（组织数据源 `users` / 名称回显 `resolve_names(user)` / 按用户解析角色 `user-roles`）能取到用户明细——**mdm 不跨库读 `sys_user`**（组织主数据归 mdm，用户（账号）归 platform，跨服务只经契约）。

1. **端点**：`POST /api/v1/platform/internal/users/query`（内部端点，东西向直连不经网关）。
2. **鉴权**：`require_service("org")`——仅接受签发方服务标识为 **mdm 组织服务键 `org`** 的有效服务 JWT（`aud=service`）；用户票据与网关服务票据（`sub=gateway`）一律拒。
3. **租户**：由服务 JWT 的 `tenant` claim 经全局租户中间件解析租户库（与 `internal_users` 现有端点同口径）。
4. **契约**：只读字段 `id` / `username` / `name` / `status` / `phone` / `email` / `dept_id`（可空）；入参 `keyword` / `status` / `ids`（限定集合）/ `page` / `size`。
5. **不做**（归他处）：用户 CRUD / 启停 / 删除 / 重置密码（归 [02_01](../../02_用户与角色_01_用户完整域后端/02_用户与角色_01_用户完整域后端.md)）；数据范围过滤与敏感字段脱敏（由消费方 mdm 出口按其 `masked_fields` 接入）；本端点不做掩码（内部端点、服务间可达）。

**与既有端点的关系**：`internal_users.py` 现有 `/profile`（单条概要）/ `/reset-target`（找回密码）/ `/create`（统一建号）保持不动，本条**只增** `POST /query`（批量 / 分页只读查询）。

## 3. 接口设计 <a id="api"></a>

### 3.1 端点 <a id="api-endpoint"></a>

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/v1/platform/internal/users/query` | `require_service("org")` | 用户只读查询（关键字 / 状态 / 限定集合 / 分页） |

- 计入 platform 公开契约（`deploy/contracts/platform.json`）；**加性变更**（新增端点不影响既有契约）→ 契约基线无需更新，`ops.contract_gate check` 应保持通过。
- 服务间调用面校验：调用方经 `BaseServiceClient`（`validate_service_request` 要求路径以 `/api/v1` 起且目标服务已登记启用）。

### 3.2 请求契约 <a id="api-req"></a>

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | `str \| None` | 否 | 关键字（账号 / 姓名，大小写不敏感）；None 不过滤 |
| `status` | `str \| None` | 否 | 账号状态（`enabled` / `disabled`）；None 不过滤；取值非法抛 `ParamError`（10001） |
| `ids` | `ConcurrentStableList[int] \| None` | 否 | **限定集合**：非空时只在该集合内筛选（与 `keyword` / `status` 叠加）；空 / None 不限定 |
| `page` | `int` | 否 | 页码（≥1，缺省 1） |
| `size` | `int` | 否 | 每页条数（1~200，缺省 20） |

> **为何用 POST**：`ids` 为可变长集合，GET 查询串不宜承载（长度上限与转义）；与 `internal_users` 现有 `POST /profile` 等端点同口径。
> **为何入参不含 `dept_id`**：`sys_user.dept_id` 尚未落字段（随需求 07-2 落地）；**不做静默忽略的参数**——待字段落地后再作为加性变更补入参。

### 3.3 响应契约 <a id="api-resp"></a>

`ApiResponse[BasePageResponse[InternalUserItem]]`（`{list, total, page, size}`；基座分页口径）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `int` | 用户主键 |
| `username` | `str` | 登录账号 |
| `name` | `str` | 昵称 / 显示名 |
| `status` | `str` | 账号状态（enabled / disabled） |
| `phone` | `str \| None` | 手机号（**原样返回**；由消费方脱敏） |
| `email` | `str \| None` | 邮箱（**原样返回**；由消费方脱敏） |
| `dept_id` | `int \| None` | 归属部门 id（**当前恒 `null`**——字段随需求 07-2 落地后生效；**2026-10-09 修订**：该字段改随需求 `07-11` **移除**，用户-部门关系归 mdm，见 §8 第 6 项） |

- **不返回**：口令哈希、失败计数、锁定字段、密码策略字段、语言时区偏好（只读出口只需展示最小集）。
- 结果顺序：按主键升序（稳定、可复现）；软删除用户不返回（基座仓储作用域已含软删过滤）。

## 4. 取数口径 <a id="impl"></a>

| 项 | 口径 |
| --- | --- |
| 仓储 | 复用 `UserRepository.list_filtered` / `count_filtered`（同口径），`_filter_conditions` 增 `ids` 限定集合（`id IN (...)`） |
| 库 | platform 服务租户库（`get_uow` 请求级会话） |
| 分页 | 基座 `BasePageQuery` 口径（`page` / `size`，`size ≤ 200`） |
| 排序 | 主键升序（本端点契约固定；不接受外部指定排序字段，避免越权探测） |
| 事务 | **只读**：不写库、不开写事务、不产生审计与事件 |

## 5. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 无服务凭证 / 凭证无效 / 非服务受众 | `AuthError`（20001 / 401） |
| 签发方服务不在白名单（含网关服务票据 `sub=gateway`） | `AuthError`（20001 / 401） |
| `status` 取值非法 | `ParamError`（10001） |
| `ids` 为空数组 | 视为「不限定」（与 None 同口径；**不返回空集**，避免调用方误用） |
| 无命中 | 空列表 + `total=0`（不报错） |
| 跨租户 | 由服务 JWT `tenant` claim 解析租户库 + 租户过滤强制叠加（不可绕过） |

## 6. 测试设计与验收映射 <a id="test"></a>

| 验收点 | 用例（`services/platform/tests/`） |
| --- | --- |
| 服务身份白名单 | 白名单服务（`org`）签发的服务 JWT 通过；其他服务标识 / 用户令牌 / 无凭证一律拒（401） |
| 关键字 / 状态筛选 | `keyword` 命中账号与姓名（大小写不敏感）；`status` 过滤；非法 `status` → 10001 |
| `ids` 限定集合 | 非空时在集合内筛选并与 `keyword` / `status` 叠加；空数组 = 不限定；集合内无命中 → 空页 |
| 分页 | `page` / `size` 生效，`total` 与筛选同口径 |
| 契约字段 | 响应字段集与最小集一致（不含口令哈希 / 锁定字段）；`dept_id` 恒 `None`；`phone` / `email` 原样（不掩码） |
| 只读 | 不写库、不产生事件（无发件箱条目） |
| 契约零漂移 | `ops.contract_snapshot check` + `api-types gen:check` + `ops.contract_gate check`（加性变更，基线不动） |
| 门禁 | `pytest`（受变更影响范围）/ `ruff` / `format` / `pyright`（strict）/ `preflight --fast` 全绿 |
| Kiwi 用例关联 | 一任务一条；**先登记 Kiwi 再编码**，代码标 `@pytest.mark.kiwi_id(<编号>)` |
