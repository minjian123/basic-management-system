## 2. 任务内容 <a id="content"></a>

1. **信息栏结构**：用户记录页信息栏＝**详细信息 / 用户分配 / 系统信息**；「用户分配」内含子 Tabs（`type="card"`）。
2. **插槽出口位置**：把具名插槽 `sys.user.detail.tabs` 的出口置于**「用户分配」页签内**（与 bms 内建「角色分配」子页签并列），插件子页签按 `order` 稳定排序（岗位 20 / 部门 30）——宿主位置细化见 [01_01 消费约定登记](../../../01_插件化挂接/01_插件化挂接_01_具名插槽挂接消费与依赖登记/设计/01_详细设计_01_具名插槽挂接消费与依赖登记.md)（机制不变）。
3. **角色分配子页签**（bms 内建）：该用户直接角色多选（写 `sys_user_role`），随宿主工具栏「保存」提交；变更后权限版本 +1、清理该用户权限缓存。
4. **插件子页签**：岗位分配 / 部门分配——由 mdm 插件渲染（列表含**主要岗位 / 主要部门**列，至多一个，置位即时提交、全量覆盖语义）；**插件缺失即隐藏**（bms 单独运行 / cw 工作区无 mdm 时只剩「角色分配」，不报错、不阻塞）。
5. **契约消费**：一律经宿主注入的 `api`（平台服务 `api.get('platform', ...)`；mdm 域 `api.product('mdm','org')`），**不自拼前缀、不自建 HTTP**；组织 / 岗位 / 部门选择经组织选择字段族与 mdm 出口取数。
6. **权限与字段**：按钮按动作码显隐（`user:assign_role` 等）；字段按 `sys_role_field` 收窄；手机号 / 邮箱按脱敏标记展示（`data:plain` 明文）。
7. **原型对照**：按 `08_用户管理/03_用户表单页.html`（2026-10-09 迭代）逐页对照，结论登记测试记录。

## 3. 完成标准 <a id="complete"></a>

用户记录页「用户分配」页签与三子页签可用；bms 内建「角色分配」随宿主保存、即时生效；插件子页签经 `sys.user.detail.tabs` 真挂接且缺失即隐藏（「主要」列可置位并按 mdm 契约即时提交）；接口全部经契约类型消费；`vue-tsc` / ESLint / Vitest 通过、新增用例覆盖率达标；原型逐页对照通过。
