## 3. 关键口径 <a id="decision"></a>

- **列表无操作列**：编辑入口＝双击行开记录页签（不设新增 / 编辑抽屉）；状态列**内联开关**（停用二次确认、失败回滚）。
- **筛选仅「关键字 + 状态」**：不含部门 / 岗位 / 角色（组织关系归 mdm，仅经记录页插件呈现）。
- **不渲染导入 / 导出**（分别归导入导出阶段与平台业务页面阶段），已同步修订原型。
- **保存分两路**：分配段存在时走编排端点（跨服务原子）；仅改基础资料时走 `PUT /users/{id}`（+ 状态变更走 `PUT /users/{id}/status`）。
- **SSO 身份绑定**：只读区块落「系统信息」页签（identity 既有端点，`sso:bind`），原型已补。
- **停用 / 新增态**：停用账号分配只读；新增态不渲染分配子页签（提示创建后可分配）。
