## 2. 任务内容 <a id="content"></a>

1. **用户管理页**：列表（筛选**关键字（username / nickname / email / phone）+ `status`**，**不含部门 / 岗位**；分页；工具栏 新增 / 刷新 / 关闭 / 删除 / 启用·停用 / 重置密码（限单行选中）/ 导入 / 导出）、**列表无操作列**（双击行开记录 Tab，**不设新增 / 编辑抽屉**）、删除、状态列**内联开关**切换（**仅启用 / 停用**；危险操作二次确认、失败回滚并提示错误码文案）、重置密码、SSO 身份绑定查看。
2. **用户记录 Tab**：信息栏＝**详细信息 / 用户分配 / 系统信息**；详细信息基础资料编辑（用户名（新增可填、创建后只读）/ 昵称 / 手机 / 邮箱 / 状态；**组织字段与 `locale` / `timezone` 不在本模块**）；「用户分配」内含 角色分配（bms 内建，随宿主工具栏保存）+ 岗位分配 / 部门分配（mdm 插件子页签，含主要岗位 / 主要部门标记）；`sys.user.detail.tabs` 出口置于**「用户分配」页签内**（mdm 插件经该槽注册，见 `01_01`）；插件缺失即隐藏、页面其余正常。
3. **账号锁定页**：锁定列表（类型 / 时间 / 解锁状态筛选、**无操作列**、双击行开记录 Tab）、锁定详情、**手动锁定**（`manual` 型、记录锁定人与原因）、手动解锁（记录 `unlock_by` / `unlock_at`）、解锁记录；锁定记录页**不含「修改密码」**（重置密码入口收敛到用户记录页）。
4. **权限与字段控制**：按动态菜单与动作权限控制按钮显隐、按字段权限控制字段可见可编辑；敏感字段按脱敏标记展示（`data:plain` 明文权限）。
5. **契约消费**：经 `@bms/api-types` 契约类型与请求层调用后端，不硬编码字段 / 路径；组织/岗位选择经组织选择字段族消费组织主数据出口。
6. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

> **追加子任务（2026-10-09）**：按需求 [07-11](../../../需求/02_需求_用户与角色.md#r07-11) 追加**嵌套子任务** [`_01 用户分配页签与插件子页签挂接`](02_用户与角色_02_用户管理前端_01_用户分配页签与插件子页签挂接/02_用户与角色_02_用户管理前端_01_用户分配页签与插件子页签挂接.md)：用户记录页信息栏改「详细信息 / **用户分配** / 系统信息」，「用户分配」内含 角色分配（bms 内建，随宿主保存）+ 岗位分配 / 部门分配（mdm 插件子页签，含「主要岗位 / 主要部门」标记、缺失即隐藏），具名插槽出口 `sys.user.detail.tabs` 置于该页签内。本任务 §2 第 2 条的「岗位分配 Tab」按新结构细化（部门分配与「主要」标记随本条并入）；另按本轮原型迭代：列表**无操作列**（双击行开记录 Tab、去新增 / 编辑抽屉）、筛选仅「关键字 + 状态」、状态列内联开关、账号锁定页补手动锁定并去掉记录页的「修改密码」。原型依据：`设计/原型设计/08_用户管理/`（2026-10-09 迭代）。

## 3. 完成标准 <a id="accept"></a>

用户管理页与账号锁定页功能齐备（CRUD、**列表无操作列 + 双击开记录 Tab**、筛选仅关键字 + 状态、启停内联、重置密码、绑定查看、手动锁定 / 解锁）；用户记录 Tab 三页签（详细信息 / 用户分配 / 系统信息）可用，「用户分配」内的插件子页签经具名插槽挂接且缺失隐藏、不报错；按钮 / 字段按权限显隐正确；接口全部经契约类型消费；`vue-tsc`、ESLint、Vitest 通过、新增用例覆盖率达标。
