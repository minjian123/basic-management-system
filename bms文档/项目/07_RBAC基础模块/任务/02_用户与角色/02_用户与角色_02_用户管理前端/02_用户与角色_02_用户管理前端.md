## 2. 任务内容 <a id="content"></a>

1. **用户管理页**：列表（筛选 `username/nickname/email/phone/status/dept_id/岗位`、分页、工具栏导出入口）、新建 / 编辑 / 删除、状态列**内联开关**切换（危险操作二次确认、失败回滚并提示错误码文案）、重置密码、角色分配查看、SSO 身份绑定查看、导入入口。
2. **用户详情**：基础资料编辑（昵称 / 邮箱 / 手机 / 部门 / `locale` / `timezone`）；`sys.user.detail.tabs` 具名插槽提供**岗位分配 Tab** 挂接位（mdm 插件经该槽注册，见 `01_01`）；插件缺失即隐藏、页面其余正常。
3. **账号锁定页**：锁定列表（类型 / 时间 / 解锁状态筛选）、锁定详情、手动锁定、手动解锁、解锁记录。
4. **权限与字段控制**：按动态菜单与动作权限控制按钮显隐、按字段权限控制字段可见可编辑；敏感字段按脱敏标记展示（`data:plain` 明文权限）。
5. **契约消费**：经 `@bms/api-types` 契约类型与请求层调用后端，不硬编码字段 / 路径；组织/岗位选择经组织选择字段族消费组织主数据出口。
6. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

用户管理页与账号锁定页功能齐备（CRUD、启停内联、重置密码、绑定查看、锁定 / 解锁）；岗位分配 Tab 经具名插槽挂接且缺失隐藏、不报错；按钮 / 字段按权限显隐正确；接口全部经契约类型消费；`vue-tsc`、ESLint、Vitest 通过、新增用例覆盖率达标。
