- **执行序**：`07_01 非界面类`（口径最简单、量最大，先行清掉多数命中）→ `07_02 组件类`（组件设计自带原型 + 件族截图）→ `07_03 页面类`（页面原型 + 真机截图 + 识图逐页，最重）→ 收口后进 `05_01` 阶段验收。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：本域依赖**门禁脚本与原型资产已就位**（均已交付，无外部前置）；`07_03` 的页面截图依赖**本机前端可运行**（依赖外置态下 `pnpm run` 不可直用，须直调 `CI=true ./node_modules/.bin/vitest` 与宿主开发态核对页，见《[开发机部署使用说明总览](../../../../资料/开发机/linux/开发机部署使用说明总览.md)》）；`07_03` 为 `05_01` 阶段验收的**前置**。
- **依赖与推进**：依赖关系与推进见[计划](../../计划/01_计划_RBAC基础模块.md)。
- **风险**：
  - **命中集合会收敛**：门禁按 `origin/main...HEAD` 校验，一旦推送，`origin/main` 前移、已推送部分的记录不再被校验；故清单**以每次执行前的脚本输出为准**，本域初判的 44 / 10 / 4 只是 2026-10-12 基线。
  - **分类误判**：少数记录的任务既有界面外壳改动又无页面交付（如 `01_认证与会话_07`、`04_API网关与边缘_01_01`）→ 采用「交付物是否含可渲染界面且详细设计登记了原型依据」判定，**逐份留痕核对结论**，存疑者按更严的一类处理（宁可多截图，不可漏对照）。
  - **截图证据真实性**：`测试/资源/<记录名>/` 下的 `.png` 必须是**实际渲染**结果；不得以占位图 / 手绘框图充数（§4.9 门禁要求截图**存在**，但真实性与识图比对由本域自行把关）。
  - **去实现命名**：界面可见文本不得出现类名 / 函数名 / 能力键 / 路径 / 包名——对照时逐页核对，发现即登记修复项（《[文档生成规范](../../../../规范/文档生成规范.md)》8.5）。
  - **历史任务已收口**：本域回写的是**既有已交付任务**的测试记录，回写不得改变其原结论语义（只增「原型对照结论」节与截图资源）；发现的实现偏离另立修复项，不回改其验收结论。
