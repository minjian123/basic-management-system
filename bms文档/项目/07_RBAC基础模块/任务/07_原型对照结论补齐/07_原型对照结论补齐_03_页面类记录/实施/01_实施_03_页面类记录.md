1. **取清单**：重跑 `check-prototype-review.py . --changed` 取最新命中（8 份页面类），替换详细设计 §3 的基线表。
2. **逐份定位原型依据**：为每份记录定位**页面原型**与《布局设计》对应节，并在记录内以相对链接引用（文件存在）；原型页经 8899 静态服务取图。
3. **逐页真机取图**：宿主页面经 5173 真机渲染（登录态 / 免登录两态）、模块页面经 5002 远端加载、开发态核对页经 `*-check.html`；交互态（`20007` 展开、具名插槽读写）经真实交互驱动后取图。截图落各历史任务 `测试/资源/<记录名>/`（命名 `实现-*.png` / `原型-*.png`）。
4. **逐页对照**：按 §4.9 八维度逐页比对，结论取「对齐 / 偏离（附处置）」；逐份结论登记到**各历史任务自身的测试记录**。
5. **偏离修复**：核对中发现的 4 项实现偏离**当批就地修复**并真机复验（见 §4）。
6. **门禁复跑与移交**：复跑 `check-prototype-review.py . --changed`（零命中）与 `check-preflight.py --fast`（该项转绿），随后移交 `05_01` 阶段验收。

## 3. 执行记录 <a id="run"></a>

```bash
# 环境（本机裸跑）
bash bms/scripts/tools/dev/本地全套.sh up            # tenant / platform / identity
bash bms/scripts/tools/dev/本地全套.sh seed          # 幂等种子（含 bootstrap 账号绑定内置系统管理员）
cd bms && node frontend/scripts/serve-module-releases.mjs          # 5002（模块产物）
cd bms/bms文档/设计 && python3 -m http.server 8899               # 原型页静态服务

# 模块产物（改动的模块需重构建重发）
pnpm --filter @bms/module-sample run build && node frontend/scripts/release-module.mjs publish --module sample --force
pnpm --filter @bms/module-slot-sample run build && node frontend/scripts/release-module.mjs publish --module slot-sample --force

# 门禁与预检
python3 scripts/tools/base-check/check-prototype-review.py . --changed
python3 scripts/tools/preflight/check-preflight.py --fast
```

- **取图载体**：`preview_url` 与 Playwright MCP（导航 / 点击 / 填表 / 截图）；页面结构经 `browser_snapshot` 核对；页面空态 / 关闭态一律用**可见性**判定（不留「元素是否存在」代替「是否可见」的空子）。
- **免登录页取值**：模块产物服务停用态另取一组图（登录页可达 + 平台外壳不受影响）。
- **发布留痕**：`frontend/releases/release-log.*` 为受跟踪文件，发布后已回退，不随本批提交。
