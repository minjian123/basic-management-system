## 2. 任务内容 <a id="content"></a>

1. **取值清单**：执行前重跑门禁取**页面类**待补记录清单（2026-10-12 初判 **4 份**：阶段四 `10_微前端骨架_01` 宿主外壳与模块加载器、阶段五 `04_首个模块样例_01`、阶段六 `05_登录前端_06` 登录页多租户选择、`01_认证与会话_07` 会话续期与登录入口可达性），并并入 `07_01` / `07_02` 移来的存疑记录。
2. **定位原型依据**：逐份定位对应**页面原型**（`设计/原型设计/**/*.html`，如 `03_通用骨架/02_登录页.html`）与《[布局设计](../../../../../设计/布局设计/)》对应节，在记录内以相对链接引用（文件须存在）。
3. **真机 / 无头截图**：逐页实际渲染后截图（交互态页面如弹窗 / 详情用静态检查确认结构），截图落 `测试/资源/<记录名>/`。
4. **识图逐页对照**：按 §4.9 八个维度逐页比对——逐页齐备（不缺失 / 不空壳）/ 视觉完整无裸骨架 / 结构对齐布局设计 / 交互对齐原型 / **去实现命名** / 主题与响应式 / 空态与加载与异常 / 主题令牌呈现。
5. **补写「原型对照结论」节**：在各历史任务自身的 `测试/*.md` 内新增该节，含①表头含「结论」的**逐页**对照表（每个界面一行）与②**至少一张存在的 `.png` 截图**引用；结论取「对齐 / 偏离（附处置归口）」；节内不含未完成词。
6. **偏离处置**：发现实现偏离原型的，**登记修复项**（含归口任务）并回写对应历史任务；**未通过不得进入阶段验收**（§4.9）。
7. **门禁复跑**：复跑 `check-prototype-review.py . --changed` 确认本批零命中；再跑 `check-preflight.py --fast`；收口后移交 `05_01`。
8. **落点**：逐份清单与对照结论落在本任务 `设计/01_详细设计_03_页面类记录.md`（执行期以脚本输出刷新）。

## 3. 完成标准 <a id="accept"></a>

判定为页面类的记录**全部**含「原型对照结论」节（逐页对照表 + 存在性 `.png` 截图 + 页面原型引用 + 去实现命名核对行），无未完成词；截图均为实际渲染结果且识图比对完成；偏离项均已登记归口；复跑 `check-prototype-review.py . --changed` 对该批零命中；`check-preflight.py --fast` 该项通过；未改动被测源码与历史记录的既有结论。
