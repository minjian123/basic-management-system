## 1. 设计目标与范围 <a id="goal"></a>

为门禁命中的**页面 / 宿主外壳 / 模块样例**类历史测试记录补写「原型对照结论」节：以**页面原型**（`设计/原型设计/` 下各模块页面 html）与《[布局设计](../../../../../../设计/布局设计/)》为基准，真机 / 无头截图 + 识图**逐页**对照。

- **范围内**：门禁命中清单中判定为**页面类**的记录（2026-10-12 基线 **4 份**，见 §3）。
- **范围外**：件族类（`07_02`）、非界面类（`07_01`）；被测实现（偏离项登记归口，不在本任务改）。
- **阶段门禁意义**：本任务为 [05_01 阶段验收](../../../../../../项目/07_RBAC基础模块/任务/05_阶段验收/05_阶段验收_01_阶段验收门禁核对与测试报告/05_阶段验收_01_阶段验收门禁核对与测试报告.md) 的**前置**（§4.9「未通过不得进入阶段验收」）。

## 2. 判定口径与依据 <a id="rule"></a>

**判定为「页面类」的条件**：该记录所属任务的交付物含**可渲染界面**（页面 / 宿主外壳 / 模块页面），且其基准为**页面原型**与《[布局设计](../../../../../../设计/布局设计/)》。

**对照维度**（§4.9 八项，逐页逐项落表）：

| # | 维度 | 判据 |
| --- | --- | --- |
| 1 | 逐页齐备 | 原型设计说明列出的每个界面，实现侧均有对应可渲染页面且可达（不缺失、不空壳） |
| 2 | 视觉完整 | 无「结构到位但无样式」的裸骨架 |
| 3 | 结构对齐布局设计 | 分区 / 三段式 / 弹窗抽屉形态 / 状态语义符合《布局设计》 |
| 4 | 交互对齐原型 | Tab 切换、弹窗开关、表单录入、视图跳转与原型一致 |
| 5 | 去实现命名 | 可见文本无类名 / 函数名 / 能力键 / 文件路径 / 包名 |
| 6 | 主题与响应式 | 亮 / 暗主题经令牌呈现，断点响应式与设计一致 |
| 7 | 空态 / 加载 / 异常 | 无白屏 / 无反馈 / 技术堆栈外露 |
| 8 | 原型依据可溯 | 记录内引用存在的页面原型 html |

## 4. 逐页对照与补写步骤 <a id="steps"></a>

```mermaid
flowchart LR
    A["重跑门禁取清单"] --> B["逐份定位页面原型 + 布局设计节"]
    B --> C["真机 / 无头逐页截图（交互态静态确认结构）"]
    C --> D["识图逐页比对（§4.9 八维度）"]
    D --> E["该任务 测试/*.md 增「原型对照结论」节（逐页表 + 截图）"]
    E --> F["偏离项登记归口"]
    F --> G["复跑门禁 + preflight → 移交 05_01"]
```

1. **取清单**：重跑门禁，替换 §3 表；并入 `07_01` / `07_02` 移来的存疑记录。
2. **定位依据**：逐份定位页面原型（`设计/原型设计/` 下对应模块页面 html）与《[布局设计](../../../../../../设计/布局设计/)》对应节，记录内相对链接引用。
3. **截图**：真机 / 无头逐页渲染后截图，落 `测试/资源/<记录名>/`；交互态（弹窗 / 详情）用静态检查确认结构（§6.2）。
4. **识图比对**：按 §2 八维度逐页比对，逐页落行；结论取「对齐 / 偏离（附处置归口）」。
5. **偏离处置**：登记修复项（含归口任务）并回写对应历史任务；**未通过不得进入阶段验收**。
6. **门禁复跑与移交**：见 §5，通过后移交 `05_01`。

## 6. 边界与开放项 <a id="boundary"></a>

- **本机前端运行**：依赖外置态下 `pnpm run` 会触发 deps 检查失败，须直调 `CI=true ./node_modules/.bin/vitest run --coverage` 与宿主开发态核对页；截图工具与路径见《[开发机部署使用说明总览](../../../../../../资料/开发机/开发机部署使用说明总览.md)》。
- **截图真实性**：`.png` 必须为实际渲染结果；门禁只校验「存在」，真实性与识图比对由本任务把关。
- **分类存疑**：`01_认证与会话_07`（改 `App.vue` / `ModuleBoundary.vue` 边界件）与 `04_API网关与边缘_01_01`（改 `src/dev/*Check.vue` 核对页）是否属页面类，**执行期按「交付物是否含可渲染界面」终判**；若判为非界面类则移交 `07_01`。
- **日期口径**：本设计的记录数与分类为 **2026-10-12 基线**；命中集合随 `origin/main` 前移收敛，执行前必须刷新。
