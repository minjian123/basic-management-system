## 2. 测试范围与判据 <a id="scope"></a>

本任务按《[原型审查规范](../../../../../../规范/原型审查规范.md)》§4.9 为门禁命中的**页面类**历史测试记录补写结论，并以**真机 / 无头截图 + 识图**逐页对照《[布局设计](../../../../../../设计/布局设计/)》与对应**页面原型**。

**页面类判据**：记录所属任务的交付物含**可渲染界面**（页面 / 宿主外壳 / 模块页面 / 开发态核对页），基准为页面原型与《布局设计》。

**对照维度（§4.9 八项，逐页落行）**：逐页齐备（不缺失 / 不空壳）· 视觉完整（无裸骨架）· 结构对齐布局设计 · 交互对齐原型 · **去实现命名**（可见文本无类名 / 函数名 / 能力键 / 路径 / 包名）· 主题与响应式 · 空态 / 加载 / 异常（无白屏 / 无反馈 / 技术堆栈外露）· 原型依据可溯（引用存在的页面原型）。

**截图真实性**：`.png` 均为**实际渲染**结果（本机全套 + 宿主 5173 + 模块产物 5002），落各历史任务 `测试/资源/<记录名>/`；不在本任务内新建或改动被测实现（除 §3.2 的 4 项偏离修复）。

**验收判据**：8 份全部补节且满足上述节内要求；复跑 `check_prototype_review.py . --changed` 对**全变更集零命中**；`preflight --fast` 该项转绿；偏离项均已就地闭环。
