## 2. 实施过程 <a id="process"></a>

1. **取清单**：在 bms 仓根重跑 `python3 scripts/tools/base-check/check-prototype-review.py . --changed`，实跑命中 **19 份**（变更集含界面改动 1 个：`frontend/apps/desktop/src/views/system/RoleRecordTab.vue`）。
2. **逐份分类（4 项决策经用户逐项确认，落详细设计 §7）**：
   - **件族 · 有渲染面 4 份**：`03_布局组件类_01 弹窗抽屉表单`、`03_布局组件类_02 异常与空状态`、`08_交互类_03_01 向导与偏好设置`、`07_01` 移入的 `01_扩展点与装配_02`（模块区域插槽）。
   - **核心基类族 7 份改判非界面类**：`02_基础组件类` 01~07 交付物为 `frontend/packages/core` 下**框架无关纯 TS 基类**（无 DOM / 模板 / 样式），按 §4.9「纯逻辑改动可写不适用并给理由」处理；执行归口仍在本任务（`07_01` 已收口，不返工重开）。
   - **页面类 8 份**：归 `07_03`（本任务不代做）。
3. **原型依据定位**：逐份定位 `设计/组件设计/` 下件族自带原型（弹窗抽屉表单 / 异常与空状态 / 向导与步骤 + 偏好设置面板 / 模块区域插槽），在记录内以相对链接引用（文件均存在）。
4. **真机渲染（本机裸跑）**：
   - 后端栈：`bash scripts/tools/dev/本地全套.sh up --reset-db`（库结构变更后须重建）+ `seed`（沿用《本地资源》登记的 `admin` 口令）+ `env`；
   - 前端：`pnpm --config.verify-deps-before-run=false --filter @bms/desktop dev`（:5173）；
   - 模块产物（区域插槽真机前置）：`pnpm --filter @bms/module-demo run build` + `node frontend/scripts/release-module.mjs publish --module demo --force` + `node frontend/scripts/serve-module-releases.mjs`（:5002）；
   - 原型基准页：`python3 -m http.server 8899`（根 `bms文档/设计`，原型页资源相对路径可达）。
5. **截图（Playwright MCP，无头 Chrome）**：原型基准页逐页签全页截图；实现侧取宿主真机（`/403`、`/404`、`/500`、`/sys/account-locks` 空状态、主框架顶栏区域插槽）与开发态核对页（`wizard-preference-check.html?auto=1`）；命名 `原型-*.png` / `实现-*.png`，落各记录 `测试/资源/<记录名>/`。
6. **补写节**：件族 4 份补「原型对照结论」节（逐件对照表 `# / 对照项 / 原型依据 / 实现实测 / 结论` + 对照截图表 + 偏离项与处置 + 去实现命名核对行）；核心基类族 7 份补「不适用 + 理由」节（逐份按任务性质说明，理由 ≥ 10 字、无未完成词）。
7. **`07_01` 遗留修正**：把 `07_01` 实施 / 测试记录中 `设计/组件设计/`（或 `设计/原型设计/`）下 `**` 通配占位写法（3 类）改为无歧义等效表述，消除门禁「原型引用文件不存在」误报。
8. **回写**：详细设计 §2/§3/§4/§5/§6/§7、任务文档 §2/§3/§4、阶段计划 §1/§2/§3/§4 与状态注记。

## 3. 关键命令 <a id="commands"></a>

```bash
cd bms
# 门禁取清单 / 复跑
python3 scripts/tools/base-check/check-prototype-review.py . --changed
# 本机裸跑（真机渲染前置）
bash scripts/tools/dev/本地全套.sh up --reset-db
bash scripts/tools/dev/本地全套.sh seed --password '<《本地资源》登记口令>'
bash scripts/tools/dev/本地全套.sh env
pnpm --config.verify-deps-before-run=false --filter @bms/desktop dev            # :5173

node frontend/scripts/release-module.mjs publish --module demo --force

# 文档与基座校验

python3 scripts/tools/check-docs/check-status.py --stage 07_RBAC基础模块
python3 scripts/tools/preflight/check-preflight.py --fast
```
