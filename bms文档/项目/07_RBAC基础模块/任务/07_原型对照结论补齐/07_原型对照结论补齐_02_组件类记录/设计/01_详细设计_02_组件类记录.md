## 1. 设计目标与范围 <a id="goal"></a>

为门禁命中的**件族类**历史测试记录补写「原型对照结论」节：以《[组件设计](../../../../../../设计/组件设计/)》**自带原型**（`设计/组件设计/` 下各件族 `NN_原型设计_XXX.html`）为基准，按件族粒度逐件对照 + 件族渲染截图。

- **范围内**：门禁命中清单中判定为**件族交付**的记录（2026-10-12 基线 **10 份**，见 §3）。
- **范围外**：页面类（`07_03`）；件族实现代码（只登记偏离修复项，不在本任务改）。

## 2. 判定口径与依据 <a id="rule"></a>

**判定为「组件类」的条件**：该记录所属任务的交付物为 `ui-ep` **件族**（基础组件类 / 布局组件类 / 交互类面板与工具等），其对照基准取**组件设计自带原型**（§4.9：「件族任务用后者」）。

**原型依据定位**：件族原型位于 `设计/组件设计/<族>/<子族>/<NN_组件设计_XXX>/<NN_原型设计_XXX.html>`（共 123 份可选项，2026-10-12 实测）；逐份按件族归属定位（如 `02_基础组件类/01_机制基类/01_组件设计_根系基类/01_原型设计_根系基类.html`）。

## 4. 逐件对照与补写步骤 <a id="steps"></a>

```mermaid
flowchart LR
    A["重跑门禁取清单"] --> B["逐份定位组件设计自带原型 html"]
    B --> C["宿主开发态核对页渲染件族 → 截图"]
    C --> D["逐件对照（结构 / 样式 / 交互 / 去实现命名）"]
    D --> E["该任务 测试/*.md 增「原型对照结论」节（表 + 截图）"]
    E --> F["复跑门禁 + preflight 该项"]
```

1. **取清单**：重跑门禁，替换 §3 表；并入 `07_01` 移来的存疑记录。
2. **定位原型**：逐份定位 `设计/组件设计/` 下对应的件族原型 `NN_原型设计_XXX.html`，在记录内以相对链接引用（文件须存在）。
3. **渲染与截图**：以宿主开发态核对页（`frontend/apps/desktop/*-check.html`）或既有组件核对入口渲染件族；**依赖外置态下 `pnpm run` 不可直用**，按《[开发机部署使用说明总览](../../../../../../资料/开发机/开发机部署使用说明总览.md)》执行。截图落 `测试/资源/<记录名>/`。
4. **逐件对照表**：节内建表，列固定建议 `# / 对照项 / 原型依据 / 实现实测 / 结论`，**逐件落行**；结论取「对齐 / 偏离（附处置归口）」。
5. **去实现命名**：核对件族可见文本无类名 / 函数名 / 能力键 / 路径 / 包名。
6. **门禁复跑**：见 §5。

```bash
cd bms

python3 scripts/tools/preflight/check-preflight.py --fast               # 期望：「界面：check-prototype-review」通过
```

节内须同时满足：标题含「原型」、表头含「结论」、≥1 行数据、≥1 张**存在**的 `.png` 引用（相对 `测试/` 目录）、无未完成词、有组件设计原型引用。

## 6. 边界与开放项 <a id="boundary"></a>

- **核对页缺失时**：若某件族无对应核对页，**只补核对项、不改组件实现**；确无渲染入口的登记为开放项并归口对应件族任务。
- **件族粒度**：一件一族内多件时按**件**逐行对照，不得以单行概括整族。
- **偏离处置**：发现组件偏离原型（如样式缺失、裸骨架）的，登记修复项并回写对应件族任务；§4.9 明令「不得出现结构到位但无样式」的裸骨架。
