### 3.2 跨仓口径核对（发现漂移）

对照 mdm 仓实际契约（`deploy/contracts/mdm.json`、`deploy/registry/mdm.json`、`services/org/src/mdm/api/{open_read,internal}.py`、`services/.../branch_handlers.py`）与 bms 消费面：

| bms 侧（修复前） | mdm 侧（现行） | 后果 |
| --- | --- | --- |
| `permission_subject.py`：`ORG_SERVICE_KEY="org"`、`/api/v1/org/user-roles` | 服务键 `mdm`、`/api/v1/mdm/user-roles` | 服务未登记 → `ParamError` 被降级吞掉 → 岗位 / 部门链角色**恒空** |
| `user_assignments.py` / `role_assignments.py`：`ORG_SERVICE="org"`、`/api/v1/org/internal/*`、`op=org.*.assign` | `/api/v1/mdm/internal/*`、`op=mdm.*.assign` | 分配内部写通道与 XA 分支 `op` 不可达 |
| `api/internal_users.py` / `api/permission.py` / `api/internal_config.py`：`require_service("org")` | mdm 以 `sub=mdm` 签服务票 | mdm 取用户明细被拒（`330101` fail-closed）；权限失效端点不可达 |
| `ops/seed_menu.py`：业务码 `org` + `org:query/create/update/delete/move` | 权限码 `mdm:query/create/update/delete`（部门移动复用 `update`） | 管理面权限码与 mdm 端点不匹配 |
| 前端 `orgSource.ts` / `endpoints.ts`：`productPrefix('mdm','org')`、`/api/mdm/v1/org` | 对外路由 `/api/mdm/v1/mdm/*`（网关 `route-mdm-mdm`） | 组织选择 / 回显 404 |

### 3.3 修复（全量对齐）

- 后端：`permission_subject`（`MDM_SERVICE_KEY` / `MDM_USER_ROLES_PATH`）、`user_assignments` 与 `role_assignments`（`MDM_SERVICE`、`MDM_*_OP`、`MDM_INTERNAL_*_PATH`、`BRANCH_ID_MDM`）、三个内部端点白名单（`MDM_SERVICE` / `require_service("mdm")`）、`ops/seed_menu`（业务码与权限码改 `mdm`）。
- 前端：`ui_ep/src/utils/orgSource.ts`（`productPrefix('mdm','mdm')`）、`apps/desktop/src/api/endpoints.ts`（`/api/mdm/v1/mdm`）、`dev/OrgCheck.vue`（核对项与断言）。
- 契约：`uv run python -m ops.contract_snapshot export` 重导出（`platform.json` 仅描述串变更，非破坏性），`check` 通过。
- 用例：平台侧 6 个测试文件与 `tests/api/test_modules.py` 同步口径；前端 3 个 spec 同步；`libs/bms_core/tests/ops/test_seed_menu.py` 改按 `mdm` 四码断言。

### 3.4 测试种子口径修复

- 现象：`services/platform/tests` 整批 setup 失败 —— `CatalogError: 服务目录校验失败：mdm/mdm → mdm：目标服务未登记（mdm）；库中缺登记行：mdm`。
- 根因：会话级种子 `ops/seed_module.seed_modules()` 只播种 `SERVICE_CATALOG`（平台静态清单），而装配期 `load_product_manifests()` 会装载产品清单（本机 `config.dev.toml` 指向 mdm 登记清单），接库对账因此不一致。
- 处置：`seed_modules()` 先装载产品清单，再播种 `service_catalog_view()` / `product_catalog_view()`（与启动校验同源）；未配置清单时行为与旧版一致。
- 连带修正：`tests/api/test_modules.py` 不再写死 17 行与旧 `org` 键，改为「接口返回 == 登记清单」+ 结构断言（末页 / 排序 / 过滤），两种环境（装载 / 不装载产品清单）均成立。
