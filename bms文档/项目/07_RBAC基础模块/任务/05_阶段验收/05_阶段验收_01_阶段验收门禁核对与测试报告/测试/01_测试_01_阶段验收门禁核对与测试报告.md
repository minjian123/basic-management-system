## 2. 测试范围与用例 <a id="scope"></a>

| 用例（Kiwi 2349 下 5 个断言函数） | 覆盖 | 判据 |
| --- | --- | --- |
| `test_gate_table_has_conclusions_and_evidence` | 计划 §5 门禁表 7 行 + 门禁对照 + 阶段达成对照 + 需求总览不承载门禁 | 每行「对应任务」「达成路径（结论与证据索引）」非空且非 `—`；含 `**门禁对照**`、达成日期 |
| `test_plan_closure_state` | 计划收口自洽 | 头部「已完成 N 项，剩余 0 项」与 §2 行数一致；§3 数据行为 0；投入「已完成 + 剩余 = 合计」；§7 台账存在并引用报告 |
| `test_stage_report_archived_with_sections` | 阶段测试报告归档 | 六节 + 界面一致性节 + 附录 A 齐备；含「17 条需求」与 `check_status` 复核口径 |
| `test_task_and_domain_status_consistent` | 三类文档状态一致 | 任务文档无状态 / 完成日期字段；域总览无状态列；计划登记 `05_01` 与完成日期 |
| `test_mdm_alignment_lockdown` | 跨仓 mdm 口径锁定 | 平台 6 个源文件取值 `mdm` 且无 `/api/v1/org` / `require_service("org")` 残留；前端 `orgSource.ts` 为 `productPrefix('mdm','mdm')`、`endpoints.ts` 为 `/api/mdm/v1/mdm` |

**配套真实运行验证**（非 Kiwi 编号用例，随本任务执行）：后端口径修复定向（`services/platform/tests` + `libs/bms_core/tests/ops`，含覆盖率）、契约快照与契约校验、前端受影响包 typecheck 与单测、文档与基座校验（`check_status` / `check_links` / `check_base` / `preflight --fast`）。

## 4. 问题与处置 <a id="issues"></a>

| # | 现象 | 处置 |
| --- | --- | --- |
| 1 | 平台测试整批 setup 失败：`CatalogError：mdm/mdm → mdm：目标服务未登记；库中缺登记行：mdm` | 种子与装配不同源 → `ops.seed_module` 改按合并视图播种；详见[实施记录 §3.4](../实施/01_实施_01_阶段验收门禁核对与测试报告.md#process) |

| 3 | 计划无「已完成 N 项，剩余 M 项」句致 S1 形态断言失败 | 计划头部补「进度唯一落点」句 |
| 4 | 前端宿主 3 份记录页 spec 50 例失败 | `git stash` 复核确认 `HEAD` 同样失败（Element Plus `ElTabPane` 断言），记遗留（计划 §7 第 46 项） |
