## 2. 任务内容 <a id="content"></a>

1. **门禁逐条核对**：按《总体项目规划》阶段七完成标准逐条给结论与证据索引——主体链任意长度权限计算正确、越权与跨租户访问被拒验证通过、数据范围读写检查生效、字段权限生效、配额超限拦截生效、三权互斥生效、租户模块开关生效。
2. **阶段测试报告归档**：汇总用例执行、缺陷、覆盖率、风险与遗留、复盘与经验教训；归档到阶段根 `01_测试报告_RBAC基础模块.md`（范式对齐阶段五 / 阶段六）。
3. **三类文档一致性核对**：需求 ↔ 任务 ↔ 计划编号与挂接一致、进度只在计划表；跑 `check-status.py --stage 07_RBAC基础模块` 与 `preflight --fast` 校核。
4. **收口回写**：按结论回写计划进度与偏差台账、架构 / 清单登记（如基类清单、登记表）、需求侧消费方标注（含 mdm 前置契约）。
5. **遗留归口**：汇总各任务遗留项，逐条给归口阶段，形成计划「后续阶段待办」台账，无「无归口」条目。

## 3. 完成标准 <a id="accept"></a>

门禁逐条有结论与证据索引、无未达标项（限定项注明归口）；阶段测试报告归档且六节齐备；需求 / 任务 / 计划文档一致、编号无缺失、`check-status` 无硬规则不合规；遗留项全部登记归口、无「无归口」条目。
