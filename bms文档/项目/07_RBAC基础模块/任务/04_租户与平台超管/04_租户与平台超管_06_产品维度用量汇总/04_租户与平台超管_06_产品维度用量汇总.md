## 2. 任务内容 <a id="content"></a>

1. **问题定位**：租户管理页只有平台三维度配额（用户数 / 存储 / 开放接口调用量），平台超管看不到各产品的资源用量，需逐个进入产品管理台查询。
2. **汇总视图**：租户详情页新增「产品用量」汇总区，按产品展示资源名、用量、限额、状态（正常 / 预警 / 超限）。
3. **数据来源**：全部来自各产品的只读数据源（复用 04-03 的板块组件与取数链路），**平台侧不存储、不双写**。
4. **状态口径**：预警 / 超限阈值由产品在数据源中给出（或按产品声明的比例计算），平台侧只做展示，不重新判定。
5. **排序与空态**：按产品名稳定排序；产品未声明数据源时显示「未提供用量」；加载失败单独标识，不影响其他产品。
6. **性能与缓存**：汇总区并发拉取多产品，设置超时与降级；单产品超时不阻塞整页。

## 3. 完成标准 <a id="accept"></a>

- 租户详情页能汇总展示多个产品的用量（以 msg 与 mdm 为验证对象）。
- 用量、限额、状态三列与产品侧一致，平台侧无二次计算或存储。
- 单产品超时 / 失败不影响其他产品展示，页面不白屏。
- 未声明数据源的产品显示「未提供用量」，与「未开通」可区分。
- 汇总区只读，不提供调整入口（调整仍在产品管理台）。
