## 2. 任务内容 <a id="content"></a>

1. **租户 CRUD**：`GET/POST/PUT /api/v1/tenants`（`sys_tenant`，`code` / `domain` 唯一，`status` 过滤）；`GET /api/v1/tenants` 列表分页。
2. **租户开通**：校验 `code` 唯一 → 建库 `bms_tenant_{code}` → 双套 Alembic 迁移（按目标库方言）→ 批量种子 → 注册 `sys_tenant` → 写入模块开通清单（`sys_tenant_module`，开通向导勾选、未勾选默认不开通）→ 预热引擎（可选）→ 落 `tenant.created`；支持 `Idempotency-Key`，任一步失败清理已建库并告警。
3. **停用 / 启用**：`POST /api/v1/tenants/{id}/suspend`（引擎回收 + 按租户前缀失效会话 + 登录拦截，落 `tenant.suspended`）、`POST /api/v1/tenants/{id}/activate`（恢复并落 `tenant.activated`）。
4. **域名配置**：`PUT /api/v1/tenants/{id}` 维护域名（`{tenant}.bms.example.com` + 泛域名 TLS 路由依据），冲突拒绝（82004）。
5. **配额管理**：`GET/PUT /api/v1/tenants/{id}/quotas`（`sys_tenant_quota`：用户数 / 存储 / 开放接口调用量，`limit_value/used_value`）；创建用户 / 上传文件 / 开放接口调用前校验，超限拒绝并告警（82005）。
6. **租户模块开关**：`GET /api/v1/tenants/{id}/modules`、`PUT /api/v1/tenants/{id}/modules/{module_key}`；`module_key` 校验 `sys_module` 已注册且启用（拒绝 82007）；停用后该模块菜单 / 接口在租户侧不可用、不可新建单据，存量数据保留可查、重新开通即恢复，进行中流程与审批不受影响（停用后入口 / 接口被拒 82008）。
7. **平台超管**：`sys_admin` 平台运营账号（首次启动创建、强制改密），跨租户运营仅到租户级、不进入租户业务数据；权限码 `tenant:manage/tenant:quota`。
8. **开通种子**：租户库三类内置管理员角色（系统 / 安全 / 审计，互斥预授）与初始系统管理员账号（首次登录强制改密）、默认 IdP 占位配置、初始归档策略（四类审计日志 90 天归档）；与 `03_02` 口径一致。
9. **前端租户管理页**：租户列表、开通向导（`code/name/domain` + 模块勾选清单）、停用 / 启用、域名配置、配额配置与用量展示、租户模块开关；经契约类型消费接口。
10. **事件与错误码**：发布 `tenant.created/suspended/activated`（Webhook 可订阅）；错误码段 820xx（82001~82008）。
11. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注、实施记录与测试记录随任务留痕。

## 3. 完成标准 <a id="accept"></a>

租户开通全流程可用（自动建库 + 迁移 + 种子）；多租户独立库隔离验证通过（跨租户访问拒绝、批量迁移正确）；配额超限拦截生效；模块开通勾选正确写入、模块开关生效（停用后菜单 / 按钮不可见、接口 82008、不可新建、存量可查、重开恢复；引用未注册 / 未启用模块被拒 82007；进行中流程不受影响）；停用即时生效；`tenant.*` 事件发布成功；开通种子完整；前端租户管理页功能齐备；新增模块覆盖率达标、`preflight --fast` 全绿。
