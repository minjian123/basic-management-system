## 2. 用例与编号 <a id="cases"></a>

| # | 用例 | 断言要点 | 完成标准映射 |
| --- | --- | --- | --- |
| 1 | `TenantTarget` 三选一 | 零个 / 多个标识 → `ParamError`（10001） | 契约边界 |
| 2 | 标识形态 | 主键非雪花串 / 编码带连字符 / 域名单段 → `ParamError`；不送租户源 | 形态先于取数 |
| 3 | `label` / `from_context` | 主键优先、缺主键回落编码、两者皆无 → `ParamError` | 上下文派生 |
| 4 | `require` 分派 | `tenant_id` / `code` / `domain` 分别命中 `by_id` / `by_code` / `by_domain` | 复用租户源 |
| 5 | `per_round` 一致 + 每轮回源 | 两次循环调用两次回源、结论同 `require` | 完成标准 1（异步循环） |
| 6 | `batch` 一次 + 批内复用 | 源调用计数 = 1，批内多次取用同上下文 | 完成标准 1（批处理前置） |
| 7 | `batch` 拒绝冒泡 | 进入阶段停用 → 批体不执行 | 失败分支 |
| 8 | `require_sync` 无循环 | 正常返回 | 同步执行体 |
| 9 | `require_sync` 有循环 | 运行中事件循环 → `ConfigError`，且未回源 | 不放行、不降级 |
| 10 | 三分支错误码（参数化 3 例） | 未知 `80001` / 404；停用 `80002` / 403；不可达 `10007` / 503 | **完成标准 4**（与 HTTP 一致） |
| 11 | 上下文兜底 | 完整上下文取主键；无上下文 / 演示兜底（无主键）→ `ConfigError` 且不回源 | 不拿演示租户冒充通过 |
| 12 | `verify` 缺省与覆写 | 缺省不拦；覆写拿到已校验上下文；顺序在 `resolve` 之后 | 完成标准 3（产品扩展） |
| 13 | `scope` 四入口转交 | `require` / `per_round` / `batch` / `require_sync` 原样转交 | 扩展契约 |
| 14 | 产品拒绝冒泡 | 子类 `verify` 抛业务异常原样冒泡 | 不改基类行为 |
| 15 | `NullTenantGuard` | `plugin_name == "null"`；两类定位调用均 `ConfigError` | 完成标准 4（不静默放行） |
| 16 | 装配接线 | `PLUGIN_WIRINGS` 的端口 / 配置分区 / state 属性；`provider` 空 → null、`source` → 默认实现、未登记 → `PluginError` | 完成标准 5（登记） |
| 17 | 平台插件登记 + 源读取成功 | `register_platform_plugins` 后经 `get_tenant_guard` 判定成功 | 装配可用 |
| 18 | 缺租户源 | 判定时报 `ConfigError`（不静默放行） | 失败分支 |
| 19 | 公共依赖出口 | `api/deps.get_tenant_guard` 与能力域同源（同一函数对象） | 出口唯一 |
| 20 | msg 继承关系 | `issubclass(MsgTenantGuard, BaseTenantGuard)`、登记名 `msg` | **完成标准 3**（示例可运行、不改基类） |
