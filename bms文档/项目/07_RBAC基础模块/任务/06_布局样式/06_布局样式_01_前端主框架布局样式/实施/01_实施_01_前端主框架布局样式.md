## 3. 实施过程 <a id="process"></a>

1. **令牌补全**（`frontend/apps/desktop/src/styles/tokens.scss`）：新增间距阶梯 `--bms-space-{1,2,3,4,6,8}`（4/8/12/16/24/32）、`--bms-radius-lg`（8px）、字号阶梯 `--bms-font-size-{xs,sm,lg}`（12/13/16）、页面底色 `--bms-color-bg-page`（亮 `#f5f7fa` / 暗 `#18191a`）、布局结构 `--bms-layout-{sidebar-width,sidebar-collapsed-width,header-height,content-padding}`；`@media (max-width: 992px)` 覆盖内容区边距为 16px；既有 `--bms-spacing-*` 保留不动。
2. **EP 变量映射补全**（同文件「组件库（Element Plus）主题映射」节）：补 `--el-bg-color` / `-bg-color-page` / `-bg-color-overlay` / `-fill-color{,-light,-lighter,-blank}` / `-text-color-{regular,secondary,placeholder,disabled}` / `-border-color{-light,-lighter,-extra-light}` / `-color-primary-light-9` 到令牌（单一来源），使布局族内嵌 EP 件暗色随令牌自动可读。
3. **布局族 18 件补样式**（`ui-ep/src/components/layout/*.vue`）：骨架语义件深度实现 —— `MainLayout`（壳：顶栏 56 / 侧栏 220↔64 / 标签栏 / 内容区 24px 边距 + 页面底色）、`SideMenu`、`SideMenuItem`、`TabNavBar`（激活 / 悬停 / 关闭 / 溢出「更多」）、`TabNavContextMenu`、`LayoutCard`、`PageContainer`、`SplitPane`、`TreeMasterDetail`、`DualTabs`、`FormLayoutShell`；薄封装件最小必要 —— `ContentTabs` / `CollapsePanel` / `CollapsePanelGroup` / `GridLayout` / `GridItem` / `SpacingDivider`（经 `--el-*` 对齐令牌，不重写 EP 外观）；`ModuleAreaOutlet` **保留既有样式、仅统一间距令牌口径**（`--bms-spacing-*` → `--bms-space-1`）。
4. **`MainLayout` 内联宽度改读结构令牌**：`sidebarWidth` 由 `64px` / `220px` 字面量改为 `var(--bms-layout-sidebar-collapsed-width, 64px)` / `var(--bms-layout-sidebar-width, 220px)`。
5. **`SideMenuItem` 补图标渲染**（经补充确认）：图标以 `<i class="bms-side-menu__icon">` 包 **标题 span 之外** 渲染（Element Plus 折叠态会隐藏 `.el-menu-item > span` / `.el-sub-menu__title > span`，置于 span 内会被一并隐藏）；无 `icon` / 未知图标降级不渲染（`IconRenderer` 传 `fallback=""`）。
6. **新增护栏用例**（`ui-ep/tests/layout-style.spec.ts`，Kiwi 2241）：18 件清单一致性 + 每件含非空 `<style scoped>` + 样式块无硬编码色值（fixture 拦截 + 正向）。
7. **宿主令牌用例补充**（`apps/desktop/tests/tokens.spec.ts`）：新增令牌存在性与 `@media (max-width: 992px)` 断言、EP 映射断言。
8. **新增开发态核对页**（`apps/desktop/src/dev/LayoutCheck.vue` + `layoutCheck.ts` + `layout-check.html`，经补充确认）：真实组装布局族（壳 + 容器 / 导航 / 分栏族）+ 亮暗切换，作为实现侧截图对照载体；同步 `.vscode/launch.json` 选页清单（工作区根与 `bms/` 两处）。

| 1 | 任务描述「18 件均无样式」与实际不符（`ModuleAreaOutlet` 已有样式） | 实测为准；经确认后**保留既有样式、仅统一间距令牌口径** |
| 2 | 令牌缺口（12/24/32 间距、8 圆角、字号阶梯、页面底色、布局结构尺寸） | 经确认**补全基础阶梯令牌 + 布局结构令牌**并入 `tokens.scss` 与《设计令牌》登记 |
| 3 | 断点口径不一致（设计 1024 / 代码 992） | 经确认**以代码为准**（768/992），CSS 媒体查询取同值、**折叠 / 抽屉只由 JS 负责**（不双重折叠） |
