## 2. 任务内容 <a id="content"></a>

1. **布局族补样式（18 件）**：`frontend/packages/ui-ep/src/components/layout/` 下全部布局组件按《布局设计 · 主框架》《布局设计 · 导航》补 `<style scoped>`——`MainLayout` / `SideMenu` / `SideMenuItem` / `TabNavBar` / `ContentTabs` / `LayoutCard` / `PageContainer` / `CollapsePanel` / `CollapsePanelGroup` / `GridLayout` / `GridItem` / `SplitPane` / `TreeMasterDetail` / `DualTabs` / `FormLayoutShell` / `SpacingDivider` / `TabNavContextMenu` / `ModuleAreaOutlet`。
2. **令牌口径**：色 / 间距 / 圆角 / 字体 / 阴影一律走设计令牌（`var(--bms-*)`，源自 `styles/tokens.scss`），**不硬编码色值**；与 `ui-ep` 既有组件同口径。
3. **主框架壳呈现**：侧栏（展开 / 折叠 / 移动端抽屉）、顶栏、多标签栏、内容区按布局设计呈现；标签页激活 / 关闭 / 右键菜单 / 刷新交互态样式齐备。
4. **主题与响应式**：亮 / 暗主题经令牌切换；断点响应式（移动端抽屉、窄屏折叠）与既有 `useResponsive` 逻辑对齐，避免双重折叠。
5. **品牌化边界**：租户品牌替换（Logo / 主题色按租户）不在本任务（归品牌化阶段，沿用 `05_01` 登记口径）。
6. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注与实施 / 测试记录留痕。

## 3. 完成标准 <a id="accept"></a>

布局族 18 件样式齐备，宿主主框架（侧栏 + 顶栏 + 多标签 + 内容区）在亮 / 暗主题与移动端 / 窄屏 / 宽屏断点下呈现符合《布局设计 · 主框架》《布局设计 · 导航》、**无裸骨架残留**；样式全部入件 `scoped` 且走令牌；`ui-ep` 用例与宿主 `vue-tsc` / ESLint / Vitest 全通过；新增 / 变更模块覆盖率达标、`preflight --fast` 全绿。
