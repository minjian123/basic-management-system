## 1. 背景与目标 <a id="goal"></a>

`frontend/packages/ui-ep` 布局族（`src/components/layout/`，18 件）阶段四只交付了结构与交互逻辑，样式为空——宿主主框架外壳（侧栏 + 顶栏 + 多标签 + 内容区）呈**裸骨架**，直接制约阶段七 `03_01` 的界面消费与观感验收，并影响后续全部页面交付。

本任务按《布局设计 · 主框架》《布局设计 · 导航》《布局设计 · 设计令牌》《布局设计 · 响应式适配》为布局族补齐样式，使外壳可真实呈现；**先行于 `03_01`**。

**边界（不在本任务）**：租户品牌替换（Logo / 主题色按租户，归品牌化阶段）；顶栏业务内容（全局搜索 / 通知 / 租户切换 / 用户下拉）的装配（属宿主与后续任务）；`03_01` 的动态菜单与权限联动。

## 4. 设计要点 <a id="design"></a>

### 4.1 样式落点与口径（强制）

- 样式一律入**各组件 `<style scoped>`**（纯 CSS，与 ui-ep 既有 78 件同口径），**不落全局文件**。
- 类名 **kebab-case**（BEM 简化），沿用组件现有 `bms-<件名>__<元素>` 前缀，**不新增类名结构**。
- 色 / 间距 / 圆角 / 字号 / 阴影一律 `var(--bms-*)`；**色值零硬编码**（`guard-tokens.spec.ts` 强制）；Element Plus 内部结构经 `--el-*` 覆盖时同样只写令牌。
- `1px` 描边、媒体查询断点、树形递归缩进等结构常量按《前端开发规范》「尺寸硬编码白名单」执行；间距 / 圆角 / 字号 / 结构尺寸一律走令牌（新增令牌见 §11）。

### 4.2 主框架壳（MainLayout）

- 根 `.bms-main-layout`：flex 列、`height: 100%`、`overflow: hidden`。
- `.bms-main-layout__sidebar`：宽由 `sidebarWidth` 读结构令牌（`--bms-layout-sidebar-width` / `--bms-layout-sidebar-collapsed-width`）给出，样式补底色 `--bms-color-bg`、右边框 `1px --bms-color-border`、`width` 过渡。
- `.bms-main-layout__logo`：高对齐顶栏高度、左右内边距、`font-weight: 600`、下边框；折叠态居中。
- `.bms-main-layout__main`：flex 列、`flex: 1`、`min-width: 0`。
- `.bms-main-layout__header`（顶栏）：高 `56px`、`flex-shrink: 0`、`display: flex` 居中对齐、左右内边距、`gap`、底色 `--bms-color-bg`、下边框。
- `.bms-main-layout__header-left/right`：flex 居中对齐 + `gap`；右侧 `margin-left: auto`。
- `.bms-main-layout__toggle`：无边框按钮、控件高度、圆角、hover 底 `--bms-color-fill`、`:focus-visible` 焦点环 `--bms-color-focus-ring`、光标 pointer。
- `.bms-main-layout__tabs`：`flex-shrink: 0`、底边框、底色（`TabNavBar` 自带）。
- `.bms-main-layout__content`：`flex: 1`、`min-height: 0`、`overflow: auto`、内边距（宽屏 / 窄屏两档）、页面底色。

### 4.3 导航族（SideMenu / SideMenuItem / TabNavBar / TabNavContextMenu）

- `SideMenu`：flex 列、`height: 100%`、`overflow: hidden`、底色；`__search` 内边距；`__menu` 宽 100% + `--el-menu-border-color: transparent`（去 EP 右侧竖线）；`__footer` 上边框；折叠态隐藏搜索。
- `SideMenuItem`：`__title` flex 居中对齐 + `gap` + 文本省略（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`）；`__badge` 微调位置与 `--el-badge-*`。
- `TabNavBar`：`__item` inline-flex、固定高度、内边距、`gap`、`flex-shrink: 0`、右边框、`cursor: pointer`、`user-select: none`；默认底（非激活）用 `--bms-color-fill`、字色 `--bms-color-text-secondary`；`:hover` 提亮；`.is-active` → 底色 `--bms-color-bg`、字色 `--bms-color-primary`、底部 2px 主色条（**视觉对应原型「工作台（固定）」深底 + 激活项高亮的形态，按布局设计取令牌**）。
- `.bms-tab-nav__close`：小尺寸按钮、圆角、hover 底、字色 `--bms-color-text-secondary`；`__title` 省略。
- `.bms-tab-nav__more` 下拉：绝对定位于容器、白底、`1px` 边框、圆角、阴影、`max-height` + `overflow: auto`、`z-index` 抬层。
- `TabNavContextMenu`：`position: fixed`、`z-index` 抬层、`min-width`、白底、边框、圆角、阴影、内边距；`__item` 块级左对齐、圆角、hover 底 `--bms-color-fill`、`:disabled` 弱化（`--bms-color-text-secondary` + `cursor: not-allowed`）。

### 4.4 内容容器族（LayoutCard / PageContainer / CollapsePanel(Group) / ContentTabs / SpacingDivider / GridLayout / GridItem）

- `LayoutCard`：圆角 / 边框 / 阴影经 `--el-card-*` 与令牌对齐；`__header` flex 两端对齐、`is-collapsible` 光标 pointer；`__title` 标题字重；`__extra` flex 居中对齐 + `gap`。
- `PageContainer`：flex 列；`__header` 两端对齐 + 下边框，`is-sticky` → `position: sticky; top: 0; z-index` + 底 `--bms-color-bg`；`__title`（`16px` / `600` / `margin: 0`）、`__description`（次要色）、`__content`（`flex: 1` + `overflow: auto`）、`__footer`（上边框 + 右对齐）。
- `CollapsePanel` / `CollapsePanelGroup` / `ContentTabs` / `GridLayout` / `GridItem` / `SpacingDivider`：**最小必要样式**——经 `--el-*` 覆盖对齐令牌（边框色 / 圆角 / 内边距 / 字号），**不重写 Element Plus 外观**（见 §11-5）。

### 4.5 分栏与主从（SplitPane / TreeMasterDetail / FormLayoutShell / DualTabs）

- `SplitPane`：flex；`[data-direction='vertical']` 转列向；`__first`（`flex: none` + `overflow: auto`）、`__handle`（`flex: none`；横向 6px 宽 / 纵向 6px 高；`cursor: col-resize|row-resize`；`touch-action: none`；底色 `--bms-color-border`，`:hover` / `:focus-visible` 主色；`is-dragging` 高亮 + `user-select: none`）、`__second`（`flex: 1` + `min-width: 0` + `overflow: auto`）。
- `TreeMasterDetail`：`height: 100%`；`__tree` flex 列、`min-width: 0`、树区滚动；`__tree-header` 内边距。
- `FormLayoutShell`：flex 列、`height: 100%`；`__body` `flex: 1` + `min-height: 0` + `overflow: auto` + 内边距 + 白底。
- `DualTabs`：flex 列；`__primary` 下边框；`__secondary` 底 `--bms-color-fill` + 小一档字号（视觉区分上下层）。

### 4.6 主题与响应式（强制）

- **主题**：颜色全部走 `--bms-color-*` / `--bms-color-fill` / 页面底色令牌 → 亮 / 暗主题经 `[data-theme='dark']` 令牌自动切换，布局件**不写 dark 专用规则**。
- **响应式（避免双重折叠）**：**折叠 / 抽屉职责归 JS**（`useResponsive` + `MainLayout` 既有逻辑）；布局件媒体查询**只做非折叠类适配**——① 内容区 / 分栏内边距宽窄两档；② 顶栏 / 标签栏的次要间距收紧。媒体查询断点取值与 `useResponsive` 缺省**同值**（§11-4 定稿）。

- 移动端工程（`frontend/apps/mobile` / `ui-vant`）不在本任务。
- 暗色令牌为「最小集」（`tokens.scss` 注释已登记），完整深色适配随品牌化任务。
