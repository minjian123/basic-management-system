## 1. 域说明 <a id="intro"></a>

本域承载阶段七的**租户与平台超管**主线：BMS 为 SaaS 多租户形态，需平台超管完成租户开通（自动建库 + 迁移 + 种子）、停用 / 启用、域名配置、配额治理与**模块开通勾选与租户模块开关**；租户业务数据一租户一独立库物理隔离，平台超管跨租户运营仅到租户级、不进入租户业务数据。

- **对应 WBS 域**：《总体项目规划》阶段七「平台超管与租户管理（含模块开通勾选与租户模块开关）」；概要 25-租户管理；架构 12-多租户路由。
- **端范围**：PC（后端 tenant 能力 + 前端租户管理页，纯平台侧、仅平台超管可见）。
- **依据**：《[概要设计 · 租户管理](../../../设计/概要设计/25_概要设计_租户管理.md)》、《[架构设计 · 多租户路由](../../../设计/架构设计/12_架构设计_子系统_多租户路由.md)》、《[架构设计 · 权限计算引擎](../../../设计/架构设计/15_架构设计_子系统_权限计算引擎.md)》§8、《[项目规划说明](../../../规划/项目规划说明.md)》（多数据源策略、初始化数据）。

## 2. 需求 07-7：租户管理与平台超管 <a id="r07-7"></a>

优先级：2（高）

**背景与动机**：BMS 目标形态是 SaaS 多租户独立库隔离，平台需要一套租户生命周期治理：开通时自动建库 / 迁移 / 批量种子，运营期可停用启用、配置域名与配额、按模块开通并开关；同时平台超管须与租户管理员职责分离、不进入租户业务数据。缺少该能力，多租户独立库隔离、配额超限拦截与租户模块开关三项阶段完成标准均无法验证。

**内容**（概要 25；架构 12；架构 15 §8）：

1. **租户 CRUD**：`sys_tenant`（`code/name/domain/db_key/status/expire_at`），`code`、`domain` 唯一，按 `status` 过滤。
2. **租户开通**：校验 `code` 唯一 → 自动建库（`bms_tenant_{code}`）→ 双套 Alembic 迁移（按目标库方言）→ 批量种子 → 注册 `sys_tenant` → 写入模块开通清单（`sys_tenant_module`，开通向导勾选，未勾选默认不开通）→ 预热引擎（可选）→ 落 `tenant.created` 事件；重型操作支持 `Idempotency-Key` 防重复开通，任一步失败清理已建库并告警。
3. **租户停用 / 启用**：停用回收引擎、按租户前缀失效会话标记、登录拦截，落 `tenant.suspended`；启用恢复并落 `tenant.activated`。
4. **域名配置**：生产子域名 `{tenant}.bms.example.com` + 泛域名 TLS，作为子域名租户路由依据；域名冲突拒绝（82004）。
5. **配额管理**：`sys_tenant_quota`（用户数 / 存储 / 开放接口调用量），`limit_value/used_value`；创建用户 / 上传文件 / 开放接口调用前校验，超限拒绝并告警（82005）。
6. **租户模块开关**：`sys_tenant_module`（`module_key/status/opened_by/opened_at/closed_at`）；`module_key` 校验 `sys_module` 已注册且启用（未注册 / 未启用拒绝 82007）；停用后该模块菜单 / 接口在租户侧不可用、不可新建单据，存量数据保留可查、重新开通即恢复，进行中流程与审批不受影响（停用后入口 / 接口被拒 82008）。
7. **平台超管**：`sys_admin` 平台运营账号（首次启动创建、强制改密），跨租户运营仅到租户级、不进入租户业务数据；权限码 `tenant:manage/tenant:quota`。
8. **开通种子**：租户库三类内置管理员角色（系统 / 安全 / 审计，权限互斥、同一用户不得兼任）与初始系统管理员账号（首次登录强制改密）、默认 IdP 占位配置、初始归档策略（四类审计日志 90 天归档）；种子内容与 [07-6 三权分立](03_需求_菜单与权限.md#r07-6) 一致。
9. **前端租户管理页**：租户列表、开通向导（`code/name/domain` + 模块勾选清单）、停用 / 启用、域名配置、配额配置与用量展示、租户模块开关。
10. **事件**：`tenant.created/suspended/activated` 发布（Webhook 可订阅）；错误码段 820xx（82001~82008）。

**完成标准**：租户开通全流程可用（自动建库 + 迁移 + 种子）；多租户独立库隔离验证通过（跨租户访问拒绝、批量迁移正确）；配额超限拦截生效；租户模块开通勾选正确写入（未勾选不开通），模块开关生效（停用后菜单 / 按钮不可见、接口 82008、不可新建、存量可查、重开恢复；引用未注册 / 未启用模块被拒 82007；进行中流程不受影响）；停用即时生效（会话失效 + 登录拦截）；`tenant.*` 事件发布成功；开通种子完整（三类内置管理员角色、初始系统管理员账号、默认 IdP 占位、归档策略）。
