# 插件化挂接需求

> BMS 基础管理系统 · 阶段七（RBAC 基础模块）· 需求域 01：具名插槽基座（1 条）

[文档首页](../../../文档首页.md) › [RBAC 基础模块总览](00_需求_RBAC基础模块.md) › 插件化挂接

## 1. 域说明 <a id="intro"></a>

本域承载阶段七的**首个需求**：**插件化挂接（具名插槽基座）**。阶段七要落地用户管理完整域与角色权限，而用户管理页需要以**具名插槽 + 前后端配套插件**挂接**数据归其他服务**的功能（典型：mdm 组织域「用户分配岗位」插件写 `org_user_post`；角色管理页「角色分配」页签挂 mdm「岗位分配 / 部门分配」插件写 `org_role_post` / `org_role_dept`）——宿主页不得硬编码依赖该插件或其后端，缺失即降级隐藏（保证 bms 单独运行 / 与其他产品并存都不缺实体）。

- **对应 WBS 域**：架构 10 §9「具名插槽与前后端配套插件化」；架构 08 §9「扩展点 + 注册表」。
- **落点说明（重要）**：本需求**不重复定义**——「具名插槽基座功能与前后端配套插件（含样例）」已在**阶段五回补需求 `05-10`** 立项（域 06，2026-10-03）；本域仅**引用**该需求作为阶段七的挂接依赖，实施与验收随 `05-10` 推进。
- **依据**：《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§8.2 / §9、《[前端开发规范](../../../规范/前端开发规范.md)》「具名插槽与插件挂接」条、《[前端基类清单](../../../前端基类清单.md)》、《[需求文档规范](../../../规范/需求文档规范.md)》。

## 2. 需求 07-1：具名插槽基座功能（插件化挂接） <a id="r07-1"></a>

优先级：2（高）

**背景与动机**：阶段七用户管理页需要挂接「用户分配岗位」等**数据归 mdm 组织域**的插件；若不先把「具名插槽 + 前后端配套插件」落为平台基座能力，宿主页将硬编码依赖具体插件（bms 无 mdm 时缺实体报错），且每个宿主页各写一套挂接不可复用。该机制作为阶段七用户管理页扩展位的前置，列为阶段七首个需求。

**内容**（《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§9、《[前端开发规范](../../../规范/前端开发规范.md)》「具名插槽与插件挂接」条）：

1. **机制落点**：**引用阶段五回补需求 `05-10`《具名插槽基座功能与前后端配套插件（含样例）》**（域 06），不在本需求重复定义。
2. **阶段七消费**：用户管理页以具名插槽（`sys.user.detail.tabs`）提供挂接位；mdm 组织域「用户分配岗位」插件挂接该槽（前后端配套，写 mdm 用户-岗位契约）；插件缺失即隐藏。**角色管理页**（`07-3`）「角色分配」页签以具名插槽（`sys.role.detail.assign`）提供挂接位，mdm「岗位分配 / 部门分配」插件挂接（写 mdm `org_role_post` / `org_role_dept`）；该槽依赖基座**显式上下文注入通道**（回补需求 `05-11`，另立项），未就绪时按降级（隐藏）推进。
3. **依赖与顺序**：本需求为阶段七用户管理页扩展位的**前置**；`05-10` 就绪前，用户管理页相关扩展位按降级（隐藏）处理，不阻塞用户完整域其余功能；角色管理页岗位/部门分配插槽另依赖 `05-11` 与 mdm 组织域。

**完成标准**：阶段五 `05-10` 完成标准全部达成（具名插槽可挂多插件、缺失降级、前后端配套约定成文、样例插件全链路跑通、护栏齐备）；用户管理页可按 `05-10` 约定挂接 mdm 插件且缺失即隐藏、不报错；角色管理页「角色分配」页签按 `05-11` 与 mdm 约定挂接岗位/部门分配插件且缺失即隐藏。

**参考文档**：阶段五 [06_需求_具名插槽与插件挂接](../../05_前端插件化/需求/06_需求_具名插槽与插件挂接.md#r05-10)（`05-10`）与其[补充需求 `05-11`](../../05_前端插件化/需求/06_需求_具名插槽与插件挂接.md#r05-11)（显式上下文注入通道）；《[架构设计 · 扩展点与插件化](../../../设计/架构设计/10_架构设计_子系统_扩展点与插件化.md)》§9；mdm《概要设计 · 岗位管理》「用户分配岗位插件」

> 注：本需求为**索引性需求**——实施与验收随阶段五 `05-10`；阶段七侧只作挂接消费与依赖登记，进度以阶段计划为唯一落点。
