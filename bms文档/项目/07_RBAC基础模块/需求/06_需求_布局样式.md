## 1. 域说明 <a id="intro"></a>

本域承载阶段七的**布局族样式补齐**：阶段四交付的 `ui-ep` 布局族（`layout/` 下 18 件组件）只交付了结构与交互逻辑、**无任何样式实现**，宿主主框架外壳（侧栏 + 顶栏 + 多标签 + 内容区）呈**裸骨架**。本域按《布局设计 · 主框架》《布局设计 · 导航》与《布局设计 · 设计令牌》补齐样式，使主框架外壳具备真实视觉呈现，支撑阶段七 `03_01`（动态菜单与界面消费）及后续全部页面的观感交付与验收。

- **对应 WBS 域**：前端基座（布局族）实施；《[架构设计 · 前端架构](../../../设计/架构设计/08_架构设计_前端架构.md)》、《[前端基类清单](../../../前端基类清单.md)》「宿主横切底座」节。
- **落点说明**：布局族组件本体属阶段四前端组件库交付物（`ui-ep`）；本条为**样式实现缺口**的补充需求，在阶段七补足，先行于 `03_01`。
- **依据**：《[布局设计 · 主框架](../../../设计/布局设计/04_布局设计_主框架.html)》《[布局设计 · 导航](../../../设计/布局设计/05_布局设计_导航.html)》《[布局设计 · 设计令牌](../../../设计/布局设计/02_布局设计_设计令牌.html)》、《[前端开发规范](../../../规范/前端开发规范.md)》「样式规范」节、《[需求文档规范](../../../规范/需求文档规范.md)》。

## 2. 需求 07-9：前端主框架布局样式（主题令牌 + 响应式） <a id="r07-9"></a>

优先级：2（高）｜**补充需求**（2026-10-04 立项）

**背景与动机**：阶段四交付的 `ui-ep` 布局族（`layout/` 下 18 件：`MainLayout` / `SideMenu` / `SideMenuItem` / `TabNavBar` / `ContentTabs` / `LayoutCard` / `PageContainer` / `CollapsePanel` / `CollapsePanelGroup` / `GridLayout` / `GridItem` / `SplitPane` / `TreeMasterDetail` / `DualTabs` / `FormLayoutShell` / `SpacingDivider` / `TabNavContextMenu` / `ModuleAreaOutlet`）**只交付了结构与交互逻辑、无任何样式实现**（组件无 `<style>` 块、全库无对应样式规则）——宿主主框架外壳（侧栏 + 顶栏 + 多标签 + 内容区）呈**裸骨架**。

阶段七 `03_01`（菜单/表单/按钮/字段挂接与动态菜单）要按动态菜单注册路由与侧边栏并做界面消费，其完成标准（菜单 / 页面免发版生效、按权限显隐）**需要可见的主框架外壳**才能验收；该缺口同时影响后续全部页面的观感交付。故在阶段七补充本条需求，先行于 `03_01` 落地。

**内容**（《[布局设计 · 主框架](../../../设计/布局设计/04_布局设计_主框架.html)》《[布局设计 · 导航](../../../设计/布局设计/05_布局设计_导航.html)》《[布局设计 · 设计令牌](../../../设计/布局设计/02_布局设计_设计令牌.html)》、《[前端开发规范](../../../规范/前端开发规范.md)》「样式规范」节）：

1. **样式补齐范围**：`ui-ep/components/layout/` 全部布局组件（18 件）按布局设计补样式；样式入各组件 `<style scoped>`，色 / 间距 / 圆角 / 字体等一律走设计令牌（`var(--bms-*)`），与 `ui-ep` 既有组件同口径。
2. **主框架壳**：侧栏（展开 / 折叠 / 移动端抽屉）、顶栏、多标签栏、内容区按《布局设计 · 主框架》《布局设计 · 导航》呈现；标签页交互态（激活 / 关闭 / 右键菜单 / 刷新）样式齐备。
3. **主题与响应式**：亮 / 暗主题经令牌切换；断点响应式（移动端抽屉、窄屏折叠）与既有 `useResponsive` 逻辑对齐。
4. **品牌化边界**：租户品牌替换（Logo / 主题色按租户）**不在本条**，归品牌化阶段（沿用 `05_01` 登记口径）。
5. **测试与登记**：先登记 Kiwi 用例再编码；用例编号标注与实施 / 测试记录留痕。

**完成标准**：布局族 18 件样式齐备，宿主主框架（侧栏 + 顶栏 + 多标签 + 内容区）在亮 / 暗主题与移动端 / 窄屏 / 宽屏断点下呈现符合《布局设计 · 主框架》《布局设计 · 导航》；无裸骨架残留；`ui-ep` 用例与宿主 `vue-tsc` / ESLint / Vitest 全通过；新增 / 变更模块覆盖率达标。
