## 1. 域说明 <a id="intro"></a>

## 2. 需求 07-8：阶段验收门禁核对与阶段测试报告 <a id="r07-8"></a>

优先级：2（高）

**背景与动机**：阶段七涉及权限、数据范围、字段权限、三权与多租户等高风险能力，收口必须逐条核对完成标准、留证据并归档阶段测试报告，否则「权限计算正确、越权被拒、配额拦截、三权互斥、租户模块开关生效」等结论无据可查，遗留项也易失联。

**内容**：

1. **门禁逐条核对**：按《总体项目规划》阶段七完成标准逐条给出结论与证据索引——主体链任意长度权限计算正确、越权与跨租户访问被拒验证通过、数据范围读写检查生效、字段权限生效、配额超限拦截生效、三权互斥生效、租户模块开关生效。
2. **阶段测试报告归档**：汇总用例执行、缺陷、覆盖率、风险与遗留、复盘与经验教训（范式对齐阶段五 / 阶段六测试报告）。
3. **三类文档一致性核对**：需求 ↔ 任务 ↔ 计划编号与挂接一致，进度只在计划表；遗留项登记归口。
4. **收口回写**：按核对结论回写计划进度、架构 / 清单登记（如基类清单、登记表）与需求侧消费方标注。

**完成标准**：门禁逐条有结论与证据索引、无未达标项（或限定项注明归口）；阶段测试报告归档且六节齐备；需求 / 任务 / 计划文档一致、编号无缺失；遗留项全部登记归口、无「无归口」条目。

**参考文档**：《[总体项目规划](../../../规划/总体项目规划.md)》「阶段内容与完成标准」「验收与收尾」节；《[测试规范](../../../规范/测试规范.md)》；阶段五 [01_测试报告_前端插件化](../../05_前端插件化/01_测试报告_前端插件化.md)、阶段六 [01_测试报告_认证与安全](../../06_认证与安全/01_测试报告_认证与安全.md)（范式）
