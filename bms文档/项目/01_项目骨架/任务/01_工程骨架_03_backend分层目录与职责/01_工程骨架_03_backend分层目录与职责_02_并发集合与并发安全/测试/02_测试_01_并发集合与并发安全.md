## 2. 测试范围与用例 <a id="scope"></a>

**范围**：进程内四种锁策略行为一致性、多线程混合读写不丢不重、遍历快照、原子复合方法与缺失分支、分片策略初始化与视图合并；Redis 有序结构排序语义、Lua 原子写/删、版本号惰性重载与本地失效。不含：真实 Redis 集群、free-threading、500 并发压测（随阶段九/十）。

| Kiwi ID | 用例 | 类型 | 自动化文件 | 结果 |
| --- | --- | --- | --- | --- |
| 16 | 进程内并发安全（读写锁互斥、四策略行为一致、原子方法、多线程 4×100 键不丢不重、快照不可变、分片数校验） | 单元·并发 | `tests/core/test_concurrent.py`（18 条含参数化） | 通过 |
| 17 | Redis 有序封装（ZSET 操作与版本号、ZSET+Hash 字典 Lua 原子、数值/字符串键序、快照惰性重载与失效） | 单元 | `tests/core/test_redis_collections.py`（4 条） | 通过 |
| 1–15 | 既有接口/基类/集合用例回归 | 接口·单元 | 既有 `tests/*` | 通过 |

## 3. 执行记录与结果 <a id="run"></a>

```bash
cd backend
uv run pytest -q
# 65 passed

uv run python -m benchmarks.bench_collections
# 输出单/4 线程吞吐表（裸 SortedDict 约 586 万 ops/s，并发封装 67–99 万，4 线程 54–75 万）
```

| 验证点 | 实测 |
| --- | --- |
| 写锁下读等待、读锁下写等待 | 事件断言 50ms 未进入，释放后进入（通过） |
| 四策略 × 列表/集合/字典行为一致 | 参数化用例全通过 |
| 4 线程 400 键 `set + update_atomic` | 无丢失、值全部为 `index + 1` |
| `get_locked` 写回 | `1 → 11` 生效；缺失键抛 KeyError |
| fakeredis Lua（set/set_if_absent/delete） | Hash 与 ZSET 一致；`set_if_absent` 返回既有值 |
| 版本号惰性重载 | 初载 1 次；无变化不重载；跨实例写入后重载；`invalidate` 强制重载 |

**结果汇总**：用例通过率 65/65（100%）；全仓覆盖率 100%（774 语句）。

## 6. 偏差与遗留 <a id="deviations"></a>

- Redis integration 用例（真实 mjbk Redis）随 05-02 三库集成统一接入；当前 fakeredis 已覆盖 Lua 与版本号逻辑。
- free-threading（3.14t）与 500 并发 / P99 ≤ 1s 验收随阶段九/十复测（微基准入口固定）。
- 大 key 阈值与分片数按压测校准；`update_atomic` 类 CAS 的 Redis 侧实现（WATCH/Lua）随 02 域按需扩展。
