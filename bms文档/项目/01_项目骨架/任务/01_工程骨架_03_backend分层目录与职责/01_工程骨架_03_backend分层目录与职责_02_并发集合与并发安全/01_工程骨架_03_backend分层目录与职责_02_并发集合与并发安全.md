## 2. 任务内容 <a id="content"></a>

1. 进程内并发集合（`core/concurrent.py`）：ConcurrentSortedList / ConcurrentSortedDict / ConcurrentSortedSet，四种策略按场景选用——读写锁（默认）、单锁、分片锁（按 key 哈希分桶）、快照替换（不可变副本 + 原子引用）；复合操作原子方法（put_if_absent / update_atomic / remove_atomic 等）；遍历一律返回快照
2. Redis 有序结构封装（`core/redis_collections.py`）：ZSET / Hash / List 映射；Lua 脚本保证复合操作原子；跨副本一致性以 Redis 为唯一事实源 + 本进程只读快照 + 版本号惰性比对（key 遵循 `bms:{租户|global}:{域}:{键}`）
3. 性能验证：微基准脚本（单/多线程吞吐、读写比 9:1 与 1:1、锁开销对比裸 sortedcontainers）；并发正确性用例（多线程混合读写不丢不重、遍历快照一致）
4. 测试：先登记 Kiwi 用例（进程内并发安全、Redis 有序封装），单元用 fakeredis，真实 Redis 用例标 integration

## 3. 完成标准 <a id="accept"></a>

进程内三种集合在读写混合并发下无数据丢失与异常，遍历快照一致；Redis 封装的有序查询与 Lua 原子复合操作可用（fakeredis 用例全绿，integration 用例随 05-02 验证）；微基准报告产出（记录锁开销与吞吐对比）；`uv run ruff check .` 与 `uv run pyright` 无错误；覆盖率 100%；Kiwi 用例登记并标注。
