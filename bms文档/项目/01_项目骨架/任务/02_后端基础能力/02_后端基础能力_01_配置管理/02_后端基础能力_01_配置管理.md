## 2. 任务内容 <a id="content"></a>

1. `config.toml` 分区与键清单：`[app]`（name/env/debug）、`[server]`（host/port/workers）、`[log]`（level/format/slow_request_ms）、`[database]`（platform/tenants/archive，每库 url（不含密码）+ primary/replicas + pool_size/max_overflow/pool_recycle/pool_pre_ping）、`[redis]`（host/port/db/max_connections）、`[minio]`（占位）、`[security]`（占位）、`[cors]`（allow_origins/allow_credentials/allow_methods/allow_headers）；键逐项中文注释
2. 环境分层：`BMS_ENV` 指定 dev/test/prod（未设置默认 dev、非法值启动失败）；基础节 + `[env.dev]`/`[env.test]`/`[env.prod]` 覆盖节，优先级为基础节 < 当前环境覆盖节 < `BMS_` 环境变量（最高）；`BMS_` 前缀环境变量可覆盖全部配置键，嵌套键用双层下划线（`BMS_DATABASE__PLATFORM__URL` → `[database].platform.url`）；密钥类配置只走环境变量（密码如 `BMS_DATABASE__PLATFORM__PASSWORD`）；`[app].env` 仅作展示与默认值，不与 `BMS_ENV` 强校验
3. `app/core/config.py` pydantic-settings 建模（Settings 类），lifespan 内加载校验：必填缺失、类型/取值非法、未知或拼错的分区/键（不静默忽略，`extra="forbid"` 且嵌套模型同样严格；`[env.*]` 覆盖节整体纳入校验）、`BMS_ENV` 非法值均启动失败并报键名，结果存 `app.state.settings`；config 先于日志初始化，失败以非 0 退出码中止、错误信息含键名与原因且不回显配置值；`config.toml` 缺失或为空视为配置缺失启动失败
4. 敏感值保护：任何位置不回显配置密码与含密连接串（`Settings` 的 `__repr__`、日志与异常信息一并脱敏，与 02 脱敏联动）
5. 环境变量模板：新增 `backend/.env.example`（全部 `BMS_` 应用键 + 占位示例值、不含真实密钥），与 `deploy/.env`（基础设施凭据）分离；`backend/.env` 纳入 `.gitignore` 不入库
6. 阶段一边界：本阶段仅做建模与启动校验，`[database]`/`[minio]` 不建立实际连接（数据访问底座在阶段二、文件在阶段六），连接池参数仅校验取值不生效；`[cors]` 本任务仅保证三环境加载正确，`CORSMiddleware` 接入另立（随前端联调）

## 3. 完成标准 <a id="accept"></a>

`BMS_ENV=dev|test|prod` 三环境可切换加载（未设置时默认 dev）；`BMS_DATABASE__PLATFORM__URL` 注入后覆盖生效且优先级高于 `[env.*]` 覆盖节；删除必填键、写入类型/取值非法值、写入未知/拼错键、`BMS_ENV` 取非法值**四类**情形均启动失败，以非 0 退出码中止并指出键名与原因、不回显配置值；三环境差异处（日志级别、CORS）加载结果正确；密钥类配置（密码、含密连接串）不出现在 `config.toml`、`.env.example` 与日志中（`config.toml` 的 url 不含密码）；单测覆盖加载/覆盖/校验失败路径，覆盖率随全局门禁，用例同步 Kiwi（若已部署）。
