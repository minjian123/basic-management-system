## 2. 任务内容 <a id="content"></a>

1. structlog 配置（`app/core/logging.py`）：processors 链（时间戳/级别/logger 名/上下文合并/堆栈单行化/渲染器）；输出 stdout 不落文件；级别默认 dev=DEBUG、prod=INFO；渲染器由 `[log] format` 控制（dev=console 可读、test/prod=单行 JSON）；禁止 print
2. 上下文字段中间件注入：request_id、trace_id（读 `X-Trace-Id` 头，缺失生成 UUID4，并一律回写响应头 `X-Trace-Id`）、tenant（03_04 接入后启用）、user_id/user（阶段四启用）、client_ip、duration_ms
3. 请求日志中间件：每请求 1-2 条（进入 + 结束带 status/duration_ms）；4xx WARNING、5xx ERROR；未捕获异常 ERROR + 堆栈单行，生产响应不回显堆栈；探针（`/healthz`、`/readyz`）与文档路径（`/docs`、`/redoc`、`/openapi.json`）排除请求日志（不记 INFO 或仅 DEBUG）
4. 脱敏清单：密码、token、验证码、私钥、PII、连接串密码、ORM bind params、第三方密钥
5. 慢请求分级：阈值走 `[log] slow_request_ms`（由 01 配置管理提供）；超阈值请求记 WARNING；慢查询依赖三库慢查询日志

## 3. 完成标准 <a id="accept"></a>

test/prod 请求日志为单行 JSON 且含 request_id/trace_id/client_ip/duration_ms（dev 为 console 渲染）；`X-Trace-Id: abc` 请求日志 trace_id 为 `abc` 且响应头回写 `X-Trace-Id: abc`，缺失时生成 UUID4 并回写；未捕获异常 ERROR 行堆栈单行、响应无堆栈；密码/token 全量日志不出现明文；`/healthz` `/readyz` 与 `/docs` 不产生 INFO 请求日志行；超 `[log] slow_request_ms` 请求记 WARNING；单测覆盖上下文字段注入、脱敏与探针路径排除，覆盖率随全局门禁，用例同步 Kiwi（若已部署）。
