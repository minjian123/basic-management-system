## 3. 任务内容 <a id="content"></a>

1. 注册载体：`sys_module` 表（+ `sys_module_i18n` 多语言附表）与平台域 4 行种子（`sys` / `wf` / `rpt` / `ai`）；业务模块不预置，由产品仓库交付时随平台扩展接入登记
2. 唯一性校验：三要素（`table_prefix` / `errcode_segment` / `event_domain`）的启动校验 + CI 查重 + 数据库复合唯一索引兜底
3. 只读查询契约：`GET /api/v1/modules`（无写接口），豁免租户解析

## 4. 完成标准 <a id="accept"></a>

冲突种子被三重拒绝（启动失败 + CI 校验 job 失败 + 数据库唯一索引拒绝）；平台域注册清单可查且字段与契约一致、无写接口暴露；`sys_module_i18n` 英文名可查（逐项验收见子任务清单）。
