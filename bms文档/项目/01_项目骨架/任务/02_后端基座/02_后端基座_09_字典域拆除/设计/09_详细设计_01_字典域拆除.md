## 1. 目的与口径 <a id="purpose"></a>

按 2026-10-10 用户拍板（「只保留主数据相关字典内容，其他后来无根据的生造出来的字典类型、字典条目相关全部删除」）**拆除字典域**——即 `sys_dict_type`（字典类型）/ `sys_dict_item`（字典条目）两级结构及其整套机制（取数 / 翻译 / 缓存 / 高级查询 / 写路径 / 前端组件族）。

- **唯一保留**：数据权限件左列那份「**字典列表**」（业务口径＝**主数据清单**：部门 / 地区 / 项目 / 客户…）——**改由主数据承载**（见 §3）。
- **一并拆除**：`sys_dict_attr`（扩展属性 schema）、`region` 种子、`dict` / `dict_multi` 字段类型、错误码段 `401xx`、缓存键 `bms:{tenant}:dict:*`。

## 3. 替代方案（唯一保留项的新承载） <a id="replacement"></a>

**目标**：数据权限件左列不再读字典域，改列**主数据清单**，四策略形态不变（数据选择 / 数据区域 / 数据匹配 / 扩展权限，仍然「只选不编」）。

1. **承载**：左列清单由**主数据登记**提供——登记项＝（主数据标识 / 名称 / 数据出口 / 可用于数据权限的字段白名单）。bms 侧只读，主数据本体由 mdm（组织 `org_`）与后续主数据域承载。
2. **后端**：`sys_data_scope` 的 `dict_type_id` 改为**主数据标识**（列名与类型随实现定，迁移改列 + 存量清理，因字典域整体废弃故无需回填）；平台库角色字典策略表同步；数据权限读 / 写校验改按主数据出口。
3. **前端**：数据权限件左列改读主数据登记清单；区域 / 匹配的取值选择改走**主数据选择器**（组织选择字段族已具备），动态字典件随域删除。
4. **边界**：主数据本体不在 bms 落副本；数据权限只存「标识 + 策略 config」。

## 4. 执行顺序 <a id="order"></a>

1. 需求变更：作废 `02-44` / `02-56` / `06-6`；`07-3` 改写为按主数据；需求总览与域计数同步。
2. 架构 / 概要 / 布局 / 组件设计文档拆除与改写（含对照表、登记、索引）。
3. 替代方案落地（§3）：主数据登记 + 数据权限改按主数据（后端契约 + 前端件）。
4. 数据库：新增 drop 迁移（六表与索引），三库实测；表文件与总览登记移除。
5. 后端：删除 dict 域代码与路由、错误码段、装配与种子接线、测试与 Kiwi 登记。
6. 前端：删除组件族与缓存 / 翻译 / 契约套件 / dev 页；字段类型 `dict` / `dict_multi` 下线。
7. 契约产物重生成；前后端全量测试与门禁全绿。
8. 数据：历史字典行幂等清理脚本（与结构迁移分离）。
9. 登记回写：任务 / 父任务 / 计划 / 基类清单 / 需求状态。

## 5. 迁移与回滚 <a id="migration"></a>

- **迁移**：新增 drop 脚本（平台与租户两链按表归属分别落），**先删数据后删表**（幂等）；三库（MySQL / PostgreSQL / DM8）实测并记录；SQLite 开发库由启动期建表逻辑同步（不再建表）。
- **回滚**：drop 迁移的 `downgrade` 重建六表（空表即可，种子与业务数据不再回填）；代码回滚以本任务提交为界。
- **数据清理**：`ops/` 下幂等脚本删除历史字典行（按类型码删除类型 / 条目 / i18n / attr），可重复执行；不进结构迁移。

## 6. 验收与测试 <a id="accept"></a>

- □ 六表在三库 drop 成功、模型元数据零漂移；表文件与总览登记移除
- □ `/api/v1/dicts/*` 全线下线，前后端无悬挂引用（编译 / 类型 / 门禁通过）
- □ 数据权限左列改由主数据承载并可读（四策略形态不变）
- □ 前端全量测试（core / ui-ep / apps）与后端全量测试通过；`api-types` 已重生成
- □ 文档 144 份收口、门禁全绿（check-links / check-docs-scope / check-base / check-status / preflight）
- □ 历史数据幂等清理脚本入库并有使用说明

## 7. 风险与遗留 <a id="risk"></a>

- **面广**：跨需求 / 架构 / 概要 / 布局 / 组件 / 数据库 / 后端 / 前端 / 契约 / 文档，必须按 §4 顺序推进，禁止"先删代码后改文档"。
- **替代前置**：§3 未落地前不得 drop 表（否则数据权限断链）。
- **残留**：代码与架构里另有「动作枚举 / 三态枚举 / 渠道枚举 / 场景枚举」等**通用开发用词**，与本域无关，不在拆除范围。
