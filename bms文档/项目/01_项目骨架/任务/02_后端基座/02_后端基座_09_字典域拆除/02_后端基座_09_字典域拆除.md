## 2. 任务内容 <a id="content"></a>

**口径来源（2026-10-10 用户拍板）**：「只保留主数据相关字典内容，其他后来无根据的生造出来的字典类型、字典条目相关全部删除。」经交互确认：**唯一保留**＝数据权限件左列那份「字典列表」（＝主数据清单：部门 / 地区 / 项目 / 客户…），**改由主数据承载**；`region` 种子与字典扩展属性一并随域拆除。

1. **需求侧**：作废 `02-44` / `02-56` / `06-6`；`07-3` 数据权限「按字典类型结构化」改写为**按主数据**（保留四策略形态：数据选择 / 数据区域 / 数据匹配 / 扩展权限）；需求总览、域计数与任务索引同步。
2. **架构 / 概要 / 设计侧**：数据架构「字典与系统参数管理」、概要设计 09「字典管理」、布局设计 17「字典页」、组件设计「字典字段」节点及其引用；组件设计「选项源能力」「查询方案能力」的数据源清单同步。
3. **数据库侧**：六表（`sys_dict_type` / `sys_dict_item` / `sys_dict_attr` + 三张 `_i18n`）与相关索引、迁移（`0001_dict_and_query_scheme` / `0010_dict_item_parent_id_bigint` / `0011_dict_field_names`）、表文件与总览登记；`sys_data_scope.dict_type_id` 与平台库角色字典策略表改按主数据承载。
4. **后端侧**：dict 域 39 个文件（取数 / 翻译 / 缓存 / 高级查询 / 写路径 / 种子 / 装配 / 错误码段 `401xx`）+ `/api/v1/dicts/*` 13 路由；`ops/seed_dict.py` / `init_tenant.py` 种子接线；测试与 Kiwi 登记。
5. **前端侧**：字典字段组件族与缓存 / 翻译 / 契约套件 / 投影 / dev 核对页共 71 个文件；字段类型 `dict` / `dict_multi` 与渲染分发；`api-types` 契约产物重生成。
6. **数据侧**：历史种子数据（`user_status` / `user_gender` / `biz_type` / `region`）与既有字典行的**幂等清理脚本**（数据变更与结构迁移分离）。
