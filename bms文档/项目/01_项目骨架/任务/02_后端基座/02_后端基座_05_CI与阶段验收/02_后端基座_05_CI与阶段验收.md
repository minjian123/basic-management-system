## 3. 任务内容 <a id="content"></a>

1. 三库集成在流水线收口：`bms_test` 前缀测试库「建库 → 迁移 → 集成用例 → 清理」；拓扑路由与租户隔离用例；重验证层三库集成 job 激活（`deploy/ci/verify-enabled` 开关）
2. 阶段门禁证据与回写：逐项核对 **M1 门禁六项**（异常体系 / `BaseModel` 落库 / 三库拓扑 / 租户隔离与批量迁移 / 模块注册校验 / 跨阶段基座登记）并回写需求总览门禁表
3. 测试报告与 README：阶段测试报告四章节（用例 / 缺陷 / 覆盖率 / 风险与遗留）+ 三工程 README 与现状一致

## 4. 完成标准 <a id="accept"></a>

MySQL / PostgreSQL / 达梦 DM8 三库迁移与集成用例全绿、重验证层集成 job 激活并稳定；M1 门禁六项结论与证据索引落文档、本域 16 条需求状态与完成日期回写完毕；测试报告四章节齐备且数据来自 CI 采集、README 与现状一致（逐项验收见子任务清单）。
