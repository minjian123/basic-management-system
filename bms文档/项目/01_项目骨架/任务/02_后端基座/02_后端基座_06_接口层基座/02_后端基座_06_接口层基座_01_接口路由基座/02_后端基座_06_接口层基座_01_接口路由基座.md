## 2. 任务内容 <a id="content"></a>

1. 按需求 02-55 落「接口路由基座」：统一模块路由基类 `BaseRouter`（继承 FastAPI `APIRouter`：前缀 / tags / 响应模型 / 异常映射 / 元信息）
2. 路由注册与统一挂载：`BaseRouter` 子类登记 + 应用工厂统一挂载（替换 `api/router.py` 手工 `include_router`）
3. 参数绑定：分页 / 排序 / 筛选参数统一经 `Depends` 工厂解析（复用 `BasePageQuery` / `BaseSortQuery`，筛选经通用查询参数模型绑定）
4. 统一响应与异常收口、鉴权 / 权限依赖占位（登录态与权限依赖随认证 / RBAC 阶段）
5. 登记：《后端基类清单》「接口层基座」节 + 《架构设计 · 接口与集成》「公共约定」节

## 3. 完成标准 <a id="accept"></a>

路由基类与注册 / 统一挂载就位、现有模块路由改经基座；参数绑定与统一响应 / 异常口径可核对；依赖注入可解析、应用可启动不报错；**不实现真实鉴权**（登录态与权限依赖占位）；`pytest`、`ruff`、`pyright` 全绿。
