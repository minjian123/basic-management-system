## 2. 测试范围与用例 <a id="scope"></a>

| 层 | 用例 | 覆盖点 |
| --- | --- | --- |
| 契约 | `test_dict.py::test_constants_and_data_contracts` | `DictItem` 字段集含 `id`；`DictQuery.parent_id` 为整型；默认值（`id=0`、`parent_id=None`） |
| 空实现 | `test_dict.py::test_null_by_type_fixed_version_and_filters` | 占位条目 `parent_id` 为父条目 `id`（`1`）；级联过滤 `parent_id=1` 返回子条目；版本一致返回 `items=None` |
| 路由 | `test_dict.py::test_routes_with_in_memory_implementations` | `GET /dicts/{type}` 的 `parent_id` 整型参数透传（`parent_id=1`） |
| 真实取数 | `test_dict_real.py::test_by_type_version_filters_locale_and_disabled` | 三态：`parent_id=0` 取顶层、`parent_id=<父 id>` 取子集；条目带 `id`；关键字 / 按值子集 / 探针截断 / locale 回退 / 停用不可见不受影响 |
| 迁移与种子 | `test_dict_real.py::test_migration_creates_tables_and_indexes`、`test_seed_idempotent` | 迁移建表与索引齐备；种子两阶段写父 `id` 关系且重复执行幂等 |
| 写路径与高级查询 | `test_dict_real.py::test_advanced_query_engine_and_provider` | 条目更新载荷 `parent_id=<父 id>` 生效，属性条件引擎不受影响 |
| 前端领域 | `tests/domain-dict.spec.ts` | `normalizeDictItem` 解析 `id`（数字 → 字符串）与 `parent_id`（`'0'` 视为顶层）；树按 `id` 归并（孤儿提升顶层 / 排序）；线参数丢弃空串、`'0'` 与具体 id 透传 |
| 前端能力 | `tests/dict-select.spec.ts`、`testing/dict.ts` 级联用例 | `setParent('<父 id>')` 清空受控值并重载子条目；桩按 id 三态过滤 |
