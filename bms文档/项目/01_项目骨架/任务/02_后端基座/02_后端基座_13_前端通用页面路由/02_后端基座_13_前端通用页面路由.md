## 2. 任务内容 <a id="content"></a>

**口径来源**：《数据库开发规范》§3.1.2——`form_key` 为**表单标识**（界面相关），**供通用页面路由 / 查询方案（`field_key = form_key`）/ 用户偏好（`list.{form_key}`）**引用。

1. **通用页面路由**：按 `form_key` 解析页面 / 表单（表单标识 → 页面），统一挂载与寻址。
2. **数据源清单接入**：`GET /api/v1/data-sources`（`02_12` 契约）驱动前端；`form_key → data_source_key`（多对一）经注册清单解析。
3. **联动**：查询方案（`field_key = form_key`）与用户偏好（`list.{form_key}`）按 `form_key` 联动。
4. **契约类型**：消费 `@bms/api-types`（`02_12` 重生成产物），零漂移。

> **协同（已交付，2026-10-11）**：任务 [`02_11`](../02_后端基座_11_系统字段form_key落表/02_后端基座_11_系统字段form_key落表.md) 已交付 `form_key` 构建期清单（`bms_core/registry/forms.py`）与各字典表 `form_key` 列（**多表联合取数判别列**）；本任务按 `form_key` 解析页面 / 表单，并消费 `form_key → data_source_key`（多对一，由 `02_10` 回填）。

> **协同（已交付，2026-10-11）**：任务 [`02_10`](../02_后端基座_10_统一数据源注册与通用数据接口/02_后端基座_10_统一数据源注册与通用数据接口.md) 已交付**统一数据源注册**（`DataSourceRegistry` / `DATA_SOURCE_CATALOG`，覆盖 bms 侧全部字典表）、**通用数据接口三层**（`BaseGenericDataSource` ← `BaseFormDataSource` / `BaseDictDataSource`，含可直用 / 可继承实现类 `DictTableDataSource`）、**命名重构**（`dict_key → data_source_key` 全链收口、插件键 `data_source`、`GET /api/v1/data-sources` 清单），并完成 `form_key → data_source_key` **回填**；`@bms/api-types` 已按新契约**重生成**（零漂移）——本任务可直接消费，无需再生成。

> **协同（已交付，2026-10-12）**：任务 [`02_12`](../02_后端基座_12_数据源注册与通用接口契约/02_后端基座_12_数据源注册与通用接口契约.md) 已交付**契约正式化**——`GET /api/v1/data-sources` 与字典族 5 端点响应收敛为**具名模型**（`DataSourceResponse` / `DictTypeResult` / `DictBatchResult` / `DictAdvQueryResult` 等；**列表统一 `{items:[...]}` 包装**），契约快照 + 基线 + `@bms/api-types` 重生成（零漂移）。**本任务据此对接**：`GET /api/v1/data-sources` 的清单在 `data.items`（`DataSourceResponse[]`，字段 `data_source_key` / `kind` / `strategies` / `allowlist` / `cascade` …）；`frontend/apps/desktop/src/api/permissionMeta.ts` 现仍调用**已移除**的 `GET /dicts`，须改指 `GET /api/v1/data-sources` 并读 `data.items`；`@bms/core` 的 `normalizeAttrs` / `normalizeProviders` 已由 `02_12` 兼容 `{items}` 包装。

> 详细设计（路由解析规则、清单接入、与查询方案 / 用户偏好的联动）见 [13 详细设计 · 前端通用页面路由](设计/13_详细设计_01_前端通用页面路由.md)（2026-10-12 定稿；10 项决策确认）。后端配套端点 `GET /api/v1/form-keys` 作嵌套子任务 [`02-13-1`](02_后端基座_13_前端通用页面路由_01_表单标识清单接口/02_后端基座_13_前端通用页面路由_01_表单标识清单接口.md)。
