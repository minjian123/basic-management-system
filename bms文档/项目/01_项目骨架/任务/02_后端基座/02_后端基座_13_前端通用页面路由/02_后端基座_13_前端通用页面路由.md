## 2. 任务内容 <a id="content"></a>

**口径来源**：《数据库开发规范》§3.1.2——`form_key` 为**表单标识**（界面相关），**供通用页面路由 / 查询方案（`field_key = form_key`）/ 用户偏好（`list.{form_key}`）**引用。

1. **通用页面路由**：按 `form_key` 解析页面 / 表单（表单标识 → 页面），统一挂载与寻址。
2. **数据源清单接入**：`GET /api/v1/data-sources`（`02_12` 契约）驱动前端；`form_key → data_source_key`（多对一）经注册清单解析。
3. **联动**：查询方案（`field_key = form_key`）与用户偏好（`list.{form_key}`）按 `form_key` 联动。
4. **契约类型**：消费 `@bms/api-types`（`02_12` 重生成产物），零漂移。

> **协同（已交付，2026-10-11）**：任务 [`02_11`](../02_后端基座_11_系统字段form_key落表/02_后端基座_11_系统字段form_key落表.md) 已交付 `form_key` 构建期清单（`bms_core/registry/forms.py`）与各字典表 `form_key` 列（**多表联合取数判别列**）；本任务按 `form_key` 解析页面 / 表单，并消费 `form_key → data_source_key`（多对一，由 `02_10` 回填）。

> 详细设计（路由解析规则、清单接入、与查询方案 / 用户偏好的联动）随后续开发窗口另出——本任务**仅立项**。
