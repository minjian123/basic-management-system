## 1. 概述 <a id="overview"></a>

- **目标**：落地文件（对象）存储能力域契约与占位实现——`app/storage/base.py` 的数据契约 `StoredObject` / `PresignedUrl`、存储契约 `BaseObjectStorage`（`put` / `get` / `delete` / `exists` / `presign`）、占位实现 `NullObjectStorage`（固定返回、不连 MinIO / 不落盘）；常量清单 `STORAGE_BUCKET` / `DEFAULT_PRESIGN_TTL` / `NULL_ETAG` / `NULL_PRESIGNED_URL`；`app/api/deps.py` 提供者 `get_object_storage`；`app/main.py` 装配单例。
- **范围**：`app/storage/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-17 登记。
- **不含**（归后续阶段）：真实 MinIO（S3 SDK、私有桶 `bms-files`、预签名 URL 生成、多实例共享）与本地文件系统实现 → **文件管理阶段**；分片上传 / 断点续传状态机、上传下载路由与预览、类型白名单与大小上限、租户存储配额（`storage_bytes`）、孤儿分片回收 → 同阶段；导入导出（openpyxl）→ 导入导出基座 / 阶段（见架构 19「Excel 导入导出」节）；备份与生命周期策略 → 部署与运维阶段。
- **依据**：需求 [02-17](../../../../../需求/02_需求_后端基座.md#r02-17)、《[架构设计 · 文件管理](../../../../../../../设计/架构设计/19_架构设计_子系统_文件管理.md)》「概述」「安全控制」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段落地（地基波 + 回补）」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |
| --- | --- |
| 全库无 `BaseObjectStorage` / `StoredObject` / `PresignedUrl`（检索零命中）；无 `app/storage/` 目录 | 对象存储无统一入口；文件 / 头像 / 导入导出 / 归档各自接 MinIO 会让 key 口径、签名与生命周期发散 |
| 存储技术选型已定案（架构 19：MinIO S3 兼容、私有桶、按租户前缀隔离、预签名 URL 直开、后端不代理文件流） | 无契约承载「写入 / 读取 / 删除 / 是否存在 / 预签名」 |
| 文件安全控制已定案（类型白名单 + 大小上限、SHA256 校验、配额联动、故障告警） | 上述策略为上层（文件管理阶段）职责，本任务只落存储原语契约 |
| `api/deps.py` 已汇总 18 个能力域提供者 | 新能力域无提供者，「依赖注入可解析」无落点 |
| 导入导出（openpyxl）、备份归档等依赖文件存取 | 统一经本契约取对象存储，避免各自实现（回补阶段接入） |

## 4. 文件存储能力域（`app/storage/base.py`） <a id="storage"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `STORAGE_BUCKET` | `str` 常量 | 默认私有桶名 `"bms-files"`（架构 19「安全控制」节；占位期仅登记不校验） |
| `DEFAULT_PRESIGN_TTL` | `int` 常量 | 预签名 URL 默认有效期（秒），默认 `3600`（1 小时） |
| `NULL_ETAG` | `str` 常量 | 占位对象 etag `"null-etag"`（`NullObjectStorage.put` 固定返回） |
| `NULL_PRESIGNED_URL` | `str` 常量 | 占位预签名 URL `"null-presigned-url"`（占位固定返回，便于断言） |
| `StoredObject` | frozen dataclass（数据契约） | 对象元数据：`key: str` / `size: int` / `content_type: str \| None = None` / `etag: str \| None = None` |
| `PresignedUrl` | frozen dataclass（数据契约） | 预签名结果：`url: str` / `expires_in: int` / `method: str = "GET"` |
| `BaseObjectStorage(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "object_storage"` |
| `put(key, data, *, content_type=None) -> StoredObject` | 抽象方法（async） | 写入对象（真实实现落 MinIO 私有桶） |
| `get(key) -> bytes` | 抽象方法（async） | 读取对象内容（未命中抛 `NotFoundError`） |
| `delete(key) -> None` | 抽象方法（async） | 删除对象（幂等，不存在不报错） |
| `exists(key) -> bool` | 抽象方法（async） | 对象是否存在 |
| `presign(key, *, method="GET", expires_in=DEFAULT_PRESIGN_TTL) -> PresignedUrl` | 抽象方法（async） | 生成限时预签名 URL（下载 / 上传直连，后端不代理文件流） |
| `NullObjectStorage(BaseObjectStorage, BaseNullObject)` | 占位实现 | `put` 回显 `StoredObject`（`etag=NULL_ETAG`）、`get` 返回空字节、`delete` 空操作、`exists` 恒 True、`presign` 固定返回（不连 MinIO / 不落盘） |
| `get_object_storage(request) -> BaseObjectStorage` | 模块函数（提供者） | 取应用级单例（`request.app.state.object_storage`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `put` 入参 / 返回 | `put(key, data: bytes, *, content_type=None) -> StoredObject`（回显 key / size / content_type / etag，供上层记录元数据） |
| `get` 未命中 | 抛 `NotFoundError`（10002，全局处理器统一转 404），与仓储统一不存在语义一致 |
| `delete` 语义 | **幂等**（对象不存在也返回成功），不抛错 |
| `exists` 语义 | 只判存在、不取内容；占位恒 True（恒定存在，Null Object「恒定通过」口径） |
| `presign` 返回 | `PresignedUrl`（url / expires_in / method）；默认 `method="GET"`、TTL 取 `DEFAULT_PRESIGN_TTL` |
| key 口径 | 由上层（文件管理阶段）按 `bms:{租户}:files:{业务键}` 约定构造；本契约只做透传，不校验前缀 |
| 安全控制 | 类型白名单、大小上限、SHA256 校验、配额联动属**上层**职责，本契约不实现（架构 19「安全控制」节） |
| 后端不代理流 | 下载 / 预览走预签名 URL 直连对象存储；`get` 供后端内部读取（如校验、解析） |
| 异步口径 | 五入口全异步（真实实现为网络 IO，与 lock / masking / ratelimit 统一） |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_object_storage`（`app/storage/base.py`）；模块 docstring 补「对象存储」 |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（上传 / 下载 / 预览 / 分片路由归文件管理阶段），故无路由与中间件改动。真实 MinIO 实现替换 `NullObjectStorage` 时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseObjectStorage → BaseCapability → BaseObject`；`NullObjectStorage → BaseObjectStorage + BaseNullObject → BasePlaceholder → BaseObject`。
- `StoredObject` / `PresignedUrl` 为能力域数据契约（frozen dataclass，同 `SpanContext` / `OAuthToken` / `HealthCheckResult` 风格）。
- 与 `app/db/`、`app/cache/` 分工：数据库 / 缓存为结构化存储；本域为**非结构化对象存储**（文件字节），三者独立、互不替代。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实对象存储实现**（MinIO S3 SDK / 本地文件系统、私有桶 `bms-files`、按租户前缀隔离、预签名 URL 生成、多实例共享）→ 文件管理阶段；已登记计划「后续阶段待办」。
- **文件上传 / 下载 / 预览路由与分片状态机**（≤20MB 整包 / 超限分片 + 断点续传、`sys_file` 元数据、`file.uploaded` 事件）→ 文件管理阶段。
- **安全控制**（类型白名单 + 大小上限、分片 / 整文件 SHA256 校验、租户存储配额 `storage_bytes`、对象存储故障告警）→ 文件管理阶段 / 多租户路由 / 部署与运维。
- **Excel 导入导出**（openpyxl）→ 导入导出基座（02-4-10）/ 导入导出阶段；经本契约存取上传的模板与导出文件。
- **备份与生命周期策略**（MinIO 增量备份、归档对象）→ 部署与运维阶段；归档文件亦存 MinIO（经本契约）。
- **占位语义已知项**：占位 `get` 返回空字节、`exists` 恒 True（不反映真实存储状态）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实存取用例（写入后读回、预签名 URL 可访问、删除后不存在）随回补阶段补充。
