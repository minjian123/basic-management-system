## 1. 概述 <a id="overview"></a>

- **目标**：落地归档能力域两组契约与占位实现——`app/archive/base.py` 的常量 `ARCHIVE_LOCATIONS`、数据契约 `ArchiveResult`、归档策略契约 `BaseArchivePolicy`（`matches` / `archive`）、查询路由契约 `BaseArchiveQueryRouter`（`resolve`）、占位实现 `NullArchivePolicy`（恒定不归档）与 `NullArchiveQueryRouter`（恒定在线库）；`app/api/deps.py` 提供者 `get_archive_policy` / `get_archive_query_router`；`app/main.py` 装配两单例。
- **范围**：`app/archive/`（新增）、`app/api/deps.py`（两提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-35 登记。
- **不含**（归后续阶段）：真实归档流转（热表超阈值 → 链完整性校验 → 迁归档库 `bms_archive`、在线查询路由、Celery 调度执行、`sys_archive_policy` / `sys_archive_log`）→ **归档管理阶段**；归档冷化（`bms_archive` 按保留期转对象存储冷化 MinIO）、物理清理（过期归档文件与软删除残留）、回收站（软删除查看 / 恢复 / 过期清理）→ 同阶段；哈希链随归档导出与跨归档校验 → 审计哈希链阶段（02-4-11）；归档数据在线查询的只读库访问 → 数据访问与分片。
- **依据**：需求 [02-35](../../../../../需求/02_需求_后端基座.md#r02-35)、《[架构设计 · 数据架构](../../../../../../../设计/架构设计/07_架构设计_数据架构.md)》「数据分布」节、《[架构设计 · 核心交互时序](../../../../../../../设计/架构设计/06_架构设计_核心交互时序.md)》「归档流转」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 归档能力域（`app/archive/base.py`） <a id="archive"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `ARCHIVE_LOCATIONS` | `tuple[str, ...]` 常量 | 数据位置：`("online", "archive")`（在线库 / 归档库 `bms_archive`；占位期仅登记不校验） |
| `ArchiveResult` | frozen dataclass（数据契约） | 归档结果：`matched: int`（命中条数）/ `archived: int`（已归档条数）/ `detail: str \| None = None` |
| `BaseArchivePolicy(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "archive_policy"` |
| `matches(record, *, now=None) -> bool` | 抽象方法（async） | 判断记录是否达归档条件（真实实现按 `sys_archive_policy` 阈值 / 时间窗） |
| `archive(records) -> ArchiveResult` | 抽象方法（async） | 执行归档搬迁（真实实现经链校验后迁 `bms_archive`） |
| `BaseArchiveQueryRouter(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "archive_query_router"` |
| `resolve(*, table) -> str` | 抽象方法（同步） | 解析查询位置（取 `ARCHIVE_LOCATIONS` 之一；真实实现按表 / 数据范围路由在线库或归档库） |
| `NullArchivePolicy(BaseArchivePolicy, BaseNullObject)` | 占位实现 | `matches` 恒 False（不归档）、`archive` 返回空 `ArchiveResult`（**不搬数据**） |
| `NullArchiveQueryRouter(BaseArchiveQueryRouter, BaseNullObject)` | 占位实现 | `resolve` 恒定返回在线库（不路由归档库） |
| `get_archive_policy(request)` / `get_archive_query_router(request)` | 模块函数（提供者） | 取应用级单例（`app.state.archive_policy` / `app.state.archive_query_router`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `matches` 入参 | `record: Mapping[str, object]` + 可选 `now: datetime`（可注入当前时间便于测试；真实实现按策略判断） |
| `archive` 入参 / 返回 | `records: Sequence[Mapping[str, object]]` → `ArchiveResult`（命中 / 已归档条数 + 说明） |
| `resolve` | 关键字 `table`（逻辑表名）→ 位置字符串（`ARCHIVE_LOCATIONS` 之一）；**同步纯决策**，不涉 IO |
| 链校验 | 归档前链完整性校验取 02-4-11 `BaseHashChain.verify`（上层接线）；哈希链随归档导出 |
| 冷化 / 物理清理 | `bms_archive` 按保留期转对象存储冷化（02-4-1）、过期物理清理、回收站归上层（归档管理阶段） |
| 占位语义 | `NullArchivePolicy.matches` 恒 False（不归档）、`archive` 空结果；`NullArchiveQueryRouter.resolve` 恒在线库；不搬数据 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（归档管理接口归归档管理阶段），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseArchivePolicy` / `BaseArchiveQueryRouter → BaseCapability → BaseObject`；两 `Null* → 对应契约 + BaseNullObject → BasePlaceholder → BaseObject`。
- `ArchiveResult` 为能力域数据契约（frozen dataclass，同 `QueryResult` / `ImportResult` 风格）。
- 与数据访问 / 分片分工：`BaseRepository` / 分片路由管在线库读写；本域管**归档策略与在线 / 归档位置路由**，二者配合（归档后查询经本域路由到 `bms_archive`）。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实归档流转**（`sys_archive_policy` → Celery 调度；热表超阈值 → 链校验 → 迁 `bms_archive`；在线查询路由）→ **归档管理阶段**；已登记计划「后续阶段待办」。
- **冷化与物理清理**（`bms_archive` 按保留期转对象存储、过期归档文件与软删除残留清理）、**回收站**（软删除查看 / 恢复 / 过期清理）→ 归档管理阶段。
- **跨归档链校验 / 哈希链随归档导出** → 02-4-11 `BaseHashChain`（任务文档已标前置契约）；归档文件存取 → 02-4-1 `BaseObjectStorage`。
- **归档数据在线查询**（只读 `bms_archive`）→ 数据访问与分片 / 归档管理阶段；路由经本域 `resolve`。
- **占位语义已知项**：占位恒不归档 / 恒在线库（不反映真实归档）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实归档用例（阈值判定、搬迁、在线 / 归档路由、链校验）随回补阶段补充。
