## 1. 概述 <a id="overview"></a>

- **目标**：落地出站集成两组契约与占位实现——`app/outbound/http.py` 的 `HttpResponse` 数据契约、`BaseHttpClient`（统一 `request`，超时 / 重试 / 熔断）、`NullHttpClient`（固定成功响应、不外呼），`app/outbound/webhook.py` 的 `WebhookResult` 数据契约、`BaseWebhookSender`（`send`，签名 / 投递 / 重试）、`NullWebhookSender`（固定投递成功、不外呼）；常量 `DEFAULT_TIMEOUT` / `DEFAULT_MAX_RETRIES`；`app/api/deps.py` 提供者 `get_http_client` / `get_webhook_sender`；`app/main.py` 装配两单例。
- **范围**：`app/outbound/`（新增 `__init__.py` / `http.py` / `webhook.py`）、`app/api/deps.py`（两提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-22 登记。
- **不含**（归后续阶段）：真实 httpx 封装（超时 / 重试 / 熔断接入 `BaseCircuitBreaker` 与 `BaseFallbackPolicy`、连接池、代理）→ **系统集成阶段**；真实 Webhook 投递（签名 `sha256(secret, body)` 经 `SignatureCodec`、指数退避重试、`sys_webhook_log` 失败记录、事件总线异步推送）→ 同阶段；邮件 / 短信（阿里 / 腾讯）→ 通知公告阶段（经 02-4-4 `BaseNotifier`）；企业微信 / 钉钉免登与群机器人 → 系统集成 / 运维阶段。
- **依据**：需求 [02-22](../../../../../需求/02_需求_后端基座.md#r02-22)、《[架构设计 · 接口与集成](../../../../../../../设计/架构设计/09_架构设计_接口与集成.md)》「出站集成」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段落地（地基波 + 回补）」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |
| --- | --- |

## 4. HTTP 出站能力域（`app/outbound/http.py`） <a id="http"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `DEFAULT_TIMEOUT` | `int` 常量 | 默认超时（秒），默认 `10` |
| `DEFAULT_MAX_RETRIES` | `int` 常量 | 默认最大重试次数，默认 `3` |
| `HttpResponse` | frozen dataclass（数据契约） | 响应：`status_code: int` / `headers: Mapping[str, str]` / `content: bytes` |
| `BaseHttpClient(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "http_client"` |
| `request(method, url, *, headers=None, content=None, timeout=None) -> HttpResponse` | 抽象方法（async） | 统一出站请求（超时 / 重试 / 熔断由实现内部处理） |
| `NullHttpClient(BaseHttpClient, BaseNullObject)` | 占位实现 | `request` 固定返回成功响应（`status_code=200`、空头 / 空 body；**不外呼**） |
| `get_http_client(request) -> BaseHttpClient` | 模块函数（提供者） | 取应用级单例（`request.app.state.http_client`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 方法签名 | 统一 `request`（method / url + 可选 headers / content / timeout），不提供 `get` / `post` 分方法（避免重复实现） |
| 超时 / 重试 / 熔断 | 由**实现**内部处理（真实实现接 `BaseCircuitBreaker` / `BaseFallbackPolicy` 与 `DEFAULT_TIMEOUT` / `DEFAULT_MAX_RETRIES`）；契约不暴露重试参数 |
| 返回 | `HttpResponse`（状态码 / 头 / 字节内容）；非 2xx 是否抛错由实现 / 调用方决定，契约不封装业务异常 |
| 占位语义 | `NullHttpClient.request` 固定返回 `200` 空响应（不外呼），便于上层链路验证 |

## 5. Webhook 出站能力域（`app/outbound/webhook.py`） <a id="webhook"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `WebhookResult` | frozen dataclass（数据契约） | 投递结果：`delivered: bool` / `status_code: int \| None = None` / `attempts: int = 1` |
| `BaseWebhookSender(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "webhook_sender"` |
| `send(url, payload, *, secret=None) -> WebhookResult` | 抽象方法（async） | 投递 Webhook（签名 / 重试由实现内部处理） |
| `NullWebhookSender(BaseWebhookSender, BaseNullObject)` | 占位实现 | `send` 固定返回投递成功（`delivered=True`、`status_code=200`、`attempts=1`；**不外呼**） |
| `get_webhook_sender(request) -> BaseWebhookSender` | 模块函数（提供者） | 取应用级单例（`request.app.state.webhook_sender`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 方法签名 | `send(url, payload: Mapping[str, object], *, secret: str \| None = None) -> WebhookResult` |
| 签名口径 | 真实实现按**出站口径** `sha256(secret, body)`（body 为序列化后字节）经 [02-3-10](../../../02_后端基座_03_core横切基座/02_后端基座_03_core横切基座_10_限流幂等防重放中间层/02_后端基座_03_core横切基座_10_限流幂等防重放中间层.md) `SignatureCodec` 计算（与本任务前置契约一致，不另写 HMAC） |
| 重试 / 失败记录 | 指数退避重试与 `sys_webhook_log` 失败记录归上层（系统集成阶段）；契约只返回投递结果（含 `attempts`） |
| 异步推送 | Webhook 经事件总线异步推送（RocketMQ）归上层；本契约提供投递原语 |
| 占位语义 | `NullWebhookSender.send` 固定返回投递成功（不外呼），便于上层链路验证 |

## 6. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_http_client` / `get_webhook_sender`；模块 docstring 补「出站」 |
| `app/main.py` `create_app()` | 装配 `app.state.http_client = NullHttpClient()`、`app.state.webhook_sender = NullWebhookSender()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（出站为内部调用，无 HTTP 入口），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 7. 继承与分层 <a id="base"></a>

- `BaseHttpClient` / `BaseWebhookSender → BaseCapability → BaseObject`；`NullHttpClient` / `NullWebhookSender → 对应契约 + BaseNullObject → BasePlaceholder → BaseObject`。
- `HttpResponse` / `WebhookResult` 为能力域数据契约（frozen dataclass，同 `StoredObject` / `SendResult` 风格）。
- 与通知 / 事件总成分工：通知渠道（02-4-4）管站内信 / 邮件 / 短信；本域管**通用 HTTP 出站与 Webhook 投递**；出站签名复用 `SignatureCodec`、熔断 / 降级复用 02-3-8 基座。

## 12. 边界与开放项 <a id="boundary"></a>

- **真实 httpx 封装**（超时 / 重试 / 熔断接 02-3-8 基座、连接池、代理）→ 系统集成阶段；已登记计划「后续阶段待办」。
