## 1. 概述 <a id="overview"></a>

- **目标**：落地国际化翻译能力域契约与占位实现——`app/i18n/base.py` 的常量 `DEFAULT_LOCALE` / `SUPPORTED_LOCALES`、统一翻译契约 `BaseTranslator`（`translate` / `resolve_locale` / `load_messages`）、占位实现 `NullTranslator`（原样返回 key / 默认 locale / 空语言包）；`app/api/deps.py` 提供者 `get_translator`；`app/main.py` 装配单例。
- **范围**：`app/i18n/base.py`（新增，`app/i18n/__init__.py` 口径同步）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-37 登记。
- **不含**（归后续阶段）：真实语言包（`sys_i18n_message` 取词 + Redis 缓存下发、`sys_i18n_locale` 语言清单动态扩展、Babel 开发期提取）→ **国际化阶段**；业务数据文案 i18n 附表（`{主表}_i18n` 查询与回退）、用户 locale / 时区偏好（`sys_user.locale` / `timezone`）、运行时通知 / 邮件模板多语言、RTL 布局、前后端文案种子 → 国际化 / 前端组件体系 / 通知公告阶段；语言包下发接口（`GET /api/v1/i18n/messages`）→ 国际化阶段。
- **依据**：需求 [02-37](../../../../../需求/02_需求_后端基座.md#r02-37)、《[架构设计 · 国际化](../../../../../../../设计/架构设计/23_架构设计_子系统_国际化.md)》「固定文案语言包」「业务数据文案」「语言与 RTL」「运行时渲染」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段落地（地基波 + 回补）」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 国际化翻译能力域（`app/i18n/base.py`） <a id="i18n"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `DEFAULT_LOCALE` | `str` 常量 | 默认语言 `"zh-CN"`（缺省与回退） |
| `SUPPORTED_LOCALES` | `tuple[str, ...]` 常量 | 种子语言清单 `("zh-CN", "en-US")`（架构「语言与 RTL」节；可由 `sys_i18n_locale` 动态扩展） |
| `BaseTranslator(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "translator"` |
| `translate(key, *, locale=None, params=None) -> str` | 抽象方法（async） | 取词（按 locale 查语言包、缺省回退默认文案） |
| `load_messages(locale) -> Mapping[str, str]` | 抽象方法（async） | 语言包加载（真实实现读 `sys_i18n_message` / Redis 缓存） |
| `resolve_locale(accept_language=None) -> str` | 抽象方法（同步） | 语言解析（`Accept-Language` 驱动；无匹配回退 `DEFAULT_LOCALE`） |
| `NullTranslator(BaseTranslator, BaseNullObject)` | 占位实现 | `translate` 原样返回 key（不翻译 / 不插值）、`resolve_locale` 返 `DEFAULT_LOCALE`、`load_messages` 返空映射 |
| `get_translator(request) -> BaseTranslator` | 模块函数（提供者） | 取应用级单例（`request.app.state.translator`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| key 命名 | `模块.页面.字段`（如 `user.form.username`、`common.confirm`）；错误码文案按 `error.{code}` 映射（上层接线） |
| locale 取值 | 取 `SUPPORTED_LOCALES` 之一或 `sys_i18n_locale` 动态扩展；无匹配回退 `DEFAULT_LOCALE` |
| `translate` | 按 locale 查语言包取词 + 插值 `params`；缺省回退默认文案；未命中回退 key |
| `load_messages` | 返回 `key → 文案` 映射（真实实现读 `sys_i18n_message` / Redis 缓存；前端经接口拉取 + localStorage 二次缓存） |
| `resolve_locale` | 同步纯解析（`Accept-Language` 匹配语言清单），无 IO |
| 同步性 | `translate` / `load_messages` 异步（真实读缓存 / DB），`resolve_locale` 同步（纯解析） |
| 占位语义 | `NullTranslator` 原样返回 key（不翻译）、语言解析取默认、语言包为空 |
| 与 i18n 附表 | 业务数据文案（`{主表}_i18n`）查询与回退归上层；本域只落固定文案取词原语 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_translator`；模块 docstring 补「国际化」 |
| `app/main.py` `create_app()` | 装配 `app.state.translator = NullTranslator()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（语言包下发接口归国际化阶段），故无路由与中间件改动。真实实现替换 `NullTranslator` 时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseTranslator → BaseCapability → BaseObject`；`NullTranslator → BaseTranslator + BaseNullObject → BasePlaceholder → BaseObject`。
- 无新增数据契约（`translate` 返字符串、`load_messages` 返映射），与 `BaseFieldTypeRegistry` 风格一致。
- 与安全 / 错误码分工：`BizError` / `ErrorCode` 管异常与码位；本域管码位 → 文案的取词（上层按 `error.{code}` 取）。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实语言包实现**（`sys_i18n_message` 取词 + Redis 缓存下发、`sys_i18n_locale` 动态扩展、Babel 开发期提取）→ **国际化阶段**；已登记计划「后续阶段待办」。
- **i18n 附表**（`{主表}_i18n` 业务文案查询与回退）、用户 locale / 时区偏好、RTL 布局、前后端文案种子 → 国际化阶段 / 前端组件体系。
- **运行时通知 / 邮件模板多语言** → 通知公告阶段（取本域 + 通知渠道）。
- **错误码文案映射**（`error.{code}`）→ 上层接线；语言包下发接口 → 国际化阶段。
- **占位语义已知项**：占位原样返回 key（不翻译）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实取词 / 语言包用例（按 locale 取词、回退、缓存）随回补阶段补充。
