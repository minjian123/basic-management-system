## 1. 概述 <a id="overview"></a>

- **目标**：落地数据查询提供者能力域契约与占位实现——`app/query/base.py` 的 `QueryResult` 数据契约、提供者契约 `BaseQueryProvider`（`key` + `query`）、注册表契约 `BaseQueryProviderRegistry`（`register` / `get` / `keys` + `query` 聚合模板）、占位实现 `NullQueryProvider`（空结果）与 `NullQueryProviderRegistry`（注册空操作、`query` 固定返回空结果；不执行 SQL）；`app/api/deps.py` 提供者 `get_query_provider_registry`；`app/main.py` 装配单例。
- **范围**：`app/query/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-28 登记。
- **不含**（归后续阶段）：真实数据集查询（`rpt_dataset` SQL 建模、只读从库执行、字段 / 参数、超时与限流、慢查询走查）→ **报表 BI 阶段**；字典高级查询界面与数据（`layout_config` 三级解析、可选字段 / 操作符 / 默认方案 / 结果列）→ **表单定制阶段**；AI 问数 N片段SQL（数据集白名单 + 只读从库 + 安全校验）→ AI 阶段；查询结果缓存 / 分页 / 导出 → 对应阶段。
- **依据**：需求 [02-28](../../../../../需求/02_需求_后端基座.md#r02-28)、《[架构设计 · 报表 BI](../../../../../../../设计/架构设计/23_架构设计_子系统_报表BI.md)》「数据集管理」节、《[架构设计 · 表单定制](../../../../../../../设计/架构设计/30_架构设计_子系统_表单定制.md)》「字典高级查询扩展点」、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段落地（地基波 + 回补）」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 数据查询能力域（`app/query/base.py`） <a id="query"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `QueryResult` | frozen dataclass（数据契约） | 查询结果：`rows: tuple[Mapping[str, object], ...]` / `total: int = 0` |
| `BaseQueryProvider(BaseObject, ABC)` | 提供者契约 | 抽象属性 `key: str` + 抽象异步 `query(params) -> QueryResult`（**只读数据源约束**） |
| `BaseQueryProviderRegistry(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "query_provider_registry"`；抽象 `register` / `get` / `keys` + **具体聚合模板** `query` |
| `register(provider) -> None` | 抽象方法 | 注册查询提供者（启动期注册；同名以 `key` 为键、后注册覆盖由实现决定） |
| `get(key) -> BaseQueryProvider \| None` | 抽象方法 | 按 key 解析提供者（未命中返回 None） |
| `keys() -> tuple[str, ...]` | 抽象方法 | 已注册提供者 key 清单（注册顺序，稳定） |
| `query(key, params) -> QueryResult` | **具体方法**（async 模板） | 固定编排「解析提供者 → 委托查询」；未命中 key 抛 `NotFoundError` |
| `NullQueryProvider(BaseQueryProvider, BaseNullObject)` | 占位提供者 | `key = "null_query_provider"`；`query` 返回空 `QueryResult`（不执行 SQL） |
| `NullQueryProviderRegistry(BaseQueryProviderRegistry, BaseNullObject)` | 占位注册表 | `register` 空操作、`get` 返回 None、`keys` 返回空元组；`query` 固定返回空结果（不抛） |
| `get_query_provider_registry(request) -> BaseQueryProviderRegistry` | 模块函数（提供者） | 取应用级单例（`request.app.state.query_provider_registry`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 提供者身份 | `BaseQueryProvider.key` 为抽象属性（实现按用途取 `"dict:user"` / `"dataset:xxx"` 等）；注册表以 `key` 解析 |
| `query` 入参 | `params: Mapping[str, object]`（查询参数）；提供者只返回结果，不关心调用来源 |
| 只读约束 | 数据集白名单 + 只读从库 + 租户隔离由**实现**保证；契约在 docstring 声明「只读数据源约束」，禁止经此写库 |
| 注册表模板 | `BaseQueryProviderRegistry.query(key, params)` 为**具体模板方法**（解析 → 委托），未命中抛 `NotFoundError`（10002，全局处理器转 404） |
| 占位语义 | `NullQueryProvider.query` 返回空 `QueryResult`；`NullQueryProviderRegistry` 注册空操作、`query` 固定返回空结果（便于上层链路验证，不抛错） |
| 异步口径 | 提供者 `query` 与注册表 `query` 全异步（真实为 DB IO） |
| 与报表 / 表单定制 | 报表数据集与字典高级查询各自注册提供者，前端只做发现与调用（架构 29）；本契约不实现具体数据集 / 字典查询 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_query_provider_registry`；模块 docstring 补「查询」 |
| `app/main.py` `create_app()` | 装配 `app.state.query_provider_registry = NullQueryProviderRegistry()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（数据集 / 高级查询接口归报表 / 表单定制阶段），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseQueryProvider → BaseObject`（查询提供者为可注册组件，非 DI 能力域）；`BaseQueryProviderRegistry → BaseCapability → BaseObject`。
- `NullQueryProvider → BaseQueryProvider + BaseNullObject → BasePlaceholder → BaseObject`；`NullQueryProviderRegistry → BaseQueryProviderRegistry + BaseNullObject → BasePlaceholder → BaseObject`。
- `QueryResult` 为能力域数据契约（frozen dataclass，同 `HealthCheckReport` / `SearchResult` 风格）。
- 与仓储 / 分页分工：仓储（`BaseRepository`）管实体 CRUD；本域管**即席数据集 / 高级查询**扩展点，两者独立。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实数据集查询**（`rpt_dataset` SQL 建模、只读从库执行、字段 / 参数、超时与限流、慢查询走查）→ 报表 BI 阶段；已登记计划「后续阶段待办」。
- **字典高级查询**（`layout_config` 三级解析、可选字段 / 操作符 / 默认方案 / 结果列）→ 表单定制阶段。
- **AI 问数 N片段SQL**（数据集白名单 + 只读从库 + 安全校验）→ AI 阶段（十七）。
- **查询结果缓存 / 分页 / 导出** → 对应阶段（缓存取通用能力阶段、分页取分页契约、导出取导入导出基座）。
- **占位语义已知项**：占位 `query` 固定返回空结果（不反映真实数据）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实数据集 / 字典查询用例（SQL 执行、白名单、租户隔离）随回补阶段补充。
