## 1. 概述 <a id="overview"></a>

- **目标**：落地表单字段类型能力域契约与占位实现——`app/fieldtype/base.py` 的方言常量 `COLUMN_TYPE_DIALECTS` / `NULL_COLUMN_TYPE`、字段类型提供者契约 `BaseFieldType`（`validate` / `render_metadata` / `column_type`）、注册表契约 `BaseFieldTypeRegistry`（`register` / `get` / `keys` + `validate` / `column_type` 聚合模板）、占位实现 `NullFieldTypeRegistry`（恒定通过 / 固定映射）；`app/api/deps.py` 提供者 `get_field_type_registry`；`app/main.py` 装配单例。
- **范围**：`app/fieldtype/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-36 登记。
- **不含**（归后续阶段）：真实字段类型实现（各类型校验 / 渲染元数据 / 四库类型映射，`sys_field_ext` 自建字段）→ **表单定制阶段**；动态 DDL（`ALTER TABLE ADD COLUMN ext_{field_key}`、停用不删列 / 重建复用、四库类型映射执行、分片表禁自建字段）→ 同阶段 + 数据访问与分片；服务端动态校验接入（必填 / 范围 / 正则 / 选项集，前置校验在请求模型层）→ 同阶段；布局驱动渲染器组件映射 → 前端组件体系 / 表单定制阶段。
- **依据**：需求 [02-36](../../../../../需求/02_需求_后端基座.md#r02-36)、《[架构设计 · 表单定制](../../../../../../../设计/架构设计/30_架构设计_子系统_表单定制.md)》「字段扩展机制（动态 DDL）」「服务端动态校验」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |

| `api/deps.py` 已汇总 35 个能力域提供者 | 新能力域无提供者，「依赖注入可解析」无落点 |

## 4. 表单字段类型能力域（`app/fieldtype/base.py`） <a id="fieldtype"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `COLUMN_TYPE_DIALECTS` | `tuple[str, ...]` 常量 | 方言清单：`("mysql", "postgresql", "dm", "sqlite")`（四库；占位期仅登记不校验） |
| `NULL_COLUMN_TYPE` | `str` 常量 | 占位列类型 `"varchar(255)"`（`NullFieldTypeRegistry.column_type` 固定返回） |
| `BaseFieldType(BaseObject, ABC)` | 字段类型提供者契约 | 抽象属性 `key: str` + 同步 `validate` / `render_metadata` / `column_type` |
| `validate(value, *, options=None) -> tuple[str, ...]` | 抽象方法（同步） | 校验字段值，返回违规原因元组（空元组通过） |
| `render_metadata() -> Mapping[str, object]` | 抽象方法（同步） | 渲染元数据（组件名 / 属性），供前端按字段类型映射组件 |
| `column_type(dialect) -> str` | 抽象方法（同步） | 按方言返回物理列类型（四库类型映射） |
| `BaseFieldTypeRegistry(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "field_type_registry"` |
| `register(provider) -> None` / `get(key) -> BaseFieldType \| None` / `keys() -> tuple[str, ...]` | 抽象方法 | 注册 / 解析 / 清单 |
| `validate(field_type, value, *, options=None) -> tuple[str, ...]` | **具体方法**（同步模板） | 解析字段类型 → 委托校验；未命中抛 `NotFoundError` |
| `column_type(field_type, dialect) -> str` | **具体方法**（同步模板） | 解析字段类型 → 委托类型映射；未命中抛 `NotFoundError` |
| `NullFieldTypeRegistry(BaseFieldTypeRegistry, BaseNullObject)` | 占位实现 | 注册空操作、`get` None、`keys` 空；`validate` 恒空违规（恒定通过）、`column_type` 固定返回 `NULL_COLUMN_TYPE`（不映射） |
| `get_field_type_registry(request) -> BaseFieldTypeRegistry` | 模块函数（提供者） | 取应用级单例（`request.app.state.field_type_registry`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 字段类型身份 | `BaseFieldType.key` 为抽象属性（实现按类型取 `"text"` / `"number"` / `"date"` / `"select"` 等）；注册表以 `key` 解析 |
| `validate` | 同步纯计算校验，返回违规原因元组（空组通过）；**服务端动态校验**（必填 / 范围 / 正则 / 选项集）按类型实现 |
| `render_metadata` | 渲染元数据（组件名 / 属性），供布局驱动渲染器按 `type` 映射组件（前端组件体系） |
| `column_type` | 按 `dialect`（四库）返回物理列类型；`BaseModel` 四库映射负责公共字段，本域负责**自建字段类型**级映射 |
| 注册表模板 | `validate` / `column_type` 为**具体模板**（解析 → 委托），未命中抛 `NotFoundError`（10002，全局处理器转 404） |
| 占位语义 | `NullFieldTypeRegistry` 注册空操作、`validate` 恒空违规（恒定通过）、`column_type` 固定返回 `NULL_COLUMN_TYPE`；不校验 / 不映射 |
| 同步性 | 三方法及两模板全同步纯计算（真实亦为纯计算；DDL 执行 / 落库归上层） |
| 与动态 DDL | 动态 DDL（`ALTER TABLE ADD COLUMN ext_*`、停用不删列）归上层（表单定制阶段 + 数据访问与分片）；本域只提供类型校验与列类型映射 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_field_type_registry`；模块 docstring 补「字段类型」 |
| `app/main.py` `create_app()` | 装配 `app.state.field_type_registry = NullFieldTypeRegistry()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（表单定制管理接口归表单定制阶段），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseFieldType → BaseObject`（字段类型为可注册组件，非 DI 能力域）；`BaseFieldTypeRegistry → BaseCapability → BaseObject`。
- `NullFieldTypeRegistry → BaseFieldTypeRegistry + BaseNullObject → BasePlaceholder → BaseObject`。
- 无新增数据契约（`render_metadata` / 违规元组用标准容器类型），与 `BaseHealthCheckRegistry` 风格一致。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实字段类型实现**（各类型校验 / 渲染元数据 / 四库类型映射）→ **表单定制阶段**；已登记计划「后续阶段待办」。
