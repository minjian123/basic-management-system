## 1. 概述 <a id="overview"></a>

- **目标**：落地审计哈希链能力域契约与占位实现——`app/audit/hashchain.py` 的常量 `GENESIS_HASH` / `HASH_ALGORITHM`、数据契约 `HashChainEntry` / `ChainVerifyResult`、哈希链契约 `BaseHashChain`（`compute` / `verify`）、占位实现 `NullHashChain`（固定返回 / 恒定通过）；`app/api/deps.py` 提供者 `get_hash_chain`；`app/main.py` 装配单例。
- **范围**：`app/audit/hashchain.py`（新增，复用既有 `app/audit/` 域）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-34 登记。
- **不含**（归后续阶段）：真实哈希链计算（`SHA256(prev_hash + 规范化记录内容)`、分片表内成链、跨月表首尾衔接、链头 `prev_hash` 取上月末条）→ **审计哈希链阶段**；审计捕获（ORM 事件字段级变更 `sys_data_audit_log`、操作日志、登录日志）与分区有序消费（RocketMQ 分区键 = 租户）→ 同阶段；链校验巡检（内置任务 + 归档前强制校验 + 告警）、留存与销毁（90 天热表 + 两段式归档）、审计日志按月索引（`bms-log-*`）→ 同阶段 / 可观测性 / 归档阶段。
- **依据**：需求 [02-34](../../../../../需求/02_需求_后端基座.md#r02-34)、《[架构设计 · 审计哈希链](../../../../../../../设计/架构设计/19_架构设计_子系统_审计哈希链.md)》「审计捕获」「哈希链构造」「校验与巡检」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 审计哈希链能力域（`app/audit/hashchain.py`） <a id="hashchain"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `GENESIS_HASH` | `str` 常量 | 首月链头约定初始值（64 位零 hex；首条记录 `prev_hash`） |
| `HASH_ALGORITHM` | `str` 常量 | 哈希算法 `"sha256"` |
| `HashChainEntry` | frozen dataclass（数据契约） | 链上一条记录：`prev_hash: str` / `record: Mapping[str, object]` / `record_hash: str` |
| `ChainVerifyResult` | frozen dataclass（数据契约） | 链校验结果：`valid: bool` / `broken_index: int \| None = None`（断裂位置） |
| `BaseHashChain(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "hash_chain"` |
| `compute(prev_hash, record) -> str` | 抽象方法（同步） | 计算单条 `record_hash`（真实实现 `SHA256(prev_hash + 规范化记录内容)`） |
| `verify(entries) -> ChainVerifyResult` | 抽象方法（同步） | 逐条重算校验链完整性，定位断裂 |
| `NullHashChain(BaseHashChain, BaseNullObject)` | 占位实现 | `compute` 固定返回占位哈希、`verify` 恒定通过（**不计算**） |
| `get_hash_chain(request) -> BaseHashChain` | 模块函数（提供者） | 取应用级单例（`request.app.state.hash_chain`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `compute` | 入参 `prev_hash: str` + `record: Mapping[str, object]`（规范化后拼接）；返回 `record_hash`；**同步纯计算**（无 IO，与 `BasePermissionChecker.check` 同类） |
| `verify` | 入参 `entries: Sequence[HashChainEntry]`（分片内成链的记录序列）；逐条重算比对 `prev_hash` / `record_hash`，返回 `ChainVerifyResult`（首条不匹配或中间断裂 → `valid=False` + `broken_index`） |
| 链接口径 | `record_hash = SHA256(prev_hash + 规范化记录内容)`；`prev_hash` 取当前分片表末条；跨月首条 `prev_hash` = 上月末条；首月首条 = `GENESIS_HASH`（归实现） |
| 同步性 | 两方法同步纯计算（真实实现亦为纯计算；跨分片巡检 / 归档前校验的 IO 编排归上层） |
| 占位语义 | `compute` 固定返回占位哈希、`verify` 恒定通过（不计算），便于上层链路验证 |
| 与审计捕获 | `app/audit/base.py` 的 `AuditCapturer` 管**捕获**（字段级变更 → 审计事件）；本域管**链计算与校验**，二者配合（捕获后计算哈希落库） |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_hash_chain`；模块 docstring 补「审计哈希链」 |
| `app/main.py` `create_app()` | 装配 `app.state.hash_chain = NullHashChain()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（审计 / 校验接口归审计哈希链阶段），故无路由与中间件改动。真实实现替换 `NullHashChain` 时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseHashChain → BaseCapability → BaseObject`；`NullHashChain → BaseHashChain + BaseNullObject → BasePlaceholder → BaseObject`。
- `HashChainEntry` / `ChainVerifyResult` 为能力域数据契约（frozen dataclass，同 `FieldChange` / `QueryResult` 风格）。
- 与既有 `AuditCapturer`（`app/audit/base.py`）同域协作：捕获（变更 → 事件）与链计算（prev + 记录 → hash）分层，不重复。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实哈希链计算**（`SHA256(prev_hash + 规范化记录)`、分片内成链、跨月首尾衔接、链头取上月末条）→ **审计哈希链阶段**；已登记计划「后续阶段待办」。
- **审计捕获与有序消费**（ORM 事件字段级变更 `sys_data_audit_log`、操作 / 登录日志、RocketMQ 分区有序消费）→ 审计哈希链阶段 / 事件总线。
- **链校验巡检与归档前强制校验、留存销毁**（90 天热表 + 两段式归档）→ 审计哈希链阶段 / 归档阶段 / 任务调度。
- **审计日志按月索引**（`bms-log-*`）→ 02-4-3 `BaseSearchIndex`（任务文档已标前置契约）。
- **占位语义已知项**：占位 `compute` 返回固定哈希、`verify` 恒定通过（不反映真实链）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实哈希链用例（逐条计算、跨月衔接、篡改定位）随回补阶段补充。
