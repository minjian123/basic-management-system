## 1. 概述 <a id="overview"></a>

- **目标**：落地实时推送能力域契约与占位实现——`app/ws/base.py` 的事件常量 `REALTIME_EVENTS`、数据契约 `RealtimeEvent`、统一推送契约 `BaseRealtimePublisher`（`emit` / `join` / `leave`）、占位实现 `NullRealtimePublisher`（三方法空操作；不连 Socket.IO / Redis）；`app/api/deps.py` 提供者 `get_realtime_publisher`；`app/main.py` 装配单例。
- **范围**：`app/ws/`（新增 `base.py`，`__init__.py` 口径同步）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-21 登记。
- **不含**（归后续阶段）：真实 python-socketio 服务端（ASGI 应用挂载、握手鉴权 token、连接确认）→ **实时推送阶段**；连接注册表（Redis `user_id → [{session_id, sid}]`、断线清理）、RedisManager 跨实例广播、nginx 亲和、事件路由消费（`approval.todo` / `notification.new` / `session.revoked` 触发）、断线恢复补偿、Socket.IO 连接数指标 → 同阶段；原生 WebSocket 明确不采用（统一 Socket.IO，架构 17）。
- **依据**：需求 [02-21](../../../../../需求/02_需求_后端基座.md#r02-21)、《[架构设计 · 实时推送](../../../../../../../设计/架构设计/18_架构设计_子系统_实时推送.md)》「握手与鉴权」「连接注册」「跨实例广播」「事件路由」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 实时推送能力域（`app/ws/base.py`） <a id="realtime"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `REALTIME_EVENTS` | `tuple[str, ...]` 常量 | 事件清单：`("approval.todo", "notification.new", "session.revoked")`（架构 17「事件路由」节；占位期**仅登记不校验**） |
| `RealtimeEvent` | frozen dataclass（数据契约） | 推送事件：`event: str` / `data: Mapping[str, object]` / `user_id: str \| None = None` / `session_id: str \| None = None` / `room: str \| None = None` |
| `BaseRealtimePublisher(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "realtime_publisher"` |
| `emit(event) -> None` | 抽象方法（async） | 发送事件到目标（用户 / 会话 / 房间，按事件字段选择；任一实例可推送任意用户） |
| `join(session_id, room) -> None` | 抽象方法（async） | 连接加入房间（Socket.IO 服务端 `join`） |
| `leave(session_id, room) -> None` | 抽象方法（async） | 连接离开房间（Socket.IO 服务端 `leave`） |
| `NullRealtimePublisher(BaseRealtimePublisher, BaseNullObject)` | 占位实现 | 三方法空操作（**不连 Socket.IO / Redis**） |
| `get_realtime_publisher(request) -> BaseRealtimePublisher` | 模块函数（提供者） | 取应用级单例（`request.app.state.realtime_publisher`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 事件命名 | 服务端事件按域命名（`领域.动作`，架构 17）；占位期仅登记 `REALTIME_EVENTS`、不校验 |
| 目标选择 | `RealtimeEvent` 携带 `user_id`（推给某用户全部连接）/ `session_id`（某会话全部连接）/ `room`（房间内全部连接）；三者由调用方按场景指定，实现据此路由 |
| `data` 载荷 | `Mapping[str, object]`（事件参数，随事件语义）；占位不校验 |
| `join` / `leave` | 按会话 / 连接加入或离开房间（Socket.IO 服务端语义）；房间命名由上层按 `bms:{租户}:{域}:{键}` 约定构造，本契约只透传 |
| 异步口径 | 三方法全异步（真实为 Redis 广播 / 连接 IO） |
| 跨实例 | 真实实现经 RedisManager 适配器广播——发送目标 → 目标连接所在实例 → 向 sid 推送；本契约不暴露实例细节 |
| 握手鉴权 / 连接注册 / 断线恢复 | 归实时推送阶段上层；本契约不实现（只落推送原语） |
| 与通知 / 工作流分工 | 站内信落库后触发 `notification.new`、审批待办触发 `approval.todo`、踢出广播 `session.revoked` 均为上层接线（通知公告 / 工作流 / 认证阶段），经本契约发送 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_realtime_publisher`（`app/ws/base.py`）；模块 docstring 补「实时推送」 |
| `app/main.py` `create_app()` | 装配 `app.state.realtime_publisher = NullRealtimePublisher()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不挂载 Socket.IO ASGI 应用 / 不落路由**（socket.io 服务端与握手鉴权归实时推送阶段），故无路由与中间件改动。真实实现替换 `NullRealtimePublisher` 时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseRealtimePublisher → BaseCapability → BaseObject`；`NullRealtimePublisher → BaseRealtimePublisher + BaseNullObject → BasePlaceholder → BaseObject`。
- `RealtimeEvent` 为能力域数据契约（frozen dataclass，同 `SearchQuery` / `NotificationMessage` 风格）。
- 与通知 / 事件总成分工：事件总线负责**服务端解耦的事件流转**（RocketMQ）；本域负责**向已连接客户端实时推送**（Socket.IO）；站内信落库后由上层桥接二者。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实 python-socketio 服务端**（ASGI 挂载、握手校验 access token、连接确认）→ 实时推送阶段；已登记计划「后续阶段待办」。
- **连接注册与跨实例广播**（Redis `user_id → [{session_id, sid}]`、断线清理、RedisManager 适配器、nginx 亲和）→ 实时推送阶段。
- **事件路由消费**（`approval.todo` / `notification.new` / `session.revoked` 触发）→ 通知公告 / 工作流 / 认证阶段接线；事件名已登记 `REALTIME_EVENTS`。
- **断线恢复补偿**（重连后拉取未读数 / 待办数）→ 前端 + 通知公告阶段。
- **Socket.IO 连接数指标**（`bms_ws_connections`，已登记 `METRIC_NAMES`）→ 可观测性 / 实时推送阶段。
- **占位语义已知项**：占位三方法空操作（不反映真实推送）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实推送用例（握手鉴权、用户 / 会话 / 房间路由、跨实例广播、踢出关闭连接）随回补阶段补充。
