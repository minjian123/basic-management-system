## 2. 任务内容 <a id="content"></a>

1. 按需求 02-27 落「IdP与会话存储扩展基座」的统一接口 / 抽象 + 占位实现（纳入能力域中间层基座，依赖注入可解析）
2. 登记：平台《后端基类清单》「跨阶段基座」节
3. 真实实现随对应阶段回补（同一任务文档，不重复立项；实现期要点见[需求 02-27](../../../../需求/02_需求_后端基座.md#r02-27)）
4. **协同契约（边界口径）**：本任务为**客户端侧**（BMS 作为客户端接外部 IdP / 会话存储，`BaseIdentityProvider` / `BaseSessionStore`）；BMS **兼作服务端**（对外 OIDC Provider / Client Credentials 签发与 scope 校验）归 [02-3-13 开放接口 OAuth2 服务端与 scope 基座](../../02_后端基座_03_core横切基座/02_后端基座_03_core横切基座_13_开放接口OAuth2服务端与scope基座/02_后端基座_03_core横切基座_13_开放接口OAuth2服务端与scope基座.md)（2026-09-14 交付契约与占位，`BaseOAuthServer` / `BaseScopeChecker`），两侧不重复建设同一 IdP 逻辑
5. **前置契约（已交付）**：对接外部 IdP（Keycloak / AD / Authing、企业微信 / 钉钉）的 HTTP 调用取 [02-4-6 出站集成基座](../02_后端基座_04_跨阶段基座_06_出站集成基座/02_后端基座_04_跨阶段基座_06_出站集成基座.md)（2026-09-14 交付）的 `BaseHttpClient`（`request`，超时 / 重试 / 熔断由实现内部处理），本任务不另建 httpx 调用
