## 1. 概述 <a id="overview"></a>

- **目标**：落地身份源与会话存储两组契约与占位实现——`app/idp/base.py` 的协议常量 `IDP_PROTOCOLS`、数据契约 `IdentityToken` / `IdentityUser`、身份源契约 `BaseIdentityProvider`（`authorize` / `exchange_token` / `userinfo`）、占位实现 `NullIdentityProvider`（固定返回、不连外部 IdP）；`app/session/base.py` 的 `DEFAULT_SESSION_TTL`、会话存储契约 `BaseSessionStore`（`save` / `load` / `delete`）、占位实现 `NullSessionStore`（写 / 删空操作、`load` 返回占位会话、不连 Redis）；`app/api/deps.py` 两提供者；`app/main.py` 装配两单例。
- **范围**：`app/idp/`、`app/session/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-27 登记。
- **不含**（归后续阶段）：真实多身份源适配（authlib OIDC / CAS、企业微信 / 钉钉免登、JIT 自动建号 + `sys_user_identity` 映射）→ **认证阶段**；真实会话存储（`sys_session` 持久层 + Redis 运行时标记 `bms:{租户}:sess:{session_id}`、强制踢出、多端会话上限）→ 同阶段；双 token（access / refresh）签发与轮换 → 架构 13 §2 / 认证阶段；登录 / SSO 回调路由与会话中间件 → 认证阶段；服务端 OIDC Provider / Client Credentials → 02-3-13。
- **依据**：需求 [02-27](../../../../../需求/02_需求_后端基座.md#r02-27)、《[架构设计 · 认证与会话](../../../../../../../设计/架构设计/14_架构设计_子系统_认证与会话.md)》「SSO 集成」「会话管理」「双 token 模型」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 身份源能力域（`app/idp/base.py`） <a id="idp"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `IDP_PROTOCOLS` | `tuple[str, ...]` 常量 | 协议清单：`("oidc", "cas", "wecom", "dingtalk")`（占位期**仅登记不校验**） |
| `IdentityToken` | frozen dataclass（数据契约） | 身份源令牌：`access_token: str` / `token_type: str = "Bearer"` / `expires_in: int = 0` |
| `IdentityUser` | frozen dataclass（数据契约） | 身份源用户：`subject: str`（外部唯一标识）/ `username: str` / `email: str \| None = None` / `tenant: str \| None = None` |
| `BaseIdentityProvider(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "identity_provider"` |
| `authorize(state) -> str` | 抽象方法（async） | 构造 / 返回授权入口 URL（携带 `state` 防 CSRF） |
| `exchange_token(code) -> IdentityToken` | 抽象方法（async） | 用授权码换取令牌（真实实现经 02-4-6 `BaseHttpClient` 调 token 端点） |
| `userinfo(access_token) -> IdentityUser` | 抽象方法（async） | 拉取用户信息（真实实现经 02-4-6 `BaseHttpClient` 调 userinfo 端点） |
| `NullIdentityProvider(BaseIdentityProvider, BaseNullObject)` | 占位实现 | 三方法固定返回（占位授权 URL / 占位令牌 / 占位用户；**不连外部 IdP**） |
| `get_identity_provider(request) -> BaseIdentityProvider` | 模块函数（提供者） | 取应用级单例（`request.app.state.identity_provider`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `authorize` | 返回授权入口 URL 字符串；`state` 由调用方生成并持有，用于回调校验（防 CSRF），本契约只透传 |
| `exchange_token` | 以授权码换令牌，返回 `IdentityToken`；真实实现按协议调 token 端点（经 `BaseHttpClient`） |
| `userinfo` | 以 access token 拉取用户信息，返回 `IdentityUser`；`subject` 为外部唯一标识（供 `sys_user_identity` 映射 / JIT 建号） |
| 协议 | 取值见 `IDP_PROTOCOLS`（OIDC / CAS / 企业微信 / 钉钉）；占位不校验 |
| 占位语义 | `authorize` 返回占位 URL、`exchange_token` 返回占位令牌、`userinfo` 返回占位用户；不连外部 IdP |

## 5. 会话存储能力域（`app/session/base.py`） <a id="session"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `DEFAULT_SESSION_TTL` | `int` 常量 | 默认会话 TTL（秒），默认 `1209600`（14 天，与 refresh token 对齐） |
| `BaseSessionStore(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "session_store"` |
| `save(session_id, payload, *, ttl) -> None` | 抽象方法（async） | 写入 / 覆盖会话（真实实现落 `sys_session` + Redis 标记） |
| `load(session_id) -> Mapping \| None` | 抽象方法（async） | 读取会话（不存在返回 None） |
| `delete(session_id) -> None` | 抽象方法（async） | 删除会话（幂等，不存在不报错） |
| `NullSessionStore(BaseSessionStore, BaseNullObject)` | 占位实现 | `save` / `delete` 空操作、`load` 返回占位会话（**不连 Redis**） |
| `get_session_store(request) -> BaseSessionStore` | 模块函数（提供者） | 取应用级单例（`request.app.state.session_store`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 会话标识 | `session_id` 字符串（对应架构 13 的会话 id；真实 key `bms:{租户}:sess:{session_id}` 由实现拼接） |
| 载荷 | `payload: Mapping[str, object]`（会话数据，如用户 / 设备 / 生效信息）；契约不约束字段 |
| TTL | `save` 带 TTL（默认 `DEFAULT_SESSION_TTL`），真实实现写入 Redis 过期时间 |
| `load` 未命中 | 返回 `None`（与「会话不存在 = 已踢出 / 登出」语义一致） |
| 占位语义 | `save` / `delete` 空操作；`load` **固定返回占位会话**（`{"session_id": session_id}`），便于上层链路验证；不连 Redis |
| 与会话管理 | 强制踢出、多端会话上限、`sys_session` 持久化为上层（认证阶段），本契约只落会话存取原语 |

## 7. 继承与分层 <a id="base"></a>

- `BaseIdentityProvider` / `BaseSessionStore → BaseCapability → BaseObject`；两 `Null* → 对应契约 + BaseNullObject → BasePlaceholder → BaseObject`。
- `IdentityToken` / `IdentityUser` 为能力域数据契约（frozen dataclass，同 `OAuthToken` / `HealthCheckResult` 风格）。
- 与 02-3-13 分工：本任务为**客户端侧**（BMS 接外部 IdP / 会话存储）；`app/oauth`（02-3-13）为**服务端侧**（BMS 对外签发 / scope 校验），两侧不重叠。

## 12. 边界与开放项 <a id="boundary"></a>

- **真实多身份源适配**（authlib OIDC / CAS、企业微信 / 钉钉免登、JIT 自动建号 + `sys_user_identity`）→ 认证阶段；已登记计划「后续阶段待办」。
- **真实会话存储**（`sys_session` 持久层 + Redis `bms:{租户}:sess:{session_id}`、强制踢出、多端会话上限）→ 认证阶段。
- **双 token**（access / refresh 签发与轮换、黑名单）→ 认证阶段（架构 13 §2）。
- **登录 / SSO 回调路由与会话中间件**、IdP 配置管理（`sys_identity_provider`）→ 认证阶段。
- **服务端 OIDC Provider / Client Credentials** → 02-3-13（`BaseOAuthServer` / `BaseScopeChecker`），客户端侧不重复。
- **占位语义已知项**：占位 `load` 恒返回占位会话（不反映真实会话）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实身份源 / 会话用例（授权回调、换取令牌、建号映射、会话踢出）随回补阶段补充。
