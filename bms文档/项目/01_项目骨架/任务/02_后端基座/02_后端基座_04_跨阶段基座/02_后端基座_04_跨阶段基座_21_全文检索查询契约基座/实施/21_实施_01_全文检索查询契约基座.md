结果小结：新建独立能力域 `app/globalsearch/`——多域聚合检索契约 `BaseGlobalSearch`（`domains()` 可检索域并集 + `search` 多域分组）、审计日志检索契约 `BaseAuditSearch`（`audit_logs`，时间范围必填）、文件内容检索契约 `BaseFileContentSearch`（`file_content`）；三空实现（空结果 + 降级标记）；数据契约（分组 / 审计 / 文件三类结果，均含降级三字段）；检索错误码 `10101`~`10107`；占位路由 `/api/v1/search` 基于 02-6-1 路由基座统一挂载；应用可启动、提供者可解析；`pytest` / `ruff` / `pyright` 全绿，新增模块覆盖率 100%。

## 3. 实施过程 <a id="process"></a>

1. **能力域契约与数据契约**：新增 `app/globalsearch/base.py`——常量（`GLOBAL_SEARCH_DOMAINS` / `DEGRADE_REASONS` / `NULL_DEGRADE_REASON` / `NULL_SEARCH_ALTERNATIVE` / `DEFAULT_GLOBAL_SEARCH_SIZE` / `GLOBAL_SEARCH_MAX_PAGE`）；数据契约 `GlobalSearchHit` / `GlobalSearchGroup` / `GlobalSearchResult`（多域分组）、`AuditLogHit` / `AuditSearchResult`、`FileContentHit` / `FileContentSearchResult`（均 `BaseSchema`，含降级三字段）；三契约（`key = plugin_key` 分别 `global_search` / `audit_search` / `file_content_search`）与三提供者 `get_global_search` / `get_audit_search` / `get_file_content_search`。
2. **契约口径**：可检索域按权限并集（`domains()`）；租户隔离 + 动作级数据范围由实现强制注入、契约不显式传参、调用方不可绕过；结果只返业务标识与高亮（详情回查库）；引擎不可用 / 超时 / 降级兜底返回 `degraded` / `degrade_reason` / `alternative`；审计时间范围必填（≤ 31 天）。
3. **空实现**：新增 `app/globalsearch/null.py`——`NullGlobalSearch`（`domains` 空、`search` 空分组 + 降级）/ `NullAuditSearch` / `NullFileContentSearch`（空结果 + 降级）。
4. **错误码登记**：`app/core/error_codes.py` 增 `10101`~`10107`（检索不可用 / 超时 / 降级中 / 索引未就绪 / 重建进行中 / 文件不可检索 / 时间范围超限）。
5. **装配与依赖注入**：`app/core/config.py` 增三检索分区；`app/core/assembly.py` 增 `app.globalsearch.null` 与三条 `PluginWiring`；`app/api/deps.py` 导出三提供者。
6. **占位路由**：新增 `app/api/search.py`（`BaseRouter`，`prefix="/search"`，`Depends(require_auth)`）——`GET /search/global`（`q` / `types` 多值 / `page` / `size`，限深 ≤ 100）、`GET /search/logs`（`q` / `log_type` / `start_time` / `end_time` / 分页）、`GET /search/files`（`q` / `file_type` / 分页）；`app/api/router.py` 登记。
7. **测试**：新增 `tests/globalsearch/test_global_search.py`（7 条，含内存多域 / 审计 / 文件实现），Kiwi 821。
8. **前置契约适配**（消费方）：`tests/api/test_router_base.py` 登记表键补 `search`；`tests/crosscut/test_plugin_registration.py::_EXPECTED_PLUGIN_KEYS` 补三个能力键。
9. **Kiwi 登记**：已在 mjbk Kiwi TCMS（分类「平台骨架」、P2、CONFIRMED、标签「自动化」）登记用例 **821「02-4-21 全文检索查询契约基座：多域 / 审计 / 文件三契约与降级断言」**（2026-09-20），与 `@pytest.mark.kiwi_id(821)` 一致。
10. **登记回写**：架构 09「公共约定」「错误码分段」/ 25「查询路径」「降级策略」、《后端基类清单》§9 / §10 / 目录、《后端开发规范》§3.1、计划 §3 / §3.1、需求 02-48 注块、任务 / 父任务状态回写。

## 6. 偏差与遗留 <a id="deviations"></a>

- **偏差**：任务原写「在 `02-19` 之上扩展多域检索契约」、基类清单原写「扩展 `02-19` 检索域」，经逐项确认改为**新建独立能力域 `app/globalsearch/`**（三契约并行、空实现与装配一次到位）；架构 25、《后端基类清单》§9 / §10 已按新落点登记。
- **偏差**：需求未点名 `domains()` 与错误码，经确认**增补** `BaseGlobalSearch.domains()`（权限并集）与检索错误码 `10101`~`10107`（登记于 `core/error_codes.py` 与架构 09）。
- **遗留归口（已登记，随对应阶段销项）**：
  - 真实 ES 索引 / 查询 DSL / 高亮 / 多域聚合 / 权限并集过滤 / 租户与数据范围强制注入 → **全文检索阶段（十六）**；已登记计划 §3.1「全文检索真实实现」行。
  - 审计日志跨月多索引路由与时间范围校验（≤ 31 天，`10107`）→ **全文检索阶段**。
  - 文件内容解析 / 重新解析与不可检索标记（`10106`）→ 全文检索阶段（解析）+ 文件管理阶段（重解析入口）。
  - 降级兜底（数据库模糊查询）与恢复重放重建 → **全文检索阶段**；本任务只固化降级字段与错误码。
  - 限深 / 限流 / 超时快速失败 → **全文检索阶段**（占位不校验）。
  - 权限码 `log:query` / `file:query` 与动作级数据范围 → **RBAC 阶段**；登录态真实鉴权 → **认证阶段**（`require_auth` 占位）。
- **处理偏差与遗留（2026-09-20 闭环）**：计划 §3.1「全文检索真实实现」行补查询契约已就位说明；需求 02-48 `> 注：` 块补实现期要点；消费方（全文检索 / 文件管理 / RBAC / 认证阶段）已在计划与需求注块登记去向。
- **结论**：本任务遗留已全部登记去向，偏差与遗留处理完成。
