## 1. 概述 <a id="overview"></a>

- **目标**：落地导入导出两组契约与占位实现——`app/transfer/base.py` 的共享列定义契约 `ColumnSpec`、`app/transfer/importer.py` 的 `RowError` / `ImportResult` 数据契约、导入契约 `BaseImporter`（`parse` / `validate`）、占位实现 `NullImporter`（空结果、不读写文件）、`app/transfer/exporter.py` 的导出契约 `BaseExporter`（`export`，流式写出）、占位实现 `NullExporter`（空流、不读写文件）；`app/api/deps.py` 提供者 `get_importer` / `get_exporter`；`app/main.py` 装配两单例。
- **范围**：`app/transfer/`（新增 `__init__.py` / `base.py` / `importer.py` / `exporter.py`）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-33 登记。
- **不含**（归后续阶段）：真实 openpyxl 导入导出（模板下载、上传解析、校验预览、批量入库幂等、导出含脱敏字段掩码、大数据量分页流式拉取）→ **通用能力阶段**；导入导出路由与前端交互 → 同阶段；模板 / 结果文件存取 → 02-4-1 `BaseObjectStorage`（任务文档已标前置契约）；导出脱敏 → 02-3-5 `BaseMasker`（性能与安全阶段）。
- **依据**：需求 [02-33](../../../../../需求/02_需求_后端基座.md#r02-33)、《[架构设计 · 文件管理](../../../../../../../设计/架构设计/20_架构设计_子系统_文件管理.md)》「Excel 导入导出」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 共享列定义（`app/transfer/base.py`） <a id="base"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `ColumnSpec` | frozen dataclass（数据契约） | 列定义：`key: str`（字段键）/ `title: str`（表头）/ `required: bool = False`（是否必填）；导入解析与导出列定义共用 |

## 5. 导入能力域（`app/transfer/importer.py`） <a id="importer"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `RowError` | frozen dataclass（数据契约） | 行错误回执：`row: int`（行号）/ `field: str \| None = None`（字段）/ `message: str`（说明） |
| `ImportResult` | frozen dataclass（数据契约） | 导入结果：`rows: tuple[Mapping[str, object], ...]`（有效行）/ `errors: tuple[RowError, ...] = ()`（错误回执） |
| `BaseImporter(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "importer"` |
| `parse(data, *, columns) -> tuple[Mapping, ...]` | 抽象方法（async） | 解析文件字节为行（按列定义取字段） |
| `validate(rows, *, columns) -> ImportResult` | 抽象方法（async） | 行校验：筛出有效行 + 错误回执 |
| `NullImporter(BaseImporter, BaseNullObject)` | 占位实现 | `parse` 返回空行、`validate` 返回空 `ImportResult`（**不读写文件**） |
| `get_importer(request) -> BaseImporter` | 模块函数（提供者） | 取应用级单例（`request.app.state.importer`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `parse` | 入参 `data: bytes`（上传文件字节）+ `columns: Sequence[ColumnSpec]`；返回原始行（`tuple[Mapping]`），不做业务校验 |
| `validate` | 入参原始行 + 列定义；返回 `ImportResult`（有效行 + `RowError` 回执），承载「行校验 / 错误回执」 |
| 列定义 | 共用 `ColumnSpec`（key / title / required）；必填缺失记 `RowError` |
| 文件来源 | 模板 / 上传文件由调用方经 02-4-1 `BaseObjectStorage` 取字节后传入，本契约不直接接存储 |
| 批量入库 | 幂等（幂等键 + 唯一约束兜底）与分批入库归上层（通用能力阶段） |
| 占位语义 | `NullImporter.parse` 返回空行、`validate` 返回空 `ImportResult`；不读写文件 |

## 6. 导出能力域（`app/transfer/exporter.py`） <a id="exporter"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `BaseExporter(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "exporter"` |
| `export(rows, *, columns) -> AsyncIterator[bytes]` | 抽象方法 | 流式写出（按列定义输出，分块产出字节） |
| `NullExporter(BaseExporter, BaseNullObject)` | 占位实现 | 空流（不产出任何分块、**不写文件**） |
| `get_exporter(request) -> BaseExporter` | 模块函数（提供者） | 取应用级单例（`request.app.state.exporter`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| `export` | 入参 `rows: Sequence[Mapping[str, object]]` + `columns: Sequence[ColumnSpec]`；返回 `AsyncIterator[bytes]`（流式分块，供大数据量分页拉取场景） |
| 写出目标 | 结果文件由调用方经 02-4-1 `BaseObjectStorage` 落对象存储 / 直接回下载流；本契约只产出字节流 |
| 导出脱敏 | 敏感字段掩码经 02-3-5 `BaseMasker`（调用方在传入 `rows` 前完成），本契约不内置脱敏 |
| 占位语义 | `NullExporter.export` 返回空异步迭代器（不产出分块）；不写文件 |

## 7. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_importer` / `get_exporter`；模块 docstring 补「导入导出」 |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（导入导出接口归通用能力阶段），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 8. 继承与分层 <a id="baseclass"></a>

- `BaseImporter` / `BaseExporter → BaseCapability → BaseObject`；`NullImporter` / `NullExporter → 对应契约 + BaseNullObject → BasePlaceholder → BaseObject`。
- `ColumnSpec` / `RowError` / `ImportResult` 为能力域数据契约（frozen dataclass，同 `QueryResult` / `StoredObject` 风格）。
- 与对象存储分工：`BaseObjectStorage` 管字节存取；本域管**结构化表格解析 / 校验 / 流式写出**，二者配合使用。

## 13. 边界与开放项 <a id="boundary"></a>

- **真实 openpyxl 导入导出**（模板下载、上传解析、校验预览、批量入库幂等、导出流式与脱敏、大数据量分页）→ **通用能力阶段**；已登记计划「后续阶段待办」。
- **导入导出路由与前端交互**（模板下载 / 上传 / 错误回执展示）→ 通用能力阶段。
- **模板 / 结果文件存取** → 02-4-1 `BaseObjectStorage`（任务文档已标前置契约）；**导出脱敏** → 02-3-5 `BaseMasker`。
- **占位语义已知项**：占位 `parse` / `validate` 返回空、`export` 空流（不反映真实解析写出）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实解析 / 校验 / 导出用例（表头映射、必填与类型校验、分块写出）随回补阶段补充。
