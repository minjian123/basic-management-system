## 1. 概述 <a id="overview"></a>

- **目标**：落地全文检索能力域契约与占位实现——`app/search/base.py` 的数据契约 `SearchDocument` / `SearchQuery` / `SearchHit` / `SearchResult`、统一索引契约 `BaseSearchIndex`（`index` / `delete` / `search`）、占位实现 `NullSearchIndex`（可写空操作、`search` 固定占位命中；不连 ES）；常量清单 `SEARCH_INDEX_PREFIX` / `DEFAULT_SEARCH_SIZE` / `NULL_SEARCH_HIT_ID`；`app/api/deps.py` 提供者 `get_search_index`；`app/main.py` 装配单例。
- **范围**：`app/search/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-19 登记。
- **不含**（归后续阶段）：真实 ElasticSearch 8.x（索引创建 / 映射、查询 DSL、高亮、别名切换、多节点集群）→ **全文检索阶段（十六）**；同步管线（变更事件 → RocketMQ → event-worker ES 同步组 → 文本解析任务 → 写索引）、索引重建（事件重放 + 快照 + 别名切换）、ES 故障降级（库模糊查询兜底）→ 同阶段；文件内容文本解析（PDF / Word / Excel / TXT）→ 文件管理阶段；扫描件 OCR 与语义检索（Milvus）→ AI 阶段（复用 02-4-2 `BaseLlmProvider`）。
- **依据**：需求 [02-19](../../../../../需求/02_需求_后端基座.md#r02-19)、《[架构设计 · 全文检索](../../../../../../../设计/架构设计/25_架构设计_子系统_全文检索.md)》「索引规划」「查询路径」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段落地（地基波 + 回补）」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 全文检索能力域（`app/search/base.py`） <a id="search"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `SEARCH_INDEX_PREFIX` | `str` 常量 | 索引名前缀 `"bms-"`（架构 24：`bms-main` / `bms-prd-*` / `bms-log-*` / `bms-file`；占位期仅登记不校验） |
| `DEFAULT_SEARCH_SIZE` | `int` 常量 | 默认返回条数 `20` |
| `NULL_SEARCH_HIT_ID` | `str` 常量 | 占位命中 id `"null-search-hit"`（`NullSearchIndex.search` 固定返回） |
| `SearchDocument` | frozen dataclass（数据契约） | 待索引文档：`index: str` / `doc_id: str` / `fields: Mapping[str, object]`（`tenant_id` 由实现从上下文注入） |
| `SearchQuery` | frozen dataclass（数据契约） | 检索请求：`index: str` / `text: str` / `filters: Mapping[str, object] \| None = None` / `offset: int = 0` / `size: int = DEFAULT_SEARCH_SIZE` |
| `SearchHit` | frozen dataclass（数据契约） | 命中项：`id: str` / `score: float` / `highlight: Mapping[str, str] \| None = None` |
| `SearchResult` | frozen dataclass（数据契约） | 检索结果：`hits: tuple[SearchHit, ...]` / `total: int = 0` |
| `BaseSearchIndex(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "search_index"` |
| `index(document) -> None` | 抽象方法（async） | 写入 / 更新单个文档（真实实现写 ES 索引） |
| `delete(index, doc_id) -> None` | 抽象方法（async） | 删除文档（幂等，不存在不报错） |
| `search(query) -> SearchResult` | 抽象方法（async） | 检索（只返回 id + 分数 + 高亮；详情回查数据库） |
| `NullSearchIndex(BaseSearchIndex, BaseNullObject)` | 占位实现 | `index` / `delete` 空操作；`search` 固定返回单条占位命中（**不连 ES**） |
| `get_search_index(request) -> BaseSearchIndex` | 模块函数（提供者） | 取应用级单例（`request.app.state.search_index`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 传参形态 | `index` 以 `SearchDocument`、`search` 以 `SearchQuery` **数据契约对象**传参（便于扩展字段 / 分页而不改方法签名） |
| `delete` 入参 | `delete(index: str, doc_id: str)`（无需完整文档；幂等，不存在不报错） |
| 租户隔离 | 约定：索引均含 `tenant_id` 字段、查询**强制**租户隔离；`tenant_id` 由**实现**从上下文（`core/context.py` 的 `current_tenant`）注入，契约方法**不显式传租户参数** |
| 数据权限过滤 | 约定：查询叠加动作级数据权限范围过滤（真实实现接 `DataScope` / `BasePermissionChecker`）；调用方传业务 `filters`，权限过滤由实现强制叠加，不可绕过 |
| 检索结果 | 只返回 `id` + `score` + `highlight`（不返回整文档），详情回查数据库取最新数据（避免双写一致性难题） |
| 分页 | `SearchQuery.offset` / `size`（默认 `DEFAULT_SEARCH_SIZE`）；`total` 为命中总数 |
| 占位语义 | `index` / `delete` 空操作；`search` 固定返回单条占位命中（`id == NULL_SEARCH_HIT_ID`、`score=0.0`、`total=1`），便于上层链路验证 |
| 异步口径 | 三方法全异步（真实为载体网络 IO） |
| 降级 | ES 故障降级库模糊查询兜底（架构 24「降级策略」）归上层 / 回补阶段实现，本契约不实现 |
| 与语义检索 | 关键词检索（ES，本域）与语义检索（Milvus，AI 阶段）互补；embedding 取 02-4-2 `BaseLlmProvider` |

## 6. 继承与分层 <a id="base"></a>

- `BaseSearchIndex → BaseCapability → BaseObject`；`NullSearchIndex → BaseSearchIndex + BaseNullObject → BasePlaceholder → BaseObject`。
- `SearchDocument` / `SearchQuery` / `SearchHit` / `SearchResult` 为能力域数据契约（frozen dataclass，同 `StoredObject` / `EmbeddingResult` / `SpanContext` 风格）。
- 与对象存储 / LLM 适配分工：对象存储管文件字节（02-4-1）、LLM 适配管模型调用与向量化（02-4-2）、本域管关键词索引与检索；文件内容检索 = 文件管理解析文本 + 本域索引。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实 ElasticSearch 8.x 实现**（索引创建 / 映射、查询 DSL、高亮、别名切换、多节点集群）→ 全文检索阶段（十六）；已登记计划「后续阶段待办」。
- **同步管线与索引重建**（变更事件 → RocketMQ → event-worker ES 同步组 → 文本解析 → 写索引；事件重放 + 快照 + 别名切换）→ 全文检索阶段；文件文本解析（PDF / Word / Excel / TXT）→ 文件管理阶段。
- **ES 故障降级**（库模糊查询兜底 + 页面提示）→ 全文检索阶段上层。
- **租户隔离与数据权限过滤真实实现** → 接 `core/context.py` 的 `current_tenant` 与 `DataScope` / `BasePermissionChecker`（RBAC 阶段起）。
- **语义检索（Milvus）与扫描件 OCR** → AI 阶段（十七）；embedding / OCR 取 02-4-2 `BaseLlmProvider`；关键词检索与本域互补。
- **占位语义已知项**：占位 `search` 返回单条常量命中（不反映真实索引内容）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实检索用例（索引后命中、租户隔离、权限过滤、重建后查询）随回补阶段补充。
