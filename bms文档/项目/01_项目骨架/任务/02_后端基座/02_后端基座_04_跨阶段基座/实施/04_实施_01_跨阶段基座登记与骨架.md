## 3. 实施过程 <a id="process"></a>

1. **能力域包与契约**：
   - `app/cache/base.py`：`CacheRegion` + `build_cache_key` + `is_stale`。
   - `app/scope/base.py`：`DataScope` + `NullDataScope`。
   - `app/sharding/base.py`：`ShardingRouter` + `ShardBinding` + `NullShardingRouter`。
   - `app/events/base.py`：`EventEnvelope` + `EventPublisher` + `EventConsumer`。
   - `app/audit/base.py`：`FieldChange` + `AuditCapturer`。
   - `app/tasks/base.py`：`BaseTask`。
2. **仓储钩子**：`BaseRepository` 增 `_data_scope` / `_apply_data_scope`（数据范围）与 `_sharding_router` / `_resolve_shard` 路由接入。
3. **模型骨架**：`app/models/system.py` 落 `SysTask`（`sys_task`）/ `SysTaskLog`（`sys_task_log`）。
4. **登记**：《架构设计 · 后端基础类体系》§8 扩充六类「代码位置 / 契约 / 回补阶段」表；计划 §3.1 标注契约骨架就位。
5. **测试**：新增 `tests/crosscut/test_cross_phase_bases.py`（Kiwi 24）。
6. **验证**：`uv run pytest` / `uv run ruff check .` / `uv run pyright` 全绿，覆盖率 100%（详见[测试记录](../测试/04_测试_01_跨阶段基座登记与骨架.md)）。
