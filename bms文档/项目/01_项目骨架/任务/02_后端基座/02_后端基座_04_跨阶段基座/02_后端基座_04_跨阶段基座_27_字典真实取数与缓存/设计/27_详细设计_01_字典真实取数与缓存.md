## 1. 设计目标与范围 <a id="goal"></a>

交付[需求 02-56](../../../../../需求/02_需求_后端基座.md#r02-56) 与[任务 02-4-27](../02_后端基座_04_跨阶段基座_27_字典真实取数与缓存.md) 的**字典真实取数与缓存**——把 `02-4-17` 已交付的三契约占位落地为真实实现（首次落库：建表 + Alembic 首个迁移 + 幂等种子），供阶段四 `06_06` 字典字段（前端件族）端到端联调：

- **数据模型**：字典六表（`sys_dict_type` / `sys_dict_item` / `sys_dict_type_i18n` / `sys_dict_item_i18n` / `sys_dict_attr` / `sys_dict_attr_i18n`）+ 查询方案表 `sys_query_scheme`（表声明出自 `02-4-20`），落**租户库**。
- **真实取数**：`SqlDictSource`（`by_type` / `batch`）——版本比对三态、关键字、级联父值、按值子集、探针截断、locale 回退、停用不可见。
- **真实翻译**：`SqlDictTranslator.translate`——与取数共用同一份缓存，缺失 values 一次 `IN` 回填防 N+1。
- **缓存两层**：通用内存 Region（`app/cache/memory.py`）与 Redis 真实 Region（`app/cache/redis.py`，**redis-py 自写**：类型 key + TTL 随机偏移、空值防穿透、SETNX 防击穿、版本键 `INCR`）；字典域扩展 `DictCacheRegion`（L1 双分区 + 版本惰性比对）由 `app/dict/cache.py` 两实现承接。
- **高级查询四接口**：`attrs`（属性 schema）/ `query-providers`（提供者清单）/ `advanced-query`（通用条件引擎：字段与操作符白名单 + 参数绑定；`target=items` 取项，`target=business` 经 `02-4-9` 查询提供者注册表）/ `query-schemes`（`sys_query_scheme` 三级方案与默认解析，落地 `02-4-20` 契约）。
- **写路径**：类型 / 条目 / 属性服务层 CRUD + 简化 REST（写库 → 删缓存 → `INCR` 版本），供「变更后展示同步」联调。
- **字段类型登记**：`dict` / `dict_multi` 经 `02-4-13` 字段类型注册表登记（真实注册表 `LocalFieldTypeRegistry`），与前端 `FIELD_WIDGET_MAP` 对齐。
- **对外契约不变**：`02-4-17` 冻结的三契约签名、参数对象 / 结果契约、常量与错误码 `40101`~`40103` **只增不改**；路由保持 `/api/v1/dicts`（扩展子路径）。

### 1.1 口径与依从 <a id="positioning"></a>

- **架构铁律**：可替换实现走插件基类 + 注册表（三契约继承 `BasePluggable`，装配经 `PLUGIN_WIRINGS` 按配置解析）；横切缓存能力落 `app/cache/` 通用实现；字典域只做域内编排与查询，不另起缓存实现。
- **继承链（唯一权威见《[后端基类清单](../../../../../../../后端基类清单.md)》）**：`BaseObject → BaseCapability → BasePluggable` 固定三段；`SqlDictSource` / `SqlDictTranslator` → 对应契约；`MemoryDictCacheRegion` / `RedisDictCacheRegion` → `DictCacheRegion`（字典域扩展，domain 固定 `dict`）；`SqlQuerySchemeStore` → `BaseQuerySchemeStore`；`LocalFieldTypeRegistry` → `BaseFieldTypeRegistry`；`DictFieldType` / `DictMultiFieldType` → `BaseFieldType`（`BaseProvider`）。
- **租户口径**：字典表在租户库；实现侧从请求上下文解析租户（`app/db/tenant.py` 的 `TenantContext` / `current_tenant`，缺省 `demo`）并经 `EngineRegistry.get(db_key)` 取引擎，**调用方不传租户参数**（契约面不变）。缓存 key 含租户前缀（`DictCacheRegion` 既有语义）。
- **Redis 实现方式（用户拍板）**：**redis-py 自写**（同步 `redis.Redis` 供通用同步契约；异步 `redis.asyncio.Redis` 供字典域异步流程），不引入 `dogpile.cache`；理由与 02-13 口径回写见第 16 节。
- **版本语义**：`items=None`＝版本一致（复用本地缓存）；`items=()`＝空字典；非空＝条目集。版本比对只承担「缓存是否新鲜」，不承担正确性兜底（Redis 故障降级直连 DB 并返回全量）。
- **扩展属性隔离**：`attr_json` 只经高级查询接口按命中子集分页返回，**不进普通取数与缓存链路**。
- **跨库**：SQLite 实测跑通；模型与迁移按四库兼容编写（`JSON` 列与 JSON 提取经方言 helper），三库真库执行随阶段二窗口（需求 02-56 完成标准）。
- **窗口**：本任务为补充六（真实实现口径），48h；三库真库执行、权限码真实接入、管理页面等模块级功能归阶段八「通用能力·字典模块」（边界见需求 02-56 注块）。

## 5. 缓存设计 <a id="cache"></a>

### 5.1 分层与职责 <a id="cache-layers"></a>

| 层 | 载体 | 职责 | 失效 |
| --- | --- | --- | --- |
| L1 进程内 | `MemoryDictCacheRegion`（字典域；双分区） | 小字典整类型直出（零反序列化零往返）；超大字典已查子集 | 版本惰性比对（读时比版本）；写路径 `bump` |
| 共享层 | `RedisDictCacheRegion`（Redis） | 跨实例类型 key（TTL 随机偏移）、全局版本键（`INCR`）、SETNX 互斥锁（防击穿）、空值标记（防穿透） | 写路径 `DEL` + `INCR`；TTL |
| 降级 | 无 Redis / Redis 故障 | 直连 DB 并始终返回全量 `items`；版本号回落进程内计数 | 进程重启 |

### 5.2 通用内存 Region（`app/cache/memory.py`） <a id="cache-memory"></a>

```python
class MemoryCacheRegion(CacheRegion):
    """通用内存 Region：进程内 dict + TTL + LRU 上限 + 版本号（真实实现，无 IO）。"""
    def __init__(self, *, domain: str = "memory", max_items: int = 1024) -> None: ...
    @property
    def domain(self) -> str: ...
    def get(self, key: str) -> object | None: ...            # 过期即删、命中刷新 LRU
    def set(self, key: str, value: object, ttl: int | None = None) -> None: ...
    def delete(self, key: str) -> bool: ...
    def get_global_version(self) -> int: ...
    def bump_version(self) -> int: ...                        # 版本 +1（写路径 / Redis 版本同步）
```

- 机制：内部 `OrderedDict`（命中 `move_to_end`；超 `max_items` 淘汰最早）；`ttl` 缺省 `self.default_ttl`；单进程线程安全经 `threading.Lock`（同步方法可能被多线程健康检查调用）。
- 注册 `plugin_name = 'memory'`（构造经 `register_plugin` 的零参工厂在装配层登记为 `memory`）。

### 5.3 Redis Region（`app/cache/redis.py`） <a id="cache-redis"></a>

```python
class RedisCacheRegion(CacheRegion):
    """Redis Region（redis-py 自写）：同步契约方法 + 异步方法；JSON 序列化；TTL 抖动；SETNX / INCR。"""

    def set(self, key: str, value: object, ttl: int | None = None) -> None: ...
    def delete(self, key: str) -> bool: ...
    def get_global_version(self) -> int: ...                  # GET int（缺省 0）
    # 异步方法（字典域主路径；redis.asyncio）
    async def aget(self, key: str) -> object | None: ...
    async def aset(self, key: str, value: object, ttl: int | None = None) -> None: ...
    async def adelete(self, key: str) -> bool: ...
    async def aincrease(self, key: str) -> int: ...           # INCR（版本键）
    async def asetnx(self, key: str, token: str, ttl: int) -> bool: ...  # 互斥锁
```

- 序列化：`json.dumps(value, ensure_ascii=False, default=str)`；反序列化失败按未命中（防脏值）。
- 锁：调用方拼 `f"lock:{key}"` 并带唯一 token；释放用 Lua 比对 token（避免误删他锁——`EVAL` 脚本由 `adelete` 之外单列 `arelease_lock`）。
- 客户端生命周期：`setup()` 建连（`aclose()` 关闭）；`Redis.from_url` / `redis.asyncio.from_url`；配置取 `settings.redis.url`。
- 不可用降级：连接 / 命令异常统一捕获 → 记日志 → 返回未命中 / 空操作（**不抛错**，由域层直连 DB 兜底）。

```python
class DictCacheRegion(CacheRegion, ABC):

    async def adrop_type(self, tenant, locale, dict_type) -> None: ...
    async def avalue_subset(self, tenant, locale, dict_type, values: Sequence[str]) -> dict[str, str]: ...
        """读「按值子集」局部缓存（超大字典批量翻译）。"""
    async def aset_value_subset(self, tenant, locale, dict_type, mapping: Mapping[str, str]) -> None: ...
```

- `MemoryDictCacheRegion(DictCacheRegion)`（`plugin_name='memory'`）：内部 `MemoryCacheRegion(domain='dict')` 组合 + 双分区键（`整类型` 键即 `dict_key`；子集键 `value_key` 拼 `f"{locale}:{type}:v:{value}"`）+ 进程内版本；`bump_version()` 同步写路径。纯内存 async 方法直接返回（无 await 的 `async def`）。

- 域内查询流程（`SqlDictSource.by_type`）：
  ```text
  1. version = await region.aversion(tenant)          # Redis 版本（或内存版本）
  2. version 命中请求 version → 返回 items=None（零 DB、零传输）
  3. L1 命中且条目版本一致 → 直出
  4. Redis 类型 key 命中 → 回填 L1 → 直出
  5. 未命中 → SETNX 锁（防击穿）→ 未获锁短暂重读 → 仍无则查 DB → 写 L1 + Redis（TTL 抖动）
     → 空结果写空值标记（防穿透）
  ```

### 6.1 `SqlDictSource` <a id="sql-source"></a>

```python
class SqlDictSource(BaseDictSource):
    """真实字典取数（租户库；版本比对 / 关键字 / 级联 / 按值子集 / 探针截断；缓存两层）。"""
    plugin_name: str = "sql"
    def __init__(self, *, engines: EngineRegistry, cache: DictCacheRegion,
                 tenant_resolver: Callable[[], str | None] = default_tenant) -> None: ...
    async def by_type(self, query: DictQuery) -> DictTypeResult: ...
    async def batch(self, query: DictBatchQuery) -> DictBatchResult: ...
```

| 行为 | 口径 |
| --- | --- |
| 版本比对 | 请求 `version` 非空且 `== 全局版本` → `items=None`（`has_more=False`、`total=0`）；不做 DB / Redis 类型读取 |
| 查询 | `SELECT` 条目 join `sys_dict_type`（`type` 匹配、`deleted_at IS NULL`）left join `_i18n`（`locale` 匹配）；`status='enabled'`；`parent_id` 过滤（`None` 参数不过滤）；`keyword` 对 `label / value / code` `LIKE`（前缀 + 包含）；`values` 按 `value IN`；排序 `sort, id` |
| 探针 | `limit` 非空 → 取 `limit+1` 条判 `has_more`（`DICT_PROBE_LIMIT` 探针同口径）；`total` 用独立 `COUNT`（带同过滤条件） |
| count 优化 | `limit` 为空且结果 ≤ 阈值时 `total = len(items)`；`values` 查询 `total = len(回填)` |
| locale | `_i18n.label` 命中用译文，缺省回退主表 `label`；`locale` 由 `Accept-Language` 经 `BaseTranslator.resolve_locale`（02-4-14）解析，缺省 `DEFAULT_LOCALE` |
| 输出 | `DictItem(value, label, code, parent_id, sort, status, color)`；**不含 `attr_json`** |
| 空字典 | 确无数据 → `items=()`（与版本一致的 `None` 区分） |
| 缓存写入 | 整类型（无过滤条件）写类型 key + L1；带过滤（keyword / parent_id / values）**只回填 L1 短键**，不写整类型 key（避免污染） |
| 降级 | 缓存层异常 → 直达 DB 并返回全量；日志告警 |

- **`batch`**：一次会话内按 `types` 批量查（`type IN (...)` 一次查询按类型分组 + 一次 i18n join）；逐类型应用探针截断与 `has_more` / `total`；`version` 一致的类型返回 `None`；结果按类型写 L1 / Redis。
- 会话与租户：`engines.get(db_key)` + `async_sessionmaker`；租户解析缺省 `demo`（`current_tenant` 上下文，未设置回落 `DEMO_TENANT`）。
- 错误：数据源异常抛 `ErrorCode.DICT_SOURCE_UNAVAILABLE`（40101）；类型不存在抛 40102；locale 不在支持列表抛 40103（经 `SUPPORTED_LOCALES` 校验）。

## 7. 高级查询（`app/dict/query.py` / `app/dict/providers.py` / `app/listing/store.py`） <a id="adv"></a>

### 7.1 属性 schema（`GET /dicts/{type}/attrs`） <a id="adv-attrs"></a>

- 读 `sys_dict_attr`（`type` 解析、`status='enabled'`、`sort` 排序）join `sys_dict_attr_i18n`（locale 回退）；返回 `[{attr_key, name, data_type, operators, widget, options, sort, scope}]`。
- `operators` / `options` 为 JSON 数组；空值回退按 `data_type` 派生的默认操作符集（`text → [eq, ne, contains, ...]` 等，常量在 `app/dict/query.py`）。

### 7.2 查询提供者清单（`GET /dicts/query-providers`） <a id="adv-providers"></a>

- 经 `BaseQueryProviderRegistry.keys()` 返回已注册提供者；每个提供者实现 `describe()`（`key` / `name` / `target` / `dict_types` / `param_schema`）。内建：
  - `builtin`：通用条件引擎（`target=items`）；
  - `dict_items`：字典条目只读示例（`target=business`，演示「发现—选择—调用」，供前端联调）。
- 清单按 `type` 查询参数过滤（提供者声明 `dict_types` 为空 = 全部）。

### 7.3 条件引擎（`POST /dicts/{type}/advanced-query`） <a id="adv-engine"></a>

- 条件组模型（组件设计 8.2）：`{logic: 'AND'|'OR', children: [条件项 | 子组]}`；条件项 `{field, operator, value}`；最多 2 层嵌套（常量 `DICT_ADV_MAX_DEPTH = 2`）。
- 字段白名单：固定字段 `value / label / code / sort / status` + 属性 `attr.<attr_key>`（仅该类型已定义属性）。
- 操作符白名单（按 `data_type`）：`eq / ne / contains / not_contains / starts_with / between / gt / lt / is_null / not_null / in / not_in`。
- 参数绑定：全部经 SQLAlchemy 表达式构造（**不拼字符串**）；`attr_json` 提取经方言 helper `json_text(column, key)`（SQLite `json_extract` / MySQL `JSON_UNQUOTE(JSON_EXTRACT(...))` / PostgreSQL `->>` / 达梦 `JSON_VALUE`，`dialect.name` 分支）。
- `target=items`：条件评估 → 分页（`page` / `size`，`size ≤ 100`）→ `{items, total, page, size}`（items 为 `DictItem` 全字段，**可含 attr_json 子集**——属性行按需返回）。
- `target=business`：`provider` 非空 → 经 `BaseQueryProviderRegistry.query(provider, params)` 委托；未注册 → `NotFoundError`（404）；`provider` 缺省 → `builtin` 对字典条目表只读查询（示例）。
- 安全：字段 / 操作符 / provider 全白名单校验；无写操作；租户隔离由会话库连接保证。

## 12. 失败分支与边界 <a id="edge"></a>

| 边界 / 失败场景 | 处置 |
| --- | --- |
| Redis 不可用 / 命令异常 | 缓存层捕获降级（未命中 / 空操作）；直连 DB 返回全量；日志告警；不抛业务错 |
| Redis 与 DB 均不可用 | 抛 `40101`（数据源不可用）→ 统一响应 |
| 字典类型不存在 | `by_type` / `attrs` 抛 `40102`（类型不存在） |
| locale 不支持 | 抛 `40103`（语言不支持）；缺省回退 `zh-CN`（请求头缺失时） |
| 版本一致但客户端缓存被清 | 客户端传 `version=null` 即返回全量（版本比对只作优化） |
| 空字典 | `items=()`；写空值标记（防穿透），TTL 短 |
| 超大字典（> 探针上限） | `has_more=True`；不整类型写缓存（仅 L1 短键 / 子集）；关键字走 `idx_item_label` 前缀 |
| 级联父值无子项 | `items=()`（空集合，不报错） |
| 按值子集未命中 | **不占位**（与组织回显不同），映射中缺项 |
| 写并发冲突 | 乐观锁 `StaleDataError` → 统一转冲突响应（`ConflictError` 语义） |
| 唯一约束冲突（type / code） | 数据库唯一索引兜底 → 转 `ConflictError`（不新增错误码；复用参数校验 / 冲突语义） |
| 软删除后重建同 type / code | 复合唯一含 `deleted_at`，天然放行 |
| 条件字段不在白名单 / 操作符不匹配 `data_type` | 拒查（400 语义，参数校验错误），不发 SQL |
| `attr_json` 为空的行参与属性过滤 | JSON 提取返回 `NULL` → `is_null` / `not_null` 语义正确；其余操作符排除 |
| provider 未注册（`target=business`） | `NotFoundError`（10002 / 404） |
| 查询方案跨用户越权访问 | 个人方案仅本人可见（`owner_id` 过滤）；共享方案读、写按 scope |
| 迁移目标库不可达 | `alembic upgrade` 失败即拒（本地/CI 明确报错，不静默） |
| 种子重复执行 | 幂等（存在即跳过），不重复插入 |

## 15. 边界与开放项 <a id="open"></a>

- **不在本期**：字典管理页面与菜单、`dict:manage` / `dict:query-scheme` 权限码真实接入、操作日志与字段级审计、回收站、导入导出、i18n 管理界面（归阶段八「通用能力·字典模块」）；三库真库执行（`ops/test_db.py` 真实 `create/migrate/drop` 与 CI db 档）归阶段二窗口。
- **四库差异**：`JSON` 列在达梦的映射（TEXT-as-JSON）与 JSON 提取函数名（`JSON_VALUE`）为编写口径，实际抵达梦随阶段二实测；SQLite / MySQL / PostgreSQL 三条 SQL 分支已实现（SQLite 实测，另两条登记待测）。
- **高级查询工程边界**：条件引擎按「字段 / 操作符白名单 + 参数绑定」实现，不引入通用查询构建器；`attr_json` 条件只支持一层键（`attr.<key>`）；超过 2 层嵌套拒绝。
- **缓存一致性**：版本号 INCR 与类型 key 删除非原子（先删后 INCR）——极端时序下最长一个请求窗口陈旧（业务可接受，与《概要设计》一致）。
- **L1 内存边界**：L1 LRU 上限进程内配置（缺省 1024 项）；超大字典子集按 value 计数上限淘汰。
- **Kiwi 用例编号**：平台登记后回填代码与记录。
- **工时**：名义 48h（模型 / 迁移 / 种子 8h、取数与翻译 10h、双缓存与版本 8h、高级查询与方案 14h、写接口与装配 4h、测试与登记 4h）；实际以实施记录为准。

## 18. 实施对齐记录 <a id="align"></a>

| # | 设计口径 | 实施落定 | 原因 |
| --- | --- | --- | --- |
| 1 | 实现类声明 `plugin_name`（`sql` / `memory` / `redis` / `local`） | **实现类与零参工厂均不声明 `plugin_name`**，经装配工厂 `register_plugin` 显式登记（带参工厂保留声明） | 与既有实现口径一致；零参实现类 / 工厂声明 `plugin_name` 会被插件注册表自动收集，与显式登记重名（构建期拒启） |
| 2 | 缓存读写：无过滤即读 / 写整类型缓存 | 读：无过滤**且无 `limit`**；写：无过滤**且（无 `limit` 或未截断）** | 带 `limit` 的请求若命中整类型缓存会破坏探针截断语义；未截断的探针（小字典）仍写缓存，大字典探针不写 |
| 3 | `DictCacheRegion` 仅列 `alock`（互斥锁获取） | 增补 `arelease_lock`（只增不改；内存 / Redis 实现覆写），`by_type` 查库完成即释放 | 锁不释放会导致 5s 内后续请求走「未获锁重读缓存」分支；释放后语义正确且无等待 |
| 4 | 示例提供者两个（`builtin` + `dict_items`） | 合并为 `builtin` 一个（business 默认提供者） | `target=items` 由 `DictQueryService` 直接承载，无需注册提供者；清单精简 |
