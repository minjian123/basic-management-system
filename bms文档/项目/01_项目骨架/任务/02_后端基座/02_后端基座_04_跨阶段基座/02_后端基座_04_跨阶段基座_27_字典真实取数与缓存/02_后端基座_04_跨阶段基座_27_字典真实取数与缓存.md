## 2. 任务内容 <a id="content"></a>

1. 数据模型与迁移：`sys_dict_type` / `sys_dict_item` / `sys_dict_type_i18n` / `sys_dict_item_i18n` / `sys_dict_attr` / `sys_dict_attr_i18n` 六表（租户库，字段与索引按《概要设计 · 字典管理》）；Alembic 首个迁移（四库兼容）+ 幂等种子（`user_status` / `user_gender` / `biz_type` / `region` 省市区级联示例，含 i18n 与 `color`）。
2. 真实取数 `SqlDictSource`（继承 `BaseDictSource`）：`by_type`（版本比对三态 / 关键字 label·value·code / `parent_id` 级联 / `values` 子集 / `limit` 探针截断与 `has_more`·`total` / locale 经 `_i18n` 回退 / 停用不可见）与 `batch`（多类型合并、逐类型探针截断）。
3. 真实翻译 `SqlDictTranslator`（继承 `BaseDictTranslator`）：与取数共用同一份 L1；缺失 values 一次 `IN` 回填防 N+1；label 缺失回退主表。
4. 缓存真实实现：`app/cache/` 通用内存 Region + Redis 真实 Region（redis-py asyncio：类型 key + TTL 随机偏移、空值防穿透、SETNX 防击穿、全局版本键 `INCR`）；`DictCacheRegion` 字典域扩展（L1 双分区与版本惰性比对）。
5. 高级查询四接口真实实现：`attrs` / `query-providers` / `advanced-query`（通用条件引擎：字段与操作符白名单 + 参数绑定；`target=items` 取项，`target=business` 经查询提供者注册表）/ `query-schemes`（`sys_query_scheme` 三级方案与默认解析）。
6. 写路径与装配：类型 / 条目 / 属性服务层 CRUD + 简化 REST（删缓存 + `INCR` 版本）+ 幂等接线；`dict` / `dict_multi` 字段类型经 `02-36` 注册表登记；错误码 `40101`~`40103` 真实抛错；装配（config / assembly / deps / router）与登记回写。

## 3. 完成标准 <a id="accept"></a>

真实取数 / 批量 / 级联 / 按值子集 / 翻译 / 版本比对与缓存失效在 SQLite 实测跑通并可核对；高级查询四接口与写路径可用（改条目后展示同步）；迁移与查询按四库兼容编写（三库真库执行随阶段二窗口）；`pytest`、`ruff`、`pyright` 全绿、覆盖率门禁达标；登记齐备（含 `02-13` 缓存实现口径回写）。
