## 1. 概述 <a id="overview"></a>

- **目标**：落地首页工作台卡片能力域契约与占位实现——`app/dashboard/base.py` 的卡片类型常量 `CARD_TYPES`、卡片提供者契约 `BaseDashboardCardProvider`（`key` + `metadata` / `fetch`）、注册表契约 `BaseDashboardCardRegistry`（`register` / `get` / `keys` + `metadata` / `fetch` 聚合模板）、占位实现 `NullDashboardCardRegistry`（空卡片集）；`app/api/deps.py` 提供者 `get_dashboard_card_registry`；`app/main.py` 装配单例。
- **范围**：`app/dashboard/`（新增）、`app/api/deps.py`（提供者导出）、`app/main.py`（装配）、单测；架构 04 §4 / §8、《后端基类清单》/《后端开发规范》/ 计划 / 需求 02-38 登记。
- **不含**（归后续阶段）：真实卡片注册与模板解析（`sys_dashboard_card` 双轨制内置 / 数据集卡、`sys_dashboard_template` 三级模板回退、布局解析接口、卡片 / 布局 Redis 缓存）→ **首页工作台阶段**；内置卡数据接口（待办 / 通知 / 公告 / 统计，转发来源模块既有接口）、数据集图表卡（`rpt_dataset` + ECharts，取 02-4-9 `BaseQueryProvider`）、前端 gridstack 渲染与卡片组件注册表、一键重置与编辑态保存 → 同阶段 / 报表 BI / 前端组件体系；i18n 卡片名（`sys_dashboard_card_i18n`）→ 02-4-14 `BaseTranslator` + 首页工作台阶段。
- **依据**：需求 [02-38](../../../../../需求/02_需求_后端基座.md#r02-38)、《[架构设计 · 首页工作台](../../../../../../../设计/架构设计/29_架构设计_子系统_首页工作台.md)》「卡片注册机制（双轨制）」「模板与布局解析」「数据与缓存」节、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[命名规范](../../../../../../../规范/命名规范.md)》「后端命名」节。

## 4. 首页工作台卡片能力域（`app/dashboard/base.py`） <a id="dashboard"></a>

| 成员 | 形态 | 说明 |
| --- | --- | --- |
| `CARD_TYPES` | `tuple[str, ...]` 常量 | 卡片类型（双轨制）：`("builtin", "dataset")`（内置功能卡 / 数据集图表卡；占位期仅登记不校验） |
| `BaseDashboardCardProvider(BaseObject, ABC)` | 卡片提供者契约 | 抽象属性 `key: str` + 同步 `metadata()` / 异步 `fetch(params)` |
| `metadata() -> Mapping[str, object]` | 抽象方法（同步） | 卡片元数据（名称 / 尺寸 / `render_key` / 数据接口地址 / `card_type` 等） |
| `fetch(params) -> Mapping[str, object]` | 抽象方法（async） | 取卡片数据（真实实现转发来源模块既有接口，不绕行其权限校验） |
| `BaseDashboardCardRegistry(BaseCapability, ABC)` | 能力域契约中间层 | `key: str = "dashboard_card_registry"` |
| `register(provider) -> None` / `get(key) -> BaseDashboardCardProvider \| None` / `keys() -> tuple[str, ...]` | 抽象方法 | 注册 / 解析 / 卡片集 |
| `metadata(card_key) -> Mapping[str, object]` | **具体方法**（同步模板） | 解析卡片 → 委托元数据；未命中抛 `NotFoundError` |
| `fetch(card_key, params) -> Mapping[str, object]` | **具体方法**（async 模板） | 解析卡片 → 委托取数；未命中抛 `NotFoundError` |
| `NullDashboardCardRegistry(BaseDashboardCardRegistry, BaseNullObject)` | 占位实现 | 注册空操作、`get` None、`keys` 空；`metadata` / `fetch` 固定返回空映射（空卡片集） |
| `get_dashboard_card_registry(request) -> BaseDashboardCardRegistry` | 模块函数（提供者） | 取应用级单例（`request.app.state.dashboard_card_registry`） |

**口径**：

| 情形 | 处置 |
| --- | --- |
| 卡片身份 | `BaseDashboardCardProvider.key` 为抽象属性（实现按卡片取 `"todo"` / `"notice"` / `"stats"` / `"dataset:{id}"` 等）；注册表以 `key` 解析 |
| 卡片类型 | `metadata()` 回带 `card_type`（取 `CARD_TYPES` 之一）；内置卡 `render_key` 映射前端组件，数据集卡带 `dataset_id` / `chart_type` |
| `metadata` | 同步纯返回元数据（名称 / 尺寸 / 渲染键 / 数据接口地址）；随布局接口下发，前端不硬编码卡片清单 |
| `fetch` | 异步取数；内置卡转发来源模块接口（工作流 / 通知 / 公告）、数据集卡取 02-4-9 `BaseQueryProvider`；**不绕行来源模块权限校验** |
| 注册表模板 | `metadata` / `fetch` 为**具体模板**（解析 → 委托），未命中抛 `NotFoundError`（10002，全局处理器转 404） |
| 占位语义 | `NullDashboardCardRegistry` 注册空操作、`metadata` / `fetch` 固定返回空映射（空卡片集） |
| 模板解析 | 三级模板回退（个人 > 角色 > 平台默认）与布局缓存归上层（首页工作台阶段），本域只提供卡片提供者注册与取数原语 |

## 5. 应用装配与依赖注入 <a id="di"></a>

| 位置 | 变更 |
| --- | --- |
| `app/api/deps.py` | 导出 `get_dashboard_card_registry`；模块 docstring 补「工作台」 |
| `app/main.py` `create_app()` | 装配 `app.state.dashboard_card_registry = NullDashboardCardRegistry()`（置于能力域基座装配段） |

提供者为普通同步函数（取 `app.state` 单例，无 IO）；本任务**不落路由**（工作台布局 / 卡片接口归首页工作台阶段），故无路由与中间件改动。真实实现替换占位时调用面零改动。

## 6. 继承与分层 <a id="base"></a>

- `BaseDashboardCardProvider → BaseObject`（卡片为可注册组件，非 DI 能力域）；`BaseDashboardCardRegistry → BaseCapability → BaseObject`。
- `NullDashboardCardRegistry → BaseDashboardCardRegistry + BaseNullObject → BasePlaceholder → BaseObject`。
- 无新增数据契约（元数据 / 取数结果用标准映射类型），与 `BaseFieldTypeRegistry` / `BaseHealthCheckRegistry` 风格一致。

## 11. 边界与开放项 <a id="boundary"></a>

- **真实卡片注册与模板解析**（`sys_dashboard_card` 双轨制、`sys_dashboard_template` 三级模板回退、布局解析接口与 Redis 缓存）→ **首页工作台阶段**；已登记计划「后续阶段待办」。
- **内置卡数据接口**（待办 / 通知 / 公告 / 统计，转发来源模块既有接口、不绕行权限校验）→ 首页工作台阶段 + 工作流 / 通知公告。
- **数据集图表卡**（`rpt_dataset` + ECharts，取 02-4-9 `BaseQueryProvider`）→ 首页工作台 / 报表 BI 阶段。
- **前端 gridstack 渲染与卡片组件注册表、一键重置与编辑态保存、移动端单列渲染** → 前端组件体系 / 首页工作台阶段。
- **卡片名多语言**（`sys_dashboard_card_i18n`）→ 02-4-14 `BaseTranslator` + 首页工作台阶段。
- **占位语义已知项**：占位空卡片集（不反映真实卡片）；真实判定随回补阶段生效——已知、可接受。
- **测试**：真实卡片用例（注册 / 元数据 / 取数 / 模板回退）随回补阶段补充。
