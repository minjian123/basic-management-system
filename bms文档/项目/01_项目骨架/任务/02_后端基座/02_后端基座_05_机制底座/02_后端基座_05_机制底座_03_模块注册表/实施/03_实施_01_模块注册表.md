## 3. 实施过程 <a id="process"></a>

1. **模型**：`app/models/platform.py` 落 `SysModule`（四要素 `(字段, deleted_at)` 复合唯一）/ `SysModuleI18n`（`(module_id, locale, deleted_at)` 唯一）。
2. **注册服务**：`app/services/module_registry.py` 落 `ModuleRecord` / `PLATFORM_MODULES`（sys/wf/rpt/ai）/ `ModuleRegistry`（`list_modules` / `validate`）。
3. **启动校验**：`main.py` lifespan 启动阶段校验，冲突 / 非法 → CRITICAL 明细 + `RuntimeError`（启动中止）；`app.state.module_registry` 装配。
4. **CI 校验**：`ops/check_modules.py` 复用同规则，失败退出码 1。
5. **只读接口**：`app/api/modules.py`（`GET /api/v1/modules?status=`，统一 `ApiResponse`，无写接口）；挂载聚合路由。
6. **登记**：数据表文件（`sys_module` / `sys_module_i18n`）+《数据库设计总览》7.3；《架构设计 · 模块注册》段号口径同步。
7. **测试**：Kiwi 28（服务 / 接口 / 启动校验 / CI 脚本）。
8. **验证**：`uv run pytest` / `uv run ruff check .` / `uv run pyright` 全绿，覆盖率 100%（详见[测试记录](../测试/03_测试_01_模块注册表.md)）。

关键命令：

```bash
uv run pytest --cov=app -q

uv run pyright
uv run python ops/check_modules.py
```
