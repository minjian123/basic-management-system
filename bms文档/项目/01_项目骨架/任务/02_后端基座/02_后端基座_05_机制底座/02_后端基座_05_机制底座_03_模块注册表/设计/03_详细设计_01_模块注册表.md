## 1. 概述 <a id="overview"></a>

- **目标**：落地平台「注册制」载体——`sys_module` / `sys_module_i18n` 表声明、平台域固定注册清单（`sys` / `wf` / `rpt` / `ai`）、三要素（表前缀 / 错误码段 / 事件域）唯一与格式校验、启动校验与 CI 校验入口、`GET /api/v1/modules` 只读占位；**无写接口**。
- **范围**：`app/models/platform.py`、`app/services/module_registry.py`、`app/api/modules.py`（+ 聚合路由）、`app/main.py`（lifespan 启动校验）、`ops/check_modules.py`、`数据表设计/sys_module*.md`、单测。
- **不含**（随落库 / 后续阶段）：真实落表与种子迁移、接库查重（CI 三库）、租户模块开关 `sys_tenant_module`、`platform:manage` 鉴权、产品级注册与下线治理。
- **依据**：需求 [02-16](../../../../../需求/02_需求_后端基座.md#r02-16)、《[架构设计 · 模块注册](../../../../../../../设计/架构设计/11_架构设计_子系统_模块注册.md)》「注册表结构与数据」「注册时机与唯一性校验」节、《[命名规范](../../../../../../../规范/命名规范.md)》「数据库命名」节、《[API接口规范](../../../../../../../规范/API接口规范.md)》第 2/3 节。

## 4. 数据模型 <a id="models"></a>

`app/models/platform.py`（平台库）：

| 模型 | 表 | 字段级结构（唯一事实源） |
| --- | --- | --- |
| `SysModule(BaseModel)` | `sys_module` | [sys_module](../../../../../../../设计/数据库设计/数据表设计/sys_module.md)：`module_key` / `name` / `table_prefix` / `errcode_segment` / `event_domain` / `status` + 公共字段；四要素 `(字段, deleted_at)` 复合唯一 |
| `SysModuleI18n(BaseModel)` | `sys_module_i18n` | [sys_module_i18n](../../../../../../../设计/数据库设计/数据表设计/sys_module_i18n.md)：`module_id` / `locale` / `name` + 公共字段；`(module_id, locale, deleted_at)` 复合唯一 |

- 多语言附表**继承 `BaseModel`**（含雪花 ID / 审计 / 软删除 / 乐观锁），以 `(module_id, locale, deleted_at)` 唯一约束实现「同模块同语言唯一」；不新增 `BaseI18n` 基类。
- `status`：`enabled` / `disabled` / `planned`；平台域 4 行为 `enabled`。

## 5. 注册清单与唯一性校验 <a id="registry"></a>

`app/services/module_registry.py`：

| 成员 | 说明 |
| --- | --- |
| `PLATFORM_MODULES` | 平台域固定清单（4 行）：`sys` / `wf` / `rpt` / `ai` |
| `ModuleRegistry` | 注册服务：`list_modules(status=None)`（占位返回固定行，按 `status` 筛选）、`validate()`（返回冲突 / 非法明细，空列表为通过） |

平台域占位清单：

| module_key | name | table_prefix | errcode_segment | event_domain | status |
| --- | --- | --- | --- | --- | --- |
| `sys` | 系统 | `sys_` | `01` | `sys` | enabled |
| `wf` | 工作流 | `wf_` | `02` | `wf` | enabled |
| `rpt` | 报表 | `rpt_` | `03` | `rpt` | enabled |
| `ai` | AI 域 | `ai_` | `04` | `ai` | enabled |

校验规则（`validate()`）：

- **唯一**：`module_key` / `table_prefix` / `errcode_segment` / `event_domain` 分别全局唯一（不区分平台 / 业务）。
- **格式**：`table_prefix` `^[a-z][a-z0-9]*_$`；`errcode_segment` `^\d{2}$` 且业务模块 ≥ `10`（平台保留 `01`~`09`）；`event_domain` `^[a-z][a-z0-9_]*$`（全小写）。
- **段号表示**：`errcode_segment` 为字符串、列宽留余量（`VARCHAR(8)`）；当前按 2 位数字校验，将来 90 个业务段用尽可放宽为 3 位（`100` 起）而无需改列；段号注册即定、不回收。
- 明细：冲突项给出「模块 + 字段 + 冲突值 / 非法原因」。

## 6. 启动校验与 CI 校验 <a id="check"></a>

- **启动校验**：`create_app` lifespan 启动阶段调用 `ModuleRegistry.validate()`；非空 → 记录 **CRITICAL** 明细并抛 `RuntimeError`（应用启动失败）；平台域占位清单恒通过。
- **CI 校验**：`ops/check_modules.py`（`main(argv)`）复用同一校验规则，校验占位清单 / 后续迁移种子，冲突或非法 → 打印明细并退出码 `1`；供流水线调用（真实接库查重随落库阶段）。

## 7. 只读接口 <a id="api"></a>

`app/api/modules.py`（挂 `/api/v1/modules`）：

| 方法与路径 | 说明 |
| --- | --- |
| `GET /api/v1/modules?status=` | 返回模块注册清单（占位 4 行固定数据），`?status` 按值筛选（`enabled` / `disabled` / `planned`）；软删除过滤（占位无）；统一 `ApiResponse`；**归属平台接口豁免租户解析**（不挂租户依赖） |
| `POST` / `PUT` / `DELETE /api/v1/modules` | **不提供**（仅 GET 注册；写方法 → `405 Method Not Allowed`，路径存在但无写方法） |

- 本阶段暂不鉴权；RBAC 阶段接入 `platform:manage`。

## 9. 实施步骤 <a id="steps"></a>

1. `app/models/platform.py` 落 `SysModule` / `SysModuleI18n`。
2. `app/services/module_registry.py` 落占位清单 + `ModuleRegistry`（列表 / 筛选 / 校验）。
3. `app/api/modules.py` + 聚合路由挂载；`main.py` lifespan 增启动校验。
4. `ops/check_modules.py` 落 CI 校验入口。
5. 登记《数据库设计总览》（已登记两张表文件）。
6. 新增 Kiwi 28 用例。
7. 验证：`uv run pytest`、`uv run ruff check .`、`uv run pyright` 全绿。
8. 回写：实施 / 测试记录 + 任务 / 需求 / 计划状态。

## 11. 边界与开放项 <a id="boundary"></a>

- 真实落表、种子迁移与接库查重随落库阶段；本阶段不建表、不连库。
- 租户模块开关 `sys_tenant_module`（架构 10 §3.4）归租户管理阶段。
- `platform:manage` 鉴权随 RBAC 阶段（后续）。
- 平台域豁免租户解析：当前无租户中间件，天然豁免；02-5-2 落地依赖后以豁免清单标注。
