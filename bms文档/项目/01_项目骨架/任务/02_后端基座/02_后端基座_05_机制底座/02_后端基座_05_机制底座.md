## 3. 任务内容 <a id="content"></a>

1. 机制底座三块接口占位：数据访问底座（异步引擎 / 会话工厂 / 四库方言 / 读写分离）、多租户数据拓扑（三库模型 / 租户解析 / 引擎注册 / 批量迁移）、模块注册表（`sys_module` 声明 / 唯一性校验 / 只读查询）
2. 统一「接口占位」口径：依赖注入可解析、应用可启动不报错、占位返回固定 / 批量数据；不连真库、不跑迁移、不建表
3. 就位后与上层链路联调（认证 / RBAC 阶段填真实实现）

## 4. 完成标准 <a id="accept"></a>

三块机制底座的接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位返回固定 / 批量数据可支撑上层链路；`GET /api/v1/modules` 契约正确且无写接口暴露；`pytest`、`ruff`、`pyright` 全绿。**不连真库、不跑迁移、不建表**。
