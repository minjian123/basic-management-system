## 1. 概述 <a id="overview"></a>

- **目标**：落地 SQLAlchemy 2.0 **异步**数据访问底座——异步引擎 / 会话工厂接口、`DbUnitOfWork`、基类异步切换（`BaseRepository` / `BaseMemoryRepository` / `BaseDbRepository` / `BaseService` / `BaseTransactionalService`）、分页与软删除过滤回填、读写分离上下文标记与钩子、乐观锁冲突转译；上层 demo 链路随之一并切异步。
- **范围**：`app/db/{engine,session,unit_of_work}.py`、`app/core/context.py`（只读标记）、repositories / services / demo / api 异步切换、单测适配与新增。
- **不含**（归后续）：真实四库连通与集成用例、连接池实测、`BaseDbRepository` 真实 CRUD 与软删除 SQL 落地、读写分离真实路由（主从拓扑）、达梦 `asyncio.to_thread` 封装实测、多租户引擎注册（02-5-2）。
- **依据**：需求 [02-14](../../../../../需求/02_需求_后端基座.md#r02-14)、《[架构设计 · 数据访问与分片](../../../../../../../设计/架构设计/12_架构设计_子系统_数据访问与分片.md)》、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》§8、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |
| --- | --- |
| `app/db/{engine,session}.py` 仅占位；`BaseMemoryRepository` / `BaseService` 为同步 | 无异步引擎 / 会话工厂；无 `DbUnitOfWork`；基类未异步 |
| `BaseDbRepository` 占位 raise；`_resolve_binding` 固定 `default` | 无分页 / 软删除回填；无只读上下文标记；无乐观锁转译 |
| demo 链路同步（api / service / repo / tests） | 随基类一并切异步 |

## 4. 引擎 / 会话 / 工作单元设计 <a id="db"></a>

### 4.1 异步引擎工厂 `app/db/engine.py` <a id="engine"></a>

`EngineFactory(BaseObject)`：按数据源创建并缓存 `AsyncEngine`。

| 成员 | 说明 |
| --- | --- |
| `__init__(settings)` | 注入配置（URL 经配置基座读取） |
| `create(db_key="platform") -> AsyncEngine` | `platform` / `archive` / 其余按租户库 URL；`create_async_engine(url, pool_pre_ping=True)`，非 SQLite 附连接池参数（`pool_size` / `max_overflow` / `pool_timeout` / `pool_recycle`）；按 `db_key` 缓存 |
| `dispose() -> None`（async） | 释放全部缓存引擎 |

- 方言：SQLite `sqlite+aiosqlite`（开发 / 测试）、MySQL `mysql+aiomysql`、PostgreSQL `postgresql+psycopg`、达梦 `dm+dmPython`（同步驱动经 `asyncio.to_thread` 封装，URL 口径由配置提供）；建引擎**不建连**。

### 4.2 会话工厂 `app/db/session.py` <a id="session"></a>

| 成员 | 说明 |
| --- | --- |
| `build_session_factory(engine) -> async_sessionmaker[AsyncSession]` | `expire_on_commit=False` |
| `get_db(request) -> AsyncIterator[AsyncSession]` | 请求级依赖：经 `app.state.engine_factory` 建会话，`async with factory()` 保证释放；**禁止跨请求共享** |

### 4.3 工作单元 `app/db/unit_of_work.py` <a id="uow"></a>

| 成员 | 说明 |
| --- | --- |
| `UnitOfWork.begin() -> AsyncContextManager[None]` | 事务边界改异步 |
| `commit()` / `rollback()` | 改 `async def` |
| `session -> AsyncSession \| None` | 请求级会话 |
| `NullUnitOfWork` | 空事务（`asynccontextmanager` 无操作） |
| `DbUnitOfWork(session)` | `begin()` 返回 `session.begin()`；`commit/rollback` 委派会话 |

### 4.4 只读标记与绑定 `app/core/context.py` + `app/db/routing.py` <a id="routing"></a>

- `context.py`：`read_only: ContextVar[bool]`（默认 False）+ `set_read_only()` / `reset_read_only()` / `is_read_only()`。
- `routing.py`：`WRITE_BINDING = "default"`、`READ_BINDING = "default"`（**本阶段主从同源**，回补时读走副本）。
- `BaseRepository._resolve_binding(*, read_only=None)`：为空取上下文标记，返回对应绑定键（当前同为 `default`）。

## 5. 基类异步切换 <a id="async-base"></a>

| 基类 | 变更 |
| --- | --- |
| `BaseRepository[ModelT]` | `list` / `get` / `count` / `create` / `update` / `delete` 改 `async def`；`exists` 异步派生；新增 `list_page(query)` / `list_cursor(query)` 派生分页；`_resolve_binding` 接只读标记；新增 `_guard_version()` 异步上下文转译 `StaleDataError → ConcurrentConflictError` |
| `BaseMemoryRepository[ModelT]` | 字典存储改异步实现（模块 `_build` / `_apply` 仍同步） |
| `BaseDbRepository[ModelT]` | 异步占位（`NotImplementedError`）；软删除过滤（`deleted_at IS NULL`）、真实 CRUD、乐观锁转译随落库阶段回补 |
| `BaseService[ModelT]` | CRUD 改 `async def`；新增 `page` / `cursor_page` 返回分页响应契约 |
| `BaseTransactionalService[ModelT]` | `async with self._uow.begin()` 包写操作 |

- 分页复用 [02-2-3 请求 / 响应基类](../../../../02_后端基座/02_后端基座_02_模块基类/02_后端基座_02_模块基类_03_请求响应基类/02_后端基座_02_模块基类_03_请求响应基类.md) 的 `BasePageQuery` / `BasePageResponse` / `BaseCursorQuery` / `BaseCursorResponse`；软删除过滤在 DB 侧由 `deleted_at` 处理（内存基线无该字段）。

## 6. 上层链路适配 <a id="adapt"></a>

- `DemoService`：方法改 `async def` 并 `await` 基类。
- `api/demo.py`：端点改 `async def` + `await`（FastAPI 原生支持）。
- `main.py`：`app.state.engine_factory = EngineFactory(get_settings())`（`get_db` 依赖注入来源）；demo 服务仍用内存基线。
- 既有 `pytest` 用例（repositories / services / api）适配 `async` / `await`。

## 7. 测试设计（Kiwi 先行） <a id="tests"></a>

| Kiwi | 用例 | 断言要点 |
| --- | --- | --- |

| 25 | 会话工厂 / get_db | `build_session_factory` 产出 `AsyncSession`；会话可开关 |
| 25 | 工作单元 | `NullUnitOfWork.begin()` 异步空事务；`DbUnitOfWork` 用会话 `begin/commit` |
