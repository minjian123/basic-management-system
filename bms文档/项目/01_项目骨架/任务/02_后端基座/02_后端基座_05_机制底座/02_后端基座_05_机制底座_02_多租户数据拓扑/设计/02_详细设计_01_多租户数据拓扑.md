## 4. 三库声明与建库标准 <a id="databases"></a>

| 库 | 命名 | 用途 | 开发环境（SQLite） |
| --- | --- | --- | --- |
| 平台库 | `bms_platform` | 租户注册、平台统一菜单 / 权限码、模块注册 | `bms_platform.db` |
| 租户库 | `bms_tenant_{code}`（`code` 全小写） | 一租户一库，业务数据 | `bms_tenant_demo.db` |
| 归档库 | `bms_archive` | 归档数据统一收存（只读） | `bms_archive.db` |

- 环境库命名 `bms_dev` / `bms_test` / `bms_prod`；建库字符集：MySQL `utf8mb4`、PostgreSQL `UTF8`、达梦 `UTF8`（schema 前缀 `bms_dev`，小写标识符）。
- 跨库引用一律逻辑外键（code），不建物理外键；跨库查询禁止 JOIN（服务层聚合 / 事件同步）。
- 配置以 `DatabaseSettings` 三目标（`platform` / `tenants` / `archive`）承载，dev 默认多 SQLite 文件。

## 5. `sys_tenant` 模型 <a id="tenant-model"></a>

`app/models/platform.py`：`SysTenant(BaseModel)`，`__tablename__ = "sys_tenant"`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `String(64)` | 租户编码（全小写），`(code, deleted_at)` 唯一 |
| `name` | `String(128)` | 租户名称 |
| `domain` | `String(255)` nullable | 子域名（`idx_domain`） |
| `db_key` | `String(64)` | 数据源键（`tenant_{code}`） |
| `status` | `String(16)` | 状态（active / suspended） |
| `expire_at` | `DateTime` nullable | 到期时间 |

- 继承 `BaseModel`（雪花 ID / 审计 / 软删除 / 乐观锁）；占位数据 `demo` 租户以固定值返回（不落表）。

## 6. 租户解析与上下文 <a id="resolve"></a>

`app/db/tenant.py`：

| 成员 | 说明 |
| --- | --- |
| `TenantContext(BaseObject)` | `tenant_code` / `db_key` / `name`；`DEMO_TENANT` 占位 |
| `TENANT_EXEMPT_PATHS` | `/`、`/docs`、`/openapi.json`、`/healthz`、`/readyz`、平台级接口预留 |
| `is_exempt_path(path)` | 豁免判定 |
| `resolve_tenant(*, host, header, token_tenant)` | 解析链：子域名 → `X-Tenant-ID` → token 内 tenant_id；命中 demo 返回；未知抛 `TenantNotFoundError`（404 / 80001）；无来源回落 demo（开发兜底） |
| `get_tenant(request)` | FastAPI 依赖：豁免路径放行（返回 None），否则解析并返回 `TenantContext` |

- `TenantContext` 经依赖注入传入 services / repositories；**禁止全局单例持有租户引擎**。

## 7. `EngineRegistry` <a id="registry"></a>

`app/db/registry.py`：`EngineRegistry(BaseAsyncResource)`。

| 成员 | 说明 |
| --- | --- |
| `__init__(settings, *, factory=None, max_active=32, idle_timeout=1800)` | 平台引擎常驻；租户引擎懒加载 |
| `get(db_key)` | 取 / 建引擎并刷新 LRU；超 `max_active` 逐出最久未用（dispose） |
| `release(db_key)` | 强制回收（停用租户） |
| `active_keys()` | 当前活跃 `db_key` 列表 |
| `check_connection_budget(workers, pool, max_connections)` | 连接预算：`workers × (pool_size + max_overflow) ≤ max_connections × 70%` |
| `aclose()` | 释放全部引擎（幂等） |

- 并发保护占位：每 `db_key` 一把 `asyncio.Lock`；Redis `SETNX` 钩子预留（不真连）。

## 8. Alembic 与脚本占位 <a id="migrate"></a>

- `backend/alembic/env.py`：迁移环境骨架（URL 经配置 / 环境变量读取，offline / online 分支占位）；`script.py.mako` 模板；`versions/.gitkeep`；`alembic.ini` 补 `script_location`。真实迁移与种子归 **03-6**。
- `backend/ops/migrate_tenants.py`：`--target all|tenant_code|platform`、`--db mysql|postgres|dameng|sqlite`、`--dry-run`；逐库执行（失败不中断、幂等约定）——本阶段 `--dry-run` 输出固定库清单。
- `backend/ops/init_tenant.py`：`--code`、`--dry-run`；建库 → 迁移 → 幂等种子步骤占位。
- `core/error_codes.py` 增 `TENANT_NOT_FOUND = 80001`；`core/exceptions.py` 增段位基 `OpenTenantError`（8xxxx）与 `TenantNotFoundError`（80001 / 404）。
