## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：后端基座体系 54 条需求——根基类与集合体系登记（02-1 ~ 02-4）、模块基类落地（02-5 ~ 02-8）、core 横切基座（02-9 ~ 02-12）、跨阶段基座登记（02-13）、机制底座接口占位（02-14 ~ 02-16）、跨阶段基座扩展（02-17 ~ 02-28）、横切扩展基座（02-29 ~ 02-41）、前端组件支撑基座（02-42 ~ 02-53）、工厂基座（02-54）。
- **依据**：[需求 · 后端基座](../../需求/02_需求_后端基座.md)、《[架构设计 · 后端基础类体系](../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「基座分层」节「阶段交付与跨阶段基座契约」节、《[后端开发规范](../../../../规范/后端开发规范.md)》「后端基座体系」节、《[命名规范](../../../../规范/命名规范.md)》「后端命名」节「数据库命名」节、《[数据库开发规范](../../../../规范/数据库开发规范.md)》、《[API接口规范](../../../../规范/API接口规范.md)》。
- **口径**：机制类（数据访问 / 多租户拓扑 / 模块注册）只落**接口占位**——依赖注入可解析、应用可启动、占位返回固定 / 批量数据；**不连真库、不跑迁移、不建表**，真实实现随后续 后端基座回补。
- **命名规则（强制）**：基类一律 `Base` 打头，非 `Base` 打头为继承基类的具体实现类。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：117h（01 1h + 02 18h + 03 33h + 04 58h + 05 7h；其中 02 / 03 / 04 / 05 为含嵌套子任务的父任务；04 含自有内容 8h）。后追加的嵌套子任务（需求 02-42 ~ 02-53 前端组件支撑基座 12 条 / 39h、需求 02-54 工厂基类 12h）随阶段一补做窗口实施，父任务 03 / 04 由「已完成」重开为「部分完成」。
- **关键依赖**：03 → 工程骨架（01_03 交付件）；02 → 03（异常体系，服务基座统一不存在语义）；05 → 02（仓储 / 模型基类）与 03（配置 / 异常）；01 → 工程骨架（01_03 交付件，登记核对）；04 → 01 ~ 03（跨阶段基座登记 + 扩展基座接口占位）；**02-42 → 02-31 / 02-20 / 02-25（验证码域扩展与渠道 / 限流协作）；02-43 ~ 02-53 → 02_04 与各自协作基座（数据范围 / 脱敏 / 缓存 / 查询提供者 / 对象存储 / 推送 / 排序 / 降级 / LLM / 多租户）**。
- **风险**：占位实现「能跑不报错」要求被弱化（以上层占用契约用例护栏）；机制类真实实现推迟到后续阶段需回填并补实测（三库 / 达梦 / 租户隔离）；`BaseModel` 四库类型映射与实际落库差异（映射随需求固化并在模型注释标注）。
