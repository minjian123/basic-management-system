## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：后端基座（地基波）六块——基座与异常体系（异常体系与统一响应、core 基座补齐与登记）、数据访问底座（SQLAlchemy 异步底座与基类异步切换）、多租户数据拓扑（三库拓扑 / 模型基类 / 平台库表 / 租户解析 / 引擎池 / 批量迁移）、模块注册表（`sys_module` 与种子 / 唯一性校验 / 查询接口）、CI 与阶段验收（三库集成 / M1 门禁核对 / 测试报告）、跨阶段基座（六类基座登记与按阶段回补）。
- **定位**：后端**全部模块的前置地基**——基类与基座先立，后续认证 / RBAC / 通用能力等模块才有统一写法；本域不在工程骨架期完成，后续模块就会各自定义异常、会话、路由与注册，口径必然发散。
- **依据**：[需求 02-1 ~ 02-16](../../需求/02_需求_后端基座.md#r02-1)、《[架构设计 · 后端基础类体系](../../../../设计/架构设计/33_架构设计_后端基础类体系.md)》「基座分层」节「阶段落地（地基波 + 回补）」节、《[架构设计 · 数据访问与分片](../../../../设计/架构设计/09_架构设计_子系统_数据访问与分片.md)》、《[架构设计 · 多租户路由](../../../../设计/架构设计/08_架构设计_子系统_多租户路由.md)》、《[架构设计 · 模块注册](../../../../设计/架构设计/07_架构设计_子系统_模块注册.md)》、《[后端开发规范](../../../../规范/后端开发规范.md)》「后端基座体系」节、《[数据库开发规范](../../../../规范/数据库开发规范.md)》、《[API接口规范](../../../../规范/API接口规范.md)》。
- **边界**：基座对**配置**只提供统一入口的方法与结构（占位实现），真实读取由「[03 后端基础能力](../03_后端基础能力/03_后端基础能力.md)」的配置管理落地；认证 / RBAC 等能力的**具体实现**、真实分片规则、缓存三防加固归对应阶段；前端组件库与业务模块不在本域。

## 3. 工时与依赖 <a id="effort"></a>

- **工时合计**：63h（10 + 12 + 19 + 6 + 8 + 8；16 条需求、16 个子任务）。
- **关键依赖**：01 域为其余各域前置（异常与统一响应先行）；02 域为 03 域前置（引擎 / 会话 / 方言就绪后拓扑与迁移才可落地）；04 域依赖 02 / 03 域（`sys_module` 复用 `BaseModel` 与迁移流水线）；05 域依赖 01~04 域（三库集成与门禁核对在其后）；06 域依赖 01~03 域（登记六类基座契约）。上游依赖工程骨架（backend 工程、分层目录、core 基座首批已交付）。
- **下游**：后续认证 / RBAC / 通用能力 / 工作流等全部后端模块，以及产品仓库后端模块（按本域基类与基座写法接入）。
- **风险**：达梦方言差异与 dmPython 同步驱动接入（02 / 03 / 05 域受阻）；基类异步切换为一次性调用面改动（回归风险，以用例护栏 + 同步内存基线作测试替身）；跨阶段基座易在后续模块各自实现（以登记与回补窗口约束）；三库集成 job 依赖 registry / 网络（以激活开关守卫）。
