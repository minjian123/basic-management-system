## 3. 任务内容 <a id="content"></a>

1. 异步引擎与会话工厂：按数据源创建 / 缓存 `AsyncEngine`（连接池参数、超时、`pool_pre_ping`；取值经配置基座读取接口，真实读取随 [03 后端基础能力](../../03_后端基础能力/03_后端基础能力.md) 配置管理落地），`async_sessionmaker` + 请求级会话、事务边界显式
2. 四库方言与例外口径：MySQL / PostgreSQL / 达梦 DM8 / SQLite 适配；达梦同步驱动（dmPython）经 `asyncio.to_thread` 封装
3. 基类异步切换与读写分离占位：数据库实现覆写原子方法为异步、分页与软删除过滤等通用能力回填基类（只改基类，模块类不动）、读写路由接口占位（本阶段主从同源）

## 4. 完成标准 <a id="accept"></a>

异步引擎与会话工厂可用、事务边界正确；四库方言可切换（SQLite 单测通过、三库集成随 [05 CI 与阶段验收](../02_后端基座_05_CI与阶段验收/02_后端基座_05_CI与阶段验收.md)）；基类异步切换完成且调用面一致；分页 / 软删除过滤在基类生效；读写分离占位可用；`pytest`、`ruff`、`pyright` 全绿（逐项验收见子任务清单）。
