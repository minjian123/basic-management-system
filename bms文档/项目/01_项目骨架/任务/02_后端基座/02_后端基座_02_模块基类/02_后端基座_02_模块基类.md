## 3. 任务内容 <a id="content"></a>

1. 模块基类落地四套：`BaseRepository[T]`、`BaseService[T]`、`BaseSchema`、`BaseModel`（数据库实现占位，不连库）
2. 继承约定统一登记：模块仓储 / 服务 / 请求响应 / 模型必须继承对应基类，只写差异与业务规则，禁止绕过基类另起炉灶
3. 基类单测：四套基类的通用行为与继承生效（内存基线作为测试替身）

## 4. 完成标准 <a id="accept"></a>

四套模块基类可继承、通用行为正确（基类单测通过）；数据库实现为占位且不连库；继承约定纳入规范；`pytest`、`ruff`、`pyright` 全绿。
