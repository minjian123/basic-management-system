## 2. 任务内容 <a id="content"></a>

1. 仓储基类分层：`BaseRepository[T]`（契约：CRUD 抽象 + `exists` 派生 + 数据源 / 分片路由钩子）与 `BaseMemoryRepository[T]`（内存基线：字典存储 + `_build` / `_apply`）
2. 数据库实现骨架 `BaseDbRepository[T]`（占位、不连库），继承契约层；真实实现归 02-5-1
3. 继承约定：模块仓储继承 `BaseMemoryRepository`（内存）或 `BaseDbRepository`（数据库），只写差异
4. 基类单测：契约 / 内存基线 / DB 骨架与路由钩子

## 3. 完成标准 <a id="accept"></a>

`BaseRepository[T]` 可继承、`exists` / `count` 行为正确（基类单测通过）；数据库实现为占位且不连库；继承约定纳入规范；`pytest`、`ruff`、`pyright` 全绿。
