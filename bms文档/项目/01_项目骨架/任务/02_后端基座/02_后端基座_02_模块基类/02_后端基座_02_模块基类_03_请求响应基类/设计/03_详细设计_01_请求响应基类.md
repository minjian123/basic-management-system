## 1. 概述 <a id="overview"></a>

- **目标**：把序列化取字段口径**上提到 `BaseObject`（L0）**——「声明字段优先」：dataclass → `dataclasses.fields`；Pydantic → `model_dump()`；其余 → `__dict__` 兜底；`BaseSchema` 只需 Pydantic 公共配置，天然获得分型序列化；并新增**公共分页契约层**（页码 + 游标）。
- **范围**：`BaseObject._public_fields` 口径升级、`BaseSchema` 契约、`pagination.py` 四个分页契约基类、继承与使用约定登记、单测。
- **不含**（归相邻任务）：`ApiResponse` 统一响应与错误码（[02-3-1](../../../02_后端基座_03_core横切基座/02_后端基座_03_core横切基座_01_异常体系与统一响应/02_后端基座_03_core横切基座_01_异常体系与统一响应.md) 复用本任务分页契约作 `data` 载荷）；`BaseModel`（02-2-4）；仓储 / 服务基类（02-2-1 / 02-2-2）。
- **依据**：需求 [02-7](../../../../../需求/02_需求_后端基座.md#r02-7)、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「基类清单与继承链」节「各层基类与模块约定」节、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节、《[API接口规范](../../../../../../../规范/API接口规范.md)》「参数与分页」节、01-3-1《基础类详细设计》§4/§8。
- **L0 触及说明**：本次升级 `BaseObject`（02-01 交付件）的序列化实现，不改变其对外契约（`to_dict` / `to_json` 签名）；登记回写《架构设计 · 后端基础类体系》§4「BaseObject」职责与《后端开发规范》§3.2。

## 2. 现状与差距 <a id="gap"></a>

| 现状 | 差距 |
| --- | --- |
| `BaseObject._public_fields`：dataclass 走 `dataclasses.fields`，**其余一律 `__dict__` 公开项** | `__dict__` 太弱：依赖实例状态；Pydantic 的**别名 / 排除 / 计算字段**缺失 |
| `BaseSchema(BaseModel, BaseObject)` 仅 `model_config` | 契约未定型；序列化受上述 `__dict__` 限制 |
| 无公共分页契约 | 模块各自定义分页结构与字段，口径易发散 |

**取字段口径对比**（实测 Pydantic v2）：

| 口径 | 字段来源 | 别名 / 排除 | 计算字段 | 适用 |
| --- | --- | --- | --- | --- |
| `__dict__` | 实例字典 | ❌ | ❌ | 任意（兜底） |
| `dataclasses.fields` | 类声明字段 | — | — | dataclass |
| Pydantic `model_fields` + getattr | 类声明字段 | ❌ | ❌ | Pydantic |
| Pydantic `model_dump()` | Pydantic 序列化器 | ✅ | ✅ | Pydantic |

选型：**声明字段优先**——dataclass 用 `dataclasses.fields`；Pydantic 用 `model_dump()`（声明字段的完整形态）；其余 `__dict__` 兜底。

## 4. 序列化口径设计（BaseObject） <a id="base-object"></a>

`app/core/base.py`：`_public_fields` 改为**声明字段优先**，其余保持（`to_dict` 递归 `_convert`、`to_json` 走 `core/serialization` 稳定序）。

| 对象类型 | 取字段 | 说明 |
| --- | --- | --- |
| Pydantic（有 `model_dump` 与 `model_fields`） | `self.model_dump()` | 覆盖字段、别名默认口径、排除、计算字段；嵌套模型由 Pydantic 序列化为 dict |
| dataclass | `dataclasses.fields` + getattr | 声明序稳定（现状保留） |
| 其他 | `__dict__` 公开项 | 无声明元数据时兜底 |

```python
def _public_fields(self) -> dict[str, object]:
    """取公开字段：Pydantic 序列化器 → dataclass 声明字段 → 实例字典兜底。"""
    model_dump = getattr(self, "model_dump", None)
    if callable(model_dump) and getattr(type(self), "model_fields", None) is not None:
        return cast("dict[str, object]", model_dump())
    if dataclasses.is_dataclass(self) and not isinstance(self, type):
        ...
    return {k: v for k, v in getattr(self, "__dict__", {}).items() if not k.startswith("_")}
```

- 影响评估：集合类自带 `to_dict`（覆盖）；Redis 封装 / 仓储 / 服务等非 dataclass / 非 Pydantic 对象仍走 `__dict__`，行为不变；Pydantic 输出由「字段名 + 计算字段」补齐（默认 `by_alias=False`，字段名即接口契约）。

## 5. BaseSchema 设计 <a id="base"></a>

`app/schemas/base.py`：

| 成员 | 说明 |
| --- | --- |
| `model_config = ConfigDict(from_attributes=True, str_strip_whitespace=True)` | ORM / 实体直接校验；字符串去首尾空白 |
| 序列化 | **不覆写**：继承 `BaseObject`，经声明字段优先口径获得 `to_dict` / `to_json`（稳定序） |

- 继承链：`BaseSchema → (pydantic.BaseModel, BaseObject)`；Pydantic 自身 `__eq__/__repr__/model_dump` 语义优先。
- 公共字段（`id` / 时间戳）由模块声明或 `BaseModel`（02-2-4）承载；统一响应 `ApiResponse` 归 02-3-1。
- 禁止请求 / 响应模型直接继承 `pydantic.BaseModel`。

## 6. 公共分页契约层设计 <a id="pagination"></a>

`app/schemas/pagination.py`（字段口径依《API接口规范》「参数与分页」节）：

| 基类 | 字段 | 说明 |
| --- | --- | --- |
| `BasePageQuery` | `page: int = 1`（`ge=1`）、`size: int = 20`（`ge=1, le=200`） | 页码分页请求 |
| `BasePageResponse[ItemT]` | `list: list[ItemT]`、`total: int`、`page: int`、`size: int` | 页码分页响应 |
| `BaseCursorQuery` | `cursor: str \| None = None`、`limit: int = 20`（`ge=1, le=200`） | 游标分页请求（日志 / 审计等大数据量） |
| `BaseCursorResponse[ItemT]` | `list: list[ItemT]`、`next_cursor: str \| None`、`has_more: bool` | 游标分页响应 |

- 分页基类继承 `BaseSchema`；泛型用 PEP 695 `[ItemT]`（Pydantic v2 / Python 3.14 支持），实现期若类型检查受限回退 `Generic[ItemT]`。
- 排序 / 筛选参数不进通用分页基类（模块按需扩展）；`cursor` 为不透明串，首页传 `None`。

## 7. 继承与实现约定（登记） <a id="convention"></a>

- 请求 / 响应模型**必须**继承 `BaseSchema`（或分页契约基类），禁止直接继承 `pydantic.BaseModel`。
- 列表接口分页统一用页码或游标契约；`ApiResponse.data` 分页载荷复用上述响应基类。
- 序列化一律走基类口径（声明字段优先），模块类不得各自实现序列化。
- 登记落点：《架构设计 · 后端基础类体系》§4「BaseObject」职责与分页契约基类、§7 模块约定；《后端开发规范》§3.2 / §3.4。

## 11. 边界与开放项 <a id="boundary"></a>

- `ApiResponse` / 错误码 / 全局响应结构归 02-3-1；其分页 `data` 复用本任务分页响应基类。
- 默认 `model_dump()` 用字段名（`by_alias=False`，字段名即接口契约）；需要别名输出时由调用方显式 `model_dump(by_alias=True)`。
- 排序 / 筛选 / 字段白名单属模块 Query 扩展；分页执行（limit/offset、游标查询）属 repositories / services。
- 若 Pydantic 对 PEP 695 泛型支持有版本限制，回退 `Generic[ItemT]`（实现期校验）。
