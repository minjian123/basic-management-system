## 2. 任务内容 <a id="content"></a>

1. 序列化口径上提 `BaseObject`（L0）：声明字段优先（dataclass → `dataclasses.fields`；Pydantic → `model_dump()`；其余 → `__dict__`），`to_json` 走稳定 JSON
2. `BaseSchema`：Pydantic 公共配置（`from_attributes` / `str_strip_whitespace`），经 `BaseObject` 获分型序列化
3. 公共分页契约层（`app/schemas/pagination.py`）：`BasePageQuery` / `BasePageResponse` / `BaseCursorQuery` / `BaseCursorResponse`
4. 继承约定：请求 / 响应模型必须继承 `BaseSchema`（或分页契约基类），禁止直接继承 `pydantic.BaseModel`
5. 基类单测：分型序列化（Kiwi 14）、公共配置与分页契约（Kiwi 13）

## 3. 完成标准 <a id="accept"></a>

`BaseSchema` 可继承、公共配置与序列化行为正确（基类单测通过）；继承约定纳入规范；`pytest`、`ruff`、`pyright` 全绿。
