## 3. 实施过程 <a id="process"></a>

1. **事务钩子**：`app/services/base_service.py` 新增 `_transaction() -> AbstractContextManager[None]`，占位返回 `contextlib.nullcontext()`。
2. **写操作包裹**：`create` / `update` / `delete` 委派仓储时包入 `with self._transaction():`；缺失分支抛 `NotFoundError` 同样在事务内；`list` / `get` / `exists` / `count` 只读不包。
3. **登记**：《架构设计 · 后端基础类体系》§7 模块约定、《后端开发规范》§3.4 服务基类条补「事务边界由基类 `_transaction` 钩子统一」。
4. **测试**：`tests/services/test_base_service.py` 增 spy 子类 `SpyService` 与 `test_transaction_hook_wraps_writes_only`（Kiwi 12），校验写操作进入、只读不进入、缺失分支在事务内抛错。
5. **验证**：`uv run pytest` / `uv run ruff check .` / `uv run pyright` 全绿，覆盖率 100%（详见[测试记录](../测试/01_测试_01_服务基类.md)）。

关键命令：

```bash
uv run pytest --cov=app -q
uv run ruff check .
uv run pyright
```
