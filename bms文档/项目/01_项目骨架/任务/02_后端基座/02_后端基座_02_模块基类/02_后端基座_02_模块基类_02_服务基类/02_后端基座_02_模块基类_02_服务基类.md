## 2. 任务内容 <a id="content"></a>

1. 服务基类分层：`BaseService[T]`（通用 CRUD 委派仓储 + 统一不存在语义，`NotFoundError` 占位）与 `BaseTransactionalService[T]`（事务扩展层，写操作经 `UnitOfWork` 进入事务）
2. 新增工作单元 `UnitOfWork` / `NullUnitOfWork`（`app/db/unit_of_work.py`）：事务公共方法 `begin` / `commit` / `rollback` 单点收敛
3. 继承约定：模块服务按需继承两层基类，只写业务规则；不得拼 SQL、不得跨模块直连仓储、不得自起事务
4. 基类单测：CRUD 委派与不存在语义、事务包裹范围、工作单元占位

## 3. 完成标准 <a id="accept"></a>

`BaseService[T]` 可继承、不存在语义行为正确（基类单测通过）；继承约定纳入规范；`pytest`、`ruff`、`pyright` 全绿。
