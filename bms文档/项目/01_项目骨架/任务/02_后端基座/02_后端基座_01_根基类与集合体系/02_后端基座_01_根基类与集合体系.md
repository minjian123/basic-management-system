## 2. 任务内容 <a id="content"></a>

1. L0 根基类 `BaseObject`（`app/core/base.py`）登记：序列化、稳定序序列化、统一字符串输出、主键相等与哈希——公共方法唯一落点，登记职责与继承链
2. 有序集合登记：`BaseSorted[T]`（`app/core/collections.py`）→ `SortedList` / `SortedDict` / `SortedSet`（插入即有序），「对外输出必须稳定序、公共位置一律使用有序集合」强制口径
3. 进程内并发集合登记：`BaseConcurrentSorted`（`app/core/concurrent.py`，锁策略守卫 + SNAPSHOT 写时复制）→ `ConcurrentSorted*`（读写锁 / 单锁 / 分片锁 / 快照替换四种锁策略），原子复合方法与遍历取快照约定
4. 跨副本 Redis 封装登记：`app/core/redis_collections.py`（Redis 唯一事实源 + 本进程只读快照 + 版本号惰性比对 + Lua / WATCH 复合操作），「禁止进程内集合跨副本共享」约定
5. 登记职责、继承关系与代码位置回写《架构设计 · 后端基础类体系》与《后端开发规范》；标注「模块类不得重复实现基类公共方法」

## 3. 完成标准 <a id="accept"></a>

四条继承链（`BaseObject`；`BaseSorted` → `Sorted*`；`BaseConcurrentSorted` → `BaseSorted`；`redis_collections` 封装）的职责 / 代码位置在架构节点与规范一致、可核对；「对外稳定序」与「禁止进程内集合跨副本共享」约定纳入规范且可核对；`pytest`、`ruff`、`pyright` 全绿。
