## 3. 任务内容 <a id="content"></a>

1. 根基类（L0）：`BaseObject`（`to_dict` / `to_json` / `__str__` / `__repr__` / `__eq__` / `__hash__`）作为公共方法唯一落点，登记其职责与继承链
2. 集合体系：有序集合（`BaseCollection` → `SortedList` / `SortedDict` / `SortedSet`）、进程内并发集合（`ConcurrentSorted*` 四种锁策略）、跨副本 Redis 封装（`redis_collections`：ZSET / Hash / List + Lua 复合操作）——登记职责、继承关系与代码位置
3. 登记回写：《[架构设计 · 后端基础类体系](../../../../../设计/架构设计/33_架构设计_后端基础类体系.md)》与《[后端开发规范](../../../../../规范/后端开发规范.md)》保持同源一致；标注「模块类公共能力只加到基类」的强制约定

## 4. 完成标准 <a id="accept"></a>

基座分层图与基类清单（L0 + 集合体系）在架构节点与规范一致、无缺项；各基类职责 / 继承关系 / 代码位置可核对；继承约定（模块类不得重复实现基类公共方法）纳入规范（详见子任务清单）。
