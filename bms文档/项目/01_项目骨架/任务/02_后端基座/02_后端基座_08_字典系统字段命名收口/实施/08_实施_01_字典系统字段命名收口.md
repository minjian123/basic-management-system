## 3. 实施过程 <a id="process"></a>

1. **先改限定名**：`SysDictType.type` → `.code`、`SysDictItem.type_id` → `.dict_type_id`、`SysDictAttr.type_id` → `.dict_type_id`、`SysDictItem.label` → `.name`（限定名替换不会误伤契约对象 `DictItem.label`，后者是 pydantic 契约而非 ORM 行）。
2. **再改裸引用**：`row.type` / `type_row.type` / `row.type_id` / `row.label` / `item.type_id`、构造关键字 `type=payload.type` / `label=payload.label` / `type_id=type_row.id`、按类型码判存 `SysDictType.type == ...`。
3. **模型与索引**：改列定义、唯一约束列与索引定义（`idx_dict_item_label` → `idx_dict_item_name`）。
4. **迁移**：`batch_alter_table` 改名 + 索引先删后建（SQLite 重建表；MySQL 8 / PostgreSQL / 达梦按方言 `RENAME COLUMN`）；不改类型 / 可空性、不动数据、**无回填**。
5. **接口层**：`_type_out` / `_item_out` / `_attr_out` 仅改取值属性，**响应字段名不变** ⇒ 契约与前端零改动。
