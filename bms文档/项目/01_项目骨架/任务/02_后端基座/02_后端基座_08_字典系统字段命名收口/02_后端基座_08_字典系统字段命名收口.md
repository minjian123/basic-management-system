## 2. 任务内容 <a id="content"></a>

按《[数据库开发规范](../../../../../规范/数据库开发规范.md)》「系统字段（基础 / 表单 / 字典统一口径）」节 §3.1.4 的**收口项**，把字典侧列名对齐到规范口径（列名 + ORM 属性 + 索引名；**API 契约字段名与前端不动**，见详细设计决策记录）：

1. **`sys_dict_type.type` → `code`**（代码列）：模型属性、服务层（类型 CRUD 与按类型码查）、种子、取数、迁移与索引。
2. **`sys_dict_item.label` → `name`**（名称列，走 `_i18n` 附表，主表列为派生快照）。
3. **`sys_dict_item.type_id` → `dict_type_id`、`sys_dict_attr.type_id` → `dict_type_id`**（主表 ID 口径 `{主表}_id`，与 `sys_dict_item_i18n.dict_item_id` / `sys_dict_type_i18n.dict_type_id` 同形态）。
4. **索引随列重建**（命名含列名）：`idx_dict_item_value`、`idx_dict_item_parent_sort`、`idx_dict_item_label` → `..._name`、`idx_sys_dict_item_type_id` → `..._dict_type_id`、`idx_dict_attr_sort`；唯一约束列同步。
5. **迁移**：`platform:tenant` 链新迁移（`batch_alter_table` + `alter_column(new_column_name=...)`，四库兼容写法；SQLite 经重建）。
6. **文档回写**：`sys_dict_type.md` / `sys_dict_item.md` / `sys_dict_attr.md` 字段表与索引表 + 变更记录、《概要设计 · 字典管理》「核心表」节、需求 02-44 / 02-56 注块、《组件设计 · 字典字段》相关字段清单。

## 3. 完成标准 <a id="accept"></a>

列名与规范 §3.1.3 字典清单一致（类型 `code` / `name` / `status` / `sort`；条目 `code` / `name` / `status` / `sort` / `parent_id` / `dict_type_id`），字典取数 / 翻译 / 级联 / 写路径 / 种子 / 高级查询全部跑通；迁移在 SQLite 实测通过、脚本按四库兼容写法（真库执行随部署窗口）；`pytest` / `ruff` / `pyright` 全绿；表文件、概要设计、组件设计与需求注块回写齐备；实施 / 测试记录落盘。
