## 4. 安全中间层与接口设计 <a id="security"></a>

`app/core/security.py`：所有安全原语继承**中间层基类 `BaseSecurity`**（`BaseSecurity → BaseObject`），统一安全约定（密钥只走环境变量、不落日志 / 配置、脱敏），真实实现随认证阶段。

```python
class BaseSecurity(BaseObject, ABC):
    """安全原语中间层基类：统一安全约定与入口。"""
```

| 原语类 | 父类 | 方法签名（占位抛 `NotImplementedError`） |
| --- | --- | --- |
| `PasswordHasher` | `BaseSecurity` | `hash(password) -> str`（bcrypt / argon2）；`verify(password, hashed) -> bool` |
| `TokenCodec` | `BaseSecurity` | `encode(claims, expires_in=None) -> str`（access / refresh）；`decode(token) -> dict[str, object]` |
| `SessionSecurity` | `BaseSecurity` | `new_session_id() -> str`；`fingerprint(ip, user_agent) -> str`；`blacklist_key(session_id) -> str`（Redis 黑名单键） |

- 密码哈希禁止明文 / MD5 / SHA1（bcrypt / argon2）；token 双 token（access 短时 / refresh 长时 + 黑名单）；均按《安全开发规范》。
- 占位实现统一抛 `NotImplementedError("安全实现随认证阶段接入")`，防止被误用；类本身可实例化（构造可解析、应用可启动）。
- 不做全局单例：由认证阶段按配置注入实现（依赖注入）。

## 5. 应用基类体系 <a id="base"></a>

- `BaseSecurity` 继承 `BaseObject`（L0），统一序列化 / 字符串输出；三个原语类继承 `BaseSecurity`。
- 继承链：`PasswordHasher` / `TokenCodec` / `SessionSecurity` → `BaseSecurity` → `BaseObject`。

## 9. 边界与开放项 <a id="boundary"></a>

- 真实实现（bcrypt/argon2、JWT、会话黑名单）随认证阶段；AuthError / PermissionError 错误码实现随认证 / RBAC。
- 密钥只走环境变量（`BMS_`），不入库、不入镜像、不写日志（配置基座 / 安全规范）。
- 依赖注入提供者由认证阶段按配置基座注入（本阶段仅类与签名）。
