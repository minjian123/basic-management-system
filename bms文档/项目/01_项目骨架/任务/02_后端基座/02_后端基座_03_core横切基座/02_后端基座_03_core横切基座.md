## 3. 任务内容 <a id="content"></a>

1. 异常与统一响应（**落地**）：`BizError` 体系（携带错误码与参数）+ 全局异常处理器 → 统一响应 `{code, message, data}`；`ApiResponse` 模型；错误码段位登记；移除阶段一临时 404 处理器
2. 配置基座（**结构占位**）：`app/core/config.py` 提供配置模型与读取接口的统一入口（分区模型、取值方法），本阶段返回默认值即可；真实 `config.toml` 读取 / 环境分层 / 启动校验由 [03 后端基础能力](../../03_后端基础能力/03_后端基础能力.md) 配置管理落地后回填登记
3. 安全与日志基座（**结构占位**）：`app/core/security.py`（密码哈希 / 令牌与会话原语接口声明）与日志基座接入点（structlog 初始化入口）先落声明；实现随认证阶段与日志体系任务

## 4. 完成标准 <a id="accept"></a>

`BizError` 与统一响应经全局处理器生效、临时处理器移除；配置基座结构就位且真实读取由 03_01 落地后回填登记；安全 / 日志基座接口声明就位、可被上层引用；`pytest`、`ruff`、`pyright` 全绿（逐项验收见子任务清单）。
