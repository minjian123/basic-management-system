## 3. 任务内容 <a id="content"></a>

1. 异常体系**落地**先行：`BizError` 统一异常基类 + 常用子类、全局异常处理器、统一响应 `ApiResponse`、错误码段位骨架；`main.py` 注销临时 404 处理器
2. 配置 / 安全 / 日志**结构占位**：`app/core/config.py` / `security.py` / `logging.py` 的接口与结构声明就位，真实读取与实现分别交由 03 后端基础能力与认证阶段
3. 登记：core 横切基座的职责与代码位置回写《架构设计 · 后端基础类体系》

## 4. 完成标准 <a id="accept"></a>

异常体系与统一响应生效（`BizError` → `{code, message, data}`、未捕获异常 500 不泄露堆栈、临时处理器移除）；配置 / 安全 / 日志结构声明就位并可被上层引用；依赖注入可解析、应用可启动不报错；`pytest`、`ruff`、`pyright` 全绿。
