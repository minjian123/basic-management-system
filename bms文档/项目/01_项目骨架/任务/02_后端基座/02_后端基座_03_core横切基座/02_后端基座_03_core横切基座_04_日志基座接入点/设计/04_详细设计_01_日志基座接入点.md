## 1. 概述 <a id="overview"></a>

- **目标**：落地 `app/core/logging.py` 的**日志基座接入点**——中间层基 `BaseLogger`（`BaseObject` 体系，日志门面）+ 占位实现 `StdoutLogger` + 入口 `configure_logging(settings)` / `get_logger(name)`；标准库 logging 输出 **stdout（不落文件）**，应用工厂接入；真实 structlog 结构化 JSON / 上下文字段 / 脱敏归 03-2。
- **范围**：`app/core/logging.py`（中间层基 + 占位实现 + 入口）、`main.py` 接入、单测。
- **不含**（归相邻任务）：structlog JSON 渲染、上下文字段注入（`trace_id` / `tenant` / `user`）、脱敏过滤器、请求日志中间件（[03-2 日志体系](../../../../../需求/03_需求_后端基础能力.md#r03-2)）；`trace_id` 链路追踪随日志体系 / OpenTelemetry。
- **依据**：需求 [02-12](../../../../../需求/02_需求_后端基座.md#r02-12)、《[架构设计 · 后端基础类体系](../../../../../../../设计/架构设计/04_架构设计_后端基础类体系.md)》「core 横切基座」节、《[日志规范](../../../../../../../规范/日志规范.md)》、《[后端开发规范](../../../../../../../规范/后端开发规范.md)》「后端基座体系（强制）」节。

## 4. 日志中间层与入口设计 <a id="logging"></a>

`app/core/logging.py`：

| 成员 | 说明 |
| --- | --- |
| `BaseLogger(BaseObject, ABC)` | 日志门面中间层基（统一入口）：`debug` / `info` / `warning` / `error` / `exception(event, **fields)`、`bind(**fields) -> BaseLogger` |
| `StdoutLogger(BaseLogger)` | 占位实现：包装标准库 `logging.Logger`，输出 **stdout、不落文件**；真实 structlog 化归 03-2 |
| `configure_logging(settings: Settings) -> None` | 初始化入口：标准库 `logging.basicConfig(level=settings.log.level, stream=sys.stdout)`；幂等；**结构对应 structlog 初始化入口**（03-2 替换实现） |
| `get_logger(name: str = "bms") -> BaseLogger` | 取日志门面（模块级统一入口） |

```python
class BaseLogger(BaseObject, ABC):
    """日志门面中间层基类：统一日志接入点与上下文绑定。"""

    @abstractmethod
    def bind(self, **fields: object) -> "BaseLogger": ...
```

- **stdout 约定**：只写 stdout、不写文件（容器由 Docker / Loki 收集）；禁止 `print`（《日志规范》）。
- 渲染形态由配置 `[log] format` 控制（占位按标准库 `level` 生效；`format=json` 的真实渲染归 03-2）。
- 上下文（`trace_id` / `tenant` / `user_id` ...）由 03-2 中间件注入，本任务 `bind` 提供签名。

## 5. 应用基类体系 <a id="base"></a>

- `BaseLogger` 继承 `BaseObject`（L0）；`StdoutLogger` 继承 `BaseLogger`。
- 继承链：`StdoutLogger → BaseLogger → BaseObject`。

## 6. 应用工厂接入 <a id="app"></a>

`app/main.py` 的 `create_app()` 调用 `configure_logging(get_settings())`（配置来自 02-3-2 配置基座），使应用启动即具备统一日志出口；`get_logger(...)` 供各层取日志门面。

## 10. 边界与开放项 <a id="boundary"></a>

- structlog JSON 渲染、上下文字段（`trace_id` / `tenant` / `user`）、脱敏、请求日志中间件归 03-2；本任务 `configure_logging` 为其初始化入口。

- 日志只写 stdout、不落文件；禁止 `print`；密钥 / PII 不落日志。
