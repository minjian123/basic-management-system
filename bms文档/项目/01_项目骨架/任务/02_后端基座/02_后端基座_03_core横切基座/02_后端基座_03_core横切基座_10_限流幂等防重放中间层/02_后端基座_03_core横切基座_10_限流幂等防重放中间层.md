## 2. 任务内容 <a id="content"></a>

1. 按需求 02-25 落「限流幂等防重放中间层」的统一接口 / 抽象 + 占位实现（纳入能力域中间层基座，依赖注入可解析）
2. 登记：平台《架构设计 · 后端基础类体系》「阶段落地（地基波 + 回补）」跨阶段基座表 + 《后端基类清单》
3. 真实实现随对应阶段回补（同一任务文档，不重复立项；实现期要点见[需求 02-25](../../../../需求/02_需求_后端基座.md#r02-25)）
4. **前置契约（已交付）**：幂等去重与防重放的临界区互斥取 [02-3-6 分布式锁基座](../02_后端基座_03_core横切基座_06_分布式锁基座/02_后端基座_03_core横切基座_06_分布式锁基座.md)（2026-09-14 已交付，`app/lock/base.py`）：锁 key 经 `build_lock_key` 拼接、经 `get_distributed_lock` 注入；本任务只做接线与中间层实现，不重复实现锁
5. **登录侧联动（口径）**：登录失败限流（如 5 次锁 15 分钟）与「连续失败 3 次强制图形验证码」的失败计数窗口由本中间层提供，登录侧只接线；验证码校验取 [02-3-7 验证码与密码策略基座](../02_后端基座_03_core横切基座_07_验证码与密码策略基座/02_后端基座_03_core横切基座_07_验证码与密码策略基座.md) 的 `BaseCaptcha`，密码策略取其 `BasePasswordPolicy`
6. **降级动作取用（口径）**：限流的 Redis 故障降级（Redis → memory 后端）属本中间层**内部策略**；如需与全局降级矩阵统一口径，可问 [02-3-8 降级与熔断基座](../02_后端基座_03_core横切基座_08_降级与熔断基座/02_后端基座_03_core横切基座_08_降级与熔断基座.md)（2026-09-14 已交付）的 `BaseFallbackPolicy.resolve("redis")` 取动作（依赖清单 `DEPENDENCIES` 已就位），不另立判定逻辑
