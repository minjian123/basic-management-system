## 2. 实施过程 <a id="process"></a>

1. **工厂基类**：新增 `app/core/factory.py`——`BaseFactory[OptionsT, ProductT]`（继承 `BasePluggable`；`validate` 默认空 + `create` 抽象）+ 四域工厂基类 `BaseApplicationFactory` / `BaseDbFactory` / `BaseIdFactory` / `BasePluginFactory`（后者 `__call__` 兼容 `PluginImpl` 零参口径）；并落地**工厂专用注册表** `register_factory` / `resolve_factory`。
2. **数据访问工厂**：`EngineFactory` 改挂 `BaseDbFactory`（`create(options: str | None)`，构造缺省取全局配置）；新增 `SessionFactory(BaseDbFactory)`，移除 `build_session_factory`。
3. **ID 工厂**：新增 `IdGeneratorFactory(BaseIdFactory)` 与模块级默认生成器 `id_generator`；`SnowflakeGenerator` 增 `reconfigure`；移除 `configure_id_generator` / `generate_id`；`app/models/base.py` 的 `id` 默认值改指 `id_generator.next_id`；`core/config.py` 经 `reconfigure` 接线。
4. **应用工厂**：`create_app()` 移除，新增 `ApplicationFactory(BaseApplicationFactory)`；ASGI 入口改 `app/asgi.py` 的模块级 `app`（`uvicorn app.asgi:app`）；引擎 / 会话工厂解析前移到 `ApplicationFactory.create`（引导顺序）。
5. **插件实现工厂类化**：装配层 4 个闭包工厂改为 `LocalObjectStorageFactory` / `MinioObjectStorageFactory` / `HealthCheckRegistryFactory` / `DefaultMaskerFactory`（`BasePluginFactory` 子类）。
6. **调用面同步**：`create_app()` → `ApplicationFactory().create(None)` 等机械替换覆盖 `tests/` 39 个文件 + `ops/check_plugins.py` + `conftest.py` + `tests/contracts/support.py`；README（根 / backend）与 `scripts/tools/governance/review_stage.py` 的启动命令改 `app.asgi:app`。
7. **用例**：新增 `tests/core/test_factory.py`（Kiwi 778）；护栏 `_ports()` 跳过 `app.core.factory`（工厂基类非能力域端口）。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 循环导入 `config → id → factory → plugin → logging → config` | `config.py` 改为在 `validate_startup` 内延迟导入 `id_generator` |
| 2 | 关键工厂若进「能力插件注册表」，破坏既有契约护栏（快照键集=能力清单）且引入跨应用单例共享 | 改为**工厂专用注册表**（`register_factory` / `resolve_factory`，按次新建、不缓存实例），能力注册表不动；设计 §7 已回写该口径 |
| 3 | `Null*` 类落点护栏（`Null*` 仅限 `null.py`） | `NullMaskerFactory` 改名 `DefaultMaskerFactory`（产出 `NullMasker`） |
| 4 | 引擎 / 会话引导：`create` 期需已解析工厂，而注册表构建在 lifespan | 将「平台实现登记 → 注册表构建 → 关键工厂解析」前移进 `ApplicationFactory.create`；lifespan 只做模块校验与能力装配 |
| 5 | ASGI 入口：`create_app` 移除后需模块级实例 | 新增 `app/asgi.py`（模块级 `app`），避免 `app.main` 导入期构造影响测试 |

## 5. 偏差与遗留 <a id="legacy"></a>

- **偏差**：`ApplicationFactory` 为引导工厂，不注册为可替换（应用未起时解析循环）；ID 工厂替换性为**结构性**（`IdGeneratorFactory` 可登记 / 解析，ORM 默认值仍走模块级 `id_generator` 单例、经 `reconfigure` 重设 WorkerId）——设计 §13 登记项 7/8 的实施结论。
- **遗留**：ASGI 入口 `app/asgi.py` 在导入期构造应用（加载配置）；若后续部署形态需要延迟构造，按设计 §13-8 调整。`_ports()` 护栏跳过 `app.core.factory` 的口径随本次合入。
- **历史文档**：`01_工程骨架` 等历史任务记录中「`app.main:create_app --factory`」为当时事实，不回改；现行入口以 README 与 `app/asgi.py` 为准。
