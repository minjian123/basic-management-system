## 2. 任务内容 <a id="content"></a>

1. 新增工厂基类 `BaseFactory`（`app/core/factory.py`，中间层，继承 `BasePluggable`）：层级 `BaseFactory → 各域工厂基类 → 具体工厂类`；契约对齐前端——`create(options)` 抽象 + `validate(options)` 默认空实现 + 创建入口标识（`key` / `plugin_name` / `contract_version`）+ 产出物释放登记（经 `ResourceManager`）
2. 各域工厂基类（按创建域设）：公共创建逻辑只在域工厂基类维护
3. 既有工厂对齐：`EngineFactory` 改挂工厂链；函数式创建（应用工厂 `create_app`、会话工厂 `build_session_factory`、装配层插件实现工厂闭包、雪花 ID 生成器配置）**类化**为具体工厂类；`build_*_key` 键拼接工具不纳入
4. 登记：《后端基类清单》「中间层基类」+「继承链与代码位置」+「跨端命名对照」；《架构设计 · 后端基础类体系》中间层语义
5. 真实实现（非占位）——工厂契约用例 + 迁移回归用例，先登记 Kiwi 再编码

## 3. 完成标准 <a id="accept"></a>

`BaseFactory` 与各域工厂基类就位、既有工厂全部改挂工厂链（无游离创建入口）；依赖注入可解析、应用可启动不报错；工厂契约用例与迁移回归通过；`pytest`、`ruff`、`pyright` 全绿。
