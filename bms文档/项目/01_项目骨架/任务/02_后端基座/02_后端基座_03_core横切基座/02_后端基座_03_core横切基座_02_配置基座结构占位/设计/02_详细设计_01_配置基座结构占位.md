## 4. 配置模型设计 <a id="models"></a>

`app/core/config.py`：新增**配置分区公共基 `BaseSettings`（继承 `BaseSchema`）**——统一配置行为（`extra="forbid"` 拒绝未知键、`populate_by_name` 字段名填充）；所有分区模型与 `Settings` 均继承 `BaseSettings`（纳入基类体系，Pydantic 公共配置 + 声明字段优先序列化）。**提前按 03-1 完整分区 / 关键键建模**，占位给默认值。

| 分区模型 | 关键键（默认值，占位） |
| --- | --- |
| `AppSettings` | `name`（BMS 基础管理系统）、`env`（`dev`，`Literal["dev","test","prod"]`）、`debug`（True） |
| `ServerSettings` | `host`（0.0.0.0）、`port`（8000）、`workers`（1） |
| `LogSettings` | `level`（DEBUG）、`format`（console）、`slow_request_ms`（1000） |
| `DatabaseTargetSettings` | `url`（不含密码）、`replicas`（list）、`pool`（`DbPoolSettings`：size / max_overflow / timeout / recycle） |
| `DatabaseSettings` | `platform` / `tenants` / `archive`（各为 `DatabaseTargetSettings`；dev 默认多 SQLite 文件） |
| `RedisSettings` | `url`（redis://localhost:6379/0） |
| `MinioSettings` | `endpoint` / `access_key` / `secret_key` / `bucket` / `secure`（占位，空 / 默认） |
| `SecuritySettings` | `secret_key`（空）/ `algorithm`（HS256）/ `access_token_expire_minutes`（60）（占位） |
| `CorsSettings` | `allow_origins` / `allow_methods` / `allow_headers` / `allow_credentials` |

```python
class Settings(BaseSchema):
    """应用配置（占位：默认值，不读文件 / 环境变量）。"""

    app: AppSettings = Field(default_factory=AppSettings)
    server: ServerSettings = Field(default_factory=ServerSettings)
    log: LogSettings = Field(default_factory=LogSettings)
    database: DatabaseSettings = Field(default_factory=DatabaseSettings)
    redis: RedisSettings = Field(default_factory=RedisSettings)
    minio: MinioSettings = Field(default_factory=MinioSettings)
    security: SecuritySettings = Field(default_factory=SecuritySettings)
    cors: CorsSettings = Field(default_factory=CorsSettings)
```

- `env` 用 `Literal` 约束取值（非法值校验失败；真实分层由 03-1）。
- `replicas` / `allow_*` 用 `list`/`Field(default_factory=...)`，避免可变默认共享。
- 密钥类字段占位为空字符串，**不落配置文件 / 日志**（03-1 从环境变量注入）。

## 5. 读取接口设计 <a id="getter"></a>

```python
@lru_cache(maxsize=1)
def get_settings() -> Settings:
    """取应用配置（占位：返回默认值；真实读取由 03-1 接入）。"""
    return Settings()
```

- `lru_cache` 单例：依赖注入与上层多次取用同一实例；`get_settings.cache_clear()` 供测试与 03-1 重载。
- **不读 `config.toml` / 环境变量**；03-1 落地后改为 `pydantic-settings`（`SettingsConfigDict`、`BMS_` 覆盖、`BMS_ENV` 分层、启动校验）并回填本基座登记。

## 6. 应用基类体系 <a id="base"></a>

- `Settings` 与分区模型继承 `BaseSchema` → 纳入 L0 继承体系（`BaseObject`），可直接 `to_dict` / `to_json` 稳定序列化（脱敏由 03-1 / 日志规范约束）。
- 读取接口是函数（非类），不涉及继承。
