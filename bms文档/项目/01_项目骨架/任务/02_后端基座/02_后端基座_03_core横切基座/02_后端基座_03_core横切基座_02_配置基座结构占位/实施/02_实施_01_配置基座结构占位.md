## 3. 实施过程 <a id="process"></a>

1. **分区模型**：`app/core/config.py` 落地 `AppSettings` / `ServerSettings` / `LogSettings` / `DbPoolSettings` / `DatabaseTargetSettings` / `DatabaseSettings` / `RedisSettings` / `MinioSettings` / `SecuritySettings` / `CorsSettings`，均继承 `BaseSchema`（纳入基类体系）。
2. **根模型**：`Settings` 组合八分区（`Field(default_factory=...)`，避免可变默认共享）。
3. **读取接口**：`get_settings()` 用 `functools.lru_cache(maxsize=1)` 单例，占位返回默认值；`cache_clear` 供测试 / 03-1 重载。
4. **登记**：《架构设计 · 后端基础类体系》§6、《后端开发规范》§3.5（配置基座结构占位；真实读取由 03-1 落地后回填）。
5. **测试**：新增 `tests/core/test_config.py`（Kiwi 21）。
6. **验证**：`uv run pytest` / `uv run ruff check .` / `uv run pyright` 全绿，覆盖率 100%（详见[测试记录](../测试/02_测试_01_配置基座结构占位.md)）。
