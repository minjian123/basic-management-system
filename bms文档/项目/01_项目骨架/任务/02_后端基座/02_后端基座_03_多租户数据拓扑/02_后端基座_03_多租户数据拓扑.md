## 3. 任务内容 <a id="content"></a>

1. 三库模型与建库口径：平台库 `bms_platform` / 租户库 `bms_tenant_{code}` / 归档库 `bms_archive` 的职责与命名、开发环境 SQLite 多文件模拟、字符集与跨库逻辑外键（禁 JOIN）
2. 模型基类与表规范：`BaseModel`（雪花 ID / 审计字段 / 软删除 / 乐观锁 / 四库类型映射）、`(唯一字段, deleted_at)` 复合唯一索引与索引 / 表级规范
3. 租户解析与引擎路由：`TenantContext` 与解析链（子域名 / `X-Tenant-ID` / 开发兜底）、豁免路径与未知租户拒绝；`EngineRegistry` 懒加载 / LRU 回收 / 连接预算 / 创建加锁
4. 迁移与初始化工具链：Alembic 三套方言（`env.py` + `versions/`）、批量迁移脚本、新租户初始化（建库 → 迁移 → 幂等种子）

## 4. 完成标准 <a id="accept"></a>

三库拓扑可路由（MySQL / PostgreSQL / 达梦三库实测连通与迁移通过）；`BaseModel` 落库生效（审计字段自动填充、软删除复合唯一索引、乐观锁版本冲突返回明确错误码）；租户隔离与批量迁移正确（`X-Tenant-ID` 路由落库、跨租户被拒、`init_tenant.py` 重跑幂等）；demo 租户种子可查询（逐项验收见子任务清单）。
