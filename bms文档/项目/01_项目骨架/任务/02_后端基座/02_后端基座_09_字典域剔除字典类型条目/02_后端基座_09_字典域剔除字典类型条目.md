## 2. 任务内容 <a id="content"></a>

**口径来源（2026-10-11 用户拍板）**：**字典域＝原始需求**——字典字段、取数、缓存、翻译、数据权限左列、字典页，「字典」即**基础数据 / 主数据**；AI 自行编造的「**字典类型 / 字典条目 / 字典属性**」一套与其混在一起造成混淆，需**剔除**；被剔除处**改由「主数据」承载**。**不存在「拆除字典域」**（原立项作废）。

1. **删除（编造内容）**：「字典类型 / 字典条目 / 字典属性」——表 `sys_dict_type` / `sys_dict_item` / `sys_dict_attr` + 3 张 `_i18n` 附表；`bms_core/dict/` 的 `models` / `service`（维护写路径）/ `query`（高级查询执行）/ `providers` / `seed` / `sql`（本地表取数）；`ops/seed_dict.py` / `ops/backfill_dict_parent_id.py`；`platform/api/dict.py` 的**维护 / 属性 / 高级查询**端点；相关表文件与总览登记。
2. **保留（字典域本体，命名仍「字典」、路径仍 `/api/v1/dicts/*`）**：取数 / 翻译 / 缓存契约与实现（`dict/base|cache|http|null`）、前端字典字段组件族、数据权限左列、字典页、字典需求（02-44 / 02-56）。
3. **新增（主数据承载）**：**主数据登记**（统一注册表 + 构建期清单，各项目装载注入）+ **统一出口**；字典**取数 / 缓存 / 翻译 / 高级查询**改由主数据供数（不再读本地字典表）。
4. **数据权限**：`sys_data_scope` 归属由字典类型改按**主数据**（`master_data_code` VARCHAR）；平台库角色策略表同步。
5. **文档**：只改「字典类型 / 字典条目」相关内容；字典域文档（字典字段 / 字典页 / 概要设计 09 取数段 / 数据架构取数缓存段）**保留**。

> 详细设计（含迁移、契约、主数据登记/出口的字段与边界、测试映射）**待需求评审通过后落 `设计/`**。
