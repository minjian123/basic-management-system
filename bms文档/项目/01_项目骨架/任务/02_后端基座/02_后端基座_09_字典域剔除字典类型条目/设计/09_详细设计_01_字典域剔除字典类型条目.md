## 1. 目的与口径 <a id="purpose"></a>

按 2026-10-11 用户拍板：**字典域＝原始需求**——字典字段、取数、缓存、翻译、数据权限左列、字典页，「字典」即**基础数据 / 主数据**；AI 自行编造的「**字典类型 / 字典条目 / 字典属性**」一套与其混在一起造成混淆，**剔除之**，被剔除处**改由「主数据」承载**。**不存在「拆除字典域」**。

- **保留**：字典取数 / 翻译 / 缓存契约与实现（`dict/base|cache|http|null`）、`/api/v1/dicts/*` 运行时取数、前端字典字段组件族、数据权限左列、字典页、需求 02-44 / 02-56。
- **删除**：「字典类型 / 字典条目 / 字典属性」三表 + 3 `_i18n`、`dict/models|service|query|providers|seed|sql`、`ops/seed_dict|backfill_dict_parent_id`、`platform/api/dict.py` 的维护 / 属性 / 高级查询端点、相关表文件与登记。
- **新增（主数据承载）**：主数据**登记**（统一注册表 + 构建期清单）+ **统一出口**；字典取数 / 缓存 / 翻译 / 高级查询改由主数据供数。
- **数据权限**：`sys_data_scope` 归属列改按主数据（`master_data_code` VARCHAR）。

## 3. 主数据承载（登记 + 统一出口） <a id="masterdata"></a>

- **登记**：`（主数据标识（业务码字符串）/ 名称 / 数据出口 / 可用于数据权限的字段白名单）`；bms 侧持**统一注册表 + 构建期清单**，各项目装载时注入（构建期清单合并），合并后只读。
- **统一出口**：按**主数据标识**取数（取数 / 版本比对 / 批量合并 / 标签翻译 / 级联 / 高级查询）；字典取数 `GET /api/v1/dicts/{code}`、`POST /dicts/batch` 行为不变，**实现内部改调主数据出口**，`dict/http.py` 的跨服务取数目标改为主数据出口。
- **缓存**：字典缓存域（`dict/cache.py`）保留；缓存 key 由「字典类型码」取值换为「主数据标识」取值。

## 4. 数据权限改按主数据 <a id="data-scope"></a>

- `sys_data_scope` 归属列 `dict_type_id`（BIGINT → 字典类型）改为 **`master_data_code` VARCHAR(64)**（业务码字符串，如 `org_dept` / `region` / `material`）。
- 迁移：`platform:tenant` 链新迁移改列 + 存量清理（字典域废弃、无需回填）；唯一约束列同步。
- 校验：由主数据登记提供字段白名单与存在性（不再查字典类型 / 扩展属性表）。

## 5. 迁移与回滚 <a id="migration"></a>

- **drop 迁移**：拆六表（`batch_alter_table` 四库兼容；先删数据后删表、幂等）；`downgrade` 重建六张空表。
- **改列迁移**：`sys_data_scope` 归属列改 `master_data_code`；`downgrade` 回退为 `dict_type_id`。
- **回滚**：以本任务提交为界；数据侧字典行随表拆除不回填。

## 7. 风险与遗留 <a id="risk"></a>

- **面广**：跨数据库 / 后端 / 前端 / 契约 / 文档，按「先设计后实施」推进，禁止先删代码后改文档。
- **替代前置**：主数据承载（登记 + 出口）须先就位，字典取数方可切数据源。
- **残留**：代码里另有「动作枚举 / 三态枚举」等通用开发用词，与本域无关，不在范围。
