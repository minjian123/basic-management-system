## 2. 过程 <a id="process"></a>

1. **决策确认**：按《AI开发规范》逐项确认（question 工具，共 22 项）——默认 widget、下拉键名、旧配置迁移方式、列类型迁移方式、翻译契约、迁移脚本落点、契约版本、旧类型别名、校验形态、`option_multi` 列类型、设计回写、seed、三库实测方式、Kiwi 登记、`ids` 元素类型、缓存键与常量、旧分发分支归属、`sys_field_ext` 范围、插件端口版本。第 7 项拍板「无存量数据、删库重建、不做迁移脚本」，第 17/21 项拍板「只收整数 id、不做字符串兼容」。
2. **设计回写（先行）**：`option_multi` 列类型由 `VARCHAR(255)` 改为四库统一 `TEXT` 承载，回写《组件设计 · 开关与枚举字段》「值域与存储口径」节与《概要设计 · 表单定制》「数据模型」节。
3. **详细设计**：落 [14 详细设计](../设计/01_详细设计_01_字典字段绑定ID与字段类型更名.md)（目标 / 现状差距 / 交付物 / 契约表 / 实施细节 / 失败分支 / 测试映射 / 登记落点 / 决策记录 / 开放项）。
4. **Kiwi 登记**：容器内 Django shell 登记一条用例（**2329**），标注「自动化」，覆盖范围写入用例文本。
5. **实施（后端）**：
   - `fieldtype/local.py`：`select` → `option`（`widget=radio`）、`multi_select` → `option_multi`（`widget=checkbox`，列 `text`）；`dict` 改 `kind=id` / 列 `bigint`、`dict_multi` 改 `kind=id_list`；新增整数 id 校验分支；登记下拉形态语义键常量 `OPTION_DROPDOWN_WIDGET` / `OPTION_MULTI_DROPDOWN_WIDGET`。
   - `dict/base.py`：`DictQuery.values` / `DictTranslateQuery.values` → `ids`（`ConcurrentStableList[int]`）；`translate` 返回 `ConcurrentStableDict[int, str]`；`value_cache_key` → `id_cache_key`（`:id`）、`avalue_subset` / `aset_value_subset` → `aid_subset` / `aset_id_subset`。
   - `dict/cache.py`：Redis 实现子集方法改名，载荷 JSON 键为字符串化 id、读时按 `str(id)` 精确匹配。
   - `dict/outlet.py`：出口过滤按 `item.id`；翻译按 `item.id` 匹配并返回 `id → label`。
   - `dict/http.py`：取数透传 `ids`（逗号拼接）；翻译映射键为整数、分块常量改名 `TRANSLATE_IDS_CHUNK`、降级回退 `str(id)`。
   - `dict/null.py`：占位过滤按 `ids`、占位翻译 `{id: "占位{key}:{id}"}`。
   - `api/dict.py`：`parse_values` → `parse_ids`（正整数校验）；查询参数 `values` → `ids`。
   - `ops/seed_menu.py`：`FIELD_SEEDS` 全部 `select` → `option`。
   - `bms_platform/__init__.py`：`CONTRACT_VERSION` `0.2.0` → `0.3.0`；`services/module_registry.py` 服务目录登记同步 `0.3.0`。
6. **契约与类型**：`ops.contract_snapshot export` 重生成 9 份快照；`ops.contract_gate baseline-update --service platform` 更新破坏性变更基线；`pnpm run api-types:gen` 重生成 `@bms/api-types`（仅 `platform.json` / `platform.ts` 变化）。
7. **用例补齐**：更新字段类型 / 字典域 / HTTP 出口 / 缓存 / 路由用例；新增类型分家、整数 id 校验、`parse_ids` 非正整数、`?ids=` 非法值四条断言（Kiwi 2329）；预检扩圈暴露的两处**既有**覆盖率缺口（字段权限求值器空收窄行、元数据服务工厂）以最小用例补齐。
