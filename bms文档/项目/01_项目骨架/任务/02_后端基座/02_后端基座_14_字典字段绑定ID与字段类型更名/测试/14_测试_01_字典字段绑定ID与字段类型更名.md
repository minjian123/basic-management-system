## 3. 三库实测 <a id="db"></a>

开发服务器三库测试对象上以探针表 `tmp_dict_probe` 验证（跑完即清理）：

| 库 | 反射列类型 | 大整数往返（`2^53+1`） | `dict_multi` 承载（JSON 数组文本） |
| --- | --- | --- | --- |
| MySQL 8 | `BIGINT` / `BIGINT` / `TEXT` | 保真 | 写入 `["9007199254740993","9007199254740995"]`，读出 `json.loads` 一致 |
| PostgreSQL 16 | `BIGINT` / `BIGINT` / `TEXT` | 保真 | 同上 |
| 达梦 DM8（模式级） | `BIGINT` / `BIGINT` / `TEXT` | 保真 | 同上（经 `dmxa+dmPython` 同步引擎） |

结论已回写《[MySQL](../../../../../../设计/数据库设计/方言特性/01_MySQL.md)》《[PostgreSQL](../../../../../../设计/数据库设计/方言特性/02_PostgreSQL.md)》《[DM8](../../../../../../设计/数据库设计/方言特性/03_DM8.md)》「类型映射」与「实测记录」节（标「实测」）。
