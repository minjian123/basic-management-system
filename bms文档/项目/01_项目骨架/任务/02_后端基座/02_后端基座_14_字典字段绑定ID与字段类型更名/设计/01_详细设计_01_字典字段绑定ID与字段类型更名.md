## 1. 设计目标与范围 <a id="goal"></a>

交付[需求 02-59](../../../../需求/02_需求_后端基座.md#r02-59) 与[任务 02-14](../02_后端基座_14_字典字段绑定ID与字段类型更名.md) 的**字段类型更名**与**字典字段绑定条目 `id`**：

1. **类型更名**：内建字段类型 `select` → `option`、`multi_select` → `option_multi`；旧名不保留别名（旧名解析即报「字段类型不存在」）。
2. **类型分家**：`option` / `option_multi` 只接注册表选项集（值 = 常量字符串）；`dict` / `dict_multi` 只接字典（值 = 条目 `id`，BIGINT / JSON 数组文本）。后端只保证类型级映射与校验分流，**前端分发分支由 `06_09` 移除**。
3. **字典字段绑定 `id`**：`dict` 列类型 `bigint`、`dict_multi` 列类型 `text`（存 `id` 的 JSON 数组文本，应用层解析）；`validate` 只收**整数 id**（字符串 id 判违规——序列化未转换属调用方缺陷）。
4. **取数 / 翻译按 `id` 子集**：`DictQuery.values` → `ids`（`ConcurrentStableList[int]`）、`DictTranslateQuery.values` → `ids`、`GET /dicts/{data_source_key}?values=` → `?ids=`；出口、缓存子集键、跨服务 HTTP 出口同口径。
5. **不写迁移脚本**（2026-10-21 用户拍板）：现阶段无存量业务数据，删库重建；`sys_field_ext` 尚未落库，一并标「不适用」。

### 1.1 口径与依从 <a id="positioning"></a>

- **架构铁律**：字段类型提供者经 `BaseFieldType` 继承链派生（`SimpleFieldType` → `BaseFieldType`），注册表 `LocalFieldTypeRegistry` → `BaseFieldTypeRegistry`；字典取数 / 翻译 / 缓存三契约不改继承关系，只改契约字段与实现。
- **继承链权威**：《[后端基类清单](../../../../../../后端基类清单.md)》，本任务不新增基类、不改继承链层级。
- **契约版本**：平台服务公开契约 `CONTRACT_VERSION` `0.2.0` → `0.3.0`（参数改名属破坏性变更，0.x 阶段以次版本表达，主版本不变 → 服务目录清单与库内模块登记无需改主版本）；**基座插件端口契约版本保持 `0.1.0`**（端口与全部实现同仓同发布，无跨版本实现并行）。
- **ID 口径**：库内 `BIGINT`、契约 `ids` 参数与字段值为**整数**；`DictItem.id` 等 `id` / `*_id` 字段仍经 `BaseSchema` 统一字符串化输出（JS 安全整数），`ids` 键不命中 `is_id_key`，故契约中为整数数组。
- **UI 口径**：`option` → `widget=radio`、`option_multi` → `widget=checkbox`（默认形态，对齐《组件设计 · 选项集字段》第 4 节「形态由字段属性决定」）；下拉形态的语义键登记为 `dropdown` / `dropdown-multi`，本次后端**不产出**，供字段属性层与前端 `06_09` 使用。
- **不在本任务**：前端任何改动（`FIELD_WIDGET_MAP` / `formWidgets` / `form-render` 由 `06_09` 承担）、`sys_field_ext` 建表与自建字段 DDL、表单定制字段属性层、迁移脚本。

## 4. 契约与数据结构 <a id="contract"></a>

### 4.1 字段类型表（内建） <a id="fieldtypes"></a>

| 类型键 | widget | kind | multiple | 物理列类型 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `option` | `radio` | `string` | `false` | `varchar(64)` | 单选枚举（选项集常量）；下拉形态键 `dropdown`（登记，不产出） |
| `option_multi` | `checkbox` | `string_list` | `true` | `text` | 多选枚举；按选项集顺序去重、`,` 拼接，应用层解析 |
| `dict` | `dict-select` | `id` | `false` | `bigint` | 绑定字典条目 `id` |
| `dict_multi` | `dict-multi` | `id_list` | `true` | `text` | `id` 的 JSON 数组文本（应用层解析） |

- 模块级常量登记下拉语义键：`OPTION_DROPDOWN_WIDGET = "dropdown"`、`OPTION_MULTI_DROPDOWN_WIDGET = "dropdown-multi"`（供字段属性层 / 前端 `06_09` 使用，`builtin_field_types()` 不产出）。
- `text` / `longtext` 等既有类型不变；`select` / `multi_select` 不再注册，解析即抛 `NotFoundError`（10002 / 404）。

### 4.2 `validate` 口径 <a id="validate"></a>

| kind | 通过 | 违规（返回原因元组） |
| --- | --- | --- |
| `id` | 空值（`None` / `""`）放行；`int` 且非 `bool` 且 `> 0` | 字符串（含字符串化数字）、`bool`、`0` / 负数、非整数 |
| `id_list` | 空值（`None` / `[]`）放行；`list[int]`，元素均为非 `bool` 的正整数 | 非列表、含字符串 / `bool` / 非正元素 |

> 字符串化 `id` 判违规是**刻意**的（2026-10-21 用户拍板）：前端回传字符串说明序列化未转换，应在契约边界修正，不做容错。

### 4.3 字典契约变更 <a id="dict-contract"></a>

| 契约 | 变更前 | 变更后 |
| --- | --- | --- |
| `DictQuery` | `values: ConcurrentStableList[str] \| None`（指定 value 子集） | `ids: ConcurrentStableList[int] \| None`（指定条目 id 子集） |
| `DictTranslateQuery` | `values: ConcurrentStableList[str]` | `ids: ConcurrentStableList[int]` |
| `BaseDictTranslator.translate` 返回 | `ConcurrentStableDict[str, str]`（value → label） | `ConcurrentStableDict[int, str]`（id → label；未命中项不出现在映射中） |
| `DictCacheRegion` 子集键 | `value_cache_key` → `...:{locale}:{key}:v` | `id_cache_key` → `...:{locale}:{key}:id` |
| 子集读写 | `avalue_subset` / `aset_value_subset`（`str → str`） | `aid_subset` / `aset_id_subset`（`int → str`，缓存 JSON 键为字符串，读出按 `int` 解析、非法键跳过） |
| `DictItem.id` | 条目主键 | 不变（对外仍字符串化输出）；`value` / `code` 语义收窄为**展示与外部交换**，不参与字段绑定 |
| `http.TRANSLATE_VALUES_CHUNK` | 200 | `TRANSLATE_IDS_CHUNK = 200` |

- `ids=None` = 不按子集过滤；`ids=[]` = 空子集（返回空条目 / 空映射），与既有 `values` 语义一致。
- 过滤匹配键从 `item.value` 改为 `item.id`；`keyword` 仍匹配 `label` / `value` / `code`（展示字段不变）。
- 翻译映射的未命中项**不占位**（与既有口径一致）；`HttpDictTranslator` 降级时回退为 `str(id)`（原值可展示）。

### 4.4 接口参数 <a id="api"></a>

| 接口 | 变更 |
| --- | --- |
| `GET /api/v1/dicts/{data_source_key}` | `values`（逗号分隔 value）→ `ids`（逗号分隔的**正整数**）；非法整数 / 非正数 → `ParamError`（业务码 `10001`，HTTP 200 统一口径） |
| `POST /api/v1/dicts/batch` | 不变（不承载子集取数） |
| 其余字典端点（attrs / advanced-query / query-providers） | 不变 |

- `parse_ids(raw: str) -> ConcurrentStableList[int]`：按 `,` 切分、去空白、去空项、`int()` 解析；空串由路由层转 `None`（不过滤）。

## 5. 实施细节 <a id="impl"></a>

### 5.1 字段类型注册表 <a id="impl-fieldtype"></a>

```python
_KIND_ID = "id"
_KIND_ID_LIST = "id_list"
OPTION_DROPDOWN_WIDGET = "dropdown"
OPTION_MULTI_DROPDOWN_WIDGET = "dropdown-multi"

SimpleFieldType(key="option", widget="radio", kind=_KIND_STRING, column_type="varchar(64)")
SimpleFieldType(key="option_multi", widget="checkbox", kind=_KIND_STRING_LIST, multiple=True, column_type="text")
SimpleFieldType(key="dict", widget="dict-select", kind=_KIND_ID, column_type="bigint")
SimpleFieldType(key="dict_multi", widget="dict-multi", kind=_KIND_ID_LIST, multiple=True, column_type="text")
```

- `validate` 增两个分支：`id`（`isinstance(value, int) and not isinstance(value, bool) and value > 0`）、`id_list`（`list` 且逐元素同判定）。
- 模块与类 docstring 同步：`select` / `multi_select` 已废弃、`dict` 绑定 `id`、下拉键口径。

### 5.2 字典契约与出口 <a id="impl-dict"></a>

| 文件 | 改动要点 |
| --- | --- |
| `dict/base.py` | `DictQuery.ids` / `DictTranslateQuery.ids`（`Annotated[ConcurrentStableList[int] \| None, CONTRACT_COLLECTION]`）；`translate` 返回类型改 `ConcurrentStableDict[int, str]`；`value_cache_key` → `id_cache_key`（后缀 `:id`）；`avalue_subset` / `aset_value_subset` → `aid_subset` / `aset_id_subset`（入参 `ids: ConcurrentStableList[int]`、映射 `ConcurrentStableDict[int, str]`）；docstring 全量改 id 口径 |
| `dict/cache.py` | 两实现的子集方法改名；Redis / L1 载荷 JSON 键为 `str(id)`，读时按 `int(key)` 解析（非法跳过）；写时 `str(id)` 归一 |
| `dict/outlet.py` | `_apply_filters`：`wanted = set(query.ids)`、`item.id in wanted`；`_is_filtered` 判 `query.ids`；`RoutedDictTranslator.translate` 按 `item.id` 匹配并返回 `int → label`（按入参顺序去重输出） |
| `dict/http.py` | `_fetch_type(ids=...)` 拼 `"ids": ",".join(str(i) for i in ids)`；`HttpDataSource.by_type` 传 `ids=query.ids`；`HttpDictTranslator.translate` 映射键 `int`、缓存 `aid_subset`、分块常量改名；`_chunks` 泛化为 id 序列 |
| `dict/null.py` | 占位过滤按 `query.ids`；`NullDictTranslator` 返回 `{id: f"占位{key}:{id}"}` |
| `api/dict.py` | `parse_values` → `parse_ids`（正整数校验，非法抛 `ParamError`）；`values` 查询参数 → `ids`；docstring 同步 |

- 高级查询（`dict/query.py`、`dict/providers.py`）不变：可查字段仍是 `value` / `label` / `code` / `sort` / `status`，与字段绑定值无关。

### 5.3 种子与契约版本 <a id="impl-seed"></a>

- `ops/seed_menu.py` 的 `FIELD_SEEDS`：所有 `type="select"` 改为 `"option"`（用户 / 角色状态、锁定类型、菜单状态、业务码 / 动作码状态、租户状态）。
- `bms_platform/__init__.py`：`CONTRACT_VERSION = "0.3.0"`（注释补「`ids` 子集参数改名」的破坏性变更说明）。
- 契约快照：`uv run python -m ops.contract_snapshot export` 后 `pnpm run api-types:gen`（工作区根 `bms/`）。

## 6. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 字段类型旧名（`select` / `multi_select`） | `registry.get()` 返 `None`；`validate` / `column_type` 抛 `NotFoundError`（10002 / 404），**不提供别名** |
| `dict` 值为字符串化 id（`"123"`） | `validate` 返回违规 `dict 需要整数 id` |
| `dict` 值为 `0` / 负数 / `bool` | 违规（id 必须为正整数） |
| `dict_multi` 含字符串元素 | 违规 `dict_multi 数组元素需为整数 id` |
| 空值 | `None` / `""` / `[]` 放行（必填由字段规则承载） |
| `GET /dicts/{key}?ids=a,b` | `parse_ids` 抛 `ParamError`（业务码 `10001`），不发取数 |
| `GET /dicts/{key}?ids=`（空串） | 视为未传（`None`），返回全量（与既有 `values=` 口径一致） |
| `ids=[]`（内部契约） | 空子集 → `items=()` / 翻译空映射 |
| 翻译未命中 id | 不出现在映射中（调用方回退展示原 id） |
| 跨服务不可达 | `HttpDictTranslator` 回退 `str(id)`；`HttpDataSource` 返回空结果（既有降级语义不变） |
| 缓存子集含非法键（历史脏值） | 读时跳过该键，不抛错 |

## 10. 边界与开放项 <a id="open"></a>

- **`_id` 结尾字段 key 风险（登记，归表单定制阶段）**：`option` / `dict` 等字段若以 `_id` 结尾，全局 `stringify_ids` 会把整型值序列化为字符串；本任务按「整数 id」定案不做容错，表单定制阶段需以字段命名约束或字段值序列化豁免解决。
- **`option_multi` 长度**：`TEXT` 承载不设上限，应用层按 `,` 分隔解析；极端多选（数千项）需在表单定制侧约束 `maxItems`。
- **前端同版本发布**：本任务只交付后端契约；`06_09` 未合并前，前端旧映射会因类型名变化渲染不出——按任务书「同版本发布」执行，不单独做兼容层。
- **三库实测范围**：只验证 `bigint` 列与 `text` 承载（JSON 数组文本）可建可读；动态 `ext_*` 列 DDL 归表单定制阶段。
- **无迁移脚本**：删库重建后 `ops/seed_menu.py` 直接种新类型名；后续有存量数据时按第 3 / 4 / 9 项拍板口径另立任务。
