## 2. 任务内容 <a id="content"></a>

1. **字段类型更名**：`LocalFieldTypeRegistry` 内建类型 `select` → `option`、`multi_select` → `option_multi`；同步 `render_metadata`（`widget` 与 `multiple`）与后端校验分派。
2. **字典字段绑定条目 `id`**：`dict` 列类型改 `bigint`、`dict_multi` 改 JSON 数组（四库统一 `text` 承载、应用层解析）；`validate` 按**整数 id**（字符串化 id 判违规）；`DictItem.value` / `code` 收口为展示与外部交换用途。
3. **字典取数按 id 回填**：`DictQuery` / 接口参数 `values` → `ids`（条目整数 id 子集）；统一出口（`RoutedDataSource`）与 `RoutedDictTranslator`、跨服务 HTTP 出口同口径。
4. **迁移脚本（本任务不适用，2026-10-21 拍板）**：现阶段无存量业务数据，删库重建、`ops/seed_*` 直接产新类型名；`sys_field_ext` 尚未落库故不涉。后续有存量数据时按既定口径（批处理映射 value → id + 未命中清单；原地 ALTER + 回填）另立任务。
5. **契约与登记**：公开契约快照与 `@bms/api_types` 重生成（零漂移）；《后端基类清单》《后端基类实现契约》《数据库开发规范》按实现回写。

## 3. 完成标准 <a id="accept"></a>

类型更名与 id 绑定生效、前后端同版本发布；契约快照与 `@bms/api_types` 零漂移；三库（MySQL / PostgreSQL / 达梦）列类型与 JSON 承载实测通过；受影响用例覆盖率 100%；`pytest`、`ruff`、`pyright` 全绿。

> **迁移脚本项已按 2026-10-21 拍板调整**：无存量业务数据，删库重建，不写迁移脚本（口径变更记录见第 4 节）。
