## 2. 任务内容 <a id="content"></a>

1. **字段类型更名**：`LocalFieldTypeRegistry` 内建类型 `select` → `option`、`multi_select` → `option_multi`；同步 `render_metadata`（`widget` 与 `multiple`）与后端校验分派。
2. **字典字段绑定条目 `id`**：`dict` 列类型改 `bigint`、`dict_multi` 改 JSON 数组（四库统一 `text` 承载、应用层解析）；`validate` 按字符串化 id；`DictItem.value` / `code` 收口为展示与外部交换用途。
3. **字典取数按 id 回填**：`DictQuery` / 接口参数 `values` → `ids`（条目 id 子集）；`SqlDictSource` / `SqlDictTranslator` 同步；跨服务 HTTP 出口同口径。
4. **迁移脚本**：存量 `sys_field.type` / `sys_field_ext.type` 更名；「`select` / `multi_select` + 字典标识」配置迁移为 `dict` / `dict_multi`（类型与值一次转换），幂等可重跑。
5. **契约与登记**：公开契约快照与 `@bms/api-types` 重生成（零漂移）；《后端基类清单》《后端基类实现契约》《数据库开发规范》按实现回写。

## 3. 完成标准 <a id="accept"></a>

类型更名与 id 绑定生效、前后端同版本发布；迁移脚本幂等且可回滚；契约快照与 `@bms/api-types` 零漂移；三库（MySQL / PostgreSQL / 达梦）列类型与 JSON 承载实测通过；受影响用例覆盖率 100%；`pytest`、`ruff`、`pyright` 全绿。
