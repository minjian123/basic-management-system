## 2. 任务内容 <a id="content"></a>

**口径来源**：需求 02-57 第 1/4 条——数据源注册出口与 `data_source_key` 改名须**进契约**并驱动前端类型生成。

1. **数据源注册出口契约**：`GET /api/v1/data-sources`（清单：`data_source_key` / 名称 / **类型**（`dict` / `form`，预留其它）/ 可用策略 / 字段白名单 / 级联）。
2. **字典出口键改名**：`/api/v1/dicts/{data_source_key}` 及批量 / 高级查询契约同步（`dict_key` → `data_source_key`）。
3. **契约基线与门禁**：platform 契约快照基线更新；破坏性变更门禁（oasdiff / `ops.contract_gate`）。
4. **`@bms/api_types`**：按新契约**重生成**，零漂移门禁通过。

> **协同（已交付，2026-10-11）**：任务 [`02_10`](../02_后端基座_10_统一数据源注册与通用数据接口/02_后端基座_10_统一数据源注册与通用数据接口.md) 已交付数据源注册 + 三层通用数据接口 + `data_source_key` 命名重构；其**已完成**签发侧两件：**契约快照（`deploy/contracts/platform.json` + `baseline`）已更新**（`ops.contract_snapshot export` + `contract_gate baseline-update --service platform`）、**`@bms/api_types` 已重生成**（`pnpm run api_types:gen`，零漂移；因 `preflight --fast` 的「契约类型零漂移」为必检项，随 `02_10` 落地）。本任务承接**契约正式化 / 破坏性变更复核（oasdiff）/ 前端对接说明**。

> **本任务已交付（2026-10-12）**：**契约正式化**——新增 `DataSourceResponse` / `DataSourceListResponse`（`bms_core/schemas/datasource.py`）与 `DictAttrListResponse` / `DictQueryProviderListResponse`（`bms_core/dict/query.py`），`GET /api/v1/data-sources` 与字典族 5 端点响应收敛为**具名模型**（列表统一 `{items:[...]}` 包装）并直接返回模型；契约快照 + 基线重生成、`@bms/api_types` 重生成（零漂移）；**破坏性变更复核**以结构化等价比对（无删除路径 / 操作 / 组件，仅新增 21 组件 + 6 处响应收敛）；**前端归一化兼容** `@bms/core` 列表包装（零破坏）；**前端对接说明**见[详细设计](设计/12_详细设计_01_数据源注册与通用接口契约.md) §7。实施与测试记录见[实施记录](实施/12_实施_01_数据源注册与通用接口契约.md) / [测试记录](测试/12_测试_01_数据源注册与通用接口契约.md)（Kiwi **2290**）。
