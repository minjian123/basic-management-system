## 2. 实施过程 <a id="process"></a>

1. **新增数据源登记响应契约** `bms_core/schemas/datasource.py`：`DataSourceResponse`（字段与 `DataSourceRecord` 一一对应，`kind` / `origin` / `strategies` / `status` 为强类型枚举）+ `DataSourceListResponse`（`items` 为 `Annotated[ConcurrentStableList[DataSourceResponse], CONTRACT_COLLECTION]`）。
2. **字典族列表包装** `bms_core/dict/query.py`：新增 `DictAttrListResponse` / `DictQueryProviderListResponse`（并入 `__all__`）。
3. **清单端点类型化** `api/data_source.py`：`GET /api/v1/data-sources` 返回 `ApiResponse[DataSourceListResponse]`，逐条 `DataSourceResponse.model_validate(record)`。
4. **字典族端点类型化** `api/dict.py`：`batch_dicts` → `ApiResponse[DictBatchResult]`；`list_query_providers` → `ApiResponse[DictQueryProviderListResponse]`（`_provider_record` 重构为 `_provider_info`，直接构造 `DictQueryProviderInfo`、按 `data_source_keys` 过滤）；`get_dict_attrs` → `ApiResponse[DictAttrListResponse]`；`advanced_query_dict` → `ApiResponse[DictAdvQueryResult]`；`get_dict_by_type` → `ApiResponse[DictTypeResult]`。均**直接返回模型**，去掉 `model_dump(mode="json")` 中转。`kind` 查询参数保持 `str` + `ParamError`（决策 10）。
5. **契约重生成**：`ops.contract_snapshot export`（仅 `platform.json` 变更）→ 结构化等价比对（见 §5 / §6）→ `ops.contract_gate baseline-update --service platform`；`pnpm run api-types:gen` 重生成 `@bms/api-types`。
6. **前端归一化兼容** `frontend/packages/core/src/capabilities/dict-query.ts`：新增 `toItems()` 解列表响应，`normalizeAttrs` / `normalizeProviders` **同时接受裸数组与 `{items:[...]}`**（向后兼容旧桩 / 旧宿主）。
7. **契约护栏用例**：新增 `services/platform/tests/api/test_data_sources_api.py`、`test_dict_api.py`（Kiwi 2290）；新增 `frontend/packages/core/tests/dict-meta-wrapper.spec.ts`（Kiwi 2290）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | **`ApiResponse[list[...]]` 触发 `check-bare-collections`**：端点返回注解写裸 `list` 属违规（基线已清零） | 列表响应统一包一层包装模型（`XxxListResponse.items` 用 `Annotated[ConcurrentStableList[...], CONTRACT_COLLECTION]`，决策 4 / 5），同时获得干净的契约组件名 |
| 2 | **列表包装改变 `data` 形状会打破既有前端消费方**：`@bms/core` 的 `normalizeAttrs` / `normalizeProviders` 原按裸数组解析 | 归一化函数改为 `toItems()` **兼容裸数组与 `{items:[...]}`**（决策 6，零破坏）；`permissionMeta` 改指 `/data-sources` 归 `02_13` |
| 3 | **`_provider_record` 返回通用映射**：类型化后需返回 `DictQueryProviderInfo` | 重构为 `_provider_info`：有 `info()` 用其声明、否则按契约降级构造 `DictQueryProviderInfo`；过滤改读 `data_source_keys` |
| 4 | **字典族用例命中的 `sys_role.form_key` 缺列**：`GET /dicts/role` 走平台实体表，测试库该表无 `form_key`（02_11 遗留，属既有失败） | 契约形状用例改用**不落库的注册键 `module`**（`PlatformDictDataSource` 对非 `role` 返回空、命中不报错）；`role` 相关失败与改动前基线一致、非本任务引入 |

## 6. 破坏性变更复核（结构化等价比对） <a id="breaking-review"></a>

以「改动前基线 `deploy/contracts/baseline/platform.json` ↔ 重生成快照」逐项比对（口径同 oasdiff「只加不删」）：

| 维度 | 结论 |
| --- | --- |
| 删除的路径 / 操作 | **无** |
| 删除的 schema 组件 | **无**（`ApiResponse` 泛型组件保留，仍被未类型化端点使用） |
| 删除的属性 | **无** |
| 新增组件 | **21 个**（`DataSourceResponse` / `DataSourceListResponse` / `DataSourceKind` / `DataSourceOrigin` / `DataSourceStrategy` / `DataSourceStatus` / `DictAttrListResponse` / `DictQueryProviderListResponse` / `DictTypeResult` / `DictBatchResult` / `DictItem` / `DictAdvQueryResult` / `DictAdvItem` / `DictAttrInfo` / `DictQueryProviderInfo` + 6 个 `ApiResponse_*` 参数化组件） |
| 200 响应 `$ref` 变化 | **6 处端点响应由泛型 `ApiResponse` 收敛为具名模型**（data-sources / dicts 单取 / batch / advanced-query / attrs / query-providers）——响应收窄，对消费方兼容 |

**结论**：无破坏性删除，仅新增组件与响应契约收敛，属**预期变更**；基线已按门禁提示更新（`ops.contract_gate baseline-update --service platform`）。oasdiff 正式拦截留 CI 下次命中 `backend/**` / `deploy/**` 时按需触发。

## 7. 覆盖率 <a id="coverage"></a>

- 新增 `bms_core/schemas/datasource.py`（纯契约模型，无分支）由 `test_data_sources_api.py` 直接断言（`DataSourceResponse.model_fields` / 枚举取值 / 契约组件）。
- 字典族类型化由 `test_dict_api.py` 断言 5 端点响应形状与契约 `$ref`；前端归一化由 `dict-meta-wrapper.spec.ts` 覆盖两种输入形状。

## 8. 偏差与遗留 <a id="leftover"></a>

- **列表响应形状变更（三处）**：`data` 由裸数组变 `{items:[...]}`（data-sources / attrs / query-providers）；前端归一化已兼容，`permissionMeta`（`GET /dicts` → `GET /api/v1/data-sources`）**待 `02_13` 收口**——登记计划「偏差与遗留」。
- **`kind` 查询参数仍为 `str`**：非法值走 `ParamError`（200 / 10001），未改枚举（决策 10）；前端筛选值自校验。
- **本地 oasdiff 未跑**：以结构化等价比对复核（§6），正式拦截留 CI。
- **`api-types:check` 的 `tsc` 外置依赖 shim 路径失效**：环境问题，非本任务引入；以 `gen:check` 零漂移 + `@bms/core` typecheck 覆盖。
