## 2. 任务内容 <a id="content"></a>

> **本阶段口径（接口占位）**：只落接口 / 抽象声明与占位实现（返回固定或批量数据，便于上层先跑通链路），不连真库、不跑迁移、不建表；下方为实现要点，随对应后续阶段填实现。
1. 三库模型：平台库 `bms_platform`（本阶段仅 sys_tenant 与 sys_module）、租户库 `bms_tenant_{code}`（一租户一库）、归档库 `bms_archive`（本阶段仅登记命名与连接配置占位，不建业务表）
2. 开发环境库模拟：多个 SQLite 文件模拟（bms_platform.db / bms_tenant_demo.db / bms_archive.db）；环境库命名 bms_dev/bms_test/bms_prod
3. 建库标准：字符集 MySQL utf8mb4、PostgreSQL UTF8、达梦 UTF8；达梦注意 schema 前缀（bms_dev）与小写标识符口径；SQLite 开发库自动建表（Base.metadata.create_all）
4. 跨库引用原则：逻辑外键（code）不建物理外键；跨库查询禁止 JOIN

## 3. 完成标准 <a id="accept"></a>

接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位实现返回固定或批量数据可支撑上层链路；`pytest`、`ruff`、`pyright` 全绿。

> 实现期验收要点（随后续阶段）：三库 SQLite 模拟建库成功、互不串库；MySQL/PostgreSQL/达梦三实例上 bms_platform 与 bms_tenant_demo 建库成功且字符集符合标准；跨库引用无物理外键。
