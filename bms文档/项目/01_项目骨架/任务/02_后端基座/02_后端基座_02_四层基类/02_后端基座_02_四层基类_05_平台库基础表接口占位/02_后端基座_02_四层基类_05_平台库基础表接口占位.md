## 2. 任务内容 <a id="content"></a>

> **本阶段口径（接口占位）**：只落接口 / 抽象声明与占位实现（返回固定或批量数据，便于上层先跑通链路），不连真库、不跑迁移、不建表；下方为实现要点，随对应后续阶段填实现。
1. `sys_tenant` 表（平台库）：code VARCHAR(32)（(code, deleted_at) 复合唯一，建库后缀来源）、name VARCHAR(64)、domain VARCHAR(128) 可空（子域名解析来源）、db_key VARCHAR(32)（数据源配置键）、status SMALLINT 默认 1、expire_at DATETIME 可空（阶段五起用）+ 基类字段；索引 uq_code_deleted_at、idx_domain
2. `sys_module` 表占位引用（表结构与种子在 04_01，与 sys_tenant 同迁移流水线）
3. 种子：demo 租户记录（code=demo、name=演示租户、db_key=tenants、status=1），走 Alembic 数据迁移或幂等种子脚本
4. 范围约束：本阶段只建 sys_tenant 与 sys_module；其余平台表随阶段四/五交付

## 3. 完成标准 <a id="accept"></a>

接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位实现返回固定或批量数据可支撑上层链路；`pytest`、`ruff`、`pyright` 全绿。

> 实现期验收要点（随后续阶段）：sys_tenant 三库迁移通过；demo 种子落库可查询；(code, deleted_at) 复合唯一索引生效（重复 code 插入被拒）；其余平台表未建。
