## 2. 任务内容 <a id="content"></a>

> **本阶段口径（接口占位）**：只落接口 / 抽象声明与占位实现（返回固定或批量数据，便于上层先跑通链路），不连真库、不跑迁移、不建表；下方为实现要点，随对应后续阶段填实现。
1. `GET /api/v1/modules`：平台库 sys_module 只读查询；响应 `{code: 0, message: "ok", data: {list: [{module_key, name, table_prefix, errcode_segment, event_domain, status}], total}}`；不分页、按 module_key 排序；查询参数 status 可选；软删除过滤；归属平台接口（豁免租户解析）
2. 鉴权口径：本阶段暂不鉴权（OpenAPI 标注 TODO：阶段五接入 platform:manage）；无任何写接口（POST/PUT/DELETE 不存在，404）
3. 实现约束：repository 层查询、响应模型显式声明（不直接返回 ORM 对象）、接口 docstring 完整（进入 OpenAPI 契约）

## 3. 完成标准 <a id="accept"></a>

接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位实现返回固定或批量数据可支撑上层链路；`pytest`、`ruff`、`pyright` 全绿。

> 实现期验收要点（随后续阶段）：`GET /api/v1/modules` 返回 4 条平台域注册记录、字段与响应契约一致；`?status` 筛选行为正确（当前 status=0 为空）；POST 该路径返回 404；接口在 /docs 可见且 docstring 完整。
