## 2. 任务内容 <a id="content"></a>

> **本阶段口径（接口占位）**：只落接口 / 抽象声明与占位实现（返回固定或批量数据，便于上层先跑通链路），不连真库、不跑迁移、不建表；下方为实现要点，随对应后续阶段填实现。
1. 解析链（按优先级）：子域名 `{tenant}.bms.example.com`（生产，查 sys_tenant.domain + Redis 短 TTL 缓存）→ 请求头 `X-Tenant-ID`（一人多租户切换，阶段四接入）→ token 内 tenant_id（开发兜底，阶段四接入；本阶段无认证，dev 环境 X-Tenant-ID + 默认 demo 兜底）
2. `TenantContext`（`app/core/tenant.py`）：tenant_code/db_key/引擎引用，FastAPI 依赖注入；禁止全局单例持有租户引擎/上下文
3. 中间件行为：未识别或未知租户（无记录/停用）→ HTTP 404 + 业务码 80001（登记错误码总表）；租户上下文注入日志 tenant 字段
4. 豁免路径：`/`、`/docs`、`/openapi.json`、`/healthz`、`/readyz`；平台级接口预留豁免位
5. dev/test 口径：X-Tenant-ID 指定租户、缺省 demo；prod token 缺席 401 占位不生效

## 3. 完成标准 <a id="accept"></a>

接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位实现返回固定或批量数据可支撑上层链路；`pytest`、`ruff`、`pyright` 全绿。

> 实现期验收要点（随后续阶段）：`X-Tenant-ID: demo` 请求日志 tenant 字段为 demo、数据读写落 bms_tenant_demo 库（SQLite 实测）；未知租户返回 404 + 80001；豁免路径不受租户校验影响；并发请求下 TenantContext 互不串扰（pytest 并发用例）。
