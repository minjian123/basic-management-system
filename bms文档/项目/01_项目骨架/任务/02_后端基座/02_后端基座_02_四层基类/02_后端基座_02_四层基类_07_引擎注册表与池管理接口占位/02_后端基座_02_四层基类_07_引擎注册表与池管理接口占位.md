## 2. 任务内容 <a id="content"></a>

> **本阶段口径（接口占位）**：只落接口 / 抽象声明与占位实现（返回固定或批量数据，便于上层先跑通链路），不连真库、不跑迁移、不建表；下方为实现要点，随对应后续阶段填实现。
1. `EngineRegistry`（`app/db/registry.py`）：`{db_key → engine}` 注册表；平台引擎常驻（启动即建）；租户引擎懒加载（首次访问创建，参数来自 config.toml）；get_engine 进程内锁保护创建段
2. 闲置回收：LRU + 最后使用时间（默认 30 分钟可配）dispose 回收；停用租户强制回收；活跃引擎数上限（默认 32 可配）超出按 LRU 淘汰
3. 连接预算：总连接 = worker × (pool_size + max_overflow) ≤ 数据库 max_connections 的 70%；启动校验超限告警日志
4. 并发保护：创建加锁（进程内锁 + Redis SETNX）；创建失败快速失败记 ERROR
5. 与 02_01（数据访问底座）衔接：EngineRegistry 管理工厂产出引擎（含达梦同步引擎）；TenantContext 持引擎引用

## 3. 完成标准 <a id="accept"></a>

接口 / 抽象声明就位、依赖注入可解析、应用可启动不报错、占位实现返回固定或批量数据可支撑上层链路；`pytest`、`ruff`、`pyright` 全绿。

> 实现期验收要点（随后续阶段）：demo 租户引擎首次请求才创建（启动后仅平台引擎存在）；闲置阈值调短后租户引擎自动回收；活跃上限调小后按 LRU 淘汰；并发 20 请求仅创建 1 个租户引擎；连接预算超限启动输出告警日志。
