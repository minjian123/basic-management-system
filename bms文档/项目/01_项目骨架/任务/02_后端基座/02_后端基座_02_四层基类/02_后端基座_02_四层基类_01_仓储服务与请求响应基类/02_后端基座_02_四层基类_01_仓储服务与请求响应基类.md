## 2. 任务内容 <a id="content"></a>

1. `BaseRepository[T]`：通用 CRUD 模板方法（`_build` / `_apply`）与 `exists` / `count` 派生方法；数据库实现作为**占位**保留（不连库）；数据源 / 分片路由钩子预留
2. `BaseService[T]`：通用 CRUD 委派仓储 + 统一不存在语义（`NotFoundError` → `BizError` 体系）
3. `BaseSchema`：Pydantic 公共配置（`from_attributes` / `str_strip_whitespace`）与统一序列化（继承 `BaseObject`）
4. 继承约定收口：模块类必须继承对应基类、只写差异部分；`ruff` / `pyright` 门禁保持零错误

## 3. 完成标准 <a id="accept"></a>

三套基类可继承、`exists` / `count` 与不存在语义行为正确（基类单测通过）；模块类不得重复定义基类公共字段 / 方法的约定可核对；`pytest` / `ruff` / `pyright` 全绿。
