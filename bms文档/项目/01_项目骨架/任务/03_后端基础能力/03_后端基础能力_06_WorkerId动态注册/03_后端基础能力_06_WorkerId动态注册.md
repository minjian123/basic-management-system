## 2. 任务内容 <a id="content"></a>

1. **Redis 租约注册**：启动时 `SET NX EX` 占一个空闲 WorkerId，定期心跳续租，进程退出释放；键形如 `bms:{env}:{unit}:worker_id:v2:{id}`（环境 + 部署单元隔离）。
2. **分配范围**：0 ~ 2⁴⁰−1（与 126 位方案的 40 位机器段一致），跳过已占用。
3. **降级**：Redis 不可用或注册失败回落 `BMS_APP__WORKER_ID` 并告警，不阻塞启动；生产未配置兜底且注册失败时拒启。
4. **短命进程**：seed / migrate / 一次性脚本同样走注册，用完释放，不长期占号。
5. **测试**：fakeredis 双进程注册不同号、释放后复用、TTL 到期回收、Redis 不可用回落；真 Redis 双实例用例。

## 3. 完成标准 <a id="accept"></a>

多进程并发启动拿到不同 WorkerId；进程崩溃后 TTL 到期可回收；Redis 不可用按降级口径回落配置值；注册键按环境 + 部署单元隔离；生产未配置且注册失败拒启；真 Redis 双实例用例通过；覆盖率达标（口径见《[AI开发规范](../../../../../规范/AI开发规范.md)「覆盖率要求」）。
