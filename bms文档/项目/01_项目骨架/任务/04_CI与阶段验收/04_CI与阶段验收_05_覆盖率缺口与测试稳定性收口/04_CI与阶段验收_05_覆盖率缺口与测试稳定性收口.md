## 2. 任务内容 <a id="content"></a>

1. **服务公共出口契约**：7 个服务 `domains/*/public.py` 的空 `__all__` 出口补「可导入 + 出口稳定」用例。
2. **迁移 / 注册表模块覆盖**：`db/migration.py`、`db/migration_guard.py`、`db/bootstrap.py`、`registry/products.py` 按可单测 / 仅集成分治，补用例或明确集成跳过口径。
3. **服务属性与边角分支**：`permission_meta.services.permission_meta` 等未触及属性 / 分支补断言或删除死代码。
4. **测试稳定性**：修正依赖仓库根 cwd 的用例（`test_heavy_command_guard` / `test_products`）与并行共享态用例（`test_modules`）。
5. **门禁复核**：全量 pytest + 覆盖率 100%（行 + 分支）+ `preflight --full` 全绿；回写《测试规范》本地全量口径。

## 3. 完成标准 <a id="accept"></a>

后端全量用例全绿；全量覆盖率 100%（行 + 分支，集成跳过项有明确口径）；`preflight --full` 全绿；`check_links` / `check_docs_scope` / `check_base` / `check_status` 全绿；不改变业务行为。
