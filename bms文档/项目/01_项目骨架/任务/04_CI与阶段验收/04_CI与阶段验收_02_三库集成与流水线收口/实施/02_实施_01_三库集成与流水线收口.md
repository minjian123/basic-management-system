## 3. 实施过程 <a id="process"></a>

1. **Kiwi 先登记**：登记本任务 1 条用例并取得编号 **67**（产品「BMS 基础管理系统」/ 分类「平台骨架」/ P2 / CONFIRMED / 标签「自动化」/ `is_automated=True`），题面含五项断言（计划输出、占位口径、骨架就位、真库 job 换镜像、开关守门）。
2. **占位脚本**：新增 `backend/ops/test_db.py`——`plan` / `create` / `migrate` / `drop` 四个子命令 + `--engine mysql|postgres|dm8`；库清单常量为**唯一事实源**（`bms_test_mysql` / `bms_test_pg` / 模式 `BMS_TEST_DM`）；占位口径＝默认计划模式，`--execute` 仅打印「真实执行归落库阶段」提示且无副作用；非法 `--engine` 由 argparse 以退出码 2 结束；模块方式调用（`uv run python -m ops.test_db`）。
3. **单测**：新增 `tests/ops/test_test_db.py`——三方言 `plan` 输出（库名 + 四步骤）、**与 `.gitlab-ci.yml` 的 `BMS_TEST_DB_URL` 库名逐字一致**（防两处漂移的常驻守护）、不带 `--execute` 为计划模式、带 `--execute` 仅占位提示、非法 engine 退出码 2、`resolve_test_database` 映射。
4. **集成骨架**：新增 `tests/integration/test_tenant_routing_integration.py`（`pytestmark = pytest.mark.integration`）——平台引擎同一性、租户解析 → 库键 → 引擎、跨租户隔离（占位口径＝库键分离）、租户引擎回收与连接预算边界、批量迁移 / 测试库清单（纯清单断言，**无需真库、恒常绿**）；需真库的 4 条以 `BMS_TEST_DB_URL` 未配置即跳过（形态对齐既有 Redis 集成用例）。
5. **CI 改动**：① 新增常跑 job `integration-plan`（stage `test`、镜像 `ci-backend:py314`、存在性守卫 `backend/ops/test_db.py`、依次跑三方言 `plan`）；② `.integration-base` 锚点：`image` 由 `python:3.14-slim` 改为 `$REGISTRY_IMAGE_PREFIX/ci-backend:py314`，**删除** `before_script` 的 `pip install uv && uv sync --frozen`，脚本改为 `cd backend` → `plan --engine "$DB_DIALECT"` → `pytest tests/integration -k "$DB_DIALECT" -v`，注释补「激活前置四项 + 所需 CI/CD 变量清单」。
6. **本地门禁**：`ruff check` / `ruff format --check` / `pyright` 通过；`pytest -q --cov=app --cov-branch --cov-fail-under=70` = **417 passed / 7 skipped**、覆盖率 **99.75%**；`base-check` 五项通过。
7. **推送验证**：推送 `247ee0b` → 流水线 **174 全绿、总时长 50 秒**；作业列表含新增 `integration-plan`（success），**真库 job 未出现**（无 `deploy/ci/verify-enabled`）。
8. **登记**：达梦方言实测四项与真库激活前置已入计划「后续阶段待办」节（设计 [§7.3](../设计/02_详细设计_01_三库集成与流水线收口.md#activation) / [§8](../设计/02_详细设计_01_三库集成与流水线收口.md#dm8)）。

## 6. 偏差与遗留 <a id="deviations"></a>

- **设计偏差（已回写设计 §14 第 12 行）**：`tests/db/test_tenant.py` **未重复扩充**——既有 Kiwi 38 用例已覆盖解析链（子域名 / 请求头 / token）、豁免路径、未知租户 404 / 80001、依赖注入与 `sys_tenant` 声明，重复扩充无增量价值；改为以新增集成骨架 + `tests/ops/test_test_db.py` 承担本任务测试增量。
- **遗留（均已在计划「后续阶段待办」节登记）**：
  1. **真实建库 / Alembic 迁移 / 删库清理**：`test_db.py` 的 `create` / `migrate` / `drop` 需填实现，并接通 `alembic/env.py` 在线分支 → 首个落库阶段；
  2. **真库用例与方言匹配**：真库用例须按方言命名或加方言标记，保证 `pytest -k "$DB_DIALECT"` 有匹配用例（否则退出码 5「无用例收集」误判失败）→ 激活前置第 4 项；
  3. **达梦方言实测四项**（软删除复合唯一索引 NULL 语义 / 迁移 DDL / schema 前缀与大小写 / 类型映射）→ 首个落库阶段，不通过即按《项目规划说明》「数据库兼容」节口径调整并修订需求；
  4. **CI/CD 变量配齐**（`MYSQL_TEST_PASSWORD` / `POSTGRES_TEST_PASSWORD` / `DM8_TEST_PASSWORD` / `MYSQL_ROOT_PASSWORD` / `GITLAB_API_TOKEN`）与 `verify-enabled` 开关 → 激活前置第 1、2、5 项。
