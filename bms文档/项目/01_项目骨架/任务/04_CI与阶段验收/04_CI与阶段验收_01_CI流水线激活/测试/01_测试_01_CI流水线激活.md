## 2. 测试范围与用例 <a id="scope"></a>

本任务的被测对象是 **CI 流水线本身**，用例以「流水线作业结论 + 本地等价命令」双轨验证：

| Kiwi | 断言 | 类型 | 验证载体 | 实测结果 |
| --- | --- | --- | --- | --- |
| 66-1 | 冒烟层 job 出现且全绿（含新增 `backend-typecheck` / `backend-modules` / `mobile-check`） | 流水线 | 流水线 170（`4c6553dc`）作业列表 | 11 job 全 success |
| 66-2 | 覆盖率门禁生效（后端 < 70%、前端双端 < 70% 时红） | 本地等价 + 配置 | `pytest --cov-fail-under=70`；双端 `vitest.config.ts` `thresholds` | 后端 99.75%、双端 100%（阈值 70% 未触发） |
| 66-3 | 模块注册清单校验（`-m` 方式退出码 0；冲突退出码 1） | 本地等价 + CI job | `uv run python -m ops.check_modules`；job `backend-modules` | `校验通过（4 项）`，job 2.6 秒 success |
| 66-4 | 免跑层：纯业务文档推送不建流水线；基座路径改动触发 `base-integrity` 且通过 | 流水线 | `074f4fb`（纯 `项目/` 文档）/ `9ec9c64`（含《测试规范》《文档首页》） | 前者无流水线；后者流水线 167 `base-integrity` success |
| 66-5 | 重验证层守卫：无 `deploy/ci/verify-enabled` 时重验证 job 不出现 | 流水线 | 流水线 170 作业列表 | 未出现 `e2e-playwright` / `integration-*` / `container-scanning` / `swagger-snapshot` / `allure-report` / `defect-capture` |

## 3. 执行记录与结果 <a id="run"></a>

```bash

$ uv run ruff format --check .     # 通过
$ uv run pyright                   # 0 errors, 0 warnings
$ uv run pytest -q --cov=app --cov-branch --cov-report=term --cov-fail-under=70
404 passed, 3 skipped in 1.58s
TOTAL                         3668      3    392      7    99%
Required test coverage of 70% reached. Total coverage: 99.75%
$ uv run python -m ops.check_modules
[模块注册] 校验通过（4 项）

# 前端双端（bms/frontend、bms/frontend-mobile）
$ npm run lint && npm run test:cov
 Test Files  4 passed (4)      Tests  18 passed (18)      All files | 100 | 100 | 100 | 100   # 两端同款

# 基座文档自检（bms 根）
$ python3 scripts/tools/base-check/check-base.py
1. 链接自洽：断链 0 处，失效锚点 0 处   2. 基座跨层引用：0 处   3. 项目专属措辞残留：0 处
4. 清单一致：登记 146 个，磁盘 146 个   5. 跨文档编号引用：0 处     → base-integrity 通过
```

## 5. 覆盖率 <a id="coverage"></a>

| 对象 | 口径 | 实测 | 门禁 |
| --- | --- | --- | --- |
| 后端 | `pytest --cov=app --cov-branch` | **99.75%**（3668 语句 / 3 未覆盖、392 分支 / 7 未覆盖） | 整体 ≥ 70%（`--cov-fail-under=70`）；核心模块 ≥ 80% 随认证 / RBAC 阶段接入 |
| apps/desktop | Vitest v8（被用例导入文件） | **100%**（18 用例 / 4 spec） | statements / branches / functions / lines 均 ≥ 70% |
| frontend-mobile | 同上 | **100%**（18 用例 / 4 spec） | 同上 |

> 前端全量 `src/**` 采集与阈值覆盖面随阶段四（前端组件库）扩面，口径见详细设计 §6.2。
