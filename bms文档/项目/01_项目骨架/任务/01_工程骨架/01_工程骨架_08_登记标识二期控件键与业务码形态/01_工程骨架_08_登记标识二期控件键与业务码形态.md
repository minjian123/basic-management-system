## 2. 任务内容 <a id="content"></a>

1. **字段控件语义键改 snake_case**：后端 `bms_core/fieldtype` 注册表的 `widget` 字面量（`dict-select` / `dict-multi` 等）与前端 `FIELD_WIDGETS` / 控件分发映射（`org-select` / `tree-select` / `file-upload` / `image-upload` / `dropdown-multi` / `i18n-name` / `i18n-text` 等）一次改齐；`ui_ep` 组件按语义键分发处与用例同步。
2. **业务码 / 动作码形态收紧**：后端权限元数据 schema 的 `code` 正则改 `^[a-z][a-z0-9_]*$`；前端业务 / 动作维护页提示文案与反例用例同步；**存量行不迁移**（现值无连字符）。
3. **自建图标码形态收紧**：`bms_core/icon/base.py::_ICON_CODE_RE` 与图标 schema 描述改 snake_case；前端图标维护页提示同步；**上游图标名**（`el:User` / `van:todo-o`）保留例外。
4. **机器护栏**：`check_base.py` 第 6 项扩扫三类登记面——控件语义键清单（前端 `FIELD_WIDGETS` + 后端 `widget=` 字面量）、业务 / 动作码与图标码形态正则（源码断言）、前端提示文案口径；并补 `--self-test` 正反例。
5. **规范与文档回写**：《命名规范》§2.1 登记面表补「字段控件语义键」、图标键条目限定为上游图标名例外（自建码按 snake）；《后端开发规范》字段类型节、《前端开发规范》控件语义键说明、`docs` 中相关示例同步。

## 3. 完成标准 <a id="accept"></a>

全仓无连字符形态的控件语义键；业务码 / 动作码 / 自建图标码在连字符输入下被拒（反例用例覆盖），上游图标名仍可用；`check_base` 对新增连字符控件键 / 业务动作码 / 自建图标码报错；后端全量用例与覆盖率 100%、前端全量 test / lint / typecheck / build、`check_links` / `check_docs_scope` / `check_status` / `preflight --fast` 全绿。
