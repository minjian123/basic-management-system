## 3. 执行记录与结果 <a id="run"></a>

```bash
cd frontend && npm run lint && npm run test:cov && npm run build
cd frontend-mobile && npm run lint && npm run test:cov && npm run build
# 各：12 passed；All files 100%（语句/分支/函数/行）
```

| 验证点 | 实测 |
| --- | --- |
| useRequest 竞态 | 两次并发 run，旧响应返回不改写 data；旧请求失败不写 error |
| useListPage | search 回第 1 页；changePage 透传；reset 恢复默认；reload 保持条件；空数据回退 []/0 |
| validators | 手机/邮箱/身份证/URL 正反例；密码强度 weak/medium/strong（含无小写组合）；规则工厂结构 |
| useTabs | 重复建不新增；白名单外忽略；关闭非激活不切换；关闭激活回退最后一个；关到空清空；持久化与容错恢复 |
| EntityStatus | `common.enabled/disabled` 映射与 i18n 文案（启用/停用） |
