## 2. 任务内容 <a id="content"></a>

1. **实现下沉**：新增 `frontend/scripts/api-types/generate.mjs` 作为唯一实现（多契约枚举、`--files-from` 增量跳过、`--check` 零漂移 + 缺失 / 多余 / 差异行号），导出 `run({ packageDir })` 并提供 `--config` CLI 入口；依赖按**调用方包目录**解析（`createRequire`），不从实现文件位置静态导入。
2. **产品配置化**：三仓 `packages/api-types*/api-types.config.json` 声明 `contractsDir` / `outDir` / `indexFile` / 头注释文案 / 汇总导出模板 / 增量判据前缀；实现不出现任何仓名。
3. **薄壳保留**：三仓 `scripts/generate.mjs` 改为薄壳（传本包目录），`pnpm run api-types:gen|gen:check`、预检步骤与 CI 命令一律不变。
4. **产物零变化**：三仓生成物与 `index.ts` 逐字节不变；`--check` 全绿。
5. **口径回写**：msg 前端生成器用例（Kiwi 2463）按统一文案与退出码更新；新增产品仓只加配置 + 薄壳。

## 3. 完成标准 <a id="accept"></a>

- 三仓 `node packages/api-types*/scripts/generate.mjs --check` 全绿且无产物 diff；
- bms `--files-from` 携带无关改动时打印「跳过」并退 0；
- msg 前端用例（Kiwi 2463）全绿；
- 三仓 lint / 预检 / CI 前端 job 全绿。

## 4. 边界 <a id="boundary"></a>

| 项 | 处理 |
| --- | --- |
| 契约快照生成（后端 `contract_snapshot export`） | 不在本任务：那是后端侧事实源导出 |
| 生成器产物形态（导入路径 / 类型风格） | 不变（`openapi-typescript` 版本由各仓锁文件决定） |
| 产品仓另立任务 | 不做：产品仓只提交薄壳 + 配置，提交信息引用本任务 |
