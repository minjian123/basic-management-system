## 2. 实施过程 <a id="process"></a>

1. **统一实现**：新增 `bms/frontend/scripts/api-types/generate.mjs`（导出 `run`，含 CLI `--config`；多契约枚举 / 增量 / 零漂移 + 缺失 / 多余 / 差异行号）。
2. **依赖解析**：`createRequire(<packageDir>/package.json)` 解析 `openapi-typescript` 再动态 import（兼容 CJS 桥接形态），避免从基座 scripts 目录静态导入导致 `ERR_MODULE_NOT_FOUND`。
3. **三仓配置**：`bms/frontend/packages/api_types/api-types.config.json`（含 bms 原有 4 条增量前缀）、`mdm/frontend/packages/api-types/api-types.config.json`、`msg/frontend/packages/api-types/api-types.config.json`。
4. **三仓薄壳**：`scripts/generate.mjs` 改为 import 基座实现并传本包目录；bms 走 `../../../scripts/api-types/`，mdm / msg 走 `../../../../../bms/frontend/scripts/api-types/`。
5. **用例同步**：msg `tests/api-types-generation.spec.ts` 的漂移 / 缺失退出码断言由 `2` 改为 `1`（统一口径）。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
