## 3. 实施过程 <a id="process"></a>

### 3.1 进程内并发集合（`core/concurrent.py`）

- `ReadWriteLock`：读并行、写独占、**写优先防饿死**（有等待写者时新读者排队）；
- `LockStrategy`：`RW`（默认）/ `RLCK` / `SHARDED`（仅 dict/set，list 自动降级 RW）/ `SNAPSHOT`（读无锁、写复制后原子替换）；
- `ConcurrentSortedList / ConcurrentSortedSet / ConcurrentSortedDict`：所有写操作走策略上下文；遍历/序列化一律**快照副本**；
- 原子复合方法：`put_if_absent`、`update_atomic`（键缺失抛 KeyError）、`remove_atomic`、`replace_if_equal`（CAS）、`get_and_remove`、`get_locked`（holder 写回）；集合另有 `add_if_absent` / `remove_atomic`；
- 分片策略：`hash(key) % N` 分桶、桶内 RLock；单键操作持「全局读锁 + 桶锁」（跨桶并行），整体视图持全局写锁后合并各桶有序快照（`heapq.merge`，输出仍按键全局有序）。

### 3.2 Redis 有序封装（`core/redis_collections.py`）

- `RedisSortedSet[T]`：ZSET 直用（add/incr/remove/score/range_by_rank/top/range_by_score/size）；
- `RedisSortedDict[K, V]`：`{key}:index`（ZSET，数值键按数值 score、其余 score=0 字典序）+ `{key}:data`（Hash）；`set / set_if_absent / delete` 用 **Lua 脚本**原子保证两结构一致；`get / contains / items / size` 用原生命令；
- 版本号：写路径 `INCR {key}:version`；`RedisSnapshot` 本地只读快照按版本号惰性比对、`invalidate` 强制重载（与 dogpile 全局版本号机制同构）；
- key 命名遵循《命名规范》`bms:{租户|global}:{域}:{键}`，由调用方传入完整 key；连接注入 `redis.asyncio.Redis`。

### 3.3 微基准与规范

- `benchmarks/bench_collections.py`：单/4 线程、读写比 1:9、键空间 500，对比裸 `SortedDict` 与四策略（输出表格 + JSON）；CI 不跑；
- 《后端开发规范》§8 增补并发集合条款（策略选择、锁内禁 IO、跨副本走 Redis）。

## 4. 问题与处置 <a id="issues"></a>

| # | 问题 / 现象 | 原因 | 处置 | 落点 |
| --- | --- | --- | --- | --- |
| 1 | 分片策略下 `get("a") is None`（初始数据丢失） | 构造时只建了 `_data` 副本，未把初始条目分发到分片 | 物化 entries 后按键哈希写入分片；迭代器先 `list(...)` 避免被 `_data` 构造消费 | `concurrent.py` |
| 2 | 快照用例顺序断言失败（期望 `[a, b]` 得 `[b, a]`） | `top` 按 score 降序，用例预期写反 | 修正断言 | 测试记录 |
| 3 | 4 线程吞吐低于单线程 | CPython GIL 下内存密集操作无并行收益，锁为正确性成本 | 基准如实记录；策略按场景选择，500 并发随阶段九/十压测复评 | 基准输出 |

## 6. 偏差与遗留 <a id="deviations"></a>

- 与设计一致；`RedisSortedDict` 复合写使用 Lua 三脚本（set / set_if_absent / delete），`update_atomic` 等 CAS 类复合操作在 01-3-2 未提供——已于 **01-3-3「Redis 复合操作与并发语义」补全**（Lua CAS + WATCH 乐观重试）。
- 真实 Redis integration 用例已由 01-3-3 提供（`tests/integration/test_redis_collections_integration.py`，标 `integration`，经 `BMS_TEST_REDIS_URL` 注入），并已补入 05-02 集成用例清单；集群/哨兵口径随部署设计。
- 大 key 阈值（10 万元素 / 10MB）与分片数默认 16 待**阶段十（性能加固与压测）**校准。
- free-threading（3.14t）未启用，启用后复跑微基准确认锁开销。
