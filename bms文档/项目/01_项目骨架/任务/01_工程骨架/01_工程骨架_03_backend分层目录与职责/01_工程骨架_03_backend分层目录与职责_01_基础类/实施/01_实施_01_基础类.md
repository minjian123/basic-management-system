## 3. 实施过程 <a id="process"></a>

### 3.1 Kiwi TCMS 用例登记（先登记再写代码）

沿用产品「BMS 基础管理系统」/ 分类「平台骨架」，登记 Case 11（BaseRepository 通用 CRUD 与派生方法）、12（BaseService 不存在语义）、13（BaseSchema 公共配置与继承链）。

### 3.2 三套基类

- `repositories/base_repository.py`：`BaseRepository[ModelT](ABC)` 模板方法——子类只实现 `_build/_apply`；`list/get/create/update/delete` 通用流程（自增 ID、排序、字典存取）基类实现；`exists/count` 派生方法；内存基线字段 `_items/_next_id`（数据库实现覆写原子方法后弃用）。
- `services/base_service.py`：`BaseService[ModelT]` 委派仓储；`get/update/delete` 不存在统一抛 `NotFoundError`；`list/exists/count/create` 转发。
- `schemas/base.py`：`BaseSchema` 统一 `ConfigDict(from_attributes=True, str_strip_whitespace=True)`。

泛型写法采用 **PEP 695**（`class BaseRepository[ModelT]`），由 ruff（UP046，target py314）提示修正，设计稿同步更新。

### 3.3 不存在语义收敛

- `core/exceptions.py` 新增 `NotFoundError`（占位，02-3 归入 BizError 体系）。
- `main.py` 注册临时处理器：`NotFoundError → JSONResponse(404, {"detail": ...})`（与 FastAPI 默认 404 body 对齐）。
- api/service 层删除逐个 `None` 判断，404 一处产出。

### 3.4 demo 三件套改造

- `DemoRepository(BaseRepository[Demo])`：只写 `_build/_apply`（`str(values["name"])`）。
- `DemoService(BaseService[Demo])`：保留 `list_demos/get_demo/create_demo/update_demo/delete_demo` 模块命名（api 与用例不动），内部转发基类；返回类型去 Optional。
- demo 请求/响应模型继承 `BaseSchema`。
- `api/demo.py`：删除 `HTTPException` 与 None 判断，端点回归「取数 → 组装响应」。

### 3.5 规范与层 docstring

- 《后端开发规范》§4 增补「类继承约定（强制）」四条：Repository/Service/Schema 继承对应基类、公共能力只加基类。
- repositories/services/schemas 三处 `__init__.py` docstring 增加继承约定行。

### 3.6 测试与提交

新增 `tests/repositories/test_base_repository.py`（6 条）、`tests/services/test_base_service.py`（5 条）、`tests/schemas/test_base_schema.py`（3 条），全部标注 `kiwi_id`；既有 API 用例 1–10 回归。随后形成本批提交（等用户指令）。

## 6. 偏差与遗留 <a id="deviations"></a>

- 偏差：设计稿泛型示例原为 `TypeVar + Generic` 写法，实现按 ruff 提示改为 PEP 695（已回写设计 §4）。
- `NotFoundError` 与 404 处理器为过渡实现：02-3 统一异常体系接管后替换（测试只断言状态码，body 调整不影响断言）。
- 通用能力（分页、软删除过滤等）待 02-5/03-2 定稿后**只回填基类**，模块类不改（继承约定即为此服务）。
- async 化随 02-5 在基类统一切换，调用面改动集中一次。
- **后续变更回写（2026-09-13）**：`Demo` 由内存 dataclass 改为继承 `BaseModel` 的 ORM 模型（随 02-2-4）；`BaseObject` 去 `ABC`、序列化口径升级为声明字段优先（随 02-2-3 / 02-2-4）；`NotFoundError` 纳入 `BizError` 体系（随 02-3-1）。详见各任务实施 / 测试记录。
