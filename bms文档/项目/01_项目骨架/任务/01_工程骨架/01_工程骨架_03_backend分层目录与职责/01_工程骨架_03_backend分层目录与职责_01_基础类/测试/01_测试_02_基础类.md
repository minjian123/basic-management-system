## 3. 执行记录与结果 <a id="run"></a>

```bash
cd backend
uv run pytest -q
# 65 passed
```

| 验证点 | 实测 |
| --- | --- |
| `Demo(id=1, name="甲").to_json()` | `{"id": 1, "name": "甲"}` |
| `Nested(...).to_json()` 含不可序列化对象 | 键排序输出，`object object at ...` 降级字符串 |
| `Entity(1) == Entity(1)` / `Entity(None) != Entity(None)` | 主键相等 / 身份不等 |
| `SortedList([3, 1, 2]).to_json()` | `[1, 2, 3]` |
| `SortedDict({"b": 2, "a": 1}).to_dict()` | `{"a": 1, "b": 2}`（键序） |
| `SortedList([1]).to_dict()` | 抛 TypeError（提示 to_list） |

质量门禁（辅助）：`ruff` 通过；`pyright` 0 errors。
