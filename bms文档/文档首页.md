## 1. 用途说明 <a id="purpose"></a>

本文档是 `bms文档/` 目录的**全量索引**，汇总 BMS 项目全部规划、规范、资料与设计文档，按目录分类提供跳转入口。文件格式约定：正文载体不限（`.md` / `.html`），线框图/可交互原型用 `.html` 资产（见《[文档生成规范](规范/文档生成规范.md)》）。

## 2. 目录结构总览 <a id="structure"></a>

```text
bms文档/
├── 基座文档清单.md  # 通用基座权威清单（bms 权威源；产品侧以软链引用基座）
├── 规划/       # 项目级规划文档
├── 项目/       # 按阶段的项目基线
│   └── 00_准备期/  # 阶段0（准备期 / M0 启动就绪）
│       ├── 需求/   # 阶段需求基线
│       ├── 任务/   # 阶段任务基线（按需求域分文件夹）
│       └── 计划/   # 阶段计划基线
├── 规范/       # 开发与文档规范
├── 设计/       # 系统设计文档
│   ├── 架构设计/  # 总体架构与子系统设计
│   ├── 概要设计/  # 平台模块详细设计
│   ├── 布局设计/  # 界面布局方案
│   └── 组件设计/  # 通用组件契约与交互设计
├── 资料/       # 参考资料、工具与部署使用说明
│   ├── 开发服务器/ # linux/ 子目录为 mjbk 部署说明，windows/ 子目录为 mjw 部署说明
│   ├── 开发机/   # mjpc 开发机部署记录
│   └── 知识档案/  # 技术栈知识档案（72 项技术介绍）
└── 用户文档/   # 本地资源（机器凭据等）
```
