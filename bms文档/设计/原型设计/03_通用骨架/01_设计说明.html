1. 模块概述

全系统复用的通用骨架：登录页（租户标识 + 账号密码 + 策略渠道验证码 + SSO / 扫码入口）、扫码登录页（二维码五态 + 多入口切换）、用户注册页（自助注册到租户，产品启用开关）、主框架（侧边栏 + Tab 栏 + 顶栏角标）、 个人中心（改密/语言/时区/主题/列表个性化/通知偏好）。对应《概要设计》认证与会话、 《架构设计-前端架构》。

3. 交互要点

  • 登录：独立全屏页 + 居中单卡片；租户标识默认隐藏，后端无法唯一解析租户（`20007`）时才展开输入框并聚焦（本机已记住的租户编码静默带上、不显示该项；单租户 / 子域名部署下永不出现）；验证码初始不显示、策略强制或首次失败后出现（形态按策略渠道取首个可渲染：滑块默认 / 图形兜底）；记住我默认不勾选；SSO 入口按 IdP 清单渲染、清单为空整块隐藏，含可扫码入口；锁定 / 停用 / 强制改密提示
  • 扫码登录：独立全屏页（与登录页同形态族）；二维码相位五态 + 有效期倒计时（过期遮罩 + 自动重取一次 + 手动刷新）；可扫码入口 > 1 分段切换、= 0 空态并返回账号登录；二维码内容不含账号 / 口令 / 令牌明文
  • 用户注册：独立全屏页（与登录页同形态族）；注册是平台身份能力，是否开放由产品启用开关决定（biz 不启用 → 整块空态并返回登录；cw 启用）；自助注册到租户——租户标识默认隐藏，后端无法唯一解析租户（`20007`）时才展开输入框并聚焦（单租户 / 子域名部署下永不出现）；邮箱 / 手机至少一项（验证码发往所填通道、60 秒倒计时）；密码强度实时反馈（长度 ≥8 / 小写 / 大写 / 数字 / 符号，提交要求 ≥ 中）；服务协议与隐私政策必勾
  • 主框架：工作台 Tab 固定不可关；侧边栏折叠为图标态；角标随模拟数据变化
  • 表单框架：列表 Tab 固定不可关；双击行开表单 Tab（默认只读）；新增开编辑态 Tab；修改未保存切换/关闭触发脏数据确认；保存后回填 id 并刷新列表
  • 个人中心：改密复杂度实时校验；偏好保存即 Toast 确认（模拟跨端同步）

4. 主框架 ↔ 表单框架 联动链路

实体模块（用户管理及各类业务表单等）在内容区以表单框架（FormFrame）形态承载，形成「页面级 Tab → FormFrame 层 Tab」两级嵌套：

  1. 主框架：点击侧边菜单叶子（如「用户列表」）→ 打开页面级 Tab，内容区加载对应实体页面（FormFrame 外壳）
  2. 表单框架 · 列表：FormFrame 顶部「列表」Tab 固定不可关，承载该实体的列表页；列表页为独立组件，仅通过约定事件与框架交互
  3. 双击明细行：双击列表数据行 → 在 FormFrame 内打开对应记录的表单页（详情 Tab），标题取记录标识字段，表单回填该行数据（主框架内打开时经 openDetail 回调，独立打开时直接跳转并带参）
  4. 详情 Tab（多开）：不同记录各自新开一个详情 Tab（可同时打开多条记录，每个 Tab 为独立表单实例、切换保留状态）；已打开的记录再次双击则激活对应 Tab，不重复新建；默认只读，可点「修改」进入编辑态；关闭详情 Tab 后激活其左侧相邻 Tab，无详情 Tab 时回到列表 Tab（列表 Tab 不可关）
工具栏分开：列表页工具栏（新增/刷新/关闭等）与表单页工具栏（修改/保存/删除/刷新/关闭，编辑态「修改」变「保存」）为两处独立工具栏，分别承载于列表页、表单页组件内部（见《布局设计-表单框架》第 4 节）；FormFrame 层不提供统一工具栏。
