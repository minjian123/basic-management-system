1. 模块概述

平台超管维护的权限元数据：菜单树 CRUD、菜单 ↔ 表单多对多挂接（关联表 sys_menu_form）、 表单 1:1 挂业务、按钮 1:1 挂权限码、字段挂表单，以及业务码 / 动作码 / 权限码三本字典与租户自定义图标清单。 数据存于平台库（自定义图标存租户库），是动态路由、侧边栏与表单元数据下发的唯一依据；租户侧只读引用。

三词分治（2026-10-10 拍板）：业务码（sys_business，纯资源维度）、动作码（sys_action， 全局动词维度，去业务归属）为独立字典，权限码＝业务码 × 动作码组合（sys_permission，唯一强制校验单位）； 三者各独立成页（业务码管理 / 动作码管理 / 权限码管理），权限码为受控可授项、只能选已存在的组合。

界面按《布局设计 · 表单框架》组织为「列表 Tab + 记录 Tab」： 列表页无操作列、双击行打开记录 Tab；菜单 / 表单 / 按钮 / 字段挂接并入「菜单记录 Tab」的「挂接配置」页签。 字段权限（sys_role_field）授予归角色管理（role:grant），本模块只提供配置入口。 对应《概要设计-菜单管理》、《组件设计 · 图标选择器》。

边界说明：挂接配置 ≠ 角色授权

本模块的挂接配置与角色管理的菜单权限 / 表单权限（操作 · 字段）最容易混淆，但二者处于不同层面、不重复： 挂接配置定义「系统里有哪些菜单 / 表单 / 按钮 / 字段、它们之间怎么挂、每个按钮对应哪个动作码」（授权对象的定义，平台库元数据、平台超管维护、全局一份）； 角色的菜单 / 表单权限决定「某个角色能用其中哪些」（授权关系，租户库、安全管理员维护、按角色多份）。 即：前者是有哪些可授项，后者是给谁授了哪些。

  • 「表单挂接」 vs 角色的「菜单权限 / 表单权限」：前者定义 菜单 ↔ 表单 的结构关系（多对多，sys_menu_form）；后者勾选「这个角色能看到哪个菜单入口、能进哪个表单」（sys_role_permission.target_id 指向挂接配置定义出的对象）。
  • 「按钮维护 / 字段维护」 vs 角色的「权限码 / 字段权限」：前者定义按钮实体（名称、类型、挂哪个权限码）与字段实体（field_key、名称、类型、排序），即「这个表单上有哪些按钮 / 字段」；后者是勾选授予「这个角色能用哪些按钮、哪些字段可见 / 可编辑」，不改按钮 / 字段本身的定义。
  • 「字段权限入口」：菜单记录页「挂接配置」内只是跳转入口（去角色管理配 role:grant），本身不做授予。

分口依据：唯一授权落点是角色管理——菜单权限 / 表单权限码写 sys_role_permission、字段权限写 sys_role_field（均需 role:grant）；菜单管理只做实体定义与挂接。 见《概要设计-菜单管理》「职责边界」、《概要设计-角色管理》「功能点分解」。

3. 交互要点

  • 宿主：列表 Tab 固定不可关；双击数据行 / 点「新增」打开对应记录 Tab（新增即编辑态，保存后回填并刷新列表）；列表页无操作列。
  • 单一保存：记录页保存只在页面工具栏一处——菜单记录页「挂接配置」内表单挂接 / 按钮维护 / 字段维护的改动均只进草稿，随宿主工具栏「保存」一次统一提交（「取消」即放弃草稿）。
  • 菜单树：树形表格承载层级（parent_id）；隐藏（hidden）仅隐藏侧边栏入口、权限仍生效（路由可直达）；路径 / 组件冲突或格式非法拒绝保存（40203）；元数据量级小，树形一次返回不分页。
  • 树形展开策略：菜单树节点为目录 / 菜单（按钮归独立实体，不在树内）；默认展开按规模自适应——节点数 ≤ 阈值（原型取 50）默认全展开、超过则只展开第一层（避免大树默认铺开的视觉冗长与定位困难）；展开状态本地记忆（localStorage，键 bms_menu_expanded，与主框架侧栏同口径），刷新 / 返回保留；搜索命中自动展开命中路径并高亮（筛选态下的临时展开不写入偏好）；工具栏「全部展开 / 全部折叠」一键切换。本策略为通用表格「树形模式」的组件默认行为（见《组件设计 · 通用表格》§7），本页按默认生效。
  • 树形表格性能口径：菜单树为元数据、量级小（几十~几百节点，树形一次返回不分页），卡顿风险低；注意 Element Plus 树形表格折叠时行仍保留在 DOM（仅 display:none），故「默认展开」主要影响视觉长度与定位而非 DOM 量——性能护栏靠元数据量级小，而非展开策略；若未来节点规模显著增长，再评估虚拟滚动或按层懒加载。
  • 挂接链完整性：菜单 ↔ 表单多对多（关联表 sys_menu_form，同一表单可被多入口引用、表单可无入口）、表单 1:1 挂业务、按钮 1:1 挂权限码、字段挂表单；任一缺失导致该链路不可见 / 不可用，保存时校验并提示（40202）。
  • 字段权限入口：字段权限（visible / editable）写入 sys_role_field，授予归角色管理（role:grant），本页仅提供「前往角色管理」入口。
  • 权限码：业务 / 动作 / 权限码存平台库、平台统一维护，租户侧可见、可分配、不可增删（40204）；一经发布稳定不变，停用代替删除，被引用时先解除授权（40206）。业务码 / 动作码 / 权限码三本字典各独立成页——业务码为纯资源维度、动作码为全局动词维度（去业务归属）、权限码＝业务码 × 动作码组合（受控可授项）。
  • 图标 key 口径：菜单 / 卡片等字段一律存完整 icon key——el: 平台官方 / biz: 业务自绘 / custom: 租户自定义；租户自定义 icon key 由后端按 custom:{图标键}（kebab-case）统一派生，业务与前端不得自拼前缀。
  • 自定义图标：上传仅 SVG（类型白名单 + 大小上限），内容清洗（移除脚本 / 事件属性 / 外链）由后端兜底、前端内联渲染前再清洗；引用检查——被菜单 / 卡片引用时先解除引用或用「停用」代替（40206）；停用后不在选择器候选与渲染清单中出现，已引用处按降级处理；清单浏览登录即可，维护需 icon:manage。
  • 错误码：挂接链断裂 40202、路径 / 组件冲突或格式非法 40203、业务 / 动作码平台维护租户不可改 40204、字段 key 表单内重复 40205、被引用禁停用 / 删除 40206、字段权限与字段实体不匹配 40207；菜单 / 表单 / 按钮 / 字段变更发布 sys.form.updated。
