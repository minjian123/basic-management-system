1. 模块概述

用户＝系统账号：用户增删改查、启用/停用、重置密码、角色分配，以及账号锁定治理（锁定列表、手动锁定、手动解锁、解锁记录查询）。 界面按《布局设计 · 表单框架》组织为「列表 Tab + 用户记录 Tab」： 列表页无操作列、双击行打开记录 Tab；角色分配与经 mdm 插件的岗位 / 部门分配并入记录 Tab 的「用户分配」页签。

组织与岗位关系归 mdm：用户页不硬依赖 mdm 对象——无部门 / 岗位列、无部门 / 岗位筛选； 岗位分配、部门分配由 mdm 组织域插件经具名插槽插入（插件缺失即隐藏，bms 单独运行 / cw 工作区无 mdm 时该能力不呈现，页面其余正常）。 语言与时区偏好（locale / timezone）属个人中心，不在本模块。 对应《概要设计-用户管理》；脱敏与密码策略见认证与安全。

3. 交互要点

  • 宿主：列表 Tab 固定不可关；双击数据行 / 点「新增」打开用户记录 Tab（新增即编辑态，保存后回填并刷新列表）；列表页无操作列。
  • 单一保存：用户记录页保存只在页面工具栏一处——「详细信息」页签保存基本资料，「角色分配」随该次保存提交；mdm 插件页签（岗位 / 部门分配）为即时提交（不随宿主工具栏保存）。
  • 状态内联开关：用户列表「状态」列以内联开关切换（复用 PUT /api/v1/users/{id}/status，不新增 toggle 接口）；停用为危险操作，切换前二次确认，停用即时失效该用户全部会话（踢出）；内置管理员不可停用（30009）。状态仅表示 sys_user.status（启用 / 停用）——账号锁定态归「账号锁定」页，不进用户列表。
  • 角色分配：多选角色（写 sys_user_role，与角色管理页「角色分配 — 用户分配」同一张关系表）；变更后权限版本 +1 并清理该用户权限缓存，即时生效。
  • 用户分配页签：内含三子页签——角色分配（bms 内建）· 岗位分配 · 部门分配（后两者由 mdm 插件插入）。一个用户可有多个岗位 / 部门，其中至多一个主要岗位 / 主要部门，用户所属岗位与部门以主要项为准。
  • 插件降级：mdm 未注册 / 未启用时，岗位分配与部门分配子页签不渲染（页面其余正常、不报错）；页面提供「模拟 mdm 插件」开关演示三态。
  • 重置密码：列表工具栏入口限单行选中（不批量）；重置后写密码历史（近 5 次不可重复）、强制改密可选、全部会话失效。
  • 手动锁定 / 解锁：手动锁定写 sys_account_lock manual 型（无期限，须手动解锁），记录锁定人与原因；解锁记录 unlock_by / unlock_at，落操作日志与审计；已解锁记录不可再选、不可再解锁。
