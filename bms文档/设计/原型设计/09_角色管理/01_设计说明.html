1. 模块概述

角色增删改查、主体绑定（用户 / 岗位 / 部门任意主体链）、授权配置（权限树 / 字段权限 / 数据范围）， 以及角色授权变更的即时生效。界面按《布局设计 · 表单框架》组织为「表单框架」：列表 Tab + 角色记录 Tab， 列表页无操作列、双击行打开记录 Tab；授权配置并入角色记录 Tab 的「权限配置」页签。 对应《概要设计-角色管理》、 《组件设计-权限配置》； 三权分立约束见权限模型。

3. 交互要点

  • 宿主：列表 Tab 固定不可关；双击数据行 / 点「新增」打开角色记录 Tab（新增即编辑态，保存后回填并刷新列表）；列表页无操作列，状态列内联开关。
  • 基本信息：角色码创建后只读；内置角色（系统 / 安全 / 审计管理员，code 固定）不可删除 / 停用 / 变更归属；三权互斥由后端校验（30048）。
  • 权限树：菜单 → 表单 → 业务（推导只读）→ 动作（按钮，1:1 挂动作）；勾选菜单隐含其表单与业务权限（业务不直接授予）；动作默认无；挂接缺失节点标记「未挂接」且不可授予（30046）；支持搜索、三态勾选。
  • 字段权限：表单 × 字段矩阵（可见 / 可编辑），默认全部可见可编辑、授予后收窄；批量全选、仅显示已收窄、搜索；不可见字段读时不返回、不可编辑字段写时拒绝（30049）。
  • 数据范围：按动作配置规则表达式（字段 + 运算符 + 预置变量，如 dept_id = @current_dept），默认无数据权限；预置变量插入与模板套用（本人 / 本部门 / 本部门及下级 / 本租户）；保存前校验（30047），规则结果强制叠加租户过滤。
  • 主体绑定：用户 / 岗位 / 部门页签，搜索 + 勾选即绑定、移除即解绑；单主体可绑定角色数上限（默认 20）超限提示；post / dept 主体引用 mdm 组织主数据 id（跨库逻辑引用）。
  • 授权提交：四类授权全量覆盖提交（先删后插、单事务）+ 幂等键；保存后权限版本 +1（一次递增）并清理关联用户缓存，即时生效；未保存变更标记脏数据，切换 / 关闭前拦截。
