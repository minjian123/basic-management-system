1. 模块概述

角色增删改查、主体绑定（用户 / 岗位 / 部门任意主体链）、授权配置（权限树 / 字段权限 / 数据范围）， 以及角色授权变更的即时生效。界面按《布局设计 · 表单框架》组织为「表单框架」：列表 Tab + 角色记录 Tab， 列表页无操作列、双击行打开记录 Tab；授权配置并入角色记录 Tab 的「权限配置」页签。 对应《概要设计-角色管理》、 《组件设计-权限配置》； 三权分立约束见权限模型。

2. 界面清单

界面原型（可点击操作）主要交互验证点
角色列表页（表单框架 · 列表 Tab）角色列表页.html三段式（工具栏 / 筛选 / 表格）、无操作列、双击行打开记录 Tab、批量删除（内置角色保护）、状态标签
角色表单页（表单框架 · 角色记录 Tab）角色表单页.html只读 / 编辑分态、信息栏三子页签（详细信息 / 权限配置 / 系统信息）、工具栏单一保存；权限配置四页签：菜单权限（菜单树 → 该入口的操作权限 / 字段权限两 Tab）、表单权限（所有表单列表 → 操作权限 / 字段权限两 Tab，含无菜单入口的表单）、数据范围、主体绑定；权限按来源区分（本入口连带可改 / 非本入口只读）

3. 交互要点

  • 宿主：列表 Tab 固定不可关；双击数据行 / 点「新增」打开角色记录 Tab（新增即编辑态，保存后回填并刷新列表）；列表页无操作列。
  • 单一保存：保存只在页面工具栏一处——「详细信息」页签保存基本信息，「权限配置」页签保存授权；授权页签不再另设保存按钮，未保存变更以脏数据提示，工具栏「撤销」放弃授权变更。
  • 基本信息：角色码创建后只读；内置角色（系统 / 安全 / 审计管理员，code 固定）不可删除 / 停用 / 变更归属；三权互斥由后端校验（30048）。
  • 菜单权限：菜单树只列菜单入口（不出现按钮 / 操作）；勾选菜单入口＝对用户显示，并连带授予其表单查看权限。选中入口后右侧两个 Tab：操作权限（该表单的操作，默认无）+ 字段权限（该表单字段，默认全开）；均按来源区分——本入口连带生成的可改，非本入口来源只读（标注「来自其它入口」）。
  • 表单权限：列出所有表单（含无菜单入口的表单，菜单 ↔ 表单**多对多**）；选中表单右侧两 Tab（操作权限 / 字段权限）作为补充授权：表单级直接授予的可改，来自菜单入口的来源只读（标注「来自菜单入口」）。
  • 数据范围：按动作配置规则表达式（字段 + 运算符 + 预置变量，如 dept_id = @current_dept），默认无数据权限；预置变量插入与模板套用（本人 / 本部门 / 本部门及下级 / 本租户）；保存前校验（30047），规则结果强制叠加租户过滤。
  • 主体绑定：用户 / 岗位 / 部门页签，搜索 + 勾选即绑定、移除即解绑；单主体可绑定角色数上限（默认 20）超限提示；post / dept 主体引用 mdm 组织主数据 id（跨库逻辑引用）。
  • 授权提交：四类授权全量覆盖提交（先删后插、单事务）+ 幂等键；保存后权限版本 +1（一次递增）并清理关联用户缓存，即时生效。
