1. 目的与适用范围

规范 PC 管理端登录页的页面形态、区块划分与交互语义。登录页是未登录用户进入系统的唯一入口， 承载本地账号密码登录、租户识别、验证码与外部身份（SSO）入口。

登录页是独立全屏页——不嵌入主框架（无侧边菜单与 Tab 标签栏）， 与《布局设计-异常与空状态》的错误页同属「全屏独立页」形态； 登录成功后的跳转与回跳目标由路由守卫负责（见《架构设计 · 前端架构》「路由守卫」节）。

上游依据：《概要设计 · 身份认证（SSO）》「页面清单」节 （登录页＝账号密码登录 + 租户配置的 IdP 入口展示）、 《架构设计 · 认证与会话》（双 token 模型与 SSO 集成）、 《组件设计 · 验证码》（验证码字段与阈值联动）。

2. 页面形态与整体布局

2.1 独立全屏页

  • 独立路由、独立视图，不套主框架：无侧边菜单、无 Tab 标签栏、无面包屑。
  • 整页一屏，页面背景铺满视口；内容垂直水平居中。
  • 与主框架共用设计令牌与主题（亮 / 暗），但不共用主框架的骨架结构。
  • 已登录用户访问登录页时由路由守卫直接回跳目标页（本页不负责该判定）。

2.2 居中单卡片

区块内容说明
品牌区Logo + 系统名称按租户替换，缺省用平台默认品牌资源（见第 6 节）
表单区租户标识 / 账号 / 密码 / 验证码 / 提交按钮 / 错误反馈见第 3、4 节；字段随状态增减（如验证码仅失败后出现）
第三方入口区IdP 登录入口见第 5 节；无可用 IdP 时整块不渲染
  • 卡片宽度固定、水平居中；高度随内容自适应（验证码出现 / 错误提示出现时向下伸展，不跳动布局锚点）。
  • 区块自上而下：品牌区 → 表单区 → 第三方入口区；区块之间用间距令牌分隔，不用分割线堆叠。
  • 不展示技术信息（版本号、环境标识、堆栈），遵循《安全开发规范》。

2.3 窄屏与暗色

  • 窄屏：视口小于断点时卡片宽度收敛为「视口宽度 − 安全边距」，不出现横向滚动；字号与间距按断点收敛（断点口径见《布局设计-响应式适配》）。
  • 暗色：背景与卡片、输入、文本全部走令牌，暗色模式下对比度达标，无硬编码色值。
  • 移动端：移动端登录页为独立体系（见《布局设计-移动端》与《布局设计-移动端细化》），本节点只约束 PC；两端登录口径（错误码、验证码策略、会话链路）同源。

3. 表单区

字段 / 元素形态语义与交互
租户标识文本框（可选）缺省回填本机已记住的租户编码，可清空；占位提示「子域名部署可留空」；留空表示由子域名或后端上下文解析租户
账号文本框（必填）支持账号 / 手机 / 邮箱等后端认可口径；去掉首尾空白后再提交
密码密码框（必填）不回填、不写日志与本地存储；提供明文切换（仅组件内存态）；声明一次性密码自动填充语义以抑制浏览器误填
验证码字段件（按策略）见第 4 节；未出现时不占位
记住我复选框（可选）缺省不勾选；勾选仅延长 refresh 保留时长（14 天持久），不勾选为会话级（浏览器关闭即失效）；不落 access、不变更 access 有效期（口径成文，见 05-5）
提交主按钮（整宽）点击或回车触发；提交中按钮内 loading 且整个表单禁用（防重复提交）
错误反馈表单级提示 + 字段级提示账号 / 密码类错误按「账号或密码错误」等价文案呈现（不泄露账号是否存在）；账号锁定 / 停用 / 限流给出对应引导文案
  • 提供「记住我」勾选项：仅影响 refresh 保留时长（勾选=14 天持久 / 不勾选=会话级），不落 access、不变更 access 有效期（口径成文，见 05-5）。
  • 不显示密码强度提示：登录场景输入的是既有密码，强度语义归改密 / 注册场景。
  • 字段排列为单列、自上而下；标签与占位文案遵循《命名规范》与全局语言能力。

4. 验证码与登录保护

项设计
展示时机初始不显示；首次登录失败后出现并强制；后端返回「需要验证码」时同样触发显示（阈值由按租户下发的场景策略决定）
形态选择按场景策略下发的可用渠道序列取首个可用形态（平台默认滑块 → 图形兜底）；不提供用户切换入口
图形码展示后端生成的图片，点击图片或刷新按钮重新出题（防缓存）；校验失败或使用后一次性失效并自动刷新
滑块拖动到缺口位置后提交轨迹由后端判定；失败自动复位并提示可重试；键盘可操作
短信目标手机号脱敏展示 + 发送按钮 + 倒计时（以服务端冷却为准）；命中发送限流时提示但不重置倒计时
错误提示验证码错误 / 已失效 / 发送过于频繁分别提示，文案与后端错误码语义一致
  • 验证码渠道不可用（未注入数据通路 / 策略强制而数据源不可达）时按字段件的降级占位呈现，不静默放行。
  • 连续失败驱动的保护联动（失败计数、锁定）以后端判定为准，前端只按返回结果呈现。

5. SSO 与其它入口

  • IdP 入口：按后端下发的 IdP 清单（仅启用项）渲染入口按钮（图标 + 名称，按排序值升序）；点击后跳转外部授权端点，回跳由后端回调完成并落地会话。
  • 不可用时隐藏：清单为空或某 IdP 凭据缺失 / 不可用时不渲染该入口（不出现点了没反应的按钮）；SSO 故障不影响本地账号密码登录（超管应急通道口径）。
  • 失败回显：SSO 回调失败时回到登录页并展示错误提示（错误码 → 文案）。
  • 扫码登录：登录页第三方入口区在存在可扫码入口（企业微信 / 钉钉）时显示「扫码登录」入口，进入扫码登录独立页（见 5.1）；无可用入口时不渲染该入口。
  • 忘记密码：本页暂不放找回密码入口（找回 / 重置页面归后续阶段），后续以次要链接形式加入表单区底部。

5.1 扫码登录独立页

  • 页面形态：独立全屏页（不嵌主框架），品牌区 + 居中单卡片，与登录页同一形态族；亮 / 暗主题走令牌。
  • 可扫码入口：按后端下发的 IdP 清单过滤可扫码类型（企业微信 / 钉钉）；其余类型仍走登录页的跳转入口。
  • 二维码与状态：经二维码件渲染授权二维码；状态可视（待扫 / 已扫待确认 / 已确认 / 过期 / 失败），过期显示遮罩与刷新；二维码内容不含账号 / 口令 / 令牌明文。
  • 多入口切换：同一租户存在多个可扫码入口时提供切换（标签 / 分段），切换后重建二维码与状态。
  • 可扫码入口为空：整块空态提示并返回账号登录（不出现点了没反应的二维码）。
  • 完成与返回：授权确认后进入系统（沿用登录回跳目标）；页面提供「返回账号登录」，返回时保留回跳目标。

6. 品牌与主题

  • 品牌区 Logo、系统名称与页面背景按租户替换，缺省用平台默认品牌资源；资源管理口径见《布局设计-主题与租户品牌化》。
  • 租户主色经令牌覆盖，登录页按钮与链接随主色变化；不硬编码色值。
  • 亮 / 暗主题跟随全局偏好；页面背景在暗色下使用令牌语义底色。

7. 交互与状态

状态表现
登录提交中提交按钮内 loading，表单整体禁用；重复提交被拦截
首屏会话续期由应用根骨架屏承载等待态；登录页在续期判定完成前不渲染（不闪登录页）
登录成功写入会话并跳转：有回跳目标则回原页面，否则回首页
登录失败表单级错误提示；验证码按第 4 节规则出现 / 刷新；密码框内容保留以便用户修正
账号锁定 / 停用明确提示与引导（联系管理员 / 稍后重试），不暴露内部细节
限流命中提示频繁并给出重试指引；不重置短信倒计时
需强制改密登录成功后提示「请尽快修改初始密码」（改密页面归后续阶段）
  • 键盘：Tab 序自上而下、回车提交；明文切换按钮可聚焦并有可访问名称。
  • 不写控制台日志、不落 `localStorage` / `sessionStorage`（租户编码除外，见第 3 节与《安全开发规范》「前端密码口径」）。

8. 边界与检查清单

  • □ 独立全屏页，不嵌主框架；卡片居中、窄屏收敛无横向滚动
  • □ 品牌区按租户替换；亮 / 暗主题正常
  • □ 租户标识可选并可回填；账号 / 密码 / 验证码齐备
  • □ 验证码初始不显示、失败后出现；渠道按策略取首个、图形兜底；失败刷新与短信倒计时正确
  • □ IdP 入口按清单渲染，不可用即隐藏；SSO 失败回登录页有提示
  • □ 提供「记住我」勾选项（缺省不勾选；勾选=14 天 / 不勾选=会话级）、无密码强度提示（口径成文，见 05-5）
  • □ 密码不回填、不明文落存储、明文切换仅内存态
  • □ 登录中态防重复提交；错误 / 锁定 / 限流 / 强制改密提示齐备
