1. 目的与适用范围

定义 BMS 前端（PC 管理端 Element Plus + 移动端 H5 Vant）的设计令牌（Design Tokens）： 色彩、字体、间距、栅格、圆角、阴影、图标等基础规范，作为全部布局与组件样式的单一事实来源。 与《前端开发规范》配套。

4. 间距与栅格

令牌值典型用途
--space-xs4px图标与文字、行内元素

--space-md12px表单项间距、列表单元

  • 栅格：PC 24 列（Element Plus el-row/el-col，12 列为其基础栅格倍数），内容区宽度随浏览器缩放自适应（不设固定最大宽度，见《响应式适配》第 3 节）；间距遵循 4px 基准（4/8/12/16/24/32）。
  • 页面内容区边距：PC 24px（--space-xl），移动端 16px。
  • 禁止散落魔法间距值（如 13px、21px），一律取令牌。

  --color-primary: #0969da;

  /* ... 全部令牌 */
}
/* 映射到 Element Plus 变量 */
:root {
  --el-color-primary: var(--color-primary);
  --el-border-radius-base: var(--radius-md);

工程命名映射（2026-09-16 登记）

  • 前缀：基础令牌在工程中统一加 --bms- 前缀（--bms-color-* / --bms-font-* / --bms-line-height-* / --bms-space-* / --bms-radius-* / --bms-shadow-*），避免与组件库变量（--el-* / --van-*）及第三方冲突。
  • 间距命名：工程采用数字步进 --bms-space-{n}（n × 4px）——与语义名映射：xs→1(4px) / sm→2(8px) / md→3(12px) / lg→4(16px) / xl→6(24px) / xxl→8(32px)；新增档位零命名成本。
  • 组件库映射：PC 端映射 Element Plus（五语义色 + 全色阶经 color-mix() 运行时派生 + 圆角 + 字体族与基础字号）；移动端映射 Vant 四语义色；租户品牌覆盖（动态主色与色阶跟随）归《主题与租户品牌化》。

组件令牌（size / density，2026-09-16 登记）

/* frontend/apps/{desktop,mobile}/src/styles/tokens.scss —— 组件根属性协议（两端各自导入） */
:root {
  --bms-size-control-height-{small|default|large}: 24px | 32px | 40px;
  --bms-size-font-{small|default|large}: 12px | 14px | 16px;
  --bms-size-icon-{small|default|large}: 14px | 16px | 20px;
  --bms-density-gap-{compact|default|loose}: 4px | 8px | 16px;
  --bms-density-row-{compact|default|loose}: 28px | 32px | 40px;
}
/* 语义变量（组件只消费这五个） */
[data-size='small' | 'default' | 'large'] {
  --bms-size-control-height: …; --bms-size-font: …; --bms-size-icon: …;
}
[data-density='compact' | 'default' | 'loose'] {
  --bms-density-gap: …; --bms-density-row: …;
}
  • 档位：size（small / default / large）与 density（compact / default / loose）；组件只消费语义变量 --bms-size-control-height / --bms-size-font / --bms-size-icon / --bms-density-gap / --bms-density-row，不关心档位。
  • 属性协议：组件根（BaseComponent / useComponentBase / BaseComponent.vue）把档位写在根元素属性 data-size / data-density 上，令牌文件用属性选择器映射；不设 data-density 表示继承上层（密度上下文提供者随布局域任务）。
  • 文件与落地：阶段四组件库先行实现为 frontend/apps/*/src/styles/tokens.scss（两端各自导入 main.ts）；基础令牌（--bms-* 五组）已随 03_06 落地（2026-09-16），size 字号 / density 间距已改为引用基础令牌（属性协议不变）。
  • 组件样式不硬编码色值与尺寸；新增令牌同样先在本文件登记后使用。
