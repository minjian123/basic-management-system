## 1. 模块概述与归属 <a id="overview"></a>

邮件通知承载**外发渠道**：邮件模板（Jinja2 + 多语言）、短信模板（场景 / 渠道 / 厂商模板）、异步 SMTP 与阿里云 / 腾讯云短信发送、发送记录与失败定位。模板平台默认在代码内置、租户库可覆盖；发送统一经外发调度器（渠道过滤 / 免打扰）与作业中心（重试 / 死信）。

| 项 | 值 |
| --- | --- |
| 对应概要 | [《概要设计 · 邮件通知》](../概要设计/24_概要设计_邮件通知.md) |
| 对应架构 | [《架构设计 · 子系统 · 通知公告》](../架构设计/22_架构设计_子系统_通知公告.md) §4 / §5 / §6 |
| 归属部署单元 / 库 | notification 服务租户库 `bms_notification_{code}`（域 `notification`，`datasource=tenant`） |
| 迁移 | 历史脚本已清空；结构以模型为唯一事实源，随 `notification:tenant` 链幂等建表 |

## 3. 关键设计要点 <a id="key"></a>

- **主键与软删除**：五表均继承 `BaseModel`（雪花 ID 主键 + `deleted_at` 软删除 + 审计 + 乐观锁）；模板唯一约束统一带 `deleted_at`（阶段八贯穿口径）。
- **平台默认 + 租户覆盖**：默认模板在代码内置（`mail_defaults.py` / `sms_defaults.py`），本表只存租户行；读取先租户库、无同 code 回落内置；租户行 `disabled` 视为显式停用不回落，删除覆盖行后自动回落。
- **多语言**：邮件主题 / 正文逐语言存 `sys_mail_template_i18n`；主表两列是系统默认语言派生快照；读取三级回退（请求 / 收件人 locale → 系统默认语言 → 主表列）。短信不建 i18n 附表。
- **沙箱**：模板保存时 Jinja2 语法校验 + 危险结构拦截 + 沙箱冒烟渲染；发送前严格渲染（缺参 / 超时 / 超输出即失败）。
- **异步发送**：发送请求同事务写 `sys_*_log`（`pending`）+ 提交作业（`notification.mail.send` / `notification.sms.send`）；worker 执行成功回写 `success` / `sent_at`，失败回写 `failed` / `error_msg` 并由作业中心重试（3 次 / 30 秒退避）。
- **正文存放**：渲染结果放作业负载（随作业保留期清理）；邮件日志只存主题，短信日志存脱敏正文。
- **渠道与场景**：短信模板按 `(code, channel)` 区分厂商模板，`scene` 取选项集 `bms.sms.scene`；全局配置 `[sms].channel` 决定当前生效渠道，日志标注实际渠道。
- **统一过滤**：渠道开关与免打扰只在外发调度器判定；通知组把已读偏好传入，避免两处漂移。
- **审计**：两张模板表属关键表，字段级变更经 ORM 事件记录（notification 服务装载期注册白名单）；三张日志表不审计。
- **索引**：`sys_mail_template` 唯一 + `(status)` + 公共 = 3；`sys_mail_template_i18n` 唯一 + 公共 = 2；`sys_mail_log` / `sys_sms_log` 唯一 + 3 业务索引 + 公共 = 5；`sys_sms_template` 唯一 + 2 业务索引 + 公共 = 4。

## 4. 与相邻模块的边界 <a id="boundary"></a>

| 相邻 | 归属 | 说明 |
| --- | --- | --- |
| [通知中心](18_数据库设计_通知中心.md) | `sys_notification` | 站内信；外发渠道经通知组消费后交外发调度器，不直写通知表 |
| [公告管理](19_数据库设计_公告管理.md) | `sys_notice` | 公告与邮件 / 短信数据隔离；公告不直接产生外发记录 |
| 国际化管理（30） | `sys_i18n_locale` / `sys_i18n_message`（platform 服务） | 邮件模板多语言只走 `sys_mail_template_i18n`；默认语言标记暂由基座常量兜底 |
| 用户管理（04） | `sys_user`（platform 服务） | 收件地址 / locale 经平台用户只读出口读取，不跨库读 `sys_user` |
| 异步作业中心（38） | `sys_job` / `sys_job_error` | 发送作业经作业中心执行、重试与死信；本节点不建作业表 |
| 归档（31） | 归档策略机制 | 五表可纳入 14_01 归档策略；本节点不建策略 |
| 认证与会话（14） | 验证码 / 找回密码 | `BaseNotifier` 的 `http` 实现调通知服务内部发送端点，事务性消息跳过偏好过滤 |
