## 2. 字段 <a id="fields"></a>

公共字段继承 `BaseModel`（雪花 ID / 审计 / 软删除 / 乐观锁），下表不再重复说明其语义。

| 字段 | 类型 | 可空 | 约束 / 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | DECIMAL(38,0) | 否 | 主键，雪花 ID | 主键 · **系统字段**：ID |
| `field_id` | DECIMAL(38,0) | 否 | 与 `locale` / `deleted_at` 复合唯一；建索引 | 自建字段 ID（逻辑外键 → `sys_field_ext.id`，同库） · **系统字段**：主表 ID |
| `locale` | VARCHAR(16) | 否 | 同上 | 语言标识（IETF 标准形态，如 `zh-CN`；比较大小写不敏感） |
| `name` | VARCHAR(128) | 否 | — | 字段名的该语言文案 |
| `parent_id` | DECIMAL(38,0) | 是 | — | 上级明细 ID（自引用同表 `id`；本表无层级，按附表统一口径保留） · **系统字段**：上级明细 ID |

| `updated_by` | DECIMAL(38,0) | 是 | 审计 | 更新人 · **系统字段**：审计字段 |
| `deleted_at` | DATETIME | 是 | 软删除（NULL=未删） | 软删除时间 · **系统字段**：软删除 |

## 3. 索引与约束 <a id="index"></a>

| 名称 | 类型 | 列 | 说明 |
| --- | --- | --- | --- |
| `uq_sys_field_ext_i18n_field_locale_deleted_at` | 唯一 | `(field_id, locale, deleted_at)` | 同字段同语言仅一条；软删除后可复用 |

- 无物理外键；`field_id` 为同库逻辑外键（`sys_field_ext.id`）。
- **同生命周期**：主表软删时附表行同事务连带软删（经 `bms_core/repositories/i18n.py::soft_delete_i18n`），不留孤儿行（台账 `check_i18n_attachments.py` 断言）。
- **主表默认文案列是派生快照**：`sys_field_ext.name` 由服务端按「系统默认语言 → 必填语言 → 首个有值语言」派生写入，永不为空；写侧只提交「locale → 文案」映射。
