## 1. 模块概述与归属 <a id="overview"></a>

国际化管理承载「加一门语言不发版」的数据底座：**语言清单**（`sys_i18n_locale`，含 RTL 与默认语言标记）与**固定文案语言包**（`sys_i18n_message`，`msg_key` × `locale`）；业务数据的多语言不走主表列，一律走 `{主表}_i18n` 附表（约定见《[数据规范](02_数据库设计_数据规范.md)》§5，本节点不重复）。

| 对应架构 | [《架构设计 · 子系统 · 国际化》](../架构设计/24_架构设计_子系统_国际化.md) §2 / §3 / §4 |

## 3. 关键设计要点 <a id="key"></a>

- **平台默认物化到租户库**：平台默认语言行与文案行由幂等种子（`bms_core/i18n/seed.py`）下发到各租户库，标 `is_overridden=false`；租户改值 / 新增语言置 `true`。读取**只走租户库单表**，不做跨库合并；平台默认升级只刷新 `false` 行，不覆盖租户定制。
- **默认语言唯一且不写死标识**：默认语言由 `sys_i18n_locale.is_default` 标记确定（全清单恰一条、不可停用、不可删除）；它只承担「派生主表默认文案」与「缺省回退目标」，**不承担必填语义**（必填语言＝当前登录用户语言）。唯一性由应用层保证（软删 + 布尔列无法用跨方言一致的唯一索引表达），缺失 / 重复即 `44006`。
- **locale 形态统一**：库内、契约、前端一律 IETF 标准形态（`zh-CN` / `en-US` / `ar-SA`），比较一律大小写不敏感（与既有 `sys_*_i18n` 附表数据一致）。
- **文案缺失即空白**：`value` 去空白后为空即视为该语言缺失，读取侧回退默认语言文案；不存「缺失」状态列。
- **唯一性靠应用层**：两表沿用 `(唯一字段, deleted_at)` 复合唯一，但 `deleted_at IS NULL` 时该约束不生效（NULL 互不相等，三库同语义），写路径必须先 `SELECT` 判重；该共性问题在总览登记、阶段收口统一评估。
- **缓存**：清单键 `bms:{tenant}:i18n:locales`、语言包键 `bms:{tenant}:i18n:messages:{locale}`、版本键 `bms:{tenant}:i18n:version`（`INCR`、不设过期）；写路径「提交事务 → DEL 键 → INCR 版本 → 刷新进程内快照」，语言清单变更连带失效全部语言包键（切默认语言会改变所有语言的回退结果）。
- **审计**：语言清单与语言包的写路径经 `AuditCapturer.capture` 落字段级审计（落库与哈希链归 06_01 / 06_02），语言包数据量小、不分片不归档。
- **不建物理外键**：`sys_i18n_message.locale` 为对 `sys_i18n_locale.code` 的软引用（允许语言停用后保留存量文案）。

## 4. 与相邻模块的边界 <a id="boundary"></a>

| 相邻 | 归属 | 说明 |
| --- | --- | --- |
| 菜单管理（[08](01_数据库设计_总览.md#structure-modules)） | `sys_menu_i18n` 等附表 | 菜单 / 表单 / 字段 / 业务码 / 动作码名称的多语言走各自附表，本节点只提供语言清单（语言格与默认语言标记） |
| 字典管理（[10](01_数据库设计_总览.md#structure-modules)） | 字典数据源 | 字典取数缓存键含 locale 维度（`bms:{tenant}:dict:{locale}:{type}`）；语言清单变更后，字典缓存按既有 `DictInvalidator` 口径失效 |
| 邮件通知（[25](01_数据库设计_总览.md#structure-modules)） | `sys_mail_template_i18n` | 模板多语言内容走附表，主题与正文按收件人 locale 取；固定文案（错误 / 按钮）才走 `sys_i18n_message` |
| 用户管理（[04](01_数据库设计_总览.md#structure-modules)） | `sys_user.locale` / `timezone` | 用户语言 / 时区偏好字段留 `sys_user`；偏好维护归 05_02，本节点只提供语言清单 |
| 审计合规（[29](01_数据库设计_总览.md#structure-modules)） | `sys_data_audit_log` | 语言包与清单变更落字段级审计事件，由审计链消费 |
