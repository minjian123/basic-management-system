## 1. 模块概述与归属 <a id="overview"></a>

帮助中心是**与权限同级的横切机制**：声明面（元数据 `help_key`，08_01）、装载面（产品帮助包，08_03）、内容面（分类 / 文章 / 反馈，12_01）。本节点只承载**内容面的数据表**；锚点声明在菜单 / 表单 / 字段 / 按钮 / 动作码五表，不在此节点。

| 项 | 值 |
| --- | --- |
| 对应概要 | [《概要设计 · 帮助中心》](../概要设计/17_概要设计_帮助中心.md) |
| 对应架构 | [《架构设计 · 子系统 · 帮助中心》](../架构设计/28_架构设计_子系统_帮助中心.md) §3.3 / §3.4 / §4.2 |
| 归属部署单元 / 库 | platform 服务租户库 `bms_platform_{code}`（域 `help`，`datasource=tenant`） |
| 迁移 | 历史脚本已清空；结构以模型为唯一事实源，随 `help:tenant` 链幂等建表 |

- 声明面五表（`sys_menu` / `sys_form` / `sys_field` / `sys_button` / `sys_action` 的 `help_key`）归 08-菜单管理，不在此节点重复。

  由维护入口在同一事务内增减，统计与列表读计数列而不聚合反馈表。

## 3. 关键设计要点 <a id="key"></a>

- **三态文章**：`draft` 草稿 / `published` 已发布 / `offline` 已下架；解析只取 `published`，草稿与下架不进入前台与检索。
- **来源与优先级**：`source` ∈ `builtin`（平台内建）/ `product`（产品包）/ `tenant`（租户自建）；同目标多篇按 `builtin > product > tenant` 取一篇，同来源按包版本降序。产品包不得覆盖平台内建同目标文章（装载期跳过并告警）。
- **包版本与幂等**：`sys_help_package` 一行一个「产品 × 版本」；同版本 + 同校验和重复装载零变更；包内移除只置 `offline`，不物理删；卸载按产品清理，租户自建保留。
- **本地覆盖**：`local_override=true` 的文章在升级时整篇跳过，租户编辑优先；但包内移除仍置 `offline`。
- **多锚点**：文章与目标一对多，落 `sys_help_article_target`；`target_key` 逐字等于元数据 `help_key`，`global` 为空串。装载期校验锚点存在且类型匹配（`40008`）。
- **多语言**：标题 / 正文逐语言存 `sys_help_article_i18n`；主表两列为租户默认语言派生快照，读取按「请求语言 → 租户默认语言 → 主表快照」回退。
- **分类弱归属**：分类按路径 upsert，已存在只更新 `sort`，不改其下已有文章；删除分类前须先迁移或级联下架文章（12_01 校验）。
- **索引**：文章 `(category_id, status)`、`(status, is_top, publish_at)`、`(source, source_key)`；目标 `(target_type, target_key)`；包 `(product_key, status)`；分类 `(parent_id, sort)`——均在表文件登记，每表 ≤5。
- **软删除**：全部表复用 `deleted_at`；包内移除与卸载只改状态，不软删文章，保留审计与恢复能力。
- **反馈联合唯一**：`sys_help_feedback` 以 `(article_id, user_id, deleted_at)` 防重复；再次提交即改投并调整文章表两侧计数，
  不产生第二行；计数经单条 `UPDATE` 自增（不进字段级审计，审计只覆盖内容变更）。

## 4. 与相邻模块的边界 <a id="boundary"></a>

| 相邻 | 归属 | 说明 |
| --- | --- | --- |
| 菜单管理（节点 08） | 五表 `help_key` | 帮助只引用锚点，不创建 / 修改菜单、表单、字段、按钮、动作码 |
| [国际化管理](30_数据库设计_国际化管理.md) | `sys_help_article_i18n` | 附表结构与回退口径遵循《数据规范》§5；台账在 30 节点登记 |
| 12_01 帮助内容维护 | `sys_help_feedback` / 维护接口 / 读者面 | 反馈表与维护、读者、统计、包管理接口随 12_01 落地；分类 / 文章状态机与内容缓存同批交付 |
| 08_04 覆盖率门禁 | — | 覆盖率对账读元数据锚点，不读帮助内容表；「有锚点无文章」由内容面单独统计 |
