## 1. 模块概述与归属 <a id="overview"></a>

异步作业中心承载**一次性、可恢复、有进度**的异步执行：作业提交 / 消费 / 租约 / 进度 / 重试 / 取消 / 死信 / 监控。数据分两处落点——作业记录与行级错误是**基础设施表**（每服务每链各一份，与作业执行同库同事务），作业类型目录与监控投影在**平台库**（跨服务统一视图）。本节点对应四张表（字段唯一事实源为各表文件，本节点不复制字段清单）。

## 3. 关键设计要点 <a id="key"></a>

- **作业记录随执行落库**：`sys_job` 是基础设施表，进每条服务平台链与租户链的建表集（`unit_tables` 追加），与发件箱三表同口径；作业只能在提供方服务自己的库里被抢占与执行。
- **状态机六态**：`queued` / `running` / `succeeded` / `failed` / `canceled` / `dead`；终态不可回退，重试只发生在 `running → queued`；`failed` 是业务终态失败，`dead` 是重试耗尽 / 系统异常的死信。
- **至少一次执行**：租约（`lease_owner` + `lease_until`）到期后回收重排；`attempts` 每次抢占 +1，handler 必须幂等或以业务唯一约束兜底。
- **抢占是条件 UPDATE**：`status='queued' AND (next_run_at IS NULL OR next_run_at<=now)` 上做 CAS，`rowcount=1` 才算抢到；不依赖 `SKIP LOCKED`，四方言同一口径。
- **公平调度**：`priority` 只在同租户内排序（`ORDER BY priority DESC, id ASC`），单租户并发上限在 worker 进程内约束，不跨租户抢占。
- **幂等提交**：`(job_type, idempotency_key)` 唯一约束兜底并发穿透；作业记录按保留期硬删，唯一约束**不并入 `deleted_at`**（NULL 互异会破坏幂等）。
- **目录是声明投影**：`sys_job_type` 由 `[[jobs]]` 装载写入，`content_hash` 未变不写；平台不手写产品记录，退役用 `status=retired` 表达，不删行。
- **监控投影可重建**：`sys_job_monitor` 由 `job-monitor` 消费组按 `job_id` upsert，`last_event_at` 防旧事件覆盖；投影不可用只影响平台统一列表，不影响执行与服务本地查询。
- **保留期**：作业与投影同为 30 天（`[jobs].retention_days`）；`sys_job_error` 随作业硬删；`queued` / `running` 永不删除。
- **不建物理外键**：`sys_job_error.job_id`、`sys_job_monitor.job_id` 均为逻辑关联。

## 4. 与相邻模块的边界 <a id="boundary"></a>

| 相邻 | 归属 | 说明 |
| --- | --- | --- |
| 任务调度（[24](01_数据库设计_总览.md#structure-modules)） | `sys_task` / `sys_task_log` | 任务定义与 cron 保留；到期提交 `sys.task.run` 作业，执行结果回写 `sys_task_log` 作为历史 |
| 事件总线（[05](01_数据库设计_总览.md#structure-modules)） | `sys_outbox` / `sys_event_consumed` | 四条 `sys.job.*` 事件与状态更新同事务写发件箱；投影消费幂等沿用消费账本 |
| 文件管理（[14](14_数据库设计_文件管理.md)） | `sys_file` / `sys_file_part` | 孤儿清理迁为 `file.cleanup_orphans` 作业；文件表仍归 file 域，作业中心不跨库写 |
| 导入导出（[20](01_数据库设计_总览.md#structure-modules)） | 复用本节点 | 阈值内同步导入走 `run_inline`（同一 `sys_job` 记录与状态机）；超阈值提交异步作业，不另建导入作业表 |
| 通知中心（[18](01_数据库设计_总览.md#structure-modules)） | `sys_notification` | 作业完成事件 `sys.job.completed` 登记为可订阅事件，通知中心后续消费；作业中心不直连渠道 |
| 服务目录（[03](03_数据库设计_模块注册.md)） | `sys_module` | 作业提供方按服务目录校验 `service_key`；`sys_job_type` 不替代服务目录 |
