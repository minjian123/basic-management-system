## 1. 模块概述与归属 <a id="overview"></a>

租户管理承载 SaaS 多租户的**租户注册、库名对照、配额与模块开通**：一租户一独立库（每服务），平台库只保存租户级运营数据。本节点对应 **tenant 服务平台库** `bms_tenant` 的四张表（字段唯一事实源为各表文件，本节点不复制字段清单）。

## 3. 关键设计要点 <a id="key"></a>

- **租户类型**：`sys_tenant.kind`（`business` / `platform`）。平台租户全局唯一一条（`code` 取 `[platform_tenant].code`），承载平台超管的账号 / 角色 / 会话，与业务租户**同构**；业务租户列表、唯一启用租户兜底与租户切换一律排除平台租户。
- **开通状态机**：`provisioning`（注册行已落、建库/建表/种子进行中）→ `active`；失败清理已建库并删除注册行。`suspended` 为停用，仅可 `activate` 恢复。
- **域名唯一**：`(domain, deleted_at)` 复合唯一承担子域名路由唯一性；冲突 `82004`。
- **配额无行即不限**：默认值由 `[tenant_quota]` 播种；用量实时增量（原子条件更新），不按用户复制规则。
- **模块清单**：平台基础模块（foundation / capability 分组）恒开通；产品模块的恒开通由**服务行声明**（`tenant_base = true`，如主数据服务），其余产品模块仅勾选才写行；停用只切状态、不删行（存量数据保留可查）。
- **不建物理外键**：`tenant_id` / `module_key` 均为逻辑外键（同库 / 跨库按 code），跨库查询禁止 JOIN。
- **库名基**：库键与库名由 `sys_tenant_database.db_basis` 派生，`code` 变更不重命名库。

## 4. 与相邻模块的边界 <a id="boundary"></a>

| 相邻 | 归属 | 说明 |
| --- | --- | --- |
| `sys_module` / `sys_product` | platform 服务平台库 | 模块目录与产品注册；`sys_tenant_module.module_key` 逻辑引用 `sys_module.code`（只读经契约 / 快照） |
| `sys_user` / `sys_role` / `sys_session` | platform / identity 服务租户库 | 平台租户的账号 / 角色 / 会话与业务租户同构，落各自的 `*_platform` 租户库；本节点不持有账号数据 |
| 审计 / 归档策略 | platform 服务租户库 `sys_config` | 开通种子写「四类审计日志 90 天归档」参数；正式策略表归审计合规节点 |
