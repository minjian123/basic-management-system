## 2. 类型映射 <a id="type"></a>

| 逻辑类型（设计侧写法） | 达梦 DM8 落点 | 结论 |
| --- | --- | --- |
| `BIGINT`（主键 / 外键） | BIGINT | 实测（DDL 编译 + 真库建表） |
| `DATETIME`（各 `*_at`） | DATETIME | 实测 |
| `INT` / `SMALLINT` | INTEGER / SMALLINT | 实测 |
| `VARCHAR(n)` | **VARCHAR2(n CHAR)**（按字符计长） | 实测（n 以字符为单位，与 MySQL / PostgreSQL 语义一致） |
| `TEXT` | TEXT | 实测 |
| `BOOLEAN` | SMALLINT | 实测（布尔经小整数等价表达，见 [数据规范](../02_数据库设计_数据规范.md) 第 3 节） |
| `JSON`（多值字段） | JSON | 实测（建表通过；JSON 值读写与检索 **待验**） |
| `DECIMAL(20,4)`（金额） | DECIMAL(20,4) | 实测（DDL 编译） |

- 设计侧**禁止**直接写 `VARCHAR2`：沿用逻辑类型 `VARCHAR(n)`，由方言层映射（迁移脚本不写方言类型）。
- 需按时间比较的列统一 DATETIME（UTC naive），不依赖库端时间函数。

## 3. DDL 与对象差异 <a id="ddl"></a>

| 事项 | 达梦 DM8 行为 | 对平台的影响 |
| --- | --- | --- |
| 库级隔离 | 模式为单位：`CREATE SCHEMA <名>` / `DROP SCHEMA <名> CASCADE`（**实测**） | 建删库经 `ops/db_admin.py`（达梦分支建删模式，同步助手线程执行） |
| 会话模式切换 | 迁移前 `SET SCHEMA <模式>`（会话级，**实测**）；不支持时回落 `ALTER SESSION SET CURRENT_SCHEMA` | 迁移命令加 `-x schema=<模式名>`，由 `apply_session_schema` 写入（非达梦为空操作） |
| 模式存在性检查 | `ALL_USERS` **不含** `CREATE SCHEMA` 建出的模式；须查 `SYS.SYSOBJECTS WHERE TYPE$ = 'SCH'`（**实测**） | 建删库存在性判断按此实现（否则误判「不存在」而跳过） |
| Alembic DDL impl | Alembic **未内建** `dm` 方言实现，`MigrationContext` 会直接 `KeyError: 'dm'`（**实测**） | `alembic/env.py` 注册 `DMImpl`（`__dialect__ = "dm"`，DDL 沿用通用实现） |
| 隐式事务 | `SET SCHEMA` 会打开隐式事务；若不结束，Alembic 视为外部事务而**不再提交** → 版本行为空（表已建）（**实测**） | `apply_session_schema` 切换后显式结束隐式事务（提交） |
| 「表不存在」异常类 | 报 `DatabaseError`（与 PostgreSQL / MySQL 的 `ProgrammingError`、SQLite 的 `OperationalError` 不同）（**实测**） | 「是否已迁移」判断须同时捕获三类异常 |
| 幂等建表 | 支持 `CREATE TABLE IF NOT EXISTS` | 与其余库形态一致 |

- 迁移、建删库与批量迁移命令口径见《[数据库开发规范](../../../规范/数据库开发规范.md)》「迁移与建表口径」节；模式口径细节回写见 01_04 实施 / 测试记录。

## 4. 空值与排序 <a id="null"></a>

| 事项 | 达梦 DM8 行为 | 平台口径 |
| --- | --- | --- |
| 默认 NULL 位次 | 待验（Oracle 兼容语义下通常视 NULL 为最大） | **不依赖库默认**：统一「NULL 恒排末位」，由 ORDER BY 内 `列 IS NULL` 排序键实现（四库一致，已实测于 SQLite 真库 + 四方言编译） |
| `NULLS FIRST/LAST` 语法 | 不使用 | 禁止写入 SQL（各库支持度不一） |
| 唯一索引与多 NULL | 按 Oracle 兼容口径允许多个 NULL（**待验**：真库写入验证） | 复合唯一 `(唯一字段, deleted_at)`；真库验证列入三库集成阶段 |
| 空串与 NULL | 达梦可将空串与 NULL 视为等价（Oracle 兼容口径，**待验**：受实例参数影响） | 不用空串表达「无值」；业务空值统一 NULL，字符串非空校验在契约层完成 |

## 5. 标识符与模式 <a id="identifier"></a>

- 未加引号的标识符**默认折叠为大写**存储；查询与运维脚本须注意大小写（平台统一小写书写、由数据库折叠，跨库行为差异仅体现于元数据展示）。
- 模式名（库级隔离单位）实测以大写呈现（如 `BMS_MIGRCHECK`）；迁移脚本不写模式前缀（由会话当前模式决定）。
- 标识符引用用双引号；设计侧不依赖大小写敏感命名（统一 snake_case 小写）。

## 6. 索引与约束 <a id="index"></a>

- 索引与约束名在**模式内**唯一；平台命名含表名（`idx_{表}_{列}`）以对齐其余库口径。
- 每表索引 ≤ 5 个（平台强制）；唯一约束与索引行为随 Oracle 兼容语义（多 NULL 见第 4 节，**待验**）。
- 无物理外键；逻辑外键由应用侧维护（与其余库一致）。
- 索引重命名语法与 MySQL / PostgreSQL 均不同（**待验**：需真库确认后再用于迁移脚本）。

## 7. 事务与连接 <a id="tx"></a>

| 事项 | 达梦 DM8 行为 / 平台做法 | 结论 |
| --- | --- | --- |
| 异步方言 | **无**异步驱动；应用运行期与迁移均走同步引擎（`create_engine`/`dmPython`） | 实测（引擎分支按方言判定） |
| DDL 与事务 | DDL 参与事务；`SET SCHEMA` 的隐式事务须显式结束（见第 3 节） | 实测（版本行提交结论） |
| 隔离级别 | 默认按实例配置（Oracle 兼容语义下多为读已提交） | 待验（不依赖隔离级别差异） |
| 连接池 | `pool_size` / `max_overflow` / `pool_timeout` / `pool_recycle` / `connect_timeout` 取配置 `[database.*.pool]` | 实测（配置项生效） |
| 慢查询日志 | 开启（开发联调） | 实测（已配置） |
| 运行期并发 | 同步驱动在异步应用内经线程池执行（基座统一封装） | 实测（同步助手线程路径） |

- 三库测试库（需库级隔离）与临时演练一律用**模式**：`CREATE SCHEMA` → 迁移 → 校验 → `DROP SCHEMA … CASCADE`（实测全流程通过）。
