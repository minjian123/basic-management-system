## 1. 模块概述与归属 <a id="overview"></a>

操作日志承载**关键操作审计**：谁在何时对什么做了什么、参数（脱敏）、来源、耗时与结果。数据只追加、物理保留、按写入月份分片，并以哈希链串联防篡改；热表保留 90 天，超期由归档任务先校验链完整再迁出（归 14_01）。字段唯一事实源为表文件，本节点不复制字段清单。

| 项 | 值 |
| --- | --- |
| 对应概要 | [《概要设计 · 操作日志》](../概要设计/11_概要设计_操作日志.md) |
| 对应架构 | [《架构设计 · 审计哈希链》](../架构设计/19_架构设计_子系统_审计哈希链.md) §3 / §4 / §5 / §6 |
| 归属部署单元 / 库 | `platform` 服务 · **平台服务库** `bms_platform`（审计属平台治理数据，集中存放；带 `tenant_id`，不按租户分库） |
| 迁移 | 逻辑表不进迁移链（`planned`）；物理分片由运行期 `ensure_shard` 幂等建表 |

## 3. 关键设计要点 <a id="key"></a>

- **分片键 = 写入时刻**：消费者按事件写入时刻所在月路由分片，事件时间另存 `occurred_at`；避免「延迟事件插入旧月」在旧月链尾追加而破坏次月首条已建立的 `prev_hash`。
- **链在 `(log_type, tenant_id)` 内成链**：`record_hash = SHA256(prev_hash + 规范化记录)`；`prev_hash` 取同租户更早分片末条，无则 `GENESIS_HASH`；同分片内按雪花 `id` 升序（有序消费组单写者保证）。
- **只追加**：无更新 / 删除入口；`event_id` 唯一索引兜底消费幂等。
- **脱敏**：`params` / `query_params` 在捕获侧按 `[log]` 敏感名单脱敏后落库，密码 / token / 密钥不落原始值。
- **查询路由**：按时间范围取台账分片集合（前后各扩一月覆盖跨月延迟）后 `UNION ALL`；详情按雪花 ID 反解月份定位单一分片。
- **归档**：90 天热表；归档前强制链校验，两段式归档（归档库 → 对象存储）归 14_01；台账提供待归档清单。
- **不建物理外键**：`tenant_id` / `user_id` 为逻辑外键。
