## 1. 模块概述与归属 <a id="overview"></a>

审计合规承载**字段级变更审计**：关键表被新增 / 修改 / 软删时，逐字段记录旧值、新值、操作人与业务域归属，数据只追加、物理保留、按写入月份分片，并以哈希链串联防篡改。热表保留 90 天，超期由归档任务先校验链完整再迁出（归 14_01）。字段唯一事实源为表文件，本节点不复制字段清单。

| 项 | 值 |

| 对应概要 | [《概要设计 · 审计合规》](../概要设计/28_概要设计_审计合规.md) |
| 对应架构 | [《架构设计 · 审计哈希链》](../架构设计/19_架构设计_子系统_审计哈希链.md) §2 / §3 / §4 / §5 / §6 |

## 3. 关键设计要点 <a id="key"></a>

- **一行一字段**：一次更新改 N 个字段即 N 条记录，`field` / `old_value` / `new_value` 单值列；链逐行成链，篡改定位可精确到字段。
- **分片键 = 写入时刻**（消费时刻），事件时间另存 `occurred_at`，与操作 / 登录日志同口径——延迟事件不会插进旧月破坏跨月链。
- **链在 `(log_type=data_audit, tenant_id)` 内成链**：`record_hash = SHA256(prev_hash + 规范化记录)`；`prev_hash` 取同租户更早分片末条，无则 `GENESIS_HASH`。
- **只追加**：无更新 / 删除入口；`event_id` 唯一索引兜底消费幂等；不做软删除。
- **域归属**：`domain_key` 由表归属派生（`domain_of_table`），产品表未登记域时落 `unknown`，不阻断写入。
- **脱敏与截断**：敏感列（密码 / token / 密钥 / 证件 / 银行卡等）旧新值一律落 `***`；单值超上限截断并标注。
- **直连 SQL 盲区**：捕获由 ORM 会话事件完成，**不经 ORM 的直连 SQL 写入不产生审计**——口径显式声明，不假装覆盖。
- **归档**：90 天热表；归档前强制链校验，两段式归档（归档库 → 对象存储）归 14_01；台账提供待归档清单。
