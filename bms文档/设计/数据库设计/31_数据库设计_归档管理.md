## 1. 模块概述与归属 <a id="overview"></a>

归档管理承载数据的两段式生命周期流转：热表数据达阈值迁入归档库（可在线只读查询），满保留期冷化为对象存储文件，并提供过期清理、合规销毁与执行留痕。策略**全表可配**（表名 / 时间字段 / 阈值 / 保留期 / 目标 / 批次 / 启停），由任务调度经作业中心执行。字段唯一事实源为表文件，本节点不复制字段清单。

## 3. 关键设计要点 <a id="key"></a>

- **通用行表而非镜像表**：归档库以 `sys_archive_record.payload` 存源行完整 JSON，`tenant_id` / `source_table` / `source_id` / `archived_at` 提供检索维度；零动态 DDL、跨四库无类型映射风险。查询口径为租户 + 源表 + 时间 + 源主键（与页面筛选一致）。
- **两段式流转**：`target=archive_db` 先热表 → 归档库（在线只读查），满 `retention_days` 再冷化为 NDJSON.gz；`target=minio` 跳过归档库直接冷化。
- **审计分片整月归档**：按台账 `sys_audit_shard` 取 `active` 且整月早于阈值的分片；归档前强制链校验；迁移完成后写 `sys_archive_chain_tail`（按租户存链头 / 链尾 / 条数），随后删除物理分片表并把台账置 `archived`。
- **跨归档链校验**：校验器对已归档月份改读 `sys_archive_chain_tail` 的链尾，不再回扫已删除的物理表；已归档月份用冷化文件 + 清单独立校验。
- **幂等**：`sys_archive_record` 唯一 `(source_table, source_id)` 保证重复执行不重复归档；`sys_archive_log.batch_key` 唯一；同一策略执行期间由分布式锁 + `running` 记录互斥。
- **只读查询**：只查归档库，不合并在线库；普通用户强制本租户，审计管理员（`log:query`）可跨租户。已冷化数据经执行记录的 `file_key` 预签名下载取回。
- **清理与销毁**：过期冷化文件按 `retention_until` 清理；合规销毁按归档批次或单条归档行执行，二次确认 + 执行记录留痕；软删除残留物理清理归 13_01，不在此重复实现。
