## 1. 集合体系护栏与基线

**裸无序集合护栏与基线（08-1 交付；白名单收紧 + 豁免取消随 08_02）**：**类字段注解**、**函数签名注解**（参数 / 返回）与**函数体带注解局部变量**中的**集合声明必须命中集合类白名单**——白名单**只含插入序形态**（`ConcurrentStableList` / `ConcurrentStableSet` / `ConcurrentStableDict` 及后续登记形态）；以下一律判违规——裸 `dict` / `list` / `set` / `frozenset` 及 typing 别名（`Dict` / `List` / `Set` / `FrozenSet` / `DefaultDict`）、只读 / 可变抽象（`Sequence` / `Mapping` / `AbstractSet` / `Collection` / `MutableSequence` / `MutableMapping` / `MutableSet`）、**升序形态**（`ConcurrentSorted*` / `Sorted*`）；**不查**迭代与调用协议（`Iterable` / `Iterator` / `Generator` / `AsyncIterator` / `Callable`，非集合声明）；**不属约束对象**：集合体系**实现文件**（`core/collections.py` / `core/concurrent.py` / `core/sorted_collections.py` / `core/redis_collections.py`）——护栏只约束**业务侧集合声明**（对外数据契约 / 值对象 / 模块类），实现文件是体系自身、其内置容器为内部底座与序列化出口（不再称「豁免」）。`ClassVar` 类级常量、`BaseSettings` 配置字段、测试目录与函数体局部变量**不再豁免**（一律纳入扫描）。**框架边界豁免**：**框架自有容器**（Starlette / FastAPI 的 ASGI `scope` / `scope["state"]`、查询入参绑定、路由构造参数与端点返回注解等，以及 pydantic-settings 配置源 `__call__` 契约等，框架强制为内置类型）在**声明行行尾或紧邻上一行**标注 `# bare-collections:allow`（附理由）后跳过；`--self-test` 矩阵含该断言。白名单收紧后既有命中按「新增」处理——先 `--update-baseline` 如实纳入 `bare_collections_baseline.json`，再按批次递减。**`scripts/tools` 口径（拍板）**：`scripts/tools` **统一纳入长期强制扫描、不设内部工具豁免**——不依赖 `bms_core` 的独立工具脚本以 `sys.path` 引导（`backend/libs/bms_core/src`）引入基座集合类，`bms_core.core.concurrent` 依赖链为无依赖面（仅标准库），存量随批次递减至归零。

## 4. 脱敏规则清单

> **脱敏规则清单（04_01）**：`DefaultMasker` 内置策略的掩码口径（字段 → 策略经 `register` 或 `[masking].options.rules` 注册；未注册字段不掩码）。

| 策略 | 保留规则 | 固定星数 | 示例 |
| --- | --- | --- | --- |
| `phone` | 前 3 + 后 4 | 4 | `13812345678` → `138****5678` |
| `id_card` | 前 6 + 后 4 | 8 | `110101199001011234` → `110101********1234` |
| `bank_card` | 前 4 + 后 4 | 8 | `6222021234567890` → `6222********7890` |
| `name` | 前 1 | 1 | `张三` → `张*` |
| `address` | 前 6 | 3 | `北京市朝阳区某某路1号` → `北京市朝阳区***` |
| `email` | 首字符 + 域名 | 3 | `zhangsan@example.com` → `z***@example.com` |
| `custom` | 不保留（全掩码） | 3 | `EMP-0001` → `***` |

星数按策略固定（不随被掩码字符数变化，不泄露真实长度）；长度不足时退化为「保留可用前段 + 掩码」（不原样回显、不抛错）；策略解析顺序＝已注册自定义策略 → 内置策略 → 兜底 `custom` 全掩码；字段级注册（`register`）决定字段用哪个策略。
