## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端的**通用格式化与横切能力**的组件设计：日期时间、数值、金额、百分比、文件大小、时长、相对时间的格式化，以及标签页状态、表单校验规则、稳定序列化、用户时区/语言偏好读取等横切能力。适用于全部页面组件与字段类组件（尤其 [日期时间字段](../../06_字段类/02_组件设计_日期时间字段/02_组件设计_日期时间字段.md)、[数值与金额字段](../../06_字段类/03_组件设计_数值与金额字段/03_组件设计_数值与金额字段.md)）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；架构依据[《架构设计 · 国际化》](../../../架构设计/24_架构设计_子系统_国际化.md)（时区、按 locale 本地化、语言包运行时拉取）与[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)（性能、列表页个性化）；页面形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「系统信息」时间格式（`yyyy-MM-dd HH:mm`，按租户时区）与[《布局设计 · 主框架》](../../../布局设计/04_布局设计_主框架.html)标签栏；编码约定依据[《前端开发规范》](../../../../规范/前端开发规范.md)「布局框架」「基础类与继承约定」节。

> 本篇为「格式化工具」节点。格式化职责的边界是「输入 → 输出」的纯函数（无副作用、可单测）；带界面行为的部分以继承链上的能力域基类承载（能力即链上的一层），不链外自由挂接。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 日期时间格式化 | 日期时间格式化，按用户时区 + locale；含日期、日期范围、相对时间 |
| 数值与金额格式化 | 数值千分位、金额（精度/币种）、百分比 |
| 其他格式化 | 文件大小、时长、相对时间 |
| 脱敏 | 通用脱敏（手机号/邮箱/身份证等规则），供展示与明文权限协作 |
| 时区能力 | 读取用户时区偏好（`sys_user.timezone`），提供转换与格式化基准 |
| 语言能力 | 当前 locale 读取与切换（与语言包联动） |
| 标签页能力 | 标签页状态（打开/关闭/切换，契约见 7.1） |
| 表单校验规则 | 表单校验规则集（必填、长度、邮箱、手机号、金额、区间等） |
| 稳定序列化 | 对象键排序后的稳定序列化（幂等键/签名/深比较用） |

- 移动端为同一契约的另一实现（各自实现、口径同源），复用格式化**逻辑口径**（同一时区/locale 规则）（见第 10 节）。

## 3. 时区与 locale 基准 <a id="basis"></a>

| 项 | 设计 |
| --- | --- |
| 存储 | 时间统一 UTC 存储（后端），前端只负责按用户时区展示 |
| 时区来源 | `sys_user.timezone`（用户偏好，个人中心可改）；缺省取浏览器时区 |
| locale 来源 | 用户语言偏好（`sys_user.locale` 与本地副本），与全局语言能力一致 |
| 格式化引擎 | 一律走标准本地化格式化能力（按 locale/时区），不手工拼字符串 |
| 基准一致性 | 同一时刻在同一用户时区下，列表页、表单页、导出预览、系统信息区展示必须一致 |

- 系统信息区时间格式统一 `yyyy-MM-dd HH:mm`（[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html) 2.1.1 节），按租户时区格式化，不加时区后缀。
- 时区与 locale 变化时，需触发页面重新格式化（依赖该基准的展示响应式更新）。

## 4. 日期时间格式化 <a id="datetime"></a>

| 场景 | 输出示例（zh-CN / Asia/Shanghai） |
| --- | --- |
| 列表/表单默认 | `2026-09-11 14:30` |
| 含秒（日志类） | `2026-09-11 14:30:05` |
| 日期范围（日期字段） | `2026-09-01 ~ 2026-09-11` |
| 相对时间（通知） | `3 分钟前` / `昨天 14:30`（1 分钟内 → 刚刚） |
| 空值 | 返回占位 `—`（不显示 `Invalid Date`） |

- 空值/非法值统一返回占位符，由调用方或组件传入占位文案。
- 日期**字段组件**（[日期时间字段](../../06_字段类/02_组件设计_日期时间字段/02_组件设计_日期时间字段.md)）负责选择与取值（ISO/UTC 字符串），本节点只负责展示格式化。

## 5. 数值与金额格式化 <a id="number"></a>

| 规则 | 说明 |
| --- | --- |
| 千分位 | 默认开启，按 locale 决定分隔符 |
| 金额精度 | 默认 2 位；后端以字符串/定点传输，前端仅格式化展示，**不做浮点累加运算** |
| 币种 | 默认展示数字 + 币种符号（如 `¥`）；多币种时由字段配置指定 |
| 百分比 | 支持「已乘 100」与「比值（×100）」两种输入口径，显式区分 |
| 空值 | 统一占位 `—` |
| 负数/零 | 负数保留符号（可配红色语义，在组件层处理） |

> 金额的**输入与校验**在 [数值与金额字段](../../06_字段类/03_组件设计_数值与金额字段/03_组件设计_数值与金额字段.md)节点定义（精度、上下限、单位）；本节点只提供展示格式化。

## 6. 其他格式化 <a id="others"></a>

| 工具 | 说明 |
| --- | --- |
| 文件大小格式化 | `1024` → `1 KB`、`1048576` → `1 MB`（1024 进制，2 位精度） |
| 时长格式化 | `3661` → `1 小时 1 分 1 秒` |
| 脱敏 | 手机号 `138****5678`、邮箱 `z***@x.com`、身份证保留首尾；供展示与明文权限协作（见 [权限指令](../02_组件设计_权限指令/02_组件设计_权限指令.md)） |

## 7. 横切组合式能力 <a id="composables"></a>

### 7.1 标签页状态 <a id="use-tabs"></a>

| 成员 | 说明 |
| --- | --- |
| 标签列表 | 当前打开的 Tab 列表（与 URL 一一对应，[《布局设计 · 主框架》](../../../布局设计/04_布局设计_主框架.html)） |
| 当前标签 | 当前激活 Tab |
| 打开 / 关闭 / 关闭其他 | 打开、关闭、关闭其他（固定工作台首页 Tab 不可关闭） |
| 刷新 | 刷新指定 Tab（缓存清除） |
| 持久化 | 本地存储键 `bms_open_tabs`（模块级单例，非全局状态） |

- 表单 Tab 关闭前若存在未保存修改（`dirty`）→ 二次确认拦截。
- 状态保持：Tab 切换保留组件状态（缓存）。

### 7.2 表单校验规则 <a id="validators"></a>

| 校验器 | 说明 |
| --- | --- |
| 必填 | 必填校验（可配提示文案） |
| 长度区间 | 长度区间（最小值 / 最大值） |
| 格式校验 | 邮箱 / 手机号 / URL（与后端同规则） |
| 金额 | 金额精度与范围（最小值 / 最大值 / 精度） |
| 数值区间 | 数值区间（最小值 / 最大值） |
| 编码规则 | 编码规则（如 `sys_config` 的点分小写、岗位编码规则） |

- 校验规则与表单组件兼容；前后端规则需一致，后端仍强校验（见 [请求封装](../01_组件设计_请求封装/01_组件设计_请求封装.md)）。

### 7.3 稳定序列化 <a id="stable-stringify"></a>

- 对象键排序后序列化，保证同一逻辑对象得到同一字符串；用于幂等键、请求签名、深比较、查询条件变更检测。
- 与普通序列化的区别：键顺序无关、可选忽略未定义值。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大列表格式化 | 格式化函数为纯函数、轻量（本地化格式化器按 locale 缓存复用），千行列表格式化无压力 |
| 格式化器复用 | 按 locale / 时区 / 格式缓存复用，避免重复构造 |
| 边界值 | 空值/非法值返回占位；极大/极小数值不抛异常 |
| 时区切换 | 用户改时区后需重新格式化（依赖时区基准的展示响应式更新） |
| 单测 | 纯函数全部纳入单元测试（含时区/夏令时边界，[《架构设计 · 测试与质量》](../../../架构设计/32_架构设计_测试与质量.md)） |

## 10. 移动端说明 <a id="mobile"></a>

- 移动端独立实现格式化（体积与依赖考虑），但**格式化口径与 PC 一致**（同一时区、同一小数规则），避免同数据两端展示不一致。
- 标签页能力 PC 与移动端各自实现、契约同源（移动端以页面栈导航为主）。
- 移动端表单校验复用同一规则口径（移动端组件库校验器）。

## 11. 检查清单 <a id="checklist"></a>

- □ 日期时间格式化按用户时区 + locale，走标准本地化格式化，空值占位；系统信息区格式 `yyyy-MM-dd HH:mm`
- □ 数值/金额千分位、精度、币种、百分比（两种输入口径区分）正确；金额不做浮点运算
- □ 文件大小/时长/相对时间/脱敏齐备，脱敏与明文权限口径一致
- □ 标签页能力单例、未保存拦截、状态保持（本地存储 `bms_open_tabs`）
- □ 表单校验规则与后端同规则；稳定序列化用于幂等/签名/深比较
- □ 本地化格式化器按组合键缓存复用；时区/locale 变化触发响应式重格式化
- □ 纯函数纳入单元测试（含时区与夏令时边界）
- □ 移动端格式化口径与 PC 一致（第 10 节）
