## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **日期时间类字段**的通用组件设计：日期选择（DateField）、日期时间选择、时间选择（TimeField）、日期范围（DateRangeField），以及值模型与时区转换工具 `useDateValue`。适用于管理端全部业务表单、查询筛选区与列表列渲染（如创建时间、生效日期、统计区间、业务单据日期）。

本节对应[《项目规划说明》](../../../规划/项目规划说明.md)前端与国际化章节；上游设计依据[《布局设计 · 表单页》](../../布局设计/08_布局设计_表单页.html)（系统信息区时间格式 `yyyy-MM-dd HH:mm`、按租户时区、只读/编辑分态）与[《布局设计 · 列表页》](../../布局设计/07_布局设计_列表页.html)（查询区日期用日期范围）；时区与 locale 依据[《架构设计 · 国际化》](../../架构设计/20_架构设计_子系统_国际化.md)；格式化口径依据[《组件设计 · 格式化工具》](../21_组件设计_格式化工具/21_组件设计_格式化工具.md)。

> 本篇为组件设计体系字段类第 03 篇；上游概要节点按具体使用模块（用户管理、操作日志、会话管理等）引用，本节点只定义通用字段契约。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `DateField.vue` | `src/components/field/` | 日期选择（`el-date-picker` type=date）：单日期、只读回显 |
| `DateTimeField.vue` | `src/components/field/` | 日期时间选择（type=datetime）：精确到分/秒 |
| `TimeField.vue` | `src/components/field/` | 时间选择（`el-time-picker`）：仅时分（可选秒） |
| `DateRangeField.vue` | `src/components/field/` | 日期范围（type=daterange）：查询区与业务区间 |
| `useDateValue()` | `src/utils/useDateValue.ts` | 值模型工具：UTC ↔ 用户时区显示、字符串归一、空值处理 |

- 字段类组件统一**受控**：`modelValue` / `update:modelValue` 双向绑定，变更额外抛 `change`（[《组件设计 · 总览》](../01_组件设计_总览.md)通用设计约定）。
- 命名遵循[《命名规范》](../../../规范/命名规范.md)（组件 PascalCase 单数名词、组合式函数 `use` + 名词）。
- 移动端（frontend-mobile）不套用 PC 组件（第 11 节）。

## 3. 值模型与时区 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 存储 | 后端统一 UTC 存储；`modelValue` 为 ISO 8601 UTC 字符串（如 `2026-09-11T06:30:00Z`）或 `null` |
| 展示 | 按用户时区（`sys_user.timezone`）与 locale 展示，走 `formatDateTime`（见 21 节点） |
| 转换 | `useDateValue().toDisplay(utc)` / `.toUtc(display)` 负责双向转换；组件内部统一在此层完成，业务不感知时区 |
| 空值 | `null` 表示未填；回显占位 `—`（可配 `placeholder`） |
| 精度 | 日期（`YYYY-MM-DD`）、日期时间（分钟）、日期时间（秒）；由字段元数据 `widget` 决定精度 |
| 查询参数 | 查询区提交时按后端约定传输（日期范围传 `start`/`end`，均为 UTC 或业务日边界） |

> 时区转换只在**边界**发生：组件接收 UTC、展示按用户时区；提交时把本地选择换算为 UTC。日期（不含时间）字段的边界以用户时区当天 00:00:00 ~ 23:59:59 计算。

## 4. DateField / DateTimeField Props 与事件 <a id="date-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | — | ISO UTC 字符串，或日期字符串（date 型） |
| `type` | 'date' \| 'datetime' \| 'datetime-seconds' | date | 精度；对应 `el-date-picker` 的 type/format |
| `disabled` | boolean | false | 只读/无权限时置 true（字段权限 editable=false 由表单页传入） |
| `clearable` | boolean | true | 可清空 |
| `placeholder` | string | 请选择 | 占位文案（走 i18n） |
| `shortcuts` | Shortcut[] | [] | 快捷键（今天/昨天/最近 7 天/本月等，仅 date/range 生效） |
| `valueFormat` | string | 'YYYY-MM-DDTHH:mm:ss[Z]' | 回传值与后端对齐（UTC） |
| `min` / `max` | string \| null | null | 可选范围限制（如生效日期不得早于今天） |
| `defaultTime` | string | — | datetime 型默认时分（选择日期后补齐） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | ISO UTC \| null | v-model 绑定 |
| `change` | ISO UTC \| null | 变化通知（联动其他字段/查询） |
| `blur` / `focus` | — | 透传（触发校验时机） |

```html
<DateField v-model="form.effectiveDate" type="datetime" :shortcuts="shortcuts"
           :min="todayUtc" :disabled="readonly" placeholder="请选择生效时间" />
```

## 5. DateRangeField 与快捷键 <a id="range"></a>

| 项 | 设计 |
| --- | --- |
| Props | 同 DateField，`modelValue` 为 `[start, end] \| null`，`rangeSeparator` 默认 `~` |
| 查询区用法 | [《布局设计 · 列表页》](../../布局设计/07_布局设计_列表页.html)：日期类查询条件用日期范围；提交参数与列表接口一致（如 `created_start`/`created_end`） |
| 快捷键 | `今天`、`昨天`、`最近 7 天`、`最近 30 天`、`本月`、`上月`（文案走 i18n，值按用户时区边界计算） |
| 区间校验 | 起 ≤ 止；单边为空表示不限；业务区间（如统计区间）在表单页做必填与跨度校验 |
| 展示 | 只读回显为 `start ~ end`（`formatDateRange`） |

## 6. TimeField <a id="time"></a>

- 基于 `el-time-picker`，`modelValue` 为时间字符串（`HH:mm` 或 `HH:mm:ss`）；用于「每日提醒时间」「班次时间」等纯时间场景。
- 不涉及时区换算（纯时刻），但仍按 locale 展示 12/24 小时制（默认 24 小时制，与[《布局设计 · 表单页》](../../布局设计/08_布局设计_表单页.html)系统信息一致）。
- 支持 `min`/`max` 限制与固定步长（`step`）。

## 7. 只读回显与列表列渲染 <a id="readonly"></a>

- 表单只读态：组件置 `disabled`，显示 `formatDateTime(value)`（系统信息区固定 `yyyy-MM-dd HH:mm`，不加时区后缀）。
- 列表列渲染：`el-table-column` 用 formatter 调 `formatDateTime`，与表单回显口径一致（见 21 节点）。
- 空值统一 `—`；时间列排序按 UTC 值排序（不按展示文本排序）。

## 8. 查询区筛选协作 <a id="filter"></a>

- 查询区由展示类「查询筛选区」（11）承载；日期字段以 `DateRangeField` 呈现（[《布局设计 · 列表页》](../../布局设计/07_布局设计_列表页.html)：状态/字典类用下拉、日期用日期范围、部门用树选择）。
- 查询条件变化回第 1 页；分页/排序变化保留筛选条件（`useListPage`，见 19 请求封装）。
- 提交前把展示值换算为后端约定参数（UTC 起止），避免时区错位。

## 10. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大列表时间列 | 纯格式化函数、`Intl` 实例缓存；千行渲染无压力（见 21 节点） |
| 时区切换 | 依赖 `useTimezone()` 响应式重格式化 |
| 边界值 | 跨时区零点、DST 切换按 `Intl`/时区库口径处理，纳入单测 |
| 非法输入 | 手输模式下非法值不提交，回退上次有效值并提示 |
| 空值 | 统一 `null`，展示 `—` |

## 11. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 由表单页不渲染；`editable=false` 传 `disabled`，组件不感知权限（见 20 权限指令）。
- **i18n**：占位、快捷键、快捷文案走 vue-i18n；日期展示按 locale（`Intl`），不硬编码格式串用于展示。
- **移动端**：frontend-mobile 用 Vant 日期选择器（`van-date-picker`/`van-calendar`），值模型与时区口径同源（UTC 存储、用户时区展示），不复用 PC 组件。

## 12. 检查清单 <a id="checklist"></a>

- □ 受控组件 `modelValue` / `update:modelValue` + `change`；`disabled` 回显
- □ 值模型 ISO UTC 字符串；展示按用户时区 + locale；提交换算回 UTC
- □ 日期/日期时间/时间/日期范围四种形态齐备；精度由字段元数据决定
- □ 快捷键（今天/最近 7 天/本月等）按用户时区边界计算，文案走 i18n
- □ 查询区用日期范围，提交 `*_start`/`*_end`，变化回第 1 页、保留筛选
- □ 只读回显与列表列渲染统一 `formatDateTime`，系统信息区 `yyyy-MM-dd HH:mm`
- □ 空值 `—`；时间列按 UTC 排序；跨时区/DST 边界纳入单测
- □ 字段权限（visible/editable）与移动端口径符合第 11 节
