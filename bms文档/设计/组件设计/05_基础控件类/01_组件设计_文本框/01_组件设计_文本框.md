## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 PC 渲染插件 `frontend/packages/ui-ep`（目标落点 `frontend/packages/ui-ep/src/components/input/`；移动端按需 `frontend/packages/ui-vant/src/components/input/`；宿主 `frontend/apps/*` 消费）**文本框** `TextField` 的组件设计：单行文本输入的**基础控件**，用于姓名、编码、标题、账号、关键字等短文本。它按输入域口径组合核心能力 `field`（字段编排，含 `value` 受控值 / `field-shell` 字段壳 / `field-perm` 字段权限）+ `input-control`（输入形态）→ 组件根 `BaseComponent` → 根系 `BaseFrontend`（能力类登记 `capabilities/manifest.ts`，投影取 `useField` / `useValue`），即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「文本框」**。基础控件只提供"无数据源、无特殊格式"的输入原语；带数据源/特殊交互/特殊格式的字段归 字段类（如字典下拉、日期、数值金额、上传、富文本）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | `null` | 受控值 |
| `maxlength` | number | — | 最大长度（显示计数） |
| `minlength` | number | — | 最小长度（校验） |
| `showWordLimit` | boolean | false | 显示字数统计 |
| `pattern` | string | — | 正则（提交前校验，后端一致） |
| `trim` | boolean | true | 提交前去首尾空格 |
| `mask` | boolean | false | 脱敏展示（如手机号，配合 `v-plain` 看明文） |

（其余 `placeholder`/`readonly`/`disabled`/`clearable`/插槽等继承 输入形态能力 `input-control` / 组件根 `BaseComponent` / 输入域口径。）

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `change` | 继承链提供（归一后值） |
| `validate` | 长度/正则校验结果 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 长度 | `maxlength` 前端截断 + 计数；`minlength` 校验 |
| 正则 | `pattern` 提交前校验（后端强制）；错误定位到字段 |
| 归一 | `trim=true` 提交前去空格；空串 → `null`（受控值能力 `value`） |
| 只读/三态 | 只读回显由字段壳能力 `field-shell` 决定纯文本或 disabled；三态未设置/空/已填 |
| 脱敏 | 敏感文本默认掩码，持 `data:plain` 查看明文（[字段权限能力](../../02_基础组件类/02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)） |
| 权限 | `visible`/`editable` 由字段编排能力 `field` 判定（不渲染/disabled） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力（[字段权限能力](../../02_基础组件类/02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)）判定可见/可编辑；脱敏按标记。
- **i18n**：标签/占位由元数据下发；错误文案走 i18n。
- **移动端**：键盘类型与输入法适配（text）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控、composition 分离；`change` 可去抖（搜索型） |
| 边界 | 超长截断与计数、前后空格、正则与后端不一致、脱敏复制、只读与三态 |
| 不支持 | 长文本（文本域）、数值（数字框）、下拉/单选/复选、富文本（字段类） |
