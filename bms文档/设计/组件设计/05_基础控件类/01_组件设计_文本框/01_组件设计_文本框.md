## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**文本框**的组件设计：单行文本输入的**基础控件**，用于姓名、编码、标题、账号、关键字等短文本。它继承[输入域基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（受控值、字段壳、字段权限、校验触发），经[组件根基类](../../02_基础组件类/01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)与[根系基类](../../02_基础组件类/01_机制基类/01_组件设计_根系基类/01_组件设计_根系基类.md)取得通用能力，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「文本框」**。基础控件只提供"无数据源、无特殊格式"的输入原语；带数据源/特殊交互/特殊格式的字段归**字段类**（如字典下拉、日期、数值金额、上传、富文本）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 文本框件 | 单行文本框：受控、长度/正则约束、前后缀与清空、只读与三态、脱敏展示、校验绑定 |
| 继承链 | 文本框 → 输入域（域基类层：受控值/字段壳/字段权限）→ 组件根 → 根系；行为在链上层维护，不在组件内重复实现 |

- 命名与落点遵循[《命名规范》](../../../../规范/命名规范.md)与[《前端开发规范》](../../../../规范/前端开发规范.md)；实现侧命名与落点见《[前端基类清单](../../../../前端基类清单.md)》。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入域基类（受控绑定、值归一、禁用合并、三态） |
| 最大/最小长度 | 最大长度输入截断并显示计数；最小长度用于校验 |
| 字数统计 | 可显示字数统计 |
| 正则校验 | 提交前按正则校验（与后端一致）；错误定位到字段 |
| 去首尾空格 | 可配置提交前去除首尾空格 |
| 脱敏展示 | 敏感文本默认掩码（如手机号）；持对应动作权限时可查看明文 |
| 其余契约 | 占位、只读、禁用、可清空、插槽等继承输入域基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入域基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 长度 | 最大长度前端截断 + 计数；最小长度校验 |
| 正则 | 提交前校验（后端强制）；错误定位到字段 |
| 归一 | 可配置去首尾空格；空串归一到统一空值（受控值语义） |
| 只读/三态 | 只读回显由[字段壳能力](../../02_基础组件类/02_能力类/10_组件设计_字段壳能力/10_组件设计_字段壳能力.md)决定纯文本或禁用控件；三态（未设置/空/已填）继承输入域语义 |
| 脱敏 | 敏感文本默认掩码，持动作权限可查看明文（[字段权限能力](../../02_基础组件类/02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)） |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力（[字段权限能力](../../02_基础组件类/02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)）判定可见/可编辑；脱敏按字段属性。
- **i18n**：标签/占位由元数据下发；错误文案走全局语言能力。
- **移动端**：键盘类型与输入法适配（文本输入），与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控输入与输入法组合事件分离；业务变更可去抖（搜索型） |
| 边界 | 超长截断与计数、前后空格、正则与后端不一致、脱敏复制、只读与三态 |
| 不支持 | 长文本（文本域）、数值（数字框）、下拉/单选/复选、富文本（字段类） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 根系），行为不在组件内重复实现
- □ 契约语义：长度/正则/计数/去首尾空格/脱敏；受控与三态
- □ 权限（可见/可编辑/脱敏）、i18n、移动端符合第 7 节
- □ 与文本域/数字框/下拉等基础控件边界清晰
- □ 三项上游登记已确认
