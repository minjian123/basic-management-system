## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**文本框** `TextField` 的组件设计：单行文本输入的**基础控件**，用于姓名、编码、标题、账号、关键字等短文本。它继承 **02 基础组件类** 的 L4-01 输入域基类（`BaseInput`）→ L3 字段基类/受控值基类 → L2-02 输入组件基类 → L1b 最基础组件基类 → L0 总基类，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **03 基础控件类第 01 篇**。基础控件只提供"无数据源、无特殊格式"的输入原语；带数据源/特殊交互/特殊格式的字段归 04 字段类（如字典下拉、日期、数值金额、上传、富文本）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基础类体系」节。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `TextField.vue` | `src/components/base-control/` | 单行文本框：受控、长度/正则约束、前后缀与清空、只读与三态、脱敏展示、校验绑定 |

- 继承链：`TextField → BaseInput(L4-01) → BaseField(L3-02) → BaseValue(L3-01) → BaseInputControl(L2-02) → BaseComponent(L1b) → BaseFrontend(L0)`。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | `null` | 受控值 |
| `maxlength` | number | — | 最大长度（显示计数） |
| `minlength` | number | — | 最小长度（校验） |
| `showWordLimit` | boolean | false | 显示字数统计 |
| `pattern` | string | — | 正则（提交前校验，后端一致） |
| `trim` | boolean | true | 提交前去首尾空格 |
| `mask` | boolean | false | 脱敏展示（如手机号，配合 `v-plain` 看明文） |

（其余 `placeholder`/`readonly`/`disabled`/`clearable`/插槽等继承 L2-02/L1b/L4-01。）

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `change` | 继承链提供（归一后值） |
| `validate` | 长度/正则校验结果 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 长度 | `maxlength` 前端截断 + 计数；`minlength` 校验 |
| 正则 | `pattern` 提交前校验（后端强制）；错误定位到字段 |
| 归一 | `trim=true` 提交前去空格；空串 → `null`（L3-01） |
| 只读/三态 | 只读回显由字段壳决定纯文本或 disabled；三态未设置/空/已填 |
| 脱敏 | 敏感文本默认掩码，持 `data:plain` 查看明文（[L3-04](../../02_基础组件类/L3_受控值与字段基类/04_组件设计_字段权限基类/04_组件设计_字段权限基类.md)） |
| 权限 | `visible`/`editable` 由字段基类判定（不渲染/disabled） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限（[L3-04](../../02_基础组件类/L3_受控值与字段基类/04_组件设计_字段权限基类/04_组件设计_字段权限基类.md)）判定可见/可编辑；脱敏按标记。
- **i18n**：标签/占位由元数据下发；错误文案走 i18n。
- **移动端**：键盘类型与输入法适配（text）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控、composition 分离；`change` 可去抖（搜索型） |
| 边界 | 超长截断与计数、前后空格、正则与后端不一致、脱敏复制、只读与三态 |
| 不支持 | 长文本（文本域）、数值（数字框）、下拉/单选/复选、富文本（04 字段类） |
