## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**开关**的组件设计：布尔值开关的**基础控件**，用于启用/停用、是否类字段。它继承[输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（输入组件基类）（受控值、字段壳、字段权限、校验触发），沿继承链（值能力基类 → 组件根 → 总基类）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「开关」**。范围边界：**布尔开关字段（含列表内联切换、失败回滚、三态语义）** 归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其字段实现继承本控件）；本篇只做开关原语。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 开关件 | 布尔开关：值/文案、三态、加载态、危险切换确认 |
| 继承链 | 开关 → 输入组件基类 → 字段能力基类 → 值能力基类 → 组件根 → 总基类（唯一权威见《前端基类清单》§2，全系统唯一一份）；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入组件基类（受控绑定、值归一、禁用合并、三态）；支持未设置/关/开三态 |
| 开关文案 | 可配开启/关闭文案，走 i18n |
| 加载态 | 切换中显示加载并禁止重复操作 |
| 危险切换确认 | 可配危险切换二次确认文案（如停用关键配置） |
| 其余契约 | 只读、禁用、尺寸等继承输入组件基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入组件基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 值域 | 前端只暴露布尔/未设置；后端 1/0 存储由边界归一（受控值语义） |
| 三态 | 三态开启时「未设置」与「关」区分显示 |
| 加载 | 切换中显示加载并禁止重复；失败回滚（内联场景由字段类「开关与枚举字段」处理） |
| 危险切换 | 危险确认开启时二次确认（如停用关键配置） |
| 文案 | 开启/关闭文案走 i18n |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单字段 | 启用/停用、是否类 |
| 列表行内 | 状态快速切换（字段类「开关与枚举字段」内联开关） |
| 设置项 | 参数开关 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑。
- **i18n**：开关文案走 i18n。
- **移动端**：触控尺寸，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 切换 | 受控；加载态防重复；失败回滚由字段层（字段类「开关与枚举字段」）负责 |
| 边界 | 未设置与关、文案溢出、加载中连点、危险确认取消 |
| 不支持 | 列表内联切换与回滚（字段类「开关与枚举字段」）、枚举单选/多选（单选/复选） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 总基类），行为不在组件内重复实现
- □ 契约语义：值域/三态/加载态/危险切换确认/开关文案
- □ 值域归一（1/0 与布尔）、三态、加载态、危险确认
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与字段类开关与枚举字段边界清晰
- □ 三项上游登记已确认
