## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**下拉框**的组件设计：**静态选项**下拉选择的**基础控件**。它继承[输入族基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（`BaseInput`）（受控值、字段壳、字段权限、校验触发），沿继承链（`BaseValue → BaseComponent → BaseObject`）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「下拉框」**。范围边界：**字典来源**下拉归 [字段类「字典字段」](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)；**枚举选项集**（自定义选项/多选标签）归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)；本篇只做**静态选项**的选择原语，被上述字段继承。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 下拉框件 | 静态选项下拉：单选/多选、搜索、清空、分组、禁用选项 |
| 继承链 | 下拉框 → `BaseInput` → `BaseField` → `BaseValue` → `BaseComponent` → `BaseObject`（唯一权威见《前端基类清单》§2，全系统唯一一份）（唯一权威见《前端基类清单》§2）；行为在链上基类维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入族基类（受控绑定、值归一、禁用合并、三态） |
| 静态选项 | 选项模型（值/文本/禁用/分组），与字典/枚举同构，便于字段类继承 |
| 多选 | 多选时值为数组；可设数量上限并提示；标签可折叠 |
| 搜索 | 静态选项本地过滤 |
| 可清空 | 一键清空；清空后归一到统一空值 |
| 只读回显 | 只读回显经展示域语义（受控值 + 展示形态）；只读与三态一致 |
| 其余契约 | 占位、只读、禁用、尺寸等继承输入族基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入族基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 选项模型 | 选项集（值/文本/禁用/分组），与字典/枚举同构，便于继承 |
| 多选 | 多选时值为数组；数量上限提示；标签折叠 |
| 搜索 | 本地过滤（静态选项） |
| 归一 | 空值归一到统一空值（单选）/空数组（多选）；去除无效值 |
| 只读/三态 | 只读回显经展示域语义；三态（未设置/空/已填）继承输入域语义 |
| 分组 | 按分组字段分节显示 |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单字段 | 少量静态选项（如性别、优先级） |
| 查询筛选区 | 静态条件选择 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑。
- **i18n**：选项文本按 locale（由使用方下发）。
- **移动端**：底部弹层选择器，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 选项 | 少量静态选项本地过滤；大量选项时应改用字典/远程搜索字段 |
| 边界 | 无效值回显、多选上限、禁用选项、空值与 0 值、异步选项（非本控件） |
| 不支持 | 字典下拉（字段类「字典字段」）、枚举多选标签（字段类「开关与枚举字段」）、树/级联（字段类「树选择字段」/「级联选择」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → `BaseComponent` → `BaseObject`），行为不在组件内重复实现
- □ 契约语义：静态选项/单选与多选/搜索/清空/分组/数量上限/空值三态
- □ 选项模型统一（值/文本/禁用/分组）；空值归一；多选上限
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与字段类字典/枚举字段边界清晰
- □ 三项上游登记已确认
