## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 PC 渲染插件 `frontend/packages/ui-ep`（目标落点 `frontend/packages/ui-ep/src/components/input/`；移动端按需 `frontend/packages/ui-vant/src/components/input/`；宿主 `frontend/apps/*` 消费）**下拉框** `SelectInput` 的组件设计：**静态选项**下拉选择的**基础控件**。按输入域口径组合核心能力 `field`（字段编排，含 `value` / `field-shell` / `field-perm`）+ `input-control`（输入形态）→ 组件根 `BaseComponent` → 根系 `BaseFrontend`（能力类登记 `capabilities/manifest.ts`，投影取 `useField` / `useValue`）。

> 本篇为 **基础控件类「下拉框」**。范围边界：**字典来源**下拉归 [字段类「字典字段」](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)；**枚举选项集**（自定义选项/多选标签）归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)；本篇只做**静态 options** 的选择原语，被上述字段继承。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `SelectInput.vue` | `frontend/packages/ui-ep/src/components/input/`（目标落点，随域 05+ 回补波交付） | 静态选项下拉：单选/多选、搜索、清空、分组、禁用选项 |

> **实现口径（2026-09-17，新体系；实现随域 05+ 回补波交付）**：组件目标落点 PC `frontend/packages/ui-ep/src/components/input/`（移动端按需 `frontend/packages/ui-vant/src/components/input/`），宿主 `frontend/apps/*` 消费；按输入域口径组合核心能力 `field` + `input-control`（已类化为 `frontend/packages/core/src/capabilities/<key>.ts` 核心能力类，登记 `capabilities/manifest.ts`）；本控件只做静态 `options` 原语，字典/枚举等动态来源的取数、缓存与回显由 字段类节点接入 选项源能力 `option-source`（`frontend/packages/core/src/capabilities/option-source.ts`，无投影按需回补）；原 `BaseInput` 域包装与旧 `useXxx` 组合式随旧层删除（历史经 git 追溯），按「核心能力 + 投影 + 插件包装」随域 05+ 回补波重建；旧 `base-control` 组件目录已删除（历史经 git 追溯）。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | any \| any[] \| null | `null` | 受控值 |
| `options` | OptionItem[] | [] | 静态选项（`value/label/disabled/group?`） |
| `multiple` | boolean | false | 多选 |
| `filterable` | boolean | false | 可搜索 |
| `clearable` | boolean | true | 可清空 |
| `collapseTags` | boolean | false | 多选标签折叠 |
| `maxCount` | number | — | 多选数量上限 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 选项模型 | `OptionItem`（值/文本/禁用/分组），与字典/枚举同构，便于继承 |
| 多选 | `multiple`，值数组；`maxCount` 上限提示；标签折叠 |
| 搜索 | `filterable` 本地过滤（静态选项） |
| 归一 | 空 → `null`（单选）/`[]`（多选）；去除无效值 |
| 只读/三态 | 只读回显经展示域口径（`value` + `display-control`）；三态一致 |
| 分组 | 按 `group` 分节显示 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：选项文本按 locale（由使用方下发）。
- **移动端**：底部弹层选择器。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 选项 | 少量静态选项本地过滤；大量选项时应改用字典/远程搜索字段 |
| 边界 | 无效值回显、多选上限、禁用选项、空值与 `false`/`0` 值、异步选项（非本控件） |
| 不支持 | 字典下拉（字段类「字典字段」）、枚举多选标签（字段类「开关与枚举字段」）、树/级联（字段类「树选择字段」/「级联选择」） |
