## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**复选**的组件设计：静态选项多选的**基础控件**，按形态配置渲染 checkbox / tag 两种形态。它继承[输入域基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（受控值、字段壳、字段权限、校验触发），经[组件根基类](../../02_基础组件类/01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)与[根系基类](../../02_基础组件类/01_机制基类/01_组件设计_根系基类/01_组件设计_根系基类.md)取得通用能力，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「复选」**。范围边界：**自定义选项集多选**归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其字段实现继承本控件）；本篇只做静态复选项原语。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 复选项件 | 静态复选项：checkbox/tag、全选、数量上下限、只读、空值 |
| 继承链 | 复选 → 输入域（域基类层：受控值/字段壳/字段权限）→ 组件根 → 根系；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入域基类（受控绑定、值归一、禁用合并、三态）；多选值为数组 |
| 静态选项 | 选项模型（值/文本/禁用），与字典/枚举同构，便于字段类继承 |
| 形态 | 两种形态（checkbox / tag），tag 形态标签可关闭 |
| 全选 | 可显示全选/反选（忽略禁用项） |
| 数量上下限 | 可配最少/最多选择数量，越限校验并提示 |
| 其余契约 | 占位、只读、禁用、尺寸等继承输入域基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入域基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | checkbox 列表；tag 标签多选（可关闭） |
| 全选 | 全选/反选（忽略禁用项） |
| 数量 | 最少/最多选择数量校验并提示（如「最多选 3 项」） |
| 归一 | 值去重、保序（按选项顺序输出，与勾选顺序无关）；空值归一到空数组 |
| 只读 | 只读态展示已选标签/勾选 |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单字段 | 标签、兴趣、角色多选 |
| 查询筛选区 | 多值条件 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑。
- **i18n**：选项文本按 locale 下发。
- **移动端**：触控标签换行，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 选项少（建议 ≤12）；多则用穿梭框/下拉多选 |
| 边界 | 数量上下限、全选与禁用、去重保序、无效值、只读回显 |
| 不支持 | 字典多选（字段类「字典字段」）、枚举多选标签（字段类「开关与枚举字段」）、穿梭框（字段类「穿梭框」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 根系），行为不在组件内重复实现
- □ 契约语义：静态选项/两形态/全选/数量上下限/只读/空值
- □ 两形态；全选；数量校验；去重保序；空值归一到空数组
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与字段类枚举/穿梭框边界清晰
- □ 三项上游登记已确认
