## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**复选** `CheckboxField` 的组件设计：静态选项多选的**基础控件**，按 `widget` 渲染 `checkbox` / `tag` 两种形态。继承 **02 基础组件类** L4-01 输入域基类。

> 本篇为 **03 基础控件类第 07 篇**。范围边界：**自定义选项集多选**归 [04 字段类 08 开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其 `EnumCheckboxField` 继承本控件）；本篇只做静态复选项原语。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `CheckboxField.vue` | `src/components/base-control/` | 静态复选项：checkbox/tag、全选、数量上下限、只读、空值 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | any[] | [] | 受控值（数组） |
| `options` | OptionItem[] | [] | 静态选项 |
| `widget` | 'checkbox' \| 'tag' | 'checkbox' | 形态 |
| `min` / `max` | number | — | 数量上下限 |
| `selectAll` | boolean | false | 显示全选 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | checkbox 列表；tag 标签多选（可关闭） |
| 全选 | `selectAll` 全选/反选（忽略禁用项） |
| 数量 | `min`/`max` 校验并提示（如「最多选 3 项」） |
| 归一 | 值去重、保序（按选项顺序输出，与勾选顺序无关）；空 → `[]` |
| 只读 | 只读态展示已选标签/勾选 |

| 查询筛选区 | 多值条件 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：选项文本按 locale 下发。
- **移动端**：触控标签换行。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 选项少（建议 ≤12）；多则用穿梭框/下拉多选 |
| 边界 | 数量上下限、全选与禁用、去重保序、无效值、只读回显 |
| 不支持 | 字典多选（04-01）、枚举多选标签（04-08）、穿梭框（04-09） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整；契约：`options`/`widget`/`min`/`max`/`selectAll`

- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与 04 字段类枚举/穿梭框边界清晰
