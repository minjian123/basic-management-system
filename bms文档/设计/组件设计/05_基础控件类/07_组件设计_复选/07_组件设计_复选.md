## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 PC 渲染插件 `frontend/packages/ui-ep`（目标落点 `frontend/packages/ui-ep/src/components/input/`；移动端按需 `frontend/packages/ui-vant/src/components/input/`；宿主 `frontend/apps/*` 消费）**复选** `CheckboxField` 的组件设计：静态选项多选的**基础控件**，按 `widget` 渲染 `checkbox` / `tag` 两种形态。按输入域口径组合核心能力 `field`（字段编排，含 `value` / `field-shell` / `field-perm`）+ `input-control`（输入形态）→ 组件根 `BaseComponent` → 根系 `BaseFrontend`（能力类登记 `capabilities/manifest.ts`，投影取 `useField` / `useValue`）。

> 本篇为 **基础控件类「复选」**。范围边界：**自定义选项集多选**归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其 `EnumCheckboxField` 继承本控件）；本篇只做静态复选项原语。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `CheckboxField.vue` | `frontend/packages/ui-ep/src/components/input/`（目标落点，随域 05+ 回补波交付） | 静态复选项：checkbox/tag、全选、数量上下限、只读、空值 |

> **实现口径（2026-09-17，新体系；实现随域 05+ 回补波交付）**：组件目标落点 PC `frontend/packages/ui-ep/src/components/input/`（移动端按需 `frontend/packages/ui-vant/src/components/input/`），宿主 `frontend/apps/*` 消费；按输入域口径组合核心能力 `field` + `input-control`（已类化为 `frontend/packages/core/src/capabilities/<key>.ts` 核心能力类，登记 `capabilities/manifest.ts`）；静态选项原语，枚举多选来源由 字段类节点接入 选项源能力 `option-source`；原 `BaseInput` 域包装与旧 `useXxx` 组合式随旧层删除（历史经 git 追溯），按「核心能力 + 投影 + 插件包装」随域 05+ 回补波重建；旧 `base-control` 组件目录已删除（历史经 git 追溯）。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | any[] | [] | 受控值（数组） |
| `options` | OptionItem[] | [] | 静态选项 |
| `widget` | 'checkbox' \| 'tag' | 'checkbox' | 形态 |
| `min` / `max` | number | — | 数量上下限 |
| `selectAll` | boolean | false | 显示全选 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | checkbox 列表；tag 标签多选（可关闭） |
| 全选 | `selectAll` 全选/反选（忽略禁用项） |
| 数量 | `min`/`max` 校验并提示（如「最多选 3 项」） |
| 归一 | 值去重、保序（按选项顺序输出，与勾选顺序无关）；空 → `[]` |
| 只读 | 只读态展示已选标签/勾选 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：选项文本按 locale 下发。
- **移动端**：触控标签换行。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 选项少（建议 ≤12）；多则用穿梭框/下拉多选 |
| 边界 | 数量上下限、全选与禁用、去重保序、无效值、只读回显 |
| 不支持 | 字典多选（容器组件类「弹窗抽屉表单」）、枚举多选标签（容器组件类「分区容器」）、穿梭框（容器组件类「宽高比容器」） |
