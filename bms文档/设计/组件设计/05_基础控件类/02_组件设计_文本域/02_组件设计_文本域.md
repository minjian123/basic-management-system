## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**文本域**的组件设计：多行文本输入的**基础控件**，用于备注、说明、地址、意见等长文本。它继承[输入域基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（受控值、字段壳、字段权限、校验触发），经[组件根基类](../../02_基础组件类/01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)与[根系基类](../../02_基础组件类/01_机制基类/01_组件设计_根系基类/01_组件设计_根系基类.md)取得通用能力，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「文本域」**。范围边界：富文本（可格式化内容）归 [字段类「富文本字段」](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)；本篇只做纯文本多行输入。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 文本域件 | 多行文本：行数与自适应高度、字数统计、换行保留、受控与只读、去首尾空格与脱敏 |
| 继承链 | 文本域 → 输入域（域基类层：受控值/字段壳/字段权限）→ 组件根 → 根系；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入域基类（受控绑定、值归一、禁用合并、三态） |
| 行数与自适应高度 | 初始行数可配；可高度自适应（最小/最大行数），超出上限出现滚动条 |
| 字数统计 | 超限截断并显示字数（已输入/上限） |
| 换行保留 | 保留换行；后端存储换行符统一 |
| 去首尾空格 | 可配置提交前去除首尾空格 |
| 脱敏展示 | 敏感长文本按规则掩码；持对应动作权限时可查看明文 |
| 其余契约 | 占位、只读、禁用等继承输入域基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入域基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 高度 | 固定行数或高度自适应（最小/最大行数），超限出现滚动条 |
| 计数 | 超限截断并显示已输入/上限 |
| 换行 | 保留换行；提交原样（后端存储换行符统一） |
| 归一 | 可配置去首尾空格；空串归一到统一空值（受控值语义）；只读与三态继承输入域语义 |
| 脱敏 | 敏感长文本按规则掩码（[字段权限能力](../../02_基础组件类/02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)） |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑；脱敏按字段属性。
- **i18n**：标签/占位/计数文案由元数据下发；错误文案走全局语言能力。
- **移动端**：多行输入、高度自适应与键盘避让，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控输入与输入法组合事件分离；长文本计数可去抖 |
| 边界 | 超长截断、高度自适应抖动、换行符统一、去首尾空格、只读与三态 |
| 不支持 | 富文本/格式化（字段类「富文本字段」）、单行文本（文本框） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 根系），行为不在组件内重复实现
- □ 契约语义：行数/自适应高度/长度/计数/去首尾空格/换行保留/脱敏；受控与三态
- □ 权限（可见/可编辑/脱敏）、i18n、移动端符合第 7 节
- □ 与文本框/富文本字段边界清晰
- □ 三项上游登记已确认
