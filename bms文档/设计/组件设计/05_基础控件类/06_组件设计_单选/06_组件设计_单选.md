## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**单选**的组件设计：静态选项单选的**基础控件**，按形态配置渲染 radio / button / segmented 三种形态。它继承[输入族基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（`BaseInput`）（受控值、字段壳、字段权限、校验触发），沿继承链（`BaseValue → BaseComponent → BaseObject`）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「单选」**。范围边界：**自定义选项集枚举**归 [字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其字段实现继承本控件）；本篇只做静态单选项原语。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 单选项件 | 静态单选项：radio/button/segmented、禁用、只读、空值 |
| 继承链 | 单选 → `BaseInput` → `BaseField` → `BaseValue` → `BaseComponent` → `BaseObject`（唯一权威见《前端基类清单》§2，全系统唯一一份）；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入族基类（受控绑定、值归一、禁用合并、三态） |
| 静态选项 | 选项模型（值/文本/禁用），与字典/枚举同构，便于字段类继承 |
| 形态 | 三种形态（radio / button / segmented）；button 形态可配语义色 |
| 禁用与只读 | 禁用项不可选；只读态保留选中高亮但不响应 |
| 其余契约 | 占位、尺寸等继承输入族基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后值）继承输入族基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | radio 纵向/横向；button 按钮组；segmented 分段控件 |
| 选项模型 | 复用统一选项模型（值/文本/禁用，与字典/枚举同构） |
| 归一 | 空值归一到统一空值；无效值回退空 |
| 只读 | 只读态可保留选中高亮但不响应 |
| 横向溢出 | 选项多时换行/滚动 |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单字段 | 性别、类型、优先级、是否类 |
| 工具栏 | 视图切换（segmented） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑。
- **i18n**：选项文本按 locale 下发。
- **移动端**：触控尺寸与换行，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 选项少（建议 ≤7）；多则用下拉框 |
| 边界 | 无效值回显、横向溢出、只读高亮、0 值 |
| 不支持 | 字典（字段类「字典字段」）、枚举单选（字段类「开关与枚举字段」）、下拉（下拉框） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → `BaseComponent` → `BaseObject`），行为不在组件内重复实现
- □ 契约语义：静态选项/三形态/禁用与只读/空值三态
- □ 三形态渲染；选项模型复用；空值归一
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与字段类开关与枚举字段边界清晰
- □ 三项上游登记已确认
