## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**单选** `RadioField` 的组件设计：静态选项单选的**基础控件**，按 `widget` 渲染 `radio` / `button` / `segmented` 三种形态。继承 **02 基础组件类** L4-01 输入域基类。

> 本篇为 **03 基础控件类第 06 篇**。范围边界：**自定义选项集枚举**归 [04 字段类 08 开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其 `EnumField` 继承本控件）；本篇只做静态单选项原语。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `RadioField.vue` | `src/components/base-control/` | 静态单选项：radio/button/segmented、禁用、只读、空值 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | any \| null | `null` | 受控值 |
| `options` | OptionItem[] | [] | 静态选项 |
| `widget` | 'radio' \| 'button' \| 'segmented' | 'radio' | 形态 |
| `optionType` | 'default' \| 'success' \| 'warning' \| 'danger' | 'default' | button 形态语义色 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | radio 纵向/横向；button 按钮组；segmented 分段控件 |
| 选项模型 | 复用 `OptionItem`（与字典/枚举同构） |
| 归一 | 空 → `null`；无效值回退空 |
| 只读 | 只读态可保留选中高亮但不响应 |
| 横向溢出 | 选项多时换行/滚动 |

| 工具栏 | 视图切换（segmented） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：选项文本按 locale 下发。
- **移动端**：触控尺寸与换行。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 选项少（建议 ≤7）；多则用下拉框 |
| 边界 | 无效值回显、横向溢出、只读高亮、`0`/`false` 值 |
| 不支持 | 字典（04-01）、枚举多选（04-08）、下拉（下拉框） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整；契约：`options`/`widget`/`optionType`
- □ 三形态渲染；`OptionItem` 复用；空值归一
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与 04 字段类枚举边界清晰
- □ 三项上游登记已确认
