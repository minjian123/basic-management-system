## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**密码框**的组件设计：密码输入的**基础控件**，用于登录、新增/修改密码、初始化密码等。它继承[输入族基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（`BaseInput`）（受控值、字段壳、字段权限、校验触发），沿继承链（`BaseValue → BaseComponent → BaseObject`）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「密码框」**。安全底线：密码**不回填**（编辑态留空表示不修改）、明文切换仅前端内存、不落日志/本地存储。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 密码框件 | 密码输入：掩码显示、明文切换、强度提示、一致性校验、不回填 |
| 继承链 | 密码框 → `BaseInput` → `BaseField` → `BaseValue` → `BaseComponent` → `BaseObject`（唯一权威见《前端基类清单》§2，全系统唯一一份）；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入族基类（受控绑定、值归一、禁用合并、三态）；密码不回填（编辑态留空表示不修改） |
| 明文切换 | 提供明文切换入口，仅前端内存态，切换不触发日志 |
| 强度提示 | 按规则计算并提示（弱/中/强），不阻断（由校验决定） |
| 最小长度 | 最小长度约束参与校验 |
| 阻止自动填充 | 可阻止浏览器自动填充 |
| 校验 | 长度/强度/一致性校验结果回传字段壳 |
| 其余契约 | 占位、只读、禁用等继承输入族基类与组件根 |
| 值变化通知 | 受控更新与业务变更继承输入族基类语义；不回显到日志 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 不回填 | 编辑态初始为空；提交时为空表示不修改（后端约定） |
| 明文切换 | 仅前端内存态；切换不触发日志 |
| 强度 | 按规则计算并提示（弱/中/强），不阻断（由校验决定） |
| 一致性 | 确认密码字段引用同一规则做一致性校验 |
| 安全 | 值不写日志/不落本地存储；自动填充可禁 |
| 归一 | 密码不去首尾空格（保留空格）；空串归一到统一空值 |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：修改密码入口按权限/本人约束（后端强校验）；字段权限能力判定可见/可编辑。
- **i18n**：强度提示/错误文案走全局语言能力。
- **移动端**：安全键盘、掩码显示与键盘避让，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控输入与输入法组合事件分离；强度计算可去抖 |
| 边界 | 自动填充泄露、明文切换残留、确认不一致、长度与复杂度、编辑态回填误用 |
| 不支持 | 验证码（[字段类「验证码」](../../06_字段类/10_组件设计_验证码/10_组件设计_验证码.md)）、普通文本（文本框） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → `BaseComponent` → `BaseObject`），行为不在组件内重复实现
- □ 契约语义：明文切换/强度提示/最小长度/阻止自动填充；不回填与三态
- □ 不回填、明文仅内存、不落日志/存储；强度提示与一致性校验
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与验证码/文本框边界清晰
- □ 三项上游登记已确认
