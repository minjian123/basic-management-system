## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**单布尔复选**的组件设计：承载**单一布尔值**的基础控件（勾选 / 不勾选），按形态呈现复选框。它继承[输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（输入组件基类）（受控值、字段壳、字段权限、校验触发），沿继承链（值能力基类 → 组件根 → 总基类）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「单布尔复选」**。范围边界：**多值 / 自定义选项集多选**归 [复选](../07_组件设计_复选/07_组件设计_复选.md)；**开关形态的布尔**归 [基础控件类「开关」](../08_组件设计_开关/08_组件设计_开关.md)；带数据源 / 特殊语义的枚举布尔归[字段类「开关与枚举字段」](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)。本篇只做**单一布尔复选原语**。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 单布尔复选项件 | 单一布尔勾选：受控值、三态（未设置）、禁用、不确定态、文案 |
| 继承链 | 单布尔复选 → 输入组件基类 → 字段能力基类 → 值能力基类 → 组件根 → 总基类（唯一权威见《前端基类清单》§2，全系统唯一一份）；行为在链上基类维护，不在组件内重复实现 |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入组件基类（受控绑定、值归一、禁用合并、三态）；值为**单一布尔**（`true` / `false` / 未设置） |
| 文案 | 复选项内联文案（勾选项旁的说明文字），缺省为空 |
| 禁用 | 禁用态不可交互，视觉灰化 |
| 不确定态 | 仅视觉「部分选中」呈现，**不改变布尔值**（用于筛选等汇总态） |
| 其余契约 | 只读、尺寸、字段壳、字段权限等继承输入组件基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后布尔值）继承输入组件基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 勾选 / 取消 | 点击复选项或文案区切换：勾选=真、取消=假；同值不重复派发 |
| 三态 | 未设置（初值）与「假」区分：未设置不主动派发，交互后归一到 `true` / `false` |
| 不确定态 | 独立视觉属性，不回写值；与「假」的区别仅在呈现 |
| 归一 | 非布尔回传一律归一为布尔；未设置不触发变更 |
| 只读 | 只读态以只读复选（禁用态）呈现勾选结果 |
| 权限 | 可见 / 可编辑由字段编排语义判定（不渲染 / 禁用） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 登录「记住我」 | 单一布尔选项，随登录请求提交（见项目详细设计 05-5） |
| 表单开关项 | 「我已阅读并同意」等单一确认项 |
| 查询汇总 | 表头「全选」的父级不确定态呈现 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见 / 可编辑。
- **i18n**：复选文案按 locale 下发。
- **移动端**：触控命中区放大，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 单值轻量；无数据源、无异步 |
| 边界 | 三态（未设置 / 真 / 假）、不确定态、禁用、只读回显 |
| 不支持 | 多值多选（复选）、开关形态（开关）、枚举布尔（字段类「开关与枚举字段」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 总基类），行为不在组件内重复实现
- □ 契约语义：单一布尔 / 三态 / 不确定态 / 禁用 / 文案
- □ 勾选归一为布尔；未设置不误派发；不确定态不回写值
- □ 权限 / i18n / 移动端符合第 7 节；边界符合第 8 节
- □ 与复选（多值）/ 开关 / 枚举字段边界清晰
- □ 两项上游登记已确认
