## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**数字框**的组件设计：纯数值输入的**基础控件**，用于排序号、数量、次数等无金额语义的数字。它继承[输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（输入组件基类）（受控值、字段壳、字段权限、校验触发），沿继承链（值能力基类 → 组件根 → 总基类）取得通用职责，即获得受控绑定、三态、字段权限、字段壳、校验触发与通用能力。

> 本篇为 **基础控件类「数字框」**。范围边界：**金额/百分比/精度语义**归 [字段类「数值与金额字段」](../../06_字段类/03_组件设计_数值与金额字段/03_组件设计_数值与金额字段.md)（其字段实现继承本控件再加金额语义）；本篇只做纯数字。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 数字框件 | 纯数字输入：整数/小数、精度、上下限、步进、千分位显示 |
| 继承链 | 数字框 → 输入组件基类 → 字段能力基类 → 值能力基类 → 组件根 → 总基类（唯一权威见《前端基类清单》§2，全系统唯一一份）；行为在链上层维护，不在组件内重复实现 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 继承输入组件基类（受控绑定、值归一、禁用合并、三态）；未设置与已填 0 可区分（空值 vs 零值） |
| 精度 | 小数位可配（0 为整数），决定显示与存储精度 |
| 上下限 | 可配最小值/最大值；越界钳制或校验（可配） |
| 步进 | 步进值控制上下调节与键盘上下键 |
| 千分位显示 | 仅显示层，存储为数值 |
| 校验 | 范围/精度校验结果回传字段壳 |
| 其余契约 | 占位、只读、禁用等继承输入组件基类与组件根 |
| 值变化通知 | 受控更新与业务变更（归一后数值）继承输入组件基类语义 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 归一 | 空串归一到统一空值；精度四舍五入；上下限越界钳制或校验（可配） |
| 精度 | 由精度配置决定显示与存储精度（0 为整数） |
| 步进 | 步进值控制上下箭头；支持键盘上下键 |
| 千分位 | 千分位仅显示层，存储为数值 |
| 三态 | 未设置/空/已填（空值与 0 区分） |
| 安全 | 非数值输入拦截 |
| 权限 | 可见/可编辑由字段编排语义判定（不渲染/禁用） |

## 5. 场景集成 <a id="scenes"></a>

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限能力判定可见/可编辑。
- **i18n**：千分位/小数按 locale（[基础类「格式化工具」](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）。
- **移动端**：数字键盘与输入法适配，与 PC 同一契约多实现。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控输入；非数值即时拦截 |
| 边界 | 精度舍入、越界钳制、空值与零值、千分位与输入解析、科学计数法、大数精度（超安全整数用字符串） |
| 不支持 | 金额/币种/百分比（字段类「数值与金额字段」）、日期（字段类「日期时间字段」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整（输入域 → 组件根 → 总基类），行为不在组件内重复实现
- □ 契约语义：精度/上下限/步进/千分位/空值三态
- □ 归一与精度、越界、空值与零值、千分位
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与字段类数值与金额字段边界清晰
- □ 三项上游登记已确认
