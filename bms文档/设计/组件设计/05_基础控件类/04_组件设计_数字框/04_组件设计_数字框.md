## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 PC 渲染插件 `frontend/packages/ui-ep`（目标落点 `frontend/packages/ui-ep/src/components/input/`；移动端按需 `frontend/packages/ui-vant/src/components/input/`；宿主 `frontend/apps/*` 消费）**数字框** `NumberInput` 的组件设计：纯数值输入的**基础控件**，用于排序号、数量、次数等无金额语义的数字。按输入域口径组合核心能力 `field`（字段编排，含 `value` / `field-shell` / `field-perm`）+ `input-control`（输入形态）→ 组件根 `BaseComponent` → 根系 `BaseFrontend`（能力类登记 `capabilities/manifest.ts`，投影取 `useField` / `useValue`）。

> 本篇为 **基础控件类「数字框」**。范围边界：**金额/百分比/精度语义**归 [字段类「数值与金额字段」](../../06_字段类/03_组件设计_数值与金额字段/03_组件设计_数值与金额字段.md)（其 `NumberField`/`AmountField` 可继承本控件再加金额语义）；本篇只做纯数字。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | number \| null | `null` | 受控值 |
| `precision` | number | 0 | 小数位（0=整数） |
| `min` / `max` | number | — | 上下限 |
| `step` | number | 1 | 步进 |
| `thousands` | boolean | false | 千分位显示 |

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `change` | 归一后数值 |
| `validate` | 范围/精度校验结果 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 归一 | 空串 → `null`；`precision` 四舍五入；`min`/`max` 越界钳制或校验（可配） |
| 精度 | 由 `precision` 决定显示与存储精度（`0` 整数） |
| 步进 | `step` 控制上下箭头；键盘上下键 |
| 千分位 | `thousands` 仅显示层，存储为数值 |
| 三态 | 未设置/空/已填（`null` vs `0` 区分） |
| 安全 | 非数值输入拦截 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：千分位/小数按 locale（[基础类「格式化工具」](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）。
- **移动端**：数字键盘（`inputmode=decimal`）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控；非数值即时拦截 |
| 边界 | 精度舍入、越界钳制、`null`/`0`、千分位与输入解析、科学计数法、大数精度（超安全整数用字符串） |
| 不支持 | 金额/币种/百分比（字段类「数值与金额字段」）、日期（字段类「日期时间字段」） |
