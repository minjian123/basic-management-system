## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **文件预览**的组件设计：预览容器 `FilePreview.vue`（类型分发、多文件切换、下载、失效与降级），图片预览 `ImageViewer.vue`（缩放/旋转/切换），PDF 预览 `PdfViewer.vue`（翻页/缩放），以及组合式函数 `useFilePreview.ts`（预签名 URL 获取与失效刷新、内容类型判定、下载）。适用于管理端各处**文件在线预览**（[01 字段类 06 文件上传字段](../../01_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md) 回显点击、[02 展示类 03 状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 文件值、业务单据附件）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**文件管理**模块；上游设计依据[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)（文件元数据、预签名下载与在线预览、`file:download`）与[《架构设计 · 文件管理》](../../../架构设计/16_架构设计_子系统_文件管理.md)（分片状态机、安全控制、预签名 URL 直开、MinIO 对象存储）；协作节点为[01 字段类 06 文件上传字段](../../01_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（上传与文件列表回显）、[02 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（加载/错误/失效态）、[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（预签名 URL 获取）、[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`file:download`）；形态依据[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html)（预览遮罩层）与[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)（移动端图片预览）。

> 本篇为组件设计体系展示类第 08 篇。**范围边界**：**文件存储、分片上传、预签名生成、内容安全**归[《架构设计 · 文件管理》](../../../架构设计/16_架构设计_子系统_文件管理.md)（本节点只消费预签名 URL）；**上传与文件列表**归 [01 字段类 06 文件上传字段](../../01_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)；**Office 文档在线编辑/转换**（如需）不在 MVP（仅提供下载）；**富文本正文**归 [01 字段类 08 富文本字段](../../01_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)；移动端不复用 PC 组件（见第 10 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `FilePreview.vue` | `src/components/file-preview/` | 预览容器：按内容类型分发（图片/PDF/音视频/文本/其他）；多文件切换（上一/下一、缩略图）；下载；预签名失效重取；不支持类型降级下载；遮罩/抽屉/页内三种形态 |
| `ImageViewer.vue` | `src/components/file-preview/` | 图片预览：等比缩放、旋转、多图切换、适应窗口/原始尺寸、下载 |
| `PdfViewer.vue` | `src/components/file-preview/` | PDF 预览：分页翻页、页码跳转、缩放、下载；加载失败降级下载 |
| `useFilePreview.ts` | `src/utils/useFilePreview.ts` | 组合式函数：按类型分发、预签名 URL 获取与失效刷新（限期解析）、内容类型判定、下载、加载/错误态 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，预览归 `file-preview/`；组合式函数放 `src/utils/`）。
- **音视频/文本内联**：`FilePreview` 内直接使用浏览器原生 `<video>`/`<audio>`/`<pre>`（或 `<img>`），不额外拆组件；仅图片/PDF 因交互复杂单拆。
- **预签名 URL 直开**：预览地址为后端预签名 URL（限时有效），前端不代理文件流（[《架构设计 · 文件管理》](../../../架构设计/16_架构设计_子系统_文件管理.md)）。

## 3. 预览容器 FilePreview <a id="container"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | boolean | false | 显隐（`v-model`） |
| `files` | FileItem[] | [] | 文件列表（`{ id, name, mimeType, size }`），支持多文件切换 |
| `index` | number | 0 | 初始预览索引 |
| `mode` | 'overlay' \| 'drawer' \| 'inline' | 'overlay' | 遮罩层 / 抽屉 / 页内嵌 |
| `showDownload` | boolean | true | 是否显示下载（受 `file:download`） |
| `listType` | 'none' \| 'thumbnails' | 'thumbnails' | 多文件切换形式 |

| 事件 | 说明 |
| --- | --- |
| `closed` | 关闭预览 |
| `change` | 切换文件（索引 + 文件） |
| `error` | 预览失败（失效/不支持/加载失败），携带文件与原因 |

- 类型分发：图片 → `ImageViewer`；PDF → `PdfViewer`；视频/音频 → 原生播放器；文本（txt/csv/json/代码）→ `<pre>`（大文件截断）；其他（office/压缩包等）→ **降级为下载**（提示「该类型不支持在线预览，请下载查看」）。
- 多文件：上一/下一、缩略图条（图片）/文件列表；键盘 ←/→ 切换、Esc 关闭。
- 失效处理：预签名 URL 过期或对象不可读 → 自动请求新 URL 一次；仍失败则错误态 + 下载入口（[02 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)）。

## 5. PDF 预览 PdfViewer <a id="pdf"></a>

| 项 | 设计 |
| --- | --- |
| 承载 | `<iframe>`/`<embed>` 直开预签名 URL（浏览器内置 PDF 阅读器）或自绘分页；缺省用浏览器内置 |
| 翻页/跳转 | 页码输入跳转、上一/下一；总页数（若可得） |
| 缩放 | 适应宽度/适应页面（视浏览器能力，必要时自绘） |
| 下载 | 下载 PDF（`file:download`） |

- PDF 预览以**浏览器内置阅读器**为主（轻量、无额外库）；若需统一体验再评估引入 PDF.js（登记项②）。

## 6. 音视频与文本预览 <a id="media-text"></a>

| 类型 | 实现 | 说明 |
| --- | --- | --- |
| 视频 | 原生 `<video controls>` | 支持 Range 请求（预签名 URL 支持分段，[《架构设计 · 文件管理》](../../../架构设计/16_架构设计_子系统_文件管理.md)）；封面可空 |
| 音频 | 原生 `<audio controls>` | 简单播放器 |
| 文本 | `<pre>` 展示解析文本 | txt/csv/json/代码；大文件截断（前 N KB）+ 下载查看全文；超长行横向滚动 |
| 图片 | `ImageViewer` | 见第 4 节 |
| PDF | `PdfViewer` | 见第 5 节 |

- 音视频/文本为**扩展预览类型**（原设计为图片/PDF；本节点扩展并登记上游，登记项③）。
- 移动端音视频使用移动端播放器（系统/微信内核），文本按移动端样式。

## 7. 组合式函数 useFilePreview <a id="use-file-preview"></a>

```typescript
interface UseFilePreviewOptions { files: FileItem[]; index?: number; }
interface UseFilePreviewReturn {
  open: boolean;
  current: FileItem | null;
  currentIndex: number;
  kind: 'image' | 'pdf' | 'video' | 'audio' | 'text' | 'other';
  previewUrl: Ref<string | null>;
  loading: Ref<boolean>;
  error: Ref<string | null>;
  next / prev;
  resolveUrl: (file: FileItem) => Promise<string>;   // 预签名 URL 获取/刷新
  download: (file: FileItem) => void;
  close: () => void;
}
```

| 行 | 设计 |
| --- | --- |
| 类型判定 | 按 `mimeType`（缺省按扩展名）判 kind；`other` 直接降级下载 |
| 预签名 | `resolveUrl` 调后端获取预签名 URL（限时）；URL 失效（加载错误/超时）时**重取一次**，仍失败给错误态 + 下载 |
| 下载 | 下载走预签名 URL（`file:download`，[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)） |
| 切换 | `next`/`prev` 切换文件并重置子查看器状态（缩放/翻页）；按需预取相邻图片 |
| 释放 | 关闭时释放 URL（不泄漏）、停止播放（音视频） |
| 错误 | 对象不存在/已清理（文件已失效）、无权限、不支持类型、加载失败分类提示 |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：预览与下载需 `file:download`（[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)）；对象归属与数据范围由后端校验（预签名生成时鉴权）；无权限时不展示预览/下载入口（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：界面文案（加载/错误/不支持类型提示/页码）、错误码走 vue-i18n；文件名不翻译。
- **移动端**：不复用 PC 组件；图片用 `van-image-preview`、音视频用系统/内嵌播放器、文本按移动端样式；预签名与下载复用后端接口与 `file:download`（[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 加载 | 预签名 URL 直开（前端不代理流）；图片可按需懒加载/预取相邻；PDF 用浏览器内置阅读器按需加载 |
| 内存 | 关闭时释放 URL、停止音视频播放、销毁子查看器；大图避免同时多份解码 |
| 文本 | 大文本截断（前 N KB）+ 下载全文；超长行横向滚动 |
| 音视频 | Range 分段按需加载，不整包下载 |
| 失效 | URL 过期/对象不可读 → 重取一次 → 错误态 + 下载；不缓存超期 URL |
| 安全 | 不安全类型（HTML/SVG/可执行）不做内嵌渲染，降级下载；预签名限时降低泄露风险 |
| 边界 | 多文件空列表、索引越界、超大文件、损坏对象、类型判定失败（按 other 降级）、无权限、URL 失效、浏览器不支持内嵌 PDF、移动端差异 |
| 不支持 | 上传/分片（06 文件上传字段）、存储/预签名生成（架构 16）、Office 在线编辑（MVP 不提供，仅下载）、富文本正文（08 富文本字段）、移动端组件 |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：`FilePreview` 分发容器、`ImageViewer` 图片、`PdfViewer` PDF、`useFilePreview` 状态与 URL，音视频/文本内联；职责不重叠
- □ 类型分发：图片/PDF/音视频/文本/其他（降级下载）；mimeType 判定（缺省扩展名）
- □ 图片：缩放/旋转/适应/多图切换/下载；PDF：翻页/跳转/缩放/下载；音视频：原生播放器 + Range；文本：截断 + 下载
- □ 多文件切换（上一/下一/缩略图/键盘）、三形态（遮罩/抽屉/页内）
- □ 预签名：`resolveUrl` 获取/失效重取一次/失败错误态 + 下载；关闭释放、停止播放
- □ 权限（`file:download`）、i18n（文案/错误码/页码）、移动端（van-image-preview/系统播放器）符合第 10 节
- □ 性能边界：直开不代理、按需/懒加载、大文本截断、Range、URL 释放、不安全类型降级
- □ 三项上游登记已确认：文件预览交互契约、预签名 URL 使用与安全、扩展预览类型至音视频/文本
