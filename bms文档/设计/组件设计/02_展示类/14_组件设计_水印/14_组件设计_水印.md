## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **水印**的组件设计：水印容器 `Watermark.vue`（包裹内容叠加文字/图片水印，防截图泄露）与组合式函数 `useWatermark.ts`（水印内容生成、动态更新、防篡改）。适用于**敏感数据页面**（用户/角色/权限、审计日志、报表与大屏、文件预览、财务数据）的**可见水印**，标识访问者身份与时间，形成威慑与溯源依据。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「认证与安全」章节；上游设计依据[《安全开发规范》](../../../../规范/安全开发规范.md)（数据防泄露、敏感信息保护）、[《概要设计 · 审计合规》](../../../概要设计/28_概要设计_审计合规.md)（审计数据仅授权人员查看）、[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（报表数据防泄露）；协作节点为[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（时间格式化）、[02 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)/[02 展示类 09 审计差异查看](../09_组件设计_审计差异查看/09_组件设计_审计差异查看.md)（敏感内容承载）、[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)（颜色/透明度）。

> 本篇为组件设计体系展示类第 14 篇。**范围界定**：水印是**可见威慑**（非加密、非 DRM），不替代后端的数据脱敏与访问控制（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；**数据脱敏**归各业务字段与权限；**隐藏水印/数字水印/盲水印**等隐写方案不在 MVP；移动端不复用 PC 组件（见第 9 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `Watermark.vue` | `src/components/display/` | 水印容器：包裹内容叠加重复水印（文字/图片）、旋转/间距/透明度/层级、全屏或局部、响应式重绘、防篡改监听 |
| `useWatermark.ts` | `src/utils/useWatermark.ts` | 组合式函数：生成水印内容（用户名+工号+时间）、动态更新（定时刷新时间戳）、防篡改（DOM 变更监听并恢复） |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（展示类归 `display/`；组合式函数放 `src/utils/`）。
- 基于 Element Plus `el-watermark` 定制（2.9+ 已有）；缺失时自绘 Canvas 平铺层。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `content` | string \| string[] | — | 水印文案（一行或多行）；缺省由 `useWatermark` 生成（用户名/工号/时间） |
| `image` | string \| null | null | 图片水印（logo），`content` 与 `image` 可叠加 |
| `font` | `{ color, fontSize, fontWeight, fontFamily }` | 令牌 | 字体（颜色引用令牌、透明度内置于 color 或 `opacity`） |
| `opacity` | number | 0.15 | 水印整体透明度（不宜过高遮挡内容） |
| `rotate` | number | -22 | 旋转角度（度） |
| `gap` | [number, number] | [100, 100] | 水印间距 [水平, 垂直]（px） |
| `offset` | [number, number] | [0, 0] | 偏移 |
| `width` / `height` | number | 120 | 单个水印尺寸 |
| `zIndex` | number | 9 | 层级（高于内容、低于弹窗遮罩） |
| `fullscreen` | boolean | false | 是否全屏（整页）水印；false 时仅包裹区域 |
| `showTime` | boolean | true | 是否包含时间（配合定时刷新） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `ready` | — | 水印就绪 |
| `change` | content | 水印内容更新（时间戳刷新） |

- 暴露方法：`refresh()`（重绘/更新时间）、`getDataURL()`（导出水印图，可选）。

## 4. 水印内容与形态 <a id="content"></a>

| 项 | 设计 |
| --- | --- |
| 内容 | 默认多行：`用户名` / `工号或账号` / `yyyy-MM-dd HH:mm`（[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；可按页面配置 |
| 图片水印 | logo 图片 + 文案叠加（可选） |
| 颜色/透明度 | 颜色引用令牌（如 `--color-text-secondary`）+ 低透明度（默认 0.15），深色主题下用浅色 |
| 旋转/间距 | 默认 -22°、间距 100×100；密集内容可调小间距 |
| 全屏 vs 局部 | 敏感页整页水印（`fullscreen`）；弹窗/预览局部（包裹区域） |
| 响应式 | 容器尺寸变化重绘（间距按容器计算），保证铺满不空洞 |
| 打印 | 打印时水印同样输出（打印样式保留水印层）；导出图片可选叠加 |
| 不可选中 | 水印层 `pointer-events: none`、不可选中，避免干扰操作 |

## 5. 防篡改 <a id="protect"></a>

| 项 | 设计 |
| --- | --- |
| DOM 篡改监听 | `MutationObserver` 监听水印层被删除/改样式（如通过开发者工具移除），**自动重新插入**并恢复样式 |
| 内容刷新 | `showTime` 时按分钟级刷新时间戳（`useWatermark` 定时器），保持水印时效 |
| 层级 | 水印层置于内容之上、弹窗遮罩之下，防止被内容覆盖或遮挡弹窗 |
| 局限说明 | 可见水印为**威慑与溯源**手段，不能阻止截图或专业去除；真正的防护依赖访问控制、脱敏与审计 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：水印内容取当前登录用户（登录态内建）；水印**不替代**访问控制与脱敏（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；无权限用户无法进入敏感页（路由/接口层拦截）。
- **i18n**：水印为用户名/工号/时间等数据，**不翻译**；文案标签（如「工号」）如使用则走 vue-i18n。
- **移动端**：不复用 PC 组件；移动端敏感页以 Canvas 平铺水印实现，内容与透明度口径同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 水印层用 Canvas/背景图一次性生成，平铺展示；不逐元素 DOM；`pointer-events: none` |
| 重绘 | 容器尺寸变化防抖重绘；全屏水印监听窗口 resize |
| 刷新 | 时间戳按分钟级刷新（非每秒），降低开销 |
| 防篡改 | MutationObserver 轻量；避免与水印自身重绘形成循环（重绘时不触发递归） |
| 边界 | 容器为 0 尺寸（延迟绘制）、深色主题、间距过密遮挡、透明度不当、弹窗内嵌套（层级）、打印样式、开发者工具移除（恢复）、超长内容 |
| 不支持 | 隐藏/数字/盲水印（MVP 外）、真正的截图防护、数据脱敏（各字段）、移动端组件复用 |

## 10. 检查清单 <a id="checklist"></a>

- □ 组件分层：`Watermark` 容器与水印绘制、`useWatermark` 内容生成/时间刷新/防篡改
- □ 内容：用户名/工号/时间多行；可选图片水印
- □ 形态：颜色/透明度（令牌）、旋转、间距、层级、全屏/局部、响应式重绘、打印保留、不可选中
- □ 防篡改：MutationObserver 自动恢复、时间戳分钟级刷新、层级正确
- □ 权限（不替代访问控制/脱敏）、i18n（数据不翻译）、移动端（Canvas，口径同源）符合第 8 节
- □ 性能边界：Canvas 平铺、resize 防抖、时间刷新降频、防篡改无递归
- □ 三项上游登记已确认：敏感页水印口径、水印颜色与透明度令牌、报表/大屏水印
