## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **指标卡**的组件设计：指标展示卡 `StatCard.vue`（标题 + 数值 + 单位 + 环比/同比 + 趋势 + 状态色 + 口径说明 + 跳转），组合式函数 `useStat.ts`（数值格式化、倍数与差值计算、数字滚动动画），以及可选迷你趋势图（复用图表卡封装）。适用于**首页工作台统计卡**、**业务看板汇总**、**报表顶部汇总指标**等「单一数值/少量数值」的呈现。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**首页工作台**「数据统计卡」与**报表中心**汇总；上游设计依据[《概要设计 · 首页工作台》](../../../概要设计/35_概要设计_首页工作台.md)（内置统计卡、`sys_dashboard_card` 注册表 `render_key=stats`）、[《架构设计 · 首页工作台》](../../../架构设计/25_架构设计_子系统_首页工作台.md)（统计卡聚合接口、短缓存）；视觉依据[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「卡片形态规范」（小卡 2×2 单一统计数、数据卡片数值标注与口径说明）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；协作节点为[02 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)（迷你趋势图复用 `EChart`）、[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（数字/金额/百分比格式化）、[02 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（加载/空/错误）、[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（聚合取数）。

> 本篇为组件设计体系展示类第 10 篇。**范围边界**：**图表**（折线/柱/饼等）归 [02 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)（本节点为**单一指标**；迷你趋势图为可选复用）；**工作台卡片容器/编辑定制**归[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)与工作台页面；**聚合口径与数据**（`/dashboard/stats`、报表汇总）在后端；移动端不复用（见第 9 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `StatCard.vue` | `src/components/display/` | 指标卡：标题、数值（可滚动动画）、单位/前缀、环比/同比、趋势箭头与状态色、口径说明、跳转、加载/空/错误态、尺寸（小/中） |
| `useStat.ts` | `src/utils/useStat.ts` | 组合式函数：数值格式化分发（数量/金额/百分比）、环比/同比计算（倍数/差值/方向）、数字滚动动画、异常值处理 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（展示类归 `display/`；组合式函数放 `src/utils/`）。
- 迷你趋势图（可选）：复用 [02 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md) 的 `EChart`（`type='line'`），无趋势数据时不渲染。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 指标标题（i18n 或元数据下发） |
| `value` | number \| string \| null | null | 指标值（数字或已格式化字符串） |
| `unit` / `prefix` | string | '' | 单位（如「笔」「人」「元」）/ 前缀（如 `¥`） |
| `format` | 'number' \| 'amount' \| 'percent' \| 'custom' | 'number' | 格式化方式（`custom` 用 `formatter`） |
| `precision` | number \| null | null | 小数位（缺省按 format 默认） |
| `compare` | StatCompare \| null | null | 环比/同比：`{ type:'mom'\|'yoy', value:number, higherIsBetter?:boolean }` |
| `trend` | number[] \| null | null | 迷你趋势数据（sparkline，可选） |
| `statusColor` | boolean | true | 是否按趋势方向着状态色（升 success / 降 danger，可比 `higherIsBetter` 反转） |
| `caption` | string \| null | null | 口径说明（数据卡片必需，[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)） |
| `linkTo` | string \| RouteLocationRaw \| null | null | 点击跳转（详情/明细） |
| `loading` | boolean | false | 加载态（骨架/占位） |
| `size` | 'small' \| 'default' | 'default' | 小卡（单一数值）/ 默认 |
| `animate` | boolean | true | 数值滚动动画（首次加载） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `click` | — | 点击卡片（`linkTo` 由父组件路由或组件内跳转） |
| `refresh` | — | 刷新（可选，工作台卡片刷新） |

## 4. 数值与趋势 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 格式化 | `number`→千分位；`amount`→2 位 + 币种符号（[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；`percent`→百分比；`custom`→`formatter(value)` |
| 单位/前缀 | 前缀（如 `¥`）在数值前，单位（如「人」「笔」）在数值后，样式弱化 |
| 环比/同比 | `compare.value` 为百分比变化/倍数；展示方向箭头（↑/↓/—）与数值（如「较上月 +12.5%」）；`type='mom'`（环比）/'yoy'（同比）文案不同 |
| 趋势色 | 默认「升=success、降=danger」，`higherIsBetter=false` 时反转（如「逾期率」下降为好）；未知/持平用 info |
| 空值 | `value` 为 null/空 → 显示 `—`（[02 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 口径说明 | `caption` 说明统计口径（如「含税金额」「本月累计」），必填于数据卡片 |
| 数字动画 | `animate` 首次加载从 0 滚动到目标（短时长，遵守 `prefers-reduced-motion`）；刷新不重复动画 |

## 5. 迷你趋势图（可选） <a id="sparkline"></a>

| 项 | 设计 |
| --- | --- |
| 用途 | 卡片内展示近 N 期走势（无坐标轴/图例，仅形状） |
| 实现 | 复用 [02 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md) `EChart`（`type='line'`，隐藏轴/网格，面积淡色），或轻量 SVG 折线 |
| 数据 | `trend: number[]`（后端随指标返回）；无数据不渲染 |
| 交互 | 不响应点击（点击整体跳转）；tooltip 可选关闭 |
| 性能 | 视口内懒渲染；容器 resize 自适应 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：指标可见性随其数据来源（工作台卡片/报表权限）；跳转按目标路由权限显隐（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；无权限/取数失败按卡片级降级（不影响其他卡）。
- **i18n**：标题、单位、环比/同比文案（较上月/较去年同期）、口径说明走 vue-i18n 或元数据下发；数值格式按 locale（[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；不翻译用户数据。
- **移动端**：不复用 PC 组件；Vant 卡片单列展示，值与格式化同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 取数 | 聚合接口短缓存（~30s）；多卡并行取数、单卡失败隔离 |
| 动画 | 数字滚动一次；尊重 `prefers-reduced-motion`；刷新不重复 |
| 趋势图 | 视口内懒渲染；容器 resize 自适应；无数据不渲染 |
| 渲染 | 单卡轻量（文本 + 可选迷你图）；多卡网格布局 |
| 边界 | 空值/`—`、异常值（NaN/负数场景）、超大数值（缩写如 1.2万）、环比无基期、趋势数据缺失、无权限、取数失败（卡片级降级/重试）、窄容器、深色主题 |
| 不支持 | 多图表/复杂图表（04 图表卡）、工作台卡片容器与编辑（布局/工作台页）、聚合口径实现（后端）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 组件分层：`StatCard` 展示、`useStat` 格式化/趋势/动画；迷你趋势图复用 `EChart`（可选）
- □ 数值：格式化分发（number/amount/percent/custom）、单位/前缀、精度、空值 `—`
- □ 趋势：环比/同比方向箭头与文案、状态色（`higherIsBetter` 反转、令牌变量）、口径 `caption`
- □ 交互：`linkTo` 跳转/`click`、加载态、刷新、数字动画（reduced-motion）
- □ 迷你趋势图：无坐标轴/图例、视口懒渲染、resize 自适应、无数据不渲染
- □ 权限（数据来源/跳转）、i18n（标题/单位/文案/格式化，不翻译数据）、移动端（Vant，口径同源）符合第 8 节
- □ 性能：短缓存、并行取数、卡片级降级、动画一次
- □ 三项上游登记已确认：统计卡指标结构与趋势/环比、卡片规格与数值标注、趋势色与可达性
