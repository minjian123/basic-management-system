## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **大屏设计器与播放**的组件设计：总容器 `ScreenDesigner.vue`（工具栏 + 三区 + 多页管理），组件面板 `ComponentPanel.vue`，自由画布 `ScreenCanvas.vue`（绝对定位、拖拽、缩放、对齐吸附、层级），属性面板 `ScreenPropertyPanel.vue`（位置/尺寸/样式/数据源），播放器 `ScreenPlayer.vue`（全屏、轮播切页、数据刷新），以及组合式函数 `useScreenDesigner.ts`（组件模型、画布坐标、`canvas_config` 序列化、保存发布）。适用于**报表中心**的可视化大屏设计（PC 管理端）与**大屏播放**（独立路由）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**报表中心**模块「可视化大屏（自由画布设计器 + 轮播播放）」；上游设计依据[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（`rpt_screen`、大屏设计器与播放、权限）与[《架构设计 · 报表BI》](../../../架构设计/19_架构设计_子系统_报表BI.md)（大屏自由画布）、[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)（`vue-flow` 自由画布选型，与 gridstack/vuedraggable 三者分工）；协作节点为[05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)（大屏内图表渲染复用 `EChart` 与主题）、[05 展示类 01 通用表格](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)（数据表组件）、[03_交互类 09 报表设计器](../08_组件设计_报表设计器/08_组件设计_报表设计器.md)（数据集/取数与 `chart_config` 口径复用）、[03_交互类 01 弹窗抽屉表单](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（删除/发布确认）、[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)、[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`rpt:design`/`rpt:view`）。

> 本篇为组件设计体系交互类第 10 篇。**范围边界**：**数据集 SQL 与取数**归[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（大屏组件数据源复用数据集接口）；**图表渲染内核**归 [05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)；**网格报表排版**（gridstack）归 [03_交互类 09 报表设计器](../08_组件设计_报表设计器/08_组件设计_报表设计器.md)，本节点为**自由画布**（vue-flow），二者不混用；移动端不提供大屏设计器与播放（见第 11 节）。

| `useScreenDesigner.ts` | `src/utils/useScreenDesigner.ts` | 组合式函数：画布配置（分辨率/背景/主题）、组件模型、多页、选择与坐标、`canvas_config` 序列化、保存发布、脏数据基线 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，大屏归 `screen-designer/`；组合式函数放 `src/utils/`）。
- **技术分工**：`vue-flow`（自由画布，本节点）· `gridstack`（网格布局，报表设计器/工作台）· `vuedraggable`（列表排序，表单设计器）——三者**互不混用**（[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)「技术要点」节）。

## 3. 总体结构 <a id="structure"></a>

```mermaid
flowchart LR
    TB["工具栏：新建 / 打开 / 保存 / 发布 / 预览播放 / 多页管理 / 标尺网格"]
    CP["组件面板（左）<br/>图表 / 数据表 / 指标卡 / 文本 / 图片 / 时间 / 装饰"]
    CV["自由画布（中）<br/>vue-flow · 绝对定位 · 拖拽/缩放 · 对齐吸附 · 层级"]
    PP["属性面板（右）<br/>位置尺寸 / 样式 / 数据源 / 层级"]
    TB --> CP --- CV --- PP
```

| 区域 | 内容 |
| --- | --- |
| 工具栏 | 新建、打开、保存（草稿）、`发布`、预览播放、多页管理（增删/排序/设默认页）、标尺与网格开关 |
| 组件面板（左） | 组件分类（图表/数据表/指标卡/文本/图片/时间/装饰），点击或拖放到画布创建 |
| 自由画布（中） | 绝对定位组件；拖拽移动、右下角缩放、对齐辅助线吸附、层级调整；画布缩放/平移；标尺 |
| 属性面板（右） | 选中组件的坐标/尺寸/样式/数据源/层级；未选中时显示大屏级配置（分辨率/背景/主题） |

## 4. 画布与坐标系 <a id="canvas"></a>

| 项 | 设计 |
| --- | --- |
| 画布尺寸 | 大屏配置的分辨率（如 1920×1080），绝对坐标系（px）；设计态按容器宽度等比缩放显示（缩放比不影响坐标值） |
| 承载 | `vue-flow`（`@vue-flow/core`，绝对定位节点 + 缩放平移 + 连线能力预留），与网格报表严格区分 |
| 对齐与吸附 | 拖动时显示对齐辅助线（上/下/左/右/居中/等距），接近时吸附；网格可选 |
| 层级 | 组件的 z-index 顺序（上移/下移/置顶/置底）；属性面板可调 |
| 多选与组合 | 支持框选多选、对齐/分布；分组（可选） |
| 坐标序列化 | 组件 `{x, y, w, h, z}` 存 `canvas_config`；设计态缩放仅显示层，不写入坐标 |
| 自适应播放 | 播放时按目标屏幕等比缩放（contain/cover），保证任意分辨率下不变形 |

## 5. 组件库与组件模型 <a id="components-model"></a>

| 组件类型 | 说明 | 数据源 |
| --- | --- | --- |
| 图表 | ECharts 图表（折线/柱/饼/环/散点/漏斗/雷达/仪表盘/地图），复用 [05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 的 `EChart`/`chartTheme` | 数据集 + `chart_config` |
| 数据表 | 只读数据表（滚动/轮播行），复用 [05 展示类 01 通用表格](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md) | 数据集 |
| 指标卡 | 单指标大数字 + 单位 + 环比/同比 | 数据集聚合（数据集承担聚合） |
| 文本 | 标题/说明文本（可富文本） | 静态/接口（可选） |
| 图片 | 图片/Logo/背景（对象存储 URL） | 文件管理 |
| 时间 | 当前时间/日期（按租户时区） | 系统 |
| 装饰 | 边框/背景/分隔（纯样式） | 静态 |

```typescript
interface ScreenCanvasConfig {
  width: number; height: number;            // 分辨率
  background: string;                       // 背景（颜色/图片）
  theme: 'light' | 'dark' | 'auto';         // 主题
  pages: ScreenPage[];                      // 多页（轮播）
}
interface ScreenPage {
  id: string; name: string;
  components: ScreenComponent[];
}
interface ScreenComponent {
  id: string; type: ScreenComponentType;    // chart/table/metric/text/image/time/decor
  x: number; y: number; w: number; h: number; z: number;
  datasetId?: string; chartConfig?: Record<string, any>;  // 图表/表格/指标
  props?: Record<string, any>;              // 样式与文案
}
```

- `canvas_config` 存 `rpt_screen.canvas_config`（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)「数据模型」节）；图表配置与数据集取数口径与[03_交互类 09 报表设计器](../08_组件设计_报表设计器/08_组件设计_报表设计器.md)一致。

## 7. 多页与轮播播放 <a id="player"></a>

| 项 | 设计 |
| --- | --- |
| 多页 | 大屏可定义多页（页 = 一组组件），支持增删/排序/设默认页；播放时轮播切页 |
| 轮播 | 按配置间隔定时切页（可设单页停留时长）；支持手动上下页、暂停 |
| 播放入口 | 独立路由（`/screen/play/{code}`，默认需 `rpt:view`）；全屏播放、隐藏设计工具栏 |
| 自适应 | 按目标屏幕等比缩放（contain），保持设计分辨率比例 |
| 数据刷新 | 各组件数据源可按配置定时刷新（对齐 [05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 轮询口径，页面不可见暂停） |
| 权限 | 播放默认需权限（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)「业务规则」节） |
| 降级 | 数据集停用/取数失败：单组件降级占位，不阻断整屏（复用 [05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 状态口径） |

## 8. 组合式函数 useScreenDesigner <a id="use-designer"></a>

```typescript
interface UseScreenDesignerOptions { screenId?: string; onSaved?: () => void; onPublished?: () => void; }
interface UseScreenDesignerReturn {
  config: Ref<ScreenCanvasConfig>;
  page: Ref<ScreenPage | null>;            // 当前页
  selected: Ref<ScreenComponent | null>;
  zoom: Ref<number>;
  dirty: ComputedRef<boolean>;
  loading: Ref<boolean>; saving: Ref<boolean>;
  addComponent: (type) => void;
  updateComponent: (patch) => void;
  removeComponent: (id) => void;
  reorderLayer: (id, action) => void;
  addPage / removePage / setPage / reorderPage;
  save: () => Promise<void>;
  publish: () => Promise<void>;
}
```

| 行 | 设计 |
| --- | --- |
| 模型 | `config`（分辨率/背景/主题/多页）+ 当前 `page` + `selected`；组件增删改与层级调整只改本地 |
| 坐标 | 设计态显示缩放（`zoom`）与组件实际坐标解耦；拖拽/缩放时换算为设计坐标写入 |
| 序列化 | 保存时打包 `canvas_config`（多页 + 组件 + 位置尺寸 + 数据源）写 `rpt_screen` |
| 脏数据 | 打开时 `stableStringify`（[07 基础类 03 格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）记基线；比对得 `dirty` |
| 错误 | 数据集停用（90001）、执行超时/从库不可用（90003）、结果超限（90005）、限流（90006）按码提示（i18n） |

## 11. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：设计需 `rpt:design`；播放默认需 `rpt:view`（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)）；取数沿用动作级数据范围（[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；后端 `require_permission` 兜底。
- **i18n**：界面文案、校验与错误码（`error.900xx`）走 vue-i18n；文本组件内容/大屏名称可多语言；时间组件按租户时区（[07 基础类 03 格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；**不翻译用户数据**。
- **移动端**：**不提供**大屏设计器与播放（大屏为宽屏场景）；移动端报表查看归移动端工程。

## 12. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 分包 | 设计器/播放器与 vue-flow/ECharts 独立分包懒加载，不进首屏主包 |
| 多组件渲染 | 图表组件视口内按需初始化、离屏不渲染（复用 [05 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) `lazy`）；缩放/拖拽结束才 `resize()` |
| 取数 | 组件数据源限深/限流/只读从库；定时刷新受页面可见性约束；同数据集多组件合并请求（可选） |
| 播放 | 轮播切页时只渲染当前页组件，非当前页暂停；全屏高分屏按 devicePixelRatio 渲染 |
| 边界 | 数据集停用（90001）、超时/从库不可用（90003）、超限（90005）、限流（90006）、组件越界/重叠（允许重叠但给层级）、空大屏、单组件降级、播放无权限、缩放失真、脏数据拦截 |
| 不支持 | 数据集 SQL/取数（后端）、图表渲染内核（05 展示类 04 图表卡）、网格报表（06 交互类 09 报表设计器）、移动端大屏 |

## 13. 检查清单 <a id="checklist"></a>

- □ 组件分层：`ScreenDesigner` 装配与工具栏、`ComponentPanel` 组件源、`ScreenCanvas` 自由画布、`ScreenPropertyPanel` 属性、`ScreenPlayer` 播放、`useScreenDesigner` 状态与提交，职责不重叠
- □ 画布：绝对定位、拖拽/缩放、对齐吸附、层级、缩放平移、标尺；与 gridstack/vuedraggable 不混用
- □ 组件库：图表/数据表/指标卡/文本/图片/时间/装饰；图表复用 `EChart`/主题；数据源复用数据集口径
- □ 属性面板：位置尺寸/层级/样式（令牌）/数据源；画布级分辨率/背景/主题/多页
- □ 多页与播放：多页增删排序、轮播定时/手动、全屏、自适应缩放、数据刷新、独立路由与权限、单组件降级
- □ 保存/发布：`canvas_config` 序列化、`Idempotency-Key`、脏数据拦截、错误码（900xx）
- □ 权限（`rpt:design`/`rpt:view`/数据范围）、i18n（文案/错误码/时间）、移动端（不提供）符合第 11 节
- □ 性能边界：独立分包、视口按需渲染、resize 防抖、取数限流限深、轮播只渲染当前页
- □ 三项上游登记已确认：大屏设计器交互与 `canvas_config` 结构、播放口径与自适应、大屏前端选型与分包
