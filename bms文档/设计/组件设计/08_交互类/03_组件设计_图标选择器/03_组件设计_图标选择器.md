## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **图标选择与渲染**的组件设计：图标选择器 `IconPicker.vue`（搜索、分类、网格、最近使用、已选预览）、只读渲染器 `IconDisplay.vue`（按 icon key 统一解析渲染）、图标清单管理 `IconLibrary.vue`（浏览/搜索/复制、租户自定义图标增删改启停与引用检查），以及图标注册表 `iconRegistry.ts`（内置清单、动态解析、分类与搜索、最近使用、自定义图标缓存）。适用于**菜单图标**、**首页工作台快捷入口/卡片图标**、**帮助/公告分类图标**与**图标清单管理页**（PC 管理端）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)技术选型（`@element-plus/icons-vue`）；视觉与来源依据[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)「图标与图片」节（PC 用 `@element-plus/icons-vue`、业务图标自绘放 `src/assets/icons/`、图标尺寸随字号 14/16/20px）；上游设计依据[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（`sys_menu.icon` 字段与菜单维护）、[《概要设计 · 首页工作台》](../../../概要设计/35_概要设计_首页工作台.md)（快捷入口/卡片图标）；协作节点为[文件上传字段](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（自定义图标 SVG 上传）、[富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)（SVG 清洗口径参照）、[弹窗抽屉表单](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（自定义图标编辑弹窗）、[通用表格](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)（清单/引用表格）、[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（自定义图标取数）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`icon:manage`）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（搜索归一）。

> 本篇为组件设计体系交互类第 04 篇。**范围边界**：图标**资源本身**（Element Plus 官方图标、业务自绘 SVG）由官方库与 `src/assets/icons/` 提供，本节点只负责**选取、解析渲染与清单管理**；SVG 上传的存储/分片归 [文件上传字段](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)；SVG 内容安全清洗属后端与渲染方（参照 [富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)白名单净化口径）；菜单/卡片的其他字段维护归各自页面；移动端不复用 PC 组件（见第 10 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `IconPicker.vue` | `src/components/icon/` | 图标选择器：弹层、关键词搜索、分类 Tab、图标网格、hover 名称、已选预览、最近使用、清除与校验 |
| `IconDisplay.vue` | `src/components/icon/` | 只读渲染器：按 icon key 动态解析 Element Plus / 业务自绘 / 租户自定义图标并渲染，未知 key 降级 + 告警 |
| `IconLibrary.vue` | `src/components/icon/` | 图标清单管理：内置/业务/自定义图标浏览与搜索、复制 icon key、引用计数；租户自定义图标新增（上传 SVG）/编辑/启停/删除（引用检查） |
| `iconRegistry.ts` | `src/utils/iconRegistry.ts` | 图标注册表：内置清单（El 图标 + 业务 manifest）、动态解析 `resolve()`、分类 `groups()`、搜索 `search()`、最近使用缓存、自定义图标注册与缓存、Key→组件/SVG 映射 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、工具函数 camelCase；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，图标归 `icon/`；工具放 `src/utils/`）。
- 所有渲染图标的入口统一走 `IconDisplay`（或 `iconRegistry.resolve()`），避免各处各自 import 图标；尺寸统一走设计令牌（14/16/20px，[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)）。

## 3. 图标清单与取值格式 <a id="registry"></a>

### 3.1 icon key 取值格式 <a id="icon-key"></a>

统一以**带前缀的 icon key** 标识图标来源，避免多来源同名冲突：

| 来源 | 前缀 | 格式 | 示例 | 载体 |
| --- | --- | --- | --- | --- |
| Element Plus 官方 | `el:` | `el:{PascalCase}` | `el:User`、`el:Setting` | `@element-plus/icons-vue`（PC） |
| 业务自绘（随代码发布） | `biz:` | `biz:{kebab-case}` | `biz:purchase-order`、`biz:receipt` | `src/assets/icons/*.svg` + manifest |
| 租户自定义（运行时） | `custom:` | `custom:{id}` | `custom:1024` | 后端 `sys_icon`（SVG），见登记项① |
| 移动端 Vant（仅移动端） | `van:` | `van:{name}` | `van:todo-o` | Vant 图标（frontend-mobile，不共用 PC 选择器） |

- 存储到业务的字段（如 `sys_menu.icon`、卡片配置）一律存**完整 icon key**；渲染时 `iconRegistry.resolve()` 解析来源与组件。
- **兼容**：历史裸名（无前缀，如 `User`）在解析时按 `el:` 处理并给出开发环境告警，便于平滑迁移（登记项②）。

### 3.2 注册与解析 <a id="registry-resolve"></a>

```mermaid
flowchart TD
    A["icon key"] --> B{"前缀"}
    B -->|"el:"| C["ElementPlusIconsVue[Name] 组件"]
    B -->|"biz:"| D["manifest 懒加载 SVG（import.meta.glob）"]
    B -->|"custom:"| E["自定义图标缓存（接口拉取 + localStorage）"]
    B -->|"van:"| F["Vant 图标（移动端）"]
    B -->|"无前缀/未知"| G["按 el: 兜底（开发告警）→ 仍未知则降级问号图标"]
```

- 内置 El 图标清单在构建期由 `@element-plus/icons-vue` 提供（**按需引入 + 图标选择独立分包懒加载**，见登记项④）。
- 业务自绘图标通过 `import.meta.glob('../assets/icons/*.svg', { eager: false })` 生成清单，**默认懒加载**，只在被解析或被清单页浏览时加载。
- 自定义图标由接口拉取（列表 + SVG 内容/URL），注册表缓存（内存 + localStorage，带版本失效）；解析失败/已删除 → 降级问号图标并告警。

## 4. 图标选择器 IconPicker <a id="picker"></a>

### 4.1 Props / 事件 / 插槽 <a id="picker-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | null | 选中的 icon key（`el:`/`biz:`/`custom:`） |
| `size` | 'small' \| 'default' \| 'large' | 'default' | 触发框尺寸（对齐表单控件尺寸） |
| `placeholder` | string | '选择图标' | 占位文案（i18n） |
| `clearable` | boolean | true | 是否可清除 |
| `disabled` | boolean | false | 禁用（字段权限 `editable=false` 时由表单传 disabled） |
| `categories` | string[] \| null | null | 限定分类（如仅 `menu` 可用集合）；缺省展示全部 |
| `includeCustom` | boolean | true | 是否包含租户自定义图标 |
| `recentCount` | number | 12 | 最近使用展示数量（0 = 不展示） |
| `teleported` | boolean | true | 弹层挂载 body（抽屉/弹窗内避免裁剪） |
| `trigger` | 'input' \| 'button' | 'input' | 触发形态：输入框（表单内）/ 按钮（工具栏） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string \| null | 选中/清除同步 |
| `change` | string \| null | 值变化（含清除） |

| 插槽 | 说明 |
| --- | --- |
| `trigger` | 自定义触发元素（`trigger='button'` 时） |
| `footer` | 弹层底部附加（如「管理图标」入口，持 `icon:manage` 时链接到 `IconLibrary`） |

- 暴露方法：`open()`、`close()`、`clear()`。

### 4.2 交互与形态 <a id="picker-interaction"></a>

| 项 | 设计 |
| --- | --- |
| 展开 | 点击触发框打开弹层（`el-popover`/`el-dialog`，`teleported`）；弹层含搜索框、分类 Tab、图标网格、最近使用 |
| 搜索 | 关键词按 **icon key/名称** 归一匹配（小写、去前缀、支持 kebab）返回结果；输入防抖 200ms；无结果空态 |
| 分类 | 分类 Tab（如「全部 / 菜单常用 / 方向 / 编辑 / 媒体 / 业务 / 自定义」）；分类由注册表 `groups()` 提供，可由 `categories` 限定 |
| 网格 | 图标网格（每行 8-10 个），hover 显示图标名 tooltip，点击选中并关闭；当前选中高亮 |
| 已选预览 | 触发框内显示图标 + icon key（可选）；弹层顶部展示「已选」 |
| 最近使用 | 按用户记录最近 N 个（localStorage，用户维度）；数量与是否展示由 `recentCount` 控制 |
| 清除 | 允许清除（`clearable`），清除后值为 null |
| 校验 | 表单校验规则 `icon` 校验 icon key 可解析；非法/未知 key 提示「图标不可用」 |
| 目录来源 | 候选来自 `iconRegistry`（内置 + 业务 + 自定义），自定义按 `includeCustom` 决定是否出现 |

### 4.3 列表/工具栏场景 <a id="picker-inline"></a>

- 菜单树内联编辑图标时用 `size='small'`；工具栏筛选/批量场景可用 `trigger='button'`。

## 5. 只读渲染器 IconDisplay <a id="display"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `name` | string \| null | null | icon key（`el:`/`biz:`/`custom:`） |
| `size` | number \| string | 16 | 尺寸（数字 px）；缺省按场景（内联 14、菜单 16、按钮 20） |
| `color` | string \| null | null | 颜色（缺省继承 `currentColor`，用 CSS 变量） |
| `spin` | boolean | false | 旋转（加载态） |
| `fallback` | string | 'QuestionFilled' | 解析失败时的兜底图标（El 图标名） |

- **渲染策略**：`el:` → 动态组件（El 图标组件）；`biz:` → 懒加载 SVG 组件；`custom:` → 内联 SVG（运行时内容，经安全清洗）；未知 → `fallback` + 开发环境告警一次（同名去重）。
- **嵌入位置**：菜单项、按钮前置图标、卡片标题、状态/列表单元格、快捷入口宫格；全部走本组件，保证多来源图标**统一尺寸、颜色与降级**。
- **无 name 时不渲染**（不占位）；`color` 一律用设计令牌变量，不硬编码。

## 6. 图标清单管理 IconLibrary <a id="library"></a>

### 6.1 清单浏览 <a id="library-browse"></a>

| 项 | 设计 |
| --- | --- |
| 来源分组 | 「平台图标」（`el:`）、「业务图标」（`biz:`）、「自定义图标」（`custom:`）分组展示，可切换 |
| 搜索/分类 | 关键词搜索 + 分类筛选；结果网格展示（名称 + 预览 + 来源标签） |
| 复制 key | 点击「复制 icon key」，便于配置菜单/卡片时粘贴 |
| 引用计数 | 展示该图标被菜单/卡片等引用次数（可选，数据来自引用扫描；点击查看引用明细） |
| 只读范围 | 平台/业务图标随代码维护，管理页**只读浏览**（新增/修改走发布流程） |

### 6.2 自定义图标管理（租户级） <a id="library-custom"></a>

| 操作 | 行为 | 权限 |
| --- | --- | --- |
| 新增 | 上传 SVG + 填写名称（icon key 的 kebab 段）/分类/标签 + 预览 → 保存（`custom:{id}`） | `icon:manage` |
| 编辑 | 修改名称/分类/标签、替换 SVG | `icon:manage` |
| 启停 | 停用后不在选择器候选与渲染清单中出现（已引用的按降级处理） | `icon:manage` |
| 删除 | **引用检查**：被菜单/卡片引用时提示先解除引用或用「停用」代替（不可直接删除） | `icon:manage` |

- **上传要求**：仅 SVG（类型白名单）、大小上限（如 100KB）；**SVG 内容安全清洗**（移除 script/事件属性/外链，参照 [富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)白名单净化口径），后端存储前清洗、前端内联渲染前再清洗（双向）。
- **名称与 i18n**：自定义图标名称支持多语言（登记项①附表 `sys_icon_i18n`，可选），列表按 locale 展示。
- **编辑弹窗**复用 [弹窗抽屉表单](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)表单对话框；列表/引用用 [通用表格](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)。

## 7. 注册表 iconRegistry <a id="registry-api"></a>

```typescript
interface IconMeta {
  key: string;              // 完整 icon key（el:/biz:/custom:）
  name: string;             // 展示名（El 图标为组件名，自定义为名称）
  source: 'el' | 'biz' | 'custom' | 'van';
  category?: string;        // 分类
  tags?: string[];          // 标签（搜索用）
}

interface IconRegistry {
  resolve(key: string | null): ResolvedIcon | null;   // { type, component|svg, meta }
  groups(): { key: string; label: string; count: number }[];
  search(keyword: string, opts?: { category?: string; includeCustom?: boolean }): IconMeta[];
  recent(): IconMeta[];                               // 最近使用
  pushRecent(key: string): void;
  loadCustom(): Promise<void>;                        // 拉取并缓存自定义图标
  registerCustom(list: IconMeta[]): void;
}
```

| 行 | 设计 |
| --- | --- |
| 内置清单 | El 图标清单（构建期生成）+ 业务图标 manifest（`import.meta.glob`，懒加载） |
| 自定义清单 | 运行时拉取（`GET /api/v1/icons`），缓存 + 版本失效；登录后/进入列表页时加载 |
| 解析缓存 | `key → ResolvedIcon` 内存缓存；未知 key 缓存降级结果并**告警一次** |
| 最近使用 | localStorage 按用户存储，去重、上限（默认 24），写入防抖 |
| 搜索 | 归一（小写、去前缀、kebab/Pascal 互转）+ 名称/标签匹配；大清单先在注册表层过滤再渲染 |

## 8. 场景集成 <a id="scenes"></a>

| 场景 | 用法 | 说明 |
| --- | --- | --- |
| 菜单管理（`sys_menu.icon`） | `IconPicker`（`categories=['menu']`） | 选了 key 存库，菜单树用 `IconDisplay` 渲染（[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)） |
| 首页工作台快捷入口/卡片 | `IconPicker` + `IconDisplay` | 快捷入口宫格图标、卡片标题图标 |
| 帮助/公告分类 | `IconPicker` | 分类图标维护 |
| 图标清单管理页 | `IconLibrary` | 浏览/搜索/复制；自定义图标增删改启停 |
| 表单定制字段属性 | `IconPicker`（可选） | 字段只读展示形态的图标（若启用） |
| 移动端 | Vant 图标（`van:`） | 不复用 PC 选择器与渲染器；同源 icon key 口径，配置侧仍存 `el:`/`biz:` 时移动端做映射或降级 |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：图标清单浏览登录即可；自定义图标的新增/编辑/启停/删除需 `icon:manage`（按钮用 `v-perm` 显隐）；`IconPicker` 的「管理图标」入口按权限显示（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；SVG 上传与清洗由后端兜底。
- **i18n**：图标分类名、按钮、占位、空态、告警文案走 vue-i18n；`el:` 图标名不翻译（专有名）；`biz:`/`custom:` 图标名称按 locale 下发（`sys_icon_i18n`，可选）；搜索支持中文别名（标签）。
- **移动端**：不复用 PC `IconPicker`/`IconDisplay`；移动端用 Vant 图标（`van:`）与内联 SVG 渲染；配置侧 icon key 在移动端做**映射或降级**（`el:`/`biz:` 映射到相近 Vant 图标或自绘 SVG）；移动端不做清单管理页。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 图标数量 | El 图标约 300+，网格按可视区分片/虚拟滚动渲染；搜索在注册表层过滤（O(n) 字符串匹配）后再渲染 |
| 分包 | 全量图标库仅图标选择器/清单页需要 → 独立分包懒加载；常规页面只按名引用的图标随业务分包 |
| 业务 SVG | `import.meta.glob` 懒加载，仅在解析或浏览时加载对应 SVG，不一次性进主包 |
| 自定义图标 | 接口拉取 + 内存/localStorage 缓存（版本失效）；不在每次渲染请求 |
| 渲染缓存 | `key → 组件` 解析结果缓存；未知 key 降级结果缓存并去重告警 |
| 搜索 | 输入防抖 200ms；归一化（小写、去前缀、kebab/Pascal 互转） |
| 边界 | 未知 key（降级 + 告警）、已停用/删除的自定义图标（引用处降级问号）、无搜索结果（空态）、同名冲突（前缀区分）、历史裸名（按 `el:` 兼容）、清除后为 null、SVG 超限/含脚本（拒绝 + 清洗）、最近使用超限（裁剪）、`teleported` 在抽屉内的层级 |
| 不支持 | 引入 iconify 等外部多图标库（离线/体积成本）、运行时图标代码编辑、移动端清单管理 |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：`IconPicker` 选取、`IconDisplay` 只读渲染、`IconLibrary` 清单管理、`iconRegistry` 解析与缓存，职责不重叠
- □ icon key 格式统一（`el:`/`biz:`/`custom:`/`van:`），存储存完整 key；历史裸名按 `el:` 兼容并告警
- □ 选择器：搜索（防抖/归一）、分类 Tab、网格（分片/虚拟滚动）、hover 名称、已选预览、最近使用、清除、校验、`teleported`
- □ 渲染器：多来源解析、统一尺寸（14/16/20）与令牌颜色、未知 key 降级问号 + 去重告警、无 name 不渲染
- □ 清单管理：来源分组、搜索/分类、复制 key、引用计数；自定义图标增删改启停 + **引用检查** + SVG 白名单/大小/双向清洗
- □ 注册表：内置清单 + 业务 manifest 懒加载 + 自定义缓存（版本失效）、解析缓存、最近使用用户维度
- □ 权限（`icon:manage`）、i18n（分类/文案/名称多语言，El 图标名不翻译）、移动端（Vant 图标 + 映射/降级）符合第 10 节
- □ 性能边界：图标选择独立分包、业务 SVG 懒加载、自定义图标缓存、搜索防抖、未知/失效 key 降级
- □ 四项上游登记已确认：icon key 与自定义图标管理（`sys_icon`/`icon:manage`）、设计令牌图标取值口径、命名规范 icon key、前端图标引入与分包
