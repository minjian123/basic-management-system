## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **代码/表达式编辑器**的组件设计：通用内核封装 `CodeEditor.vue`（CodeMirror 6）、SQL 编辑器 `SqlEditor.vue`、表达式编辑器 `ExpressionEditor.vue`、cron 编辑器 `CronEditor.vue`、只读代码高亮 `CodeViewer.vue`，以及组合式函数 `useCodeEditor.ts`（实例、语言包加载、校验、格式化、值同步）。适用于**报表数据集 SQL 建模**、**工作流网关条件表达式**、**动作数据范围规则表达式**、**任务调度 cron**，以及**只读代码/JSON 查看**（日志、任务参数、Webhook 载荷、配置）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)技术选型（新增 CodeMirror 6；PrismJS 用于代码高亮）；上游设计依据[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（数据集 SQL 建模、安全校验、测试执行、字段清单）、[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)（网关条件分支表达式）、[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)与[《架构设计 · 权限计算引擎》](../../../架构设计/11_架构设计_子系统_权限计算引擎.md)（数据范围规则表达式：字段 + 运算符 + 预置变量）、[《概要设计 · 任务调度》](../../../概要设计/23_概要设计_任务调度.md)（5 段 cron 与校验）、[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)（按需懒加载与分包）；协作节点为[富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)（富文本内代码块高亮，PrismJS 同源）、[弹窗抽屉表单](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（编辑器常置于表单/抽屉内）、[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（校验与测试执行）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（设计类权限码）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（文本工具）。

> 本篇为组件设计体系交互类第 05 篇。**范围边界**：**表达式/SQL/cron 的语法与执行语义在后端**（校验、编译、只读从库执行、cron 计算），本节点只负责**前端编辑体验与校验调用**；报表设计器（拖拽 ECharts）、大屏画布、流程建模画布分别归各自设计器；富文本正文编辑归 [富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)；移动端不提供代码编辑（见第 12 节）。

## 3. 内核与选型 <a id="kernel"></a>

| 项 | 设计 |
| --- | --- |
| 编辑内核 | **CodeMirror 6**（`@codemirror/*` + 语言包）：模块化、体积可控、按需语言、易接令牌主题、支持行号/括号/搜索/折叠；**独立分包懒加载** |
| 语法包 | `@codemirror/lang-sql`、`lang-json`、`lang-javascript`；表达式使用轻量自定义高亮（关键词/变量/运算符）或复用 SQL/JS 词法 |
| 只读高亮 | `CodeViewer` 用 **PrismJS**（项目已选，[《项目规划说明》](../../../../规划/项目规划说明.md)技术栈）——只读不需编辑内核，更轻；与 [富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)代码块高亮同源 |
| 不采用 | Monaco Editor：功能强但体积大（数 MB、多 worker），与前端性能预算/离线分包要求不符；轻量 textarea 方案无补全/行号等编辑体验，故编辑用 CM6、只读用 Prism |
| 主题 | 编辑器主题由 `useCodeEditor` 读取设计令牌（背景/文字/关键字/字符串/注释色）生成，随深浅模式/租户品牌变化重建 |
| 分包 | CM6 与语言包仅在打开编辑器时动态 `import()`；`SqlEditor`/`ExpressionEditor`/`CronEditor` 按路由/组件懒加载，不进首屏主包（登记项④） |

## 4. 通用契约 CodeEditor <a id="code-editor"></a>

### 4.1 Props / 事件 / 插槽 <a id="code-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string | '' | 编辑内容（`v-model`） |
| `language` | 'sql' \| 'expression' \| 'json' \| 'javascript' \| 'text' | 'text' | 语言（决定高亮与提示） |
| `readonly` | boolean | false | 只读（设计字段只读/查看态） |
| `height` | number \| string | 240 | 编辑区高度 |
| `lineNumbers` | boolean | true | 行号 |
| `placeholder` | string | '' | 占位（i18n） |
| `lint` | boolean | false | 是否启用校验（语法/业务规则） |
| `lintDelay` | number | 500 | 校验防抖（ms） |
| `indentUnit` | number | 2 | 缩进空格数 |
| `theme` | 'auto' \| 'light' \| 'dark' | 'auto' | 主题（`auto` 跟随全局） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string | 值变化 |
| `validate` | `{ ok, errors: {line, message}[] }` | 校验结果（内联标注 + 事件） |
| `ready` | 编辑器实例 | 初始化完成 |

| 插槽 | 说明 |
| --- | --- |
| `toolbar` | 工具栏（格式化、测试执行、插入片段等，按子组件定制） |
| `footer` | 底部（校验汇总、字段清单、结果预览等） |

- 暴露方法：`focus()`、`getValue()`、`setValue(v)`、`format()`、`insertSnippet(text)`、`getSelection()`。

### 4.2 交互约定 <a id="code-interaction"></a>

- **值同步**：内部编辑 → `update:modelValue`；外部 setValue 不触发校验风暴。
- **校验**：`lintDelay` 防抖后调用校验（前端轻校验 + 后端接口），结果以内联标记（波浪线/行标）+ `footer` 汇总展示；错误行点击可定位。
- **格式化**：SQL 走格式化器（前端或后端）后 `setValue`，保留历史（撤销栈）。
- **主题**：跟随全局主题/租户品牌；切换时重建编辑器（保留内容与光标位置）。
- **只读**：`readonly=true` 禁用编辑但可选中/复制/搜索。

## 5. SQL 编辑器 SqlEditor <a id="sql"></a>

| 项 | 设计 |
| --- | --- |
| 高亮/编辑 | 基于 `CodeEditor language='sql'`；行号、括号匹配、关键字/表名/字符串高亮 |
| 格式化 | `format()` 调用 SQL 格式化（前端 formatter 或后端接口）；保留注释与参数 |
| 前端轻校验 | 语句类别快速判断（**仅 SELECT** 提示），非法即内联警示；**以服务端校验为准**（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)「安全校验」节） |
| 服务端校验 | 调校验接口（登记项②）返回语法/白名单/字段错误（错误码 90002），内联标注 |
| 测试执行 | `POST /rpt/datasets/{id}/test`（只读从库、限时）：展示结果集预览 + 耗时；超时/从库不可用按错误码提示（90003） |
| 字段清单 | 确认后展示返回字段（fields 声明），支持复制列名；未声明字段禁止返回（90005 超限同理） |
| 参数 | 支持 `:param` 参数化（防注入）；参数区由页面提供 |
| 工具栏 | 格式化 / 校验 / 测试执行（按 `rpt:design` 显隐） |

## 6. 表达式编辑器 ExpressionEditor <a id="expression"></a>

| 项 | 设计 |
| --- | --- |
| 语法 | 表达式 = **字段 + 运算符 + 预置变量**（[《架构设计 · 权限计算引擎》](../../../架构设计/11_架构设计_子系统_权限计算引擎.md)「数据范围」节），如 `dept_id = @current_dept AND status = 1`；预置变量（`@current_user`/`@current_dept`/`@tenant` 等）由后端下发定义 |
| 变量/字段面板 | 侧栏或下拉列出可用**字段**与**预置变量**，点击插入到光标处；来源随场景（数据范围→动作关联实体字段；工作流条件→实例业务字段/流程变量） |
| 运算符/函数提示 | 支持运算符（`= != > < >= <= IN LIKE AND OR NOT` 等）与常用函数提示，插入片段 |
| 模板 | 常用表达式模板（如「本部门」「本部门及下级」「本人」），一键插入 |
| 校验 | 调表达式校验接口（登记项③）返回语法/字段/变量错误，内联标注；保存时后端二次强制校验 |
| 场景 | 动作数据范围规则（[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)）、工作流网关条件（[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)） |

## 7. Cron 编辑器 CronEditor <a id="cron"></a>

| 项 | 设计 |
| --- | --- |
| 段结构 | 标准 **5 段**：分 / 时 / 日 / 月 / 周；每段支持输入（`*`、`a-b`、`a,b`、`*/n`）与常用值选择 |
| 人类可读描述 | 实时生成自然语言描述（i18n），如「每周一 09:00」；随段编辑即时更新 |
| 常用模板 | 每分钟 / 每小时 / 每天 0 点 / 每周一 / 每月 1 日 等一键套用 |
| 校验 | 合法性校验（错误码 70002 cron 非法），非法段内联提示 |
| 下次执行 | 可选展示下次执行时间（后端计算或前端轻量推算，避免误算以服务端为准） |
| 集成 | 常置于任务编辑弹窗（[弹窗抽屉表单](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)）内，随表单提交 |

## 9. 组合式函数 useCodeEditor <a id="use-code-editor"></a>

```typescript
interface UseCodeEditorOptions {
  language?: string;
  readonly?: boolean;
  theme?: 'auto' | 'light' | 'dark';
  lint?: boolean;
  lintDelay?: number;
  onValidate?: (result: ValidateResult) => void;
  validateFn?: (value: string) => Promise<ValidateResult>;  // 场景校验（SQL/表达式/cron）
}

interface UseCodeEditorReturn {
  host: Ref<HTMLElement | null>;
  ready: Ref<boolean>;
  value: Ref<string>;
  errors: Ref<{ line: number; message: string }[]>;
  setValue: (v: string) => void;
  getValue: () => string;
  format: () => Promise<void>;
  insertSnippet: (text: string) => void;
  validate: () => Promise<ValidateResult>;
  focus: () => void;
  dispose: () => void;
}
```

| 行 | 设计 |
| --- | --- |
| 实例 | 动态 `import()` CodeMirror 6 与语言包后创建；卸载 `dispose()` 释放 |
| 校验 | `lintDelay` 防抖调 `validateFn`（走 [请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)），结果转 CM6 诊断标注 |
| 主题 | 读设计令牌生成主题；监听全局主题/租户变化重建 |
| 值同步 | 与组件 `modelValue` 双向同步，避免循环触发 |
| 片段插入 | 在光标处插入变量/模板/字段，保持撤销栈 |

## 12. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：编辑器按场景权限码控制（报表 `rpt:design`、数据范围 `role:grant`、工作流 `wf:define`、任务 `task:manage`）；只读查看用 `*:query`；无权限字段只读或整块隐藏（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：工具栏、校验提示、cron 人类可读描述、模板名走 vue-i18n；错误按错误码映射（90002 SQL、70002 cron、40403 表达式等）；**表达式/SQL 内容不翻译**；预置变量名保留英文（`@current_dept`）。
- **移动端**：**不提供代码/表达式/cron 编辑**（移动端无此类配置场景）；如需查看 SQL/JSON，按普通只读文本渲染，不加载编辑器内核。

## 13. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 分包 | CM6 内核与语言包动态加载、独立分包；`CodeViewer` 的 PrismJS 亦按需加载；编辑器不进首屏主包 |
| 校验 | 输入防抖（默认 500ms）；仅变更后校验，避免全量校验风暴；错误内联标注不阻塞输入 |
| 大文本 | 行数与字符上限（超限提示）；CM6 原生视口渲染；`CodeViewer` 长文折叠 + `max-height` 滚动 |
| 主题切换 | 重建编辑器但保留内容与光标；令牌色值来自 CSS 变量 |
| 格式化 | 保留撤销栈；格式化失败给出可读原因 |
| 边界 | 非法语法（内联 + 底部汇总）、非 SELECT（拒绝/警示）、SQL 超时/从库不可用（90003）、结果超限（90005）、表达式变量/字段缺失、cron 非法（70002）、只读态、空内容、超长单行、复制、离线（本地依赖）、主题/租户切换、编辑器实例泄漏（`dispose`） |
| 不支持 | 表达式/SQL/cron 的执行语义（后端）、报表/大屏/流程画布（各自设计器）、富文本正文（[富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)）、移动端编辑 |

## 14. 检查清单 <a id="checklist"></a>

- □ 组件分层：`CodeEditor` 内核封装、`SqlEditor`/`ExpressionEditor`/`CronEditor` 场景化、`CodeViewer` 只读高亮、`useCodeEditor` 实例与校验，职责不重叠
- □ 内核选型：编辑用 CodeMirror 6（语言包按需），只读用 PrismJS；两者独立分包懒加载；主题接设计令牌
- □ 通用契约：语言/只读/行号/缩进/防抖校验/格式化/插入片段/主题重建/`dispose` 齐备，值同步不循环触发
- □ SQL：仅 SELECT 轻校验 + 服务端校验（90002）、格式化、测试执行（只读从库、结果预览、90003/90005）、字段清单确认
- □ 表达式：字段/预置变量面板与插入、运算符/函数提示、模板、校验（同源接口）、三场景（数据范围/工作流条件）复用
- □ cron：5 段编辑、人类可读描述（i18n）、常用模板、合法性校验（70002）、下次执行（可选）
- □ 只读高亮：PrismJS、行号、复制、换行、长文折叠；日志/JSON/配置场景
- □ 权限（场景权限码）、i18n（文案/cron 描述/错误码，内容不翻译）、移动端（不提供编辑）符合第 12 节
- □ 性能边界：动态 `import()` 分包、校验防抖、大文本限制、主题重建保留状态、实例释放
- □ 四项上游登记已确认：编辑器内核选型（CodeMirror 6 + PrismJS 分工）、SQL 校验/测试接口口径、表达式校验接口与变量下发、前端编辑器分包与主题
