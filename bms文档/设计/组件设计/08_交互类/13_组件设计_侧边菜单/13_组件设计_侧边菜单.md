## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 PC 管理端**侧边菜单**的组件设计：菜单栏（按后端动态菜单树渲染、折叠图标态、子菜单展开、当前路由高亮、菜单搜索、徽标、隐藏项过滤）与菜单项（递归渲染）。适用于**主框架侧边导航**（PC 管理端），是动态路由与权限渲染的菜单呈现。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「前端页面清单与菜单机制」；上游设计依据[《布局设计 · 导航》](../../../布局设计/05_布局设计_导航.html)（侧边菜单：折叠为图标态、子菜单展开、当前高亮、徽标）、[《布局设计 · 主框架》](../../../布局设计/04_布局设计_主框架.html)（侧栏 + Tab 栏联动）、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（动态菜单接口 `GET /menus/my`、菜单树字段）、[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)（菜单树由后端按权限下发、前端不硬编码路由）；协作节点为[交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)（菜单图标渲染）、[交互类「多标签导航」](../../03_布局组件类/04_组件设计_多标签导航/04_组件设计_多标签导航.md)（点击菜单打开/激活标签）、[展示类「通知与消息」](../../07_展示类/06_组件设计_通知与消息/06_组件设计_通知与消息.md)（待办/通知角标口径）、[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)。

> 本篇为「侧边菜单」节点。**范围边界**：**菜单数据与权限过滤**归[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（后端按用户权限下发，本节点只渲染）；**动态路由注册**归[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)（本节点只做菜单与路由联动）；**顶栏**（通知铃铛/搜索/用户区）归[《布局设计 · 导航》](../../../布局设计/05_布局设计_导航.html)与 [通知与消息](../../07_展示类/06_组件设计_通知与消息/06_组件设计_通知与消息.md)/[全局搜索](../../07_展示类/07_组件设计_全局搜索/07_组件设计_全局搜索.md)；移动端不使用侧边菜单（TabBar，见第 9 节）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 菜单栏 | 动态菜单树渲染、折叠/展开、当前路由高亮、菜单搜索、徽标、隐藏项过滤、滚动、与标签栏联动 |
| 菜单项 | 菜单项递归渲染：图标、名称、子菜单折叠、徽标、外链、禁用/隐藏、深度限制 |
| 菜单状态来源（宿主） | 菜单树来源（后端动态菜单接口）+ 展开集 + 搜索过滤（本节点消费） |


## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 菜单树 | 后端按权限下发的动态菜单树（含 `name`/`path`/`component`/`icon`/`sort`/`hidden`/`children`/`badge?`） |
| 折叠态 | 折叠时仅图标 + 悬浮展开子菜单 |
| 当前路由 | 当前路径（高亮与父级展开） |
| 菜单搜索 | 是否显示菜单搜索 |
| 同级唯一展开 | 同级是否只展开一个子菜单（手风琴） |
| 主题 | `light` / `dark`（侧栏底色，随主框架主题） |
| 导航通知 | 点击叶子菜单（打开/激活标签并路由） |
| 折叠通知 | 折叠状态变化 |
| 对外能力 | 设置当前项、按路径展开、按关键词过滤 |

## 4. 渲染与交互 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 数据来源 | `GET /menus/my`（按用户权限过滤后的菜单树，[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)）；`hidden=true` 不上菜单但可用于路由 |
| 递归渲染 | 菜单项递归；叶子点击 → 导航（打开/激活页面级标签，[交互类「多标签导航」](../../03_布局组件类/04_组件设计_多标签导航/04_组件设计_多标签导航.md)） |
| 图标 | 菜单图标按图标标识渲染（[交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)），缺失降级 |
| 折叠态 | 折叠时仅显示图标；悬浮弹出子菜单；折叠状态持久化（用户偏好） |
| 当前高亮 | 按当前路径高亮叶子并**自动展开父级**；支持路由参数匹配 |
| 子菜单展开 | 点击父节点展开/收起；同级唯一展开时同级只留一个 |
| 搜索 | 按菜单名过滤并展开命中路径；无命中空态；搜索不改变路由 |
| 徽标 | `badge`（待办/通知数）显示于节点右侧（口径同 [展示类「通知与消息」](../../07_展示类/06_组件设计_通知与消息/06_组件设计_通知与消息.md)） |
| 排序/隐藏 | 按 `sort` 升序；`hidden` 不上菜单；无权限菜单后端已过滤（前端不再判断） |
| 深度 | 建议 ≤ 3 级；超深菜单允许但提示体验问题 |
| 外链 | `external=true` 时新开窗口；菜单项可配置 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：菜单树后端按用户权限过滤（无权限菜单不下发），前端**不再判断**；路由守卫兜底（[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)）；徽标数据沿用来源模块权限。
- **i18n**：菜单名由 `sys_menu_i18n` 按 locale 下发；界面文案（搜索占位/空态）走全局语言能力。
- **移动端**：不使用侧边菜单；移动端以抽屉式菜单或底部 TabBar 导航，菜单数据同源。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 菜单树体量小；递归渲染；折叠态不渲染子项（按需） |
| 搜索 | 本地过滤（菜单已在前端），命中路径自动展开 |
| 缓存 | 菜单树登录后一次性拉取（含 i18n），语言切换重取；路由切换不重取 |
| 边界 | 无菜单（空态）、超深菜单、折叠态子菜单溢出、路由参数匹配、隐藏项、外链、图标缺失、徽标 0/超 99、语言切换重建菜单名 |
| 不支持 | 菜单数据与权限过滤（后端菜单管理）、路由注册（前端架构）、顶栏元素（导航/通知/搜索）、移动端组件 |

## 9. 检查清单 <a id="checklist"></a>

- □ 职责分层：菜单栏、递归菜单项、宿主菜单状态来源；图标按图标标识渲染
- □ 渲染：动态菜单树、排序、hidden 过滤、无权限后端过滤、外链、深度
- □ 交互：折叠图标态与悬浮展开、当前高亮 + 父级自动展开、子菜单手风琴（可选）、菜单搜索、徽标
- □ 联动：点击叶子打开/激活页面级标签；折叠状态持久化
- □ 权限（后端过滤/路由守卫）、i18n（菜单名按 locale/文案）、移动端（抽屉/TabBar，数据同源）符合第 7 节
- □ 性能边界：登录后一次拉取、语言切换重取、搜索本地过滤、折叠按需渲染
- □ 三项上游登记已确认：侧边菜单交互细则、菜单树字段与徽标、折叠偏好
