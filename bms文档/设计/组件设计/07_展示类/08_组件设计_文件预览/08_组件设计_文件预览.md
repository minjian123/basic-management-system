## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 **文件预览**的组件设计：预览容器（类型分发、多文件切换、下载、失效与降级），图片预览（缩放/旋转/切换），PDF 预览（翻页/缩放），以及预签名与状态编排（预签名 URL 获取与失效刷新、内容类型判定、下载）。预签名获取与媒体类型判定由**能力域基类**承担（能力域基类是继承链上的一类基类，主体内建走继承轨）。适用于管理端各处**文件在线预览**（[字段类「文件上传字段」](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md) 回显点击、[展示类「状态标签与描述列表」](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 文件值、业务单据附件）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**文件管理**模块；上游设计依据[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)（文件元数据、预签名下载与在线预览、`file:download`）与[《架构设计 · 文件管理》](../../../架构设计/20_架构设计_子系统_文件管理.md)（分片状态机、安全控制、预签名 URL 直开、对象存储）；协作节点为[字段类「文件上传字段」](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（上传与文件列表回显）、[展示类「异常与空状态」](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（加载/错误/失效态）、[基础类「请求封装」](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（预签名 URL 获取）、[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`file:download`）；形态依据[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html)（预览遮罩层）与[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)（移动端图片预览）。

> 本篇为「文件预览」节点。**范围边界**：**文件存储、分片上传、预签名生成、内容安全**归[《架构设计 · 文件管理》](../../../架构设计/20_架构设计_子系统_文件管理.md)（本节点只消费预签名 URL）；**上传与文件列表**归 [字段类「文件上传字段」](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)；**Office 文档在线编辑/转换**（如需）不在 MVP（仅提供下载）；**富文本正文**归 [字段类「富文本字段」](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)；移动端为按需的另一实现（见第 2 / 10 节）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 预览容器件 | 按内容类型分发（图片/PDF/音视频/文本/其他）；多文件切换（上一/下一、缩略图）；下载；预签名失效重取；不支持类型降级下载；遮罩/抽屉/页内三种形态 |
| 图片预览件 | 图片预览：等比缩放、旋转、多图切换、适应窗口/原始尺寸、下载 |
| PDF 预览件 | PDF 预览：分页翻页、页码跳转、缩放、下载；加载失败降级下载 |
| 预签名与状态编排（能力域基类） | 按类型分发、预签名 URL 获取与失效刷新（限期解析）、内容类型判定、下载、加载/错误态 |

- **音视频/文本内联**：容器内直接使用浏览器原生视频/音频/文本能力呈现，不额外拆组件；仅图片/PDF 因交互复杂单拆。
- **预签名 URL 直开**：预览地址为后端预签名 URL（限时有效），前端不代理文件流（[《架构设计 · 文件管理》](../../../架构设计/20_架构设计_子系统_文件管理.md)）。

## 3. 预览容器 <a id="container"></a>

预览容器语义项：显隐（双向绑定）、文件列表（`{ id, name, mimeType, size }`，支持多文件切换）、初始预览索引、形态（遮罩层/抽屉/页内嵌）、是否显示下载（受 `file:download`）、多文件切换形式（无/缩略图）。

| 事件 | 说明 |
| --- | --- |
| 关闭 | 关闭预览 |
| 切换 | 切换文件（索引 + 文件） |
| 错误 | 预览失败（失效/不支持/加载失败），携带文件与原因 |

- 类型分发：图片 → 图片预览；PDF → PDF 预览；视频/音频 → 原生播放器；文本（txt/csv/json/代码）→ 文本视图（大文件截断）；其他（office/压缩包等）→ **降级为下载**（提示「该类型不支持在线预览，请下载查看」）。
- 多文件：上一/下一、缩略图条（图片）/文件列表；键盘 ←/→ 切换、Esc 关闭。
- 失效处理：预签名 URL 过期或对象不可读 → 自动请求新 URL 一次；仍失败则错误态 + 下载入口（[展示类「异常与空状态」](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)）。

## 5. PDF 预览 <a id="pdf"></a>

| 项 | 设计 |
| --- | --- |
| 承载 | 浏览器内置 PDF 阅读器直开预签名 URL，或自绘分页；缺省用浏览器内置 |
| 翻页/跳转 | 页码输入跳转、上一/下一；总页数（若可得） |
| 缩放 | 适应宽度/适应页面（视浏览器能力，必要时自绘） |
| 下载 | 下载 PDF（`file:download`） |
| 降级 | 浏览器不支持内嵌 PDF 或加载失败 → 下载（提示） |

- PDF 预览以**浏览器内置阅读器**为主（轻量、无额外库）；若需统一体验再评估自绘 PDF 渲染（登记项②）。

## 6. 音视频与文本预览 <a id="media-text"></a>

| 类型 | 实现 | 说明 |
| --- | --- | --- |
| 视频 | 浏览器原生视频播放器 | 支持 Range 请求（预签名 URL 支持分段，[《架构设计 · 文件管理》](../../../架构设计/20_架构设计_子系统_文件管理.md)）；封面可空 |
| 音频 | 浏览器原生音频播放器 | 简单播放器 |
| 文本 | 文本视图展示解析文本 | txt/csv/json/代码；大文件截断（前 N KB）+ 下载查看全文；超长行横向滚动 |
| 图片 | 图片预览 | 见第 4 节 |
| PDF | PDF 预览 | 见第 5 节 |

- 音视频/文本为**扩展预览类型**（原设计为图片/PDF；本节点扩展并登记上游，登记项③）。
- 移动端音视频使用移动端播放器（系统内核），文本按移动端样式。

## 7. 状态与预签名语义 <a id="use-file-preview"></a>

| 项 | 设计 |
| --- | --- |
| 类型判定 | 按 `mimeType`（缺省按扩展名）判类型；`other` 直接降级下载 |
| 预签名 | 调后端获取预签名 URL（限时）；URL 失效（加载错误/超时）时**重取一次**，仍失败给错误态 + 下载 |
| 下载 | 下载走预签名 URL（`file:download`，[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)） |
| 切换 | 上一/下一切换文件并重置子查看器状态（缩放/翻页）；按需预取相邻图片 |
| 释放 | 关闭时释放 URL（不泄漏）、停止播放（音视频） |
| 错误 | 对象不存在/已清理（文件已失效）、无权限、不支持类型、加载失败分类提示 |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：预览与下载需 `file:download`（[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)）；对象归属与数据范围由后端校验（预签名生成时鉴权）；无权限时不展示预览/下载入口（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：界面文案（加载/错误/不支持类型提示/页码）、错误码走全局语言能力；文件名不翻译。
- **移动端**：按需实现（同接口多实现 + 契约套件同一套断言）；图片用移动端图片预览基础件、音视频用系统/内嵌播放器、文本按移动端样式；预签名与下载复用后端接口与 `file:download`（[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 加载 | 预签名 URL 直开（前端不代理流）；图片可按需懒加载/预取相邻；PDF 用浏览器内置阅读器按需加载 |
| 内存 | 关闭时释放 URL、停止音视频播放、销毁子查看器；大图避免同时多份解码 |
| 文本 | 大文本截断（前 N KB）+ 下载全文；超长行横向滚动 |
| 音视频 | Range 分段按需加载，不整包下载 |
| 失效 | URL 过期/对象不可读 → 重取一次 → 错误态 + 下载；不缓存超期 URL |
| 安全 | 不安全类型（HTML/SVG/可执行）不做内嵌渲染，降级下载；预签名限时降低泄露风险 |
| 边界 | 多文件空列表、索引越界、超大文件、损坏对象、类型判定失败（按 other 降级）、无权限、URL 失效、浏览器不支持内嵌 PDF、移动端差异 |
| 不支持 | 上传/分片（字段类「文件上传字段」）、存储/预签名生成（《架构设计 · 文件管理》）、Office 在线编辑（MVP 不提供，仅下载）、富文本正文（字段类「富文本字段」）、移动端宿主装配（各端工程） |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：预览容器分发、图片预览、PDF 预览、预签名与状态编排，音视频/文本内联；职责不重叠
- □ 类型分发：图片/PDF/音视频/文本/其他（降级下载）；`mimeType` 判定（缺省扩展名）
- □ 图片：缩放/旋转/适应/多图切换/下载；PDF：翻页/跳转/缩放/下载；音视频：原生播放器 + Range；文本：截断 + 下载
- □ 多文件切换（上一/下一/缩略图/键盘）、三形态（遮罩/抽屉/页内）
- □ 预签名：获取/失效重取一次/失败错误态 + 下载；关闭释放、停止播放
- □ 权限（`file:download`）、i18n（文案/错误码/页码）、移动端（移动端图片预览/系统播放器）符合第 10 节
- □ 性能边界：直开不代理、按需/懒加载、大文本截断、Range、URL 释放、不安全类型降级
- □ 三项上游登记已确认：文件预览交互契约、预签名 URL 使用与安全、扩展预览类型至音视频/文本
