## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **图表渲染**的组件设计：基础封装 `EChart.vue`（ECharts 实例/option/自适应/主题）、工作台卡片容器 `ChartCard.vue`（卡头、数据集取数、刷新/下钻、空/加载/错误/降级态），以及组合式函数 `useChart.ts`（实例生命周期、ResizeObserver、主题切换）与图表主题工具 `chartTheme.ts`（令牌 → ECharts 主题）。适用于**首页工作台数据集图表卡**（[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)）与**报表查看/移动端数据查询**的图表渲染（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)）；图表渲染器向二者共用，卡片容器只服务工作台场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**首页工作台**与**报表中心**模块、技术选型的 ECharts 选型说明；视觉依据[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)（图表色板与语义色、禁硬编码色值）与[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「卡片形态规范」节（图卡尺寸、图表必须含坐标轴/图例/数据集标注、空态插画、单卡异常降级）；异常口径依据[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)与[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)（断点与容器尺寸）；上游设计依据[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)「技术要点」节（ECharts 渲染、按需引入与分包）、[《架构设计 · 首页工作台》](../../../架构设计/25_架构设计_子系统_首页工作台.md)「卡片注册机制」「前端渲染架构」节（通用 ChartCard、dataset 卡、gridstack 自适应）、[《架构设计 · 报表BI》](../../../架构设计/19_架构设计_子系统_报表BI.md)（数据集执行与 ECharts 图表类型）、[《概要设计 · 首页工作台》](../../../概要设计/35_概要设计_首页工作台.md)（`sys_dashboard_card` 的 `dataset_id`/`chart_type`、布局接口下发卡片元数据）、[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（`rpt_dataset` 字段清单、数据集执行与安全校验）；协作节点为[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（并行取数与错误处理）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（数值/日期轴与 tooltip 格式化）、[日期时间字段](../../06_字段类/02_组件设计_日期时间字段/02_组件设计_日期时间字段.md)（时间范围参数）、[状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（数据表视图与状态语义色）、[通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)（图表卡的数据表视图回退）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`rpt:view` 口径）。

> 本篇为组件设计体系展示类第 04 篇。**范围边界**：图表**设计态**（拖拽配置 chart_config、数据集 SQL 建模、大屏自由画布）归[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)与报表设计器/大屏设计器页面，本节点**不做设计器**；数据聚合、SQL 与结果集口径归报表数据集；通用表格渲染归[通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)；状态语义色与纯值格式化归[12](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)/[21](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)，本节点只负责「图表渲染、卡片容器、取数编排、主题与自适应」。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `EChart.vue` | `src/components/chart/` | 基础图表封装：ECharts 实例绑定、option 与数据类型、自适应 resize、加载/空/错误态、事件透传（图表类型按需注册由 `chartTheme.ts` 统一完成） |
| `ChartCard.vue` | `src/components/chart/` | 工作台图表卡容器：卡头（标题/操作）、数据集取数、刷新/轮询、下钻事件、编辑态移除、空/加载/错误/降级态、数据表视图切换 |
| `useChart.ts` | `src/utils/useChart.ts` | 组合式函数：实例生命周期、ResizeObserver + 防抖、主题/租户切换重建、视口懒渲染、导出图片、卸载释放 |
| `chartTheme.ts` | `src/utils/chartTheme.ts` | 主题工具：读取设计令牌 CSS 变量生成 ECharts 主题、注册主题名、深层色板/坐标轴/tooltip/图例默认值、深色模式变体 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、工具与组合式函数 camelCase（`use` + 名词）、目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 下按域分目录，通用工具与组合式函数放 `src/utils/`）。
- 移动端（frontend-mobile）不复用上述 PC 组件：工作台图表卡按[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「移动端工作台」节显示摘要或省略，报表移动端「数据查询」由 Vant 工程自行封装，但**同源 chart_type/option 口径与令牌色板**（见第 11 节）。

## 3. 基础图表封装 EChart <a id="echart"></a>

### 3.1 Props 与事件 <a id="echart-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `option` | EChartsOption \| null | null | 完整 ECharts 配置；与 `type` 二选一（同时给出时以 `option` 为准，`type` 仅作兜底） |
| `type` | ChartType \| null | null | 便捷图表类型（见第 7 节）；未给 `option` 时由组件按 `type` + `dataset` 生成基础 option |
| `dataset` | ChartDataSet \| null | null | 数据集结果（`{ columns, rows }`，字段声明来自 `rpt_dataset.fields`）；用于按类型生成或作为 ECharts `dataset` 源 |
| `height` | number \| string | '100%' | 画布高度（数字按 px）；工作台卡片内由容器高度决定，默认撑满 |
| `renderer` | 'canvas' \| 'svg' | 'canvas' | 渲染模式；工作台与报表默认 `canvas`（大数据量），低数量可 `svg` |
| `theme` | 'auto' \| 'light' \| 'dark' | 'auto' | 主题；`auto` 跟随全局主题（深浅）、租户品牌与令牌，见第 4 节 |
| `loading` | boolean | false | 加载态（ECharts loading 动画） |
| `empty` | boolean | false | 空数据态（显示空态插画 + 文案，不渲染坐标轴） |
| `error` | string \| null | null | 错误态（错误文案 + 重试按钮）；优先级高于 empty |
| `notMerge` | boolean | false | `setOption` 是否不与旧配置合并（切换图表类型时为 true 防残留） |
| `autoresize` | boolean | true | 是否自动监听容器尺寸变化（见 3.3） |
| `lazy` | boolean | true | 是否进入视口后才初始化渲染（工作台多卡场景，见第 12 节） |
| `events` | Record\<string, Function\> | {} | 需要透传的 ECharts 事件（如 `click`、`legendselectchanged`、`datazoom`） |
| `showTools` | boolean | false | 是否显示右上工具箱（保存图片/还原/数据视图） |
| `dataSource` | string \| null | null | 数据集标注（数据集名称 + 口径说明），渲染为图表脚注（[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「图表必须含数据集标注」） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `ready` | ECharts 实例 | 实例初始化完成（供调用方 `dispatchAction`/导出） |
| `resize` | `{ width, height }` | 容器尺寸变化后触发 |
| `retry` | — | 错误态点「重试」触发，由调用方重新取数 |
| `click` | ECharts 事件参数 | 数据点点击（下钻由 `ChartCard` 转 `drilldown`） |

- **方法（模板 ref 暴露）**：`getInstance()`、`setOption(option, opts?)`、`resize()`、`dispatchAction(payload)`、`getDataURL(opts?)`、`clear()`。
- `option` 中的 `color` 缺省即用主题色板；调用方**不应**在业务 `option` 里写死色值（需要固定语义色时引用令牌变量对应的十六进制，由 `chartTheme.ts` 提供取值函数）。

### 3.2 图表类型与 series 映射 <a id="echart-type"></a>

`ChartType` 与 ECharts series 的默认映射（`type` + `dataset` → option 的生成依据）：

| ChartType | ECharts series | 适用 / 默认构成 |
| --- | --- | --- |
| `line` | `line`（平滑可选） | 趋势；x 轴类目/时间、y 轴数值、tooltip axis |
| `area` | `line` + `areaStyle` | 趋势与累计；默认单色渐变面积 |
| `bar` | `bar` | 分类对比；类目轴 x |
| `hbar` | `bar`（y 类目） | 排名/长名称分类；横向条形 |
| `stacked_bar` | `bar` + `stack` | 结构占比；多 series 堆叠 |
| `pie` | `pie` | 占比；默认标签含百分比 |
| `doughnut` | `pie` + `radius` | 占比（中空，可放汇总数） |
| `scatter` | `scatter` | 相关性；双数值轴 |
| `funnel` | `funnel` | 转化漏斗 |
| `radar` | `radar` | 多维对比 |
| `gauge` | `gauge` | 单一指标达成率（统计卡） |
| `table` | 无（回退数据表） | 明细/宽表；渲染走[通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)的只读数据表，不画裸图 |
| `map` | `map`（geo） | 地域分布；**geoJSON 按需懒加载**，见第 7 节 |

- 支撑图表类型所需的 ECharts 组件（grid/tooltip/legend/toolbox/dataZoom/markLine、各 series、Canvas/SVG renderer）由 `chartTheme.ts` 统一按需注册；**未使用的图表类型不注册**，保证分包体积。
- `table` 与其他图表可**同源切换**（`ChartCard` 卡头提供「图表 / 数据表」切换，复用同一份 `dataset`）。

### 3.3 实例生命周期与自适应 <a id="echart-lifecycle"></a>

```mermaid
flowchart TD
    A["挂载 / 进入视口"] --> B{"容器尺寸可用？"}
    B -->|"否（隐藏 / 尺寸 0）"| B
    B -->|"是"| C["echarts.init(el, themeName, renderer)"]
    C --> D["setOption(option, {notMerge})"]
    D --> E["ResizeObserver 监听容器"]
    E -->|"尺寸变化（防抖 150ms）"| F["chart.resize()"]
    G["全局主题 / 租户品牌变化"] -->|"dispose + 重新注册主题 + init"| C
    H["卸载 / keep-alive deactivated"] --> I["dispose()（释放实例）"]
    D --> J["click / legendselectchanged 等事件透传"]
```

| 项 | 设计 |
| --- | --- |
| 初始化时机 | 容器可见且宽高均 > 0 时初始化；尺寸为 0（隐藏 Tab、未展开卡片、gridstack 尚在布局）时延迟到首次可见（配合 `lazy` + IntersectionObserver） |
| 自适应 | 组件内 `ResizeObserver` 监听**画布容器**（不是 window）；防抖 150ms；gridstack 拖拽/缩放**结束时**由容器尺寸变化自然触发 `resize()`，不逐帧 resize |
| 主题切换 | 深浅模式/租户品牌切换 → `dispose` 后用新主题名重新 `init` 并 `setOption`（ECharts 主题在实例创建时固化，不能热改） |
| `option` 更新 | 默认增量合并；切换图表类型或字段结构变化时 `notMerge: true`，避免旧 series 残留 |
| 释放 | 组件卸载与 `keep-alive` `deactivated`（工作台切换 Tab）时 `dispose()`；`activated` 后按需重建；避免离屏实例常驻内存 |
| 事件 | 通过 `events` map 注册/解绑；组件卸载时统一 `off`，防内存泄漏 |

### 3.4 空 / 加载 / 错误态 <a id="echart-states"></a>

| 态 | 表现 | 说明 |
| --- | --- | --- |
| 加载 | ECharts loading 动画（或容器骨架块） | 首次加载与刷新共用；不阻塞卡头操作 |
| 空数据 | 空态插画 + 文案「暂无数据」 | 行数为 0 或无有效数值；**不渲染坐标轴与图例**（[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「无数据时显示空态插画」） |
| 错误 | 错误文案 + 「重试」按钮 | 单卡降级，不阻塞整页；`retry` 由调用方重新取数 |
| 数据集不可用 | 「数据集不可用」降级占位（无重试或仅提示） | 数据集已停用/删除（错误码 90001）；工作台允许编辑态移除该卡 |
| 无权限 | 「无权限查看」提示 | 数据取数被报表中心权限/数据范围拦截（`rpt:view` 缺失或数据范围为空） |

## 4. 主题与色板 <a id="theme"></a>

### 4.1 色板来源与令牌 <a id="palette"></a>

图表配色**统一来自设计令牌**，由 `chartTheme.ts` 在运行时读取 CSS 变量生成 ECharts 主题对象；**禁止在 option 中硬编码色值**（对齐 [状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)「颜色一律引用设计令牌」）。色板结构（具体值在[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)「图表色板」节定义，本节点登记）：

| 序 | 令牌 | 基准值 | 说明 |
| --- | --- | --- | --- |
| 1 | `--chart-color-1` | `#0969da` | 主序列（对齐 `--color-primary`） |
| 2 | `--chart-color-2` | `#2da44e` | 第二序列（对齐 `--color-success`） |
| 3 | `--chart-color-3` | `#d4a72c` | 第三序列（对齐 `--color-warning`） |
| 4 | `--chart-color-4` | `#cf222e` | 第四序列（对齐 `--color-danger`） |
| 5 | `--chart-color-5` | `#57606a` | 第五序列（对齐 `--color-info`） |
| 6 | `--chart-color-6` | `#8250df` | 扩展序列（紫） |
| 7 | `--chart-color-7` | `#1b7c83` | 扩展序列（青） |
| 8 | `--chart-color-8` | `#bc4c00` | 扩展序列（橙） |

| 辅助令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--chart-axis` | `--color-border` | 坐标轴线、刻度 |
| `--chart-grid` | `--color-border`（低透明度） | 网格线（仅数值轴） |
| `--chart-text` | `--color-text-secondary` | 坐标轴标签、图例文字 |
| `--chart-tooltip-bg` | `--color-bg-page` | tooltip 背景 |
| `--chart-tooltip-text` | `--color-text` | tooltip 文字 |

- **序列取色**：多序列按 `--chart-color-1..8` 顺序循环；**语义场景**（如达成率达标/预警、地域高低）显式映射到语义色（`--color-success` / `--color-warning` / `--color-danger`），与 [状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 语义色口径一致，不因图表而自造色。
- **面积/饼图透明度、渐变**由主题按主色生成（不新增令牌）；深色模式下自动调整网格/文字对比度。

### 4.2 深浅模式与租户品牌 <a id="theme-switch"></a>

| 项 | 设计 |
| --- | --- |
| 深浅模式 | 主题从 `[data-theme]` / 全局偏好读取（[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)主题机制）；切换时 `chartTheme.ts` 重新读取变量并重建实例 |
| 租户品牌 | 租户覆盖 `--color-primary` 等变量后，图表第 1 序列与强调色随之变化（[《布局设计 · 主题与租户品牌化》](../../../布局设计/03_布局设计_主题与租户品牌化.html)） |
| 主题名 | 注册 `bms-light` / `bms-dark` 两个 ECharts 主题；实例以主题名初始化 |
| 图标与标注 | tooltip、图例、坐标轴默认值（字号、字体栈、axisPointer、零值线）在主题中统一定义，业务 option 不重复设置 |

## 5. 工作台图表卡 ChartCard <a id="chart-card"></a>

### 5.1 Props 与事件 <a id="chart-card-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `card` | DashboardCardMeta | — | 卡片元数据（`code`/`name`/`card_type`/`dataset_id`/`chart_type`/`default_width`/`default_height`），由布局接口下发（[《概要设计 · 首页工作台》](../../../概要设计/35_概要设计_首页工作台.md)） |
| `params` | Record\<string, any\> | {} | 数据集查询参数（如时间范围 `*_start`/`*_end`、筛选条件），序列化口径对齐[查询筛选区](../02_组件设计_查询筛选区/02_组件设计_查询筛选区.md) |
| `height` | number \| string | — | 卡片内容区高度（gridstack 卡片高度驱动） |
| `chartTypeOverride` | ChartType \| null | null | 卡内临时切换图表类型（不持久化；持久化需改卡片定义，走报表设计器） |
| `view` | 'chart' \| 'table' | 'chart' | 图表 / 数据表视图（`table` 走 [通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)只读数据表） |
| `refreshable` | boolean | true | 是否显示刷新按钮 |
| `refreshInterval` | number | 0 | 轮询秒数（0 = 不轮询）；启用时受页面可见性约束（不可见暂停） |
| `editable` | boolean | false | 编辑态（显示移除/拖拽手柄，由工作台编辑模式传 true） |
| `linkTo` | string \| RouteLocationRaw \| null | null | 卡头「查看详情」跳转（报表查看/业务明细） |
| `dataSourceLabel` | string \| null | null | 数据集标注文案（数据集名 + 口径说明），缺省取 `card.dataset_name` |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `refresh` | card.code | 用户点刷新（调用方或组件内部重新取数） |
| `drilldown` | `{ card, params, dataPoint }` | 数据点点击下钻（携带点击维度值，由工作台路由到明细/报表） |
| `remove` | card.code | 编辑态移除卡片（仅前端布局变更，保存时提交） |
| `state-change` | `{ code, state }` | 卡内状态变化（loading/empty/error/unavailable/forbidden），供工作台统计 |

- **插槽**：`header-actions`（卡头右侧自定义操作）、`empty`、`error`、`footer`（脚注/标注）、`params`（卡内参数区，如时间范围切换）。

### 5.2 卡片形态 <a id="chart-card-shape"></a>

| 区域 | 内容 |
| --- | --- |
| 卡头 | 标题（`card.name`，按 locale 下发）+ 右侧操作：视图切换（图表/数据表，可选）、刷新、查看详情、编辑态移除；高度 16px 标题字号（[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「通用卡片头」） |
| 内容区 | `EChart` 画布（撑满）；`table` 视图时为只读数据表；空/加载/错误态占位 |
| 脚注 | 数据集标注（`dataSourceLabel`）与「最后更新时间」，字号 `small`；无标注时不渲染 |
| 尺寸 | 图卡默认 `6×4` / `12×4`（[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「卡片尺寸规格」）；尺寸由 gridstack 容器决定，图表随容器 resize 自适应 |

- 图表**必须含坐标轴、图例与数据集标注**（饼/仪表盘等无坐标轴时不强制坐标轴，但需数值标注与口径说明），禁止只渲染裸图形。
- 卡头操作按钮按权限/场景显隐（查看详情受 `rpt:view` 与目标路由权限约束）。

### 5.3 数据集取数 <a id="chart-card-data"></a>

```mermaid
sequenceDiagram
    autonumber
    participant 工作台 as 工作台页面
    participant 卡 as ChartCard
    participant 图表 as EChart
    participant 接口 as 报表数据集取数接口
    participant 缓存 as 浏览器短缓存

    工作台->>卡: 布局接口下发卡片元数据(dataset_id/chart_type/接口地址)
    卡->>缓存: 命中同参数结果？(TTL 内)
    缓存-->>卡: 命中则直接返回
    卡->>接口: POST /rpt/datasets/{id}/query（参数化 + 权限/数据范围）
    接口-->>卡: { columns, rows }（只读从库）
    卡->>图表: dataset + chart_type → option → setOption
    图表-->>卡: 渲染完成
    卡->>接口: 手动刷新 / 轮询（页面可见时）
```

| 项 | 设计 |
| --- | --- |
| 取数归属 | `ChartCard` 负责取数编排与状态机；`EChart` 只接收数据/option，不发起请求（保持纯渲染） |
| 接口 | 数据集运行取数接口（见第 10 节登记项①）：参数化、只读从库、强制租户与数据范围过滤；请求封装走[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md) |
| 参数 | `params` 序列化与[查询筛选区](../02_组件设计_查询筛选区/02_组件设计_查询筛选区.md)一致（区间 `*_start`/`*_end`、多值逗号、布尔 `1/0`） |
| 并行与隔离 | 工作台多卡**并行拉取**（`Promise.allSettled`），单卡失败不影响其他卡（[《架构设计 · 首页工作台》](../../../架构设计/25_架构设计_子系统_首页工作台.md)「数据拉取」节） |
| 短缓存 | 同卡同参数结果浏览器短缓存（如 30s，对齐统计卡口径），防高频刷新打库；手动刷新强制绕过 |
| 轮询 | 仅当 `refreshInterval > 0` 且页面可见；`document.hidden` 时暂停 |
| 下钻 | `click` 数据点 → `drilldown` 事件携带维度值，由工作台路由到明细/报表（本节点不定义下钻目标） |
| 数据表视图 | `view='table'` 时用同一份 `dataset` 渲染只读数据表（[通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)），支持导出复用导入导出节点 |

## 6. 组合式函数 useChart <a id="use-chart"></a>

```typescript
interface UseChartOptions {
  renderer?: 'canvas' | 'svg';
  theme?: 'auto' | 'light' | 'dark';
  autoresize?: boolean;      // 默认 true，ResizeObserver + 防抖
  lazy?: boolean;            // 默认 true，IntersectionObserver 视口懒渲染
  resizeDebounce?: number;   // 默认 150ms
  onReady?: (chart: ECharts) => void;
}

interface UseChartReturn {
  el: Ref<HTMLElement | null>;        // 绑定容器
  instance: Ref<ECharts | null>;      // 当前实例
  ready: Ref<boolean>;                // 是否已初始化
  setOption: (option: EChartsOption, opts?: { notMerge?: boolean }) => void;
  resize: () => void;
  clear: () => void;
  dispose: () => void;
  getDataURL: (opts?: Record<string, any>) => string | null;
}
```

| 行 | 设计 |
| --- | --- |
| 实例管理 | `init` / `dispose` / 主题切换重建全部内聚，组件只调用 `setOption` |
| 尺寸监听 | `ResizeObserver` 绑容器；`resizeDebounce` 防抖；容器尺寸 0 时不 resize（防 `NaN` 警告） |
| 懒渲染 | `IntersectionObserver` 监听进入视口才 `init`，配合 `keep-alive` 的 `activated/deactivated` 暂停/恢复 |
| 主题联动 | 订阅全局主题 store，变化时重建实例并重放最近一次 option |
| 卸载 | `onBeforeUnmount` 统一 `dispose` + 断开 observer，防泄漏 |

- `useChart` 只依赖 ECharts 与 Vue，不含业务；`EChart.vue` 与报表侧自定义图表可复用同一函数。

## 7. 图表类型扩展与地图 <a id="types"></a>

| 项 | 设计 |

## 10. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：数据取数沿用报表中心 `rpt:view` 与动作级数据范围（租户强制隔离）；被拦截时卡内显示「无权限查看」降级，不报错中断整页；「查看详情」跳转按目标路由权限显隐（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：卡片标题、图例/字段名按数据集 `fields` 声明与 locale 下发（对齐 [《架构设计 · 国际化》](../../../架构设计/20_架构设计_子系统_国际化.md)）；「加载中 / 暂无数据 / 加载失败 / 重试 / 数据集不可用 / 无权限查看 / 最后更新」等界面文案走 vue-i18n；坐标轴与 tooltip 的数值/日期格式复用[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)与 `Intl`（按 locale），**不翻译用户数据**。
- **移动端**：不复用 PC 组件；工作台图表卡按[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「移动端工作台」节显示**摘要或省略**（受 `mobile_supported` 标记约束）；报表移动端「数据查询」由 Vant 工程自封装，但 **chart_type、option 生成口径与令牌色板同源**，取数走同一后端接口（跨端一致）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 包体积 | ECharts 按需注册 + 独立分包懒加载，**不进首屏主包**；地图 geoJSON 按需加载；原型用 UMD 单文件仅为离线演示（[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)性能预算） |
| 多卡同屏 | `lazy` 视口内才初始化；离屏/隐藏 Tab 不渲染；实例按需创建，避免一次性 init 十余个画布 |
| resize | `ResizeObserver` + 防抖 150ms；gridstack 拖拽/缩放结束触发一次；避免逐帧 `resize()` 抖动 |
| 大数据量 | `canvas` 渲染；折线/柱状开启 `dataZoom`、`sampling`/`large`；结果集上限与分页/聚合由数据集承担（超限提示 90005） |
| 取数 | 多卡 `Promise.allSettled` 并行、单卡失败隔离；同参数短缓存（~30s）防打库；轮询受页面可见性约束 |
| 内存 | 卸载与 `keep-alive` 失活 `dispose`；主题切换重建前先 `dispose`；事件统一 `off` |
| 边界 | 空结果（空态不画轴）、单点/单序列、超长类目标签（省略 + tooltip）、超多序列（色板循环 + 图例滚动分页）、结果集超限、数据集停用/删除（降级）、无权限（降级）、从库不可用/超时（错误重试）、地图 geoJSON 加载失败（降级提示）、容器尺寸为 0（延迟初始化）、深浅/租户切换重建、移动端摘要/省略 |
| 不支持 | 图表设计器（拖拽配置归报表设计器）、大屏自由画布（vue-flow 归大屏设计器）、数据集 SQL 与聚合（归报表数据集）、通用表格渲染（归 [通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)）、纯值格式化与状态色（归 [状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)/[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层正确：`EChart` 纯渲染（不取数）、`ChartCard` 取数编排、`useChart` 实例/自适应/主题、`chartTheme` 令牌主题，职责不重叠
- □ `ChartType` 覆盖常用集 + 地图（line/area/bar/hbar/stacked_bar/pie/doughnut/scatter/funnel/radar/gauge/table/map），`table` 回退数据表不画裸图
- □ 颜色一律来自设计令牌图表色板（`--chart-color-1..8`）与辅助令牌，无硬编码色值；语义场景映射语义色；深浅/租户切换重建实例
- □ 生命周期与自适应：视口懒初始化、`ResizeObserver` + 防抖、gridstack resize 只触发一次、卸载/失活 `dispose`、事件解绑
- □ 状态齐备：加载、空态（不画轴）、错误（重试）、数据集不可用降级、无权限降级、地图加载失败降级
- □ `ChartCard` 形态：卡头（标题/视图切换/刷新/详情/编辑态移除）、脚注数据集标注、图表含坐标轴/图例/标注；尺寸随 gridstack 自适应
- □ 取数：数据集运行接口参数化、并行 + 单卡隔离、同参数短缓存、轮询受页面可见性约束、下钻事件携带维度值
- □ ECharts 按需注册 + 独立分包 + 地图 geoJSON 懒加载，不进首屏；大数据量 canvas + dataZoom/sampling + 结果集限深
- □ 权限（`rpt:view` + 数据范围，无权限降级）、i18n（标题/字段/locale 数值日期/界面文案，不翻译用户数据）、移动端（摘要/省略，口径同源）符合第 10 节
- □ 四项上游登记已确认：数据集运行取数接口、设计令牌图表色板、工作台卡片元数据与图表配置、前端架构图表封装与分包；《架构设计 · 首页工作台》通用 ChartCard 引用本节点
