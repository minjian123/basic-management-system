## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **通用表格**（`ProTable`）的组件设计：声明式列配置、数据取数与分页排序、多选与展开、树形表格、行内编辑、列个性化持久化、工具栏与空/加载/错误态。适用于管理端全部列表页（用户、角色、菜单、字典、公告、日志、任务等）、表单页的表格明细区，以及查询筛选区下方的数据展示。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与「前端页面清单与菜单机制」章节；页面形态依据[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（工具栏 + 筛选 + 表格三段式、**无操作列**、双击行打开表单、状态 tag 语义色）、[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)（明细区列布局、工具栏、行内编辑、自动空行）、[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)（列表 Tab 与记录 Tab 交互协议）、[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)与[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)（空态、加载分级、失败兜底）；上游设计依据[《概要设计 · 用户喜好》](../../../概要设计/04_概要设计_用户喜好.md)（`list.{form_key}` 列个性化偏好）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（明细区列配置）、[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)（导出参数与列表一致）、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（`sys_field`/`sys_role_field` 列可见性）；接口与性能依据[《架构设计 · 接口与集成》](../../../架构设计/08_架构设计_接口与集成.md)（统一响应、分页与排序）、[《架构设计 · 前端架构》](../../../架构设计/30_架构设计_前端架构.md)（列表页个性化、性能预算）与[《API接口规范》](../../../../规范/API接口规范.md)「参数与分页」节；协作节点为[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（`useListPage` 取数与错误码）、[字典字段](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)（字典列批量翻译）、状态标签与描述列表（状态列标签）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（列级权限与脱敏）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（列格式化口径）、导入导出（导出按钮）与[开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（状态列内联切换）。

## 3. 列配置模型 <a id="columns"></a>

```typescript
interface ProTableColumn<T = any> {
  prop: string;                 // 字段名（与后端字段同名，deptId ↔ dept_id 映射在数据类型层）
  label: string | i18nKey;      // 列头文案（元数据驱动时为 i18n key，见第 12 节）
  width?: number;               // 固定列宽（px）；虚拟表格模式必填
  minWidth?: number;            // 最小列宽（自适应基准）
  fixed?: 'left' | 'right';     // 固定列
  sortable?: boolean;           // 参与排序（true 时按 sortField 提交）
  sortField?: string;           // 后端排序字段名（缺省取 prop）
  align?: 'left' | 'center' | 'right';
  ellipsis?: boolean;           // 溢出省略 + 悬浮全文（showOverflowTooltip）
  formatter?: (row: T) => string;   // 纯展示列格式化（复用格式化工具）
  dictType?: string;            // 字典列：走字典字段批量翻译
  tagColor?: boolean;           // 状态标签列：由 StatusTag 渲染（语义色三层取色与形态见状态标签与描述列表节点）
  mask?: boolean;               // 脱敏列：maskValue（配合 v-plain 看明文）
  defaultVisible?: boolean;     // 默认是否显示（用户可改）
  editable?: boolean;           // 行内编辑模式下可编辑
  slot?: string;                // 具名插槽名（复杂单元格）
  compare?: (a: T, b: T) => number; // 表格内排序（仅当数据已全量在前端时使用）
}
```

渲染优先级（同一列自上而下命中即用）：**具名插槽** → `dictType`（字典 label） → `tagColor`（状态标签，由 [状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) `StatusTag` 渲染） → `mask`（脱敏） → `formatter` → 原值（空值统一 `—`）。

- **列来源**：① 页面声明式传入（默认）；② 表单元数据生成（[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)明细区列配置 → 字段清单映射为列，含 `label`/`width`/`fixed`/可见性）；两者按 `prop` 合并，元数据提供默认值、页面声明可覆盖。
- **列宽**：显式 `width` 优先；未指定时按 `minWidth` 自适应（超出容器横向滚动）；「自动列宽」按表头与当前页内容宽度测算（Canvas 测量 + 单元格内边距）后写回列宽；用户拖拽列宽优先于二者（见第 9 节持久化）。
- **列渲染器**：字典列**批量翻译**（一列一次 `translateDictValues`，禁止逐行请求，见 [字典字段](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)）；状态列可选内联切换（复用[开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md) `InlineSwitch`）；金额/日期列统一走 `formatAmount`/`formatDateTime`（[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）。

## 4. 数据流与取数 <a id="dataflow"></a>

```mermaid
flowchart TD
    A["页面：查询条件（查询筛选区）"] --> B["useListPage（请求封装）"]
    C["ProTable：列配置 / 分页 / 排序"] --> B
    B --> D["GET /资源?page&size&order_by&order&筛选"]
    D --> E["后端（白名单校验排序字段 + 数据权限过滤）"]
    E --> B
    B --> F["ProTable 渲染：list / total / loading / error"]
    F --> G["列个性化 useTablePrefs（list.{form_key}）"]
```

| 项 | 设计 |
| --- | --- |
| 取数归属 | 页面用 `useListPage`（[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）持有 `query`/`list`/`total`/`loading`/`error`；`ProTable` 只负责渲染与交互回传，**不自行发请求**（表格明细区可由页面传入数据源或分页接口） |
| 查询变化 | 筛选条件变化回第 1 页；分页/排序变化保留筛选条件（[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)交互约定） |
| 行数据持有 | 列表数据由页面组件持有，不入 Pinia（[《前端开发规范》](../../../../规范/前端开发规范.md)状态管理约定） |
| 局部更新 | 行内状态变更/删除成功后**局部更新该行或重新拉取当前页**，不整表重建 |

## 5. 分页与多列排序 <a id="page-sort"></a>

### 5.1 分页 <a id="pagination"></a>

| 项 | 设计 |
| --- | --- |
| 参数 | `page`（从 1 起）/ `size`；响应 `{list, total, page, size}`（[《API接口规范》](../../../../规范/API接口规范.md)「参数与分页」节） |
| 每页条数 | 默认 **20**，可选 10/20/50/100，**上限 200**；选择结果写入用户偏好（第 9 节） |
| 表单页明细区 | 默认 **10 条/页**（≤ 10 行不分页），与[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)一致 |
| 区布局 | 「总数, 选择页码, 跳页, 每页条数, 页码」靠右，与表格工具栏（靠左）同处表格下方一行 |
| 游标分页 | 日志/审计类超长列表用 `cursor`/`limit`（无总页数）：表格隐藏页码、显示「加载更多」或无限滚动，排序仅支持后端默认序 |
| 数据量保护 | 单页请求 `size ≤ 200`；全量数据不落地前端（导出走 [导入导出](../../08_交互类/01_组件设计_导入导出/01_组件设计_导入导出.md)流式/分批） |

### 5.2 多列排序 <a id="sort"></a>

- **交互**：点击表头切换单列排序（升/降/取消）；**Shift + 点击**叠加多列，表头显示优先级序号（1/2/3），最多 **3 列**；表头悬浮提示当前排序组合。
- **参数序列化**（`useTableSort`）：

```text
单列：order_by=status&order=desc
多列：order_by=status,created_at&order=desc,asc
```

- `order` 与 `order_by` **位置一一对应**，缺省 `desc`；`sortField` 缺省取 `prop`。
- **白名单**：后端按字段白名单校验，**不在白名单的字段忽略该排序项**（不报错、不拼接 SQL）；前端仅在 `sortable=true` 的列开启排序入口，双层防注入。
- **不持久化排序**：排序属会话态（不进用户偏好），页面可通过 `defaultSort` 指定初始排序；数据在前端全量时可用 `compare` 做本地排序（不提交后端）。

## 6. 选择、展开与行交互 <a id="selection"></a>

| 项 | 设计 |
| --- | --- |
| 多选列 | 有批量操作时才出现，宽 48px；行点击**不**默认勾选（需点复选框）；选中集用 `Set` 维护，跨页保留策略由页面声明（默认**不跨页保留**） |
| 批量操作 | 工具栏或操作区按钮随选中态启用/禁用（[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)检查清单）；批量删除二次确认（`ElMessageBox.confirm`） |
| 双击行 | 双击行打开表单 Tab（列表页**无操作列**，见[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)）；可编辑单元格需阻止冒泡避免误触 |
| 展开行 | 展开行承载只读表格明细（最近 N 条、不分页、不承载增删），见[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)；展开内容用插槽 |
| 行内切换 | 状态列可用 [开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md) `InlineSwitch`（行级 loading、失败回滚、局部刷新） |
| 行交互 | 悬停高亮；行高按密度（宽松 `default` / 紧凑 `small`）；斑马纹与边框由主题令牌统一（不逐页配置） |

## 7. 树形模式 <a id="tree"></a>

| 项 | 设计 |
| --- | --- |
| 场景 | 部门管理、菜单管理、字典分类等树形数据（[《概要设计 · 部门管理》](../../../概要设计/08_概要设计_部门管理.md)、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)） |
| 配置 | `tree: { rowKey: 'id', children: 'children', defaultExpandAll?, indent?: number }`，走 `el-table` 原生 `row-key` + `tree-props` |
| 分页 | 树形数据**不分页**（树量级小，一次返回；对齐概设「树形返回不分页」约定） |
| 层级约束 | 层级深度与子节点数由业务侧约束（如部门树最大深度 10、单节点子部门 ≤ 500），前端只展示不校验 |
| 行交互 | 展开/收起由首列缩进箭头承担；树形模式下同样支持多选与双击行 |
| 限制 | 树形模式**不与**虚拟表格模式叠加（`el-table-v2` 不支持树形） |

## 8. 行内编辑模式（供表格明细复用） <a id="inline-edit"></a>

| 项 | 设计 |
| --- | --- |
| 开关 | `editable` prop（表单页编辑态传入 `true`，只读态 `false`）；整表或按列 `column.editable` 控制 |
| 编辑方式 | 单元格内直接渲染字段组件（文本/数字/日期/字典/开关等，复用字段类节点），未保存修改随整体保存提交 |
| 自动空行 | 编辑态表格末行**自动追加一行空明细**供录入；只读态不显示（[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)工具栏节） |
| 空行过滤 | 保存前由调用方调 `getRows({ filterEmpty: true })` 过滤未录入任何数据的行 |
| 校验 | `validate()` expose（基于 `validators`，[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；错误内联展示，`validate()` 返回 `false` 阻止提交 |
| 行操作 | 新增行/删除行/上移/下移由调用方调用 `addRow()` / `removeRow(index)` / `moveRow(from, to)`；删除二次确认 |
| 保存归属 | **事务与整体保存归调用方**（表单页/09 表格明细）：主表 + 明细单事务、`version` 乐观锁、失败整体回滚 |
| 性能 | 行数据逐行响应式（`row.id` 为 key），单元格编辑只触发该行重渲染，不整表重渲染 |

## 9. 列个性化与持久化 <a id="prefs"></a>

按**页面维度**（`form_key`，如 `user_form`）存 `sys_user_preference` 的 `list.{form_key}`（[《概要设计 · 用户喜好》](../../../概要设计/04_概要设计_用户喜好.md)），PC 多设备与移动端读同一份偏好；接口 `GET /preferences/{key}`、`PUT /preferences/{key}`、`DELETE /preferences/{key}`（恢复默认），批量保存走 `PUT /preferences/batch`。

```json
{
  "columns": [{ "prop": "username", "visible": true, "order": 1, "width": 180 }],
  "pageSize": 20,
  "density": "default"
}
```

| 项 | 设计 |
| --- | --- |
| 应用时机 | 渲染前合并：列定义（元数据/声明式）→ 偏好覆盖（显隐/顺序/宽度）→ 计算可见列 |
| 保存时机 | 列设置/密度/每页条数变更后**防抖 500ms** 保存；列宽拖拽结束（`header-dragend`）后保存 |
| 恢复默认 | 「恢复默认」调 `DELETE /preferences/{key}` 并清本地副本（对齐[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)「自定义列」抽屉） |
| 本地回退 | 偏好接口失败/未登录态用 localStorage 副本（键 `bms:table:{form_key}`）快速回退；登录拉取后以服务端为准覆盖 |
| 约束 | 单 key ≤ 64KB（[《概要设计 · 用户喜好》](../../../概要设计/04_概要设计_用户喜好.md)上限）：列数量异常时裁剪并告警；仅保存**展示层**字段，不含数据 |
| 不受偏好影响 | 排序列、页码、展开状态、选中行（会话态，不持久化） |

## 12. 字段权限 / i18n / 脱敏 / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 的列不渲染（后端读时过滤字段，前端不感知）；行内编辑列受 `editable` 约束；列级权限与表单页字段权限同源（`sys_role_field`，[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：列头 `label` 支持 i18n key（元数据驱动时按 locale 下发）；工具栏 tooltip、密度/分页文案、空态与错误态文案走 vue-i18n；**列名与数据不翻译用户输入**。
- **脱敏**：`mask: true` 的列默认脱敏展示（`maskValue`，[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；持 `data:plain` 动作权限时该列渲染明文切换入口（`v-plain`，[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **移动端**：`frontend-mobile` 不用表格（卡片/列表形态，`van-list` + 触底加载），不提供列显隐/顺序；**分页与排序参数口径同源**（`page`/`size`、`order_by`/`order`），每页条数沿用同一份偏好（跨端同步）。

## 13. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 单页数据量 | 默认 20 条，上限 200 条；超长列表（审计/日志）用游标分页 + 虚拟表格（`el-table-v2`，阈值 **200 行**，由 `virtual` prop 开启） |
| 虚拟表格限制 | 虚拟模式下列宽必须显式声明（建议 ≥ 100px），不支持树形/展开行/行内编辑；固定列与自动列宽不适用 |
| 千行列表 | 非虚拟模式下用分页控制行数；字典列批量翻译（一列一次请求）、格式化函数纯函数 + `Intl` 实例缓存（[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |
| 列数 | 建议 ≤ 20 列（超出走列设置裁剪与横向滚动）；列配置计算仅依赖元数据与偏好，无网络开销 |
| 行内编辑 | 行级响应式更新（`row.id` 为 key）、单元格编辑不整表重渲染；`validate()` 只校验已渲染行 |
| 偏好写入 | 防抖 500ms 合并写；失败静默回退本地副本（不阻塞交互） |
| 边界 | 空数据、单页仅 1 条、最后一页被删空后回退上一页、多列排序字段非法、列宽拖拽到极限、树形层级过深（滚动）、编辑态空行未录入、偏好超 64KB 裁剪、游标分页与排序冲突（禁用排序入口） |
| 不支持 | 表格内拖拽行排序（明细行上下移由按钮承载）、列冻结任意位置（仅左右固定）、单元格合并（复杂报表走 [图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)/报表节点）、前端全量排序大数据集 |

## 14. 检查清单 <a id="checklist"></a>

- □ 列配置声明式（`ProTableColumn`）与表单元数据生成两条来源，按 `prop` 合并，渲染优先级正确（插槽 > 字典 > 标签 > 脱敏 > formatter > 原值）
- □ 取数走 `useListPage`（[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）；筛选变化回第 1 页、分页/排序保留筛选；行数据不入 Pinia
- □ 分页：默认 20、可选 10/20/50/100、上限 200；明细区默认 10/页；日志类支持游标分页
- □ 多列排序：表头点击 + Shift 叠加（≤ 3 列，含优先级序号）；`order_by`/`order` 一一对应；后端白名单双层防注入；排序不持久化
- □ 多选列按需（48px、行点击不勾选）；双击行打开表单；展开行承载只读明细；状态列可内联切换（[开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)）
- □ 树形模式（`row-key` + `children`、不分页）与虚拟模式互斥
- □ 行内编辑：`editable` 开关、编辑态末行自动空行、`getRows({filterEmpty:true})` 空行过滤、`validate()` 校验；事务与整体保存归调用方
- □ 列个性化存 `list.{form_key}`（列显隐/顺序/宽度 + 每页条数 + 密度），防抖保存、本地回退、恢复默认；单 key ≤ 64KB
- □ 工具栏按钮（刷新/密度/列设置/全屏/自动列宽/导出）图标 + tooltip；导出参数与列表筛选/排序一致且受 `export` 权限约束
- □ 状态视图：首屏骨架屏、后续遮罩 loading、空态与搜索无结果文案、失败内联错误 + 重试
- □ 字段权限（列可见性/行内编辑）、i18n（列头 key/工具栏/空态）、脱敏（`mask` + `data:plain`）、移动端（卡片形态 + 参数同源）符合第 12 节
- □ 四项上游登记已确认：多列排序参数、`list.{form_key}` 偏好结构、明细区列配置生成表列、导出参数含排序
