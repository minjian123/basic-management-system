## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **异常与空状态**的组件设计：错误页 `ErrorPage.vue`（403/404/500），空状态 `EmptyState.vue`（列表/搜索无结果/待办/消息等场景），骨架屏 `SkeletonBlock.vue`（页面级/区块级占位），内容遮罩 `LoadingMask.vue`（局部刷新 loading），以及组合式函数 `useFeedback.ts`（空/错/载态编排与重试）。适用于管理端全部页面的**兜底呈现**与**加载分级**，保证任何场景下用户有明确引导、系统不白屏。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；页面形态与使用口径依据[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)「错误页」「空状态」「加载状态」「异常兜底」节，以及[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)、[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)（移动端骨架 + 触底加载 + 下拉刷新）；上游协作依据[《前端开发规范》](../../../../规范/前端开发规范.md)（目录、错误提示与加载约定）、[《安全开发规范》](../../../../规范/安全开发规范.md)（不展示技术堆栈）、[《API接口规范》](../../../../规范/API接口规范.md)（统一响应与错误码）；协作节点为[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（axios 拦截、401 跳登录、错误码文案）、[05 展示类 01 通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)（表格空态/局部 loading/骨架）、[05 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)（图表空/错误/降级态）、[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`v-perm` 控制「去创建」按钮）、[07 基础类 03 格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)。

> 本篇为组件设计体系展示类第 05 篇。**范围边界**：**接口错误的统一拦截与错误码文案**归[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（本节点只提供呈现组件与重试入口）；**表格内空态/骨架/局部 loading** 的触发与列渲染归[05 展示类 01 通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)，本节点提供其复用的 `EmptyState`/`SkeletonBlock`/`LoadingMask`；**图表错误/降级态**归[05 展示类 04 图表卡](../04_组件设计_图表卡/04_组件设计_图表卡.md)；按钮内 loading 由 Element Plus 自带，本节点不重复实现；移动端不复用 PC 组件（见第 11 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `ErrorPage.vue` | `src/components/feedback/` | 错误页：403/404/500 插画 + 标题 + 说明 + 主操作；不展示技术堆栈；支持自定义标题/操作 |
| `EmptyState.vue` | `src/components/feedback/` | 空状态：插画/图标 + 文案 + 引导按钮；覆盖列表无数据、搜索无结果、待办为空、消息为空等场景（受权限控制按钮） |
| `SkeletonBlock.vue` | `src/components/feedback/` | 骨架屏：与内容结构一致的占位块（列表/表格/表单/卡片），支持行数、动画开关 |
| `LoadingMask.vue` | `src/components/feedback/` | 内容遮罩 loading：局部刷新时覆盖指定区域（不整页闪烁），支持文案与延时显示 |
| `useFeedback.ts` | `src/utils/useFeedback.ts` | 组合式函数：统一的空/错/载态判定与渲染选择、错误码→文案映射调用、重试动作、延时显示 loading |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，反馈类归 `feedback/`；组合式函数放 `src/utils/`）。
- **插画资源**：空态/错误插画统一放 `src/assets/images/empty-*.svg`（kebab-case，[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)），组件按 `type` 引用，不在组件内内联大段 SVG。

## 3. 错误页 ErrorPage <a id="error-page"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `code` | 403 \| 404 \| 500 | 404 | 错误类型（决定默认插画/标题/操作） |
| `title` | string \| null | null | 自定义标题（缺省按 code） |
| `description` | string \| null | null | 自定义说明（缺省按 code） |
| `actions` | Action[] | [] | 自定义操作（缺省按 code：返回首页/刷新重试/联系管理员） |

| code | 默认文案 | 默认操作 |
| --- | --- | --- |
| 404 | 页面不存在（或已被移除） | 返回首页 |
| 403 | 没有访问权限（如需申请请联系管理员） | 返回首页 / 联系管理员 |
| 500 | 服务开小差了（请稍后重试） | 刷新重试 / 返回首页 |

- 布局：居中插画（SVG）+ 标题 + 说明 + 主操作按钮；**不展示技术堆栈**（[《安全开发规范》](../../../../规范/安全开发规范.md)）。
- 未登录访问受保护路由 → 由[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)拦截跳登录并携带回跳参数（本节点不处理）。
- 路由接入：错误页作为独立路由（`/403`、`/404`、`/500`）或由全局错误处理器按需渲染（登记项②）。

## 4. 空状态 EmptyState <a id="empty"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | 'list' \| 'search' \| 'todo' \| 'message' \| 'custom' | 'list' | 场景（决定默认插画/文案，见下） |
| `title` / `description` | string \| null | null | 自定义文案（缺省按场景） |
| `image` | string \| null | null | 自定义插画（`src/assets/images/` 下资源） |
| `action` | Action \| null | null | 引导按钮（如「去创建」「清除筛选」） |
| `actionPerm` | string \| null | null | 引导按钮权限码（无权限不渲染，[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)） |
| `size` | 'default' \| 'small' | 'default' | 尺寸（表格内/卡片内用 small） |

| 场景 | 默认表现 |
| --- | --- |
| 列表无数据 | 空插画 + 「暂无数据」；有权限时「去创建」主按钮 |
| 搜索无结果 | 「未找到相关内容」+ 清除筛选/重置按钮 |
| 待办为空 | 「暂无待办，享受这一刻」正向引导 |
| 消息为空 | 「暂无消息」 |
| 自定义 | 业务文案引导优先（插画为辅） |

- 空状态优先**文案引导**而非纯插画（[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)「空状态」节）。

## 5. 骨架屏 SkeletonBlock <a id="skeleton"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `variant` | 'list' \| 'table' \| 'form' \| 'card' | 'list' | 与内容结构一致的骨架形态 |
| `rows` | number | 5 | 行数 |
| `animated` | boolean | true | 是否显示动画 |
| `loading` | boolean | true | 是否处于加载态（false 时渲染默认插槽内容） |

- 用于**首屏/页面级**加载；与内容结构一致，避免整页闪烁；表格骨架可复用 [05 展示类 01 通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md) 的首屏骨架。
- 长内容列表首屏骨架行数按可视区估算，加载完成即替换。

## 6. 内容遮罩 LoadingMask <a id="loading"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `loading` | boolean | false | 是否显示遮罩 |
| `text` | string \| null | null | 遮罩文案（i18n） |
| `delay` | number | 200 | 延时显示（ms，避免闪烁；短请求不显示） |
| `fullscreen` | boolean | false | 整页遮罩（默认仅覆盖包裹内容区） |

- 用于**局部刷新**（表格翻页、卡片刷新、区域重载），覆盖局部而非整页；配合 `delay` 避免闪屏。
- 按钮提交 loading 用 Element Plus `el-button :loading`，防重复提交（本节点不重复实现）。
- 首屏 vs 局部权限：首屏用 `SkeletonBlock`，局部用 `LoadingMask`（[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)「加载状态」节）。

## 7. 组合式函数 useFeedback <a id="use-feedback"></a>

```typescript
type FeedbackState = 'loading' | 'empty' | 'error' | 'ready';

interface UseFeedbackOptions<T> {
  loader: () => Promise<T>;
  isEmpty?: (data: T) => boolean;          // 缺省按数组长度/空对象判定
  errorText?: (err: any) => string;        // 缺省走请求层错误码→文案
  retryText?: string;
}

interface UseFeedbackReturn<T> {
  state: Ref<FeedbackState>;
  data: Ref<T | null>;
  error: Ref<{ code?: number; message: string } | null>;
  loading: ComputedRef<boolean>;
  load: () => Promise<void>;
  retry: () => Promise<void>;
}
```

| 行 | 设计 |
| --- | --- |
| 状态机 | `loading → ready / empty / error`；`retry` 回 `loading` 重试 |
| 空判定 | 数组空/`null`/空对象按场景判定（可由 `isEmpty` 覆盖）；搜索无结果区分「有筛选条件」与「真的无数据」 |
| 错误文案 | 缺省调用[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)错误码→i18n 映射；不暴露堆栈 |
| 重试 | `retry()` 重新 `loader`；断网/超时给重试入口（[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)「异常兜底」节） |
| 组件选择 | 页面据 `state` 渲染 `SkeletonBlock`/`EmptyState`/`ErrorPage`（区块级用 `EmptyState` + 重试按钮） |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：空状态引导按钮（如「去创建」）按权限码显隐（`actionPerm`，[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；403 错误页对应无权限场景（由请求层判定），不泄露后端细节。
- **i18n**：错误页/空状态文案、加载文案走 vue-i18n；错误码按 `error.{code}` 映射（[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）；不翻译用户数据。
- **移动端**：不复用 PC 组件；移动端以骨架屏 + 触底加载 + 下拉刷新 + 空状态（Vant `van-empty`/`van-skeleton`）实现，文案与判空口径同源（[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 骨架 | 骨架块轻量（CSS 动画），首屏骨架与内容同结构；加载完成即替换，避免二次布局抖动 |
| 遮罩 | `delay` 防闪屏（短请求不显示）；仅覆盖局部区域，不整页重绘 |
| 插画 | SVG 资源按需引用（`empty-*.svg`），不内联大段；错误页懒加载路由组件 |
| 空判定 | 区分「无数据」与「有筛选但无结果」，避免误导引导 |
| 边界 | 空数组/`null`/空对象、搜索无结果、断网/超时、5xx 重试、401 回跳、403 无权限、超长错误消息、插画缺失回退默认、骨架行数自适应、遮罩与按钮 loading 叠加（避免双重） |
| 不支持 | 接口拦截与错误码映射（请求封装）、表格内空态触发（通用表格）、图表降级态（图表卡）、按钮内 loading（Element Plus）、移动端组件 |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：`ErrorPage`/`EmptyState`/`SkeletonBlock`/`LoadingMask`/`useFeedback` 职责清晰，不重叠请求层与表格/图表内态
- □ 错误页：403/404/500 插画+文案+操作齐备，不展示技术堆栈；401 回跳由请求层处理；独立路由接入
- □ 空状态：列表/搜索/待办/消息场景矩阵；引导按钮受权限控制；优先文案引导；插画 `empty-*.svg`
- □ 加载分级：首屏骨架（与内容同结构）、局部遮罩（`delay` 防闪）、按钮内 loading（Element Plus）
- □ 异常兜底：断网/超时提示与重试；错误码→文案；区分无数据与无结果
- □ 权限（引导按钮 `v-perm`、403 场景）、i18n（文案/错误码）、移动端（骨架+触底+下拉刷新，口径同源）符合第 10 节
- □ 性能边界：SVG 按需、错误页懒加载、遮罩防闪、骨架替换无抖动
