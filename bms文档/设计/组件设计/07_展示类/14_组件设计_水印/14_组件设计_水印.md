## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 **水印**的组件设计：水印容器件（包裹内容叠加文字/图片水印，防截图泄露）与水印内容组装（水印内容生成、动态更新、防篡改；归**水印能力**——继承链上的能力层，绘制/注入由渲染实现承担）。适用于**敏感数据页面**（用户/角色/权限、审计日志、报表与大屏、文件预览、财务数据）的**可见水印**，标识访问者身份与时间，形成威慑与溯源依据。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「认证与安全」章节；上游设计依据[《安全开发规范》](../../../../规范/安全开发规范.md)（数据防泄露、敏感信息保护）、[《概要设计 · 审计合规》](../../../概要设计/28_概要设计_审计合规.md)（审计数据仅授权人员查看）、[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（报表数据防泄露）；协作节点为[基础类「格式化工具」](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（时间格式化）、[展示类「图表卡」](../04_组件设计_图表卡/04_组件设计_图表卡.md)/[展示类「审计差异查看」](../09_组件设计_审计差异查看/09_组件设计_审计差异查看.md)（敏感内容承载）、[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)（颜色/透明度）。

> 本篇为「水印」节点。**范围界定**：水印是**可见威慑**（非加密、非 DRM），不替代后端的数据脱敏与访问控制（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；**数据脱敏**归各业务字段与权限；**隐藏水印/数字水印/盲水印**等隐写方案不在 MVP；移动端按需实现（见第 2 / 8 节）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 水印容器件 | 包裹内容叠加重复水印（文字/图片）、旋转/间距/透明度/层级、全屏或局部、响应式重绘、防篡改监听 |
| 水印内容组装（消费水印能力） | 生成水印内容（用户名+工号+时间）、动态更新（定时刷新时间戳）、防篡改（DOM 变更监听并恢复） |


## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 水印文案 | `content`：一行或多行；缺省由水印能力组装（用户名/工号/时间） |
| 图片水印 | `image`：图片水印（logo），与 `content` 可叠加 |
| 字体 | `font`：颜色（引用令牌）、字号、字重、字体族；透明度内置于颜色或 `opacity` |
| 透明度 | `opacity`：水印整体透明度（默认 0.15，不宜过高遮挡内容） |
| 旋转 | `rotate`：旋转角度（默认 -22 度） |
| 间距与偏移 | `gap`：水印间距 `[水平, 垂直]`（默认 [100, 100]）；`offset`：偏移（默认 [0, 0]） |
| 单个水印尺寸 | `width` / `height`：默认 120 |
| 层级 | `zIndex`：默认 9（高于内容、低于弹窗遮罩） |
| 范围 | `fullscreen`：是否全屏（整页）水印；false 时仅包裹区域 |
| 时间 | `showTime`：是否包含时间（配合定时刷新） |
| 交互 | 水印就绪（`ready`）、水印内容更新（`change`，时间戳刷新） |
| 对外语义 | 重绘/更新时间、导出水印图（可选） |

## 4. 水印内容与形态 <a id="content"></a>

| 项 | 设计 |
| --- | --- |
| 内容 | 默认多行：`用户名` / `工号或账号` / `yyyy-MM-dd HH:mm`（[基础类「格式化工具」](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）；可按页面配置 |
| 图片水印 | logo 图片 + 文案叠加（可选） |
| 颜色/透明度 | 颜色引用设计令牌（次要文本色）+ 低透明度（默认 0.15），深色主题下用浅色 |
| 旋转/间距 | 默认 -22°、间距 100×100；密集内容可调小间距 |
| 全屏 vs 局部 | 敏感页整页水印（`fullscreen`）；弹窗/预览局部（包裹区域） |
| 响应式 | 容器尺寸变化重绘（间距按容器计算），保证铺满不空洞 |
| 打印 | 打印时水印同样输出（打印样式保留水印层）；导出图片可选叠加 |
| 不可选中 | 水印层不可选中、不拦截指针操作，避免干扰操作 |

## 5. 防篡改 <a id="protect"></a>

| 项 | 设计 |
| --- | --- |
| DOM 篡改监听 | 变更监听：水印层被删除/改样式（如通过开发者工具移除）时**自动重新插入**并恢复样式 |
| 内容刷新 | `showTime` 时按分钟级刷新时间戳（水印能力侧定时刷新），保持水印时效 |
| 层级 | 水印层置于内容之上、弹窗遮罩之下，防止被内容覆盖或遮挡弹窗 |
| 局限说明 | 可见水印为**威慑与溯源**手段，不能阻止截图或专业去除；真正的防护依赖访问控制、脱敏与审计 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：水印内容取当前登录用户（登录态内建）；水印**不替代**访问控制与脱敏（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；无权限用户无法进入敏感页（路由/接口层拦截）。
- **i18n**：水印为用户名/工号/时间等数据，**不翻译**；文案标签（如「工号」）如使用则走全局语言能力。
- **移动端**：按需实现（同一契约多实现）；敏感页以平铺水印实现，内容与透明度口径同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 水印层一次性生成平铺图案展示；不逐元素 DOM；不拦截指针 |
| 重绘 | 容器尺寸变化防抖重绘；全屏水印监听窗口尺寸变化 |
| 刷新 | 时间戳按分钟级刷新（非每秒），降低开销 |
| 防篡改 | 变更监听轻量；避免与水印自身重绘形成循环（重绘时不触发递归） |
| 边界 | 容器为 0 尺寸（延迟绘制）、深色主题、间距过密遮挡、透明度不当、弹窗内嵌套（层级）、打印样式、开发者工具移除（恢复）、超长内容 |
| 不支持 | 隐藏/数字/盲水印（MVP 外）、真正的截图防护、数据脱敏（各字段）、移动端宿主装配（各端工程） |

## 10. 检查清单 <a id="checklist"></a>

- □ 组成分层：水印容器件与水印绘制、水印内容组装（生成/时间刷新/防篡改）
- □ 内容：用户名/工号/时间多行；可选图片水印
- □ 形态：颜色/透明度（令牌）、旋转、间距、层级、全屏/局部、响应式重绘、打印保留、不可选中
- □ 防篡改：变更监听自动恢复、时间戳分钟级刷新、层级正确
- □ 权限（不替代访问控制/脱敏）、i18n（数据不翻译）、移动端（平铺水印，口径同源）符合第 8 节
- □ 性能边界：平铺生成、尺寸变化防抖、时间刷新降频、防篡改无递归
- □ 三项上游登记已确认：敏感页水印口径、水印颜色与透明度令牌、报表/大屏水印
