## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **审计差异查看**的组件设计：总容器 `AuditDiffViewer.vue`（列表 + 详情差异 + 链校验装配），变更列表 `DiffTable.vue`（记录级列表），字段级差异 `FieldDiff.vue`（旧值/新值对比，类型感知 + 脱敏），链校验面板 `ChainVerifyPanel.vue`（`prev_hash`/`record_hash` 展示与校验结果、篡改定位），以及组合式函数 `useAuditDiff.ts`（分片时间范围查询、详情取数、链校验、值渲染分发）。适用于**数据变更审计**页（PC 管理端，审计管理员）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**审计合规**模块「字段级变更审计」「审计数据查询」；上游设计依据[《概要设计 · 审计合规》](../../../概要设计/28_概要设计_审计合规.md)（`sys_data_audit_log`、字段旧值/新值、哈希链、三权分立、按月分片、接口与错误码）与[《架构设计 · 审计哈希链》](../../../架构设计/17_架构设计_子系统_审计哈希链.md)（链构造与校验、跨月衔接、归档导出）、[《架构设计 · 数据访问与分片》](../../../架构设计/11_架构设计_子系统_数据访问与分片.md)（按月分片路由）；协作节点为[05 展示类 01 通用表格](../01_组件设计_通用表格/01_组件设计_通用表格.md)（列表）、[05 展示类 03 状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（字段值格式化与只读渲染）、[05 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（空/加载/错误/缺分片键提示）、[04 字段类 08 富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)（富文本值只读渲染与清洗）、[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)、[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`log:query`/`log:manage`）。

> 本篇为组件设计体系展示类第 9 篇。**范围边界**：审计**写入**（ORM 事件捕获、哈希链构造、RocketMQ 有序消费、分片落库）归[《架构设计 · 审计哈希链》](../../../架构设计/17_架构设计_子系统_审计哈希链.md)；**操作/登录/开放接口日志**列表归[《概要设计 · 操作日志》](../../../概要设计/11_概要设计_操作日志.md)（本节点只覆盖**数据变更审计差异**）；**链校验工具本身**（逐条重算）在后端，本节点只触发与展示结果；归档数据查询复用归档管理入口；移动端不提供（见第 10 节）。

## 3. 总体结构 <a id="layout"></a>

```mermaid
flowchart TD
    F["筛选：表名 / 记录 ID / 操作人 / 时间范围（必填分片键）"]
    LIST["DiffTable（变更记录列表）<br/>表名 · 记录ID · 字段数 · 操作人 · 时间 · 链状态"]
    DIFF["FieldDiff（字段级旧值 → 新值）<br/>类型感知 · 脱敏 · 折叠"]
    CHAIN["ChainVerifyPanel（链字段与校验）<br/>prev_hash/record_hash · 校验结果 · 篡改定位"]
    F --> LIST --> DIFF
    LIST --> CHAIN
```

| 区域 | 内容 |
| --- | --- |
| 筛选区 | 表名、记录 ID、操作人、**时间范围（分片键，必填）**；查询/重置 |
| 变更列表 | 记录级行：表名、记录 ID、变更字段数、操作人、时间、链状态（正常/待校验） |
| 详情差异 | 展开某记录：按字段列出旧值 → 新值（`FieldDiff`） |
| 链校验 | 记录详情展示 `prev_hash`/`record_hash`；面板可触发/查看链校验结果与篡改定位 |

## 4. 变更列表 DiffTable <a id="list"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `filters` | `{ table?, recordId?, operator?, start, end }` | — | 筛选（`start`/`end` 必填，分片路由） |
| `rows` | AuditChangeRow[] | [] | 记录（`table_name`/`record_id`/`fields`/`operator`/`created_at`/`chainStatus`） |
| `cursor` | boolean | false | 游标分页（大数据量兜底） |

| 项 | 设计 |
| --- | --- |
| 分片键 | **时间范围必填**（按月分片路由）；缺失时拒绝并提示（91002），前端查询前校验 |
| 筛选 | 表名/记录 ID/操作人/时间范围；后端按分片路由 |
| 分页 | 分页；大数据量游标分页兜底（last_id + 排序键） |
| 链状态 | 展示记录链是否已校验/正常（由链校验结果回填，缺省「未校验」） |
| 列表列 | 表名、记录 ID、变更字段数、操作人、时间（[07 基础类 03 格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）、操作（查看差异） |
| 状态 | 加载/空/错误（[05 展示类 05 异常与空状态](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |

## 5. 字段级差异 FieldDiff <a id="diff"></a>

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `field` | string | 字段名（可映射元数据 label） |
| `oldValue` / `newValue` | any | 旧值/新值（JSON 序列化，已脱敏） |
| `valueType` | 'text' \| 'number' \| 'date' \| 'boolean' \| 'json' \| 'richtext' \| 'dict' | 渲染类型（缺省按值推断） |

| 类型 | 渲染 |
| --- | --- |
| 文本/长文本 | 纯文本；长值折叠 2 行 + 展开（复用 [05 展示类 03 状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 口径） |
| 数字/金额 | `formatNumber`/`formatAmount`（[07 基础类 03 格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |
| 日期时间 | `formatDateTime`（用户时区） |
| 布尔 | 是 / 否（语义色可选，复用 [05 展示类 03 状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)） |
| JSON | 结构化展示（格式化 + 折叠；不裸文本） |
| 富文本 | 纯文本摘要或白名单清洗后渲染（[04 字段类 08 富文本字段](../../06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)） |
| 字典/枚举 | label 翻译（[04 字段类 01 字典字段](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)/[04 字段类 08 开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md) 口径） |
| 脱敏 | 敏感字段（密码/token/密钥/手机号等）**后端已脱敏**，前端不再还原；展示 `***` |

- 差异呈现：`旧值 → 新值` 左右对比（新增字段新值仅显示、删除字段旧值仅显示）；变化字段高亮（新增/修改/删除色）。
- 富文本/HTML 类新值必须**白名单清洗**后渲染（防存储型 XSS）。

## 6. 链字段与校验 ChainVerifyPanel <a id="chain"></a>

| 项 | 设计 |
| --- | --- |
| 链字段展示 | `prev_hash`/`record_hash` 缩写（前 8 位 + …）+ 悬浮/点击查看全文 + 复制 |
| 校验入口 | 按租户/月份范围触发链校验（`log:manage`）；结果展示通过/异常 |
| 校验结果 | 通过：绿色提示；异常（91001）：列出被篡改记录定位（`id`/时间/摘要）并可**跳转定位**到列表对应行 |
| 任务状态 | 校验进行中（91004）提示稍后查询结果 |
| 只读 | 本模块全部只读接口，无写操作 |

## 7. 组合式函数 useAuditDiff <a id="use-audit"></a>

```typescript
interface UseAuditDiffOptions { onVerified?: (r: VerifyResult) => void; }
interface UseAuditDiffReturn {
  filters: Ref<{ table?: string; recordId?: string; operator?: string; start: string; end: string }>;
  rows: Ref<AuditChangeRow[]>;
  detail: Ref<AuditChangeDetail | null>;
  verifying: Ref<boolean>;
  verifyResult: Ref<VerifyResult | null>;
  loading: Ref<boolean>;
  requireRange: ComputedRef<boolean>;   // 时间范围是否已填（分片键）
  loadList: (cursor?) => Promise<void>;
  loadDetail: (id: string) => Promise<void>;
  verifyChain: (scope: { months: string[] }) => Promise<void>;
  valueKind: (field: string, value: any) => string;
}
```

| 行 | 设计 |
| --- | --- |
| 分片键 | `requireRange` 校验时间范围；未填时禁用查询并提示（91002） |
| 取数 | `loadList`/`loadDetail` 走 `log:query`；大数据量游标分页 |
| 链校验 | `verifyChain` 走 `log:manage`；异常定位回填 `rows` 的链状态并支持跳转 |
| 值渲染 | `valueKind` 按字段元数据/值推断渲染类型；脱敏值直接展示 `***` |
| 错误 | 91001 链异常、91002 缺分片键、91003 不存在（已归档）、91004 校验中，按码提示（i18n） |
| 归档 | 热表与归档库均未命中 → 提示已归档至冷存储（91003）；归档库只读查询复用归档管理入口 |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：查询 `log:query`（审计管理员）；链校验触发/巡检结果 `log:manage`；三权分立（审计管理员只读，无写权限，[《概要设计 · 审计合规》](../../../概要设计/28_概要设计_审计合规.md)「权限与配置」节）；后端 `require_permission` 兜底（[07 基础类 02 权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：界面文案、错误码（`error.910xx`）走 vue-i18n；字段名可映射元数据 label；**审计值原文不翻译**（字典/枚举值按 01/09 口径翻译展示）。
- **移动端**：**不提供**审计查询（审计数据仅管理端审计管理员查看，[《概要设计 · 审计合规》](../../../概要设计/28_概要设计_审计合规.md)「页面清单」节）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 分包 | 审计差异查看按需分包懒加载 |
| 列表 | 分页 + 游标兜底；时间范围限定分片；避免无时间范围全分片扫描（91002） |
| 差异渲染 | 长值折叠、JSON 结构化折叠、富文本摘/清洗；变化字段高亮；按需展开 |
| 链校验 | 重操作单独限流；进行中提示；结果大范围时摘要 + 定位 |
| 边界 | 缺时间范围（91002）、记录不存在/已归档（91003）、校验中（91004）、链异常（91001）、脱敏值、空旧值/空新值（新增/删除字段）、超长值/大 JSON、富文本清洗、游标分页、热点月份限流 |
| 不支持 | 审计写入与链构造（后端）、链校验算法（后端）、操作/登录日志列表（操作日志）、归档执行（归档管理）、移动端 |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：`AuditDiffViewer` 装配、`DiffTable` 列表、`FieldDiff` 字段差异、`ChainVerifyPanel` 链字段与校验、`useAuditDiff` 状态与取数，职责不重叠
- □ 筛选：表名/记录 ID/操作人/**时间范围必填（分片键）**；缺范围提示 91002；分页 + 游标兜底
- □ 列表：记录级行（表名/记录ID/字段数/操作人/时间/链状态）；点击展开详情
- □ 字段差异：旧值 → 新值；类型感知（文本/数字/日期/布尔/JSON/富文本/字典）；脱敏值展示 `***`；新增/删除字段单侧值；长值折叠
- □ 链字段：`prev_hash`/`record_hash` 缩写 + 全文/复制；校验结果（通过/异常 91001 + 篡改定位跳转）；校验中 91004
- □ 权限（`log:query`/`log:manage`、审计管理员只读）、i18n（文案/错误码，值不翻译）、移动端（不提供）符合第 10 节
- □ 性能边界：分包、游标分页、长值/JSON 折叠、富文本清洗、链校验限流
- □ 三项上游登记已确认：差异查看交互契约、前端链字段与校验结果展示、差异查看分包与大数据渲染
