## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 **快捷入口**的组件设计：宫格件（图标 + 名称的多入口宫格、路由跳转、权限过滤、可选角标/分组、列数自适应）与入口编排（入口配置取数、按权限过滤、路由跳转、角标绑定）。适用于**首页工作台快捷入口卡**、**移动端工作台快捷入口**、**个人中心/看板常用入口**。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**首页工作台**「快捷入口卡」；上游设计依据[《概要设计 · 首页工作台》](../../../概要设计/35_概要设计_首页工作台.md)（内置快捷入口卡、卡片注册表、个人布局定制）、[《架构设计 · 首页工作台》](../../../架构设计/29_架构设计_子系统_首页工作台.md)（内置卡渲染器 `render_key`）；视觉依据[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)「卡片形态规范」（快捷入口卡：图标宫格 3-4 列、入口数据来自前端可配置默认菜单白名单、点击路由跳转）；协作节点为[交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)（入口图标 icon key）、[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（按权限过滤入口）、[展示类「通知与消息」](../06_组件设计_通知与消息/06_组件设计_通知与消息.md)（角标口径）、[基础类「格式化工具」](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)。

> 本篇为「快捷入口」节点。**范围边界**：**动态菜单与路由注册**归[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)（本节点只是入口的**呈现与跳转**，不新增路由）；**工作台卡片容器/编辑定制/三级模板**归[《布局设计 · 首页工作台》](../../../布局设计/13_布局设计_首页工作台.html)与工作台页面；**入口数据的持久化**归[《概要设计 · 用户喜好》](../../../概要设计/04_概要设计_用户喜好.md) 或卡片配置（登记项①）；移动端按需实现（见第 8 节）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 快捷入口宫格件 | 图标 + 名称、列数自适应（3/4 列）、点击路由跳转、权限过滤、可选角标、分组标题、空态、图标 key 解析（复用图标选择器） |
| 入口编排（随组件内聚） | 入口配置取数、按权限过滤、跳转、角标绑定、排序与去重 |

- 图标渲染复用 [交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md) 的统一 icon key 解析与降级。
- 权限过滤消费权限上下文能力（继承链上的能力域基类），不在组件内自建权限判定。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 入口项 | `entries`：入口项集合（见第 4 节） |
| 列数 | `columns`：3 / 4 / `auto`；`auto` 按容器宽度（移动端 4 列、窄容器降列） |
| 图标尺寸 | `iconSize`：默认 22（对齐设计令牌：内联 14/菜单 16/按钮 20，此处宫格用 22-24） |
| 名称显隐 | `showLabel`：是否显示名称（纯图标模式） |
| 权限过滤 | `filterByPerm`：是否按权限过滤入口（默认菜单白名单 + 业务/动作权限） |
| 可编辑 | `editable`：是否可编辑（工作台编辑态，支持排序/增删，由工作台页面调用） |
| 交互 | 点击入口（`open`，携带入口项）、路由跳转（`navigate`，由父级路由或组件内跳转） |
| 对外语义 | 入口设置与可见入口读取（过滤后的入口） |

## 4. 入口数据与权限 <a id="data-perm"></a>

| 语义项 | 说明 |
| --- | --- |
| 入口项结构 | `key`（唯一标识：菜单/表单 code）、`label`（名称，i18n）、`icon`（icon key）、`route`（目标路由）、`badge`（角标，可选）、`group`（分组，可选）、`order`（排序，可选）、`perm`（权限码，可选；无则登录可见） |
| icon key | 前缀 `el:` / `biz:` / `custom:`（解析见[交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)） |
| 入口来源 | 默认菜单白名单（前端可配置）或卡片配置下发的入口项；由工作台卡片元数据/用户布局决定 |
| 权限过滤 | `filterByPerm` 为真时按 `perm` 与用户已授权菜单/动作过滤，**无权限入口不渲染**（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)） |
| 跳转 | `route` 为目标路由；**动态路由由前端按菜单注册**，入口只做跳转；未注册路由不渲染并告警（防白屏） |
| 角标 | `badge` 显示（如待办数），实时性由数据来源（通知/待办）决定（[展示类「通知与消息」](../06_组件设计_通知与消息/06_组件设计_通知与消息.md) 口径） |
| 排序/去重 | 按 `order` 排序；`key` 去重 |
| 编辑（可选） | 工作台编辑态支持增删/排序入口（`editable`），保存到用户布局/卡片配置 |

## 5. 形态与响应式 <a id="layout"></a>

| 项 | 设计 |
| --- | --- |
| 宫格 | 图标（上）+ 名称（下）的等高宫格；列数 `columns` 或 `auto` |
| 响应式 | 宽容器 4 列、窄容器/移动端降列（对齐[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)）；卡片内按卡片宽度自适应 |
| 图标 | 统一走图标选择器的 icon key 解析与降级；尺寸走令牌；缺失图标降级（问号） |
| 悬停 | 图标底色/缩放反馈；tooltip 显示名称（纯图标模式必需） |
| 分组 | `group` 存在时按分组小标题分块（可选） |
| 空态 | 无可见入口（权限过滤后为空）→ 空态（[展示类「异常与空状态」](../05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 加载 | 入口配置异步加载时骨架（复用 05） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：入口按 `perm` 与用户授权过滤，无权限不渲染（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；目标路由另有路由守卫兜底；角标数据沿用来源模块权限。
- **i18n**：入口名称由菜单 i18n 附表按 locale 下发；界面文案走全局语言能力。
- **移动端**：按需实现（同一契约多实现）；宫格（4 列）实现，入口数据与权限过滤同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 入口数量少（≤ 8-12）；图标按需解析与缓存；宫格轻量渲染 |
| 取数 | 入口随卡片元数据/布局接口下发（不额外请求）；角标数据独立短缓存 |
| 权限 | 过滤在前端缓存之上（登录后权限已缓存），不逐入口请求 |
| 边界 | 权限过滤后为空、路由未注册、图标缺失降级、角标 0/超 99、纯图标模式 tooltip、窄容器降列、编辑态排序/增删 |
| 不支持 | 动态路由注册（前端架构）、卡片容器与模板（布局/工作台）、入口持久化实现（用户喜好/卡片配置）、移动端宿主装配（各端工程） |

## 10. 检查清单 <a id="checklist"></a>

- □ 组成分层：快捷入口宫格件呈现、入口编排取数/过滤/跳转；图标复用图标选择器解析
- □ 入口数据：`key/label/icon/route/badge/group/order/perm`；按 `order` 排序、`key` 去重
- □ 权限：`perm` 过滤，无权限不渲染；路由未注册拦截提示（防白屏）
- □ 形态：图标 + 名称、3/4 列/auto、响应式降列、悬停反馈、纯图标 tooltip、分组、角标、空/加载态
- □ 编辑（可选）：工作台编辑态增删/排序，持久化到用户布局
- □ 权限（`perm`/路由守卫）、i18n（菜单 i18n）、移动端（宫格 4 列，口径同源）符合第 8 节
- □ 性能边界：随布局下发不额外请求、图标缓存、角标短缓存、入口数量受限
- □ 三项上游登记已确认：快捷入口数据与用户配置、入口卡形态与列数、路由未注册防护
