## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **级联选择**的组件设计：多级联动字段 `CascaderField.vue`（多级下拉联动、逐级加载、路径选择与回显）与组合式函数 `useCascader.ts`（选项取数、懒加载、路径/值转换、搜索、多选）。适用于**行政区划**（省/市/区）、**多级分类**（产品/物料分类）、**层级字典**等「逐级下钻」的选择场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态 disabled 回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 部门管理》](../../../概要设计/08_概要设计_部门管理.md)（层级组织）、[《概要设计 · 字典管理》](../../../概要设计/09_概要设计_字典管理.md)（层级字典/多级分类）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[04 字段类 04 树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（树形选择，含「含下级」）、[04 字段类 01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典级联 `DictCascader`）、[05 展示类 03 状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（只读路径回显）。

> 本篇为组件设计体系字段类第 12 篇。**范围边界**：**树形勾选/含下级过滤**归 [04 字段类 04 树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（本节点为**单路径下钻**的级联下拉）；**字典级联**（`DictCascader`）已在 [04 字段类 01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)覆盖，本节点面向**通用层级数据**（行政区划/分类）与懒加载大数据；**层级数据的维护**归对应模块（部门/字典）；移动端不复用（见第 9 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `CascaderField.vue` | `src/components/field/` | 级联字段：多级下拉联动、懒加载、任意级可选、多选、可搜索、路径回显、清除、只读回显、禁用 |
| `useCascader.ts` | `src/utils/useCascader.ts` | 组合式函数：选项取数（静态/懒加载）、路径与值转换、搜索、多选扁平化、缓存与去重 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（字段控件归 `field/`；组合式函数放 `src/utils/`）。
- 基于 Element Plus `el-cascader` 定制（`props`/`lazy`/`lazyLoad`/`checkStrictly`/`multiple`）。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `(string \| number)[]` / Array | null | 选中值：单选取路径数组（如 `['广东省','深圳市','南山区']`）或末级值；多选为路径数组的数组 |
| `options` | `CascaderOption[]` | [] | 静态层级选项（`{ value, label, children?, disabled?, leaf? }`） |
| `lazy` | boolean | false | 是否懒加载（配合 `load`） |
| `load` | `(node, resolve) => void` | null | 懒加载子级回调（后端按 parent 拉取） |
| `checkStrictly` | boolean | true | 是否允许选择任意级（true）或仅末级（false） |
| `multiple` | boolean | false | 是否多选（多路径） |
| `filterable` | boolean | true | 是否可搜索（本地或远程） |
| `clearable` | boolean | true | 可清除 |
| `emitPath` | boolean | true | 值是否含完整路径（false 仅末级值） |
| `showPath` | boolean | true | 选中标签是否显示完整路径 |
| `expandTrigger` | 'click' \| 'hover' | 'click' | 展开触发方式 |
| `disabled` | boolean | false | 禁用 |
| `readonlyText` | boolean | false | 只读态以「省 / 市 / 区」纯文本回显 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | any | 值变化 |
| `change` | value | 值变化（含路径） |

- 暴露方法：`setValue(v)`、`clear()`、`getCheckedNodes()`。

## 4. 交互与形态 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 逐级联动 | 选择上级后展开下级；`expandTrigger` 点击/悬停 |
| 任意级可选 | `checkStrictly=true` 允许选择非末级（如只选省）；false 仅末级可选 |
| 懒加载 | 大数据/深层（如全国区划）用 `lazy` + `load`：按父节点拉子级，缓存已加载节点；加载中显示 loading |
| 搜索 | `filterable` 本地过滤或远程搜索（部分层级数据）；搜索结果显示完整路径 |
| 多选 | `multiple` 选择多条路径；标签以路径展示，可逐个移除 |
| 回显 | 单选显示完整路径（如「广东省 / 深圳市 / 南山区」）；`showPath` 控制；无 label 回退 value |
| 清除 | `clearable` |
| 只读 | `disabled` 置灰；`readonlyText` 以「省 / 市 / 区」纯文本回显（对齐[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)只读口径） |
| 空态 | 无可选项时展示占位 |

## 5. 数据与缓存 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 选项来源 | 静态 `options`（小数据，如产品分类）或懒加载接口（行政区划等大数据） |
| 懒加载 | `load(node, resolve)` 按 `node.value` 请求子级；已加载节点缓存，避免重复请求；失败可重试 |
| 值转换 | `emitPath`：true 存完整路径（便于回显与下钻），false 存末级值（需配合 label 查询）；由业务统一（登记项②） |
| 回显 | 已有值为路径/末级码 → 反查 label 回显；懒加载下需按路径逐级加载再回显（`useCascader` 处理） |
| 缓存 | 层级数据按父节点缓存；行政区划类可本地静态包或接口缓存 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：编辑性由 `editable`（[07 基础类 02 权限指令](../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制；选项可见范围由后端数据权限过滤。
- **i18n**：占位、加载/空态、搜索无结果走 vue-i18n；层级 label 由数据源按 locale 下发；用户选择值不翻译。
- **移动端**：不复用 PC 组件；移动端以 `van-cascader` 级联弹出实现，值与路径口径同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 懒加载 | 仅请求展开层级；已加载节点缓存；避免一次性拉全树 |
| 搜索 | 本地过滤或远程搜索（防抖）；大数据用远程 |
| 回显 | 懒加载下按路径逐级加载再回显（可显示已存 label 避免卡顿） |
| 渲染 | 每级列表独立；超长路径标签省略 + title 全文 |
| 边界 | 无可选项、懒加载失败重试、深层级、任意级/末级可选、多选去重、路径 vs 末级值、已选节点被停用（回退显示原值）、窄容器、禁用 |
| 不支持 | 树形勾选/含下级（04 树选择字段）、字典级联（01 字典字段 `DictCascader`）、层级数据维护（部门/字典模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：`modelValue`/`update:modelValue` + `change`；暴露 setValue/clear/getCheckedNodes
- □ 多级联动（点击/悬停）、懒加载（按父拉取 + 缓存 + loading + 失败重试）、任意级可选（`checkStrictly`）
- □ 单选/多选、可搜索（本地/远程）、清除、路径回显（`showPath`）、无 label 回退 value
- □ `emitPath` 值口径（完整路径 vs 末级值）与回显；已选节点停用回退
- □ 形态：label 上方、窄容器单列；`disabled` 置灰；`readonlyText` 路径纯文本回显
- □ 权限（`editable`）、i18n（文案/层级 label）、移动端（van-cascader，口径同源）符合第 8 节
- □ 性能边界：懒加载缓存、远程搜索防抖、深层级回显、超长路径省略
- □ 三项上游登记已确认：组件类型白名单扩展、层级数据接口与值口径、字段形态与只读口径
