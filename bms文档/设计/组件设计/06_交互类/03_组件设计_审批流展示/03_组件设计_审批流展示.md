## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **审批流展示与操作**的组件设计：流程进度 `FlowProgress.vue`（简化节点进度、当前节点高亮）、审批时间线 `ApprovalTimeline.vue`（全链路轨迹）、审批操作面板 `ApprovalActionPanel.vue`（同意/驳回/转办/撤回/评论），可选 BPMN 只读图 `BpmnViewer.vue`（bpmn-js 懒加载、高亮当前节点），以及组合式函数 `useApproval.ts`（实例/记录取数与审批提交）。适用于**流程实例详情**、**我的待办/已办审批**、**我发起的**与**业务单据内嵌审批区**（PC + 移动端）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**工作流管理**模块；上游设计依据[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)（流程实例、审批执行与会签/或签、审批记录、接口与错误码）、[《架构设计 · 工作流》](../../../架构设计/17_架构设计_子系统_工作流.md)（BPMN 定义/实例执行、bpmn-js 选型、前端高亮）；页面形态依据[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)「详情页」节（审批详情：状态条 + 关键信息卡 + 流转记录时间线 + 底部操作栏同意/驳回/转办）与[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（审批区嵌于记录详情内的排版）；协作节点为[状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（审批状态标签取色与只读字段）、[弹窗抽屉表单](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（驳回/撤回二次确认与评论弹窗）、[富文本字段](../../04_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)（审批意见富文本，可选）、[文件上传字段](../../04_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（审批附件）、[请求封装](../../07_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（取数与幂等提交）、[权限指令](../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`wf:approve`）、[格式化工具](../../07_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（时间格式化）。

> 本篇为组件设计体系交互类第 03 篇。**范围边界**：**流程建模**（bpmn-js 拖拽画布、节点属性、版本发布）归流程建模页与[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)，本节点只做**只读展示**（BpmnViewer 不可编辑）；流程实例列表/待办列表的表格渲染归 [通用表格](../../05_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)，筛选归 [查询筛选区](../../05_展示类/02_组件设计_查询筛选区/02_组件设计_查询筛选区.md)；状态标签取色归 [状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)；移动端不复用 PC 组件（见第 10 节）。

## 3. 流程进度 FlowProgress <a id="flow-progress"></a>

### 3.1 Props 与事件 <a id="flow-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `nodes` | FlowNode[] | [] | 实例节点序列（含节点名、审批人、状态、时间、是否会签），由实例详情接口下发 |
| `currentNodeId` | string \| null | null | 当前节点（高亮 + 定位） |
| `orientation` | 'horizontal' \| 'vertical' | 'horizontal' | 横/纵向；窄容器与移动端用 `vertical` |
| `status` | 'running' \| 'finished' \| 'rejected' \| 'abnormal' | 'running' | 实例状态（决定整体语义色与已完成/驳回展示） |
| `compact` | boolean | false | 紧凑模式（仅节点圆点 + 名称，用于卡片摘要） |
| `showAssignee` | boolean | true | 是否展示节点审批人/时间 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `node-click` | node | 点击节点（可联动时间线定位该节点记录） |

- `FlowNode`：`{ nodeId, name, status: 'done'|'active'|'pending'|'rejected'|'skipped', assignees?: {id,name}[], signed?: boolean, time?: string, rejectedTarget?: string }`。

### 3.2 节点状态与形态 <a id="flow-states"></a>

| 状态 | 语义色 | 表现 |
| --- | --- | --- |
| 已完成 `done` | `--color-success` | 实心节点 + 对勾，连线着色 |
| 当前 `active` | `--color-primary` | 高亮节点（描边/脉冲），文案「进行中」，审批人待处理 |
| 待处理 `pending` | `--color-info` | 空心节点，连线灰色 |
| 驳回 `rejected` | `--color-danger` | 节点叉号；被驳回指向的目标节点标 `rejectedTarget` |
| 跳过 `skipped` | `--color-info` | 虚线/置灰（分支未走路径，与并行分支互斥） |

- **当前节点固定高亮并可自动滚动到可视区**（横向超宽时容器内滚动/居中定位）。
- **会签节点**聚合展示为「已完成 n / 共 m」（`signed=true` 时在节点下显示进度），点击展开该节点各审批人处理状态（浮层或时间线定位）。
- **分支路径**：默认只展示主干/已走路径；未走分支以「跳过/置灰」降级展示，避免复杂 BPMN 图导致进度条不可读。需要完整图形时用可选 BPMN 只读图（第 6 节）。

### 3.3 数据来源 <a id="flow-data"></a>

- `nodes` 来自实例详情接口返回的**节点序列与当前节点**（见第 9 节登记项①）；节点顺序即流程推进顺序，包含已走与未走节点。
- **不解析 BPMN XML 生成进度**：进度条消费后端结构化的节点序列，避免前端解析 BPMN 带来的复杂分支计算；完整图形才由 `BpmnViewer` 用 XML 渲染。

## 4. 审批时间线 ApprovalTimeline <a id="timeline"></a>

### 4.1 Props 与事件 <a id="timeline-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `records` | ApprovalRecord[] | [] | 审批记录（全链路），接口下发 |
| `loading` | boolean | false | 加载态 |
| `showNode` | boolean | true | 是否按节点分组展示 |
| `highlightAction` | string \| null | null | 高亮某动作（用于回看） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `record-click` | record | 点击记录（展开意见全文/附件预览） |

- `ApprovalRecord`：`{ id, nodeId, nodeName, assigneeId, assigneeName, avatar?, action, comment?, attachments?, createdAt }`。

### 4.2 动作与形态 <a id="timeline-actions"></a>

| 动作 `action` | 展示 | 语义色 |
| --- | --- | --- |
| 同意（approve） | 「同意」+ 意见 | `success` |
| 驳回（reject） | 「驳回」+ 意见（必填）+ 驳回目标 | `danger` |
| 撤回（withdraw） | 「撤回流程」 | `warning` |
| 转办（transfer） | 「转办给 某某」 | `info` |
| 评论（comment） | 「添加了评论」 | `info` |

- 时间线按**时间倒序或正序**（缺省正序，按节点推进），展示节点名、审批人（头像 + 姓名）、动作标签、意见（长文折叠，复用 [状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 长文本口径）、时间（[格式化工具](../../07_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）、附件（预览，[文件上传字段](../../04_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)）。
- **空态**：无记录时显示「暂无审批记录」插画（[《布局设计 · 异常与空状态》](../../../布局设计/12_布局设计_异常与空状态.html)）。

## 5. 审批操作面板 ApprovalActionPanel <a id="actions"></a>

### 5.1 Props 与事件 <a id="action-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `task` | ApprovalTask \| null | null | 当前待办任务（含 `taskId`/`nodeId`/`nodeName`/`signed`/`deadline`） |
| `instance` | ApprovalInstance \| null | null | 流程实例（`instanceId`/`status`/`initiatorId`） |
| `mode` | 'panel' \| 'bar' | 'panel' | 面板（详情内）或底部固定操作栏（移动端/钻取）；`bar` 见 5.4 |
| `commentRequired` | boolean | false | 评论是否必填（一般驳回强制、同意可配） |
| `transferMode` | 'user' \| 'role' | 'user' | 转办选择方式（转办给用户/角色） |
| `perm` | string | 'wf:approve' | 审批动作权限码 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `approved` | `{ taskId, comment, attachments }` | 同意提交成功 |
| `rejected` | `{ taskId, comment, targetNodeId? }` | 驳回提交成功（含退回目标） |
| `transferred` | `{ taskId, targetUserId, comment }` | 转办成功 |
| `withdrawn` | `{ instanceId, comment }` | 撤回成功（发起人） |
| `commented` | `{ taskId, comment }` | 仅评论（不推进流程） |

- Props 补充：`rejectTargets`（可退回的节点列表，来自实例节点序列，供驳回选择）；`showWithdraw`（发起人撤回入口）；`showTransfer`（是否展示转办）。

### 5.2 操作与规则 <a id="action-rules"></a>

| 操作 | 前置条件 | 必填 | 确认 | 说明 |
| --- | --- | --- | --- | --- |
| 同意 | 当前人持有该待办（`wf:approve`） | 评论可选 | 否（大额/关键单据可加确认） | 会签节点：本条任务置已办，剩余任务处理完才推进 |
| 驳回 | 同上 | **意见必填** | **是（danger 二次确认）** | 可选退回目标节点或终止实例；驳回即节点不通过 |
| 转办 | 同上 | 目标审批人必填 | 是（warning） | 转移当前任务给他人，本人不再待办 |
| 撤回 | **发起人**且实例未结束 | 意见可选 | **是（danger 二次确认）** | 撤回整个流程实例 |
| 评论 | 任意有权限用户 | 意见必填 | 否 | 仅留痕，不推进流程 |

- **越权与状态校验**：非当前审批人（错误码 60003）、任务状态不允许（60004）、会签未完成（60008）等由后端兜底，前端按错误码提示；面板在无当前任务时隐藏操作按钮。
- **幂等提交**：审批提交携带 `Idempotency-Key`（[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)「接口设计」节），前端在提交时生成、重复点击/重试复用，成功或重复返回首次结果；提交中按钮 loading 且禁二次点击。
- **驳回目标**：默认退回上一节点；实例节点序列支持时提供「退回指定节点」下拉（`rejectTargets`）；无配置时仅「终止/退回上一节点」。
- **二次确认**：驳回/撤回/转办走 [弹窗抽屉表单](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md) `useConfirm`（danger/warning），确认正文说明后果（「驳回后流程将退回至 xx 节点」）。

### 5.3 意见与附件 <a id="action-comment"></a>

- 意见输入：默认多行文本（`el-input type=textarea`，长度上限与 i18n 提示）；可选富文本（[富文本字段](../../04_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)），由业务配置决定。
- 附件：可选上传（[文件上传字段](../../04_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)），随审批记录留痕。
- **常用意见**（可选）：预设意见快捷选择（同意/不同意模板），减少重复输入。

### 5.4 底部操作栏（bar 模式） <a id="action-bar"></a>

- `mode='bar'`：底部固定操作栏（安全区避让），主操作右侧——同意（primary）、驳回（danger）、转办（默认）、撤回按权限与场景显隐；评论随操作弹窗或内联输入（[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)「详情页」节）。
- PC 详情页可嵌于记录 Tab 的侧栏/底部；移动端与 PC 使用**同一套操作规则与文案**，仅形态不同（不共用 PC 组件）。

## 6. 可选 BPMN 只读图 BpmnViewer <a id="bpmn"></a>

| 项 | 设计 |
| --- | --- |
| 用途 | 实例详情展开「查看流程图」；完整展示 BPMN 图形并高亮当前节点（[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)「流程实例」功能点） |
| 依赖 | bpmn-js（Viewer，**只读**，不做 Palette/建模器）；与流程建模页共用同一依赖，**独立分包懒加载**，不进首屏主包 |
| 数据 | 实例详情下发 `bpmn_xml`（定义版本快照）+ 当前节点 id；无 XML 时**降级**为 `FlowProgress` |
| 高亮 | 对当前节点做 `canvas.addMarker('highlight')` 着色 + 滚动居中；驳回实例标记驳回节点 |
| 只读 | 禁用拖拽/编辑，缩放平移可用（适配鼠标滚轮/触控） |
| 失败降级 | bpmn-js 加载失败或 XML 解析失败 → 显示 `FlowProgress` + 提示「流程图加载失败，已切换为进度视图」 |

- 默认场景用 `FlowProgress`（轻量、无依赖）；`BpmnViewer` 作为按需展开项，二者数据同源（节点序列/Xml），状态色一致（[状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 语义色）。

## 7. 组合式函数 useApproval <a id="use-approval"></a>

```typescript
interface UseApprovalOptions {
  instanceId?: string;
  taskId?: string;
  onSubmitted?: (action: string, result: any) => void;  // 提交后刷新实例/记录/待办角标
}

interface UseApprovalReturn {
  instance: Ref<ApprovalInstance | null>;
  nodes: Ref<FlowNode[]>;
  records: Ref<ApprovalRecord[]>;
  task: Ref<ApprovalTask | null>;
  canApprove: ComputedRef<boolean>;     // 当前人有待办 + wf:approve + 实例进行中
  canWithdraw: ComputedRef<boolean>;    // 发起人 + 实例未结束
  loading: Ref<boolean>;
  submitting: Ref<boolean>;
  load: () => Promise<void>;            // 详情 + 记录并行拉取
  approve: (payload) => Promise<void>;  // 同意
  reject: (payload) => Promise<void>;   // 驳回（含目标节点）
  transfer: (payload) => Promise<void>; // 转办
  withdraw: (payload) => Promise<void>; // 撤回
  comment: (payload) => Promise<void>;  // 仅评论
}
```

| 项 | 设计 |
| --- | --- |
| 取数 | `load()` 并行拉取实例详情（含节点序列/当前节点/`bpmn_xml`）与审批记录（`Promise.allSettled`，单失败不整体报错） |
| 可操作判定 | `canApprove`/`canWithdraw` 由任务归属 + 实例状态 + `wf:approve` 共同决定；面板据此显隐按钮 |
| 提交 | 每个提交方法生成/复用 `Idempotency-Key`；提交成功走 `onSubmitted` 刷新（实例状态、记录、待办角标） |
| 冲突/越权 | 60003/60004/60005/60008 按错误码提示，刷新最新实例状态（避免基于过期状态操作） |
| 释放 | 页面卸载/切 Tab 时清理未完成请求与定时（如有 deadline 倒计时） |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：操作按钮按 `wf:approve` 显隐；任务非当前审批人或实例已结束则不显示操作；`canApprove`/`canWithdraw` 由归属与状态判定；后端 `require_permission` 与任务归属校验兜底（错误码 60003/60004）。
- **i18n**：节点名、动作名、状态文案、按钮、确认与错误提示走 vue-i18n 或按错误码映射（`error.600xx`）；节点名可由流程定义下发（按 locale）；时间走 [格式化工具](../../07_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)；**不翻译用户输入的审批意见**。
- **移动端**：不复用 PC 组件；[《布局设计 · 移动端细化》](../../../布局设计/16_布局设计_移动端细化.html)「详情页」节形态——状态条（`van-steps`/自绘进度）+ 信息卡 + 流转记录（`van-steps` 时间线）+ 底部固定操作栏（同意/驳回/转办，安全区避让，`van-dialog` 二次确认）；**操作规则、幂等键、状态语义与 PC 同源**，取数走同一后端接口。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 依赖 | `FlowProgress`/`ApprovalTimeline`/`ApprovalActionPanel` 无额外依赖；bpmn-js 仅 `BpmnViewer` 懒加载独立分包 |
| 取数 | 实例详情 + 记录并行拉取（`Promise.allSettled`），单失败不阻断；待办操作为单条任务，无大列表压力 |
| 分支渲染 | 进度条消费结构化节点序列，复杂分支以「跳过/置灰」降级，不做前端 BPMN 解析 |
| 提交 | 幂等键 + 按钮 loading，防重复推进；提交后仅刷新实例/记录/角标，不整页重载 |
| 实时 | 待办角标与审批到达由 Socket.IO 推送（[《架构设计 · 实时推送》](../../../架构设计/14_架构设计_子系统_实时推送.md)）；详情页可按需订阅 `approval.todo` 增量 |
| 边界 | 无当前任务（隐藏操作）、非当前审批人（60003）、状态不允许（60004）、重复提交（60005）、会签未完成（60008）、实例异常（60009，只读展示 + 提示人工处理）、无记录（空态）、bpmn-js/XML 加载失败（降级 FlowProgress）、超长意见（折叠）、超长流程（横向滚动/纵向堆叠）、移动端单列 |
| 不支持 | 流程建模（bpmn-js Modeler 归流程建模页）、流程实例列表/待办列表表格（归 [通用表格](../../05_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)）、审批状态标签取色（归 [状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)） |

## 12. 检查清单 <a id="checklist"></a>

- □ 组件分层：`FlowProgress` 进度、`ApprovalTimeline` 轨迹、`ApprovalActionPanel` 操作、`BpmnViewer` 可选只读图、`useApproval` 取数与提交，职责不重叠
- □ 进度：节点状态色语义正确（done/active/pending/rejected/skipped）、当前节点高亮并居中、会签聚合（n/m）、分支降级；数据来自实例节点序列而非前端解析 XML
- □ 时间线：记录字段（节点/审批人/动作/意见/附件/时间）齐备，动作语义色正确，长意见折叠，空态完整
- □ 操作面板：同意/驳回/转办/撤回/评论齐备；驳回意见必填 + 目标节点、转办选人、撤回仅发起人；二次确认；幂等键 + loading 防重复
- □ 越权与错误码：60003/60004/60005/60008/60009 按码提示并刷新状态；无当前任务隐藏操作
- □ BPMN 只读图：懒加载独立分包、只读禁编辑、高亮当前节点、无 XML/加载失败降级 FlowProgress
- □ 权限（`wf:approve`/`wf:query`）、i18n（节点/动作/错误码/时间，不翻译意见）、移动端（状态条+时间线+底部操作栏，规则同源）符合第 10 节
- □ 性能边界：并行取数、幂等提交、分支降级、实时角标、异常实例只读展示
- □ 两项上游登记已确认：审批展示数据结构与操作接口（含转办/撤回/评论）、前端展示选型（简化进度 + 只读 BPMN）；[状态标签与描述列表](../../05_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)回写为引用本节点
