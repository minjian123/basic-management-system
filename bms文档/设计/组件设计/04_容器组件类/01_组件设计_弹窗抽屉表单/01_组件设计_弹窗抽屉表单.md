## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **弹窗/抽屉表单**的组件设计：表单抽屉容器 `FormDrawer.vue`、表单对话框容器 `FormDialog.vue`、确认对话框 `ConfirmDialog.vue`，以及组合式函数 `useFormModal.ts`（开关/三态/校验/提交/脏数据）与 `useConfirm.ts`（确认类对话框）。适用于管理端**轻量表单与快捷操作**（快速新建、字典项编辑、权限配置、导入映射、批量操作配置）与**确认类交互**（删除、危险操作二次确认）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；页面形态依据[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html)（抽屉/对话框选用、尺寸阶梯、底部操作栏、遮罩与 Esc 关闭规则）、[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」「校验与提交」节（label 上方、窄容器单列、必填与乐观锁、提交后刷新列表）、[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（工具栏与行内操作、删除二次确认）、[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)「渲染规则（三态共用/回退/权限叠加）」节（新增/编辑/详情一套布局、权限优先）；上游设计依据[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（`GET /forms/{form_code}/layout-effective` 渲染元数据、字段属性与服务端动态校验）、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（`sys_button` 动作挂接、`sys_field`/`sys_role_field` 字段权限）；协作节点为[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（提交与错误处理）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（`stableStringify` 脏数据比对、校验器工厂）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（动作权限与字段权限）、[字典字段](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)～[开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（插槽内字段渲染）、[状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（查看态的只读展示口径）。

> 本篇为组件设计体系交互类第 01 篇。**范围边界**：**完整记录的查看/编辑走表单页 Tab**（[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html) FormFrame，本节点**不承载**），弹窗/抽屉只承载**轻量表单与快捷操作**；字段的控件渲染、字典/组织等数据源、校验规则分别归字段类各节点与[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)；文件上传字段归 [07](../../06_字段类/06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)；导入映射/导出参数表单归 导入导出；移动端不复用 PC 组件（见第 11 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `FormDrawer.vue` | `src/components/modal/` | 表单抽屉容器：抽屉开关、三态标题、尺寸阶梯、固定页脚（提交/取消）、脏数据拦截、提交 loading、插槽承载表单 |
| `FormDialog.vue` | `src/components/modal/` | 表单对话框容器：对话框开关、尺寸阶梯（420/480/520）、简单表单（≤ 4 字段）与确认引导，其余契约与抽屉共用 |
| `ConfirmDialog.vue` | `src/components/modal/` | 确认对话框：正文自定义（含二次输入确认）、danger 语义、禁止遮罩/Esc 关闭、确认回调 loading |
| `useFormModal.ts` | `src/utils/useFormModal.ts` | 组合式函数：`visible`/`mode`/`formData` 状态、`openCreate`/`openEdit`/`openView`、校验、提交（create/update）、脏数据基线与比对、成功后关闭并回调 |
| `useConfirm.ts` | `src/utils/useConfirm.ts` | 确认类封装：基于 `ElMessageBox.confirm` 的轻量确认（删除/危险），统一 danger 样式与关闭规则；复杂内容转 `ConfirmDialog.vue` |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，弹窗/抽屉类容器归 `modal/`；通用组合式函数放 `src/utils/`）。
- `FormDrawer` 与 `FormDialog` **共用同一份 Props/事件/插槽契约**（差异仅形态与尺寸阶梯），页面按[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html)选用原则二选一；页脚与脏数据逻辑由 `useFormModal` 统一，两个容器不各写一套。

## 3. 选用与尺寸 <a id="choose-size"></a>

### 3.1 容器选用 <a id="choose"></a>

| 场景 | 选用 | 说明 |
| --- | --- | --- |
| 轻量表单（快捷新建、子项编辑，≤ 6 字段） | 抽屉 `FormDrawer`（**首选**） | 保留列表上下文，[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html) |
| 简单表单（≤ 4 字段，如重置密码） | 对话框 `FormDialog` | 字段少而短，不承载大表单 |
| 确认/危险操作（删除、停用、驳回） | 对话框（`useConfirm` / `ConfirmDialog`） | 正文说明后果，确定按钮 danger |
| 完整记录查看/编辑、含明细 | **不使用本节点** | 走表单页 Tab（FormFrame），弹窗空间不足 |
| 导入映射、批量操作配置 | 抽屉（复杂表单档 640/720） | 参数多，窄抽屉内部滚动 |

- 标题 = **动作 + 对象**（「新增部门」「编辑用户」），由 `mode` + `title` 生成，避免只写对象名。
- 抽屉内表单字段**单列**、label 在上方（[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节）；对话框内字段同样单列。

### 3.2 尺寸阶梯 <a id="size"></a>

| 容器 | 档位令牌 | 宽度 | 适用 |
| --- | --- | --- | --- |
| 抽屉 | `sm` / `md` / `lg` / `xl` | 400 / 480 / 640 / 720+ px | 简单表单 / 常规表单 / 复杂表单或明细 / 大表单或自定义列 |
| 对话框 | `sm` / `md` / `lg` | 420 / 480 / 520 px | 确认类 / 简单表单 / 通知引导 |

- `width` 接受**档位令牌**（`sm`/`md`/`lg`/`xl`）或显式数值，缺省 `md`；不得随意填非阶梯宽度（[《布局设计 · 弹窗》](../../../布局设计/10_布局设计_弹窗.html)检查清单）。
- 抽屉高度撑满、正文内部滚动、页脚固定；对话框按内容高度、超长正文内部滚动、页脚固定。

## 4. 共用契约（Props / 事件 / 插槽） <a id="contract"></a>

### 4.1 Props <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | boolean | false | 显隐（`v-model`） |
| `mode` | 'create' \| 'edit' \| 'view' | 'create' | 三态；决定标题、字段可编辑性与页脚按钮 |
| `title` | string \| null | null | 对象名；缺省标题按 `mode` 生成（新增/编辑/查看 + `title`） |
| `width` | 'sm' \| 'md' \| 'lg' \| 'xl' \| number \| string | 'md' | 尺寸档位或显式宽度（见 3.2） |
| `submitLoading` | boolean | false | 提交中（页脚保存按钮 loading，禁止关闭） |
| `confirmOnClose` | boolean | true | 关闭前脏数据拦截（见第 7 节） |
| `closeOnClickModal` | boolean | false | 点遮罩关闭；**表单类默认关闭**（防误触丢数据） |
| `closeOnPressEscape` | boolean | true | Esc 关闭；确认/danger 类强制 false |
| `destroyOnClose` | boolean | true | 关闭即销毁内容（表单重置、避免残留校验态） |
| `lockScroll` | boolean | true | 打开时锁定背景滚动 |
| `showFooter` | boolean | true | 是否渲染页脚操作栏 |
| `submitText` / `cancelText` | string | 保存 / 取消 | 页脚文案（按场景可传「同意 / 提交」等） |
| `submitPerm` | string \| null | null | 保存动作权限码（如 `user:create` / `user:update`），无权限则不渲染保存按钮（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)） |
| `showDelete` / `deleteText` / `deleteHandler` | boolean / string / Function | false / 删除 / — | `view`/`edit` 态可选删除入口，走 danger 二次确认（权限码 `business:delete`） |
| `beforeClose` | (done) => void \| null | null | 自定义关闭前钩子（与脏数据拦截串联，先脏数据后 beforeClose） |

### 4.2 事件 <a id="events"></a>

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | boolean | 显隐同步 |
| `open` / `opened` | mode | 打开前 / 打开动画结束 |
| `submit` | formData | 点保存、校验通过后抛出（由页面或 `useFormModal` 接管提交） |
| `success` | 返回数据 | 提交成功（用于关闭并刷新列表/局部更新） |
| `cancel` / `close` / `closed` | — | 取消 / 关闭前 / 关闭完成 |
| `dirty-change` | boolean | 表单脏状态变化（供页面提示或跨组件联动） |

### 4.3 插槽 <a id="slots"></a>

| 插槽 | 说明 |
| --- | --- |
| 默认插槽 | 表单内容（字段栅格、字典/组织等控件，复用 字段类各节点渲染器） |
| `title` | 自定义标题（缺省按 `mode` 生成） |
| `tips` | 标题下提示/说明条（i18n 文案，如「保存后将同步至全部租户」） |
| `footer-extra` | 页脚左侧附加按钮（如「重置」；主操作仍在右侧） |
| `footer` | 完全自定义页脚（覆盖默认保存/取消，需自行处理 loading 与权限） |

### 4.4 暴露方法（模板 ref） <a id="expose"></a>

| 方法 | 说明 |
| --- | --- |
| `submit()` | 触发校验并提交（供页面工具栏/快捷键调用） |
| `close()` | 走完整关闭流程（含脏数据拦截与 `beforeClose`） |
| `resetFields()` | 重置表单与校验态（`useFormModal` 打开时默认调用） |
| `setFormData(data)` | 直接注入/回填表单数据（详情异步返回时用） |

## 5. 表单内容与三态 <a id="three-modes"></a>

| 态 | 数据来源 | 字段可编辑性 | 页脚 |
| --- | --- | --- | --- |
| `create` | 元数据默认值 + 页面 `defaultData` | 可编辑（`editable=false` 字段禁用） | 取消 / 保存 |
| `edit` | 按 id 拉详情回填 | 可编辑（`editable=false` 禁用） | 取消 / 保存（可选删除） |
| `view` | 按 id 拉详情回填 | 全部禁用（与[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)只读态一致：disabled 输入框） | 关闭（持权限时显示「编辑」转 edit） |

- **三态共用一套布局**（[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)「渲染规则」节）：字段清单/顺序/跨列来自 `GET /forms/{form_code}/layout-effective`，只读态不另做布局；`visible=false` 字段不渲染，`editable=false` 字段在编辑态禁用（后端写时校验兜底）。
- **字段渲染复用**：插槽内使用与表单页同一套字段渲染器与[02](../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)～[09](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)控件，保证同一字段在表单页与弹窗内取值、校验、只读口径一致。
- **字段组织**：单选/文本等 label 上方**单列**；> 8 字段用分区标题（`el-divider`）；长文本/备注跨整行。
- **敏感字段**：默认脱敏展示，持 `data:plain` 显示明文切换（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)），提交不回传脱敏值。
- **字段子集（快速表单，可选）**：轻量新增/编辑可只渲染布局声明的字段子集，未列字段取默认值；该能力依赖表单元数据声明（见第 10 节登记项②）。

## 6. 打开 / 提交 / 关闭生命周期 <a id="lifecycle"></a>

```mermaid
sequenceDiagram
    autonumber
    participant 页面 as 列表页/配置页
    participant hook as useFormModal
    participant 容器 as FormDrawer/FormDialog
    participant 接口 as 模块 create/update/detail
    participant 列表 as 列表数据(useListPage)

    页面->>hook: openCreate(defaultData) / openEdit(id) / openView(id)
    hook->>hook: 重置表单 + 记录脏数据基线(stableStringify)
    opt edit/view
        hook->>接口: 拉详情
        接口-->>hook: 记录数据(含 version)
    end
    hook->>容器: visible=true, mode, formData
    页面->>hook: submit()
    hook->>hook: formRef.validate()
    alt 校验失败
        hook-->>页面: 字段级错误提示（i18n），不提交
    else 校验通过
        hook->>接口: create(payload) / update(id, payload, version)
        接口-->>hook: 成功 / 409 冲突 / 其余错误
        alt 409 乐观锁冲突
            hook-->>页面: 提示「记录已被修改」→ 重新拉详情覆盖
        else 成功
            hook->>容器: 提交成功 → close()
            hook->>列表: 刷新列表 / 局部更新
        end
    end
```

| 项 | 设计 |
| --- | --- |
| 打开 | `openCreate`（默认值）、`openEdit(id)`（拉详情）、`openView(id)`（拉详情 + 只读）；打开前重置表单与校验态、重建脏数据基线 |
| 提交前 | `formRef.validate()`；失败内联提示不提交；`submitLoading` 防重复提交 |
| 提交 | 由 `useFormModal` 调模块 `create`/`update`（走[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）；`edit` 携带记录 `version`（乐观锁） |
| 提交后 | 成功 → `success` 事件 → 关闭容器 → 刷新列表或按返回数据局部更新（[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「校验与提交」节）；失败 → 保留弹窗与已填值，按错误码提示 |
| 冲突 | 409「记录已被修改」→ 提示并重新拉详情覆盖（不清空弹窗） |
| 关闭 | 走第 7 节拦截链；`destroyOnClose` 销毁内容，下次打开重新初始化 |

## 7. 关闭与未保存拦截 <a id="dirty"></a>

```mermaid
flowchart TD
    A["请求关闭（按钮/遮罩/Esc/close()）"] --> B{"提交中？"}
    B -->|"是"| X["忽略关闭（防重复/丢提交）"]
    B -->|"否"| C{"dirty 脏数据？"}
    C -->|"否"| E{"beforeClose 钩子？"}
    C -->|"是"| D["确认框：放弃修改？(放弃/继续编辑)"]
    D -->|"继续编辑"| X
    D -->|"放弃"| E
    E -->|"有且放行"| F["执行关闭"]
    E -->|"无"| F
```

| 项 | 设计 |
| --- | --- |
| 脏数据基线 | 打开时以 `stableStringify(formData)`（[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）记录基线；字段变化与基线不等即 dirty |
| 拦截范围 | 按钮取消、点遮罩、Esc、外部 `close()` 统一走拦截链（`confirmOnClose=false` 可关闭拦截，如查看态） |
| 确认文案 | 「有未保存的修改，确定放弃吗？」（i18n）；确认框危险按钮为「放弃修改」（danger），次按钮「继续编辑」 |
| 遮罩 / Esc | 表单类**默认不允许**点遮罩关闭；Esc 允许但同样走脏数据拦截；安全场景可显式关闭两者 |
| 提交中 | 禁止任何方式关闭（含 Esc/遮罩/取消按钮），保存按钮 loading |
| 查看态 | 无编辑、无脏数据，`confirmOnClose` 自动失效，直接关闭 |
| 钩子顺序 | 先脏数据拦截，通过后再执行 `beforeClose` 自定义钩子（如保存草稿提示），两者串联 |

## 8. 确认类对话框 <a id="confirm"></a>

| 工具 | 用途 | 说明 |
| --- | --- | --- |
| `useConfirm.ts` | 轻量确认（删除、启停、简单危险操作） | 封装 `ElMessageBox.confirm`：统一 `type='warning'`、确定按钮 danger、`closeOnClickModal=false`、`closeOnPressEscape=false`；返回 Promise，确认后可带 `onConfirm` loading |
| `ConfirmDialog.vue` | 需自定义正文/二次输入确认 | 自定义内容插槽（如「输入操作对象名称以确认」）、确认回调 loading、危险语义；关闭规则同确认类（禁遮罩/Esc） |

- **危险操作二次确认**（[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)「删除二次确认」节）：删除/停用/驳回等必须显式确认，正文说明后果（「删除后不可恢复」），确定按钮 danger。
- **确认后行为**：成功后关闭并刷新列表/局部移除行，失败保留并提示错误码文案，不整表重载（对齐 [开关与枚举字段](../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)内联切换口径）。
- **权限**：危险按钮按动作权限码显隐（如 `business:delete`），无权限不渲染。

## 9. 场景集成 <a id="scenes"></a>

| 场景 | 形态 | 说明 |
| --- | --- | --- |
| 列表页快捷新增/编辑（子项） | `FormDrawer` `sm`/`md` | 字典项、岗位、参数等轻量实体；保留列表上下文 |
| 权限配置 / 复杂参数 | `FormDrawer` `lg`/`xl` | 内部滚动，页脚固定；正文分组 |
| 重置密码 / 简单操作 | `FormDialog` `md` | ≤ 4 字段，短小 |
| 删除 / 危险操作 | `useConfirm` / `ConfirmDialog` | 不可遮罩/Esc，danger 确定 |
| 导入映射 / 批量配置 | `FormDrawer` `xl`（或转表单页） | 参数多时优先抽屉；过大改走表单页 |
| 完整记录查看/编辑 | **不使用本节点** | 走表单页 Tab（FormFrame），避免两套编辑口径 |

## 11. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：页脚保存/删除按钮按动作权限码显隐（`submitPerm` / `deleteHandler`）；字段按 `visible`/`editable` 渲染（权限优先于布局）；敏感字段默认脱敏、`data:plain` 明文；后端 `require_permission` 与动态校验兜底（[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：标题（动作词 + 对象名）、页脚文案、脏数据确认、错误提示、字段 label 均按 locale 下发或走 vue-i18n；字段 label 来自 `layout-effective`（`sys_field_i18n`）；错误文案按错误码映射（`error.xxxxx`），后端不拼文案；**不翻译用户输入**。
- **移动端**：不复用 PC 组件；移动端快捷操作按 `van-popup`（`position='bottom'` 底部弹出）+ `van-form` 实现，确认类用 `van-dialog`（`before-close` 拦截）；三态、字段权限、脱敏与校验复用同一份元数据与同一套校验规则，提交走同一后端接口（跨端一致）。

## 12. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 实例复用 | 容器默认 `destroyOnClose`，关闭即销毁表单内容与校验态；同一页面复用单个 `useFormModal` 实例，避免多份状态 |
| 打开成本 | `create` 用本地默认值即时打开；`edit`/`view` 拉详情期间显示 loading，避免白屏 |
| 重复提交 | 提交中 `submitLoading` + 禁用取消/关闭；成功后才关闭 |
| 滚动锁 | `lockScroll` 仅锁最上层弹窗；嵌套弹窗退出时恢复上层滚动（防止背景跳动） |
| 层级 | 嵌套弹窗 z-index 递增；确认框置于当前弹窗之上；同一层级同时只允许一个主表单弹窗 |
| 校验 | 前端校验复用 [格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)校验器工厂，规则与后端动态校验一致；异步校验（如唯一性）防抖并显示 loading |
| 大数据 | 字段过多（> 12）或含明细时**不推荐弹窗**，引导走表单页；抽屉正文内部滚动，页脚常驻 |
| 边界 | 打开时详情请求失败（错误态 + 重试，不空表单提交）、409 乐观锁冲突、字段被停用（跳过不阻断）、脏数据拦截与 `beforeClose` 串联、提交中关闭、嵌套弹窗滚动锁、Esc/遮罩规则、`destroyOnClose` 后状态重置、移动端底部弹出 |
| 不支持 | 完整记录与明细编辑（表单页 FormFrame）、字段控件实现（字段类各节点）、导入导出参数表单（[导入导出](../../08_交互类/01_组件设计_导入导出/01_组件设计_导入导出.md)）、设计器配置（表单定制） |

## 13. 检查清单 <a id="checklist"></a>

- □ 选用正确：轻量表单走抽屉（首选），简单表单/确认走对话框，完整记录走表单页（本节点不承载）
- □ 尺寸走阶梯（抽屉 400/480/640/720，对话框 420/480/520），标题为「动作 + 对象」
- □ 抽屉/对话框共用同一份 Props/事件/插槽契约；`FormDialog` 不重复实现页脚与脏数据逻辑
- □ 三态齐备：新增默认值、编辑回填、查看只读（disabled 与表单页一致）；字段清单/权限来自 `layout-effective`，权限优先
- □ 生命周期：打开重置 + 建脏数据基线、校验失败不提交、提交 loading 防重复、成功关闭并刷新/局部更新、409 冲突重载
- □ 关闭与未保存拦截：脏数据确认（放弃/继续编辑）、表单类禁遮罩/Esc 拦截、提交中禁关、`beforeClose` 串联
- □ 确认类：`useConfirm`/`ConfirmDialog` 危险语义、禁遮罩/Esc、确认 loading、确认后刷新/局部移除；危险按钮按权限显隐
- □ 权限（`submitPerm`/字段可见可编辑/脱敏）、i18n（标题/文案/错误码/字段 label）、移动端（`van-popup`/`van-dialog` 同源口径）符合第 11 节
- □ 性能边界：实例复用 + `destroyOnClose`、滚动仅锁最上层、嵌套 z-index、大数据引导表单页、打开失败错误态不空提交
- □ 三项上游登记已确认：弹窗关闭与未保存拦截口径、弹窗字段子集与三态承载、弹窗页脚动作权限口径
