## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端渲染插件 `frontend/packages/ui-ep`（PC 落点 `frontend/packages/ui-ep/src/components/container/`；移动端同契约实现 `frontend/packages/ui-vant/src/components/container/`；宿主消费 `frontend/apps/*`）**滚动容器** `ScrollContainer` 的组件设计：统一滚动区域——固定/自适应高度、自定义滚动条、滚动位置保持、触底/触顶事件。继承 [容器能力（原「容器能力」）](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)。

> 本篇为 **容器组件类「滚动容器」**。范围边界：虚拟滚动归 [容器组件类「虚拟列表容器」](../06_组件设计_虚拟列表容器/06_组件设计_虚拟列表容器.md)；自适应高度归 [容器组件类「自适应高度容器」](../05_组件设计_自适应高度容器/05_组件设计_自适应高度容器.md)；弹窗/抽屉容器归 [容器组件类「弹窗抽屉表单」](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `height` | number \| string | — | 高度（`auto` 内容撑开） |
| `maxHeight` | number \| string | — | 最大高度 |
| `nativeScrollbar` | boolean | false | 用原生滚动条 |
| `keepPosition` | boolean | false | 保持滚动位置（切换恢复） |
| `throttle` | number | 100 | 滚动事件节流（ms） |

| 事件 | 说明 |
| --- | --- |
| `scroll` | 滚动（节流） |
| `reach-bottom` / `reach-top` | 触底/触顶（可配阈值） |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 高度 | `height` 固定或 `auto`；配合 自适应高度容器 |
| 滚动条 | 可自定义（宽度/颜色令牌）；移动端隐藏 |
| 位置保持 | `keepPosition` 记录/恢复滚动位置（切换 Tab/返回） |
| 触底加载 | 触底到底阈值触发 `reach-bottom`（分页/懒加载） |
| 令牌 | 滚动条/背景只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 长列表 | 触底加载更多 |
| 长表单/详情 | 内部滚动 + 固定头/底 |
| Tab 内容 | 切换保持滚动位置 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：无文案。
- **移动端**：触屏滚动、原生滚动条、上拉加载（与触底事件一致）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 滚动 | 事件节流；触底用 IntersectionObserver 更优 |
| 边界 | 嵌套滚动（滚动穿透）、高度计算时机（内容异步）、位置保持在动态内容下失效、触底重复触发 |
| 不支持 | 虚拟滚动（容器组件类「虚拟列表容器」）、自适应高度（容器组件类「自适应高度容器」）、弹窗外壳（容器组件类「弹窗抽屉表单」） |
