## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**滚动容器**的组件设计：统一滚动区域——固定/自适应高度、自定义滚动条、滚动位置保持、触底/触顶通知。继承[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的一层：标题/插槽/区域内边距等区域语义）。

> 本篇为 **容器组件类「滚动容器」**。范围边界：虚拟滚动归 [容器组件类「虚拟列表容器」](../06_组件设计_虚拟列表容器/06_组件设计_虚拟列表容器.md)；自适应高度归 [容器组件类「自适应高度容器」](../05_组件设计_自适应高度容器/05_组件设计_自适应高度容器.md)；弹窗/抽屉容器归 [容器组件类「弹窗抽屉表单」](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 滚动区容器件 | 滚动区：高度/最大高度、滚动条、位置保持、触底/触顶通知 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 高度与最大高度 | 固定高度或按内容自撑（`auto`），可设最大高度；超出时形成独立滚动区 |
| 滚动条 | 可用原生滚动条或主题化滚动条（宽度/颜色消费令牌）；移动端隐藏 |
| 位置保持 | 可保持滚动位置，切换 Tab/返回时恢复 |
| 触底与触顶 | 到达阈值时向外通知（供分页/懒加载接入），阈值可配 |
| 滚动通知 | 滚动变化按节流阈值向外通知 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 高度 | 固定高度或内容自撑；配合 自适应高度容器 |
| 滚动条 | 可自定义（宽度/颜色令牌）；移动端隐藏 |
| 位置保持 | 记录/恢复滚动位置（切换 Tab/返回） |
| 触底加载 | 到达触底阈值触发通知（分页/懒加载） |
| 令牌 | 滚动条/背景只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 长列表 | 触底加载更多 |
| 长表单/详情 | 内部滚动 + 固定头/底 |
| Tab 内容 | 切换保持滚动位置 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：无文案。
- **移动端**：触屏滚动、原生滚动条、上拉加载（与触底通知一致）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 滚动 | 事件节流；触底判定采用视口相交观察（避免滚动监听）更优 |
| 边界 | 嵌套滚动（滚动穿透）、高度计算时机（内容异步）、位置保持在动态内容下失效、触底重复触发 |
| 不支持 | 虚拟滚动（容器组件类「虚拟列表容器」）、自适应高度（容器组件类「自适应高度容器」）、弹窗外壳（容器组件类「弹窗抽屉表单」） |
