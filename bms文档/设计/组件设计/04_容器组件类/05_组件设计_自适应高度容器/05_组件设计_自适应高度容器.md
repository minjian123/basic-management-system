## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**自适应高度容器**的组件设计：高度自动占满父容器剩余空间（如内容区减去头部/底部/工具栏），用于列表/表格/编辑器撑满可用区域。继承[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的一层：标题/插槽/区域内边距等区域语义）。

> 本篇为 **容器组件类「自适应高度容器」**。范围边界：滚动行为归 [容器组件类「滚动容器」](../02_组件设计_滚动容器/02_组件设计_滚动容器.md)；全屏归 [全屏容器](../04_组件设计_全屏容器/04_组件设计_全屏容器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 自适应高度容器件 | 高度=父剩余空间：尺寸变化重算、最小/最大高度、扣除高度、内部滚动 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 扣除高度 | 需从父剩余空间中扣除的高度（头部/工具栏/边距），缺省 0 |
| 最小/最大高度 | 自适应结果的上下限裁剪 |
| 内部滚动 | 内容超出时内部滚动（默认开启） |
| 重算节流 | 尺寸变化重算的节流时长（默认 100ms） |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 计算 | 父容器可用高度 − 扣除高度；父容器尺寸/窗口尺寸变化时重算 |
| 限制 | 最小/最大高度裁剪 |
| 滚动 | 开启内部滚动时内容超出内部滚动 |
| 时序 | 挂载后与内容变化后重算（防止 0 高度） |
| 令牌 | 间距/边框只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 列表/表格 | 撑满内容区、表体滚动 |
| 编辑器 | 富文本/代码编辑器占满 |
| 工作台 | 图表区自适应 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：无文案。
- **移动端**：用动态视口高度，注意地址栏收缩。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 计算 | 尺寸观察 + 去抖；避免循环触发 |
| 边界 | 初始 0 高度、内容异步导致的重复计算、嵌套自适应、扣除高度变更未重算、移动端视口高度抖动 |
| 不支持 | 滚动事件（容器组件类「滚动容器」）、全屏（容器组件类「全屏容器」） |
