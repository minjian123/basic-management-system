## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端渲染插件 `frontend/packages/ui-ep`（PC 落点 `frontend/packages/ui-ep/src/components/container/`；移动端同契约实现 `frontend/packages/ui-vant/src/components/container/`；宿主消费 `frontend/apps/*`）**自适应高度容器** `AutoHeight` 的组件设计：高度自动占满父容器剩余空间（如内容区减去头部/底部/工具栏），用于列表/表格/编辑器撑满可用区域。继承 [容器能力（原「容器片段」）](../../02_基础组件类/02_能力片段/04_组件设计_容器片段/04_组件设计_容器片段.md)。

> 本篇为 **容器组件类「自适应高度容器」**。范围边界：滚动行为归 [容器组件类「滚动容器」](../02_组件设计_滚动容器/02_组件设计_滚动容器.md)；全屏归 [全屏容器](../04_组件设计_全屏容器/04_组件设计_全屏容器.md)。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `offset` | number | 0 | 需扣除的高度（头部/工具栏/边距） |
| `minHeight` / `maxHeight` | number | — | 高度限制 |
| `scroll` | boolean | true | 内部滚动（内容超出） |
| `resizeDebounce` | number | 100 | 重算节流（ms） |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 计算 | 父容器可用高度 - `offset`；ResizeObserver/窗口 resize 重算 |
| 限制 | `minHeight`/`maxHeight` 裁剪 |
| 滚动 | `scroll=true` 内容超出时内部滚动 |
| 时序 | 挂载后与内容变化后重算（防止 0 高度） |
| 令牌 | 间距/边框只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |

| 编辑器 | 富文本/代码编辑器占满 |
| 工作台 | 图表区自适应 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：无文案。
- **移动端**：用视口高度（`100vh` 动态 `dvh`），注意地址栏收缩。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 计算 | ResizeObserver + 去抖；避免循环触发 |
| 边界 | 初始 0 高度、内容异步导致的重复计算、嵌套自适应、`offset` 变更未重算、移动端 vh 抖动 |
| 不支持 | 滚动事件（容器组件类「滚动容器」）、全屏（容器组件类「全屏容器」） |
