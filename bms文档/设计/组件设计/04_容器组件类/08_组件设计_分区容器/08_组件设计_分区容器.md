## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**分区容器** `SectionContainer` 的组件设计：**轻量分区**——标题/描述/工具区/内容，无卡片边框外观（区别于 [03-10 卡片](../../03_布局组件类/10_组件设计_卡片/10_组件设计_卡片.md)），用于表单分区、详情分区、设置分组。继承 [02 基础组件类 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md)。

> 本篇为 **04 容器组件类第 08 篇**。范围边界：卡片（带边框/阴影）归 [03-10 卡片](../../03_布局组件类/10_组件设计_卡片/10_组件设计_卡片.md)；折叠面板组归 [03-11 折叠面板](../../03_布局组件类/11_组件设计_折叠面板/11_组件设计_折叠面板.md)；表单分区栅格归 [08 交互类 12 表单渲染器](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `SectionContainer.vue` | `src/components/container/` | 分区：标题/描述/工具区/内容/折叠、间距与分隔 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 分区标题 |
| `description` | string | '' | 描述 |
| `collapsible` | boolean | false | 可折叠 |
| `collapsed` | boolean | false | 折叠态（v-model:collapsed） |
| `divider` | boolean | true | 标题下分隔线 |
| `padding` | 'none' \| 'small' \| 'default' \| 'large' | 'default' | 内边距（令牌） |

| 事件 | 说明 |
| --- | --- |
| `update:collapsed` / `collapse-change` | 折叠 |

- 插槽：`title`、`extra`（工具区）、`default`、`footer`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 轻量 | 无边框/阴影（默认）；仅标题 + 内容 + 间距 |
| 折叠 | 折叠仅隐藏内容，标题保留 |
| 工具区 | 右上 `extra`（操作/筛选） |
| 令牌 | 间距/分隔线令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单分区 | >8 字段分区（配合渲染器） |
| 详情分区 | 信息分组 |
| 设置页 | 分组设置 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：工具区动作按权限。
- **i18n**：标题/描述按 locale。
- **移动端**：内边距收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠按需渲染内容 |
| 边界 | 与卡片外观混淆、分区嵌套、折叠状态、标题过长、分隔线与边框叠加 |
| 不支持 | 卡片（03-10）、折叠面板组（03-11）、虚拟滚动（04-06） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`title`/`description`/`collapsible`/`collapsed`/`divider`/`padding` + 插槽
- □ 轻量分区、折叠、工具区、令牌
- □ 继承 02 L2-04；与 03-10/03-11 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
