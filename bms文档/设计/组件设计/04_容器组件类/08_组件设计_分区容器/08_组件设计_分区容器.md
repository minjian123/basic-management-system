## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**分区容器**的组件设计：**轻量分区**——标题/描述/工具区/内容，无卡片边框外观（区别于 [布局组件类「卡片」](../../03_布局组件类/10_组件设计_卡片/10_组件设计_卡片.md)），用于表单分区、详情分区、设置分组。它沿继承链派生——分区容器 → 容器能力（继承链上的一层）→ `BaseComponent` → `BaseObject`，通用行为在链上层维护、不在组件内重复实现。

> 本篇为 **容器组件类「分区容器」**。范围边界：卡片（带边框/阴影）归 [布局组件类「卡片」](../../03_布局组件类/10_组件设计_卡片/10_组件设计_卡片.md)；折叠面板组归 [布局组件类「折叠面板」](../../03_布局组件类/11_组件设计_折叠面板/11_组件设计_折叠面板.md)；表单分区栅格归 [交互类「表单渲染器」](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 分区容器件 | 分区：标题/描述/工具区/内容/折叠、间距与分隔 |

- **继承关系**：沿继承链派生——分区容器 → 容器能力（继承链上的一层）→ `BaseComponent` → `BaseObject`；行为在链上层维护，不在组件内重复实现。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 标题 | 分区标题（i18n）；可被标题插槽替代 |
| 描述 | 标题下方的描述文案 |
| 可折叠 | 是否可折叠（默认否） |
| 折叠态 | 受控折叠状态（默认展开），折叠变化对外通知 |
| 分隔线 | 标题下是否显示分隔线（默认显示） |
| 内边距 | `none` / `small` / `default` / `large` 四态（令牌，默认 `default`） |
| 插槽 | 标题、工具区（右上）、默认内容、页脚 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 轻量 | 无边框/阴影（默认）；仅标题 + 内容 + 间距 |
| 折叠 | 折叠仅隐藏内容，标题保留 |
| 工具区 | 右上工具区承载操作/筛选 |
| 令牌 | 间距/分隔线只消费令牌 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：工具区动作按权限。
- **i18n**：标题/描述按 locale。
- **移动端**：内边距收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠按需渲染内容 |
| 边界 | 与卡片外观混淆、分区嵌套、折叠状态、标题过长、分隔线与边框叠加 |
| 不支持 | 卡片（布局组件类「卡片」）、折叠面板组（布局组件类「折叠面板」）、虚拟滚动（容器组件类「虚拟列表容器」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：标题/描述/可折叠/折叠态/分隔线/内边距 + 插槽
- □ 轻量分区、折叠、工具区、令牌
- □ 沿继承链派生（容器能力为继承链上的一层）；与 卡片 / 折叠面板 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认：分区容器契约、分区令牌、容器组件类归属
