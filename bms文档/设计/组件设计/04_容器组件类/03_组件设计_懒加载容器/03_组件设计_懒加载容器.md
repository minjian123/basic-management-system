## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**懒加载容器** `LazyContainer` 的组件设计：内容进入视口才挂载，用于长页面（首页工作台、长表单、图片列表）的性能优化。继承 [02 基础组件类 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md)。

> 本篇为 **04 容器组件类第 03 篇**。范围边界：虚拟滚动（大列表按需渲染）归 [04-06 虚拟列表容器](../06_组件设计_虚拟列表容器/06_组件设计_虚拟列表容器.md)；图片懒加载由 [04-09 宽高比容器](../09_组件设计_宽高比容器/09_组件设计_宽高比容器.md)/媒体基类处理。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `LazyContainer.vue` | `src/components/container/` | 视口懒渲染：占位、进入视口挂载、可选延迟卸载 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `minHeight` | number \| string | 令牌 | 未渲染时占位高度（防抖动） |
| `rootMargin` | string | '100px' | 提前触发的视口边距 |
| `once` | boolean | true | 只渲染一次 |
| `unmountOnLeave` | boolean | false | 离开视口卸载（`once=false` 时） |
| `placeholder` | — | 默认骨架 | 未渲染占位 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 触发 | IntersectionObserver 进入视口（含 `rootMargin` 提前量） |
| 占位 | 未渲染显示占位骨架，`minHeight` 防布局抖动 |
| 缓存 | `once=true` 渲染后不卸载；`unmountOnLeave` 释放 |
| 令牌 | 占位/骨架令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 工作台长页 | 图表卡/列表进入视口才加载 |
| 长表单 | 底部区块懒渲染 |
| 移动端长列表 | 逐屏渲染 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：懒加载内容权限由内容自身判断。
- **i18n**：无文案。
- **移动端**：视口触发更敏感（滚动频繁）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 触发 | IntersectionObserver（避免 scroll 监听） |
| 边界 | 占位高度不准导致滚动抖动、首屏内容被懒加载（应排除首屏）、卸载后状态丢失、SSR/无 IntersectionObserver 降级直接渲染 |
| 不支持 | 虚拟滚动（04-06）、滚动区（04-02） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`minHeight`/`rootMargin`/`once`/`unmountOnLeave`/`placeholder`

- □ 继承 02 L2-04；与 04-06 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
