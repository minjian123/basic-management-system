## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**懒加载容器**的组件设计：内容进入视口才挂载，用于长页面（首页工作台、长表单、图片列表）的性能优化。继承[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的一层：标题/插槽/区域内边距等区域语义）。

> 本篇为 **容器组件类「懒加载容器」**。范围边界：虚拟滚动（大列表按需渲染）归 [容器组件类「虚拟列表容器」](../06_组件设计_虚拟列表容器/06_组件设计_虚拟列表容器.md)；图片懒加载由 [容器组件类「宽高比容器」](../09_组件设计_宽高比容器/09_组件设计_宽高比容器.md)与媒体能力处理。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 懒加载容器件 | 视口懒渲染：占位、进入视口挂载、可选离开视口卸载 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 占位高度 | 未渲染时的占位高度（防布局抖动），缺省取占位令牌 |
| 提前量 | 进入视口前提前触发的视口边距（如提前一屏） |
| 一次性渲染 | 渲染后不再卸载（默认）；可配置为离开视口时卸载 |
| 占位内容 | 未渲染时显示默认骨架或自定义占位 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 触发 | 进入视口才挂载（含提前量）；无法观察视口的环境降级为直接渲染 |
| 占位 | 未渲染显示占位骨架，占位高度防布局抖动 |
| 缓存 | 一次性渲染后不卸载；离开视口卸载可释放 |
| 令牌 | 占位/骨架令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 工作台长页 | 图表卡/列表进入视口才加载 |
| 长表单 | 底部区块懒渲染 |
| 移动端长列表 | 逐屏渲染 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：懒加载内容权限由内容自身判断。
- **i18n**：无文案。
- **移动端**：视口触发更敏感（滚动频繁）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 触发 | 视口相交观察（避免滚动监听） |
| 边界 | 占位高度不准导致滚动抖动、首屏内容被懒加载（应排除首屏）、卸载后状态丢失、SSR/无法观察视口的环境降级为直接渲染 |
| 不支持 | 虚拟滚动（容器组件类「虚拟列表容器」）、滚动区（容器组件类「滚动容器」） |
