## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**宽高比容器** `AspectRatio` 的组件设计：固定宽高比的容器，用于图片/视频/地图/二维码/占位，保证加载前后布局稳定（防抖动）。继承 [02 基础组件类 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md)、并复用 [02 L2-06 媒体组件基类](../../02_基础组件类/L2_形态基类/06_组件设计_媒体组件基类/06_组件设计_媒体组件基类.md) 的媒体加载能力。

> 本篇为 **04 容器组件类第 09 篇**。范围边界：媒体加载状态机归 [L2-06 媒体组件基类](../../02_基础组件类/L2_形态基类/06_组件设计_媒体组件基类/06_组件设计_媒体组件基类.md)；文件预览类型分发归 [07 展示类 08 文件预览](../../07_展示类/08_组件设计_文件预览/08_组件设计_文件预览.md)；二维码归 [07 展示类 13 二维码](../../07_展示类/13_组件设计_二维码/13_组件设计_二维码.md)。

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `AspectRatio.vue` | `src/components/container/` | 固定宽高比：比例、填充模式、占位、防抖动 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ratio` | number \| string | '16/9' | 宽高比（数字或 `'w/h'`） |
| `fit` | 'fill' \| 'contain' \| 'cover' \| 'none' | 'cover' | 内容填充 |
| `maxWidth` | number \| string | — | 最大宽度 |
| `minHeight` | number | — | 最小高度 |
| `placeholder` | — | 令牌背景 | 占位 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 比例 | 用 `aspect-ratio` CSS 或 padding-top 技巧；响应式宽度自适应 |
| 填充 | `fit` 映射 `object-fit`（图片/视频）或内层铺满 |
| 占位 | 未加载显示占位背景（令牌），保证布局稳定 |
| 响应式 | 宽度随容器；可 `maxWidth` 限制 |
| 令牌 | 占位色/圆角令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 图片/头像 | 固定比例展示 |
| 视频/地图 | 16:9 / 4:3 播放器 |
| 二维码/图表 | 固定方形比例 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：媒体可见性由数据范围/字段权限与预签名控制（[L2-06](../../02_基础组件类/L2_形态基类/06_组件设计_媒体组件基类/06_组件设计_媒体组件基类.md)）。
- **i18n**：无文案。
- **移动端**：比例自适应、懒加载。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 布局 | aspect-ratio 避免重排；内容懒加载 |
| 边界 | 比例字符串解析、`fit` 与容器尺寸、内容超高溢出、旧浏览器无 `aspect-ratio` 降级 padding 技巧 |
| 不支持 | 媒体加载状态机（L2-06）、文件预览（07-08） |
