## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**宽高比容器**的组件设计：固定宽高比的容器，用于图片/视频/地图/二维码/占位，保证加载前后布局稳定（防抖动）。它沿继承链派生——宽高比容器 → 容器能力（继承链上的一层）→ `BaseComponent` → `BaseObject`；媒体加载语义复用[媒体能力](../../02_基础组件类/02_能力类/06_组件设计_媒体能力/06_组件设计_媒体能力.md)。

> 本篇为 **容器组件类「宽高比容器」**。范围边界：媒体加载状态机归 [媒体能力](../../02_基础组件类/02_能力类/06_组件设计_媒体能力/06_组件设计_媒体能力.md)；文件预览类型分发归 [展示类「文件预览」](../../07_展示类/08_组件设计_文件预览/08_组件设计_文件预览.md)；二维码归 [展示类「二维码」](../../07_展示类/13_组件设计_二维码/13_组件设计_二维码.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 宽高比容器件 | 固定宽高比：比例、填充模式、占位、防抖动 |
| 媒体加载（复用） | 媒体加载状态机复用[媒体能力](../../02_基础组件类/02_能力类/06_组件设计_媒体能力/06_组件设计_媒体能力.md)（按需） |

- **继承关系**：沿继承链派生——宽高比容器 → 容器能力（继承链上的一层）→ `BaseComponent` → `BaseObject`；行为在链上层维护，不在组件内重复实现。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 比例 | 宽高比：数字或 `'宽/高'` 字符串（默认 16:9） |
| 填充模式 | `fill` / `contain` / `cover` / `none`（默认 `cover`） |
| 最大宽度 | 可选的最大宽度限制 |
| 最小高度 | 可选的最小高度 |
| 占位 | 未加载时的占位背景（令牌背景，默认） |
| 内容 | 默认插槽承载媒体/占位内容 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 比例 | 按比例撑起占位（不依赖内容高度）；宽度随容器自适应 |
| 填充 | 填充模式作用于图片/视频的内容适配，或内层铺满 |
| 占位 | 未加载显示占位背景（令牌），保证布局稳定 |
| 响应式 | 宽度随容器；可限最大宽度 |
| 令牌 | 占位色/圆角只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 图片/头像 | 固定比例展示 |
| 视频/地图 | 16:9 / 4:3 播放器 |
| 二维码/图表 | 固定方形比例 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：媒体可见性由数据范围/字段权限与预签名控制（[媒体能力](../../02_基础组件类/02_能力类/06_组件设计_媒体能力/06_组件设计_媒体能力.md)）。
- **i18n**：无文案。
- **移动端**：比例自适应、懒加载。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 布局 | 固定比例提前占位避免重排抖动；内容懒加载 |
| 边界 | 比例字符串解析、填充模式与容器尺寸、内容超高溢出、旧浏览器降级为占位撑高（浏览器能力降级） |
| 不支持 | 媒体加载状态机（媒体能力）、文件预览（展示类「文件预览」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：比例/填充模式/最大宽度/最小高度/占位
- □ 比例稳定、填充模式、占位防抖动、响应式、令牌
- □ 沿继承链派生（容器能力为继承链上的一层）；按需复用媒体能力；与 展示类「文件预览」/「二维码」 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认：宽高比与占位令牌、防抖动、容器组件类归属
