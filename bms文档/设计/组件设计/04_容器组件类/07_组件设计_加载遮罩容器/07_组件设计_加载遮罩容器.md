## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**加载遮罩容器**的组件设计：包裹内容并统一处理 **加载（遮罩/骨架）/ 空 / 错误 / 重试** 四态，用于列表、图表、详情等异步区域。它沿继承链派生——加载遮罩容器 → 容器能力（继承链上的一层）→ 组件根 → 总基类，通用行为在链上层维护、不在组件内重复实现。

> 本篇为 **容器组件类「加载遮罩容器」**。范围边界：整块空状态/错误页归 [展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（本容器复用其骨架/空/错误展示件）；懒加载归 [容器组件类「懒加载容器」](../03_组件设计_懒加载容器/03_组件设计_懒加载容器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 加载遮罩容器件 | 四态容器：加载（遮罩/骨架/旋转）、空、错误+重试、内容，按优先级互斥呈现 |
| 四态展示件（复用） | 遮罩/骨架/空/错误的展示件复用[展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md) |

- **继承关系**：沿继承链派生——加载遮罩容器 → 容器能力（继承链上的一层）→ 组件根 → 总基类；行为在链上层维护，不在组件内重复实现。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 加载态 | 是否处于加载中（默认否） |
| 加载形态 | `mask`（遮罩）/ `skeleton`（骨架）/ `spin`（旋转），默认 `mask` |
| 延迟显示 | 加载开始后延迟显示加载态（默认 200ms，防闪烁，见第 4 节） |
| 空态 | 无数据时为真（默认否） |
| 错误信息 | 错误文案；非错误态不显示 |
| 占位高度 | 各态占位的最小高度（默认取令牌） |
| 重试 | 错误态提供重试入口，点击对外通知重试 |
| 插槽 | 默认内容、自定义加载、空态、错误态四类插槽 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 延迟显示 | 快请求（快于延迟阈值）不显示加载态，避免闪烁 |
| 形态 | 遮罩 / 骨架 / 旋转三种加载形态（默认遮罩） |
| 四态互斥 | 加载 > 错误 > 空 > 内容（优先级） |
| 重试 | 错误态显示重试按钮并对外通知重试 |
| 令牌 | 遮罩/骨架/空态只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 详情区 | 局部加载遮罩 |
| 工作台卡片 | 骨架加载 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：错误信息不泄露技术细节（[《安全开发规范》](../../../../规范/安全开发规范.md)）。
- **i18n**：空态/错误/重试文案走 i18n。
- **移动端**：遮罩轻量、骨架适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 仅当前态渲染；骨架轻量 |
| 边界 | 闪烁（延迟显示）、快速切换态竞态、错误信息脱敏、占位高度抖动、重试重复点击 |
| 不支持 | 空状态组件本体（展示类「异常与空状态」）、懒加载（容器组件类「懒加载容器」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：加载态/加载形态/延迟显示/空态/错误信息/占位高度 + 重试
- □ 四态优先级、延迟显示、重试、令牌
- □ 沿继承链派生（容器能力为继承链上的一层）；与 展示类「异常与空状态」/ 懒加载容器 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认：四态容器契约、延迟显示、容器组件类归属
