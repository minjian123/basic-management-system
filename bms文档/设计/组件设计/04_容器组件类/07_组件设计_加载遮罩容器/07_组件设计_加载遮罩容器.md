## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**加载遮罩容器** `LoadingContainer` 的组件设计：包裹内容并统一处理 **loading（遮罩/骨架）/ 空 / 错误 / 重试** 四态，用于列表、图表、详情等异步区域。继承 [02 基础组件类 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md)。

> 本篇为 **04 容器组件类第 07 篇**。范围边界：整块空状态/错误页归 [07 展示类 05 异常与空状态](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)（本容器复用其骨架/空/错误组件）；懒加载归 [04-03](../03_组件设计_懒加载容器/03_组件设计_懒加载容器.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `LoadingContainer.vue` | `src/components/container/` | 四态容器：loading（mask/skeleton/spin）、empty、error+retry、content |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `loading` | boolean | false | 加载中 |
| `mode` | 'mask' \| 'skeleton' \| 'spin' | 'mask' | 加载形态 |
| `delay` | number | 200 | 延迟显示（防闪烁，ms） |
| `empty` | boolean | false | 空态 |
| `error` | string \| false | false | 错误信息 |
| `minHeight` | number \| string | 令牌 | 占位高度 |

| 事件 | 说明 |
| --- | --- |
| `retry` | 点击重试 |

- 插槽：`default`、`loading`（自定义加载）、`empty`、`error`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 延迟显示 | 快请求（< `delay`）不显示 loading，避免闪烁 |
| 形态 | mask 遮罩 / skeleton 骨架 / spin 旋转 |
| 四态互斥 | loading > error > empty > content（优先级） |
| 重试 | `error` 显示重试按钮触发 `retry` |
| 令牌 | 遮罩/骨架/空态令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 列表/图表 | 加载/空/错误统一 |
| 详情区 | 局部加载遮罩 |
| 工作台卡片 | 骨架加载 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：错误信息不泄露技术细节（[《安全开发规范》](../../../../规范/安全开发规范.md)）。
- **i18n**：空态/错误/重试文案走 i18n。
- **移动端**：遮罩轻量、骨架适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 仅当前态渲染；骨架轻量 |
| 边界 | 闪烁（延迟显示）、快速切换态竞态、错误信息脱敏、`minHeight` 抖动、重试重复点击 |
| 不支持 | 空状态组件本体（07-05）、懒加载（04-03） |
