## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端渲染插件 `frontend/packages/ui-ep`（PC 落点 `frontend/packages/ui-ep/src/components/container/`；移动端实现按需 `frontend/packages/ui-vant`；宿主消费 `frontend/apps/*`）**全屏容器** `FullscreenContainer` 的组件设计：将指定区域（或整个视口）全屏展示，用于大屏预览、报表/图表放大、代码/富文本阅读编辑。继承 [容器能力（原「容器能力」）](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)。

> 本篇为 **容器组件类「全屏容器」**。范围边界：大屏设计器播放归 [交互类「大屏设计器与播放」](../../08_交互类/09_组件设计_大屏设计器与播放/09_组件设计_大屏设计器与播放.md)（内部可用本容器）；弹窗外壳归 [容器组件类「弹窗抽屉表单」](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | boolean | false | 是否全屏（v-model） |
| `target` | 'self' \| 'document' \| Element | 'self' | 全屏目标 |
| `showTip` | boolean | true | 首次进入提示（Esc 退出） |
| `background` | string | 令牌 | 全屏背景色 |

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `fullscreen-change` | 全屏状态 |
| `fullscreen-error` | 请求全屏失败（降级） |

- 暴露方法：`enter()`、`exit()`、`toggle()`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 请求 | `requestFullscreen()`；失败（浏览器限制/iframe）降级为容器内铺满 |
| 退出 | Esc 或 API；监听 `fullscreenchange` 同步状态 |
| 内容 | 全屏内自适应（配合栅格/图表 resize） |
| 令牌 | 背景色只消费令牌 |

- **权限**：全屏入口按权限/场景。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 全屏 | 全屏内重算尺寸（图表 resize） |
| 边界 | 请求被浏览器拒绝（需用户手势）、iframe 限制、Esc 与自定义退出冲突、全屏中路由跳转 |
| 不支持 | 大屏播放逻辑（交互类「大屏设计器与播放」）、弹窗（容器组件类「弹窗抽屉表单」） |
