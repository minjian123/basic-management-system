## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**全屏容器**的组件设计：将指定区域（或整个视口）全屏展示，用于大屏预览、报表/图表放大、代码/富文本阅读编辑。继承[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的一层：标题/插槽/区域内边距等区域语义）。

> 本篇为 **容器组件类「全屏容器」**。范围边界：大屏设计器播放归 [交互类「大屏设计器与播放」](../../08_交互类/09_组件设计_大屏设计器与播放/09_组件设计_大屏设计器与播放.md)（内部可用本容器）；弹窗外壳归 [容器组件类「弹窗抽屉表单」](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 全屏状态 | 受控全屏状态（双向绑定） |
| 全屏目标 | 容器自身 / 整个文档 / 指定元素（缺省容器自身） |
| 首次提示 | 首次进入显示退出提示（Esc 退出） |
| 背景 | 全屏背景色（消费令牌） |
| 状态通知 | 全屏状态变化通知；请求全屏失败通知（供降级处理） |
| 命令 | 进入全屏 / 退出全屏 / 切换 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 请求 | 请求浏览器全屏；失败（浏览器限制/iframe）降级为容器内铺满 |
| 退出 | Esc 或命令退出；监听全屏状态变化同步 |
| 内容 | 全屏内自适应（配合栅格/图表尺寸重算） |
| 令牌 | 背景色只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 图表/报表 | 放大查看 |
| 大屏预览 | 全屏播放 |
| 富文本/代码 | 沉浸式阅读 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：全屏入口按权限/场景。
- **i18n**：全屏提示文案走 i18n。
- **移动端**：iOS 对元素全屏支持有限，优先整页沉浸。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 全屏 | 全屏内重算尺寸（图表自适应） |
| 边界 | 请求被浏览器拒绝（需用户手势）、iframe 限制、Esc 与自定义退出冲突、全屏中路由跳转 |
| 不支持 | 大屏播放逻辑（交互类「大屏设计器与播放」）、弹窗（容器组件类「弹窗抽屉表单」） |
