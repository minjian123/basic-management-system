## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**虚拟列表容器**的组件设计：大数据列表只渲染可视区（+缓冲），用于万级列表/日志/明细的性能优化。它沿继承链派生——虚拟列表容器 → 容器能力（继承链上的一层）→ 组件根 → 根系，通用行为在链上层维护、不在组件内重复实现。

> 本篇为 **容器组件类「虚拟列表容器」**。范围边界：分页列表归 [展示类「通用表格」](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)；视口懒加载归 [容器组件类「懒加载容器」](../03_组件设计_懒加载容器/03_组件设计_懒加载容器.md)；滚动行为归 [容器组件类「滚动容器」](../02_组件设计_滚动容器/02_组件设计_滚动容器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 虚拟列表件 | 可视区渲染：只渲染可视区 + 缓冲项，可视区外用占位撑高，DOM 数量恒定 |
| 项渲染 | 项内容由调用方经作用域插槽提供，支持定高与动态高度 |
| 可视区计算 | 由滚动位置、项高与缓冲推导可视区起止索引（PC 与移动端同一套契约口径） |

- **继承关系**：沿继承链派生——虚拟列表容器 → 容器能力（继承链上的一层）→ 组件根 → 根系；行为在链上层维护，不在组件内重复实现。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 数据源 | 列表项数组，由调用方持有（容器不取数） |
| 项高 | 定高按统一项高计算（默认 40）；动态高度按估算值渲染并在测量后缓存修正 |
| 缓冲项数 | 可视区上下各多渲染的项数（默认 5），减少快速滚动的白屏 |
| 项唯一键 | 项唯一标识（默认 `id`），用于渲染复用与滚动定位 |
| 容器高度 | 可视区高度（默认占满容器，可显式指定） |
| 滚动 | 可视区变化对外通知（滚动语义） |
| 触底 | 到达底部对外通知（配合加载更多，见第 4 节） |
| 滚动到索引 | 对外提供滚动到指定项的能力（数据未加载时的定位口径见第 8 节） |
| 插槽 | 默认作用域插槽，向调用方提供当前项与索引 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 渲染 | 只渲染可视区 + 缓冲项；可视区外用占位撑起总高，DOM 数量恒定 |
| 定高/动态 | 定高按公式计算；动态高度需测量并缓存 |
| 触底 | 触底触发加载更多（配合[容器组件类「滚动容器」](../02_组件设计_滚动容器/02_组件设计_滚动容器.md)） |
| 性能 | 大列表（≥1000 项）启用；小列表用普通渲染 |
| 令牌 | 项间距/边框只消费令牌 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：项内容按数据范围/字段权限。
- **i18n**：无文案。
- **移动端**：触屏惯性滚动、动态高度测量代价高。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 只渲染可视区+缓冲项；DOM 数量恒定 |
| 边界 | 动态高度测量抖动、项唯一键重复、滚动到索引时机（数据未加载）、触底重复触发、小列表误用（反性能） |
| 不支持 | 分页表格（展示类「通用表格」）、懒加载容器（容器组件类「懒加载容器」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：数据源/项高/缓冲项数/项唯一键/容器高度 + 滚动/触底/滚动到索引
- □ 可视区渲染、缓冲、定高/动态、触底
- □ 沿继承链派生（容器能力为继承链上的一层）；与 懒加载容器 / 通用表格 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认：虚拟滚动契约、触底加载、容器组件类归属
