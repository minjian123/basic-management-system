## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端渲染插件 `frontend/packages/ui-ep`（PC 落点 `frontend/packages/ui-ep/src/components/container/`；移动端同契约实现 `frontend/packages/ui-vant/src/components/container/`；宿主消费 `frontend/apps/*`）**虚拟列表容器** `VirtualList` 的组件设计：大数据列表只渲染可视区（+缓冲），用于万级列表/日志/明细的性能优化。继承 [容器能力（原「容器能力」）](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)。

> 本篇为 **容器组件类「虚拟列表容器」**。范围边界：分页列表归 [展示类「通用表格」](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)；视口懒加载归 [容器组件类「懒加载容器」](../03_组件设计_懒加载容器/03_组件设计_懒加载容器.md)；滚动行为归 [容器组件类「滚动容器」](../02_组件设计_滚动容器/02_组件设计_滚动容器.md)。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `items` | any[] | [] | 数据源 |
| `itemHeight` | number | 40 | 项高（定高）；动态高度用 `estimatedHeight` |
| `buffer` | number | 5 | 上/下缓冲项数 |
| `keyField` | string | 'id' | 项唯一键 |
| `height` | number \| string | 100% | 容器高度 |

| 事件 / 方法 | 说明 |
| --- | --- |
| `scroll` | 滚动（可视区变化） |
| `reach-bottom` | 触底（加载更多） |
| 方法 `scrollToIndex(i)` | 滚动到索引 |

- 插槽：`default`（作用域提供 `{ item, index }`）。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 渲染 | 只渲染可视区 + `buffer`；上下留白用占位撑高 |
| 定高/动态 | 定高按公式计算；动态高度需测量并缓存 |
| 触底 | 触底触发加载更多（配合 滚动容器） |
| 性能 | 大列表（≥1000）启用；小列表用普通渲染 |
| 令牌 | 项间距/边框令牌 |

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 只渲染可视区+缓冲；DOM 数量恒定 |
| 边界 | 动态高度测量抖动、`keyField` 重复、滚动到索引时机（数据未加载）、触底重复触发、小列表误用（反性能） |
