## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **报表设计器**的组件设计：总容器 `ReportDesigner.vue`（工具栏 + 三区布局 + 保存/发布），数据集选择 `DatasetSelector.vue`，图表配置面板 `ChartConfigPanel.vue`（图表类型、数据映射、ECharts 配置），报表画布 `ReportCanvas.vue`（gridstack 网格 + 图表卡渲染），以及组合式函数 `useReportDesigner.ts`（数据集取数、图表配置、布局序列化、保存发布）。适用于**报表中心**的拖动式报表设计（PC 管理端）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)「功能模块」之**报表中心**模块；上游设计依据[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（数据集 SQL 建模、拖拽报表设计器 ECharts、报表查看与参数、安全校验）与[《架构设计 · 报表BI》](../../../架构设计/19_架构设计_子系统_报表BI.md)（数据集管理、拖拽设计 ECharts、只读从库执行）；协作节点为[02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)（`EChart`/`chartTheme`/`ChartCard` 渲染与令牌色板，设计器与工作台共用）、[02 展示类 01 通用表格](../../02_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)（数据表视图）、[02 展示类 02 查询筛选区](../../02_展示类/02_组件设计_查询筛选区/02_组件设计_查询筛选区.md)（报表参数区，可选）、[03_交互类 05 代码表达式编辑器](../05_组件设计_代码表达式编辑器/05_组件设计_代码表达式编辑器.md)（数据集 SQL 与参数表达式，归属数据集管理页）、[03_交互类 01 弹窗抽屉表单](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（另存/发布确认）、[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)、[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（`rpt:design`）。

> 本篇为组件设计体系交互类第 09 篇。**范围边界**：**数据集 SQL 建模与安全执行**归[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)（本节点只选择数据集与取数预览）；**图表渲染内核**归 [02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)（本节点复用其 `EChart` 与主题）；**大屏自由画布**（vue-flow）归 10 大屏设计器与播放；**报表查看页**（按参数渲染）复用图表卡渲染，本节点只做设计态；移动端不提供设计器（见第 11 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `ReportDesigner.vue` | `src/components/report-designer/` | 总容器：工具栏（打开/新建/保存/发布/另存为/预览）、三区装配、脏数据拦截、加载与空态 |
| `DatasetSelector.vue` | `src/components/report-designer/` | 数据集选择：按 code/name 搜索选择 `rpt_dataset`、展示字段清单（`fields`）与参数、数据预览、状态校验（停用提示） |
| `ChartConfigPanel.vue` | `src/components/report-designer/` | 图表配置：图表类型（ECharts 全场景）、维度/度量数据映射、标题/图例/坐标轴/色板等常用项、高级 ECharts option（JSON 编辑器） |
| `ReportCanvas.vue` | `src/components/report-designer/` | 报表画布：gridstack 网格（12 列）、图表卡增删/拖拽/缩放、选中联动、实时渲染（复用 `EChart`）、多图表排版 |
| `useReportDesigner.ts` | `src/utils/useReportDesigner.ts` | 组合式函数：数据集/字段/参数、图表项模型、`chart_config` 与 `layout` 序列化、预览取数、保存/发布、脏数据基线 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，报表设计器归 `report-designer/`；组合式函数放 `src/utils/`）。
- **渲染共用**：画布内图表统一用 [02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 的 `EChart` 封装与 `chartTheme` 令牌主题，保证设计态、报表查看页、工作台图表卡三者一致。

## 3. 总体结构 <a id="structure"></a>

```mermaid
flowchart LR
    TB["工具栏：新建 / 打开 / 保存 / 发布 / 另存为 / 预览"]
    DS["数据集选择（左）<br/>选择 rpt_dataset · 字段清单 · 参数 · 数据预览"]
    CV["报表画布（中）<br/>gridstack 12 列网格 · 图表卡拖拽/缩放 · 实时渲染"]
    CP["图表配置（右）<br/>图表类型 · 维度/度量映射 · 常用项 · 高级 option"]
    TB --> DS --- CV --- CP
```

| 区域 | 内容 |
| --- | --- |
| 工具栏 | 新建、打开（选 `rpt_report`）、保存（草稿）、`发布`、另存为、预览（设计态 → 查看态） |
| 数据集选择（左） | 搜索选择数据集、展示字段与参数、拉取样例数据预览、停用/不可用提示 |
| 报表画布（中） | gridstack 网格 + 图表卡；点击图表卡选中，右侧配置联动；支持多图表排版 |
| 图表配置（右） | 按选中图表卡配置：类型、数据映射、样式常用项、高级 option |

## 4. 数据集与取数 <a id="dataset"></a>

| 项 | 设计 |
| --- | --- |
| 数据集来源 | `rpt_dataset`（`code`/`name`/`fields`/`status`/参数），只读从库执行（[《架构设计 · 报表BI》](../../../架构设计/19_架构设计_子系统_报表BI.md)） |
| 选择 | 搜索选择；展示字段清单（`fields`：名称/类型）供数据映射；停用数据集不可选并提示 |
| 参数 | 数据集声明的参数（页面/系统参数）；设计态可填样例值预览 |
| 预览取数 | 复用数据集执行接口（`/rpt/datasets/{id}/query` 或报表数据接口），返回 `{columns, rows}`；**只读从库 + 限深 + 限流**（同 [02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 取数口径） |
| 权限与数据范围 | 取数沿用 `rpt:view` 与动作级数据范围（查看时过滤）；设计态预览同样受数据范围约束 |
| 安全 | 数据集 SQL 由后端安全校验（仅 SELECT/白名单/参数化），前端不输入 SQL |

## 5. 图表配置 ChartConfigPanel <a id="chart-config"></a>

| 配置项 | 说明 |
| --- | --- |
| 图表类型 | ECharts 全场景（折线/面积/柱/条形/堆叠/饼/环/散点/漏斗/雷达/仪表盘/地图等，对齐 [02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md) 类型集） |
| 数据映射 | 维度（类目/时间轴）、度量（数值）、系列（分组字段）；可多度量 |
| 常用样式 | 标题、图例位置、坐标轴名称、堆叠、平滑、数据标注、色板（令牌图表色板） |
| 高级配置 | ECharts `option` 片段/JSON 编辑器（覆盖生成结果，仍以令牌主题为基础，**不硬编码色值**） |
| 主题联动 | 配色与坐标轴由 `chartTheme` 令牌主题统一，随深浅/租户品牌变化（[02 展示类 04 图表卡](../../02_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)「主题与色板」节） |
| 配置产物 | 序列化为 `chart_config`（图表类型 + 映射 + option 覆盖）存 `rpt_report.chart_config` |

## 6. 网格布局与画布 <a id="canvas"></a>

| 项 | 设计 |
| --- | --- |
| 网格 | **gridstack.js** 12 列网格（与首页工作台统一技术，[《架构设计 · 前端架构》](../../../架构设计/28_架构设计_前端架构.md)「技术要点」节）；图表卡可拖拽换位、右下角缩放 |
| 卡片 | 每个图表卡 = 一个 `rpt_report` 内的图表项（引用数据集 + chart_config + 位置尺寸 via gridstack） |
| 选中联动 | 点击卡片选中 → 右侧 `ChartConfigPanel` 联动；选中卡片高亮 |
| 卡片操作 | 新增图表卡（选数据集 + 类型）、复制、删除、居中等 |
| 布局序列化 | gridstack 结构（x/y/w/h + 图表项 id）序列化为 `layout` 存 `rpt_report.layout` |
| 实时渲染 | 卡片内用 `EChart` 渲染，配置变更即时更新；gridstack 缩放触发 `resize()` |
| 响应式 | 画布断点收窄（列数随宽度调整），与编辑栅格一致 |

- 与工作台卡片：gridstack 为工作台个人布局与报表设计器**统一网格技术**（layout_config 序列化结构一致），但**报表设计器布局属 `rpt_report.layout`**，不混入用户偏好。

## 7. 预览、保存与发布 <a id="save"></a>

| 操作 | 行为 |
| --- | --- |
| 预览 | 设计态在画布内直接渲染（真实 `EChart`）；「预览」可切换查看态（按参数取数、数据范围过滤） |
| 保存 | 校验（数据集有效、映射完整、option 合法）→ 写 `rpt_report`（status=draft/已保存）；清缓存 |
| 发布 | status=published；报表查看页可访问（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)） |
| 另存为 | 以当前定义新建 `rpt_report`（code/name） |
| 幂等 | 报表定义写接口支持 `Idempotency-Key`（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)「分页/幂等/限流」节） |
| 脏数据 | 配置/布局变更记基线，切换/离开拦截（[03_交互类 01 弹窗抽屉表单](../01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)口径） |

## 8. 组合式函数 useReportDesigner <a id="use-designer"></a>

```typescript
interface UseReportDesignerOptions {
  reportId?: string;
  onSaved?: () => void;
  onPublished?: () => void;
}

interface UseReportDesignerReturn {
  report: Ref<Report | null>;
  datasets: Ref<DatasetMeta[]>;
  currentDataset: Ref<DatasetMeta | null>;
  charts: Ref<ChartItem[]>;            // 图表项（dataset_id + chart_config + layout）
  selected: Ref<ChartItem | null>;
  preview: Ref<{ columns: string[]; rows: any[][] } | null>;
  dirty: ComputedRef<boolean>;
  loading: Ref<boolean>;
  saving: Ref<boolean>;
  loadDatasets: () => Promise<void>;
  selectDataset: (id: string) => Promise<void>;
  loadPreview: (params?) => Promise<void>;
  addChart / updateChart / removeChart / updateLayout;   // 结构操作
  save: () => Promise<void>;
  publish: () => Promise<void>;
  saveAs: (code, name) => Promise<void>;
}
```

| 行 | 设计 |
| --- | --- |
| 取数 | `loadDatasets()` 拉数据集清单；`loadPreview()` 调数据集执行接口取样例数据（只读从库、限深、限流） |
| 图表项 | `ChartItem = { id, datasetId, chartType, mapping, optionOverride, layout: {x,y,w,h} }`；`layout` 由 gridstack 变更回写 |
| 序列化 | 保存时打包 `chart_config`（类型/映射/覆盖）与 `layout`（gridstack）写 `rpt_report` |
| 脏数据 | 打开时 `stableStringify`（[04 基础类 03 格式化工具](../../04_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）记基线；比对得 `dirty` |
| 错误处理 | 数据集停用/不可用（90001）、执行超时/从库不可用（90003）、结果超限（90005）、限流（90006）按错误码提示（i18n） |

## 11. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：设计（数据集选择/图表配置/保存发布）需 `rpt:design`；查看/预览取数沿用 `rpt:view` 与动作级数据范围；报表定义写接口 `require_permission` 兜底（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：界面文案（工具栏/配置项/提示/错误码）走 vue-i18n；报表名称、图表标题可配多语言；数据集字段标签按 locale 下发；错误码按 `error.900xx` 映射；**不翻译用户数据**。
- **移动端**：不提供报表设计器；报表查看/数据查询在移动端复用后端接口渲染（[《概要设计 · 报表中心》](../../../概要设计/27_概要设计_报表中心.md)）。

## 12. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 分包 | 设计器与 gridstack/ECharts 独立分包懒加载；报表查看页也按需加载图表库 |
| 画布性能 | 多图表卡按需渲染（视口内）；gridstack 拖拽/缩放结束触发 `resize()`（防抖），不逐帧重绘 |
| 取数 | 预览取数限深/限流/只读从库；配置变更不频繁重取（改样式不重取数据，改映射才重取或本地重算） |
| 保存 | `chart_config`+`layout` 覆盖式提交；`Idempotency-Key` 防重复；保存中禁用重复提交 |
| 边界 | 数据集停用（90001）、执行超时/从库不可用（90003）、结果超限（90005）、限流（90006）、字段映射缺失、option 非法、空报表、多图表重叠（gridstack 约束）、脏数据拦截、无权限 |
| 不支持 | 数据集 SQL 建模与安全执行（后端）、图表渲染内核（02 展示类 04 图表卡）、大屏自由画布（10 大屏设计器）、报表查看页参数逻辑（页面）、移动端设计器 |

## 13. 检查清单 <a id="checklist"></a>

- □ 组件分层：`ReportDesigner` 装配与工具栏、`DatasetSelector` 数据集、`ChartConfigPanel` 配置、`ReportCanvas` 网格画布、`useReportDesigner` 状态与提交，职责不重叠
- □ 数据集：选择/搜索、字段清单、参数、样例预览（只读从库 + 限深/限流 + 数据范围）、停用提示
- □ 图表配置：图表类型集、维度/度量映射、常用样式、高级 option 覆盖、令牌主题（不硬编码色值）
- □ 网格画布：gridstack 12 列、增删/拖拽/缩放、选中联动、实时渲染（复用 `EChart`）、布局序列化
- □ 保存/发布/另存：`chart_config`+`layout` 结构、`Idempotency-Key`、脏数据拦截、错误码（900xx）
- □ 共用与分包：设计态/查看页/工作台图表一致，gridstack/ECharts 独立分包懒加载
- □ 权限（`rpt:design`/`rpt:view`/数据范围）、i18n（文案/字段标签/错误码）、移动端（不提供设计器）符合第 11 节
- □ 性能边界：画布按需渲染、resize 防抖、预览限流限深、保存幂等
- □ 三项上游登记已确认：报表设计器交互与配置结构、设计器与图表渲染共用与分包、预览取数与数据范围口径
