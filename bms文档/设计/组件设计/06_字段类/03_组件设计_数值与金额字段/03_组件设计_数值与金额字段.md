## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **数值与金额类字段**的通用组件设计：通用数值输入（NumberField）、金额输入（AmountField，含精度/币种/单位）、百分比输入（PercentField），以及精度与范围校验工具 `useNumberInput`、金额大写转换 `toChineseAmount`。适用于全部业务表单、查询筛选区与列表列渲染（如金额、数量、比例、费率、排序号）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与数据规范；上游设计依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（只读/编辑分态、字段校验）与[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（金额类查询用区间）；数据口径依据[《架构设计 · 数据架构》](../../../架构设计/05_架构设计_数据架构.md)（BIGINT 主键、`DECIMAL` 定点金额）与[《命名规范》](../../../../规范/命名规范.md)（金额/数量字段命名与精度约定）；展示格式化依据[《组件设计 · 格式化工具》](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)。

> 本篇为组件设计体系字段类第 03 篇；具体业务金额（合同金额、报销金额、订单金额）由各业务模块上游概要节点定义，本节点只定义通用字段契约。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `NumberField.vue` | `src/components/field/` | 通用数值输入：精度、上下限、步长、千分位显示 |
| `AmountField.vue` | `src/components/field/` | 金额输入：精度（默认 2）、币种符号、单位、可选大写提示 |
| `PercentField.vue` | `src/components/field/` | 百分比输入：口径（比值/已乘 100）、精度、范围 0~100 或 0~1 |
| `useNumberInput()` | `src/utils/useNumberInput.ts` | 精度/范围归一与校验规则生成（与后端同规则） |
| `toChineseAmount()` | `src/utils/amount.ts` | 金额转中文大写（合同/发票/凭证场景） |

- **继承**：`NumberField` 继承 03 基础控件·数字框（`NumberInput`）；`AmountField`/`PercentField` 在其上加币种、大写、百分比语义。
- 字段类组件统一受控：`modelValue` / `update:modelValue` + `change`（见[《组件设计 · 总览》](../../01_组件设计_总览.md)）。
- 命名遵循[《命名规范》](../../../../规范/命名规范.md)。

## 3. 值模型与精度 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 传输类型 | 金额/数值**以字符串或定点形式传输**（后端 `DECIMAL`），前端不以 JS `number` 做累加运算，避免浮点误差 |
| 前端内部 | 输入期允许编辑字符串；校验与展示走字符串/定点规则；仅格式化展示 |
| 精度 | 由字段元数据声明（金额默认 2，数量按业务，百分比默认 2/4）；`precision` 控制小数位 |
| 范围 | `min`/`max` 由字段元数据声明；超范围拦截并提示 |
| 空值 | `null` 表示未填；展示占位 `—` |
| 单位 | 金额可带单位（元/万元）、数值可带单位（个/件/次），仅展示层附加，不参与存储 |

> 关键红线：**金额不得使用浮点累加**。前端只负责录入与展示；汇总/计算由后端定点运算完成（见[《架构设计 · 数据架构》](../../../架构设计/05_架构设计_数据架构.md)）。

## 4. NumberField Props 与事件 <a id="number-props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| number \| null | — | 受控值 |
| `precision` | number | 0 | 小数位（0 表示整数） |
| `min` / `max` | number \| null | null | 上下限 |
| `step` | number | 1 | 步进（配合 `el-input-number`） |
| `unit` | string | '' | 单位后缀（展示用，走 i18n） |
| `thousandSeparator` | boolean | true | 失焦时显示千分位，聚焦时还原纯数字 |
| `disabled` | boolean | false | 只读/无权限（`editable=false` 由表单页传入） |
| `placeholder` | string | 请输入 | 占位文案 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string \| null | v-model 绑定（保持字符串精度） |
| `change` | string \| null | 变化通知 |
| `blur` / `focus` | — | 触发校验时机 |

## 5. AmountField（金额） <a id="amount"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | — | 金额（字符串，定点） |
| `precision` | number | 2 | 小数位（金额默认 2） |
| `currency` | string | 'CNY' | 币种（展示符号 `¥`/`$` 等） |
| `min` / `max` | string \| null | null | 金额范围（如 0 ~ 99999999.99） |
| `allowNegative` | boolean | false | 是否允许负数（如调整额） |
| `showUpper` | boolean | false | 是否显示中文大写提示（合同/发票） |
| `unit` | string | '元' | 单位（元/万元） |

- 失焦时按 `precision` 补齐小数位并加千分位；聚焦时还原可编辑纯数字。
- `showUpper` 开启时在输入框下方展示 `toChineseAmount(value)` 大写（如「壹万贰仟叁佰肆拾伍元陆角柒分」）。
- 金额精度与币种由**字段元数据**声明（[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)「字段属性调整」：组件类型、校验规则与默认值在线可配），组件 `precision`/`currency` 仅作兜底默认值；上游系统参数清单未定义金额精度项，如需系统级统一默认须先在[《概要设计 · 系统参数》](../../../概要设计/10_概要设计_系统参数.md)新增 `sys_config` 参数（登记为上游变更建议）。

## 6. PercentField <a id="percent"></a>

| 项 | 设计 |
| --- | --- |
| 口径 | `ratio=false`（默认）：输入即百分数（`12.34` → `12.34%`）；`ratio=true`：输入比值（`0.1234` → `12.34%`） |
| 精度 | 默认 2 位，可配（费率类可 4 位） |
| 范围 | 默认 0~100（ratio 时 0~1）；可配允许负数（增长率） |
| 展示 | 输入框右侧固定 `%`；只读回显走 `formatPercent` |

## 7. 校验规则 <a id="validate"></a>

| 规则 | 说明 |
| --- | --- |
| `required` | 必填（业务要求时） |
| `precision` | 小数位不得超过声明精度（如金额 2 位） |
| `min`/`max` | 范围校验（与后端同边界） |
| `allowNegative` | 是否允许负数 |
| `step` 对齐 | 数量类可按步长校验（如必须为整数件） |
| 一致性 | `useNumberInput()` 生成 `el-form` FormItemRule，前后端规则一致；后端仍强校验 |

## 8. 只读回显与列表渲染 <a id="readonly"></a>

- 表单只读态：组件置 `disabled`，展示 `formatAmount`/`formatNumber`（带千分位与单位）。
- 列表列：金额列右对齐（约定），用 formatter 统一格式化；空值 `—`。
- 汇总行/合计：由后端返回汇总值，前端仅展示（不在前端累加）。
- 导出：金额/数值列格式与页面一致（[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)），日期与金额格式由导出模板统一。

## 9. 查询区区间 <a id="filter"></a>

- 金额/数值类查询条件用区间（`el-input-number` × 2 或专用区间控件），提交参数 `*_min`/`*_max`（[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)）。
- 区间校验：min ≤ max；变化回第 1 页、保留其他筛选（`useListPage`，见 [请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大列表 | 格式化纯函数 + `Intl.NumberFormat` 缓存（见 [格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |
| 精度误差 | 前端不累加，避免浮点误差；输入以字符串承载 |
| 极大值 | 超出 `max` 或超过安全整数范围时拦截提示 |
| 粘贴输入 | 清洗非数字字符（除小数点与负号）；非法值不提交 |
| 边界值 | 0、负数、精度上限、上下限边界纳入单测 |

## 12. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 不渲染；`editable=false` 传 `disabled`（见 [权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；金额类字段常见「可见不可改」授权。
- **i18n**：单位、币种、占位走 vue-i18n；数字分隔符与小数符号按 locale（`Intl`）。
- **移动端**：frontend-mobile 用 `van-field type=number` + 自定义精度处理，值模型与校验规则口径同源，不复用 PC 组件。

## 13. 检查清单 <a id="checklist"></a>

- □ 受控组件 + `change`；`disabled` 只读回显
- □ 金额/数值以字符串/定点承载，前端不做浮点累加
- □ 精度、上下限、币种、单位、是否负数均可配；默认值取字段元数据（上游无金额精度系统参数）
- □ 失焦补精度 + 千分位，聚焦还原纯数字；`showUpper` 可显示大写金额
- □ 百分比口径（ratio）显式区分；范围默认 0~100（或 0~1）
- □ 校验规则由 `useNumberInput` 生成，前后端一致；后端强校验
- □ 只读/列表/导出格式统一；查询区间 `*_min`/`*_max` 且变化回第 1 页
- □ 字段权限与移动端口径符合第 12 节
