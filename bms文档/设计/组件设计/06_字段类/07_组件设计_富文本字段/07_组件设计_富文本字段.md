## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **富文本字段**的通用组件设计：富文本编辑字段 `RichTextField`（wangEditor 5 内核）、只读渲染 `RichTextViewer`、轻 Markdown 编辑字段 `MarkdownField`，以及组合式函数 `useRichText` 与净化工具 `sanitizeHtml`。覆盖双模式（富文本 / 轻 Markdown）、全量档工具栏（图片、附件卡片、表格、公式、代码高亮、目录导航）、HTML 白名单**双向** XSS 清洗、内嵌图片与附件复用 07 上传引擎、列表摘要与只读回显。适用于公告正文、帮助文章正文（含多语言附表）、邮件模板、业务长文本说明等场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与帮助中心/公告章节；上游设计依据[《概要设计 · 帮助中心》](../../../概要设计/17_概要设计_帮助中心.md)（`sys_help_article.content`、在线编辑、XSS 白名单清洗、内容校验错误码 40005）、[《概要设计 · 公告管理》](../../../概要设计/18_概要设计_公告管理.md)（`sys_notice.content`、公告渲染口径）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（字段属性组件类型切换、字段类型白名单）、[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)（技术要点、性能预算与分包）与[《架构设计 · 性能与安全》](../../../架构设计/30_架构设计_性能与安全.md)（XSS 防护：纯文本默认转义、富文本白名单净化）；页面形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（只读/编辑分态）；协作节点为 [文件上传字段](../06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)（图片与附件上传引擎）、[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（错误码提示）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（字段权限）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（文本处理口径）。

> 本篇为组件设计体系字段类第 07 篇。内容形态为 **HTML**（统一入库口径）：轻 Markdown 档保存时解析为 HTML 并净化后入库，不保留 Markdown 原文列；图片/附件上传复用 [文件上传字段](../06_组件设计_文件上传字段/06_组件设计_文件上传字段.md)，不重复设计。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `RichTextField.vue` | `src/components/field/` | 富文本编辑字段：wangEditor 5 内核、工具栏配置、字数/长度校验、只读/禁用态、v-model（HTML 字符串） |
| `RichTextViewer.vue` | `src/components/common/` | 只读渲染：净化后 HTML + 统一排版样式（标题层级、表格、代码块、公式、图片自适应、目录导航） |
| `MarkdownField.vue` | `src/components/field/` | 轻 Markdown 档：源码编辑 + 实时预览，保存时转 HTML（帮助中心技术文档场景） |
| `useRichText()` | `src/utils/useRichText.ts` | 编辑器生命周期与模式切换、内容序列化（HTML/纯文本）、可选目录提取、实例销毁与内存回收 |
| `sanitizeHtml()` | `src/utils/sanitize.ts` | DOMPurify 封装：HTML 白名单净化（渲染前二次过滤，白名单与后端同源） |
| `renderMarkdown()` | `src/utils/markdown.ts` | Markdown → HTML（markdown-it + 表格/代码/公式扩展），解析结果仍走 `sanitizeHtml()` |

- 字段类组件统一受控：`modelValue` / `update:modelValue` + `change`（见[《组件设计 · 总览》](../../01_组件设计_总览.md)）；`modelValue` 为 **HTML 字符串**（空值 `null`）。
- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词、工具函数 camelCase。
- 移动端（frontend-mobile）工程独立：只读按同一份净化后 HTML 渲染，需编辑时用源码输入，不复用 PC 组件（见第 12 节）。

## 3. 内容链路与双模式 <a id="flow"></a>

```mermaid
flowchart TD
    subgraph 编辑端
        A1["RichTextField（富文本档）"]
        A2["MarkdownField（轻 Markdown 档）"]
    end
    subgraph 提交与存储
        B1["序列化：统一产出 HTML"]
        B2["前端净化：sanitizeHtml（DOMPurify 白名单收窄）"]
        B3["提交 API（content = HTML）"]
        B4["后端白名单清洗（权威口径；不通过 → 内容校验错误码）"]
        B5["入库：sys_notice.content / sys_help_article.content(+i18n)"]
    end
    subgraph 渲染端
        C1["RichTextViewer / 前台、移动端、导出预览"]
        C2["前端二次净化：sanitizeHtml（防存量脏数据与接口直出）"]
        C3["统一排版样式渲染（含目录导航）"]
    end
    A1 --> B1
    A2 -->|"renderMarkdown"| B1
    B1 --> B2 --> B3 --> B4 --> B5
    B5 --> C1 --> C2 --> C3
```

| 模式 | 适用场景 | 编辑形态 | 保存口径 |
| --- | --- | --- | --- |
| 富文本档（`mode='rich'`） | 公告正文、帮助文章（图文混排）、邮件模板 | wangEditor 5 所见即所得（全量档工具栏） | 编辑器输出 HTML → 前端净化 → 提交 |
| 轻 Markdown 档（`mode='markdown'`） | 帮助中心技术文档（代码/表格/公式为主，编辑者偏好源码） | 左侧源码（等宽字体）+ 右侧实时预览（防抖 200ms） | `renderMarkdown()` → 前端净化 → 提交 **HTML** |
| 模式来源 | 由表单元数据（随 `GET /menus/my` 下发）或字段属性决定，**字段级固定** | — | 同一字段不做 HTML → Markdown 逆向转换（有损）；确需换模式时按纯文本源码降级展示并提示人工校对 |

- 两档共用同一套净化与渲染链路，**入库后不再区分来源模式**，前台/移动端/导出/AI 知识源只看 HTML。
- 编辑器与插件**异步按需加载**（`defineAsyncComponent` + 动态 `import()`）：仅当页面出现富文本字段时拉取，独立分包，不进入首屏主包（见第 11 节）。

## 4. 内容安全与白名单（XSS 双向清洗） <a id="security"></a>

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 前端净化（编辑入库前） | `sanitizeHtml()`，`RichTextField` / `MarkdownField` 序列化处 | 提交前净化一次，剔除粘贴带入的脏标签、事件属性与危险 URL；避免脏数据进库 |
| 前端净化（渲染前） | `sanitizeHtml()`，`RichTextViewer` / Markdown 预览 | 二次净化，防**存量脏数据**与接口直出（后端被绕过/历史数据）；只读回显只渲染净化后 HTML |
| 后端清洗（权威口径） | 接口 service / 序列化层 | 按白名单清洗，防接口直写脏数据；不通过返回内容校验错误码（帮助 40005，公告按公告模块 7xxxx 段） |
| 渲染原则 | `RichTextViewer` | **禁止 `v-html` 直出未净化内容**；纯文本字段仍走 Element Plus 默认转义；导出/打印同样只取净化后 HTML |

白名单（前后端同源，本节点登记为上游变更，见第 10 节）：

| 类别 | 允许 |
| --- | --- |
| 块级 | `p` `div` `h1`-`h6` `blockquote` `pre` `hr` `ul` `ol` `li` `table` `thead` `tbody` `tr` `th` `td` |
| 行内 | `span` `strong` `em` `u` `s` `code` `br` `sub` `sup` `a`（`href` 限 `http`/`https`/`mailto`/站内相对路径，渲染时强制 `rel="noopener noreferrer"`） |
| 图片 | `img`（`src` 仅允许站内文件预览 URL/预签名 URL，禁止 `data:` 与 `javascript:`；保留 `alt`/`title`；统一 `referrerpolicy="no-referrer"`） |
| 公式 | KaTeX 输出结构（`span.katex` 及其子节点/`mathml` 白名单子集） |
| 代码高亮 | `pre > code` 及 `class="language-*"`（语言白名单限定常用语言） |
| 附件卡片 | `a.rt-attachment[data-file-id][data-file-name]`（自定义属性需白名单放行，渲染层转 07 的下载/预览） |
| 样式 | `style` 属性按**属性级白名单**收窄（仅 `text-align` / `text-indent` / `width` / `height` / `max-width`），其余剥离；禁 `expression()`、`url(...)` |
| 禁止 | `script` `style` `iframe` `object` `embed` `form` `input` `video` `audio` `svg`、全部 `on*` 事件属性、`javascript:`/`data:text/html` URL、外链视频嵌入 |

- 实现：`sanitizeHtml(html)` 基于 DOMPurify，配置标签/属性/URL 协议白名单 + `afterSanitizeAttributes` 钩子（补 `rel`、校验图片 URL、过滤 `style` 属性）；同一份白名单以常量导出，供 Markdown 预览与只读渲染共用。
- 粘贴处理：编辑器 `paste` 过滤（Word/网页粘贴先净化再入编辑器），脚本与事件属性一律剥离；外链图片默认保留并统一 `referrerpolicy`，字段属性可配置「仅允许站内图片」时剥除外链。
- 与字段权限的关系：字段不可见（`visible=false`）不渲染、不可编辑（`editable=false`）走只读渲染；正文本身不落脱敏字段，脱敏（`v-plain`）不适用于富文本正文。

## 6. 工具栏与插件清单（全量档） <a id="toolbar"></a>

| 分组 | 项 | 依赖 / 实现 |
| --- | --- | --- |
| 文本 | 加粗、斜体、下划线、删除线、上下标、文字颜色、背景色、字号、字体 | wangEditor 内置 |
| 段落 | 标题 H1-H6、引用、有序/无序列表、对齐与缩进、分割线 | 内置 |
| 插入 | 表格、链接、图片上传、附件卡片、代码块（高亮）、公式、目录导航 | 图片与附件复用 07 `useFileUpload`；公式 `@wangeditor/plugin-formula`（KaTeX）；代码高亮 `@wangeditor/plugin-code-highlight`（PrismJS）；**附件卡片与目录导航为自定义菜单模块（自研，本节点交付项）** |
| 其他 | 撤销/重做、全屏、清空、字数统计 | 内置 |
| 排除项 | 视频、外链视频、协同编辑 | 本次范围不支持（见第 11 节边界） |

- **附件卡片（自研菜单模块）**：插入 `<a class="rt-attachment" data-file-id="..." data-file-name="..." data-file-size="...">`，编辑器内渲染为卡片（图标 + 文件名 + 大小）；只读渲染层转 07 的下载/预览入口，下载受 `file:download` 动作权限约束。
- **目录导航（TOC）**：只读渲染态按 `h1`-`h3` 自动生成锚点目录（侧栏或悬浮，滚动高亮）；编辑器内不放大纲面板（简化实现，升级项），`toc=false` 时不生成。
- **公式**：KaTeX 全量 CSS + 按需字体异步加载；渲染态直接复用同一套 CSS 渲染 KaTeX 输出结构，不二次解析。
- **代码高亮**：编辑器内用 PrismJS 高亮；只读渲染按 `class="language-*"` 高亮，语言限定常用白名单（避免整包引入全部语言）。
- 工具栏按字段属性裁剪（如公告可关闭公式/代码块），`basic` 档仅保留文本与段落两组 + 图片。

## 7. 轻 Markdown 模式 <a id="markdown"></a>

| 项 | 设计 |
| --- | --- |
| 解析器 | `markdown-it`（CommonMark 基线 + 表格/任务列表 + 代码高亮插件），输出 HTML 后统一 `sanitizeHtml()` |
| 编辑形态 | 左侧源码（等宽字体、行号可选）+ 右侧实时预览（防抖 200ms）；支持 Tab 缩进、粘贴图片自动上传并插入 `![](...)` |
| 语法集 | 标题/列表/表格/引用/代码块/行内代码/链接/图片/公式（`$...$` 与 `$$...$$` 交 KaTeX 渲染）/附件语法糖 `[附件:file_id]`（解析为附件卡片标签） |
| 安全 | 解析结果一律净化：`html` 选项仅对白名单标签放行，**禁止 raw HTML 直通**（防 Markdown 内嵌脚本） |
| 存储 | 保存时 `renderMarkdown()` → `sanitizeHtml()` → 提交 HTML（与富文本档同一入库口径），不保留 Markdown 原文列 |
| 切换 | 字段级固定（元数据 `mode`）；跨模式切换不做自动逆向转换（HTML → Markdown 有损），需人工校对后保存 |

## 8. 图片与附件上传协作 <a id="upload"></a>

- 内嵌图片：复用 [文件上传字段](../06_组件设计_文件上传字段/06_组件设计_文件上传字段.md) 的 `useFileUpload`（分片、秒传、断点续传、进度、失败重试）；上传成功插入 `img`（`src` 为预览 URL，附 `data-file-id`），编辑器内以占位图 + 进度呈现。
- 附件卡片：同样复用 07 上传与下载/预览能力；卡片携带 `data-file-id` 与展示用文件名/大小（避免渲染时逐个查询）。
- 限额与类型：继承 07 的字段级 `accept` / `maxSize` / `limit`；富文本内嵌图片默认 10MB/张、类型 `png,jpg,jpeg,webp,gif`，数量上限由字段属性声明。
- 失败与删除：上传失败内联提示（错误码 5xxxx）且不阻断正文编辑（占位可重试/移除）；删除图片或附件**不删文件**，由文件管理侧的孤儿回收策略统一清理（见[《概要设计 · 文件管理》](../../../概要设计/13_概要设计_文件管理.md)与[《架构设计 · 文件管理子系统》](../../../架构设计/19_架构设计_子系统_文件管理.md)）。
- 失效文件：渲染时 `data-file-id` 对应文件已失效（删除/过期）时展示「文件已失效」占位，不可下载。

## 9. 只读回显与渲染 <a id="readonly"></a>

| 场景 | 设计 |
| --- | --- |
| 表单只读态 / 详情页 | `RichTextViewer`：净化后 HTML + `.rich-text-content` 统一排版样式（标题层级、表格边框、代码块、引用、图片最大宽度 100%、表格横向滚动） |
| 列表页摘要 | 取 `getText()` 纯文本截断 + 单行省略；**列表不渲染 HTML**（避免 `v-html` 开销与样式污染） |
| 目录导航 | `toc=true` 时按 `h1`-`h3` 生成锚点目录，滚动高亮当前节 |
| 打印 / 导出预览 | 复用同一净化后 HTML 与样式表；PDF/Word 导出由导出引擎按 HTML 片段渲染 |
| 前台与移动端 | 帮助中心前台、公告查看、移动端均用同一净化后 HTML 口径，各端按自身样式适配 |
| 空值 | 展示占位 `—` 或「暂无内容」 |
| 多语言 | 正文按 `sys_help_article_i18n.content` / 公告多语言附表按 locale 取用，缺省回退默认语言（见第 12 节） |

## 10. 依赖接口与上游变更 <a id="api"></a>

### 10.1 上游接口与口径 <a id="api-contract"></a>

## 11. 性能与边界 <a id="performance"></a>

| 项 | 设计 |
| --- | --- |
| 加载策略 | 编辑器、插件、KaTeX/PrismJS 均**异步按需加载**并独立分包，仅富文本字段所在页面进入时拉取，不进入首屏主包（对齐[《架构设计 · 前端架构》](../../../架构设计/08_架构设计_前端架构.md)「路由分片后单页 JS 包 gzip ≤ 300KB」预算） |
| 公式 / 高亮 | KaTeX 仅公式档加载；PrismJS 只注册常用语言（不整包引入全部语言）；字体异步加载避免阻塞 |
| 大文档 | 字数上限（默认 2 万字）+ HTML 长度上限双兜底；超长内容提示分段；Markdown 预览防抖 200ms |
| 粘贴 | 粘贴先净化；大图片按 07 能力压缩后再上传；外链图片统一 `referrerpolicy` 或按字段属性剥除 |
| 内存 | 组件卸载与页面切换时销毁编辑器实例（`onBeforeUnmount` → `destroy()`）；Tab 缓存场景切回时按需重建 |
| 渲染 | 只读渲染一次性注入净化后 HTML；列表页不渲染 HTML（摘要取纯文本） |
| 边界 | 空内容、纯图片、仅公式、超长文本、超长 HTML、粘贴 Word/网页、外链图片、失效 `file_id` 图片、模式切换（不逆向）纳入测试 |
| 不支持 | 视频/外链视频、协同编辑（多人同时编辑）、版本对比与历史回滚（由审计与业务侧承载） |

## 12. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 不渲染；`editable=false` 走 `RichTextViewer` 只读渲染（不加载编辑器内核，节省体积）；正文不含脱敏字段，脱敏指令不适用（见 [权限指令与字段权限](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：工具栏提示、占位文案、字数超限、上传失败提示走 vue-i18n（错误码起于 [请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）；正文内容按 `sys_*_i18n` 附表多语言存储、按 locale 取用，**不翻译用户输入内容**；公式与代码块不参与翻译。
- **移动端**：只读按同一份净化后 HTML 渲染（H5 适配：图片 100% 宽、表格横向滚动、代码块换行、公式限宽）；需编辑时提供 Markdown/纯文本源码输入（textarea），**不引入移动端富文本编辑器**；双端共用 HTML 入库口径，展示一致。

## 13. 检查清单 <a id="checklist"></a>

- □ 受控组件（v-model 为 HTML 字符串）；双模式（`rich` / `markdown`）按字段元数据固定，不做逆向转换
- □ 工具栏全量档：图片、附件卡片、表格、公式（KaTeX）、代码高亮（PrismJS）、目录导航；不含视频
- □ XSS 双向清洗：提交前净化 + 渲染前净化（DOMPurify 白名单），后端清洗为权威口径（40005 兜底）；禁止未净化 `v-html`
- □ 白名单（标签/属性/URL 协议/`style` 属性级）与后端同源，已在帮助中心、公告管理、性能与安全登记
- □ 图片/附件复用 07 上传引擎（分片/秒传/断点续传/进度/失败重试）；下载受 `file:download` 约束；删除内容不删文件
- □ 列表摘要取纯文本不渲染 HTML；只读渲染统一排版样式；`toc=true` 生成 h1-h3 目录
- □ 编辑器与插件异步按需加载、独立分包、不进入首屏主包；卸载即销毁实例
- □ 字段权限（`editable=false` → 只读渲染）、i18n 提示与多语言正文、移动端只读 + 源码输入
- □ 上游变更已登记：字段属性组件类型、内容口径与白名单、新增前端依赖
