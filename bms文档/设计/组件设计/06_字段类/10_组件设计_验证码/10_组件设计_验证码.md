## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **验证码**的组件设计：验证码字段 `Captcha.vue`（类型分发：图形 / 滑块 / 短信）与组合式函数 `useCaptcha.ts`（获取/刷新/倒计时/校验/错误处理/阈值联动）。适用于**登录页**（图形验证码，连续失败后强制）、**找回密码 / 绑定手机 / 手机号验证**（短信验证码）、**防刷场景**（滑块）。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与安全章节；上游设计依据[《概要设计 · 身份认证 SSO》](../../../概要设计/26_概要设计_身份认证SSO.md)（本地账号密码登录、连续失败限流 + 图形验证码策略）、[《概要设计 · 会话管理》](../../../概要设计/14_概要设计_会话管理.md)（认证段与验证码错误）、[《概要设计 · 登录日志》](../../../概要设计/12_概要设计_登录日志.md)（失败原因含验证码错误、连续失败 3 次强制图形验证码）、[《概要设计 · 邮件通知》](../../../概要设计/24_概要设计_邮件通知.md)（短信通道 `sys_sms_template`/`sys_sms_log`、`/sms/send`、每账号 1 次/5 分钟、每 IP 5 次/小时限流）、[《概要设计 · 系统参数》](../../../概要设计/10_概要设计_系统参数.md)（`captcha.required_after_failures`）；协作节点为[07 基础类 01 请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（获取/校验请求与限流错误处理）。

> 本篇为组件设计体系字段类第 10 篇。**范围边界**：验证码**生成与校验**（图形码生成、短信下发、Redis 限流、校验与一次性失效）在**后端**；本节点只负责前端展示、输入、刷新、倒计时与错误提示；**滑块**为可选前端交互（是否启用由安全策略配置）；登录页整体布局归[《布局设计》](../../../布局设计/01_布局设计_总览.html)/原型（登录页），本节点只提供验证码字段；移动端不复用 PC 组件（见第 10 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `Captcha.vue` | `src/components/field/` | 验证码字段：类型分发（图形/滑块/短信）；图形展示与刷新、短信输入与倒计时按钮、滑块交互、校验状态与错误提示 |
| `useCaptcha.ts` | `src/utils/useCaptcha.ts` | 组合式函数：获取/刷新验证码、短信倒计时与重发、提交校验、阈值联动（失败 N 次强制图形）、错误处理 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（字段控件归 `field/`；组合式函数放 `src/utils/`）。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string | '' | 用户输入（短信验证码/图形验证码文本）；滑块类型不绑定值（以 `verified` 表示） |
| `type` | 'image' \| 'slider' \| 'sms' | 'image' | 验证码类型 |
| `imageUrl` | string \| null | null | 图形验证码图片地址（后端生成）；缺省由 `useCaptcha` 获取 |
| `phone` | string | '' | 短信目标手机号（脱敏显示） |
| `length` | number | 6 | 输入长度（短信默认 6） |
| `countdown` | number | 60 | 短信重发倒计时（秒） |
| `refreshable` | boolean | true | 图形验证码是否可点击刷新 |
| `disabled` | boolean | false | 禁用 |
| `required` | boolean | true | 是否必填展示（登录阈值未到时可隐藏） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string | 输入变化 |
| `verified` | boolean | 滑块验证通过（`type='slider'`） |
| `refresh` | — | 刷新图形验证码 |
| `send` | phone | 请求发送短信（由父组件调接口）；成功后启动倒计时 |
| `change` | value | 值/验证状态变化 |

- 暴露方法：`refresh()`、`sendSms()`、`reset()`。

## 4. 图形验证码 <a id="image"></a>

| 项 | 设计 |
| --- | --- |
| 展示 | 后端生成的图片（`imageUrl`，含干扰线/字符）；点击图片或刷新按钮重新获取（`refresh`，不缓存、带随机参数防缓存） |
| 输入 | 文本输入框（长度 4-6，大小写不敏感由后端判定），回车提交 |
| 显示时机 | **连续登录失败达阈值后强制显示**（`captcha.required_after_failures`，默认 3，[《概要设计 · 登录日志》](../../../概要设计/12_概要设计_登录日志.md)）；未达阈值可隐藏（由父页面按后端返回决定） |
| 校验 | 随登录/提交一并提交，后端校验；错误提示「验证码错误」并刷新图片 |
| 一次性 | 校验失败或使用后失效，需重新获取（后端保证） |

## 5. 滑块验证码 <a id="slider"></a>

| 项 | 设计 |
| --- | --- |
| 交互 | 拖动滑块到缺口位置；松手后前端把位移/轨迹 token 提交后端校验（后端判定，前端不做真伪判断） |
| 状态 | 待拖动 → 拖动中 → 校验中 → 通过（绿色对勾）/ 失败（自动复位 + 提示可重试） |
| 触发 | 高频/风控场景启用（登录、注册、找回密码）；是否启用由安全策略与后端下发决定 |
| 降级 | 滑块不可用时降级为图形验证码（后端策略） |
| 可访问性 | 提供键盘可操作与失败重试；不阻塞服务端强校验 |

## 6. 短信验证码 <a id="sms"></a>

| 项 | 设计 |
| --- | --- |
| 展示 | 手机号（脱敏）+ 验证码输入框 + 「获取验证码」按钮 |
| 发送 | 点「获取验证码」→ 父组件调 `/sms/send`（[《概要设计 · 邮件通知》](../../../概要设计/24_概要设计_邮件通知.md)）→ 成功启动倒计时（默认 60s），按钮置灰显示「重新发送(59s)」 |
| 限流提示 | **每账号 1 次/5 分钟、每 IP 5 次/小时**（后端 Redis 限流）；命中限流提示「发送过于频繁，请稍后再试」并**不启动/重置倒计时**（倒计时与后端冷却一致） |
| 校验 | 用于找回密码、绑定/更换手机、手机号验证；随业务提交，后端校验一次性有效性 |
| 错误 | 验证码错误、已过期、发送失败（渠道错误）分别提示（i18n/错误码） |
| 防缓存 | 不缓存验证码；输入框 `autocomplete="one-time-code"`（移动端可自动填充） |

## 7. 组合式函数 useCaptcha <a id="use-captcha"></a>

```typescript
interface UseCaptchaOptions {
  type: 'image' | 'slider' | 'sms';
  phone?: string;
  countdown?: number;
  fetchImage?: () => Promise<string>;      // 获取图形验证码
  sendSms?: (phone: string) => Promise<void>;
}
interface UseCaptchaReturn {
  imageUrl: Ref<string | null>;
  code: Ref<string>;
  countdown: Ref<number>;
  sending: Ref<boolean>;
  verified: Ref<boolean>;                   // 滑块/通过
  refreshImage: () => Promise<void>;
  sendSms: () => Promise<void>;
  startCountdown: () => void;
  reset: () => void;
}
```

| 行 | 设计 |
| --- | --- |
| 图形 | `refreshImage` 获取图片 URL（随机参数防缓存）；失败可重试 |
| 短信 | `sendSms` 成功后 `startCountdown`（倒计时随组件生命周期、页面隐藏不暂停但以后端冷却为准）；命中限流不重置 |
| 阈值联动 | 父页面据后端返回的「是否需要验证码」决定是否渲染图形验证码（失败达阈值） |
| 校验 | 由父页面随业务请求提交；组件只负责取值与错误展示 |
| 释放 | 卸载清除倒计时定时器 |

## 10. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：验证码为登录态前能力（无权限码）；短信发送受后端渠道与限流约束；不涉及字段权限。
- **i18n**：占位、刷新提示、倒计时、错误提示走 vue-i18n；图形验证码字符本身由后端生成；错误码按 `error.2xxxx` 映射。
- **移动端**：不复用 PC 组件；移动端登录/找回密码以 Vant 表单 + 验证码按钮（含倒计时）+ 滑块实现，值与校验口径同源。

## 11. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 图形 | 图片请求带随机参数防缓存；不预取；点击即刷新 |
| 短信倒计时 | 定时器随组件生命周期；卸载清除；以后端冷却为准（前端倒计时仅辅助） |
| 滑块 | 本地交互轻量；校验请求异步不阻塞其他输入 |
| 边界 | 验证码错误/失效、刷新失败重试、短信限流（提示且不重置倒计时）、渠道发送失败、手机号格式非法、阈值未到隐藏图形验证码、滑块失败复位、倒计时与后端冷却不一致、禁用态、移动端键盘 |
| 不支持 | 验证码生成/校验/限流（后端）、登录页整体布局、字段权限（不适用）、移动端组件 |

## 12. 检查清单 <a id="checklist"></a>

- □ 类型分发：图形 / 滑块 / 短信；`modelValue` 受控 + `change`
- □ 图形：展示后端图片、点击/按钮刷新（防缓存）、失败/使用后一次性失效、随提交校验；连续失败阈值后强制显示
- □ 滑块：拖动交互、校验中/通过/失败复位；只提交轨迹 token，不做前端判断；不可用降级图形
- □ 短信：手机号脱敏、发送倒计时（60s）、限流命中提示且不重置倒计时、`autocomplete="one-time-code"`、错误（错误/过期/发送失败）
- □ `useCaptcha`：刷新/发送/倒计时/校验/释放；阈值联动由父页面
- □ i18n（文案/错误码/倒计时）、移动端（Vant + 滑块，口径同源）符合第 10 节
- □ 性能边界：防缓存、定时器清理、以后端冷却为准、异步校验不阻塞
- □ 三项上游登记已确认：验证码前端契约与阈值联动、短信交互与限流口径、滑块作为可选防刷
