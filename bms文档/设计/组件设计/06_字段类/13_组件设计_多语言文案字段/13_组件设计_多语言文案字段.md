## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**多语言文案字段**的组件设计：表单里只占**一行**——一个文本框（就地编辑**必填语言**即当前登录用户语言的文案）+ 一个打开**多语言明细弹框**的按钮；弹框内以**明细表**呈现全部语言（语言 / 文案两列，行内编辑），支持语言关键字与「仅看缺失 / 仅看已填」筛选，并标出**系统默认语言**与**必填语言**。适用于平台与产品全部需要多语言维护的展示文案实体：菜单、表单、按钮、字段、业务码、动作码、字典类型与字典项、邮件与短信模板、工作台卡片、租户自定义图标、表单定制的租户自建字段。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；上游设计依据[《架构设计 · 国际化》](../../../架构设计/24_架构设计_子系统_国际化.md)「业务数据文案（i18n 附表）」节（文案不入主表、按 locale 关联、缺省回退默认文案）、[《数据库设计 · 数据规范》](../../../数据库设计/02_数据库设计_数据规范.md)「多语言与 i18n 附表」节、[《概要设计 · 国际化管理》](../../../概要设计/29_概要设计_国际化管理.md)（语言清单、启用语言下发、默认语言标记）与[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「字段 i18n」节；协作节点为[容器组件类「弹窗抽屉表单」](../../04_容器组件类/01_组件设计_弹窗抽屉表单/01_组件设计_弹窗抽屉表单.md)（弹框容器与确认/取消语义）、[展示类「通用表格」](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)（明细表行内编辑）、[交互类「国际化文案编辑器」](../../08_交互类/11_组件设计_国际化文案编辑器/11_组件设计_国际化文案编辑器.md)（前后端**固定文案**的网格维护，与本节点范围不同）、[基础控件类「文本框」](../../05_基础控件类/01_组件设计_文本框/01_组件设计_文本框.md) / [基础控件类「文本域」](../../05_基础控件类/02_组件设计_文本域/02_组件设计_文本域.md)（字段外壳与明细内层输入）、[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（字段可编辑性）。

> 本篇为「多语言文案字段」节点。**范围边界**：**前后端固定文案**（错误消息、按钮、提示）的网格维护归 [交互类「国际化文案编辑器」](../../08_交互类/11_组件设计_国际化文案编辑器/11_组件设计_国际化文案编辑器.md)，本节点只管**业务实体的展示文案**；**语言清单自身的增改启停与默认语言标记**归「国际化管理」模块（本节点只消费启用语言清单）；**语言 / 时区偏好**归个人中心；**机翻与译文生成**不在本节点（只做人工录入）；移动端不提供文案维护（见第 8 节）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 多语言文案字段件（字段外壳） | 一行装配：文本框（就地编辑必填语言文案）+ **图标按钮**（悬停提示「多语言文案」，不写文字标签）；必填校验、缺省占位、只读回显、禁用；字段下方给出「已填 x / y · 缺失：…」提示 |
| 多语言明细弹框件 | 明细表（语言 / 文案行内编辑）、筛选（语言关键字 / 仅看缺失 / 仅看已填）、标记（系统默认语言 / 必填语言）、确定与取消、脏数据拦截 |
| 语言清单装配 | 取启用语言清单（语言标识 / 语言名 / 默认标记 / RTL）、解析**必填语言**与**系统默认语言**、停用语言的存量值处理 |
| 提交装配 | 整体映射提交（弹框确定回写字段值，最终随宿主「保存」提交）、必填语言缺失校验与定位、停用语言存量值透传 |
| 继承链 | 多语言文案字段 → [输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md) → 值能力基类 / 字段能力基类 → 组件根 → 总基类；明细弹框件自成一族（弹出式编辑器族，经弹窗抽屉表单口径），行为在链上层维护 |

- 明细弹框件**独立成件**：字段件只负责「一行外壳 + 打开弹框」，弹框件可被任何多语言场景单独复用（表单字段、列表批量补文案、导入前核对）。
- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 语言标识 → 文案的**映射**（整体提交，如「zh-CN → 用户管理」「en-US → User management」） |
| 字段外壳值 | 就地编辑**必填语言**的文案（等价于映射中该语言的值），不存在双份存储 |
| 语言清单 | 启用语言清单（语言标识、语言名、默认语言标记、RTL 标记），随宿主取数注入；停用语言不进入明细表 |
| 必填语言 | **当前登录用户的界面语言**；该语言不在启用清单或为空时，回退为**系统默认语言**。必填语言文案为空即校验不通过 |
| 系统默认语言 | 语言清单的**默认语言标记**（全清单唯一）；只用于两件事：**派生主表默认文案**与作为**缺省回退目标**，不承担「必填」语义 |
| 明细表顺序 | 必填语言恒置顶标「必填」；系统默认语言标「默认」；其余按清单序 |
| 必填口径 | 仅必填语言必填；其余启用语言可缺省 |
| 缺省回退 | 某语言缺省时按**系统默认语言**文案回退展示；字段**不合成**回退值，回退由展示与下发侧统一处理 |
| 缺失标记 | 明细表内标「缺失」（该语言值为空），字段下方汇总「已填 x / y 种语言，缺失：…」，点缺失语言直接打开弹框并定位 |
| 形态 | 单行（名称 / 标题）与多行（描述 / 备注 / 正文）两种，作用于字段外壳与明细内层输入；由宿主按文案语义声明 |
| 条数上限 | 单条文案按 Unicode 码点计上限（与平台固定文案编辑器同口径），超长截断提示 |
| 只读回显 | 只读态按**当前界面语言**回显单值；该语言无值时沿回退链（当前语言 → 系统默认语言 → 首个有值语言） |
| 禁用与权限 | 字段可编辑性由字段权限控制：不可编辑时字段外壳禁用且「多语言」按钮隐藏；不可见时不渲染 |
| 值变化通知 | 受控更新 + 变更通知（带变更的语言标识） |
| 内容操作 | 整体设值、按语言设值、取缺失语言集合、打开 / 关闭明细弹框、提交前校验 |

## 4. 交互与形态 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 字段占用 | 表单里恒定**一行**（文本框 + 图标按钮），高度与语言数量无关、与同排字段对齐——这是本节点采用「外壳 + 弹框」而**不逐语言铺开**的根本原因 |
| 就近编辑 | 文本框就地编辑必填语言文案：用户最常写的正是自己看得懂的那一份，无需开弹框 |
| 字段提示 | **不占字段下方的固定行**：完整度与缺失放进**按钮悬停提示**（无缺失为「多语言文案 · 已填 2 / 4」，有缺失为「多语言文案 · 缺失：日本語、한국어」）；字段标签不标注「多语言」字样（入口由按钮本身表达），必填语言与系统默认语言在弹框内标记 |
| 打开明细 | 点字段旁的**图标按钮**（悬停提示「多语言文案」）打开明细弹框；**弹框内为草稿**——「确定」把草稿回写字段（页面显示为新值），「取消」丢弃弹框内改动；最终仍随宿主工具栏「保存」统一提交（对齐[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「整体保存」口径） |
| 明细行内编辑 | 明细表两列（语言 / 文案），文案列行内编辑；长文案形态下内层为多行输入并支持行展开 |
| 语言项生成 | 明细行**由启用语言清单动态生成**——新增语言即多一行、停用语言即少一行，界面与提交契约都不随语言增减而变化 |
| 标记 | 语言列标出「必填」（必填语言）与「默认」（系统默认语言）；两者可为同一语言 |
| 筛选 | 语言关键字（按语言名或语言标识）；「仅看缺失」（该语言值为空）与「仅看已填」互斥切换；筛选为弹框内本地筛选，不额外请求 |
| 缺省提示 | 非必填语言的文案列为空时，输入占位提示回退目标（回退链首位有值者） |
| 脏数据保护 | 弹框内有改动时点「取消」或按 Esc 关闭 → 二次确认（放弃 / 继续编辑）；字段级 dirty 由宿主统一拦截 |
| 停用语言 | 停用语言不出现在明细表，但其**存量值随提交透传**，不因界面未展示而清空 |
| 只读态 | 字段外壳按当前界面语言回显纯文本、无「多语言」按钮（需要总览时只读展示明细表，不可编辑） |
| 语言清单取数失败 | 降级为「仅必填语言可编辑」并在字段下方提示（弹框按钮置灰），不阻断其它字段录入 |
| 语言清单异常 | 清单无默认语言标记属异常，快速失败并提示（不静默取第一项语言） |
| 空态 | 语言清单为空时展示占位，字段不可编辑 |

## 5. 数据与缓存 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 语言清单来源 | 启用语言**只读出口**（登录即可访问，见第 7 节登记项①）；按会话缓存，语言清单变更后失效重取 |
| 提交口径 | 整体映射**一次提交**（不按语言逐次请求）；弹框确定只改本地字段值，落库随宿主保存 |
| 必填校验 | 前端阻断 + **服务端按请求语言强制**（请求语言 = 登录用户语言，未启用则回退系统默认语言）；多客户端（产品模块 / 开放接口 / 导入）共用同一道门 |
| 默认文案派生 | 服务端按**优先级兜底**派生主表默认文案列：**系统默认语言 → 必填语言 → 清单中首个有值的语言**——保证该列永不为空（列表 / 排序 / 菜单标题不闪空），界面不单独维护该列 |
| 读取口径 | 读侧返回**完整映射**（含各语言）+ 默认文案列（供列表零关联展示）；缺省语言由消费侧按系统默认语言文案回退 |
| 回退链 | 某语言无值 → 回退系统默认语言文案；系统默认语言亦无值 → 取默认文案列（派生兜底值）；再无可取 → 空值占位（不渲染空白阻塞） |
| 缓存 | 语言清单随会话缓存；业务实体的文案随宿主记录缓存，保存后以返回体刷新 |

## 6. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 平台元数据维护 | 菜单 / 表单 / 按钮 / 字段 / 业务码 / 动作码 / 租户自定义图标表单内的名称维护（字段外壳 + 明细弹框） |
| 字典维护 | 字典类型与字典项的名称维护 |
| 通知与模板 | 邮件 / 短信模板的主题与正文（多行形态；条数多时改用弹框内的表格分页或独立维护页） |
| 工作台卡片 | 内置卡片与平台默认模板的卡片名维护 |
| 表单定制 | 租户自建字段的名称维护 |
| 列表批量补文案 | 新增语言后，从列表页按「缺失语言」筛出记录，逐条打开明细弹框补齐（弹框件独立复用） |
| 消费侧只读 | 动态菜单与表单元数据按 locale 下发已解析文案，本节点不参与消费侧渲染 |
| 移动端 | 不提供文案维护；移动端仅按 locale 只读展示 |

### 7.2 需登记的上游变更 <a id="api-upstream"></a>

| 变更点 | 目标文档 | 内容 |
| --- | --- | --- |
| ① 启用语言只读出口 | [《概要设计 · 国际化管理》](../../../概要设计/29_概要设计_国际化管理.md)「接口设计」节 | 语言清单查询现为 `i18n:manage`；补「登录即可」的**启用语言只读出口**，供各模块表单渲染语言项（产品模块维护页不必持有语言管理权限） |
| ② 默认语言标记 | [《概要设计 · 国际化管理》](../../../概要设计/29_概要设计_国际化管理.md)「数据模型」与「业务规则」节 | 语言清单增**默认语言标记**（全清单唯一、不可停用、不可删除）；默认语言只承担「派生默认文案 + 缺省回退目标」，**不承担必填语义**；切换默认语言不搬动业务文案 |
| ③ 必填语言口径 | [《架构设计 · 国际化》](../../../架构设计/24_架构设计_子系统_国际化.md)「业务数据文案（i18n 附表）」节、[《概要设计 · 国际化管理》](../../../概要设计/29_概要设计_国际化管理.md)「业务规则」节 | 明确**必填语言 = 当前登录用户语言**（该语言未启用或为空时回退系统默认语言）；服务端保存时按**请求语言**强制校验其文案非空，前端同口径阻断 |
| ④ 多语言附表口径 | [《数据库设计 · 数据规范》](../../../数据库设计/02_数据库设计_数据规范.md)「多语言与 i18n 附表」节 | 明确**附表承载全部语言（含默认语言）**；主表默认文案列为服务端按**优先级兜底**（系统默认语言 → 必填语言 → 首个有值语言）派生的快照，写侧只提交映射；缺省回退口径一并写明 |
| ⑤ 业务数据文案口径 | [《架构设计 · 国际化》](../../../架构设计/24_架构设计_子系统_国际化.md)「业务数据文案（i18n 附表）」节 | 补「附表承载全部语言、主表默认文案派生」与「默认语言由语言清单标记驱动」两条，替换隐含的「默认语言固定为某标识」表述 |
| ⑥ 表单内形态与旧写法清理 | [《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「字段 i18n」节 | 补多语言文案字段的表单内形态（**字段外壳一行 + 多语言明细弹框**、必填语言就近编辑、缺失汇总与跳转、只读回退）；同时清理各章节「中英文名称两栏」与「逐语言铺开」的写法，标注本节点为契约依据 |

> 按[《文档生成规范》](../../../../规范/文档生成规范.md)「引用与追溯」节，上述变更需用户确认后由上游文档同步；本节点只定义组件契约，不单独裁决接口与存储格式。

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段可编辑性由字段权限（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制；多语言文案的维护权限随**宿主模块**（菜单维护、字典维护、图标维护等），本节点不引入独立权限码；启用语言清单为只读、登录即可。
- **i18n**：本组件自身界面文案（语言名、必填 / 默认 / 缺失标记、筛选、占位、提示）走全局语言能力，语言名由语言清单下发（用户维护）；**语言项数量与语言标识不写死在界面**，这是本节点存在的根本理由。
- **移动端**：不提供文案维护（管理端能力）；移动端按 locale 只读展示下发的文案。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 语言数量 | 明细行随清单增减；字段恒定一行 + 弹框内滚动，语言再多也不影响表单高度与对齐 |
| 长文案 | 多行形态；明细内层多行输入 + 行展开；单条按 Unicode 码点计上限；条数多的实体（邮件模板等）可在弹框内置表格分页 |
| 提交 | 整体映射一次提交；弹框确定只改本地值；不为每个语言发起独立请求 |
| 边界 | 必填语言缺失（阻断并定位）、必填语言不在启用清单（回退系统默认语言）、启用语言新增后存量记录缺该语言、停用语言存量值保留、语言清单取数失败降级、语言清单无默认标记（快速失败）、弹框内脏数据取消（二次确认）、只读回退链（当前语言 → 系统默认语言 → 派生默认文案 → 空值占位）、超长文案截断提示、RTL 语言方向 |
| 不支持 | 固定文案的网格维护（[交互类「国际化文案编辑器」](../../08_交互类/11_组件设计_国际化文案编辑器/11_组件设计_国际化文案编辑器.md)）、语言清单增改启停（国际化管理模块）、语言 / 时区偏好（个人中心）、机翻与自动译文、移动端维护 |

## 10. 检查清单 <a id="checklist"></a>

- □ 字段恒定一行：文本框（就地编辑必填语言文案）+ 图标按钮（悬停提示「多语言文案」，不写文字标签；不在字段标签上标注「多语言」）；**不逐语言铺开**
- □ 完整度与缺失只在**按钮悬停提示**中出现（不在字段下方占用固定行；缺失语言以文字列在提示里）
- □ 明细弹框：明细表两列行内编辑、必填语言置顶、系统默认语言与必填语言标记、语言关键字 / 仅看缺失 / 仅看已填筛选（本地筛选）
- □ 弹框为草稿：确定回写字段、取消丢弃并二次确认；落库随宿主工具栏「保存」，不单独提交
- □ 语言项由启用语言清单**动态生成**，界面与提交契约不写死语言个数与语言标识
- □ 必填语言 = 当前登录用户语言（未启用则回退系统默认语言）：为空即阻断并定位；服务端按请求语言强制校验
- □ 系统默认语言（清单默认标记）只用于派生默认文案与缺省回退目标；清单无标记时快速失败
- □ 缺省与缺失：非必填语言缺省不阻断、占位提示回退目标；字段下方汇总「已填 x / y，缺失：…」可点击跳转
- □ 停用语言存量值随提交透传不丢值；只读态按当前界面语言回显并沿回退链
- □ 派生：主表默认文案按「系统默认语言 → 必填语言 → 首个有值语言」优先级兜底，永不为空
- □ 权限（字段权限）、i18n（界面文案走全局语言能力、语言名由清单下发）、移动端（不提供维护）符合第 8 节
- □ 六项上游登记已确认：启用语言只读出口、默认语言标记、必填语言口径、多语言附表口径、业务数据文案口径、表单内形态与旧写法清理
