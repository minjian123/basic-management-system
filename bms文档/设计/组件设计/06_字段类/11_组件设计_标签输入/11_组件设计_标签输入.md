## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**标签输入**的组件设计：标签字段（多标签录入与回显、选项建议、新建、去重、上限、颜色）与组合逻辑（选项取数、值归一、去重/上限校验、粘贴解析）。适用于**用户/客户/供应商标签**、**字典条目标签**、**公告标签**、**图标标签**（[交互类「图标选择器」](../../08_交互类/03_组件设计_图标选择器/03_组件设计_图标选择器.md)）等「自由输入 + 建议」的多值场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态禁用回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 用户管理》](../../../概要设计/03_概要设计_用户管理.md)、[《概要设计 · 字典管理》](../../../概要设计/09_概要设计_字典管理.md)（标签/枚举选项）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[展示类「状态标签与描述列表」](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（只读标签展示与语义色）、[字段类「开关与枚举字段」](../08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（固定选项集）、[字段类「字典字段」](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典候选项）。

> 本篇为「标签输入」节点。**范围边界**：**只读展示**标签归 [展示类「状态标签与描述列表」](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（本节点为**可编辑录入**控件）；**固定选项枚举**归 [字段类「开关与枚举字段」](../08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（本节点允许自由新建标签）；**标签的持久化与规范化**（入库策略、查询）归各业务模块；移动端不复用（见第 9 节）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 标签输入件 | 多标签输入/回显、回车/分隔符/失焦创建、选项建议与异步搜索、去重、上限、颜色映射、删除、只读回显、禁用 |
| 组合逻辑 | 选项取数（静态/异步）、值归一（去空白、去重、大小写策略）、上限与长度校验、粘贴批量解析、颜色解析 |
| 继承链 | 标签输入 → [输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)→ 能力域基类（[选项源能力](../../02_基础组件类/02_能力类/12_组件设计_选项源能力/12_组件设计_选项源能力.md)等）→ 组件根 → 总基类；行为在链上层维护，不在组件内重复实现 |

- 交互基于既有选择/标签控件形态；大数据选项建议走异步搜索（见第 4 节）。
- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 标签值（字符串数组），受控 |
| 建议选项 | 静态建议选项（含展示文本与颜色） |
| 异步建议源 | 异步建议源（搜索），与静态选项二选一 |
| 自由新建 | 是否允许新建（自由标签） |
| 单/多标签 | 多标签（默认为单标签可配） |
| 数量上限 | 标签数量上限（不限或超限提示） |
| 单标签长度上限 | 单标签字符上限（超长截断/提示） |
| 去重 | 是否去重（大小写敏感可配） |
| 颜色映射 | 标签 → 语义色（引用设计令牌） |
| 分隔符 | 输入时触发创建的分隔符（默认中英文逗号） |
| 粘贴拆分 | 粘贴多值自动按分隔符拆分 |
| 禁用与只读 | 禁用；只读态以纯文本（顿号分隔）展示 |
| 值变化通知 | 受控更新 + 变化明细（新增/移除）；超上限时抛出提示 |
| 内容操作 | 新增标签、移除标签、清空、设置值 |

## 4. 交互与形态 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 创建 | 输入后回车 / 输入分隔符（默认中英文逗号）/ 失焦即创建标签；不允许自由新建时只能从建议选择 |
| 建议 | 聚焦/输入展示候选（本地或异步搜索，防抖 300ms）；多选 + 过滤形态 |
| 去重 | 去重开启时忽略重复（去空白后比较；可按需大小写不敏感）；重复输入高亮已有标签提示 |
| 上限 | 达上限禁止新增并抛出提示（父组件提示「最多 N 个标签」） |
| 长度 | 单标签超长时截断或提示（按配置） |
| 粘贴 | 粘贴含分隔符文本自动拆分为多个标签 |
| 颜色 | 标签色取自颜色映射（语义令牌）或选项自带色；未知回退 `info`（复用 [展示类「状态标签与描述列表」](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 取色口径） |
| 删除 | 标签删除入口；退格删除末尾 |
| 只读回显 | 禁用置灰；只读纯文本以「a、b、c」展示（对齐表单页只读口径） |
| 空态 | 无标签时展示占位（占位文案 i18n） |

## 5. 值归一与持久化 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 值格式 | 前端始终为字符串数组（去空白、去空串、去重、按单标签长度上限截断） |
| 入库格式 | 由业务模块约定（JSON 数组或逗号分隔字符串）；提交前按业务格式转换（登记项②） |
| 归一 | 统一归一（去空白/去重/截断）；失败项给出提示 |
| 回显 | 后端返回标签数组/字符串 → 归一后回显；历史脏值（空串/重复）在回显时清理 |
| 选项来源 | 静态建议选项、字典（[01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)）或业务标签库（异步） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：编辑性由字段权限（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制，组件只暴露禁用态；选项可见范围由后端数据权限过滤。
- **i18n**：占位、上限/长度提示、新建文案走全局语言能力；标签文本为用户数据**不翻译**；选项 label 由数据源按 locale 下发。
- **移动端**：不直接复用 PC 组件；移动端以标签 chips + 弹出输入/选择实现，值与归一策略同源（同接口多实现，契约套件同一套断言）。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 建议 | 本地过滤小数据集；大数据走异步搜索 + 防抖；选项按需加载 |
| 渲染 | 标签数量受上限限制；超长标签截断展示（悬浮全文） |
| 归一 | 粘贴批量解析一次性处理，避免逐条触发重渲染 |
| 边界 | 空标签、重复、超上限、超长、粘贴多值、大小写差异、选项失效（历史标签不在选项库 → 保留展示）、单标签模式、只读回显、禁用 |
| 不支持 | 只读标签展示（展示类「状态标签与描述列表」）、固定枚举选项（字段类「开关与枚举字段」）、标签业务规则（各模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：受控双向绑定 + 变更通知（新增/移除）；暴露新增/移除/清空/设置值
- □ 创建：回车/分隔符/失焦；允许新建开关；建议（本地/异步防抖）
- □ 去重（可配）、上限（超限提示）、长度（截断/提示）、粘贴批量拆分
- □ 颜色：颜色映射/选项色引用令牌；只读以 [展示类「状态标签与描述列表」](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 口径展示
- □ 值归一（去空白/去重/截断）与入库格式转换；历史脏值回显清理
- □ 形态：label 上方、窄容器单列；禁用置灰；只读纯文本回显
- □ 权限（字段权限）、i18n（文案/选项，标签不翻译）、移动端（chips + 弹出，口径同源）符合第 8 节
- □ 性能边界：异步防抖、按需选项、粘贴一次性解析、超长截断
- □ 三项上游登记已确认：组件类型白名单扩展、标签值格式与选项来源、字段形态与只读口径
