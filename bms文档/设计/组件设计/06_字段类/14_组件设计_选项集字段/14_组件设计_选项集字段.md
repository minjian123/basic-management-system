## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**选项集字段**的组件设计：注册表选项集枚举（单选与多选、多种形态）、选项集解析、枚举回显与值域校验语义。适用于用户/角色/菜单/租户/系统参数等管理页的优先级、类型、等级等**运行期不可变**的枚举字段；**平台状态类字段（用户/角色状态、锁定类型、菜单状态、业务码/动作码状态、租户状态）即属此类**，字段类型为 `option`。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；上游设计依据[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（字段类型 `option` / `option_multi`、字段属性与选项集、服务端动态校验）、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（平台字段维护与字段权限）、[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)（行级枚举校验与错误行报告）；页面形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（只读/编辑分态）与[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（无操作列、状态标签语义色）；查询区条件形态依据[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)；协作节点为[开关字段](../08_组件设计_开关字段/08_组件设计_开关字段.md)（布尔开关与内联切换）、[字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（运行期可维护值域）、[状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（状态标签本体）、[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)。

> 本篇为「选项集字段」节点。**范围边界**：布尔开关与内联切换归[开关字段](../08_组件设计_开关字段/08_组件设计_开关字段.md)；字典字段（`dict` / `dict_multi`，含字典下拉、级联、远程搜索、版本缓存）归[《组件设计 · 字典字段》](../01_组件设计_字典字段/01_组件设计_字典字段.md)。本篇只负责 `option` / `option_multi` 的选项集枚举，候选项**只有一种来源**——装载时注册的选项集；两种字段类型与值语义**不得混用**（见第 5 节）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 枚举单选件 | 枚举单选：按字段属性以单选框组/按钮组/分段控件/单选下拉呈现 |
| 枚举多选件 | 枚举多选：按字段属性以复选框组/标签点选/多选下拉（`dropdown-multi`）呈现，含数量上下限 |
| 选项集解析 | 取装载时注册的选项集候选条目，统一为同一选项结构（顺序、去重、i18n、颜色、禁用） |
| 回显与值域 | 枚举值 → 展示文本（单值/多值），缺失回退原值；值域校验按注册表条目判定 |
| 继承链 | 单选 → [基础控件类·单选](../../05_基础控件类/06_组件设计_单选/06_组件设计_单选.md)；多选 → [基础控件类·复选](../../05_基础控件类/07_组件设计_复选/07_组件设计_复选.md)；下拉 → [基础控件类·下拉框](../../05_基础控件类/05_组件设计_下拉框/05_组件设计_下拉框.md)；均经能力域基类（[选项源能力](../../02_基础组件类/02_能力类/12_组件设计_选项源能力/12_组件设计_选项源能力.md)等）→ 组件根 → 总基类；行为在链上层维护，不在组件内重复实现 |

- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。
- 移动端与 PC 端同接口多实现（契约套件同一套断言），不引用 PC 组件（见第 11 节）。

## 3. 值域与存储口径 <a id="value"></a>

| 字段类型 | 前端值 | 库值 / 列类型 | 空值 | 说明 |
| --- | --- | --- | --- | --- |
| `option`（枚举单选） | 字符串 | `VARCHAR(64)` | 未设置 | 值即选项 `value`；不存 label；形态可为 radio / button / segmented / dropdown |
| `option_multi`（枚举多选） | 标量数组 | `TEXT`（按选项集顺序、去重后用 `,` 分隔；四库统一 TEXT 承载、应用层解析） | 空数组 | 展示顺序按选项集排序，与用户勾选顺序无关；形态可为 checkbox / tag / dropdown-multi |
| `dict` / `dict_multi`（字典字段） | 见[字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md) | `BIGINT` / JSON 数组 | 未设置 / 空数组 | **不在本篇**：字典字段绑定条目 `id`，与本表选项集字段的值语义完全不同 |

- **唯一真值来源是选项 `value`**：前端任何展示文本（label）都由 `value` 归一得出，不落库、不参与比较。
- **写回统一**：多选写回按选项集顺序排序去重后的 `value` 数组，序列化交给请求层。
- 自建字段物理列类型为 `VARCHAR(64)`（option）、`TEXT`（option_multi，四库统一承载、应用层按 `,` 分隔解析），见[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)数据模型节。

## 4. 形态由字段属性决定 <a id="enum-widget"></a>

| 字段属性 `widget` | 形态 | 适用 |
| --- | --- | --- |
| `radio` | 单选框组 | 2-5 个选项、需展示全部候选（默认形态） |
| `button` | 按钮组 | 选项少、强调操作感（如优先级） |
| `segmented` | 分段控件 | 2-4 个互斥视图切换（如时间粒度），**建议 ≤ 5 项** |
| `checkbox` | 复选框组 | 多选、选项 ≤ 8 |
| `tag` | 标签点选 | 多选、选项多且需紧凑（技能标签、业务标签） |
| `dropdown` | 下拉选择（单选） | 选项较多（> 8）或需搜索；控件本体继承[基础控件类·下拉框](../../05_基础控件类/05_组件设计_下拉框/05_组件设计_下拉框.md) |
| `dropdown-multi` | 下拉选择（多选） | 多选且选项较多（> 8）或需搜索；语义键与后端字段类型注册表 `dropdown-multi` 一致，控件本体同上 |

- 形态由字段属性 `widget` 声明（默认 `radio` / `checkbox`）；选项数量超过 8 的**单选**场景建议改用 `dropdown`，**多选**场景建议改用 `dropdown-multi`。
- 下拉形态（`dropdown` / `dropdown-multi`）的候选项来源只有注册表选项集；控件**不做取数**，选项由字段层注入。
- 移动端形态降级为底部选择/复选形态（见第 11 节）。

## 5. 候选来源：注册表选项集（与字典字段分家） <a id="enum-source"></a>

枚举字段的候选项**只有一种来源**：装载时注册的**选项集**，字段属性用 `optionSetKey` 引用，随表单元数据下发，零网络开销。

- **运行期可维护的值域不走本节点**——改用**字典字段**（字段类型 `dict` / `dict_multi`），其绑定值是数据源条目 `id`，见[《组件设计 · 字典字段》](../01_组件设计_字典字段/01_组件设计_字典字段.md)。
- 两者不是“同一个字段的两种来源”，而是**两种字段类型**：表单定制按“值域运行期会不会变”直接选类型，不需要在属性里再选来源。

| 维度 | 选项集字段（本篇：`option` / `option_multi`） | 字典字段（`dict` / `dict_multi`） |
| --- | --- | --- |
| 值语义 | 枚举**常量**（字符串） | 数据源**条目主键 `id`**（雪花，库内 BIGINT） |
| 值域 | 封闭、可穷尽 | 开放、条目可增删 |
| 控件 | 单选 / 复选 / 分段 / 按钮 / 标签 / **选项下拉**（本地选项） | **字典下拉** / 级联（远程搜索、版本缓存、大小字典切换） |
| 取数 | 随表单元数据下发，零请求 | 运行时接口 + 版本比对缓存 |
| 校验 | 注册表值域 | 条目存在且启用 |
| 导入导出 | label ↔ 常量 | label ↔ 条目 `id` |
| 二次开发 | 可写死映射、穷尽判断 | 必须容错未知值，经 `id` 关联 |

- **禁止跨类型混用**：不得给 `option` / `option_multi` 配字典标识，也不得给 `dict` / `dict_multi` 配选项集标识；历史「`select` / `multi_select` + 字典标识」配置在迁移时改为字典字段类型。
- **值稳定性**：选项集 `value` 是常量，被业务数据引用后不得改值；字典字段绑定 `id`，条目的 `value` / `code` 可改而不影响存量数据。

选项集的注册与冲突规则（装载期强制）：

- **全局唯一**：选项集标识带命名空间前缀（基座 `bms`、产品用已登记简称），纳入标识符登记；同一标识全系统只有一份定义。
- **冲突即失败**：同 `value` 且同 `label` 的声明合并；**同 `value` 不同 `label`、同 `label` 不同 `value`、同标识不同义**均判冲突，装载直接失败；**不允许产品覆盖基座已注册项**。
- **双向校验**：代码引用了未注册的选项集标识 → 判失败；已注册但从未被引用的选项集 → 装载告警并列入死项清单（**不物理删除**，与注册基座 `unused_option_sets` 口径一致）。
- **变更等级**：选项集**加一项也是破坏性变更**（穷尽判断会漏掉新分支），须评审 + 发版 + 影响面评估。
- **禁止配置期自由填写**：表单定制只能引用已注册的选项集标识，不得在属性面板自由录入选项；需要运行期增删改的值域必须改用字典字段（建字典）。

选项项为契约级最小结构（解析后产出）：

- `value`：唯一真值来源
- `label` / `labelKey`：当前 locale 展示文本（i18n key 与 label 二选一）
- `color`：语义色（只读标签用，缺省回退默认色）
- `disabled`：不可选（存量值仍可回显）
- `sort`：展示顺序

- **解析顺序**：按排序升序 → 相同 `value` 去重（保留首个）→ i18n key 经语言能力翻译（缺翻译回退 `label`）→ 产出只读选项集。
- **值冻结**：`value` 一旦被业务数据引用即冻结，不得改值或复用；只可改 `label`、停用项；**加新项须按破坏性变更走评审与发版**。
- **停用/删除选项**：选项集是代码/配置的一部分，**不得物理删除已注册项**；停用项不参与新选择，存量值照常回显。
- **禁用选项**：`disabled=true` 的选项在选择集合中不可新增，但存量值保留展示（编辑态可见但不可再次勾选）。
- **缺项回显**：回显找不到选项时回退原值 `value` 并在开发环境告警，不阻断页面。

> **落地时点**：上述注册与冲突规则由后端「选项集注册与校验基座」（`bms_core/optionset/`，当前状态**占位**，契约已就位）承载，真实装载注入随表单定制阶段回补；前端只消费表单元数据下发的已解析选项集，不重复实现注册与冲突判定。

## 6. 枚举交互与契约语义 <a id="enum-props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 单选为标量，多选为数组 |
| 形态 | 由字段属性 `widget` 决定（radio / button / segmented / checkbox / tag / dropdown / dropdown-multi） |
| 选项集 | 引用装载时注册的选项集标识（唯一来源；字典走字典字段类型） |
| 数量上下限 | 多选数量上下限（超限内联提示并阻止提交） |
| 权限 | 不可编辑时置禁用（字段权限语义由表单页下发） |
| 尺寸 | 默认 / 紧凑两档 |
| 颜色标签 | 只读态可以语义色标签渲染；标签由 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 渲染（取色与形态见该节点「取色优先级」节） |
| 值变化通知 | 受控更新 + 变更通知（多选为归一排序后的数组）；超限时抛出提示事件 |

## 7. 校验与默认值 <a id="validate"></a>

| 项 | 规则 |
| --- | --- |
| 单选必填 | 未设置判未填；选中值不在选项集内视为非法（存量脏值仅在只读态回退原值，编辑态要求重选） |
| 多选必填 | 空数组判未填；数量上下限（`minItems` / `maxItems`）超限内联提示并阻止提交 |
| 默认值 | 由字段属性 `default` 提供：单选默认某个 `value`、多选默认空数组；**默认值必须落在选项集当前值域内**；新增表单按默认值预填，属性变更不回写存量数据 |
| 服务端一致 | 新增/编辑接口按当前生效布局配置做动态校验（必填/选项集），前端校验仅为体验前置，**以服务端为准**（[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)「服务端动态校验」节） |
| 配置错误 | `minItems > maxItems`、`default` 不在值域内、`optionSetKey` 未注册或冲突等属性非法值由定制侧拦截（表单定制 40408），前端不静默修正 |
| 时机 | 变更即时校验 + 失焦校验 + 提交前统一校验；错误文案走 i18n |

## 8. 只读回显与颜色标签 <a id="readonly"></a>

| 场景 | 设计 |
| --- | --- |
| 枚举单选只读 | 按选项集回显 label；缺 label 回退原值 |
| 枚举多选只读 | 按选项集顺序取 label，**顿号（、）分隔**；超长时单行省略并悬浮全文 |
| 未设置 | 统一 `—`（未设置、多选空数组） |
| 颜色标签（可选） | 字段属性开启时由 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 渲染（本节点不再自绘）：取色走该节点「取色优先级」节的四层优先级——`semantic` 显式指定 → 数据源自带色 → 字段级 `colorMap` 映射 → 内置语义映射 → 兜底 `info`；颜色引用设计令牌，形态支持胶囊/点状/圆点/图标 |
| 查询区筛选 | 状态/类型类查询条件以枚举下拉呈现（[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)查询类字段），本节点只提供值映射，不定义查询区布局 |
| 导出与打印 | 一律取 label 文本口径（第 9 节），不导出库值 |

## 9. 导入导出协作 <a id="import"></a>

| 项 | 导出 | 导入（宽容归一） |
| --- | --- | --- |
| 枚举单选 | 选项 label | 优先按 label 反查 `value`；也接受直接填 `value`；两者都不匹配 → 行级错误 |
| 枚举多选 | 按选项集顺序拼接 label，分隔符统一「、」 | 接受 `、` / `,` / `|` / `;` 混合分隔，拆分去重后逐个反查；存在未识别项 → 行级错误 |

- 模板列注释给出可选值清单（label 列表），降低填写错误。
- 校验在导入解析阶段完成，逐行失败**跳过该行并记错误行号与原因**（[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)业务规则节）；提交带 `Idempotency-Key`。
- **存储与展示分隔符分离**：库内与写回统一半角逗号 `,`（按选项集顺序、去重后拼接）；展示与导出统一顿号「、」；导入接受 `、` / `,` / `|` / `;` 混合分隔，拆分去重后反查。
- 本节点**不新增接口**，只约定值 ↔ 文本的映射口径；行级错误报告、模板列生成与错误明细下载归[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)业务规则节。

## 10. 依赖接口与上游变更 <a id="api"></a>

### 10.1 上游接口与口径 <a id="api-contract"></a>

### 10.2 需登记的上游变更 <a id="api-upstream"></a>

| 变更点 | 目标文档 | 内容 |
| --- | --- | --- |
| ① 平台字段的选项集来源与组件形态承载位 | [《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)「字段属性调整」「数据模型」节；[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)字段维护节 | 平台字段的组件形态与**选项集来源引用**（`optionSetKey`）由**表单定制的字段属性层**承载，不新增列；**平台字段的 `value` 由代码/注册表冻结**，定制员只能调整展示（label 文案、颜色、形态、顺序），不得增删改 `value`；选项集标识未注册或冲突按 40408 拦截；据此下发到前端 |
| ② 选项集的注册与冲突校验 | [《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)「字段属性调整」「错误码」节；[《后端基类清单》](../../../../后端基类清单.md)「跨阶段基座」节；[《命名规范》](../../../../规范/命名规范.md)「通用原则」节 | 选项集在**装载时注册**，标识带命名空间前缀并纳入标识符登记；同 value 合并、同 value 异名 / 同 label 异值 / 同标识异义一律失败，禁止产品覆盖基座；表单定制只能引用已注册标识，不得自由录入选项；加项按破坏性变更处理 |
| ③ 字段类型更名 | [《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md) | `select` → `option`、`multi_select` → `option_multi`；存量 `sys_field.type` / `sys_field_ext.type` 同步迁移 |

> 上述变更**已由用户确认（2026-10-21）**，随本节点同步至上游文档。

## 11. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：不可见由表单页不渲染；不可编辑置禁用；组件不感知权限逻辑。枚举为码值，无脱敏需求（见[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：校验提示、导入错误行文案走全局语言能力；选项 label 优先按 i18n key 翻译（注册时登记的 labelKey）；**不翻译用户输入与库值**。
- **移动端**：移动端以简化形态实现（单选、复选、标签），**只读一律纯文本**（枚举 label），不做颜色标签；值域、归一与校验口径与 PC 同源（第 3、7 节），不套用 PC 组件。
- **查询区**：状态/类型类条件在查询区以枚举下拉呈现，取数走本节点的值映射；查询区布局与折叠由[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)与展示类「查询筛选区」承载。

## 12. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 选项集（注册表） | 装载时注册、随表单元数据下发，零网络开销；解析结果按「字段 key + locale」缓存于表单页作用域 |
| 大选项集 | 单选选项 > 8 建议改用 `dropdown` 形态、多选选项 > 8 建议改用 `dropdown-multi`；分段控件建议 ≤ 5 项，超出给配置告警（定制侧） |
| 边界 | 选项缺失/停用、多选重复值与顺序、`minItems > maxItems` 配置错误、超上限提示、只读缺 label 回退原值，均纳入单测 |
| 不支持 | 枚举的分组展示（分组枚举按业务拆多个字段）、基于枚举的联动显隐表达式（表单定制当前未提供联动能力，待其落地后由上游登记接入） |

## 13. 检查清单 <a id="checklist"></a>

- □ 枚举形态由字段属性 `widget` 决定（radio / button / segmented / checkbox / tag / dropdown / dropdown-multi）；下拉形态的选项由字段层注入、控件不取数
- □ 选项集是枚举字段的**唯一**来源：字段类型 `option` / `option_multi` + `optionSetKey`；字典字段（`dict` / `dict_multi`）另属字典字段节点，不得跨类型混用
- □ 选项集只用于与业务代码强绑定的封闭值域：标识已在装载期注册且全局唯一、命名空间前缀合规、页面不得自由录入选项；同 value 异 label / 同 label 异 value 装载即失败；加项按破坏性变更处理
- □ 标记禁用的选项不可新增但存量可回显
- □ 多选数量上下限生效；默认值走字段属性 `default`；与服务端动态校验一致
- □ 只读回显纯文本（枚举 label 顿号分隔；空值 `—`）；颜色标签由状态标签节点渲染
- □ 导入导出：枚举 label 优先反查 value、多选分隔符拆分、未知值行级错误；**库内与写回统一半角逗号 `,`、展示与导出统一顿号「、」**
- □ 字段权限（可见/可编辑）、i18n（选项翻译）、移动端（简化形态、只读纯文本）符合第 11 节
- □ 三项上游登记已确认：平台字段选项集承载位、选项集注册与冲突校验、字段类型更名；**平台状态类字段（用户/角色状态、锁定类型、菜单状态等）已裁决为选项集 `option`**，与后端 `02-14` 种子一致
