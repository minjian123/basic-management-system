## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**穿梭框字段**的组件设计：双列表选择组件（候选/已选两栏、搜索、分组、全选、穿梭操作、值绑定与只读回显）与候选取数组合逻辑（候选项取数、异步搜索、分页/大数据、值映射、批量）。适用于**权限主体绑定**（用户/岗位/部门选入角色）、**租户模块开通**（已开通/未开通双向）、**字段/列选择**、**多值关联配置**等「左侧候选 → 右侧已选」的选择场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态禁用回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)（主体绑定与权限授予）、[《概要设计 · 租户管理》](../../../概要设计/25_概要设计_租户管理.md)（模块开通/开关）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典候选项）、[01 树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)/[01 组织选择字段](../05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)（组织类候选）、[交互类「权限配置」](../../08_交互类/07_组件设计_权限配置/07_组件设计_权限配置.md)（主体绑定/权限授予使用）、[基础类「请求封装」](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（异步候选取数）。

> 本篇为「穿梭框」节点。**范围边界**：候选项**数据源**（字典/组织/权限实体）归各自模块与字段类[字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)/[树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)/[组织选择字段](../05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)；**树形结构**的双列表（带层级）归[树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（本节点为**扁平/分组**双列表）；**权限与主体绑定业务逻辑**归[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)（本节点只做选择与值绑定）；移动端不复用（见第 8 节）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 穿梭框字段件 | 候选/已选两栏、全选/半选、单项/批量穿梭、搜索、分组、计数、值绑定与只读回显、禁用、空态 |
| 候选取数与值映射 | 候选项取数（同步/异步搜索）、已选回显（按标识批量查 label）、分页/大数据、值映射（标识 ↔ 对象）、受控值同步 |
| 继承链 | 穿梭框字段 → [输入组件基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)→ 能力域基类（[选项源能力](../../02_基础组件类/02_能力类/12_组件设计_选项源能力/12_组件设计_选项源能力.md)等）→ 组件根 → 总基类；行为在链上层维护，不在组件内重复实现 |

- 基于既有穿梭控件定制；大数据/异步/分组能力由候选取数与值映射组合逻辑与自绘列表补齐（见第 4、5 节）。
- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 已选标识列表（字符串/数字），受控 |
| 候选来源 | 静态候选项或异步候选源（分页/搜索）二选一 |
| 两栏标题 | 候选 / 已选标题可配（i18n） |
| 搜索 | 可搜索（本地过滤或触发远程搜索） |
| 分组 | 可按分组字段分组展示 |
| 分页 | 候选分页大小可配（不分页/一次性或分页/虚拟滚动） |
| 上限 | 已选上限可配（不限或超限阻止并提示） |
| 禁用与只读 | 禁用置灰；只读态以纯文本展示已选项（label 拼接） |
| 取值/展示字段名 | 取值与展示字段名可配（对齐数据源） |
| 值变化通知 | 受控更新 + 变化明细（新增/移除项）；远程搜索触发通知 |
| 内容操作 | 设置值、刷新候选、清空 |

## 4. 交互与形态 <a id="interaction"></a>

```mermaid
flowchart LR
    A["候选（左）<br/>搜索 · 分组 · 分页"] -->|"选中 → 穿梭"| B["已选（右）<br/>值列表 · 计数"]
    B -->|"移除 → 穿梭"| A
    A -.->|"异步搜索/分页"| S["异步候选源取数"]
    B -.->|"按标识批量回显 label"| S
```

| 项 | 设计 |
| --- | --- |
| 双栏 | 左候选、右已选；两栏顶部全选/清空、搜索框、计数；中间穿梭按钮 |
| 搜索 | 可搜索：本地过滤（小数据）或远程搜索（异步候选源，防抖）；远程搜索只影响候选栏 |
| 分组 | 可按分组字段分组标题展示（如按部门分组） |
| 分页/大数据 | 候选分页（或虚拟滚动），避免一次性渲染上万项 |
| 上限 | 超过已选上限时阻止并提示 |
| 只读回显 | 禁用置灰；只读纯文本时以「label、label」展示（对齐[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)只读口径） |
| 空态 | 候选/已选为空时展示占位（复用 [展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 校验 | 必填校验（长度非空）；与后端一致 |

## 5. 取数与回显 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 候选取数 | 静态候选项或异步候选源（按关键字/分页）；字典候选复用 [字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md) 的批量取数与缓存；组织候选复用字段类「树选择字段」/「组织选择字段」 |
| 已选回显 | 编辑态只持有标识列表，需按标识**批量查 label** 回显已选项；缺 label 回退显示标识 |
| 大数据 | 分页/虚拟滚动；已选集合单独维护（不随候选分页变化） |
| 缓存 | 字典/组织候选复用对应缓存；异步搜索防抖 300ms |
| 失效 | 已选项在候选中不存在（已停用/删除）→ 保留展示并标记「已失效」（提交由后端校验） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段可编辑性由字段权限（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制，组件只暴露禁用态；候选项可见范围由后端数据权限过滤。
- **i18n**：标题、搜索占位、空态、超限提示走全局语言能力；候选项 label 由数据源按 locale 下发。
- **移动端**：不直接复用 PC 组件；移动端以「底部弹出多选面板 + 已选 chips」实现，值格式与校验同源（同接口多实现，契约套件同一套断言）。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大数据候选 | 分页/虚拟滚动；不一次性渲染全部；远程搜索防抖 |
| 回显 | 按标识批量查 label；已选集合独立于候选分页 |
| 渲染 | 已选栏轻量；分组标题不重复计算 |
| 边界 | 候选/已选为空、超上限、已选项失效、远程搜索无结果、异步失败重试、值类型（字符串/数字）混用、去重、只读回显、禁用 |
| 不支持 | 树形双列表（字段类「树选择字段」）、候选数据源实现（字典/组织模块）、权限业务逻辑（角色/租户模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：受控双向绑定 + 变更通知（新增/移除明细）
- □ 双栏：全选/清空、搜索、分组、计数、穿梭按钮；空态
- □ 取数：静态候选与异步候选源（搜索/分页）；已选按标识批量回显 label；失效项标记
- □ 形态：label 上方、窄容器单列；禁用置灰；只读纯文本回显；上限超限提示
- □ 校验：必填与后端一致
- □ 权限（字段权限/数据范围）、i18n（标题/占位/选项）、移动端（底部多选，值格式同源）符合第 8 节
- □ 性能：分页/虚拟滚动、远程搜索防抖、回显批量、已选集合独立
- □ 三项上游登记已确认：主体绑定/模块开通使用契约、字段形态与只读口径、组件类型白名单扩展
