## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**开关与枚举字段**的组件设计：布尔开关（含列表/详情内联切换）、注册表选项集枚举（单选与多选多种形态）、选项集解析与枚举回显/布尔值归一能力语义。覆盖值域与存储映射、三态与默认值、校验、列表内联切换、只读回显（含可选颜色标签）与导入导出映射。适用于用户/角色/菜单/租户/系统参数等管理页的「启用停用」开关、状态标记、优先级与类型等枚举字段。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与字典管理章节；上游设计依据[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（字段类型白名单 `switch`/`option`/`option_multi`、字段属性调整与选项集、服务端动态校验）、[《概要设计 · 菜单管理》](../../../概要设计/07_概要设计_菜单管理.md)（平台字段维护与字段权限）、[《概要设计 · 字典管理》](../../../概要设计/09_概要设计_字典管理.md)（字典取数与缓存）、[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)（行级枚举校验与错误行报告）；页面形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（只读/编辑分态）与[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（无操作列、行内状态变更、状态标签语义色，配合[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)）；查询区条件形态依据[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)；协作节点为[字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典取数与翻译）、[状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（状态标签本体）、[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（错误码提示与列表分页）、[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（字段权限）、[格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)（布尔与多值文本格式化）。

> 本篇为「开关与枚举字段」节点。**范围边界**：**字典字段**（字段类型 `dict` / `dict_multi`，含下拉、级联、远程搜索、版本缓存）整体归[《组件设计 · 字典字段》](../01_组件设计_字典字段/01_组件设计_字典字段.md)；本篇负责布尔开关与**选项集枚举字段**（字段类型 `option` / `option_multi`），候选项**只有一种来源**——装载时注册的选项集。两者字段类型、控件与值语义完全分开（见第 6.2 节），**不得混用**；只读态颜色标签在本篇仅保留**开关的颜色标记属性**，标签本体归 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（取色三层优先级见该节点）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 布尔开关件 | 布尔开关：三态（未设置）、启用/停用文案变体、危险切换确认、加载态、只读回显 |
| 内联切换件 | 列表/详情内联切换：乐观值、二次确认、行级加载、失败回滚 |
| 枚举单选件 | 枚举单选：按字段属性以单选框组/按钮组/分段控件呈现 |
| 枚举多选件 | 枚举多选：按字段属性以复选框组/标签点选/下拉多选呈现，含数量上下限 |
| 枚举下拉件 | 枚举下拉：按字段属性 `dropdown` 以单下拉/多选下拉呈现（搜索、清空、分组、禁用继承基础控件类·下拉框） |
| 选项集解析 | 选项集解析：取**装载时注册的选项集**候选条目，统一为同一选项结构（顺序、去重、i18n、颜色、禁用） |
| 回显与归一 | 枚举值 → 展示文本（单值/多值），缺失回退原值；后端值形态归一为布尔、布尔 → 只读文本（是/否或文案变体） |
| 继承链 | 布尔开关 → [基础控件类·开关](../../05_基础控件类/08_组件设计_开关/08_组件设计_开关.md)；枚举单选 → [基础控件类·单选](../../05_基础控件类/06_组件设计_单选/06_组件设计_单选.md)；枚举多选 → [基础控件类·复选](../../05_基础控件类/07_组件设计_复选/07_组件设计_复选.md)；枚举下拉 → [基础控件类·下拉框](../../05_基础控件类/05_组件设计_下拉框/05_组件设计_下拉框.md)；均经能力域基类（[选项源能力](../../02_基础组件类/02_能力类/12_组件设计_选项源能力/12_组件设计_选项源能力.md)等）→ 组件根 → 总基类；行为在链上层维护，不在组件内重复实现 |

- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。
- **继承**：布尔开关继承基础控件类·开关；枚举单选继承基础控件类·单选；枚举复选继承基础控件类·复选；字段外观（标签/必填/校验/权限）与选项取数在链上层维护。
- 移动端与 PC 端同接口多实现（契约套件同一套断言），不引用 PC 组件（见第 11 节）。

## 3. 值域与存储口径 <a id="value"></a>

| 字段类型 | 前端值 | 库值 / 列类型 | 空值 | 说明 |
| --- | --- | --- | --- | --- |
| `switch`（布尔开关） | 布尔 | `SMALLINT`（1=是/启用，0=否/停用） | 未设置 | 前端**只暴露布尔**，1/0 在组件边界归一 |
| `option`（枚举单选，选项集） | 字符串 | `VARCHAR(64)` | 未设置 | 值即选项 `value`；不存 label；形态可为 radio / button / segmented / dropdown |
| `option_multi`（枚举多选，选项集） | 标量数组 | `VARCHAR(255)`（按选项集顺序、去重后用 `,` 分隔） | 空数组 | 展示顺序按选项集排序，与用户勾选顺序无关；形态可为 checkbox / tag / dropdown（多选） |
| `dict` / `dict_multi`（字典字段） | 见[字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md) | `BIGINT` / JSON 数组 | 未设置 / 空数组 | **不在本篇**：字典字段绑定条目 `id`，与本表选项集字段的值语义完全不同 |

- **唯一真值来源是选项 `value`**：前端任何展示文本（label、是/否）都由 `value` 归一得出，不落库、不参与比较。
- **归一容错**：后端历史值与接口直出可能出现 `0`/`1`/`'0'`/`'1'`/`'true'`/`'是'`/`'否'`，统一归一为布尔；无法识别的值按未设置处理并记录一次性告警（开发环境）。
- **写回统一**：布尔写回 `1`/`0`（未设置写空值）；多选写回按选项集顺序排序去重后的 `value` 数组，序列化交给请求层。
- 自建字段对应的物理列类型为 `SMALLINT`（switch）、`VARCHAR(64)`（option）、`VARCHAR(255)`（option_multi），见[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)数据模型节。

## 4. 开关交互与契约语义 <a id="switch-props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值与三态 | 布尔值受控；未设置（三态）可开放清空入口并展示不确定态 |
| 文案变体 | 启用/停用等文案可配，空则只显示开关本体；走 i18n |
| 危险切换确认 | 可配置切换前二次确认与自定义确认文案（如「停用后该用户将立即退出登录」）；确认前不改变受控值，确认通过后才抛出变更 |
| 加载态 | 外部提交中置加载态（内联切换由内联切换件驱动） |
| 尺寸 | 默认 / 紧凑两档（表格内用紧凑） |
| 权限 | 不可编辑时置禁用（字段权限语义由表单页下发） |
| 切换前置判定 | 可选切换前判定（不允许则撤销切换），表单页用于联动校验 |
| 值变化通知 | 受控更新 + 变更通知（**确认通过后**才抛出，未确认不产生变更）；确认取消可供页面统计/提示 |
| 确认与受控的配合 | 确认生效时先弹确认、确认前不修改值；确认后由父层提交（异步提交期间置加载态，失败由父层回滚） |

## 5. 列表/详情内联切换 <a id="inline"></a>

[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)「交互与状态约定」节已定案「行内状态变更（启用/停用、审批）成功后局部刷新并提示」，且列表页**无操作列**——内联切换即放置在状态列内，不新增操作按钮。

| 项 | 设计 |
| --- | --- |
| 触发 | 状态列内内联切换件（紧凑尺寸），点击即切换；不可编辑时降级为只读文本 |
| 接口 | **复用业务既有写接口**：优先业务专用状态接口（如 `PUT /users/{id}/status`），无专用接口时用该记录 update 接口；**不新增 toggle 接口** |
| 权限 | 记录级可编辑 + 业务动作权限（如 `user:update`、`tenant:manage`）；不满足则只读（见 [权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)） |
| 确认 | 危险开关弹二次确认（危险按钮样式）；普通开关免确认（对齐列表页既有口径） |
| 成功 | 行级成功提示 + **局部刷新该行**（不整表重载），行内其他字段不闪动 |
| 失败 | 回滚为原值（乐观值丢弃）+ 错误码文案提示（[请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)错误码 → i18n 映射） |
| 并发 | 同一行切换中禁用再次点击（行级加载）；不同行互不影响 |
| 乐观锁 | 后端版本冲突时提示「数据已被他人修改」并刷新该行 |

## 6. 枚举字段：形态与选项集 <a id="enum"></a>

### 6.1 形态由字段属性决定 <a id="enum-widget"></a>

| 字段属性 `widget` | 形态 | 适用 |
| --- | --- | --- |
| `radio` | 单选框组 | 2-5 个选项、需展示全部候选（默认形态） |
| `button` | 按钮组 | 选项少、强调操作感（如优先级） |
| `segmented` | 分段控件 | 2-4 个互斥视图切换（如时间粒度），**建议 ≤ 5 项** |
| `checkbox` | 复选框组 | 多选、选项 ≤ 8 |
| `tag` | 标签点选 | 多选、选项多且需紧凑（技能标签、业务标签） |
| `dropdown` | 下拉选择 | 选项较多（> 8）或需搜索；单选/多选（`multiple`）均可；控件本体继承[基础控件类·下拉框](../../05_基础控件类/05_组件设计_下拉框/05_组件设计_下拉框.md) |

- 形态由字段属性 `widget` 声明（默认 `radio` / `checkbox`）；选项数量超过 8 的**单选**场景建议改用 `dropdown`（控件本体继承基础控件类·下拉框，选项仍来自注册表选项集）。
- `dropdown` 的候选项来源只有注册表选项集（第 6.2 节）；控件**不做取数**，选项由字段层注入。
- 移动端形态降级为底部选择/复选形态（见第 11 节）。

### 6.2 候选来源：注册表选项集（与字典字段分家） <a id="enum-source"></a>

枚举字段的候选项**只有一种来源**：装载时注册的**选项集**，字段属性用 `optionSetKey` 引用，随表单元数据下发，零网络开销。

- **运行期可维护的值域不走本节点**——改用**字典字段**（字段类型 `dict` / `dict_multi`），其绑定值是数据源条目 `id`，见[《组件设计 · 字典字段》](../01_组件设计_字典字段/01_组件设计_字典字段.md)。
- 两者不是“同一个字段的两种来源”，而是**两种字段类型**：表单定制按“值域运行期会不会变”直接选类型，不需要在属性里再选来源。

| 维度 | 选项集字段（本篇：`option` / `option_multi`） | 字典字段（`dict` / `dict_multi`） |
| --- | --- | --- |
| 值语义 | 枚举**常量**（字符串） | 数据源**条目主键 `id`**（雪花，库内 BIGINT） |
| 值域 | 封闭、可穷尽 | 开放、条目可增删 |
| 控件 | 单选 / 复选 / 分段 / 按钮 / 标签 / **选项下拉**（本地选项） | **字典下拉** / 级联（远程搜索、版本缓存、大小字典切换） |
| 取数 | 随表单元数据下发，零请求 | 运行时接口 + 版本比对缓存 |
| 校验 | 注册表值域 | 条目存在且启用 |
| 导入导出 | label ↔ 常量 | label ↔ 条目 `id` |
| 二次开发 | 可写死映射、穷尽判断 | 必须容错未知值，经 `id` 关联 |

- **禁止跨类型混用**：不得给 `option` / `option_multi` 配字典标识，也不得给 `dict` / `dict_multi` 配选项集标识；历史「`select` / `multi_select` + 字典标识」配置在迁移时改为字典字段类型（旧类型名同时更名为 `option` / `option_multi`）。
- **值稳定性**：选项集 `value` 是常量，被业务数据引用后不得改值；字典字段绑定 `id`，条目的 `value` / `code` 可改而不影响存量数据。

选项集的注册与冲突规则（装载期强制）：

- **全局唯一**：选项集标识带命名空间前缀（基座 `bms`、产品用已登记简称），纳入标识符登记；同一标识全系统只有一份定义。
- **冲突即失败**：同 `value` 且同 `label` 的声明合并；**同 `value` 不同 `label`、同 `label` 不同 `value`、同标识不同义**均判冲突，装载直接失败；**不允许产品覆盖基座已注册项**。
- **双向校验**：代码引用了未注册的选项集标识 → 判失败；已注册但从未被引用的选项集 → 告警并清理死项。
- **变更等级**：选项集**加一项也是破坏性变更**（穷尽判断会漏掉新分支），须评审 + 发版 + 影响面评估。
- **禁止配置期自由填写**：表单定制只能引用已注册的选项集标识，不得在属性面板自由录入选项；需要运行期增删改的值域必须改用字典字段（建字典）。

选项项为契约级最小结构（解析后产出）：

- `value`：唯一真值来源
- `label` / `labelKey`：当前 locale 展示文本（i18n key 与 label 二选一）
- `color`：语义色（只读标签用，缺省回退默认色）
- `disabled`：不可选（存量值仍可回显）
- `sort`：展示顺序

- **解析顺序**：按排序升序 → 相同 `value` 去重（保留首个）→ i18n key 经语言能力翻译（缺翻译回退 `label`）→ 产出只读选项集。
- **值冻结**：`value` 一旦被业务数据引用即冻结，不得改值或复用；只可改 `label`、停用项；**加新项须按破坏性变更走评审与发版**（业务代码需覆盖新分支或显式兜底）。
- **停用/删除选项**：选项集是代码/配置的一部分，**不得物理删除已注册项**；停用项不参与新选择，存量值照常回显。
- **禁用选项**：`disabled=true` 的选项在选择集合中不可新增，但存量值保留展示（编辑态可见但不可再次勾选）。
- **缺项回显**：回显找不到选项时回退原值 `value` 并在开发环境告警，不阻断页面。

### 6.3 枚举交互与契约语义 <a id="enum-props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 单选为标量，多选为数组 |
| 形态 | 由字段属性 `widget` 决定（radio / button / segmented / checkbox / tag / dropdown） |
| 选项集 | 引用装载时注册的选项集标识（唯一来源；字典走字典字段类型，不在本节点） |
| 数量上下限 | 多选数量上下限（超限内联提示并阻止提交） |
| 权限 | 不可编辑时置禁用（字段权限语义由表单页下发） |
| 尺寸 | 默认 / 紧凑两档 |
| 颜色标签 | 只读态可以语义色标签渲染；标签由 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 渲染（取色与形态见该节点「取色优先级」节） |
| 值变化通知 | 受控更新 + 变更通知（多选为归一排序后的数组）；超限时抛出提示事件 |

## 7. 校验与默认值 <a id="validate"></a>

| 项 | 规则 |
| --- | --- |
| 布尔必填 | **仅当三态且值为未设置**判未填；假值视为已填（勾选类语义：显式关闭是有效选择） |
| 布尔非必填 | 未设置与假值均可提交；只读回显分别呈现「—」与「否/停用」 |
| 多选必填 | 空数组判未填；数量上下限（`minItems` / `maxItems`）超限内联提示并阻止提交 |
| 单选必填 | 未设置判未填；选中值不在选项集内视为非法（存量脏值仅在只读态回退原值，编辑态要求重选） |
| 默认值 | 统一由字段属性 `default` 提供：布尔默认假值（三态时可为未设置）、单选默认某个 `value`、多选默认空数组；**默认值必须落在当前值域内**（选项集字段取选项 `value`；字典字段取条目 `id`）；新增表单按默认值预填，字段属性变更不回写存量数据 |
| 服务端一致 | 新增/编辑接口按当前生效布局配置做动态校验（必填/选项集），前端校验仅为体验前置，**以服务端为准**（[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)「服务端动态校验」节） |
| 配置错误 | `minItems > maxItems`、`default` 不在值域内、`optionSetKey` 未注册或冲突等属性非法值由定制侧拦截（表单定制 40408），前端不静默修正 |
| 时机 | 变更即时校验 + 失焦校验 + 提交前统一校验；错误文案走 i18n |

## 8. 只读回显与颜色标签 <a id="readonly"></a>

| 场景 | 设计 |
| --- | --- |
| 开关（表单只读态 / 详情页） | 置禁用展示开关本体 + 文案变体；无文案配置时按「是/否」回显 |
| 开关（列表列，不可编辑） | 只读文本「是/否」（或字段配置的启用/停用文案），**不渲染开关控件** |
| 枚举单选只读 | 按选项集回显 label；缺 label 回退原值 |
| 枚举多选只读 | 按选项集顺序取 label，**顿号（、）分隔**；超长时单行省略并悬浮全文 |
| 未设置 | 统一 `—`（布尔未设置、枚举未设置、多选空数组） |
| 颜色标签（可选） | 字段属性开启时由 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 渲染（本节点不再自绘）：取色走该节点「取色优先级」节的三层优先级——数据源自带色 → 字段级颜色映射 → 内置语义映射 → 兜底 `info`；颜色引用设计令牌，形态支持胶囊/点状/圆点/图标 |
| 查询区筛选 | 状态/类型类查询条件以「全部 / 是 / 否」或枚举下拉呈现（[《布局设计 · 表单定制》](../../../布局设计/14_布局设计_表单定制.html)查询类字段），本节点只提供值映射，不定义查询区布局 |
| 导出与打印 | 一律取 label / 是 否 文本口径（第 9 节），不导出库值 |

## 9. 导入导出协作 <a id="import"></a>

| 项 | 导出 | 导入（宽容归一） |
| --- | --- | --- |
| 开关 | 「是 / 否」 | 接受 `是`/`否`、`1`/`0`、`true`/`false`（大小写与全半角归一、首尾空白去除）；未知值 → 行级错误 |
| 枚举单选 | 选项 label | 优先按 label 反查 `value`；也接受直接填 `value`；两者都不匹配 → 行级错误 |
| 枚举多选 | 按选项集顺序拼接 label，分隔符统一「、」 | 接受 `、` / `,` / `|` / `;` 混合分隔，拆分去重后逐个反查；存在未识别项 → 行级错误 |

- 模板列注释给出可选值清单（label 列表，开关列注明「是/否」），降低填写错误。
- 校验在导入解析阶段完成，逐行失败**跳过该行并记错误行号与原因**，成功与失败行数汇总返回（[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)业务规则节）；提交带 `Idempotency-Key`，重复提交被拦截。
- 导入导出模板列按布局配置生成（平台字段 + 已生效自建字段），列头与表单一致；本节点**不新增接口**，只约定值 ↔ 文本的映射口径。

## 11. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：不可见由表单页不渲染；不可编辑置禁用（编辑态置灰或只读文本），组件不感知权限逻辑；列表内联切换额外要求记录级可编辑（第 5 节）。开关与枚举均为枚举码值，无脱敏需求（见[权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：文案变体、确认文案、校验提示、导入错误行文案走全局语言能力；选项 label 优先按 i18n key 翻译——选项集来源用注册时登记的 labelKey；**不翻译用户输入与库值**（字典字段的多语言由字典接口按 locale 下发，见字典字段节点）。
- **移动端**：移动端以简化形态实现（开关、单选、复选、标签），**只读一律纯文本**（是/否、枚举 label），不做颜色标签；值域、归一与校验口径与 PC 同源（第 3、7 节），不套用 PC 组件（同接口多实现，契约套件同一套断言）。
- **查询区**：状态类条件在查询区以「全部 / 是 / 否」或枚举下拉呈现，取数走本节点的值映射；查询区布局与折叠由[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)与展示类「查询筛选区」承载。

## 12. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 选项集（注册表） | 装载时注册、随表单元数据下发，零网络开销；解析结果按「字段 key + locale」缓存于表单页作用域 |
| 千行列表 | 状态列内联切换为轻量控件（紧凑尺寸）；切换仅更新该行数据对象，避免整表重渲染；行级加载不阻塞其他行 |
| 大选项集 | 单选选项 > 8 建议改用 `dropdown` 形态（控件本体继承基础控件类·下拉框；字典来源的远程搜索细节归「字典字段」）；分段控件建议 ≤ 5 项，超出给配置告警（定制侧） |
| 连点与并发 | 切换中禁用再次点击；同一行串行；失败回滚原值，冲突（版本）则刷新该行 |
| 边界 | 三态未设置、存量脏值（`'0'`/`'1'`/`'是'`/`'否'`）、选项缺失/停用、多选重复值与顺序、`minItems > maxItems` 配置错误、超上限提示、只读缺 label 回退原值，均纳入单测 |
| 不支持 | 开关的动画/过渡自定义、枚举的分组展示（分组枚举按业务拆多个字段）、基于枚举的联动显隐表达式（由表单定制的联动能力承载） |

## 13. 检查清单 <a id="checklist"></a>

- □ 受控组件（受控双向绑定 + 变更通知）；布尔只暴露真/假，1/0 与其他形态由值归一承接
- □ 三态：未设置可展示不确定态；必填仅未设置判未填（假值视为已填）
- □ 内联切换：复用业务既有写接口（专用状态接口优先）、需记录级可编辑、危险开关二次确认、失败回滚、局部刷新与行级加载
- □ 枚举形态由字段属性 `widget` 决定（radio / button / segmented / checkbox / tag / dropdown）；标记禁用的选项不可新增但存量可回显；`dropdown` 的选项由字段层注入、控件不取数
- □ 选项集是枚举字段的**唯一**来源：字段类型 `option` / `option_multi` + `optionSetKey`；字典字段（`dict` / `dict_multi`）另属字典字段节点，不得跨类型混用
- □ 选项集只用于与业务代码强绑定的封闭值域：标识已在装载期注册且全局唯一、命名空间前缀合规、页面不得自由录入选项；同 value 异 label / 同 label 异 value 装载即失败；加项按破坏性变更处理
- □ 多选数量上下限生效；默认值走字段属性 `default`；与服务端动态校验一致
- □ 只读回显纯文本（开关 是/否 或启用/停用；枚举 label 顿号分隔；空值 `—`）；颜色标签（字段属性开启时）由 [状态标签与描述列表](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 渲染，取色与形态以该节点为准
- □ 导入导出：开关「是/否」宽容归一、枚举 label 优先反查 value、多选分隔符拆分、未知值行级错误
- □ 字段权限（可见/可编辑）、i18n（文案与选项翻译）、移动端（简化形态、只读纯文本）符合第 11 节
