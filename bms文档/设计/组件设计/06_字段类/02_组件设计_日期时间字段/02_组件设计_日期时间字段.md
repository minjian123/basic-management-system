## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**日期时间类字段**的组件设计：日期选择、日期时间选择、时间选择、日期范围，以及值模型与时区转换语义。适用于管理端全部业务表单、查询筛选区与列表列渲染（如创建时间、生效日期、统计区间、业务单据日期）。

它继承[输入域基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（域基类层：受控值、字段壳、字段权限、校验触发），经[组件根基类](../../02_基础组件类/01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)与[根系基类](../../02_基础组件类/01_机制基类/01_组件设计_根系基类/01_组件设计_根系基类.md)取得通用能力；时区与本地化格式上下文经[语言上下文能力](../../02_基础组件类/02_能力类/26_组件设计_语言上下文能力/26_组件设计_语言上下文能力.md)协作。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端与国际化章节；上游设计依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)（系统信息区时间格式 `yyyy-MM-dd HH:mm`、按租户时区、只读/编辑分态）与[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)（查询区日期用日期范围）；时区与 locale 依据[《架构设计 · 国际化》](../../../架构设计/24_架构设计_子系统_国际化.md)；格式化口径依据[《组件设计 · 格式化工具》](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)。

> 本篇为组件设计体系字段类「日期时间字段」；上游概要节点按具体使用模块（用户管理、操作日志、会话管理等）引用，本节点只定义通用字段契约。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 日期件 | 日期选择：单日期、只读回显 |
| 日期时间件 | 日期时间选择：精确到分/秒 |
| 时间件 | 时间选择：仅时分（可选秒） |
| 日期范围件 | 日期范围：查询区与业务区间 |
| 值模型工具 | 值模型：UTC ↔ 用户时区显示、字符串归一、空值处理 |

- 继承与分层：日期时间字段 → 输入域（域基类层：受控值/字段壳/字段权限）→ 组件根 → 根系；时区与本地化格式上下文经语言上下文能力（继承链上的一层）协作；行为在链上层维护，不在组件内重复实现。
- 字段类统一受控：受控值双向绑定并向业务抛出变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。
- 移动端与 PC 端同契约多实现（同一套契约断言保障），不套用 PC 端件（第 11 节）。

## 3. 值模型与时区 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 存储 | 后端统一 UTC 存储；受控值为 ISO 8601 UTC 字符串（如 `2026-09-11T06:30:00Z`）或 `null` |
| 展示 | 按用户时区（`sys_user.timezone`）与 locale 展示，走日期时间格式化（见 [格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |
| 转换 | 值模型双向换算：UTC ↔ 用户时区显示（组件内部统一在此层完成，业务不感知时区） |
| 空值 | `null` 表示未填；回显占位 `—`（可配占位文案） |
| 精度 | 日期（`YYYY-MM-DD`）、日期时间（分钟）、日期时间（秒）；由字段元数据 `widget` 决定精度 |
| 查询参数 | 查询区提交时按后端约定传输（日期范围传 `start`/`end`，均为 UTC 或业务日边界） |

> 时区转换只在**边界**发生：组件接收 UTC、展示按用户时区；提交时把本地选择换算为 UTC。日期（不含时间）字段的边界以用户时区当天 00:00:00 ~ 23:59:59 计算。

## 4. 日期与日期时间件语义 <a id="date-props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | ISO UTC 字符串，或日期字符串（日期型） |
| 精度 | 日期 / 日期时间（分）/ 日期时间（秒）；由字段元数据决定 |
| 禁用 | 只读/无权限时置为禁用（字段权限 editable=false 由表单页传入） |
| 可清空 | 可清空 |
| 占位文案 | 占位文案（走 i18n） |
| 快捷键 | 快捷键（今天/昨天/最近 7 天/本月等，仅日期/范围生效） |
| 回传格式 | 回传值与后端对齐（UTC） |
| 范围限制 | 可选范围限制（如生效日期不得早于今天） |
| 默认时分 | 日期时间型选择日期后补齐默认时分 |
| 值变化通知 | 受控更新与变化通知（联动其他字段/查询）；失焦/聚焦触发校验时机 |

## 5. 日期范围与快捷键 <a id="range"></a>

| 项 | 设计 |
| --- | --- |
| 契约 | 同日期件；受控值为 `[起, 止]` 或空，范围分隔符默认 `~` |
| 查询区用法 | [《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)：日期类查询条件用日期范围；提交参数与列表接口一致（如 `created_start`/`created_end`） |
| 快捷键 | `今天`、`昨天`、`最近 7 天`、`最近 30 天`、`本月`、`上月`（文案走 i18n，值按用户时区边界计算） |
| 区间校验 | 起 ≤ 止；单边为空表示不限；业务区间（如统计区间）在表单页做必填与跨度校验 |
| 展示 | 只读回显为 `起 ~ 止`（范围格式化） |

## 6. 时间件语义 <a id="time"></a>

- 仅时分（可选秒），受控值为时间字符串（`HH:mm` 或 `HH:mm:ss`）；用于「每日提醒时间」「班次时间」等纯时间场景。
- 不涉及时区换算（纯时刻），但仍按 locale 展示 12/24 小时制（默认 24 小时制，与[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)系统信息一致）。
- 支持最小/最大限制与固定步长。

## 7. 只读回显与列表列渲染 <a id="readonly"></a>

- 表单只读态：组件置为禁用，显示日期时间格式化结果（系统信息区固定 `yyyy-MM-dd HH:mm`，不加时区后缀）。
- 列表列渲染：表格列格式化统一走日期时间格式化，与表单回显口径一致（见 [格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)）。
- 空值统一 `—`；时间列排序按 UTC 值排序（不按展示文本排序）。

## 8. 查询区筛选协作 <a id="filter"></a>

- 查询区由展示类「查询筛选区」承载；日期字段以日期范围件呈现（[《布局设计 · 列表页》](../../../布局设计/07_布局设计_列表页.html)：状态/字典类用下拉、日期用日期范围、部门用树选择）。
- 查询条件变化回第 1 页；分页/排序变化保留筛选条件（见 [请求封装](../../09_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）。
- 提交前把展示值换算为后端约定参数（UTC 起止），避免时区错位。

## 10. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大列表时间列 | 纯格式化函数、本地化格式化器缓存；千行渲染无压力（见 [格式化工具](../../09_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)） |
| 时区切换 | 依赖语言上下文能力（时区/格式上下文）响应式重格式化 |
| 边界值 | 跨时区零点、夏令时切换按时区库口径处理，纳入单测 |
| 非法输入 | 手输模式下非法值不提交，回退上次有效值并提示 |
| 空值 | 统一 `null`，展示 `—` |

## 11. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 由表单页不渲染；`editable=false` 下发禁用，组件不感知权限（见 [权限指令](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：占位与快捷键文案走全局语言能力；日期展示按 locale（本地化格式），不硬编码格式串用于展示。
- **移动端**：移动端用触控日期选择器/日历，值模型与时区口径同源（UTC 存储、用户时区展示），不直接复用 PC 端件（同契约多实现，同一套契约断言保障）。

## 12. 检查清单 <a id="checklist"></a>

- □ 受控与变更通知；禁用回显
- □ 值模型 ISO UTC 字符串；展示按用户时区 + locale；提交换算回 UTC
- □ 日期/日期时间/时间/日期范围四种形态齐备；精度由字段元数据决定
- □ 快捷键（今天/最近 7 天/本月等）按用户时区边界计算，文案走 i18n
- □ 查询区用日期范围，提交 `*_start`/`*_end`，变化回第 1 页、保留筛选
- □ 只读回显与列表列渲染统一日期时间格式化，系统信息区 `yyyy-MM-dd HH:mm`
- □ 空值 `—`；时间列按 UTC 排序；跨时区/夏令时边界纳入单测
- □ 字段权限（visible/editable）与移动端口径符合第 11 节
