## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**级联选择**的组件设计：多级联动字段（多级下拉联动、逐级加载、路径选择与回显）与组合逻辑（选项取数、懒加载、路径/值转换、搜索、多选）。适用于**行政区划**（省/市/区）、**多级分类**（产品/物料分类）、**层级字典**等「逐级下钻」的选择场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态禁用回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 部门管理》](../../../概要设计/08_概要设计_部门管理.md)（层级组织）、[《概要设计 · 字典管理》](../../../概要设计/09_概要设计_字典管理.md)（层级字典/多级分类）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[字段类「树选择字段」](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（树形选择，含「含下级」）、[字段类「字典字段」](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典级联）、[展示类「状态标签与描述列表」](../../07_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（只读路径回显）。

> 本篇为「级联选择」节点。**范围边界**：**树形勾选/含下级过滤**归 [字段类「树选择字段」](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（本节点为**单路径下钻**的级联下拉）；**字典级联**已在 [字段类「字典字段」](../01_组件设计_字典字段/01_组件设计_字典字段.md)覆盖，本节点面向**通用层级数据**（行政区划/分类）与懒加载大数据；**层级数据的维护**归对应模块（部门/字典）；移动端不复用（见第 9 节）。分层权威见[《前端开发规范》](../../../../规范/前端开发规范.md)「前端基类体系」节。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 级联字段件 | 多级下拉联动、懒加载、任意级可选、多选、可搜索、路径回显、清除、只读回显、禁用 |
| 组合逻辑 | 选项取数（静态/懒加载）、路径与值转换、搜索、多选扁平化、缓存与去重 |
| 继承链 | 级联字段 → [输入域基类](../../02_基础组件类/03_域基类/01_组件设计_输入域基类/01_组件设计_输入域基类.md)（域基类层）→ 能力层（[选项源能力](../../02_基础组件类/02_能力类/12_组件设计_选项源能力/12_组件设计_选项源能力.md)等）→ 组件根 → 根系；行为在链上层维护，不在组件内重复实现 |

- 基于既有级联控件定制；懒加载/任意级/多选形态由组合逻辑与字段属性声明（见第 3、4 节）。
- 字段类组件统一**受控**：受控双向绑定，变更额外抛出业务变更通知（见[《组件设计 · 总览》](../../01_组件设计_总览.md)通用设计约定）。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 受控值 | 选中值：单选取路径数组（如 `['广东省','深圳市','南山区']`）或末级值；多选为路径数组的数组 |
| 静态层级选项 | 静态层级选项（含子级、禁用、叶子标记） |
| 懒加载 | 是否懒加载（配合子级加载回调） |
| 子级加载回调 | 按父节点拉取子级的回调（如后端按父级请求） |
| 任意级可选 | 允许选择任意级（默认为是）或仅末级可选 |
| 多选 | 是否多选（多路径） |
| 可搜索 | 是否可搜索（本地或远程） |
| 可清除 | 可清除 |
| 值含完整路径 | 值是否含完整路径（或仅末级值） |
| 路径展示 | 选中标签是否显示完整路径 |
| 展开触发 | 点击 / 悬停展开 |
| 禁用与只读 | 禁用；只读态以「省 / 市 / 区」纯文本回显 |
| 值变化通知 | 受控更新 + 变更通知（含路径） |
| 内容操作 | 设置值、清除、取已选节点 |

## 4. 交互与形态 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 逐级联动 | 选择上级后展开下级；展开触发可配（点击/悬停） |
| 任意级可选 | 允许选择非末级（如只选省）；关闭则仅末级可选 |
| 懒加载 | 大数据/深层（如全国区划）按父节点拉子级：缓存已加载节点；加载中显示加载态 |
| 搜索 | 可本地过滤或远程搜索（部分层级数据）；搜索结果显示完整路径 |
| 多选 | 选择多条路径；标签以路径展示，可逐个移除 |
| 回显 | 单选显示完整路径（如「广东省 / 深圳市 / 南山区」）；可配是否显示完整路径；无 label 回退 value |
| 清除 | 可清除 |
| 只读 | 禁用置灰；只读纯文本以「省 / 市 / 区」回显（对齐[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)只读口径） |
| 空态 | 无可选项时展示占位 |

## 5. 数据与缓存 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 选项来源 | 静态层级选项（小数据，如产品分类）或懒加载接口（行政区划等大数据） |
| 懒加载 | 按父节点标识请求子级；已加载节点缓存，避免重复请求；失败可重试 |
| 值转换 | `emitPath` 口径：含完整路径（便于回显与下钻）或仅末级值（需配合 label 查询）；由业务统一（登记项②） |
| 回显 | 已有值为路径/末级码 → 反查 label 回显；懒加载下需按路径逐级加载再回显（由组合逻辑处理） |
| 缓存 | 层级数据按父节点缓存；行政区划类可本地静态包或接口缓存 |

| 场景 | 说明 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：编辑性由字段权限（[基础类「权限指令」](../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制；选项可见范围由后端数据权限过滤。
- **i18n**：占位、加载/空态、搜索无结果走全局语言能力；层级 label 由数据源按 locale 下发；用户选择值不翻译。
- **移动端**：不直接复用 PC 组件；移动端以级联弹出实现，值与路径口径同源（同接口多实现，契约套件同一套断言）。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 懒加载 | 仅请求展开层级；已加载节点缓存；避免一次性拉全树 |
| 搜索 | 本地过滤或远程搜索（防抖）；大数据用远程 |
| 回显 | 懒加载下按路径逐级加载再回显（可显示已存 label 避免卡顿） |
| 渲染 | 每级列表独立；超长路径标签省略 + 悬浮全文 |
| 边界 | 无可选项、懒加载失败重试、深层级、任意级/末级可选、多选去重、路径 vs 末级值、已选节点被停用（回退显示原值）、窄容器、禁用 |
| 不支持 | 树形勾选/含下级（字段类「树选择字段」）、字典级联（字段类「字典字段」）、层级数据维护（部门/字典模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：受控双向绑定 + 变更通知；暴露设置值/清除/取已选节点
- □ 多级联动（点击/悬停）、懒加载（按父拉取 + 缓存 + 加载态 + 失败重试）、任意级可选
- □ 单选/多选、可搜索（本地/远程）、清除、路径回显、无 label 回退 value
- □ `emitPath` 值口径（完整路径 vs 末级值）与回显；已选节点停用回退
- □ 形态：label 上方、窄容器单列；禁用置灰；只读路径纯文本回显
- □ 权限（字段权限）、i18n（文案/层级 label）、移动端（级联弹出，口径同源）符合第 8 节
- □ 性能边界：懒加载缓存、远程搜索防抖、深层级回显、超长路径省略
- □ 三项上游登记已确认：组件类型白名单扩展、层级数据接口与值口径、字段形态与只读口径
