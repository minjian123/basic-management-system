## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **字段级权限**的权威契约：`useFieldPerm`（返回字段 `visible`/`editable`）、脱敏明文指令 `v-plain`、字段元数据来源与下发、只读/编辑/隐藏三态口径、必填口径、读写双端协作。它是 00 基础组件类第 3 篇，**被 [00-02 字段壳](../02_组件设计_字段壳/02_组件设计_字段壳.md) 与 [03 交互类 13 表单渲染器](../../03_交互类/13_组件设计_表单渲染器/13_组件设计_表单渲染器.md) 消费**，统一回答"字段界面渲染、可见/不可见、可编辑/不可编辑、是否必填、是否脱敏"。

> **权威迁移**：本篇为字段权限的**权威定义**；原[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)中的字段权限部分（`useFieldPerm`/`v-plain`/字段数据来源/只读分态/脱敏）**已迁入本篇**，04-02 缩为「动作权限指令」并引用本篇。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `useFieldPerm()` | `src/utils/useFieldPerm.ts` | 依据表单元数据返回字段 `visible`/`editable`（供字段壳与渲染器协作） |
| `v-plain`（指令） | `src/directives/plain.ts` | 持 `data:plain` 动作权限时展示脱敏字段明文，否则掩码 |
| `maskValue()` | `src/utils/mask.ts` | 按字段脱敏规则掩码（手机/邮箱/身份证等），供展示类与导出复用 |
| 字段元数据（`formMeta`） | 见 [04 基础类 02 动作权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md) `usePermissionStore` | `GET /menus/my` 下发的字段定义与本用户 `visible`/`editable`/`required`/脱敏标记 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)。

## 3. 字段权限模型与数据来源 <a id="model"></a>

| 项 | 设计 |
| --- | --- |
| 字段实体 | `sys_field`（`form_id` + `field_key`）挂表单 |
| 授予 | `sys_role_field`（`role_id, form_id, field_id, visible, editable`），默认全部可见可编辑，授予后收窄 |
| 读时过滤 | 不可见字段（`visible=false`）后端序列化层过滤，**不返回**；前端不渲染 |
| 写时校验 | 不可编辑字段（`editable=false`）保存时后端拒绝，前端置 `disabled` |
| 下发路径 | `GET /api/v1/menus/my` 表单元数据随菜单下发，含按钮与字段的可见/可编辑/必填/脱敏状态 |
| 必填 `required` | 来自字段属性/校验规则（**非权限收窄项**）；[00-02 字段壳](../02_组件设计_字段壳/02_组件设计_字段壳.md) 统一推导星号 |
| 脱敏协作 | 脱敏是掩码展示；字段权限是可见性控制，两者互补（`data:plain` 查看明文） |

## 4. 契约 <a id="contract"></a>

### 4.1 useFieldPerm <a id="use-field-perm"></a>

```typescript
const { visible, editable, required } = useFieldPerm(formKey, fieldKey)
// visible=false  → 字段壳/渲染器跳过渲染该字段（栅格自然收缩）
// editable=false → 字段壳向控件传 disabled（编辑态也禁用）
// required       → 字段壳显示必填星号（来自字段属性/校验规则，非权限）
```

- 字段 label/help/必填/脱敏标记由表单元数据接口按当前 locale 下发（`sys_field_i18n` 附表），字段组件不重复渲染 label。
- 字段组件**不感知权限逻辑**：只接受 `disabled`（[00-01 基类](../01_组件设计_基础输入组件基类/01_组件设计_基础输入组件基类.md)）与"是否渲染"（由字段壳/渲染器决定）。
- 保存时若包含不可编辑字段，后端拒绝并返回错误码；前端以 `silent` 请求处理并回显（[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）。

### 4.2 只读/编辑/隐藏三态 <a id="field-state"></a>

| 状态 | 字段渲染 |
| --- | --- |
| 只读态（查看） | 全部字段只读回显（`readonlyMode` 纯文本或 `disabled`，不区分 `editable`） |
| 编辑态 | `editable=true` 可编辑；`editable=false` 仍 `disabled` |
| `visible=false` | 任何状态都不渲染 |

## 5. 脱敏与 v-plain <a id="mask"></a>

- 敏感字段（`sys_field` 注册脱敏标记，如手机号、邮箱、身份证）默认按规则掩码展示（如 `138****5678`）。
- 持 `data:plain` 动作权限的用户可请求明文；`v-plain` 指令或 `hasPerm('data:plain')` 控制在掩码与明文间切换。
- 脱敏字段的导出同样受 `data:plain` 约束（[《概要设计 · 导入导出》](../../../概要设计/19_概要设计_导入导出.md)：敏感字段默认脱敏，持 `data:plain` 方可导出明文）。
- 明文请求不落 localStorage，仅内存态。

## 6. 与动作权限 / 请求封装协作 <a id="cooperate"></a>

- **双重控制**：前端显隐（字段权限 + `v-perm`）+ 后端 `require_permission`/字段写校验；即使前端被绕过，后端仍拒绝。
- 403 响应由响应拦截器统一提示并跳 403（[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)）。
- 权限版本变更（实时推送或下次请求）→ `usePermissionStore.load()` 重新装配菜单、权限集合与字段元数据（含 `visible`/`editable`）。
- 租户切换后字段权限随权限集合整体重算（[03 交互类 21 租户切换](../../03_交互类/21_组件设计_租户切换/21_组件设计_租户切换.md)）。

## 8. 权限 / i18n / 移动端 <a id="cooperate-2"></a>

- **权限**：字段权限为角色级授予；本节点即权限渲染的字段侧权威；动作权限见 04-02；后端强校验为准。
- **i18n**：字段 label/help/脱敏提示由后端按 locale 下发，前端不硬编码。
- **移动端**：独立工程，字段权限同为表单元数据下发；移动端表单按 `visible` 跳过、`editable` 置只读；脱敏与 `data:plain` 机制同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 判断开销 | `visible`/`editable` 来自元数据 O(1) 读取；字段壳不重复查询 |
| 重装配 | 权限版本变化时一次性重装配字段元数据，避免逐字段请求 |
| 明文 | 明文仅内存态，不落 localStorage |
| 边界 | 未登录/租户未解析时元数据为空（字段全按无权限处理，页面加载/跳登录）、`visible=false` 与栅格收缩、`editable=false` 被绕过（后端拒绝）、脱敏与必填并存、明文请求失败回退掩码、字段元数据与渲染器版本不一致 |
| 不支持 | 动作权限（04-02）、字段壳渲染（00-02）、控件（00-01/05/01）、后端强校验实现 |

## 10. 检查清单 <a id="checklist"></a>

- □ `visible=false` 不渲染（栅格自然收缩）、`editable=false` 传 `disabled`，字段组件不感知权限逻辑
- □ `required` 来自字段属性/校验规则、非权限收窄项；必填星号由字段壳统一推导
- □ 只读/编辑/隐藏三态清晰；只读态全字段只读回显
- □ 脱敏字段按规则掩码，`data:plain` 才可看/导明文，明文不落 localStorage
- □ 双重控制：前端显隐 + 后端读过滤/写校验；403 统一处理
- □ 权限版本变更/租户切换触发字段元数据重装配
- □ 与 04-02 动作权限分工清晰（本节点已从 04-02 迁出并引用）
- □ 权限/i18n/移动端符合第 8 节；性能边界符合第 9 节
- □ 三项上游登记已确认：字段权限权威口径、字段元数据下发、字段权限页面口径
