## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**栅格**的组件设计：24 栅格布局与响应式断点，用于页面/表单/卡片内的分栏排布。位于继承链末端，经[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)层（继承链上的能力层：栅格/断点/令牌）取得布局语义。

> 本篇为 **布局组件类「栅格」**（编号承接迁移后的阅读顺序）。范围边界：可拖拽分栏归 [布局组件类「分栏」](../08_组件设计_分栏/08_组件设计_分栏.md)；表单栅格跨度归 [交互类「表单渲染器」](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 栅格行件 / 栅格列件 | 24 栅格行/列：跨度/偏移/间距/对齐、响应式断点、嵌套 |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 列间距（gutter） | 行内列间距（数值或横向/纵向二值），取设计令牌 |
| 主轴/交叉轴对齐（justify / align） | 行内对齐方式 |
| 换行（wrap） | 行内是否换行 |
| 跨度与偏移（span / offset） | 列跨度/偏移（0–24） |
| 断点跨度（xs / sm / md / lg / xl） | 响应式断点下取跨度，窄屏回退单列 |

## 4. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 栅格 | 24 栅格 + `span`/`offset`；`gutter` 横向/纵向间距 |
| 响应式 | 断点对象取跨度；与[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)一致 |
| 嵌套 | 支持嵌套行/列；避免过深 |
| 令牌 | `gutter`/对齐只消费令牌 |
| 分层 | 栅格行件/列件沿继承链派生：布局能力层（栅格/断点/令牌）→ 组件根 → 根系；行为在链上层维护 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单分区 | 主表三列（配合字段壳跨度） |
| 卡片/工作台 | 指标卡/图表卡栅格 |
| 页面分栏 | 内容区左右分栏 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：布局不做权限判定。
- **i18n**：无文案。
- **移动端**：断点驱动单列。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 纯布局，无额外逻辑 |
| 边界 | 嵌套 gutter 叠加、断点抖动、跨度超 24、gutter 与边框叠加 |
| 不支持 | 分栏拖拽（布局组件类「分栏」）、间距/分割线（布局组件类「间距与分割线」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：列间距 / 主轴与交叉轴对齐 / 换行 / 跨度与偏移 / 断点跨度
- □ 24 栅格、响应式、嵌套、令牌消费
- □ 分层：经继承链上的布局能力层取得布局语义；与 间距与分割线 / 分栏 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
