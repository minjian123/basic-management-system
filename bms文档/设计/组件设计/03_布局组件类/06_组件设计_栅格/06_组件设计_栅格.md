## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**栅格** `Grid`（`GridRow` / `GridCol`）的组件设计：24 栅格布局与响应式断点，用于页面/表单/卡片内的分栏排布。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 06 篇**（编号承接迁移后的阅读顺序）。范围边界：可拖拽分栏归 [03-08 分栏](../08_组件设计_分栏/08_组件设计_分栏.md)；表单栅格跨度归 [08 交互类 12 表单渲染器](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `GridRow.vue` / `GridCol.vue` | `src/components/layout/` | 24 栅格行/列：span/offset/gutter/justify/align、响应式断点、嵌套 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 组件 | 属性 | 说明 |
| --- | --- | --- |
| Row | `gutter`（number \| [x,y]） | 列间距（令牌） |
| Row | `justify` / `align` | 主轴/交叉轴对齐 |
| Row | `wrap` | 换行 |
| Col | `span` / `offset` | 跨度 / 偏移（0-24） |
| Col | `xs/sm/md/lg/xl` | 断点跨度（响应式） |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 栅格 | 24 栅格 + `span`/`offset`；`gutter` 横向/纵向间距 |
| 响应式 | 断点对象取跨度；与[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)一致 |
| 嵌套 | 支持嵌套 Row/Col；避免过深 |
| 令牌 | `gutter`/对齐只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单分区 | 主表三列（配合字段壳 span） |
| 卡片/工作台 | 指标卡/图表卡栅格 |
| 页面分栏 | 内容区左右分栏 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：布局不做权限判定。
- **i18n**：无文案。
- **移动端**：断点驱动单列。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 纯布局，无额外逻辑 |
| 边界 | 嵌套 gutter 叠加、断点抖动、跨度超 24、gutter 与边框叠加 |
| 不支持 | 分栏拖拽（03-08）、间距/分割线（03-07） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：Row `gutter`/`justify`/`align`/`wrap`；Col `span`/`offset`/断点
- □ 24 栅格、响应式、嵌套、令牌消费
- □ 继承 02 L2-07；与 03-07/03-08 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
