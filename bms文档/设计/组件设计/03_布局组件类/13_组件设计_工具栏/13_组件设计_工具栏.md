## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**工具栏**的组件设计：列表页与表单页顶部动作行的统一结构——动作项模型、左右分组、排序、权限显隐、禁用 / 危险态、溢出收纳、加载态，以及作为基类内建动作的**页面内帮助入口**。

列表工具栏与表单工具栏**分别派生**：列表工具栏维护列表默认动作集（新增 / 刷新 / 关闭 / 批量操作 / 导出等），表单工具栏维护表单默认动作集（修改 / 保存 / 删除 / 刷新 / 关闭等）；页面只声明差异动作与顺序，不重复实现分组、权限、溢出与帮助逻辑。

- 上游依据：《[布局设计 · 列表页](../../../布局设计/07_布局设计_列表页.html)》§4「工具栏」、《[布局设计 · 表单页](../../../布局设计/08_布局设计_表单页.html)》§2「工具栏」、《[布局设计 · 表单框架](../../../布局设计/06_布局设计_表单框架.html)》§4「工具栏」；帮助入口依据《[概要设计 · 帮助中心](../../../概要设计/17_概要设计_帮助中心.md)》§5 与 08_02 解析契约。
- 下游消费：列表页、表单页、页面容器右上工具栏；后续全部平台页面统一迁移。
- 不在本节点：具体业务动作语义（新增 / 保存 / 删除的业务校验）、帮助文章与分类内容（内容侧与 12_01）、长文弹层形态（容器组件类「弹窗抽屉表单」）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 通用工具栏 | 动作项模型、左右分组、排序、权限显隐、禁用 / 危险、溢出收纳、加载态；帮助动作位 |
| 列表工具栏 | 继承通用工具栏；列表默认动作集与默认顺序；批量操作随选中态启用 |
| 表单工具栏 | 继承通用工具栏；表单默认动作集与只读 / 编辑分态；保存为唯一主操作 |
| 帮助动作 | 基类内建：按当前页面锚点显隐，打开帮助弹层；默认位于右侧组末位 |
| 溢出收纳 | 右侧组超出可用宽度时收进「更多」；权限与禁用态保持 |
| 具体件 | 只做渲染与事件回传；不自行取数、不自行判定权限、不重复实现帮助状态 |

- 继承与分层：通用工具栏沿**布局组件基类**派生；列表工具栏 / 表单工具栏分别派生自通用工具栏；具体件是渲染实现，行为在链上层维护。
- 动作项是声明式数据（键 / 文案 / 图标 / 分组 / 顺序 / 权限码 / 禁用 / 危险 / 确认），工具栏只负责按声明渲染与回传，不解析业务。

## 3. 动作项与分组语义 <a id="actions"></a>

| 语义项 | 说明 |
| --- | --- |
| 动作键 | 唯一键（用于事件回传与扩展覆盖） |
| 文案 / 图标 | 文案走 i18n；图标走统一图标注册表；纯图标动作必须有悬停提示 |
| 分组 | 左侧组（主操作 / 批量操作）与右侧组（次要操作 / 导出 / 帮助）；组内按顺序排列 |
| 顺序 | 同组内按声明顺序；页面可覆盖默认动作顺序 |
| 权限码 | 按动作权限显隐；无权限不渲染，不占位 |
| 禁用 | 随选中态 / 编辑态 / 加载态禁用；禁用态保留悬停原因 |
| 危险动作 | 删除 / 停用等用危险语义；确认类动作由页面注入确认流程，工具栏不自行弹确认 |
| 溢出 | 右侧组超出宽度收进「更多」；左侧组主操作不收纳 |
| 加载态 | 工具栏级加载禁用全部动作；单动作加载由页面经动作项状态传入 |
| 扩展 | 页面可新增动作、覆盖默认动作、调整分组；不修改基类 |

- **列表工具栏默认**：左侧「新增 / 刷新 / 关闭 / 批量操作（随选中态启用）」；右侧「帮助 / 导出 / 自定义列 / 更多」。
- **表单工具栏默认**：左侧「修改 / 保存（编辑态唯一主操作）/ 删除 / 刷新 / 关闭」；右侧「帮助」。
- 具体默认集由列表 / 表单派生维护，页面只声明差异；默认集不写死在具体件内。

## 4. 帮助动作语义 <a id="help"></a>

| 项 | 设计 |
| --- | --- |
| 显隐 | 当前页面锚点存在即显示（含暂无文章）；无锚点不显示；顶栏入口常驻 |
| 位置 | 默认右侧组末位；列表 / 表单派生可覆盖位置，页面可再调整 |
| 上下文 | 模块（当前菜单锚点段）/ 表单（业务码）/ 字段 / 动作 / 产品；字段级缺表单时跳过 |
| 解析 | 打开时调用 08_02 五级解析；同上下文并发合并；不预取、不自动轮询 |
| 命中 | 有可展示文章 → 弹层显示文章 + 相关内容 + 分类入口 |
| 有锚点无文章 | 弹层显示「暂无帮助内容」+ 分类列表 |
| 无锚点 | 按钮不显示；顶栏入口按全局级呈现 |
| 失败 | 弹层给错误提示与重试；不自动重试 |
| 弹层 | 长文走容器组件类「长文阅读对话框」；工具栏只负责触发与传上下文 |

- 帮助动作是**基类内建动作**：列表 / 表单派生只在默认顺序上摆放，不各自实现显隐、解析与弹层。
- 帮助动作不参与业务动作权限（帮助接口登录即可）；其显隐只由锚点与上下文决定。

## 5. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 结构 | 左侧组 + 弹性空隙 + 右侧组；窄屏时右侧组按优先级收纳 |
| 分态 | 列表：常规 / 有选中 / 加载；表单：只读 / 编辑 / 加载；分态只切动作状态，不改结构 |
| 权限 | 权限码集合由宿主权限能力提供；工具栏只消费判定结果；权限变化即时重算显隐 |
| 帮助 | 上下文由页面提供；工具栏只把上下文交给帮助动作，不自行解析 |
| 令牌 | 间距 / 背景 / 边框 / 危险色只消费令牌；不硬编码色值与尺寸 |
| 分层 | 通用工具栏 → 布局组件基类 → 组件根 → 总基类；列表 / 表单工具栏在通用工具栏上派生 |
| 页面扩展 | 页面传动作声明与差异（新增 / 覆盖 / 排序），不继承具体件、不改基类 |

## 6. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 列表页 | 列表工具栏：新增 / 刷新 / 关闭 / 批量 / 帮助 / 导出 / 自定义列 |
| 表单页 | 表单工具栏：修改 / 保存 / 删除 / 刷新 / 关闭 / 帮助；只读与编辑分态 |
| 页面容器 | 非表单页右上工具栏复用通用工具栏；动作集由页面声明 |
| 迁移 | 先用户管理页列表 / 表单试点；其余页面阶段十五迁移，迁移时只替换工具栏壳，不改变页面业务 |
| 移动端 | 工具栏折叠为「主操作 + 更多」；帮助入口收进「更多」，不单独占位 |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：动作按权限码显隐；帮助动作不挂权限码（登录即可）；权限变化后工具栏即时重算。
- **i18n**：动作文案、帮助文案、溢出「更多」、禁用原因走全局语言能力；图标走统一图标注册表。
- **移动端**：主操作直显、其余收进「更多」；帮助入口收进「更多」；同一动作声明与权限口径，不单独实现业务。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 动作较多 | 右侧组按优先级收纳；不横向滚动；「更多」内保持分组与顺序 |
| 权限变化 | 只重算显隐，不重建整页；不请求后端 |
| 帮助 | 打开时解析一次；同上下文合并；不预取；失败可重试 |
| 窄屏 | 主操作保留、次要动作收纳；帮助在「更多」内可达 |
| 边界 | 无权限动作不占位、禁用动作有原因、危险动作需页面确认、帮助无锚点不显示、长文弹层滚动与操作栏固定 |
| 不支持 | 业务动作执行与校验、帮助文章 / 分类维护、长文弹层内容渲染（归容器组件类与内容侧） |

## 10. 检查清单 <a id="checklist"></a>

- □ 通用工具栏动作项 / 左右分组 / 排序 / 权限 / 禁用 / 危险 / 溢出 / 加载态齐备
- □ 列表工具栏与表单工具栏分别派生，默认动作集与分态正确，页面可扩展
- □ 帮助动作由基类内建：按锚点显隐、默认右侧末位、五级上下文、未命中分类、失败重试
- □ 顶栏帮助入口常驻；页内帮助与顶栏入口共用同一解析与弹层
- □ 长文走 640px 长文阅读对话框；正文滚动、底部操作固定
- □ 权限 / i18n / 移动端符合第 8 节；边界符合第 9 节
- □ 五项上游登记已确认；用户管理页试点通过，其余页面迁移有归口
