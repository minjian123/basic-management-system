## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**页面容器**的组件设计：非表单类页面的标准布局壳——标题/描述/面包屑、右上工具栏、内容区、底部操作栏、返回。适用于详情页、设置页、工作台子页、大屏配置页等。位于继承链末端，经[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)层（继承链上的能力域基类：栅格/断点/令牌）取得布局语义。

> 本篇为 **布局组件类「页面容器」**。范围边界：表单页/列表页骨架归 主框架布局壳 / 表单框架壳；内容区滚动/自适应归 容器组件类；本篇只做**页面级壳与区域编排**。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 页面容器件 | 页面壳：标题/描述/面包屑、工具栏、内容、底部操作栏、返回 |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 页面标题（title） | 页面标题（i18n） |
| 描述（description） | 描述/副标题 |
| 面包屑（breadcrumb） | 面包屑项列表 |
| 返回（back） | 是否显示返回入口 |
| 头部吸顶（sticky） | 头部区域吸顶，缺省开启 |
| 底部操作栏（footer） | 是否显示底部操作栏（保存/取消） |
| 区域插槽 | 标题 / 右上工具栏 / 面包屑 / 内容 / 底部操作栏 |
| 事件语义 | 返回、刷新（工具栏） |

## 4. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 头部 | 标题/描述/面包屑 + 右上工具栏（额外区）；吸顶可配 |
| 内容 | 独立滚动；配合自适应高度/滚动容器 |
| 底部操作栏 | 固定底部（保存/取消），窄屏堆叠 |
| 返回 | 显示返回入口；与标签栏关闭联动 |
| 令牌 | 间距/背景/边框只消费令牌 |
| 分层 | 页面容器件沿继承链派生：布局能力域基类 → 组件根 → 总基类；行为在链上层维护 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 详情/设置页 | 标题 + 内容 + 操作栏 |
| 工作台子页 | 面包屑 + 工具栏 |
| 设计器/大屏配置 | 全宽内容 + 底部操作 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：工具栏动作按动作权限显示。
- **i18n**：标题/描述/面包屑按 locale。
- **移动端**：头部简化、底部操作栏吸附。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 壳轻量；内容懒加载 |
| 边界 | 吸顶与内容滚动冲突、面包屑过长省略、底部操作栏遮挡内容、返回与标签关闭联动、窄屏堆叠 |
| 不支持 | 表单/列表骨架（布局组件类「主框架布局壳」/「表单框架壳」）、滚动容器（容器组件类「滚动容器」） |
