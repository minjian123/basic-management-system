## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **页面容器** `PageContainer` 的组件设计：非表单类页面的标准布局壳——标题/描述/面包屑、右上工具栏、内容区、底部操作栏、返回。适用于详情页、设置页、工作台子页、大屏配置页等。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 03 篇**。范围边界：表单页/列表页骨架归 03-01/03-02；内容区滚动/自适应归 04 容器组件类；本篇只做**页面级壳与区域编排**。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `PageContainer.vue` | `src/components/layout/` | 页面壳：标题/描述/面包屑、工具栏、内容、底部操作栏、返回 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 页面标题（i18n） |
| `description` | string | '' | 描述/副标题 |
| `breadcrumb` | BreadcrumbItem[] | [] | 面包屑 |
| `back` | boolean | false | 显示返回 |
| `sticky` | boolean | true | 头部吸顶 |
| `footer` | boolean | false | 显示底部操作栏 |

| 事件 | 说明 |
| --- | --- |
| `back` | 返回 |
| `refresh` | 刷新（工具栏） |

- 插槽：`title`、`extra`（右上工具栏）、`breadcrumb`、`default`、`footer`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 头部 | 标题/描述/面包屑 + 右上工具栏（`extra`）；`sticky` 吸顶 |
| 内容 | 独立滚动；配合 04 自适应高度/滚动容器 |
| 底部操作栏 | `footer` 固定底部（保存/取消），窄屏堆叠 |
| 返回 | `back` 显示返回；与标签栏关闭联动 |
| 令牌 | 间距/背景/边框只消费令牌 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 详情/设置页 | 标题 + 内容 + 操作栏 |
| 工作台子页 | 面包屑 + 工具栏 |
| 设计器/大屏配置 | 全宽内容 + 底部操作 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：工具栏动作按动作权限显示。
- **i18n**：标题/描述/面包屑按 locale。
- **移动端**：头部简化、底部操作栏吸附。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 壳轻量；内容懒加载 |
| 边界 | 吸顶与内容滚动冲突、面包屑过长省略、底部操作栏遮挡内容、返回与标签关闭联动、窄屏堆叠 |
| 不支持 | 表单/列表骨架（03-01/03-02）、滚动容器（04） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`title`/`description`/`breadcrumb`/`back`/`sticky`/`footer` + 插槽

- □ 继承 02 L2-07；与 03-01/03-02 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
