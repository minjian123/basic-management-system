## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**折叠面板**的组件设计：可展开 / 收起的多面板容器（手风琴或可多开），用于高级查询、说明区、分组设置等。继承[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)（继承链上的能力域基类：栅格/断点、间距/对齐令牌、根元素与属性透传），经组件根、总基类取得公共语义；折叠语义与[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的能力域基类）一致。

> 本篇为 **布局组件类「折叠面板」**。范围边界：卡片可折叠是其选项（[布局组件类「卡片」](../10_组件设计_卡片/10_组件设计_卡片.md)）；本篇为**面板组**原语；折叠语义与容器能力一致。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 折叠面板件（组 + 项） | 面板组：手风琴 / 多开、图标位置、禁用项、默认展开、内容懒渲染 |
| 折叠语义（复用） | 面板组折叠展开（继承链上的容器能力域基类） |
| 继承链 | 折叠面板 → 布局能力（能力域基类：栅格/断点、间距/对齐令牌、根元素与属性透传）→ 组件根 → 总基类 |

- 移动端为同一契约的另一实现（同一套契约断言保障）；触控展开、图标位置适配。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 展开项 | 当前展开项（受控；手风琴为单项，多开为多项集合） |
| 手风琴 | 同时只展开一个 |
| 图标位置 | 左 / 右 |
| 懒渲染 | 首次展开才渲染内容 |
| 项标识 / 标题 / 禁用 | 项标识、标题（i18n）、可禁用（如无权限查看的内容） |
| 展开变化通知 | 展开项变化对外通知 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 模式 | 手风琴或多开；默认展开项可配 |
| 懒渲染 | 首次展开才挂载内容（性能） |
| 禁用 | 项可禁用 |
| 令牌 | 边框 / 背景 / 间距只消费令牌 |
| 状态持久化 | 展开项可选持久化（用户偏好，按需） |

## 5. 场景集成 <a id="scenes"></a>

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：面板/项可禁用或按权限隐藏（按需）。
- **i18n**：标题按 locale。
- **移动端**：为同一契约的另一实现（同一套契约断言保障）；触控展开、图标位置适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 懒渲染：首次展开才挂载；可配缓存（保活） |
| 边界 | 手风琴与多开切换、禁用项、持久化冲突、懒渲染与缓存、与卡片折叠混淆 |
| 不支持 | 卡片折叠（布局组件类「卡片」）、滚动容器（容器组件类「滚动容器」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：展开项 / 手风琴 / 图标位置 / 懒渲染；项标识、标题、禁用；展开变化通知
- □ 手风琴/多开、懒渲染、禁用、令牌、持久化（按需）
- □ 继承布局能力（继承链上的能力域基类）；折叠语义与容器能力一致；与卡片边界清晰
- □ 权限 / i18n / 移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
