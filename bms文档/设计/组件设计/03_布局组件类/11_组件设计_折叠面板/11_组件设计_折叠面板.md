## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**折叠面板** `Collapse` 的组件设计：可展开/收起的多面板容器（手风琴或可多开），用于高级查询、说明区、分组设置等。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 11 篇**。范围边界：卡片可折叠是其选项（[03-10 卡片](../10_组件设计_卡片/10_组件设计_卡片.md)）；本篇为**面板组**原语；与 [02 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md) 的折叠语义一致。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `Collapse.vue` / `CollapseItem.vue` | `src/components/layout/` | 折叠面板组：手风琴/多开、图标位置、禁用、默认展开、内容懒渲染 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 组件 | 属性 | 说明 |
| --- | --- | --- |
| Collapse | `modelValue`（string \| string[]） | 展开项（v-model） |
| Collapse | `accordion` | 手风琴（同时只开一个） |
| Collapse | `iconPosition`（left/right） | 图标位置 |
| Collapse | `lazy` | 首次展开才渲染内容 |
| CollapseItem | `name` / `title` / `disabled` | 项标识/标题/禁用 |

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `change` | 展开项变化 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 模式 | 手风琴（`accordion`）或多开；默认展开项可配 |
| 懒渲染 | `lazy` 首次展开才挂载内容（性能） |
| 禁用 | 项可禁用（如无权限查看的内容） |
| 令牌 | 边框/背景/间距只消费令牌 |
| 状态持久化 | 展开项可选持久化（用户偏好，按需） |

## 5. 场景集成 <a id="scenes"></a>

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：面板/项可禁用或按权限隐藏（按需）。
- **i18n**：标题按 locale。
- **移动端**：触控展开、图标位置适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | `lazy` 首次展开才挂载；可配 keep-alive |
| 边界 | 手风琴与多开切换、禁用项、持久化冲突、懒渲染与缓存、与卡片折叠混淆 |
| 不支持 | 卡片折叠（03-10）、滚动容器（04） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：Collapse `modelValue`/`accordion`/`iconPosition`/`lazy`；Item `name`/`title`/`disabled`
- □ 手风琴/多开、懒渲染、禁用、令牌、持久化（按需）
- □ 继承 02 L2-07（折叠语义同 L2-04）；与 03-10 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
