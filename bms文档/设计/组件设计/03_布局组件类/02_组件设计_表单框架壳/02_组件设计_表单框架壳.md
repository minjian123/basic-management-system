## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**表单框架壳**的组件设计：实体页面的「列表 + 详情」双层结构——列表 Tab 固定、详情 Tab 多开（双层标签交互见[布局组件类「多标签导航」](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)），承载列表组件与详情组件。它是[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)的组件化落地：位于继承链末端，经[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)层与[页签状态能力](../../02_基础组件类/02_能力类/15_组件设计_页签状态能力/15_组件设计_页签状态能力.md)层（均为继承链上的能力层）取得布局与双层标签语义。

> 本篇为 **布局组件类「表单框架壳」**。范围边界：双层 Tab 交互归[布局组件类「多标签导航」](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)；列表归[展示类「通用表格」](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)；详情表单归[交互类「表单渲染器」](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 表单框架壳件 | 实体页面骨架：列表/详情组件装配、双层 Tab、事件约定（打开详情 / 保存 / 删除 / 标题变化 / 列表刷新 / 脏数据） |
| 详情标签状态（页签状态能力层） | 详情 Tab 状态（打开/激活/关闭/缓存、列表刷新联动） |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 页面标题 | 取菜单名（i18n） |
| 列表 / 详情组件装配 | 组件名 → 组件映射解析；未注册拦截提示 |
| 详情打开方式（openMode） | 枚举：标签（tab）/ 抽屉（drawer）/ 页面（page），缺省标签 |
| 详情标签缓存（cacheDetail） | 详情 Tab 参与标签缓存（按记录区分），可按需关闭；上限控制 |
| 事件语义 | 打开详情（记录标识）/ 保存或删除后刷新列表 / 脏数据状态（切换或关闭前确认）/ 详情标题变化 |

## 4. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 双层 Tab | 列表 Tab 固定不可关；详情 Tab 多开（不同记录各自新开、已开激活） |
| 开详情 | 双击列表行打开；标题取记录标识字段 |
| 关闭 | 关闭详情激活相邻；无详情则回列表 |
| 脏数据 | 编辑未保存切换/关闭前确认（脏数据标记） |
| 组件映射 | 组件名 → 组件注册；未注册拦截提示（[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)） |
| 刷新 | 保存/删除后刷新列表（局部刷新优先） |
| 分层 | 表单框架壳件沿继承链派生：布局能力层 + 页签状态能力层（链上的能力层）→ 组件根 → 根系；列表/详情分别复用通用表格与表单渲染器语义 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：列表/详情按菜单与动作权限；脏数据拦截。
- **i18n**：标题取菜单名（locale）；详情标题为记录标识（不翻译）。
- **移动端**：列表点击进入详情页（单页栈），不用双层 Tab。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 缓存 | 详情 Tab 标签级缓存；按记录区分缓存键；上限控制 |
| 刷新 | 保存/删除后局部刷新列表 |
| 边界 | 组件名未注册、重复打开、关闭相邻、脏数据、详情缓存上限、列表与详情状态不同步 |
| 不支持 | 双层 Tab 交互（布局组件类「多标签导航」）、列表（展示类「通用表格」）、详情表单（交互类「表单渲染器」） |
