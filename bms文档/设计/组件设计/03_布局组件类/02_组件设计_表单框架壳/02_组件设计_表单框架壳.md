## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **表单框架壳** `FormFrame` 的组件设计：实体页面的「列表 + 详情」双层结构——列表 Tab 固定、详情 Tab 多开（见 [03-04 多标签导航](../04_组件设计_多标签导航/04_组件设计_多标签导航.md) 的 `FormFrameTabs`），承载列表组件与详情组件。它是[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)的组件化落地，继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 02 篇**。范围边界：双层 Tab 交互归 03-04 `FormFrameTabs`；列表归 [07 展示类 01 通用表格](../../07_展示类/01_组件设计_通用表格/01_组件设计_通用表格.md)；详情表单归 [08 交互类 12 表单渲染器](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `FormFrame.vue` | `src/components/layout/` | 实体页面骨架：列表/详情组件装配、双层 Tab、事件约定（open-detail/saved/deleted/title-change/fetchList/dirty） |
| `useFormFrame.ts` | `src/components/layout/` | 详情 Tab 状态（打开/激活/关闭/缓存、列表刷新联动） |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 页面标题（菜单名） |
| `listComponent` | Component \| string | — | 列表组件（映射表解析） |
| `detailComponent` | Component \| string | — | 详情组件 |
| `openMode` | 'tab' \| 'drawer' \| 'page' | 'tab' | 详情打开方式 |
| `cacheDetail` | boolean | true | 详情 Tab keep-alive |

| 事件 | 说明 |
| --- | --- |
| `open-detail` | 打开详情（记录 id） |
| `saved` / `deleted` | 保存/删除后刷新列表 |
| `dirty` | 脏数据状态（切换/关闭前确认） |
| `title-change` | 详情标题（记录标识）变化 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 双层 Tab | 列表 Tab 固定不可关；详情 Tab 多开（不同记录各自新开、已开激活） |
| 开详情 | 双击列表行打开；标题取记录标识字段 |
| 关闭 | 关闭详情激活相邻；无详情则回列表 |
| 脏数据 | 编辑未保存切换/关闭前确认（`expose dirty`） |
| 组件映射 | `import.meta.glob` 注册组件名 → 组件；未注册拦截提示（[《布局设计 · 表单框架》](../../../布局设计/06_布局设计_表单框架.html)） |
| 刷新 | 保存/删除后刷新列表（局部刷新优先） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：列表/详情按菜单与动作权限；脏数据拦截。
- **i18n**：标题取菜单名（locale）；详情标题为记录标识（不翻译）。
- **移动端**：列表点击进入详情页（单页栈），不用双层 Tab。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 缓存 | 详情 Tab keep-alive；按记录区分缓存键；上限控制 |
| 刷新 | 保存/删除后局部刷新列表 |
| 边界 | 组件名未注册、重复打开、关闭相邻、脏数据、详情缓存上限、列表与详情状态不同步 |
| 不支持 | 双层 Tab 交互（03-04）、列表（07-01）、详情表单（08-12） |
