## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**主框架布局壳**的组件设计：管理端整体骨架——侧边栏（[13 侧边菜单](../../08_交互类/13_组件设计_侧边菜单/13_组件设计_侧边菜单.md)）、顶栏（导航/搜索/通知/用户区）、多标签栏（[04 多标签导航](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)）、内容区（路由出口）。它是[《布局设计 · 主框架》](../../../布局设计/04_布局设计_主框架.html)的组件化落地：位于继承链末端，经[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)层（继承链上的能力域基类：栅格/断点/令牌）取得布局语义。

> 本篇为 **布局组件类「主框架布局壳」**。范围边界：侧边菜单、多标签导航、顶栏元素归各专用组件（通知/搜索/用户）；本篇只负责**整体骨架与区域编排**。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 主框架布局壳件 | 主框架骨架：侧栏/顶栏/标签栏/内容区编排、侧栏折叠、响应式、区域插槽 |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 侧栏折叠 | 侧栏折叠为图标态（[《布局设计 · 导航》](../../../布局设计/05_布局设计_导航.html)）；状态持久化到用户偏好 |
| 标签栏显隐 | 是否显示多标签栏（缺省继承用户偏好） |
| 侧栏显隐 | 纯内容页可关闭侧栏 |
| 顶栏高度 / 侧栏宽度 | 取设计令牌（侧栏展开/折叠两态） |
| 区域插槽 | 侧栏 / 顶栏 / 标签栏 / 内容区 / 底部（可选） |
| 折叠变化 | 折叠状态变化回传（驱动联动） |
| 断点变化 | 断点变化回传（窄屏抽屉侧栏） |

## 4. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 区域 | 侧栏（导航）+ 顶栏（工具）+ 标签栏（可选）+ 内容区（滚动） |
| 折叠 | 侧栏折叠为图标态（[《布局设计 · 导航》](../../../布局设计/05_布局设计_导航.html)）；状态持久化到用户偏好 |
| 响应式 | 窄屏折叠/抽屉侧栏；标签栏溢出滚动（[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)） |
| 令牌 | 背景/间距/高度只消费设计令牌 |
| 内容区 | 独立滚动；配合自适应高度容器 |
| 分层 | 主框架布局壳件沿继承链派生：布局能力域基类（栅格/断点/令牌）→ 组件根 → 总基类；行为在链上层维护，不在本件内重复实现 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：菜单/按钮显隐由权限系统；布局不做判定。
- **i18n**：区域文案由子组件提供。
- **移动端**：移动端用底部标签导航骨架（同一契约多实现），不复用 PC 主框架。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 骨架常驻；内容区按路由懒加载 |
| 边界 | 折叠状态持久化冲突、窄屏抽屉、标签栏溢出、内容区滚动与固定头部、插槽缺失 |
| 不支持 | 侧边菜单（交互类「侧边菜单」）、多标签导航（布局组件类「多标签导航」）、顶栏元素专用组件 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：侧栏折叠 / 标签栏显隐 / 侧栏显隐 / 顶栏高度与侧栏宽度 / 区域插槽 / 折叠与断点通知
- □ 区域编排、折叠持久化、响应式抽屉、令牌消费、内容区独立滚动
- □ 分层：经继承链上的布局能力域基类取得布局语义；与 多标签导航 / 侧边菜单 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
