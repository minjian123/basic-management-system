## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **主框架布局壳** `AppLayout` 的组件设计：管理端整体骨架——侧边栏（[13 侧边菜单](../../08_交互类/13_组件设计_侧边菜单/13_组件设计_侧边菜单.md)）、顶栏（导航/搜索/通知/用户区）、多标签栏（[04 多标签导航](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)）、内容区（路由出口）。它是[《布局设计 · 主框架》](../../../布局设计/04_布局设计_主框架.html)的组件化落地，继承 [02 基础组件类 L2-07 布局组件基类](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 01 篇**。范围边界：侧边菜单归 08-13、多标签导航归 03-04、顶栏元素归各专用组件（通知/搜索/用户）；本篇只负责**整体骨架与区域编排**。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `AppLayout.vue` | `src/components/layout/` | 主框架骨架：侧栏/顶栏/标签栏/内容区编排、侧栏折叠、响应式、区域插槽 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `collapsed` | boolean | false | 侧栏折叠（v-model:collapsed） |
| `showTabs` | boolean | 继承用户偏好 | 是否显示多标签栏 |
| `showSidebar` | boolean | true | 是否显示侧栏（纯内容页可关） |
| `headerHeight` | number | 令牌 | 顶栏高度 |
| `sidebarWidth` | number | 令牌 | 侧栏宽度（展开/折叠） |

| 事件 | 说明 |
| --- | --- |
| `update:collapsed` | 折叠变化 |
| `resize-breakpoint` | 断点变化（窄屏抽屉侧栏） |

- 插槽：`sidebar`、`header`、`tabs`、`default`（内容）、`footer`（可选）。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 区域 | 侧栏（导航）+ 顶栏（工具）+ 标签栏（可选）+ 内容区（滚动） |
| 折叠 | 侧栏折叠为图标态（[《布局设计 · 导航》](../../../布局设计/05_布局设计_导航.html)）；状态持久化到用户偏好 |
| 响应式 | 窄屏折叠/抽屉侧栏；标签栏溢出滚动（[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)） |
| 令牌 | 背景/间距/高度只消费设计令牌 |
| 内容区 | 独立滚动；配合 04 自适应高度容器 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：菜单/按钮显隐由权限系统；布局不做判定。
- **i18n**：区域文案由子组件提供。
- **移动端**：`frontend-mobile` 用底部 TabBar 骨架，不复用 PC 主框架。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 骨架常驻；内容区按路由懒加载 |
| 边界 | 折叠状态持久化冲突、窄屏抽屉、标签栏溢出、内容区滚动与固定头部、插槽缺失 |
| 不支持 | 侧边菜单（08-13）、多标签导航（03-04）、顶栏元素专用组件 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`collapsed`/`showTabs`/`showSidebar`/`headerHeight`/`sidebarWidth` + 插槽

- □ 继承 02 L2-07；与 03-04/08-13 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
