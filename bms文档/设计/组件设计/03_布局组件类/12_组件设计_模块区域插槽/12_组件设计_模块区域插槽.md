## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**模块区域插槽**的组件设计：宿主在布局既有区域位上放置一个插槽，插槽按**区域标识**把该区域已登记的模块项依次渲染进来——模块的页面区域声明经此可见，而无须宿主逐处硬编码。

继承[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)（继承链上的能力域基类：断点与根元素协议），经组件根、总基类取得公共语义；容器形态语义（承载内容的插槽、区域内边距与背景令牌）复用[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的能力域基类）——与[布局组件类「主框架布局壳」](../01_组件设计_主框架布局壳/01_组件设计_主框架布局壳.md)同口径。

> 本篇为 **布局组件类「模块区域插槽」**。范围边界：区域位的**布局形态**归主框架布局壳（本插槽只填充，不改布局）；模块区域**声明与校验**归《[架构设计 · 前端模块契约](../../../架构设计/35_架构设计_前端模块契约.md)》（本插槽只读消费）；工作台卡片归[展示类「指标卡」](../../07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md)（卡片内容可放入区域项，插槽本身不承载卡片语义）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 模块区域插槽件 | 按区域标识读取该区域已登记项并**依序渲染**；区域未登记任何项时渲染为空 |
| 布局语义（复用） | 断点与根元素协议（继承链上的布局能力域基类） |
| 容器语义（复用） | 承载内容的插槽位、区域内边距与背景令牌（继承链上的容器能力域基类） |
| 继承链 | 模块区域插槽 → 布局能力（主链）＋容器形态语义（复用容器能力）→ 组件根 → 总基类 |

- 移动端为同一契约的另一实现（同一套契约断言保障）；窄屏下区域项顺序与换行按容器语义收紧。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 区域标识 | 宿主布局的**点分区域标识**（如顶栏左、顶栏右、内容区顶部、表单工具条）；插槽只消费指定标识 |
| 区域项 | 键（模块命名空间）、所属区域标识、挂接内容、**顺序提示**；键唯一性由装配侧负责 |
| 渲染范围 | 仅渲染**已登记**的区域项——未登记者不参与渲染（不注册即不可用） |
| 保序 | 按登记序渲染；同区域项携带**顺序提示**时以其为序（同值按登记序） |
| 挂接内容 | 组件或懒加载件（首次渲染时按需加载）；加载中与失败按模块边界兜底处理 |
| 装配变化 | 区域项登记 / 释放后插槽内容随之更新（挂载即出现、卸载即消失） |
| 空与非命中 | 区域无登记项 → 渲染为空；区域标识不存在 → 同样为空，**不替调用方兜底**（不渲染占位文案、不降级到其它区域） |
| 只读约束 | 插槽只读区域登记，不修改登记、不参与冲突裁决、不做业务兜底 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 结构 | 单个区域位内的**顺序排列容器**；无自带头尾与标题（外壳由所在区域位提供） |
| 渲染 | 逐项渲染；懒加载件首次进入时加载，加载中不阻塞其余项 |
| 顺序变化 | 登记序或顺序提示变化后按新的次序渲染 |
| 令牌 | 内边距 / 背景 / 间距只消费令牌，不写死色值与尺寸 |
| 与布局关系 | 只填既定区域位，不改布局（不新增区域位、不改变区域位宽度与折叠行为） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 主框架区域位 | 顶栏左 / 顶栏右区域由模块插入工具项（如快捷入口、状态提示） |
| 页面内容区顶部 | 模块在自身页面顶部插入提示条或工具条 |
| 工作台区域 | 区域项承载工作台卡片外壳（卡片语义见展示类） |
| 表单工具条 | 模块在表单页工具条区域插入扩展动作 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：区域项可见性由其挂接内容自持（插槽不做权限过滤，不替模块裁决）。
- **i18n**：区域本身无文案；区域项文案随模块文案包并入宿主（消费口径见《前端模块契约》）。
- **移动端**：为同一契约的另一实现（同一套契约断言保障）；窄屏下按容器语义收紧内边距与换行。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 空区域零渲染；懒加载件按需加载且互不阻塞 |
| 重新渲染 | 仅在装配变化（登记 / 释放）时重算区域项，不随路由滚动高频重算 |
| 边界 | 区域项数量较多时的换行与溢出、懒加载件失败（由模块边界兜底）、卸载残留、未知区域标识、同区域顺序提示冲突 |
| 不支持 | 新增区域位与布局形态（主框架布局壳）、模块声明与校验（模块契约）、卡片与工作台语义（展示类） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：区域标识 / 区域项（键 / 顺序提示 / 挂接内容）/ 保序 / 装配变化更新 / 空与非命中为空
- □ 渲染仅覆盖已登记项（不注册即不可用）；只读区域登记，不做冲突裁决与业务兜底
- □ 继承布局能力（主链）＋容器形态语义复用容器能力；与主框架布局壳、模块契约、展示类卡片边界清晰
- □ 权限 / i18n / 移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
