## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**内容页签**的组件设计：**页面内容区**的页签切换（如详情页「基本信息/明细/日志」），区别于[布局组件类「多标签导航」](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)（**页面级**多标签）。继承[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)（继承链上的能力域基类：栅格/断点、间距/对齐令牌、根元素与属性透传），经组件根、总基类取得公共语义；页签状态语义复用[页签状态能力](../../02_基础组件类/02_能力类/15_组件设计_页签状态能力/15_组件设计_页签状态能力.md)（继承链上的能力域基类），内容页签只复用交互模式，不参与顶层页签与持久化。

> 本篇为 **布局组件类「内容页签」**。范围边界：页面级多标签归多标签导航（不参与内容页签）；明细 Tab 归[交互类「表单渲染器」](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md)的明细区；本篇只做**内容页签原语**。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 内容页签件 | 内容页签：形态 / 可关闭 / 可增删 / 懒渲染 / 切换 / 溢出滚动 |
| 页签状态语义（复用） | 切换 / 关闭 / 缓存语义（继承链上的页签状态能力域基类）；内容页签只复用交互模式，不参与顶层页签与持久化 |
| 继承链 | 内容页签 → 布局能力（能力域基类：栅格/断点、间距/对齐令牌、根元素与属性透传）→ `BaseComponent` → `BaseObject` |

- 移动端为同一契约的另一实现（同一套契约断言保障）；页签横向滚动 / 下拉。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 激活页签 | 当前激活页签标识（受控） |
| 形态 | 线条 / 卡片 / 带边框卡片 |
| 可关闭 / 可新增 | 页签可关闭、可新增；关闭当前后激活相邻 |
| 懒渲染 | 切换才挂载内容；缓存（保活）由使用方控制上限 |
| 等宽铺满 | 页签等宽铺满容器（可选） |
| 切换 / 关闭 / 新增通知 | 切换、关闭、新增对外通知 |
| 溢出 | 页签过多横向滚动 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：页签内动作按权限；页签本身可配可见性（按需）。
- **i18n**：页签标题按 locale。
- **移动端**：为同一契约的另一实现（同一套契约断言保障）；页签横向滚动 / 下拉。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 懒渲染；缓存（保活）由使用方控制上限 |
| 边界 | 页签过多溢出、关闭后激活相邻、懒渲染与缓存、动态增删、与页面级标签混淆 |
| 不支持 | 页面级多标签（布局组件类「多标签导航」）、明细区（交互类「表单渲染器」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：激活页签 / 形态 / 可关闭 / 可新增 / 懒渲染 / 等宽铺满；切换、关闭、新增通知
- □ 形态、懒渲染、关闭激活相邻、溢出、令牌
- □ 继承布局能力（继承链上的能力域基类）；页签状态语义复用页签状态能力（不参与顶层页签与持久化）；与多标签导航边界清晰
- □ 权限 / i18n / 移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
