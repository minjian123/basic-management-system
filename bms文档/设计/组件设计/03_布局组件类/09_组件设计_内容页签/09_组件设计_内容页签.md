## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**内容页签** `Tabs` 的组件设计：**页面内容区**的页签切换（如详情页「基本信息/明细/日志」），区别于 [03-04 多标签导航](../04_组件设计_多标签导航/04_组件设计_多标签导航.md)（**页面级**多标签）。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 09 篇**。范围边界：页面级多标签归 03-04（不参与内容页签）；明细 Tab 归 [08 交互类 12 表单渲染器](../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md) 的明细区；本篇只做**内容页签原语**。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string | '' | 激活页签（v-model） |
| `type` | 'line' \| 'card' \| 'border-card' | 'line' | 形态 |
| `closable` | boolean | false | 可关闭 |
| `addable` | boolean | false | 可新增 |
| `lazy` | boolean | true | 懒渲染（切换才挂载） |
| `stretch` | boolean | false | 等宽铺满 |

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` / `tab-change` | 切换 |
| `tab-remove` / `tab-add` | 关闭 / 新增 |

- 插槽：`default`（`TabPane` 子项）。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 形态 | line / card / border-card；`stretch` 等宽 |
| 懒渲染 | `lazy` 切换才挂载；可选 keep-alive（由使用方） |
| 可关闭/增删 | `closable`/`addable`；关闭当前后激活相邻 |
| 溢出 | 页签过多横向滚动 |
| 令牌 | 激活态/边框令牌 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：页签内动作按权限；页签本身可配权限（按需）。
- **i18n**：页签标题按 locale。
- **移动端**：页签横向滚动/下拉。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 懒渲染；keep-alive 由使用方控制上限 |
| 边界 | 页签过多溢出、关闭后激活相邻、懒渲染与缓存、动态增删、与页面级标签混淆 |
| 不支持 | 页面级多标签（03-04）、明细区（08-12） |
