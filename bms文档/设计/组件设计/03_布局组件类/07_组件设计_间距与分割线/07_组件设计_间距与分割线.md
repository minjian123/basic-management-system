## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**间距与分割线**的组件设计：**元素间距**（方向、尺寸档位、换行、对齐）与**分割线**（方向、文案位置、线型）。两者均为布局组件类，继承[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)（继承链上的能力层：栅格/断点、间距/对齐令牌、根元素与属性透传），经组件根、根系取得公共语义；公共行为在链上层维护，不在组件内重复实现。

> 本篇为 **布局组件类「间距与分割线」**。范围边界：栅格间距归[布局组件类「栅格」](../06_组件设计_栅格/06_组件设计_栅格.md)（gutter）；本篇用于**内联元素间距**与**区域分隔**。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 元素间距件 | 元素间距：方向 / 尺寸档位 / 换行 / 对齐 |
| 分割线件 | 分割线：方向 / 文案 / 位置 / 线型 |
| 继承链 | 间距与分割线 → 布局能力（能力层：栅格/断点、间距/对齐令牌、根元素与属性透传）→ 组件根 → 根系 |

- 移动端为同一契约的另一实现（同一套契约断言保障）；窄屏下间距档位可整体收紧。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 方向 | 横向 / 纵向（纵向用于行内，如工具栏） |
| 尺寸档位 | 无 / 小 / 默认 / 大（`none` / `small` / `default` / `large`）或自定义数值；映射间距令牌 |
| 换行与对齐 | 可控制换行；主轴与交叉轴对齐方式可选 |
| 文案位置 | 分割线文案居左 / 居中 / 居右 |
| 线型 | 实线 / 虚线 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 间距 | 尺寸档位映射间距令牌（4/8/12/16/24）；只消费令牌，不硬编码像素值 |
| 分割线 | 文案居中 / 左 / 右；纵向分割线用于行内（工具栏） |
| 结构语义 | 元素间距不产生多余包裹（单层布局根） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 工具栏按钮组 | 元素间距横向排布按钮 |
| 表单/详情分组 | 分割线分隔 + 标题 |
| 行内操作 | 纵向分割线分隔链接 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定；区域内动作由使用方按权限控制。
- **i18n**：分割线文案由使用方提供。
- **移动端**：为同一契约的另一实现（同一套契约断言保障）；间距档位在窄屏可整体收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 纯布局，无逻辑 |
| 边界 | 间距与栅格 gutter 叠加、纵向分割线在换行时错位、分隔线文案过长 |
| 不支持 | 栅格（布局组件类「栅格」）、分栏（布局组件类「分栏」） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：元素间距方向 / 尺寸档位 / 换行与对齐；分割线方向 / 文案位置 / 线型
