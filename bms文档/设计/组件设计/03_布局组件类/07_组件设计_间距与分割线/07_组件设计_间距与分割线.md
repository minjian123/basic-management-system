## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**间距与分割线**的组件设计：`Space`（元素间距）与 `Divider`（分割线）。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 07 篇**。范围边界：栅格间距归 [03-06 栅格](../06_组件设计_栅格/06_组件设计_栅格.md)（`gutter`）；本篇用于**内联元素间距**与**区域分隔**。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `Space.vue` | `src/components/layout/` | 元素间距：方向/尺寸/换行/对齐 |
| `Divider.vue` | `src/components/layout/` | 分割线：方向/文案/位置/样式 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 组件 | 属性 | 说明 |
| --- | --- | --- |
| Space | `direction`（horizontal/vertical） | 方向 |
| Space | `size`（none/small/default/large 或 number） | 间距（令牌） |
| Space | `wrap` / `align` | 换行 / 对齐 |
| Divider | `direction`（horizontal/vertical） | 方向 |
| Divider | `contentPosition`（left/center/right） | 文案位置 |
| Divider | `dashed` / `borderStyle` | 样式 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 间距 | 尺寸映射间距令牌（4/8/12/16/24）；避免硬编码 px |
| 分割线 | 文案居中/左/右；垂直分割线用于行内（工具栏） |
| 语义 | `Space` 不产生多余包裹（单层 flex） |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 工具栏按钮组 | Space 横向间距 |
| 表单/详情分组 | Divider 分隔 + 标题 |
| 行内操作 | 垂直 Divider 分隔链接 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：分割线文案由使用方提供。
- **移动端**：间距令牌在窄屏可整体收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 纯布局，无逻辑 |
| 边界 | 间距与栅格 gutter 叠加、垂直分割线在换行时错位、分隔线文案过长 |
| 不支持 | 栅格（03-06）、分栏（03-08） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承 02 L2-07；与 03-06 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
