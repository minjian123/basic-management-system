## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **分栏** `Split` 的组件设计：可拖拽的分割布局（左右/上下），用于主从、目录-内容、编辑-预览等并排区域。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)。

> 本篇为 **03 布局组件类第 08 篇**。范围边界：树形主从（左树右表）归 [03-05 树形主从布局](../05_组件设计_树形主从布局/05_组件设计_树形主从布局.md)（内部可用本组件或栅格实现）；栅格归 [03-06](../06_组件设计_栅格/06_组件设计_栅格.md)。

## 2. 组件清单与职责 <a id="components"></a>

| --- | --- | --- |
| `Split.vue` | `src/components/layout/` | 分栏：方向/比例/可拖拽/最小尺寸/折叠/比例持久化 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `direction` | 'horizontal' \| 'vertical' | 'horizontal' | 左右 / 上下 |
| `defaultRatio` | number | 0.5 | 初始比例（0-1） |
| `min` / `max` | number \| string | 令牌 | 两侧最小/最大尺寸 |
| `collapsible` | boolean | false | 可折叠一侧 |
| `storageKey` | string | '' | 比例持久化键（用户偏好） |

| 事件 | 说明 |
| --- | --- |
| `resize` / `resize-end` | 拖拽过程/结束（比例） |
| `collapse-change` | 折叠 |

- 插槽：`first`、`second`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 拖拽 | 分割条拖拽调整比例；`min`/`max` 限制 |
| 折叠 | `collapsible` 折叠一侧，另一侧占满 |
| 持久化 | 比例存用户偏好（`storageKey`） |
| 响应式 | 窄屏转上下/单栏（[《布局设计 · 响应式适配》](../../../布局设计/11_布局设计_响应式适配.html)） |
| 令牌 | 分割条与最小尺寸消费令牌 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做判定。
- **i18n**：无文案。
- **移动端**：转上下/单栏、手势拖拽。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 拖拽 | 拖拽过程轻量（CSS 变量）；结束才持久化 |
| 边界 | 比例越界、折叠后入口、持久化键冲突、窄屏转换、拖拽与滚动冲突 |
| 不支持 | 栅格（03-06）、树形主从语义（03-05）、滚动容器（04） |
