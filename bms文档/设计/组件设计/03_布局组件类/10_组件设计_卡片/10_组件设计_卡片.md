## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**卡片** `Card` 的组件设计：带标题/操作区/内容/底栏的卡片容器，用于工作台、详情分区、表单分区等。继承 [02 基础组件类 L2-07](../../02_基础组件类/L2_形态基类/07_组件设计_布局组件基类/07_组件设计_布局组件基类.md)，与 [02 基础组件类 L2-04 容器组件基类](../../02_基础组件类/L2_形态基类/04_组件设计_容器组件基类/04_组件设计_容器组件基类.md) 的容器语义一致。

> 本篇为 **03 布局组件类第 10 篇**。范围边界：指标/图表内容归 [07 展示类 10 指标卡](../../07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md)/[07 展示类 04 图表卡](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)；折叠面板归 [03-11](../11_组件设计_折叠面板/11_组件设计_折叠面板.md)（本卡片可折叠是其选项）。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 标题 |
| `description` | string | '' | 描述/副标题 |
| `collapsible` | boolean | false | 可折叠 |
| `collapsed` | boolean | false | 折叠态（v-model:collapsed） |
| `hoverable` | boolean | false | 悬浮阴影 |
| `loading` | boolean | false | 加载态（骨架/遮罩） |
| `bordered` | boolean | true | 边框 |

| 事件 | 说明 |
| --- | --- |
| `update:collapsed` / `collapse-change` | 折叠 |

- 插槽：`title`、`extra`、`default`、`footer`、`cover`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 结构 | 头（标题/描述/操作）+ 内容 + 底栏；可选封面 |
| 折叠 | 折叠仅隐藏内容，头保留 |
| 加载 | `loading` 显示骨架或遮罩（[07 展示类 05 异常与空状态](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 令牌 | 背景/边框/圆角/内边距/阴影只消费令牌 |
| 栅格 | 常与 [03-06 栅格](../06_组件设计_栅格/06_组件设计_栅格.md) 组合排布 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：卡片内动作按权限；卡片本身可配可见性（按需）。
- **i18n**：标题/描述按 locale。
- **移动端**：单列、内边距收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠/加载按需渲染内容 |
| 边界 | 嵌套卡片、折叠持久化、加载骨架与内容切换抖动、hover 与触屏、标题过长 |
| 不支持 | 指标/图表内容（07-10/07-04）、折叠面板原语（03-11）、滚动容器（04） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`title`/`description`/`collapsible`/`collapsed`/`hoverable`/`loading`/`bordered` + 插槽
- □ 结构、折叠、加载态、令牌、与栅格组合
- □ 继承 02 L2-07（容器语义同 L2-04）；与 03-11 边界清晰
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
