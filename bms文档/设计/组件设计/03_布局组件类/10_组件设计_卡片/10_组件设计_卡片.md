## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**卡片**的组件设计：带标题 / 描述 / 操作区 / 内容 / 底栏的卡片容器，用于工作台、详情分区、表单分区等。继承[布局能力](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)（继承链上的能力层：栅格/断点、间距/对齐令牌、根元素与属性透传），经组件根、根系取得公共语义；容器形态语义（标题 / 操作 / 底栏区域位、折叠展开、区域内边距与背景令牌）复用[容器能力](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md)（继承链上的能力层）。

> 本篇为 **布局组件类「卡片」**。范围边界：指标/图表内容归[展示类「指标卡」](../../07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md)/[展示类「图表卡」](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)；折叠面板归[布局组件类「折叠面板」](../11_组件设计_折叠面板/11_组件设计_折叠面板.md)（本卡片可折叠是其选项）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 卡片件 | 卡片：标题 / 描述 / 操作 / 内容 / 底栏、可折叠、悬浮、加载态 |
| 容器形态语义（复用） | 标题 / 操作 / 底栏区域位、折叠展开、区域内边距与背景令牌（继承链上的容器能力层） |
| 继承链 | 卡片 → 布局能力（能力层：栅格/断点、间距/对齐令牌、根元素与属性透传）→ 组件根 → 根系 |

- 移动端为同一契约的另一实现（同一套契约断言保障）；单列、内边距收紧。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 标题 / 描述 | 标题与描述（副标题）文案（i18n） |
| 可折叠 / 折叠态 | 可折叠开关与折叠态（受控）；折叠仅隐藏内容，头保留 |
| 悬浮 | 悬浮阴影（可选） |
| 加载态 | 加载中显示骨架或遮罩（对齐[展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 边框 | 是否显示边框（默认显示） |
| 区域位 | 标题 / 操作 / 内容 / 底栏 / 封面区域位 |
| 折叠通知 | 折叠状态变化对外通知 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 结构 | 头（标题 / 描述 / 操作）+ 内容 + 底栏；可选封面 |
| 折叠 | 折叠仅隐藏内容，头保留 |
| 加载 | 加载态显示骨架或遮罩（[展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 令牌 | 背景 / 边框 / 圆角 / 内边距 / 阴影只消费令牌 |
| 栅格 | 常与[布局组件类「栅格」](../06_组件设计_栅格/06_组件设计_栅格.md)组合排布 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：卡片内动作按权限；卡片本身可配可见性（按需）。
- **i18n**：标题/描述按 locale。
- **移动端**：为同一契约的另一实现（同一套契约断言保障）；单列、内边距收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠/加载按需渲染内容 |
| 边界 | 嵌套卡片、折叠持久化、加载骨架与内容切换抖动、悬浮与触屏、标题过长 |
| 不支持 | 指标/图表内容（展示类「指标卡」/「图表卡」）、折叠面板原语（布局组件类「折叠面板」）、滚动容器（容器组件类） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：标题 / 描述 / 可折叠与折叠态 / 悬浮 / 加载态 / 边框；区域位（标题/操作/内容/底栏/封面）
- □ 结构、折叠（仅隐藏内容）、加载态、令牌、与栅格组合
- □ 继承布局能力（继承链上的能力层）；容器形态语义复用容器能力；与折叠面板边界清晰
- □ 权限 / i18n / 移动端符合第 7 节；边界符合第 8 节
- □ 三项上游登记已确认
