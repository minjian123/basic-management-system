## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端渲染插件 `frontend/packages/ui-ep`（PC 落点 `frontend/packages/ui-ep/src/components/layout/`；移动端实现按需 `frontend/packages/ui-vant`；宿主消费 `frontend/apps/*`）**卡片** `Card` 的组件设计：带标题/操作区/内容/底栏的卡片容器，用于工作台、详情分区、表单分区等。继承 [布局能力（原「布局能力」）](../../02_基础组件类/02_能力类/07_组件设计_布局能力/07_组件设计_布局能力.md)，与 [容器能力（原「容器能力」）](../../02_基础组件类/02_能力类/04_组件设计_容器能力/04_组件设计_容器能力.md) 的容器语义一致。

> 本篇为 **布局组件类「卡片」**。范围边界：指标/图表内容归 [展示类「指标卡」](../../07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md)/[展示类「图表卡」](../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)；折叠面板归 [布局组件类「折叠面板」](../11_组件设计_折叠面板/11_组件设计_折叠面板.md)（本卡片可折叠是其选项）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `Card.vue` | `frontend/packages/ui-ep/src/components/layout/` | 卡片：标题/描述/操作/内容/底栏、可折叠、hover、加载态 |

> **实现口径（2026-09-17，新体系）**：组件实现落 PC 渲染插件 `frontend/packages/ui-ep/src/components/layout/`（移动端按需 `frontend/packages/ui-vant`；同一契约多实现，契约套件 `@bms/core/testing` 同一套断言）；所有 UI 组件经 `@bms/vue` 的 `useComponentBase`（`frontend/packages/vue/src/bindings/useComponentBase.ts`）挂组件根（令牌属性协议 / 尺寸密度 / attrs 透传）；继承能力 `layout`（`BaseLayout`，`frontend/packages/core/src/capabilities/layout.ts`，登记 `capabilities/manifest.ts`；原「布局能力」），容器语义对齐能力 `container`（`BaseContainer`，投影 `useContainer`；原「容器能力」）。旧工程组件包装与旧能力实现已随旧层删除（历史经 git 追溯）；现行护栏 = 核心护栏 `frontend/packages/core/tests/guard-core-framework-agnostic.spec.ts` + 契约套件 `@bms/core/testing`（各插件同一套断言）。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 标题 |
| `description` | string | '' | 描述/副标题 |
| `collapsible` | boolean | false | 可折叠 |
| `collapsed` | boolean | false | 折叠态（v-model:collapsed） |
| `hoverable` | boolean | false | 悬浮阴影 |
| `loading` | boolean | false | 加载态（骨架/遮罩） |
| `bordered` | boolean | true | 边框 |

| 事件 | 说明 |
| --- | --- |
| `update:collapsed` / `collapse-change` | 折叠 |

- 插槽：`title`、`extra`、`default`、`footer`、`cover`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 结构 | 头（标题/描述/操作）+ 内容 + 底栏；可选封面 |
| 折叠 | 折叠仅隐藏内容，头保留 |
| 加载 | `loading` 显示骨架或遮罩（[展示类「异常与空状态」](../../07_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 令牌 | 背景/边框/圆角/内边距/阴影只消费令牌 |
| 栅格 | 常与 [布局组件类「栅格」](../06_组件设计_栅格/06_组件设计_栅格.md) 组合排布 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：卡片内动作按权限；卡片本身可配可见性（按需）。
- **i18n**：标题/描述按 locale。
- **移动端**：单列、内边距收紧。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠/加载按需渲染内容 |
| 边界 | 嵌套卡片、折叠持久化、加载骨架与内容切换抖动、hover 与触屏、标题过长 |
| 不支持 | 指标/图表内容（展示类「指标卡」/「图表卡」）、折叠面板原语（布局组件类「折叠面板」）、滚动容器（容器组件类） |
