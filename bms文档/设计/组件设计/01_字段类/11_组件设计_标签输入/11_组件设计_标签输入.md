## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **标签输入**的组件设计：标签字段 `TagInput.vue`（多标签录入与回显、选项建议、新建、去重、上限、颜色）与组合式函数 `useTagInput.ts`（选项取数、值归一、去重/上限校验、粘贴解析）。适用于**用户/客户/供应商标签**、**字典条目标签**、**公告标签**、**图标标签**（[03 交互类 04 图标选择器](../../03_交互类/04_组件设计_图标选择器/04_组件设计_图标选择器.md)）等「自由输入 + 建议」的多值场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态 disabled 回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 用户管理》](../../../概要设计/03_概要设计_用户管理.md)、[《概要设计 · 字典管理》](../../../概要设计/09_概要设计_字典管理.md)（标签/枚举选项）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[02 展示类 03 状态标签与描述列表](../../02_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（只读标签展示与语义色）、[01 字段类 08 开关与枚举字段](../08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（固定选项集）、[01 字段类 01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典候选项）。

> 本篇为组件设计体系字段类第 11 篇。**范围边界**：**只读展示**标签归 [02 展示类 03 状态标签与描述列表](../../02_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（本节点为**可编辑录入**控件）；**固定选项枚举**归 [01 字段类 08 开关与枚举字段](../08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（本节点允许自由新建标签）；**标签的持久化与规范化**（入库策略、查询）归各业务模块；移动端不复用（见第 9 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `TagInput.vue` | `src/components/field/` | 标签字段：多标签输入/回显、回车/逗号/失焦创建、选项建议与异步搜索、去重、上限、颜色映射、删除、只读回显、禁用 |
| `useTagInput.ts` | `src/utils/useTagInput.ts` | 组合式函数：选项取数（静态/异步）、值归一（trim、去重、大小写策略）、上限与长度校验、粘贴批量解析、颜色解析 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（字段控件归 `field/`；组合式函数放 `src/utils/`）。
- 基于 Element Plus `el-select`（`multiple` + `filterable` + `allow-create`）定制，或自绘 `el-tag` + 输入；大数据选项建议走异步搜索。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string[] | [] | 标签值（字符串数组）；受控 |
| `options` | `TagOption[]` | [] | 建议选项（`{ value, label?, color? }`） |
| `dataSource` | `TagDataSource \| null` | null | 异步建议源（搜索），与 `options` 二选一 |
| `allowCreate` | boolean | true | 是否允许新建（自由标签） |
| `multiple` | boolean | true | 多标签（false 为单标签） |
| `max` | number | 0 | 标签数量上限（0 = 不限） |
| `maxLength` | number | 0 | 单标签字符上限（超长截断/提示） |
| `unique` | boolean | true | 是否去重（大小写敏感可配） |
| `colorMap` | Record\<string, string\> | null | 标签 → 语义色（引用设计令牌） |
| `delimiters` | string[] | [',', '，'] | 输入时触发创建的分隔符 |
| `pasteSplit` | boolean | true | 粘贴多值自动按分隔符拆分 |
| `disabled` | boolean | false | 禁用 |
| `readonlyText` | boolean | false | 只读态以纯文本（顿号分隔）展示 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string[] | 值变化 |
| `change` | `{ value, added, removed }` | 变化明细 |
| `exceed` | value | 超上限时触发（父组件提示） |

- 暴露方法：`add(tag)`、`remove(tag)`、`clear()`、`setValue(tags)`。

## 4. 交互与形态 <a id="interaction"></a>

| 项 | 设计 |
| --- | --- |
| 创建 | 输入后回车 / 输入分隔符（默认中英文逗号）/ 失焦即创建标签；`allowCreate=false` 时只能从建议选择 |
| 建议 | 聚焦/输入展示候选（本地或异步搜索，防抖 300ms）；`el-select` 多选 + 过滤 |
| 去重 | `unique` 时忽略重复（trim 后比较；可按需大小写不敏感）；重复输入高亮已有标签提示 |
| 上限 | `max>0` 时达上限禁止新增并抛 `exceed`（父组件提示「最多 N 个标签」） |
| 长度 | `maxLength>0` 时超长截断或提示（按配置） |
| 粘贴 | 粘贴含分隔符文本自动拆分为多个标签（`pasteSplit`） |
| 颜色 | 标签色取自 `colorMap`（语义令牌）或选项自带色；未知回退 info（复用 [02 展示类 03 状态标签与描述列表](../../02_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 取色口径） |
| 删除 | 标签 `×` 删除；Backspace 删除末尾 |
| 只读回显 | `disabled` 置灰；`readonlyText` 以「a、b、c」纯文本（对齐表单页只读口径） |
| 空态 | 无标签时展示占位（占位文案 i18n） |

## 5. 值归一与持久化 <a id="value"></a>

| 项 | 设计 |
| --- | --- |
| 值格式 | 前端始终为 `string[]`（去空白、去空串、去重、按 `maxLength` 截断） |
| 入库格式 | 由业务模块约定（JSON 数组或逗号分隔字符串）；提交前按业务格式转换（登记项②） |
| 归一 | `useTagInput.normalize()` 统一 trim/去重/截断；失败项给出提示 |
| 回显 | 后端返回标签数组/字符串 → 归一后回显；历史脏值（空串/重复）在回显时清理 |
| 选项来源 | 静态 `options`、字典（`getDictOptions`，[01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)）或业务标签库（异步） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：编辑性由 `editable`（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制，组件只暴露 `disabled`；选项可见范围由后端数据权限过滤。
- **i18n**：占位、上限/长度提示、新建文案走 vue-i18n；标签文本为用户数据**不翻译**；选项 label 由数据源按 locale 下发。
- **移动端**：不复用 PC 组件；移动端以 `van-tag` chips + 弹出输入/选择实现，值与归一策略同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 建议 | 本地过滤小数据集；大数据走异步搜索 + 防抖；选项按需加载 |
| 渲染 | 标签数量受 `max` 限制；超长标签截断展示（title 全文） |
| 归一 | 粘贴批量解析一次性处理，避免逐条触发重渲染 |
| 边界 | 空标签、重复、超上限、超长、粘贴多值、大小写差异、选项失效（历史标签不在选项库 → 保留展示）、单标签模式、只读回显、禁用 |
| 不支持 | 只读标签展示（02 展示类 03）、固定枚举选项（01 字段类 08）、标签业务规则（各模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：`modelValue`/`update:modelValue` + `change`（新增/移除）；暴露 add/remove/clear
- □ 创建：回车/分隔符/失焦；`allowCreate` 控制；建议（本地/异步防抖）
- □ 去重（可配）、上限（`exceed`）、长度（截断/提示）、粘贴批量拆分
- □ 颜色：`colorMap`/选项色引用令牌；只读以 [02 展示类 03 状态标签与描述列表](../../02_展示类/03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md) 口径展示
- □ 值归一（trim/去重/截断）与入库格式转换；历史脏值回显清理
- □ 形态：label 上方、窄容器单列；`disabled` 置灰；`readonlyText` 纯文本回显
- □ 权限（`editable`）、i18n（文案/选项，标签不翻译）、移动端（chips + 弹出，口径同源）符合第 8 节
- □ 性能边界：异步防抖、按需选项、粘贴一次性解析、超长截断
- □ 三项上游登记已确认：组件类型白名单扩展、标签值格式与选项来源、字段形态与只读口径
