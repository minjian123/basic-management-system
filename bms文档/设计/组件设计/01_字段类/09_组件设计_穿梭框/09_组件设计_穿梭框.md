## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **穿梭框字段**的组件设计：双列表选择组件 `TransferField.vue`（候选/已选两栏、搜索、分组、全选、穿梭操作、值绑定与只读回显）与组合式函数 `useTransfer.ts`（候选项取数、异步搜索、分页/大数据、值映射、批量）。适用于**权限主体绑定**（用户/岗位/部门选入角色）、**租户模块开通**（已开通/未开通双向）、**字段/列选择**、**多值关联配置**等「左侧候选 → 右侧已选」的选择场景。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；字段形态依据[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)「表单组织」节（label 上方、窄容器单列、只读态 disabled 回显）与[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)；上游设计依据[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)（主体绑定 `sys_role_assign`、权限授予）、[《概要设计 · 租户管理》](../../../概要设计/25_概要设计_租户管理.md)（模块开通/开关）、[《概要设计 · 表单定制》](../../../概要设计/36_概要设计_表单定制.md)（组件类型与字段属性）；协作节点为[01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md)（字典候选项）、[01 树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)/[01 组织选择字段](../05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)（组织类候选）、[03 交互类 08 权限配置](../../03_交互类/08_组件设计_权限配置/08_组件设计_权限配置.md)（主体绑定/权限授予使用）、[04 基础类 01 请求封装](../../04_基础类/01_组件设计_请求封装/01_组件设计_请求封装.md)（异步候选取数）。

> 本篇为组件设计体系字段类第 09 篇。**范围边界**：候选项**数据源**（字典/组织/权限实体）归各自模块与 01/04/05 节点；**树形结构**的双列表（带层级）归 [01 树选择字段](../04_组件设计_树选择字段/04_组件设计_树选择字段.md)（本节点为**扁平/分组**双列表）；**权限与主体绑定业务逻辑**归[《概要设计 · 角色管理》](../../../概要设计/06_概要设计_角色管理.md)（本节点只做选择与值绑定）；移动端不复用（见第 12 节）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `TransferField.vue` | `src/components/field/` | 穿梭框字段：候选/已选两栏、全选/半选、单项/批量穿梭、搜索、分组、计数、值绑定与只读回显、禁用、空态 |
| `useTransfer.ts` | `src/utils/useTransfer.ts` | 组合式函数：候选项取数（同步/异步搜索）、已选回显（按 id 批量查 label）、分页/大数据、值映射（id↔对象）、受控值同步 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（`src/components/` 按域分目录，字段控件归 `field/`；组合式函数放 `src/utils/`）。
- 基于 Element Plus `el-transfer` 定制；大数据/异步/分组能力不足处由 `useTransfer` 与自绘列表补齐。

## 3. Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `(string \| number)[]` | [] | 已选值（id 列表）；受控 |
| `options` | `TransferOption[]` | [] | 候选项（`{ key, label, disabled?, group? }`）；静态数据源 |
| `dataSource` | `TransferDataSource \| null` | null | 异步候选源（分页/搜索），与 `options` 二选一 |
| `titles` | `[string, string]` | ['候选', '已选'] | 两栏标题（i18n） |
| `searchable` | boolean | true | 是否可搜索（本地过滤或触发远程搜索） |
| `groupable` | boolean | false | 是否按 `group` 分组展示 |
| `pageSize` | number | 0 | 候选分页大小（0 = 不分页/一次性） |
| `max` | number | 0 | 已选上限（0 = 不限），超限提示 |
| `disabled` | boolean | false | 禁用（字段权限 `editable=false` 时由表单传） |
| `readonlyText` | boolean | false | 只读态以纯文本展示已选项（label 拼接） |
| `valueKey` / `labelKey` | string | 'key' / 'label' | 取值/展示字段名（对齐数据源） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | id[] | 值变化 |
| `change` | `{ value, added, removed }` | 变化明细（新增/移除项） |
| `search` | keyword | 远程搜索触发（配置 `dataSource` 时） |

- 暴露方法：`setValue(ids)`、`refresh()`、`clear()`。

## 4. 交互与形态 <a id="interaction"></a>

```mermaid
flowchart LR
    A["候选（左）<br/>搜索 · 分组 · 分页"] -->|"选中 → 穿梭"| B["已选（右）<br/>值列表 · 计数"]
    B -->|"移除 → 穿梭"| A
    A -.->|"异步搜索/分页"| S["dataSource 取数"]
    B -.->|"按 id 批量回显 label"| S
```

| 项 | 设计 |
| --- | --- |
| 双栏 | 左候选、右已选；两栏顶部全选/清空、搜索框、计数；中间穿梭按钮 |
| 搜索 | `searchable` 本地过滤（小数据）或远程搜索（`dataSource`，防抖）；远程搜索只影响候选栏 |
| 分组 | `groupable` 按 `group` 分组标题展示（如按部门分组） |
| 分页/大数据 | `pageSize>0` 时候选栏分页（或虚拟滚动），避免一次性渲染上万项 |
| 上限 | `max>0` 时超限阻止并提示 |
| 只读回显 | `disabled` 置灰；`readonlyText` 时以「label、label」纯文本展示（对齐[《布局设计 · 表单页》](../../../布局设计/08_布局设计_表单页.html)只读口径） |
| 空态 | 候选/已选为空时展示占位（复用 [02 展示类 05 异常与空状态](../../02_展示类/05_组件设计_异常与空状态/05_组件设计_异常与空状态.md)） |
| 校验 | 必填校验（长度非空）；与后端一致 |

## 5. 取数与回显 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 候选取数 | 静态 `options` 或 `dataSource.load({ keyword, page })` 异步；字典候选走 [01 字典字段](../01_组件设计_字典字段/01_组件设计_字典字段.md) 缓存；组织候选走 04/05 节点 |
| 已选回显 | 编辑态只持有 id 列表，需按 id **批量查 label**（`dataSource.loadByIds`）回显已选项；缺 label 回退显示 id |
| 大数据 | 分页/虚拟滚动；已选集合单独维护（不随候选分页变化） |
| 缓存 | 字典/组织候选复用对应 store 缓存；异步搜索防抖 300ms |
| 失效 | 已选项在候选中不存在（已停用/删除）→ 保留展示并标记「已失效」（提交由后端校验） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段可编辑性由 `editable`（[04 基础类 02 权限指令](../../04_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）控制，组件只暴露 `disabled`；候选项可见范围由后端数据权限过滤。
- **i18n**：标题、搜索占位、空态、超限提示走 vue-i18n；候选项 label 由数据源按 locale 下发。
- **移动端**：不复用 PC 组件；移动端以「底部弹出多选面板 + 已选 chips」实现，值格式与校验同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 大数据候选 | 分页/虚拟滚动；不一次性渲染全部；远程搜索防抖 |
| 回显 | 按 id 批量查 label；已选集合独立于候选分页 |
| 渲染 | 已选栏轻量；分组标题不重复计算 |
| 边界 | 候选/已选为空、超上限、已选项失效、远程搜索无结果、异步失败重试、值类型（string/number 混用）、去重、只读回显、禁用 |
| 不支持 | 树形双列表（04 节点）、候选数据源实现（字典/组织模块）、权限业务逻辑（角色/租户模块）、移动端组件 |

## 10. 检查清单 <a id="checklist"></a>

- □ 受控：`modelValue`/`update:modelValue`，变更抛 `change`（新增/移除）
- □ 双栏：全选/清空、搜索、分组、计数、穿梭按钮；空态
- □ 取数：静态 `options` 与异步 `dataSource`（搜索/分页）；已选按 id 批量回显 label；失效项标记
- □ 形态：label 上方、窄容器单列；`disabled` 置灰；`readonlyText` 纯文本回显；`max` 超限提示
- □ 校验：必填与后端一致
- □ 权限（`editable`/数据范围）、i18n（标题/占位/选项）、移动端（底部多选，值格式同源）符合第 8 节
- □ 性能：分页/虚拟滚动、远程搜索防抖、回显批量、已选集合独立
- □ 三项上游登记已确认：主体绑定/模块开通使用契约、字段形态与只读口径、组件类型白名单扩展
