## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**文本域** `TextareaField` 的组件设计：多行文本输入的**基础控件**，用于备注、说明、地址、意见等长文本。继承 **02 基础组件类** L4-01 输入域基类（`BaseInput`）→ L3/L2/L1b/L0 继承链。

> 本篇为 **03 基础控件类第 02 篇**。范围边界：富文本（可格式化内容）归 [04 字段类 07 富文本字段](../../04_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)；本篇只做纯文本多行输入。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `TextareaField.vue` | `src/components/base-control/` | 多行文本：行数/自适应高度、字数统计、受控与只读、trim 与脱敏 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | `null` | 受控值 |
| `rows` | number | 3 | 初始行数 |
| `autosize` | boolean \| { minRows, maxRows } | false | 高度自适应 |
| `maxlength` / `showWordLimit` | number / boolean | — | 最大长度与字数统计 |
| `trim` | boolean | true | 提交前去首尾空格 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 高度 | 固定行数或 `autosize`（min/maxRows），滚动条出现阈值 |
| 计数 | 超限截断并显示 `n/max` |
| 换行 | 保留换行；提交原样（后端存储换行符统一 `\n`） |
| 归一 | `trim`、空串 → `null`（L3-01）；只读/三态与文本框一致 |
| 脱敏 | 敏感长文本按规则掩码 |

## 5. 场景集成 <a id="scenes"></a>

| --- | --- |

| 明细行内 | 较长文本列 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑；脱敏按标记。
- **i18n**：标签/占位/计数文案走 i18n。
- **移动端**：多行输入、自适应高度、键盘避让。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控；长文本计数防抖 |
| 边界 | 超长截断、`autosize` 抖动、换行符统一、trim、只读三态 |
| 不支持 | 富文本/格式化（04-07）、单行文本（文本框） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整；契约：`rows`/`autosize`/`maxlength`/`trim`
- □ 换行保留与统一；计数；只读回显
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与富文本字段边界清晰
- □ 三项上游登记已确认
