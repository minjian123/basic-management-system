## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**开关** `SwitchInput` 的组件设计：布尔值开关的**基础控件**，用于启用/停用、是否类字段。继承 **02 基础组件类** L4-01 输入域基类。

> 本篇为 **03 基础控件类第 08 篇**。范围边界：**布尔开关字段（含列表内联切换、失败回滚、三态语义）**归 [04 字段类 08 开关与枚举字段](../../04_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)（其 `SwitchField` 继承本控件）；本篇只做开关原语。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `SwitchInput.vue` | `src/components/base-control/` | 布尔开关：值/文案、三态、加载态、危险切换确认 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | boolean \| null | `null` | 受控值（支持三态） |
| `activeText` / `inactiveText` | string | '' | 开关文案 |
| `loading` | boolean | false | 加载态（切换中） |
| `dangerConfirm` | string | '' | 危险切换确认文案 |
| `threeState` | boolean | false | 区分未设置/关 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 值域 | 前端只暴露布尔/`null`；后端 `SMALLINT` 1/0 由边界归一（继承链） |
| 三态 | `threeState` 时 `null` 显示「未设置」，与 `false` 区分 |
| 加载 | 切换中显示 loading 并禁止重复；失败回滚（内联场景由 04-08 处理） |
| 危险切换 | `dangerConfirm` 时二次确认（如停用关键配置） |
| 文案 | `activeText`/`inactiveText` 走 i18n |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：开关文案走 i18n。
- **移动端**：触控尺寸。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 切换 | 受控；加载态防重复；失败回滚由字段层（04-08）负责 |
| 边界 | `null`/`false`、文案溢出、加载中连点、危险确认取消 |
| 不支持 | 列表内联切换与回滚（04-08）、枚举单选/多选（单选/复选） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整；契约：`modelValue`/`activeText`/`loading`/`dangerConfirm`/`threeState`
- □ 值域归一（1/0 ↔ 布尔）、三态、加载态、危险确认
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与 04 字段类开关枚举边界清晰
- □ 三项上游登记已确认
