## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**密码框** `PasswordField` 的组件设计：密码输入的**基础控件**，用于登录、新增/修改密码、初始化密码等。继承 **02 基础组件类** L4-01 输入域基类。

> 本篇为 **03 基础控件类第 03 篇**。安全底线：密码**不回填**（编辑态留空表示不修改）、明文切换仅前端内存、不落日志/本地存储。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `PasswordField.vue` | `src/components/base-control/` | 密码输入：掩码显示、明文切换、强度提示、一致性校验、不回填 |
| `usePasswordStrength.ts` | `src/utils/` | 密码强度计算（长度/字符类别，规则可配） |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| null | `null` | 受控值（不回填） |
| `showToggle` | boolean | true | 明文切换按钮 |
| `strength` | boolean | false | 显示强度提示 |
| `minLength` | number | 8 | 最小长度 |
| `noAutofill` | boolean | true | 阻止浏览器自动填充 |

| 事件 | 说明 |
| --- | --- |
| `change` | 值变化（不回显到日志） |
| `validate` | 长度/强度/一致性校验结果 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 不回填 | 编辑态初始为空；提交时为空表示不修改（后端约定） |
| 明文切换 | 仅前端内存态；切换不触发日志 |
| 强度 | `strength` 按规则计算并提示（弱/中/强），不阻断（由校验决定） |
| 一致性 | 确认密码字段引用同一规则做一致性校验 |
| 安全 | 值不写日志/不落 localStorage；自动填充可禁 |
| 归一 | 密码不 trim（保留空格）；空串 → `null` |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：修改密码入口按权限/本人约束（后端强校验）。
- **i18n**：强度提示/错误文案走 i18n。
- **移动端**：安全键盘、掩码显示、避让键盘。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 输入 | 受控；强度计算去抖 |
| 边界 | 自动填充泄露、明文切换残留、确认不一致、长度与复杂度、编辑态回填误用 |
| 不支持 | 验证码（[04 字段类 10 验证码](../../04_字段类/10_组件设计_验证码/10_组件设计_验证码.md)）、普通文本（文本框） |

- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与验证码/文本框边界清晰
- □ 三项上游登记已确认
