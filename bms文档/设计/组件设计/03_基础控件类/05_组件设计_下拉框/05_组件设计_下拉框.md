## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**下拉框** `SelectInput` 的组件设计：**静态选项**下拉选择的**基础控件**。继承 **02 基础组件类** L4-01 输入域基类。

> 本篇为 **03 基础控件类第 05 篇**。范围边界：**字典来源**下拉归 [04 字段类 01 字典字段](../../04_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)；**枚举选项集**（自定义选项/多选标签）归 [04 字段类 08 开关与枚举字段](../../04_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)；本篇只做**静态 options** 的选择原语，被上述字段继承。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `SelectInput.vue` | `src/components/base-control/` | 静态选项下拉：单选/多选、搜索、清空、分组、禁用选项 |

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | any \| any[] \| null | `null` | 受控值 |
| `options` | OptionItem[] | [] | 静态选项（`value/label/disabled/group?`） |
| `multiple` | boolean | false | 多选 |
| `filterable` | boolean | false | 可搜索 |
| `clearable` | boolean | true | 可清空 |
| `collapseTags` | boolean | false | 多选标签折叠 |
| `maxCount` | number | — | 多选数量上限 |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 选项模型 | `OptionItem`（值/文本/禁用/分组），与字典/枚举同构，便于继承 |
| 多选 | `multiple`，值数组；`maxCount` 上限提示；标签折叠 |
| 搜索 | `filterable` 本地过滤（静态选项） |
| 归一 | 空 → `null`（单选）/`[]`（多选）；去除无效值 |
| 只读/三态 | 只读回显经展示域基类；三态一致 |
| 分组 | 按 `group` 分节显示 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单字段 | 少量静态选项（如性别、优先级） |
| 查询筛选区 | 静态条件选择 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限判定可见/可编辑。
- **i18n**：选项文本按 locale（由使用方下发）。
- **移动端**：底部弹层选择器。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 选项 | 少量静态选项本地过滤；大量选项时应改用字典/远程搜索字段 |
| 边界 | 无效值回显、多选上限、禁用选项、空值与 `false`/`0` 值、异步选项（非本控件） |
| 不支持 | 字典下拉（04-01）、枚举多选标签（04-08）、树/级联（04-04/12） |

## 9. 检查清单 <a id="checklist"></a>

- □ 继承链完整；契约：`options`/`multiple`/`filterable`/`maxCount`
- □ `OptionItem` 统一模型；空值归一；多选上限
- □ 权限/i18n/移动端符合第 7 节；边界符合第 8 节
- □ 与 04 字段类字典/枚举边界清晰
- □ 三项上游登记已确认
