## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **头像与用户信息**的展示组件设计：头像 `UserAvatar.vue`（图片/首字母/默认色/尺寸/状态点/角标），用户胶囊 `UserPill.vue`（头像 + 姓名 + 部门/岗位，紧凑展示，可选悬浮用户卡片），以及组合式函数 `useUserDisplay.ts`（用户展示信息取数/缓存、头像色派生、姓名/部门回显、脱敏）。适用于**审批人/已办人展示**、**列表用户列**、**通知消息项**、**工作台/看板**、**头像上传预览**等。

本节对应[《项目规划说明》](../../../../规划/项目规划说明.md)前端章节；上游设计依据[《概要设计 · 用户管理》](../../../概要设计/03_概要设计_用户管理.md)（用户/部门/岗位信息、头像 `avatar`）、[《概要设计 · 通知中心》](../../../概要设计/16_概要设计_通知中心.md)（消息项展示）、[《概要设计 · 工作流管理》](../../../概要设计/15_概要设计_工作流管理.md)（审批人/已办人展示）；视觉依据[《布局设计 · 设计令牌》](../../../布局设计/02_布局设计_设计令牌.html)（头像尺寸、语义色）与[《布局设计 · 表格明细》](../../../布局设计/09_布局设计_表格明细.html)；协作节点为[04 字段类 05 组织选择字段](../../04_字段类/05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)（用户选择回显）、[05 展示类 03 状态标签与描述列表](../03_组件设计_状态标签与描述列表/03_组件设计_状态标签与描述列表.md)（语义色）、[05 展示类 06 通知与消息](../06_组件设计_通知与消息/06_组件设计_通知与消息.md)（消息项复用）、[07 基础类 03 格式化工具](../../07_基础类/03_组件设计_格式化工具/03_组件设计_格式化工具.md)、[07 基础类 02 权限指令](../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)（脱敏）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `UserAvatar.vue` | `src/components/display/` | 头像：图片（预签名 URL）/首字母/默认色兜底、尺寸（xs/sm/md/lg）、形状（圆/方）、状态点、角标、组合头像组 |

- 命名遵循[《命名规范》](../../../../规范/命名规范.md)：组件 PascalCase、组合式函数 `use` + 名词；目录遵循[《前端开发规范》](../../../../规范/前端开发规范.md)（展示类归 `display/`；组合式函数放 `src/utils/`）。

## 3. 头像 UserAvatar <a id="avatar"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `src` | string \| null | null | 头像图片地址（预签名/静态）；缺省回退首字母 |
| `name` | string | '' | 用户姓名（用于首字母与默认色派生） |
| `size` | 'xs' \| 'sm' \| 'md' \| 'lg' | 'md' | 尺寸（xs 20 / sm 28 / md 32 / lg 40，2×2 卡片与列表不同档） |
| `shape` | 'circle' \| 'square' | 'circle' | 形状 |
| `status` | 'online' \| 'offline' \| 'locked' \| null | null | 状态点（可选，右下角） |
| `badge` | number \| null | null | 角标（可选） |
| `group` | UserBrief[] | [] | 头像组（多人叠加展示，如审批会签） |
| `max` | number | 3 | 头像组最多显示数（超出 +N） |

- **回退链**：图片 → 首字母（姓名首字）→ 默认图标；图片加载失败回退首字母（不暴露破图）。
- **默认色派生**：按用户名 hash 从设计令牌语义色/图表色板取稳定色（同一用户颜色稳定），文字白色；不得硬编码色值。
- **组合头像**：多人（会签、协作者）叠加，超出显示 `+N`，点击展开全部。
- **脱敏**：姓名受字段脱敏/`data:plain` 约束时按 [07 基础类 02 权限指令](../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md) 口径掩码。

## 4. 用户胶囊 UserPill <a id="pill"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `user` | UserBrief \| null | null | 用户简要（`{ id, name, avatar?, deptName?, postName?, status? }`） |
| `size` | 'sm' \| 'md' | 'md' | 头像与字号档位 |
| `showDept` | boolean | false | 是否显示部门/岗位（次要文本） |
| `linkTo` | string \| null | null | 点击跳转用户详情（受权限） |
| `popover` | boolean | false | 是否悬浮展示用户卡片（姓名/部门/岗位/状态/联系方式，联系方式受脱敏） |
| `text` | boolean | false | 仅文字（无头像，用于窄列） |

- **悬浮卡片**：`popover` 时悬停显示用户简要卡（头像、姓名、部门、岗位、状态；联系方式按脱敏/权限）；卡片数据来自 `useUserDisplay` 缓存（避免逐条请求）。
- **空用户**：`user=null` 显示「—」；用户已删除显示「已删除用户」（保留 id 占位，不报错）。
- **紧凑列表**：表格用户列、审批时间线、消息项默认 `size='sm'`；卡片头用 `md`。

## 5. 组合式函数 useUserDisplay <a id="use-user-display"></a>

```typescript
interface UseUserDisplayOptions { cache?: boolean; }
interface UseUserDisplayReturn {
  users: Ref<Record<string, UserBrief>>;     // id -> 展示信息
  loadByIds: (ids: (string | number)[]) => Promise<void>;   // 批量取（去重 + 缓存）
  getUser: (id: string | number) => UserBrief | null;
  initial: (name: string) => string;          // 首字母
  colorOf: (key: string) => string;           // 稳定默认色（令牌）
  displayName: (id) => string;                // 姓名/回退/已删除
}
```

| 行 | 设计 |
| --- | --- |
| 批量取数 | 列表/审批页把本屏出现用户 id 去重后**批量**查展示信息（一个接口），缓存（会话级）；不逐条请求 |
| 缓存 | `id → UserBrief` 内存缓存；用户改名后由用户模块事件/刷新失效（可选） |
| 回退 | 缺展示信息回退 id；已删除返回「已删除用户」；姓名受脱敏 |
| 颜色 | `colorOf` 按 key hash 取稳定色（图表色板/语义色），同用户跨页一致 |
| 按需懒取 | 悬浮卡片需要部门/联系方式时再补取（如首屏只取姓名/头像） |

## 8. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：`linkTo` 用户详情按目标路由权限显隐；姓名/联系方式受脱敏与 `data:plain`（[07 基础类 02 权限指令](../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）；用户数据可见范围由后端数据权限过滤。
- **i18n**：空用户/已删除用户/状态等文案走 vue-i18n；用户姓名/部门为用户数据**不翻译**。
- **移动端**：不复用 PC 组件；移动端以 `van-image` 圆形头像 + 姓名/部门文字实现，回显数据同源。

## 9. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 取数 | 批量按 id 查询 + 会话级缓存；不逐条请求；悬浮卡片按需补取 |
| 渲染 | 头像图片懒加载（`loading="lazy"`）；首字母兜底即时渲染；长列表复用同一缓存 |
| 首字母 | 中文取姓氏首字、英文取首字母；大小写归一 |
| 边界 | 无头像、图片加载失败、空用户、已删除用户、姓名脱敏、长姓名（省略 + title）、头像组超出（+N）、彩色默认色稳定、状态点 |
| 不支持 | 可编辑用户选择（04 字段类 05）、头像上传（04 字段类 06）、用户数据维护（后端）、移动端组件 |
