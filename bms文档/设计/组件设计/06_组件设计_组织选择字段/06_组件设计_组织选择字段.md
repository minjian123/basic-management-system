## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/` **组织成员选择字段**的通用组件设计：人员选择（UserSelectField，远程搜索、多选）、岗位选择（PostSelectField）、组织复合选择（OrgSelectField，部门 × 岗位），以及远程选项取数工具 `useRemoteOptions`。适用于经办人、负责人、审批人、抄送人、成员、岗位归属等需要从组织数据中选择的场景。

本节对应[《项目规划说明》](../../../规划/项目规划说明.md)前端与组织权限章节；上游设计依据[《概要设计 · 用户管理》](../../概要设计/03_概要设计_用户管理.md)（用户列表分页查询、用户选择相关接口、脱敏）、[《概要设计 · 岗位管理》](../../概要设计/05_概要设计_岗位管理.md)（岗位列表）、[《概要设计 · 部门管理》](../../概要设计/08_概要设计_部门管理.md)（部门树，作为过滤维度）；页面形态依据[《布局设计 · 列表页》](../../布局设计/07_布局设计_列表页.html)、[《布局设计 · 表单页》](../../布局设计/08_布局设计_表单页.html)。

> 本篇为组件设计体系字段类第 06 篇；部门树选择见 05 树选择字段节点（本篇按部门过滤人员时复用其树数据）。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `UserSelectField.vue` | `src/components/field/` | 人员选择：远程搜索、单选/多选、可选按部门过滤、脱敏展示 |
| `PostSelectField.vue` | `src/components/field/` | 岗位选择：单选/多选、按状态过滤 |
| `OrgSelectField.vue` | `src/components/field/` | 组织复合选择：部门（树）+ 人员/岗位（列表）联动 |
| `useRemoteOptions()` | `src/utils/useRemoteOptions.ts` | 远程选项取数：防抖、缓存、已选值回填（详情态无搜索时按 id 批量取名称） |

- 字段类组件统一受控：`modelValue` / `update:modelValue` + `change`（见[《组件设计 · 总览》](../01_组件设计_总览.md)）。
- 命名遵循[《命名规范》](../../../规范/命名规范.md)。

## 3. 数据来源与远程搜索 <a id="data"></a>

| 项 | 设计 |
| --- | --- |
| 人员列表 | `GET /api/v1/users`（分页 + `keyword` 模糊查询：用户名/昵称/手机号）；见[《概要设计 · 用户管理》](../../概要设计/03_概要设计_用户管理.md) |
| 岗位列表 | `GET /api/v1/posts`（分页 + `keyword`、`status`）；见[《概要设计 · 岗位管理》](../../概要设计/05_概要设计_岗位管理.md) |
| 部门过滤 | 结合部门树（05 节点）传 `dept_id`（可 `include_children`）过滤人员 |
| 搜索 | `filterable` + `remote`，输入 **300ms 防抖** 后按 `keyword` 请求；下拉限制返回条数（如 20 条） |
| 已选回填 | 编辑/详情态仅有 id 时，按 id 批量查询名称（`id_in=1,2,3`）回填标签；缓存已解析的名称 |
| 缓存 | 同一关键词结果短期缓存；已选对象常驻内存，避免重复请求 |
| 脱敏 | 人员手机号/邮箱默认脱敏展示（见 20 权限指令与 `v-plain`） |

## 4. UserSelectField Props 与事件 <a id="props"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| string[] \| null | — | 用户 id（多选为数组） |
| `multiple` | boolean | false | 是否多选 |
| `limit` | number | 10 | 多选上限（超出提示） |
| `deptId` | string \| null | null | 按部门过滤（联动 05 树选择） |
| `includeChildren` | boolean | true | 部门过滤是否含下级 |
| `status` | string \| null | 'enabled' | 仅选启用状态用户（可选） |
| `showAvatar` | boolean | false | 下拉是否显示头像 |
| `disabled` | boolean | false | 只读/无权限（`editable=false` 由表单页传入） |
| `placeholder` | string | 请选择 | 占位文案 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:modelValue` | string \| string[] \| null | v-model 绑定 |
| `change` | id \| id[] \| null | 变化通知（联动） |
| `select` | user | 选中某用户（取完整对象，如带出手机号） |

## 5. PostSelectField <a id="post"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | string \| string[] \| null | — | 岗位 id |
| `multiple` | boolean | false | 是否多选（一个用户可多岗位时） |
| `status` | string \| null | null | 按岗位状态过滤 |
| `showCode` | boolean | true | 下拉是否展示岗位编码 |
| `disabled` | boolean | false | 只读/无权限 |

- 岗位为组织岗位字典（非字典表），数据源为岗位接口；编码规则见[《概要设计 · 岗位管理》](../../概要设计/05_概要设计_岗位管理.md)与[《命名规范》](../../../规范/命名规范.md)。

## 6. OrgSelectField（部门 × 岗位/人员） <a id="org"></a>

- 复合布局：左侧部门树（05 节点数据），右侧人员/岗位列表；适用于需要「先选部门再选人」的场景（如数据权限配置）。
- 已选以标签展示，支持从标签移除；关闭弹窗后回填 `modelValue`。
- 与交互类「选择器弹窗」（17）协作：复杂选择（带部门树 + 搜索 + 分页）用弹窗承载；简单单选在字段内联下拉。

## 7. 多选与标签折叠 <a id="multiple"></a>

| 项 | 设计 |
| --- | --- |
| 标签展示 | `collapse-tags` + `collapse-tags-tooltip`；超过 N 个折叠为「张三 +3」 |
| 上限 | `limit` 超出提示「最多选择 N 人」 |
| 去重 | 同一 id 不重复添加 |
| 清空 | 支持一键清空（`clearable`） |

## 8. 只读回显与列表渲染 <a id="readonly"></a>

- 只读回显：显示人员/岗位**名称**（由已选对象或 id 批量解析得出），人员可显示「昵称（用户名）」。
- 列表列：主办人/负责人列显示名称；多人以「、」分隔，超长折叠。
- 节点/人员已删除或停用：回退展示 `id` 并加「已删除」标记。

## 9. 查询区筛选协作 <a id="filter"></a>

- 列表页查询区「负责人」「岗位」等用本组件；与部门树筛选（05）联动（先部门后人员）。
- 提交参数按后端约定（`owner_id`、`post_id`、`dept_id`）；查询变化回第 1 页、保留筛选（`useListPage`，见 19 请求封装）。

## 11. 性能与大数据量 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 远程搜索 | 300ms 防抖 + 每次请求带 `keyword`，下拉限制条数，避免全量拉取 |
| 已选回填 | 按 id 批量请求（一次拿多条），避免 N 次单查 |
| 缓存 | 关键词结果短缓存 + 已选对象常驻内存 |
| 大组织 | 按部门过滤缩小范围；下拉虚拟滚动（人员众多时） |
| 首屏 | 未展开/不可见时不请求；已有 `modelValue` 时才触发回填请求 |

## 12. 字段权限 / i18n / 移动端 <a id="cooperate"></a>

- **字段权限**：`visible=false` 不渲染（避免无谓请求）；`editable=false` 传 `disabled`（见 20 权限指令）；人员数据可见范围由后端按数据权限过滤。
- **i18n**：占位、「最多选择 N 人」等走 vue-i18n；人员昵称/岗位名称按后端 locale 下发。
- **移动端**：frontend-mobile 用 Vant 选择器 + 弹层搜索，数据源与回填口径同源，不复用 PC 组件。

## 13. 检查清单 <a id="checklist"></a>

- □ 受控组件 + `change` / `select`；单选/多选、上限、去重、清空
- □ 远程搜索 300ms 防抖、下拉限条数、关键词缓存；不展开不请求
- □ 编辑/详情态按 id 批量回填名称；已删除/停用回退 id 并标记
- □ 支持按部门过滤（联动 05 树数据，`include_children`）
- □ 人员脱敏展示，`data:plain` 看明文
- □ 标签折叠（collapse-tags）、超长展示规则统一
- □ 查询区提交参数与列表接口一致，变化回第 1 页、保留筛选
- □ 字段权限与移动端口径符合第 12 节
