## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**水印能力**的组件设计：统一**水印注入**——页面区域与导出内容叠加**用户 / 租户信息**水印（涉密防泄漏）；供 [展示类「水印」](../../../07_展示类/14_组件设计_水印/14_组件设计_水印.md)（组件形态）、[交互类「打印与导出PDF」](../../../08_交互类/19_组件设计_打印与导出PDF/19_组件设计_打印与导出PDF.md) 与敏感页面共用。它是基础组件类中的「水印能力」，是继承链上**能力层**的一层（能力即继承链上的层）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 能力核心 | 水印内容组装与显示状态：内容组装 / 显隐；契约语义：注入 / 移除 / 更新 / 生成水印图片（绘制 / 注入由渲染插件承担） |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 水印内容 | 默认：姓名 + 工号 / 手机号 + 租户名 + 日期（可覆盖为多行文本） |
| 透明度 | 默认 0.15（0-1） |
| 旋转 | 默认 -20 度 |
| 间距 | 水印间距（密度；默认 180 / 120） |
| 字号 | 默认 14 |
| 防移除 | 默认开启（水印层被删 / 样式被篡改时重建） |
| 注入 | 注入水印（元素级 / 页面级）；返回句柄 |
| 移除 | 移除水印（卸载 / 权限放开后） |
| 更新 | 更新内容或样式（用户切换后） |
| 生成水印图片 | 生成水印图片（供导出 / 打印注入） |

## 4. 行为与分层关系 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 内容组装 | 默认组装当前用户（姓名 / 工号）+ 租户名 + 日期；可覆盖；**不引入敏感信息超范围**（与安全口径一致） |
| 生成方式 | 平铺图案生成 → 背景图（性能好、无 DOM 逐块；渲染插件侧实现）；旋转 / 间距 / 透明度参数化 |
| 防移除 | 开启时监视水印层被删除 / 样式篡改并重建（渲染插件侧实现；提高摘除成本，不承诺绝对防） |
| 范围 | 页面级（根容器）或区域级（敏感卡片）；导出 / 打印经水印图片注入 |
| 释放 | 观察者 / 句柄登记[异步资源基类](../../01_机制基类/05_组件设计_异步资源基类/05_组件设计_异步资源基类.md)（组件卸载自动移除，渲染插件侧） |
| 依赖方向 | 只依赖 组件根 / 机制基类（能力层依赖登记为空；用户 / 租户信息经调用方注入协作）；被页面与导出流程组合消费；能力在继承链上、依赖单向 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 敏感页面 | 员工信息 / 薪资 / 审计页面页面级水印（防拍照泄露威慑） |
| 导出 PDF / Excel | 导出内容叠加水印（水印图片注入页眉 / 背景） |
| 打印 | 打印件水印（与打印样式协作） |
| 区域水印 | 文件预览 / 图表卡区域级水印 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：水印是否启用可由页面 / 权限决定；本能力不判权。
- **i18n**：水印内容中的"日期 / 租户名"按当前语言格式化（语言上下文能力协作）。
- **移动端**：移动端渲染插件为同一契约的另一实现（同一套契约断言保障）；能力语义一致（密度参数按端调整）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 生成 | 平铺图案一次生成（不逐块 DOM）；参数变化才重生成 |
| 边界 | 水印被移除（防移除重建）、打印样式差异、导出时高度不足（平铺）、深色背景可读性、内容过长溢出 |
| 不支持 | 组件视觉壳（展示类「水印」）、导出流程（打印导出）、权限判定 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：水印内容 / 透明度 / 旋转 / 间距 / 字号 / 防移除 + 注入 / 移除 / 更新 / 生成水印图片
- □ 行为：内容组装不超范围、平铺图案生成、防移除重建、导出注入、卸载自动移除
- □ 被敏感页面 / 导出流程组合消费；能力为继承链上的一层、依赖单向
- □ 权限 / i18n / 移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
