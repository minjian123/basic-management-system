## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**容器能力**的组件设计：为**布局容器/区域类组件**（卡片、面板、分区、折叠面板、分栏、抽屉内容容器等）提供通用形态——标题/工具栏/页脚插槽、折叠展开、分栏、区域与内边距令牌。它是组件设计体系**能力（继承链上的一层）**，继承[组件根基类](../../01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 容器能力核心 | 容器形态语义：折叠状态、区域语义（标题/工具栏/页脚/分栏/内边距） |
| 组件包装（按需） | 容器渲染：标题区/工具区/内容区/页脚与折叠交互，按需提供 |
| 能力内聚件（按需） | 折叠触发与空态等内聚件（按需） |

- **继承方式**：能力是**继承链上的一层**（组件根之上、域基类与具体组件之下）；上层经继承取得能力语义，不在链外自由挂接（口径见[《前端开发规范》](../../../../../规范/前端开发规范.md)「架构铁律」与「前端基类体系」节）。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 标题 | 区域标题（i18n）；可被头部插槽替代 |
| 可折叠 | 可折叠开关；折叠态可受控，折叠变化对外通知 |
| 边框 | 是否显示边框（默认显示） |
| 内边距 | `none` / `small` / `default` / `large` 四态（令牌） |
| 分栏 | 内部栅格列数（默认 1） |
| 插槽 | 头部（替代标题）、工具栏（右上工具区）、默认内容、页脚、空态 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 插槽 | 标题/工具栏/页脚/内容/空态；工具栏右对齐 |
| 折叠 | 折叠仅隐藏内容，标题与工具栏保留；状态可持久化（按需） |
| 分栏 | 内部栅格；响应式断点由使用方或 表单容器能力 控制 |
| 令牌 | 背景/边框/圆角/内边距只消费令牌 |
| 嵌套 | 支持容器嵌套；避免过深（建议 ≤3 层） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：容器不做权限判定；区域内动作按动作权限显示。
- **i18n**：标题/占位经全局语言能力取词。
- **移动端**：PC 与移动端为同一契约的多实现（同一套契约断言保障）；窄屏单栏、内边距令牌适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠态不渲染内容（按需缓存可配） |
| 边界 | 嵌套过深、折叠状态持久化冲突、分栏与断点冲突、插槽缺失、内边距令牌缺失回退 |
| 不支持 | 表单语义（表单容器能力）、弹窗外壳（弹窗抽屉表单）、权限 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：标题/可折叠/折叠态/边框/内边距/分栏
- □ 插槽：头部/工具栏/默认/页脚/空态；折叠与分栏；令牌消费
- □ 与 表单容器能力、弹窗抽屉表单 边界清晰
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
