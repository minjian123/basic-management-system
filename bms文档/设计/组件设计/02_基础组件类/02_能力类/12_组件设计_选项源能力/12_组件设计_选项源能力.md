## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**选项源能力**的组件设计：为**依赖远程选项的字段**（[字典字段](../../../06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)、[组织选择字段](../../../06_字段类/05_组件设计_组织选择字段/05_组件设计_组织选择字段.md)、[开关与枚举字段](../../../06_字段类/08_组件设计_开关与枚举字段/08_组件设计_开关与枚举字段.md)、[树选择字段](../../../06_字段类/04_组件设计_树选择字段/04_组件设计_树选择字段.md)、[级联选择](../../../06_字段类/12_组件设计_级联选择/12_组件设计_级联选择.md)）提供统一的**选项加载、缓存与版本比对、搜索、回显**能力。它是组件设计体系**继承链上的能力域基类**，依赖受控值能力（单向、登记校验）、与字段编排能力协作；继承 [组件根基类](../../01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 选项源能力核心 | 选项源：加载 / 搜索 / 单值与批量回显 / 缓存失效；缓存与版本比对；占位降级 |
| 组件包装（按需） | 包装形态按需评估（能力核心 + 组件包装两层） |

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 数据源 | 数据源标识（字典类型编码 / 接口别名 / 枚举名） |
| 模式 | 远程 / 静态（静态由调用方直接提供选项） |
| 搜索 | 可开启关键字搜索（远程搜索 / 本地过滤） |
| 选项字段 | 选项值 / 选项文本字段可指定（默认 `value` / `label`） |
| 级联 | 父子联动加载（不用于树，树见树数据能力） |
| 缓存 | 按数据源 + 版本号缓存（可关闭） |
| 回显 | 单值回显（列表 / 只读场景）与批量回显（优先批量接口） |
| 失效 | 使缓存失效（字典更新 / 版本号变化） |
| 占位与错误 | 占位文案（i18n）；加载失败信息（降级展示） |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 缓存与版本比对 | 按数据源缓存选项 + 版本号；请求带版本号，**未变化命中缓存**（防重复、防击穿，复用数据架构三防口径） |
| 批量回显 | 列表场景优先批量接口（一次取多值标签），避免 N+1；批量回显为统一入口 |
| 搜索 | 可搜索时远程搜索（防抖 + 竞态取消，取消登记[异步资源基类](../../01_机制基类/05_组件设计_异步资源基类/05_组件设计_异步资源基类.md)）；小数据量本地过滤 |
| 占位降级 | 后端字典 / 组织接口未就绪时按**占位语义**：不请求（或返回空结果）、下拉禁用或空态提示；接入后无需改调用方（对齐[占位基类](../../01_机制基类/04_组件设计_占位基类/04_组件设计_占位基类.md)） |
| 级联 | 按父值加载子级（省市区 / 分类）；懒加载与缓存按父值分键 |
| 释放 | 在途请求经异步资源登记，卸载 / 切换自动取消（防竞态写入） |
| 依赖方向 | 只依赖 组件根 / 中间层基类 / 受控值能力（单向登记）；不依赖具体字段组件；字段组件组合消费本能力 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 字典字段 | 数据源为字典类型：下拉选项、只读回显（标签） |
| 组织选择字段 | 数据源为组织接口：下拉 / 树（树数据能力提供树语义） |
| 开关与枚举字段 | 数据源为枚举名：静态或远程枚举映射 |
| 级联选择 | 开启级联：省市区 / 分类多级联动 |
| 列表批量回显 | 表格列显示字典标签：批量接口一次回显 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：选项范围由后端按权限 / 数据范围过滤；前端不二次过滤（敏感选项不下发）。
- **i18n**：选项 label 由接口按 locale 下发；空态 / 加载文案走全局语言能力。
- **移动端**：移动端为同一契约的另一实现（同一套契约断言保障），选项源语义一致（触控选择器）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 缓存 | 同屏同数据源只请求一次；版本未变化命中缓存；列表用批量回显 |
| 搜索 | 远程搜索防抖 + 竞态取消；避免每键入一字符一次请求 |
| 边界 | 缓存与字典更新不同步（版本号兜底）、回显缺失值（显示原 code / 占位）、级联父值变化未清子值、占位与真实切换 |
| 不支持 | 树语义（树数据能力）、字段外观（字段壳）、权限判定 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：数据源 / 远程或静态 / 可搜索 / 选项值键 / 选项文本键 / 级联 / 缓存 + 加载 / 搜索 / 单值与批量回显 / 失效
- □ 行为：缓存与版本比对、批量回显优先、搜索防抖与竞态取消、占位降级不请求、释放走异步资源
- □ 依赖方向单向（不依赖具体字段组件）；字段组件组合消费本能力
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
