## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**媒体能力**的组件设计：为**图片/音视频/文件预览类组件**提供通用能力——加载态、占位、失败回退、宽高比、懒加载、预签名失效重取与降级下载。它是继承链上的**媒体组件基类**（父基类 尺寸能力基类，被上位基类继承、由具体组件实现；落点见《[前端基类清单](../../../../../前端基类清单.md)》§2.1），依赖预签名能力（单向）。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 媒体能力核心 | 媒体形态语义：加载状态机、占位、失败回退、宽高比、懒加载、预签名重取 |
| 组件包装（按需） | 媒体渲染：占位/骨架、失败态与重试、降级入口，按需提供 |
| 能力内聚件（按需） | 占位与失败态插槽等内聚件（按需） |

- **继承方式**：本基类是**继承链上的媒体组件基类**（父基类 尺寸能力基类）；上位经继承取得其语义、不在链外自由挂接（父基类与落点见《[前端基类清单](../../../../../前端基类清单.md)》§2.1；口径见[《前端开发规范》](../../../../../规范/前端开发规范.md)「架构铁律」与 §3.4）。
- **依赖关系**：依赖预签名能力（失效重取），方向单向，经登记表显式声明。

## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 媒体地址 | 媒体地址（可能是预签名 URL） |
| 宽高比 | 宽高比（如 `16/9`），保持布局稳定 |
| 懒加载 | 默认开启：进入视口再加载 |
| 填充方式 | `fill` / `contain` / `cover` 三态（默认 `cover`） |
| 失败回退 | 失败回退图/占位（可选） |
| 预签名重取 | 预签名 URL 失效时自动重取（默认开启） |
| 事件语义 | 加载成功/失败对外通知；预签名失效在重取前通知 |
| 插槽 | 占位/骨架、失败态 |

## 4. 行为语义 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 加载状态机 | 加载中 → 已加载 / 失败（`loading` → `loaded` / `error`）；失败显示失败态并可重试 |
| 占位 | 骨架/占位色；按宽高比保持布局稳定（避免抖动） |
| 预签名 | 加载失败且开启重取时触发失效通知 → 经预签名能力重取地址后重试一次；仍失败显示失败态 |
| 懒加载 | 进入视口再加载（视口观察在渲染实现侧，本能力承载状态机） |
| 令牌 | 占位色/圆角/尺寸只消费令牌 |
| 降级 | 不支持的类型/加载失败可降级为下载（由使用方决定） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：媒体可见性由数据范围/字段权限与预签名授权决定；本能力不判权限。
- **i18n**：失败提示经全局语言能力取词，不内嵌文案。
- **移动端**：PC 与移动端为同一契约的多实现（同一套契约断言保障）；手势缩放由移动端预览细化。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 加载 | 懒加载 + 宽高比占位防抖动；失败重试一次 |
| 边界 | 预签名过期、跨域、大文件、并发重取、失败回退缺失、类型不支持、无网 |
| 不支持 | 上传（字段类「文件上传字段」）、预览类型分发/交互（展示类「文件预览」）、存储与签名（[《概要设计 · 文件管理》](../../../../概要设计/13_概要设计_文件管理.md)） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：媒体地址/宽高比/懒加载/填充方式/失败回退/预签名重取；加载/失败/失效事件
- □ 状态机：加载中→已加载/失败；占位防抖动；预签名失效重取一次；降级下载
- □ 令牌消费；懒加载；占位/失败插槽
- □ 与 文件上传字段、展示类「文件预览」 边界清晰
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
