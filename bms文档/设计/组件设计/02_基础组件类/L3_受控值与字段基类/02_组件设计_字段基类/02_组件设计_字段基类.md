## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**字段基类**的组件设计：`BaseField` 与 `useFieldMeta`，在 [L3-01 受控值基类](../01_组件设计_受控值基类/01_组件设计_受控值基类.md) 的**值语义**之上提供**表单字段语义**——字段上下文（label/必填/错误，来自 [L3-03 字段壳基类](../03_组件设计_字段壳基类/03_组件设计_字段壳基类.md)）、字段权限（`visible`/`editable`，来自 [L3-04 字段权限基类](../04_组件设计_字段权限基类/04_组件设计_字段权限基类.md)）、校验触发、`fieldKey`。它是组件设计体系 **L3 承前启后层第 2 篇**，**组合** `BaseFieldShell` + `BaseFieldPerm`。

## 3. 契约（Props 与方法） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `fieldKey` | string | '' | 字段标识（上下文注册、错误定位、元数据读取） |
| `label` | string | '' | 字段标签（经字段壳；也可由元数据下发） |
| `required` | boolean \| 'auto' | 'auto' | 必填（`'auto'` 由字段属性/规则推导） |
| `help` | string | '' | 帮助说明 |
| `span` | number | 1 | 栅格跨度 |
| `modelValue` | any | `undefined` | 值（继承 L3-01 归一/三态） |

| 事件 / 方法 | 说明 |
| --- | --- |
| `change` | 值变化（继承 L3-01） |
| `validate` | 触发/转发校验结果 |
| `fieldContext` | 暴露给控件（provide/inject）：`readonly`/`disabled`/`required`/`error` |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 字段上下文 | 由 L3-03 字段壳 `provide`，本层注入并转发给控件（label/占位/必填/错误） |
| 字段权限 | 由 L3-04 判定：`visible=false` 整壳不渲染；`editable=false` 合并 `disabled`；`required`/脱敏按元数据 |
| 校验触发 | 值变化触发字段校验并回传上下文；提交时由表单容器 `validate` 汇总 |
| `fieldKey` | 挂载注册、卸载注销；未提供时降级为匿名字段 |
| 依赖方向 | 组合 L3-01/L3-03/L3-04；被 L4-01 继承；不依赖具体控件 |

## 5. 场景集成 <a id="scenes"></a>

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：字段权限由 [L3-04](../04_组件设计_字段权限基类/04_组件设计_字段权限基类.md) 判定；本层只负责应用（不渲染/传 disabled）。
- **i18n**：label/help 由元数据按 locale 下发。
- **移动端**：字段语义同款，单列渲染。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 上下文 | 注册/注销 O(1)；避免逐字段重复读元数据 |
| 边界 | `fieldKey` 缺失/重复、`visible` 与栅格收缩、`editable` 被绕过（后端拒绝）、必填与三态、脱敏与复制 |
| 不支持 | 值语义（L3-01）、壳/权限细节（L3-03/L3-04）、域细化（L4）、元数据取数（13） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`fieldKey`/`label`/`required`/`help`/`span` + `change`/`validate`/`fieldContext`
- □ 组合字段壳（L3-03）与字段权限（L3-04）；值语义继承 L3-01
- □ 校验触发与上下文注册；依赖方向单向
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
