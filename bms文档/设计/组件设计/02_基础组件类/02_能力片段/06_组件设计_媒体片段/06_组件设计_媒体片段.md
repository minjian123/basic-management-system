## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/packages/*`（核心 `frontend/packages/core` + 按需的 Vue 投影 `frontend/packages/vue`；渲染插件 `ui-ep` / `ui-vant` 按需）**媒体能力（原「媒体片段」）**的组件设计：核心能力类 `BaseMedia`（`frontend/packages/core/src/capabilities/media.ts`，登记 `capabilities/manifest.ts`；`depends: presigned-url`）（+ 按需的 Vue 投影），为**图片/音视频/文件预览类组件**提供通用能力——加载态、占位、失败回退、宽高比、懒加载、预签名 URL 失效重取与降级下载。它是组件设计体系**能力**，继承 [组件根基类](../../01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)。

| 组件 / 工具 | 位置 | 职责 |

> **实现口径（2026-09-17，新体系）**：原「媒体片段」（旧 `useMedia` 组合式）已类化为核心能力类 `BaseMedia`（`frontend/packages/core/src/capabilities/media.ts`，继承 `BaseCapability`，登记 `capabilities/manifest.ts`；依赖 `presigned-url` 单向下沉）；本能力暂无 Vue 投影（按需回补，`useXxx` 只落 `frontend/packages/vue/src/bindings/`），`BaseMedia.vue` 组件包装为按需形态（历史未落码）；旧片段实现（原 `useXxx` 组合式）已随旧层删除（历史经 git 追溯）。`depends` 由能力机制开发态校验（单向、无循环）；契约语义（Props / 事件 / 插槽 / 行为规则）保持不变。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `src` | string | '' | 媒体地址（可能是预签名 URL） |
| `ratio` | number \| string | '' | 宽高比（如 `16/9`） |
| `lazy` | boolean | true | 懒加载 |
| `fit` | 'fill' \| 'contain' \| 'cover' | 'cover' | 填充方式 |
| `fallback` | string | '' | 失败回退图（可选） |
| `retryOnExpired` | boolean | true | 预签名 URL 失效时自动重取 |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `load` / `error` | event | 加载成功/失败 |
| `expired` | — | 预签名失效（重取前） |

- 具名插槽：`placeholder`（占位/骨架）、`error`（失败态）。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 加载状态机 | loading → loaded / error；`error` 显示失败态并可重试 |
| 占位 | 骨架/占位色；`ratio` 保持布局稳定（避免抖动） |
| 预签名 | 加载失败且 `retryOnExpired` 时触发 `expired` → 经依赖能力 `presigned-url`（`BasePresignedUrl`）重取 URL 后重试一次；仍失败显示失败态 |
| 懒加载 | 进入视口再加载（视口观察由渲染插件实现，核心只承载状态机） |
| 令牌 | 占位色/圆角/尺寸只消费令牌 |
| 降级 | 不支持的类型/加载失败可降级为下载（由使用方决定） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：媒体可见性由数据范围/字段权限与预签名授权决定；本能力不判权限。
- **i18n**：失败提示经 根系 `t`。
- **移动端**：`ui-vant` 为同一契约的另一实现（契约套件同一套断言）；手势缩放由移动端预览细化。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 加载 | 懒加载 + 宽高比占位防抖动；失败重试一次 |
| 边界 | 预签名过期、跨域、大文件、并发重取、失败回退缺失、类型不支持、无网 |
| 不支持 | 上传（06）、预览类型分发/交互（展示类「文件预览」）、存储与签名（概要 13） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`src`/`ratio`/`lazy`/`fit`/`fallback`/`retryOnExpired` + load/error/expired
- □ 状态机：loading→loaded/error；占位防抖动；预签名失效重取一次；降级下载
- □ 令牌消费；懒加载；占位/失败插槽
- □ 与 文件上传字段、展示类「文件预览」 边界清晰
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
