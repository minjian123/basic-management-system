## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/packages/*`（核心 `frontend/packages/core` + Vue 投影 `frontend/packages/vue`；渲染插件 `ui-ep` / `ui-vant` 按需）**容器能力（原「容器片段」）**的组件设计：核心能力类 `BaseContainer`（`frontend/packages/core/src/capabilities/container.ts`，登记 `capabilities/manifest.ts`）+ 投影 `useContainer`，为**布局容器/区域类组件**（卡片、面板、分区、折叠面板、分栏、抽屉内容容器等）提供通用形态——标题/工具栏/页脚插槽、折叠展开、分栏、区域与内边距令牌。它是组件设计体系**能力**，继承 [组件根基类](../../01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `BaseContainer`（核心能力类，key `container`） | `frontend/packages/core/src/capabilities/container.ts`（登记 `capabilities/manifest.ts`） | 容器形态：折叠状态机、区域语义（插槽/分栏/区域令牌由绑定与渲染插件承担） |
| `useContainer`（Vue 投影） | `frontend/packages/vue/src/bindings/useContainer.ts` | 核心 `BaseContainer` ↔ Vue 响应式：受控折叠（`isControlled` / `onCollapseChange`）、`containerAttrs`、插槽判定；不重复实现能力逻辑 |
| `BaseContainer.vue`（可选组件包装） | 按需形态（历史未落码） | 按需随回补波按「核心类 + 投影（+ 插件包装）」重建 |

> **实现口径（2026-09-17，新体系）**：原「容器片段」（旧 `useContainer` 组合式）已类化为核心能力类 `BaseContainer`（`frontend/packages/core/src/capabilities/container.ts`，继承 `BaseCapability`，登记 `capabilities/manifest.ts`）+ Vue 投影 `useContainer`（`frontend/packages/vue/src/bindings/useContainer.ts`，`useXxx` 只存在于此）；`BaseContainer.vue` 组件包装为按需形态（历史未落码）；旧片段实现（原 `useXxx` 组合式）已随旧层删除（历史经 git 追溯）。`depends` 由能力机制开发态校验（单向、无循环）；契约语义（Props / 事件 / 插槽 / 行为规则）保持不变。

## 3. 契约（Props 与事件） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 区域标题（i18n） |
| `collapsible` | boolean | false | 可折叠 |
| `collapsed` | boolean | false | 折叠态（v-model:collapsed） |
| `bordered` | boolean | true | 是否显示边框 |
| `padding` | 'none' \| 'small' \| 'default' \| 'large' | 'default' | 内边距（令牌） |
| `columns` | number | 1 | 分栏数（内部栅格） |

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| `update:collapsed` | boolean | 折叠变化 |
| `collapse-change` | boolean | 折叠事件 |

- 具名插槽：`header`（替代标题）、`toolbar`（右上工具区）、`default`（内容）、`footer`、`empty`。

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 插槽 | 标题/工具栏/页脚/内容/空态；工具栏右对齐 |
| 折叠 | 折叠仅隐藏内容，标题与工具栏保留；状态可持久化（按需） |
| 分栏 | `columns` 内部栅格；响应式断点由使用方或 表单容器能力 控制 |
| 令牌 | 背景/边框/圆角/内边距只消费令牌 |
| 嵌套 | 支持容器嵌套；避免过深（建议 ≤3 层） |

## 5. 场景集成 <a id="scenes"></a>

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：容器不做权限判定；区域内动作按动作权限显示。
- **i18n**：标题/占位经 根系 `t`。
- **移动端**：`ui-vant` 为同一契约的另一实现（契约套件同一套断言）；窄屏单栏、内边距令牌适配。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 折叠态不渲染内容（按需 keep 可配） |
| 边界 | 嵌套过深、折叠状态持久化冲突、分栏与断点冲突、插槽缺失、内边距令牌缺失回退 |
| 不支持 | 表单语义（表单容器能力）、弹窗外壳（弹窗抽屉表单）、权限 |

## 9. 检查清单 <a id="checklist"></a>

- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
