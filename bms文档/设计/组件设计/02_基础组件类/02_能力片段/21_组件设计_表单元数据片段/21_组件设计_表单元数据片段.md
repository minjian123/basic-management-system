## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**表单元数据片段**的组件设计：`useFormMeta`（能力片段，对外契约）。它是组件设计体系**能力片段「表单元数据片段」**，承载**菜单下发的表单元数据**（字段列表、类型、校验、布局、权限属性）的**加载、缓存与版本比对**；供 [交互类「表单渲染器」](../../../08_交互类/12_组件设计_表单渲染器/12_组件设计_表单渲染器.md) 与[交互类「表单设计器」](../../../08_交互类/05_组件设计_表单设计器/05_组件设计_表单设计器.md) 共用。

## 3. 契约（参数与方法） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `menuKey` | string | 必填 | 菜单 / 表单标识（元数据键） |
| `cache` | boolean | true | 是否缓存（按 menuKey + 版本号） |
| `fallbackToDefault` | boolean | true | 元数据缺失时回退默认渲染（由渲染器实现） |

| 状态 / 方法 | 说明 |
| --- | --- |
| `meta` | 元数据（字段列表 / 布局 / 分组 / 权限属性；响应式） |
| `version` | 当前元数据版本号（比对用） |
| `loading` / `error` | 加载态与错误（降级展示） |
| `load(menuKey)` | 加载（带版本号请求；未变化命中缓存） |
| `refresh(payload?)` | 强制刷新（设计态保存后；可传新元数据直接更新） |
| `get(menuKey)` | 同步读缓存（已加载时零等待） |
| `invalidate(menuKey?)` | 失效（设计器保存 / 菜单变更后） |

## 4. 行为与实现约定 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 版本比对 | 请求带当前版本号；服务端返回 `not-modified` 或新版本；未变化命中缓存（与选项源片段同口径） |
| 缓存 | 按 `menuKey` 缓存元数据；跨页面复用（同一菜单多入口）；`invalidate` 主动失效 |
| 归一 | 元数据字段结构归一（`type` / `key` / `label` / `rules` / `props` / `perm` / `layout`），供渲染器直接消费 |
| 设计态 | 设计器保存成功后 `refresh(newMeta)` 直接更新缓存（不需额外请求）；发布后其他端靠版本号拉新 |
| 降级 | 元数据接口未就绪时按占位语义：空元数据 + 提示；渲染器回退静态字段（如开发期） |
| 释放 | 在途请求登记[异步资源基类](../../01_机制基类/05_组件设计_异步资源基类/05_组件设计_异步资源基类.md) |
| 依赖方向 | 只依赖 组件根 / 机制基类；被渲染器 / 设计器消费；不依赖具体字段组件 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 表单渲染器 | 按 `meta.fields` 渲染字段（类型 → 控件经注册表）、校验、布局、权限属性 |
| 表单设计器 | 读取 / 保存元数据（设计态刷新） |
| 动态表单页 | 同一页面按菜单 key 加载不同元数据（多租户定制差异） |
| 字段权限 | 元数据中的权限属性与[字段权限片段](../11_组件设计_字段权限片段/11_组件设计_字段权限片段.md)协作（visible / editable / required） |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：元数据按菜单权限下发（无权限菜单不返回）；字段权限属性由[字段权限片段](../11_组件设计_字段权限片段/11_组件设计_字段权限片段.md)消费。
- **i18n**：字段 label 由元数据（含 locale）下发；渲染器不翻译业务字段。
- **移动端**：独立工程，同一元数据可渲染不同布局（由端内渲染器决定）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 缓存 | 按 menuKey 缓存 + 版本比对；同菜单多入口只请求一次 |
| 边界 | 元数据版本不同步、字段类型未注册（降级提示）、设计态与发布态混用、缓存过期、多租户元数据差异 |
| 不支持 | 字段渲染（表单渲染器）、设计态编辑（表单设计器）、字段权限判定（字段权限片段） |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约：`menuKey`/`cache`/`fallbackToDefault` + `load`/`refresh`/`get`/`invalidate` + `meta`/`version`
