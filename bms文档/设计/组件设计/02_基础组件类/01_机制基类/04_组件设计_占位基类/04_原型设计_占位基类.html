本原型对应当前目录 《组件设计 · 占位基类》：演示占位标记与 describe、三类占位原因（待实现 / 空实现 / 未实现）与空态·禁用·降级三种降级语义；占位态不请求。
reason： pending 待实现 null 空实现 stub 未实现 degrade： empty 空态 disabled 禁用 hidden 隐藏
组织选择字段 ← 占位态不发起请求
调用占位 API 调用 resolve() {{ callResult }}
describe() → {{ describeText }} 属性：data-placeholder="{{ reason }}"（开发态标记，silentInProd 时生产静默） 降级：{{ degradeText }} 说明：pending＝依赖后端能力未就绪（空结果 / 降级）；null＝空实现（恒空 / 恒成功、无副作用）； stub＝未实现（调用即抛错，对齐后端 BaseStub）；占位与真实实现跑同一套契约测试。
