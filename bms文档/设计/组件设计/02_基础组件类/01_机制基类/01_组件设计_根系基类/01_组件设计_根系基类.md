## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**总基类（原根系基类）**的组件设计：为**一切前端基类**（组件根、插件基类、公共基类、能力基类、契约与数据对象基类、工厂基类、错误基座）提供**通用字段与通用方法**。它是继承链的**总基类 总基类**（一切基类之根，与后端根系 根基类 总基类 同名同职责）；继承链的完整父子关系见《[前端基类清单](../../../../../前端基类清单.md)》（**全系统唯一一份**），强制口径见[《前端开发规范》](../../../../../规范/前端开发规范.md)第 3 节「前端基类体系（强制）」。

### 1.1 定位与继承链位置 <a id="positioning"></a>

```mermaid
flowchart TD
    OBJ["总基类（一切前端基类之根）"] --> CAP["能力域基类（能力键 / 依赖登记）"]
    CAP --> PLG["插件基类（实现名 / 契约版本 / 注册与解析 / 生命周期）"]
    PLG --> COMP["组件根（UI 通用协议）"]
    COMP --> AB["能力基类（横切功能）"]
    AB --> CB["组件基类（各组件族）"]
    PLG --> REG["统一注册表基座 / 工厂基类"]
    OBJ --> RT["资源 / 占位 / 错误基座"]
    OBJ --> CT["契约 / 数据对象基类"]
```

| 职责 | 归属 |
| --- | --- |
| 所有基类共有的通用字段 / 方法（日志、错误上报、配置 / 环境、i18n 取词、生命周期钩子） | **本节点（总基类 总基类）** |
| 契约 / 数据对象基类（实体、分页查询、模块 API） | 契约节点 + 宿主实现（落点与状态见《[前端基类清单](../../../../../前端基类清单.md)》§6） |
| UI 组件公共能力（透传、尺寸/密度/主题、i18n、可访问性、加载/禁用…） | [组件根基类](../../01_机制基类/02_组件设计_组件根基类/02_组件设计_组件根基类.md) |
| 能力基类（值 / 字段 / 输入 / 展示 / 树 …）与组件基类 | 能力基类节点（详见[总览](../../../01_组件设计_总览.md)路线图；父基类以《[前端基类清单](../../../../../前端基类清单.md)》§2.1 为准） |

上游依据：[《前端开发规范》](../../../../../规范/前端开发规范.md)（§3 分层权威、依赖方向与扩展规则）、[《架构设计 · 前端架构》](../../../../架构设计/08_架构设计_前端架构.md)（组件分层与目录）。

> 本篇为 **基础组件类 · 总基类**。**范围边界**：总基类只放「所有基类共有」的横切职责；数据 / UI 特有逻辑不得上提；横切功能见各能力基类节点，父基类关系以《[前端基类清单](../../../../../前端基类清单.md)》§2.1 为准。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 总基类核心 | 通用字段与通用方法（纯逻辑、框架无关） |
| 响应式投影（按需） | 核心实例与 Vue 响应式的桥接，提供等价的响应式入口；投影只做桥接，不重复实现 |
| 模板包装件（按需） | 模板层的包装形态，按需评估 |


## 3. 交互与契约语义 <a id="contract"></a>

| 语义项 | 说明 |
| --- | --- |
| 命名空间与实例标识 | 用于日志前缀、样式前缀、埋点域与错误上报定位 |
| 运行环境与配置 | 只读配置视图（按命名空间隔离）；配置缺失回退默认值 |
| 日志 | 统一日志（级别、命名空间、时间戳；生产分级） |
| 错误上报 | 统一上报（去重、限流；不阻断业务） |
| i18n 取词 | 委托全局语言能力（支持参数），不硬编码文案 |
| 生命周期钩子 | 创建 / 销毁钩子供子类扩展；子类通过覆写钩子接入，不直接改总基类行为 |

## 4. 继承与依赖关系 <a id="inherit"></a>

| 项 | 设计 |
| --- | --- |
| 派生关系 | **一切基类均继承总基类**（组件根、插件基类、公共基类、能力基类、契约 / 数据对象基类、工厂基类、错误基座）；父子关系以《[前端基类清单](../../../../../前端基类清单.md)》§2.1 为准 |
| 双入口等价 | 核心实现与投影能力等价；投影只做「核心实例 ↔ Vue 响应式」桥接，不重复实现 |
| 依赖方向 | 总基类只被其下位基类依赖，**不得依赖任何下位**；不得引用 UI、状态、业务 |
| 横切边界 | 只有「所有基类共有」的职责才进总基类；单侧（数据或 UI）特有逻辑不得上提 |
| 扩展 | 出现新的「所有基类共有」职责时增补总基类；出现「某一侧共有」职责时增补对应基类（组件根 / 插件基类 / 公共基类） |
| 多实现一致 | PC 与移动端按同一契约多实现，由同一套契约断言保障 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 契约 / 数据对象基类 | 继承总基类，取得日志 / 错误上报 / 配置读取 |
| 组件根 / 插件基类 | 继承总基类，再向公共基类与能力基类传递通用职责 |
| 具体组件 | 通过继承链获得日志 / 配置 / i18n，不各自实现 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：总基类不含权限判定（字段权限见[字段权限能力](../../02_能力类/11_组件设计_字段权限能力/11_组件设计_字段权限能力.md)，动作权限见[基础类「权限指令」](../../../09_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)）。
- **i18n**：取词委托全局语言能力，不硬编码文案。
- **移动端**：PC 与移动端按同一契约多实现（同一套契约断言保障）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 开销 | 总基类无渲染开销，纯逻辑；日志与上报分级、限流 |
| 边界 | 配置缺失（回退默认）、环境判断错误、日志风暴、错误上报重复、i18n 未就绪、命名空间冲突 |
| 不支持 | 契约 / 数据对象基类、UI 组件公共职责（组件根）、能力基类职责、权限判定 |

## 9. 检查清单 <a id="checklist"></a>

- □ 通用字段与通用方法齐备：命名空间 / 实例标识 / 运行环境 / 配置；日志 / 错误上报 / 配置读取 / i18n 取词 / 生命周期钩子
- □ 派生：**一切基类由总基类派生（零例外）**；依赖方向单向（总基类不依赖下位）
- □ 只放共有职责，不掺 UI / 业务 / 权限
- □ 核心实现与响应式投影能力等价；PC 与移动端同一契约多实现
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认：总基类契约、组件工程分包与目录、前端配置与环境
