## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端**图表域基类**的组件设计：图表域语义统一**图表实例生命周期**（按需加载 / 销毁）、**尺寸自适应**、**主题令牌适配**（亮暗 / 租户品牌）、**空数据占位**与加载态、导出。它是组件设计体系**图表域语义基类**，供 [展示类「图表卡」](../../../07_展示类/04_组件设计_图表卡/04_组件设计_图表卡.md)、[展示类「指标卡」](../../../07_展示类/10_组件设计_指标卡/10_组件设计_指标卡.md) 与[交互类「大屏设计器与播放」](../../../08_交互类/09_组件设计_大屏设计器与播放/09_组件设计_大屏设计器与播放.md) 共用。

## 2. 职责与组成 <a id="components"></a>

| 组成部分 | 职责 |
| --- | --- |
| 图表域语义（组件基类） | 容器与尺寸自适应、图表库按需加载、主题注入、空态/加载态（组件基类承载） |
| 域包装件 | 继承链上的域层包装（组件基类之上、具体组件之下）：容器 / 自适应、实例管理入口与对外事件，可被模板层消费 |
| 实例管理（按需） | 实例初始化 / 更新配置 / 重算尺寸（节流）/ 销毁（登记异步资源）/ 主题重建 |
| 导出协作 | 导出图片供打印 / 导出复用 |

- **继承方式**：组件基类是**继承链上的组件基类**（其上位基类之上、具体组件 / 件之下）；图表卡、指标卡与大屏图表经图表域派生取得公共行为语义，不在链外自由挂接（口径见[《前端开发规范》](../../../../../规范/前端开发规范.md)§1「架构铁律」与 §3.4）。

## 3. 交互与契约语义 <a id="props"></a>

| 语义项 | 说明 |
| --- | --- |
| 图表配置 | 系列 / 坐标轴 / 提示等配置（由使用方下发的配置对象） |
| 高度 | 图表高度（自动时随容器） |
| 主题模式 | 自动 / 亮色 / 暗色 三态；自动跟随全局亮暗与租户品牌令牌 |
| 尺寸自适应 | 容器尺寸变化自动重绘（监听 + 节流） |
| 加载态 | 加载骨架 / 加载指示（防抖） |
| 空数据 | 走占位语义，不初始化实例 |
| 渲染方式 | 画布 / 矢量 两种（大屏 / 多实例场景可选矢量） |
| 操作语义 | 更新配置（增量或全量）、手动重算尺寸（容器隐藏后显示需调用）、取实例（高级用法）、导出图片、销毁（组件卸载自动销毁） |
| 事件语义 | 就绪与交互事件（点击 / 图例变化等常用项透传） |

## 4. 基类行为 <a id="behavior"></a>

| 项 | 设计 |
| --- | --- |
| 按需加载 | 图表库与图表类型组件**异步加载**（独立分包，不进首屏）；加载期显示骨架 |
| 实例生命周期 | 容器可见时初始化（空数据 / 加载中不初始化）；销毁登记[异步资源基类](../../01_机制基类/05_组件设计_异步资源基类/05_组件设计_异步资源基类.md)，卸载自动销毁 |
| 尺寸自适应 | 监听容器尺寸变化（重绘节流，避免抖动）；容器隐藏时尺寸为 0 的守卫（显示后再重算尺寸） |
| 主题适配 | 亮暗 / 品牌切换时按令牌重建主题（颜色只取设计令牌，不硬编码色值）；主题模式可手动覆盖自动 |
| 空态 / 加载态 | 空数据走占位空态（不初始化实例）；加载骨架防抖 |
| 导出 | 导出图片供打印 / 导出复用（与打印导出组件协作） |
| 依赖方向 | 只依赖 展示形态能力 / 公共基类 / 组件根；被图表卡、指标卡、大屏消费，不反向依赖 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：图表数据由后端按数据范围过滤；前端不二次过滤。
- **i18n**：图表标题 / 图例文案由配置与数据下发；提示数值格式走格式化工具（按 locale）。
- **移动端**：PC 与移动端同一契约多实现（图表能力一致：触控缩放 / 响应式尺寸）。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 分包 | 图表库与图表类型异步加载、独立分包；首屏不含 |
| 多实例 | 大屏多图表实例：共享图表库模块、矢量渲染可选、懒初始化（进入视口再初始化） |
| 边界 | 容器隐藏尺寸 0、尺寸重绘抖动、主题切换残留旧色、空数据与加载态并置、实例未销毁泄漏 |
| 不支持 | 图表配置与取数（使用方）、空态视觉（展示类「异常与空状态」）、权限判定 |

## 9. 检查清单 <a id="checklist"></a>

- □ 契约语义：图表配置/高度/主题模式（自动·亮色·暗色）/尺寸自适应/加载态/空数据/渲染方式；更新配置、重算尺寸、导出、销毁与就绪·交互事件
- □ 行为：异步加载与骨架、卸载自动销毁（登记异步资源）、尺寸监听节流、主题令牌消费（不硬编码色值）、空数据不初始化实例
- □ 被图表卡 / 指标卡 / 大屏消费；依赖方向单向
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认
