## 1. 目的与适用范围 <a id="purpose"></a>

定义 BMS 前端 `frontend/`（`frontend-mobile/` 同款）**最基础组件基类**的组件设计：抽象类 `BaseComponent` 与组合式 `useComponentBase`，为**所有 UI 组件**（03 基础控件、04 字段类、05 展示类、06 交互类）提供公共能力——attrs 透传与根元素约定、尺寸/密度/主题令牌、i18n 与命名空间、生命周期与埋点、可访问性与 `expose`、通用 `loading`/`disabled`/显隐。它是组件设计体系 **L1b 层**，继承 [L0 总基类](../../L0_总基类/01_组件设计_总基类/01_组件设计_总基类.md)。

## 2. 组件清单与职责 <a id="components"></a>

| 组件 / 工具 | 位置 | 职责 |
| --- | --- | --- |
| `BaseComponent` | `src/base/l1b/BaseComponent.ts` | 抽象类：通用 props、根元素与 attrs 透传、尺寸/密度/主题、i18n/命名空间、生命周期埋点、可访问性、`expose` 规范 |

## 3. 契约（通用 Props 与能力） <a id="contract"></a>

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `size` | 'small' \| 'default' \| 'large' | 'default' | 尺寸（映射设计令牌） |
| `density` | 'compact' \| 'default' \| 'loose' | 继承 | 密度（表格/表单/用户偏好） |
| `ns` | string | '' | 命名空间（样式前缀、埋点域；缺省取应用级） |
| `loading` | boolean | false | 通用加载态（展示 loading 或禁用交互，按组件语义） |
| `disabled` | boolean | false | 通用禁用态 |
| `visible` | boolean | true | 通用显隐（`false` 时不渲染） |
| `dataTest` | string | '' | 测试标识（渲染为 `data-test`） |

| 能力 | 说明 |
| --- | --- |
| attrs 透传 | 未声明属性/事件透传根元素（`id`/`class`/`style`/`data-*`）；约定**单根元素** |
| 主题令牌 | 颜色/尺寸/间距只消费设计令牌，随亮暗与租户品牌自动适配（[06 交互类 20 主题与品牌化](../../../06_交互类/20_组件设计_主题与品牌化/20_组件设计_主题与品牌化.md)） |
| 命名空间/样式前缀 | class 前缀由 `ns` 派生（如 `bms-`），避免全局污染 |
| i18n | 通过 L0 `t` 取词，组件不硬编码文案 |
| 生命周期与埋点 | `onMounted`/`onUnmounted` 统一埋点钩子（曝光/点击按需） |
| 可访问性 | 根元素 `aria-*`、角色与键盘焦点基础约定（可交互组件继承 L2 交互基类细化） |
| `expose` 规范 | 统一通过 `defineExpose` 暴露公共方法（如 `focus`/`blur`/`validate`，按组件而定） |

- 事件：`base-mounted`/`base-unmounted`（可选）供埋点；具体组件事件另定义。

## 4. 继承与实现约定 <a id="inherit"></a>

| 项 | 设计 |
| --- | --- |
| 派生 | L2 六形态基类继承 L1b；L3_受控值与字段基类/L4 经 L2 间接继承 |
| 模拟继承 | 组合式 `useComponentBase()` + 组件包装；单根元素 + `inheritAttrs` |
| 依赖方向 | 只依赖 L0；不得依赖 L2-L4 或具体组件 |
| 令牌消费 | 不得硬编码色值/尺寸；密度/尺寸走令牌，主题切换自动生效 |
| 双端同款 | frontend 与 frontend-mobile 同步 |

## 5. 场景集成 <a id="scenes"></a>

| 场景 | 说明 |
| --- | --- |
| 所有 UI 组件 | 通过 L2-L4 继承链获得透传/尺寸/主题/i18n/可访问性 |
| 主题与品牌化 | 令牌消费使所有组件随主题/品牌变化 |
| 埋点与测试 | 生命周期钩子与 `data-test` 支撑埋点与自动化测试 |

## 7. 权限 / i18n / 移动端 <a id="cooperate"></a>

- **权限**：不做权限判定；字段权限见 [L3-04](../../L3_受控值与字段基类/04_组件设计_字段权限基类/04_组件设计_字段权限基类.md)，动作权限见 [07 基础类 02](../../../07_基础类/02_组件设计_权限指令/02_组件设计_权限指令.md)。
- **i18n**：统一经 L0 `t`；不硬编码。
- **移动端**：独立工程，能力同款。

## 8. 性能与边界 <a id="performance"></a>

| 场景 | 设计 |
| --- | --- |
| 渲染 | 基类薄；透传不产生额外包裹元素（单根） |
| 埋点 | 生命周期钩子按需启用，生产可关闭细粒度埋点 |
| 边界 | 多根元素透传冲突、attrs 与声明 props 冲突、命名空间缺失回退应用级、主题令牌缺失回退、密度上下文缺失、`visible=false` 与 v-show 混淆、expose 未声明 |
| 不支持 | 通用字段/方法（L0）、形态差异（L2）、值/字段语义（L3）、域细化（L4）、权限判定 |

## 9. 检查清单 <a id="checklist"></a>

- □ 通用 props：`size`/`density`/`ns`/`loading`/`disabled`/`visible`/`dataTest`
- □ attrs 透传与单根元素；命名空间/样式前缀；令牌消费（不硬编码色值/尺寸）
- □ i18n 经 L0；生命周期埋点与 `data-test`；可访问性与 `expose` 规范
- □ 继承 L0、被 L2 继承，依赖方向单向；双端同款
- □ 权限/i18n/移动端符合第 7 节；性能边界符合第 8 节
- □ 三项上游登记已确认：最基础组件基类契约、组件分层与目录、尺寸与密度令牌
