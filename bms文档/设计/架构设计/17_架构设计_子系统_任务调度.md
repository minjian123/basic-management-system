# 架构设计 · 子系统 · 任务调度

> BMS · 定时任务入库、调度器与执行

> **执行归口（2026-11-01 立项）**：任务调度的执行侧（队列、租约、进度、重试、取消、死信）已统一由[异步作业中心](40_架构设计_子系统_异步作业中心.md)承载；本节点只保留**任务定义、cron 计算、到期与手动触发**（“什么时候做”）。任务调度到期**生产作业**，由作业中心执行。

## 1. 概述 <a id="overview"></a>

任务调度子系统负责**任务定义与“什么时候做”**：任务定义入库（sys_task）、页面动态增删改与启停、手动触发、执行历史（sys_task_log）。任务到期后只**生产作业**，真正的执行、进度、重试、取消与死信统一归[异步作业中心](40_架构设计_子系统_异步作业中心.md)。对应[《项目规划说明》](../../规划/项目规划说明.md)的「定时任务」章节，覆盖任务调度模块。

## 2. 任务模型 <a id="model"></a>

- `sys_task`：code / name、handler（`module:attr` 执行体路径）、cron、args、status、next_run_at、last_run_at、remark
- `sys_task_log`：task_id、run_id、trigger_source、status（running/success/failed/**skipped**）、retry_count、cost_time、error_msg、started_at、finished_at；**保留为任务执行历史**，由作业终态同步写入
- 权限码：查询 task:query、维护与启停 task:manage、手动触发 task:trigger

## 3. 调度器设计 <a id="scheduler"></a>

- beat 单副本长驻：逐租户扫描到期任务，按 cron 计算 next_run，**条件 UPDATE 抢占**（`WHERE next_run_at <= now`，`rowcount = 1` 才算抢到）后**提交作业**（作业类型为任务型，负载带任务与执行记录标识）
- 单副本保障 = **数据库 CAS 抢占 + Redis 锁双保险**：锁（`bms:global:lock:beat`）只省扫描，正确性由 CAS 保证——锁在 TTL 边界 / 网络分区失效时第二个 beat 的 UPDATE 因 `rowcount = 0` 自动让行
- 变更热加载：任务 CRUD/启停 → Redis pub/sub **只做唤醒**（不持久、断线即丢），正确性由 `poll_interval` 周期轮询兜底，最多晚一个周期生效
- 任务调度与事件总线解耦（任务定义走数据库，事件走 RocketMQ）；**执行队列不再由本节点持有**，统一由作业中心按作业记录消费

## 4. 执行与重试（归异步作业中心） <a id="execution"></a>

- 任务的执行不再由本节点另起一套队列与 worker：到期任务提交为作业后，由[异步作业中心](40_架构设计_子系统_异步作业中心.md)按统一状态机抢占、续租、执行、重试与收尾。
- 任务执行记录（sys_task_log）保留为**任务维度的历史视图**：作业终态时同步写入状态、耗时与错误摘要，任务页面与既有查询口径不变；作业记录是执行事实源。
- 终止态（success / failed / **skipped**）与执行记录**同事务**写 `sys_outbox`，发 `sys.task.completed`（Webhook 默认不可订阅）；重试中间态不发事件。
- 任务执行超时、worker 失联、取消与死信统一按作业中心的租约与失败语义处理，本节点不再单独定义超时回收参数。

## 6. 与其他子系统的协调 <a id="coordination"></a>

- **[文件管理](20_架构设计_子系统_文件管理.md)**：孤儿分片回收由任务调度生产作业，文件服务注册作业执行
- **[异步作业中心](40_架构设计_子系统_异步作业中心.md)**：任务到期只生产作业；执行、进度、重试、取消、死信与监控归作业中心
- **[审计哈希链](19_架构设计_子系统_审计哈希链.md)**：日志归档任务执行前做链完整性校验
- **[部署与运维](33_架构设计_部署与运维.md)**：备份任务（sys_backup_task）与恢复演练登记由本子系统调度
- **[事件总线](16_架构设计_子系统_事件总线.md)**：任务完成落事件；与 RocketMQ 事件总线互不干扰（独立 broker）
