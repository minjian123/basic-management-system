## 1. 概述 <a id="overview"></a>

前端架构定义 PC 管理端与移动端 H5 双工程的总体设计：工程结构、技术要点、动态菜单机制、页面清单与性能要求。对应[《项目规划说明》](../../规划/项目规划说明.md)的「前端」「前端页面清单与菜单机制」「移动端」章节。通用组件的**分层体系、八类边界、分包加载与阶段落地**另见《[架构设计 · 前端组件体系](05_架构设计_前端组件体系.md)》；本节点第 8 节只保留组件体系的**语义定位与登记指引**（实现侧登记表见《前端基类清单》）。

## 2. 双工程结构 <a id="engines"></a>

- PC 管理端（Vue 3 + Vite + TypeScript + UI 组件库）与移动端（Vue 3 + 移动端 UI 组件库）为两个彻底独立的工程：各自依赖清单 / 锁文件与 ESLint / Prettier / TS 配置，不共享基础配置与公共类型
- 包管理 npm（Node 官方自带，不生成额外配置文件）；CI 用锁定安装
- 工程目录：接口封装、路由（动态路由生成）、状态（Pinia）、页面（按模块）、布局、通用组件、国际化、工具
- 前后端契约：由后端 OpenAPI schema 自动生成 TS 类型（与后端 Pydantic schema 一致）

> 工程目录的**具体路径与文件登记**见《[前端基类清单](../../前端基类清单.md)》「目录与依赖」节与《[前端开发规范](../../规范/前端开发规范.md)》§2「目录约定」。

## 3. 技术要点 <a id="tech"></a>

| 项 | 选型与要点 |
| --- | --- |
| 路由 / 状态 | Vue Router 4（路由守卫配合业务权限菜单级控制）、Pinia（TS 支持好） |
| HTTP | Axios：请求拦截器注入 access token、处理 401 刷新；响应拦截器统一错误提示（请求层已交付，落点见《前端基类清单》「契约与横切底座」节） |
| 错误兜底 | 错误页独立路由（403 / 404 / 500，懒加载；未知路径兜底 404）；全局运行时错误处理器（开发环境详报 / 生产记录监控日志）随后续 |
| 流程建模与审批展示 | bpmn-js 拖拽绘制 BPMN（可编辑 Modeler），导出 XML 交 SpiffWorkflow 执行；**审批实例只读图与建模画布共用同一份 bpmn-js 依赖与同一按需分包，均不进首屏主包**（只读图用 Viewer，不引属性面板包以减体积） |
| 图表 | ECharts（报表与大屏渲染）；**按需注册（未用类型不注册）+ 独立分包懒加载，不进首屏主包**；图表主题接设计令牌（`--bms-chart-*`、深浅 / 租户品牌随令牌），业务配置不写死色值；设计态 / 报表查看页 / 工作台共用同一图表渲染（组件基类 `BaseChart` + 基础图表件，色板与四态口径统一） |
| 网格拖拽 | gridstack.js（首页工作台卡片与报表设计器统一布局：网格拖拽 / 尺寸调整 / 响应式，布局配置序列化其结构）；**报表设计器网格内核经独立分包件懒加载，不进首屏** |
| 大屏画布 | vue-flow（大屏自由画布：绝对定位拖拽、连线与缩放，与 gridstack 分工不混用）；**画布内核经独立分包件懒加载，不进首屏主包**；播放舞台按设计分辨率 CSS transform 等比 contain 自适应（2026-09-20 登记） |
| 表单设计器 | vuedraggable（SortableJS 封装，字段排序 / 分组 / 跨区拖拽；三库分工：列表排序 / 网格布局 / 自由画布）；**设计器与拖拽能力独立分包懒加载，不进首屏主包**；设计态画布与业务表单页渲染器**复用同一份布局元数据与字段渲染**（所见即所得） |
| 富文本编辑 | wangEditor 5（公式 KaTeX、代码高亮 PrismJS 官方插件，附件卡片与目录导航为自定义菜单模块）；轻 Markdown 档用 markdown-it 解析后统一转 HTML；富文本 HTML 前端 DOMPurify + 后端白名单**双向**清洗（语义与契约见[《组件设计 · 富文本字段》](../组件设计/06_字段类/07_组件设计_富文本字段/07_组件设计_富文本字段.md)）；编辑器与插件异步按需加载、独立分包，不进首屏主包 |
| 高级查询 | 字典高级查询件：条件组（AND / OR 分组 + 常用操作符）+ 查询提供者发现（按参数定义动态渲染）；后端实现类注册、前端只选择调用，不受前端条件能力限制（语义与契约见[《组件设计 · 字典字段》](../组件设计/06_字段类/01_组件设计_字典字段/01_组件设计_字典字段.md)） |

| 规范 / 测试 | ESLint + Prettier；Vitest 单元 + Playwright E2E |

## 4. 动态菜单与权限渲染 <a id="menu"></a>

- 菜单树由后端按用户业务权限动态返回（菜单与表单挂接业务权限过滤，按当前 locale 关联 i18n 附表返回翻译文案）
- 表单元数据（按钮 / 字段定义与当前用户可见 / 可编辑状态）随菜单接口一并下发；前端根据菜单树动态注册路由与生成侧边栏
- 前端不硬编码路由表：新增菜单 / 表单 / 按钮 / 字段无需发版
- **路由守卫已接入**：无 token 跳登录（登录页未就绪时占位放行，由请求层 401 兜底）、`meta.perm` → 权限判定 → 403；菜单数据层支持占位 loader 注入，真实菜单接口与权限下发随后续；菜单 → 路由注册已接（占位菜单经动态路由能力构建并注册，未注册视图回退占位）
- 按钮按动作权限显隐（默认无按钮权限）：经权限指令控制；字段权限控制表单字段可见 / 可编辑
- 双重控制：前端显隐 + 后端强制校验

## 7. 前端性能 <a id="perf"></a>

- UI 组件库按需引入；路由懒加载（错误页独立路由 + 未知路径兜底）
- **重交互设计器按需分包**：表单设计器（含拖拽内核）与其画布 / 属性面板 / 自建字段对话框各自独立分包，业务表单页**不加载设计器**；设计器与渲染器共享同一份布局元数据（同形契约，避免「设计的」与「渲染的」不一致）
- **BPMN 渲染分包与布局信息（DI）**：流程建模画布与审批实例只读图共用同一份 bpmn-js 依赖与同一按需分包（懒加载、不进首屏），二者主题与图形资源统一；**渲染依赖 XML 中的图形布局信息（BPMN DI）**——后端下发的定义版本快照由建模器导出、天然含布局信息；缺布局信息时前端按降级链回退为简化进度视图（不报错阻断页面）
- 静态资源 gzip / brotli 压缩 + 缓存头
- **性能预算**（阶段十五验收口径）：Core Web Vitals 目标 LCP ≤ 2.5s / INP ≤ 200ms / CLS < 0.1（管理端桌面基线）；路由分片后单页 JS 包 gzip ≤ 300KB；Lighthouse 抽测随 E2E 执行，超标页面列入优化清单跟踪
- **构建体积预算**：双端各自体积阈值（基线 +20%）已挂构建门禁，超限阻断；运行时模块以独立构建产物计量（阈值与脚本见[32-测试与质量](32_架构设计_测试与质量.md)「CI 流水线」节与《[前端开发规范](../../规范/前端开发规范.md)》「构建体积预算」节）。**首屏口径（2026-09-19 登记）**：首屏预算只统计 `index.html` 静态引用的入口块，路由级 / 组件级异步块（含 `vendor-echarts` 等）不计入首屏，直接编码「首屏不加载」
- **容器级性能约定（2026-09-16 登记）**：长页面区块视口懒渲染（可视区外不渲染 + 占位防抖动 + 一次性 / 可卸载，能力不可用降级直接渲染）；大数据列表虚拟滚动（建议 ≥1000 条启用，可视区 + 缓冲渲染、DOM 数量恒定、动态高度经尺寸观测测量缓存 + 前缀和重建、触底事件配合加载更多）；自适应父剩余高度（尺寸观测 + 去抖 + 值比较防循环）；固定宽高比防布局抖动（CSS `aspect-ratio` + `@supports` 降级）
- 语言包运行时拉取（服务端缓存 + 本地二次缓存）；**语言包维护页（管理端）与运行时拉取分离**——维护页按需分包懒加载，其文案网格为独立分包入口（仅管理员进入），**不进入业务页首屏**；运行时语言包初始化仍为登录后必须（轻量）
- 深色 / 浅色主题：CSS 变量驱动切换，主题偏好持久化（跨端同步）+ 本地临时态
- 列表页个性化：列显隐 / 顺序 / 宽度、每页条数与密度按页面维度存偏好，列表渲染前应用
- 无障碍：WCAG / 信息无障碍专项适配不纳入 MVP（UI 组件库基础可访问性兜底），合同要求时以 WCAG 2.1 AA 为基线专项立项（见[目标与约束](02_架构设计_目标与约束.md)明确不采用清单）

## 9. 前端插件化与运行时组合（微前端） <a id="plugin"></a>

对应[《项目规划说明》](../../规划/项目规划说明.md)「前端」章节（前端插件化条目）与「平台扩展接入流程」章节；机制见 [10-扩展点与插件化](10_架构设计_子系统_扩展点与插件化.md)，组件侧见 [05-前端组件体系](05_架构设计_前端组件体系.md)。

- **扩展点 + 注册表**：路由 / 菜单（后端菜单树下发、动态注册）、页面区域、通用组件、字段渲染器、图标、工作台卡片、主题令牌、文案包（i18n）各设注册表；插件以注册方式挂接，不互相直接依赖。
  - **注册表基座已交付**：同键唯一性拒重（严格域抛错、一般域告警保留首个）、未命中返回空、保序、只读快照；**各域注册表基于同一基座扩展，不得另起映射**（微前端骨架承接路由 / 菜单等最小实现落地；落点见《[前端基类清单](../../前端基类清单.md)》）。
  - **统一装配**：平台自身注册与模块注册经**同一装配通道**（装配时序：平台自身注册 → 模块注册），注册项携带来源（平台 / 模块名）供排查与归因；模块注册项做命名空间校验（防覆盖平台项）。
  - **注册项消费接线**：注册结果必须有消费方——页面区域经**区域插槽件**渲染（区域标识 → 区域项保序渲染，空区域渲染为空）、主题令牌**注入根元素令牌变量**、模块文案包**并入宿主文案真源**；三者随模块挂载生效、卸载还原，避免「注册了却无人消费」。
  - **能力声明与登记机制同期交付**：供组件与宿主声明能力键并做依赖校验；渲染绑定投影只落绑定层（历史能力片段目录已随重构删除，经 git 追溯）。
- **动态导入分包**：插件页面与重组件一律异步加载、独立分包，不进首屏（见第 7 节性能预算与 [05-前端组件体系](05_架构设计_前端组件体系.md)「分包与加载策略」节）。
- **模块契约**：宿主注入上下文、模块注册声明与**样式 / 运行时约束**以《[前端模块契约](35_架构设计_前端模块契约.md)》为权威（阶段四交付，阶段五同接口接远端；隔离约定、机器护栏与接入检查项见该契约 §5 / §7）。
- **运行时组合（微前端，Module Federation）**：宿主为**薄壳**（布局 / 路由 / 模块加载器），模块经契约接入——宿主注入上下文（路由 / 状态 / 国际化 / 令牌 / 租户）与模块注册声明；**模块清单**（名称 / 入口 / 版本 + **加载形态**）驱动运行时加载；共享依赖设单例模式防重复实例。**新业务页面按模块形态独立构建与发布**（首个业务页面即首个模块样例），平台自身页面仍在主应用内；治理按**最小闭环 + 逐步补齐**（落地节奏见阶段计划，要求见下表）。见知识档案《[微前端](../../资料/知识档案/微前端/01_微前端_总览.md)》专题与 [10-扩展点与插件化](10_架构设计_子系统_扩展点与插件化.md)。
  - **宿主与远端的接入形态（2026-09-21 落地登记）**：宿主接入 MF 作**纯 host**（`name` + `shared`，**不声明静态 `remotes`**）；远端地址来自清单，在运行期经运行时 API 登记并按暴露键加载——**改清单不必重构建**（清单治理 / 灰度 / 回滚随发布治理）；远端容器入口文件名与暴露键为**固定约定**（`remoteEntry.js` / `./module`），容器名即清单 `name`。宿主与模块共用同一 `ModuleLoader` 接口与同一校验链，**入口来源由解析器注入**（构建期合并形态用本地入口表解析器、运行时形态用远端解析器）。
  - **模块独立构建与计量**：模块工程独立（自有依赖清单 / 锁文件 / 构建配置 / 产物目录），产物**不并入主应用产物**；模块产物以**自身口径单独计量**（入口块闭包 + 页面分包断言）并单独归档——首屏口径不变（首屏只统计宿主 `index.html` 静态引用的入口块，模块代码仅运行期 URL 引用，天然不进首屏）。
- **构建期合并保留为过渡 / 存量形态**：平台自身页面与未迁移模块仍随平台构建发布，产品模块迁移完成后仅作兼容；**两形态由模块清单显式区分**（加载形态字段），由**同一加载器**承接、不做隐式回退。**沙箱式微前端（`iframe` / 沙箱方案）不采用**：异构技术栈或强隔离需求出现时再评估（见《[微前端](../../资料/知识档案/微前端/03_微前端_技术方案对比.md)》「选型启发式」节）。
- **权限边界**：前端显隐只是体验，真正鉴权在后端（动态菜单 + 权限指令 + 后端强制校验，见第 4 节）。

**模块治理要求（语义）**：

| 治理面 | 治理要求 |
| --- | --- |
| 样式与运行时隔离 | Scoped / 令牌约定与模块命名空间前缀；模块不污染全局（禁改全局原型、全局事件、全局样式、全局变量、根节点）与运行时约束（禁直连 / 自建宿主实例、禁持久化）；**约定 + 机器护栏**（模块源码与产物双扫描面，含 fixture）；隔离增强（Shadow DOM / JS 沙箱）**本期不引入**，触发条件命中时立项评估 |
| 依赖共享与版本偏斜 | 共享依赖单例声明；版本取自依赖清单（版本偏斜检查）；生产构建验证无重复实例；版本协商与升级契约（框架大版本 = 跨团队契约） |
| 模块清单与发布治理 | 模块清单（名称 / 入口 / 版本）与加载器版本字段；模块独立构建产物并纳入体积预算计量；版本发现 / 灰度 / 蓝绿 / 回滚 / 模块契约测试 |
| 可观测与失败兜底 | 模块加载失败兜底（错误边界 / 降级 UI）与超时；错误上报带模块名与版本；按模块归因（错误 / 性能 / 体积）与 sourcemap 映射 |

> 治理项的**落地节奏、分档与窗口**以《总体项目规划》与阶段计划为准（需求见《[阶段五需求提出清单](../../项目/05_前端插件化/README.md)》）；评估见知识档案《[微前端 · 06 项目评估](../../资料/知识档案/微前端/06_微前端_项目评估.md)》「演进路径」节。
