## 1. 概述 <a id="overview"></a>

多租户路由子系统承载 BMS 的 SaaS 多租户形态：请求级确定目标租户与数据库引擎，管理引擎
生命周期与连接预算，执行租户开通/停用与配额治理。对应[《项目规划说明》](../../规划/项目规划说明.md)的「多数据源策略」
「租户管理」「认证与安全（租户识别）」章节，覆盖租户管理模块与平台超管运营视图。

> **微服务形态（2026-09-22）**：租户数据模型由「一租户一库」升级为**「每服务 × 每租户一库」**；每个服务只路由到自身的租户库。见《[微服务演进规划](../../规划/微服务演进规划.md)》。

## 2. 租户解析链 <a id="resolve"></a>

| 来源 | 场景 | 优先级 |
| --- | --- | --- |
| 子域名 `{tenant}.bms.example.com` | 生产环境（泛域名 DNS + 泛 TLS 证书） | 1 |
| `X-Tenant-ID` 请求头 | 一人多租户切换（切换后重发 token） | 2 |
| access token 内 tenant_id | 开发环境兜底 | 3 |

解析结果构造租户上下文（租户编码、数据源键、引擎引用），经框架依赖注入传入服务层与数据访问层；禁止全局单例持有租户引擎。子域名在平台库租户注册表匹配（命中缓存，短 TTL）。

- **租户自助**：用户视角的「我加入的租户 / 切换租户 / 品牌信息」经**统一租户自助出口**提供，业务与前端不得自建租户列表 / 切换 / 品牌读取；当前租户仍以解析链为**唯一权威来源**——该出口不参与解析、不读请求上下文，当前租户由调用方传入。切换结果以「生效方式（经重发令牌 / 经会话内切换）+ 是否需重发令牌 + 令牌」表达语义，令牌签发归认证阶段；切换后客户端经子域名或请求头携带目标租户，**解析链命中优先级不变**。品牌信息（名称 / 标识 / 主题）随租户配置提供、**登录前可用**（供登录页与顶栏使用），未配置项回退平台默认。真实取数随 RBAC 阶段、品牌来源与平台超管租户管理随租户管理阶段回补（契约与占位已交付，2026-09-20）

## 3. 引擎注册表与生命周期 <a id="engine"></a>

| 机制 | 设计 |
| --- | --- |
| 引擎注册表 | 「**服务 × 数据源键** → 引擎实例」映射；每个服务只持自身库引擎（平台服务库 + 该服务租户库）；常驻与懒加载按服务/租户 |
| 闲置回收 | LRU + 最后使用时间：超时未访问的租户引擎 dispose 回收；停用租户强制回收；控制活跃引擎数上限 |
| 连接预算 | 连接预算按**服务**分别核算（每服务 worker 数 × (pool_size + max_overflow) ≤ 该库 max_connections 的 70%）；多租户按活跃租户数规划，避免全量租户连接常驻 |
| 并发保护 | 引擎创建加锁（进程内锁 + Redis 锁），防多实例同时建引擎；创建失败快速失败并告警 |

## 4. 租户开通/停用 <a id="provision"></a>

- 开通流程（平台超管 `tenant:manage`）：校验 code 唯一 → **按服务建库** `bms_{service}_{tenant}`（每个服务一库）→ 每个服务三套 Alembic 迁移（按目标库方言，MySQL/PostgreSQL/达梦 DM8）→ 批量种子（三类内置管理员角色 + 初始系统管理员账号（首次登录强制改密）+ 默认 IdP 占位 + 归档策略 + 平台统一菜单/表单/按钮/字段挂接与权限码）→ **模块开通勾选**（可选已注册启用模块写入 sys_tenant_module，租户模块开关运营期启停，见[模块注册节点](11_架构设计_子系统_模块注册.md) 3.4）→ 注册 sys_tenant → 预热引擎（可选）→ 落 tenant.created 事件
- 停用：租户引擎全部回收、会话标记失效（按租户前缀批量清理 Redis）、登录拦截；启用：恢复正常 + 落 tenant.activated 事件
- 批量迁移：迁移工具遍历 **服务 × 租户** 逐库执行（运维脚本口径见《[部署发布规范](../../规范/部署发布规范.md)》）

## 5. 配额管理 <a id="quota"></a>

- 配额维度（sys_tenant_quota.quota_key）：user_count / storage_bytes / open_calls
- 超限拦截：创建用户/上传文件/开放接口调用前校验配额，超限拒绝并告警；used_value 计数落库
- 配额变更由平台超管运营视图配置（tenant:quota）

## 6. 隔离边界 <a id="isolation"></a>

- 第一层：引擎物理隔离（**每服务每租户一独立库**，库级隔离；服务只访问自身库）
- 第二层：查询强制 tenant 过滤（repository 统一注入 tenant_id 条件）
- 第三层：跨库引用走 code 逻辑外键（不建物理外键）；业务/动作权限码跨库引用同理
- 跨服务：禁止访问他服务数据库，跨服务读经契约 / 事件或只读投影（服务化地基 S2）
- 验证：跨租户访问拒绝测试纳入 CI（安全专项用例集）

## 7. 与其他子系统的协调 <a id="coordination"></a>

- **[认证与会话](14_架构设计_子系统_认证与会话.md)**：token 携带 tenant_id，会话 key 带租户前缀；踢出/锁定按租户维度生效
- **[数据访问与分片](13_架构设计_子系统_数据访问与分片.md)**：租户上下文决定数据源路由；分片键支持按租户（预留）
- **[事件总线](16_架构设计_子系统_事件总线.md)**：事件信封携带 tenant_id，审计链分区键 = 租户（保证租户内有序）
- **[缓存架构](07_架构设计_数据架构.md)**：租户数据 key 必含租户前缀，平台数据用 global
- **[权限计算引擎](15_架构设计_子系统_权限计算引擎.md)**：权限码租户侧可见、可分配、不可增删（平台统一维护）

## 8. 三库命名与建库标准 <a id="databases"></a>

阶段一登记（配置默认值见配置项清单；字段级表结构见数据库设计数据表文件）：

| 库类别 | 命名 | 用途 |
| --- | --- | --- |
| 平台服务库 | `bms_{service}` | 各平台服务在平台层的数据（跨租户） |
| 服务租户库 | `bms_{service}_{tenant}`（`tenant` 全小写） | 每服务每租户一库，该服务业务数据 |
| 归档库 | `bms_archive` | 归档数据统一收存（只读） |

- 环境库命名 `bms_dev` / `bms_test` / `bms_prod`；建库字符集：MySQL `utf8mb4`、PostgreSQL `UTF8`、达梦 `UTF8`（schema 前缀 `bms_dev`、小写标识符）。
- 跨库引用一律逻辑外键（code），不建物理外键；跨库查询禁止 JOIN（服务层聚合 / 事件同步）。
- 租户注册表：租户编码 / 名称 / 域名 / 状态 / 到期时间 + 基类审计字段；租户编码唯一、域名建索引（字段级结构见数据库设计数据表文件）。**租户注册不持有数据源键**：库键一律由「服务标识 + 租户编码」派生。
- **迁移链与建库执行口径（06_02 落地）**：每「服务 × 数据源」一条迁移链——链名 `{service}:{datasource}`、配置段 `[alembic:{service}:{datasource}]`（缺省链 `platform:tenant` 用 `[alembic]`）、版本目录 `alembic/versions/{service}/{datasource}/`、表集由表归属登记派生；建库与迁移编排为 `ops/provision_tenant.py`（按服务 × 租户建库，`--migrate` 建库后自动执行对应链迁移）与 `ops/migrate_tenants.py`（服务 × 数据源 × 租户矩阵，幂等、单库失败不中断、输出库数量统计），单租户三步初始化见 `ops/init_tenant.py`（链取 `{service}:tenant`）。

**数据源键与建库口径**（每服务每租户建库与路由）：

| 项 | 口径 |
| --- | --- |
| 库键形态 | **相对键**（`platform` 本服务平台库、`tenant_{code}` 本服务的该租户库，缺省补当前服务）与**全限定键**（`platform_{service}`、`tenant_{service}_{code}`，显式指向某服务）；归档库单键 `archive` 不服务化 |
| 库名派生 | 由库键派生：平台服务库 `bms_{service}`、服务租户库 `bms_{service}_{tenant}`、归档库 `bms_archive`；平台与租户目标**均**按连接串模板的 `{database}` 占位解析（模板为空则回落单库） |
| 建库入口 | 按「**服务 × 租户**」遍历幂等建库（平台服务库 + 各服务租户库）；服务维度取服务目录**已启用**服务，租户维度取租户注册（或显式指定） |
| 库级越界拒绝 | 取引擎入口校验全限定键的服务归属：服务段非当前服务即拒（**数据所有权 10008**）；跨服务建库 / 迁移经**运维通道**显式豁免（仅运维脚本，运行期服务不得使用） |
| 读出口 | 跨服务读经契约 / 事件 / 只读投影；平台层共享数据的跨服务读取同样经所属服务契约（不共享库、不跨库 JOIN） |
