## 1. 目的与适用范围 <a id="purpose"></a>

定义**产品前端模块**与**宿主薄壳**之间的契约边界：宿主注入什么、模块声明什么、双方各自不得做什么。阶段四交付薄壳与契约（本地演示模块验证），阶段五接入 Module Federation 运行时加载——**契约不因加载形态改变**。

范围：模块上下文注入、注册声明字段与校验、注册表基座与解析规则、样式与运行时约束。不在范围：隔离增强（Shadow DOM / JS 沙箱）、依赖版本协商、模块清单 / 灰度 / 回滚、按模块观测（见「模块治理要求」表，随后续阶段落地）。

## 2. 角色与边界 <a id="roles"></a>

| 角色 | 职责 | 不得 |
| --- | --- | --- |
| 宿主薄壳 | 布局壳与顶层路由、模块加载与挂载 / 卸载、上下文注入、注册表实例与解析、加载失败兜底 | 含业务页面逻辑；替模块裁决业务兜底 |
| 产品模块 | 声明路由 / 组件 / 字段渲染器 / 图标 / 工作台卡片；在 `setup` 内使用注入上下文（**只读快照**） | 直接写注册表；持有 / 持久化凭据；直连宿主 store / router 实例或自建宿主级实例；改全局原型 / 全局事件 / 全局样式 / 全局变量 / 根节点 |

## 3. 宿主注入上下文 <a id="context"></a>

| 注入项 | 类型 | 说明 |
| --- | --- | --- |
| `router` | 路由实例 | 模块只读使用；不得替换或改写宿主路由表 |
| `store` | Pinia 实例 | 模块不得注册与宿主冲突的全局 store |
| `i18n` | 国际化实例 | 文案键遵循《命名规范》 |
| `user` | 当前用户 | **只读** |
| `tenant` | 当前租户 | **只读** |
| ~~`token`~~ | — | **不注入**；模块不得读取 / 持久化凭据 |

- 契约类型：`ModuleHostContext`（`@bms/core`，**单一契约类型**——模块契约与模块上下文能力基类同源，不另立同形定义）；模块侧经模块上下文能力基类 `BaseModuleContext` 消费（冻结为只读快照）。
- 上下文缺失项以 `undefined` 呈现，模块须自行降级，不得假定存在。
- `i18n` 项为**宿主文案承载**：宿主未接入国际化库时以轻量文案承载（并入 / 还原 / 取文案）承担；接入后以适配层替换内部实现（语言包合并 / 移除），**对外接口不变**。

## 4. 模块声明与注册 <a id="registration"></a>

```ts
defineModule({
  manifest: { name, version, entry? },
  setup: (context) => ({ routes?, components?, fieldRenderers?, icons?, cards?, regions?, themeTokens?, i18nPacks? }),
})
```

| 注册项 | 键规则 | 校验 |
| --- | --- | --- |
| `routes` | 键 = 路由名（缺省路径） | `path` 须以 `/` 开头；与既有路由名冲突则**跳过**（不覆盖宿主路由） |
| `components` | `<模块名>:<键>`（kebab） | 命名空间前缀校验 + 同键唯一性拒重 |
| `fieldRenderers` | `<模块名>:<键>`（kebab） | 命名空间前缀校验 + 同键唯一性拒重（可按字段类型解析） |
| `icons` | `<模块名>:<键>` | 同上 |
| `cards` | `<模块名>:<键>` | 同上 |
| `regions` | `<模块名>:<区域项>`；另持 `area`（**点分区域标识**，如 `layout.header`） | 键前缀与命名空间校验 + 区域标识格式校验 |
| `themeTokens` | `<模块名>:<主题标识>`；载荷为令牌映射（`--bms-*` 变量 → 值）+ 可选 `mode` | 键前缀与命名空间校验 |
| `i18nPacks` | `<模块名>:<语言标识小写>`；载荷为文案映射（`msg_key` → 文案） | 键前缀与命名空间校验 + 语言标识小写归一校验 |

**模块清单（宿主下发）**：名称 / 入口 / 版本为必填三元，另以**加载形态** `mode`（`local`〔缺省〕＝构建期合并；`remote`＝运行时远端加载）**显式区分**两形态——**不由字符串形态推断**，`entry` 的语义随 `mode` 而定：`local` 为模块源码标识（宿主本地入口表键），`remote` 为**远端入口 URL**（须为绝对 URL，相对路径一律拒绝；发布态指向版本目录）。清单另持**可见性** `enabled`（缺省 `true`；`false`＝停用：不加载、不挂载、不进菜单，保留入口与版本）。清单整份形态非法即抛错（宿主按「空清单 + 错误状态」继续，不阻塞启动）；单项缺字段 / 形态非法 / 可见性非布尔 / 远端入口非绝对 URL / 重名**逐项拒绝**，不影响其余项。

- **清单是模块加载与回滚的唯一来源**：加载器只认清单；发布与回滚只改清单（产物按版本归档、回滚即清单指向切换）；清单版本须与模块自报版本、产物元数据**严格一致**（版本发现，通过才可入清单）。发布 / 回滚流程与留痕见《[部署发布规范](../../规范/部署发布规范.md)》「模块发布与回滚」节。

- **注册执行方**：模块只声明；宿主装配时经**统一装配器**（同一通道，平台自身注册与模块注册共用）逐项倒入八类扩展点注册表（路由·菜单 / 页面区域 / 通用组件 / 字段渲染器 / 图标 / 工作台卡片 / 主题令牌 / i18n 文案包），均基于统一提供者注册表基座（同键拒重、保序、只读快照）。
- **来源与归因**：注册项携带**来源**（平台 / 模块名）；模块注册项须以 `<模块名>:` 为命名空间前缀，越权即拒绝（防覆盖平台项）。
- **装配时序与原子性**：平台自身注册（启动期）→ 模块注册（挂载期），同一入口；装配先整体校验后逐项倒入，校验失败不产生任何登记，倒入途中冲突回滚本次已登记项（无残留）。
- **不注册不可用**：解析未命中返回 `undefined`（区域与语言返回空数组），由使用方降级；宿主不替调用方兜底。
- **消费接线（注册必有消费）**：页面区域经**区域插槽件**按区域标识渲染（保序；空区域与未知区域渲染为空）、主题令牌**注入根元素令牌变量**、文案包**并入宿主文案真源**——随模块**挂载生效、卸载还原**，不得「注册了却无人消费」。
- 卸载：宿主按登记键**逆序**注销，模块级路由按路由名移除；消费侧（区域内容 / 令牌变量 / 并入文案）随注销一并还原。

## 5. 一致性基础 <a id="consistency"></a>

- **组件契约复用**：模块可直接消费 `@bms/ui-ep` 组件与 `@bms/core` 契约类型。
- **设计令牌复用**：模块样式只使用 `--bms-*` 令牌变量，不写死色值 / 间距（令牌由宿主注入，随主题 / 租户品牌化统一变化）。
- **样式作用域（强制）**：模块与组件 `<style>` 一律 `scoped`；禁 `:global`、禁全局选择器（`:root` / `html` / `body` / `*`）、禁全局样式导入；模块自有类名以**模块名前缀**（约定成文）；模块样式只消费 `--bms-*` 令牌（`themeTokens` 注册载荷为**令牌定义源**，随挂载生效、卸载还原）。
- **全局污染（强制）**：禁改全局原型（`Object.prototype` 等，含 `__proto__`）、禁挂全局事件、禁写全局样式、禁改全局变量、禁直控根节点（`document.documentElement` / `document.body`）；机器护栏拦截（**源码面 + 产物面双扫描**，含 fixture 拦截用例，独立预览壳豁免）。
- **运行时（强制）**：模块不得直连宿主 store / router 实例（只经注入上下文与注册声明）、不得自建宿主级实例、不得私自持久化（`localStorage` / `sessionStorage` / `document.cookie` 禁；凭据一律不得持久化）；宿主能力只经 `setup(context)` 只读快照消费，缺失项由模块自行降级。
- **隔离增强**：`Shadow DOM` / JS 沙箱**本期不引入**；触发条件（异构技术栈 / 不可信代码 / 同页多模块强隔离 / 第三方全局冲突 / 合规要求）命中时立项评估。
- **契约版本（强制）**：模块定义自报 `contractVersion`（平台常量），构建期写入产物元数据；**加载器**校验「模块自报 = 平台常量」、**发布与回滚**校验「产物元数据 = 平台常量」——不一致即拒绝（加载拒绝 / 不得入清单 / 不得回滚生效）。契约变更（注入上下文 / 注册声明 / 清单字段语义 / 校验链）走**版本升级与协同升级**（平台通告 → 模块适配升版本 → 重新构建发布）。
- **失败兜底（强制）**：模块加载（远端入口解析 + 校验 + `setup`）设**超时**（缺省 10s，整个 `load()` 计时）；加载失败 / 超时 / 初始化异常一律由宿主模块边界渲染错误页（带**模块名与版本**），**不白屏**；重试为**手动、仅重挂该模块**（不整页刷新、不自动重试）。
- **可观测（强制）**：错误上报统一经总基类通道（`configureBase` 注入 sink）并携带**模块名与版本**、按模块聚合，覆盖加载 / 挂载 / 渲染三面；加载 / 渲染耗时与产物体积按模块归因；Web Vitals 按当前活动模块归属；模块产物外部 sourcemap 随发布按版本归档，线上异常可按模块 / 版本映射到源码。实现落点见《[前端基类清单](../../前端基类清单.md)》（能力域基类 `BaseModuleTelemetry` + 插件基类 `BaseModuleReporter`）。

## 6. 与阶段五的衔接 <a id="stage5"></a>

| 项 | 阶段四（本节点） | 阶段五 |
| --- | --- | --- |
| 加载形态 | 本地模块（静态 `import`） | **模块清单驱动**（清单下发 → 入口按需加载）→ Module Federation 远端模块（清单 `mode: remote` + `entry` 为远端入口 URL） |
| 接口 | `ModuleLoader`（`load` / `mount` / `unmount`） | 同接口换实现（宿主装配不变）：清单驱动加载器 + **入口解析器注入**（本地入口表解析器 / 远端 MF 解析器），校验链同一 |
| 远端接入方式 | — | 宿主为**纯 host**（`name` + `shared`，不声明静态 `remotes`）；远端在**运行期**按清单登记（`registerRemotes`，含远端入口类型 `module`）并按暴露键加载（`loadRemote('<模块名>/module')`）——改清单不必重构建 |
| 远端命名约定 | — | MF 容器名 = 清单 `name`；容器入口文件名固定 `remoteEntry.js`；暴露键固定 `./module`（模块定义默认导出） |
| 两形态共存 | — | 由清单 `mode` **显式区分**（`local` 构建期合并 / `remote` 运行时远端），共用同一加载器与装配 / 卸载路径；加载器只认清单、不做隐式回退 |
| 模块构建与发布 | 随宿主构建 | 模块工程独立（自有依赖清单 / 构建配置 / 产物目录），产物独立计量与独立归档；不并入主应用产物 |
| 加载失败处置 | — | 清单缺字段 / 形态与入口形态非法 / 版本不匹配 / 加载失败 / **加载超时**（10s）**一律拒绝加载** + 错误边界兜底（带模块名与版本，手动单模块重试）；清单获取失败不阻塞宿主启动 |
| 可观测与失败兜底 | — | **已交付**（阶段五 `03_03`）：加载超时与降级重试、错误上报带模块名与版本并按模块聚合、加载 / 渲染耗时与体积按模块归因、Web Vitals 按活动模块、sourcemap 随版本归档与映射；观测能力经能力域基类 `BaseModuleTelemetry` + 插件基类 `BaseModuleReporter` 入链 |
| 清单治理 | `name` / `version` / `entry` 字段预留 | **已交付**（阶段五 `03_02`）：清单唯一来源（含可见性 `enabled`）、版本发现（清单 = 产物元数据 = 源码）、发布与回滚（清单指向切换、产物按版本保留）、契约版本双端校验、发布留痕；灰度 / 蓝绿仅保留「按清单指向切换」 |
| 共享依赖 | 不引入 MF 依赖 | `shared` singleton 与版本偏斜检查：共享面**受控白名单**且版本要求取自**单一来源**；消费方不打包本地副本、版本不满足即拒绝加载；构建期与运行期双层断言实例数为 1；UI 组件库与平台基座包按实测结论登记为**受控非共享项**（共享前提变化时重评） |

## 7. 检查清单 <a id="checklist"></a>

- □ 注入清单与只读约束（`token` 不注入）
- □ 注册键命名空间与路由路径校验（模块项须 `<模块名>:` 前缀）
- □ 八类扩展点注册表基于统一基座，解析未命中返回 `undefined`（区域与语言返回空数组）
- □ 平台自身注册与模块注册经同一装配通道，注册项来源可查、卸载无残留
- □ 「不注册不可用」：未登记项不可解析，护栏与 fixture 通过
- □ 样式 scoped / 无 `:global` / 无全局选择器 / 只消费 `--bms-*` 令牌（护栏通过）
- □ 无全局污染（原型 / 事件 / 全局变量 / 根节点 / 全局样式）与运行时违规（自建宿主实例 / 持久化），源码面与产物面护栏通过
- □ 隔离增强评估结论已登记（本期不引入；触发条件命中时立项评估）
- □ 加载失败兜底与错误带模块名 / 版本
- □ 契约不依赖加载形态（阶段五同接口）
- □ 清单以 `mode` **显式区分**两形态（`remote` 入口须为绝对 URL，非法即拒绝）；两形态共用同一加载器与同一校验链
- □ 远端模块**独立构建**（自有构建命令与产物目录），产物独立计量与独立归档，不并入主应用产物
- □ 清单**唯一来源**与**可见性**（`enabled` 缺省可见；停用不加载且保留入口与版本）就位
- □ **版本发现**：清单版本 = 产物元数据 = 模块源码版本（构建期注入、发布前校验）
- □ **契约版本**双端校验（加载器校验模块自报；发布 / 回滚校验产物元数据）；契约变更走协同升级
- □ 发布 / 回滚流程与**留痕**成文（三关强校验、版本不可变、回滚目标产物保留）
- □ **模块契约用例齐备**：每个模块工程经契约用例工厂跑同一套断言（注入上下文 / 注册声明 / 共享依赖 / 样式约束）
- □ **失败兜底与超时**：加载失败 / 超时 / 初始化异常呈现降级 UI（带模块名与版本、不白屏；手动单模块重试）
- □ **错误上报带模块名与版本**（复用总基类上报通道、按模块聚合；覆盖加载 / 挂载 / 渲染）
- □ **按模块归因**：加载 / 渲染耗时与产物体积按模块可见；Web Vitals 按活动模块归属
- □ **sourcemap**：模块产物外部 sourcemap 随发布按版本归档，发布前强校验存在
