本节点定义 BMS 的接口规范与外部集成架构：内部 API 公共约定、错误码体系、开放接口（OAuth2）、

## 2. API 设计规范 <a id="api"></a>

### 2.1 公共约定 <a id="api-common"></a>

- 前缀：全部内部接口 `/api/v1`；开放接口 `/api/open`（与内部隔离）
- 统一响应：`{code, message, data}`；code=0 成功，非 0 为业务错误码；HTTP 状态码与业务错误码分离
- 分页：查询参数 `page`（从 1 起）、`size`；响应 `{list, total, page, size}`；大数据量列表游标分页（`cursor`/`limit`）
- 排序：查询参数 `order_by`（可**多值**，逗号分隔，如 `status,created_at`）与 `order`（方向数组，与 `order_by` 位置一一对应，缺省 `desc`）；排序字段按白名单逐项校验，非法字段忽略该项（防注入）；游标分页与排序互斥
- 命名：RESTful 资源式（GET /users、POST /users、PUT /users/{id}、DELETE /users/{id}），列表筛选用查询参数；动作类动词短语（/auth/login、/users/{id}/reset-password）
- 鉴权：除登录/刷新/健康检查外一律 Bearer access token；权限校验用 `require_permission` 依赖（业务:动作）
- 租户识别：生产按子域名解析（{tenant}.bms.example.com），开发以 token 内 tenant_id 兜底；一人多租户经 X-Tenant-ID 请求头切换并重发 token
- 幂等：审批提交、Excel 导入等写接口支持幂等键（请求头 Idempotency-Key）；实现为 Redis SETNX 前置拦截（重复键直接返回首次结果）+ 幂等键字段唯一约束兜底（并发穿透时拒绝重复提交）
- **长任务型出站接口（2026-09-19 登记，前端组件库 08_05）**：数据量可能很大的**取数出站接口**按阈值分两通道——阈值内**同步返回文件流**（或结果体）；超阈值改造为**后台任务**——接口返回**任务标识**而非结果流，调用方以任务标识复查状态与进度，完成后经通知中心 / 站内消息提供**限时下载**。该形态不占长连接、不阻塞页面，任务标识与状态口径见[任务调度](17_架构设计_子系统_任务调度.md)；错误明细等**按首次结果派生的取数接口**同理走任务标识 + 限时有效取址，不直接暴露存储路径
- 生产环境关闭在线文档端点；OpenAPI 契约快照由 CI 导出存档分发
- **列表查询与偏好契约（2026-09-20 登记，前端组件库 07_05）**：列表统一「分页 + 多列排序 + 筛选参数序列化」口径（排序白名单逐项校验、非法项忽略）；列表个性化（列显隐 / 顺序 / 宽度、每页条数、密度与筛选条件）以**用户偏好**持久化，查询方案按**个人 / 租户 / 平台三级**保存与共享——列表页不自建偏好存储；后端契约：筛选 `FilterSpec` / `BaseFilterQuery`（操作符复用数据范围白名单）、列表偏好 `ListPreference`（键 `list.{form_key}` 经 `BasePreferenceStore`）、查询方案 `BaseQuerySchemeStore`（`resolve_default` 三级优先级）+ 通用接口 `/api/v1/query-schemes`
- **接口路由基座（2026-09-20 登记，补充五 02-55）**：模块（能力域）路由**一律继承统一路由基类** `BaseRouter`（统一前缀 / tags / 默认错误响应 / 元信息），经路由登记表 `RouterRegistry` **统一挂载**到 `/api/v1`（`build_api_router`），禁止裸建 `APIRouter` / 手工拼前缀；分页 / 排序 / 筛选参数经统一 `Depends` 工厂绑定，统一响应与异常沿用 `ApiResponse` + 全局处理器（`api/errors.py`）；探针路由（`/healthz` `/readyz`）**豁免**统一前缀与统一响应包裹；真实登录态与权限校验随认证 / RBAC 阶段回补
- **用户偏好接口（2026-09-20 登记，补充三 02-50）**：`/api/v1/preferences/{key}`（GET 读 / PUT 写 upsert / DELETE 重置，登录即可、无权限码）；读写统一经后端 `BasePreferenceStore`（键 `{域}.{键}`、列表偏好 `list.{form_key}`、单键上限统一；占位实现固定回退默认值）；全量 `GET /preferences` 与批量 `PUT /preferences/batch`、key 白名单与大小校验随通用能力阶段
- **通知中心接口（2026-09-20 登记，补充三 02-46）**：`/api/v1/notifications`（列表 / 详情（查看即已读）/ 未读计数 / 已读（批量 / 全部）/ 删除，登录即可）；读接口统一经后端 `BaseNotificationCenter`，**未读数以服务端为唯一口径**——已读接口返回操作后的未读总数，前端据此校准角标，实时推送与已读的并发由实现侧按用户加锁裁决；列表筛选 / 分页复用 `BaseFilterQuery` / `BasePageQuery`；`notification.new` 推送负载含 `title` / `type` / `biz_type` / `biz_id` / `created_at`
- **流式与会话响应（2026-09-20 登记，前端组件库 08_10）**：AI 对话等长会话（流式输出）与检索类接口约定——流式契约只描述**事件语义**（增量片段 / 结束 / 错误 / 审计标识，支持中断），不绑定具体传输实现；检索类接口只返回业务标识与高亮片段，详情一律回查库，避免双写一致性难题；AI 对话 / 会话 / 自动执行确认撤销统一经能力域契约承载（契约边界与命名见《[后端基类清单](../../后端基类清单.md)》「跨阶段基座」节）——**会话以审计数据为派生视图、不另建独立会话事实源**，自动执行执行前**强制二次确认**、缺少确认一律拒绝、撤销落审计，占位路由 `/api/v1/chat`（登录即可）
- **检索查询接口（2026-09-20 登记，补充三 02-48）**：全局搜索 / 审计日志检索 / 文件内容检索统一经检索查询契约承载（契约边界与命名见《[后端基类清单](../../后端基类清单.md)》「跨阶段基座」节）——可检索域按**权限并集**确定、租户隔离与动作级数据范围在**检索侧强制**（调用方不可绕过）、结果只返业务标识与高亮（详情回查库）、命中高亮按白名单清洗后渲染；引擎不可用 / 超时 / 降级兜底时返回**降级标记与替代入口**；占位路由 `/api/v1/search/global` `/search/logs` `/search/files`（登录即可），审计日志检索时间范围必填（单次 ≤ 31 天）

### 2.2 错误码分段 <a id="api-error"></a>

既有平台域错误码 5 位数字，万位为模块段、后 4 位为段内序号，一经发布稳定不变；文案由前端按 i18n 映射（`error.{code}`），后端不承担文案拼装。既有 1xxxx-9xxxx 段保持不动：

| 段 | 区间 | 覆盖模块 |
| --- | --- | --- |
| 1xxxx | 10001-19999 | 通用（参数校验、限流、系统内部；`101xx` 子段为全文检索） |
| 2xxxx | 20001-29999 | 认证（登录/刷新/登出/验证码/找回密码/会话） |
| 3xxxx | 30001-39999 | 用户与组织（用户/部门/角色/权限/三权分立；`301xx` 子段为组织主数据） |
| 4xxxx | 40001-49999 | 系统配置（配置加载/校验、菜单/字典/系统参数/国际化语言包；`401xx` 子段为字典取数） |
| 5xxxx | 50001-59999 | 文件（上传/下载/分片/导入导出） |
| 6xxxx | 60001-69999 | 工作流（流程定义/实例/待办/审批/会签） |
| 7xxxx | 70001-79999 | 通知/邮件/任务调度 |
| 8xxxx | 80001-89999 | 开放接口/Webhook/租户/SSO |
| 9xxxx | 90001-99999 | 报表/审计/归档/监控 |

**平台已发布码位（骨架，新增在 `core/error_codes.py` 单一登记）**：`10000` 系统内部 / `10001` 参数校验 / `10002` 资源不存在（404）/ `10003` 业务冲突 / `10004` 并发冲突（409）/ `10005` 限流（429）/ `10101`~`10107` 检索（不可用 / 超时 / 降级中 / 索引未就绪 / 重建进行中 / 文件不可检索 / 时间范围超限）/ `20001` 认证失效（401）/ `20101`~`20103` 验证码（校验失败 / 不存在或已过期 / 发送过于频繁）/ `30001` 权限不足（403）/ `30101`~`30103` 组织主数据（数据源不可用 / 回显目标类型不支持 / 部门不存在）/ `40001` 配置加载校验失败（500）/ `40002` 插件注册构建失败（500，启动期致命）/ `40101`~`40103` 字典取数（数据源不可用 / 类型不存在 / 语言不支持）/ `80001` 租户不存在（404）。

**业务模块扩展段**：10xxxx 起扩展新段（模块注册制，sys_module.errcode_segment 为权威登记值），错误码随段号升为 6 位（段号两位 + 段内序号 4 位），注册即定、稳定不变（详见《[项目规划说明](../../规划/项目规划说明.md)》「错误码段规则与注册」节）：

| 段 | 区间 | 覆盖产品模块 |
| --- | --- | --- |
| 10xxxx | 100001-109999 | biz·采购（pur_） |
| 11xxxx | 110001-119999 | biz·收付款（pay_） |
| 12xxxx | 120001-129999 | biz·销售（sale_） |
| 13xxxx | 130001-139999 | biz·仓储（wh_） |
| 14xxxx | 140001-149999 | biz·供应商（sup_） |
| 15xxxx+ | 150001 起顺延 | 其他产品（cw 等）按注册登记 |

### 2.3 版本演进 <a id="api-version"></a>

- 破坏性变更升级大版本（/api/v2），新旧版本并行至少一个发布周期后下线旧版
- 非破坏性变更（新增字段/接口）在版本内演进

## 3. 对外 API（外部系统调 BMS） <a id="open-api"></a>

- 鉴权：OAuth2 Client Credentials——client_id/secret 换取 access token（自签 JWT，短 TTL），支持 scope（接口权限范围）、独立撤销、调用审计
- 防重放：/api/open 请求强制携带 X-Timestamp（服务器时间 ±5 分钟窗口，超窗拒绝）与 X-Nonce（随机唯一串，Redis SETNX 去重、TTL 与窗口对齐，重复拒绝）；与 Client Credentials + IP 白名单叠加构成三重防护
- 路由：独立前缀 /api/open，与内部接口隔离；按 client 维度独立限流（slowapi）
- 开放范围：全量 CRUD 按 scope 控制；安全默认——scope 最小化分配，写接口（POST/PUT/DELETE）需显式授予，未授予一律拒绝
- 契约：OpenAPI 契约快照作为集成契约；CI 构建时导出存档，随版本分发给外部系统；生产关闭在线文档端点
- BMS 兼作 IdP：对外提供 OIDC Provider（授权码流程），第三方系统以 BMS 租户用户体系实现单点登录；客户端注册复用 sys_client（redirect_uris/grant_types 扩展字段）
- 调用审计：sys_open_log 按月分片 + 哈希链防篡改
- **独立服务接入骨架（阶段十交付）**：`sys_client` 注册要素、最小 scope 集合、必供项（健康检查 / 审计 / 事件订阅）与平台版本兼容承诺清单；口径见平台《平台可扩展性规划》独立服务形态节

## 4. 出站集成（BMS 调外部） <a id="outbound"></a>

| 方式 | 机制 |
| --- | --- |
| 同步调用 | httpx 统一封装（超时/重试/熔断，复用降级机制） |
| 事件推送（Webhook） | 事件发生后经 RocketMQ 事件总线异步推送至注册 URL；HMAC 签名校验（sha256(secret, body)）、指数退避重试、失败记录（sys_webhook_log） |
| 邮件 / 短信 | aiosmtplib（SMTP）+ 阿里云/腾讯云短信渠道；模板入库渲染；发送记录（sys_mail_log / sys_sms_log） |
| 企业微信 / 钉钉 | OAuth 免登 + 群机器人告警（Alertmanager webhook receiver 转 BMS 内部接口转换格式） |

## 5. 事件模型清单 <a id="events"></a>

事件命名 `{域}.{对象}.{动作}`，经 RocketMQ 事件总线发布，Webhook 订阅按事件名匹配。默认清单（开发期可扩展）：

| 事件 | 触发时机 | 主要载荷 | Webhook 订阅 |
| --- | --- | --- | --- |
| user.created / user.updated / user.deleted | 用户创建/修改/删除后 | 用户 ID、username、dept_id、status | 是 |
| user.password_reset | 管理员重置密码或自助找回后 | 用户 ID | 是 |
| dept.changed | 部门增删改/移动 | dept_id、parent_id | 否 |
| wf.process.deployed | 流程定义发布新版本 | definition_key、version | 是 |
| wf.instance.started | 流程实例启动 | instance_id、business_type、business_id | 是 |
| wf.task.completed | 审批节点通过 | task_id、instance_id、approver、action | 是 |
| wf.instance.rejected | 流程被驳回 | instance_id、node_id、comment | 是 |
| wf.instance.finished | 流程实例结束 | instance_id、result | 是 |
| pur.apply.submitted | biz·采购申请提交 | apply_no、applicant_id、amount | 是 |
| pur.order.created | biz·审批通过生成采购订单 | order_no、apply_id、supplier | 是 |
| pay.receipt.confirmed | biz·收款单确认 | receipt_no、amount、biz_type、biz_id | 是 |
| pay.approved | biz·付款单审批通过 | payment_no、amount、payee | 是 |
| pay.executed | biz·付款执行完成 | payment_no、amount、channel_code | 是 |
| pay.refund.completed | biz·退款完成 | refund_no、refund_type、original_id、amount | 是 |
| file.uploaded | 文件上传完成 | file_id、sha256、size | 否 |
| notification.sent | 通知/邮件/短信发送 | user_id、type、biz_type | 否 |
| notice.published | 公告发布/更新/下线 | notice_id、title、is_top | 是 |
| form.updated | 菜单/表单/字段/按钮变更（平台统一维护） | form_id、menu_id、business_id、changed_type | 否（AI 帮助更新触发） |
| help.article.published / help.article.updated / help.article.deleted | 帮助文章发布/更新/删除 | article_id、category_id、target_key | 否 |
| task.completed | 定时任务执行完成 | task_id、status | 否 |
| tenant.created / tenant.suspended / tenant.activated | 租户开通/停用/启用 | tenant code、db_key、status | 是 |
| sso.user.jit_created | SSO 首登自动建号 | user_id、idp_key | 是 |
| archive.completed | 归档批次完成 | policy_id、archived_count、target | 否 |

## 6. 开放接口管理模块 <a id="open-module"></a>

- 第三方应用注册（client_id/secret 生成、名称、负责人）

- 业务权限码 `open`、动作码 `call`（`open:call`）
