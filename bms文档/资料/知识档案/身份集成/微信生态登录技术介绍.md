## 1. 技术概述 <a id="overview"></a>

微信生态对外提供登录能力的主要是两条线，二者账号体系与接口域都不同，务必区分：

- **企业微信（WeCom）**：企业自建应用的免登与扫码登录，身份来自**企业通讯录成员**（`userid`），接口域为 `qyapi.weixin.qq.com`。
- **微信开放平台 / 微信公众号**：面向 C 端微信用户，身份以 `openid`（单应用）/ `unionid`（同主体多应用统一）标识，接口域为 `api.weixin.qq.com`；网站应用扫码登录用 `snsapi_login`，公众号 H5 授权用 `snsapi_base` / `snsapi_userinfo`。

本项目阶段六「SSO 与身份联邦」的「企业微信 / 钉钉免登适配」以**企业微信**为接入对象（PC 扫码 + 移动端内嵌 H5），走统一的外部身份框架与 JIT 建号；微信开放平台 / 公众号链路作为同类 OAuth 变体一并记录，便于后续接入微信 C 端用户。

- **协议形态**：OAuth 2.0 授权码的私有变体（授权码换 access_token，再取用户信息），非标准 OIDC，无 ID Token / JWKS 验签。
- **身份主键**：企业微信成员 `userid`（企业内唯一）、非成员 `openid`（企业内唯一）；微信开放平台 `unionid` 优先、`openid` 兜底。
- **本档案定位**：理解与联调用参考资料，协议细节以微信 / 企业微信官方文档为准。

## 2. 核心概念与术语 <a id="concepts"></a>

| 术语 | 说明 |
| --- | --- |
| CorpID（企业 ID） | 企业唯一标识，企业微信应用参数 `appid`（网页授权 / 扫码登录都以它作 `appid`） |
| AgentID（应用 ID） | 企业自建应用的编号，企微扫码登录与内嵌 H5 授权需携带 |
| AppSecret（应用密钥） | 应用级密钥，换取应用 `access_token` 用；一个企业各应用 secret 独立，权限互不相同 |
| userid | 企业成员的账号标识（企业通讯录内唯一），企业内部应用拿到的稳定主键 |
| openid | 用户在某应用 / 某公众号下的标识，**同一用户对不同应用不同** |
| unionid | 微信用户在**同一开放平台主体**下的统一标识；绑定到开放平台后，同主体多应用可互通 |
| access_token（企业微信） | 应用级调用凭证，`gettoken` 换取，正常 7200 秒；须服务端缓存、失效重取 |
| access_token（微信开放平台） | 用户级授权凭证，`sns/oauth2/access_token` 以 code 换取，7200 秒；与「基础支持 access_token」不是同一个 |
| code（授权码） | 授权回跳带来的一次性码，换取令牌后立即失效；企微 5 分钟、开放平台 10 分钟过期 |
| user_ticket | 企业微信敏感信息票据，`snsapi_privateinfo` 授权后由 `getuserinfo` 返回，1800 秒有效，用于 `getuserdetail` |
| snsapi_login | 微信开放平台网站应用扫码登录使用的 scope |
| snsapi_base / snsapi_userinfo | 公众号网页授权 scope：前者静默仅取 openid，后者显式授权可取昵称头像 |
| snsapi_base / snsapi_privateinfo | 企业微信网页授权 scope：前者静默仅取 userid，后者手动授权可取敏感信息 |
| 可信域名 | 企业微信后台为应用配置的回调域（OAuth 可信域名 / Web 网页授权回调域名），回跳域名须与之完全一致 |

## 3. 企业微信（WeCom）登录 <a id="wecom"></a>

企业微信提供两种拿 `code` 的入口，**回跳都是 `redirect_uri?code=CODE&state=STATE`，且都走同一个换身份接口** `cgi-bin/auth/getuserinfo`。

### 3.1 PC 扫码登录 <a id="wecom-qr"></a>

新版登录链接（同时支持移动端企微扫码与桌面端企微快速登录）：

```text
https://login.work.weixin.qq.com/wwlogin/sso/login
  ?login_type=CorpApp&appid=CORPID&agentid=AGENTID
  &redirect_uri=URLENCODE(REDIRECT_URI)&state=STATE
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| login_type | 是 | `CorpApp`（企业自建 / 代开发应用）；`ServiceApp`（服务商） |
| appid | 是 | 自建 / 代开发填企业 CorpID；服务商填登录授权 SuiteID |
| agentid | 否 | `login_type=CorpApp` 时填写应用 AgentID |
| redirect_uri | 是 | 回跳地址，须 URLEncode；域名须为应用配置的可信域名 |
| state | 否 | 防 CSRF，原样回传，建议随机数 + 会话校验（须 URLEncode） |
| lang | 否 | `zh` / `en` |

- 旧版扫码入口 `https://open.work.weixin.qq.com/wwopen/sso/qrConnect?appid=…&agentid=…&redirect_uri=…&state=…` 仍可用，官方建议升级到上面的新版。
- 也可用 `@wecom/jssdk`（>=2.3.2）的 `ww.createWWLoginPanel` 把登录面板内嵌到网页，授权后由组件回调 `auth code`，免跳转。
- 回跳：用户确认后 `redirect_uri?code=CODE&state=STATE`。

### 3.2 网页授权登录（企微内置 Webview / 移动端 H5） <a id="wecom-web"></a>

```text
https://open.weixin.qq.com/connect/oauth2/authorize
  ?appid=CORPID&redirect_uri=URLENCODE(REDIRECT_URI)
  &response_type=code&scope=SCOPE&state=STATE&agentid=AGENTID#wechat_redirect
```

| scope | 语义 | 可得信息 |
| --- | --- | --- |
| `snsapi_base` | 静默授权，用户无感 | 仅成员基础身份（`userid`） |
| `snsapi_privateinfo` | 手动授权，用户需确认 | 敏感信息（性别 / 头像 / 手机 / 邮箱等），且成员须在应用可见范围内 |

- `agentid` 建议携带；当 `appid=corpid` 且 `scope=snsapi_privateinfo` 时**必填**，否则视为 `snsapi_base` 不返回敏感信息。
- 移动端内嵌 H5 免登即用此入口（本项目的移动端 H5 免登留阶段十七）。

### 3.3 换取身份 <a id="wecom-exchange"></a>

三步：取应用 `access_token` → 以 `code` 换成员身份 → （可选）以 `user_ticket` 取敏感信息。

```text
# 1) 取应用 access_token（须服务端缓存；应用独立 secret）
GET https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=CORPID&corpsecret=APPSECRET
→ { "errcode":0, "access_token":"…", "expires_in":7200 }

# 2) 以 code 换成员身份（扫码登录与网页授权共用本接口）
GET https://qyapi.weixin.qq.com/cgi-bin/auth/getuserinfo?access_token=ACCESS_TOKEN&code=CODE
→ 企业成员： { "userid":"USERID", "user_ticket":"…"(仅 snsapi_privateinfo 且在可见范围) }
→ 非企业成员：{ "openid":"OPENID", "external_userid":"…"(客户且跟进人可见) }

# 3) 取敏感信息（仅网页授权 snsapi_privateinfo 场景，user_ticket 1800 秒有效）
POST https://qyapi.weixin.qq.com/cgi-bin/auth/getuserdetail?access_token=ACCESS_TOKEN
  body: {"user_ticket":"USER_TICKET"}
→ { "userid":"…", "gender":0|1|2, "avatar":"…", "qr_code":"…",
    "mobile":"…", "email":"…", "biz_mail":"…", "address":"…" }
```

要点：

- **扫码登录回跳的 code 经 `getuserinfo` 不返回 `user_ticket`**，只能拿到 `userid` / `openid`；要取手机、邮箱等敏感信息必须走网页授权 `snsapi_privateinfo`。
- 敏感字段需管理员在应用里勾选，且用户授权时确认后才返回真实值（如 `gender` 未同意时为 0、`avatar` 为默认头像）。
- 成员详细资料也可经通讯录接口 `GET /cgi-bin/user/get?access_token=…&userid=…` 获取，但需通讯录读取权限，且与「用户授权」语义不同（不要用通讯录接口冒充本人授权）。
- `gettoken` 不能频繁调用（有频率拦截），应缓存并在失效时重取；不同应用 secret 换取的 token 权限范围不同。

### 3.4 接口速查 <a id="wecom-cheatsheet"></a>

| 用途 | 方法 | 地址 |
| --- | --- | --- |
| PC 扫码登录入口 | GET（浏览器跳转） | `https://login.work.weixin.qq.com/wwlogin/sso/login` |
| 内嵌 H5 网页授权入口 | GET（浏览器跳转） | `https://open.weixin.qq.com/connect/oauth2/authorize` |
| 取应用 access_token | GET | `https://qyapi.weixin.qq.com/cgi-bin/gettoken` |
| code 换成员身份 | GET | `https://qyapi.weixin.qq.com/cgi-bin/auth/getuserinfo` |
| 取敏感信息 | POST | `https://qyapi.weixin.qq.com/cgi-bin/auth/getuserdetail` |
| 读取成员详情（通讯录） | GET | `https://qyapi.weixin.qq.com/cgi-bin/user/get` |

## 4. 微信开放平台 / 公众号登录 <a id="weixin"></a>

面向微信 C 端用户：网站应用扫码登录取 `openid` / `unionid`，公众号 H5 授权取 `openid`（`snsapi_userinfo` 可补昵称头像）。

### 4.1 网站应用扫码登录（PC） <a id="weixin-qr"></a>

```text
https://open.weixin.qq.com/connect/qrconnect
  ?appid=APPID&redirect_uri=URLENCODE(REDIRECT_URI)
  &response_type=code&scope=snsapi_login&state=STATE#wechat_redirect
```

- 回跳：用户允许后 `redirect_uri?code=CODE&state=STATE`；拒绝授权则不回跳。
- 也可引入 `https://res.wx.qq.com/connect/zh_CN/htmledition/js/wxLogin.js`，用 `new WxLogin({...})` 内嵌二维码。
- 域名须与开放平台后台登记的**授权回调域**一致。

### 4.2 换取令牌与用户信息 <a id="weixin-exchange"></a>

```text
# 以 code 换 access_token
GET https://api.weixin.qq.com/sns/oauth2/access_token
  ?appid=APPID&secret=APPSECRET&code=CODE&grant_type=authorization_code
→ { access_token, expires_in:7200, refresh_token, openid, scope, unionid }

# 刷新 access_token（refresh_token 有效期 30 天且不可续期）
GET https://api.weixin.qq.com/sns/oauth2/refresh_token
  ?appid=APPID&grant_type=refresh_token&refresh_token=REFRESH_TOKEN

# 校验 access_token
GET https://api.weixin.qq.com/sns/auth?access_token=ACCESS_TOKEN&openid=OPENID

# 拉用户信息
GET https://api.weixin.qq.com/sns/userinfo?access_token=ACCESS_TOKEN&openid=OPENID&lang=zh_CN
→ { openid, nickname, sex, province, city, country, headimgurl, privilege[], unionid }
```

- 2021-10-20 起开放平台授权接口不再返回**性别与地区**；头像 URL 会失效，需自行转存。
- `sns/oauth2/access_token` 拿到的 token 只用于该用户的信息获取，与公众号「基础支持 access_token」不同。

### 4.3 公众号网页授权（微信内 H5） <a id="weixin-h5"></a>

```text
https://open.weixin.qq.com/connect/oauth2/authorize
  ?appid=APPID&redirect_uri=URLENCODE(REDIRECT_URI)
  &response_type=code&scope=snsapi_base|snsapi_userinfo&state=STATE#wechat_redirect
```

| scope | 语义 | 可得信息 |
| --- | --- | --- |
| `snsapi_base` | 静默授权 | 仅 `openid`，无需也无法调用户信息接口 |
| `snsapi_userinfo` | 显式授权（用户点击同意） | 可调 `sns/userinfo` 取昵称、头像等；`unionid` 需公众号已绑定开放平台 |

- 仅**已认证服务号**可用；链接参数顺序会被微信强校验，`#wechat_redirect` 必须带。
- code 一次性、5 分钟过期；回跳 `redirect_uri?code=CODE&state=STATE`。
- 网页授权域名须在公众号后台「网页授权域名」配置（纯域名，全域名匹配）。

### 4.4 接口速查 <a id="weixin-cheatsheet"></a>

| 用途 | 方法 | 地址 |
| --- | --- | --- |
| 网站应用扫码登录入口 | GET（浏览器跳转） | `https://open.weixin.qq.com/connect/qrconnect` |
| 公众号网页授权入口 | GET（浏览器跳转） | `https://open.weixin.qq.com/connect/oauth2/authorize` |
| code 换 access_token | GET | `https://api.weixin.qq.com/sns/oauth2/access_token` |
| 刷新 access_token | GET | `https://api.weixin.qq.com/sns/oauth2/refresh_token` |
| 校验 access_token | GET | `https://api.weixin.qq.com/sns/auth` |
| 拉用户信息 | GET | `https://api.weixin.qq.com/sns/userinfo` |

## 5. 企业微信与微信开放平台差异对照 <a id="compare"></a>

| 维度 | 企业微信 | 微信开放平台 / 公众号 |
| --- | --- | --- |
| 用户群体 | 企业通讯录成员（企业员工） | 微信 C 端用户 |
| 接口域 | `qyapi.weixin.qq.com` | `api.weixin.qq.com` |
| PC 扫码入口 | `login.work.weixin.qq.com/wwlogin/sso/login` | `open.weixin.qq.com/connect/qrconnect` |
| PC 扫码 scope | 无 scope（参数 `login_type=CorpApp`） | `snsapi_login` |
| H5 授权 scope | `snsapi_base` / `snsapi_privateinfo` | `snsapi_base` / `snsapi_userinfo` |
| 身份主键 | `userid`（成员）/ `openid`（非成员） | `openid` / `unionid` |
| 换身份接口 | `cgi-bin/auth/getuserinfo`（应用 access_token） | `sns/oauth2/access_token` + `sns/userinfo`（用户 token） |
| 令牌模型 | 应用级 `access_token`（gettoken，7200s） | 用户级 `access_token`（code 换，7200s） |
| code 有效期 | 5 分钟 | 扫码 10 分钟；网页授权 5 分钟 |
| 敏感信息 | `getuserdetail`（user_ticket，1800s） | `sns/userinfo` |
| 后台配置 | 应用可信域名（OAuth 可信域 / Web 网页授权回调域） | 开放平台授权回调域；公众号网页授权域名 |

## 6. 本项目中的用途 <a id="usage"></a>

- **企业微信免登**：作为阶段六需求 02-4 的适配对象之一，按统一身份源契约实现授权跳转、换码 / 票据校验、用户信息解析，复用同一 SSO 链路与 JIT 建号。
- **PC 扫码形态**：登录页经授权跳转入口渲染二维码，用户在企业微信客户端确认后回跳本项目回调完成会话签发；扫码登录 `code` 仅换得 `userid`，身份映射以 `userid` 为外部主体标识。
- **移动端内嵌 H5 免登**：企微内置 Webview 走网页授权（`snsapi_base` 静默），归阶段十七；真实企业凭据联调同样归阶段十七，凭据就绪可提前真跑。
- **微信开放平台 / 公众号**：本项目当前未接入微信 C 端用户，本档案先行记录以备后续扩展（如对外门户面向微信用户登录）。
- **统一外部身份框架**：微信生态登录与钉钉、OIDC、CAS 同属「外部身份 → `sys_user_identity` 映射 → 会话签发」一条链路，协议差异由各适配器承载，见《[authlib 技术介绍](../后端核心/authlib技术介绍.md)》。

## 7. 常见问题与注意事项 <a id="pitfalls"></a>

- **区分「企业微信」与「微信开放平台」**：账号体系、接口域、scope 都不同，`appid` 一个是 CorpID、一个是网站应用 AppID，混用会报「invalid appid / 无权限」。
- **可信域名必须完全一致**：企业微信回跳域名须与应用配置的可信域名完全一致（含端口），否则报 50001；开放平台 / 公众号同理。
- **code 一次性且短时**：换取后立即失效，须服务端立刻处理；重复使用报 `40029 invalid code` / `40163 code been used`。
- **企业微信 code 5 分钟过期**：未及时使用即失效，回调链路的 `state` TTL 应覆盖该窗口。
- **access_token 缓存与并发**：企微 `gettoken` 有频率拦截，须缓存并做失效重取；多实例部署建议共享缓存，避免并发穿透。
- **扫码登录拿不到敏感信息**：扫码 code 走 `getuserinfo` 不返回 `user_ticket`，手机 / 邮箱须网页授权 `snsapi_privateinfo`，且需管理员勾选 + 用户确认。
- **unionid 需要绑定开放平台**：未绑定开放平台时拿不到 `unionid`，多应用无法统一用户；企业微信成员以 `userid` 为准。
- **头像与地区信息变化**：开放平台头像 URL 会失效需转存；2021-10-20 起不再返回性别与地区。
- **state 防 CSRF**：发起授权生成随机 `state` 并落存储，回跳比对，一次性消费；不得用请求参数拼 `redirect_uri`（开放重定向风险）。
- **常见错误码**：`40029` 无效 code、`40163` code 已使用、`40003` 无效 openid、`40030` 无效 refresh_token、`40013` 无效 appid、`40125` 无效 appsecret；企业微信侧 `40001` 无效 secret、`50001` 域名不匹配。
