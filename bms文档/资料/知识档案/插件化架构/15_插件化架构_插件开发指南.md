## 1. 技术概述 <a id="overview"></a>

本指南把「怎么写一个插件」串成一份可照做的 **SOP**，把散在 [03 端口适配器](03_插件化架构_端口适配器.md)、[04 接口契约设计](04_插件化架构_接口契约设计.md)、[09 自建注册表](09_插件化架构_自建注册表.md)、[10 配置驱动实现选择](10_插件化架构_配置驱动实现选择.md) 的做法收口成一条流程。

- **面向三类作者**：平台内建实现（主线，继承统一）、产品二次开发（项目侧，组合灵活）、第三方（安装即发现）。
- **前提**：契约（能力基类）与注册机制已就绪；若目标能力还没有契约，先按 [04 接口契约设计](04_插件化架构_接口契约设计.md) 定义契约。
- **原则**：**先契约、后实现**；业务代码不得直接 `import` 具体实现，只认基类与提供者。

## 2. 开发流程 <a id="flow"></a>

```mermaid

    S1["① 判定<br/>是否值得插件化"]:::s --> S2["② 定契约<br/>或复用已有能力基类"]:::s
    S2 --> S3["③ 写实现<br/>继承/组合 + 注册"]:::s
    S3 --> S4["④ 接配置<br/>provider + options"]:::s
    S4 --> S5["⑤ 契约测试<br/>跑同一组断言"]:::s
    S5 --> S6["⑥ 登记与文档<br/>能力名/版本/依赖"]:::s
    S6 --> S7["⑦ 发布<br/>语义化版本 + 兼容范围"]:::s
    classDef s fill:#e8eef4,stroke:#38a,color:#111
```

| 步骤 | 产出 | 判据 |
| --- | --- | --- |
| ① 判定 | 结论：需要/不需要插件化 | 命中「可能被替换 / 客户会指定 / 需测试隔离」才做（见 [03 端口适配器](03_插件化架构_端口适配器.md)） |
| ② 定契约 | 能力基类（端口） | 方法签名、异常、异步语义、数据契约清晰（见 [04 接口契约设计](04_插件化架构_接口契约设计.md)） |
| ③ 写实现 | 实现类 + 注册 | 继承 `BaseXxx` 或显式注册；`plugin_key` / `plugin_name` 唯一 |
| ④ 接配置 | `config.toml` 片段 | `provider` 选定实现，`options` 有默认值，密钥走 Secret |
| ⑤ 契约测试 | 通过的测试 | 全部注册实现跑同一组契约测试（见 [04 接口契约设计](04_插件化架构_接口契约设计.md)） |
| ⑥ 登记与文档 | 能力/版本/依赖登记 | 注册要素唯一、`contract_version` 声明、依赖显式 |
| ⑦ 发布 | 版本产物 | 语义化版本 + 兼容范围 + 迁移说明 |

## 3. 目录与文件结构 <a id="layout"></a>

平台内建实现（跟随仓库，**进程内**）：

```text
bms/
├── backend/
│   └── app/
│       ├── storage/                 # 能力域：契约（端口）
│       │   └── base.py              # BaseObjectStorage + NullObjectStorage
│       └── plugins/                 # 平台内建实现（可按能力分子目录）
│           └── storage_minio.py     # MinioObjectStorage + 注册
└── ...
```

第三方/产品插件（独立发行包，**安装期发现**）：

```text
bms-plugin-acme/
├── pyproject.toml                   # 声明 entry point（第三方发现用）
├── src/
│   └── bms_plugin_acme/
│       ├── __init__.py
│       └── storage.py               # AcmeStorage + 注册
└── tests/
    └── test_contract.py             # 契约测试
```

## 4. 最小插件骨架 <a id="skeleton"></a>

```python
# 1) 实现能力基类（继承方式：主线）
from app.storage.base import BaseObjectStorage

class AcmeStorage(BaseObjectStorage):
    plugin_key = "object_storage"
    plugin_name = "acme"

    async def put(self, key, data, *, content_type): ...
    async def get(self, key): ...
    async def delete(self, key): ...
    async def exists(self, key): ...
    async def presign(self, key, *, method, expires_in): ...

# 2) 注册（继承自动登记，或显式注册；两条路径进同一注册表）
register_plugin("object_storage", "acme", AcmeStorage)
```

不继承平台基类时（项目二次开发，组合方式），用显式注册或虚拟子类登记即可（见 [03 端口适配器](03_插件化架构_端口适配器.md)「双轨」）：

```python
from app.storage.base import BaseObjectStorage

BaseObjectStorage.register(AcmeStorage)   # 虚拟子类：不继承也能被识别
register_plugin("object_storage", "acme", AcmeStorage)
```

第三方包声明入口点（安装即发现，阶段三）：

```toml
[project.entry-points."bms.plugins.object_storage"]
acme = "bms_plugin_acme.storage:AcmeStorage"
```

接入配置（改一行即切换）：

```toml
[storage]
provider = "acme"
options = { endpoint = "https://acme.example.com", bucket = "bms" }
```

## 5. 契约测试与验收 <a id="test"></a>

```python
# tests/test_contract.py —— 继承平台的契约测试基类即可
from tests.contracts import ObjectStorageContractTest
from bms_plugin_acme.storage import AcmeStorage

class TestAcmeStorage(ObjectStorageContractTest):
    impl_cls = AcmeStorage
```

验收清单（详见 [04 接口契约设计](04_插件化架构_接口契约设计.md)）：注册唯一性、契约测试全过、`contract_version` 兼容、异常隔离、租户隔离、降级可用、异步一致、可观测接入。

## 6. 发布与版本 <a id="release"></a>

- **语义化版本**：插件遵循 SemVer；破坏性变更升主版本（见 [13 第三方插件生态](13_插件化架构_第三方插件生态.md)）。
- **契约版本**：声明 `contract_version` 与适配的平台版本范围，装配时校验，不匹配跳过并告警。
- **登记要素**：能力名、`plugin_name`、依赖、错误码段（若涉及）、事件域（若涉及）须登记，冲突在 CI 拒绝。
- **发布渠道**：走受控索引/仓库；生产只加载受控来源（第三方见 [13 第三方插件生态](13_插件化架构_第三方插件生态.md)）。
- **下线**：能力下线走变更流程（公告 + 替代 + 过渡期），不静默移除（对齐平台契约承诺口径）。

## 7. 常见问题与注意事项 <a id="pitfalls"></a>

- **直接 `import` 具体实现**：业务代码绕过基类与提供者，换实现即全库改；只认基类 + `get_xxx`。
- **发现即执行**：模块导入期建连接/起线程；初始化放生命周期钩子（见 [12 生命周期与热插拔](12_插件化架构_生命周期与热插拔.md)）。
- **未声明依赖**：实现依赖外部组件却未登记，装配期才发现；依赖写进插件元数据与配置。
- **忽略异步语义**：异步栈里放同步阻塞方法；涉及 I/O 一律 `async`。
- **不写契约测试**：换实现靠手工点；继承契约测试基类即可全覆盖。
- **命名冲突**：`plugin_key`/`plugin_name` 重名；注册唯一性校验必须生效。
- **密钥进代码/配置**：密钥只走 Secret；配置只放非敏感项。
- **版本不声明**：运行时才发现不兼容；`contract_version` 与兼容范围显式声明。
