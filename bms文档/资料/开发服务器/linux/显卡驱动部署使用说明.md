## 2. 现状 <a id="status"></a>

### 2.1 硬件与驱动模式 <a id="hw"></a>

- 双显卡：Intel UHD Graphics 630（核显，驱动内屏）+ NVIDIA GeForce GTX 1060 Mobile（独显）。
- PRIME 模式：`prime-select on-demand`（核显常显、独显按需）。
- 驱动来源：发行版预编译包 `nvidia-driver-580`（**非 DKMS**）；内核模块按内核版本分包 `linux-modules-nvidia-580-<内核版本>-generic`。

### 2.2 模块与内核对齐（关键）<a id="align"></a>

- 内核模块包的 postinst 要用**同版本内核头** `linux-headers-<内核版本>-generic`（含 `scripts/module.lds`）链接出 `nvidia.ko`；缺头会导致包配置失败，`nvidia.ko` 不生成。
- 内核升级时须同步安装对应的 `linux-modules-nvidia-580-<新内核版本>-generic`，否则重启进新内核后独显驱动不加载。

## 3. 检查方法 <a id="check"></a>

| 命令 | 用途 |
| --- | --- |
| `nvidia-smi` | 独显驱动版本、P 状态、功耗、温度 |
| `modinfo nvidia` | 当前内核能否加载 nvidia 模块（报 `Module nvidia not found` 即未就绪） |
| `cat /sys/bus/pci/devices/0000:01:00.0/power/control` | 独显运行时电源管理策略：`auto` 正常；`on` 为强制常开 |
| `sensors` | CPU、无线网卡、硬盘、PCH 温度 |
| `prime-select query` | PRIME 模式 |

## 4. 正常态基线 <a id="baseline"></a>

- 空闲 `P8`、功耗约 3–4 W、温度约 45–55 ℃、`power/control=auto`。超出（如 `P0` / 数十瓦 / `power/control=on`）即独显未进入低功耗态，通常伴随风扇长转。

## 5. 已知故障与修复 <a id="issues"></a>

### 5.1 unattended-upgrade 半途失败致驱动半坏 <a id="issue-unattended"></a>

- **现象**：独显常开高功耗、风扇不停；`nvidia-smi` 报无法与驱动通信；`dpkg -l` 见 `linux-modules-nvidia-580-<内核版本>-generic` 处于 `iF`（配置失败）。
- **根因**：`unattended-upgrade` 在缺运行内核 headers 的情况下配置 nvidia 模块包失败，`nvidia.ko` 未生成。
- **修复**（补头与对齐内核，最后重启生效）：

```bash
sudo apt-get update
sudo apt-get install -y linux-headers-$(uname -r)
sudo dpkg --configure -a
sudo apt-get dist-upgrade -y
sudo reboot
```

- **验证**：重启后 `nvidia-smi` 正常，空闲回到 `P8`、功耗数瓦。
