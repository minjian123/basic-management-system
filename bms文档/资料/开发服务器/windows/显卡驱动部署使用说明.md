# 显卡驱动部署使用说明

## 1. 目的与适用范围 <a id="purpose"></a>

记录 Windows 开发服务器 mjw 的显卡驱动现状、图形模式（MSHybrid）要求、驱动远程升级步骤与独显功耗判定口径。
`<mjw-IP>`、`<账号>` 取值见《[本地资源](../../../用户文档/本地资源.md)》（已 gitignore，不入库）。

## 2. 硬件与图形模式 <a id="hw"></a>

- 双显卡：Intel UHD Graphics（核显）+ NVIDIA GeForce RTX 3070 Laptop GPU 8 GB（独显）。
- **图形模式要求 MSHybrid（混合）**：由核显驱动内屏、独显按需休眠。
  - 若 BIOS 设为 **Discrete（独显直连）**，内屏常绑独显，独显空载也维持 `P0` 高功耗、风扇常转。
  - 模式在 BIOS 中设置，需在机器旁重启进 BIOS 修改，无法远程切换。
- 模式核对：`Win32_VideoController` 中带分辨率的适配器应为 **Intel UHD**；NVIDIA 不应是内屏输出方。

## 3. 驱动升级 <a id="driver"></a>

### 3.1 查询最新版本 <a id="lookup"></a>

NVIDIA 驱动查询接口（`psid=101` GeForce、`pfid=939` RTX 3070 Laptop GPU、`osID=135` Windows 11）：

```text
https://gfwsl.geforce.com/services_toolkit/services/com/nvidia/services/AjaxDriverService.php?func=DriverManualLookup&psid=101&pfid=939&osID=135&languageCode=1033&beta=0&isWHQL=1&dltype=-1&dch=1&upCRD=0&qnf=0&sort1=0&numberOfResults=5
```

返回 JSON 的 `downloadInfo.Version` / `DownloadURL` 即版本与直链。

### 3.2 下载 <a id="download"></a>

直链必须带浏览器 UA 与 Referer，否则 CDN 返回 **403**；国内改走 `.cn` 节点。

```powershell
$ua = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/140.0 Safari/537.36"
curl.exe -sSL -A $ua -e "https://www.nvidia.com/" `
  -o C:\Windows\Temp\nv-setup.exe `
  "https://cn.download.nvidia.cn/Windows/<版本>/<版本>-notebook-win10-win11-64bit-international-dch-whql.exe"
```

下载需在**同一次远程会话内同步完成**（`Start-Process` 脱离会话后进程会被回收，导致下载中断）。

### 3.3 静默安装 <a id="install"></a>

```powershell
C:\Windows\Temp\nv-setup.exe -s -noreboot -clean
```

- `-s` 静默、`-noreboot` 不自动重启、`-clean` 清理旧驱动配置；退出码 0 为成功（约 5 分钟）。
- 安装后 `PendingFileRenameOperations` 非空，需**重启**才完全生效。
- 安装包体积约 1 GB，装完建议删除。

## 4. 检查方法 <a id="check"></a>

| 命令 | 用途 |
| --- | --- |
| `nvidia-smi --query-gpu=driver_version,pstate,clocks.gr,power.draw,temperature.gpu --format=csv` | 驱动版本、P 状态、时钟、功耗、温度 |
| `nvidia-smi -q -d PERFORMANCE` | 空闲节流原因（`clocks_throttle_reasons.active`，`0x1` 含 `GpuIdle` 位即空闲） |
| `Get-CimInstance Win32_VideoController` | 核对内屏由哪块显卡驱动 |

> **该 vBIOS 的 `power.draw` 读数不可靠**（会偶发出现远超上限的离谱值），判定以温度与节流原因为准。

## 5. 远程升级实录 <a id="log"></a>

- 2026-09-28：驱动 **512.89 → 617.14**（2026-09-22 Game Ready，Notebook DCH）。签名校验（Authenticode）通过，静默安装退出码 0、耗时约 5 分钟，重启后 `nvidia-smi` 版本为 617.14。
- 同期将 BIOS 图形模式由 Discrete 改为 MSHybrid，内屏改由 Intel UHD 驱动，独显温度由约 52 ℃ 降至约 50 ℃。
